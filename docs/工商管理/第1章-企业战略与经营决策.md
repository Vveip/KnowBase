## 二、知识点精讲

### 考点1：企业战略概述（★★★）

**1. 核心概念**

- **企业战略特征**（3组）：全局性与复杂性；稳定性与动态性；收益性与风险性。
- **企业战略管理**：为实现企业的愿景、使命和战略目标，科学地分析企业的内外部环境，制定战略方案，评估、选择并实施战略方案，并进行战略控制的**动态管理过程**。
  - 主体是**企业战略管理者**（不是全体员工）。
  - 基本任务：实现**特定阶段的战略目标**；最高任务：实现**企业的使命**。口诀：**基本目标，最高使命**。

**2. 战略层次（三层）**

| 层次 | 别称 | 研究对象 | 核心要义 |
|---|---|---|---|
| 企业总体战略 | — | 企业整体 | 最高层次、最高行动纲领；决定和揭示企业的使命和目标 |
| 企业业务战略 | 竞争战略／事业部战略 | 某个特定经营单位 | 重点改进一个业务单位的**竞争地位** |
| 企业职能战略 | — | 生产、营销、财务、人力、研发等职能部门 | 解决**资源利用效率**问题，使资源利用效率最大化 |

总体战略的四类动作：①保持原有业务组合与资源分配方式，稳定经营；②进入新经营领域，提升发展速度；③抑制某些业务发展，防范风险；④退出某些关键业务，重新配置资源。**提示：业务组合的"变与不变"**。

**3. 战略制定三步骤**：确定企业愿景、使命与战略目标 → 准备战略方案 → 评价和选择战略方案。

**4. 愿景 / 使命 / 战略目标三者区别（必考）**

| 项目 | 回答的问题 | 含义要点 | 定位／制定者 | 内容构成 |
|---|---|---|---|---|
| 企业愿景 | **"企业将成为什么"** | 内部成员制定、团队讨论、达成共识、全力以赴的未来方向，表达奋斗的心愿 | 不专属于高层，**每位员工都应参与构思** | 核心信仰（长期不变的信条，"黏合剂"）＋未来前景 |
| 企业使命 | **"企业的业务是什么"** | 说明企业根本性质与存在理由、宗旨、经营哲学、信念、原则 | 三种定位：生存目的、经营哲学、企业形象 | 为战略目标确定与战略制定提供依据 |
| 企业战略目标 | — | 一定时期内沿其经营方向预期达到的**理想成果** | 将愿景与使命转化为具体业绩目标的过程 | 一般分为**盈利、服务、员工、社会责任**四方面 |

愿景管理三步骤：**开发愿景 → 瞄准愿景 → 落实愿景**。口诀：**愿景=心+景**。

> 原文实例：某高科技公司愿景——"成为最懂用户，并能帮助用户成长的全球顶级高科技公司"；某新能源汽车制造企业使命——"创造最具吸引力的电动汽车，推动全球向可持续能源转型"；某高新技术公司战略目标——2026年年底全球渠道收入达200亿美元。

**5. 战略实施**

- 实施步骤：**战略变化分析 → 战略方案分解与实施（时间和空间）→ 战略实施的考核与激励**（关键绩效指标法、平衡计分卡）。
- **战略实施5种模式**

| 模式 | 核心要点 | 记忆锚点 |
|---|---|---|
| 指挥型 | 如何制定一个**最佳的战略**，由高层决定并强制下级实施 | 高层说了算 |
| 变革型 | 高层制定战略的同时更关注**如何实施**，重视运用组织结构、激励手段和控制系统促进实施；适用于**环境确定性较大**的企业 | 既订战略又抓执行 |
| 合作型 | 把战略实施责任范围扩大到**其他层级管理者**，调动其积极性和创造性 | 大家一起担 |
| 文化型 | 力图使**所有员工**都参与到战略实施中 | 全员参与 |
| 增长型 | 战略从**基层单位自下而上**形成 | 自下而上 |

- **7S模型**：硬件要素＝**战略、结构、制度**；软件要素＝**共同价值观、人员、技能、风格**。软件口诀**"人观技风"**。

**6. 战略控制**

- 含义：战略管理者及参与战略的实施者根据战略目标和行动方案，对战略实施状况进行全面评审，及时发现并纠正偏差的活动。
- **原则（4项，口诀"一保三适"）**：确保目标原则；适度控制原则（严格但不乏弹性，切忌过度）；适时控制原则（掌握适当时机）；适应性原则（反映不同经营业务的性质和需要）。
- **流程**：制定绩效标准 → 衡量实际绩效 → 审查结果 → 采取纠偏措施。
- **方法（口诀"杜利平"）**：杜邦分析法（基于财务指标，适合**产品多样化的大企业**）；利润计划轮盘（利润轮盘、现金轮盘、净资产收益率轮盘）；平衡计分卡（**财务、顾客、内部流程、学习和创新**四角度，代表企业三个主要利益相关者：**股东、顾客、员工**；每个角度的重要程度取决于角度本身和指标选择与企业战略一致的程度）。

### 考点2：企业战略分析（★★★）

**1. 外部环境分析三层次**

| 层次 | 方法 |
|---|---|
| 宏观环境分析 | **PESTEL分析法**（一般环境，对一切行业部门和企业都产生影响） |
| 行业环境分析 | 行业生命周期、五力模型、战略群体分析 |
| 经营及竞争环境分析 | 外部因素评价矩阵（**EFE矩阵**） |

- **行业生命周期**：形成期（企业多、竞争压力小，"双小"；重研发与工程技术，营销侧重广告宣传）→ 成长期（产品完善、市场迅速扩大，"双迅速"；**市场营销和生产管理（提高质量、降低成本）**成为关键职能）→ 成熟期（市场趋于饱和、销售额难增且后期下降，竞争激烈、兼并合并大量出现、行业由分散走向集中；**成本控制和市场营销有效性**成为关键因素）→ 衰退期（市场萎缩、行业规模缩小，"双缩"；延续或消失）。
- **五力模型**：供应者谈判能力强的情形——供应者的行业由**少数企业控制**而购买方却很多；**没有替代品**；供应者能够进行**深加工而与买方竞争**；买方只购买供应者产品的一小部分。
- **战略群体**：一个行业内执行同样或相似战略并具有类似战略特征或地位的一组企业。
- **EFE矩阵**：列出关键因素（机会／威胁）→ 赋予权重（**0～1**）→ 评分（**1～4分**）→ 计算加权分数 → 加总。总加权分数范围**1～4分，平均2.5分**；**低于2.5分**反应程度较差，**高于2.5分**能做出较好反应。

**2. 内部环境分析（口诀"内心链波哦"）**：核心竞争力、价值链分析、波士顿矩阵、内部因素评价矩阵（IFE矩阵）、VRIO框架分析法。

- **核心竞争力**：企业能够长期获得竞争优势的能力，企业特有、经得起时间考验、具有延展性、竞争对手难以模仿的技术或能力。企业的可持续竞争优势依赖于企业拥有的资源和能力，管理者必须从企业内部寻找**有价值的、稀缺的、模仿成本高的**资源，然后组织开发利用，四个方面缺一不可。特征口诀**"价质延持难难"**：价值性、异质性、延展性、持久性、难以转移性、难以复制性。三个体现：
  - **关系竞争力**：产业发展状况、与相关企业的关系、活动与国家的关系、国际经济关系及经济社会政治环境；
  - **资源竞争力**：人力资源、原材料、土地、技术、资金、组织资源、区位优势、基础设施等；
  - **能力竞争力**：战略、体制、机制、经营管理、商业模式、团队默契、环境适应性、资源开发控制的能动性与创新性。
- **价值链**：基本活动（口诀**"供产储销后"**）＝原料供应、生产加工、成品储运、市场营销、售后服务；辅助活动＝采购、技术开发、人力资源管理、企业基础职能管理。
- **波士顿矩阵**：**瘦狗类**业务的特点是业务增长率和市场占有率均较低，理智的战略是**清算战略**，如有可能也可采取转向战略或放弃战略。
- **IFE矩阵**：关键因素分为**优势和劣势**；总加权分数1～4分、平均**2.5分**；低于2.5分内部状况**弱势**，高于2.5分为**强势**。
- **VRIO框架**（四角度缺一不可）：

| 角度 | 作用 | 回答的问题 |
|---|---|---|
| 价值性 Value | 对资源／能力贡献竞争优势的判断 | 能否使企业把握机会、增加价值或消除威胁？ |
| 稀缺性 Rareness | 获得竞争优势的**基础** | 有多少竞争企业已获得这类资源／能力？ |
| 不可模仿性 Inimitability | 拥有长久竞争优势的**保证** | 不具有该类资源的企业获取时是否付出很高成本？ |
| 组织性 Organization | 发挥协同作用 | 企业能否合理组织、充分开发利用？ |

**3. 综合环境分析**

- **SWOT**：内部S优势、W劣势；外部O机会、T威胁。SO使用优势利用机会；WO利用机会克服劣势；ST使用优势避免威胁；WT克服劣势避免威胁。
- **ESG**：环境维度（E，外部对企业的环境要求：气候变化影响、资源使用、污染与废物排放、对生物系统和多样性的影响）；社会维度（S，利益相关方对社会责任的要求：员工权益、消费者权益、产品责任、供应链社会责任、社区关系、公共利益）；公司治理维度（G，治理结构与合规运营的规范与期待：公司治理监管、关联交易合规、反贿赂反腐败、行业监管政策、信息披露、数据安全与治理）。三个意义：风险前置防控、深度挖掘机遇、强化战略韧性。

### 考点3：企业战略类型（★★★）

**1. 三种基本竞争战略对比（必考表格）**

| 维度 | 成本领先战略 | 差异化战略 | 集中战略 |
|---|---|---|---|
| 别称／定义 | 又称**低成本战略**，全部成本低于竞争对手甚至行业最低，核心是加强内部成本控制 | 通过提供与众不同的产品或服务，满足顾客特殊需求，形成独特竞争优势 | 又称**专一化战略**，把经营活动集中于某一特定购买群体、产品线某一部分或某一地区市场 |
| 适用范围 | 有规模效应或潜力；供应链整合与管控能力强；运营管理能力强；市场占有率高 | 研发能力强；知名度和美誉度高；市场营销能力强 | 有特殊需求的顾客；没有竞争对手在此目标市场；经营实力较弱；目标市场吸引力强 |
| 实施途径 | 发挥规模效应；技术优势；资源整合；经营地点优势；提高供应链整体效益；利用跨业务相互关系 | 产品差异化；技术差异化；品牌形象差异化；渠道差异化；服务差异化；员工差异化 | 产品系列；细分市场选择重点客户；市场细分选择重点区域；发挥优势集中经营 |
| 判断标准 | **单位成本＝总成本÷产量** | **与众不同** | **部分市场** |

记忆口诀：**集差本**。

**2. 成长战略（6种）**

- **密集型成长战略**

| 产品／服务＼市场 | 现有产品或服务 | 新产品或服务 |
|---|---|---|
| 现有市场 | **市场渗透战略** | **新产品开发战略**（产品上的扩展） |
| 新市场 | **市场开发战略** | — |

- **多元化战略**：又称多样化、多角化、多种经营战略，指一个企业同时在两个或两个以上领域中经营。**相关多元化战略**（关联多元化）指企业进入与现有产品或服务**有一定关联**的经营领域，进而实现规模扩张，包括**水平多元化**（同一专业范围内多种经营）、**垂直多元化**（沿产业价值链或企业价值链延伸经营领域）、**同心多元化**（以市场或技术为核心，如造船厂不景气时承接海洋工程、钢结构加工）；**非相关多元化**（无关联多元化）指进入与现有产品或服务在技术、市场等方面没有任何关联的新行业／新领域。
- **一体化战略**：又称企业整合战略，把相互联系密切的经营活动纳入企业体系，组成统一经济组织进行全盘控制和调配。**纵向一体化**含前向一体化（与**输出端／经销商**联合）和后向一体化（与**输入端／供应商**联合）；**横向一体化**是与**同行业企业**联合，当今合并与收购是其主要途径。
- **战略联盟**：两个或两个以上企业为实现资源共享、风险成本共担、优势互补等特定战略目标，在保持自身独立性同时，通过**股权参与或契约联结**建立较稳固合作伙伴关系，取得双赢或多赢。

| 类型 | 亚类 | 要点 | 判断标准 |
|---|---|---|---|
| 股权式战略联盟 | 合资 | 共同出资、共担风险、共享收益 | **股权和"钱"有关** |
| | 相互持股 | 各方持有对方一定数量股份 | |
| 契约式战略联盟 | 技术开发与研究联盟 | 大学、研究机构、企业联盟，成果共同享有 | |
| | 产品联盟 | 联合生产、贴牌生产、供求联盟、生产业务外包 | **和生产有关** |
| | 营销联盟 | 特许经营、连锁加盟、品牌营销、销售渠道共享 | **和销售有关** |
| | 产业协调联盟 | 建立全面协调分工的工业联盟体系，避免恶性竞争和资源浪费，多见于高新技术企业 | |

- **国际化经营战略**：讲义此处仅以"国际化经营战略的类型"图呈现，文字条目未在原材料中列出，故不展开（考试以教材图示为准）。
- **数字化战略**：以总体战略为指引、以数字技术为核心驱动力、以数据为核心生产要素，系统性重塑客户价值主张、优化运营模式、全面提升核心能力的**前瞻性发展战略**。核心目标：创造全新价值增长点、培育创新商业模式、升级全流程客户体验。五个维度：**业务**（核心业务数字化、业务模式创新、客户体验升级）、**技术**（云计算、人工智能、物联网、区块链）、**组织**（设立数字化专项部门或跨职能项目组织，培育数据驱动、快速试错、持续创新的文化）、**数据**（激活数据资产价值）、**生态**（与利益相关者协同共赢）。五个阶段：战略规划→方案设计→落地实施→运营优化→创新拓展。

**3. 稳定战略（4种）与紧缩战略（3种）**

| 类型 | 亚类 | 核心要点 |
|---|---|---|
| 稳定战略 | 无变化战略 | 战略目标、方向、规划等基本保持不变，保持现有市场地位、利润及平衡发展 |
| | 维持利润战略 | 注重短期效果忽略长期利益，渡过暂时性难关，经济形势不景气时采用 |
| | 暂停战略 | 快速发展后遇问题，一段时间内降低目标和发展速度，重新调整内部要素、优化资源配置 |
| | 谨慎实施战略 | 外部某重要因素变化趋势不明显又难以预测，放缓方案实施进度，谨慎实施或调整 |
| 紧缩战略 | 转向战略 | ①不能维持原有产销规模和市场规模，不得不缩小；②有新机会，压缩原有领域投资为其他业务提供资金；③财务状况下降时采取**抽资转向战略** |
| | 放弃战略 | 将一个或几个部门（经营单位、一条生产线、一个事业部）转让、出卖或停止经营 |
| | 清算战略 | 卖掉资产或停止整个企业运行，终止企业存在 |

提示：**放弃一部分，清算整个企业**。

### 考点4：企业经营决策与商业模式分析（★★★）

**1. 经营决策概念与类型**

- 概念：通过内部条件和外部环境的调查研究、综合分析，运用科学的方法选择合理方案，实现企业经营目标的整个过程。包含三方面内容：①决策要有**明确的目标**；②决策要有**多个可行方案**供选择；③决策是建立在**调查研究、综合分析、评价和选择**基础上的。

| 分类标准 | 类型 |
|---|---|
| 决策影响的时间长短 | 长期决策、短期决策 |
| 决策的重要性 | **总体层、业务层、职能层**经营决策 |
| 环境因素的可控程度 | 确定型、风险型、**不确定型**决策 |
| 决策目标的数量 | 单目标决策、多目标决策 |

**2. 经营决策五要素**：决策者（主体，最基本要素）、决策目标（确立科学决策的**起点**）、决策备选方案（**存在是决策的前提**）、决策条件（决策环境）、决策结果（决策实施后产生的效果和影响）。

**3. 决策流程五阶段**：确定目标阶段（**前提**，要符合SMART原则）→ 拟订方案阶段（**基础**）→ 选定方案阶段（**最关键的一步**）→ 方案实施和监督阶段（按计划逐步推进并保证弹性；确定执行责任人；建立信息沟通系统；具有监督控制环节）→ 评价阶段。

- **SMART原则**：S具体（清晰明确不模棱两可）、M可量化（能准确衡量）、A可实现（有挑战性同时可实现）、R相关（与企业其他目标相关、互相支撑）、T时限（有明确截止期限）。同时决策目标要有**具体、明确的责任人**，不落实责任人，目标很难得以实现。

**4. 决策方法**

| 大类 | 具体方法 |
|---|---|
| **定性决策法**<br>（主观决策法，直接利用人们的知识、智慧和经验，对决策内容进行非量化的分析和研究，对方案进行评价和择优） | 头脑风暴法、德尔菲法、名义小组法、哥顿法 |
| **定量决策法** | 确定型：**线性规划法、盈亏平衡点法**；风险型：期望损益决策法、决策树法；不确定型：乐观、悲观、折中、后悔值、等概率五原则 |

四种定性决策法辨析：
- **头脑风暴法**：特点是"**敞开思路，畅所欲言**"。
- **德尔菲法**：又称专家调查法，以匿名方式通过几轮函询征求专家意见，预测组织小组对每轮意见汇总整理后作为参考再发给各专家，供其分析判断、提出新的论证，几轮函询后专家意见趋于一致，最后供决策者决策。关键在于**选择好专家、专家人数10～30人、拟好意见征询表**。
- **名义小组法**：特点是"**背靠背，独立思考**"。
- **哥顿法**：又称提喻法，由会议主持人带领进行集体讨论。不让与会者直接讨论问题本身，而只讨论问题的某一局部或某一侧面，或讨论与问题相似的某一问题，或用"抽象的阶梯"把问题抽象化向与会者提出，然后一步步引导到问题本身上来。**先抽象后具体**；优点是有利于减少束缚、产生创造性想法，难点在于主持者如何引导。
- **盈亏平衡点法**：又称**量本利分析法或保本分析法**，是进行产量决策常用的方法；基本特点是把成本分为固定成本和可变成本两部分，然后与总收益进行对比，以确定盈亏平衡时的产量或某一盈利水平的产量。
- **期望损益决策法**：已知方案所需条件，每种方案执行可能出现不同后果，多种后果的出现有一定概率，即存在风险。

**5. 不确定型决策五原则对比（必考表格）**

适用前提：决策所面临的市场状态难以确定，且各种市场状态发生的概率也无法预测（"一问两不知"）。

| 原则 | 取舍标准 | 通俗口诀 | 数学操作 |
|---|---|---|---|
| 乐观原则 | 以各方案在各种状态下的**最大期望损益值**为标准（假定最有利状态发生），在各方案最大值中取最大 | **大中取大** | max(max损益) |
| 悲观原则 | 以每个方案在各种状态下的**最小值**为标准（假定最不利状态发生），再从各方案最小值中取最大 | **小中取大** | max(min损益) |
| 折中原则 | 既非完全保守也非极端冒险，在介于两个极端的某一位置寻找方案 | α加权 | 加权平均值＝最大值×α＋最小值×(1−α)，α为乐观系数，**0＜α＜1** |
| 后悔值原则 | 先算损益值的后悔值矩阵，从各方案中选取最大后悔值，再在已选出的最大后悔值中取最小 | **因为对比，所以后悔；大中取小** | 后悔值＝该市场状态下最大损益值−该状态某方案对应损益值 |
| 等概率原则 | 无法确定某种市场状态发生的可能性大小及其顺序时，假定每一市场状态具有相等概率 | **等概率，求均值** | 平均值＝∑(损益值×1/n)；利润最大化取平均利润最大，成本最小化取平均成本最小 |

**6. 商业模式**

- 概念：为实现客户价值最大化，企业整合内外部生产要素、搭建业务体系、推动建立合作伙伴关系，形成的具有独特核心竞争力的高效运行系统，通过最优实现形式满足客户需求，实现长期可持续盈利。它是一个**整体的、系统的概念**，既包括企业外部的客户价值实现模式、商业合作模式、投融资模式，也包括企业内部的生产模式、运营模式和盈利模式等。
- 三个具体表现：**价值发现**（洞悉客户需求，发现市场潜在盈利点，**逻辑起点**）→ **价值匹配**（通过资源配置和商业运营向客户交付价值，**逻辑中介**）→ **价值获取**（通过特定盈利模式持续获取利润，**逻辑终点**）。
- 五个特点：创造独特的价值；整合性和系统性；难以模仿；具有抵御风险的能力；可操作性强。
- 要素：**企业定位（第一要素）**、资源与能力、**业务系统（商业模式的核心）**、盈利模式、现金流结构、企业价值。
- **商业模式画布**（3个步骤9个模块）：价值分析（价值主张、细分客户、渠道通路、客户关系）＋基础设施分析（核心资源、关键业务、重要伙伴）＋盈利分析（收入来源、成本结构）。

## 四、公式与计算

**公式1（风险型）**：期望损益值 ＝ ∑(损益值 × 对应概率值)

**演算例题1**：市场状态为畅销（0.3）、平销（0.5）、滞销（0.2），三方案损益值如下（单位：万元），按期望损益决策法选优。

| 方案 | 畅销0.3 | 平销0.5 | 滞销0.2 | 期望损益值 |
|---|---|---|---|---|
| 大批量 | 4000 | 2800 | 2000 | 4000×0.3＋2800×0.5＋2000×0.2＝1200＋1400＋400＝**3000** |
| 中批量 | 3600 | 3600 | 2400 | 3600×0.3＋3600×0.5＋2400×0.2＝1080＋1800＋480＝**3360** |
| 小批量 | 2800 | 2800 | 2800 | 2800×0.3＋2800×0.5＋2800×0.2＝840＋1400＋560＝**2800** |

结论：期望损益值最大为**3360**，选**中批量**方案。

**公式2（不确定型·折中原则）**：加权平均值 ＝ 最大值 × α ＋ 最小值 × (1−α)，0＜α＜1
**公式3（不确定型·后悔值原则）**：后悔值 ＝ 该市场状态下最大损益值 − 该状态某方案对应损益值
**公式4（不确定型·等概率原则）**：平均值 ＝ ∑(损益值 × 1/n)

**演算例题2（五原则综合，重点掌握）**：某企业有4个方案，各方案在不同市场状态下的损益值如下（单位：万元），请分别按五种原则选优。

| 方案 | 畅销 | 平销 | 滞销 |
|---|---|---|---|
| 甲 | 60 | 40 | 10 |
| 乙 | 75 | 55 | 30 |
| 丙 | 80 | 35 | −20 |
| 丁 | 100 | 50 | −30 |

| 原则 | 计算过程 | 结果 |
|---|---|---|
| 乐观（大中取大） | 各方案最大值：甲60、乙75、丙80、丁100 → 取最大 | **丁** |
| 悲观（小中取大） | 各方案最小值：甲10、乙30、丙−20、丁−30 → 取最大30 | **乙** |
| 折中（设α＝0.7） | 甲60×0.7＋10×0.3＝45；乙75×0.7＋30×0.3＝61.5；丙80×0.7＋(−20)×0.3＝50；丁100×0.7＋(−30)×0.3＝61 → 取最大61.5 | **乙** |
| 后悔值（大中取小） | 后悔值矩阵：畅销列（最大100）→甲40、乙25、丙20、丁0；平销列（最大55）→甲15、乙0、丙20、丁5；滞销列（最大30）→甲20、乙0、丙50、丁60。各方案最大后悔值：甲40、乙25、丙50、丁60 → 取最小25 | **乙** |
| 等概率（求均值） | 甲(60＋40＋10)/3≈36.67；乙(75＋55＋30)/3≈53.33；丙(80＋35−20)/3≈31.67；丁(100＋50−30)/3＝40 → 取最大53.33 | **乙** |

**结论记忆**：乐观原则选**丁**，其余四种原则均选**乙**。考试时先看原则再定方法，"一问两不知"才用这五个原则。

## 五、高频考点速记卡

1. **问：企业战略管理的主体是谁？** 答：企业战略管理者，不是全体员工。
2. **问：战略管理的基本任务和最高任务？** 答：基本任务实现特定阶段战略目标；最高任务实现企业使命。
3. **问：愿景、使命分别回答什么问题？** 答：愿景答"企业将成为什么"，使命答"企业的业务是什么"。
4. **问：战略目标一般包括哪四个方面？** 答：盈利、服务、员工、社会责任。
5. **问：愿景管理三步骤？** 答：开发愿景→瞄准愿景→落实愿景。
6. **问：变革型模式的适用条件？** 答：适用于环境确定性较大的企业。
7. **问：7S模型哪些是硬件、哪些是软件？** 答：硬件＝战略、结构、制度；软件＝共同价值观、人员、技能、风格。
8. **问：战略控制四原则口诀？** 答："一保三适"——确保目标、适度、适时、适应。
9. **问：战略控制流程？** 答：制定绩效标准→衡量实际绩效→审查结果→采取纠偏措施。
10. **问：平衡计分卡四个角度？** 答：财务、顾客、内部流程、学习和创新。
11. **问：EFE／IFE矩阵的权重、评分与分界线？** 答：权重0～1，评分1～4分，总加权分平均2.5分，高于2.5分为好（强）。
12. **问：德尔菲法的专家人数与关键？** 答：一般10～30人；关键在于选好专家、决定适当人数、拟好意见征询表。
13. **问：VRIO中"不可模仿性"的作用？** 答：企业拥有长久竞争优势的保证。
14. **问：价值链基本活动口诀？** 答："供产储销后"——原料供应、生产加工、成品储运、市场营销、售后服务。
15. **问：核心竞争力特征口诀？** 答："价质延持难难"。
16. **问：成本领先战略的判断标准？** 答：单位成本＝总成本÷产量。
17. **问：三种基本竞争战略口诀？** 答："集差本"——集中、差异化、成本领先。
18. **问：密集型成长战略有哪四种？** 答：市场渗透、市场开发、新产品开发（"新产品×新市场"组合不存在）。
19. **问：前向／后向一体化的联合对象？** 答：前向联合输出端（经销商），后向联合输入端（供应商）。
20. **问：契约式战略联盟的判断口诀？** 答：产品联盟和生产有关，营销联盟和销售有关。
21. **问：稳定战略有哪4种？** 答：无变化、维持利润、暂停、谨慎实施战略。
22. **问：放弃战略与清算战略的区别？** 答：放弃是转让／出卖／停止一个或几个部门；清算是卖掉资产或停止整个企业运行。
23. **问：决策流程中最关键的一步？** 答：选定方案阶段。
24. **问：SMART原则五个字母含义？** 答：具体、可量化、可实现、相关、有时限；决策目标还要有具体、明确的责任人。
25. **问：商业模式的第一要素、核心与画布模块数？** 答：企业定位是第一要素，业务系统是核心；画布为3个步骤9个模块。

## 七、易错点与避坑指南

1. **错把"愿景"和"使命"答反**。愿景答"企业将成为什么"（员工广泛参与制定，含核心信仰＋未来前景），使命答"企业的业务是什么"（三种定位：生存目的、经营哲学、企业形象）。**记法**：愿景＝"心+景"（未来的样子），使命＝"业务是什么"。
   > 注：题库第7题解析中出现"企业愿景回答的是'我是谁'"的表述，与冲刺讲义"企业将成为什么"不一致；按写作规范以**讲义口径**为准。

2. **混淆7S软硬件要素**。战略、结构、制度是**硬件**；共同价值观、人员、技能、风格是**软件**。**记法**：软件口诀"人观技风"，剩下三个就是硬件。

3. **把EFE矩阵和IFE矩阵混用**。EFE分析外部（机会／威胁），IFE分析内部（优势／劣势），两者权重均为0～1、评分均为1～4分、平均分均为**2.5分**。**记法**：E=External外部，I=Internal内部。

4. **五种战略实施模式张冠李戴**。"高层强制下级"是指挥型，"自下而上从基层形成"是增长型，"所有员工参与"是文化型，"责任扩大到其他层级管理者"是合作型。**记法**：题干出现"基层／自下而上"只选增长型。

5. **放弃战略≠清算战略**。放弃是转让、出卖或停止**一个或几个部门**（经营单位／生产线／事业部）；清算是卖掉资产或停止**整个企业**运行。**记法**：放弃一部分，清算整个企业。

6. **前向／后向一体化方向搞反**。前向＝向输出端（经销商／下游）联合；后向＝向输入端（供应商／上游）联合。**记法**："前"销"后"供。

7. **不确定型五原则选错方法**。有概率是风险型（期望损益法），"一问两不知"（状态难定、概率难测）才用五原则。**记法**：乐观"大中取大"、悲观"小中取大"、折中"α加权"、后悔值"大中取小"、等概率"求均值"。

8. **多元化与一体化辨析错误**。先看是否**跨行业**：不跨行业只沿价值链或同行业联合，是一体化；跨行业且与现有技术／市场**无关联**，是非相关多元化。**记法**：房地产做教育→跨行业且无关联→非相关多元化。
