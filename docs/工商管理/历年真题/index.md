## 使用建议

1. **真题最大的价值不是「押题」**，而是帮你适应「错选不得分、少选得 0.5 分」的规则，形成稳定的选项策略；
2. 每套真题至少做两遍：第一遍限时模考，第二遍逐题讲出「为什么选它、为什么不选别的」；
3. 错题按**考点**归类而非按年份归类，后期复盘才能定位到具体得分点；
4. 近年考点分布可对照 [2026年真题速攻考点归纳](/工商管理/2026年真题速攻考点归纳) 交叉验证。
