## 二、知识点精讲

### 考点1：人力资源规划的分类（★★）
1. **核心概念**：企业人力资源规划可按不同标准划分为不同类型，分类标准是高频命题点。
2. **要点展开**（四种划分标准必须与划分结果一一对应）：

| 划分标准 | 规划类型 |
|---|---|
| 按规划的**性质** | **总体规划**和**具体计划** |
| 按规划**时间的长短** | 短期规划、中期规划、长期规划 |
| 按规划的**主体** | 企业规划、部门规划 |
| 按规划的**职能** | 招聘规划、培训规划等各类专项计划 |

3. **记忆提示/口诀**：「性质总体与具体，时间短中长，主体企业和部门，职能招聘培训薪酬」。

### 考点2：人力资源规划的信息基础（★★★）
1. **核心概念**：制定人力资源规划需先收集人力资源信息，再分析企业经营战略对人力资源的要求。
2. **要点展开**：人力资源信息分为**企业内部信息**和**外部环境信息**两大类。**外部环境信息是企业制定人力资源规划的「硬约束」**，企业制定的任何政策和措施均应与之相适应，否则会影响规划的有效性。

| 类别 | 具体内容 |
|---|---|
| 企业内部信息 | 企业发展战略、经营计划、人力资源现状（包括员工数量和构成、**员工使用情况**、教育培训情况、**离职率和流动性**等） |
| 外部环境信息 | 宏观经济形势和行业经济形势、技术发展趋势、产品市场竞争状况、劳动力市场供求状况、人口和社会发展趋势、政府管制/政府政策等 |

3. **记忆提示/口诀**：内部＝「战略+计划+现状」，外部＝「宏观+技术+竞争+劳动力+人口+政府」。判断技巧：凡超出企业边界、企业无法左右的信息即为外部信息。

### 考点3：人力资源的具体规划——劳动关系计划（★★）
1. **核心概念**：人力资源的具体规划含人员补充、劳动关系等专项计划，各有其追求目标（真题直接考查）。
2. **要点展开**（劳动关系计划，真题直接考查）：
   - **目标**：**降低非期望离职率、改善劳动关系、减少投诉和争议**等；
   - **政策**：依法管理、参与管理、加强沟通；
   - **预算**：相关工作费用和法律诉讼费。
3. **分类/对比**（由真题干扰项反推的其他计划目标）：

| 具体计划 | 追求的目标 |
|---|---|
| 劳动关系计划 | 降低非期望离职率、改善劳动关系、减少投诉和争议 |
| 人员补充（招聘）计划 | 明确补充人员的**数量、类型、层次**，优化人员结构 |
| 人员接续/晋升计划 | 确定**后备人员数量**，优化人员结构，提高绩效目标 |
| 人力资源总体规划层面 | 劳动供给增加、士气提高、绩效改善 |

### 考点4：人力资源需求预测方法（★★★）
1. **核心概念**：预测未来一定时期内企业所需人力资源的数量、质量和结构。
2. **要点展开**：

| 方法 | 关键特征 | 备注 |
|---|---|---|
| **管理人员判断法** | 由企业各级管理人员根据自己工作中的经验和对企业未来业务量增减情况的直觉考虑，**自下而上**确定未来所需人员；方法**粗略、简便易行** | **主要适用于短期预测**（真题答案） |
| **德尔菲法** | 专家匿名、多轮反馈的定性方法；与**头脑风暴法、名义小组技术、哥顿法**并列为定性决策方法 | 真题干扰项 |
| **转换比率分析法** | 原材料仅列为选项，未展开 | 真题干扰项 |
| **一元回归分析法** | 原材料仅列为选项，未展开 | 真题干扰项 |

3. **记忆提示/口诀**：「短期预测找管理人员的直觉」——题干出现「短期」「简便易行」「自下而上」即可锁定管理人员判断法。

### 考点5：人力资源供给预测方法（★★★）
1. **核心概念**：预测未来一定时期内企业内部和外部可提供给企业的人力资源。
2. **要点展开**：

| 方法 | 关键特征 |
|---|---|
| **马尔可夫模型法** | 用来预测具有**时间间隔（如一年）**的时间点上各类人员分布状况的方法。第一步是做一个**人员变动矩阵表**，表中每一个元素表示从一个时期到另一个时期在两个职务之间员工**调动数量的历年平均百分比（以小数表示）**，即一种职务的人员**变动概率**；可描述员工**流入、流出和内部流动**的整体情况 |
| **管理人员接续计划法** | 原材料列为供给预测方法选项，未展开 | 真题干扰项 |
| **时间序列分析法** | 原材料列为供给预测方法选项，未展开 | 真题干扰项 |

3. **记忆提示/口诀**：题干出现「人员变动矩阵」「流入、流出和内部流动」「历年平均百分比」→ **马尔可夫模型法**。

### 考点6：外部人力资源供给的影响因素（★★）
1. **核心概念**：企业外部人力资源供给受多种因素影响，直接影响招聘工作的难易。
2. **要点展开**（影响因素共六项）：**本地区人口总量与人力资源供给率**、**本地区人力资源的总体构成**、**宏观经济形势和失业率预期**、**本地区劳动力市场供求状况**、**本行业劳动力市场供求状况**、**职业市场状况**。
3. **易混点**：题干强调「**企业所在地区**的劳动力市场供求状况会对企业**招聘**人力资源产生重要影响」→ 选**本地区劳动力市场供求状况**。在我国，可参考各地人力资源和社会保障部门、规划部门以及行业管理部门等公布的统计资料。
4. **关于「招聘渠道」的说明**：本章原材料（题库与真题解析）中未出现**内部招聘渠道与外部招聘渠道的对比内容**，为避免臆造，本笔记不列对比表。可确定的关联考点仅有两处：一是人力资源规划**按职能划分**包含**招聘规划、培训规划**等；二是人员补充（招聘）计划的目标是明确补充人员的**数量、类型、层次**，优化人员结构。渠道分类（如内部晋升/推荐、外部招聘会/网络/校园/猎头等）请结合教材「员工招聘与甄选」一节补充。

### 考点7：绩效的特点与绩效考核的内容（★★）
1. **核心概念**：绩效作为一种工作结果和工作行为，具有三个基本特点。
2. **要点展开**：

| 特点 | 含义 |
|---|---|
| **多因性** | 员工个人绩效的优劣及形成是**多种因素综合作用**的结果，而不是由某个单一的因素能够决定的 |
| **多维性** | 员工个人的绩效往往是从**多方面**体现的，因此必须从多维度或多方面分析考查员工的工作绩效 |
| **变动性** | 员工个人的绩效不是固定不变的，随着时间的推移和主客观条件的变化，绩效也会发生变化，因而用**变化发展的观点**看待绩效问题 |

3. **绩效考核的内容**：绩效考核内容是对企业员工工作任务的界定，明确回答了企业员工在绩效考核期内**应该完成什么样的工作**，具体包括**绩效考核项目**和**绩效考核指标**两个部分。
4. **记忆提示/口诀**：绩效三特点＝「多因、多维、变动」；干扰项「收益性」「可靠性」均为杜撰。

### 考点8：绩效考核的功能（★★★）
1. **核心概念**：作为人力资源管理的一项重要职能，绩效考核具有**六项**功能。
2. **要点展开**：**① 管理功能；② 激励功能；③ 学习和导向功能；④ 沟通功能；⑤ 监控功能；⑥ 增进绩效的功能**。（「审核功能」为常见干扰项）
3. **重点辨析——增进绩效的功能**，主要表现在两个方面：
   - 首先，绩效考核在企业内创造了一种**优胜劣汰的压力环境**，必然会强化企业员工的**竞争意识和自强意识**，促使其设法提高自己的知识、技能及综合素质，努力工作，从而提高工作效率；
   - 其次，绩效考核将**员工个人的发展目标和企业的发展目标结合与统一起来**，也必然对企业整体绩效的提高发挥积极的作用。
4. **记忆提示/口诀**：「管激学沟监增进」——六字谐音串记。

### 考点9：绩效考核的流程（步骤）（★★★）
1. **核心概念**：绩效考核流程分为**四个步骤**，各阶段任务必须严格区分。
2. **要点展开**：

| 阶段 | 主要工作 |
|---|---|
| ① 绩效考核的**准备阶段**（技术准备） | **选择考核者、明确考核标准、确定考核方法** |
| ② 绩效考核的**实施阶段** | **绩效沟通、绩效考核评价** |
| ③ 绩效考核**结果的反馈** | 上级领导就绩效考核的结果与考核对象沟通，具体指出被考核者在绩效方面存在的问题，**指导制订出绩效改进的计划**，还要对该计划的执行情况进行跟踪并给予指导 |
| ④ 绩效考核**结果的运用** | 最后一个步骤，将考核结果用于薪酬调整、晋升、培训等 |

3. **记忆提示/口诀**：「准备三件事（选人、定标、定法）→ 实施两件事（沟通、评价）→ 反馈改计划 → 运用是终点」。题干出现「制订绩效改进计划」→ **结果反馈阶段**。

### 考点10：绩效考核的方法（★★★）
1. **核心概念**：方法辨识是本章最热的考点，须抓住各方法的关键词。
2. **要点展开**：

| 方法 | 关键特征 | 适用/备注 |
|---|---|---|
| **评级量表法** | 把绩效考核的指标和标准制作成量表，据量表对考核对象的工作绩效进行考核；通常设**优秀、良好、合格、基本合格、差 5 个等级**，每一等级对应相应分数 | 最常用、最基础 |
| **行为锚定评价法** | 量表上的**每个分数刻度都对应一些典型行为的描述性文字说明**，供考核者打分时参考；本质是把**评级量表法与关键事件记录法结合起来，取二者之所长** | 辨识点＝「分数刻度+典型行为描述」 |
| **关键事件法** | 记录员工工作中特别有效或特别无效的关键行为事件 | 与行为锚定法易混 |
| **书面鉴定法**（叙述法） | 以文字描述形式对考核对象作出定性评价 | 也称叙述法 |
| **民主评议法** | 由多人共同参与评价 | 常用于中层/管理者考核 |
| **平衡计分卡** | 从多维度综合衡量绩效 | — |
| **比较法** | 员工之间相互比较排序 | — |

3. **对比提示**：**职位分类法、职位等级法属于基本薪酬制度设计方法**，不是绩效考核方法（真题直接作为干扰项出现）。
4. **记忆提示/口诀**：「评级给等级，锚定给描述，关键记事件，书面写评语」。

### 考点11：薪酬的构成（★★★）
1. **核心概念**：在企业中，员工的薪酬一般由**三个部分**构成：**基本薪酬、激励薪酬、间接薪酬**。
2. **要点展开**：

| 构成 | 含义 | 与绩效的关系 |
|---|---|---|
| **基本薪酬** | 员工薪酬的基础部分 | 相对稳定 |
| **激励薪酬** | 与绩效直接挂钩的变动部分（奖金、绩效工资、计件工资、股票期权等） | **直接挂钩** |
| **间接薪酬** | 企业给员工提供的**各种福利** | **与员工个人的工作和绩效没有直接的关系，往往都具有普遍性，通俗地讲就是「人人都有份」** |

3. **记忆提示/口诀**：「基本打底、激励看绩效、间接人人有份」。企业为员工缴纳的**社会保险费属于间接薪酬**（国家法定福利）。

### 考点12：薪酬制度设计的原则（★★★）
1. **核心概念**：企业设计薪酬制度时应遵循的基本原则，每项原则都有明确的判断关键词。
2. **要点展开**：

| 原则 | 核心含义 | 题干关键词 |
|---|---|---|
| **公平原则** | 企业向员工提供的薪酬应该与员工对企业的贡献保持平衡。包括三个层次：**内部公平**（企业内部不同职位之间）、**外部公平**（同一行业或同一地区或同等规模企业中类似职务的薪酬水平应当基本相同）、**员工个人公平**（同一企业中相同贡献的员工） | 「同一行业/同一地区/同等规模企业中类似职务」→ **外部公平** |
| **竞争原则** | 应**高于**同一地区或同一行业其他企业同种职位的薪酬标准，以使自己的企业具有吸引力和竞争力 | 「定得比同行业其他企业高」「吸引优秀人才」 |
| **激励原则** | 企业内部各类、各级职位之间的薪酬标准要**适当拉开距离**，避免平均化，利用薪酬的激励功能提高员工的工作积极性 | 「拉开距离」「避免平均化」 |
| **合法原则** | 应遵循国家有关法律法规和政策的要求，做到合法合理付酬 | 「法律法规」 |
| **量力而行原则** | 应考虑自身的**经济实力**，避免薪酬过高造成企业成本过高，也避免过低造成企业缺乏竞争力和吸引力 | 「考虑自身经济实力」 |

### 考点13：福利与直接薪酬的差异（★★★）
1. **核心概念**：福利是企业支付给员工的**间接薪酬**，与直接薪酬相比既有独特优势，也存在问题。
2. **要点展开**：

| 比较维度 | 福利（间接薪酬） | 直接薪酬（基本薪酬+激励薪酬） |
|---|---|---|
| 形式 | **形式灵活多样**，可以满足员工不同的需要 | 形式相对固定 |
| 与绩效的关联 | 具有**普遍性**，与员工个人绩效**并没有太大的直接联系** | 与绩效直接相关 |
| 对绩效的作用 | **提高员工工作绩效方面的效果不如直接薪酬那么明显**（这是福利最主要的问题） | 激励直接、见效快 |
| 性质 | 具有典型的**保健性质**，可以减少员工的不满意，有助于吸引和留住员工，增强企业的凝聚力 | 兼具保健与激励 |
| 税收 | 具有**税收方面的优惠**，可以使员工得到更多的实际收入 | 一般需纳税 |
| 规模效应 | 由企业**集体购买**某种福利产品，具有规模效应，可以为员工节省一定的支出 | 无此特点 |
| 刚性 | 具有**刚性**，一旦提供了某种福利就很难取消，会导致**福利支出不断膨胀**，从而增加企业的负担 | 可随绩效浮动 |

3. **记忆提示/口诀**：福利「四优两缺」——优在灵活、保健、税收、规模；缺在绩效激励不明显、支出刚性膨胀。

### 考点14：福利的内容（★★★）
1. **核心概念**：福利包括**国家法定的福利**和**企业自主的福利**两大类。
2. **要点展开**：

| 类别 | 具体项目 |
|---|---|
| **国家法定福利** | 公休假日、**带薪休假**、**住房公积金**、**社会保险**（企业为员工缴纳的社会保险费属于此类） |
| **企业自主福利** | **员工退休计划、儿童看护、老人护理**等 |

3. **记忆提示/口诀**：「法定：假、公积金、社保；自主：退休、看护（儿童/老人）」。真题常以「下列不属于企业自主福利的是」形式命题，答案为**带薪休假**（属国家法定福利）。

### 考点15：激励薪酬（★★★）
1. **核心概念**：激励薪酬按激励对象分为**个人激励薪酬**和**群体激励薪酬**两类。
2. **要点展开**：

| 类别 | 形式 | 含义/要点 |
|---|---|---|
| **个人激励薪酬** | **计件制** | 按产出数量计酬 |
| | **工时制** | 根据员工**完成工作的时间**来向员工支付相应的薪酬 |
| | **绩效工资** | 包括：① **绩效调薪**（根据员工的绩效考核结果对其**基本薪酬**进行调整，考核优秀者薪酬等级上调一级，基本合格以下者下调一级）；② **绩效奖金**（员工达到某一规定的绩效而进行激励、表彰而发放的奖金）；③ **月/季度浮动薪酬**；④ **特殊绩效认可计划**（在个人或部门**远远超出工作要求**，表现出特别的努力而且实现了优秀的绩效或做出了重大贡献的情况下，组织**额外给予**的一种奖励与认可） |
| **群体激励薪酬** | **利润分享计划** | 用**盈利状况的变化**来对整个企业的业绩进行衡量，把**超过目标利润的部分在企业全体员工之间**进行分配的制度 |
| | **收益分享计划** | 企业提供的一种与员工**分享因生产率提高、成本节约和质量提高等而带来的收益**的绩效奖励模式 |
| | **员工持股计划** | 企业向内部员工提供公司股票的所有权计划，是**利润分享的重要形式**；**股票期权**是其中一种重要表现形式 |

3. **对比提示**：**住房公积金、带薪休假、保险福利属于间接薪酬（福利）**，不是激励薪酬。
4. **记忆提示/口诀**：「个人：计件、工时、绩效工资；群体：利润、收益、员工持股」。

### 考点16：基本薪酬制度设计方法（★★★）
1. **核心概念**：基本薪酬制度设计方法分为**以职位为导向**、**以技能为基础**、**以知识为基础**三类。
2. **要点展开**：

| 类别 | 方法 | 关键特征 |
|---|---|---|
| **以职位为导向** | **职位等级法** | 原材料仅列名，未展开 |
| | **职位分类法** | 将企业中的所有职位划分为若干类型，如**管理类、技术类、操作类（或生产类）、财务类、营销类、行政类**等职位类型，然后根据各类职位对企业的**重要程度和贡献**，确定每一类职位中所有员工的薪酬水平 |
| | **计点法** | 找出各种职位中包含的共同「**付酬因素**」，把各付酬因素划分为若干等级并对因素及其等级予以界定和说明，对每个付酬因素**指派分数**以及其在该因素各等级间的分配数值，最后利用一张**转换表**将处于不同职级上的职位所得的付酬因素数值转换成具体的薪酬金额 |
| | **因素比较法** | 原材料仅列名，未展开（属职位导向四法之一，真题正确选项） |
| **以技能为基础** | — | 根据员工**能够胜任的工作的种类数目**（即员工**技能的广度**）来确定员工的基本薪酬；员工所掌握的技能种类越多，得到的报酬也就越多；**较适用于工作在生产和业务一线的员工** |
| **以知识为基础** | — | **比较适用于企业职能管理人员**基本薪酬的确定 |

3. **记忆提示/口诀**：「职位导向四兄弟：等级、分类、计点、因素比较」；题干出现「付酬因素」「指派分数」「转换表」→ **计点法**；出现「划分为管理类、技术类、操作类、财务类、营销类等职位类型」→ **职位分类法**；出现「胜任的工作种类数目」→ **以技能为基础**；出现「职能管理人员」→ **以知识为基础**。

### 考点17：薪酬区间与薪酬浮动率（★★★）
1. **核心概念**：
   - **薪酬区间**：某一薪酬等级内部允许薪酬变动的最大幅度，反映了同一薪酬等级内部**最低薪酬水平和最高薪酬水平之间的绝对差距**。
   - **薪酬浮动率**：薪酬区间的最高值或最低值**偏离区间中值**的比率。
2. **要点展开——确定薪酬浮动率时要考虑的因素**：**企业的薪酬支付能力、各薪酬等级自身的价值、各薪酬等级之间的价值差异、各等级的重叠比率**等。
3. **记忆提示/口诀**：「浮动率四因素＝支付能力、自身价值、等级间差异、重叠比率」；注意「同一行业其他企业同种职位的薪酬标准」属于**薪酬水平/竞争原则**的考虑因素，**不属于**确定薪酬浮动率的因素。

### 考点18：宽带型薪酬结构（★★★）
1. **核心概念**：宽带型薪酬结构是对多个薪酬等级以及薪酬变动范围进行**重新组合**，使之变成只有**相当少数的薪酬等级**以及相应**比较宽的薪酬变动范围**。
2. **要点展开——六项作用**：**① 支撑了扁平型组织结构的运行；② 引导员工重视个人技能的增长和能力的提高；③ 有利于促进职位轮换与调整；④ 有利于员工适应劳动力市场的供求变化；⑤ 有利于管理人员及人力资源专业人员的角色转变；⑥ 有利于促进薪酬管理水平的提高。**
3. **最大特点**：**扩大了员工通过技术和能力的提升增加薪酬的可能性**，使员工薪酬的增长更多地依赖于本人技能和能力的提高以及对企业的贡献的增加，而**不是地位的提高**，从而也进一步**减少了对员工进行横向甚至向下调动时所遇到的阻力**。
4. **记忆提示/口诀**：「宽带＝少等级+宽范围」；「最大特点＝靠本事不靠位子」。

### 考点19：影响薪酬管理的因素（★★）
1. **核心概念**：薪酬管理受企业内部因素和外部因素共同影响。
2. **要点展开**：

| 类别 | 具体因素 |
|---|---|
| **外部因素** | **法律法规、物价水平、劳动力市场的状况**等 |
| **内部因素** | **企业的财务状况**等（选项中出现「企业的财务状况」即属内部因素） |

## 四、公式与计算

**公式1 薪酬区间最高值/最低值**

- 区间**最高值** = 区间中值 ×（**1 + 薪酬浮动率**）
- 区间**最低值** = 区间中值 ×（**1 − 薪酬浮动率**）

**公式2 薪酬等级内部各级别的薪酬值**

- 第 **1** 级别（最低）的薪酬值 = 区间最低值
- 相邻级别级差 =（区间最高值 − 区间最低值）÷（该薪酬等级的**薪酬级别数 − 1**）
- 第 n 级别的薪酬值 = 区间最低值 + 级差 ×（n − 1）

### 演算例题（据 2020 年真题案例）

某企业第四薪酬等级分为 **4** 个薪酬级别，该等级的薪酬区间中值为 **5 万元/年**，薪酬浮动率为 **10%**。

1. 区间最高值 = 5 ×（1 + **10%**）= **5.50 万元/年**
2. 区间最低值 = 5 ×（1 − **10%**）= **4.50 万元/年**
3. 级差 =（5.50 − 4.50）÷（**4 − 1**）= 1 ÷ 3 ≈ **0.333 万元**
4. 第 2 级别的薪酬值 = 4.50 + 1 ÷ 3 ≈ **4.83 万元/年**

**其他速算示例**：区间中值 **3000** 元、薪酬浮动率 **20%** → 最高值 = 3000 × 1.2 = **3600** 元；区间中值 **6000** 元、薪酬浮动率 **25%** → 最低值 = 6000 × 0.75 = **4500** 元。

## 五、高频考点速记卡

1. **问**：人力资源规划按「性质」如何划分？**答**：**总体规划**和**具体计划**（时间长短分短中长期；主体分企业/部门；职能分招聘/培训等）。
2. **问**：外部环境信息在规划中的地位？**答**：是企业制定人力资源规划的**「硬约束」**；企业内部信息包括企业发展战略、经营计划、人力资源现状（员工数量和构成、**员工使用情况**、教育培训情况、**离职率和流动性**等）。
3. **问**：劳动关系计划的目标？**答**：**降低非期望离职率、改善劳动关系、减少投诉和争议**；预算含相关工作费用和**法律诉讼费**。
4. **问**：适用于**短期**预测的人力资源需求预测方法？**答**：**管理人员判断法**（粗略、简便易行、自下而上）。
5. **问**：使用**人员变动矩阵**描述员工流入、流出和内部流动的是哪种供给预测方法？**答**：**马尔可夫模型法**（时间间隔通常为**一年**，元素为历年平均调动百分比）。
6. **问**：绩效的三个特点？**答**：**多因性、多维性、变动性**；绩效考核内容包括**绩效考核项目**和**绩效考核指标**两部分。
7. **问**：绩效考核有几项功能？**答**：**六项**——管理、激励、学习和导向、沟通、监控、增进绩效（「审核功能」是干扰项）。
8. **问**：绩效考核流程四步？**答**：**准备（选考核者、明确考核标准、确定考核方法）→ 实施（绩效沟通、绩效考核评价）→ 结果反馈 → 结果运用（最后一步）**；「制订绩效改进计划」属**结果反馈阶段**。
9. **问**：评级量表法通常设几个等级？**答**：**5 个**——优秀、良好、合格、基本合格、差。
10. **问**：行为锚定评价法的本质？**答**：把**评级量表法与关键事件记录法结合起来**，每个分数刻度对应典型行为的描述性文字。
11. **问**：薪酬由哪三部分构成？**答**：**基本薪酬、激励薪酬、间接薪酬（福利）**；间接薪酬与员工个人工作和绩效**没有直接关系**，具有**普遍性**、**人人都有份**，社会保险费属之。
12. **问**：薪酬制度设计五原则及辨识关键词？**答**：**公平（同一行业/地区/同等规模企业中类似职务薪酬基本相同＝外部公平）、竞争（高于同行业同种职位）、激励（拉开距离、避免平均化）、合法（符合法规）、量力而行（考虑自身经济实力）**。
13. **问**：福利优于直接薪酬的四个方面？**答**：形式灵活多样；**保健性质**减少不满意、增强凝聚力；**税收优惠**增加实际收入；**集体购买的规模效应**节省支出。
14. **问**：福利最主要的问题是什么？**答**：具有普遍性、与个人绩效无直接联系，**提高工作绩效的效果不如直接薪酬明显**；且具有**刚性**，易导致福利支出不断膨胀。
15. **问**：法定福利与自主福利如何区分？**答**：法定＝**公休假日、带薪休假、住房公积金、社会保险**；自主＝**员工退休计划、儿童看护、老人护理**。
16. **问**：按员工**完成工作的时间**支付薪酬的形式？**答**：**工时制**。
17. **问**：群体激励薪酬有哪三种？**答**：**利润分享计划、收益分享计划、员工持股计划**（股票期权是员工持股的重要表现形式）；利润分享计划分配的是**超过目标利润的部分**，在**全体员工**之间分配。
18. **问**：根据绩效考核结果调整**基本薪酬**的制度？**答**：**绩效调薪**。
19. **问**：以职位为导向的基本薪酬设计方法有哪四种？**答**：**职位等级法、职位分类法、计点法、因素比较法**。
20. **问**：方法辨识关键词？**答**：「付酬因素、指派分数、转换表」→ **计点法**；「划分为管理类、技术类、操作类、财务类、营销类等职位类型」→ **职位分类法**；「能胜任的工作种类数目（技能广度）」→ **以技能为基础**（适用生产业务一线员工）；「职能管理人员」→ **以知识为基础**。
21. **问**：宽带型薪酬结构的特征与最大特点？**答**：**较少**的薪酬等级 + **比较宽**的薪酬变动范围；最大特点是扩大员工通过**技术和能力提升**增加薪酬的可能性（靠本事不靠位子）。
22. **问**：确定薪酬浮动率要考虑哪几个因素？**答**：**企业的薪酬支付能力、各薪酬等级自身的价值、各薪酬等级之间的价值差异、各等级的重叠比率**；「同一行业其他企业同种职位的薪酬标准」不选。
23. **问**：薪酬区间的定义？**答**：某一薪酬等级内部允许薪酬变动的**最大幅度**，反映同一等级内最低与最高薪酬水平的**绝对差距**。
24. **问**：影响薪酬管理的外部因素有哪些？**答**：**法律法规、物价水平、劳动力市场的状况**等（企业的财务状况属**内部**因素）。
25. **问**：绩效考核与薪酬设计的方法如何区分？**答**：**职位分类法、职位等级法是基本薪酬设计方法**；**关键事件法、民主评议法、书面鉴定法**才是绩效考核方法。

## 七、易错点与避坑指南

1. **错把「规划划分标准」与「划分结果」配错**。如「总体规划/具体计划」对应的是**性质**，不是时间或主体。**记法**：先背「性质—总体/具体」这一组，其余按「时间—短中长、主体—企业/部门、职能—招聘培训」顺推。
2. **把外部环境信息当成内部信息**。「员工使用情况」带「员工」二字易误判为外部，其实它属于**人力资源现状**，是**内部信息**；而「产品市场竞争情况」「劳动力市场供求状况」才是外部信息。**记法**：凡企业自身能掌握的状况（员工数量、使用、流动）均为内部。
3. **混淆绩效考核四阶段的任务**。最容易错的是把「选择考核者、明确考核标准、确定考核方法」归入**实施阶段**——它们属于**准备阶段（技术准备）**；实施阶段只有**绩效沟通**和**绩效考核评价**两件事。**记法**：「准备定规则，实施去打分」。
4. **混淆评级量表法与行为锚定评价法**。题干只写「划分 5 个等级、每等级给分」→ **评级量表法**；一旦出现「每个分数刻度都对应典型行为的描述性文字」→ **行为锚定评价法**。另注意**职位分类法、职位等级法是薪酬设计方法**，不是考核方法。
5. **把福利当激励薪酬**。住房公积金、带薪休假、保险福利均属**间接薪酬（福利）**；而计件工资、奖金、股票期权属**激励薪酬**。**记法**：人人有份、与绩效无关的是福利；与绩效直接挂钩的是激励薪酬。
6. **混淆「企业自主福利」与「国家法定福利」**。**带薪休假、公休假日、住房公积金、社会保险**是法定福利；**员工退休计划、儿童看护、老人护理**才是自主福利。**记法**：「法定」是政府强制、人人依法享有的基础项目。
7. **把「同一行业其他企业同种职位的薪酬标准」列为薪酬浮动率的影响因素**。它属于**薪酬水平（竞争原则）**的考量；确定薪酬浮动率只看**支付能力、等级自身价值、等级间价值差异、重叠比率**四项。
8. **薪酬区间计算符号出错**。最高值用（**1 + 浮动率**），最低值用（**1 − 浮动率**）；计算等级内部各级别时，级差要除以「**级别数 − 1**」（如分 **4** 个级别则除以 **3**），勿除以级别数本身。
9. **宽带型薪酬结构的方向记反**。宽带型是「**较少**的薪酬等级 + **比较宽**的薪酬变动范围」，不是「较多等级、较窄范围」。
