## 二、知识点精讲

### 考点1：市场营销环境（★★）

1. **核心概念**：市场营销环境是影响企业营销活动的各种外在因素，分为宏观环境与微观环境两个层次。
2. **要点展开**：
   - **宏观环境**：人口环境、经济环境、自然环境、技术环境、政治法律环境、社会文化环境。其中社会文化环境包括民族特征、价值观念、宗教信仰、生活方式、风俗习惯、伦理道德、教育水平、相关群体、社会结构等。
   - **微观环境**：企业自身因素、营销渠道企业、顾客、竞争者、公众、供应商。
3. **威胁—机会矩阵**（按机会水平 × 威胁水平划分四种业务）：

| 业务类型 | 机会 | 威胁 |
|---|---|---|
| 理想业务 | 高 | 低 |
| 冒险业务 | 高 | 高 |
| 成熟业务 | 低 | 低 |
| 困难业务 | 低 | 高 |

4. **记忆提示**：宏观环境记「6类环境」，微观环境记「6类主体」；「公众」是微观环境，真题常考反向提问。

### 考点2：市场营销战略（★★）

**（一）市场营销战略规划（四步）**

1. **确定企业任务**：目标有限、具体、明确；市场导向而非产品导向；富有激励性；政策具体、分工明确。
2. **规定企业目标**：投资收益率、销售增长率、市场占有率（公式见第四节）。
3. **安排业务组合**：波士顿咨询集团法（BCG）、通用电气公司法（GE）。
4. **制定新业务计划**：密集型成长战略、一体化战略、多元化战略。

**通用电气矩阵（GE矩阵）**：选用**行业吸引力**和**业务力量**两个综合性指标评价各战略业务单位，以做出投资决策。

| 地带 | 战略业务单位 | 战略措施 |
|---|---|---|
| 「绿色地带」（左上角） | 大强、中强、大中 | 开绿灯：增加投资、重点发展 |
| 「黄色地带」（对角线） | 小强、中中、大弱 | 开黄灯：维持现有投资水平和市场占有率 |
| 「红色地带」（右下角） | 小弱、小中、中弱 | 开红灯：收割或放弃 |

**（二）目标市场战略**

1. **市场细分**：基础是**消费者需求的差异性**。四类变量：

| 变量 | 具体内容 | 典型例子 |
|---|---|---|
| 地理变量 | 国家、地区、城镇、农村、面积、气候、地形、交通条件、通讯条件、城镇规划 | 「南甜北咸东辣西酸」；防潮御寒用品 |
| 人口变量 | 人口总数、人口密度、家庭户数、年龄、性别、职业、民族、文化、宗教、国籍、收入、家庭生命周期 | 儿童/中青年/老年市场 |
| 心理变量 | 生活方式、个性、购买动机、价值取向、对商品和服务方式的感受和偏爱、对商品价格反应的灵敏度 | 追求时尚 vs 维护传统；外向型/内向型顾客 |
| 行为变量 | 购买时机、使用者状况、忠诚程度、使用频率、待购阶段和态度 | 忠诚客户 vs 普通客户 |

口诀：心理变量是「内在心理活动」，行为变量是「外在行为表现」。

2. **目标市场选择战略（3种）**：

| 战略 | 要点 | 适用情形 |
|---|---|---|
| 无差异营销 | 把整体市场看作一个大的目标市场，只投放单一商品、设计一种营销组合，通过大规模分销和大众化广告满足绝大多数消费者 | 同质市场（如食盐）；不可替代的必需品（如书画用墨）；卖方市场 |
| 差异性营销 | 针对不同子市场需求特点，设计生产不同产品，采用不同营销组合 | 资源雄厚的企业 |
| 集中性营销 | 选择一个或几个细分市场，实行专业化经营，资源集中使用 | 资源有限的中小企业 |

3. **目标市场进入模式（5种，对比表见第三节）**。
4. **市场定位方法（5种）**：根据属性与利益定位（A汽车「货币的价值」、B「耐用」、C「节能环保」）；根据使用者定位（面向15—25岁、崇尚新奇的年轻一代）；根据竞争者的情况定位（方便面强调调料包口味 vs 强调面饼「非油炸」）；根据价格定位（「一分价钱一分货」，价格是质量的标志）；组合定位（护肤品含SOD抗衰老＋价格实惠＋男女老少皆宜）。

### 考点3：市场营销组合策略（★★★）

**（一）产品策略**

1. **产品组合4维度**：宽度＝企业经营的**不同产品线的数量**；长度＝产品组合中**产品项目的总数**；深度＝产品线中每种产品的**花色、品种、规格**数量；关联度＝各产品线在**最终使用条件、生产条件、分销渠道**等方面的密切相关程度。口诀：宽度、长度对应多条产品线，深度对应一条产品线。
2. **产品组合策略**：扩大产品组合（增加宽、长、深）；缩减产品组合（减少宽、长、深）；产品线延伸（向上延伸＝加高档产品，向下延伸＝加低档产品，双向延伸＝高低档都加）；产品线现代化策略（把现代科学技术应用到生产过程，如设备更新）。
3. **包装3层次**：首要包装（直接盛装产品）；次要包装（保护首要包装的二次包装）；装运包装（若干次要包装的集合，便于储运）。
4. **包装策略（9种）**：相似包装、个别包装、相关包装（化妆品套装）、分等级包装、分量包装、复用包装（双重用途包装）、附赠品包装、改变包装（销路不畅或长期使用一种包装时，改变设计、材料）。
5. **新产品分类**：全新产品（应用新技术、新材料，具有全新功能）；换代产品（完全或部分采用新技术、新材料、新工艺）；改进产品（改善原有产品的质量、性能、结构、造型）。
6. **新产品开发策略**：按开发方式分自主开发、委托开发、联合研制；按革新程度分创新策略、模仿策略；按开发时机分抢先策略、跟进策略。

**（二）定价策略**

1. **影响产品定价的3个因素**：市场需求（影响产品价格的**上限**）、成本（构成产品价格的**下限**）、市场竞争（不同市场竞争不同，定价策略也不同）。
2. **定价方法（3类）**：
   - 成本导向定价法：在产品成本基础上定价，包括**成本加成定价法**、**目标利润定价法**；
   - 需求导向定价法：以市场上消费者的**需求强度和价值感受**为基础，包括**认知价值定价法**（直接价格评比法、直接认知价值评比法、诊断法）、需求差别定价法；
   - 竞争导向定价法：以竞争者的价格为依据，包括**随行就市定价法**（把本企业产品价格保持在市场平均价格水平上，获得平均报酬）、**密封投标定价法**（各投标企业相互独立报价，报价最低者通常中标，其报价即承包价格）。
   具体公式详见第四节。

**（三）渠道策略**：详见第四章内容。

**（四）促销策略**

- **拉引策略**：利用广告和公共关系向消费者介绍产品和企业，激发兴趣、吸引购买——「拉消费者」。
- **推动策略**：运用人员推销和销售促进，沿生产商→批发商→零售商→消费者推进——「推中间商」。
- **促销组合（5种方式）**：

| 方式 | 核心要点 |
|---|---|
| 广告 | 广告主以**付费**的方式、有计划通过媒体向选定消费对象宣传商品或服务的优点和特色；功能：展示、认知、激发、引导 |
| 人员推销 | 由企业派出推销人员或委派专职推销机构向目标市场顾客介绍和销售商品；队伍结构：地区型、产品型、顾客型、复合型 |
| 销售促进 | 在较大目标市场中为刺激需求而采取的、能迅速产生激励作用的促销措施。对消费者：价格促销、赠品促销、抽奖、会员与积分、免费试用；对中间商：价格折扣、津贴补助、销售奖励、培训支持；对推销人员：业务培训、奖金、佣金 |
| 公共关系 | 为取得社会、公众的了解与信赖，树立企业及产品良好形象而进行的各种活动；对象为企业外部公众和企业内部公众 |
| 直复营销 | 不通过中间商而是直接与目标顾客接触，以获取快速反应并培养长期顾客关系；方式：直邮、电话、电视、网络直复营销 |

### 考点4：品牌与品牌资产（★★）

1. **品牌含义**：用来识别一种（一系列）产品或服务的名称、术语、标记、符号或图案，或其组合，使之与竞争对手相区别。
2. **品牌内容（6方面）**：属性、利益、价值、文化、个性、群体。
3. **品牌资产五星模型**（大卫·艾克于**1991年**提出，表格见第三节）：品牌知名度、品牌认知度、品牌联想度、品牌忠诚度、品牌其他资产，其中**品牌忠诚度是品牌资产的核心**。口诀「他诚想知名」。
4. **品牌忠诚度5级**（由低到高）：无忠诚购买者（不断更换品牌，只对价格敏感）→习惯购买者（按习惯持续购买，遇明显竞争优势会转购）→满意购买者（非常满意，已产生较高品牌转换成本）→情感购买者（对品牌有情感认可）→承诺购买者（最高级别）。

### 考点5：品牌战略（★★）

| 决策类型 | 内容 |
|---|---|
| 品牌有无决策 | 有品牌；无品牌——难以保证统一质量、消费者无须辨认、差别不大的商品（如电力、原油、煤炭）。使用品牌的意义：提高顾客忠诚度、增强与中间商讨价还价能力、易于拓展品牌、获得品牌溢价、获得法律保护 |
| 品牌持有决策 | 制造商品牌（全国性品牌，用本企业品牌）；私人品牌（商店品牌，用中间商品牌）；两种品牌并用 |
| 品牌质量决策 | 反映产品耐用性、可靠性、精确性等属性的综合尺度 |
| 家族品牌决策 | 个别品牌策略（润滑油A、B，汽油C、D各用不同品牌）；统一品牌策略；分类家族品牌策略（润滑油同一品牌、汽油另一品牌）；企业名称与个别品牌并用策略（「海尔小英才」「海尔小元帅」） |
| 品牌延伸决策 | 把现有成功品牌用到新产品上；好处：明确新产品定位、减少市场风险、强化品牌效应、提升品牌形象与整体品牌组合投资效益 |
| 多品牌决策 | 同时经营两种或两种以上互相竞争的品牌（如A、B、C三种润滑油在相同或不同细分市场竞争）；优势：占用较大陈列面积、吸引更多顾客提高市场占有率、引入内部竞争机制、覆盖更广市场 |
| 品牌重新定位决策 | 权衡转移成本（产品品质改变费用、包装费、广告费等）与可能获得的收益 |

## 四、公式与计算

**4.1 企业目标公式**（规定企业目标）

- 投资收益率＝利润额 ÷ 投入资本总额 × 100%
- 销售增长率＝（本期销售额 − 上期销售额）÷ 上期销售额 × 100%
- 市场占有率＝本企业某产品当期销售量（销售额）÷ 该产品当期整个市场销售量（销售额）

**演算例题1**：某企业本期销售额1200万元，上期1000万元，则销售增长率＝（1200−1000）÷1000×100%＝**20%**。

**4.2 成本加成定价法**

- 产品价格＝单位成本 ×（1＋加成率）
- 单位成本＝单位可变成本＋固定成本 ÷ 销售量
- 单位可变成本＝变动总成本 ÷ 销售量；单位固定成本＝固定成本 ÷ 销售量

**演算例题2**：某产品单位可变成本10元，固定成本总额20万元，预计销售量1万件，加成率20%。
单位固定成本＝200000÷10000＝20元；单位成本＝10＋20＝30元；产品价格＝30×（1＋20%）＝**36元/件**。

**4.3 目标利润定价法**

- 目标价格＝（总成本＋目标利润）÷ 总销量
- 目标利润＝投资额 × 投资收益率
- 总成本＝总固定成本＋总变动成本

**演算例题3**：某企业投资额1000万元，期望投资收益率10%，预计总销量10万件，总固定成本200万元，单位变动成本10元。
目标利润＝1000×10%＝100万元；总成本＝200＋10×10＝300万元；目标价格＝（300＋100）÷10＝**40元/件**。

**4.4 盈亏平衡分析**

- 盈亏平衡产量＝固定成本 ÷（销售单价 − 单位变动成本）

**演算例题4（真题数据）**：某服装制造企业总固定成本60万元，单位可变成本12元，产品单位售价17元，则盈亏平衡点产量＝60÷（17−12）＝**12万件**。

## 七、易错点与避坑指南

1. **「公众」归属错**：公众、供应商属于**微观**环境，不是宏观环境。记：宏观＝6类「环境」，微观＝6类「主体」。
2. **「撇脂」莫写成「撤脂」**：新品上市定高价的策略是**撇脂定价**，试卷选项曾形近误写作「撤脂」，不要因此不敢选。
3. **GE矩阵地带方向与措施**：左上角＝绿色（投资发展）、对角线＝黄色（维持）、右下角＝红色（收割或放弃）。有试卷把黄色地带方向写成「从左下角到右上角」，方向描述虽乱，答案仍是**黄色地带＝维持**，别误选「放弃」。
4. **产品线延伸 vs 产品线现代化**：设备更新、技术改造＝现代化；增减高/低档产品＝延伸（向上、向下、双向）。
5. **附属产品定价 vs 备选产品定价**：打印机与墨盒（缺一不可、主低附高）＝附属产品定价；汽车与电子开窗遥控器（可选可不选）＝备选产品定价。
6. **品牌认知度 ≠ 品牌知名度**：认知度是对品质的整体印象（产品质量＋服务质量）；知名度是记忆程度，分无知名度、提示知名度、未提示知名度、顶端知名度4阶段。
7. **忠诚度级别张冠李戴**：因「较高的品牌转换成本」而持续购买的是**满意购买者**；最高级别是**承诺购买者**。
8. **威胁—机会矩阵混淆**：「理想业务」是高机会＋低威胁，「成熟业务」是低机会＋低威胁，题目说「机会小、威胁低」时选成熟业务。

```quiz
下列定价策略中，属于产品组合定价策略的有（ ）。

A. 产品线定价
B. 撇脂定价
C. 备选产品定价
D. 附属产品定价
E. 产品束定价

@answer A,C,D,E
@explanation 产品组合定价策略包括产品线定价、备选产品定价、附属产品定价、副产品定价、产品束定价，故选A、C、D、E。撇脂定价属于新产品定价策略（还包括市场渗透定价、温和定价），B错误。
```

```quiz
下列市场细分变量中，属于心理变量的有（ ）。

A. 生活方式
B. 使用频率
C. 个性
D. 购买动机
E. 忠诚程度

@answer A,C,D
@explanation 心理变量包括生活方式、个性、购买动机、价值取向、对商品和服务方式的感受或偏爱、对商品价格反应的灵敏度等，故选A、C、D。使用频率和忠诚程度属于行为变量，B、E错误。
```
