## 二、知识点精讲

### 考点1：渠道运营管理概述（★★）

1. **市场营销渠道与分销渠道**：市场营销渠道是促使某种商品和服务经由市场交换过程顺利转移给消费者使用的一整套相互依存的组织；分销渠道是其重要组成部分。**分销渠道成员**指商品从生产者向消费者转移过程中，取得这种商品的所有权或帮助所有权转移的所有企业和个人，包括**生产者、中间商和最终消费者**（配送公司、银行、保险公司不属于分销渠道成员）。
2. **分销渠道管理目标**：市场占有率、利润额、销售增长额。
3. **分销渠道管理任务**：提出并制定分销目标；监测分销效率；协调渠道成员关系、解决渠道冲突；促进商品销售；改善和重建分销渠道。

### 考点2：消费品分类与分销渠道模式（★★★）

1. **核心概念**：消费品指消费者个人或家庭使用的产品。
2. **要点展开**（按消费者购买习惯分四种）：

| 类型 | 定义 | 实例 |
|---|---|---|
| 便利品 | 购买频繁、不愿花时间精力比较，希望随时随地买到 | 食盐、方便面、洗涤用品、饮料 |
| —日用品 | 价格低、经常使用和购买 | 食盐、洗涤用品 |
| —冲动购买品 | 感官（视/嗅/听）受刺激后临时决定购买 | 玩具、水果、CD唱片 |
| —应急物品 | 紧急需要情况下购买 | 急诊药品、应急雨伞 |
| 选购品 | 对价格、质量、款式、耐用性等比较后才购买 | 家用电器、服装、美容美发产品 |
| 特殊品 | 具备独有特征和（或）品牌标志，购买者愿付出特殊购买努力 | 特殊品牌和式样的汽车、服装 |
| 非渴求品 | 消费者不知道，或知道但一般不会主动购买 | 人寿保险、艺术藏品、百科全书、刚上市的新产品 |

3. **消费品分销渠道四种模式**：

| 模式 | 要点 |
|---|---|
| 厂家直供模式 | 生产厂家直接将商品供应给终端渠道销售（如厂家对接蛋糕店、小卖部） |
| 多家经销（代理）模式 | 选择多家经销商（代理商），建立庞大销售网络 |
| 独家经销（代理）模式 | 一定时期、某一地区只选一家经销商（代理商） |
| 平台式销售模式 | 以商品**分装厂**为核心，由分装厂建经营部向各零售终端供货；**适用于消费密集、交通便利的大城市市场** |

4. **记忆提示**：便利品三分（日用、冲动、应急）；渴求与否看"主动"；平台模式关键词是"分装厂+大城市"。

### 考点3：工业品分销渠道构建（★★★）

1. **核心概念**：工业品指购买者以社会再生产为目的而购买的产品。
2. **市场特点**：需求的派生性、需求弹性**小**、专业采购、一次购买量**大**、顾客集中稳定。口诀：**小生定大专**（弹性小、派生性、稳定集中、专业采购、购买量大）。
3. **渠道设计**：以具有服务功能的**短渠道**为主；实践中以**直销**为主，并在主要销售点设立网点，也可利用代理商设销售点或利用批发商销售。

### 考点4：服务产品特征与分类矩阵（★★★）

1. **五大特征**：无形性、不可分离性（生产与消费同时进行）、差异性、不可储存性、所有权的不可转让性。口诀：**无差异三不可**。
2. **分类矩阵**（服务对象 × 服务行为和结果是否有形）：

| | 服务对象＝人 | 服务对象＝物 |
|---|---|---|
| **行为和结果有形** | 针对人身体的服务（人体处理），顾客**高卷入**：客运、医疗、美容、餐饮、手术 | 针对物体的服务（物体处理），对象必须在场、顾客本人不必在场：货运、维修、零售、加油、保管 |
| **行为和结果无形** | 针对思想意识的服务（脑刺激处理），顾客**意识**在场（现场或远程）：娱乐、艺术、咨询、教育、心理治疗、音乐会、广播、广告 | 针对无形资产的服务（信息处理），不一定要求顾客直接参与，现场或异地均可：会计服务、银行服务、法律服务、程序编写、科学研究、证券投资 |

> 提示：脑刺激针对消费者**意识**，信息处理针对**信息数据**。快递类服务属于针对**物体**的服务。
3. **常用分销渠道模式**：
   - **直接分销模式**：根本原因在于服务产品的**不可分离性**（如医疗机构、会计师事务所）。
   - **中介机构组建的分销渠道**：代理商（旅游、运输、信贷、工商服务业）、经纪人（如保险经纪人，以特许权方式销售服务）、批发商（大批量提供服务）、零售商（商业零售、照相馆、干洗店）。提示：中介＝中间商（批、零、代）＋经纪人。

### 考点5：渠道成员激励方法（★★★）

| 方法 | 具体手段 | 口诀 |
|---|---|---|
| 沟通激励 | 提供产品、技术动态信息；公关宴请；交流市场信息；让经销商发泄不满 | 沟通≈交流信息和情感 |
| 业务激励 | 佣金总额动态管理；灵活确定佣金比例；安排经销商会议；合作制订经营计划 | 业务≈佣金会议计划 |
| 扶持激励 | 实施优惠促销；提供广告津贴；培训销售人员；**融资支持** | 扶持≈财务支持 |

> 注意：激励过分（优惠条件超过取得合作所需条件）会导致**销售量提高而利润下降**。

### 考点6：渠道权力及其来源（★★★）

1. **核心概念**：渠道权力指特定渠道成员控制或影响另一渠道成员行为的能力。
2. **六种来源对比表**：

| 权力来源 | 含义 | 实例/别称 | 强制性/非强制性 | 中介性/非中介性 |
|---|---|---|---|---|
| 奖励权 | 影响者承诺而且能够对遵守要求者给予奖励 | 也称**承诺策略**，对服从型伙伴给予好处 | 非强制性 | **中介性** |
| 强迫权 | 影响者对受影响者施加惩罚的能力 | 渠道成员往往把它看作对企业和业务的一种攻击，导致自我防卫和报复 | **强制性** | **中介性** |
| 法定权 | 受影响者认识到影响者有明确权力对其施加影响，由交易合同或契约式垂直分销体系形成 | 法律法定权来源于成员间签署的合同；传统法定权来源于行事标准、规范、价值观和信仰 | 非强制性 | 法律法定权→**中介性**；传统法定权→**非中介性** |
| 认同权 | 也称**参照权**，一个渠道成员使用另一成员的品牌或从事对对方有利活动时对另一方产生影响 | 流通企业选择与知名制造商合作以提高商誉 | 非强制性 | **非中介性** |
| 专长权 | 受影响者认为影响者具备其不具备的某种特殊知识或有用专长 | 特许经营 | 非强制性 | **非中介性** |
| 信息权 | 渠道成员提供某类信息的能力 | — | 非强制性 | **非中介性** |

3. **区分技巧**：
   - **强制性权力只有强迫权**；奖励权、法定权、认同权、专长权、信息权均为非强制性权力（例：零售商威胁放弃厂商某商品销售＝强迫权；承诺增加该商品销售量＝非强制性权力）。
   - **中介性权力**＝奖励权、强迫权、法律法定权；**非中介性权力**＝专长权、信息权、认同权、传统法定权。
   - 奖励权与强迫权相关联，"赏罚分明"即指这两种权力的运用。

### 考点7：渠道权力的运用（6战略）与保持（★★★）

1. **权力运用6战略**：

| 战略 | 表现 |
|---|---|
| 许诺战略 | 如果你按照我说的去做，我会奖励你 |
| 威胁战略 | 如果你不按照我说的去做，我就会惩罚你 |
| 法律战略 | 你必须按照我说的去做，因为从某种意义讲你已经同意这样做了 |
| 请求战略 | 请按照我希望的去做 |
| 信息交换战略 | 无须说我想要的是什么，我们来探讨什么对我的合作伙伴更有利（所需权力来源：**专长权、信息权、奖励权**） |
| 建议战略 | 如果你按照我说的去做，你会有更多盈利 |

2. **渠道权力的保持**：本质是**渠道控制力的保持**。
   - 生产厂商保持控制力的条件（判断标准：生产厂商强大）：行业由少数几家大型厂商控制；产品无替代品；获得该厂商产品对消费者十分重要；消费者或产品差异化、厂商能方便完成成本转移；厂商能实施前向一体化。
   - 中间商保持渠道控制力的策略：采用有影响力的自主品牌；形成大批量销售规模；提供促销服务；培养忠诚顾客；集中采购；适时适度利用灰色市场；签订长期合作协议以销售流转慢的商品；适时采用垂直一体化战略；批零兼营、价格折扣吸引顾客；灵活的货款结算政策影响供应商。

### 考点8：渠道冲突管理（★★★）

1. **定义**：渠道成员之间因利益关系产生的矛盾和不协调；本质是渠道主体**利益、行为和心理**上的冲突。
2. **类型**：

| 划分标准 | 类型 | 要点 |
|---|---|---|
| 渠道成员层级关系 | 水平冲突 | 同一渠道中**同一层次**成员之间的冲突 |
| | 垂直冲突 | 同一渠道中**不同层次**成员之间的冲突 |
| | 多渠道冲突 | 厂商建立两条或以上渠道向同一市场售货，渠道间冲突 |
| 对企业发展的影响方向 | 功能性冲突 | 以相互对抗消除潜在有害紧张气氛，激励对方相互挑战，提高共同绩效（**积极**） |
| | 破坏性冲突 | 不安心理和对抗动机外化成对抗行为并超限度，产生消极破坏影响；如窜货、赖账、制假售假（**消极**） |

> 其他模型：按利益冲突与对抗性行为关系分为**杜茨模型**；按冲突频率、强度及事件重要程度分为**瓦格瑞斯和汉迪模型**。口诀：**多平直**。
3. **原因**：角色错位、目标差异、观点差异、沟通困难、决策权分歧、期望差异、资源稀缺。
4. **处理**：以共同利益为基础确定长期目标；鼓励成员积极参与渠道活动和政策制定；适当运用激励手段；采用人员交换；利用协商、调解、仲裁和诉讼等手段；适时清除渠道成员。

### 考点9：渠道差距的产生与消除（★★★）

1. **五种渠道差距（差距1—5）**：

| 差距 | 名称 | 定义 |
|---|---|---|
| 差距1 | 期望感知差距 | 企业不能准确地感知顾客的服务期望 |
| 差距2 | 质量标准差距 | 服务提供者制定的服务标准与管理者所认知的顾客期望不一致 |
| 差距3 | 服务传递差距 | 服务生产与传递过程未按照企业设定的标准进行 |
| 差距4 | 市场沟通差距 | 企业市场宣传中所承诺的服务与企业实际提供的服务不同（如组织未能执行宣传中的服务质量标准、过度承诺） |
| 差距5 | 服务感知差距【核心】 | 顾客期望的服务与顾客感知或实际体验的服务不一致 |

2. **消除思路**：
   - 消除**需求方**差距：针对不同细分市场顾客需求提供不同服务产品；根据产生原因有针对性地改进服务；通过转变目标市场、改变服务对象。
   - 消除**供应方**渠道差距：改变当前渠道成员的角色；利用新的分销技术降低成本；引进新的分销专家，改进渠道运营。
   - 改变渠道环境和管理限制所产生的渠道差距：聘请有关专家参与重新设计和修改渠道系统，缩小差距、优化渠道结构。

### 考点10：分销渠道运行绩效评估（★★★）

指标分五类：**渠道畅通性指标**（商品传输时间、商品周转速度、销售回款率）、**渠道覆盖率指标**（市场覆盖面、市场覆盖率）、**分销渠道费用指标**（费用额、费用率、费用率升降程度）、**渠道市场占有率指标**、**渠道盈利能力指标**（销售增长率、销售利润率、费用利润率、资产利润率）。公式见"四、公式与计算"。

### 考点11：分销渠道发展趋势（★）

1. **网络分销渠道与传统渠道比较**：网络渠道结构呈**网状**（以互联网站点为中心向周围发散），直接分销为零级渠道，间接分销**只有一级**；传统渠道为**线性**通道，间接分销为**多级**。网络渠道费用**低**，传统渠道费用**高**。
2. **网络分销渠道特征**：虚拟性、经济性、便利性（**不含社会性**）。
3. **网络分销系统**：订货系统、结算系统、配送系统。口诀：**订货→结算→配送**。
4. **网络分销渠道类型**：网络直销渠道（企业自建网站销售；入驻电子商务平台销售）与网络间接分销渠道（通过网络中间商销售，如目录服务商、搜索引擎服务商、虚拟商业街、网上零售商等）。
5. **渠道扁平化**：指尽量减少商品与顾客接触的中间环节，实现商品与顾客直接接触，以获得成本优势并减少中间环节信息失真。原因：网络信息技术、渠道纵向一体化、顾客需求特征的影响。形式口诀：**0，1，2**——
   - 直接渠道（绝对扁平化）：生产商—顾客；
   - 有一层中间商：生产商—经销商（代理商）或零售商—顾客；
   - 有两层中间商：生产商—经销商（代理商）—零售商—顾客，**最常用、最普遍**，关键在于商品由经销商直接到达**零售商**手中。
   - 扁平化渠道中，分销商的作用**仅表现为分销商品的物流平台**（非扁平化时还承担资金平台、信息流平台）。
6. **渠道战略联盟**：经销商之间（集中采购或建立联盟，在营销渠道中有决定性发言权）、生产商之间（一定利益驱动下的短期行为）、生产商与经销商之间（上下游联盟合作，提高整条供应链效益和效率）。

## 四、公式与计算

**（一）公式汇总**

| 指标 | 公式 |
|---|---|
| 商品传输时间 | 商品传输时间 ＝ 商品库存时间 ＋ 各环节运输时间 |
| 销售回款率 | 销售回款率 ＝ 实际收到销售款 ÷ 销售收入 × 100% |
| 市场覆盖面 | 市场覆盖面 ＝ 分销网络终端销售区域面积总和 − 相互重叠销售区域面积总和 |
| 市场覆盖率 | 市场覆盖率 ＝ 渠道市场覆盖面积 ÷ 市场总面积 × 100% |
| 分销渠道费用率 | 分销渠道费用率 ＝ 分销渠道费用额 ÷ 渠道商品销售额 × 100% |
| 分销渠道费用率升降程度 | ＝ 本期分销渠道费用率 − 上期分销渠道费用率 |
| 渠道占有率 | 渠道占有率 ＝ 某渠道分销商品销售额 ÷ 该商品同期销售总额 × 100% |
| 渠道销售增长率 | ＝（本期销售额 − 上期销售额）÷ 上期销售额 × 100% |
| 渠道销售利润率 | ＝ 渠道利润额 ÷ 渠道商品销售额 × 100% |
| 渠道费用利润率 | ＝ 渠道利润额 ÷ 分销渠道费用 × 100% |
| 渠道资产利润率 | ＝ 渠道利润额 ÷ 渠道资产占用额 × 100% |

**（二）演算例题**

**例题1（渠道费用率，真题改编）**：某企业2022年商品销售额为1000万元，其中网络渠道销售额为600万元，网络渠道费用额为250万元，则该企业2022年的网络渠道费用率是多少？

> 解：分销渠道费用率 ＝ 分销渠道费用额 ÷ 渠道商品销售额 × 100% ＝ 250 ÷ 600 × 100% ≈ **41.7%**。
> 【易错】分母是"渠道商品销售额"（该渠道自身销售额600万），不是企业商品销售总额1000万。若误用1000万，会错得25.0%。

**例题2（渠道销售增长率）**：某经销商上期销售额为800万元，本期销售额为960万元，求渠道销售增长率。

> 解：渠道销售增长率 ＝（960 − 800）÷ 800 × 100% ＝ 160 ÷ 800 × 100% ＝ **20%**。

**例题3（销售回款率）**：某企业报告期销售收入为500万元，实际收到销售款450万元，求销售回款率。

> 解：销售回款率 ＝ 450 ÷ 500 × 100% ＝ **90%**。回款率越高，说明渠道越畅通。

**例题4（渠道费用利润率）**：某渠道利润额为120万元，该渠道分销费用为300万元，求渠道费用利润率。

> 解：渠道费用利润率 ＝ 120 ÷ 300 × 100% ＝ **40%**。

## 五、高频考点速记卡

1. **问**：消费品按购买习惯分哪四种？**答**：便利品、选购品、特殊品、非渴求品。
2. **问**：便利品又分哪三种？**答**：日用品、冲动购买品、应急物品。
3. **问**：人寿保险、百科全书属于哪类消费品？**答**：非渴求品。
4. **问**：适用于消费密集、交通便利大城市市场的渠道模式？**答**：平台式销售模式（核心是分装厂）。
5. **问**：工业品市场五特点？**答**：需求派生性、需求弹性小、专业采购、一次购买量大、顾客集中稳定。
6. **问**：工业品分销渠道以什么为主？**答**：具有服务功能的短渠道，实践中以直销为主。
7. **问**：服务产品五特征？**答**：无形性、不可分离性、差异性、不可储存性、所有权不可转让性。
8. **问**：客运、医疗、美容、餐饮属于哪类服务？**答**：针对人身体的服务（人体处理），顾客高卷入。
9. **问**：快递、货运、维修、保管属于哪类服务？**答**：针对物体的服务（物体处理），对象必须在场、顾客本人不必在场。
10. **问**：会计、银行、法律服务、证券投资属于哪类服务？**答**：信息处理服务（针对无形资产）。
11. **问**：服务产品采用直接分销模式的根本原因？**答**：服务产品的不可分离性。
12. **问**：渠道成员激励三方法及代表手段？**答**：沟通（信息、宴请、发泄不满）、业务（佣金、会议、经营计划）、扶持（优惠促销、广告津贴、培训、融资支持）。
13. **问**：融资支持属于哪种激励？**答**：扶持激励。
14. **问**：渠道权力六种来源？**答**：奖励权、强迫权、法定权、认同权（参照权）、专长权、信息权。
15. **问**：唯一属于强制性权力的是？**答**：强迫权。
16. **问**：中介性权力包括？**答**：奖励权、强迫权、法律法定权。
17. **问**：流通企业选择与知名制造商合作提高商誉，制造商拥有的是？**答**：认同权（参照权）。
18. **问**：信息交换战略依据哪些权力来源？**答**：专长权、信息权、奖励权。
19. **问**：渠道冲突按层级关系分哪三类？**答**：水平冲突、垂直冲突、多渠道冲突。
20. **问**：能提高共同绩效的冲突是？**答**：功能性冲突；破坏性冲突如窜货、赖账、制假售假。
21. **问**：渠道差距五种（按顺序）？**答**：期望感知差距、质量标准差距、服务传递差距、市场沟通差距、服务感知差距（核心）。
22. **问**：市场宣传承诺与实际服务不符属于哪种差距？**答**：市场沟通差距（差距4）。
23. **问**：商品传输时间怎么算？**答**：商品库存时间 ＋ 各环节运输时间。
24. **问**：市场覆盖率公式？**答**：渠道市场覆盖面积 ÷ 市场总面积 × 100%。
25. **问**：渠道盈利能力指标有哪些？**答**：渠道销售增长率、渠道销售利润率、渠道费用利润率、渠道资产利润率。
26. **问**：网络分销渠道三特征与三系统？**答**：虚拟性、经济性、便利性；订货、结算、配送系统。
27. **问**：最常用最普遍的扁平化渠道？**答**：有两层中间商（生产商—经销商—零售商—顾客），关键在于商品由经销商直接到达零售商手中。

## 七、易错点与避坑指南

1. **平台式销售模式 ≠ 网络平台销售**。它是"以商品分装厂为核心建经营部供货给零售终端"的传统模式，关键词是分装厂与大城市市场，别与"网络分销渠道"混淆。
2. **工业品需求弹性是"小"不是"大"**，顾客是"集中稳定"不是"分散"。记口诀"小生定大专"。
3. **服务分类矩阵看两个维度**：一是针对人还是物，二是行为结果有形还是无形。"快递、保管"对象是物，属物体处理；"音乐会、广告"是顾客意识在场，属脑刺激处理；"会计、银行"针对信息数据，属信息处理。
4. **强制性权力 ≠ 中介性权力**。强制性只含强迫权一种；中介性含奖励权、强迫权、法律法定权三种。两套划分标准不同，别混。
5. **信息交换战略的权力来源**是专长权、信息权、奖励权，不是法定权、强迫权。
6. **功能性冲突是积极的**，破坏性冲突（窜货、赖账、制假售假）是消极的；做题时看到"提高共同绩效"直接选功能性冲突。
7. **渠道费用率的分母是"该渠道商品销售额"**，不是企业销售总额；真题中 250/600＝41.7%，用1000万作分母即错选25.0%。
8. **扁平化渠道中分销商的作用"仅"是物流平台**；非扁平化下分销商还承担资金平台和信息流平台。两层中间商模式商品由经销商直接到达**零售商**手中，不是消费者。
