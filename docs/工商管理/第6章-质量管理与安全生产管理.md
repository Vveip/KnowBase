## 二、知识点精讲

### 考点1　质量概述

**（1）质量的概念**：一组固有特性满足要求的程度。

**（2）质量的特点**（四点）：
- 经济性："物美价廉""物有所值""性价比高"。
- 广义性：不仅指产品质量，也指过程和体系的质量。
- 时效性：顾客及相关方的需求不断变化，原先质量好的产品可能因要求提高而不再受欢迎。
- 相对性：同一产品/同一功能可提出不同需求；须在同一等级基础上比较，不与其他等级混淆。

**（3）质量的特性**（与要求有关的固有特性），四类：
| 类型 | 内容 |
|---|---|
| 硬件质量特性 | ①内在（结构/性能/精度/化学成分）②外在（外观/形状/色泽/气味/包装）③经济（使用成本/维修时间费用）④其他（安全/环保/美观）。适用性建立在硬件质量特性基础上 |
| 服务质量特性 | ①可靠性（准确履行承诺）②响应性（迅速提供）③保证性（知识礼节自信使人信服）④移情性（设身处地为顾客着想）⑤有形性（设备设施人员） |
| 软件质量特性 | ①功能性②可靠性③易使用性④高效性⑤可维护性⑥可移植性 |
| 流程性材料质量特性 | 可定量测（强度/黏度/速度/抗化学性）；定性（色彩/质地/气味，主观判断） |

**（4）按对顾客满意程度划分的质量特性类型**（高频辨析）：
- 关键质量特性：超差直接影响产品安全性或使整体功能丧失。
- 重要质量特性：超差造成产品部分功能丧失。
- 次要质量特性：超差暂不影响功能，但可能引起功能逐渐丧失。

### 考点2　质量管理概述

- 定义：从质量方面指挥和控制组织的协调活动。
- 内容（六项职能，高频）：**质量方针**（总宗旨与方向，最高管理者确定并形成文件）、**质量目标**（通过质量方针体现）、**质量策划**（关键=制定质量目标并设法实现，合理分配资源）、**质量控制**（目的=保证质量满足要求，适用于设计/采购/服务/营销/人资几乎所有活动）、**质量保证**（对达到预期质量能力提供信任：内部向管理者、外部向顾客）、**质量改进**（增强满足质量要求的能力）。

### 考点3　质量检验

- 概念：为确定产品/服务是否符合要求，对一个或多个质量特性进行观察、测量、试验，并将结果与规定要求比较，作符合性评价的活动。
- **基本要素（四步，高频）**：①度量（试验/测量/化验/分析/感官检查）→②比较（测定结果对标准）→③判断（合格与否判定）→④处理（合格放行 or 不合格返工/返修/报废）。
- 检验方式（多角度分类）：按数量=全数/抽样；按检验后状态=破坏性/非破坏性；按质量特性值=计数/计量；按地点=固定/流动；按方法特征=理化/感官；按目的=验收/过程/监督检验。
- 活动类型：进货检验（外购品入库前接收检验）、工序检验（防止大批不合格流入后道；含①首件②巡回③末件检验）、完工检验（又称最终检验；成品验收检验+成品质量审核）。
- **主要制度**：
  - **三检制**：自检（操作者自检）+互检（操作者之间/上下道工序/同工序轮班交接）+专检（专职检验员）。**以专检为主导**。
  - 追溯制：通过记录标识追溯对象历史/应用/位置。
  - 不合格品管理制度：**"三不放过"**=不查清不合格原因不放过、不查清责任者不放过、不落实改进措施不放过；处置方法五种：①返工②返修③降级④报废⑤让步。
- 基本任务：①鉴别质量水平②判断工序质量状态③了解等级/缺陷严重程度④改善检测手段⑤反馈质量信息。

### 考点4　质量认证

- 概念：经权威机构确认，通过合格证书或合格标志，证明产品符合相应标准/规范的活动。含**产品质量认证 + 质量管理体系认证**。
- 作用：①竞争中取胜②增强国际竞争力③完善质量管理体系④节约社会检验费用⑤保护消费者权益。
- 类型（以型式试验为基础，逐级增加监督/体系评定）：型式试验→+认证后监督（市场抽样/工厂抽样/两者）→+工厂质量管理体系评定再加监督；另有工厂质量管理体系评定（即体系认证）、批量检验（不存在监督问题）、全数检验（费用很高）。

### 考点5　质量管理方法（旧七种工具，★★★）

以数理统计为基础，适合解决现场质量问题的**七种工具**：
| 工具 | 要点 |
|---|---|
| ①分层法 | 按目的分类整理数据。关键=同层波动小、层间波动大。标志：操作者/设备/原材料/缺陷项目 |
| ②调查表法 | 为分层收集数据设计的统计图表（缺陷/不良项目/不良原因/过程分布调查表） |
| ③散布图 | 又称相关图，两变量以点标于坐标图，判断相关关系（如淬火温度与硬度） |
| ④排列图 | **又称主次因素分析图/帕累托图**。"关键的少数，次要的多数"，**朱兰**将帕累托图用于质量管理 |
| ⑤因果分析图 | 以结果为特性、原因为因素，箭头表因果；集思广益，适合质量小组民主管理 |
| ⑥直方图 | 又称质量分析图，表示数据离散程度，判断工序是否受控 |
| ⑦控制图 | **休哈特**首创，反映工序质量随时间动态变化，又称管制图。**UCL上控制界限/CL中心线/LCL下控制界限** |

- 控制图种类：计量值控制图（长度/强度/纯度；单值、平均值-极差、中位数-极差；口诀"单值、平极、中极"）；计数值控制图（计件值：不合格品率/不合格品数；计点值：缺陷数/单位缺陷数）。

### 考点6　工序能力分析（★★★，含公式）

- **5M1E**：人(man)、机器(machine)、原材料(material)、方法(method)、测量(measurement)、环境(environment)。系统性因素消除、偶然性波动受控时，工序质量处于受控状态。
- **工序能力 B = 6σ**（σ为质量特性值标准差）。**B 越小，工序能力越强**（波动越小，一致性越高）。
- 工序能力指数 = 质量标准 T / 工序能力 B（T 用标准/公差/允许范围衡量，规格中心 M）：
  - 均值 μ 与规格中心 M **重合**：`Cp = T / 6σ = (T_U − T_L) / 6σ`，M=(T_U+T_L)/2。T 不易改变，σ 越小 Cp 越大。
  - 均值 μ 与规格中心 M **不重合**：引入 `Cpk = min(T_U − μ, μ − T_L) / 3σ`；单侧上限 `Cpu = (T_U − μ)/3σ`。
- **五等级判断准则（表6-8，高频背）**：

| 等级 | 工序能力指数 | 判断 |
|---|---|---|
| 特级 | 1.67 < Cp | 过剩 |
| 一级 | 1.33 < Cp ≤ 1.67 | 充足 |
| 二级 | 1.00 < Cp ≤ 1.33 | 正常 |
| 三级 | 0.67 < Cp ≤ 1.00 | 不足 |
| 四级 | Cp ≤ 0.67 | 严重不足 |

- 处置措施：
  - **过大（1.67<Cp）**：粗活细做、成本高。①降低工序能力（改用精度低但高效低成本设备）②更改设计、提高技术要求③合并或减少工序。
  - **过小（Cp≤1.00）**：①提高设备精度、改善原材料②修订标准放宽公差③工序能力不足时全检剔除不合格品或分级筛选。
  - **适宜（1.33<Cp≤1.67）**：进行控制，使工序处于受控/稳定状态。

### 考点7　全面质量管理 TQM（★★★）

- 概念：组织以质量为中心、以全员参与为基础，通过让顾客满意和组织成员及社会受益实现长期发展的管理途径。
- **"三全一多样"**：
  - 全企业的质量管理（各管理层次都有明确内容、侧重点不同；质量管理职能分散在各部门）。
  - 全过程的质量管理（除基本生产过程，还重视辅助生产过程）。
  - 全员参与的质量管理（人人有责、人人关心）。
  - 方法多种多样：**旧七种工具**（因果分析图/排列图/直方图/控制图/散布图/分层法/调查表法）+ **新七种工具**（关联图/亲和图/系统图/矩阵图/矩阵数据分析法/过程决策程序图/矢线图）+ 质量功能展开、稳健性设计(三次设计)、质量工程学、价值工程、六西格玛等。
- 实施原则：预防原则、经济原则、协作原则；抓住思想、目标、体系、技术四个要领（核心=质量管理体系的建立和运行）。
- **ISO9000 族标准七项原则**：以顾客为关注焦点、领导作用、全员参与、过程方法、持续改进、循证决策、关系管理。
- 实施工作程序"五步法"：**决策→准备→开始→扩展→综合**。
- **PDCA 循环**（基本方法）：计划 Plan → 执行 Do → 检查 Check → 处理 Action。特点="大环套小环，小环保大环"、不断循环逐步提高、**推动 PDCA 关键在 A（处理）阶段**（总结成功/失败经验并形成标准）。质量改进是 PDCA 螺旋式上升的基础。

### 考点8　六西格玛管理（★★★）

- σ 表示质量控制水平，水平越高不良品率越低：
  - **3σ ≈ 合格率 99.73%**；
  - **6σ ≈ 合格率 99.99999983%**，不合格率不超过 0.002ppm（每 100 万个产品不合格不超过 0.002 个）。
- 内涵：在总结 TQM 成功经验基础上发展的、提高企业业绩与竞争力的管理模式；追求卓越的管理哲学。基本内涵=提高顾客满意度、降低资源成本。
- **组织结构三层次**：领导层=执行领导、倡导者；骨干层=黑带大师、黑带；执行层=绿带。
  - 质量管理委员会（高级管理层组成）、质量领导（副总裁级，质量委员会召集者，管理黑带大师/黑带/绿带）、倡导者（高层，多兼职，决定"该做什么"）、黑带大师（全职专家，推行的保证者和执行者）、黑带（专职，具体执行推广）、绿带（兼职，底线收益项目负责人）。
- 步骤：①研究可行性确定是否推行（最高领导支持）②成立委员会组建团队③培训④流程实绩评估⑤确定改进目标并实现⑥持续改进。
- **改进模式 DMAIC（五阶段）**：界定 Define（确认顾客关键需求、识别改进对象）→测量 Measure（测量评估、确定过程基准）→分析 Analyze（统计分析、确定关键因素）→改进 Improve（最优方案、降低缺陷/变异）→控制 Control（成功经验制度化、维持提高）。

### 考点9　安全生产概述

- 含义：为使劳动过程在符合安全要求的物质条件和工作秩序下进行，防止伤亡/设备事故及灾害，保障劳动者安全健康、生产劳动正常进行而采取的各种措施和活动。既保护劳动者，也保护生产、财物、环境。
- 特点（四点）：①预防性②长期性③科学性④群众性。
- **基本方针**（《安全生产法》）：**"安全第一、预防为主、综合治理"**。

### 考点10　安全生产管理内容

- 含义：围绕生产过程中的安全风险与问题，科学配置资源、强化综合管理，依托计划/组织/领导/控制等职能实现安全生产目标的管理过程。
- 基本对象：企业员工，涉及所有人员、设备、设施、物料、环境、资金、信息。
- 内容：贯彻法律法规；制定目标战略、建立组织、责任落实、事故预警；制定规章制度和操作规程；定期安全教育检查评比、落实奖惩；发生事故坚决"四不放过"；正确使用安全设备设施；做好档案信息管理。
- **"四不放过"**：事故原因未查清不放过、事故责任人和员工未受到教育不放过、防范措施未建立不放过、责任人未受到处理不放过。

### 考点11　生产经营单位的安全生产职责

- **主要负责人**：本单位安全生产**第一责任人**，全面负责。其六项职责：①建立健全并落实全员安全生产责任制、加强标准化建设②组织制定实施规章制度和操作规程③组织制定实施教育培训计划④保证安全生产投入有效实施⑤组织建立落实安全风险分级管控和隐患排查治理**双重预防机制**⑥组织制定实施应急救援预案（另及时如实报告事故）。
- 工会：对安全生产工作进行监督；组织职工参加民主管理和民主监督；单位制定/修改安全生产规章制度应听取工会意见。
- 安全生产管理机构及人员：拟订规章制度/操作规程/应急预案、组织教育培训、危险源辨识评估、应急演练、检查排查隐患、制止违章指挥/强令冒险作业、督促整改。

### 考点12　生产经营单位安全生产的法律责任（数字密集，注意分级）

**主要负责人**（未履行职责）：责令限期改正，处 **2万~5万**；逾期未改，处 **5万~10万** 并责令停产停业整顿；导致事故给予撤职；构成犯罪追刑责；受刑罚/撤职后 **5年内**不得任任何生产经营单位主要负责人；对重大/特别重大事故负责的**终身**不得任本行业主要负责人。

**主要负责人因未履职导致事故**（按上一年年收入罚款）：
| 事故等级 | 罚款 |
|---|---|
| 一般事故 | 上一年年收入 **40%** |
| 较大事故 | **60%** |
| 重大事故 | **80%** |
| 特别重大事故 | **100%** |

**其他负责人和安全生产管理人员**：未履职责令限期改正，处 **1万~3万**；导致事故暂停/吊销资格，并处上一年年收入 **20%~50%**；构成犯罪追刑责。

**生产经营单位**（负有责任，按事故等级罚款）：
| 事故等级 | 罚款 |
|---|---|
| 一般事故 | **30万~100万** |
| 较大事故 | **100万~200万** |
| 重大事故 | **200万~1000万** |
| 特别重大事故 | **1000万~2000万** |

情节特别严重、影响特别恶劣的，可按上述数额的 **2倍~5倍** 处罚。

## 三、必背表格

**表1　质量特性四大类**
| 类型 | 关键词 |
|---|---|

## 四、公式与计算

- 工序能力：`B = 6σ`（B 越小能力越强）。
- 工序能力指数（居中）：`Cp = T / 6σ = (T_U − T_L) / 6σ`。
- 工序能力指数（偏移）：`Cpk = min(T_U − μ, μ − T_L) / 3σ`；`Cpu = (T_U − μ) / 3σ`。
- 规格中心：`M = (T_U + T_L) / 2`。
- σ 水平：3σ→99.73%；6σ→99.99999983%（0.002ppm）。

**例**：某质量特性公差上限 T_U=50、下限 T_L=44，σ=1，过程均值 μ=47（居中）。
Cp = (50−44)/(6×1) = 6/6 = **1.00** → 二级"正常"边界（属三级上界，需控制）。
若 μ=48（偏移）：Cpk = min(50−48, 48−44)/(3×1) = min(2,4)/3 = 2/3 ≈ **0.67** → 四级"严重不足"。

## 七、易错点

1. **排列图 = 帕累托图 = 主次因素分析图**，与"关键少数"关联的是**朱兰**（不是戴明）。
2. **控制图创始人是休哈特**；UCL/CL/LCL 三线不要混。
3. **B 越小工序能力越强**（易误记为越大越强）；Cp **过大也要处置**（粗活细做、成本高）。
4. 工序能力五等级的区间是**开闭有别**（如特级 >1.67，四级 ≤0.67），边界值归属要看符号。
5. **三检制以专检为主导**（非自检为主）。
6. **PDCA 关键在 A（处理）阶段**，不是 P。
7. 安全方针是"安全第一、预防为主、**综合治理**"三句，勿漏第三句。
8. **四不放过**（安全事故）≠ **三不放过**（质量不合格品管理），两者别混。
9. 六西格玛 6σ 合格率是 **99.99999983%**（不是 99.9997%，那是 3.4ppm 的近似说法；教材口径以 0.002ppm 为准）。
10. 法律责任金额：**主要负责人 2~5 万起**、**其他人员 1~3 万起**、**单位事故 30 万起**，三条线不要串。
