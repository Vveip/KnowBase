## 二、知识点精讲

### 考点1：电子商务的产生背景（★★）
1. **核心概念**：电子商务是在传统商务的基础上发展起来的新型商业运营模式；**经济全球化与社会信息化直接催生了电子商务**。
2. **要点展开**：
   - **技术基础——信息技术革命**。信息技术革命使商业贸易活动在互联网开放的网络环境下，买卖双方**不谋面**地进行各种商贸活动成为可能，为电子商务的产生奠定了技术基础。（2017·单选53）
   - **现实需求背景——经济全球化**。经济全球化使各国、各地区的经济活动互相依存、相互影响，企业必须立足于统一的国际市场，充分考虑各种可能性和可行性，采用一种更有效的商业模式，以便迅速将产品销往全球最需要的市场，由此产生了电子商务的现实需求。（2024·单选4）

### 考点2：电子商务的特点（★★★）
共 **8** 个特点，前 **4** 个与后 **4** 个分组记忆：

| 序号 | 特点 | 关键表述 |
| --- | --- | --- |
| 1 | 市场全球化 | 市场范围扩展至全球 |
| 2 | 跨时空限制 | 传统方式必须在商家营业时间去商场购物，受较强的时间和地点限制；电子商务能在世界各地瞬间完成传递与计算机自动处理，且无须人员干预，加快交易速度，只要有互联网就可随时、随地、随意进行商务活动 |
| 3 | 交易虚拟化 | 交易双方通过以互联网为代表的计算机网络，从洽谈、签约到订货、支付等**无须当面**进行，均通过网络完成，整个交易完全虚拟化 |
| 4 | 成本低廉化 | — |
| 5 | 交易透明化 | — |
| 6 | 操作方便化 | — |
| 7 | 服务个性化 | — |
| 8 | 运作高效化 | — |

**记忆提示**：第 1—4 个为「市场全球化、跨时空限制、交易虚拟化、成本低廉化」，第 5—8 个为「交易透明化、操作方便化、服务个性化、运作高效化」。题干抓关键词：「洽谈、签约、订货、支付均通过网络、无需当面」→**交易虚拟化**；「不受营业时间限制、随时随地」→**跨时空限制**。

**易混特点辨析**（严格对应原材料表述）：

| 题干关键词 | 对应特点 |
| --- | --- |
| 洽谈、签约、订货、支付均通过网络完成，无需当面 | 交易虚拟化 |
| 世界各地瞬间完成传递与计算机自动处理，无须人员干预，加快交易速度 | 跨时空限制 |

### 考点3：电子商务的功能（★★★）
电子商务可提供网上交易和管理等全过程的服务，具有 **7** 项功能：**广告宣传、咨询洽谈、网上订购、电子支付、网上服务、网络调研、交易管理**。
- **咨询洽谈**：交易双方借助互联网上的网站、电子邮件、新闻组和讨论组了解市场和商品信息、洽谈交易事务；如有进一步需求，还可利用**网上的白板会议**交流即时的图形信息。（题库·单选21）
- 反向识别：「提高利润」「大额转账」**不属于**电子商务功能，是多选题常见干扰项。

### 考点4：电子商务的一般框架（★★）
电子商务系统框架结构是电子商务系统中拓展性强的一种结构模式，由 **3** 个层次和 **2** 个支柱组成：
- **3** 个层次：**网络层**、信息发布与传输层、一般业务服务层。
  - **网络层**＝网络基础设施，即所谓「信息高速公路」，是实现电子商务的**最底层硬件基础设施**，包括远程通信网、有线电视网、无线通信网和互联网。（2017·单选57）
- **2** 个支柱：**公共政策和法律规范**、**技术标准和网络协议**。二者是框架中除三个层次之外的制度与技术保障，也是原材料中与「电子商务法律与信用问题」相关的唯一点位（本章材料未展开）。

### 考点5：电子商务运作系统的组成要素（★★★）

| 组成要素 | 地位与作用 | 出处 |
| --- | --- | --- |
| **企业** | 电子商务中的重要主体，通过网络平台向消费者发布产品信息、了解市场需求信息、提供服务、完成交易；既是产品和服务的提供者，又是信息的提供者，是**推动电子商务发展的根本力量** | 2024·单选32 |
| 消费者 | 交易的参与主体（需求方），企业通过网络平台向其发布信息、提供服务 | 2024·单选32 |
| 银行 | 提供资金结算支持；第三方支付平台须与产品所在国家以及国内外各大银行签约 | 题库·第三方支付解析 |
| 物流配送体系 | 为顾客进行商品配送；有形产品的网上销售需要相应的物流配送系统作为支撑 | 题库·单选15、22 |
| **CA 认证中心** | 具有权威性和公正性的第三方认证机构，保证相关主体身份的**真实性**和交易的**安全性** | 2017·单选58 |
| 其他要素 | — | 题库·单选30 |

**记忆提示**：「企、消、银、物流、CA」；**技术研发中心不属于**运作系统组成要素。

**两个高频设问**：①「谁是根本力量」→**企业**（2024·单选32）；②「谁保证身份真实性与交易安全」→**CA 认证中心**（2017·单选58）。注意选项中「物流配送机构」「银行」都是组成要素，但回答的不是这两个设问。

### 考点6：电子商务的分类（★★★）
通常采取 **3** 种分类标准：

| 分类标准 | 类型 |
| --- | --- |
| 交易的**主体** | B2B、B2C、C2C、B2G、C2G |
| 商业活动的**运行方式** | 完全电子商务、非完全电子商务 |
| 开展电子交易的**地域范围** | 区域电子商务、远程电子商务、全球电子商务 |

### 考点7：电子商务的交易模式（★★★）

| 模式 | 含义 | 关键特征 |
| --- | --- | --- |
| B2B | 企业与企业之间的电子商务 | — |
| B2C | 企业与消费者之间的电子商务 | 有 **3** 个基本组成部分：网上商店（为顾客提供在线购物场所）、物流系统（为顾客进行商品配送）、电子支付系统（资金结算）；按交易商品范围分为**综合型 B2C**（中间商或零售商通过电子商务平台向消费者提供多种类型商品，典型代表亚马逊、京东、当当）与**垂直型 B2C**（专注于某一特定细分市场） |
| C2C | 消费者与消费者之间的电子商务 | 为买卖双方提供一个在线交易平台，使卖方可以主动提供商品上网拍卖，买方可以自行选择商品进行竞价，交易方式多变 |
| O2O | 线上与线下协调集成的电子商务 | 是 **B2C 的一种特殊形式** |
| B2G | 企业与政府管理部门之间的电子商务 | 政府的电子商务行为，**不以营利为目的** |
| C2G | 公民与政府之间的电子商务模式 | — |

**解题示范**：题干出现「家电生产企业开通网上商店，为终端消费者进行商品配送，提供电子支付系统」→ 交易双方是「企业—消费者」，对应 **B2C**（其 **3** 个基本组成恰好就是网上商店、物流系统、电子支付系统）；出现「个人通过网约车平台提供服务」→ 交易双方是「消费者—消费者」，对应 **C2C**；出现「线上与线下协调集成」→ **O2O**。

**按运行方式的细分**：

| 类型 | 界定 | 交易对象 |
| --- | --- | --- |
| 完全电子商务 | 交易过程中的商流、资金流、物流、信息流**四流都能够在网上完成**，商品或服务的整个商务过程都可以在网络上实现 | 主要为**无形货物和服务**：某些计算机软件、娱乐产品的联机订购／付款／交付，或全球规模的信息服务 |
| 非完全电子商务 | 原材料未给出定义，仅作为「完全电子商务」的对照项出现 | 有形产品（如汽车）不能完全实现电子商务，其网上销售需要相应的物流配送系统支撑 |

### 考点8：商流、资金流、物流、信息流（「四流」）（★★★）

| 四流 | 概念 | 考点关键词 |
| --- | --- | --- |
| 商流 | 物品在流通中发生形态变化的过程，即由货币形态转化为商品形态以及由商品形态转化为货币形态，随着买卖关系的发生，**商品所有权发生转移**的过程（包括买卖交易活动、商务信息活动） | 动机和目的；起点和前提 |
| 资金流 | 买卖双方间随着商品实物及其所有权的转移而发生的资金往来流程，包括**支付、转账、结算**等 | **商务活动的经济效益是通过资金的流动来体现的**；条件 |
| 物流 | 商品从供应地向接收地的**实体流动**过程 | 终结和归宿 |
| 信息流 | 电子商务交易各个主体之间的信息传递与交流的过程 | **伴随整个交易过程**；具有**双向传递**特征；手段 |

- **四流关系**：商流是动机和目的，资金流是条件，物流是终结和归宿，信息流是手段；商流是物流、资金流和信息流的**起点和前提**。
- **双向传递的具体表现**：一方面卖方向买方传递商品信息、结算信息、付货信息，另一方面买方向卖方传递购买信息、付款信息、收货信息，这种信息的双向传递是电子商务活动达成的必需手段。
- **虚拟企业**：电子商务模式下出现了一种无明显边界的新型企业——**虚拟企业**，其管理由原来的相互控制转向相互支持、由监视转向激励、由命令转向指导。（2017·单选56）

### 考点9：电子商务的运作步骤（★★★）
1. **明确愿景 → 制定战略 → 选择策略 → 系统设计与开发 → 电子商务组织实施**，共 **5** 步，顺序固定。
2. **系统设计与开发**共 **5** 项内容：**①功能设计 ②流程设计 ③网站设计 ④数据库设计 ⑤系统开发**，其中应**优先实施功能设计**——先分析企业电子商务的所有功能和子功能，了解彼此之间的信息传递和联系，对企业电子商务的各项活动进行整体设计。（题库·单选5、2019·单选51）
   - **网站艺术设计**：导航栏、排版、标志等；具体需确定网站的结构、栏目的设置、网站的风格、**颜色搭配、版面布局以及文字图片的应用**等。注意「颜色搭配、版面布局、文字图片应用」属于**艺术设计**，不是功能设计，这是常见的选项陷阱。
3. **电子商务组织实施**阶段的工作包括：电子商务网站**推广、试运行、评估反馈、完善、全面实施**等。（2024·单选44）

### 考点10：电子支付与第三方支付（★★★）
1. **电子支付的特点**（**4** 项）：① 通过**数字化**的方式进行款项支付；② 工作环境基于一个**开放的系统平台**（即互联网）；③ 对**软、硬件设施的要求很高**；④ 具有**方便、快捷、高效、经济**的优势。（题库·单选26）
2. **按具体工具方式分 3 大类**：

| 类别 | 举例 |
| --- | --- |
| 电子货币类 | 电子现金、电子钱包 |
| 银行卡类 | 借记卡、信用卡 |
| 电子支票类 | 电子支票、电子汇款、电子划款 |

> 注：单选题解析中的旧表述为「电子信用卡类（智能卡、借记卡、电话卡等）」，多选题现行表述为「银行卡类（借记卡、信用卡等）」，应试以「银行卡类」为准。

3. **第三方支付**：由一些和产品所在国家以及国内外各大银行**签约**、并具备一定实力和信誉保障的**第三方独立机构**提供的交易支持平台。流程：买方选购商品后，使用第三方平台提供的账户支付货款→第三方通知卖家货款到达、进行发货→买方检验物品后通知付款给卖家→第三方再将款项转至卖家账户。作用：**解决「先付款还是先发货」的矛盾**；商家看不到客户的信用卡信息，避免信用卡信息在网络上多次公开传输而导致信息被窃。
4. **移动支付**：用户使用其移动终端（智能手机、掌上电脑、移动个人计算机等）对所消费的商品或服务进行资金支付；其中用户量最大的是**智能手机**。
5. **考点提示**：电子支付的特点是「数字化、开放平台、软硬件要求**很高**、方便快捷高效经济」，题干说「对软、硬件要求很低」即为错误选项；「第三方支付」的设问几乎必含「先付款还是先发货」这一关键词。

### 考点11：网络营销（★★★）
1. **网络营销的特点**：整合性、交互性、**经济性**、精准性。经济性指通过互联网进行信息交换代替实物交换，一方面减少印刷费用与邮递成本、实现无店铺销售，节约店铺租金、水电费用与人工成本，另一方面减少反复交换带来的损耗。（2024·单选27）
2. **常见网络营销方式**：

| 方式 | 要点 |
| --- | --- |
| 网络软文营销（又称「网络新闻营销」） | 通过网络上门户网站、地方或行业网站等平台，传播一些具有阐述性、新闻性和宣传性的文章，包括新闻通稿、深度报道、案例分析等 |
| 电商直播营销 | 主播基于网络平台和直播技术，推介商品并与消费者互动来促销；消费者在主播引导下购物，本质上除质量保证、折扣优势外，还是一种**精神消费活动** |
| 网络视频营销 | 将各种视频短片以各种形式放到互联网上，达到宣传企业品牌、产品以及服务信息的目的；形式类似电视视频短片（感染力强，形式、内容多样，富有创意），又具有互联网营销优势（互动性、主动传播性、传播速度快、成本低廉） |
| 网络事件营销、网络图片营销、即时通信营销、网络口碑营销、网络直复性营销 | 名称性考点，按题干关键词对应选择 |

3. **产品策略**：适合做网上销售的产品有信息产品、有形产品和网上服务；由于顾客的特点和网上体验的局限性，应具备 **4** 个特点——**产品标准化、重购性、时尚性、廉价性**（「产品个性化」不是）。
4. **价格策略**：产品和服务定价要考虑 **4** 个因素——
   - **国际化**：互联网营造的全球市场环境，要针对国际市场的需求状况和产品价格情况确定本企业产品的价格策略；
   - **趋低化**：网络营销使企业的产品开发和促销等成本降低，企业可以进一步降低产品价格；
   - **弹性化**：网络营销的互动性使顾客可以和企业就产品价格进行协商；
   - **价格解释体系**：企业通过互联网向顾客提供有关产品定价的资料。
5. **渠道策略**：网络营销渠道主要有 **5** 种——
   - **会员网络**：网络营销中一个**最重要**的渠道；
   - **分销网络**：根据企业提供的产品和服务不同，分销渠道不一样；
   - **快递网络**：提供有形产品的企业要把产品及时送到顾客手中，需通过快递公司的送货网络实现；
   - **服务网络**：分为网上产品服务营销和客户服务营销；
   - **生产网络**：为实现及时供货、降低生产运输等成本，企业要在一些目标市场区域建立生产中心或配送中心，形成生产网络，并同供应商的供货网络及快递公司的送货网络相结合。

### 考点12：网络市场调研的方法（★★）

| 类别 | 方法 | 实施方式 |
| --- | --- | --- |
| **直接调研**（**4** 法） | 网上观察法 | 利用相关软件和人员记录登录网络浏览者的活动，相关软件能够记录浏览者浏览企业网页时所点击的内容 |
| | 专题讨论法 | 通过新闻组、电子公告牌（BBS）或邮件列表讨论组进行 |
| | 在线问卷法 | 请求浏览其网站的每个人参与企业的各种调查 |
| | 网上实验法 | 通过在网络中所**投放的广告内容与形式**进行实验；设计几种不同的广告内容和形式在网页或新闻组上发布，也可利用 E-mail 传递广告 |
| **间接调研**（**3** 法） | 利用搜索引擎查找资料 | — |
| | 访问相关网站收集资料 | 知道某一专题的信息主要集中在某些网站后，通过直接访问这些网站获得所需要资料 |
| | 利用网上数据库查找资料 | — |

**记忆提示**：判断直接／间接，看是否**直接接触被调查对象**——观察、讨论、问卷、实验是「直接」；搜索引擎、访问网站、网上数据库是「间接」。

**解题提示**：题干出现「在互联网中投放广告内容与形式」→**网上实验法**（直接调研）；出现「知道某一专题信息主要集中在某些网站后直接访问」→**访问相关网站**（间接调研）；出现「利用相关软件记录浏览者点击的内容」→**网上观察法**。

### 考点13：信用证结算流程（★）
采用信用证方式结算货款，进出口商先在贸易合同中规定使用信用证支付；进口商向当地银行申请开证，**开证行**开出信用证寄交出口商所在地分行或代理行（**通知行**）；通知行核对印鉴无误后交给出口商；出口商审核无误后按信用证规定装运货物、备齐单据开出汇票，在信用证有效期内送请当地银行（**议付行**）议付；议付行将汇票和货运单据寄交开证行或其指定的**付款行**索偿，付款行核对单据无误后付款。银行出现顺序：**开证行 → 通知行 → 议付行 → 付款行**。（2024·单选12）

## 四、公式与计算

**网络渠道市场占有率**

> 网络渠道市场占有率 ＝ 网络渠道销售额 ÷ 商品销售总额

**演算例题**：某企业 2022 年商品销售总额为 **1000** 万元，网络渠道销售额为 **600** 万元，网络渠道费用额为 **250** 万元，则该企业 2022 年网络渠道市场占有率为：
**600 ÷ 1000 ＝ 60%**。（2024·单选38，答案 B）
**避坑**：题干中的「网络渠道费用额 **250** 万元」是干扰数据，不参与计算。

## 七、易错点与避坑指南

1. **错把「互联网技术革命」当技术基础**。错在：两个背景记混。怎么记：技术基础是**信息技术革命**，现实需求背景是**经济全球化**，「技术」对「信息」，「需求」对「经济」。（2017·53、2024·4）
2. **认为「成本高」是电子商务特点**。错在：被反向表述欺骗。怎么记：特点是**成本低廉化**，题目问「错误的是」时优先怀疑「成本高」这类反向选项。（题库·单选3）
3. **混淆「四流」概念**。错在：不看题干关键词。怎么记：「经济效益」→资金流；「所有权转移」→商流；「实体流动」→物流；「贯穿全程、双向传递」→信息流，先抓关键词再选。（题库·单选12、14、18、20、23）
4. **系统设计与开发顺序记反**。错在：把网站设计、数据库设计排在前面。怎么记：**功能设计**必须第一，顺序为「功能→流程→网站→数据库→系统开发」。（题库·单选5、2019·51）
5. **运作步骤顺序颠倒**。错在：把「制定战略」放在「明确愿景」之前。怎么记：一定是「明确愿景→制定战略→选择策略→系统设计与开发→电子商务组织实施」共 **5** 步。（题库·单选16）
6. **电子支付分类张冠李戴**。错在：把电子汇款当成电子货币。怎么记：电子现金、电子钱包属**电子货币类**；借记卡、信用卡属**银行卡类**；电子支票、电子汇款、电子划款属**电子支票类**。（题库·单选9、多选5）
7. **把「技术研发中心」算进运作系统**。错在：组成要素记不全。怎么记：只有消费者、企业、银行、物流配送体系、CA 认证中心及其他要素，**技术研发中心不属于**。（题库·单选30）
8. **O2O 与 B2C 的关系搞错**。错在：以为 O2O 是独立于 B2C 之外的新模式。怎么记：O2O 是线上与线下协调集成的电子商务，本质是**B2C 的一种特殊形式**。（2019·60）
