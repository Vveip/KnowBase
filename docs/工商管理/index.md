# 中级经济师 · 工商管理

> 本栏目基于 **2026 年中经工商（孙晶）冲刺串讲班** 与 **章节题库（520 题）** 整理。
> 内容为「知识点笔记 + 高频考点 + 真题题库」三位一体：题目就写在章节笔记里，构建时自动抽取进[刷题系统](/quiz/)，**知识点和考题永不脱节**。

## 一、考试概览

| 项目 | 内容 |
|---|---|
| 考试名称 | 全国经济专业技术资格考试（中级） |
| 报考专业 | 工商管理 |
| 考试科目 | ①《经济基础知识》 ②《工商管理专业知识和实务》 |
| 本科目满分 / 合格线 | 140 分 / 以当年官方通知为准 |
| 题型与题量 | 单选 60 题 × 1 分、多选 20 题 × 2 分、案例分析 20 小题 × 2 分 |
| 成绩管理 | 两年滚动有效，需在连续两个考试年度内通过全部科目 |

::: tip 得分规则是灵魂
多选与案例**错选不得分，少选所选的每个选项得 0.5 分**——「宁缺毋滥」是本科目拉开差距的关键。
考试安排、三轮复习法与分题型答题技巧见 [备考总览](/经济师备考/)。
:::

### 复习优先级建议

1. **第一梯队**：第 1、2、10 章 —— 分值重、计算密集，是决定能否过线的关键；
2. **第二梯队**：第 5、6、7、8、9 章 —— 高频且各有计算板块，务必动手演算；
3. **第三梯队**：第 3、4、11 章 —— 考点相对集中，适合中后期集中突破。
