## 二、知识点精讲

### 考点1 财政分权理论 ★★

财政分权理论共四大理论。**公共物品和服务理论是财政学的理论基础**，研究财政分权问题应将**分析公共物品和服务受益范围的层次性作为出发点**（即研究其层次性问题）。

**（1）公共物品和服务理论**

| 类别 | 含义 | 特征 |
|---|---|---|
| 全国性公共物品和服务 | 与国家整体有关、各位社会成员均可享用的物品和服务，受益范围是全国性的，如**国防** | ①受益范围被限定在整个**国家**的疆域之内；②提供者为**中央政府**，而不应该是某一级地方政府 |
| 地方性公共物品和服务 | 只能满足**某一特定区域范围**内居民公共需要的物品和服务，如**路灯**等城市基础设施 | ①受益范围具有**地方局限性**；②提供者为**各级地方政府**，受益者主要是本辖区居民 |

代表人物与结论：

| 代表人物 | 代表作 | 核心观点 |
|---|---|---|
| 沃伦斯·欧茨 | 《财政联邦主义》 | 地方政府为其辖区提供相应的产出水平，一般要比中央政府对所有辖区提供统一的产出水平**更加符合帕累托效率** |
| 查尔斯·提布特 | 《地方支出的纯理论》 | ①分权的最终结果将有助于对不同人口群体的公共物品和服务偏好做出判断；②个人可通过向最能反映其消费偏好的辖区流动来表示对原辖区的不满，即「**用脚投票**」 |

**（2）集权分权理论**
不论在任何制度的国家（单一制国家还是联邦制国家），**中央政府（联邦政府）都是国家利益（整体利益）的绝对代表者，地方政府是地方利益（局部利益）的代表者**。政治上的分权必定会引发经济上的分权，因而**财政分权是不可避免的**。自20世纪70年代末以来，许多发达国家以及相当数量的发展中国家都开展了下放权力的变革运动，这一变革既包括**基本政治框架的变革，又包括经济框架的变革**。

**（3）财政联邦主义**
- 含义：各级政府间财政收入和支出的划分以及由此产生的相关制度。从某种意义上说**就是财政分权**，即给予地方政府一定的**税收权力和支出责任范围**，并允许地方政府**自主决定其预算支出规模与结构**。
- **精髓**：使地方政府依据**合适与合意的财政自主权**进行决策。
- 地方分权的理由：①地方政府比中央政府**更接近民众**，更了解辖区民众的需求和效用；②一个国家内部不同地区的人有权对不同种类、不同数量的公共物品和服务进行各自的选择，而地方政府就是**实现不同地区不同选择的机制**。
- 结论：①为了实现**资源配置的有效性与分配的公平性**，某些公共决策应该在**较低层次**的政府进行；②地方政府之间也会存在竞争，但这种竞争**有利于资源配置效率的提高**。

**（4）俱乐部理论**
- 研究对象：**非纯公共物品**的供给、需求与均衡数量。
- 奠基人：**布坎南与蒂鲍特**。
- 基本目的：研究**非纯公共物品的配置效率问题**。
- 内容：俱乐部向会员提供公共物品和服务，成本由各位会员分担。新会员加入可在固定成本下由更多人分担成本，但超过**拥挤点**后，边际收益递减。
- 结论：论证了**地方政府的适当规模问题**——一个地方政府的规模应确定在**拥挤成本（边际成本）正好等于由新成员承担税收份额所带来的边际收益**这一点上。

**速记口诀**：**「欧茨效率、提布特用脚投票；中央代表国家利益；联邦主义=财政分权；俱乐部=非纯公共物品+适当规模」**

### 考点2 政府间事权的划分 ★★★

**（1）政府间财政关系的五个方面**（本章总纲，多选高频）

| 序号 | 方面 | 一句话 |
|---|---|---|
| ① | 财政事权划分 | **事该由哪级政府干**。事权包括政府事权和财政事权：政府事权是一级政府在公共事务和服务中应承担的任务和职责；财政事权是一级政府应承担的运用财政资金提供基本公共服务的任务和职责 |
| ② | 支出责任划分 | **钱该由哪级政府出**。支出责任是政府履行财政事权的支出义务和保障 |
| ③ | 收入划分 | **以税收为主体的政府收入在政府之间如何安排** |
| ④ | 转移支付制度 | **事和钱都分清楚之后**，政府间的财力盈缺如何调节 |
| ⑤ | 预算管理制度 | 明确财政收支活动的基本规则，保障财政发挥职能作用，促进中央和地方各级政府分工协作、有序运转、有效履职 |

> **政府间事权的划分是财政分权管理体制的基本内容和制度保障；预算管理体制是财政管理体制的主导环节，占有核心的地位。**
> 政府间财政关系的影响因素主要有：**大国与小国的差异、路径依赖、财权财力与事权之间的关系**。

**（2）政府间事权划分的三大原则**

| 原则 | 别称 | 核心内容 |
|---|---|---|
| **外部性原则** | 受益范围原则 | 可根据公共服务的**受益范围**确定公共服务成本的辖区范围，使**成本分担的地理边界同受益范围一致**。外部性主要发生在当地→交给该地方管理；外部性是跨区域的→由更高区域级别政府管理。各项公共服务的提供，应由控制着这一服务提供的效益与成本内部化的**最小地理区域的辖区**来进行；只要不至于产生服务成本与受益在辖区内的不匹配，公共服务供应责任就应尽可能下放到**最低层级的辖区**。解决外部性的基本思路是让外部性**内部化**，通常做法包括**征税、补贴和专利制度**等 |
| **信息复杂性原则** | —— | 信息**复杂程度越高的事务越适合于基层**来管理；信息复杂程度低一点、属于全局性的事务适合于**国家**来管理。按信息复杂程度应由地方管理、但又具有跨地区外部性的事务，可由地方管理、中央提供帮助，例如**义务教育** |
| **激励相容原则** | 调动积极性原则 | 要求财政事权划分充分体现**权责匹配**。若在某种制度安排下各级政府都按划定职能尽力做好自己的事情、可使全局利益最大化，这种制度安排就是激励相容的；若激励不相容，局部利益可能损害整体利益 |

**实现激励相容必须满足的四个条件**：①**地方政府自治**条件；②**共同市场**条件；③**预算硬约束**条件；④**权力制度化**条件。
【巧思妙记】**制度约束，市场自治**

**（3）政府间事权划分的具体做法（七方面）**

| 具体事务 | 具体做法 |
|---|---|
| 国防事务 | **立法权为中央专有**；**行政权以中央直接管辖为主**。地方所享有的国防事务行政权主要限于组织地方武装力量、协助征集兵员、负责所管辖地域的国防 |
| 外交事务 | **绝大部分国家将外交事务划归中央专门管理**，只有部分联邦制国家容许成员国保留部分外交权 |
| 公安事务 | 中央对**事关国家主权**的公安事务（如国籍管理、出入境管理）实行专门管理；维护国家安全与秩序的主要人员——**警察，由中央与地方共同管辖** |
| 内政事务 | **中央机构的建制由中央决定**，中央与地方分别建立；**地方机构的建制由地方决定并建立** |
| 司法事务 | 当代世界各国司法体制分为**高度集权、集权为主分权为辅、分权**三类。高度集权下司法制度由中央立法并实施、司法机关由中央建制并管理、地方不得插手；集权为主分权为辅下立法权集中于中央、地方只在一定范围内享有司法行政管理权；分权下实行二元司法制度，或并存两套司法系统/法律制度，或兼而有之 |
| 经济事务 | 全国范围内事关国际关系和国家主权的产业部门、行业制度由中央专门管辖。财政金融方面实行**以中央集中管理为主、地方协助管理为辅**的体制，由国家统一管理信用、货币和银行体系 |
| 文化教育事务 | 有的国家由中央负责执行，有的纳入地方政府职责范围，还有的由中央和地方共同负责。文化事业的方针政策措施一般由中央决策；文化遗产保护、馆藏事业、传播媒介、文化娱乐设施等各有不同立法执行体制；教育立法有共同立法/中央专法/地方专法，教育行政有以地方管理为主也有以中央管理为主 |

### 考点3 政府间财政支出的划分 ★★★★

**（1）财政支出划分的三原则**

| 原则 | 核心内容 |
|---|---|
| **与事权相对称原则** | **一级事权一定要保证有一级的财力**。先明确中央与地方的事权和支出责任，凡政府活动在实施行动上必须**统一规划**的领域，支出属于中央政府；凡实施过程中必须**因地制宜**的领域，支出属于地方政府，然后依据各自权责确定相应财力 |
| **公平性原则** | 各级政府间的财权财力划分要**相对平衡**，包括中央与地方政府及地方各级政府间的**纵向平衡**，以及各级地方政府间的**横向平衡** |
| **权责结合原则** | 用来解决财权财力与财政责任的结合问题。一是要在地方组织的收入中解决其支出的需要，即**收支挂钩**；二是各级财政要为各级政府履行自己的事权提供财力支撑；三是各级政府要保持**财政收支平衡** |

**（2）我国财政支出划分的具体做法（五种，曾被采用过）**

| 方法 | 核心做法 | 特点/评价 |
|---|---|---|
| **统收统支** | 地方组织的全部收入统一上缴中央，地方所需支出统一由中央拨给；地方预算支出与其组织的收入之间基本上不发生联系（收支两条线） | 在**政治经济的非正常时期有利于资金使用效率的提高**，但财权财力高度集中，**不利于调动地方的积极性** |
| **收入分类分成** | 将预算收入按项目分为中央固定收入、地方固定收入、中央和地方分成收入；分成收入分为固定比例分成收入和调剂比例分成收入 | 使地方支出与其组织的收入**挂钩**的一种形式 |
| **总额分成** | 将地方组织的预算收入总额在中央和地方之间进行分成，**地方预算支出占地方组织总收入的比例即为地方总额分成比例**，其余为中央总额分成比例 | 也是**收支挂钩**的一种形式 |
| **定额上缴或定额补助** | 在中央核定的地方预算收支基础上，凡收入大于支出由地方**定额上缴**中央；凡支出大于收入由中央**定额补助** | —— |
| **分税制** | 按照税种划分中央和地方各自收入以解决支出需要的方法 | 现行体制 |

**逻辑链**：

```
财政支出划分三原则
   ├─ 与事权相对称 → 一级事权一级财力（统一规划归中央 / 因地制宜归地方）
   ├─ 公平性 → 纵向平衡 + 横向平衡
   └─ 权责结合 → 收支挂钩 + 财力支撑 + 收支平衡
                    ↓ 应用为我国五种具体做法
   统收统支 → 收入分类分成 → 总额分成 → 定额上缴/定额补助 → 分税制
   （集中度由高到低，收支挂钩程度由低到高）
```

### 考点4 政府间收入的划分（一）：税收收入划分的原则 ★★★★

| 原则 | 划分标准 | 举例 |
|---|---|---|
| **效率原则** | 以**征税效率的高低**为标准。适于中央集中征收的归入中央收入，相反划为地方收入 | 所得税一般由中央政府征收；土地税或财产税一般划为地方税 |
| **适应原则** | 以**税基的宽窄**为标准。税基宽的税种归中央政府，税基狭窄的归地方政府 | 增值税税基宽，应属中央税；房产税税基窄，应属地方税 |
| **恰当原则** | 以**税收负担的分配是否公平**为标准。税种归哪级政府，看哪级政府更能保证税收负担的公平分配 | 所得税划归中央政府 |
| **经济利益原则** | 以**增进经济利益**为标准。税收归属应以便利经济发展、不减少经济利益为标准 | 增值税、消费税划归中央，可以使货物在全国范围内畅通无阻 |

【巧思妙记】**效基公平利**（效率—税基—公平—经济）

### 考点5 政府间收入的划分（二）：划分方式与具体做法 ★★★★

**（1）税收收入划分的五种方式（税收分割）**

| 方式 | 内容 |
|---|---|
| **分割税额** | 先统一征税，再将税收收入总额按照一定比例在中央与地方政府之间加以分割，又称**收入分享**。我国以前实行的「总额分成」实际上就属于这种方式 |
| **分割税率** | 由各级财政对**同一课税对象**按照**不同的税率**征收 |
| **分割税种** | 按税种划分收入范围，确定哪些税种归中央、哪些归地方、哪些由中央与地方共享。但在这种方式下，**地方政府不享有等同于中央的税收立法权** |
| **分割税制** | 分别设立**中央税和地方税两个相互独立的税收制度和税收管理体系**，中央与地方**均享有相应的税收立法权**、税种的开征和停征权、税目的增减权和调整权，并有权管理和运用本级财政收入 |
| **混合型** | 综合运用上述四种方式中两种及两种以上的做法而形成的中央与地方税收管理体系。在现代经济社会条件下，通常采用混合型的税收分割方式 |

> 由于世界上绝大多数国家的税收收入占财政收入的比重都在 **90% 以上**，所以划分中央财政与地方财政收入主要体现在税收收入的划分上。

**（2）税收收入划分的具体做法（五条）**

```
划归中央政府：
  ① 与稳定国民经济有关的税种 + 与收入再分配有关的税种 → 个人所得税、企业所得税
     （所得税适于累进税，具稳定经济功能，被称为"自动稳定器"，也有调节收入分配功能）
  ② 税基流动性大的税种 → 个人所得税、公司所得税、增值税、销售税、遗产赠与税
     （避免出现"税收洼地"效应）
  ③ 进出口关税和其他收费 → 全部归中央
  ④ 与自然资源有关的税种（如资源税）→ 地区间分布不均匀的归中央，以免地区间税源不平衡

划归地方政府：
  ⑤ 税基流动性较小、税源分布较广（不易统一征收）的税种 → 房产税、土地增值税等
  ⑥ 与自然资源有关的税种，若自然资源在地区间分布均匀、税基不可流动 → 更适合归地方
```

**（3）我国中央与地方收入的划分（分税制口径）**
根据**事权与财力相结合**的原则，按税种划分中央与地方的收入：将**维护国家权益、实施宏观调控所必需的税种划分为中央税**；将**同经济发展直接相关的主要税种划分为中央与地方共享税**；将**适合地方征管的税种划分为地方税**。

**（4）理顺省以下政府间收入关系（改革内容）**

| 维度 | 要点 |
|---|---|
| 参照税种属性划分收入 | **省级收入或由省级分享较高比例**：税基流动性强、区域间分布不均、年度间收入波动较大的税收收入；**市县级收入或由市县级分享较高比例**：税基较为稳定、地域属性明显的税收收入。对金融、电力、石油、铁路、高速公路等领域税费收入，可作为省级收入，也可在相关市县间合理分配。除按规定上缴财政的国有资本经营收益外，**逐步减少直至取消按企业隶属关系划分政府间收入的做法** |
| 规范收入分享方式 | 税收收入应在省以下各级政府间明确划分，对**主体税种实行按比例分享**，结合各税种税基分布、收入规模、区域间均衡度等因素合理确定分享比例。对非税收入可采取**总额分成、分类分成、增量分成**等分享方式，逐步加以规范 |
| 适度增强省级调控能力 | 结合省级财政支出责任、区域间均衡度、中央对地方转移支付等因素，合理确定省级收入分享比例。基层「三保」压力较大的地区以及区域间人均支出差距较大的地区，应逐步提高省级收入分享比例。区域间资源分布不均的地区，省级可参与资源税收入分享 |

### 考点6 政府间财政管理权的划分 ★★★

**（1）政府预算管理级次**
我国实行**一级政府一级预算**，设立**中央，省、自治区、直辖市，设区的市、自治州，县、自治县、不设区的市、市辖区，乡、民族乡、镇五级预算**。
- 全国预算由**中央预算和地方预算**组成；地方预算由各省、自治区、直辖市总预算组成。
- 地方各级总预算由**本级预算和汇总的下一级总预算**组成；下一级只有本级预算的，下一级总预算即指下一级的本级预算。
- **没有下一级预算的，总预算即指本级预算。**

**（2）预算管理权限的划分**

| 预算管理主体 | 定位 | 具体职权 |
|---|---|---|
| **各级人民代表大会** | 审批与决算的**权力机关** | **审查**总预算草案和总预算执行情况的报告；**批准**本级预算和本级预算执行情况的报告 |
| 各级人大常委会 | —— | **监督**预算的执行；**审查和批准**预算的调整方案；**审查和批准**决算 |
| 各级人民代表大会财政经济委员会 | —— | 对预算草案初步方案及上一年预算执行情况、预算调整初步方案和决算草案进行**初步审查**，提出初步审查意见 |
| **各级人民政府** | 预算管理的**国家行政机关** | 编制预算、决算草案；向本级人大做关于预算草案的报告；组织预算的执行；**决定预备费的动用**；编制预算调整方案；监督预算执行等 |
| **各级财政部门** | 预算管理的**职能部门** | 具体编制预算、决算草案；具体组织预算的执行；**提出**预算预备费动用方案；具体编制预算的调整方案；定期报告预算的执行情况等 |
| 各部门 | —— | 编制本部门预算、决算草案；组织和监督本部门预算的执行；定期向本级政府财政部门报告预算的执行 |
| 各单位 | —— | 编制本单位预算、决算草案；按照国家规定上缴预算收入、安排预算支出，并接受国家有关部门的监督 |

> 预算管理权是指国家预算方针政策、预算管理法律法规的**制定权、解释权和修订权**；国家预决算的**编制和审批权**；预算执行、调整和监督权等。

**逻辑链**：

```
人大（权力机关）：审批预算 + 审批决算

```

### 考点7 分税制财政管理体制 ★★

**（1）内涵**
**分税制是财政分权管理体制的典型代表，也是市场经济国家普遍推行的一种财政管理体制模式。** 分税制是指在明确划分中央和地方政府事权和支出范围的基础上，按照**事权与财权财力统一**的原则，结合税种的特性，划分中央与地方的税收管理权限和税收收入，并辅以补助制的一种财政管理体制。

**（2）四层含义**

| 含义 | 内容 |
|---|---|
| **分事** | 按照一定社会管理和经济体制的要求，在各级政府间划分**社会管理权和经济管理权**，并以此为依据确定各级政府的**预算支出范围** |
| **分税** | 在划分事权和支出范围的基础上，按照**财权与事权相统一**的原则，在中央与地方之间划分税种，即将税种划分为**中央税、地方税和中央与地方共享税**，以划定中央和地方的收入来源 |
| **分权** | 中央与地方都对属于自己的税种有**开停征权、调整税目税率和减免税权**，同时赋予地方**开征地方性新税**的权力 |
| **分管** | 在分事和分税的基础上实行分级财政管理，建立**中央和地方两级税收征管体系**，设置**中央和地方两套税收征管机构**，分别负责中央税和地方税的征收管理工作 |

**（3）分税的方法**

| 方法 | 内容 |
|---|---|
| **按税种划分——完全形式** | **只设中央税和地方税** |
| **按税种划分——不完全形式** | 除划定中央税和地方税之外，还设置**共享税**。共享办法大体有：①**附加式**：中央征正税，地方征附加，如伊朗的所得税和关税；②**返还式**：由中央统一征收，再按一定比例返还给地方，如巴西所得税和工业制成品税（由联邦统一征收，再按 **20%** 返还给州政府）；③**比例分成式**：统一征收同时规定中央与地方分配比例，如德国的个人所得税（联邦和州各占 **43%**，县市占 **14%**） |
| **按税源实行分率分征** | 对**同一税源**各级政府按**不同税率**征收。如美国，将所得税作为联邦的主体税种，联邦通过较高的税率将所得税的大部分税源集中为联邦支配，州和地方只能以较低税率征收所得税 |

### 考点8 我国分税制管理体制的主要内容 ★★

**（1）中央与地方事权和支出的划分**

| 事项 | 事权与支出责任划分 |
|---|---|
| **社会保障** | ①**养老保险**：信息复杂程度低且容易收集，适合由**中央管理**，但必须有制度约束；②**医疗保险**：信息复杂程度高，一般由中央与地方共管，**在我国应该以地方管理为主，中央提供帮助**；③**工伤保险、生育保险、失业保险**：可由**地方自行管理** |
| **公共卫生** | ①**传染病及免疫业务**有明显的外部性特征，该类支出责任该由**中央承担或中央委托地方实施**；②**普通的公共卫生支出和管理**信息处理比较复杂、影响范围比较有限，较为适宜由**地方政府负担** |
| **教育** | ①**义务教育支出**：中小学教育信息极度复杂，根据信息复杂性原则，应该由**地方政府管理**；②**高等教育和科研支出**：服务范围较广、跨地域外部性特征明显，支出的主要责任应该在**中央和省级政府** |
| **跨区域重大项目的建设和维护** | ①交通建设要区分跨境交通和地方性交通：跨境高速公路、国道和铁路等跨境重点项目外部性较强，建设的主要资金来源应由**中央承担**；地方性交通基础设施建设责任主要由**地方**承担。②海域和流域管理、航运、水利调度、大江大河治理、全流域国土整治、全国性生态和环保重点项目建设等具有一定辖区外溢效应且很难协调，支出责任应由**中央承担并统一管理** |
| **涉及全国市场统一标准的管理** | 在全国范围内销售的食品、药品，其安全环境具有较大的全域正外部性，只有由**中央**承担相应的支出责任及管理执行责任，才能使外部性问题内部化 |
| **关系国家安全的支出** | 国防、边境安全、界河管理等支出是典型的全国性公共物品，并涉及国家主权利益，应该由**中央统一协调和监管**及承担相应的支出责任 |
| **司法支出** | 一些司法服务具有全国性公共物品的性质，需要考虑其强烈的外部性，将**部分司法支出责任集中到中央**，是保障我国司法公正性的重要手段 |

> **来源冲突提示**：关于「养老保险」的归属，一种表述为「适合由中央管理」；另一种表述为「养老保险与医疗保险应该以地方管理为主，中央提供帮助」。两种表述并存，**以真题答案验证（2021年多选），「养老保险适合中央管理」为正确说法**，建议按前者掌握。

**（2）中央与地方收入的划分**
根据事权与财力相结合的原则，按税种划分中央与地方的收入。将维护国家权益、实施宏观调控所必需的税种划分为**中央税**；将同经济发展直接相关的主要税种划分为**中央与地方共享税**；将适合地方征管的税种划分为**地方税**。

**（3）中央财政对地方财政税收返还数额的确定**
之所以发生「税收返还」，主要是因为实行分税制，按新税制设置的税种划分为中央收入和地方收入后，中央和地方之间的收入发生互转，但总体来说是**地方收入净上划中央**。为了保持当时地方既得利益格局，建立中央财政在收入增量中逐步增长机制，达到中央财力稳定增长的目标，中央将净上划中央收入返还地方，包括**基数返还和递增返还**。中央的税收返还制度就其性质而言，是一种**转移支付**，是年年都有的**经常性收入返还**。

### 考点9 政府间转移支付的特点、理论依据 ★★

**（1）含义与特点**
最早提出转移支付概念的是著名经济学家**庇古**，他在 **1928 年**出版的**《财政学研究》**中第一次使用这一概念。政府间转移支付是指一个国家的各级政府彼此之间在**既定的职责范围、支出责任和税收划分框架下**所进行的**财政资金的相互转移**。包括上级政府对下级政府的各项补助、下级政府向上级政府的上解收入、共享税的分配以及发达地区对不发达地区的补助等。可归纳为**纵向转移支付和横向转移支付**两种形式。

**三大特点**：
1. 政府间转移支付的范围**只局限于政府之间**；
2. 政府间转移支付是**无偿的支出**；
3. 政府间转移支付**并非政府的终极支出**。

**（2）理论依据（四条）**

| 依据 | 内容 |
|---|---|
| 纠正政府间的**纵向财政失衡** | 某一级政府出现财政赤字，而其他级次政府却出现盈余；通过纵向转移支付来进行财力的再分配 |
| 纠正政府间的**横向财政失衡** | 各地方政府收入增长能力与支出需求存在差异造成；由发达地区向落后地区适当转移财力 |
| 纠正某些公共物品或服务的**外部性** | ①地方性公共物品或服务的受益或受损范围很可能会超出地方政府辖区的界限，使其他地区在受益或受损的同时并不承担任何成本或没有得到任何补偿；②某些地方性公共物品或服务出现提供数量不足和质量不佳的问题，如**义务教育、公共卫生**等；③解决方式如中央政府给予地方政府补助金，或通过向地方政府实施**有条件的转移支付** |
| 加强中央财政对地方财政的**宏观调控** | 经济繁荣时**减少**对地方的转移支付，以限制地方支出；经济萧条时**增加**对地方的转移支付以激励地方发展经济；在地方遭到严重自然灾害等非正常事件时，中央政府采用**有条件非配套转移支付**帮助地方政府渡过难关 |

【巧思妙记】**纵横外控**（纵向失衡、横向失衡、外部性、宏观调控）

**（3）纵向均衡与横向均衡**
- **纵向均衡**：各级政府的财政资金来源与各自的支出责任或事权范围相对称，使各级政府在履行各自职责时有必要的财力保障。
- **横向均衡**：基本公共物品的供给标准和供给数量在各地区的**均等化**，如义务教育、公共安全、基本医疗保健、交通设施等。
- 政府间调节制度包括**各级预算间的纵向调节和各地区预算间的横向调节**；调节的**主要手段**是政府间的转移支付，调节的**目标**是使公共资金公平分配和有效使用，并最终达到各级政府**事权和财权的统一**。

**（4）政府间转移性收支（《预算法实施条例》）**
- **转移性收入**：上级税收返还和转移支付、下级上解收入、调入资金，以及按照财政部规定列入转移性收入的无隶属关系政府的无偿援助。
- **转移性支出**：上解上级支出、对下级的税收返还和转移支付、调出资金，以及按照财政部规定列入转移性支出的给予无隶属关系政府的无偿援助。
> 另一来源表述：转移性支出主要有捐赠支出、债务利息支出和补助支出（来源表述差异，素材并列保留）。

### 考点10 政府间转移支付的种类、一般方法 ★★

**（1）种类**

| 划分标准 | 类别 | 内容 |
|---|---|---|
| 根据地方政府使用补助资金权限的大小 | **无条件转移支付** | 又称**收入分享或一般性补助**。不附带使用条件、不指定资金用途，由受助者自主决定和支配。重点解决下级政府的**财政收入与责任不对称**的问题 |
| 根据地方政府使用补助资金权限的大小 | **有条件转移支付** | 又称**专项补助**。明确规定了资金用途，受助者必须按指定用途使用补助金。体现上级政府对下级政府定向支援或委托下级政府办理某项公共服务的意图。可分为**配套补助和非配套补助** |
| 根据政府间的关系 | **纵向转移支付** | 自上而下的纵向资金转移，主要方法是拨付补助金；补助金又分为一般补助金和专项补助金。从广义上说，**共享税或税收分成也属于纵向转移支付** |
| 根据政府间的关系 | **横向转移支付** | 指发达地区直接向落后地区转移财力，实行地区间互助。其功能在于调整**横向失衡** |
| 根据政府间的关系 | **混合转移支付** | 纵向转移支付和横向转移支付的结合，**以纵向转移支付为主，辅之以横向转移支付** |

**（2）一般方法（四种模式）**

| 模式 | 说明 |
|---|---|
| **财政收入能力均等化模式** | **不考虑地区的支出需求**，只考虑地区间财政能力的均等化，依照某种收入指标确定转移支付对象与转移支付额 |
| **支出均衡模式** | **不考虑地区间财政收入能力的差异**，只考虑地区间支出需求的差异。**主要被一些发展中国家所采用** |
| **收支均衡模式** | 通过计算各地**标准收入能力和标准支出需求**，根据**收支之间的差额**确定对各个地区的财政转移支付额。不仅考虑了地区的财政能力，也考虑了地区的支出需求，**比前两种模式更为科学、全面、规范** |
| **有限的财政收入能力—支出需求均衡模式** | 「有限」是指确定影响财政收入与支出需求的因素都在**有限的范围内**。按全国平均税率和平均收费标准求出各地区应征得的各项税费（有限财政收入），测算支出需求时只包括最基本、最必要的公共服务项目（有限支出需求），在最基础的经常性项目上实现全国各地区的均衡服务水平。**有限的支出需求与有限的财政收入之间的差额就是转移支付的确定依据**。对数据和测算技术的要求不高，适用于经济基础较差、中央财力不足、转移支付规模受到一定限制、技术和管理水平都较低的国家；可作为一种逐步向比较规范的「收支均衡模式」过渡的模式 |

### 考点11 我国政府间转移支付制度 ★★★

**（1）现行中央对地方转移支付的种类**

| 类型 | 内容 |
|---|---|
| **一般性转移支付** | ①均衡地区间财力差距的**均衡性转移支付**，**不规定具体用途**，由接受补助的省级政府根据本地区实际情况统筹安排；②对**革命老区、少数民族地区、边疆地区、穷困（贫困）地区**的财力补助；③其他一般性转移支付，如作为国家增支减收政策配套措施的**调整工资转移支付、农村税费改革转移支付** |
| **专项转移支付** | 上级政府为了实现特定的经济和社会发展目标给予下级政府，并由上级政府规定用途安排使用的预算资金。我国在**基础设施建设、农业、教育卫生、社会保障以及环境保护**等方面均设立了专项转移支付项目。按事权和支出责任划分为**委托类、共担类、引导类、救济类、应急类五类** |
| **共同事权转移支付** | 为配合财政事权和支出责任划分改革，履行中央承担的共同事权的支出责任，保障地方落实相关政策所需财力，提高地方履行共同财政事权的能力方面给予的补助。包括**城乡义务教育补助经费、学生资助补助经费、就业补助资金、困难群众救助补助资金、基本公共卫生服务补助资金、城乡保障性安居工程资金**等。2019年，为与财政事权和支出责任划分相衔接，我国在涉及一般性转移支付和专项转移支付的基础上**新设共同事权转移支付，暂列一般性转移支付项下** |

**专项转移支付五类辨析**：

| 类别 | 事权归属 | 设立目的 | 资金安排 |
|---|---|---|---|
| **委托类** | 中央事权 | 中央委托地方实施而相应设立 | 中央政府**足额安排预算，不要求地方安排配套资金** |
| **共担类** | 中央与地方共同事权 | 中央将应分担部分委托地方实施而设立 | 依据公益性、外部性等因素**明确分担标准或者比例**，由中央政府和地方政府按各自应分担数额安排资金 |
| **引导类** | 地方事权 | 中央为鼓励和引导地方按照中央的政策意图办理事务而设立 | 中央政府**严格控制资金规模** |
| **救济类** | 地方事权 | 中央为帮助地方应对因**自然灾害**等发生的增支而设立 | 中央政府严格控制资金规模 |
| **应急类** | 地方事权 | 中央为帮助地方应对和处理**影响区域大、影响面广的突发事件**而设立 | 中央政府严格控制资金规模 |

**（2）中央对地方转移支付制度的改革和完善**

| 方面 | 要点 |
|---|---|
| **优化转移支付结构** | 合理划分中央和地方事权与支出责任，**增加一般性转移支付、清理规范专项转移支付**，形成以均衡地区间基本财力、由地方政府统筹安排使用的一般性转移支付为主体，一般性转移支付和专项转移支付相结合的转移支付制度 |
| **完善一般性转移支付制度** | ①**清理整合**一般性转移支付；②建立一般性转移支付**稳定增长机制**：将一般性转移支付占比提高到 **60% 以上**；③**加强管理** |
| **从严控制专项转移支付、规范分配和使用** | ①严控新设专项；②规范资金分配；③建立健全专项转移支付**定期评估和退出机制**；④严控资金配套要求（除按国务院规定应当由中央和地方共同承担的事项外，中央在安排专项转移支付时**不得要求地方政府承担配套资金**）；⑤严格资金使用。<br>**分配方法**：专项转移支付可采取**项目法或因素法**进行分配。对用于国家重大工程、跨地区跨流域的投资项目以及外部性强的重点项目，主要采取**项目法**分配，实施**项目库管理**；对具有地域管理信息优势的项目，主要采取**因素法**分配，选取客观因素、确定合理权重，按照科学规范的分配方式进行分配 |
| **强化转移支付预算管理** | ①**及时下达**：中央对地方的一般性转移支付在全国人民代表大会批准预算后 **30 日内**下达，专项转移支付在 **90 日内**下达；省级政府接到中央转移支付后应在 **30 日内**正式下达到本行政区域县级以上各级政府；县级以上各级政府提前下达下一年的转移支付预计数，一般性转移支付预计数比例一般**不低于 90%**，专项转移支付预计数比例一般**不低于 70%**。②**信息公开**：中央对地方转移支付预算安排及执行情况在全国人大批准后 **20 日内**由财政部向社会公开。③**绩效评价** |

### 考点12 政府财政事权与支出责任的调整改革 ★

**（1）推进财政事权和支出责任划分改革的原则（五条）**
1. **体现基本公共服务收益范围**（全国的、地区的、跨省的）；
2. **兼顾政府职能和行政效率**（信息复杂性）；
3. **实现权、责、利相统一**（中央事权上划、地方事权下放、明确共同事权）；
4. **激励地方政府主动作为**（激励相容）；
5. **做到支出责任与财政事权相适应**（谁的财政事权谁承担支出责任）。

**（2）改革的主要内容**

| 方面 | 要点 |
|---|---|
| **推进中央与地方财政事权划分** | ①**适度加强中央的财政事权**：强化中央的财政事权履行责任，中央的财政事权原则上由中央直接行使，通过中央本级安排支出。逐步将国防、外交、国家安全、出入境管理、国防公路、国界河湖治理、全国性重大传染病防治、全国性大通道、全国性战略性自然资源使用和保护等基本公共服务**确定或上划为中央的财政事权**。②**保障地方履行财政事权**：逐步将社会治安、市政交通、农村公路、城乡社区事务等受益范围地域性强、信息较为复杂且主要与当地居民密切相关的基本公共服务**确定为地方的财政事权**。③**减少并规范中央与地方共同财政事权**：根据基本公共服务的受益范围、影响程度，按事权构成要素、实施环节，分解细化各级政府承担的职责。④**建立财政事权划分动态调整机制** |
| **完善中央与地方支出责任划分** | ①中央的财政事权由**中央**承担支出责任；②地方的财政事权由**地方**承担支出责任；③中央与地方共同财政事权**区分情况划分支出责任** |
| **加快省以下财政事权和支出责任划分** | ①清晰界定省以下财政事权和支出责任；②理顺省以下政府间收入关系；③完善省以下转移支付制度 |

**共同财政事权支出责任划分的四种情形**：

| 情形 | 典型事权 | 支出责任划分 |
|---|---|---|
| 体现国民待遇和公民权利、涉及全国统一市场和要素自由流动 | 基本养老保险、基本公共卫生服务、义务教育等 | 可以研究制定**全国统一标准**，并由**中央与地方按比例或以中央为主**承担支出责任 |

### 表1 财政管理体制的类型（我国财政支出划分曾采用的方法）

| 类型 | 核心做法 | 关键特征 |
|---|---|---|
| **统收统支** | 地方全部收入上缴中央，地方所需支出统一由中央拨付；收支两条线 | 财权财力高度集中；非正常时期有利于资金使用效率，**不利于调动地方积极性** |
| **收入分类分成** | 预算收入按项目分为中央固定收入、地方固定收入、中央和地方分成收入；分成收入分固定比例分成和调剂比例分成 | 地方支出与其组织的收入**挂钩** |
| **总额分成** | 地方组织的预算收入总额在中央和地方之间分成；地方预算支出占地方组织总收入的比例即地方总额分成比例 | **收支挂钩** |
| **定额上缴或定额补助** | 中央核定地方预算收支：收入＞支出由地方定额上解中央；支出＞收入由中央定额补助 | 定额管理 |
| **分税制** | 按税种划分中央和地方各自收入以解决支出需要 | 现行体制；分事、分税、分权、分管 |

> **补充辨析（素材口径）**：单一制国家与联邦制国家中，**中央政府（联邦政府）都是国家利益（整体利益）的代表者，地方政府是地方利益的代表者**；**财政联邦主义从某种意义上说就是财政分权**。素材未对「财政单一制」作专门展开，**此处不作延伸**。

## 四、公式与计算

### 公式1 财政收入能力均等化模式下的转移支付额

```
某地区应得到的转移支付额
 = 该地区人口数 ×（全国地方税税基总和 / 全国总人口数 − 该地区地方税基 / 该地区人口数）× 标准税率
```

**例题（数字演算，非真题数据）**：假设全国地方税税基总和为 20000 亿元，全国总人口为 10 亿人；某地区人口为 1000 万人，该地区地方税税基为 150 亿元；标准税率为 10%。计算该地区应得到的转移支付额。

**演算**：
```
全国人均地方税税基 = 20000 亿元 ÷ 10 亿人 = 2000 元/人
该地区人均地方税税基 = 150 亿元 ÷ 1000 万人 = 1500 元/人
人均税基差额 = 2000 − 1500 = 500 元/人
应得转移支付额 = 1000 万人 × 500 元/人 × 10% = 5 亿元
```
**结论**：该地区应得到转移支付额 **5 亿元**（人均税基低于全国平均，故为接受补助地区）。

### 公式2 收支均衡模式下的转移支付额

```
某地区应得到的转移支付额 = 该地区标准财政支出 − 该地区财政标准收入
```

**例题（数字演算，非真题）**：某地区标准财政支出为 120 亿元，标准财政收入能力为 85 亿元；另一地区标准财政支出 120 亿元，标准财政收入能力 130 亿元。判断两地区的转移支付关系。

**演算**：
```
甲地区：120 − 85 = +35 亿元 → 收入小于支出，为接受补助地区，应得转移支付额 35 亿元
乙地区：120 − 130 = −10 亿元 → 收入大于支出，为转出地区，不获得补助
```
**结论**：收支均衡模式同时考虑财政能力与支出需求，**收入小于支出则为接受补助地区，收入大于支出即为转出地区**。

### 税收返还与分成中的数字演算（素材给定数据）

**税收返还机制**：实行分税制后中央与地方收入发生互转，总体上是**地方收入净上划中央**；为保持当时地方既得利益格局，中央将净上划中央收入返还地方，包括**基数返还**和**递增返还**。税收返还性质上**是一种转移支付**，是年年都有的**经常性收入返还**。（素材未给出基数返还与递增返还的具体计算比例，此处不作延伸。）

**（1）返还式（巴西）**：巴西的所得税和工业制成品税由联邦统一征收，再按 **20%** 返还给州政府。
```
若某年联邦统一征收 100 亿元 → 返还州政府 100 × 20% = 20 亿元，联邦留成 80 亿元
```

**（2）比例分成式（德国）**：德国的个人所得税统一征收同时规定统一分配比例，**联邦和州各占 43%，县市占 14%**。
```
若某年征收个人所得税 100 亿元
 → 联邦分得 43 亿元，州分得 43 亿元，县市分得 14 亿元（合计 100 亿元）
```

**（3）转移支付预算管理的期限与比例（必背数字）**

| 项目 | 数字 |
|---|---|
| 一般性转移支付占比目标 | 提高到 **60%** 以上 |
| 中央对地方一般性转移支付下达时限（全国人大批准预算后） | **30 日**内 |
| 中央对地方专项转移支付下达时限 | **90 日**内 |
| 省级政府接到中央转移支付后下达到县级以上各级政府 | **30 日**内 |
| 提前下达下一年度一般性转移支付预计数比例 | 一般不低于 **90%** |
| 提前下达下一年度专项转移支付预计数比例 | 一般不低于 **70%** |
| 财政部向社会公开中央对地方转移支付预算安排及执行情况（全国人大批准后） | **20 日**内 |

## 五、高频考点速记卡

1. **Q：政府间财政关系包括哪五个方面？**
   A：财政事权划分（事该由哪级政府干）、支出责任划分（钱该由哪级政府出）、收入划分、转移支付制度、预算管理制度。

2. **Q：政府间财政关系的影响因素有哪些？**
   A：大国与小国的差异、路径依赖、财权财力与事权之间的关系。

3. **Q：财政分权理论有哪四大理论？**
   A：公共物品和服务理论、集权分权理论、财政联邦主义、俱乐部理论。

4. **Q：公共物品和服务理论的代表人物及结论？**
   A：沃伦斯·欧茨（《财政联邦主义》）——地方政府为其辖区提供相应的产出水平一般要比中央政府对所有辖区提供统一的产出水平更加符合帕累托效率；查尔斯·提布特——「用脚投票」。

5. **Q：财政联邦主义的精髓是什么？**
   A：使地方政府依据**合适与合意的财政自主权**进行决策。财政联邦主义从某种意义上说就是财政分权。

6. **Q：俱乐部理论研究什么？奠基人是谁？**
   A：研究**非纯公共物品的配置效率问题**；现代俱乐部经济理论的真正奠基人是**布坎南和蒂鲍特**；论证了**地方政府的适当规模问题**。

7. **Q：政府间事权划分的三原则？**
   A：外部性原则（受益范围原则）、信息复杂性原则、激励相容原则（调动积极性原则）。

8. **Q：实现激励相容必须满足哪四个条件？**
   A：地方政府自治条件、共同市场条件、预算硬约束条件、权力制度化条件。（不含「预算软约束」）

9. **Q：绝大部分国家将哪类事务划归中央专门管理？**
   A：**外交事务**（只有部分联邦制国家容许成员国保留部分外交权）。

10. **Q：财政支出划分的三原则？**
    A：与事权相对称原则、公平性原则、权责结合原则。

11. **Q：「收支挂钩」体现哪项原则？**
    A：**权责结合原则**（在地方组织的收入中解决其支出的需要）。

12. **Q：我国财政支出划分曾采用哪五种方法？**
    A：统收统支、收入分类分成、总额分成、定额上缴或定额补助、分税制。

13. **Q：哪种方法在政治经济非正常时期有利于资金使用效率，但不利于调动地方积极性？**
    A：**统收统支**。

14. **Q：税收收入划分的四原则？**
    A：效率原则（征税效率）、适应原则（税基宽窄）、恰当原则（税收负担分配是否公平）、经济利益原则（增进经济利益）。

15. **Q：税收收入划分的五种方式？**
    A：分割税额、分割税率、分割税种、分割税制、混合型。（不含「分割税权」）

16. **Q：「中央与地方均享有相应的税收立法权」属于哪种方式？**
    A：**分割税制**。

17. **Q：哪些税种划归中央政府？**
    A：与稳定国民经济有关的税种和与收入再分配有关的税种（个人所得税、企业所得税）；税基流动性大的税种；进出口关税和其他收费；地区间分布不均匀的自然资源税。

18. **Q：我国预算管理级次？**
    A：一级政府一级预算，分中央、省、自治区、直辖市、设区的市/自治州、县/自治县/不设区的市/市辖区、乡/民族乡/镇**五级**。

19. **Q：审批预决算的权力机关是？决定预备费动用方案的是？提出预备费动用方案的是？**
    A：各级**人民代表大会**是权力机关；各级**人民政府**决定预备费的动用；各级**财政部门**提出预算预备费动用方案。

20. **Q：确立政府间财政关系的管理体制是？**
    A：**预算管理体制**（它是财政管理体制的主导环节，占有核心地位）。

21. **Q：分税制的四层含义？**
    A：**分事、分税、分权、分管**。

22. **Q：分税制按税种划分的「不完全形式」指什么？共享办法有哪三种？**
    A：除中央税和地方税之外还设置**共享税**；共享办法有附加式（伊朗）、返还式（巴西，按 20% 返还州政府）、比例分成式（德国，联邦和州各 43%、县市 14%）。

23. **Q：我国中央税、共享税、地方税如何划分？**
    A：维护国家权益、实施宏观调控所必需的税种→中央税；同经济发展直接相关的主要税种→中央与地方共享税；适合地方征管的税种→地方税。

24. **Q：税收返还包括哪两部分？性质上是什么？**
    A：**基数返还和递增返还**；性质上是一种**转移支付**，是年年都有的**经常性收入返还**。

25. **Q：政府间转移支付的三大特点？**
    A：范围只局限于政府之间；是无偿的支出；并非政府的终极支出。

26. **Q：实行政府间转移支付的理论依据？**
    A：纠正政府间的纵向财政失衡、纠正政府间的横向财政失衡、加强中央财政对地方财政的宏观调控、纠正某些公共物品或服务的外部性。（纵横外控）

27. **Q：政府间转移支付的一般方法有哪四种模式？**
    A：财政收入能力均等化模式、支出均衡模式、收支均衡模式、有限的财政收入能力—支出需求均衡模式。（不含「因素均衡模式」）

28. **Q：我国中央对地方转移支付的类型？**
    A：一般性转移支付、专项转移支付、共同事权转移支付。

29. **Q：专项转移支付分哪五类？**
    A：委托类、共担类、引导类、救济类、应急类。其中引导类、救济类、应急类按事权和支出责任划分均属于**地方事权**。

30. **Q：推进财政事权和支出责任划分改革的原则？**
    A：体现基本公共服务收益范围、兼顾政府职能和行政效率、实现权责利相统一、激励地方政府主动作为、做到支出责任与财政事权相适应。

31. **Q：推进中央与地方财政事权划分的总体方向？**
    A：**适度加强中央的财政事权、保障地方履行财政事权、减少并规范中央与地方共同财政事权、建立财政事权划分动态调整机制**。

**【2014·单选】以税基的宽窄为标准划分中央与地方收入，这所体现的原则是（　）。**

**答案：B**

**答案：C**

**【2016/2019·单选】精髓在于使地方政府拥有合适与合意的财政决策自主权的理论是（　）。**

**答案：C**
**解析**：财政联邦主义从某种意义上说就是财政分权，即给予地方政府一定的税收权力和支出责任范围，并允许地方政府自主决定其预算支出规模与结构，其精髓在于使地方政府依据合适与合意的财政自主权进行决策。

A. 公共产品及服务理论　B. 集权分权理论　C. 俱乐部理论　D. 财政联邦主义
**答案：D**
**解析**：财政联邦主义即给予地方政府一定的税收权力和支出责任范围，并允许地方政府自主决定其预算支出规模与结构。

**【2020·单选】在税收收入划分方式中，"中央与地方均享有相应的税收立法权"属于（　）。**

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把「财政支出划分原则」和「我国财政支出划分的具体做法」混为一谈 | 原则只有 **3 个**（与事权相对称、公平性、权责结合）；做法有 **5 种**（统收统支、收入分类分成、总额分成、定额上缴/补助、分税制）。总额分成是**做法不是原则** |
| 2 | 把「税收收入划分方式」和「税收收入划分原则」混为一谈 | 方式 **5 种**（分割税额、税率、税种、税制、混合型）；原则 **4 个**（效率、适应、恰当、经济利益） |
| 3 | 混淆「分割税种」与「分割税制」 | 关键看**税收立法权**：分割税制下中央与地方**均享有**税收立法权；分割税种下地方**不享有**等同于中央的税收立法权 |
| 4 | 多选误选「分割税权」 | 税收收入划分**没有**「分割税权」这种方式 |
| 5 | 把「预算软约束」当成激励相容的条件 | 是**预算硬约束**条件；四条件记「制度约束、市场自治」（权力制度化＋地方政府自治＋共同市场＋预算硬约束） |
| 6 | 认为外交、公安、内政、教育都归中央专门管理 | **绝大部分国家只把外交事务划归中央专门管理**；公安仅事关国家主权的部分（国籍、出入境）归中央，警察由中央与地方共同管辖 |
| 7 | 认为当代世界各国司法体制「均为高度集权」 | 分**三类**：高度集权、集权为主分权为辅、分权 |
| 8 | 把「统收统支」和「总额分成」的效果记反 | 统收统支＝收支两条线、高度集中，**非正常时期提高效率但不利调动地方积极性**；总额分成＝**收支挂钩** |
| 9 | 误以为「收支挂钩」体现与事权相对称原则 | 收支挂钩是**权责结合原则**的第一层含义 |
| 10 | 把养老保险和医疗保险的归属记混 | **养老保险适合中央管理**（信息复杂度低、易收集）；**医疗保险以地方管理为主、中央提供帮助**；工伤、生育、失业保险**地方自行管理** |
| 11 | 认为所有公共卫生支出都归中央 | 只有**传染病及免疫业务**归中央（或委托地方实施）；**普通**公共卫生支出归地方 |
| 12 | 把义务教育归中央或省级 | 义务教育信息极度复杂，按**信息复杂性原则归地方管理**；高等教育和科研的主要责任在**中央和省级** |
| 13 | 混淆人大、政府、财政部门的预备费职权 | 政府**决定**动用，财政部门**提出**动用方案 |
| 14 | 把「审查和批准决算」当成人大职权 | 人大是**审查总预算草案＋批准本级预算**；**审批决算、审批调整方案、监督执行**是**人大常委会** |
| 15 | 认为政府间转移支付是政府的终极支出 | 转移支付**并非政府的终极支出**，且**只局限于政府之间**、是**无偿**的 |
| 16 | 把「加强中央宏观调控」从理论依据中漏掉 | 四条记「**纵横外控**」：纵向失衡、横向失衡、外部性、宏观调控 |
| 17 | 混淆四种转移支付模式的考虑因素 | 只考虑能力→财政收入能力均等化；只考虑需求→支出均衡（发展中国家用）；两者都考虑→收支均衡（最科学全面规范）；有限范围内两者→有限的财政收入能力—支出需求均衡 |
| 18 | 多选误选「因素均衡模式」 | 四种模式里**没有**因素均衡模式；**因素法**只是专项转移支付的分配方法 |
| 19 | 把引导类、救济类、应急类专项转移支付当成中央事权 | 三类都属于**地方事权**，只是由中央设立专项（引导/救济/应急），且中央政府**严格控制资金规模** |
| 20 | 把「调整工资转移支付」「农村税费改革转移支付」「民族地区转移支付」当成专项 | 它们都是**一般性转移支付**；基础设施、农业、教育卫生、社保、环保才是专项 |
| 21 | 混淆 60%、90%、70%、30 日、90 日、20 日 | 一般性转移支付**占比 60% 以上**；提前下达**一般性 90%、专项 70%**；人大批准后**一般性 30 日、专项 90 日**下达；财政部**20 日**内公开 |
| 22 | 把「分事、分税、分权、分管」的张冠李戴 | 分事＝划社会管理权和经济管理权定支出范围；分税＝划分税种定收入来源；分权＝开停征权/税目税率/减免税权；分管＝两级征管体系、两套征管机构 |
| 23 | 认为税收返还是「一次性」的 | 税收返还包括**基数返还和递增返还**，是年年都有的**经常性收入返还**，性质上是一种转移支付 |
| 24 | 把省以下收入划分记反 | **省级分享较高比例**＝税基流动性强、区域间分布不均、年度间收入波动较大；**市县级**＝税基较为稳定、地域属性明显 |
| 25 | 认为共同财政事权一律按比例分担 | 分四种情形：全国统一标准按比例或以中央为主／按外溢程度按比例或中央适当补助／中央地方各自机构各自承担／中央定标准地方执行各自承担 |
