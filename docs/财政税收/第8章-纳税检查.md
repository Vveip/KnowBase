# 第8章 纳税检查

> **本章考情**：较难掌握的**超级重要章节**。2026 年新教材将「纳税检查」**独立为第8章**（旧教材中它是第7章「税务管理」下的一节），本章是新增重点章。
> - **考试分值**：16-18 分（另一来源统计：总计 20 分，共 13 题，其中单项选择题 6 道/6 分、多项选择题 2 道/4 分、案例分析题 5 道/10 分）。
> - **考试题型**：单选题、多选题、案例分析题。
> - **章节地位**：本章综合考查**税务处理和会计处理的结合**。增值税和消费税的纳税检查侧重考查**正确的会计分录和调账分录**；企业所得税的纳税检查侧重考查出现**税会差异时的纳税调整处理**。考试并不要求写出完整会计分录，只需要判断选项给出的会计分录是否正确，因此要掌握判断的方法和技巧，课下多练习典型业务的账务处理题。
> - **高频考点**：账务调整的基本方法；增值税会计科目的设置；销项税额的检查；销售收入的检查；不得税前扣除项目的检查。

## 二、知识点精讲

### 考点1 纳税检查的概念 ★★

**核心概念**：纳税检查是**税务机关**根据国家税法和财务会计制度规定，对纳税人履行纳税义务的情况进行检查和监督，以发挥税收职能作用的管理活动。

| 要素 | 内容 |
|---|---|
| **主体** | 税务机关 |
| **客体** | 纳税人，同时包括**代扣代缴义务人、代收代缴义务人、纳税担保人** |
| **对象** | 纳税人所从事的经济活动和各种应税行为，以及履行纳税义务的情况 |
| **依据** | 国家的各种税收法规、会计法规和企业财务制度；**当税收法规和其他财会制度发生冲突时，以税收法规为准** |

**纳税检查的必要性（三点）**：① 纳税检查是行使财政监督职能的具体体现；② 纳税检查是当前经济形势的客观要求；③ 纳税检查是搞好征管工作的有力保证。

**纳税检查的范围**：

| 范围 | 要点 |
|---|---|
| 检查资料 | 纳税人和扣缴义务人的账簿、凭证、报表等有关资料；责成提供各种资料 |
| 检查场所 | 到纳税人的**生产、经营场所和货物存放地**检查应纳税的商品、货物或者其他财产（**不能到生活居住场所**） |
| 询问 | 询问纳税人、扣缴义务人与纳税有关的问题和情况 |
| 查询存款账户权 | 经**县以上税务局（分局）局长**批准，凭**全国统一格式的检查存款账户许可证明**，查询从事生产、经营的纳税人、扣缴义务人在银行或者其他金融机构的存款账户 |
| 查询储蓄存款 | 税务机关在调查税收违法案件时，经**设区的市、自治州以上税务局（分局）局长**批准，可以查询案件涉嫌人员的储蓄存款。查询所获得的资料**不得用于税收以外的用途** |
| 检查托运邮寄 | 到**车站、码头、机场、邮政企业及其分支机构**检查纳税人托运、邮寄应纳税商品、货物或者其他财产的有关单据、凭证和有关资料 |

**速记口诀**：「主体税务机关，客体四类人（纳税人＋扣缴义务人＋担保人），生活场所不能进，县批查账户、市批查储蓄，资料不得他用。」

### 考点2 纳税检查的基本方法 ★★

**分类框架**：

| 分类标准 | 方法 |
|---|---|
| 检查的**范围、内容、数量和查账粗细**不同 | 详查法、抽查法 |
| **查账顺序**不同 | 顺查法、逆查法 |
| **与检查资料之间的相互关系** | 联系查法、侧面查法 |
| 独立方法 | 盘存法、分析法 |

**1. 详查法 vs 抽查法**

| 方法 | 含义 | 特点/适用 |
|---|---|---|
| **详查法** | 对被查期内的全部凭证、账册、报表和其他会计资料，进行全面、系统、细致检查 | 一般适用于**经济业务比较简单、会计核算制度不健全和财务管理比较混乱的企业**，以及立案侦查的经济案件 |
| **抽查法** | 对被查期内的凭证、账册、报表和其他会计资料，抽出一部分有目的地进行重点检查 | **抽查效果的好坏，关键在于抽查对象的确定** |

**2. 顺查法 vs 逆查法**

```
顺查法：会计凭证 → 账簿 → 报表 → 纳税情况
        特点：比较系统、全面，运用比较简单；但工作量大，重点不够突出

逆查法：报表 → 账簿 → 凭证（从经济事项的结果逆向追查其原始状况）
        特点：通过对有关资料进行分析比较，容易发现线索，
              便于抓住重点，目标比较明确，检查效果也较显著
```

**3. 联系查法 vs 侧面查法**

| 方法 | 含义 |
|---|---|
| **联系查法** | 对账证之间、账账之间、账表之间进行相互对照检查，包括**账内联系法和账外联系法** |
| **侧面查法** | 根据平时掌握的征管、信访资料和职工群众反映的情况，对有关账簿记录进行核查 |

**4. 盘存法**：盘点清查企业的**货币资金、存货和其他物资等实物资产**，对照账面余额，来推算检查企业反映的生产经营成本及推算生产经营收入是否正确的一种查账方法。

**5. 分析法**：针对企业的会计资料，运用数理统计和逻辑思维推理进行客观分析判断。**分析法不宜作为查账定案的依据**，只能揭露事物内部的矛盾，还应结合其他查账方法来证实问题的本质。

| 分析法 | 应用场景 |
|---|---|
| **比较分析法** | 根据企业会计报表中的账面数据，同企业的有关计划指标、历史资料或同类企业的相关数据进行**动态和静态对比**。有绝对数比较和相对数比较两类 |
| **推理分析法** | 一般应用于**企业资产变动与负债及所有者权益变动平衡关系**的分析 |
| **控制分析法** | 一般运用于对生产企业的**投入与产出、耗用与补偿**的控制分析 |

### 考点3 会计凭证、会计账簿和会计报表的检查 ★

**（一）会计凭证的检查**

| 原始凭证 | 具体内容 | 检查事项 |
|---|---|---|
| **外来原始凭证** | 进货发票、进账单、汇款单、运费发票 | 审查凭证的**真实性、合法性、完整性、手续是否完备**；多联式发票是否系**报销联** |
| **自制原始凭证** | 对外：现金收据、实物收据；对内：收料单、领料单、支出证明单、差旅费报销单、成本计算单 | 检查自制原始凭证的种类、格式、使用是否符合规定，审批手续是否齐全（有无利用白条代替凭证）；内容是否真实；手续是否完备；报销金额是否符合规定的开支标准和开支范围 |

**记账凭证的检查**：① 记账凭证是否附有原始凭证，两者的内容是否一致；② 会计科目及其对应关系是否正确；③ 会计记录所反映的经济内容是否完整，处理是否及时。

**（二）账簿的检查**

| 账簿 | 检查事项 |
|---|---|
| **序时账** | ① 审查账簿的真实性；② 审查借贷发生额的对应账户；③ 审查账面出现的异常情况；④ 审查银行存款收支业务 |
| **总分类账** | ① 账账关系的查核；② 账表关系的查核（总账与资产负债表、损益表核对）；③ 纵向关系的查核（本期与上期发生额、期初与期末余额）；④ 横向关系的查核（与纳税有关的账户）。**从总账中发现的问题只能作为查账的线索** |
| **明细分类账** | ① 与总分类账进行相互核对；② 上下结算期之间相互核对；③ 审查账户余额的借贷方向；④ 账实相符的检查 |

**（三）会计报表的检查**

- **资产负债表**：重点审查 ① 应收账款、预付账款、应付账款、预收账款项目（"应付账款""预收账款"中审查有无隐匿已实现的产品销售收入或其他业务收入；"应收账款""预付账款"中审查有无不符合制度的任意核销或转销；对"坏账准备"审查计算所得税时是否进行了纳税调整）；② 各项存货项目（原材料、包装物、低值易耗品、自制半成品、产成品、发出商品）；③ 固定资产（"固定资产原价""累计折旧""固定资产减值准备""固定资产净值""固定资产清理""在建工程"和"待处理财产损溢"等科目）。**税法规定，固定资产计提的减值准备不得作所得税税前扣除**。
- **利润表**：① 主营业务收入——将收入与计划或上年同期对比，看是上升还是下降；② 主营业务成本——检查企业是否存在挤占生产成本、多转或少转成本的行为；③ 销售费用——必须是与经营业务有关的费用、必须是费用性质的、必须符合制度规定的开支范围和开支标准。

### 考点4 账务调整的基本方法 ★★★★

对纳税检查过程中发现有问题的会计账目，需要按照财务会计制度进行账务调整，以保证**账账、账证、账实相符**。

| 方法 | 含义 | 适用范围 |
|---|---|---|
| **红字冲销法** | 用**红字**冲销原错误的会计分录，再用**蓝字**重新编制分录，登记账簿 | 适用于**会计科目用错**，或者**会计科目正确但核算金额大于应计金额**的情况 |
| **补充登记法** | 通过编制转账分录，把调整金额直接入账，从而更正错账 | 适用于**漏计或错账所涉及的会计科目正确，但核算金额小于应计金额**的情况 |
| **综合账务调整法** | 红字冲销法和补充登记法的综合运用，主要适用于**所得税纳税检查后**的账务调整 | 一般运用于会计分录借贷方，**有一方会计科目用错，而另一方会计科目正确**的情况。正确的一方不调整，错误的一方用错误科目转账调整，再补充上正确的会计科目 |

**【巧思妙记】多记冲销，少记补充，综合注意错账时间。**

**错账处理的时间规则（综合调整法的核心，必考）**：

```
当月发现错误        → 直接调整损益类科目（如管理费用→生产成本）
当年月度结算后发现  → 直接调整"本年利润"账户
年度结算后发现      → 直接调整"以前年度损益调整"账户
```

> 注意：如果涉及会计所得，上述规则适用；对于税法不允许扣除但企业已扣除、而**记账科目本身正确**的项目，**不用作错账更正**，直接调增应纳税所得额，只作补缴所得税的账务处理即可。

**教材例题（红字冲销法，例8-1）**：企业当月将生产领用的原材料 10000 元误记为 100000 元（会计科目正确、金额多记 90000 元）。
```
错误分录：借：生产成本 100000
           贷：原材料   100000
调整分录：借：生产成本 90000（红字）
           贷：原材料   90000（红字）
```

**教材例题（补充登记法，例8-2）**：企业当期应摊销无形资产 5000 元，实际摊销 4500 元（科目正确、金额少计 500 元）。
```
调整分录：借：管理费用   500
           贷：累计摊销   500
```

**教材例题（综合账务调整法，例8-3）**：企业当期将一笔属于生产车间职工福利列支的费用支出 50000 元记入"管理费用"（借方科目用错，贷方"银行存款"正确）。

| 发现时间 | 调账分录 |
|---|---|
| 本月发现 | 借：生产成本 50000 ／ 贷：管理费用 50000 |
| 月度结算后发现 | 借：生产成本 50000 ／ 贷：本年利润 50000 |
| 年度结算后发现 | 借：生产成本 50000 ／ 贷：以前年度损益调整 50000 |

### 考点5 增值税会计科目的设置 ★★★★

**（一）"应交税费"下的明细科目（二级科目，共 10 个）**：
应交增值税、未交增值税、预交增值税、待抵扣进项税额、待认证进项税额、待转销项税额、代扣代缴增值税、简易计税、增值税留抵税额、转让金融商品应交增值税。

**【巧思妙记】「简易交代（待），留抵金融品」**

| 明细科目 | 核算内容 |
|---|---|
| **应交增值税** | 核算销项、进项等（下设专栏，见下） |
| **未交增值税** | 核算纳税人月度终了从"应交增值税"或"预交增值税"明细科目转入**当月应交未交、多交或预缴**的增值税税额，以及**当月交纳以前期间未缴**的增值税税额 |
| **预交增值税** | 核算纳税人转让不动产、提供不动产经营租赁服务、提供建筑服务、采用预收款方式销售自行开发的房地产项目等应预缴的增值税税额 |
| **待抵扣进项税额** | 核算已取得扣税凭证并经认证，按现行制度准予**以后期间**从销项税额中抵扣的进项税额 |
| **待认证进项税额** | 核算已取得扣税凭证，准予从销项税额中抵扣但**尚未经认证**的进项税额 |
| **待转销项税额** | 核算发生应税交易，**已确认相关收入（或利得）但尚未发生增值税纳税义务**而需在以后期间确认为销项税额的税额 |
| **代扣代缴增值税** | 核算购进境外单位或个人在境内发生的应税交易应代扣代缴的增值税税额 |
| **简易计税** | 核算采用简易计税方法发生的增值税计提、扣减、预缴、缴纳等业务 |
| **增值税留抵税额** | 核算经税务机关核准的允许退还的增值税期末留抵税款以及缴回的已退还的留抵退税款 |
| **转让金融商品应交增值税** | 核算转让金融商品发生的增值税税额 |

**（二）"应交增值税"明细账内的专栏（共 10 个）**：
销项税额、销项税额抵减、进项税额、进项税额转出、已交税金、转出未交增值税、转出多交增值税、出口抵减内销产品应纳税额、减免税款、出口退税。

**【巧思妙记】「销项已转交，进项减免退」**

| 专栏 | 核算内容 |
|---|---|
| 销项税额 | 销售货物、加工修理修配劳务、服务、无形资产或不动产应收取的增值税额 |
| 销项税额抵减 | 因扣减销售额而减少的销项税额 |
| 进项税额 | 购进的货物、服务、无形资产、不动产和金融商品支付或负担的、准予从当期销项税额中抵扣的增值税额 |
| 进项税额转出 | 购进货物等发生**非正常损失**以及其他原因而不应从销项税额中抵扣，应按规定转出的进项税额 |
| 已交税金 | 纳税人**当月已缴纳**的应交增值税税额 |
| 转出未交增值税 / 转出多交增值税 | 月度终了转出当月应交未交或多交的增值税税额 |
| 出口抵减内销产品应纳税额 | 实行"免、抵、退"办法的纳税人按规定计算的应免、抵税额 |
| 减免税款 | 准予减免的增值税税额 |
| 出口退税 | 出口产品按规定退回的增值税税额 |

### 考点6 销项税额的检查 ★★★★

**知识框架**：

```
销项检查
├── 一般销售
│   ├── 交款提货：货款已收到＋发票账单和提货单交买方 → 无论商品是否发出均作销售实现
│   ├── 预收货款：发出商品时作为销售实现
│   └── 分期收款：按书面合同约定的收款日期作为销售收入实现时间（＝纳税义务发生时间）
├── 销售服务：纳税义务发生时间＝收讫销售款项或取得索取销售款项凭据的当天
│   └── 特例：提供租赁服务采取预收款方式的，为收到预收款的当天
├── 视同销售
│   ├── 委托代销：收到代销清单的当天
│   ├── 自产自用（职工福利/个人消费）
│   ├── 自产用于对外投资：货物移送当天
│   └── 自产用于无偿赠送：货物移送当天
├── 包装物：租金（价外费用）／押金（未逾期不税、逾期计税）
└── 销售额：含税换算＋价外费用
```

**（一）一般销售方式下销项税额的检查**

**1. 销售货物**

- **交款提货**：如果货款已经收到，发票账单和提货单也交给买方，无论商品、产品是否已经发出，都要作为销售的实现。
  ```
  借：银行存款
     贷：主营业务收入
        应交税费——应交增值税（销项税额）
  ```
- **预收货款**：采用预收货款方式销售商品，在企业**发出商品时**作为销售的实现。
  ```
  收到货款时：借：银行存款        贷：合同负债
  货物发出时：借：合同负债        贷：主营业务收入
                                      应交税费——应交增值税（销项税额）
  月底结转成本：借：主营业务成本   贷：库存商品
  ```
- **分期收款**：按**书面合同约定的收款日期**作为销售收入的实现时间，也就是纳税义务的发生时间。延期收取的货款具有融资性质，应按**应收合同价款的公允价值（未来现金流量现值或现销价格）**确定收入金额，差额记入"未实现融资收益"。
  > 在赊销和分期收款方式下，会计上的收入确认时点先于增值税纳税义务发生时点，应将相关销项税额计入"**应交税费——待转销项税额**"，到合同约定的收款日期再转入"应交税费——应交增值税（销项税额）"。
  > 纳税人生产销售**生产工期超过12个月的大型机械设备、船舶、飞机**等货物，增值税纳税义务发生时间为收到款项或者书面合同确定的付款日期的当日。

**隐匿销售收入的检查线索**：核查"应收账款""应付账款""其他应收款""其他应付款"等明细账户，注意**虚列户名无主户、核算内容不符合制度规定、发生额长时间挂账、余额转入账户不正常**等情况（如"应付账款"年底转入"资本公积"），极有可能存在隐匿销售收入的行为。调整时按发现时期分别调整损益类科目／"本年利润"／"以前年度损益调整"。

**2. 销售服务**

- 纳税义务发生时间：纳税人销售服务并**收讫销售款项或者取得索取销售款项凭据的当天**；先开具发票的，为开具发票的当日。
- **特例（必考）**：纳税人提供**租赁服务采取预收款方式**的，纳税义务发生时间为**收到预收款的当天**。
- 对于采取预收款方式销售服务（**租赁服务除外**）的企业，应在收到预收款项时借记"银行存款"，贷记"合同负债"；发生服务时，确认收入及补收款项，借记"合同负债""银行存款"等，贷记"应交税费——应交增值税（销项税额）""主营业务收入""其他业务收入"等。
- 租赁企业收取的预收租赁款，属于租赁准则规范范畴，**记入"预收账款"**。

**（二）视同销售方式下销项税额的检查**

**1. 委托代销**：代销双方要视同销售，委托方销售收入的实现时间一般为**收到代销清单的当天**。
```
① 发出委托代销商品：借：委托代销商品   贷：库存商品
② 收到代销清单：借：应收账款          贷：主营业务收入
                                           应交税费——应交增值税（销项税额）
                   借：主营业务成本    贷：委托代销商品
③ 收到扣除手续费后的货款：借：银行存款
                                销售费用
                                应交税费——应交增值税（进项税额）
                             贷：应收账款
```
> 检查时通过代销合同和"委托代销商品"账户核查。若"委托代销商品"账户**余额长期挂账**，可能是企业未及时转作收入；若出现**红字余额**，可能是企业在收到货款时直接按售价冲减了该账户。

**2. 自产自用**：企业将自产或委托加工的货物用于集体福利或个人消费等，要视同销售计算缴纳增值税。计税价格核定顺序：① 按纳税人最近时期同类货物的平均价格确定；② 按其他纳税人最近时期同类货物的平均价格确定；③ 按组成计税价格计算。
```
组成计税价格 = 成本×(1+成本利润率) + 消费税税额
```
> **税会差异提示**：企业将自产产品用于**本企业职工福利**，资产权属未发生改变，除按对外售价计算缴纳增值税外，**不用计算销售收入及所得税**；企业将资产移送他人（用于交际应酬、职工奖励或福利、股息分配、对外捐赠等改变资产所有权属的），应按规定视同销售确认收入，计算缴纳企业所得税。

**3. 自产货物用于对外投资**：应按销售货物计算销项税额，纳税义务发生时间为**货物移送的当天**。

**4. 自产货物用于无偿赠送**：按所赠货物的售价乘以税率计算的应纳增值税，借记"营业外支出"；按所赠货物的成本，贷记"库存商品""原材料"；按应纳销项税额，贷记"应交税费——应交增值税（销项税额）"。纳税义务发生时间为**货物移送的当日**。

**自用货物的检查方法**：① 根据该产品的性能、用途，看其是否属于多用途产品，判断企业可能在哪些项目上使用该产品；② 通过库存商品出库单上的"**领用部门**"一栏判断产品的去向和用途；③ 通过实地调查，到车间、工地进一步查看是否存在自产自用的情况。

**（三）包装物销售的检查**

| 类型 | 税务账务处理 |
|---|---|
| 随同货物出售**单独计价**的包装物 | 属于销售货物，取得收入记入"其他业务收入"，按所包装货物的适用税率计征：借：银行存款 ／ 贷：其他业务收入、应交税费——应交增值税（销项税额） |
| **一般商品押金** | 单独记账核算的，**不并入销售额征税**：借：银行存款 ／ 贷：其他应付款——包装物押金。**因逾期未收回包装物不再退还的押金**，应按所包装货物的适用税率计算销项税额：借：其他应付款——包装物押金 ／ 贷：其他业务收入、应交税费——应交增值税（销项税额） |
| **除啤酒、黄酒外的其他酒类**产品收取的包装物押金 | **无论是否返还以及会计上如何核算，均应并入当期销售额征税** |

**审查要点**：审查包装物收入有无计税；审查包装物的押金金额是否正确；审查会计核算是否正确。

**（四）销售额的检查**

1. **不含税销售额的检查**：销项税额的计税依据为不含增值税的销售额；如果纳税人的销售额为含税销售额，要将含税销售额换算为不含税销售额。
   ```
   销售额 = 含税销售额 ÷（1 + 增值税税率）
   ```
2. **价外费用的检查**：凡随同销售货物或提供应税劳务向购买方收取的价外费用，**无论其会计制度如何核算，均应并入销售额计算应纳税额**。价外费用一般在"其他应付款""其他业务收入""营业外收入"等科目中核算（企业常出现对价外费用不计算销项税额、甚至直接冲减有关费用科目的情况）。典型如延期付款利息：借：银行存款 ／ 贷：财务费用、应交税费——应交增值税（销项税额）。

### 考点7 进项税额的检查 ★★★

**（一）准予从销项税额中抵扣的进项税额（5 项）**

| 序号 | 内容 |
|---|---|
| ① | 从销售方取得的**增值税专用发票**（含税控机动车销售统一发票）上注明的增值税额 |
| ② | 从海关取得**海关进口增值税专用缴款书**上注明的增值税额 |
| ③ | 购进**免税农产品**，按照农产品收购发票或者销售发票上注明的农产品买价和 **9% 的扣除率**计算的进项税额 |
| ④ | 纳税人支付的**道路通行费** |
| ⑤ | 纳税人购进**国内旅客运输服务** |

**进项税额抵扣凭证**：增值税专用发票、海关进口增值税专用缴款书、完税凭证、农产品收购发票、农产品销售发票、代扣代缴税款的完税凭证以及其他具有进项税额抵扣功能的扣税凭证。**增值税普通发票不属于抵扣凭证**。

**（二）不得从销项税额中抵扣的进项税额**

| 教材列举版 | 增值税法条文版（第4节来源补充） |
|---|---|
| ① 用于简易计税项目、免征项目、集体福利或个人消费的购进货物 | (1) 适用简易计税方法计税项目对应的进项税额 |
| ② 非正常损失的购进货物 | (2) 免征增值税项目对应的进项税额 |
| ③ 非正常损失的在产品、产成品所耗用的购进货物 | (3) 非正常损失项目对应的进项税额 |
| ④ 非正常损失的不动产，以及该不动产所耗用的购进货物 | (4) 购进并用于集体福利或者个人消费的货物、服务、无形资产、不动产对应的进项税额 |
| ⑤ 非正常损失的不动产在建工程所耗用的购进货物 | (5) 购进并直接用于消费的餐饮服务、居民日常服务和娱乐服务对应的进项税额 |
| ⑥ 购进的**贷款服务、餐饮服务、居民日常服务和娱乐服务** | (6) 购进贷款服务，及向贷款方支付的与该笔贷款直接相关的投融资顾问费、手续费、咨询费等费用对应的进项税额 |
| | (7) 用于非应税交易对应的进项税额；(8) 国务院规定的其他进项税额 |

> **【提示】非正常损失**是指因**管理不善**造成的被盗、丢失、霉烂变质的损失。

**已抵扣进项税额的转出处理**：
```
借：应付职工薪酬／管理费用／待处理财产损溢 等
    贷：原材料／库存商品 等（成本）
        应交税费——应交增值税（进项税额转出）（转出的进项税额）
```

**（三）长期资产（固定资产、无形资产、不动产）进项税额的特殊规定**

| 用途 | 处理 |
|---|---|
| 专用于一般计税方法计税项目 | 进项税额**全额抵扣** |
| 专用于简易计税、免征增值税项目、非应税交易、集体福利或者个人消费（五类不允许抵扣项目） | 进项税额**不得抵扣** |
| **混合用途**且原值**不超过 500 万元**的单项长期资产 | 进项税额**全额抵扣** |
| **混合用途**且原值**超过 500 万元**的单项长期资产 | 购进时**先全额抵扣**，此后在用于混合用途期间，根据**调整年限**，再计算五类不允许抵扣项目对应的不得抵扣进项税额，**逐年调整** |

```
当年混合用途期间进项税额分期调整基数 = 全部进项税额 × 12 ÷（调整年限 × 12）
当年不得抵扣的进项税额 = 调整基数 × 不得抵扣部分折旧 ÷ 全部折旧
```

### 考点8 销售收入的检查（消费税） ★★

**（一）一般销售方式的检查**：一般销售方式包括交款提货、预收货款、分期收款等，检查内容与增值税检查基本相同。与增值税不同的是，**消费税是价内税**，其计提税金的会计账务处理为：
```
借：税金及附加
    贷：应交税费——应交消费税
```
> "税金及附加"账户主要反映消费税、城建税、教育费附加、资源税等，**但不包括增值税**。

**（二）视同销售方式的检查**：无同类产品对外售价的，按**组成计税价格**计算。
```
组成计税价格 =（成本 + 利润）÷（1 - 消费税税率）
            = 成本 ×（1 + 成本利润率）÷（1 - 消费税税率）
```

**（三）委托加工方式的检查**：首先应审查是否符合税法中规定的委托加工方式，如不符合规定，是否按销售自制应税消费品缴纳了消费税。

- **对受托方的检查（代收代缴消费税）**：委托加工应税消费品于**受托方交货时由受托方代收代缴消费税**，其计税依据为：按照受托方的同类消费品的销售价格计税，没有同类消费品销售价格的，按组成计税价格计税。加工费是指受托方加工应税消费品向委托方所收取的全部费用（**包括代垫辅助材料的实际成本，不包括增值税税金**）。
  审查要点：① 根据"原材料"明细账和"其他业务收入——加工收入"明细账判断是否是假委托加工业务；② 审查有无以委托方名义购进原材料进行加工的行为。
- **对委托方的检查（消费税纳税人）**：主要查看委托加工收回时，受托方是否已代收了消费税税款、计算是否正确。如果发现受托方没有代收代缴税款，**委托方要补缴税款**。

### 考点9 销售数量的检查（消费税） ★

**（一）销售数量的检查内容**：① 检查企业是否存在**少开票，多发货，转移销售收入**的情况；② 检查企业是否存在**账外结算，转移销售收入**的情况。

**（二）销售数量的检查方法**

| 检查方法 | 计算公式 | 适用范围 |
|---|---|---|
| **以盘挤销倒挤法** | 本期产品销售数量 = 上期产品结存数量 + 本期产品完工数量 - 本期产品结存数量 | 适用于**产成品管理制度不够健全**的企业 |
| **以耗核产，以产核销测定法** | 本期应出产品数量 = 本期实耗材料量 ÷ 单位产品材料消耗定额 | 适用于**产成品管理制度比较健全**的企业（运用时应抓住主要耗用材料进行核定） |

### 考点10 年度收入总额的检查 ★★

**收入总额**包括以货币形式和非货币形式从各种来源取得的收入，包括销售货物收入，提供劳务收入，转让财产收入，股息、红利等权益性投资收益，利息收入，租金收入，特许权使用费收入，接受捐赠收入，不征税收入和免税收入及其他收入等。

| 收入项目 | 主要核算科目 |
|---|---|
| 销售货物收入、提供劳务收入 | **主营业务收入** |
| 租金收入、特许权使用费收入 | **其他业务收入** |
| 固定资产转让净收益 | **资产处置收益** |

**（一）销售货物收入的检查**

**1. 收入确认标准（4 项条件）**：① 商品销售合同已经签订，企业已将商品所有权相关的主要风险和报酬转移给购货方；② 企业对已售出的商品既没有保留通常与所有权相联系的继续管理权，也没有实施有效控制；③ 收入的金额能够可靠地计量；④ 已发生或将发生的销售方的成本能够可靠地核算。
**2. 收入确认时间**

| 销售方式 | 收入确认时间 |
|---|---|
| 托收承付 | 发出货物并办妥托收手续时 |
| 预收货款方式 | 发出商品时 |
| 销售商品需要安装和检验的 | 在购买方接受商品以及安装和检验完毕时；**如果安装程序比较简单，可在发出商品时确认收入** |
| 委托代销 | 收到代销清单时 |

**3. 销售折让、折扣及销售退回**

| 项目 | 检查要点 |
|---|---|
| 销售折让 | 重点检查是否是因为售出商品质量不合格等原因，是否存在故意压低价格而从中营私舞弊的现象 |
| 商业折扣 | 应当按照**扣除商业折扣后的金额**确定销售商品收入金额 |
| 现金折扣 | 在**实际发生时作为财务费用扣除** |
| 销售退回 | 检查销售退回的真实性，是否如数冲减了"主营业务收入" |

**（二）其他收入检查要点**

- **转让财产收入**：转让固定资产主要对"固定资产清理""累计折旧""资产处置损益"等科目进行检查；转让有价证券、股权重点检查投资的真实性、转让收入或投资收益是否及时入账。
- **股息、红利等权益性投资收益**：按照**被投资方做出利润分配决定的日期**确认收入的实现；检查是否挂在往来账上、不入账或少入账。
- **利息收入**：按照**合同约定的债务人应付利息的日期**确认收入的实现；检查是否存在用利息收入直接冲减借款或财务费用等现象。

**（三）不征税收入和免税收入的检查**

| 类型 | 项目 | 检查要点 |
|---|---|---|
| 不征税收入 | 财政拨款；依法收取并纳入财政管理的行政事业性收费、政府性基金 | 检查企业是否存在骗取财政拨款、未按规定用途使用财政拨款的情形；检查收费、政府性基金是否纳入预算管理 |
| 免税收入 | 国债利息收入、地方政府债券利息收入；符合条件的居民企业之间的股息、红利；符合条件的非营利组织的收入 | 看企业是否存在将非免税收入混入免税收入，少缴企业所得税的情形 |

### 考点11 税前准予扣除项目的检查 ★★

**（一）成本项目的检查**

| 项目 | 检查要点 |
|---|---|
| 材料成本的检查 | 外购材料：查看有无列入不属于材料成本开支范围的其他费用，增加材料成本；委托加工材料：主要查看委托加工的**运杂费、加工费是否计入了加工成本** |
| 工资成本的检查 | 检查发生的工资成本是否真实；所提取的职工福利费、工会经费和职工教育经费是否符合税法规定的依据和比例 |
| 制造费用的检查 | 主要检查固定资产的入账价值、计提折旧的范围、折旧年限、折旧方法是否符合税法规定 |

**（二）成本计算的检查**：生产成本是为制造产品或提供劳务而发生的成本，主要由**直接材料、直接人工和制造费用**三个项目构成。

| 项目 | 归集要求 |
|---|---|
| 直接材料 | 凡属于制造产品耗用的直接材料费用 → 计入"**生产成本——基本生产成本**"；凡属于辅助生产车间为进行产品或劳务生产而耗用的直接材料费用 → 计入"**生产成本——辅助生产成本**"；几种产品共同耗用、领用时无法确定数量的 → 按一定标准分配后归集 |
| 直接人工 | 检查考勤记录、产量和工时记录 |
| 制造费用 | 通过"制造费用"账户检查归集是否正确 |

| 分配方法 | 适用范围 |
|---|---|
| **品种法** | 大量大批的**单步骤**生产企业 |
| **分批法** | **单件、小批**生产的企业 |
| **分步法** | 大量大批的**多步骤**生产企业 |

**完工产品成本的结转**：完工入库的产成品 → 借：库存商品 ／ 贷：生产成本；完工自制材料 → 借：原材料 ／ 贷：生产成本；为在建工程提供的劳务 → 借：在建工程 ／ 贷：生产成本。通过检查"库存商品""原材料"等科目审核完工产品成本计算是否正确。

**（三）期间费用的检查**

| 费用 | 内容（部分） | 检查要点 |
|---|---|---|
| **管理费用** | 行政部门为管理组织经营活动提供各项支援性服务而发生的费用：公司经费、工会经费、劳动保险费、董事会费、聘请中介机构费、咨询费、诉讼费、**业务招待费**、办公费、差旅费、邮电费、管理人员工资及福利费等 | 主要检查有无不属于管理费用的支出，有无违反开支标准和发放范围的支出 |
| **销售费用** | 为销售商品而发生的费用：**广告费**、运输费、装卸费、**包装费**、展览费、保险费、销售佣金、代销手续费、经营性租赁费及销售部门发生的差旅费、工资、福利费等 | 主要检查有无扩大销售费用开支范围的情况，有无提高销售费用列支标准的问题 |
| **财务费用** | 筹集经营性资金而发生的费用：**利息净支出、汇兑净损失、金融机构手续费** | 主要检查财务处理是否正确，有无将不属于财务费用的支出列入其中，支付的财务费用是否超出税法规定标准 |

**（四）税金的检查**：企业按规定缴纳的消费税、城市维护建设税、关税、资源税、土地增值税、房产税、车船税、城镇土地使用税、印花税、教育费附加等**税金及附加**准予扣除。主要是检查税金扣除项目是否正确，有无将不属于扣除范围的税金计入其中。

**（五）亏损弥补的检查**：企业纳税年度发生的亏损，准予向以后年度结转，用以后年度的所得弥补，但**结转年限最长不得超过五年**。

### 考点12 不得税前扣除项目的检查 ★★★★

**（一）不允许扣除项目的检查**：对于税法不允许扣除，但企业已作为扣除项目予以扣除的各项成本、费用和损失，应**调增应纳税所得额**。

**不得在税前扣除的项目**：
1. 向投资者支付的股息、红利等权益性投资收益款项
2. 企业所得税税款
3. 税收滞纳金、罚金、罚款
4. 非公益性（非公益救济性）捐赠支出
5. 赞助支出（非广告性质的赞助支出）
6. 未经核定的准备金支出
7. 企业为投资者或职工支付的商业保险费
8. 企业之间支付的管理费
9. 企业对外投资期间持有的投资资产成本
10. 烟草企业的烟草广告费和业务宣传费支出

> 第4节来源另补充列举：资本性支出、无形资产受让开发支出、违法经营罚款和被没收财物损失、灾害事故损失赔偿（赔偿部分不得扣除）。

**（二）超过规定标准项目的检查**：对于超过税法规定标准扣除的各种成本、费用和损失，应**调增应纳税所得额**。

| 项目 | 扣除标准 |
|---|---|
| **工资薪金** | 企业发生的合理的工资薪金支出准予扣除，但**必须是实际发放的才能扣除，计提的不能扣除** |
| **职工福利费** | 不超过工资薪金总额 **14%** 的部分准予扣除 |
| **职工教育经费** | 不超过工资薪金总额 **8%** 的部分准予扣除，超过的部分**可以结转到以后年度扣除** |
| **工会经费** | 不超过工资薪金总额 **2%** 的部分准予扣除，超过部分**不允许结转**。工会经费强调的是**拨缴工会**，不是计提，准予扣除的工会经费必须取得"**工会经费拨缴款专用收据**" |
| **利息支出** | 非金融企业向金融企业借款的利息支出准予扣除；非金融企业向非金融企业借款的利息支出，**不超过同期同类贷款利率计算的部分**准予扣除。纳税人为对外投资而借入的资金发生的借款费用，应计入有关投资的成本；企业投资者投资未到位而发生的利息支出不得税前扣除 |
| **业务招待费** | 按照发生额的 **60%** 扣除，且**不超过当年销售收入（营业收入）的 5‰**（双限额，取小者） |
| **广告费和业务宣传费** | 不超过当年销售（营业）收入 **15%** 以内的部分准予扣除，超过的部分**可以结转以后年度扣除** |
| **公益性捐赠支出** | 区分为"公益性捐赠"和"非公益性捐赠"。不超过**年度利润总额 12%** 的部分准予扣除 |

**（三）纳税调整**

```
应纳税额 = 应纳税所得额 × 适用税率

直接法：应纳税所得额 = 应税收入 - 税法允许的各项扣除
间接法：应纳税所得额 = 会计利润 + 纳税调整增加额 - 纳税调整减少额
       会计利润 = 收入 - 成本 - 费用 - 支出（按照会计处理无条件计入）
```

| 项目 | 会计准则 | 税法 | 纳税调整 |
|---|---|---|---|
| 收入（免税） | ＋100 | 0 | ↓100 |
| 费用、支出（全额扣除） | -100 | -100 | 无需调整 |
| 费用、支出（限额扣除） | -100 | -80 | ↑20 |
| 费用、支出（不得扣除） | -100 | 0 | ↑100 |
| 费用（加计扣除） | -100 | -100-100 | ↓100 |

> **调账与调税的关系（高频陷阱）**：税法不允许扣除但企业已扣除、而**记账科目正确**的项目（如营业外支出中的赞助款、公益性捐赠超限额部分），**不用作错账更正**，直接调增应纳税所得额，只作补缴所得税的账务处理即可。

### 考点13 纳税检查相关案例分析题 ★★★★

**案例分析题通用解题四步法**：

```
第一步：读业务 → 判断业务性质（一般销售/视同销售/包装物/不得抵扣……）
第二步：定时间 → 纳税义务发生时间（预收货款发货时？租赁预收款当天？分期看合同？）
第三步：算税额 → 含税先换算：÷(1+税率)；多税率分别算；销项=不含税售价×税率
第四步：对分录 → 借方科目（银行存款/应收账款/应付职工薪酬/营业外支出/长期股权投资…）
              贷方科目（主营业务收入/其他业务收入/库存商品/合同负债/预收账款
                       应交税费——应交增值税（销项税额）等）
```

**高频业务正确分录速查表**：

| 业务 | 正确账务处理 |
|---|---|
| 预收货款销售货物 | 收款：借：银行存款 ／ 贷：合同负债；发货：借：合同负债 ／ 贷：主营业务收入、应交税费——应交增值税（销项税额） |
| 预收款提供租赁服务 | 收款时即计提：借：银行存款 ／ 贷：预收账款、应交税费——应交增值税（销项税额） |
| 委托代销发出商品 | 借：委托代销商品 ／ 贷：库存商品 |
| 收到代销清单 | 借：应收账款 ／ 贷：主营业务收入、应交税费——应交增值税（销项税额）；借：主营业务成本 ／ 贷：委托代销商品 |
| 收到扣除手续费后货款 | 借：银行存款、销售费用、应交税费——应交增值税（进项税额） ／ 贷：应收账款 |
| 自产货物用于职工福利 | 借：应付职工薪酬 ／ 贷：库存商品、应交税费——应交增值税（销项税额） |
| 自产货物用于对外投资 | 借：长期股权投资 ／ 贷：主营业务收入、应交税费——应交增值税（销项税额）；借：主营业务成本 ／ 贷：库存商品 |
| 自产货物无偿赠送 | 借：营业外支出 ／ 贷：库存商品、应交税费——应交增值税（销项税额） |
| 包装物租金／逾期押金／延期付款利息（价外费用） | 先÷(1+税率)换算：租金、逾期押金贷"其他业务收入"，利息贷"财务费用"，同时贷记应交税费——应交增值税（销项税额） |
| 外购货物用于职工福利 | 借：应付职工薪酬 ／ 贷：原材料、应交税费——应交增值税（进项税额转出） |
| 非正常损失 | 借：待处理财产损溢 ／ 贷：原材料、应交税费——应交增值税（进项税额转出） |
| 购进农产品（收购价 20 万，扣率 9%） | 借：原材料 182000、应交税费——应交增值税（进项税额）18000 ／ 贷：库存现金 200000 |
| 购入办公楼（按规定抵扣） | 借：固定资产、应交税费——应交增值税（进项税额） ／ 贷：银行存款 |
| 计提消费税 | 借：税金及附加 ／ 贷：应交税费——应交消费税 |
| 查补以前年度企业所得税 | 借：以前年度损益调整 ／ 贷：应交税费——应交企业所得税 |

> 完整案例真题见第六节。

| 税种 | 检查重点 | 高频分录/要点 |
|---|---|---|
| **增值税** | ① 会计科目设置（"应交税费"10 个二级明细＋"应交增值税"10 个专栏）；② 销项税额（销售时点、视同销售、包装物、价外费用）；③ 进项税额（抵扣凭证、不得抵扣、转出） | 借：应交税费——应交增值税（已交税金）＝当月已缴；借：应交税费——未交增值税＝缴纳以前期间未交 |
| **消费税** | ① 销售收入检查（价内税，"税金及附加"）；② 销售数量检查（以盘挤销倒挤法/以耗核产以产核销测定法）；③ 委托加工代收代缴 | 计提：借：税金及附加 ／ 贷：应交税费——应交消费税；组成计税价格=（成本+利润）÷（1-消费税税率） |
| **企业所得税** | ① 年度收入总额（确认标准、时间、折让折扣）；② 税前准予扣除项目（成本、期间费用、税金）；③ 不得税前扣除项目（不允许扣 10 项＋超标准 8 项）；④ 纳税调整 | 应纳税所得额=会计利润+纳税调整增加额-纳税调整减少额 |

### 表4 十六个"不等于"（避坑专用）

| # | 说法 | 正解 |
|---|---|---|
| 1 | 纳税检查的客体包括税务机关 | ✗ 客体是纳税人、代扣代缴义务人、代收代缴义务人、纳税担保人；**税务机关是主体** |
| 2 | 顺查法从检查报表开始 | ✗ 从报表开始的是**逆查法**；顺查法从会计凭证开始 |
| 3 | 分析法、总账发现的问题可以直接定案 | ✗ 二者**只能揭露矛盾、提供线索**，不宜作为定案依据 |
| 4 | 红字冲销法适用于金额少记 | ✗ 少记用**补充登记法**；红字冲销用于科目用错或金额多记 |
| 5 | "已交税金"核算缴纳以前期间未交的增值税 | ✗ 那是"**未交增值税**"；"已交税金"只核算当月已缴纳的 |
| 6 | "转出未交增值税"是"应交税费"的二级科目 | ✗ 它是"应交增值税"明细账内的**专栏**；二级科目是"未交增值税" |
| 7 | 预收货款销售货物，收到款时计销项税额 | ✗ **发出商品时**才确认销售实现 |
| 8 | 所有预收款都在收到款时计销项税额 | ✗ 只有**预收款提供租赁服务**是收到预收款当天；其他服务收到时记"合同负债" |
| 9 | 包装物押金一律计税 | ✗ 一般商品单独记账的押金**不并入销售额**；逾期不退才计税；除啤酒、黄酒外的酒类押金无论是否返还均计税 |
| 10 | 价外费用会计上不计收入就不用计税 | ✗ 价外费用**无论会计如何核算均应并入销售额** |
| 11 | 自产货物用于职工福利，企业所得税也视同销售 | ✗ 权属未变的内部处置，**不确认收入、不缴企业所得税**（增值税仍视同销售） |
| 12 | 增值税普通发票可以抵扣进项税额 | ✗ 抵扣凭证不包括增值税普通发票 |
| 13 | 消费税通过"应交税费——应交增值税"核算 | ✗ 消费税是**价内税**，记入"税金及附加"，不含增值税 |
| 14 | 现金折扣可冲抵销售收入、商业折扣按原价确认收入 | ✗ 现金折扣**实际发生时作财务费用**；商业折扣按**扣除折扣后**的金额确认收入 |
| 15 | 计提的工资、工会经费都能扣除 | ✗ 工资须**实际发放**；工会经费强调**拨缴工会**并取得专用收据 |
| 16 | 公益性捐赠超限额可结转、所有不得扣除项目都要调账、查补税款一律记"所得税费用" | ✗ 捐赠超 12% 部分**不得结转**；科目正确的只**调税不调账**；查补**以前年度**所得税记"**以前年度损益调整**" |

## 四、公式与计算（本章计算题重点）

### 4.1 含税销售额换算与销项税额检查

```
销售额（不含税） = 含税销售额 ÷（1 + 增值税税率）
销项税额 = 不含税销售额 × 税率
```

**例题 1**：某商业企业为增值税一般纳税人，2024年5月向消费者销售一批服装，开具**普通发票**上注明价款 20000 元，款项已收到。企业账务处理为：借：银行存款 20000 ／ 贷：资本公积 20000。少计提销项税额多少？

```
不含税销售额 = 20000 ÷（1 + 13%）= 17699.12（元）
少计提销项税额 = 20000 - 17699.12 = 2300.88（元）
  或 = 20000 ÷ 1.13 × 13% = 2300.88（元）
```
**答**：少计提销项税额 **2300.88 元**。

**例题 2**：某市物流公司为增值税一般纳税人，2024年5月提供交通运输服务取得不含税收入 800 万元，提供物流辅助服务取得不含税收入 100 万元（非主营业务）。交通运输服务税率 9%，物流辅助服务税率 6%。

```
销项税额 = 8000000 × 9% + 1000000 × 6%
         = 720000 + 60000 = 780000（元）= 78（万元）
借：银行存款 9780000
    贷：主营业务收入      8000000
       其他业务收入      1000000
       应交税费——应交增值税（销项税额）780000
```

**例题 3**：某宾馆为增值税一般纳税人，2024年5月提供住宿服务取得**含税**收入 212 万元，税率 6%。企业原错误处理为全部记入"应付账款"。

```
不含税收入 = 2120000 ÷（1 + 6%）= 2000000（元）
销项税额   = 2000000 × 6% = 120000（元）
调整分录：借：应付账款 2120000
              贷：主营业务收入 2000000
                 应交税费——应交增值税（销项税额）120000
```

**例题 4（预收款租赁服务）**：某租赁公司为增值税一般纳税人，2024年5月签订为期3年的房屋租赁合同，收取预付款 1090 万元（含税），已存入银行；甲公司2025年5月20日收到乙公司一次性支付的不含税租金 10 万元和相应税款（税率 13%）。预收款提供租赁服务，纳税义务发生时间为收到预收款的当天。
```
房屋租赁：销项税额 = 10900000 ÷（1 + 9%）× 9% = 900000（元）= 90（万元）
  借：银行存款 10900000
      贷：预收账款 10000000
         应交税费——应交增值税（销项税额）900000
设备租赁：销项税额 = 100000 × 13% = 13000（元）
  5月20日：借：银行存款 113000  贷：预收账款 100000
                                  应交税费——应交增值税（销项税额）13000
  租赁期每月月末确认收入 10000（100000÷10）：借：预收账款 10000  贷：其他业务收入 10000
```
> **来源冲突提示**：设备租赁例中，一种版本记为"应于 5 月 20 日（收到预收款当日）计提销项税额"；另一种版本记为"应于 6 月 1 日（租赁月开始日）计提销项税额"。两种表述计算的销项税额均为 13000 元，考试以教材表述为准。

**例题 5（自产货物视同销售）**：某企业将自产产品 10 吨用于本企业职工食堂，已知该批产品对外不含税售价为 1000 元/吨，成本为 800 元/吨，税率 13%。
```
销项税额 = 对外售价 × 使用数量 × 税率 = 1000 × 10 × 13% = 1300（元）
借：应付职工薪酬 9300
    贷：库存商品 8000
       应交税费——应交增值税（销项税额）1300
```
> 资产权属未改变，可作为内部处置资产，不视同销售确认收入、不缴企业所得税。

**例题 6**：某企业为一般纳税人，某月销售产品 100 件，每件不含税售价 1000 元，同时收取使用期限3个月的包装物押金 20000 元；本月逾期不再退还包装物押金 10000 元。另收取延期付款利息 22600 元。
```
销售：借：银行存款 113000  贷：主营业务收入 100000
                             应交税费——应交增值税（销项税额）13000
押金：借：银行存款 20000    贷：其他应付款 20000（未逾期不计税）
逾期：借：其他应付款 10000
         贷：其他业务收入 8849.56
            应交税费——应交增值税（销项税额）1150.44
     [10000 ÷（1+13%）= 8849.56；×13% = 1150.44]
利息：借：银行存款 22600
         贷：财务费用 20000
            应交税费——应交增值税（销项税额）2600
     [22600 ÷ 1.13 = 20000；20000 × 13% = 2600]
```

### 4.3 不得抵扣进项税额的划分与进项税额转出

**例题 7**：某服装厂（增值税一般纳税人）将上月购进的布料用于职工福利。已知布料的实际成本为 11000 元，其中含运费 1000 元，其进项税额已抵扣。

```
布料进项税额转出 =（11000 - 1000）× 13% = 1300（元）
运费进项税额转出 = 1000 × 9% = 90（元）
合计转出 = 1390（元）
调整分录：借：应付职工薪酬 1390
              贷：应交税费——应交增值税（进项税额转出）1390
```

**例题 8（混合用途长期资产分期调整）**：某企业（一般纳税人）2026年1月购入一栋楼房，取得增值税专用发票注明金额 1200 万元，增值税税额 108 万元。该房产调整年限为 20 年，生产厂房用房部分计提折旧 44 万元，职工医务室用房计提折旧 11 万元。

```
当年混合用途期间进项税额分期调整基数 = 1080000 × 12 ÷（20 × 12）= 54000（元）
当年不得抵扣的进项税额 = 54000 × 11 ÷ 55 = 10800（元）
     [全部折旧 = 44 + 11 = 55（万元）]
会计处理：借：应付职工薪酬——医务室用房 10800
              贷：应交税费——应交增值税（进项税额转出）10800
```

**例题 9（购进农产品）**：某企业从农民手中购进一批农产品用于生产货物，收购凭证注明收购价格 200000 元，以现金支付。

```
进项税额 = 200000 × 9% = 18000（元）
原材料成本 = 200000 - 18000 = 182000（元）
借：原材料 182000
    应交税费——应交增值税（进项税额）18000
    贷：库存现金 200000
```

### 4.4 消费税检查计算

**例题 10**：某化妆品厂采用预收款方式销售高档化妆品 100 箱，取得价款 113000 元，商品已发出。消费税税率 15%。

```
应纳消费税 = 113000 ÷（1 + 13%）× 15% = 15000（元）
应纳增值税 = 113000 ÷（1 + 13%）× 13% = 13000（元）
借：合同负债 113000
    贷：主营业务收入 100000
       应交税费——应交增值税（销项税额）13000
借：税金及附加 15000
    贷：应交税费——应交消费税 15000
```

**例题 11（视同销售组成计税价格）**：某企业新试制加工一批高档化妆品用于职工奖励，无同类产品对外售价，生产成本 10000 元，成本利润率 5%，消费税税率 15%。

```
组成计税价格 =（10000 + 10000 × 5%）÷（1 - 15%）
            = 10500 ÷ 85% ≈ 12352.94（元）
应纳增值税 = 12352.94 × 13% ≈ 1605.88（元）
应纳消费税 = 12352.94 × 15% ≈ 1852.94（元）
借：应付职工薪酬 13958.82
    贷：主营业务收入 12352.94
       应交税费——应交增值税（销项税额）1605.88
借：税金及附加 1852.94
    贷：应交税费——应交消费税 1852.94
借：主营业务成本 10000
    贷：库存商品 10000
```

**例题 12（自产货物对外投资/无偿赠送）**：
- **对外投资**：某服装厂将 100 件自产服装用于对外投资，每件成本 1000 元，无同类市场售价，成本利润率 10%，税率 13%。组成计税价格＝100000×（1+10%）＝110000（元），销项税额＝110000×13%＝14300（元）。调整分录：借：长期股权投资 24300、主营业务成本 100000 ／ 贷：主营业务收入 110000、应交税费——应交增值税（销项税额）14300。
- **无偿赠送**：某服装厂将 100 件自产服装捐赠给贫困山区，每件成本 500 元、不含税售价 800 元。销项税额＝800×100×13%＝10400（元）。正确分录：借：营业外支出 60400 ／ 贷：库存商品 50000、应交税费——应交增值税（销项税额）10400。

### 4.5 应纳税所得额检查与纳税调整

```
直接法：应纳税所得额 = 应税收入 - 税法允许的各项扣除
间接法：应纳税所得额 = 会计利润 + 纳税调整增加额 - 纳税调整减少额
应纳税额 = 应纳税所得额 × 适用税率（25%）
```

**例题 13（视同销售补税，综合）**：2021年8月，企业将一批食品作为礼品发给本企业职工，成本价格 7200 元，同类产品不含税售价 15000 元。城建税 7%，教育费附加 3%，企业所得税 25%。

```
应补缴增值税 = 15000 × 13% = 1950（元）
应补缴城建税 = 1950 × 7% = 136.5（元）
应补缴教育费附加 = 1950 × 3% = 58.5（元）
应调增应纳税所得额 = 15000 - 7200 - 136.5 - 58.5 = 7605（元）
应补缴企业所得税 = 7605 × 25% = 1901.25（元）
```

**例题 14（业务招待费双限额）**：某企业全年实现销售收入 20000 万元。
```
（1）业务招待费 80 万元：
     20000 × 5‰ = 100（万元）；80 × 60% = 48（万元）；100 > 48 → 税前扣除 48（万元）
（2）业务招待费 200 万元：
     20000 × 5‰ = 100（万元）；200 × 60% = 120（万元）；100 < 120 → 税前扣除 100（万元）
```
**规律**：业务招待费扣除额 = min（发生额 × 60%，销售收入 × 5‰）。

**例题 15（广告费限额与结转）**：某服装企业 2022 年销售收入 2000 万元，广告费实际支出 450 万元，计算所得税时全额扣除。

```
广告费税前扣除限额 = 2000 × 15% = 300（万元）
本年度只允许扣除 300 万元，应调增应纳税所得额 150 万元，
尚未扣除的 150 万元可在以后纳税年度结转扣除。
```

**例题 16（公益性捐赠限额）**：某企业在"营业外支出"列支对贫困山区的捐助款 50 万元，通过县政府民政部门捐出，该年度会计利润 300 万元。

```
扣除限额 = 300 × 12% = 36（万元）
应调增应纳税所得额 = 50 - 36 = 14（万元）
应补缴企业所得税 = 14 × 25% = 3.5（万元）
分录：借：以前年度损益调整 35000
         贷：应交税费——应交企业所得税 35000
```

**例题 17（企业所得税综合复算，对应22年真题案例）**：会计利润 5600 万元；营业外支出中税收滞纳金 5 万元、罚款 3 万元、非广告性质赞助支出 18 万元不得扣除；职工福利费 2355 万元，扣除限额＝15000×14%＝2100 万元；研发费用 450 万元加计 100% 扣除；居民企业股息 200 万元免税。

```
应纳税所得额 = 5600 +（5+3+18）+（2355-2100）- 450 - 200 = 5231（万元）
应纳企业所得税 = 5231 × 25% = 1307.75（万元）
```

### 4.6 账务调整计算

**例题 18（红字冲销法）**：企业当月将生产领用的原材料 2000 元误记为 20000 元，多记 18000 元。
```
错误：借：生产成本 20000  贷：原材料 20000
调整：借：原材料 18000   贷：生产成本 18000   （红字冲销 18000）
```

**例题 19（补充登记法）**：企业当期应摊销无形资产 1000 元，实际摊销 500 元，少摊销 500 元。
```
调整：借：管理费用 500  贷：累计摊销 500
```

**例题 20（补充登记法，含税）**：甲公司销售产品，增值税专用发票注明价款 10000 元、增值税额 1300 元，款项已收存银行。会计误将贷方"主营业务收入"写为 1000 元、"应交税费——应交增值税（销项税额）"写为 130 元。
```
错误：借：银行存款 1130  贷：主营业务收入 1000
                              应交税费——应交增值税（销项税额）130
差额：银行存款少记 10170（11300 - 1130）
      主营业务收入少记 9000（10000 - 1000）
      销项税额少记 1170（1300 - 130）
调整：借：银行存款 10170
         贷：主营业务收入 9000
            应交税费——应交增值税（销项税额）1170
```

**例题 21（综合账务调整法）**：发现企业当期将一笔属于生产车间职工福利列支的费用支出 50000 元记入"管理费用"，贷方"银行存款"正确。

| 发现时间 | 调账分录 |
|---|---|
| 本月发现 | 借：生产成本 50000 ／ 贷：管理费用 50000 |
| 月度结算后发现 | 借：生产成本 50000 ／ 贷：本年利润 50000 |
| 年度结算后发现 | 借：生产成本 50000 ／ 贷：以前年度损益调整 50000 |

## 五、高频考点速记卡

1. **Q：纳税检查的主体和客体分别是谁？**
   A：主体是**税务机关**；客体是纳税人，同时包括**代扣代缴义务人、代收代缴义务人、纳税担保人**（不含税务机关本身）。

2. **Q：查询纳税人银行存款账户和查询案件涉嫌人员储蓄存款的批准权限？**
   A：查询银行存款账户经**县以上税务局（分局）局长**批准，凭**全国统一格式的检查存款账户许可证明**；查询案件涉嫌人员储蓄存款经**设区的市、自治州以上税务局（分局）局长**批准。查询资料不得用于税收以外的用途。

3. **Q：纳税检查方法有哪几组分类？顺查法与逆查法有何不同？**
   A：按查账粗细分详查法和抽查法；按查账顺序分顺查法和逆查法；按与检查资料的相互关系分联系查法和侧面查法；另有盘存法和分析法。顺查法＝凭证→账簿→报表，系统全面但工作量大、重点不突出；逆查法＝报表→账簿→凭证，容易发现线索、便于抓住重点、目标明确、效果显著。

4. **Q：比较分析法、推理分析法、控制分析法各自的应用场景？**
   A：比较分析法＝账面数据与计划指标、历史资料或同类企业数据进行动态和静态对比；推理分析法＝资产变动与负债及所有者权益变动平衡关系分析；控制分析法＝生产企业投入与产出、耗用与补偿的控制分析。注意：分析法**只能提供线索，不能作为查账定案的依据**。

5. **Q：三种账务调整方法及适用范围？错账发现时间不同调整哪个账户？**
   A：红字冲销法（科目用错或金额多记）、补充登记法（科目正确但金额少记）、综合账务调整法（借贷方一方科目用错另一方正确，主要用于所得税检查后的调整）。调整账户：当月发现→损益类科目；当年月度结算后发现→"本年利润"；年度结算后发现→"以前年度损益调整"。

6. **Q："应交税费"下与增值税有关的二级明细科目有哪些？**
   A：应交增值税、未交增值税、预交增值税、待抵扣进项税额、待认证进项税额、待转销项税额、代扣代缴增值税、简易计税、增值税留抵税额、转让金融商品应交增值税（口诀"简易交代，留抵金融品"）。

7. **Q："应交增值税"明细账内设哪些专栏？**
   A：销项税额、销项税额抵减、进项税额、进项税额转出、已交税金、转出未交增值税、转出多交增值税、出口抵减内销产品应纳税额、减免税款、出口退税（口诀"销项已转交，进项减免退"）。

8. **Q："已交税金"和"未交增值税"如何区分？**
   A："已交税金"专栏记录**当月已缴纳**的应交增值税；"未交增值税"核算月度终了转入的当月应交未交、多交或预缴税额，以及**交纳以前期间未缴**的增值税。

9. **Q：预收货款销售货物与预收款提供租赁服务的纳税义务时间有何不同？**
   A：预收货款销售货物在**发出商品时**确认销售；预收款提供**租赁服务**在**收到预收款的当天**发生纳税义务。

10. **Q：委托代销的销售实现时间和账务处理？**
    A：委托方销售收入实现时间一般为**收到代销清单的当天**。收到代销清单时：借：应收账款 ／ 贷：主营业务收入、应交税费——应交增值税（销项税额）；同时借：主营业务成本 ／ 贷：委托代销商品。

11. **Q：自产货物用于职工福利、对外投资、无偿赠送的贷方科目有何不同？**
    A：职工福利→贷：库存商品（权属未变，不确认收入）；对外投资→贷：主营业务收入（视同销售确认收入）；无偿赠送→贷：库存商品，销项税额记入"营业外支出"。

12. **Q：包装物押金如何处理？**
    A：一般商品单独记账核算的押金**不并入销售额征税**，记"其他应付款"；逾期不退的押金应换算不含税后计税；除啤酒、黄酒外的其他酒类产品押金**无论是否返还均并入当期销售额征税**。

13. **Q：准予抵扣的进项税额有哪几项？**
    A：① 增值税专用发票（含机动车销售统一发票）注明的税额；② 海关进口增值税专用缴款书注明的税额；③ 购进免税农产品按买价和 9% 扣除率计算的税额；④ 支付的道路通行费；⑤ 购进国内旅客运输服务。

14. **Q：不得抵扣进项税额的情形（教材列举）？**
    A：用于简易计税、免征项目、集体福利或个人消费的购进货物；非正常损失的购进货物；非正常损失的在产品、产成品所耗用购进货物；非正常损失的不动产及其所耗用购进货物；非正常损失的不动产在建工程所耗用购进货物；购进的贷款服务、餐饮服务、居民日常服务和娱乐服务。非正常损失指因**管理不善**造成的被盗、丢失、霉烂变质损失。

15. **Q：混合用途长期资产的进项税额如何处理？**
    A：原值不超过 500 万元的单项长期资产全额抵扣；原值超过 500 万元的，购进时先全额抵扣，此后在混合用途期间根据调整年限**逐年计算**不得抵扣的进项税额。

16. **Q：销售数量的两种检查方法及适用范围？**
    A：以盘挤销倒挤法（本期销售数量＝上期结存＋本期完工－本期结存）适用于产成品管理制度**不够健全**的企业；以耗核产、以产核销测定法（本期应出产品数量＝本期实耗材料量÷单位产品材料消耗定额）适用于产成品管理制度**比较健全**的企业。

17. **Q：企业所得税收入确认时间有哪些特殊规定？**
    A：托收承付＝发出货物并办妥托收手续时；预收货款＝发出商品时；需安装检验＝安装检验完毕时（安装简单可在发出商品时）；委托代销＝收到代销清单时；股息红利＝被投资方作出利润分配决定的日期；利息收入＝合同约定的债务人应付利息的日期。

18. **Q：工资薪金、职工福利费、工会经费、职工教育经费的扣除规定？**
    A：工资薪金须**实际发放**才能扣除；职工福利费不超过工资薪金总额 **14%**；工会经费不超过 **2%**（强调拨缴工会，须取得专用收据）；职工教育经费不超过 **8%**，超过部分可结转以后年度。

19. **Q：业务招待费、广告费和业务宣传费、公益性捐赠的扣除标准？**
    A：业务招待费＝发生额 60% 与当年销售收入 5‰ 取小；广告费和业务宣传费不超过当年销售（营业）收入 15%，超过部分结转以后年度；公益性捐赠不超过**年度利润总额 12%**（超限额不得结转）。

20. **Q：哪些项目不得在税前扣除？是否都要调账？**
    A：向投资者支付的股息红利等权益性投资收益款项；企业所得税税款；税收滞纳金、罚金、罚款；非公益性捐赠支出；赞助支出；未经核定的准备金支出；为投资者或职工支付的商业保险费；企业之间支付的管理费；对外投资期间持有的投资资产成本；烟草企业的烟草广告费和业务宣传费支出。若**记账科目正确**，只需调增应纳税所得额、补缴所得税，不用作错账更正。

### （一）单项选择题与多项选择题

**1.【22年真题·多选】关于纳税检查的说法，正确的有（　）。**
A. 纳税检查的主体是税务机关

E. 经县税务局局长批准，可以查询案件涉嫌人员的储蓄存款

**答案：ABD**
**解析**：纳税检查的主体是税务机关，客体包括纳税人、代扣代缴义务人、代收代缴义务人、纳税担保人，A、B 正确。查询银行存款账户须经**县以上税务局（分局）局长**批准（不是税务所所长）并凭全国统一格式的检查存款账户许可证明，C 错误、D 正确。查询案件涉嫌人员储蓄存款须经**设区的市、自治州以上税务局（分局）局长**批准，E 错误。

**2.【24年真题·单选】下列不属于纳税检查客体的是（　）。**
A. 纳税人　B. 代扣代缴义务人　C. 纳税担保人　D. 税务机关

**答案：D**
**解析**：税务机关是纳税检查的**主体**，不是客体。

**3.【25年真题·多选】纳税检查的客体包括（　）。**
A. 纳税人　B. 负税人　C. 代扣代缴义务人　D. 代收代缴义务人　E. 纳税担保人

**答案：ACDE**
**解析**：客体为纳税人、代扣代缴义务人、代收代缴义务人、纳税担保人等；**负税人不属于**纳税检查客体。

**4.【20年真题·单选】从检查报表→检查账簿→检查凭证的纳税查账方法属于（　）。**
A. 联系查法　B. 逆查法　C. 侧面查法　D. 分析法

**答案：B**
**解析**：逆查法逆会计核算程序，从检查报表开始到检查账簿，再在凭证中落实检查内容。

**5.【25年真题·单选】在纳税检查方法中，（　）一般应用于对生产企业的投入与产出、耗用与补偿的分析。**
A. 比较分析法　B. 推理分析法　C. 控制分析法　D. 联系查法

**答案：C**
**解析**：控制分析法运用于生产企业投入与产出、耗用与补偿的控制分析；推理分析法用于资产变动与负债及所有者权益变动平衡关系分析。

**6.【25年真题·多选】下列关于纳税检查基本方法的说法，正确的有（　）。**
A. 用抽查法进行纳税检查时，抽查效果的好坏关键在于抽查对象的确定
B. 分析法不仅能揭露事物内部的矛盾，还可以作为查账定案结论的依据
C. 联系查法是对相关资料有联系的地方，如账证之间、账账之间、账表之间，进行相互对照检查的一种方法
D. 详查法适用于经济业务比较简单、会计核算制度不健全和财务管理比较混乱的企业，以及立案侦查的经济案件
E. 逆查法通过对有关资料进行分析比较，容易发现线索，便于抓住重点，目标比较明确，检查效果也较显著

**答案：ACDE**
**解析**：B 错误——分析法**不宜作为查账定案的依据**，只能揭露矛盾、提供线索。

**7.【21年真题·多选】资产负债表的审查内容包括（　）。**

**8.【21年真题·多选】明细分类账的检查包括（　）。**

B. 上下结算期之间相互核对
C. 审查账户发生额的借贷方向

**9.【24年真题·单选】下列属于外来原始凭证的是（　）。**

**答案：D**

**10.【22年真题·单选】在检查某企业时，发现企业上年度将一笔营业外收入记入"资本公积"科目，已进行年度决算，该企业应调整的会计科目是（　）。**
A. 本年利润　B. 以前年度损益调整　C. 净利润　D. 利润分配

**答案：B**

**11.【21年真题·单选】对于影响本年度以前月份的所得应调整的账户是（　）。**
A. 以前年度损益调整　B. 本年利润　C. 管理费用　D. 应收账款

**答案：A**
**解析**：影响本年度以前月份（即上年度）的所得，应通过"以前年度损益调整"账户调整。

**12.【23年真题·单选】在月度结算前发现将职工福利费记入"管理费用"科目，正确调账分录为（　）。**
A. 借：应付职工薪酬　贷：管理费用
B. 借：应付职工薪酬　贷：本年利润
C. 借：职工福利费　贷：管理费用
D. 借：应付职工薪酬　贷：以前年度损益调整

**答案：A**
**解析**：月度结算前（当月）发现错误，直接调整**损益类科目**：借方由"管理费用"改为"应付职工薪酬"，贷方"银行存款"正确不调整。

**13.【20年真题·单选】某企业当期应摊销无形资产1000元，实际摊销500元。应做的账务调整分录为（　）。**
A. 借：管理成本1000　贷：累计摊销1000
B. 借：管理费用500　贷：累计摊销500
C. 借：累计摊销500　贷：管理成本500
D. 借：累计摊销1000　贷：管理费用1000

**答案：B**
**解析**：会计科目正确但核算金额**小于**应计金额，用**补充登记法**补记少摊销的 500 元。

**14.【24年真题·单选】税务机关在对某企业进行纳税检查时，发现该企业当月将生产领用的原材料2000元误记为20000元，企业应做的账务调整为（　）。**
A. 借：原材料18000　贷：生产成本18000
B. 借：生产成本18000　贷：原材料18000
C. 借：原材料18000　贷：以前年度损益调整18000
D. 借：原材料18000　贷：本年利润18000

A. 借：应收账款1017000　贷：主营业务收入900000、应交税费——应交增值税（销项税额）117000
B. 借：主营业务成本800000　贷：库存商品800000
C. 借：长期应收款1130000　贷：主营业务收入1000000、应交税费——应交增值税（销项税额）130000
D. 借：长期应收款1130000　贷：主营业务收入900000、未实现融资收益100000、应交税费——待转销项税额130000

**答案：BD**
**解析**：赊销具有融资性质，按**现销价格 900000 元**确认收入，总价 1000000 元与现销价格差额 100000 元记入"未实现融资收益"；增值税纳税义务未发生，相关销项税额 130000 元先计入"应交税费——待转销项税额"。

**3. 针对业务（3）的账务处理，正确的调整分录是（　）。**
A. 借：银行存款2180000　贷：预收账款2000000、应交税费——应交增值税（销项税额）180000
B. 借：预收账款2180000　贷：其他业务收入2000000、应交税费——应交增值税（销项税额）180000
C. 借：预收账款180000　贷：应交税费——应交增值税（销项税额）180000
D. 借：预收账款1000000　贷：其他业务收入1000000

**答案：CD**
**解析**：预收款出租不动产，纳税义务发生时间为收到预收款的当天，应先计提销项税额＝2180000÷（1+9%）×9%＝180000（元）；租赁期内分期确认收入。

**4. 针对业务（4）的账务处理，正确的调整分录是（　）。**
A. 借：待处理财产损溢130000　贷：应交税费——应交增值税（进项税额转出）130000
B. 借：营业外支出1130000　贷：原材料1000000、应交税费——应交增值税（进项税额转出）130000
C. 借：营业外支出130000　贷：应交税费——应交增值税（进项税额转出）130000
D. 借：待处理财产损溢1130000　贷：原材料1000000、应交税费——应交增值税（进项税额转出）130000

**答案：A**
**解析**：非正常损失须将已抵扣进项税额 1000000×13%＝130000（元）作转出处理，调整分录为补记进项税额转出。

**5. 针对业务（5），正确的会计分录是（　）。**
A. 借：银行存款113000　贷：主营业务收入100000、应交税费——应交增值税（销项税额）13000
B. 借：主营业务成本80000　贷：库存商品80000
C. 借：税金及附加15000　贷：应交税费——应交消费税15000
D. 借：银行存款128000　贷：主营业务收入100000、应交税费——应交增值税（销项税额）13000、应交税费——应交消费税15000

**答案：ABC**

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把税务机关当作纳税检查的客体 | **主体是税务机关，客体是纳税人＋代扣代缴＋代收代缴＋纳税担保人**，主体不进客体 |
| 2 | 查询存款账户的批准级别记错 | **县以上局长批存款账户（凭许可证明）；设区的市以上局长批储蓄存款**；税务所所长无权批准 |
| 3 | 顺查法与逆查法顺序颠倒 | 顺＝从**凭证**顺着查到报表；逆＝从**报表**倒着查到凭证。记"顺证逆表" |
| 4 | 以为分析法能定案 | 分析法**只能提供线索**，"不宜作为查账定案的依据"；总分类账中发现的问题同样**只能作为线索** |
| 5 | 红字冲销法与补充登记法混用 | **多记冲销、少记补充**；科目用错也可用红字冲销（先红冲再用蓝字） |
| 6 | 错账调整账户选错 | 当月→损益类科目；**当年月度结算后→本年利润**；**年度决算后→以前年度损益调整** |
| 7 | "已交税金""未交增值税""转出未交增值税"层级与用途混用 | **当月已缴→"已交税金"专栏；缴以前期间未交→"未交增值税"明细科目**；"转出未交增值税"只是专栏，不是二级科目 |
| 8 | 预收货款方式收到款就计销项税额 | 销售货物**发出商品时**才确认；只有**租赁服务预收款**是收到当天计税 |
| 9 | 分期收款忽视"待转销项税额" | 赊销/分期收款会计收入确认**早于**纳税义务时点，销项税额先计入"**待转销项税额**"，到收款日再转 |
| 10 | 自产货物用于职工福利，误确认收入 | 权属未变＝**内部处置**，不确认收入、不缴企业所得税，但**增值税仍视同销售** |
| 11 | 捐赠、投资业务贷方科目用错 | 无偿赠送按**成本**贷记"库存商品"、销项税入"营业外支出"、**不确认收入**；对外投资才贷记"主营业务收入" |
| 12 | 委托代销发出商品时就确认收入 | 发出只转成本（委托代销商品）；**收到代销清单**才确认收入和销项税额 |
| 13 | 包装物押金一律计税或一律不计税 | 一般商品单独记账**不计税**、逾期不退**计税**；**除啤酒黄酒外的酒类押金无论是否返还均计税** |
| 14 | 价外费用不计税、进项税额转出金额算错 | 价外费用**无论会计如何核算均并入销售额**，先÷(1+税率)换算；转出税额按**货物与运费不同税率**分别计算（如布料 13%、运费 9%） |
| 15 | 混合用途长期资产全额抵扣后忘记逐年调整 | 原值**超过 500 万元**的，购进时先全额抵，以后按**调整年限逐年计算**不得抵扣部分 |
| 16 | 把增值税计入"税金及附加" | "税金及附加"含消费税、城建税、教育费附加、资源税等，**不含增值税** |
| 17 | 组成计税价格分母用错 | 消费税组成计税价格÷（1-**消费税税率**）；无同类售价时才用，有售价按售价 |
| 18 | 现金折扣与商业折扣处理混淆 | 商业折扣按**扣除后金额**确认收入；现金折扣**实际发生时作财务费用**，不冲收入 |
| 19 | 以为计提的工资、工会经费都能扣 | 工资须**实际发放**；工会经费强调**拨缴工会**并取得专用收据，不是计提 |
| 20 | 业务招待费只乘 60% 或只乘 5‰ | **双限额取小**：min（发生额×60%，销售收入×5‰） |
| 21 | 公益性捐赠超限额部分结转扣除 | 公益性捐赠超 12% 部分**不得结转**；能结转的是**广告费（15%）和职工教育经费（8%）** |
| 22 | 所有不得扣除项目都要调账、查补税款一律记"所得税费用" | 科目正确的（赞助款、业务招待费、捐赠超标）只**调税不调账**；查补**以前年度**所得税记"**以前年度损益调整**" |
