## 二、知识点精讲

### 考点1 政府预算的含义 ★★

**核心概念**：政府预算是指通过**法定程序**审核批准、具有**法律效力**、可以**综合反映**国民经济和社会发展情况的政府**财政收支计划**，是政府筹集、分配和管理财政资金的重要工具，也是调节、控制和管理社会政治经济活动的重要手段。

- **狭义预算**：指**预算文件或预算书**。
- **广义预算**：指预算**编制、批准、执行、决算、审计结果的公布与评价**等所有环节。

**四个「看」（必考搭配）**：

| 角度 | 结论 |
|---|---|
| 从形式上看 | 以政府**财政收支计划**的形式存在；按时间跨度可分为**年度预算、多年预算**，典型形式是年度预算 |
| 从性质上看 | 经立法机关审批的预算是具有**法律效力**的文件；不经法定程序审查批准，任何人无权改变预算规定的各项收支指标 |
| 从内容上看 | 反映**公共资源的分配和政府职能范围**；是财政分配活动的**中心环节** |
| 从作用上看 | 政府调控经济和社会发展的重要手段，调控作用主要表现在**逆周期调节** |

**逆周期调节三点**：①通过预算收支规模的变动，调节社会总供给与总需求的平衡；②通过调整政府预算支出结构，调节国民经济和社会发展中的各种比例关系结构；③公平社会分配。

```
政府预算：形式＝财政收支计划（年度/多年）｜性质＝法律效力文件（立法机关审批）
          内容＝公共资源分配＋政府职能范围｜作用＝调控手段（逆周期调节）
```

**速记口诀**：**「形计划、质法律、内分配、用调控」**；广义预算五环节「**编批准执决，审计公布评**」。

### 考点2 政府预算的基本特征 ★★

**四个基本特征：法律性、预测性、集中性、综合性**（口诀：**预法集综**）。

| 特征 | 核心内容 |
|---|---|
| **法律性** | 现代预算的鲜明特征；收支形成和执行结果都要经过**立法机关**审查批准，它是一个法律文本 |
| **预测性** | 对预算收支规模、收入来源和支出用途做出事先的设想和预测 |
| **集中性** | 预算资金的规模、收入来源、支出去向、收支结构比例和财政平衡状况，由国家从国家全局整体利益出发统筹安排，集中分配 |
| **综合性** | 各项财政收支的汇集点和枢纽，综合反映国家财政收支活动全貌，反映政府活动的范围和方向 |

**预测性——国际上预测年度预算收入的四种技术手段**：

| 方法 | 判别关键词 |
|---|---|
| 专家预测法 | 利用相关专家最好的「猜测」 |
| 趋势预测法 | 根据**过往数据的变动情况**（过往绩效）做出预测 |
| 决定因子预测法 | 将政策制定作为假设，通过预测各因素的变化实现预测 |
| 计量预测法 | 建立在过往数据关系未来仍会保持的假定上，分析各种社会经济变量之间的关系 |

**速记口诀**：特征「**预法集综**」，最鲜明是**法律性**；预测四法「**专家、趋势、因子、计量**」，靠过往变动是**趋势**。

### 考点3 现代政府预算的多重研究视角 ★

| 视角 | 研究重点 |
|---|---|
| **经济学** | 最为注重政府预算的**配置和资金使用效率**问题 |
| **政治学** | 政府预算本身就是一种**政治活动**；从分析公共政策的决策过程以及预算如何执行入手 |
| **法学** | 从社会公众通过**立法机构规范政府预算行为**的角度出发，考察法律对各利益相关主体间权利与义务关系的调节与规范 |
| **管理学** | 强调政府预算的**功能性特征**，即预算的控制、管理和计划等功能 |
| **社会学** | 强调预算与整个社会之间的**互动关系**，将预算放在整个社会大背景下展开讨论 |

**速记口诀**：**「经济效率、政治活动、法学立法、管理功能、社会互动」**。

### 考点4 政府预算管理中的共同治理 ★

**三类利益主体及行为特征**：

| 主体 | 构成 | 行为特征 |
|---|---|---|
| **预算资金需求方** | 各政府部门和组织、财政拨款的事业单位、部分享受政府垄断管制或财政补贴的企业、享受政府转移支付的居民个人等 | ①追求自身利益最大化；②有追求**预算规模最大化**的内在冲动 |
| **预算资金供给方** | 履行向资金需求者配置预算资金职能的**政府预算部门** | ①具有**双重委托代理关系**；②有诱发**设租与寻租**收益的可能 |
| **预算资金监督制衡方** | 立法监督机构 | ①**代表人民利益**（最基本特征）；②具有**委员会决策机制**特点；③面临**偏好加总的困难**及组织协调的交易成本 |

**共同治理框架权能分工**：立法监督机构定预算总规模和结构性预算规模并根据审计结果奖惩；政府预算部门同资金需求者谈判并提出资金结构性分配初步建议、监督遵守预算规章；资金需求者定内部具体分配方案；审计部门监督结构性预算安排的效率与效果；社会公众和新闻媒体披露非效率行为。

```
需求方（追规模）──谈判──▶ 供给方（预算部门：配置职能，提结构性分配建议）
                                ▼
         监督制衡方（立法监督机构：定总规模＋审计奖惩）
                                │
     审计部门（监督效率效果）＋社会公众和新闻媒体（披露非效率行为）
```

**速记口诀**：**「需求追规模、供给双重代理、监督代表人民」**；最基本特征是**代表人民利益**，不是偏好加总困难。

### 考点5 政府预算的决策程序 ★★

**（一）决策程序的法定性**

1. 预算决策依据的特征及法定性：①预算决策依据与预测结论的不确定性需要法定决策程序保证；②预算决策所依据的法规、标准和原则需要依据法定程序制定；③预算决策的依据需要遵循法定程序作出的相关解释。
2. 预算方案的编制、审议通过和调整必须遵循法定程序：财政部门和预算部门依法编制预算草案，立法机构依法审议，预算执行调整依法定程序。

**（二）政府预算决策过程的实质：对公共偏好的选择**

- 政府预算决策的对象是**公共偏好**（要达到社会公认的公共商品供求均衡）；
- 公共偏好**以个人为评价基础**；公共偏好采取**政治程序**决策（公民不直接参与具体决策）；
- 政治决策程序具有**强制性**：**偏好表达的强制性**（设计公众参与表达偏好的机制）、**投票规则的强制性**（少数服从多数）、**政策意志的强制性**（将归集的公共需要转换为国家意志，力求公共偏好与当权者意志一致）、**决策结果的强制性**（决策形成后个人必须服从）。

**（三）优化政府预算决策的路径**

1. **以民主方式改进政治决策程序**：增加公众表达意愿、参与社会选择的机会；提高决策透明度。
2. **适当以市场化方式弥补预算决策政治缺陷**：以**经济的效率决策补充政治决策**，对计划项目细致审查、分析和论证，按重要性排队决定取舍，运用**计划规划预算、零基预算、绩效预算**等方法选择效率方案。
3. **明确权力边界，建立制衡机制**：制定决策标准，减少机动决策权；建立制衡机制，避免权力过分集中。

**速记口诀**：实质「**选公共偏好**」；强制「**表达、投票、意志、结果**」；优化三路径「**民主补程序、市场化补缺陷、制衡防集中**」。

### 考点6 政府预算模式 ★★★★（本章最高频）

**（一）主要预算模式——四种划分标准**

| 划分标准 | 类型 | 核心要点 |
|---|---|---|
| 按**编制结构** | 单式预算 | 全部财政收支汇集编入**一个总预算**，不区分收支性质。优点：反映整体性、统一性，明确收支规模和基本结构，便于审议和监督；缺点：不能反映收支的经济性质 |
| | 复式预算 | 按收入来源和支出性质编成**两个或两个以上**预算。**最早实行的是丹麦、瑞典**。典型形式是**双重预算＝经常预算＋资本预算** |
| 按**编制方法** | 基数预算 | 以上年度或基期收支为基数，综合考虑政策变化、财力增加额及支出实际需要量，确定增减调整比例测算年度收支指标。优点：简便易行；缺点：收支基数科学性难以界定，主观随意性较大 |
| | 零基预算 | 根据当年政策要求、财力状况和事业发展需要**重新核定**，不考虑以前年度收支基数。优点：不受以往年度收支约束，突出当年政策重点，防止收支结构僵化和财政拖累；缺点：不是所有项目都能采用，审核全部收支耗费大量人力物力财力 |
| 按**编制政策导向** | 投入预算 | 严守预算控制规则，限制甚至禁止资金跨项目转移，只反映投入用途和金额，不考虑经济效果。优点：规范化、制度化；缺点：不重视产出，效率低下 |
| | 绩效预算 | 每笔支出必须符合**绩、预算、效**三要素；又称**结果导向预算**。优点：降低成本、提高效率和效益 |
| 按**编制时间跨度** | 年度预算 | 经法定程序认可而具有法律效力的预算，收支实际经历时间为 1 年，分**历年制和跨历年制** |
| | 多年预算 | 宏观经济预测基础上的多年期滚动预算计划，通常为 **3～5 年**（有些国家更长），对年度预算具有约束力 |

**双重预算（复式预算的典型形式）**：

| | 经常预算 | 资本预算 |
|---|---|---|
| 身份 | 政府以**管理者**身份 | 政府以**资产所有者**身份 |
| 收入 | 以**税收**为主要来源 | 国有资产经营收益、资产处置收入、债务收入、经常预算结余转入等 |
| 支出 | 国家政权建设的政府日常行政经费支出，教育、科学、卫生、文化等各项事业费和社会保障支出 | 政府对国有企业的投资、对公共工程项目的投资、战略物资储备、政府贷款以及偿还公债等支出 |
| 性质 | 提供公共物品的消耗，不形成资本但必不可少；一般应收支平衡并略有结余，结余转入资本预算收入 | 反映政府干预经济过程中的投资活动，可形成一定量的资本 |

**绩效预算三要素**：**绩**＝绩效目标（尽量量化或指标化）；**预算**＝完成业绩所需拨款额（含人员工资和各种费用的全部成本）；**效**＝产出和结果指标（含量的考核指标和质的考核指标）。

**零基预算拓展**：①最早在美国实施；②系统的概念及实施步骤由美国德克萨斯仪器公司会计主管**彼·派尔**提出，四步骤：**识别决策单元、建立决策包、排序（核心内容）、编制预算**；实践中常与绩效预算融合实施。

**早期 vs 新绩效预算**：二者都强调支出绩效。**早期更强调产出，新绩效预算更强调支出的最终结果**，将绩效管理从决策编制引入执行及结果评价，更强调总额控制，下放自由裁量权，绩效管理覆盖整个预算过程。20 世纪 70 年代末到 80 年代初，**英国、澳大利亚、新西兰、加拿大**率先启动新绩效预算改革。

```
按编制结构：单式预算 / 复式预算（典型＝双重预算：经常预算＋资本预算）
按编制方法：基数预算 / 零基预算（四步：决策单元→决策包→排序→编预算）
按政策导向：投入预算（控投入） / 绩效预算（绩－预算－效）
按时间跨度：年度预算（1年，历年制/跨历年制） / 多年预算（3～5年滚动）
```

**速记口诀**：**「结构单复、方法基零、导向投绩、跨度年多」**；复式最早**丹麦瑞典**；绩效三要素「**绩、预算、效**」；新绩效强调**最终结果**。

### 考点7 政府预算的原则 ★★

| 原则 | 核心内容 |
|---|---|
| **公开性** | 各级政府预算及决算不仅要经过各级权力机关审批，而且须向社会公众**全面公开**；预算属于公开性的法律文件 |
| **可靠性** | 每一项收支项目的数字指标，必须运用科学的计算方法，依据充分，数据准确，**不得假定、估算，更不能任意编造**；对各项收支的性质必须明确区分 |
| **完整性** | **一切财政收支都要在政府预算中反映** |
| **统一性** | 预算收支按照统一的程序来编制；任何单位的收支都要**以总额列入预算**，不应当只列入收支相抵后的净额；不以临时预算或特种基金的形式另外编制预算 |
| **年度性** | 经立法机关审批的政府预算的编制、执行、决算这一完整工作程序周期性进行，通常为 **1 年**；分历年制、跨年制 |

**预算年度两种形式**：**历年制**按公历自每年 1 月 1 日起到 12 月 31 日止，实行国家主要有**中国、俄罗斯、法国、德国、意大利、西班牙、葡萄牙、墨西哥、巴西**等。**跨年制**一个预算年度跨越两个日历年度：①**4 月制**（每年 4 月起至次年 3 月 31 日止）——加拿大、英国、日本、印度、新加坡、新西兰、南非等；②**7 月制**（7 月 1 日起至次年 6 月 30 日止）——澳大利亚、巴基斯坦、孟加拉国、埃及、科威特、坦桑尼亚、肯尼亚等；③**10 月制**（10 月 1 日起至次年 9 月 30 日止）——美国联邦政府、泰国等。

**速记口诀**：原则「**年度、公开；统一、可靠、完整**」；总额列入是**统一性**，全反映是**完整性**，不准估是**可靠性**。

### 考点8 政府预算政策 ★★★

政府预算政策是财政政策的核心内容。教材此处表述为**经济学家关于政府预算这一财政政策的理论**，素材提示：这些观点或理论无所谓对错。

| 政策类型 | 代表人物 | 核心观点 |
|---|---|---|
| **健全财政政策** | 古典政治经济学家**亚当·斯密**、英国经济学家**巴斯坦布尔** | 力求保持**年度预算收支的平衡**，并以此为衡量财政是否健全的标志 |
| **功能财政预算政策** | 美国经济学家**勒纳**（20 世纪 40 年代） | 不必局限于预算收支对比关系、保持预算收支平衡，重要的是保持**国民经济整体的平衡**，采用**相机抉择方式**实现政策目标 |
| **周期平衡预算政策** | 美国经济学家**阿尔文·汉森**（20 世纪 40 年代） | 财政应在**一个完整的经济周期内**保持收支平衡，而不是在某个特定财政年度或日历时期内保持平衡。我国《预算法》规定各级政府应当建立**跨年度预算平衡机制** |
| **充分就业预算平衡政策** | —— | 按**充分就业条件下估计的国民收入规模**来安排预算收支，以此达到预算平衡 |
| **预算平衡政策** | 倾向于自由主义的经济学家（针对凯恩斯主义赤字预算理论的问题提出） | 通过预算调节经济可能引起人为的通货膨胀或经济紧缩；主张政府**不应干预经济**，不把预算收支作为干预经济的工具，谋求预算收支平衡 |

**速记口诀**：**「健全年度平（斯密），功能整体平（勒纳），周期跨年平（汉森），充分就业平，平衡不干预」**。

### 考点9 政府预算编制 ★★

**（一）编制总流程与总预算形成**

各级部门预算编制完成后，提交**本级财政部门**统一审查汇编；各级财政部门以部门预算为基础，加上自身掌握的有关收支，编制综合反映一级政府收支的预算，即**政府财政总预算**（每级政府都有自己的财政总预算）。按行政级别分为财政部汇编的**中央预算**和**地方总预算**。我国实行一级政府一级预算，设立**五级预算**，政府全部收入和支出均需纳入预算。汇编不是简单汇总，而是按预算汇编口径和预算管理办法，把有缴款、拨款关系的预算数字汇总，并把财政部门直接掌握的收支（转移支付、债务收支、总预备费等）一并编制，经审核、汇总和综合平衡后形成草案。

**（二）四大预算编制原则对比**

| 预算类型 | 编制原则 |
|---|---|
| **一般公共预算** | **量入为出、收支平衡**，除预算法规定情形外**不列赤字**。方式：预测本年收入总额→预计本年支出总额→统筹平衡确定收支总额，充分发挥预算稳定调节基金调节作用，合理利用债务收入或债务转贷收入，无资金来源的不安排支出。支出选取顺序：①工资等人员类项目；②机构运转和日常工作任务等运转类项目；③基本民生支出项目；④一般债务还本付息资金项目；⑤重点保障党委政府确定的重大项目；⑥其他项目 |
| **政府性基金预算** | 按基金项目编制，支出预算与收入预算按基金项目**一一对应**，做到**以收定支**；不同基金项目分别编制，原则上不允许项目间混编 |
| **国有资本经营预算** | **收支平衡、不列赤字**，按一定比例安排资金调入一般公共预算用于保障和改善民生；按当年取得的国有资本收益确定支出规模，以收定支。经本级人大或其常委会批准，国有资本规模较小或国企数量较少的市县**可以不编制本级**国有资本经营预算 |
| **社会保险基金预算** | ①**收支平衡**：按各险种的统筹层次和项目分别编制；②**专款专用**：不得挤占或挪作他用；③**与一般公共预算衔接**：单独编报，与公共财政预算和国有资本经营预算相对独立、有机衔接；做好基金结余保值增值，在精算平衡基础上实现可持续运行 |

**（三）一般公共预算的组成与两项关键比例**

一般公共预算由**本级部门预算、转移支付预算和预备费**等组成；一般公共预算支出规模控制本级部门预算支出、转移支付预算和预备费规模。转移支付预算包括一般性转移支付、专项转移支付、下级上解收入、上解上级支出、调入资金、调出资金、接受其他地区援助、援助其他地区支出、动用预算稳定调节基金、补充预算稳定调节基金等。

- **预算稳定调节基金**：编制年度预算调入使用后的规模**一般不超过当年本级一般公共预算支出总额（含对下级转移支付）的 5%**；调入资金用于弥补收支缺口，**调入规模不得超过基金余额**；超收收入（除用于冲减赤字外）、结余资金用于补充基金，并合理控制基金规模。
- **预备费**：按本级一般公共预算支出额的 **1%～3%** 设置，用于当年预算执行中的自然灾害等突发事件处理增加的支出及其他难以预见的开支；由财政部门直接编审预备费项目。

**（四）政府债务预算处理**

我国对政府债务**没有编制单独的预算**，而是按照所发债务的性质，分别列入**一般公共预算和政府性基金预算**：**一般债务收支纳入一般公共预算管理，专项债务收支纳入政府性基金预算管理**。

- **中央债务处理**：①中央政府债务不仅可以用于建设投资，也可以用于弥补一般公共预算支出（举借债务应控制适当规模、保持合理结构）；②对中央一般公共预算中举借的债务实行**余额管理**，余额规模不得超过**全国人大批准**的限额；③**财政部**具体负责对中央债务统一管理；④中央发行的超长期特别国债收支列入政府性基金预算管理。
- **地方债务处理**（六项限制）：**主体**——经国务院批准的省、自治区、直辖市；**范围**——省级政府预算中必需的建设投资部分资金（限于能够形成资本的公益性事业发展支出）；**方式**——只限发行地方政府债券，不得以其他任何方式举债，除法律规定外不得为他人债务提供担保；**用途**——只能用于**公益性资本支出**，不得用于经常性支出；**规范管理和监督**——经国务院批准的债务应纳入预算，债务规模由国务院报全国人大及其常委会批准，限额内举借的债务列入本级预算调整方案报本级人大常委会批准；**控制风险**——应有偿还计划和稳定偿还资金来源，国务院建立风险评估和预警机制、应急处置机制和责任追究制度。
- **地方债务分类**：按性质分**一般债务**（一般债券、外国政府贷款转贷债、国际金融组织转贷债等）和**专项债务**（专项债券等）；按管理分**显性债务（法定债务）**（地方政府债券、合法担保形成的债务）和**隐性债务**（法定债务预算之外，直接或间接以财政资金偿还以及违法提供担保等方式举借的债务）。
- **地方债务预算管理与偿还**：一般债务收支、还本付息、发行费用纳入一般公共预算，专项债务纳入政府性基金预算。省级政府为一般债券、专项债券发行主体，具体发行由省级财政部门负责；市县级确需发行的纳入本省规模、由省级财政部门代办发行并统一办理还本付息；经省级政府批准，计划单列市政府可自行发行。偿还：一般债务本金经一般公共预算收入（含调入预算稳定调节基金和其他预算资金）、发行一般债券等偿还，**利息经一般公共预算收入偿还、不得发新债偿还**；专项债务本金经对应的政府性基金收入、专项收入、发行专项债券等偿还，**利息经对应的政府性基金收入、专项收入偿还、不得发行专项债券偿还**；专项债务收支按对应的政府性基金收入、专项收入实现项目收支平衡，不同基金科目不得调剂，收入不足本息时可从相应公益性项目单位调入专项收入弥补。举债应严格落实偿债资金来源，合理制定偿债计划并在**中期财政规划**中如实反映。

```
部门预算 ──提交──▶ 本级财政部门统一审查汇编 ──＋直接掌握的收支（转移支付/债务/总预备费）──▶ 政府财政总预算
政府债务：一般债务──▶ 一般公共预算 ；专项债务──▶ 政府性基金预算
```

**速记口诀**：**「一般债进公预、专项债进基金；地方举债限主体限范围限方式限用途，只能公益性资本支出」**；稳定调节基金 **5%**、预备费 **1%~3%**。

### 考点10 跨年度预算平衡机制 ★★

**（一）年度预算平衡 vs 跨年度预算平衡**

| | 年度预算平衡 | 跨年度预算平衡 |
|---|---|---|
| 含义 | 每一年的财政收支结果都应是平衡的预算 | 预算收支的对比关系应在**一定的经济周期内**保持平衡，而不是在某一个特定财政年度内保持平衡 |
| 评价 | 缺陷：①容易忽略潜在的财政风险；②一个预算年度内收支结构调整受限，与年度内不确定因素矛盾；③限制政府对未来更长远的考虑 | 突出优点：有利于政策的**长期可持续性**，使决策者尽早发现问题、鉴别风险、采取措施、防患于未然 |

我国《预算法》规定：各级政府应当建立跨年度预算平衡机制。

**（二）构建跨年度预算平衡机制**

1. **预算超收及短收的平衡机制**
   - **超收收入**：年度本级一般公共预算收入实际完成数**超过**经本级人大或其常委会批准的预算收入数的部分。平衡机制：在**冲减赤字或化解债务后用于补充预算稳定调节基金**。
   - **短收收入**：实际完成数**小于**批准的预算收入数的情形。平衡机制：**调入预算稳定调节基金或其他预算资金、削减支出**等实现平衡，仍不能平衡则**调整预算增列赤字**。
2. **预算赤字的弥补机制**：①中央预算赤字在经全国人大或其常委会批准的**国债余额内发债平衡**；②省级政府报本级人大或其常委会批准后增列赤字，报财政部门备案，在下一年度预算中弥补（也可在国务院下达的本地区政府债务限额内**发行地方政府一般债券**平衡）；③市、县级政府申请**上级政府临时救助**实现平衡，并在下一年度预算中归还。
3. **实施中期财政规划管理**：指财政部门会同政府各部门在分析预测未来 **3～5 年**重大财政收支情况，对规划期内重大改革、重要政策和重大项目研究政策目标、运行机制和评价办法的基础上，编制的跨年度财政收支方案。
   - 国际上三种形式：**中期财政框架（MTEF）、中期预算框架（MTBF）、中期绩效框架（MTPF）**。
   - 我国按**三年滚动方式**编制，更接近中期财政框架，也是中期预算的过渡形态。
   - 与年度预算的关系：**分年度看**，第一年规划**约束**对应年度预算，后两年规划**指引**对应年度预算；年度预算执行结束后调整后两年规划、再添加一个年度规划，形成新一轮中期财政规划。**分级次看**，全国中期财政规划对中央年度预算编制起**约束**作用、对地方起**指导**作用；地方中期财政规划对地方年度预算编制起**约束**作用；部门三年滚动财政规划对部门预算起**约束**作用。

```
超收 ─▶ 冲减赤字/化解债务 ─▶ 补充预算稳定调节基金
短收 ─▶ 调入稳定调节基金/削减支出 ─▶ 仍不能平衡 ─▶ 调整预算增列赤字
赤字 ─▶ 中央：国债余额内发债平衡；省级：人大批准增列赤字＋下年度弥补；市县：上级临时救助＋下年度归还
```

**速记口诀**：**「超收补基金、短收调基金，不平增列赤字；中央发债、省批赤字、市县求救」**；中期规划「**三年滚动、第一年约束、后两年指引**」。

### 考点11 部门预算编制 ★★★★（高频考点）

**（一）部门预算的含义**

部门预算是编制政府预算的一种制度和方法，由政府各部门依据国家有关法律法规及履行职能的需要编制，反映部门所有收入和支出情况的**综合财政计划**；是**总预算的基础**，由各预算部门编制。

**基本含义三点**：①以部门作为预算编制的基础单元，财政预算**从部门编起，从基层单位编起**；②不同性质的财政资金**统一编制到使用这些资金的部门**，预算落实到每一个具体部门，预算管理以部门为依托；③限定与财政直接发生经费领拨关系的**一级预算单位**为预算部门。

**部门预算是综合预算**：既含行政单位预算又含事业单位预算；既含一般预算收支计划又含政府基金预算收支计划；既含正常经费预算又含专项支出预算；既含预算拨款收支计划又含部门其他收支计划。各部门预算应反映四大预算安排给本部门及所属各单位的所有预算资金。

**（二）部门预算的八项原则**

| 原则 | 核心内容 |
|---|---|
| **合法性原则** | 符合《预算法》规定，在法律赋予部门的职能范围内进行 |
| **真实性原则** | 收支预测必须以国家社会经济发展计划和履行部门职能的需要为依据，力求数据真实准确 |
| **完整性原则** | 所有收入和支出全部纳入部门预算，对各项财政资金统一管理、统筹安排，编制综合财政预算 |
| **科学性原则** | 收入预测、支出方向、编制程序、编制方法、预算核定都要科学 |
| **稳妥性原则** | 量入为出，收支平衡，**不得编制赤字预算**；收入预算留有余地；先保证基本工资、离退休费和日常办公经费等基本支出 |
| **重点性原则** | 兼顾一般的同时优先保证重点支出；先保证基本支出，后安排项目支出；先重点、急需项目，后一般项目 |
| **透明性原则** | 对经常性支出建立科学定员定额体系，结合财力状况与支出重点，优先安排急需、可行项目，使预算分配规范、透明 |
| **绩效性原则** | 将部门和单位预算收支全面纳入绩效管理，赋予更多管理自主权；对决策、编制、执行过程及完成结果全面追踪问效 |

**（三）部门预算的基本内容**

- **部门收入预算**：预算单位从不同来源取得的各种收入，主要包括**上年结转资金、财政拨款收入、上级补助收入、事业收入、事业单位经营收入、下级单位上缴收入、用事业基金弥补收支差额和其他收入**。
- **部门支出预算**：按支出的管理要求划分，分为**基本支出预算和项目支出预算**。

| | 基本支出预算 | 项目支出预算 |
|---|---|---|
| 含义 | 保障机构正常运转、完成日常工作任务所必需的开支而编制的预算，是部门支出预算的主要组成部分 | 单位为完成特定的行政工作任务或事业发展目标，在基本支出预算之外编制的年度支出计划 |
| 内容 | **人员经费和日常公用经费** | 基本建设、有关事业发展专项计划、专项业务费、大型修缮、大型购置、大型会议等项目支出 |
| 原则 | ①**综合预算**（不同来源收入统筹安排）；②**优先保障**（先保障基本支出，后安排项目支出）；③**定员定额管理**（以定员定额为主，结合部门资产情况建立实物费用定额标准，实现资产管理与定额管理相结合） | ①**综合预算**；②**科学论证、合理排序**（充分可行性论证和严格审核基础上按轻重缓急排序，结合财力优先安排急需、可行项目）；③**追踪问效**（坚持绩效原则，考核项目成本、效益，对实施过程及完成结果绩效考评） |
| 特征 | —— | **专项性、独立性、完整性**（项目之间支出不能交叉，与基本支出也不能交叉；应包括完成特定业务目标涉及的全部经费支出） |

**速记口诀**：部门预算原则「**合法真实完整科学，稳妥重点透明绩效**」；基本支出三原则「**综合、优先、定员定额**」；项目支出三原则「**综合、论证排序、追踪问效**」，三特征「**专项、独立、完整**」。

### 考点12 政府采购与政府购买服务 ★★

**（一）政府采购的含义与原则**

我国 **2003 年实施、2014 年修正**的《政府采购法》界定：政府采购是指各级**国家机关、事业单位和团体组织**，使用**财政性资金**（纳入预算管理的资金）采购集中采购目录以内或采购限额标准以上的货物、工程和服务的行为。所称服务包括政府自身需要的服务和向社会公众提供的公共服务；集中采购目录包括集中采购机构采购项目和部门集中采购项目。项目同时使用财政性资金和非财政性资金的，使用财政性资金采购的部分适用政府采购法。制度最早形成于 18 世纪末的西方国家，由**英国**创建；国际上政府集中采购支出占国民生产总值的比重达 **10%—20%**。
| 原则 | 核心内容 ||---|---|
| **公开透明原则** | 政府采购的有关信息、法律、政策、程序以及采购过程都要公开 |
| **公平竞争原则** | 政府采购的基本规则；给予每个参加竞争的合格投标商均等机会，不歧视任何一方 |
| **公正原则** | 采购方及其代理人应站在公允立场，平等对待所有供应竞争者。**回避制度**（与供应商有利害关系之一应回避）：①采购活动前 **3 年内**存在劳动关系；②前 **3 年内**担任董事、监事；③前 **3 年内**是控股股东或实际控制人；④与法定代表人或负责人有夫妻、直系血亲、三代以内旁系血亲或近姻亲关系；⑤其他可能影响公平公正进行的关系 |
| **诚实信用原则** | 民事活动的基本原则，同样适用于政府采购活动 |
| **讲求绩效原则** | 落实全过程绩效管理要求，根据部门预算绩效目标合理确定采购需求、计划和合同 |

**（二）政府采购的基本方式**

按是否具备招标性质分为**竞争性采购**和**非竞争性采购**；采用竞争性方式采购的，参加竞标的供应商一般**不得少于三家**。

| 类别 | 方式 | 要点 |
|---|---|---|
| 竞争性采购 | **公开招标采购（主要方式）** | 按事先确定并公布的标准从所有投标中评选中标供应商。优点：最能体现公开性、竞争性，是最普遍的方式；缺点：费用较高、费时费力 |
| | **竞争性谈判采购** | 与多家供应商分别谈判后确定中标供应商。优点：缩短采购周期、减少工作量、较好满足需求、保护民族产业；缺点：可能助长价格垄断、滋生串通舞弊、造成任意抬价。适用于紧急情况（如招标后没有供应商投标）或涉及高科技应用产品和服务的采购 |
| | **询价采购** | 发出询价单、比较报价后确定中标供应商。适用：现货或标准规格的产品和服务采购、投标文件审查需很长时间的采购等 |
| | **框架协议采购** | 竞争性采购方式之一（素材仅列明名称） |
| 非竞争性采购 | **单一来源采购（直接采购）** | 即使达到竞争性招标金额标准，但来源渠道单一（专利或首次制造、合同追加、原有项目后续扩充等），只能从唯一供应商采购。不利于降低成本，不符合竞争原则 |

**（三）政府购买服务**

通过发挥**市场机制作用**，把政府直接提供的一部分公共服务事项及履行职责所需的**辅助性服务事项**，按一定方式和程序交由具备条件的社会力量和事业单位承担，并以**合同等契约化方式**明确双方权利义务，政府按合同约定支付费用。

| 要素 | 内容 |
|---|---|
| **购买主体** | 各级行政机关和具有行政管理职能的事业单位、纳入行政编制管理且经费由财政负担的群团组织。**不包括**不具备行政管理职能的事业单位（其购买自身辅助性服务属政府采购，不属政府购买服务） |
| **承接主体** | 社会组织、事业单位、企业、机构等；**社会组织**是重要承接主体 |
| **购买内容** | 属于政府职责范围、适合采取市场化方式提供的服务事项 |
| **购买方式及程序** | 目录以内或限额以上项目：采用公开招标、邀请招标、竞争性谈判、竞争性磋商、单一来源采购等方式确定承接主体；目录以外且限额以下项目：可不采用《政府采购法》规定的采购方式，但一般应体现竞争性原则 |
| **预算与财务管理** | ①所需资金列入财政预算，从部门预算经费或经批准的专项资金等既有预算中统筹安排；②健全购买服务预算管理体系；③强化预算执行监控 |

```
政府采购
 ├─ 竞争性采购：公开招标（主要）/ 竞争性谈判 / 询价 / 框架协议
 └─ 非竞争性采购：单一来源采购（直接采购）
政府购买服务：购买主体（有行政管理职能）→ 承接主体（社会组织为重要主体）→ 市场化方式＋合同契约
```

**速记口诀**：采购原则「**公开透明、公平竞争、公正回避、诚实信用、讲求绩效**」；回避都是「**3 年**」；公开招标是**主要方式**；紧急情况用**竞争性谈判**；政府购买服务**不包括**不具备行政管理职能的事业单位。

### 考点13 现代国库制度 ★

**核心内容**：现代国库不单是指国家金库，更重要的是指财政代表政府控制预算执行、保管政府资产和负债的一系列管理职能。**国库集中收付管理、公债管理和国库现金管理**构成现代国库管理制度的核心内容。

**（一）国库集中收付管理（现代国库管理的基本制度）**

指通过建立**国库单一账户体系**，规范财政资金收入和支付运行机制，提高预算执行透明度及资金运行效率和使用效益。主要内容：①**完善的国库单一账户体系**——财政收入直接缴入国库，财政支出直接支付给收款人，所有财政资金收付活动都纳入国库单一账户体系管理；②**规范的财政资金收付程序和方式**——财政收入按规范程序直接缴入国库单一账户，财政支出通过规范程序直接支付给货物和劳务供应者，实际支付前财政资金余额全部保留在国库单一账户；③**对财政资金收支活动实行有效的监控**——运用现代信息技术对每一笔财政资金收支活动实时监控。

**我国国库集中收付制度**：我国从 **2001 年**开始推行以国库单一账户体系为基础、资金缴拨以国库集中收付为主要形式的财政国库管理制度改革。①改革账户管理体系：建立科学、可控、集中的国库单一账户体系；②改革资金收缴方式：采取**直接缴库和集中汇缴**方式，将税收收入和非税收入直接缴入国库单一账户或财政专户；③改革资金支付方式：实行**财政直接支付和财政授权支付**方式，通过国库单一账户体系将资金支付给收款人（素材仅列明两种支付方式名称，二者适用区分素材未明确）。

**（二）公债管理**

在控制公债规模和公债风险的前提下，通过公债发行、兑付、交易等一系列管理活动，长期以最小成本满足财政筹资需要，同时促进公债市场发展。①发行市场化程度不断提高，由 **1981 年**恢复发行公债时的行政摊派发展到记账式公债全部招标发行，储蓄公债由财政部确定票面利率后通过承销团承购包销发行；②期限结构多样化，记账式公债已形成从 **3 个月到 30 年及以上**的短、中、长、超长期结构，**1 年、3 年、7 年期**作为关键期限品种持续滚动发行；③交易方式不断创新，由现券交易、质押式回购发展到买断式回购、远期交易、掉期交易和融券交易。

各国对公债规模的控制分为公债**发行额管理**和公债**余额管理**，余额管理又分为**公债限额管理**和**预算差额管理**。**公债限额管理**：立法机关为发行公债设置额度限制，限额内政府自行决定发行品种、时间和方式。**预算差额管理**：立法机关每年审批预算赤字或预算盈余（公债规模的增量或减量），不审批借新还旧部分。我国全国人大常委会批准自 **2006 年**开始实行公债余额管理，改变了发行额管理下年度发行额必须全额完成的控制方式，可在不突破余额限额的前提下，根据国库库款预测合理安排发行时间和节奏。

**（三）国库现金管理**

在确保国库现金支付需要的前提下，以实现国库闲置现金最小化和投资收益最大化为目标的一系列财政管理活动。管理对象主要包括**库存现金、活期存款和与现金等价的短期金融资产**。操作方式包括商业银行定期存款、买回公债、公债回购和逆回购等；在国库现金管理**初期**，主要实施**商业银行定期存款和买回公债**两种操作方式。

**速记口诀**：现代国库核心「**集中收付、公债、现金**」；收缴「**直接缴库＋集中汇缴**」，支付「**直接支付＋授权支付**」；余额管理自 **2006 年**起；现金管理初期「**定期存款＋买回公债**」。

### 考点14 政府预算的审查、批准和监督制度 ★

**（一）政府预算的审查和批准**

预算审批是指相关部门对预算草案进行审查并批准执行的过程，包括**财政部门对预算的审查和立法机关对预算的审查及批准**；一经立法机关审批，预算草案即具有法律性和权威性，各预算单位严格遵照执行。

- **发达国家的预算审批**：大部分市场经济国家实行代议制，预算职能分工是**行政机关负责预算编制和执行，立法机关负责预算审批**。立法机关权力较大，审批发挥**实质性作用（美国）**；权力较小，**形式意义大于实质作用（德国和日本）**。
- **我国的预算审批**：**各级人民代表大会**是法定预算审批部门，审查重点是预算草案的**合法性、完整性、可行性**；审批分**初审和终审**两阶段。初审由各级人大相关部门在人大召开前对预算草案主要内容初步审查——国务院财政部门应在每年全国人大会议举行前 **45 日前**将中央预算草案初步方案提交全国人大财经委初审，省、市、县应在本级人大会议举行前 **30 日前**初审；终审由各级人大对预算草案审查批准。

**（二）政府预算的监督**

政府预算监督是指在预算的全过程中，对有关预算主体依法进行的检查、督促和制约，是政府预算管理的重要组成部分；最基本表现形式之一是**对财政收支的审计**。西方的财政监督制度开始于 **1256 年**。

- **广义与狭义**：广义指具有监督权的各主体依法定权限和程序对政府预算行为实施的检查和监督；狭义指财政机关在财政管理过程中对预算的合法性、真实性、有效性实施的审查、稽核、检查。相同：监督对象一致（国家机关、事业单位、国有企业和其他组织）；不同：监督主体范围及由此引出的监督方式和内容不同。
- **监督特点（六个）**：体系的**层次性**、主体的**多元性**、对象的**广泛性**、过程的**全面性**、依据的**法律性**、形式的**多样性**。
- **监督分类**：按体系构成分立法机关监督、财政部门监督、审计部门监督、社会中介机构监督、社会舆论监督和司法监督；按时间顺序分**事前、事中、事后**监督。- **监督主要内容**：立法机关——对预算编制、调整和变更的监督、对决算的监督；财政部门——对预算编制、收支执行、政府采购、内部财务收支的监督；审计部门——对预算编制、执行、决算的审计和对政府性基金的审计。

**（三）预算违法行为的法律责任**

1. **追究行政责任**（责令改正）：未依规编制报送预算草案、调整方案、决算草案和部门预算决算及批复；违反规定进行预算调整；未依规公开和说明预算事项；违反规定设立政府性基金项目和其他财政收入项目；违反法律法规规定使用预算预备费、预算周转金、预算稳定调节基金、超收收入；违反规定开设财政专户。
2. **给予降级、撤职、开除处分**：未将所有政府收入和支出列入预算或虚列收支；多征、提前征收或减征、免征、缓征应征预算收入；截留、占用、挪用或拖欠应上缴国库的预算收入；违反规定改变预算支出用途；擅自改变上级政府专项转移支付资金用途；违反规定拨付预算支出资金、办理预算收入收纳划分留解退付，或违法冻结、动用国库库款。
3. **给予撤职、开除处分**：违反规定举借债务或为他人债务提供担保；挪用重点支出资金；在预算之外及超预算标准建设楼堂馆所。
4. **依法给予处分**（追回资金、没收违法所得，对单位警告或通报批评）：改变预算收入上缴方式；虚报、冒领骗取预算资金；扩大开支范围、提高开支标准；其他违反财政管理规定行为。
5. **构成犯罪**的，依法追究刑事责任。

**速记口诀**：审批「**财政审、人大批；45 日中央、30 日地方；初审＋终审**」；监督特点「**层多广全法多**」；违法责任轻重有序「**行政责任→降级撤职开除→撤职开除→处分→刑责**」。

### 考点15 政府预算的绩效管理 ★

**（一）内涵**

政府预算绩效管理是把市场经济的一些基本理念融入公共管理之中，强调**投入与产出**的关系，即政府通过公共物品及服务的提供与相应的成本费用比较，要求以较小的成本费用投入取得较大的产出与成果；其宗旨在于有效降低政府提供公共产品的成本，提高财政支出的效率，约束政府支出的扩张，因此又被称为**以结果为导向的预算管理**。

**（二）绩效管理的前提（五项）**

| 前提 | 具体内容 |
|---|---|
| **构建绩效评价框架体系** | ①建立年度绩效计划：编制年度预算时根据部门战略目标确立，阐述部门在特定年度内拟提供的公共服务数量和水平，作为绩效评价依据；②提交绩效报告：比较实际绩效与计划绩效，描述绩效目标完成程度（一般要经过独立机构审计）；③进行绩效评价：绩效报告向社会公众公布，由公众评价；④反馈绩效评价结果：评价好坏直接影响拨款多少 |
| **赋予部门管理者充分的自主权** | 有人事支配权，有选择从政府部门或私人部门购买服务的权力；拨款数额内可自主决定资金用途。传统预算管理侧重对投入的控制，绩效管理模式侧重对结果的控制，逐渐转向内部控制与结果控制模式 |
| **强化部门管理者的责任** | 资金支出后未实现预期结果，支出机构负责人要承担管理责任；将预算决策重点从收入分配转向最终结果产出了多少公共服务及质量，实现手段到目的的转移 |
| **以权责发生制计量政府成本** | 权责发生制通过计提固定资产折旧和反映长期项目债务信息，能更准确全面反映政府一定时期内提供产品和服务耗费资源的成本，并更好将预算成本与预期绩效成果配比；收付实现制对资源投入控制功能较强、对产出管理功能较弱。**美国、法国、加拿大**采用改良的或修正的权责发生制；**澳大利亚、新西兰、英国**实行完全的权责发生制 |
| **建立绩效预算管理的制度和组织保障** | 以改革最彻底的新西兰为例：《国家部门法案》要求部长与 CEO 之间签订绩效协议；《公共财政法案》要求 CEO 对自己部门的财务管理负责；《财政责任法案》要求在政府会计和预算中引入权责发生制等 |

**（三）我国政府预算绩效管理的内容**

我国《预算法》规定，为了推进预算绩效管理，要将绩效理念融入预算管理全过程，使之与预算编制、预算执行、预算监督一起成为预算管理的有机组成部分，逐步建立「**预算编制有目标、预算执行有监控、预算完成有评价、评价结果有反馈、反馈结果有应用**」的预算绩效管理机制。

- **全面实施绩效管理的三个维度**：①构建**全方位**格局（政府、部门、单位、政策、项目；对实施期超过一年的重大政策和项目实行全周期跟踪问效）；②建立**全过程**链条（绩效评估、目标管理、运行监控、评价和应用）；③完善**全覆盖**体系（一般公共预算、政府性基金预算、国有资本经营预算、社会保险基金预算）。
- **各预算绩效管理关注重点**：一般公共预算——收入方面关注收入结构、征收效率和优惠政策实施效果，支出方面关注资金配置效率、使用效益特别是重大政策和任务实施效果；政府性基金预算——关注基金政策设立延续依据、征收标准、使用效果等，地方政府还关注对专项债务的支撑能力；国有资本经营预算——关注贯彻国家战略、收益上缴、支出结构、使用效果等；社会保险基金预算——关注基金收支政策效果、基金管理、精算平衡、地区结构、运行风险等。
- **健全预算绩效管理制度**：①完善绩效管理流程（绩效评估、目标管理、运行监控、评价和应用）；②健全绩效标准体系（定量和定性指标相结合，突出结果导向、重点考核实绩，运用成本效益分析法、比较法、因素分析法、公众评判法、标杆管理法等）。
- **强化预算绩效管理约束**：①明确责任约束（花钱必问效、无效必问责；地方各级政府、各部门、各单位分别是责任主体，重大项目责任人实行绩效终身责任追究制）；②强化激励约束（绩效结果与部门预算挂钩）。
**速记口诀**：绩效管理「**以结果为导向**」；机制五步「**编制有目标、执行有监控、完成有评价、评价有反馈、反馈有应用**」；三维度「**全方位、全过程、全覆盖**」；完全权责发生制国家「**澳、新、英**」。

## 四、公式与计算

> **说明（据素材）**：本章「主要为记忆型的考点，**不涉及计算**」，学完知识点后通过刷题加深记忆；素材中**没有**预算收支平衡、结转结余的计算公式与例题。本节收录素材中真实存在的**比例数字规则**与**唯一切数式公式**，并配数字演算（演算所用金额为示意数字，规则均出自素材）。

**规则1 基数预算公式（素材唯一切数式公式）**

```
预算年度某项收支数额 ＝ 上年度或基期该项收支的基数 ×（1 ± 变化率%）
```

**演算例题**：某省上年度某项收入基数为 10000 万元，预算年度按政策变化率 **＋6%** 测算，则预算年度该项收入数额 ＝ 10000 ×（1＋6%）＝ **10600 万元**。（数字为示意）

**规则2 预算稳定调节基金 5% 上限**

预算稳定调节基金在编制年度预算调入使用后的规模，一般**不超过当年本级一般公共预算支出总额（含对下级转移支付）的 5%**。

**演算例题**：某市当年本级一般公共预算支出总额（含对下级转移支付）为 5000000 万元，则预算稳定调节基金调入使用后的规模上限 ＝ 5000000 × 5% ＝ **250000 万元**。（数字为示意）

**规则3 预备费 1%～3%**

预备费按照本级一般公共预算支出额的 **1%～3%** 设置。

**演算例题**：某市本级一般公共预算支出额为 2000000 万元，则预备费规模区间 ＝ 2000000 ×（1%～3%）＝ **20000 万～60000 万元**。（数字为示意）

**规则4 国有资本经营预算调入一般公共预算比例**

国有资本经营预算应按一定比例安排资金调入一般公共预算，用于保障和改善民生；至 **2020 年**，国有资本经营预算调入一般公共预算的比例达到 **30%**。

**演算例题**：某省当年取得国有资本收益 100000 万元，按 30% 比例调入一般公共预算，则调入规模 ＝ 100000 × 30% ＝ **30000 万元**。（数字为示意）

**关键机制（无公式，逻辑必考）——预算收支平衡机制**：

```
年度本级一般公共预算收入实际完成数
```

## 五、高频考点速记卡

1. **Q：政府预算的含义？**
   A：经法定程序审核批准、具有法律效力、综合反映国民经济和社会发展情况的政府财政收支计划。狭义＝预算文件或预算书；广义＝编制、批准、执行、决算、审计结果公布与评价等所有环节。

2. **Q：四个基本特征？最鲜明的是？**
   A：法律性、预测性、集中性、综合性；最鲜明的是**法律性**（收支形成和执行结果经立法机关审查批准）。

3. **Q：预测年度预算收入的四种技术手段？靠过往数据变动的是哪种？**
   A：专家预测法、趋势预测法、决定因子预测法、计量预测法；根据过往数据变动预测的是**趋势预测法**。

4. **Q：三类预算利益主体的行为特征？**
   A：需求方——追求自身利益最大化、有预算规模最大化冲动；供给方（预算部门）——双重委托代理关系、可能诱发设租寻租；监督制衡方（立法监督机构）——代表人民利益（最基本）、委员会决策机制、面临偏好加总困难。

5. **Q：预算决策过程的实质？强制性的四个体现？**
   A：实质是对**公共偏好**的选择（以个人为评价基础、政治程序决策）。强制性：偏好表达、投票规则、政策意志、决策结果。

6. **Q：预算模式的四种划分标准及类型？**
   A：结构→单式/复式；方法→基数/零基；政策导向→投入/绩效；时间跨度→年度/多年。

7. **Q：绩效预算三要素？新绩效与早期绩效预算的区别？**
   A：三要素：绩（绩效目标）、预算（全部成本拨款额）、效（产出和结果指标）。早期强调**产出**，新绩效强调**支出的最终结果**。

8. **Q：收支以总额列入预算体现哪项原则？**
   A：**统一性**（不只列收支相抵后的净额）。

9. **Q：五种政府预算政策的核心观点？**
    A：健全财政（斯密，年度收支平衡）；功能财政（勒纳，国民经济整体平衡＋相机抉择）；周期平衡（汉森，完整经济周期内平衡）；充分就业平衡（按充分就业国民收入安排）；预算平衡（政府不干预）。

10. **Q：预算稳定调节基金和预备费的比例？**
    A：稳定调节基金调入后**≤当年本级一般公共预算支出总额（含对下级转移支付）的 5%**；预备费＝本级一般公共预算支出额的 **1%～3%**。

11. **Q：政府债务预算如何处理？地方举债的限制？**
    A：无单独债务预算，一般债务进一般公共预算、专项债务进政府性基金预算。地方举债限省级主体、只发地方政府债券、只能用于公益性资本支出。

12. **Q：超收和短收如何平衡？**
    A：超收——冲减赤字/化债后**补充预算稳定调节基金**；短收——**调入基金/削减支出**，仍不平则**增列赤字**。

13. **Q：中期财政规划的国际类型？我国类型及与年度预算的关系？**
    A：中期财政框架（MTEF）、中期预算框架（MTBF）、中期绩效框架（MTPF）。我国**三年滚动**编制，接近中期财政框架；第一年**约束**、后两年**指引**；全国规划对中央**约束**、对地方**指导**。

14. **Q：基本支出与项目支出预算的原则、特征？**
    A：基本支出＝人员经费＋日常公用经费，原则为综合预算、优先保障、定员定额管理；项目支出原则为综合预算、科学论证合理排序、追踪问效，特征为专项性、独立性、完整性。

15. **Q：我国预算审批的部门和程序？**
    A：各级人大是法定审批部门，审合法性、完整性、可行性；初审（全国人大会议前 45 日、省市县 30 日）＋终审由各级人大审查批准。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把预算审批机关记成「司法机关」「国务院」「财政部」 | 预算收支形成和执行结果经过**立法机关（各级人大）**审查批准 |
| 2 | 混淆广义预算与狭义预算 | 狭义＝**预算文件或预算书**；编制、批准、执行、决算、审计结果公布与评价属**广义** |
| 3 | 把「集中性」「综合性」当成最鲜明特征 | 最鲜明特征是**法律性**；综合性＝收支汇集点和枢纽 |
| 4 | 认为预算决策对象是「个人偏好」 | 是**公共偏好**；公共偏好**以个人为评价基础**，公民不直接参与决策 |
| 5 | 漏选政治决策程序强制性的某项 | 四个：**偏好表达、投票规则、政策意志、决策结果**（没有「程序决策」「资金筹措」） |
| 6 | 复式预算最早实行国家记成英国、美国 | **丹麦、瑞典**最早 |
| 7 | 把「绩效预算」与「投入预算」的优点混淆 | 投入预算重**规范化制度化**；绩效预算重**结果导向、降本增效** |
| 8 | 认为新绩效预算强调产出 | 早期绩效预算强调**产出**；新绩效预算强调**支出的最终结果** |
| 9 | 认为社保基金预算可补助或被用于平衡其他预算 | 社保基金「**只进不出**」，不能平衡其他三项预算；一般公共预算**可补助**社保基金 |
| 10 | 混淆五项预算政策 | **健全＝年度平衡（斯密）；功能＝整体平衡＋相机抉择（勒纳）；周期＝经济周期内平衡（汉森）；充分就业＝按充分就业国民收入安排；预算平衡＝不干预** |
| 11 | 把统一性和完整性原则混记 | **总额列入**是统一性；**一切收支全反映**是完整性 |
| 12 | 混淆 5% 与 1%~3% | 预算稳定调节基金调入后**≤支出总额 5%**；预备费＝支出额 **1%~3%** |
| 13 | 认为地方债务可多渠道多形式举借 | 只限**发行地方政府债券**；只能用于**公益性资本支出**；一般债务利息**不得发新债偿还** |
| 14 | 把「超收」「短收」处理方式记反 | 超收→冲减赤字/化债后**补充稳定调节基金**；短收→**调入基金/削减支出**，不平则**增列赤字** |
| 15 | 混淆中期财政规划对中央与地方的作用 | 全国规划对中央**约束**、对地方**指导**；地方规划对地方年度预算**约束** |
| 14 | 部门预算原则与基本支出/项目支出原则混记 | 部门八原则含**稳妥性、重点性**；基本支出三原则＝综合、优先保障、定员定额；项目支出＝综合、论证排序、追踪问效 |
| 17 | 把项目支出特征记成四个 | 只有三个：**专项性、独立性、完整性**（无「真实性」「公开性」） |
| 18 | 政府采购回避年限记成 5 年 | 劳动关系、董事监事、控股股东/实际控制人均是**前 3 年内** |
| 19 | 政府购买服务主体范围放大 | 购买主体**不包括**不具备行政管理职能的事业单位；其购买自身辅助性服务属政府采购、不属政府购买服务 |
| 20 | 混淆国库集中收付的收缴与支付方式 | 收缴＝**直接缴库＋集中汇缴**；支付＝**财政直接支付＋财政授权支付** |
| 21 | 把初审时限记混 | 全国人大会议前 **45 日**（中央预算草案初步方案）；省、市、县本级人大会议前 **30 日** |
