## 二、知识点精讲

### 考点1 财政平衡的含义 ★★

**核心概念**：财政平衡是指**财政收支之间的对比关系**。

| 对比关系 | 结果 |
|---|---|
| 收＞支 | 出现结余 |
| 收＜支 | 出现赤字 |
| 收＝支 | 出现数量上的绝对平衡 |

**关键结论**：

1. 现实中**不太可能出现收支数量上绝对平衡**的情况；一般来讲，财政收支**略有结余或略有赤字**，可以视作财政**基本平衡或大体平衡**。
2. 财政结余一般表现为**国家预算执行结果收入大于支出的余额**；财政赤字则表现为**预算赤字**或**预算执行结果支大于收的差额**。
3. 财政赤字是一种**普遍存在的经济现象**，是**调节收支平衡的重要手段**。

**财政收支不平衡的五个原因**（多选高频）：

1. 对**财政支出需要的无限性**与**财政收入可能的有限性**之间必然存在矛盾；
2. 财政决策失误、计划与实际不一致；
3. **生产力发展水平与经济管理水平**会对财政收支计划的执行产生影响；
4. **财政收入的不均衡性和部分财政支出的集中性**，导致收支在时间上不一致；
5. **某些意外情况**（严重自然灾害、政局不稳定、突发战争等）。

**核心结论**：财政收支矛盾的客观性，决定了**不平衡是财政收支活动的基本形态**。

**逻辑链**：

```
财政收支三种对比 → 结余 / 赤字 / 绝对平衡
        ↓ 现实中绝对平衡几乎不存在
略有结余或略有赤字 = 财政基本平衡（大体平衡）
        ↓ 五大原因（支出无限vs收入有限、决策失误、
        管理水平、收支时间错配、意外情况）
不平衡是财政收支活动的基本形态
```

**速记口诀**：**"收支对比定平衡，略有结余赤字也算平；五因致不平，不平衡是常态。"**

### 考点2 财政赤字的计算口径 ★★★

财政赤字是财政支出大于财政收入而形成的差额，由于会计核算中用**红字**处理，因此称为财政赤字。财政赤字是**衡量政府财政状况的重要指标**，也是**财政政策调控的重要手段**。

两种计算口径对比（**本考点核心表格，必背**）：

| 比较方式 | 硬赤字 | 软赤字 |
|---|---|---|
| 定义 | 用**债务收入弥补收支差额以后仍然存在**的赤字 | **未经债务收入弥补**的赤字 |
| 计算口径 | 硬赤字＝（经常收入＋债务收入）－（经常支出＋债务支出） | 软赤字＝经常收入－经常支出 |
| 弥补方式 | 只能通过**向中央银行借款或透支**弥补 | 通过**发行公债**弥补，西方经济学家称为"**赤字债务化**" |
| 经济影响 | 在银行信贷资金紧张时，可能产生**没有物资保证的货币购买力**，引发通货膨胀和物价上涨，对国民经济危害明显 | 只是**购买力的转移**，不会造成社会需求总量与供给总量失衡，也不会引发通货膨胀 |
| 采用情况 | —— | **目前世界上多数国家都采用软赤字的计算口径** |

**巧思妙记（素材原版）**：**有债务硬赤字，无债务软赤字**。

**逻辑链**：

```
硬赤字：经常收入+债务收入 − (经常支出+债务支出)
   → 债务收入已计入仍缺口 → 只能向央行借款/透支
   → 无物资保证的货币购买力 → 通货膨胀（危害大）

软赤字：经常收入 − 经常支出（不含债务收支）
   → 缺口用发行公债弥补 = 赤字债务化
   → 购买力转移，不引发通胀 → 世界多数国家采用
```

**速记口诀**：**"硬赤字含着债务算，透支央行惹通胀；软赤字不含债务项，发债弥补最保险。"**

> **多来源提示**：个别来源另将计算口径表述为"预算赤字（编制预算时预测）与实际赤字（预算执行中发生）"两种。此表述与主流硬/软赤字分法不同，**考试以硬赤字、软赤字分法为准**（历年真题均按此命题）。

### 考点3 财政赤字的分类 ★★★

财政赤字可以根据其**产生的原因和影响**进行分类，共 **4 类**：

| 分类 | 含义 | 典型例子 |
|---|---|---|
| **结构性赤字** | 由于**经济结构调整**导致的财政收入减少或支出增加而产生的赤字 | 经济转型过程中，政府增加对教育、医疗等领域的支出 |
| **周期性赤字** | 在**经济周期波动**中，由于**经济衰退**导致的财政收入减少或支出增加而产生的赤字 | 经济衰退时期采取扩张性财政政策，增加支出刺激经济增长 |
| **临时性赤字** | 由于**特殊事件或紧急情况**导致的财政收入减少或支出增加而产生的赤字 | 自然灾害、战争等紧急情况下增加支出应对危机 |
| **政策性赤字** | 由于**政府政策调整**导致的财政收入减少或支出增加而产生的赤字 | 实施减税政策过程中政府财政收入减少 |

**速记口诀**：**"结构调、周期衰、临时灾、政策减"**——分别对应经济结构调整、经济衰退、特殊事件紧急情况、政府政策调整四种成因。

### 考点4 财政赤字的弥补方式及其经济效应 ★★★（本章重点）

#### （一）四种弥补方式

| 弥补方式 | 具体内容 | 对货币供给的影响 |
|---|---|---|
| **增收减支** | 通过增加财政收入、减少财政支出来弥补赤字（通常没有多大余地） | 只是**改变了国民收入分配的结构**（政府份额增加、非政府部门份额减少），**不会对货币供给量产生影响** |
| **动用结余** | 动用以前年度滚存的财政结余。**前提条件是财政必须有结余**（连年赤字的财政不适用） | 若结余**未被**信贷部门使用，不增加货币供给；若结余**已被**信贷部门使用，则会增加货币供给量 |
| **向中央银行透支或借款** | 相当于**通过货币发行、凭空创造购买力**来弥补赤字，对货币流通影响很大，容易引发通货膨胀。一般情况下政府不会采用 | 通常**增加**中央银行基础货币投放量，在货币乘数作用下增加市场货币供应总量，导致物价上涨、形成通货膨胀 |
| **发行公债** | 政府通过发行公债为赤字融资，称为**债务融资**或**赤字债务化**；是**最理想**的弥补财政赤字的方法，也是世界各国弥补财政赤字的**普遍做法** | 认购者是**家庭**：购买力转移，不增加货币供给；认购者是**企业**：通常不增加，但企业认购后流动资金严重不足、增加对商业银行贷款需求且商业银行无法实现信贷收支平衡时，会增加；认购者是**商业银行**：能否实现信贷收支平衡是关键，不能平衡则增加；认购者是**中央银行**：**增加**货币供应量 |

#### （二）财政赤字的排挤效应（2026 年重点关注）

**含义**：财政赤字的排挤效应是指由于财政赤字的弥补而**导致私人经济部门投资以及个人消费减少**的现象。

**2026 年变动表述**：政府通过发行国债等方式弥补财政赤字时，会增加市场对资金的需求，从而可能导致**市场利率上升**，企业融资成本提高，进而抑制企业的投资意愿和投资规模，即民间投资被政府的赤字融资行为"排挤"出去的现象。

**影响因素**：与**货币市场的松紧程度、经济的活跃状况、政府赤字的规模和融资方式**密切相关。当货币供应量不能随赤字融资同步增加时，利率上升压力更大，排挤效应更显著；若央行采取扩张性货币政策配合赤字融资、增加货币供给，则可能减轻排挤效应。

**实现机制（按公债发行方式区分）**：

| 发行方式 | 实现途径 |
|---|---|
| **行政摊派**发行 | 通过**行政手段强制**实现：政府将公债分配给企业和个人认购，减少企业投资和个人消费 |
| **自愿认购** | ① **直接排挤效应**：政府有意识地通过**提高公债利率或降低发行价格**，吸引企业、个人甚至商业银行认购公债，进而减少投资和消费；② **间接排挤效应**：政府发债**增加了货币需求**，在货币供给一定的条件下**导致利率上升**，从而减少企业投资和个人消费 |

**排挤效应的优劣评价（须具体问题具体分析）**：

| 分析角度 | 评价 |
|---|---|
| **总量调节角度** | 社会总需求不足时，赤字出现明显排挤效应，**不利于**实现宏观调控目标；社会总需求过旺或总供求大致均衡时，赤字出现排挤效应**反而有利于**实现社会总供求均衡 |
| **结构调节角度** | 投资需求不足、消费需求过旺时，赤字排挤个人消费同时增加政府投资，是有利影响；投资需求过旺、消费需求不足时，赤字排挤企业投资、增加政府消费，同样是有利影响 |

#### （三）通货膨胀税

通常，**长时间的政府财政赤字**可能导致通货膨胀。为弥补财政赤字而导致的货币过量发行，使政府在国民生产总值的再分配中获取更大份额。在国内生产总值因物价上涨而呈现**名义增长但实际增长有限**的情况下，政府收入的增长主要通过**价格再分配机制**实现。因此政府收入分为两部分：

1. **国民生产总值正常增量的分配所得**；
2. **价格再分配所得**——后者即为西方经济学家所称的**通货膨胀税**。

**逻辑链**：

```
财政赤字 → 弥补方式四选一
   ├─ 增收减支 → 不影响货币供给
   ├─ 动用结余 → 看结余是否已被信贷部门使用
   ├─ 向央行透支/借款 → 基础货币↑ → 通胀（一般不用）
   └─ 发行公债（最理想）→ 看认购者：家庭/企业/商业银行/央行
                    ↓ 发债增加资金需求 → 利率↑ → 私人投资消费↓
               排挤效应（直接：提息降价；间接：利率上升）
                    ↓ 长时间赤字 + 货币过量发行
       政府收入 = 正常增量分配所得 + 价格再分配所得（通货膨胀税）
```

**速记口诀**：**"增收不动量，结余看信贷，透支必增量，公债看主公；排挤直接提利率、间接升利率，赤字长久通胀税。"**

### 考点5 财政政策的含义、目标 ★

#### （一）含义与特点

**含义**：财政政策是指国家（或政府）为实现宏观经济目标，通过**调整财政收入与支出**，影响社会总需求和经济活动的一系列宏观调控措施的总称。完整的财政政策体系包括**税收政策、支出政策、预算平衡政策、公债政策**等。

| 要素 | 内容 |
|---|---|
| **主体** | 财政政策的制定者和执行者。**只能是各级政府，主要是中央政府** |
| **直接性** | 财政政策由国家直接掌握和控制，可通过它直接干预和调节社会经济生活，这是价格政策、货币政策所不能相比的 |
| **强制性** | 一般通过立法形式制定和颁布实施，具有法律效力，各单位和个人都必须执行，否则受法律制裁 |

#### （二）五大目标

| 目标 | 含义 |
|---|---|
| **经济适度增长** | 一国国民收入的实际总量增长或一国人均国民收入的实际增长。经济的真正增长指国民收入增长**快于人口增长** |
| **物价基本稳定** | 物价总水平的基本稳定，物价水平在短期内没有显著或急剧的波动 |
| **收入分配公平** | 在一定社会范围和社会道德规范下，社会成员之间和可支配经济资源之间的均衡和协调 |
| **充分就业** | 有能力并且自愿参加工作者都能找到比较适当的工作。**这是政府进行宏观调控的首要目标**；并不意味着消除失业 |
| **国际收支平衡** | 国际收支包括**经常项目、资本项目、遗漏与误差、官方平衡项目**四个项目；平衡指经常项目、资本项目、遗漏与误差**三个项目**总的收支对比状况 |

**逻辑链**：

```
财政政策主体 = 各级政府（主要是中央政府）
特点 = 直接性 + 强制性（货币政策 = 间接性 + 自愿性）
体系 = 税收政策 + 支出政策 + 预算平衡政策 + 公债政策
目标 = 经济增长、物价稳定、收入公平分配、充分就业（首要）、国际收支平衡
```

**速记口诀**：**"主体各级政府重中央，直接强制两特点；五大目标增物价、配业收支，充分就业为首要。"**

### 考点6 财政政策的功能 ★★★

财政政策具有**四大功能**：

| 功能 | 内容 | 典型例子 |
|---|---|---|
| **导向功能** | 通过对物质利益（经济利益）的调整，发挥对个人和企业的经济行为以及国民经济发展方向的引导作用。分**直接导向**与**间接导向** | 直接导向：**加速折旧的税收政策**，大大激发企业对设备投资的欲望，加速固定资产更新改造；间接导向：**对某些行业实行低税政策**，促进该行业生产发展，同时影响其他企业的投资选择和消费者的消费选择 |
| **协调功能** | 对社会经济发展过程中的某些失衡状态的制约、调节能力，协调各经济主体的经济利益关系 | 支出政策、税收政策、预算政策、补贴政策相互配合、相互补充 |
| **控制功能** | 政府对人们的经济行为和宏观经济运行的制约或促进，实现对整个国民经济发展的控制。突出特征是**间接性** | —— |
| **稳定功能** | 调整总支出水平，使货币支出水平大体等于产出水平，实现国民经济稳定发展。主要特征是**反周期性和补偿性** | 反周期性：繁荣期税收自动增加、转移性支出自动下降，减轻通胀压力；衰退期税收自动减少、转移性支出增加，增加有效需求。补偿性：私人部门支出不足时，政府增加公共支出或减少税收，维持总需求不变 |

**速记口诀**：**"导、协、控、稳四功能；导向分直接间接，稳定看反周补偿。"**

### 考点7 财政政策工具 ★★★（本章核心）

财政政策工具共 **6 个**：

| 工具 | 核心要点 |
|---|---|
| **1. 政府预算** | 在各种财政政策手段中居于**核心地位**；能系统、明显地反映政府财政政策的意图和目标，具有**综合性、计划性和法律性**。预算收入对总需求产生**收缩**效果，预算支出对总需求产生**扩张**效果 |
| **2. 税收** | 调节作用主要通过**税率确定、税负分配、税收优惠和税收惩罚**体现；增税收缩需求，减税扩张需求 |
| **3. 公债** | 国家按**有偿**的信用原则筹集财政资金的形式；调节作用三个方面：调节**国民收入的使用结构**、调节**产业结构**、调节**资金供求和货币流通** |
| **4. 政府投资** | 财政用于**资本性支出**的部分，最终形成各种类型的**固定资产**；是进行国家重点建设和其他大中型项目的主要资金来源，也是形成国有资产的主要物质基础 |
| **5. 公共支出** | 政府满足纯公共需要的一般性支出（经常性项目支出），包括**购买性支出和转移性支出** |
| **6. 财政补贴** | 财政支出的一部分；特征：是一种**财政援助**（对接受补贴者产生激励作用）、为特定目标或目的服务（具有鲜明政策意图）；最主要优点是**灵活性和针对性** |

**政府预算收支差额的三种情况**（必考）：

| 预算收支差额 | 对总需求的净影响 | 政策类型 |
|---|---|---|
| 收＞支（预算结余） | **收缩性** | 紧缩性财政政策 |
| 支＞收（预算赤字） | **扩张性** | 扩张性（积极）财政政策 |
| 收＝支（收支平衡） | **中性** | 中性财政政策 |

政府预算的调控作用：① 通过预算收支规模的变动及其平衡状态，调节社会总供给与总需求的平衡关系（总需求＞总供给时采取结余政策；总需求＜总供给时采取赤字政策；大体平衡时采取中性政策）；② 通过调整政府预算支出结构，调节国民经济中的各种比例关系和经济结构（具有直接性和迅速性）。

**税收的三个作用维度**：

- 对需求的影响：增税收缩、减税扩张；
- 在资源配置中的作用：① 调节资源在**积累和消费**之间的分配（总体上看，征税会**降低积累率、提高消费率**）；② 调节资源在**产业**之间的配置（调节产业结构）；③ 调节资源在**政府部门和非政府部门（企业和居民）**之间的配置（通过确定适度的**宏观税率**实现）；
- 在收入分配中的作用：通过**调节企业的利润水平和居民的个人收入水平**实现收入公平分配。

**政府投资的项目范围**：具有**自然垄断特征、外部效应大、产业关联度高、具有示范和引导作用**的基础性产业、公共设施，以及**新兴的高科技主导产业**。

**公共支出的两部分**：
- **政府购买**：实质性支出，有商品和劳务的实际交易，可直接形成社会需求和购买力；经济萧条时期可提高购买支出水平（如举办公共工程），提高社会整体需求水平；
- **转移性支出**：主要形式有**社会保障、财政补贴**等；社会保障的范围和水平能对经济周期波动产生调节作用；财政补贴增减有着与增减税收**相反**的调节效果。

**财政政策的传导机制**：各政策工具通过某种媒介体相互作用形成的一个有机联系的整体。发挥作用的最重要传导媒介体是**收入分配、货币供应与价格**。

| 传导媒介 | 传导路径 |
|---|---|
| 收入分配 | 改变货币收入者**实得货币收入**或使货币收入者的**实际购买力**发生变化 |
| 货币供给 | 财政政策工具使用→财政收支增减变化→形成财政盈余或赤字→影响货币供应量→影响市场利率→影响市场总供给和总需求 |
| 价格 | 财政政策工具使用→引起产品和要素价格变化→影响下游产业的生产成本和消费者的选择→影响市场资源配置 |

**速记口诀**：**"六个工具预税公、投补支出；预算核心结收支；公债调节使用结构、产业结构、资金供求；传导三媒介：分配、货币、价格。"**

### 考点8 财政政策的类型 ★★★★（高频）

三种划分标准（**必背，选择题高频**）：

| 划分标准 | 类型 | 含义 |
|---|---|---|
| **按政策作用和影响范围划分** | **宏观财政政策** | 通过对经济总量发挥作用，调节社会总供给和社会总需求，也称为**经济稳定政策**；政策效应是影响总供给和总需求平衡 |
| | **中观财政政策** | 以**产业结构**为调节对象，努力实现产业结构合理化 |
| | **微观财政政策** | 通过影响**经济个体**（企业或个人）的经济行为或经济活动发挥作用，通常是影响**相对价格** |
| **按对经济周期的调节作用划分** | **自动稳定的财政政策** | 能够根据经济波动情况**自动**发生稳定作用，不用借助外力、不需要政府采取任何干预行动；主要是**累进税制度和转移支付制度**，被称为"**自动稳定器**"或"**内在稳定器**" |
| | **相机抉择的财政政策** | 政府**有意识地**运用政策手段调节社会总供求，也称为"**斟酌使用的财政政策**" |
| **按在国民经济总量方面的不同功能划分** | **扩张性财政政策** | 通过财政分配活动**增加和刺激社会总需求**；主要手段是**减税和增加财政支出规模**；一般会导致财政赤字，**等同于赤字财政政策** |
| | **紧缩性财政政策** | 通过财政分配活动**减少和抑制总需求**；主要手段是**增加税收和减少财政支出**；**等同于盈余财政政策** |
| | **中性财政政策** | 财政分配活动对社会总供求的影响保持中性，收支活动既不产生扩张效应也不产生紧缩效应；一般要求财政收支保持平衡 |

**逻辑链**：

```
扩张性财政政策（总需求不足时用）
   手段：减税 + 增加财政支出 → 总需求↑ → 往往形成赤字
   → 扩张性财政政策 ≈ 赤字财政政策
中性财政政策（总供求大体平衡时用）
   手段：收支平衡 → 对总需求净影响为中性
紧缩性财政政策（总需求过旺、有通胀缺口时用）
   手段：增税 + 减少财政支出 → 总需求↓ → 往往形成结余
   → 紧缩性财政政策 ≈ 盈余财政政策
```

**速记口诀**：**"宏观调经济总量，中观调产业结构，微观调经济个体；扩张增加需求（赤字），紧缩减少需求（盈余），中性收支求平衡；自动稳定累进税加转移支付，相机抉择靠斟酌。"**

### 考点9 货币政策的含义、目标 ★

**含义**：一国政府为实现一定的宏观经济目标所制定的关于**调整货币供应**的基本方针及相应措施的总称。货币政策体系由**信贷政策、利率政策、汇率政策**等构成。一个国家的货币政策由该国的**中央银行**制定（中国是**中国人民银行**），是中央银行实现其职能的核心所在。

**目标**：一般来说，各国货币政策的最终目标有四个，即**物价稳定、充分就业、经济增长和国际收支平衡**。《中国人民银行法》规定，货币政策的基本目标是**保持货币币值的稳定，并以此促进经济增长**。

**货币政策的特点**：对国民经济运行的调节具有**间接性和自愿性**两个明显特点（与财政政策的直接性、强制性相对）。

### 考点10 货币政策工具 ★★★★（高频）

**巧思妙记（素材原版）**：一般性政策工具——"**公开市场贴存款**"；选择性政策工具——"**控制利率保进口**"。

#### （一）工具分类

| 类别 | 工具 | 要点 |
|---|---|---|
| **一般性政策工具**（中央银行运用最多的传统工具，实施对象是整个社会总需求） | **法定存款准备金率** | 商业银行等金融机构按规定比率将所吸收存款的一部分缴存中央银行，本身不得使用；央行调高或调低比率，影响商业银行贷款能力和派生存款能力，调节货币供应量。**做法比较严厉，不宜经常使用，更不宜大幅度调整** |
| | **再贴现率** | 商业银行向中央银行办理再贴现时使用的利率；央行调整再贴现率可影响商业银行贷款数量，影响流通中货币供应量。**便于灵活运用，可根据经济需要及时调整，是可供经常使用的手段** |
| | **公开市场业务** | 央行通过在金融市场上**买进或卖出有价证券**进行调节；**传导过程短，中央银行可以直接控制货币供应量（无需通过商业银行）**，是不少西方国家中央银行最经常使用、最为灵活、最为有效的调节货币供应量的重要手段 |
| **选择性政策工具**（有选择地对某些特殊领域的信用加以调节和影响） | **消费者信用控制** | 央行对**不动产以外的各种耐用消费品**的销售融资加以控制 |
| | **不动产信用控制** | 央行对金融机构在**房地产**方面放款的限制措施，抑制房地产投机 |
| | **证券市场信用控制** | 对证券信用交易的**法定保证金比率**作出规定，是对以信用方式购买股票和债券实施的控制措施 |
| | **优惠利率** | 政府对国家鼓励、重点发展的经济部门或产业实行优惠利率 |
| | **预缴进口保证金** | 央行要求进口商预缴相当进口商品总值一定比例的存款，抑制进口过快增长 |
| **直接信用控制** | 从质和量两个方面，以行政命令或其他方式，直接对金融机构尤其商业银行的信用活动进行的控制 | 手段包括：**利率最高限、信用配额、直接干预、流动性比率** |
| **间接信用指导** | 央行通过间接办法影响商业银行的信用创造 | **道义劝告、窗口指导** |

#### （二）货币政策的传导过程（3 个基本环节）

```
环节1：中央银行 → 各金融机构和金融市场
   通过法定存款准备金率、再贴现率、公开市场业务、信贷计划等
   政策工具的操作，控制金融机构的贷款能力和金融市场的资金融通渠道
        ↓
环节2：各金融机构和金融市场 → 企业和个人的投资与消费
   通过提高或降低利息率、扩张或紧缩货币供应量，
   使各金融机构和企业、个人调整自己的投资和消费
        ↓
环节3：企业、个人的投资、消费 → 产量、物价和就业的变化
   最终影响经济发展、物价稳定、就业增加、国际收支平衡等的实现
```

**速记口诀**：**"一般性工具三大件：存款准备金、再贴现、公开市场；选择五工具：消不动证优进（消费者、不动产、证券、优惠、进口）；直接控制四手段：限配额干流动；间接指导两劝告：道义劝告、窗口指导。"**

### 考点11 货币政策的类型 ★

货币政策的核心是通过**变动货币供应量**，使货币供应量与货币需求量之间形成一定的对比关系，进而调节社会总需求与总供给。从总量调节角度分为 3 种：

| 类型 | 含义 | 手段 |
|---|---|---|
| **扩张性货币政策** | 货币供应量**超过**经济过程对货币的实际需要量，功能是**刺激社会总需求的增长** | **降低存贷款利息、降低法定存款准备金率**等 |
| **紧缩性货币政策** | 货币供应量**小于**经济过程对货币的实际需要量，功能是**抑制社会总需求的增长** | **提高法定存款准备金率和再贴现率、卖出国债**等 |
| **中性货币政策** | 货币供应量**大体等于**经济过程对货币的实际需要量，对社会总需求与总供给的对比状况不产生影响 | —— |

### 考点12 财政政策与货币政策的区别和联系 ★★

#### （一）相同点和统一性

1. 两大政策的**调控目标是统一的**，即都属于宏观经济调控目标；
2. 两者都是**需求管理政策**；
3. 从经济运行的统一性来看，财政、信贷和货币发行之间有**不可分割的内在联系**，任何一方的变化都会引起其他方面的变化，最终引起社会总供给与总需求的变化。

#### （二）不同点（六大不同）

| 不同点 | 财政政策 | 货币政策 |
|---|---|---|
| **政策工具** | 公债、政府预算、税收、公共支出、财政补贴和政府投资 | 一般性政策工具、选择性政策工具、直接信用控制、间接信用指导 |
| **调节范围** | 经济领域、**非经济领域** | **基本上限于经济领域**（其他领域属次要地位） |
| **国民收入分配** | **直接参与**国民收入的分配，并对集中起来的国民收入在全社会范围内进行再分配 | 银行对货币资金的再分配，除收取利息外，**并不直接参加**国内生产总值的分配；信贷资金以有偿方式集中使用，主要在资金盈余部门和短缺部门之间余缺调剂 |
| **需求调节** | 从消费需求看，**财政在社会消费中起决定性作用**；财政通过**个人所得税制度直接影响**个人消费需求的形成。从投资需求看，**固定资产投资主要由财政承担** | 银行对个人消费需求的形成只有**间接影响**（居民储蓄存款可随时提取，银行信贷对形成个人消费需求的影响弱于财政）；**流动资金投资主要由银行承担** |
| **扩大和紧缩需求** | 财政赤字可扩张需求、财政盈余可紧缩需求，但财政本身不具有直接"创造"货币的能力，**扩张和紧缩效应一定要通过信贷机制的传导才能发生** | 银行自身可以直接通过信贷规模的扩张和收缩起到扩张或紧缩需求的作用；**银行信贷是扩张或紧缩需求的总闸门** |
| **政策时滞性** | 财政政策的**决策时滞**一般比货币政策要**长**；**执行时滞**一般比货币政策要**长**；但从**效果时滞**看，财政政策就可能**优于**货币政策 | 决策时滞、执行时滞一般较短 |

**逻辑链**：

```
财政：直接参与国民收入分配 → 社会消费需求的决定者
    固定资产投资的承担者 → 产业/国民经济结构的调整者
    但自身不能创造货币 → 须经信贷机制传导

银行：有偿再分配货币资金 → 个人消费需求只有间接影响
      流动资金投资的承担者 → 总量和产品结构的调整者
      唯一能"创造"需求、"创造"货币的主体 → 总闸门
```

**速记口诀**：**"财政直接强制管全域，货币间接自愿限经济；消费看财政、流动看银行、固投财政流动银行；信贷是总闸门；财政决策执行慢、效果快。"**

### 考点13 财政政策与货币政策的配合运用 ★★

配合运用是指**扩张性（松的）、紧缩性（紧的）和中性**三种类型的不同组合。所谓"松紧"，实际上是指财政与信贷在**资金供应**上的"松"与"紧"。

- "**松**"的财政政策：政府通过**降低税收**或**扩大政府支出规模**（或两者同时使用）来增加社会的有效需求；
- "**松**"的货币政策：中央银行通过**降低法定存款准备金率、降低利率**来扩大信贷规模，增加货币供给；
- "**紧**"的财政政策：政府通过**增加税收**或**削减政府支出**（或两者同时使用），限制消费与投资，抑制社会总需求；
- "**紧**"的货币政策：中央银行通过**调高法定存款准备金率、调高利率**等压缩信贷支出规模，减少货币供给。

**四种组合（核心表格，必背）**：

| 适用情形 | 财政政策 | 货币政策 | 效果与风险 |
|---|---|---|---|
| **总需求严重不足**、生产能力未得到充分利用 | **松** | **松**（双松） | 可刺激经济增长、扩大就业，但配合不好会带来通货膨胀的风险 |
| **严重通货膨胀**时期 | **紧** | **紧**（双紧） | 可有效抑制需求膨胀与通货膨胀，但控制力度过猛容易导致经济衰退、失业增加 |
| 总需求与总供给**大体平衡，消费偏旺而投资不足** | **紧** | **松** | 抑制消费、刺激投资 |
| 总需求与总供给**大体平衡，投资过旺、消费不足** | **松** | **紧** | 刺激消费、抑制投资 |

**我国财政政策与货币政策配合的实践（时政考点）**：

1. 长期以来，我国实行**积极的财政政策和稳健的货币政策**；
2. 我国从 **2011 年起**开始实行**积极的财政政策和稳健的货币政策**（真题考点）；
3. **2024 年中央经济工作会议**指出：必须实施**更为积极的财政政策和适度宽松的货币政策**，通过精准施策，形成政策的"组合拳"；
4. **2025 年中央经济工作会议**指出：要科学把握财政赤字规模与结构，**合理控制赤字率**，有效防范财政赤字可能带来的**排挤效应**——既要通过适度赤字支出支持重点领域和薄弱环节，又要**避免过度举债导致市场利率上升、私人投资被挤出**；优化赤字资金投向，重点支持科技创新、战略性新兴产业、新型基础设施建设以及民生保障等领域；加强财政政策与货币政策的协调配合，通过**结构性货币政策工具**引导金融机构加大对实体经济的支持。

**逻辑链**：

```
看总量：总需求严重不足 → 双松；严重通胀 → 双紧
看结构（总量大体平衡时）：
   消费偏旺 + 投资不足 → 紧财政 + 松货币
   投资过旺 + 消费不足 → 松财政 + 紧货币
```

**速记口诀**：**"需求不足松一松，需求太多紧一紧；总量平衡看结构，消旺投紧双搭配，投旺消紧反着来。"**

## 四、公式与计算

> **重要说明**：本章多个来源均明确"本章主要是记忆型的考点，**不涉及计算**"。但财政赤字的两种计算口径涉及明确公式，是选择题的高频命题点（如"以……为口径计算的是哪种赤字"）。以下围绕素材中明确的公式配数字演算例题；**素材未涉及财政乘数（政府购买乘数、税收乘数、转移支付乘数、平衡预算乘数）及财政政策对总需求影响的测算内容，本部分不予展开（素材未明确，请勿按其他教材内容自行补充）**。

### 4.1 财政结余/赤字的基本计算

**基本公式（素材明确）**：

```
财政收支对比结果：
  经常收入 − 经常支出 ＞ 0  → 财政结余
  经常收入 − 经常支出 ＜ 0  → 财政赤字（软赤字口径）
  硬赤字 =（经常收入＋债务收入）−（经常支出＋债务支出）
```

**例题 1（硬赤字口径演算）**：某年度经常收入 8000 亿元，债务收入 2000 亿元，经常支出 8500 亿元，债务支出 1500 亿元。

```
硬赤字 =（8000＋2000）−（8500＋1500）
       = 10000 − 10000 = 0（亿元）
→ 含债务收支后收支相抵，无硬赤字。
```

**例题 2（软赤字口径演算）**：接上例数据。

```
软赤字 = 经常收入 − 经常支出 = 8000 − 8500 = −500（亿元）
→ 存在 500 亿元软赤字，应通过发行公债（赤字债务化）弥补。
```

**结论**：同一组数据，硬赤字为 0 而软赤字为 500 亿元，说明**两种口径的差异来自是否将债务收支计入**。

### 4.2 预算收支差额与总需求影响判断

**判断规则（素材明确）**：

```
预算收＞支 → 结余 → 对总需求净影响：收缩性 → 紧缩性财政政策
预算支＞收 → 赤字 → 对总需求净影响：扩张性 → 扩张性财政政策
预算收＝支 → 平衡 → 对总需求净影响：中性   → 中性财政政策
```

**例题 3**：某年预算收入 6000 亿元，预算支出 6800 亿元。

```
预算收支差额 = 6000 − 6800 = −800（亿元）→ 预算赤字 800 亿元
→ 对总需求的净影响是扩张性的，属于扩张性（积极）财政政策。
```

**例题 4（政策组合定性判断）**：某时期总需求严重不足、生产能力未得到充分利用。

```
判断：总量不足 → 双松
财政政策：松（减税、扩大政府支出规模）
货币政策：松（降低法定存款准备金率、降低利率，扩大信贷规模）
→ 组合："双松"政策。注意配合不好会带来通货膨胀的风险。
```

**例题 5（结构搭配定性判断）**：总需求与总供给大体平衡，但消费偏旺而投资不足。

```
判断：总量平衡看结构 → 抑消费、扩投资
财政政策：紧（增税、削减支出，抑制消费）
货币政策：松（降低准备金率与利率，刺激投资）
→ 组合：紧的财政政策＋松的货币政策。
```

## 五、高频考点速记卡

1. **Q：财政平衡的含义？**
   A：财政收支之间的对比关系。收＞支为结余，收＜支为赤字，收＝支为数量上的绝对平衡；略有结余或略有赤字可视为财政基本平衡。

2. **Q：为什么说不平衡是财政收支的基本形态？**
   A：支出需要的无限性与收入可能的有限性存在矛盾，加上决策失误、管理水平、收支时间错配、意外情况五大原因，收支矛盾的客观性决定不平衡是基本形态。

3. **Q：硬赤字与软赤字的公式？**
   A：硬赤字＝（经常收入＋债务收入）－（经常支出＋债务支出）；软赤字＝经常收入－经常支出。口诀"有债务硬赤字，无债务软赤字"。

4. **Q：硬赤字如何弥补？有何危害？**
   A：只能通过向中央银行借款或透支弥补；可能产生没有物资保证的货币购买力，引发通货膨胀和物价上涨。

5. **Q：软赤字如何弥补？为何被普遍采用？**
   A：通过发行公债弥补，称为"赤字债务化"；只是购买力转移，不会造成供求失衡和通胀，世界上多数国家采用。

6. **Q：财政赤字按成因分哪四类？**
   A：结构性赤字（经济结构调整）、周期性赤字（经济衰退）、临时性赤字（特殊事件/紧急情况）、政策性赤字（政府政策调整）。

7. **Q：弥补财政赤字的四种方式？**
   A：增收减支、动用结余、向中央银行透支或借款、发行公债。

8. **Q：哪种弥补方式最理想？**
   A：发行公债，称为债务融资或赤字债务化，是世界各国普遍做法。

9. **Q：动用结余弥补赤字对货币供给的影响？**
   A：结余未被信贷部门使用不增加货币供给；已被使用则会增加。

10. **Q：发行公债时，认购者不同对货币供给的影响？**
    A：家庭认购一般不增加；企业认购一般也不增加（特殊情形下增加）；商业银行认购看能否实现信贷收支平衡；中央银行认购会增加货币供应量。

11. **Q：什么是财政赤字的排挤效应？**
    A：由于财政赤字的弥补导致私人经济部门投资以及个人消费减少的现象。直接排挤：提高公债利率或降低发行价格吸引认购；间接排挤：发债增加货币需求→利率上升→投资消费减少。

12. **Q：什么是通货膨胀税？**
    A：长时间财政赤字导致货币过量发行，政府收入中通过价格再分配机制获得的部分，即政府收入＝国民生产总值正常增量的分配所得＋价格再分配所得（通货膨胀税）。

13. **Q：财政政策的主体和特点？**
    A：主体只能是各级政府，主要是中央政府；特点是直接性和强制性。

14. **Q：财政政策的五大目标？哪个是首要目标？**
    A：经济适度增长、物价基本稳定、收入分配公平、充分就业、国际收支平衡；首要目标是充分就业。

15. **Q：财政政策的四大功能？**
    A：导向、协调、控制、稳定。加速折旧税收政策属直接导向，对某些行业低税属间接导向；稳定功能的特征是反周期性和补偿性。

16. **Q：财政政策工具有哪些？居于核心地位的是？**
    A：政府预算、税收、公债、政府投资、公共支出、财政补贴；核心地位是政府预算。

17. **Q：税收在资源配置中的三个作用？**
    A：调节资源在积累和消费之间的分配（征税降低积累率、提高消费率）、在产业之间的配置、在政府部门和非政府部门之间的配置（靠适度宏观税率）。

18. **Q：公债的三个调节作用？**
    A：调节国民收入的使用结构、调节产业结构、调节资金供求和货币流通。

19. **Q：财政政策最重要的传导媒介体？**
    A：收入分配、货币供应与价格。

20. **Q：财政政策三种划分标准各得哪些类型？**
    A：按作用和影响范围分宏观/中观/微观；按对经济周期的调节作用分自动稳定/相机抉择；按总量功能分扩张性/紧缩性/中性。

21. **Q：自动稳定器指什么？**
    A：累进税制度和转移支付制度，能随经济波动自动发挥稳定作用，无需政府干预。

22. **Q：扩张性与紧缩性财政政策的手段及别称？**
    A：扩张性＝减税＋增加财政支出，等同于赤字财政政策；紧缩性＝增税＋减少财政支出，等同于盈余财政政策。

23. **Q：货币政策一般性政策工具？哪个最灵活、传导最短？**
    A：法定存款准备金率、再贴现率、公开市场业务；公开市场业务传导过程短、央行可直接控制货币供应量，是最经常使用、最为灵活有效的手段。

24. **Q：选择性货币政策工具包括哪些？**
    A：消费者信用控制、不动产信用控制、证券市场信用控制、优惠利率、预缴进口保证金。

25. **Q：财政政策与货币政策配合的四种组合？**
    A：双松（总需求严重不足）、双紧（严重通货膨胀）、紧财政＋松货币（消费偏旺投资不足）、松财政＋紧货币（投资过旺消费不足）。

26. **Q：财政政策与货币政策在时滞上有何差异？**
    A：财政政策的决策时滞、执行时滞一般比货币政策长，但效果时滞可能优于货币政策。

## 六、典型真题（含解析）

**【2021年真题·单选】下列关于硬赤字的说法，错误的是（　）。**
A. 硬赤字通过财政向中央银行透支进行弥补
B. 在银行信贷资金紧张的情况下，硬赤字会带来通货膨胀
C. 硬赤字是指用债务收入弥补收支差额以后仍然存在的赤字
D. 硬赤字用债务收入进行弥补

**答案：D**
**解析**：硬赤字是**用债务收入弥补收支差额以后仍然存在**的赤字，只能通过向中央银行借款或透支弥补（A、C 正确），在银行信贷资金紧张时会带来通货膨胀（B 正确）。用债务收入（发行公债）弥补的是**软赤字**，即"赤字债务化"，故 D 错误。

**【2020年真题·单选】以（经常收入＋债务收入）－（经常支出＋债务支出）为口径计算的是（　）。**
（注：不同来源对本题年份标注不一致，分别标为 2020 年、2024 年真题，题目与答案相同）
A. 软赤字　B. 硬赤字　C. 宽赤字　D. 紧赤字

**答案：B**
**解析**：硬赤字＝（经常收入＋债务收入）－（经常支出＋债务支出）；软赤字＝经常收入－经常支出。素材中无"宽赤字""紧赤字"概念。

**【2022年真题·多选】需要纳入软赤字计算口径的是（　）。**
A. 经常收入　B. 资本性支出　C. 经常支出　D. 债务收入　E. 债务支出

**答案：AC**
**解析**：软赤字＝经常收入－经常支出，口径中只包含经常收入与经常支出；债务收入、债务支出计入硬赤字口径，资本性支出不属于软赤字口径。

**【2023年真题·单选】在财政赤字管理中，用债务收入弥补收支差额后，仍然存在的赤字通常被称为（　）。**
A. 实赤字　B. 虚赤字　C. 硬赤字　D. 软赤字

**答案：C**
**解析**：硬赤字的定义即"用债务收入弥补收支差额以后仍然存在的赤字"；未经债务收入弥补的赤字是软赤字。

**【2022年真题·多选】下列关于发行公债引发的排挤效应的说法中，正确的有（　）。**
A. 政府通过提高公债利率来吸引企业认购公债进而减少投资是一种直接的排挤效应
B. 政府通过提高公债利率来吸引个人认购公债进而减少消费是一种间接的排挤效应
C. 政府发债，增加了货币需求，在货币供给一定的条件下，导致利率上升，从而减少企业的投资，是一种间接的排挤效应
D. 政府发债，增加了货币需求，在货币供给一定的条件下，导致利率上升，从而减少个人的消费，是一种直接的排挤效应
E. 政府通过行政摊派将公债分配给企业和个人认购，从而减少企业的投资和个人的消费是一种间接的排挤效应

**答案：AC**
**解析**：直接排挤效应是政府有意识地通过**提高公债利率或降低发行价格**吸引认购，进而减少投资和消费（A 正确，B 错在"间接"）；间接排挤效应是发债增加货币需求、在货币供给一定时**导致利率上升**，从而减少企业投资和个人消费（C 正确，D 错在"直接"）；行政摊派是通过**行政手段强制**实现的排挤，不属于间接排挤（E 错误）。

**【2020年真题·单选】（　）指由于财政赤字的弥补而导致私人经济部门投资以及个人消费减少的现象。**
A. 木桶效应　B. 马太效应　C. 破窗效应　D. 排挤效应

**答案：D**
**解析**：财政赤字的排挤效应是指由于财政赤字的弥补而致使私人经济部门投资及个人消费减少的现象。

**【2022年真题·多选】弥补财政赤字的方式通常有（　）。**
A. 减少货币发行　B. 增税　C. 向中央银行借款　D. 发行国债　E. 向国外借款

**答案：BCD**
**解析**：素材明确的弥补方式为增收减支、动用结余、向中央银行透支或借款、发行公债。增税属于"增收减支"的具体手段，向中央银行借款、发行国债均在列；减少货币发行、向国外借款不属于素材所列方式。

**【2023年真题·单选】国内生产总值因物价上升形成名义增长而无实际增长，政府通过财政赤字在国民经济分配中获得更大的份额，政府收入增长的实现机制是（　）。**

**答案：D**
**解析**：政府收入分为国民生产总值正常增量的分配所得和价格再分配所得两部分，后者即西方经济学家所称的通货膨胀税。赤字债务化指通过发行公债弥补软赤字。

**【2020年真题·单选】当社会总需求大于社会总供给时，下列做法正确的是（　）。**

A. 增加税收　B. 降低利率　C. 减少政府预算　D. 减少信贷支出

**答案：B**
**解析**："松"的货币政策指中央银行通过降低法定存款准备金率、降低利率扩大信贷规模、增加货币供给；A、C 属"紧"的财政政策手段，D 属"紧"的货币政策。

**【2023年真题·单选】下列关于财政政策与货币政策对需求调节作用的说法，正确的是（　）。**
A. 银行信贷直接影响个人消费需求的形成
B. 财政在社会消费中起决定性作用
C. 固定资产的投资主要由银行承担
D. 流动资金投资主要由财政承担

**答案：B**
**解析**：从消费需求形成看，财政在社会消费中起决定性作用；银行对个人消费需求的形成只有间接影响（A 错）；固定资产投资主要由财政承担、流动资金投资主要由银行承担（C、D 说反了）。

**【2023年真题·单选】关于财政政策与货币政策配合运用的说法，错误的是（　）。**
A. 当总需求严重不足、生产能力未得到充分利用的情况下，应采用"双松"政策
B. 当出现严重通货膨胀时，应采用力度较大的"双紧"政策，控制力度越猛效果越好
C. 当总供求大体平衡，而投资过旺、消费不足时，应采用松的财政政策和紧的货币政策
D. 当总供求大体平衡，而消费偏旺、投资不足时，应采用紧的财政政策和松的货币政策

**答案：B**
**解析**：严重通货膨胀时实行"双紧"可以抑制需求膨胀，但**控制力度过猛容易导致经济衰退、失业增加**，"越猛越好"说法错误。A、C、D 均为正确组合。

**【2022年真题·单选】为了做好宏观调控工作，我国从2011年起开始实行（　）。**
A. 积极的财政政策和稳健的货币政策
B. 稳健的财政政策和稳健的货币政策
C. 积极的财政政策和适度宽松的货币政策
D. 适度从紧的财政政策和适度从紧的货币政策

**答案：A**
**解析**：我国从 2011 年起开始实行积极的财政政策和稳健的货币政策；2024 年中央经济工作会议后转向"更为积极的财政政策和适度宽松的货币政策"。

**【2020年真题·多选】为控制通货膨胀可采取的财政政策有（　）。**
A. 减少公共支出　B. 减少税收　C. 增加税收　D. 增加公共投资　E. 提高法定存款准备金率

**答案：AC**
**解析**：控制通货膨胀应采取紧缩性财政政策，即增加税收、减少财政支出（A、C 正确）；B、D 属扩张性手段；E 是货币政策工具，且属紧缩性货币政策手段，不属于财政政策。

**【2024年真题·单选】适用于需求严重不足、生产能力未得到充分利用的情况时采取的财政政策与货币政策是（　）。**
A. "双松"政策　B. "双紧"政策
C. 紧的财政政策与松的货币政策　D. 松的财政政策与紧的货币政策

**答案：A**
**解析**：总需求严重不足、生产能力未充分利用时适用"双松"组合，可刺激经济增长、扩大就业，但配合不好会带来通货膨胀风险。

**【2017年真题·单选】关于公债调节作用的说法，错误的是（　）。**
A. 公债可以调节国民收入的使用结构
B. 公债可以调节产业结构
C. 公债可以调节资金供求和货币流通
D. 公债可以调节居民个人收入

**答案：D**
**解析**：公债的调节作用表现在三个方面：调节国民收入的使用结构、调节产业结构、调节资金供求和货币流通；"调节居民个人收入"不属于公债的调节作用。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 认为财政平衡就是收支绝对相等 | 现实中绝对平衡几乎不存在，**略有结余或略有赤字**即视为基本平衡 |
| 2 | 把"平衡"当成财政收支的基本形态 | **不平衡**才是基本形态（五大原因导致） |
| 3 | 混淆硬赤字与软赤字的债务收支处理 | "**有债务硬赤字，无债务软赤字**"：硬赤字含债务收支，软赤字只含经常收支 |
| 4 | 认为硬赤字靠发债弥补 | 硬赤字只能**向中央银行借款或透支**；发债弥补的是软赤字（赤字债务化） |
| 5 | 漏选软赤字口径的项目 | 软赤字＝**经常收入－经常支出**，只选这两项；资本性支出、债务收入、债务支出都不选 |
| 6 | 把四种赤字分类与两种计算口径混记 | 口径分**硬/软**（看算法），成因分**结构/周期/临时/政策**（看原因），两套体系不要交叉 |
| 7 | 认为"周期性赤字"是政策主动造成的 | 周期性赤字源于**经济衰退**（被动）；政策性赤字才是**政府政策调整**（主动，如减税）造成的 |
| 8 | 认为动用结余一定不影响货币供给 | 看结余**是否已被信贷部门使用**：未用不增加，已用则增加 |
| 9 | 认为发行公债都不增加货币供给 | 认购者为**中央银行**必然增加；商业银行认购后信贷收支不能平衡也会增加 |
| 10 | 把"提高公债利率吸引认购"归为间接排挤 | 属**直接排挤效应**；间接排挤是发债→货币需求增加→**利率上升**→投资消费减少 |
| 11 | 认为行政摊派属于间接排挤效应 | 行政摊派是通过**行政手段强制**实现的排挤，与自愿认购的两条途径并列 |
| 12 | 认为排挤效应一定有害 | 总需求不足时不利；总需求过旺或供求大体均衡时**反而有利**，须具体分析 |
| 13 | 把财政政策主体记成"财政部"或"央行" | 主体是**各级政府（主要是中央政府）**；央行是货币政策主体 |
| 14 | 把宏观调控首要目标记成经济增长 | 首要目标是**充分就业**（不意味着消除失业） |
| 15 | 认为国际收支平衡包括全部四个项目 | 平衡指**经常项目、资本项目、遗漏与误差**三个项目的收支对比（不含官方平衡项目） |
| 16 | 混淆直接导向与间接导向 | 加速折旧税收政策→**直接导向**；对某些行业低税→**间接导向**（影响其他企业和消费者） |
| 17 | 认为财政政策功能有"竞争功能" | 四大功能只有**导向、协调、控制、稳定** |
| 18 | 漏记"政府预算的核心地位" | 六大工具中**政府预算居核心地位**，具综合性、计划性、法律性 |
| 19 | 把税收的"积累与消费"记成"生产与消费" | 征税**降低积累率、提高消费率**，是积累与消费之间的分配 |
| 20 | 混淆扩张性与紧缩性财政政策的别称 | 扩张性＝**赤字**财政政策（减税增支）；紧缩性＝**盈余**财政政策（增税减支） |
| 21 | 认为自动稳定器包括相机抉择措施 | 自动稳定器只有**累进税制度和转移支付制度**，无需政府干预 |
| 22 | 把一般性与选择性货币政策工具混选 | 一般性＝存款准备金率、再贴现率、公开市场业务（传统、量）；选择性＝消费者/不动产/证券信用控制、优惠利率、预缴进口保证金（特定领域） |
| 23 | 认为公开市场业务需通过商业银行传导 | 公开市场业务**传导过程短、央行可直接控制**货币供应量，是最灵活常用的手段 |
| 24 | 混淆固定资产投资与流动资金投资的承担主体 | **固定资产→财政；流动资金→银行**；社会消费→财政决定；个人消费→银行仅间接影响 |
| 25 | 认为财政能直接创造货币、扩张需求 | 财政扩张/紧缩效应**必须通过信贷机制传导**；**银行信贷是总闸门** |
| 26 | 认为财政政策各环节时滞都短于货币政策 | 财政**决策时滞、执行时滞长于**货币政策，但**效果时滞可能优于**货币政策 |
| 27 | 双松/双紧适用情形记反 | 需求严重不足→**双松**；严重通胀→**双紧**；结构失衡（总量平衡）→**一松一紧** |
| 28 | 认为"双紧"力度越猛越好 | 控制力度过猛易导致**经济衰退、失业增加** |
