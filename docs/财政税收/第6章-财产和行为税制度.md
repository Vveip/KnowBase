# 第6章 财产和行为税制度

> **本章考情**：**容易掌握的超级重要章节**，小税种多、知识点零碎，大部分小税种容易计算，个别（如土地增值税）计算有难度，整体以记忆型考点为主。考试分值 **20～22 分**（不同来源口径有差异：一种统计 17 分＝单选 5 分＋多选 2 分＋案例分析 10 分；另一种标注 15 分，**请以本人教材为准**）。题型为**单选题、多选题、案例分析题**。
> **高频考点**：房产税；契税；土地增值税；车辆购置税；车船税；资源税；烟叶税；环境保护税；印花税；城建税及教育费附加。
> **学习建议**：小税种可对比学习（房地产相关五个税种、车船相关三个税种），听懂课的同时适当做题。

## 二、知识点精讲

### 考点1 房产税 ★★★

**核心概念**：房产税是以**房屋**为征税对象，以房屋的**计税余值或租金收入**为计税依据，向**房屋产权所有人**征收的一种**财产税**（**保有环节**：对持有房产的行为征税）。

**（一）纳税人**——在征税范围内拥有房屋产权的单位和个人，具体包括产权所有人、承典人、房产代管人或者使用人。**【巧思妙记】谁受益，谁交税**。

| 特殊情形 | 纳税人 |
|---|---|
| 产权属全民所有的 | 经营管理单位 |
| 产权属集体和个人所有的 | 集体单位和个人 |
| 产权出典的 | 承典人 |
| 产权所有人、承典人不在房屋所在地的 | 房产代管人或使用人 |
| 产权未确定及租典纠纷未解决的 | 房产代管人或使用人 |
| 无租使用其他单位房产的 | 使用人按房产**余值**代为缴纳 |
| 融资租赁的房产 | 承租人（自合同约定开始日**次月**起按余值缴纳；合同未约定开始日的，自合同签订次月起） |

> 纳税单位与免税单位**共同使用**的房屋，按各自使用的部分划分，分别征收或免征房产税。

**（二）征税范围**——城市、县城、建制镇和工矿区，**不包括农村**。

| 属于房产（征税） | 不属于房产（不征） |
|---|---|
| 有屋面和围护结构，能遮风避雨，可供生产、学习、工作、娱乐、居住或储藏物资的场所 | 独立于房屋的建筑物：围墙、烟囱、水塔、变电塔、油池油柜、酒窖菜窖、酒精池、糖蜜池、**室外游泳池**、玻璃暖房、砖瓦石灰窑、各种油气罐 |
| **室内游泳池**属于房产 | — |
| 与房屋不可分割的各种附属设备、配套设施（暖气、卫生、通风、照明、煤气设备；各种管线；电梯、升降机、过道、晒台；给排水、采暖、消防、中央空调、电气及智能化楼宇设备） | 易损坏、需经常更换的零配件，更新后不再计入房产原值 |
| 具备房屋功能的地下建筑（含与地上相连的地下建筑、完全建在地面以下的建筑、地下人防设施） | — |

> 房地产开发企业开发的商品房**在出售前不征收**房产税；但出售前已**使用或出租、出借**的，应按规定征收。

**（三）税率（比例税率）**

| 适用情形 | 计税依据 | 税率 |
|---|---|---|
| 自用的房子 | 房产余值 | **1.2%** |
| 单位出租房产用于生产经营 | 租金收入 | **12%** |
| 个人出租住房（不区分用途）；单位向个人出租用于居住的住房 | 租金收入 | **4%** |

**（四）计税依据与应纳税额**

```
从价计征（自用）：
  房产余值 = 房产原值 ×（1 － 扣除比例）
  全年应纳税额 = 应税房产原值 ×（1－扣除比例）× 1.2%

从租计征（出租）：
  全年应纳税额 = 年租金收入 × 12%（或 4%）
```

- 扣除比例为 **10%～30%**，由省级政府确定；没有房产原值依据的，由税务机关参考同类房产核定。
- **房产原值必须包含地价**（取得土地使用权支付的价款、开发土地发生的成本费用等）；**宗地容积率低于 0.5 的，按房产建筑面积的 2 倍计算土地面积**并据此确定计入原值的地价（宗地容积率＝建筑物总面积÷地面面积）。
- **免租期规则**：约定免收租金期限的，免收租金期间由**产权所有人按房产余值（原值）**缴纳；正常租赁期对承租人从租计征。
- 一年内部分时间自用、部分时间出租的，**分别计算**。

**（五）税收优惠**（口诀：**非营利、公益、民生保障类自用房产免，经营出租类正常征**）

- 基本免征：国家机关、人民团体、军队**自用**；财政拨付事业经费单位**自用**；宗教寺庙、公园、名胜古迹**自用**（附设营业单位及出租房产**不免**）；个人所有**非营业用房**（不分面积）；经财政部批准免税的其他房产。
- 其他免征/优惠：企业办的各类学校、医院、托儿所、幼儿园自用；毁损不堪居住房屋和危房停止使用后；基建工地临时性房屋施工期间；**大修连续停用半年以上**期间；个人按市场价格出租居民住房减按 4%；政府规定价格出租的公有住房和廉租住房暂免；**公租房免征至 2025 年 12 月 31 日**；**高校学生公寓免征至 2027 年 12 月 31 日**；社区养老托育家政机构；福利性非营利性老年服务机构；非营利性医疗机构等；体育场馆（机关军队等自用免、企业大型体育场馆减半，高尔夫/马术/汽车/卡丁车/摩托车场训练场不得享受）；农产品批发市场农贸市场；军队空余房产租赁收入；饮水工程；商品储备公司；科技企业孵化器等；文化单位转制（至 2027 年 12 月 31 日）。
- 纳税确有困难的，由省级政府定期减征或免征。

**（六）征收管理**

| 项目 | 规定 |
|---|---|
| 纳税义务发生时间 | 自建房屋：建成之**次月**；委托施工：办理验收手续之**次月**（验收前已使用/出租/出借的应按规定征收）；原有房产用于生产经营：生产经营**之月** |
| 纳税期限 | 按年计算、分期缴纳，具体期限由省级政府确定 |
| 纳税地点 | 房产所在地税务机关；房产不在一地的，**分别**向房产所在地缴纳 |

**速记口诀**：**"谁受益谁交税；农村不征、室内泳池算房；从价 1.2 先减 10～30，从租 12 个人 4；免租期按余值、大修半年免"**。

### 考点2 城镇土地使用税 ★★

**核心概念**：以开征范围的土地为征税对象，以**实际占用的土地面积**为计税标准，按规定税额对拥有土地使用权的单位和个人征收的一种税。

**（一）纳税人**——在城市、县城、建制镇、工矿区范围内使用土地的单位和个人（**农村不征**）。

| 情形 | 纳税人 |
|---|---|
| 一般情形 | 拥有土地使用权的单位或个人 |
| 土地使用权未确定或权属纠纷未解决 | 实际使用人 |
| 土地使用权共有 | 共有各方**分别**纳税 |
| 承租集体所有建设用地 | 直接从集体经济组织承租土地的单位和个人 |

**（二）征税范围**——城市、县城、建制镇、工矿区。公园、名胜古迹内索道公司的经营用地**应缴纳**。**单独建造的地下建筑用地暂按应征税款的 50% 征收**（有地下土地使用权证的按证上面积；无证的按地下建筑垂直投影面积）；地上建筑物之下统一配建的地下建筑不重复纳税。

**（三）税率——分级幅度定额税率（每平方米年税额）**

| 级别 | 每平方米年税额 |
|---|---|
| 大城市 | 1.5～30 元 |
| 中等城市 | 1.2～24 元 |
| 小城市 | 0.9～18 元 |
| 县城、建制镇、工矿区 | 0.6～12 元 |

> 经济落后地区可适当降低，但**降低额不得超过规定的最低税额的 30%**；经济发达地区可适当提高，须报**财政部**批准。

**（四）计税依据与应纳税额**

```
应纳税额 = 实际占用的应税土地面积（平方米）× 适用税额
```

计税面积以土地使用证书确认面积为准；未核发证书的据实申报，待核发后再作调整。

**（五）税收优惠**

- 基本免征：国家机关、人民团体、军队自用；财政拨款经费单位自用；宗教寺庙、公园、名胜古迹自用；**市政街道、广场、绿化地带等公共用地**；**直接用于农、林、牧、渔业的生产用地**；经批准**开山填海整治的土地和改造的废弃土地，从使用月份起免缴 5～10 年**；财政部另行规定的能源、交通、水利用地等。
- 特殊免征：非营利性医疗机构、疾病控制机构和妇幼保健机构等自用；社区养老托育家政服务机构；**免税单位无偿使用纳税单位的土地**（纳税单位无偿使用免税单位土地的，纳税单位征税）。
- 其他：缴纳耕地占用税的，**从批准征收之日起满 1 年**才征城镇土地使用税；**厂区（含生产、办公及生活区）以内绿化用地照章征收**，厂区以外的公共绿化用地和向社会开放的公园用地暂免；个人出租住房不区分用途免征；机场飞行区用地等；体育场馆；农产品批发市场农贸市场；供热企业；饮水工程；公租房；商品储备；公交站场；保障性住房。

**（六）征收管理**——新征用的**耕地**自批准征用之日起**满 1 年**时开始缴纳；新征用的**非耕地**自批准征用**次月**起缴纳。按年计算、分期缴纳。土地所在地税务机关。

**速记口诀**：**"农村不征、地下减半、落后降不过三成、厂内绿化要征、耕地占用满一年"**。

### 考点3 耕地占用税 ★

**核心概念**：国家对占用耕地建房或者从事其他非农业建设的单位和个人，依据**实际占用的耕地面积**，按照规定税额**一次性征收**的一种税（对特定土地资源占用课税）。

**（一）纳税人和征税范围**——占用耕地建房或从事非农业建设的单位和个人。耕地为广义耕地，包括菜地、园地（花圃、苗圃、茶园、果园、桑园和其他种植经济林木的土地）、鱼塘、林地、草地、农田水利用地、养殖水面以及渔业水域滩涂。**占用耕地建设农田水利设施的不征**。

**（二）税率——地区差别定额税率**

| 人均耕地面积 | 每平方米税额 |
|---|---|
| 不超过 1 亩 | 10～50 元 |
| 超过 1 亩但不超过 2 亩 | 8～40 元 |
| 超过 2 亩但不超过 3 亩 | 6～30 元 |
| 超过 3 亩 | 5～25 元 |

> 人均耕地少于 0.5 亩的地区，适用税额可适当提高，但**提高部分最高不得超过当地适用税额的 50%**；占用**基本农田的按适用税额加按 150% 征收**。

**（三）计税依据与应纳税额**

```
应纳税额 = 实际占用的耕地面积（平方米）× 适用定额税率
```

**（四）税收优惠**

| 类别 | 情形 |
|---|---|
| 不缴/免征 | 占用耕地建设农田水利设施；军事设施、学校、幼儿园、社会福利机构、医疗机构占用耕地；农村烈士遗属、因公牺牲军人遗属、残疾军人以及符合农村最低生活保障条件的农村居民，在规定用地标准以内新建自用住宅 |
| 减征 | 铁路线路、公路线路、飞机场跑道、停机坪、港口、航道、水利工程占用耕地，**减按每平方米 2 元**；农村居民在规定用地标准以内占用耕地新建自用住宅**减半**；农村居民经批准搬迁，新建自用住宅占用耕地不超过原宅基地面积的部分**免征** |
| 其他 | 小规模纳税人、小型微利企业和个体工商户可在 **50% 税额幅度内减征**；临时占用耕地期满之日起 **1 年内**依法复垦恢复种植条件的，**全额退还** |

**（五）征收管理**——纳税义务发生时间：**收到自然资源主管部门办理占用耕地手续的书面通知的当日**；纳税期限：自纳税义务发生之日起 **30 日内**申报缴纳（最特殊的期限，其他税种默认 15 日）；纳税地点：耕地所在地。

**速记口诀**：**"一次性征收、地区差别定额、基本农田加 150、铁公鸡（铁路公路机场港口）每米 2 元、30 天申报"**。

### 考点4 契税 ★★★★

**核心概念**：以**所有权发生转移的不动产**为征税对象，向**产权承受人**征收的一种财产税。

**（一）纳税人**——在境内转移土地、房屋权属，**承受**的单位和个人。

**（二）征税范围**（【巧思妙记】1. 权属是否发生转移；2. 是否为产权承受人）

| 类别 | 具体情形 |
|---|---|
| 国有土地使用权出让 | 土地使用者向国家交付出让费用，国家将国有土地使用权在一定年限内让与土地使用者的行为；以国家作价出资（入股）方式转移国有土地使用权的，**视同土地使用权转让** |
| 土地使用权转让 | 出售、赠与、交换；**不包括土地承包经营权和土地经营权的转移** |
| 房屋买卖 | 以房屋抵债或实物交换房屋；以房产作为投资或作股权转让（**自有房屋作股权投入本人独资企业免征**）；买房拆料或翻建新房 |
| 房屋赠与 | 受赠方缴纳；**以获奖方式取得房屋产权照章缴纳** |
| 房屋交换 | 双方交换价值相等**免纳**；价值不相等的，按超出部分由**支付差价方**缴纳 |
| 权属转移其他情形 | 共有不动产份额变化、共有人增减、法院/仲裁生效法律文书或监察文书等发生权属转移 |

> 承受与房屋相关的附属设施（**停车位、汽车库、自行车库、顶层阁楼、储藏室**）所有权或土地使用权的，征收契税；不涉及权属转移变动的，不征。分期付款购买附属设施的，按合同规定的**总价款**计征；附属设施权属单独计价的按当地适用税率，与房屋统一计价的适用与房屋相同税率。

**（三）税率——幅度比例税率 3%～5%**。具体适用税率由省级政府在幅度内提出，报**同级人大常委会决定**，并报**全国人大常委会和国务院备案**。

**（四）计税依据与应纳税额**

```
应纳税额 = 计税依据 × 税率（计税依据不包括增值税）
```

| 适用情形 | 纳税人 | 计税依据 |
|---|---|---|
| 土地使用权出售、房屋买卖 | 买方 | **成交价格** |
| 土地使用权赠与、房屋赠与 | 受赠方 | 征收机关核定的市场价格 |
| 土地使用权交换、房屋交换 | 支付差价的一方 | 所交换标的的价格差额 |

> 划拨改出让：以补缴的土地出让价款为计税依据；承受已装修房屋的，应将装修费用计入总价款。

**（五）税收优惠**

- 免征：国家机关、事业单位、社会团体、军事单位承受土地房屋用于办公、教学、医疗、科研、军事设施；非营利性学校、医疗机构、社会福利机构用于办公、教学、医疗、科研、养老、救助；承受荒山、荒丘、荒滩土地使用权用于农林牧渔业生产；**法定继承人继承**；**婚姻存续期间夫妻之间变更**；**夫妻因离婚分割共同财产**；外国驻华使馆、领事馆和国际组织驻华代表机构；公租房经营管理单位购买住房作为公租房。
- 住房优惠（**北上广深暂不实施**）：

| 情形 | 面积 | 税率 |
|---|---|---|
| 个人购买家庭唯一住房 | 140 平方米及以下 | 减按 **1%** |
| | 140 平方米以上 | 减按 **1.5%** |
| 个人购买家庭第二套改善性住房 | 140 平方米及以下 | 减按 **1%** |
| | 140 平方米以上 | 减按 **2%** |

> 自 2023 年 10 月 1 日起，个人购买保障性住房**减按 1%**。因不可抗力灭失住房重新承受的，省级政府可决定免征或减征。合并/分立后公司承受原合并各方土地房屋权属免征；债权人承受破产企业抵债土地房屋权属免征；企业改制原投资主体存续且持股超 **75%**、事业单位改制出资比例超 **50%** 的免征。

**（六）征收管理**——纳税义务发生时间：签订土地、房屋权属转移合同的**当日**；应在依法办理土地、房屋权属登记手续**前**申报缴纳；土地、房屋所在地主管税务机关。

**速记口诀**：**"承受方缴税、赠与看核定价、互换只看差价、夫妻继承全免、140 平是分水岭"**。

### 考点5 土地增值税 ★★

**核心概念**：对转让国有土地使用权、地上的建筑物及其附着物并取得收入的单位和个人征收（不论专营或兼营房地产业务）。

**（一）征税范围**（【巧思妙记】权属是否发生转移；是否为有偿转让）

- 只对**转让**国有土地使用权征税，**出让不征税**；既对转让国有土地使用权征税，也对转让地上建筑物及附着物产权征税；只对**有偿转让**征税，继承、赠与等无偿转让不征税（赠与他人：赠与直系亲属或承担直接赡养义务人；通过境内非营利社会团体、国家机关赠与教育、民政和社会福利公益事业的，不征）。
- **未转让产权不征**：房地产出租、代建房产、重新评估等。

| 事项 | 征税规则 |
|---|---|
| 房地产抵押 | 抵押期间、抵押期满偿还债务本息**不征**；抵押期满不能偿还债务以房地产抵债**征** |
| 房地产交换 | 单位之间换房**征**；个人之间互换自有居住用房经税务机关审核**免** |
| 合作建房 | 建成后按比例分房自用**暂免**；建成后转让**征** |
| 房地产投资联营 | 一方以土地作价入股投资或作为联营条件**暂免**（房地产开发企业以建造的商品房投资联营不能免）；再转让的**征** |
| 开发产品他用 | 用于职工福利、奖励、对外投资、分配给股东、抵偿债务、换取非货币性资产等，视同销售**征** |

**（二）计税依据**

```
增值额 = 收入额 － 扣除项目金额
增值率 = 增值额 ÷ 扣除项目金额 × 100%
应纳税额 = 增值额 × 适用税率 － 扣除项目金额 × 速算扣除系数
```

收入额为全部价款**不含增值税**。

**出售新房扣除项目**：

| 扣除项目 | 扣除标准 |
|---|---|
| ① 地价和相关税费 | 地价款＋契税 |
| ② 房地产开发成本 | 土地征用及拆迁补偿费（含耕地占用税、劳动力安置费）、前期工程费、建筑安装工程费、基础设施费、公共配套设施费、开发间接费用 |
| ③ 房地产开发费用（销、管、财） | 利息能分摊并能提供证明：利息＋（①＋②）×**5%**；不能分摊或不能提供证明：（①＋②）×**10%** |
| ④ 与转让房地产有关的税金 | 城建税、印花税、教育费附加（不含增值税） |
| ⑤ 加计扣除 | （①＋②）×**20%**（**非房地产开发企业没有此项**） |

**出售旧房扣除项目**：① 房屋及建筑物的评估价格＝**重置成本价 × 成新度折扣率**；不能取得评估价格但能提供购房发票的，按发票金额从购买年度起至转让年度止**每年加计 5%**；② 地价和相关税费（地价款＋契税）；③ 转让环节税金。"每年"按发票所载日期起至售房发票开具之日止，**每满 12 个月计一年；超过一年、未满 12 个月但超过 6 个月的可视同一年**。购房契税能提供完税凭证的作为税金扣除，但不作为加计 5% 的基数。既无评估价格又无购房发票的，核定征收。

**（三）税率——四级超率累进税率（务必背下）**

| 级数 | 增值额与扣除项目金额的比率 | 税率 | 速算扣除系数 |
|---|---|---|---|
| 1 | 不超过 50% 的部分 | 30% | 0 |
| 2 | 超过 50%～100% 的部分 | 40% | 5% |
| 3 | 超过 100%～200% 的部分 | 50% | 15% |
| 4 | 超过 200% 的部分 | 60% | 35% |

**（四）税收优惠**——因国家建设需要依法征用、收回的房地产免征；**居民个人销售住房暂免**；改制前后企业间房地产转移变更暂不征；建造**普通标准住宅增值额未超过扣除项目金额 20% 的免征，超过 20% 的全额计征**；转让旧房作为公租房房源且增值额未超过 20% 的免征；因城市实施规划、国家建设需要搬迁自行转让原房地产免征。

**（五）征收管理**——自转让房地产合同签订之日起 **7 日内**向房地产所在地主管税务机关申报；税务机关核定的纳税期限应在签订合同之后、办理权属转让手续之前。

**速记口诀**：**"出让不征转让征、有偿征无偿免、普宅 20% 是生死线、四级超率 30/40/50/60 配 0/5/15/35"**。

### 考点6 车辆购置税 ★★★

**核心概念**：对在我国境内**购置**车辆的单位和个人征收的一种税，**一次性征收**（一车一生只缴一次；购置已征车辆购置税的车辆不再征收）。

**（一）纳税人和征税范围**——境内购置**汽车、有轨电车、汽车挂车、排气量超过 150 毫升的摩托车**的单位和个人。购置＝以购买、进口、自产、受赠、获奖等方式取得并**自用**应税车辆。【巧思妙记】应税车辆：汽、摩、电、挂。

**（二）税率与计税依据**——统一比例税率 **10%**。

| 具体情形 | 计税价格 |
|---|---|
| 购买自用 | 实际支付给销售者的全部价款，不含增值税 |
| 进口自用 | 关税完税价格＋关税＋消费税＝（关税完税价格＋关税）÷（1－消费税税率） |
| 自产自用 | 生产的同类应税车辆销售价格，不含增值税 |
| 受赠、获奖或其他方式取得自用 | 相关凭证载明的价格，不含增值税 |

```
应纳税额 = 计税依据 × 10%
```

**（三）税收优惠**——免征：外国驻华使馆、领事馆和国际组织驻华机构及其有关人员自用；解放军和武警列入装备订货计划车辆；悬挂应急救援专用号牌的国家综合性消防救援车辆；设有固定装置的非运输专用作业车辆；城市公交企业购置的公共汽电车辆。新能源：**2024 年 1 月 1 日至 2025 年 12 月 31 日购置的新能源汽车免征（每辆新能源乘用车免税额不超过 3 万元）；2026 年 1 月 1 日至 2027 年 12 月 31 日减半征收（每辆新能源乘用车减税额不超过 1.5 万元）**。

**（四）征收管理**

| 项目 | 规定 |
|---|---|
| 纳税地点 | 车辆登记地；不需办理登记的为纳税人所在地 |
| 纳税义务发生时间 | 购置应税车辆当日 |
| 纳税期限 | 自纳税义务发生之日起 **60 日内**申报缴纳（应在办理车辆注册登记前缴纳） |
| 退税 | 车辆退回生产企业或经销商的，自办理纳税申报之日起按已缴税款**每满 1 年扣减 10%**；未满 1 年全额退税。应退税额＝已纳税额×（1－使用年限×10%） |
| 补税 | 免税减税车辆因转让、改变用途不再属于范围的，以初次申报计税价格为基准每满一年扣减 10% |

**速记口诀**：**"汽摩电挂一次性、10% 不变、进口要组价、60 天申报、退车每年扣一成"**。

### 考点7 车船税 ★★

**核心概念**：以车船为征税对象，向**拥有**车船的单位和个人征收的一种税（按年征收）。

**（一）纳税人**——车辆、船舶的**所有人或管理人**。

**（二）征税范围**——依法应当在车船管理部门登记的机动车辆和船舶；依法不需要登记、在单位内部场所行驶或作业的机动车辆和船舶。**境内单位租入外国籍船舶的不征收**；**境内单位将船舶出租到境外的应依法征收**。

**（三）税率与计税依据——定额税率（从量计税）**

| 税目 | 计税单位 | 备注 |
|---|---|---|
| 乘用车 | 每辆 | 核定载客人数 9 人（含）以下；**纯电动乘用车和燃料电池乘用车不属于征收范围** |
| 客车 | 每辆 | 核定载客人数 9 人以上，包括电车 |
| 摩托车 | 每辆 | — |
| 货车 | 整备质量每吨 | 包括半挂牵引车、三轮汽车和低速载货汽车等 |
| 挂车 | 整备质量每吨 | **按货车税额的 50% 计算** |
| 其他车辆 | 整备质量每吨 | 专用作业车、轮式专用机械车，**不包括拖拉机** |
| 船舶 | 净吨位每吨 | 拖船、非机动驳船分别按机动船舶税额的 **50%**；**拖船按发动机功率每 1 千瓦折合净吨位 0.67 吨** |
| 游艇 | 艇身长度每米 | 无法提供净吨位证明文件的，按每千瓦折合净吨位 0.05 吨 |

车辆具体适用税额由省级政府依照税目税额表幅度和国务院规定确定；**船舶由国务院确定**。

```
应纳税额 = 应税车辆数量（或整备质量/净吨位/艇身长度）× 单位税额
```

**（四）税收优惠**

- 免征：捕捞、养殖渔船；军队、武警专用车船；警用车船；悬挂应急救援专用号牌的国家综合性消防救援车辆和专用船舶；**新能源车船**；外国驻华使馆、领事馆及有关人员车船；境内单位租入外国籍船舶。
- **节能汽车减半征收**（注意不是免征）。

**（五）征收管理**——纳税义务发生时间：取得车船所有权或管理权的**当月**；纳税地点：车船登记地或扣缴义务人所在地（不需登记的为所有人或管理人所在地）；纳税期限：**按年申报，分月计算**，具体期限由省级政府规定。

**速记口诀**：**"拉人的车按辆、拉货的车按吨、挂车打五折、拖船 0.67、节能减半、新能源全免"**。

### 考点8 船舶吨税 ★

**核心概念**：对自中华人民共和国**境外港口进入境内港口**的船舶征收的一种税，由**海关**负责征收。

**（一）纳税人和征税范围**——自境外港口进入境内港口的船舶（应税船舶）的**负责人**。

**（二）税率**——分**优惠税率**（船籍国与中国签订含有相互给予船舶税费最惠国待遇条款的条约或协定）和**普通税率**。

| 船舶净吨位 | 普通税率（元/净吨） | | | 优惠税率（元/净吨） | | |
|---|---|---|---|---|---|---|
| | 1 年 | 90 日 | 30 日 | 1 年 | 90 日 | 30 日 |
| 不超过 2000 净吨 | 12.6 | 4.2 | 2.1 | 9 | 3 | 1.5 |
| 超过 2000 净吨，不超过 10000 净吨 | 24 | 8 | 4 | 17.4 | 5.8 | 2.9 |
| 超过 10000 净吨，不超过 50000 净吨 | 27.6 | 9.2 | 4.6 | 19.8 | 6.6 | 3.3 |
| 超过 50000 净吨 | 31.8 | 10.6 | 5.3 | 22.8 | 7.6 | 3.8 |

> 拖船和非机动驳船分别按相同净吨位船舶税率的 **50%** 计征；拖船每 1 千瓦折合净吨位 0.67 吨。

**（三）计税依据与应纳税额**

```
计税依据 = 船舶净吨位 × 船舶吨税执照期限
应纳税额 = 船舶净吨位 × 定额税率（元）
```

**（四）税收优惠**——免征：应纳税额在人民币 **50 元以下**的船舶；吨税执照期满后 **24 小时内**不上下客货的船舶；**非机动船舶（不包括非机动驳船）**；捕捞、养殖渔船；军队、武警专用或征用的船舶、警用船舶；避难、防疫隔离并不上下客货的船舶；外国驻华使领馆、国际组织驻华代表机构及其有关人员的船舶；自境外以购买、受赠、继承等方式取得船舶所有权的**初次进口到港的空载船舶**。执照延长期：避难、防疫隔离、修理、改造并不上下客货；军队、武警征用。

**速记口诀**：**"境外进境内、海关来征收、优惠普通两档、50 元以下免、执照 24 小时免、非机动免驳船不免"**。

### 考点9 资源税 ★★★

**核心概念**：为了保护和促进自然资源的合理开发与利用，适当调节自然资源级差收入，对规定的自然资源征收的一种税（**单环节征税**，开采或生产应税产品销售或自用时一次性征收）。

**（一）纳税人**——在中华人民共和国领域及管辖海域开采应税矿产品或者生产盐的单位和个人。**进口的矿产品和盐不征收，出口应税产品也不免征、不退还已纳资源税（进口不征、出口不退）**；经营已税矿产品或盐的不属于纳税人。以应税产品投资、分配、抵债、赠与、以物易物等**视同销售**。

**（二）征税范围——5 大类 164 子目**

| 税目 | 具体内容 |
|---|---|
| 能源矿产 | 原油（**不包括人造石油**）；天然气、页岩气、天然气水合物；煤（原煤和以未税原煤加工的洗选煤）；煤成（层）气；铀、钍；油页岩、油砂、天然沥青、石煤；地热 |
| 金属矿产 | 黑色金属、有色金属 |
| 非金属矿产 | 矿物类、岩石类、宝玉石类 |
| 水气矿产 | 二氧化碳气、硫化氢气、氦气、氡气；矿泉水 |
| 盐 | 钠盐、钾盐、镁盐、锂盐；海盐；天然卤水 |

**（三）税率——固定比例税率、幅度比例税率和定额税率**。具体适用税率由省级政府在税目税率表幅度内提出，报同级人大常委会决定，报全国人大常委会和国务院备案。同一税目下不同税率应税产品应**分别核算**，未分别核算的**从高适用税率**。只有地热、石灰岩、其他粘土、砂石、矿泉水、天然卤水六个子税目规定了从价定率或从量定额两种税率（**素材提示：税目税率表千万不要记忆**；素材列举的固定比例税率子目：原油 6%、天然气/页岩气/天然气水合物 6%、铀钍 4%、钨（选矿）6.50%、钼（选矿）8%、中重稀土 20%、轻稀土 7%～12%、金 2%～6%）。

**（四）计税依据与应纳税额**

```
从量计征：应纳税额 = 销售数量 × 单位税额
从价计征：应纳税额 = 销售额（不含增值税）× 税率
```

- **自产应税矿产品用于连续生产应税矿产品：不缴纳资源税**；自用于其他方面（捐赠、偿债、赞助、投资、职工福利、广告、样品等）：缴纳。
- 销售额明显偏低且无正当理由的确定顺序：① 纳税人最近时期同类产品平均销售价格；② 其他纳税人最近时期同类产品平均销售价格；③ 后续加工非应税产品销售价格减后续加工环节成本利润；④ 组成计税价格＝**成本 ×（1＋利润率）÷（1－资源税税率）**。
- 自采原矿直接销售或自用的按**原矿**征税；洗选加工为选矿产品的按**选矿**征税，原矿移送环节不缴。
- 外购与自采混合销售/加工：准予扣减外购购进金额或数量；外购原矿＋自采原矿混合洗选加工为选矿的，**准予扣减的外购购进金额＝外购原矿购进金额 ×（本地区原矿适用税率 ÷ 本地区选矿产品适用税率）**。

**（五）税收优惠**

| 类别 | 情形 |
|---|---|
| 免征 | 开采原油以及在油田范围内运输原油过程中**用于加热**的原油、天然气；煤炭开采企业因安全生产需要**抽采**的煤成（层）气；青藏铁路公司运营期间自采自用的砂石等 |
| 减征 20% | 从低丰度油气田开采的原油、天然气 |
| 减征 30% | 高含硫天然气、三次采油和从深水油气田开采的原油、天然气；从衰竭期矿山开采的矿产品 |
| 减征 40% | 稠油、高凝油 |
| 减征 50% | 充填开采置换出来的煤炭 |
| 减半 | 增值税小规模纳税人、小型微利企业和个体工商户（2023 年 1 月 1 日至 2027 年 12 月 31 日，不含水资源税） |

> 素材口诀：**免征：加热、抽采；减征：低二高四五置换，深衰岩**。罚没、收缴的应税产品不缴；工程建设项目批准占地范围内开采并直接用于本工程回填的砂石、黏土不缴。

**（六）水资源税**——2024 年 12 月 1 日起水资源费改税试点在全国全面实施。纳税人＝直接取用地表水或地下水的单位和个人；征税对象为地表水和地下水，不含再生水、集蓄雨水、海水及海水淡化水、微咸水等非常规水；**地热、矿泉水和天然卤水按矿产品征收资源税，不征收水资源税**。从量计征、差别税额（地下水、严重短缺和超载地区、特种取用水从高；疏干排水回收利用部分和水源热泵从低）。应纳税额＝实际取用水量 × 适用税额。免征：规定限额内农业生产取用水；除接入城镇公共供水管网外军队武警、国家综合性消防救援队伍其他方式取用水；抽水蓄能发电取用水；采油（气）排水经分离净化后封闭管道回注；受托国土绿化、地下水回灌、河湖生态补水等。工业用水前一年度用水效率达到国家用水定额先进值的减征本年度 20%。不缴：集体水塘水库取水、家庭生活零星散养畜禽少量取水、工程调度取水、临时应急取（排）水等。按月或按季申报，超过限额的农业生产取用水可按年申报；除跨省水力发电取用水外向取水口所在地税务机关申报。

**（七）征收管理**——纳税地点：矿产品开采地或海盐生产地（海上开采的原油天然气由海洋石油税务管理机构征收）。纳税义务发生时间：销售应税产品为收讫销售款或取得索取销售款凭据的当日（先开票的为开票当日）；自用为移送当日；赊销/分期收款为合同约定付款日期当日；预收货款为发出当日；托收承付为发出并办妥托收手续当日；委托代销为收到代销清单当日。纳税期限：按月或按季申报，不能按固定期限的可按次申报。

**速记口诀**：**"进口不征出口不退、连续生产不缴他用缴、加热抽采全免、低二衰三稠四充五、组价除率不除税"**。

### 考点11 环境保护税 ★★★

**核心概念**：对在中华人民共和国领域和管辖的其他海域**直接向环境排放应税污染物**的企业事业单位和其他生产经营者征收的税（我国第一部促进生态文明建设的单行税法）。**纳税人不包括个人**。

**（一）征税范围——大气污染物、水污染物、固体废物、噪声 4 大类**

| 不缴纳 | 应当缴纳 |
|---|---|
| 向依法设立的污水集中处理、生活垃圾集中处理场所排放应税污染物的 | 依法设立的城乡污水集中处理、生活垃圾集中处理场所**超过**国家和地方规定的排放标准向环境排放应税污染物的 |
| 在符合国家和地方环境保护标准的设施、场所贮存或者处置固体废物的 | 贮存或者处置固体废物**不符合**国家和地方环境保护标准的 |
| 依法对畜禽养殖废弃物进行综合利用和无害化处理的 | — |

> 新增：燃烧产生废气中的颗粒物按**烟尘**征收；扬尘、工业粉尘等颗粒物除可确定为烟尘、石棉尘、玻璃棉尘、炭黑尘外，按**一般性粉尘**征收。

**（二）税目税额（定额税率）**

| 税目 | 计税依据 | 税额 |
|---|---|---|
| 大气污染物 | 污染当量数 | 每污染当量 **1.2～12 元**（幅度，高低差 10 倍） |
| 水污染物 | 污染当量数 | 每污染当量 **1.4～14 元** |
| 固体废物 | 排放量（吨） | 煤矸石每吨 **5 元**；尾矿每吨 **15 元**；危险废物每吨 **1000 元**；冶炼渣、粉煤灰等其他每吨 **25 元** |
| 噪声（工业噪声） | 超标分贝数 | 超标 1～3 分贝每月 **350 元**；4～6 分贝 **700 元**；7～9 分贝 **1400 元**；10～12 分贝 **2800 元**；13～15 分贝 **5600 元**；16 分贝以上 **11200 元** |

**（三）计税依据与应纳税额**

```
应税大气污染物应纳税额 = 污染当量数 × 适用税额
应税水污染物应纳税额   = 污染当量数 × 适用税额
  污染当量数 = 该污染物的排放量 ÷ 该污染物的污染当量值
应税固体废物应纳税额   = 固体废物排放量 × 适用税额
  固体废物排放量 = 当期产生量 － 当期综合利用量 － 当期贮存量 － 当期处置量
应税噪声应纳税额       = 超过国家规定标准的分贝数对应的具体适用税额
```

- 每一排放口或没有排放口的应税大气污染物，按污染当量数**从大到小排序，对前三项**征收。
- 每一排放口的应税水污染物区分第一类和其他类，**第一类按前五项、其他类按前三项**征收。
- 排放量和分贝数确定顺序：自动监测数据 → 监测机构数据 → 生态环境主管部门规定方法 → 抽样测算。
- 噪声特别规定：一个单位有不同地点作业场所的**分别计算、合并计征**；边界多处超标按最高一处，**沿边界长度超过 100 米有两处以上超标按两个单位计税**；昼夜均超标分别计算累计计征；夜间突发噪声按等效声级和峰值中超标分贝值高的一项；**声源 1 个月内超标不足 15 天的减半计算**。

**（四）税收优惠**——暂免：农业生产（不含规模化养殖）排放；机动车、铁路机车、非道路移动机械、船舶和航空器等流动污染源；依法设立的城乡污水集中处理、生活垃圾集中处理场所排放相应应税污染物不超过标准的；综合利用的固体废物符合标准的。减征：排放浓度值低于标准 **30% 的减按 75%**；低于 **50% 的减按 50%**。任何一个排放口浓度值超过标准的不予减征。

**（五）征收管理**——纳税义务发生时间：排放应税污染物当日；按月计算、按季申报，季度终了之日起或纳税义务发生之日起 **15 日内**申报；纳税地点：应税污染物**排放地**税务机关。

**速记口诀**：**"企业事业单位缴个人不缴、超标才缴、大气前三水第一前五、低于三成七五折低于五成五折"**。

### 考点12 印花税 ★★★

**核心概念**：对境内应税凭证、证券交易征收的一种税（因主要在应税凭证上粘贴印花税票完成纳税义务而得名）。

**（一）纳税人**——在境内书立应税凭证、进行证券交易的单位和个人；**境外书立在境内使用的也应缴纳**。

| 特殊情形 | 纳税人 |
|---|---|
| 委托贷款方式书立借款合同 | 受托方和借款人，**不包括委托人** |
| 拍卖成交确认书 | 拍卖标的的产权人和买受人，**不包括拍卖人** |
| 证券交易 | **只对出让方征收**，不对受让方征收 |

**（二）征税范围**

| 类别 | 内容 |
|---|---|
| 合同（11 类） | 借款合同、融资租赁合同、买卖合同、技术合同、建设工程合同、承揽合同、运输合同、仓储合同、保管合同、租赁合同、财产保险合同。技术合同**不包括**专利权、专有技术使用权转让书据；运输合同**不包括**管道运输合同；买卖合同**不包括**个人书立的动产买卖合同；借款合同**不包括**同业拆借 |
| 产权转移书据 | 土地使用权出让书据；土地使用权、房屋等建筑物和构筑物所有权转让书据；股权转让书据；商标专用权、著作权、专利权、专有技术使用权转让书据 |
| 营业账簿 | 资金账簿（实收资本和资本公积） |
| 证券交易 | 转让股票和以股票为基础的存托凭证 |

> **不属于征收范围**：人民法院的生效法律文书、仲裁机构的仲裁文书、监察机关的监察文书；县级以上人民政府及其所属部门按行政管理权限征收、收回或补偿安置房地产书立的合同、协议或行政类文书；总公司与分公司、分公司与分公司之间书立的作为执行计划使用的凭证。
> **应当缴纳**：企业之间书立的确定买卖关系、明确双方权利义务的订单、要货单等单据且未另外书立买卖合同的；发电厂与电网、电网与电网之间书立的购售电合同（按买卖合同税目）。

**（三）税率**

| 税率 | 税目 |
|---|---|
| **0.05‰** | 借款合同、融资租赁合同 |
| **0.3‰** | 买卖合同、承揽合同、建设工程合同、运输合同、技术合同、商标专用权、著作权、专利权、专有技术使用权转让书据 |
| **1‰** | 租赁合同、保管合同、仓储合同、财产保险合同、证券交易 |
| **0.5‰** | 土地使用权出让书据、土地使用权、房屋等建筑物和构筑物所有权转让书据、股权转让书据 |
| **0.25‰** | 营业账簿（资金账簿） |

**（四）计税依据与应纳税额（从价计征）**

```
应纳税额 = 计税依据 × 适用税率
```

合同/产权转移书据按所列金额（**不含增值税**）；营业账簿按实收资本和资本公积两项合计金额；证券交易按成交金额。同一应税凭证载有两个以上税目并分别列明金额的分别计算，**未分别列明的从高适用税率**；营业账簿以后年度两科合计金额增加的，按增加部分计算。

**（五）税收优惠**——免征：应税凭证副本或抄本；外国驻华使领馆等为获得馆舍书立的凭证；解放军、武警书立的凭证；农民、家庭农场、农民专业合作社、农村集体经济组织、村民委员会购买农业生产资料或销售农产品书立的买卖合同和农业保险合同；**无息或贴息借款合同**、国际金融组织优惠贷款借款合同；财产所有权人将财产赠与政府、学校、社会福利机构、慈善组织书立的产权转移书据；非营利性医疗卫生机构采购药品或卫生材料书立的买卖合同；个人与电子商务经营者订立的电子订单。特殊优惠：个人销售或购买住房暂免；个人出租承租住房租赁合同免；房地产管理部门与个人订立的租房合同用于生活居住的暂免、用于生产经营的贴花；经济适用住房、改造安置住房相关免；金融机构与小型、微型企业借款合同免（2018.1.1—2027.12.31）；**证券交易印花税自 2023 年 8 月 28 日起减半征收**。

**（六）征收管理**——纳税地点：单位为其机构所在地；个人为凭证书立地或居住地；**不动产产权转移的为不动产所在地**。纳税义务发生时间：书立应税凭证或完成证券交易当日。纳税期限：按季、按年或按次计征，按季按年的自季度、年度终了之日起 **15 日内**，按次的自纳税义务发生之日起 **15 日内**；**证券交易印花税按周解缴，扣缴义务人自每周终了之日起 5 日内申报解缴**。

**速记口诀**：**"万一（0.05‰借款）之三（0.3‰买卖类）租赁保险千一（1‰）、权证半（0.5‰）、账簿零点二五（0.25‰）；文书不征、订单要征"**。

### 考点13 城建税及教育费附加 ★★★

**核心概念**：城建税是对缴纳增值税、消费税（"两税"）的单位和个人，以**实际缴纳的"两税"税额**为计税依据征收的一种税；教育费附加和地方教育附加是就实际缴纳"两税"税额征收的**附加费**。

**（一）纳税人（缴纳人）**——负有缴纳"两税"义务的单位和个人，征税范围与"两税"一致；外商投资企业、外国企业和外籍个人缴纳的"两税"同样征收。

**（二）税率（征收率）——三档地区差别比例税率**

| 所在地 | 城建税税率 | 教育费附加征收率 | 地方教育附加征收率 |
|---|---|---|---|
| 市区 | **7%** | **3%** | **2%** |
| 县城、镇 | **5%** | 3% | 2% |
| 其他地区 | **1%** | 3% | 2% |

> 两种特殊情况按"两税"所在地税率就地缴纳：受托方代扣代缴、代收代缴"两税"的按**受托方所在地**税率；流动经营等无固定纳税地点的按**经营地**税率。

**（三）计税依据与应纳税额**

```
城建税计税依据 = 依法实际缴纳的增值税税额 + 依法实际缴纳的消费税税额
应纳税额 = 实际缴纳的增值税、消费税税额 × 适用税率（征收率）
```

> 计税依据**不包括**滞纳金和罚款；**不含**因进口货物或境外单位和个人向境内销售劳务、服务、无形资产缴纳的"两税"（进口不征）；依法实际缴纳的增值税税额＝应纳增值税税额＋免抵税额－直接减免税额和期末留抵退税退还税额。

**（四）税收优惠**——随"两税"减免而减免，因减免税退库的可同时退库；**海关对进口产品代征的"两税"不征收**城建税及教育费附加（进口不征）；对"两税"先征后返、先征后退、即征即退的，附征的城建税和教育费附加**一律不予退（返）还**；出口退还"两税"的**不退还**已征城建税和教育费附加（出口不退）；国家重大水利工程建设基金免征；自 2023 年 10 月 1 日起保障性住房项目免收教育费附加和地方教育附加；2019.1.1—2025.12.31 重点群体创业就业城建税减免。

**（五）征收管理**——纳税义务发生时间与"两税"一致，与"两税"同时缴纳。

**速记口诀**：**"市区七、县城五、其他一；附加三加二；进口不征出口不退、滞纳罚款不计"**。

### 考点14 小税种相关案例分析题 ★★★★

案例分析题通常跨税种组合命题（房产税＋契税＋土地增值税＋印花税；资源税＋城建税＋车船税；城镇土地使用税单独成题等）。解题关键：

```
Step1  逐业务判断是否属于某税种征税范围（先定性）
Step2  找计税依据（成交价/余值/租金/面积/数量/污染当量/两税实缴额）
Step3  匹配税率或税额（注意优惠政策、分档标准）
Step4  算税额，注意"不含增值税"和扣减项
```

高频组合陷阱：① 房产税从价从租分段算；② 契税只看承受方和差价；③ 土地增值税扣除项目中契税计入"取得土地使用权所支付的金额"、耕地占用税计入"房地产开发成本"；④ 城建税进口不征、出口不退；⑤ 车船税租入外国籍船舶不征、出租到境外征。

## 四、公式与计算（配数字演算）

### 1. 房产税（从价/从租）

```
从价：应纳税额 = 应税房产原值 ×（1－扣除比例）× 1.2%
从租：应纳税额 = 年租金收入 × 12%（或 4%）
免租期：免租期间按房产原值（余值）计征 = 原值 ×（1－扣除比例）× 1.2% ÷ 12 × 月数
```

**例题（从价）**：某省一企业自有房屋 10 栋，房产原值 1000 万元，其中企业办医院使用 2 栋（原值 200 万元），该省规定一次扣除 20% 后的余值计税。
解：应纳房产税＝[（1000－200）×（1－20%）]×1.2%＝**7.68 万元**。

**例题（从租＋免租期）**：甲公司出租房产 1 年，合同约定第 1 个月为免租期，租金共 10 万元，房产原值 200 万元，扣除比例 30%。
解：应纳房产税＝10×12%＋200×（1－30%）×1.2%÷12＝1.2＋0.14＝**1.34 万元**。

**例题（跨年度从价）**：某工业企业 2024 年 9 月 20 日建成办公楼（原值 2000 万元）自用，2025 年 4 月 10 日出售，扣除比例 30%。
解：2024 年（10—12 月）应纳＝2000×（1－30%）÷12×3×1.2%＝**4.2 万元**；2025 年（1—4 月）应纳＝2000×（1－30%）÷12×4×1.2%＝**5.6 万元**。

**例题（原值含地价）**：某企业 2026 年 3 月以 1500 万元取得 5 万㎡土地使用权，建 3 万㎡厂房，建筑成本费用 2000 万元。宗地容积率＝3÷5＝0.6＞0.5，地价全额计入。
解：房产原值＝1500＋2000＝**3500 万元**。

### 2. 城镇土地使用税（定额税率 × 面积）

```
应纳税额 = 实际占用的应税土地面积（㎡）× 适用税额
```

**例题**：某商场繁华地段 6000㎡（一等地段 5 元/㎡）；两个分店共 4000㎡（三等地段 3 元/㎡）；仓库 1000㎡（五等地段 2 元/㎡）；自办托儿所 2500㎡（免税）。
解：应纳＝6000×5＋4000×3＋1000×2＝30000＋12000＋2000＝**44000 元**。

**例题（绿化用地征免）**：某企业占地 10000㎡，其中厂区以外公共绿化用地 3000㎡（免），税率 12 元/㎡。
解：应纳＝（10000－3000）×12＝**84000 元**。

### 3. 土地增值税（增值额、四级超率累进、速算扣除系数）

```
增值额 = 收入额 － 扣除项目金额
增值率 = 增值额 ÷ 扣除项目金额 × 100%
应纳税额 = 增值额 × 适用税率 － 扣除项目金额 × 速算扣除系数
```

**例题（新房）**：某房地产公司转让新建住宅，不含增值税收入 6000 万元，允许扣除项目金额合计 3500 万元。
解：增值额＝6000－3500＝2500 万元；增值率＝2500÷3500＝71.43%（属第二级，税率 40%、速算扣除系数 5%）；应纳＝2500×40%－3500×5%＝1000－175＝**825 万元**。

**例题（旧房，发票加计 5%）**：某企业 2024 年 6 月转让 2015 年 6 月购买的旧房，简易计税，含税收入 383.75 万元，无评估价但有购房发票 200 万元，支付税费 25 万元。
解：增值税＝（383.75－200）÷（1＋5%）×5%＝8.75 万元；应税收入＝383.75－8.75＝375 万元；可扣除房产原值＝200×（1＋5%×9）＝290 万元；扣除项目＝290＋25＝315 万元；增值额＝60 万元；增值率＝60÷315＝19.05%（第一级 30%）；应纳＝60×30%＝**18 万元**。

**例题（旧房，10 年）**：若上例转让时间为 2025 年 6 月（满 10 年）。
解：可扣除房产原值＝200×（1＋5%×10）＝300 万元；扣除项目＝300＋25＝**325 万元**。

### 4. 契税（成交价格）

```
应纳税额 = 计税依据 × 税率
```

**例题**：居民甲将一套住房以 100000 元出售给乙；另一套两室住房与丙的两处一室住房交换，甲支付差价 40000 元。税率 5%。
解：甲（支付差价方）应纳＝40000×5%＝**2000 元**；乙（买方）应纳＝100000×5%＝**5000 元**；丙不缴纳。

### 5. 印花税（比例/定额）

```
应纳税额 = 计税金额 × 适用税率
```

**例题**：某企业 7 月订立买卖合同 200000 元；8 月订立借款合同 400000 元、专有技术使用权转让合同 100000 元；9 月新增实收资本 200000 元、资本公积 50000 元。买卖合同与专有技术使用权转让书据 0.3‰，借款合同 0.05‰，营业账簿 0.25‰。
解：买卖合同＝200000×0.3‰＝60 元；借款合同＝400000×0.05‰＝20 元；技术转让＝100000×0.3‰＝30 元；营业账簿＝250000×0.25‰＝62.5 元；合计＝**172.5 元**。

### 6. 车船税（定额）

```
乘用车/客车/摩托车：应纳税额 = 车辆数量 × 单位税额
货车/挂车：应纳税额 = 整备质量吨位 × 单位税额（挂车×50%）
船舶：应纳税额 = 净吨位 × 单位税额（拖船、非机动驳船×50%）
游艇：应纳税额 = 艇身长度 × 单位税额
```

**例题**：某运输公司有载货汽车 14 辆（2 辆报停，整备质量均为 5 吨）；大客车 35 辆（32 座 10 辆、28 座 25 辆）；小客车 6 辆（10 座）。年基准税额：载货汽车整备质量每吨 50 元，31 座以上每辆 180 元，12～30 座每辆 150 元，11 座以下每辆 140 元。
解：货车＝12×5×50＝3000 元；乘人汽车＝10×180＋25×150＋6×140＝1800＋3750＋840＝6390 元；合计＝**9390 元**。

**例题（船舶，含拖船折算）**：某船运公司 2018 年度有旧机动船 5 艘（每艘净吨位 1500 吨）、拖船 4 艘（每艘发动机功率 3000 千瓦），7 月购置新机动船 6 艘（每艘 3000 吨）。年税额：净吨位 201～2000 吨每吨 4 元，2001～10000 吨每吨 5 元。
解：应纳＝4×1500×5＋4×3000×0.67×5×50%＋5×3000×6×6÷12＝30000＋20100＋45000＝**95100 元**。

### 7. 车辆购置税（10%）

```
应纳税额 = 计税依据 × 10%
进口自用计税价格 =（关税完税价格＋关税）÷（1－消费税税率）
```

**例题（进口）**：某企业进口 1 辆 1.8L 小轿车自用，关税完税价格 20 万元，关税税率 25%，消费税税率 5%。
解：计税价格＝20×（1＋25%）÷（1－5%）＝25÷0.95≈26.32 万元；应纳＝26.32×10%＝**2.632 万元**。

**例题（进口，三项相加）**：甲公司进口小汽车自用，关税完税价格 182000 元，关税 27300 元，消费税 20700 元。
解：应纳＝（182000＋27300＋20700）×10%＝**23000 元**。

**例题（购买自用）**：王某购买 1.5L 小轿车，收取含税价款 22.6 万元（开具机动车销售统一发票）。
解：应纳＝22.6÷（1＋13%）×10%＝**2 万元**。

### 8. 环境保护税（污染当量）

```
大气/水污染物应纳税额 = 污染当量数 × 适用税额
污染当量数 = 该污染物的排放量 ÷ 该污染物的污染当量值
固体废物应纳税额 = 固体废物排放量 × 适用税额
```

**例题**：某化工厂 1 个废气排放口 6 月排放废气 3000 万立方米，每污染当量税额 1.2 元。

| 污染物 | 浓度 | 排放量计算 | 污染当量值 | 污染当量数 |
|---|---|---|---|---|
| 一般性粉尘 | 40 毫克/m³ | 3000×10000×40÷1000÷1000＝1200 千克 | 4 千克 | 300 |
| 二氧化硫 | 200 毫克/m³ | 6000 千克 | 0.95 千克 | 6315.8 |
| 汞 | 0.1 毫克/m³ | 3 千克 | 0.0001 千克 | 30000 |
| 氮氧化物 | 150 毫克/m³ | 4500 千克 | 0.95 千克 | 4736.8 |

解：按当量数从大到小取前三项：汞 30000＋二氧化硫 6315.8＋氮氧化物 4736.8＝41052.6；应纳＝41052.6×1.2＝**49263.12 元**。

**例题**：某企业 1 个排放口排放二氧化硫 100 千克（当量值 0.95）、氟化物 100 千克（0.87）、一氧化碳 200 千克（16.7）、氯化氢 80 千克（10.75），税额 1.2 元/当量。
解：当量数分别为 105.26、114.94、11.98、7.44；取前三项（114.94＋105.26＋11.98）×1.2＝**278.62 元**。

### 9. 资源税（从价/从量）

```
从价：应纳税额 = 销售额（不含增值税）× 税率
从量：应纳税额 = 销售数量 × 单位税额
混合洗选扣减：准予扣减金额 = 外购原矿购进金额 ×（原矿税率 ÷ 选矿税率）
组价 = 成本 ×（1＋利润率）÷（1－资源税税率）
```

**例题（从价）**：某煤炭公司销售原煤 2 万吨，每吨 450 元，专票销售额 900 万元，税率 10%。
解：应纳＝900×10%＝**90 万元**。

**例题（自用视同销售）**：某油田开采原油 50 万吨，销售 40 万吨，非生产自用 2 万吨，每吨不含税售价 6000 元，税率 6%。
解：应纳＝6000×（40＋2）×6%＝252000×6%＝**151200 元＝1.512 万元**。

**例题（混合洗选扣减）**：某煤炭企业外购原煤 100 万元（专票），与自采原煤混合洗选加工为选煤销售 350 万元；当地原煤税率 3%、选煤税率 2%。
解：准予扣减金额＝100×（3%÷2%）＝150 万元；应纳＝（350－150）×2%＝**4 万元**。

**例题（加热免税）**：某油田 2023 年 7 月生产原油 6400 吨，当月销售 6100 吨（3000 元/吨），赠送 5 吨，2 吨用于采油过程中加热修井，税率 5%。
解：加热修井免税；应纳＝（6100＋5）×3000×5%＝**915750 元**。

### 10. 烟叶税

```
应纳税额 =（收购价款 + 价外补贴）× 20%
价外补贴 = 收购价款 × 10%
```

**例题**：甲县烟草公司收购烟叶，支付收购价款 70 万元，另按收购价款 10% 支付价外补贴。
解：应纳＝70×（1＋10%）×20%＝**15.4 万元**。

**例题**：某公司收购晾晒烟叶支付收购价款 113 万元，价外补贴 11.3 万元。
解：应纳＝（113＋11.3）×20%＝**24.86 万元**。

### 11. 耕地占用税

```
应纳税额 = 实际占用的耕地面积（㎡）× 适用定额税率
基本农田：× 150%
```

**例题**：某市一家企业新占用 20000 平方米耕地用于生产建设，适用定额税率 30 元/平方米。
解：应纳＝20000×30＝**600000 元**。

### 12. 城建税及教育费附加

```
应纳城建税 =（实际缴纳的增值税 + 实际缴纳的消费税）× 适用税率（7%/5%/1%）
应纳教育费附加 = 两税实缴额 × 3%
应纳地方教育附加 = 两税实缴额 × 2%
```

**例题**：某市区企业（一般纳税人）7 月实际缴纳增值税 30 万元、消费税 40 万元。
解：应纳城建税＝（30＋40）×7%＝**4.9 万元**。

**例题**：某市一企业 5 月实际缴纳增值税 20 万元、消费税 30 万元。
解：应纳教育费附加＝（20＋30）×3%＝**1.5 万元**；应纳地方教育附加＝（20＋30）×2%＝**1 万元**。

**例题（进口不征、滞纳金不计）**：某县城生产企业本期进口原材料缴纳海关代征增值税 20 万元；国内销售缴纳增值税 26 万元、消费税 54 万元，因超期缴消费税被加收滞纳金 0.46 万元。
解：应纳城建税＝（26＋54）×5%＝**4 万元**。

### 13. 船舶吨税

```
应纳税额 = 船舶净吨位 × 定额税率
拖船、非机动驳船：× 50%
```

**例题**：一艘 A 国船舶（净吨位 3000 吨）进入我国某口岸，申报纳税期 90 日，不适用优惠税率（普通税率 90 日为 8 元/吨）。
解：应纳＝3000×8＝**24000 元**。

**例题（优惠税率）**：某国货轮净吨位 60000 吨，停留 30 天，B 国与我国签订有相互给予船舶税最惠国待遇条款（优惠 30 日税率 3.8 元/吨）。
解：应纳＝60000×3.8＝**228000 元**。

## 五、高频考点速记卡

1. **Q：房产税的纳税人有哪些特殊情形？**
   A：全民所有→经营管理单位；集体和个人所有→集体单位和个人；出典→承典人；产权人/承典人不在当地或产权未确定、租典纠纷未解决→代管人或使用人；无租使用→使用人按余值代缴；融资租赁→承租人。

2. **Q：房产税从价、从租的税率分别是？个人出租住房呢？**
   A：从价 1.2%，从租 12%；个人出租住房不区分用途减按 4%，单位向个人出租用于居住的住房也减按 4%。

3. **Q：房产税从价计征的扣除比例范围？谁确定？**
   A：一次减除 10%～30% 后的余值，具体由省级政府确定；房产原值必须包含地价，宗地容积率低于 0.5 按建筑面积 2 倍计土地面积。

4. **Q：免租期如何缴房产税？**
   A：免收租金期间由产权所有人按**房产余值（原值）**缴纳；正常租赁期对承租人从租计征。

5. **Q：城镇土地使用税的四档定额税率？**
   A：大城市 1.5～30 元/㎡、中等城市 1.2～24 元/㎡、小城市 0.9～18 元/㎡、县城建制镇工矿区 0.6～12 元/㎡；经济落后地区降低不得超过最低税额 30%。

6. **Q：耕地占用税的税率档次和基本农田政策？**
   A：人均耕地≤1 亩 10～50 元/㎡、1～2 亩 8～40 元/㎡、2～3 亩 6～30 元/㎡、＞3 亩 5～25 元/㎡；占用基本农田加按 150%；人均耕地少于 0.5 亩地区提高不得超过 50%。

7. **Q：契税的纳税人、税率和计税依据？**
   A：向产权**承受人**征收；幅度比例税率 3%～5%；买卖按成交价格、赠与按核定市场价、互换按差价（支付差价方）。

8. **Q：契税住房优惠的面积分界线？**
   A：140 平方米。家庭唯一住房 140㎡ 及以下 1%、以上 1.5%；第二套改善性住房 140㎡ 及以下 1%、以上 2%；北上广深暂不实施。

9. **Q：土地增值税四级超率累进税率和速算扣除系数？**
   A：≤50% 部分 30%（0）；50%～100% 部分 40%（5%）；100%～200% 部分 50%（15%）；＞200% 部分 60%（35%）。

10. **Q：土地增值税新房扣除项目五项？**
    A：①地价和相关税费（地价＋契税）②房地产开发成本③房地产开发费用（利息能分摊：利息＋（①＋②）×5%；不能：（①＋②）×10%）④税金（城建、印花、教育费附加）⑤加计扣除（①＋②）×20%，非房地产企业无⑤。

11. **Q：房地产开发企业取得土地使用权的契税计入哪个扣除项目？**
    A：计入"**取得土地使用权所支付的金额**"，视同按国家统一规定交纳的有关费用。

12. **Q：建造普通标准住宅的土地增值税优惠？**
    A：增值额未超过扣除项目金额 20% 的免征；超过 20% 的**全额计征**。

13. **Q：车辆购置税的税率、征税范围和纳税期限？**
    A：10% 比例税率；汽车、有轨电车、汽车挂车、排气量超 150 毫升的摩托车；一次性征收；自纳税义务发生之日起 60 日内申报。

14. **Q：进口自用车辆购置税的计税价格？**
    A：（关税完税价格＋关税）÷（1－消费税税率），即关税完税价格＋关税＋消费税。

15. **Q：车船税的计税单位有哪些？挂车和拖船怎么算？**
    A：乘用车、客车、摩托车按每辆；货车、挂车、其他车辆按整备质量每吨（挂车按货车税额 50%）；船舶按净吨位每吨（拖船、非机动驳船按 50%，拖船每千瓦折合 0.67 吨）；游艇按艇身长度每米。

16. **Q：车船税中节能汽车与新能源车船的区别？**
    A：节能汽车**减半**征收，新能源车船**免征**；纯电动乘用车和燃料电池乘用车不属于征收范围。

17. **Q：境内单位租入外国籍船舶与出租到境外的车船税处理？**
    A：租入外国籍船舶**不征**车船税；将船舶出租到境外的**应依法征收**。

18. **Q：船舶吨税由谁征收？免征情形有哪些？**
    A：海关征收。免征：应纳税额 50 元以下、执照期满后 24 小时内不上下客货、非机动船舶（不含非机动驳船）、捕捞养殖渔船、军警专用或征用、警用船舶、避难防疫隔离不上下客货、外国驻华使领馆有关船舶、初次进口到港空载船舶。

19. **Q：资源税"进口不征、出口不退"怎么理解？自用呢？**
    A：进口矿产品和盐不征，出口应税产品不免征不退还已纳税款；自用于**连续生产应税产品不缴**，用于捐赠偿债赞助投资职工福利广告样品等要缴。

20. **Q：资源税减征比例？**
    A：低丰度油气田 20%；高含硫天然气、三次采油、深水油气田、衰竭期矿山 30%；稠油高凝油 40%；充填开采置换煤炭 50%；加热用油气和安全生产抽采煤层气免征。

21. **Q：烟叶税的税率、计税依据和价外补贴？**
    A：20% 比例税率；计税依据＝收购价款＋价外补贴；价外补贴统一按收购价款的 10% 计算；纳税人为收购单位，月终了 15 日内申报。

22. **Q：环境保护税的纳税人范围和四类税目？**
    A：仅对直接向环境排放应税污染物的企事业单位和其他生产经营者（不含个人）；大气污染物、水污染物、固体废物、噪声。大气每排放口取前三项，水污染物第一类取前五项、其他类前三项。

23. **Q：环境保护税的减征优惠？**
    A：浓度值低于标准 30% 减按 75%，低于 50% 减按 50%；纳税地点为排放地；按月计算按季申报，15 日内。

24. **Q：印花税五档税率分别适用哪些税目？**
    A：0.05‰（借款、融资租赁合同）；0.3‰（买卖合同、承揽、建设工程、运输、技术合同及商标著作权专利权专有技术转让书据）；1‰（租赁、保管、仓储、财产保险合同、证券交易）；0.5‰（土地使用权出让书据、产权转让书据、股权转让书据）；0.25‰（营业账簿）。

25. **Q：城建税的三档税率和教育费附加征收率？计税依据？**
    A：市区 7%、县城镇 5%、其他地区 1%；教育费附加 3%、地方教育附加 2%；依据为实际缴纳的增值税＋消费税，不含滞纳金罚款，进口不征、出口不退。

## 六、典型真题（含解析）

### （一）房产税

**1.【2013·单选】** 下列房产中，不属于房产税征税范围的是（　）。
A. 位于城市的房产　B. 位于县城的房产　C. 位于农村的房产　D. 位于建制镇的房产
**答案：C**　**解析**：房产税在城市、县城、建制镇和工矿区范围内征收，农村不征。

**2.【2014·单选】** 李某在北京拥有一套临街商铺，卖给长期居住在天津的王某，王某随即将商铺交给其朋友刘某使用，目前该商铺的房产税纳税人是（　）。
A. 李某　B. 王某　C. 刘某　D. 王某和刘某
**答案：C**　**解析**：产权所有人、承典人不在房屋所在地的，由房产代管人或使用人纳税。产权所有人王某居住在天津、房产在北京，故由使用人刘某缴纳。

**3.【2018·单选】** 根据房产税的规定，下列各项属于房产的是（　）。
A. 室内游泳池　B. 室外游泳池　C. 围墙　D. 水塔

**4.【20年真题·单选】** 下列关于房产税的纳税人表述不正确的是（　）。

**5.【20年真题·单选】** 下列选项中，属于房产税征税范围的是（　）。

### （二）城镇土地使用税

**8.【2013·多选】** 城镇土地使用税的纳税人不包括（　）。

### （四）契税

**18.【2016·多选】** 纳税人在购买房屋时，下列与房屋相关的附属设施应属于契税征收范围的是（　）。
A. 自行车库　B. 储藏室　C. 停车位　D. 顶层阁楼　E. 制冷设备
**答案：ABCD**　**解析**：承受与房屋相关的附属设施（停车位、汽车库、自行车库、顶层阁楼、储藏室）所有权或土地使用权的，征收契税；不涉及土地使用权和房屋所有权转移变动的，不征。

**19.【20年真题·单选]** 下列关于契税计税依据的表述中不正确的是（　）。
A. 受让国有土地使用权的，以成交价格作为计税依据　B. 受赠房屋的，由征收机关参照房屋买卖的市场价格核定计税依据
C. 购入土地使用权的，以评估价格作为计税依据　D. 交换土地使用权的，以交换土地使用权的价格差额作为计税依据
**答案：C**　**解析**：购入（出售）土地使用权以**成交价格**为计税依据，评估价格表述错误。

**20.【21年真题·单选]** 下列行为，不需要缴纳契税的是（　）。
A. 以房产抵债　B. 以实物交换房屋　C. 以房产作股权转让　D. 以自有房屋作股权投入本人独资经营企业
**答案：D**　**解析**：以自有房屋作股权投入本人独资经营企业，免纳契税；A、B、C 均视同房屋买卖，由产权承受方缴纳。

**21.【22年真题·单选]** 交换价值相等的房屋，契税的处理是（　）。
A. 正常征收　B. 减半征收　C. 免征　D. 减按 30% 征收
**答案：C**　**解析**：房屋所有权相互交换，双方交换价值相等的，免纳契税。

**22.【22年真题·单选]** 契税的具体适用税率，由省、自治区、直辖市人民政府在规定的税率幅度内提出，并报（　）备案。
A. 省、自治区、直辖市人民政府　B. 国家税务总局　C. 财政部　D. 全国人民代表大会常委会和国务院
**答案：D**　**解析**：由省级政府在 3%～5% 幅度内提出，报同级人大常委会**决定**，并报全国人大常委会和国务院**备案**。

**23.【22年真题·多选]** 下列情形符合契税免税规定的有（　）。
A. 个人首次购买 90 平方米以下安置房　B. 个人购买家庭唯一住房
C. 夫妻离婚分割共同财产发生土地房屋权属变更　D. 法定继承人通过继承承受土地房屋权属的
E. 承受荒滩土地使用权用于渔业生产的
**答案：CDE**　**解析**：法定继承人继承、夫妻离婚分割共同财产、承受荒滩用于农林牧渔业生产均免征；个人购买家庭唯一住房是**减按**优惠（140㎡ 及以下 1%、以上 1.5%），不是免税；A 不属于法定免税情形。

**24.【23年真题·单选]** 关于契税的说法错误的是（　）。
A. 对个人首次购买 90 平方米及以下普通住房的，暂按 1% 税率征收契税
B. 契税的纳税义务发生时间，只能是纳税人签订土地、房屋权属转移合同的当天
C. 房屋赠与应当缴纳契税　D. 契税由土地、房屋所在地的主管税务机关征收
**答案：B**　**解析**：纳税义务发生时间为签订权属转移合同当日，**或者取得其他具有权属转移合同性质凭证的当日**，"只能是"表述绝对化。

**25.【24年真题·单选]** 甲企业用价值 1000 万元的写字楼与乙企业价值 800 万元的商铺互换，乙企业支付差价。关于该业务缴纳契税的说法，正确的是（　）。

C. 甲企业按房价缴纳契税，乙企业按差价缴纳契税　D. 乙企业无需缴纳契税，甲企业按差价缴纳契税

**26.【25年真题·多选]** 下列情形中，可以免征或者不征契税的有（　）。
A. 破产企业职工承受破产企业抵债的房屋权属　B. 个人购买保障性住房

**答案：ADE**　**解析**：B 是减按 1% 征收，不是免征；C 应按规定缴纳契税。A、D、E 属于免征或不征情形。

**27.【22年真题·案例】** 甲将原值 28 万元的房产评估作价 30 万元投资乙企业，乙企业办理产权登记后将该房产赠送给丙使用。甲购买了一套价值 50 万元的房产，分期付款 20 年，将此房屋作股投资到本人独资经营的企业。甲继承了一套价值 30 万元的房产，市价 35 万元，过户给儿子作为婚房。上述房产价值均不含增值税，契税税率 3%。
（1）甲应缴纳契税（　）万元。**答案：D（1.5）**　解析：甲投资乙企业由乙缴契税；甲买房 50×3%＝1.5 万元；自有房屋作股投入本人独资企业免纳；继承免纳。
（2）甲的儿子将房产变为和妻子共有，需要缴纳契税（　）元。**答案：A（0）**　解析：婚姻关系存续期间夫妻之间变更土地、房屋权属免征。
（3）乙应缴纳契税（　）元。**答案：C（0.9）**　解析：以房产投资视同房屋买卖，由产权承受方按投资房产价值缴纳，30×3%＝0.9 万元。

（5）甲的儿子应缴纳契税（　）万元。**答案：C（1.05）**　解析：房屋赠与受赠人按规定缴纳，35×3%＝1.05 万元。

### （五）土地增值税

**30.【25年真题·单选]** 根据现行税收政策规定，旧房及建筑物的评估价格是指（　）。

### （六）车辆购置税

**32.【25年真题·单选]** 下列行为中，不属于车辆购置税征收范围的是（　）。
A. 某汽车生产企业将自产小轿车用于日常办公　B. 某物流企业接受汽车生产企业投资的运输车辆自用
C. 某工业企业租赁客车用于接送员工上下班　D. 某轮胎制造企业接受汽车生产企业抵债的小汽车自用
**答案：C**　**解析**：购置是指以购买、进口、自产、受赠、获奖或者其他方式取得并**自用**应税车辆的行为。租赁不属于购置，不缴车辆购置税。

**33.【22年真题·案例】** 某贸易公司 2021 年 2 月业务：（1）进口 4 辆排气量 1.8L 的小轿车，完税价格 20 万元/辆，将其中 1 辆用于公司经营，2 辆用于奖励员工，当月销售另外 1 辆（开具专票价款 35 万元），关税税率 25%，消费税税率 5%；（2）向自然人王某销售 1 辆 1.5L 小轿车，收取含税价款 22.6 万元，开具机动车销售统一发票。
（1）关于业务（1）车辆购置税征管说法正确的有（　）。**答案：B**　解析：进口自用车由贸易公司缴纳车辆购置税（购置并自用）；奖励员工的小轿车由取得并自用的职工缴纳；销售的小轿车不再缴纳；车辆购置税由税务机关征收，不由海关征收。
（2）业务（1）进口自用小轿车车辆购置税的计税价格为（　）万元。**答案：A（26.32）**　解析：（20＋20×25%）÷（1－5%）＝26.32 万元。
（3）业务（2）说法正确的为（　）。**答案：BC**　解析：纳税地点为车辆登记地税务机关；应在向交管部门办理车辆注册登记前缴纳。
（4）车辆购置税的纳税期限为（　）日。**答案：C（60）**　解析：自纳税义务发生之日起 60 日内申报缴纳。
（5）王某应缴纳车辆购置税（　）万元。**答案：D（2）**　解析：22.6÷（1＋13%）×10%＝2 万元。

**56.【24年真题·单选]** 下列污染物中，直接按照排放量确定环境保护税计税依据的是（　）。

**答案：C**　**解析**：大气、水污染物按污染当量数；固体废物按排放量；噪声按超过国家规定标准的分贝数。

**57.【25年真题·单选]** 关于噪声污染征收环境保护税的说法，正确的是（　）。
A. 计税依据为工业噪声的最高分贝数　B. 声源 1 个月内超标不足 15 天的，免征环境保护税
C. 一个单位有不同地点作业场所的，应合并计算应纳税额
D. 某企业边界长度超过 100 米且有两处以上噪声超标，应按照两个单位计算应纳税额
**答案：D**　**解析**：噪声计税依据为超过国家规定标准的分贝数（按最高一处超标声级计算）；超标不足 15 天**减半**计算；不同地点作业场所应**分别计算、合并计征**；沿边界长度超过 100 米有两处以上噪声超标的，按两个单位计算应纳税额。

### （十二）印花税

**58.【20年真题·多选]** 下列选项中，应当缴纳印花税的凭证有（　）。
A. 土地使用权出让书据　B. 记载资金的营业账簿　C. 管道运输合同
D. 无息借款合同　E. 建设工程合同
**答案：ABE**　**解析**：运输合同不包括管道运输合同；无息借款合同免征印花税。

**59.【23年真题·单选]** 位于 A 市的甲公司向位于 B 市的乙公司转让其位于 C 市的一栋商品楼，则印花税的纳税地点为（　）。
A. A 市税务机关　B. B 市税务机关　C. 不动产所在地　D. C 市房管所
**答案：C**　**解析**：不动产产权发生转移的，纳税人应当向不动产所在地的主管税务机关申报缴纳印花税。

**60.【23年真题·单选]** 下列情形不属于印花税征收范围的是（　）。
A. 甲公司与乙公司签订的货物运输合同　B. 股权转让书据
C. 人民法院的生效法律文书　D. 发电厂与电网之间书立的购售电合同
**答案：C**　**解析**：人民法院的生效法律文书、仲裁机构的仲裁文书、监察机关的监察文书不属于印花税征收范围。购售电合同按买卖合同税目缴纳。

**61.【24年真题·多选]** 下列合同或凭证中，不应缴纳印花税的有（　）。
A. 仲裁机构的仲裁文书
B. 市人民政府及其所属部门按照行政管理权限收回或者补偿安置房地产书立的合同
C. 总公司与分公司之间书立的作为执行计划使用的凭证
D. 发电厂与电网之间书立的购售电合同
E. 企业之间书立的确定买卖关系、明确买卖双方权利义务的订单、要货单等单据，且未另外书立买卖合同
**答案：ABC**　**解析**：D、E 均应按规定缴纳印花税。

**62.【25年真题·单选]** 根据印花税法相关规定，下列各项说法中，正确的有（　）。
A. 同一合同含运输和仓储费用但未分列金额的，可按两个税目分别计税
B. 企业签订的电厂与电网之间的购售电合同，免征印花税
C. 未履行的应税合同已缴纳的印花税，不予退还
D. 应税营业账簿，应每年按"实收资本"和"资本公积"两项科目的期末合计金额全额计算缴纳印花税
**答案：C**　**解析**：未分别列明金额的从高适用税率，A 错；购售电合同按买卖合同税目缴纳，B 错；营业账簿仅就增加部分计算，D 错；未履行的应税合同已缴纳的印花税不予退还及抵缴。

### （十三）城建税及教育费附加

**63.【2015·单选]** 位于农村的甲企业受市区的乙企业委托加工木制一次性筷子，下列对乙企业城市维护建设税的税务处理正确的是（　）。
A. 由乙企业在市区按 7% 的税率缴纳　B. 由乙企业按 7% 的税率自行选择纳税地点
C. 由甲企业在农村按 1% 的税率代收代缴乙企业的城市维护建设税　D. 由甲公司在市区按 7% 的税率代收代缴
**答案：C**　**解析**：由受托方代扣代缴、代收代缴"两税"的单位和个人，其城建税按**受托方所在地**适用税率执行。甲企业位于农村，不在市区、县城或镇，税率 1%。

**64.【2017·单选]** 关于城市维护建设税的说法，错误的是（　）。
A. 对增值税和消费税实行先征后返、先征后退、即征即退办法的，除另有规定外，对随增值税和消费税附征的城市维护建设税，也可以退（返）还
B. 外商投资企业缴纳的增值税与消费税，同样征收城市维护建设税
C. 城市维护建设税实行地区差别比例税率，设置了 7%、5% 和 1% 三档税率
D. 城市维护建设税按实际缴纳的增值税和消费税税额计征，随增值税和消费税法定减免而减免
**答案：A**　**解析**：对"两税"实行先征后返、先征后退、即征即退办法的，除另有规定外，对随"两税"附征的城建税和教育费附加**一律不予退（返）还**。

**65.【20年真题·多选]** 下列属于城市维护建设税计税依据的是（　）。
A. 实际缴纳的房产税　B. 实际缴纳的契税　C. 实际缴纳的资源税　D. 实际缴纳的消费税　E. 实际缴纳的增值税
**答案：DE**　**解析**：城建税以实际缴纳的增值税、消费税税额为计税依据。

**66.【22年真题·多选]** 下列关于城市维护建设税和教育费附加的说法，正确的有（　）。
A. 城市维护建设税的纳税人和教育费附加的缴纳人是增值税和消费税的纳税人
B. 海关对进口产品代征的增值税、消费税，不征收城市维护建设税和教育费附加
C. 城市维护建设税和教育费附加的征收依据包括纳税人违反增值税法律制度缴纳的罚款
D. 城市维护建设税和教育费附加的计征范围和增值税、消费税一致
E. 对出口产品退还代征的增值税、消费税的，不退还已征的城市维护建设税和教育费附加
**答案：ABDE**　**解析**：纳税人违反"两税"有关规定被加收的滞纳金和罚款，不作为城建税和教育费附加的计税依据，C 错。

### （十四）综合案例分析

**67.【20年真题·案例]** 甲企业本月发生以下业务：（1）进口一批烟丝，境外成交价格 100 万元，到达我国境内输入地点起卸前的运费、保险费合计 20 万元，支付给境外采购代理人的中介费 10 万元，取得海关增值税专用缴款书，运抵我国境内之后运输到甲企业的不含增值税运费 5 万元并取得专票；（2）甲、乙企业因业务需要，交换了在市区内各自的写字楼，甲企业写字楼价值 80 万元，乙企业写字楼价值 100 万元，甲企业支付差价 20 万元（均不含增值税）；（3）向农民收购烟叶一批，收购价款 200 万元，按收购价款的 10% 支付价外补贴，加工成烟丝以不含增值税价格 400 万元全部销售给丙烟草批发公司。已知：增值税税率 13%，关税税率 20%，契税税率 3%，烟丝消费税税率 20%。
（1）甲企业进口烟丝应缴纳的关税为（　）万元。**答案：B（26）**　解析：关税完税价格＝100＋20＝120 万元（购货佣金不计入），应纳关税＝120×20%＝24 万元……按该题选项口径为 B（26）。
（2）根据业务（2），下列说法正确的是（　）。**答案：B**　解析：由甲企业（支付差价方）缴纳契税，应纳＝20×3%＝0.6 万元。
（3）下列说法正确的是（　）。**答案：AC**　解析：收购烟叶的单位为烟叶税纳税人；应纳烟叶税＝200×（1＋10%）×20%＝44 万元。
（4）业务（1）甲企业进口烟丝应缴纳的进口环节增值税为（　）万元。**答案：D（25.35）**　解析：组价＝（120＋24＋烟丝消费税）÷（1－20%）后乘 13%。

**68.【25年真题·案例]** 某工业企业甲为增值税一般纳税人，2024 年 9 月 20 日建成一栋办公楼 A 用于办公，房屋原值 2000 万元。2025 年 4 月 10 日将其出售，与乙企业签订房屋买卖合同，取得含税销售收入 5000 万元，双方按规定办理不动产产权转移。当地政府规定房产余值扣除比例为 30%。
（1）（2）房产税见考点真题第 7 题（答案 B、D）。
（3）关于甲企业销售办公楼 A 的契税征收管理的说法，正确的有（　）。**答案：AD**　解析：纳税义务发生时间为房屋买卖合同签订的当日；纳税地点为办公楼 A 所在地。B 错——甲企业是出让方，乙企业是承受方，乙企业才是契税纳税人；C 错——应在依法办理房屋权属登记手续**前**申报缴纳。
（4）该企业出售办公楼 A 计算缴纳土地增值税时，扣除项目与转让房地产有关的税金包括（　）。**答案：ABD**　解析：包括城市维护建设税、印花税、教育费附加；**不包括增值税**。
（5）关于甲、乙企业买卖办公楼 A 的印花税缴纳的说法，正确的有（　）。**答案：A**　解析：不动产产权转移的，应向不动产所在地主管税务机关申报缴纳。B 错——纳税义务发生时间为书立应税凭证当日（合同签订当日，选项中"设立合同"表述不准确）；C 错——计税依据应为不含增值税金额；D 错——买卖合同税目适用于企业之间书立的买卖合同，此处为产权转移书据税目（土地使用权、房屋所有权转让书据，0.5‰）。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把出典人当成房产税纳税人 | 出典的纳税人是**承典人**（出典期间产权人无权支配房屋） |
| 2 | 认为农村房屋也缴房产税 | 房产税只在**城市、县城、建制镇、工矿区**征收 |
| 3 | 分不清室内外游泳池 | **室内是房产、室外不是**（连同围墙、水塔、烟囱一起记） |
| 4 | 从价计征直接用原值乘 1.2% | 必须先减除 **10%～30%**，且原值要含地价 |
| 5 | 忽略宗地容积率 0.5 规则 | 容积率低于 0.5，按房产建筑面积的 **2 倍**计土地面积计地价 |
| 6 | 免租期不缴房产税 | 免租期按**房产余值（原值）**缴，由产权所有人缴 |
| 7 | 把单位向个人出租住房税率记成 12% | 个人出租住房、单位向个人出租居住用房均**减按 4%** |
| 8 | 大修停用时间记错 | **连续停用半年以上**才免 |
| 9 | 城镇土地使用税四档税额记混 | 大城市 1.5～30、中等 1.2～24、小城市 0.9～18、县城镇工矿 0.6～12 |
| 10 | 落后地区降税幅度记错 | 降低额**不得超过最低税额的 30%**；发达地区提高须报财政部批准 |
| 11 | 厂区绿化用地一律免税 | **厂区以内照章征收**，厂区以外公共绿化才免 |
| 12 | 地下建筑用地全额征税 | 单独建造的地下建筑用地**暂按应征税款的 50%** |
| 13 | 把耕地占用税与契税混淆 | 耕地占用税＝占用耕地**行为**、一次性征收；契税＝**权属转移承受方** |
| 14 | 基本农田按普通税额 | 占用基本农田**加按 150%** |
| 15 | 耕地占用税纳税期限记成 15 日 | 是 **30 日**（各税种中最特殊） |
| 16 | 契税纳税人记成转让方 | 契税向**承受方**征收；互换只由支付差价方缴 |
| 17 | 契税住房优惠面积记成 90㎡ | 现行是 **140 平方米**分水岭（1%/1.5%/2%），北上广深暂不实施 |
| 18 | 土地增值税"出让"与"转让"不分 | **出让不征、转让才征**；只征有偿转让 |
| 19 | 普宅增值额超 20% 只就超出部分计税 | 超 20% **全额计征** |
| 20 | 土地增值税扣除项目张冠李戴 | 契税→取得土地使用权金额；**耕地占用税→房地产开发成本**；利息→房地产开发费用 |
| 21 | 非房地产开发企业也加计 20% | 加计扣除**仅房地产开发企业**有 |
| 22 | 旧房评估价与发票加计混淆 | 评估价＝重置成本价×成新度折扣率；无评估价时按发票金额**每年加计 5%** |
| 23 | 四级超率累进税率与系数记错 | 30/40/50/60 配 **0/5/15/35** |
| 24 | 车辆购置税与车船税混淆 | 前者**一次性 10%**，后者**按年定额** |
| 25 | 认为所有摩托车都缴车辆购置税 | 只有排气量**超过 150 毫升**的摩托车 |
| 26 | 新能源汽车免税无上限 | 每辆新能源乘用车免税额**不超 3 万元**（2026—2027 减半期减税额不超 1.5 万元） |
| 27 | 节能汽车与新能源车船优惠记反 | **节能减半、新能源免征** |
| 28 | 挂车按货车全额缴税 | 挂车按货车税额的 **50%**；拖船每千瓦折合 **0.67 吨** |
| 29 | 租入外国籍船舶与出租到境外记反 | **租入不征、出租到境外征** |
| 30 | 船舶吨税与车船税混淆 | 吨税由**海关**征收、针对境外进入境内港口船舶；非机动驳船**不**免（按 50%） |
| 31 | 资源税进口出口处理记反 | **进口不征、出口不退** |
| 32 | 自用应税产品一律缴资源税 | **连续生产应税产品不缴**，用于其他方面才缴 |
| 33 | 资源税减征比例记混 | 低丰度 20%、高含硫/三次采油/深水/衰竭期 30%、稠油高凝油 40%、充填开采 50% |
| 34 | 混合洗选扣减直接用外购金额 | 外购原矿与自采原矿混合洗选的，要按**原矿税率÷选矿税率**折算 |
| 35 | 环境保护税向个人征收 | 只对**企事业单位和其他生产经营者** |
| 36 | 向污水集中处理场所排放就缴税 | 不属直接向环境排放**不缴**；但集中处理场所**超标排放要缴** |
| 37 | 大气/水污染物全部征收 | 大气取当量数**前三项**；水污染物第一类取**前五项**、其他类前三项 |
| 38 | 环保税减征比例记错 | 低于标准 30% 减按 **75%**，低于 50% 减按 **50%** |
| 39 | 印花税五档税率与税目配错 | 借款融资租赁 0.05‰；买卖承揽建设运输技术 0.3‰；租赁保管仓储保险证券 1‰；权证股权 0.5‰；账簿 0.25‰ |
| 40 | 委托贷款/拍卖/证券交易纳税人记错 | 委托贷款＝受托方＋借款人；拍卖＝产权人＋买受人；证券交易**只对出让方** |
| 41 | 认为法律文书、订单都缴印花税 | 法院/仲裁/监察文书**不征**；企业间订单要货单**要征** |
| 42 | 城建税依据含滞纳金罚款 | 城建税依据**不含**滞纳金罚款；**进口不征、出口不退** |
| 43 | 城建税三档税率记混 | 市区 **7%**、县城镇 **5%**、其他 **1%**；教育费附加 3%、地方教育附加 2% |
| 44 | 烟叶税纳税人含个人、价外补贴按实际 | 仅**单位**收购；价外补贴统一按收购价款 **10%** 算 |
