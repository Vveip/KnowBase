# 第6章 财产和行为税制度

> **来源**：`one__讲义__39`～`46`（第六章全套讲义）
> **本章权重**：★★★（高频）  |  **建议学习时长**：4 小时

## 一、本章知识地图

**第一节**房产税、城镇土地使用税；**第二节**土地增值税、契税、耕地占用税；**第三节**印花税、城建税、教育费附加；**第四节**车船税、车辆购置税、船舶吨税；**第五节**环境保护税、资源税、烟叶税。

### 本章14个税种速查总表（考前必扫）

| 税种 | 纳税人 | 税率 | 计税依据 | 属财产行为税 |
|---|---|---|---|---|
| 房产税 | **产权所有人**（出典→承典人；人不在/权属未定→代管人或使用人；融资租赁→承租人） | **1.2%**/**12%**（个人出租 **4%**） | 房产**计税余值**或**租金** | 是 |
| 城镇土地使用税 | 拥有**土地使用权**者（权属未定→实际使用人；共有→各方） | 分级幅度**定额** | **实际占用土地面积** | 是 |
| 土地增值税 | **转让**房地产并取得收入者 | 超率累进 **30/40/50/60%** | **增值额**＝收入－扣除项目 | 是 |
| 契税 | 权属**承受方** | **3%～5%** | **成交价**（互换为差额） | 是 |
| 耕地占用税 | 占用耕地非农建设者 | **5～50元/㎡**；基本农田**加按150%** | **实际占用耕地面积** | 是 |
| 印花税 | 书立应税凭证、证券交易者 | **0.05%～1‰** | 凭证**所列金额**；账簿**实收资本＋资本公积** | 是 |
| 城建税 | 缴纳"两税"者 | **7%/5%/1%** | 实缴"两税"税额 | 是 |
| 教育费附加 | 同城建税 | **3%**（地方 **2%**） | 同城建税 | **否**（附加费） |
| 车船税 | 车船**所有人或管理人** | **定额** | 辆/整备质量/净吨位/艇长 | 是 |
| 车辆购置税 | 境内**购置并自用**者 | **10%** | 不含增值税的购置价 | 是 |
| 船舶吨税 | 境外港口进入境内港口船舶负责人 | 优惠/普通税率 | **船舶净吨位** | 是 |
| 环境保护税 | 直接排放污染物的单位和其他经营者（**不含个人**） | **定额** | 污染当量数/排放量/超标分贝数 | 是 |
| 资源税 | 开发应税资源者 | 比例＋定额 | **销售额**（不含增值税）或数量 | 是 |
| 烟叶税 | **收购**烟叶的单位 | **20%** | 收购价款总额（补贴按价款 **10%**） | 是 |

## 二、知识点精讲

### 考点1：房产税（★★★）
- **范围**：仅限**城市、县城、建制镇、工矿区**（**不含农村**）；围墙、烟囱、水塔、室外游泳池等独立建筑物**不属于房产**；房企商品房**出售前不征**，已使用或出租出借的应征。
- **纳税人**：产权所有人；全民所有→经营管理单位；出典→承典人；人不在当地或权属未定→代管人或使用人；融资租赁→承租人；**无租使用**按房产余值代缴。
- **计税**：从价＝原值×（1－扣除比例）×**1.2%**，原值**必须含地价**，容积率低于 **0.5** 按建筑面积 **2倍** 计地价；从租＝租金×**12%**（个人出租居民住房 **4%**），租金**不含增值税**；**免租期由产权人按原值计税**。
- **优惠**：机关军队团体、财政拨款单位、宗教公园名胜古迹**自用**免；个人非营业房产免；企业办学校医院托幼自用免；大修停用 **半年以上**免。
- **征收**：房产所在地税务机关；自建房屋**建成之次月**起征，委托施工的自**验收手续之次月**起征。

### 考点2：城镇土地使用税（★★★）
- **纳税人**：拥有土地使用权者；权属未定→**实际使用人**；共有→**各方**；承租集体建设用地→**直接从集体经济组织承租者**。
- **计税**：**实际占用土地面积**×适用税额。
- **特殊**：公园名胜古迹内**索道公司经营用地应缴**；单独建造**地下建筑用地暂按50%**（有证按证载面积，无证按垂直投影面积）。
- **优惠**：机关军队团体、财政拨款单位、宗教公园自用免；市政公共用地、直接农用地免；企业**区外**绿化暂免、**区内**照征；**个人出租住房不分用途免征**。
- **衔接**：缴过耕地占用税的**满1年**起征；非耕地批准征用**次月**起征。

### 考点3：土地增值税（★★★）
- **边界**：只对**转让**征、**出让不征**；只对**有偿**征、**继承赠与不征**；单位之间互换征、个人互换自有居住用房免；合作建房分房自用免、建成转让征；开发产品用于职工福利、投资、分配、抵债、换非货币资产**视同销售**。
- **四级超率累进**：≤**50%**→**30%**（系数0）；50%~100%→**40%**（**5%**）；100%~200%→**50%**（**15%**）；>200%→**60%**（**35%**）。
- **应纳税额**＝增值额×税率－扣除项目金额×速算扣除系数。
- **新建扣除5项**：地价款＋开发成本＋开发费用＋有关税金＋**加计20%**。开发费用：能分摊利息且有贷款证明→**利息＋（地价＋成本）×5%**；否则→（地价＋成本）×**10%**。
- **旧房扣除**：先评估价（重置成本×成新度）→无评估价按**发票金额每年加计5%**→核定征收；购房**契税**可作税金扣，但**不作加计5%基数**。
- **优惠**：普通标准住宅增值额未超扣除项目 **20%** 免；国家建设征用收回免；**个人销售住房暂免**。

### 考点4：契税（★★★）
- **纳税人**：权属**承受方**；税率 **3%～5%**。
- **范围**：土地出让、转让（**不含农村集体土地承包经营权/经营权转移**）、买卖、赠与、互换。
- **计税**：买卖出让用**成交价**；互换用**差额**（等值免、不等值由**付差价方**缴）；赠与及无价格按**核定价**；均不含增值税。
- **特例**：以房产**抵债或实物交换**按房屋现值；**投资或作股权转让**按房产价值或买价。承受附属设施（停车位、车库、阁楼、储藏室）所有权或土地使用权**征**，不涉权属转移**不征**。
- **征收**：**签订权属转移合同当日**为义务发生时间，须在**办理权属登记前**申报。

### 考点5：耕地占用税（★）
- **一次性征收**，定额 **5～50元/㎡**；占用**基本农田加按150%**；人均耕地少于 **0.5亩**地区提额幅度最高 **50%**。
- **优惠**：农田水利设施**不缴**；军事、学校、幼儿园、福利、医疗机构**免**；农村居民标准内新建自宅**减半**；铁路公路机场港口航道水利工程减按 **2元/㎡**。
- **征收**：收到自然资源部门办理占用耕地手续**书面通知当日**为义务发生时间，**30日内**申报。

### 考点6：印花税（★★★）
- **税率五档**：**0.05%**（借款、融资租赁）；**1‰**（租赁、保管、仓储、财产保险、证券交易）；**0.25%**（营业账簿）；**0.5%**（土地出让书据、不动产及股权转让书据）；**0.3%**（买卖、承揽、建筑工程、运输、技术合同及技术转让书据）。
- **计税**：合同/产权转移书据**所列金额**（不含列明增值税）；账簿＝**实收资本＋资本公积**；证券交易＝**成交金额**；多税目未分别列明**从高适用**。
- **特例**：委托贷款→**受托人和借款人**；拍卖成交确认书→**产权人和买受人**；证券交易印花税**只对出让方**征。
- **不征**：法院生效法律文书、仲裁文书、监察文书；县级以上政府征收收回补偿安置房地产文书；总分公司间执行计划凭证。
- **优惠与征收**：个人买卖住房、个人租承租住房免；**2023年8月28日起证券交易印花税减半**。单位纳税人向**机构所在地**，个人向**书立地或居住地**；按季按年计征于终了 **15日内**，按次于义务发生起 **15日内**。

### 考点7：城建税和教育费附加（★★）
- **城建税**：市区 **7%**、县城镇 **5%**、其他 **1%**；受托方代扣按**受托方所在地**税率，流动经营按**经营地**税率；进口货物及境外向境内销售劳务服务无形资产的"两税"**不征**；滞纳金罚款**不作**依据。
- **教育费附加 3%**、地方教育附加 **2%**；海关代征进口"两税"不征；出口退还增值税消费税**不退**已征附加。
- **易错**："两税"先征后返、先征后退、即征即退的，随征城建税和附加**一律不退（返）还**。

### 考点8：车船税（★★）
- 向**所有人或管理人**征收，按年申报；**自行车不缴**。税目含乘用车、商用车、挂车、其他车辆、摩托车、船舶。
- 计税：乘用车客车摩托车按**辆**；货车挂车按**整备质量每吨**（**挂车按50%**）；机动船舶按**净吨位**（拖船、非机动驳船按**50%**）；游艇按**艇身长度每米**。
- **优惠**：捕捞养殖渔船、军警专用、警用车船、应急救援号牌车辆免；**节能汽车减半、新能源免征**；境内租入外国籍船舶**不征**，租出境**征**。
- **征收**：**登记地或扣缴义务人所在地**；取得所有权或管理权**当月**为义务发生时间。

### 考点9：车辆购置税（★★）
- 对**购置并自用**（购买、进口、自产、受赠、获奖等）**一次性征收**；范围：汽车、有轨电车、汽车挂车、**排气量超150毫升摩托车**；税率 **10%**，计税依据**不含增值税**；进口＝关税完税价＋关税＋消费税。
- **优惠**：外国使领馆及有关人员、军警装备计划车辆、应急救援号牌车辆、固定装置非运输作业车、城市公交汽电车免；**2026.1.1—2027.12.31新能源汽车减半，每辆乘用车减税不超1.5万元**。
- **征收**：**车辆登记地**（不需登记为纳税人所在地）；**购置当日**为义务发生时间，**60日内**申报。转让改变用途补税、退货退税，均按每满一年扣减 **10%**。

### 考点10：船舶吨税（★）
- 对**境外港口进入境内港口**船舶征收，由**海关**征收；分优惠税率（我国国籍或签有最惠国待遇条约协定）与普通税率。
- 拖船每千瓦折净吨位 **0.67吨**；游艇无证明每千瓦 **0.05吨**；拖船和非机动驳船按 **50%** 计征。
- 免：税额 **50元以下**、初次进口空载船、执照期满 **24小时**内不上下客货、**非机动船舶（不含非机动驳船）**。

### 考点11：环境保护税（★★★）
- 对直接排放**大气、水、固废、噪声**污染物征收，**不含个人**；向集中处理场所排放、达标储存处置固废**不缴**。
- **计税**：气水→**污染当量数**；固废→**排放量**；噪声→**超标分贝数**。
- **税额**：大气每污染当量 **1.2～12元**；水 **1.4～14元**；煤矸石 **5元/吨**、尾矿 **15元/吨**、冶炼渣粉煤灰 **25元/吨**、危险废物 **1000元/吨**；噪声 **350～11200元/月** 六档。
- **噪声规则**：不同地点作业场所**分别计算合并计征**；边界多处超标按**最高一处**，沿边界超 **100米** 有两处以上按**两个单位**；昼夜均超标分别累计；一月内超标不足 **15天减半**。
- **优惠**：农业生产（不含规模养殖）、流动污染源、集中处理达标排放、综合利用达标固废**暂免**；浓度低于标准 **30%** 减按 **75%**，低于 **50%** 减按 **50%**。按月计算**按季申报**，季度终了 **15日内**，向**排放地**申报。

### 考点12：资源税（★★）
- 对**开发**应税资源征收（能源、金属、非金属、水气矿产、盐五大类）；**自用应缴，连续生产自用不缴**。
- 从价＝销售额（不含增值税）×比例税率；从量＝重量（体积）×税额；运杂费用有合法凭据**准予扣除**。
- **混合扣减**：外购＋自采混合**直接销售**→直接扣；混合**洗选加工为选矿**→扣减额＝外购原矿额×（**原矿税率÷选矿税率**）。
- **减征**：低丰度油气田 **20%**；高含硫天然气、三次采油、深水油气田、衰竭期矿山 **30%**；稠油高凝油 **40%**。
- **征收**：在**开采地**或海盐**生产地**缴纳；直接收款以收讫销售款或取得索取销售款凭据当日（先开票为开票日）为义务发生时间，赊销分期以合同约定付款日，预收货款以**发出当日**，委托代销以**收到代销清单当日**。

### 考点13：烟叶税（★）
- 向**收购**烟叶的单位征收（晾晒烟叶、烤烟叶）；税率 **20%**；计税依据含价外补贴（**按收购价款10%**）；**无减免项目**。
- **征收**：向**烟叶收购地**主管税务机关申报，**收购当日**为义务发生时间，月终 **15日内**申报。

## 三、必背表格汇总

### 差异1：房产税 vs 城镇土地使用税

| 项目 | 房产税 | 城镇土地使用税 |
|---|---|---|
| 对象 | 房屋 | 土地 |
| 计税依据 | 计税余值/租金收入 | 实际占用土地面积 |
| 税率 | **1.2%**/**12%**（个人 **4%**） | 分级幅度定额 |
| 地下建筑 | 具备房屋功能**应征** | 单独建造**暂按50%** |
| 农村 | **不征** | **不征** |
| 个人出租住房 | 减按 **4%** | **免征** |

### 差异2：土地增值税 vs 契税

| 项目 | 土地增值税 | 契税 |
|---|---|---|
| 纳税人 | **转让方** | **承受方** |
| 税率 | 超率累进 **30%～60%** | **3%～5%** |
| 赠与 | **不征** | 受赠人缴纳 |
| 互换 | 单位之间征、个人自有居住用房免 | 付差价方按差额缴 |
| 计税依据 | **增值额** | **成交价/差额/核定价** |

### 差异3：车船税 vs 车辆购置税 vs 船舶吨税

| 项目 | 车船税 | 车辆购置税 | 船舶吨税 |
|---|---|---|---|
| 征收环节 | **持有**期（按年） | **购置**时（一次性） | **进港**时 |
| 征收机关 | 税务机关 | 税务机关 | **海关** |
| 新能源 | 免征（节能减半） | **减半**，每辆乘用车减税≤**1.5万元** | — |

### 差异4：城建税、教育费附加、地方教育附加

| 项目 | 城建税 | 教育费附加 | 地方教育附加 |
|---|---|---|---|
| 性质 | 税 | 附加费 | 附加费 |
| 税率/比率 | **7%/5%/1%** | **3%** | **2%** |
| 进口环节 | **不征** | **不征** | **不征** |
| 先征后返 | 不退（返）还 | 不退（返）还 | 不退（返）还 |

### 土地增值税扣除项目

| 情形 | 扣除项目 |
|---|---|
| **新建房地产** | ①地价款；②开发成本；③开发费用；④有关税金；⑤**加计20%** |
| **旧房及建筑物** | ①地价款；②评估价（重置成本×成新度）；③转让环节税金 |

## 四、公式与计算

| 税种 | 公式 |
|---|---|
| 房产税（从价） | 原值×（1－扣除比例）×**1.2%** |
| 房产税（从租） | 租金×**12%**（个人 **4%**） |
| 城镇土地使用税 | 实际占用面积×适用税额 |
| 耕地占用税 | 实际占用耕地面积×定额税率 |
| 土地增值税 | 增值额×税率－扣除项目金额×速算扣除系数 |
| 契税 | 计税依据×**3%～5%** |
| 印花税 | 计税依据×适用税率 |
| 城建税 | 实缴"两税"×**7%/5%/1%** |
| 教育费附加 | 实缴"两税"×**3%**（地方 **2%**） |
| 车船税 | 辆数（吨位/净吨位/艇长）×单位税额 |
| 车辆购置税 | 计税依据×**10%** |
| 船舶吨税 | 船舶净吨位×适用税率 |
| 环境保护税 | 污染当量数（排放量/超标分贝数）×税额 |
| 资源税 | 销售额×比例税率；或重量×税额 |
| 烟叶税 | 收购金额×**20%** |

### 土地增值税四级超率累进税率表（必背）

| 级数 | 增值额与扣除项目金额的比率 | 税率 | 速算扣除系数 |
|---|---|---|---|
| 1 | 不超过 **50%** 的部分 | **30%** | **0** |
| 2 | 超过 **50%**、未超过 **100%** | **40%** | **5%** |
| 3 | 超过 **100%**、未超过 **200%** | **50%** | **15%** |
| 4 | 超过 **200%** 的部分 | **60%** | **35%** |

### 演算例题

**【例1·房产税】免租期从价＋从租合并**
> 租金共 **10万元**，房产原值 **200万元**，扣除比例 **30%**，首月免租。
> **解**：应纳税额＝10×**12%**＋200×（1－**30%**）×**1.2%**÷12＝1.2＋0.14＝**1.34万元**

**【例2·房产税】自建房屋起征时间**
> 2024年9月20日建成办公楼，原值 **2000万元**，扣除比例 **30%**。
> **解**：自**建成次月**起征。2024年＝2000×（1－**30%**）÷12×3×**1.2%**＝**4.2万元**；2025年（1—4月）＝2000×（1－**30%**）÷12×4×**1.2%**＝**5.6万元**

**【例3·城镇土地使用税】分地段＋免税剔除**
> 商场 **6000㎡**（**5元/㎡**）、分店 **4000㎡**（**3元/㎡**）、仓库 **1000㎡**（**2元/㎡**）、自办托儿所 **2500㎡**（免税）。
> **解**：年税额＝6000×**5**＋4000×**3**＋1000×**2**＝**44000元**

**【例4·土地增值税】四级超率累进完整演算**
> 转让新建普通标准住宅，不含税收入 **6000万元**，扣除项目金额 **3500万元**。
> **解**：①增值额＝6000－3500＝**2500万元**；②增值率＝2500÷3500＝**71.43%**（第二级）；③税率 **40%**、系数 **5%**；④应纳税额＝2500×**40%**－3500×**5%**＝**825万元**

**【例5·土地增值税】旧房按发票加计5%**
> 2025年6月转让2015年6月购入旧房，无评估价，购房发票 **200万元**，支付税费 **25万元**。
> **解**：可扣除原值＝200×（1＋**5%**×10）＝**300万元**；扣除项目金额＝300＋25＝**325万元**

**【例6·印花税】多税目合并**
> 买卖合同 **200000元**、借款合同 **400000元**、专有技术使用权转让 **100000元**；新增实收资本 **200000元**、资本公积 **50000元**。（买卖及技术转让 **0.3%**，借款 **0.05%**，账簿 **0.25%**）
> **解**：60＋20＋30＋（200000＋50000）×**0.25%**＝60＋20＋30＋62.5＝**172.5元**

**【例7·车辆购置税】进口组价**
> 进口小轿车，关税完税价 **20万元**，关税 **25%**，消费税 **5%**。
> **解**：计税价格＝20×（1＋**25%**）÷（1－**5%**）＝**26.32万元**；应纳＝26.32×**10%**＝**2.632万元**

**【例8·资源税】外购与自采混合洗选**
> 外购原煤 **100万元** 与自采 **200万元** 混合洗选为选煤销售，选煤销售额 **450万元**，原煤税率 **3%**、选煤 **2%**。
> **解**：准予扣减＝100×（**3%÷2%**）＝**150万元**；计税销售额＝450－150＝**300万元**；应纳税额＝300×**2%**＝**6万元**

**【例9·烟叶税】价外补贴按10%**
> 收购烟叶支付价款 **117万元**，实际支付价外补贴 **10万元**。
> **解**：应纳烟叶税＝117×（1＋**10%**）×**20%**＝**25.74万元**

## 五、高频考点速记卡

1. **问**：房产税对农村房屋征吗？**答**：**不征**，仅限城市、县城、建制镇、工矿区。
2. **问**：房产融资租赁纳税人、免租期如何处理？**答**：**承租人**；免租期由产权人按**房产原值**计税。
3. **问**：房产税从价、从租税率？**答**：**1.2%**、**12%**；个人出租居民住房 **4%**。
4. **问**：容积率低于多少按建筑面积2倍计地价？大修停用多久免？**答**：**0.5**；连续 **半年以上**。
5. **问**：单独建造地下建筑用地、个人出租住房的城镇土地使用税？**答**：暂按 **50%** 和**免征**。
6. **问**：缴过耕地占用税的土地何时征城镇土地使用税？**答**：满 **1年**；非耕地 **次月**。
7. **问**：土地增值税对"出让"征吗？**答**：**不征**，只对"转让"征。
8. **问**：土地增值税四级税率与速算扣除系数？**答**：**30/40/50/60%**，系数 **0/5%/15%/35%**。
9. **问**：房地产开发费用扣除标准？**答**：**利息＋（地价＋成本）×5%**；否则×**10%**。
10. **问**：房地产开发企业加计扣除？**答**：（地价＋开发成本）×**20%**。
11. **问**：普通标准住宅免土地增值税条件？**答**：增值额未超扣除项目金额 **20%**。
12. **问**：契税纳税人、税率、互换规则？**答**：**承受方**；**3%～5%**；等值免、不等值**付差价方**按差额缴。
13. **问**：耕地占用税基本农田、税额幅度、申报期限？**答**：**加按150%**；**5～50元/㎡**；**30日内**。
14. **问**：印花税借款合同、营业账簿、最高档税率？多税目未分别列明金额？**答**：**0.05%**、**0.25%**、**1‰**；**从高适用**。
15. **问**：证券交易印花税？**答**：只对**出让方**，2023年8月28日起**减半**。
16. **问**：城建税三档税率与进口环节？**答**：**7%/5%/1%**；进口**不征**。
17. **问**：教育费附加与地方教育附加比率？**答**：**3%** 和 **2%**。
18. **问**：车船税挂车、拖船、新能源汽车？**答**：均按 **50%**；节能**减半**、新能源**免征**。
19. **问**：车辆购置税税率、次数、摩托车标准、新能源优惠？**答**：**10%**、**一次性**、排气量**超150毫升**；2026.1.1—2027.12.31**减半**且每辆乘用车减税≤**1.5万元**。
20. **问**：船舶吨税由谁征、拖船折算？**答**：**海关**；每千瓦 **0.67吨**。
21. **问**：环保税纳税人含个人吗？三类计税依据？**答**：**不含**；**污染当量数/排放量/超标分贝数**。
22. **问**：噪声超标不足15天、环保税减征两档？**答**：**减半**；低于 **30%** 减按 **75%**、低于 **50%** 减按 **50%**。
23. **问**：资源税连续生产自用、减征比例？**答**：**不缴**；**20%/30%/40%**。
24. **问**：烟叶税税率与价外补贴比例？**答**：**20%**；按收购价款 **10%**。

## 七、易错点与避坑指南

1. **"出让"≠"转让"**：土地增值税只对**转让**征，**出让不征**。
2. **房产税免租期**：免租期**由产权所有人按房产原值**缴税，不是按租金、也不是不缴。
3. **房产原值漏算地价**：无论会计如何核算原值**均应含地价**；容积率低于 **0.5** 按建筑面积 **2倍** 计地价。
4. **加计扣除基数**：加计 **20%** 基数是"**地价＋开发成本**"，**不含费用和税金**；购房契税**不作加计5%基数**。
5. **契税纳税人搞反**：向**承受方**征；互换由**付差价方**按差额缴，不是双方各按全额。
6. **城建税依据多算**：进口环节及境外向境内销售劳务服务无形资产的"两税"**不计**；滞纳金罚款**不作**依据；先征后返**不退**。
7. **车船税与车辆购置税混淆**：车船税是**持有环节按年**，车辆购置税是**购置环节一次性**。
8. **环保税减半与免征**：一月内超标不足 **15天** 是**减半**；农业生产**暂免**但**规模化养殖不免**。
9. **资源税混合扣减**：外购＋自采**直接混合销售**可直接扣；**洗选加工为选矿**必须先乘"**原矿税率÷选矿税率**"折算。
