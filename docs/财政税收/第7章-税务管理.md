# 第7章 税务管理

> **本章考情**：考点突出的一般章节。考试分值 **6-7 分** / **约 9 分**（约 9 分口径为单项选择题 5 道 5 分 + 多项选择题 2 道 4 分，共 7 道；各家统计不一，以当年真题为准）；题型为**单选题、多选题**（本部分不涉及案例分析题）。本章以**记忆型考点**为主，不涉及复杂计算，但数字类考点（期限、比例、金额）极多，需结合实务经验在理解基础上记忆。
> **高频考点**：税款征收措施；纳税信用评价；税务行政复议。

## 二、知识点精讲

### 考点1 税务登记 ★★★

**核心概念**：税务登记管理包括**设立税务登记、变更税务登记、注销税务登记、停业复业登记**四类。"多证合一""两证整合"改革**并未取消税务登记**，税务登记的法律地位依然有效，而是通过部门信息共享实现流程整合。

**（1）设立税务登记**

| 主体 | 登记制度 | 内容 |
|---|---|---|
| 企业、农民专业合作社 | **"五证合一、一照一码"** | 整合原工商营业执照、组织机构代码证、税务登记证、社会保险登记证、统计登记证 |
| 个体工商户 | **"两证整合"** | 工商营业执照 + 税务登记证 |
| 未纳入上述制度的纳税人 | 纳税人身份信息报告 | 向生产、经营所在地税务机关申报办理，履行法定税务登记义务 |
| 从事生产、经营的个人 | 临时税务登记 | 应办而未办营业执照，但发生纳税义务的，可按规定申请办理 |

关键结论：由**市场监督管理部门**统一受理并核发加载**统一社会信用代码**的营业执照；该营业执照具备**税务登记证件**的法律效力，**统一社会信用代码即为纳税人识别号**。

**（2）变更税务登记**：纳税人税务登记内容发生变化的，应当向原税务登记机关申报办理变更税务登记。**自 2023 年 4 月 1 日起**，纳税人在市场监督管理部门依法办理变更登记后，**无须向税务机关报告登记变更信息**（税务机关根据共享信息在核心征管系统自动同步变更；处于非正常、非正常户注销等状态的，在其恢复正常状态时自动变更）。

**（3）注销税务登记**

| 情形 | 时限 |
|---|---|
| 解散、破产、撤销等依法终止纳税义务 | 向市场监管等机关办理注销登记**前**，向原税务登记机关申报 |
| 不需在市场监管等机关办理注册登记 | 自有关机关批准或宣告终止之日起 **15 日内** |
| 被吊销营业执照或被撤销登记 | 自吊销/撤销之日起 **15 日内** |
| 境外企业在境内承包建筑、安装、装配、勘探工程和提供劳务 | 项目完工、离开中国前 **15 日内** |
| **例外**：因住所、经营地点变动涉及改变税务登记机关 | 自注销税务登记之日起 **30 日内**向迁达地税务机关申报办理税务登记 |

注销前须结清应纳税款、多退（免）税款、滞纳金和罚款，缴销发票、税务登记证件和其他税务证件。

**（4）停业、复业登记**：实行**定期定额征收方式**的个体工商户需要停业的，应当在停业**前**申报办理停业登记；**停业期限不得超过 1 年**。

**逻辑链**：

```
设立（一照一码 / 两证整合 / 临时登记）
   ↓ 内容变化
变更（2023.4.1 起：市场监管变更后无须向税务机关报告，系统自动同步）
   ↓ 终止义务
注销（一般 15 日内；迁址例外 30 日内；先结清税款滞纳金罚款、缴销发票证件）
   ↕
停业 / 复业（仅限定期定额征收的个体工商户；停业期 ≤ 1 年）
```

**速记口诀**：**"企业一照一码五个证，个体两证整合一张照；变更系统自动同步，注销十五日是常规、迁址三十天；停业只一年，个体户定期定额才行。"**

### 考点2 账簿、凭证管理 ★★★

**核心概念**：账簿包括**总账、明细账、日记账和其他辅助性账簿**。凭证管理范围包括**会计凭证**和**税收凭证**两大类。

**（一）账簿的设置要求**

| 主体 | 设置要求 | 时限 |
|---|---|---|
| 从事生产、经营的纳税人 | 设置账簿 | 自领取营业执照或者发生纳税义务之日起 **15 日内** |
| 扣缴义务人 | 按所代扣、代收的税种，**分别设置**代扣代缴、代收代缴税款账簿 | 自扣缴义务发生之日起 **10 日内** |
| 生产、经营规模小又确无建账能力的纳税人 | ① 聘请经批准从事会计代理记账业务的专业机构或经税务机关认可的财会人员代为建账和办理账务；② 聘请有实际困难的，经**县以上税务机关批准**，建立**收支凭证粘贴簿、进货销货登记簿**或**使用税控装置** | — |

补充：纳税人、扣缴义务人会计制度健全，能通过计算机正确、完整计算收入和所得的，其计算机输出的完整的书面会计记录**可视同会计账簿**；会计制度不健全的，应当建立**总账**及与纳税或代扣代缴、代收代缴税款有关的明细账等其他账簿。

**（二）账簿的使用要求**

账簿、收支凭证粘贴簿、进销货登记簿等资料，除另有规定外**至少保存 10 年**，未经税务机关批准不得销毁；保管期满需要销毁时，应编造**销毁清册**，报**主管部门和税务机关**批准，然后在其监督下销毁。

**（三）凭证管理**

| 类别 | 分类 | 要点 |
|---|---|---|
| **会计凭证** | 原始凭证 | 按取得渠道分自制/外来原始凭证；按填制手续分一次凭证/累计凭证。**金额有错误的，由出具单位重开，不准更正**；其他错误由出具单位重开或更正，**更正处应加盖公章**。我国会计核算的主要原始凭证包括发票、行政性收费收据 |
| | 记账凭证 | 按记录经济内容分收款凭证、付款凭证、转账凭证。应**连续编号**；根据每张原始凭证或若干张同类原始凭证汇总填制；**必须附原始凭证并注明张数**；共同负担费用可由保存原始凭证单位填开**费用分割单**；填制错误可用**红字注销法**更正 |
| **税收凭证** | **完税凭证类** | 各种**完税证和缴款书**，是纳税人依法缴纳税款后税务机关出具的完税证明 |
| | **综合凭证类** | 各种提退减免凭证、罚款收据、票款结算单、代扣代缴税款专用发票、**纳税保证金收据、税票调换证**等 |

**速记口诀**：**"设置账簿十五天，扣缴十天分别建；小户代账或粘贴簿，县以上批准才可行。资料至少存十年，销毁清册报双批。金额错了必须重开，其他错误盖章更正。完税凭证证和书，综合凭证一大类。"**

### 考点3 发票管理 ★★★★

**核心概念**：发票**印制管理是发票管理的基础环节**。

**（一）发票印制管理**

| 项目 | 要求 |
|---|---|
| 印制企业 | **增值税专用发票**由国务院税务主管部门确定的企业印制；**其他发票**由省、自治区、直辖市税务机关确定的企业印制 |
| 防伪 | 使用国务院税务主管部门确定的全国统一的**发票防伪专用品** |
| 监制章 | 套印**全国统一发票监制章** |
| 换版 | 实行**不定期换版**制度 |
| 文字 | 使用**中文**印制；民族自治地方可加印当地一种通用民族文字；有实际需要的可同时使用中外两种文字 |

**（二）发票领用管理**

| 情形 | 手续 |
|---|---|
| 固定业户领用 | 持**税务登记证件（设立登记证件）+ 经办人身份证明**，向**主管税务机关**办理；领用纸质发票还应提供按规式样制作的**发票专用章印模**。主管税务机关根据经营范围、规模和风险等级，在 **5 个工作日内**确认领用发票的种类、数量以及领用方式 |
| 临时经营领用 | 凭购销商品、提供或接受服务等书面证明 + 经办人身份证明，**直接向经营地税务机关申请代开发票**；按规定应缴纳税款的，**先征收税款，再开具发票** |
| 跨地区经营领用 | 凭**所在地税务机关的证明**，向**经营地税务机关**领用经营地的发票 |

领用方式：**批量供应、交旧领新、验旧领新、额度确定**。

**（三）发票的开具和保管**

- 一般情况下**收款方**向付款方开具发票；特殊情况下由付款方向收款方开具。
- 取得发票时**不得要求变更品名和金额**（含不得变更涉及金额计算的单价和数量）。
- 不符合规定的发票，不得作为财务报销凭证，任何单位和个人有权拒收。
- 按规定的时限、顺序、栏目，**全部联次一次性如实开具**，开具纸质发票应加盖**发票专用章**。
- 纸质发票限于领用单位和个人在**本省、自治区、直辖市内**开具。
- **已经开具的发票存根联和发票登记簿，应当保存 5 年**。

**虚开发票的三种行为**：①为他人、为自己开具与实际经营业务情况不符的发票；②让他人为自己开具与实际经营业务情况不符的发票；③介绍他人开具与实际经营业务情况不符的发票。

**（四）电子发票（数电发票）管理**

- 电子发票的法律效力、基本用途与纸质发票相同，任何单位和个人不得拒绝。
- **2024 年 12 月 1 日起，数电发票在全国正式推广应用。**
- 数电发票：票面要素全面数字化、号码全国统一赋予、开票额度智能授予、通过税务数字账户自动流转；**与纸质发票具有同等法律效力**；为**单一联次**，以数字化形态存在。
- 类别：电子发票（增值税专用发票）、电子发票（普通发票）、电子发票（航空运输电子客票行程单）、电子发票（铁路电子客票）、电子发票（机动车销售统一发票）、电子发票（二手车销售统一发票）等；可根据特定业务标签生成建筑服务、成品油、报废产品收购等特定业务发票。
- 税务机关对电子发票开票金额实行**额度管理**，依据税收风险程度、纳税（缴费）信用级别、实际经营情况等因素确定开票额度，并动态调整；建设全国统一的电子发票服务平台，提供免费的开票、用票服务。

**速记口诀**：**"专票总局定企业，其他发票省局定；监制章加防伪品，不定期换版。五工作日确认领用量，临时先征税后开票，跨地区凭证明。存根联登记簿，保存五年不能少。数电二零二四年十二月一日全国推，单一联次同等效力。"**

### 考点4 纳税申报 ★★★

**（一）纳税申报对象**

| 对象 | 要求 |
|---|---|
| 负有纳税义务的单位和个人 | 发生纳税义务后，按税法规定或税务机关核定期限，如实向主管税务机关办理 |
| 取得临时应税收入或发生应税行为的纳税人 | **立即**向经营地税务机关办理纳税申报并缴纳税款 |
| 享有减税、免税待遇的纳税人 | 在减税、免税期间**也应当依法**办理纳税申报 |
| 扣缴义务人 | 在法律、法规规定或税务机关确定的申报期限内报送代扣代缴、代收代缴税款报告表 |

**（二）纳税申报内容**：财务会计报表及其说明材料；与纳税有关的合同、协议书及凭证；税控装置的电子报税资料；外出经营活动税收管理证明和异地完税凭证；境内或境外公证机构出具的有关证明文件；税务机关规定应当报送的其他有关证件、资料。申报表主要内容还包括**税款所属期限、延期缴纳税款、欠税、滞纳金**等。

**（三）纳税申报方式**：**直接申报（上门申报）、邮寄申报、数据电文申报、委托代理申报**。邮寄申报以**寄出的邮戳日期**为实际申报日期。

**（四）纳税申报期限**：因税种和缴纳税额不同而不同。最后一天是法定节假日的，以**休假日期满的次日**为期限的最后一天。因**不可抗力**不能按期办理的，可以延期办理，但应当在不可抗力情形消除后**立即**向税务机关报告。

**提示**：实行**定期定额**缴纳税款的纳税人，可以实行**简易申报、简并征期**等申报纳税方式。

**速记口诀**：**"四类对象都要报，免税期间照样报；临时收入立即报。四种方式：直接、邮寄、数据电文、委托代理；邮戳日期算邮寄。定期定额可简易申报、简并征期。"**

### 考点5 涉税信息报送管理 ★★★★（新增考点）

**核心概念**：纳税人、扣缴义务人和其他有关单位应当按照国家有关规定如实向税务机关提供与纳税和代扣代缴、代收代缴税款有关的信息。《互联网平台企业涉税信息报送规定》明确了**互联网平台企业**向主管税务机关报送平台内经营者和从业人员身份信息、收入信息等涉税数据的**法定义务**。

| 项目 | 内容 |
|---|---|

### 考点6 税款征收方式 ★★

**核心概念**：税务机关根据保证国家税款及时足额入库、方便纳税人、降低税收成本的原则，确定税款征收方式。常见征收方式有 **4 种**。

| 征收方式 | 含义 | 适用 |
|---|---|---|
| **查账征收** | 税务机关按照纳税人提供的账表所反映的生产、经营情况，依照适用税率计算缴纳税款 | 会计制度健全、能完整准确提供纳税资料的纳税人 |
| **核定征收** | 税务机关对不能完整、准确提供纳税资料的纳税人，采用特定方法确定其应纳税收入或应纳税额，纳税人据以缴纳 | 不能完整、准确提供纳税资料 |
| **代扣代缴与代收代缴** | 代扣代缴：在**支付款项时**，代税务机关从支付给负有纳税义务的单位和个人的收入中**扣留**并解缴；代收代缴：在**收取款项时**，代税务机关向负有纳税义务的单位和个人**收取**并缴纳 | 税收法律、行政法规已明确规定负有扣缴义务的单位和个人 |
| **委托代征** | 税务机关根据有利于税收控管和方便纳税的原则，委托有关单位和人员代征零星、分散和异地缴纳的税收；受托单位和人员按委托代征证书要求，**以税务机关的名义**依法征收税款，纳税人不得拒绝 | 零星、分散和异地缴纳的税收 |

**核定应纳税额的 4 种方法**：① 参照当地同类行业或类似行业中经营规模和收入水平相近的纳税人的收入额和利润率核定；② 按照营业收入或成本加合理费用和利润核定；③ 按照耗用的原材料、燃料、动力等推算或测算核定；④ 按照其他合理的方法核定。一种方法不足以正确核定应纳税额时，可以**同时采用两种以上**方法核定。

**关联企业的税收调整制度**

- **关联企业认定**：① 在资金、经营、购销等方面存在直接或间接的拥有或控制关系；② 直接或间接地同为第三者拥有或控制；③ 在利益上具有相关联的其他关系。
- **计税依据调整方法**：① 按独立企业之间进行相同或类似业务活动的价格；② 按再销售给无关联关系的第三者的价格所应取得的收入和利润；③ 按成本加合理费用和利润；④ 其他合理方法。
- **调整期限**：自该业务往来发生的纳税年度起 **3 年内**进行调整；有特殊情况的，可以自该业务往来发生的纳税年度起 **10 年内**进行调整。

**其他配套制度**：税务机关按照规定付给扣缴义务人代扣、代收手续费；扣缴义务人代扣、代收税款时，**必须给纳税人开具完税凭证**。

**减免税的管理**：税收的开征、停征以及减税、免税、退税、补税，依照**法律**的规定执行；法律授权国务院规定的，依照**国务院制定的行政法规**的规定执行。地方各级人民政府、各级人民政府主管部门、单位和个人违反法律、行政法规规定，擅自作出的减税、免税决定**无效**，**税务机关不得执行**，并向上级税务机关报告。

**速记口诀**：**"查账、核定、代扣代收、委托代征四种；核定四法可并用。关联调整三年常规、十年特殊。减免税：法律→行政法规，地方擅自决定无效。"**

### 考点7 税款征收措施 ★★★★（本章核心）

#### （一）应纳税额的核定

**税务机关有权核定应纳税额的情形（6 种）**：

1. 依照法律、行政法规的规定**可以不设置账簿**的；
2. 依照法律、行政法规的规定**应当设置但未设置账簿**的；
3. **擅自销毁账簿**或者拒不提供纳税资料的；
4. 虽设置账簿，但**账目混乱**或者成本资料、收入凭证、费用凭证残缺不全，**难以查账**的；
5. 发生纳税义务，未按照规定的期限办理纳税申报，经税务机关责令限期申报，**逾期仍不申报**的；
6. 纳税人申报的**计税依据明显偏低，又无正当理由**的。

> 【巧思妙记】1. 账簿有问题；2. 申报有问题；3. 计税依据有问题。

#### （二）纳税担保

**含义**：税务机关为了保证纳税人发生纳税义务后确实履行纳税义务，而要求纳税人自行提供保证及时足额上缴税款的措施。

**适用情形**：① 税务机关有根据认为从事生产、经营的纳税人有逃避纳税义务行为的，责令限期缴纳税款，在限期内发现纳税人有明显的转移、隐匿其应税收入迹象的；② **欠缴税款的纳税人需要出境的**；③ 纳税人同税务机关在纳税上发生争议，需要申请行政复议的；④ 法律法规规定可以提供纳税担保的其他情形。

**担保范围**：**税款、滞纳金和实现税款、滞纳金的费用**（包括抵押、质押登记费用，质押保管费用，以及保管、拍卖、变卖担保财产等相关费用支出）。用于纳税担保的财产、权利的价值**不得低于**应当缴纳的税款、滞纳金，并考虑相关费用。

**三种担保形式对比**：

| 形式 | 是否转移财产占有 | 内容 | 可担保财产 |
|---|---|---|---|
| **纳税保证** | 不涉及财产占有 | 纳税保证人向税务机关保证，当纳税人未按规定期限缴清税款、滞纳金时，由保证人按约定履行缴纳义务。为**连带责任保证** | — |
| **纳税抵押** | **不转移**财产占有 | 纳税人或纳税担保人将其财产作为税款及滞纳金的担保，逾期未缴的税务机关有权依法处置 | 动产、不动产（抵押人所有或依法有权处分的国有房屋和其他地上定着物、机器、交通运输工具和其他财产等） |
| **纳税质押** | **移交**税务机关占有 | 经税务机关同意，纳税人或纳税担保人将其动产或权利凭证移交税务机关占有作为担保。分为**动产质押**和**权利质押** | 现金以及其他除不动产以外的财产；汇票、支票、本票、债券、存款单等权利凭证 |

**纳税保证人资格**：在中国境内具有纳税担保能力的自然人、法人或其他经济组织。法人或其他经济组织**财务报表资产净值超过需要担保的税额及滞纳金 2 倍以上**的；自然人、法人或其他经济组织所拥有或者依法可以处分的**未设置担保的财产的价值超过**需要担保的税额及滞纳金的，被视为具有纳税担保能力。**国家机关，学校、幼儿园、医院等事业单位，社会团体不得作为纳税保证人**；企业法人的职能部门不得作为纳税保证人；企业法人的分支机构有法人书面授权的，可以在授权范围内提供纳税担保。

#### （三）税收保全措施 vs 税收强制执行措施

| 对比项 | 税收保全措施 | 税收强制执行措施 |
|---|---|---|
| 含义 | 对可能由于纳税人的行为或某种客观原因致使以后税款征收不能保证或难以保证的案件，采取**限制纳税人处理或转移**商品、货物或其他财产的措施 | 纳税人不履行纳税义务时，有关国家机关采用强制手段**强迫**纳税人履行纳税义务的行为 |
| 适用对象 | **仅限于从事生产、经营的纳税人**；不包括非从事生产经营的纳税人，也不包括扣缴义务人和纳税担保人 | 未按规定期限缴纳或解缴税款，经责令限期缴纳、逾期仍未缴纳的从事生产、经营的纳税人、**扣缴义务人和纳税担保人** |
| 前提条件 | ① 纳税人有逃避纳税义务的行为；② 必须在**规定的纳税期之前和责令限期缴纳应纳税款的期限内** | 经税务机关责令限期缴纳，**逾期仍未缴纳** |
| 批准权限 | 经**县级以上税务局（分局）局长**批准 | 经**县级以上税务局（分局）局长**批准 |
| 措施 | ① 书面通知开户银行或其他金融机构**冻结**相当于应纳税款的存款；② **扣押、查封**价值相当于应纳税款的商品、货物或其他财产 | ① 书面通知开户银行或其他金融机构从其存款中**扣缴税款**；② **扣押、查封、拍卖或变卖**价值相当于应纳税款的商品、货物或其他财产，以拍卖或变卖所得**抵缴税款** |
| 不适用范围 | 个人及其所扶养家属维持生活必需的住房和用品、**单价 5000 元以下**的生活用品 | 个人及其所扶养家属维持生活必需的住房和用品、**单价 5000 元以下**的生活用品 |
| 滞纳金 | — | 对未缴纳的**滞纳金同时强制执行** |

**补充要点**：拍卖或变卖所得抵缴税款、滞纳金、罚款以及扣押、查封、保管、拍卖、变卖等费用后，**剩余部分应当在 3 日内退还被执行人**。

> 【巧思妙记】保全＝**冻结、查封、扣押**（"冻封扣"，事前防转移）；强制＝**扣缴、拍卖变卖抵缴**（"扣拍卖"，事后强履行）。

#### （四）税款追征与退还

| 产生原因 | 追征处理 |
|---|---|
| 因**税务机关的责任**致使未缴或少缴 | 税务机关在 **3 年内**可以要求纳税人、扣缴义务人补缴税款，但**不得加收滞纳金** |
| 因**纳税人、扣缴义务人计算错误等失误** | 税务机关在 **3 年内**可以追征税款、滞纳金；有特殊情况的，追征期可以延长到 **5 年** |
| **偷税、抗税、骗税** | **无限期追征**（不受规定期限限制） |

| 情形 | 退还时限 |
|---|---|
| **纳税人发现**多缴税款 | 自结算缴纳税款之日起 **3 年内**要求退还，可要求加算银行同期存款利息，税务机关查实后立即退还 |
| **税务机关发现**多缴税款 | **应当立即退还** |

#### （五）延期缴纳税款制度

纳税人未按照规定期限缴纳税款的，税务机关除责令限期缴纳外，从滞纳税款之日起，**按日加收滞纳税款 0.5‰ 的滞纳金**。纳税人因有特殊困难不能按期缴纳税款的，经**省、自治区、直辖市税务局**批准，可以延期缴纳税款，但**最长不得超过 3 个月**。

**特殊困难**：① 因不可抗力，导致纳税人发生较大损失，正常生产经营活动受到较大影响的；② 当期货币资金在扣除应付职工工资、社会保险费后，不足以缴纳税款的。

#### （六）欠税清缴制度

- 欠缴税款的纳税人或者其法定代表人需要出境的，应当在出境前结清应纳税款、滞纳金或者提供担保；对未结清税款、滞纳金又不提供担保的，税务机关可以通知出境管理机关阻止其出境。
- **税收优先权**：**税收优先于无担保债权**（法律另有规定的除外）；欠缴税款发生在以其财产设定抵押、质押或被留置**之前**的，税收先于抵押权、质权、留置权执行；欠缴税款同时又被处以罚款、没收违法所得的，**税收优先于罚款、没收违法所得**。
- 欠税及滞纳金**不再要求同时缴纳**，可要求先行缴纳欠税，再依法缴纳滞纳金。
- 欠税人怠于行使到期债权、放弃到期债权、无偿或明显不合理低价转让财产，对国家税收造成损害的，税务机关可以行使**代位权、撤销权**，但不免除其尚未履行的纳税义务和法律责任。
- 破产清算中的欠税管理：所欠税款、社会保险费按企业破产法**单独申报**；税款滞纳金、利息按**普通破产债权**申报；社会保险费滞纳金、罚款按规定申报。

**逻辑链（征收措施全流程）**：

```
账簿有问题 / 申报有问题 / 计税依据偏低无理由
        ↓
税务机关核定应纳税额（4 种方法，可并用）
        ↓
可能逃税 → 责令限期缴纳 → 限期内发现转移隐匿迹象
        ↓
责成提供纳税担保（保证 / 抵押 / 质押）
        ↓ 拒不提供或无力提供
税收保全（冻结存款 + 扣押查封）  ← 仅限从事生产经营的纳税人，事前
        ↓ 逾期仍不缴
税收强制执行（扣缴存款 + 拍卖变卖抵缴） ← 含扣缴义务人、纳税担保人，事后
        ↓
少缴税款 → 追征（税局责任 3 年不加滞纳金 / 纳税人失误 3 年可延至 5 年 / 偷抗骗无限期）
多缴税款 → 退还（纳税人发现 3 年内 + 利息 / 税务机关发现立即退）
```

**速记口诀**：**"保全冻封扣、强制扣拍卖；对象不同要记牢，保全只限生产经营纳税人。追征三、五、无限期；税局责任不加滞纳金。欠税先税后费（债权、抵押、罚款）。"**

### 考点8 纳税缴费信用评价 ★★★

**核心概念**：2026 年新教材本节为「**纳税缴费信用管理**」（原「纳税信用管理」）。《纳税缴费信用管理办法》适用于**已办理税务信息确认、身份信息报告，从事生产、经营的企业纳税人缴费人（以下简称经营主体）**；**个体工商户和从事生产、经营的其他类型纳税人缴费人可自愿申请纳入**。

> **教材变动提示（须并列核对）**：原《纳税信用管理办法（试行）》适用于**已办理税务登记，从事生产、经营并适用查账征收的企业纳税人**，暂不包括扣缴义务人与自然人；非独立核算分支机构可自愿参与纳税信用评价。新旧办法适用对象表述不同，请以现行教材为准。

**管理体制**：**国家税务总局**主管全国纳税缴费信用管理工作；**省以下税务机关**负责所辖地区纳税缴费信用管理工作的组织和实施。

**信用信息采集**（三类）：

| 信息类型 | 内容 |
|---|---|
| 信用基本信息 | 经营主体的基础信息和纳税缴费信用历史记录 |
| 税务内部信息 | **经常性指标信息**（税费申报信息、税费款缴纳信息、发票与税控器具信息、登记与账簿信息等）+ **非经常性指标信息**（税务检查信息等） |
| 外部信息 | **外部参考信息**（相关部门评定的优良信用记录和不良信用记录）+ **外部评价信息**（从相关部门取得的影响评价的指标信息） |

采集工作由国家税务总局和省税务机关组织实施；信用基本信息、税务内部信息从**税务管理系统**中采集，外部信息主要通过税务管理系统、国家统一信用信息平台、部门间数据交换等渠道采集（旧办法：纳税信用信息**按月**采集）。

**评价方式**：**年度评价指标得分 + 直接判级**。评价指标包括税务内部信息和外部评价信息。

- **年度评价指标得分**采取**扣分方式**：经常性指标和非经常性指标信息齐全的，从 **100 分**起评；非经常性指标缺失、经常性指标中纳税缴费信息齐全的，从 **93 分**起评；不齐全的，从 **90 分**起评。（93 分为【教材变动】新增起评分；旧办法为"齐全 100 分起评、非经常性指标缺失 90 分起评"）
- **直接判级**：适用于**首次在税务机关办理税费事宜的经营主体（新设立经营主体）**或者**有严重失信行为的经营主体**。
  - 【教材变动】旧办法中直接判级仅适用于有严重失信行为的纳税人。

**信用级别（A、B、M、C、D 五级）**：

| 级别 | 分值/条件 |
|---|---|
| **A 级** | 年度评价指标得分 **90 分以上** |
| **B 级** | 年度评价指标得分 **70 分以上不满 90 分** |
| **M 级** | **新设立经营主体**，或者年度评价指标得分 70 分以上但**评价年度内无生产经营业务收入**的 |
| **C 级** | 年度评价指标得分 **40 分以上不满 70 分** |
| **D 级** | 年度评价指标得分**不满 40 分**或者有严重失信行为的 |

> 【教材变动】M 级为新增级别。旧办法仅设 A、B、C、D 四级。

**评价周期**：一个**公历年度**。距首次在税务机关办理税费事宜时间**不满一个评价年度**的经营主体，**不参加本期年度评价**。

**本评价年度不能评为 A 级的 4 种情形**：① 实际生产经营期**不满 3 年**的；② 上一评价年度评价结果为 **D 级**的；③ 非正常原因一个评价年度内增值税**连续 3 个月或者累计 6 个月**零申报、负申报的；④ 不能按照国家统一的会计制度规定设置账簿，并根据合法、有效凭证核算，向税务机关提供准确税务资料的。

**直接判为 D 级的情形**（新办法，13 项）：① 存在逃避追缴欠税、骗取出口退税、虚开增值税专用发票、骗取留抵退税等税收违法行为；② 存在逃避缴纳税款、虚开增值税专用发票以外的其他发票等违法行为，被移送公安机关或被公安机关直接立案查处；③ 偷税（逃避缴纳税款）金额 **10 万元以上且占各税种应纳税总额 10% 以上**；④ 在规定期限内未按税务机关处理结论足额缴纳税款、利息、滞纳金和罚款；⑤ 以暴力、威胁方法拒不缴纳税款或拒绝、阻挠税务机关依法实施税务稽查执法行为；⑥ 违反发票管理法规，导致其他单位或个人未缴、少缴或骗取税款；⑦ 提供虚假材料，骗取税收优惠；⑧ 骗取国家出口退税款，被停止出口退（免）税资格未到期；⑨ 认定为非正常户或走逃（失联）户；⑩⑪ 由非正常户、走逃（失联）户或 D 级经营主体的直接责任人员在相应认定之后注册登记、负责经营；⑫ 被确定为重大税收违法失信主体；⑬ 存在税务机关依法认定的其他严重失信情形。

**不影响评价的 3 种情形**：① 由于税务机关原因或者不可抗力，造成未能及时履行纳税缴费义务的；② 由于**非主观故意的计算公式运用错误以及明显的笔误**，造成未缴或者少缴税费款的；③ 国家税务总局认定的其他不影响评价的情形。

**速记口诀**：**"九十七十四十，A/B/M/C/D 五级；M 级新设或无收入。起评一百分，缺非经常性九十三，再不齐九十。三年一期 D 级不能评 A，连续三月累计六月零负申报。不影响评价：税局原因、不可抗力、笔误公式错。"**

### 考点9 纳税缴费信用结果的应用与修复 ★★

**确定和发布**：遵循**谁评价、谁确定、谁发布**的原则。税务机关原则上**每年 4 月**确定上一年度评价结果，并提供**自我查询**服务。对级别实行**动态调整**；按分级分类原则，**主动公开 A 级**名单，逐步开放 B、M、C、D 级名单，定期或不定期公布重大税收违法案件信息。

**复评（核）**：① 年度评价结果确定前对扣分或判级情况有异议的，可在评价年度**次年 3 月**申请复核；② 对评价结果有异议的，可在次年年度评价前申请复评，主管税务机关自受理申请之日起 **15 个工作日内**完成复评；③ 因距首次办理税费事宜不满一个评价年度未参加年度评价的，可在纳入管理满 **12 个月**后申请复评，并于受理申请的**次月**完成复评。

**分类服务和管理（守信激励、失信惩戒）**：

| 级别 | 管理措施 |
|---|---|
| **A 级** | ① 主动向社会公布 A 级名单；② **下一年度起评分提高 1 分**，连续评为 A 级的可累积提高，起评分最高不超过 100 分；③ 可以一次领取**不超过 3 个月**的增值税发票用量，需要调整可即时办理，其他普通发票按需领用，符合条件的可按规定申请按需开具数电发票；④ **连续 3 年评为 A 级**的，还可提供绿色通道或专门人员辅导办理税费事项；⑤ 联合激励措施及结合当地实际的其他激励措施 |
| **B 级** | 适时进行税费政策和管理规定辅导，并视信用评价状态变化趋势参考 A 级激励措施（旧办法：实施正常管理） |
| **M 级** | 适时进行税费政策和管理规定的辅导 |
| **C 级** | 依法从严管理，并视信用评价状态变化趋势选择性地采取有关管理措施 |
| **D 级** | ① 对直接责任人员在经营主体被评价为 D 级之后注册登记、负责经营的其他经营主体直接判为 D 级；② 结合风险评估情况，**限额限量领用增值税专用发票，限制数电发票额度**；普通发票领用实行交（验）旧领新、严格限量供应；③ 列入重点监控对象，加强信用监管；④ 除关联 D 级外，因直接判级评为 D 级的，**D 级评价保留至第 2 年，第 3 年不得评为 A 级**；因年度评价指标得分评为 D 级的，**次年评价时加扣 11 分**；⑤ 依法依规将 D 级评价结果提供相关部门，并结合实际采取其他严格管理措施 |

> **教材变动提示**：新办法将"D 级评价保留 2 年，第三年纳税信用不得评价为 A 级"表述为"D 级评价保留至第 2 年，第 3 年不得评为 A 级"，并新增"因年度评价指标得分评为 D 级的，次年评价时加扣 11 分"。旧办法还含公开 D 级纳税人及其直接责任人员名单、加强出口退税审核、严格审核报送资料等措施，请以现行教材为准。

**纳税信用修复**：失信行为已记入评价结果的，可在**次年年度评价前**申请修复，主管税务机关自受理申请之日起 **15 个工作日内**完成修复；失信行为尚未记入评价结果的，**无需提出申请**，税务机关在年度评价时统一更新结果。旧办法列举的修复情形包括：未按法定期限办理纳税申报、税款缴纳、资料备案等事项且已补办的；未按处理结论缴纳或足额缴纳税款、滞纳金、罚款，未构成犯罪被直接判 D 级，在处理结论明确期限期满后 **60 日内**足额缴纳补缴的；依法解除非正常户状态的；破产企业或其管理人在重整或和解程序中已依法缴纳税款、滞纳金、罚款并纠正失信行为的；等等。
**速记口诀**：**"A 级激励：公布名单、起评分加一分、发票领三个月、三连 A 绿色通道；D 级惩戒：限量发票、重点监控、保留到第二年、第三年不评 A，得分判 D 次年加扣十一分。"**

### 考点10 税务行政复议 ★★★★

**核心概念**：税务行政复议是指当事人（纳税人、扣缴义务人、纳税担保人及其他税务当事人）不服税务机关及其工作人员作出的税务具体行政行为，依法向上一级税务机关（复议机关）提出申请，复议机关经审理对原税务机关具体行政行为依法作出维持、变更、撤销等决定的活动。复议机关受理行政复议申请，**不得向申请人收取任何费用**；在申请人的行政复议请求范围内，**不得作出对申请人更为不利的行政复议决定**。

**（一）范围：分清必经复议和选择复议**

> 【巧思妙记】**必经复议：与征税有关；选择复议：与征税无关。**

| 类型 | 范围 |
|---|---|
| **必经复议（复议前置）** | **征税行为**：① 确认纳税主体、征税对象、征税范围、减税、免税、退税、抵扣税款、适用税率、计税依据、纳税环节、纳税期限、纳税地点和税款征收方式等具体行政行为；② 征收税款、**加收滞纳金**；③ 扣缴义务人、受税务机关委托的单位和个人作出的**代扣代缴、代收代缴、代征行为** |
| **选择复议** | ① 行政许可、行政审批行为；② 发票管理行为（发售、收缴、代开发票等）；③ 税收保全措施、强制执行措施；④ 行政处罚行为（罚款、没收财物和违法所得、停止出口退税权）；⑤ 不依法履行职责的行为（开具出具完税凭证、跨区域涉税事项相关证明、行政赔偿、行政奖励、颁发税务登记等）；⑥ 资格认定行为；⑦ 不依法确认纳税担保行为；⑧ 政府信息公开工作中的具体行政行为；⑨ 纳税缴费信用等级评定行为；⑩ 通知出入境管理机关阻止出境行为；⑪ 其他具体行政行为 |

**规定的审查申请**：申请人认为具体行政行为所依据的下列规定不合法，可一并提出审查申请：① 国家税务总局和国务院其他部门的规定；② 其他各级税务机关的规定；③ 地方各级人民政府的规定；④ 地方人民政府工作部门的规定。**此处规定不包括规章。**

**（二）税务行政复议管辖**

| 作出行政行为的税务机关 | 复议机关 |
|---|---|
| 各级税务局 | 向**上一级税务局** |
| 计划单列市税务局 | 向**国家税务总局** |
| 税务所（分局）、各级税务局的稽查局 | 向**其所属税务局** |
| 国家税务总局 | 向**国家税务总局** |
| 两个以上税务机关以共同名义作出 | 向**共同上一级税务机关** |
| 税务机关与其他行政机关以共同名义作出 | 向其**共同上一级行政机关** |
| 被撤销的税务机关在撤销前作出的 | 向**继续行使其职权的税务机关的上一级税务机关** |
| 逾期不缴纳罚款加处罚款的决定不服 | 向**作出行政处罚决定的税务机关**；对已处罚款和加处罚款都不服的，一并向其**上一级税务机关** |

> 对国家税务总局的具体行政行为不服的，向国家税务总局申请行政复议；对行政复议决定不服的，可以向人民法院提起行政诉讼，也可以向**国务院申请裁决**，**国务院的裁决为终局裁决**。

**（三）申请人与被申请人**

| 申请人情形 | 规定 |
|---|---|
| 合伙企业 | 以**核准登记的企业**为申请人，由**执行合伙事务的合伙人**代表该企业参加 |
| 股份制企业的股东大会、股东代表大会、董事会 | 认为税务具体行政行为侵犯企业合法权益的，可以**以企业名义**申请 |
| 有权申请的公民死亡 | 其**近亲属**可以申请 |
| 有权申请的公民为无行为能力人或限制行为能力人 | 其**法定代理人**可以代理申请 |
| 法人或其他组织合并、分立或终止 | **承受其权利义务**的法人或其他组织可以申请 |
| 同一行政复议案件申请人超过 **5 人** | 应当推选 **1 至 5 名**代表参加 |

| 被申请人情形 | 规定 |
|---|---|
| 对具体行政行为不服 | **作出该具体行政行为的税务机关** |
| 对扣缴义务人的扣缴税款行为不服 | **主管该扣缴义务人的税务机关** |
| 对税务机关委托的单位和个人的代征行为不服 | **委托税务机关** |
| 税务机关与法律、法规授权的组织共同名义作出 | 税务机关和该组织为**共同被申请人** |
| 经上级税务机关批准作出 | **批准机关** |
| 经重大税务案件审理程序作出 | **审理委员会所在税务机关** |

申请人、第三人可以委托 **1-2 名**代理人参加行政复议；**被申请人不得委托本机关以外人员**参加行政复议。

**（四）申请期限与受理**

- 申请人可以在知道税务机关作出具体行政行为之日起 **60 日内**提出行政复议申请。因不可抗力或被申请人设置障碍等原因耽误法定申请期限的，应扣除被耽误时间。
- 申请期限计算：当场作出的，自作出之日起；直接送达的，自受送达人签收之日起（依法应送达而未送达的，视为不知道该具体行政行为）；邮寄送达的，自邮件签收单签收之日或送达回执签名之日起；公告形式告知的，自公告规定期限届满之日起；事后补充告知的，自收到补充告知通知之日起。- **复议前置 + 缴纳税款**：对征税行为不服申请行政复议的，**必须依照税务机关根据法律法规确定的税额、期限，先行缴纳或者解缴税款和滞纳金，或者提供相应的担保**，才可以在缴清税款和滞纳金以后或者所提供的担保得到确认之日起 **60 日内**提出行政复议申请。担保方式包括**保证、抵押和质押**。
- **受理**：行政复议机关收到申请后，应当在 **5 日内**审查，决定是否受理；未按规定期限审查并作出不予受理决定的，**视为受理**。
- **提起诉讼**：对复议前置情形，复议机关决定不予受理或受理后超过复议期限不作答复的，申请人可以自收到不予受理决定书之日起或者行政复议期满之日起 **15 日内**向人民法院提起行政诉讼。
- **诉中不议**：复议机关已受理的，在法定复议期限内不得向法院起诉；法院已依法受理的，不得申请行政复议。

**（五）审查和决定**

- 原则上采用**书面审查**；申请人提出要求或行政复议机构认为有必要时，应听取意见并可调查了解。
- **听证**：对重大、复杂案件，可采取听证方式审理；听证应当公开举行（涉及国家秘密、商业秘密或个人隐私的除外）；**听证人员不得少于 2 人**，听证主持人由行政复议机构指定；听证应制作笔录，申请人、被申请人和第三人应当确认。
- 证据：被申请人对其作出的具体行政行为**负有举证责任**；行政复议过程中，被申请人**不得自行**向申请人和其他有关组织或个人收集证据；调查取证时工作人员**不得少于 2 人**。

| 决定类型 | 适用情形 |
|---|---|
| **维持** | 认定事实清楚，证据确凿，适用依据正确，程序合法，内容适当 |
| **履行** | 被申请人不履行法定职责，决定其在一定期限内履行 |
| **撤销、变更或确认违法** | ① 主要事实不清、证据不足；② 适用依据错误；③ 违反法定程序；④ 超越职权或滥用职权；⑤ 具体行政行为明显不当。可责令被申请人在一定期限内重新作出 |

其他规定：责令重新作出具体行政行为的，被申请人**不得以同一事实和理由**作出与原具体行政行为相同或基本相同的具体行政行为（但以违反法定程序决定撤销的除外）；**不得作出对申请人更为不利的决定**（但以主要事实不清、证据不足或适用依据错误决定撤销的除外）；对重新作出的行为不服，**可以依法申请行政复议或者提起行政诉讼**。行政复议决定书**一经送达即发生法律效力**。

```
   ↓
是不是"征税行为"？
   ├── 是 → 必经复议：先缴税款和滞纳金（或提供担保）→ 60 日内申请复议 → 不服可诉讼
   └── 否 → 选择复议：可复议，也可直接诉讼
   ↓
找谁复议？（上一级税务局 / 所属税务局 / 国家税务总局 / 共同上一级）
   ↓
5 日内审查决定是否受理（逾期不决定 = 视为受理）
   ↓
书面审查（重大复杂可听证，≥2 人）→ 维持 / 履行 / 撤销变更确认违法
   ↓
对复议决定不服 → 15 日内起诉
```

**速记口诀**：**"征税行为必经复议，其他二选一；六十日内提申请，五日审查定受理；逾期不决定视为受理；不予受理十五天起诉；听证至少两个人；被申请人负举证责任。"**

### 考点11 税务行政诉讼 ★★

**核心概念**：税务行政诉讼是指公民、法人和其他组织认为税务机关及其工作人员的具体税务行政行为违法或不当，侵犯其合法权益，依法向人民法院提起的行政诉讼。

**（一）受案范围**：基本与税务行政复议的范围一致。包括：① 税务机关作出的征税行为；② 责令纳税人提交纳税保证金或提供纳税担保行为；③ 行政处罚行为；④ 通知出境管理机关阻止出境行为；⑤ 税收保全措施；⑥ 税收强制执行措施；⑦ 申请行政许可，税务机关拒绝或在法定期限内不予答复，或对其他决定不服；⑧ 税务机关的复议行为。

**（二）起诉和受理**

起诉条件：① 原告是认为具体税务行政行为侵犯其合法权益的公民、法人或其他组织；② 有明确的被告；③ 有具体的诉讼请求和事实、法律依据；④ 属于人民法院受案范围和受诉人民法院管辖。

- **复议前置**的，对复议决定不服的，可以在接到复议决定书之日起 **15 日内**向人民法院起诉；对其他具体行政行为不服的，可以在接到通知或知道之日起 **15 日内**直接起诉。
- 税务机关作出具体行政行为时**未告知当事人诉权和起诉期限**，致使当事人逾期起诉的，起诉期限从当事人实际知道诉权或起诉期限时计算，但**最长不得超过 2 年**。
- 人民法院接到诉状，经审查应当在 **7 日内**立案或者作出裁定不予受理。

**（三）审理和判决**

- 人民法院**公开审理**行政案件，但涉及**国家秘密、个人隐私**和法律另有规定的除外；涉及**商业秘密**的案件，当事人申请不公开审理的，可以不公开审理。审理的核心是审查被诉具体行政行为**是否合法**。
- **诉讼期间不停止行政行为的执行**，但下列情形裁定停止执行：① **被告认为需要停止执行**；② 原告或利害关系人申请停止执行，人民法院认为该行政行为的执行会造成**难以弥补的损失**，并且停止执行**不损害国家利益、社会公共利益**；③ 人民法院认为该执行会给国家利益、社会公共利益造成**重大损害**；④ 法律法规规定停止执行。当事人对停止执行或不停止执行的裁定不服的，可以**申请复议 1 次**。

| 判决方式 | 适用情形 |
|---|---|
| **维持判决** | 证据确凿，适用法律法规正确，符合法定程序 |
| **撤销判决** | ① 主要证据不足；② 适用法律法规错误；③ 违反法定程序；④ 超越职权；⑤ 滥用职权；⑥ 明显不当 |
| **履行判决** | 税务机关不履行或拖延履行法定职责，判决其在一定期限内履行 |
| **变更判决** | 行政处罚明显不当，或其他行政行为涉及对款额的确定、认定确有错误。判决变更**不得加重原告的义务或减损原告的权益**（利害关系人同为原告且诉讼请求相反的除外） |

**速记口诀**：**"受案范围基本同复议；起诉十五日，未告知诉权最长两年；法院七日定立案。不停止执行是原则，四种情形才停；判决四种：维持、撤销、履行、变更。"**

## 四、公式与计算

### 4.1 滞纳金计算

**公式**：

```
滞纳金 = 滞纳税款 × 0.5‰ × 滞纳天数
（从滞纳税款之日起，按日加收；0.5‰ 即每日万分之五）
```

**滞纳天数**：自缴纳期限届满的次日起，至实际缴纳税款之日止（含起算日，不含截止日）。

> **【定案】** 税收滞纳金按日加收滞纳税款的 **0.5‰（万分之五）**（《税收征管法》第32条）。个别来源写作"0.5%"系笔误，一律以 0.5‰ 为准。

**【演算例题 1】** 某纳税人应于 2026 年 3 月 15 日缴纳增值税 20 万元，因资金紧张迟至 2026 年 4 月 5 日才缴清。计算应加收的滞纳金。

```
滞纳期间：3 月 16 日 ~ 4 月 5 日
  3 月 16 日—3 月 31 日 = 16 天
  4 月 1 日—4 月 5 日   =  5 天
  合计 = 21 天

滞纳金 = 200 000 × 0.5‰ × 21
       = 200 000 × 0.0005 × 21
       = 100 元/天 × 21 天
       = 2 100 元
```

**答：应加收滞纳金 2 100 元。**

### 4.2 税款补征 / 追征期限

**规则表**：

| 少缴原因 | 追征期限 | 是否加收滞纳金 |
|---|---|---|
| 税务机关的责任 | **3 年内**可要求补缴 | **不得**加收 |
| 纳税人、扣缴义务人计算错误等失误 | **3 年内**可追征税款；有特殊情况延长到 **5 年** | 可以追征 |
| 偷税、抗税、骗税 | **无限期追征**（不受规定期限限制） | 可以追征 |

**【演算例题 2】** 某企业因自身计算错误，少缴 2021 年度企业所得税 50 万元（税款缴纳期限为 2022 年 5 月 31 日）。税务机关于 2026 年 6 月开展检查时发现该笔少缴税款。问：税务机关能否追征？追征期如何计算？

```
判断步骤：
① 少缴原因：纳税人计算错误 → 一般追征期 3 年（至 2025 年 5 月 31 日）
② 发现时间：2026 年 6 月 → 已超过 3 年，但未超过 5 年（至 2027 年 5 月 31 日）
③ 结论：属于"有特殊情况"，追征期可延长到 5 年，税务机关在 5 年内
   仍可追征税款 50 万元及滞纳金。

对照：若属于税务机关责任致少缴 → 3 年内可要求补缴，不得加收滞纳金；
      若属于偷税、抗税、骗税 → 无限期追征。
```

**答：可以追征。追征期按"特殊情况"延长到 5 年，可追征税款 50 万元并加收滞纳金。**

### 4.3 纳税担保财产/权利价值判断

**规则**：

```
① 法人或其他经济组织：财务报表资产净值 > 需要担保的税额及滞纳金 × 2
② 自然人、法人或其他经济组织：所拥有或依法可处分的未设置担保的财产价值
   > 需要担保的税额及滞纳金
→ 满足任一，被视为具有纳税担保能力
担保范围 = 税款 + 滞纳金 + 实现税款、滞纳金的费用
```

**【演算例题 3】** 甲公司需担保的税额及滞纳金合计 80 万元。甲公司财务报表资产净值为 210 万元；其法定代表人王某拥有未设置担保的财产价值 60 万元。问：谁具备纳税担保能力？

```
甲公司（法人）：资产净值 210 万元 > 80 × 2 = 160 万元  → 具备纳税担保能力
王某（自然人）：未设置担保财产价值 60 万元 < 80 万元     → 不具备纳税担保能力
```

**答：甲公司具备纳税保证人资格；王某不具备。**

### 4.4 拍卖变卖余款退还

**规则**：

```
拍卖/变卖所得
  − 抵缴税款
  − 抵缴滞纳金
  − 抵缴罚款
  − 扣押、查封、保管、拍卖、变卖等费用
  = 剩余部分 → 应当在 3 日内退还被执行人
```

**【演算例题 4】** 税务机关拍卖某纳税人财产得款 120 万元。该纳税人欠缴税款 100 万元、滞纳金 2 万元，扣押查封保管拍卖等费用支出 3 万元。计算应退还金额。

```
剩余 = 120 − 100 − 2 − 3 = 15 万元
→ 税务机关应当在 3 日内将 15 万元退还被执行人
```

**答：应退还 15 万元，且须在 3 日内退还。**

### 4.5 纳税缴费信用起评分与级别判定

**规则**：

```
经常性指标 + 非经常性指标信息齐全        → 从 100 分起评
非经常性指标缺失、经常性指标中纳税缴费信息齐全 → 从 93 分起评
信息不齐全                             → 从 90 分起评
年度评价指标得分 − 扣分 = 最终得分

级别判定：A ≥ 90 ｜ 70 ≤ B < 90 ｜ 40 ≤ C < 70 ｜ D < 40 ｜ M = 新设立或无业务收入
```

**【演算例题 5】** 某经营主体经常性指标和非经常性指标信息齐全，从 100 分起评，评价年度被扣 10 分；另一新设立经营主体首次参评。分别确定级别。

```
主体一：100 − 10 = 90 分 → 90 分以上 → A 级
主体二：首次在税务机关办理税费事宜 → 新设立经营主体 → 直接判为 M 级
       （或按年度评价指标得分判定，不适用起评分）
补充：若主体一为非经常性指标缺失但经常性指标中纳税缴费信息齐全：
      93 − 10 = 83 分 → 70 分以上不满 90 分 → B 级
```

**答：主体一为 A 级；主体二为 M 级。**

### 4.6 互联网平台企业涉税信息报送罚款

```
一般违法（未按期报送、瞒报谎报漏报、拒绝报送）：
    责令限期改正 → 逾期不改正 → 2 万元以上 10 万元以下罚款
情节严重：
    责令停业整顿 + 10 万元以上 50 万元以下罚款
```

**【演算例题】** 某互联网平台企业未按"季度终了的次月内"规定期限报送平台内经营者收入信息，经税务机关责令限期改正后逾期仍未改正，且情节严重。确定处理。

```
一般违法罚款区间：2 万 ~ 10 万元
情节严重：责令停业整顿，并处 10 万 ~ 50 万元罚款
```

**答：责令停业整顿，并处 10 万元以上 50 万元以下罚款。**

## 五、高频考点速记卡

1. **Q：“五证合一、一照一码”是哪五证？**
   A：工商营业执照、组织机构代码证、税务登记证、社会保险登记证、统计登记证。

2. **Q：从事生产经营的纳税人多久内设置账簿？扣缴义务人呢？**
   A：纳税人自领取营业执照或发生纳税义务之日起 **15 日内**；扣缴义务人自扣缴义务发生之日起 **10 日内**，按所代扣代收税种分别设置账簿。

3. **Q：账簿资料至少保存多少年？销毁要经谁批准？**
   A：至少 **10 年**；销毁时编造销毁清册，报**主管部门和税务机关**批准，然后在其监督下销毁。

4. **Q：完税凭证类包括哪些？**
   A：各种**完税证和缴款书**。综合凭证类包括提退减免凭证、罚款收据、票款结算单、代扣代缴税款专用发票、纳税保证金收据、税票调换证等。

5. **Q：已经开具的发票存根联和发票登记簿保存几年？**
   A：**5 年**。

6. **Q：数电发票何时全国正式推广？法律效力如何？**
   A：**2024 年 12 月 1 日**起全国正式推广应用；与纸质发票具有**同等法律效力**，为单一联次、数字化形态存在。

7. **Q：纳税申报有哪四种方式？邮寄申报以何日期为准？**
   A：直接申报、邮寄申报、数据电文申报、委托代理申报。邮寄申报以**寄出的邮戳日期**为实际申报日期。

8. **Q：互联网平台企业涉税信息报送的时间要求？**
   A：自从事互联网经营业务之日起 **30 日内**报送基本信息；基本信息变化的，自变化之日起 **30 日内**报送；**季度终了的次月内**报送身份信息和上季度收入信息。

9. **Q：互联网平台企业涉税信息违法的罚款幅度？**
   A：逾期不改正处 **2 万元以上 10 万元以下**罚款；情节严重的责令停业整顿，并处 **10 万元以上 50 万元以下**罚款。

10. **Q：代扣代缴与代收代缴的区别？**
    A：代扣代缴是在**支付款项时**从支付给纳税人的收入中**扣留**并解缴；代收代缴是在**收取款项时**向纳税人**收取**并缴纳。

11. **Q：税务机关有权核定应纳税额的情形可归为几类？**
    A：三类——**账簿有问题**（可不设账、应设未设、擅自销毁、账目混乱难以查账）、**申报有问题**（逾期仍不申报）、**计税依据明显偏低又无正当理由**。

12. **Q：纳税担保的范围包括什么？罚款在不在范围内？**
    A：包括**税款、滞纳金和实现税款、滞纳金的费用**（抵押质押登记费、质押保管费、保管拍卖变卖担保财产等费用）。**罚款不属于**纳税担保范围。

13. **Q：三种纳税担保形式如何区分？**
    A：看**是否转移财产占有**——纳税保证（保证人连带责任）、纳税抵押（**不转移**占有）、纳税质押（**移交税务机关占有**，分动产质押和权利质押）。

14. **Q：税收保全措施和税收强制执行措施分别有哪些？**
    A：保全＝**冻结存款 + 扣押查封**（仅限从事生产经营的纳税人）；强制＝**扣缴存款 + 扣押查封拍卖变卖抵缴**（含扣缴义务人、纳税担保人，滞纳金同时强制执行）。

15. **Q：税款追征的期限分别是多少？**
    A：税务机关责任 **3 年内**可要求补缴（不得加收滞纳金）；纳税人计算错误 **3 年内**追征税款和滞纳金，特殊情况延长到 **5 年**；偷税抗税骗税**无限期追征**。

16. **Q：延期缴纳税款的最长期限和批准机关？**
    A：经**省、自治区、直辖市税务局**批准，最长不得超过 **3 个月**。

17. **Q：纳税缴费信用级别分几级？各级分值？**
    A：A、B、M、C、D 五级。A ≥ 90 分；B 为 70 分以上不满 90 分；M 为新设立经营主体或 70 分以上但评价年度内无生产经营业务收入；C 为 40 分以上不满 70 分；D 为不满 40 分或有严重失信行为。

18. **Q：不能评为 A 级的情形有哪些？**
    A：① 实际生产经营期不满 **3 年**；② 上一评价年度为 **D 级**；③ 非正常原因一个评价年度内增值税**连续 3 个月或累计 6 个月**零申报、负申报；④ 不能按国家统一会计制度设置账簿并提供准确税务资料。

19. **Q：哪些情形不影响纳税信用评价？**
    A：① 税务机关原因或不可抗力致未能及时履行纳税义务；② 非主观故意的计算公式运用错误以及明显的笔误造成少缴税款；③ 国家税务总局认定的其他情形。

20. **Q：A 级纳税人的激励措施有哪些？**
    A：主动公布 A 级名单；下一年度起评分提高 1 分（可累积，最高不超 100 分）；一次领取不超过 3 个月的增值税发票用量；普通发票按需领用；连续 3 年 A 级可享绿色通道或专门人员辅导。

21. **Q：D 级纳税人的惩戒措施有哪些？**
    A：直接责任人员之后注册登记、负责经营的其他经营主体直接判 D；限额限量领用增值税专用发票、限制数电发票额度；普通发票交（验）旧领新、严格限量供应；列入重点监控；**D 级评价保留至第 2 年，第 3 年不得评为 A 级**；因年度评价指标得分评为 D 级的，**次年评价时加扣 11 分**。

22. **Q：税务行政复议申请期限？复议机关审查期限？**
    A：知道具体行政行为之日起 **60 日内**申请；复议机关收到申请后 **5 日内**审查决定是否受理（逾期不决定视为受理）。

23. **Q：征税行为不服怎么办？**
    A：**必经复议**——必须先缴纳税款和滞纳金或提供相应担保，再申请行政复议；对复议决定不服的，才可以向人民法院提起行政诉讼。

24. **Q：税务行政诉讼的起诉期限？未告知诉权如何处理？**
    A：接到复议决定书或知道之日起 **15 日内**起诉；税务机关未告知诉权和起诉期限致逾期起诉的，从实际知道时起算，但**最长不得超过 2 年**。

25. **Q：税务行政诉讼期间是否停止执行？哪些情形裁定停止？**
    A：原则是**不停止执行**。裁定停止：① 被告认为需要停止；② 原告或利害关系人申请且法院认为执行会造成难以弥补的损失、停止执行不损害国家和社会公共利益；③ 法院认为执行会给国家和社会公共利益造成重大损害；④ 法律法规规定停止执行。

**【2016 年真题·单选】关于发票管理的说法，正确的是（　）。**
A. 发票印制管理是发票管理的基础环节
B. 有固定经营场地的纳税人申请领购发票，主管税务机关有权要求其提供担保人，不能提供担保人的，可以视其情况，要求其提供保证金，并限期缴销发票

**【2020 年真题·多选】关于税收征收管理法中的税款追征制度的说法，正确的有（　）。**

B. 因纳税人失误造成的未缴或少缴税款，追征期一般为 5 年
C. 因扣缴义务人计算错误等失误造成的少缴税款，追征期一般为 3 年
D. 因纳税人的责任致使纳税人未缴或少缴税款的，追征期为 5 年，不加收滞纳金
E. 由于税务机关的责任造成未缴或少缴税款的，税务机关有权追征税款和滞纳金

| 1 | 认为"一照一码""两证整合"取消了税务登记 | **没取消**。法律地位依然有效，只是流程整合；加载统一社会信用代码的营业执照具备**税务登记证件**效力，代码即纳税人识别号 |
| 2 | 把"五证"记成含专利证书 | 五证＝工商营业执照、组织机构代码证、税务登记证、社会保险登记证、统计登记证。**专利证书不在内** |
| 3 | 变更税务登记记成"仍须向税务机关报告" | **自 2023 年 4 月 1 日起**，在市场监管部门办理变更登记后**无须向税务机关报告**，系统自动同步 |
| 4 | 注销、停业的时限和适用范围记混 | 注销常规 **15 日内**，唯一例外是**迁址改变税务登记机关：注销之日起 30 日内**向迁达地申报；停业登记仅限**实行定期定额征收方式的个体工商户**，且**停业期限不得超过 1 年** |
| 5 | 账簿设置期限记混：纳税人 15 日 vs 扣缴义务人 10 日 | **纳税人 15 日、扣缴义务人 10 日**（"15 大 10 扣"） |
| 6 | 账簿保存年限与发票存根联混淆；销毁报"财政部门" | 账簿等资料**至少 10 年**；发票存根联和发票登记簿**保存 5 年**；销毁须报**主管部门和税务机关**批准，然后在其监督下销毁 |
| 7 | 原始凭证金额错误"划线更正" | **金额有错误必须重开，不准更正**；只有非金额错误才可更正并加盖出具单位印章 |
| 8 | 完税凭证与综合凭证分不清 | 完税凭证类＝**完税证 + 缴款书**；提退减免凭证、罚款收据、票款结算单、代扣代缴税款专用发票、纳税保证金收据、税票调换证都属**综合凭证类** |
| 9 | 发票"定期换版""可以跨省使用""临时用票也要先领购" | 是**不定期换版**；除特殊情形外**限于本省内**开具；临时使用**凭证明直接向经营地税务机关申请代开**，应缴税款的**先征税后开票** |
| 10 | 代扣代缴与代收代缴混淆 | 代扣代缴＝**付款时扣留**；代收代缴＝**收款时收取**（"扣在付出，收在取得"） |
| 11 | 认为罚款属于纳税担保范围 | 担保范围＝**税款 + 滞纳金 + 实现税款滞纳金的费用**；**罚款不在内** |
| 12 | 纳税抵押与纳税质押分不清；认为学校、医院可作纳税保证人 | 抵押**不转移占有**，质押**移交税务机关占有**；**国家机关，学校、幼儿园、医院等事业单位，社会团体不得作为纳税保证人** |
| 13 | 税收保全与强制执行措施张冠李戴；以为保全可适用于扣缴义务人、纳税担保人 | 保全＝**冻结、查封、扣押**（事前，**仅限从事生产经营的纳税人**）；强制＝**扣缴、拍卖变卖抵缴**（事后，**含扣缴义务人、纳税担保人**） |
| 14 | 认为生活用品都可保全/强制执行 | 个人及其所扶养家属维持生活必需的住房和用品、**单价 5000 元以下**的生活用品，均**不在**保全和强制执行范围内 |
| 15 | 认为纳税担保人欠缴的滞纳金不能强制执行 | 强制执行时，对纳税人、扣缴义务人、**纳税担保人未缴纳的滞纳金同时强制执行** |
| 16 | 认为欠税和滞纳金必须同时缴纳 | **不再要求同时缴纳**，可要求先行缴纳欠税，再依法缴纳滞纳金 |
| 17 | 追征期限记错：一律 3 年或一律 5 年 | 税局责任 **3 年**（不加滞纳金）；纳税人失误 **3 年，特殊情况延至 5 年**；偷抗骗**无限期** |
| 18 | 认为税务机关发现多缴税款也要等 3 年 | **税务机关发现：应当立即退还**；只有"纳税人发现"才适用 3 年 + 银行同期存款利息 |
| 19 | 延期缴纳批准机关记成"县以上税务局局长"或"最长 60 日" | 经**省、自治区、直辖市税务局**批准，最长不得超过 **3 个月**（税收保全/强制才是县级以上税务局局长批准） |
| 20 | 滞纳金比例记成 0.5% 或万分之三 | 税收滞纳金按日加收 **0.5‰（万分之五）**（《税收征管法》第32条）；写成 0.5% 系笔误 |
| 21 | 纳税信用级别还按 A/B/C/D 四级记；起评分只记 100 分和 90 分 | 新教材为**纳税缴费信用管理**，级别 **A、B、M、C、D 五级**（M 为新设立主体或 70 分以上无业务收入）；起评分三种：齐全 **100 分**、非经常性缺失但经常性中纳税缴费信息齐全 **93 分**、不齐全 **90 分** |
| 22 | 把"不能评为 A 级"与"直接判为 D 级"混淆；把"不影响评价"与"不能评 A"混淆 | 不能评 A：经营期不满 3 年、上年 D 级、连续 3 个月或累计 6 个月零负申报、不按规定设账簿；直接判 D：骗税、虚开专票、偷税 10 万以上且占比 10% 以上等；不影响评价：税局原因/不可抗力、非主观故意公式错误、明显笔误 |
| 23 | A 级激励记成"增值税专用发票按需领用" | 是**普通发票按需领用**；一般纳税人可一次领取**不超过 3 个月**的增值税发票用量 |
| 24 | 必经复议与选择复议范围颠倒；以为对征税行为不服可直接起诉 | **征税行为必经复议**（确认税制要素、征收税款、加收滞纳金、代扣代收代征），且须**先缴税款和滞纳金或提供担保**；发票管理、保全强制、处罚、资格认定、信用等级评定等**可选择** |
| 25 | 诉讼起诉期限与"最长 2 年"混淆；以为诉讼期间一律停止执行 | 一般 **15 日内**起诉，未告知诉权致逾期的从实际知道时起算但**最长不得超过 2 年**，法院 **7 日内**决定立案；原则**不停止执行**，仅四种法定情形才裁定停止 |

### 8.1 期限类（日 / 月 / 年）

| 数字 | 考点 |
|---|---|
| **15 日** | 从事生产、经营的纳税人自领取营业执照或发生纳税义务之日起设置账簿 |
| **15 日** | 注销税务登记：不需办理注册登记的自批准/宣告终止之日起；被吊销/撤销登记的自吊销/撤销之日起；境外企业承包工程自项目完工、离开中国前 |
| **15 日** | 纳税人逾期不缴罚款加处罚款，不服申请复议的管辖/起诉相关期限（接到复议决定书或知道之日起 15 日内起诉） |
| **10 日** | 扣缴义务人自扣缴义务发生之日起设置代扣代缴、代收代缴税款账簿 |
| **30 日** | 因住所、经营地点变动涉及改变税务登记机关的，自注销税务登记之日起向迁达地申报 |
| **30 日** | 互联网平台企业自从事互联网经营业务之日起报送基本信息；基本信息变化的自变化之日起 |
| **1 年** | 纳税人的停业期限不得超过 |
| **3 个月** | 延期缴纳税款最长不得超过 |
| **5 个工作日** | 主管税务机关确认领用发票的种类、数量以及领用方式 |
| **3 日** | 拍卖或变卖所得抵缴税款、滞纳金、罚款及各项费用后，剩余部分退还被执行人 |
| **5 日** | 行政复议机关收到申请后审查决定是否受理 |
| **60 日** | 税务行政复议申请期限（知道具体行政行为之日起）；缴清税款/担保确认之日起 60 日内提出 |
| **60 日** | 纳税信用修复中，未按处理结论缴纳被直接判 D 级，在处理结论明确期限期满后足额缴纳补缴 |
| **15 个工作日** | 纳税缴费信用复评（核）、信用修复完成时限 |
| **12 个月** | 纳入纳税缴费信用管理满 12 个月后可申请复评 |

| **2023 年 4 月 1 日** | 变更税务登记无须向税务机关报告的起始日 |
| **2024 年 12 月 1 日** | 数电发票在全国正式推广应用 |
| **每年 4 月** | 税务机关确定上一年度纳税缴费信用评价结果 |
| **次年 3 月** | 年度评价结果确定前对扣分或判级情况有异议申请复核 |
| **3 年** | 账簿、收支凭证粘贴簿、进销货登记簿等资料至少保存 |

### 8.2 比例 / 金额 / 倍数类

| 数字 | 考点 |
|---|---|
| **0.5‰（每日万分之五）** | 税收滞纳金：从滞纳税款之日起按日加收（《税收征管法》第32条；写成 0.5% 系笔误） |
| **2 倍** | 法人或其他经济组织财务报表资产净值超过需要担保的税额及滞纳金 2 倍以上，视为具有纳税担保能力 |
| **5000 元** | 单价 5000 元以下的生活用品，不在税收保全和强制执行措施范围内 |
| **90 分 / 70 分 / 40 分** | A 级 ≥ 90；B 级 70 以上不满 90；C 级 40 以上不满 70；D 级不满 40 |
| **100 分 / 93 分 / 90 分** | 年度评价指标得分起评分（齐全 / 非经常性缺失但经常性中纳税缴费信息齐全 / 不齐全） |
| **1 分** | A 级经营主体下一年度起评分提高 1 分（连续 A 级可累积，最高不超过 100 分） |
| **11 分** | 因年度评价指标得分评为 D 级的，次年评价时加扣 |
| **10 万元 / 10%** | 偷税（逃避缴纳税款）金额 10 万元以上且占各税种应纳税总额 10% 以上，直接判为 D 级 |
| **3 个月** | 一般纳税人可一次领取不超过 3 个月的增值税发票用量 |
| **1-5 名 / 超过 5 人** | 同一行政复议案件申请人超过 5 人应推选代表（1 至 5 名） |
| **1-2 名** | 申请人、第三人可委托代理人参加行政复议（被申请人不得委托本机关以外人员） |
| **2 人** | 行政复议听证人员不得少于；调查取证工作人员不得少于 |
| **2 万 / 10 万 / 50 万** | 互联网平台企业涉税信息违法罚款：2 万~10 万；情节严重责令停业整顿并处 10 万~50 万 |
| **五证 / 两证** | "五证合一、一照一码"（企业、农民专业合作社）/ "两证整合"（个体工商户） |
| **4 种** | 税款征收方式：查账征收、核定征收、代扣代缴与代收代缴、委托代征 |
| **4 种** | 核定应纳税额的方法 |
| **3 种** | 虚开发票行为；纳税担保形式（保证、抵押、质押） |
| **4 类** | 税务行政诉讼判决：维持、撤销、履行、变更 |
| **5 级 / 4 级** | 新教材纳税缴费信用级别 A/B/M/C/D 五级；旧办法纳税信用级别 A/B/C/D 四级 |
