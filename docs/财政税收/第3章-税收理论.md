## 二、知识点精讲

### 考点1 税收的本质与职能 ★

#### 一、税收的本质（概念）

税收是国家为满足**社会公共需要**，依据其社会职能，按照**法律**规定，参与社会产品的分配，**强制、无偿地**取得财政收入的一种规范形式。税收是一种工具、手段和形式，是政府取得财政收入**最佳、最有效**的形式。

**三点含义**：

1. 税收是一种工具，其被使用的目的是为国家取得财政收入，从而满足社会公共需要；
2. 这种工具由**国家**掌握和运用，税收由国家征收，**行使征税权的主体是国家**，征税权力归国家所有；
3. 税收按照法律的规定，通过强制的征收，把纳税单位和个人的收入转移到政府手中，形成财政收入。

税收表现了**国家与纳税人**在征税、纳税和利益分配上的一种特殊关系；其本质是作为权力主体的国家在取得财政收入的分配活动中，同社会集团、社会成员之间形成的**一种特定分配关系**，是社会整个产品分配关系、整个生产关系的有机组成部分。

**税收的形式特征：强制性、无偿性、固定性。**

**产生、存在和发展的条件**：税收是在**国家产生**、并已具备**一定的社会经济条件**以后才产生、存在和发展的。其中，**社会经济是内在的、根本的决定因素**，**国家的存在和对资金的需求是必要的前提条件**。

#### 二、税收的职能

税收的职能是税收**客观存在的固有的功能**，**由税收的本质决定**，是税收本质的体现；具有**客观性**，不以人们主观意志为转移。

| 职能 | 别称 | 核心内容 |
|---|---|---|
| **财政职能** | 收入职能 | 通过参与社会产品和国民收入的分配再分配，为国家取得财政收入的功能。是各国取得财政收入的最主要形式，是税收**首要的和基本的职能** |
| **经济职能** | 调节职能 | 为实现社会总需求与总供给的平衡，通过税收分配，对**资源配置、国民经济的地区分配格局、产业结构、社会财富分配和居民消费结构**等进行调节。主要通过**财富的所有权转移**这一经济手段实现 |
| **监督职能** | — | ①宏观：税收变动情况可在一定程度上反映经济波动状况，通过信息反馈监督经济运行、实施宏观调控；②微观：通过税收征管过程监督纳税人生产经营活动，促其正确履行纳税义务、遵守国家经济政策。兼涉**宏观与微观**两个层次 |

**逻辑链**：

```
税收的本质（满足社会公共需要的特定分配关系）
        ↓ 决定
税收的职能（财政／经济／监督）
        ↓ 其中
财政职能（收入职能）＝ 首要和基本的职能
        ↓ 调节手段
财富所有权转移 → 经济职能（调节职能）
```

**速记口诀**：**"本质定职能，财政排第一；经济调结构，监督管两级"**——监督职能管宏观、微观两个层次。

### 考点2 税收原则 ★★（多来源标注★★，现代税收原则部分另有来源标★★★★★）

#### 一、税收原则理论的形成和发展

税收原则的**核心问题**是**如何使税收关系适应一定的生产关系的要求**，它体现了政府征税的基本思想，是建立科学的税收制度的依据。

| 代表人物 | 原则体系 | 具体内容 |
|---|---|---|
| **威廉·配第** | 税收（三）原则 | **历史上第一次提出税收原则**。三条标准：**公平**（对任何人、任何东西"无所偏袒"，税负不能过重）、**简便**（征税手续不能过于烦琐，方法要简明）、**节省**（征税成本不能过高，应尽量节约费用）。代表作《赋税论》《政治算术》 |
| **亚当·斯密** | 税收（四）原则 | 《国富论》（《国民财富性质和原因的研究》）中提出：**平等原则**（所有国民应平等纳税）、**确定原则**（各种国民税赋必须是确定的，不得随意变更）、**便利原则**（以纳税人感到最方便的方式征收）、**最少征收费用原则**（以最少的征收费用获得尽可能多的税收收入） |
| **阿道夫·瓦格纳** | "四端九项" | ①**财政政策原则**：收入充分原则、收入弹性原则；②**国民经济原则**：慎选税源原则、慎选税种原则；③**社会公正（社会正义）原则**：普遍原则、平等原则；④**税务行政原则**：确定原则、便利原则、节约原则。基本思想：国家利用税收不应以满足财政需要为唯一目的，而应运用政府权力解决社会问题 |

> 记忆抓手：瓦格纳"四端九项"——**财政政策**讲"钱够不够、能不能调"；**国民经济**讲"别伤税本、注意转嫁"；**社会公正**讲"人人纳税、能力定负"；**税务行政**讲"定了别改、方便纳税人、少花钱"。

#### 二、现代税收原则

一般认为，适应现代市场经济发展的要求和现代国家社会政策的需要，税收应遵循的基本原则主要有**财政原则、经济原则、公平原则**。

```
现代税收原则
├─ 财政原则 → 充裕、弹性、便利、节约（"充弹便节"）
├─ 经济原则 → 配置原则、效率原则（"配置效率"）
└─ 公平原则 → 普遍原则、平等原则（"普遍平等"）★最重要原则
```

| 原则 | 具体内容 | 要点 |
|---|---|---|
| **财政原则** | **充裕原则** | 通过征税获得的收入要充分，能满足一定时期财政支出的需要；应选择税源广大、收入稳定的征税对象 |
| | **弹性原则** | 税收收入应随着财政支出的需要进行调整；税收弹性包含**税收收入弹性和税率弹性**两个方面 |
| | **便利原则** | 使纳税人付出的"奉行费用"较少。两个要求：①确立尽可能简化和便利的纳税期限和缴纳方法（含纳税地点、纳税手续）；②税收制度应由**民意机关参与制定**并保持相对稳定，不可朝令夕改 |
| | **节约原则** | 以尽可能少的税务行政费用，获取应得的税收收入 |
| **经济原则** | **配置原则** | ①资源已处于最优配置状态时，税收活动就不应妨碍最优配置状态；②资源还未处于最优配置状态时，税收活动、税负轻重就应促使资源的转移和重新配置，以提高资源利用效率（如资源在私人部门利用效率小于公共部门时，应进一步征税、扩大公共部门支出） |
| | **效率原则** | 分**税收的经济效率原则**与**税收本身的效率原则**。经济效率原则：税收应有利于资源的有效配置和经济的有效运行，**检验标准是税收额外负担最小化和额外收益最大化**；本身的效率原则：节约税收行政费用，**以最小的税收成本取得最大的税收收入** |
| **公平原则** | **普遍原则** | 一般情况下，税收应由本国全体公民共同负担；不允许任何阶级、阶层、经济成分、个人或法人享有免税特权 |
| | **平等原则** | **横向公平**：对相同境遇（经济能力相同）的纳税人课征相同的税收（要求排除特权阶级免税，自然人和法人均需纳税，公私经济均等纳税，对本国人和外国人一视同仁）；**纵向公平**：对不同境遇的纳税人课征不同的税收，判断境遇的标准一般包括**受益标准和能力标准**；测定纳税能力强弱通常有**收入（是测定纳税人纳税能力的最好尺度）、财产和消费支出**三种标准 |

**公平原则**（瓦格纳称为社会正义原则）是指国家征税应使各个纳税人承受的负担与其经济状况相适应，并使各个纳税人之间的负担水平保持均衡，是**设计和实施税收制度的最重要的原则**。

**速记口诀**：**"财政充弹便节，经济配置效率，公平普遍平等；公平最重要，收入是最好尺度。"**

### 考点3 税收制度（税制构成要素）★★★

#### 一、税收制度的含义

税收制度简称**税制**。

| 角度 | 内容 |
|---|---|
| **广义** | 税收的各种法律制度的总称，包括国家的各种税收**法律法规、税收管理体制、征收管理制度以及税务机关内部管理制度**等 |
| **狭义** | 指**税收法律制度**，主要是从税收管理的角度来研究税制 |
| **另外含义** | 一个国家在一定历史条件下所形成的税收制度的结构体系，各税类、税种、税制要素相互配合协调构成的税制体系（即税制结构） |

#### 二、税收制度的基本要素

**基本要素＝纳税人、征税对象、税率**。这三个要素回答了"由谁纳税、对什么征税、征多少税"最基本的税收问题。

**（1）纳税人（纳税义务人、纳税主体）**

| 类型 | 内容 |
|---|---|
| **纳税人** | 税法规定**直接负有纳税义务**的单位和个人，是税款的**直接承担者**；可以是自然人，也可以是法人 |
| **负税人** | **实际负担税款**的单位和个人，是税款的**最终承担者**。**直接税的纳税人等于负税人，间接税的纳税人不等于负税人** |
| **代扣代缴义务人** | 不承担纳税义务，但在向纳税人支付收入、结算货款、收取费用时，有义务代扣代缴其应纳税款的单位和个人。目的是实行**源泉控制**，保证国家财政收入。例：出版社代扣代缴作者稿酬所得的个人所得税 |
| **代收代缴义务人** | 不承担纳税义务，但在向纳税人收取商品或劳务收入时，有义务代收代缴其应纳税款的单位和个人。例：**委托加工**应税消费品，由受托方代收代缴消费税 |

> 三个"一定"：纳税义务人一定是组织或者个人等主体；**纳税义务人不一定是负税人**，甚至大多数情况下并不是负税人；**纳税义务人一定不是代扣代缴义务人、代收代缴义务人**。

**（2）征税对象（征税客体）**

指**对什么征税**，即国家征税的标的物。它规定了每一种税的**征税界限**，是**一种税区别于另一种税的主要标志**。每一种税一般都有特定的征税对象（如企业所得税的征税对象为所得额，车船税的征税对象为车辆、船舶）。

| 划分 | 概念 | 内容 |
|---|---|---|
| **质的具体化** | **征税范围**（课税范围） | 征税对象的具体内容或范围，凡是列入征税范围的都应征税 |
| | **税目**（课税品目、征税品目） | 税法规定应征税的具体项目，是征税对象的**具体化**，体现**征税的广度**，反映各税种具体的征税范围。例：消费税设置了烟、酒、高档化妆品等 **15 个税目** |
| **量的具体化** | **计税依据** | 计算应纳税额所依据的标准。**从价计征**以**计税金额**为计税依据；**从量计征**以征税对象的**重量、容积、体积、数量**等为计税依据 |
| | **计税标准** | 两个含义：①划分征税对象适用税目税率所依据的标准；②计算应纳税额的依据，与计税依据同义 |

**相关概念群**：**税类**（构成税制结构的最基本层次）；**税种**（一个税种由若干税制要素构成）；**税基**（广义＝抽象征税基础；中义＝具体税种征税基础，即征税对象；狭义＝计税依据）；**税源**（税收的经济来源或最终出处，来自当年创造的社会剩余产品）。

**（3）税率**

税率是**应纳税额与征税对象数额（量）之间的法定比例**，是计算税额和税收负担的尺度，体现征税的程度，是**税收制度的中心环节**，是税收制度中**最活跃、最有力**的因素。

| 税率形式 | 含义 | 适用/细分 |
|---|---|---|
| **比例税率** | 对同一征税对象，不论数额大小，均按同一比例计征 | 一般适用于**商品流转额**的征税，如增值税。可分为产品比例税率、地区差别比例税率、幅度比例税率 |
| **累进税率** | 随征税对象数额或相对比例的增大而**逐级提高**税率的一种递增等级税率；数额或相对比例越大，等级税率越高 | 分为**全额累进、超额累进、全率累进、超率累进、超倍累进**；其中使用时间较长、应用较多的是**超额累进税率** |
| **定额税率**（固定税额） | 对每一单位的征税对象直接规定固定税额 | 一般适用于**从量计征**的税种，如车船税。可分为地区差别定额税率、幅度定额税率、分类分级定额税率 |

**速记口诀**：**"比例税率看价格；定额税率看数量；累进税率高低各不同。"**

**三种累进税率辨析**：

| 类别 | 划分依据 | 计税规则 | 典型应用 |
|---|---|---|---|
| **全额累进税率** | 征税对象的**绝对数额** | 全部数额按与之相应的**一级**税率计征，只适用一个等级的税率 | — |
| **超额累进税率** | 征税对象的**绝对数额** | 全部数额中符合不同级距的部分，**分别**按相应各级税率计征（分段计算），同时适用几个等级税率 | **个人所得税中的综合所得税率** |
| **超率累进税率** | 征税对象数额的**相对比率** | 全部数额中处于不同级距的部分，分别按相应各级税率计征，以某种比率作为累进依据 | **土地增值税税率** |

**速算扣除数法**（为简化超额累进税率的计税方法）：

```
应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数
速算扣除数 = 全额累进计算的税额 − 超额累进计算的税额
本级速算扣除数 =（本级税率 − 上一级税率）× 上一级征税对象的最高数额 + 上一级速算扣除数
```

#### 三、税收制度的其他要素

| 要素 | 内容 |
|---|---|
| **纳税环节** | 税法规定的商品在整个**流转过程中**应当缴纳税款的环节。按纳税环节多少分为**一次课征制、两次课征制、多次课征制** |
| **纳税期限** | 税法规定的纳税人申报缴纳税款的间隔时间。分为**按年征收、按季征收、按月征收、按天征收和按次征收**等多种形式 |
| **减税免税** | **减税**是从应征税款中减征部分税款；**免税**是免征全部税款。分为**税基式减免**与**税额式减免**（见下表） |
| **违章处理** | 对纳税人违反税法的行为所作的处罚，是税收**强制性**的一种具体体现。方式主要有**加收滞纳金、处以罚款、通知银行扣款、吊销税务登记证、移送司法机关追究刑事责任**等 |

| 减免方式 | 实现路径 | 具体形式 |
|---|---|---|
| **税基式减免** | 通过**直接缩小计税依据**实现 | **起征点、免征额、项目扣除、跨期结转** |
| **税额式减免** | 通过**直接减少应纳税额**实现 | **全部免征、减半征收、核定减免率、另定减征税额** |

**速记口诀**：**"税基减少应税所得，税额减少应纳税额。"**

**起征点 vs 免征额（高频陷阱）**：

| 区别 | 起征点 | 免征额 |
|---|---|---|
| 定义 | 征税对象**达到一定数额开始征税的起点** | 征税对象全部数额中**免予征税的数额** |
| 税务处理 | 收入＜起征点，**全额不征**；收入≥起征点，**全额征税** | 收入≤免征额，**全额免征**；收入＞免征额，**只就超过部分征税** |
| 适用范围 | 对**一部分纳税人**的税收优惠 | 对适用范围内**所有纳税人**的税收优惠 |

> **税收支出**与减税免税其实质是一致的，但税收支出的形式除上述各种减免税形式外，还包括**税收抵免、延迟纳税**等形式。

### 考点4 税制结构 ★

#### 一、税制结构模式

**税制结构**是指税收制度中**税种**的构成及**各税种在其中所处的地位**。**税制结构模式**是指由**主体税特征**所决定的税制结构类型。

| 模式 | 含义 | 优势 | 局限性 |
|---|---|---|---|
| **以所得税为主体** | 所得税占比较高并起主导作用；主要**发达国家**多为此特点 | ①所得税作为直接税，**税负相对不易转嫁**，通过累进税率设置有利于实现税收**公平**原则，对**收入再分配**具有重要调节作用；②税收收入**弹性较高**，具有**自动稳定器**功能，有利于宏观经济稳定 | ①**抑制劳动者工作积极性和投资者投资热情**，促使其更多选择闲暇和消费，从而对经济产生扭曲；②计算和征管相对复杂，**征税成本相对更高** |
| **以货物和劳务税为主体** | 货物和劳务税占比较高并起主导作用；一些**发展中国家**多为此特点 | ①**征税对象普遍、税源丰富，对经济扭曲较小**；②**征管相对容易，征收成本较小**；③**税负容易转嫁** | ①与**价格关系密切**，一旦提高税率往往导致价格上涨、抑制需求，从而使税收减少；②具有一定的**累退性**，不利于税收公平目标的实现 |
| **以所得税与货物和劳务税为双主体** | 二者占有**相近的比重**，在财政收入和调节经济方面共同起主导作用 | 既能确保财政收入的**稳定可靠**，又能使税收的**刚性与弹性相结合**，充分发挥税收的**宏观调控**作用 | 无 |

#### 二、税制结构的影响因素

| 因素 | 内容 |
|---|---|
| **经济因素（根本因素）** | ①**经济发展水平**是制约税制结构的**根本因素**：水平较高则企业利润及个人收入较高，具备广泛征收所得税的基础；水平较低则所得税税基与税源有限，货物和劳务的流转额相较所得更稳定，故货物和劳务税占比较大。②**经济结构**：不同经济结构形成不同税源结构，进而影响各税种收入，最终影响税制结构（农业经济→直接税为主体；工商经济→间接税与直接税并重） |
| **政策因素** | 发达国家缩小收入分配差距的需求更强烈，故选择收入分配调节职能较强的所得税为主体；发展中国家发展经济任务更迫切、对稳定财政收入需求更高，故选择税基税源更稳定、征收相对容易的货物和劳务税作为主体税种 |
| **征管因素** | 发达国家先进的征管手段有助于实现对税源的监控和征收，为所得税成为主体税种提供条件；发展中国家征管水平相对落后，大规模征收所得税在技术上存在困难，故更倾向货物和劳务税为主体 |

> **来源冲突标注**：部分新教材变动讲义将"税制结构的影响因素"整节标注为**删除**。本文按"并列保留"处理，两说并记——若考新教材可不作为重点，但作为理解性知识仍建议掌握。

#### 三、我国现行税制结构

我国现行税收法律制度共由 **18 个税种** 组成，按其性质和作用大致分为 **5 大类**：

| 税类（5） | 税种（18） | 作用 |
|---|---|---|
| **货物和劳务税类**（流转税类） | 增值税、消费税、关税 | 在生产、流通或服务业中发挥调节作用 |
| **所得税类** | 企业所得税、个人所得税 | 在国民收入形成后，对生产经营者的利润和个人的纯收入发挥调节作用 |
| **财产税类** | 房产税、契税、车船税 | 对某些财产和行为发挥调节作用 |
| **资源税类** | 资源税、城镇土地使用税、耕地占用税、土地增值税 | 对因开发和利用自然资源差异而形成的**级差收入**发挥调节作用 |
| **行为、目的税类** | 环境保护税、印花税、城市维护建设税、车辆购置税、烟叶税、船舶吨税 | 为达到特定目的，对特定对象和特定行为发挥调节作用 |

**我国税制结构现状**：具有较为典型的**发展中国家**税制结构特点，**货物和劳务税构成了我国税收总额的主体部分**，财产和特定行为税的比重较低。就单个税种而言，**增值税的比重最高，其次是企业所得税**。随着经济发展以及征收管理水平的提高，所得税占比不断上升，显示我国税制结构正向以**所得税与货物和劳务税为双主体**的模式转变。

**深化税制改革（"十五五"方向）**：优化税制结构，健全有利于高质量发展、社会公平、市场统一的税收制度，**保持合理的宏观税负水平**；**提高直接税比重**，完善综合和分类相结合的个人所得税制度，逐步扩大综合征收范围，健全经营所得、资本所得、财产所得税收政策；完善增值税留抵退税政策和抵扣链条，优化共享税分享比例；研究同新业态相适应的税收制度；健全地方税体系，推进**消费税征收环节后移并稳步下划地方**。另有来源提出：研究把城市维护建设税、教育费附加、地方教育附加合并为**地方附加税**，授权地方在一定幅度内确定具体适用税率。

**速记口诀**：**"货物劳务打头阵，增值第一企所得第二；十八税种五大类，双主体是方向。"**

### 考点5 税收负担的衡量指标 ★★★

#### 一、税收负担的概念

税收负担是指一定时期内纳税人因国家征税而承受的经济负担。

| 考察角度 | 内容 |
|---|---|
| **绝对值** | 纳税人应支付给国家的**税款额** |
| **相对值** | **税收负担率**，即纳税人的应纳税额与其计税依据价值的**比率** |

**税收负担是税收制度和税收政策的核心**。税收制度和税收政策制定的目的归根结底是为了解决两个问题：一是如何确定税收负担的总量；二是如何将税收负担总量进行合理的分配。

#### 二、宏观税负衡量指标

宏观税负衡量指标是从**全社会角度**衡量税收负担，综合、全面地反映一个国家税收负担的总体状况。

| 指标 | 计算公式 | 说明 |
|---|---|---|
| **国民生产总值（或国内生产总值）负担率** | 税收收入总额 ÷ 国民生产总值（或国内生产总值）× 100% | 反映一个国家在一定时期内**所有产品和服务**负担税收的程度，通常代表一国的**积累程度和税收总水平** |
| **国民收入负担率** | 税收收入总额 ÷ 国民收入 × 100% | 同 GNP/GDP 负担率相比，**国民收入负担率更能准确地衡量一国总体的税收负担水平**（国民收入只包括一定时期内新创造的或进入最终消费的产品和服务的价值，不包括中间产品的价值） |

#### 三、微观税负衡量指标

微观税负衡量指标是从某一具体方面反映一定的税收负担状况，主要是指纳税人负担率。由于存在货物和劳务税的**转嫁**问题，微观税负衡量指标往往只能作为**参考性的指标**。

| 指标 | 计算公式 |
|---|---|
| **企业（个人）综合税收负担率** | 企业（或个人）缴纳的各项税收的总和 ÷ 企业总产值（或个人毛收入）× 100% |
| **直接税负担率** | 企业（或个人）一定时期缴纳的所得税（包括财产税）÷ 企业（或个人）一定时期获得的**纯收入** × 100% |
| **货物和劳务税税收负担率** | 一定时期实际缴纳的货物和劳务税税额 ÷ 同期销售（营业）收入 × 100% |
| **企业所得税税收负担率** | 实际缴纳的所得税税额 ÷ 同期实现的**利润总额** × 100% |
| **个人所得税税收负担率** | 一定时期实际缴纳的个人所得税税额 ÷ 同期**个人收入总额** × 100% |
| **企业增值税税收负担率** | 一定时期实际缴纳的增值税税额 ÷ 同期实现**营业收入总额** × 100% |

**速记口诀**：**"增值税税负率找销售收入；企业所得税税负率找利润总额。"**

### 考点6 税收负担的影响因素 ★

| 因素 | 具体内容 |
|---|---|
| **经济因素** | ①**经济发展水平**：一国的经济发展水平是影响其税收负担水平的**决定性因素**，经济发展水平较高的国家税收负担也要重一些。②**政治经济体制**：中央集权制或非市场经济体制的国家税收负担要重一些；若国家参与国民收入分配的形式除税收外还有利润等其他形式且占相当份额，税收负担会较轻 |
| **政策因素** | 国家实行**紧缩的财政政策**时，需要增加税收、减少财政支出，这时税收负担会**加重**；实行**扩张的财政政策**时，税收负担则会有所**减轻** |
| **税制因素** | ①**征税对象**：范围和数额越大，税收负担水平越高。②**计税依据**：允许扣除的项目越多，计税依据越小，实际税收负担率低于名义税率。③**税率**：其他要素不变时，税率直接决定税负高低；**比例税率**下（不考虑转嫁、税前扣除等）税率等于纳税人实际税收负担率，**累进税率**下名义边际税率与实际税收负担率不同，税率累进程度越大，名义税率与实际税率、边际税率与平均税率的差距越大。④**减免税**：使纳税人税收负担**减轻**的因素。⑤**税收附加和加成**：使纳税人税收负担**加重**的税制因素 |
| **征管因素** | 一国税务部门**征管水平**较高，税收征收率也就较高；反之则税收流失严重，必然导致**宏观税负下降** |

**速记口诀**：**"经济定水平，政策调松紧，税定五要素（对象、依据、税率、减免、附加加成），征管定征收。"**

### 考点7 税收负担的转嫁与归宿 ★★★★

#### 一、概念

**税负转嫁**是指纳税人通过各种途径将应缴税金**全部或部分**地转给他人负担，从而造成**纳税人与负税人不一致**的经济现象。**税负归宿**是指税收负担的**最终归着点**。

#### 二、税负转嫁的四种形式

| 转嫁形式 | 别称 | 含义 | 关键特征 |
|---|---|---|---|
| **前转** | **顺转** | 纳税人在进行商品或劳务的交易时，通过**提高价格**的方法将其应负担的税款**向前**转移给商品或劳务的**购买者或最终消费者**负担 | **税负转嫁最典型和最普通的形式**，多发生在商品和劳务征税上 |
| **后转** | **逆转** | 纳税人通过**压低生产要素的进价**，将应缴纳的税款转嫁给生产要素的**销售者或生产者**负担 | 一般是因为市场供求条件**不允许纳税人提高商品价格**、不能采取前转方式所致 |
| **消转** | **税收转化** | 纳税人对其税收负担**既不向前转嫁也不向后转嫁**，而是通过**改善经营管理或改进生产技术**等方法，**自行消化** | 严格地说并未将税收负担转嫁给他人，是一种**特殊的税负转嫁形式**；**可不依赖价格运作** |
| **税收资本化** | **资本还原** | 生产要素**购买者**将购买的生产要素未来应纳税款，通过**从购入价格中扣除**的方法，**向后**转移给生产要素的**出售者** | 主要发生在某些**资本品**的交易中。名义上税款由买主缴纳，实际上由卖主承担。例：政府征收土地税，土地购买者将预期应纳土地税折入资本，使实际地价下降，此后名义上由购买者按期纳税，实际由**出售者**负担 |
**速记口诀**：**"前转提价给消费者，后转压价给生产者；消转自己消化不掉，资本化扣购入价给卖主。"**

#### 三、税负转嫁的条件

| 条件 | 理解 |
|---|---|
| **商品经济的存在** | 自给自足的自然经济社会，产品一般不经过市场交换，税收只能由土地所有者负担，不能实现税负转嫁。商品经济产生后出现市场交易，**多环节、多层次的流通交换过程为税负转嫁提供了可能** |
| **自由的价格体制** | 税负转嫁一般通过**价格变动**实现——或提高售价，或压低购价，或以税收资本化改变价格，都要求市场价格具有**可变性**和各市场主体具有**自由定价权**。政府指令性计划价格制度基本不存在税负转嫁；市场经济集发达的商品经济和自由开放的价格体制于一身，为税负转嫁提供适宜条件 |

#### 四、税负转嫁的一般规律

```
税负转嫁四规律
① 供给弹性大 + 需求弹性小 → 易转嫁
② 垄断性商品 → 易转嫁（竞争性商品较弱）
③ 货物和劳务税（间接税）→ 易转嫁（所得税/直接税一般不能转嫁）
④ 征税范围广的税种 → 易转嫁
```

**供求弹性与税负转嫁之间的关系（三条，必考）**：

| 规律 | 内容 |
|---|---|
| **需求弹性** | 商品**需求弹性大小与税负向前转嫁的程度成反比，与税负向后转嫁的程度成正比**。需求弹性越大，前转量越小、后转量越大；**需求完全有弹性时，税负将全部由供给方负担；需求完全无弹性时，税负将全部由需求方负担** |
| **供给弹性** | 商品**供给弹性大小与税负向前转嫁的程度成正比，与税负向后转嫁的程度成反比**。供给弹性越大，前转量越大、后转量越小；**供给完全无弹性时，税负将全部由供给方负担；供给完全有弹性时，税负将全部由需求方负担** |
| **两者比较** | 当商品的**需求弹性大于供给弹性**时，税负由**需求方**负担的比例**小于**由供给方负担的比例；当需求弹性小于供给弹性时，税负由需求方负担的比例**大于**由供给方负担的比例 |

**其余三条规律的理由**：

1. **垄断性商品**——转嫁主要通过改变价格实现，垄断性商品对市场的独占性决定其对价格的**控制权**，提价转嫁能力强；竞争性商品按市场供求定价，转嫁能力较弱。
2. **货物和劳务税**——作为**间接税**，税负能通过提高或降低商品价格转由他人负担，转嫁多少取决于定价方式、价格弹性、征税范围；**所得税作为直接税，因对收益所得额征税，一般由纳税人负担，不能转嫁**。
3. **征税范围广的税种**——对全部商品或同一类商品都征税，消费者**选择余地小**；征税范围窄则选择余地大，可能以其他商品替代，故不易转嫁。

### 考点8 税收管辖权 ★★

#### 一、国际税收概述

**国际税收**是指两个或两个以上国家政府因行使各自的征税权力，在对跨国纳税人进行分别征税而形成的征纳关系中所发生的**国家之间的税收分配关系**。

两重含义：①国际税收**不是一种独立的税种**（实际上是由国家税收派生出来的）；②国际税收**不能离开跨国纳税人**。

研究内容：主要研究**所得税和资本收益税**方面的问题，包括税收管辖权问题、国际重复征税的产生与免除、国际避税与反避税、国际税收协定等。

#### 二、税收管辖权

**税收管辖权**是国家主权在税收领域中的体现，是一国政府行使主权征税所拥有的各种权力。

| 确定原则 | 标准 | 对应管辖权 | 内容 |
|---|---|---|---|
| **属地主义原则** | 纳税人的**收入来源地或经济活动所在地** | **收入来源地管辖权**（亦称**地域管辖权**） | 一国政府只对来自或被认为是来自本国境内的所得拥有征税权力；对跨国纳税人来自本国境内的收入或在本国境内从事经济活动带来的收入，不论其居住地是否在本国、是否为本国居民，一律行使征税权力。这是各国行使税收管辖权的**最基本**的原则 |
| **属人主义原则** | 纳税人的**国籍和住所** | **居民管辖权** | 一国政府对本国居民的**全部所得**拥有征税权力，不论该收入是否来源于本国 |

**税收管辖权的选择**：几乎所有国家都实行了收入来源地管辖权，它既体现了国际经济利益分配的合理性，又在税务行政管理上较为方便。**目前，多数国家包括我国，都是同时实行收入来源地管辖权和居民管辖权**（属人兼属地）。

**速记口诀**：**"属地看来源地，属人看国籍住所；我国两类一起用。"**

### 考点9 国际重复征税的产生与免除 ★★★★（部分来源标★★★）

#### 一、含义与产生原因

**国际重复征税**是指**两个或两个以上国家**对跨国纳税人的**同一征税对象或税源**进行分别征税所形成的**交叉重叠征税**。它是国际税收的基本理论问题和核心内容。

产生原因：
1. **跨国纳税人、跨国所得、各国对所得税的开征**是产生国际重复征税的**重要前提**；
2. 产生国际重复征税的**根本原因是各国税收管辖权的交叉**；
3. 各国都实行单一的税收管辖权时，由于各国对居民或收入来源地的认定标准不同，也会出现居民管辖权与居民管辖权的交叉、收入来源地管辖权与收入来源地管辖权的交叉，从而产生国际重复征税。

#### 二、免除方法

| 方法 | 主要内容 | 效果 |
|---|---|---|
| **低税法** | 居住国政府对其居民国外来源的所得，**单独制订较低的税率**征税，以减轻重复征税 | **一定程度上降低，不能彻底解决**。只有当单独制定的较低税率趋于 0 时，国际重复征税才趋于彻底免除 |
| **扣除法** | 居住国政府对其居民取得的国内外所得汇总征税时，允许居民将其**在国外已纳的所得税视为费用**在应税所得中予以扣除，就扣除后的部分征税 | **不能彻底解决** |
| **免税法**（豁免法） | 居住国政府对其居民来源于非居住国的所得额，**单方面放弃征税权**（国外所得在国内缴纳的税款为 0） | **彻底解决**，但这是承认收入来源地管辖权的独占地位，会使**居住国利益损失较大**，故采用的国家很少 |
| **抵免法** | 居住国政府对其居民国外所得在国外已纳的所得税，**允许从其应汇总缴纳的本国所得税款中抵扣** | **目前解决国际重复征税最有效的方法** |

**速记口诀**：**"低税法单独低税率，扣除法当费用扣，免税法放弃不征，抵免法抵扣最有效。"**

#### 三、抵免法与抵免限额

为维护居住国税收利益，实行抵免时通常要规定一个**限额（抵免限额）**，在此限度内实行全额抵免，超过此限度的只能就限额进行抵免。

**抵免法计算四步**：

```
① 计算抵免限额   （分国／综合／分项）
② 计算国外实纳税款
③ 确定抵免额     → 两数相比，取其小
     抵免限额 < 实纳税款  → 以抵免限额为允许抵免额
     抵免限额 ≥ 实纳税款 → 以实纳税款为允许抵免额
④ 计算国内交税   → 国内应交税款 − 允许抵免额
     回国应补缴税款 = 抵免限额 − 允许抵免额（仅在抵免限额 > 实纳税款时）
```

**直接抵免与间接抵免**：

| 方法 | 内容 | 适用范围 |
|---|---|---|
| **直接抵免** | 居民纳税人在非居住国**直接缴纳**的所得税款，允许冲抵其应向居住国政府缴纳的所得税款 | 同一经济实体的跨国纳税人，如**跨国总公司与分公司之间汇总利润**的税收抵免 |
| **间接抵免** | 对境内母公司来自外国**子公司股息**形成的相应利润所缴纳的外国政府所得税，允许母公司在应缴本国政府所得税内进行抵免 | **跨国母子公司之间**的税收抵免 |

**三种抵免限额**：

| 方法 | 计算公式 | 特点 |
|---|---|---|
| **分国抵免限额** | 国内外应税所得额×本国税率×（某一外国应税所得额÷国内外应税所得额）＝**某一外国应税所得额×本国税率** | 对来自**每一项外国**的所得分别计算抵免限额 |
| **综合抵免限额** | 国内外应税所得额×本国税率×（国外应税所得额÷国内外应税所得额）＝**国外应税所得额×本国税率** | 对**全部外国来源所得**不分国别、项目汇总计算；可使不同国家的**不足限额和超限额部分相互抵消**，纳税人获得**最大限度的抵免** |
| **分项抵免限额** | 国内外应税所得额×本国税率×（国外某一单项应税所得额÷国内外应税所得额）＝**国外某一单项所得额×本国税率** | 对股息、利息等投资所得或农、林业收入单独计算限额，防止以某外国较低税率形成的**不足限额**冲抵另一外国较高税率形成的**超限额**进行国际间逃避税；是对综合抵免限额的**补充**，以维护居住国利益为出发点 |

#### 四、税收饶让

**税收饶让**（税收饶让抵免）是指居住国政府对其居民在国外得到的所得税**减免优惠的部分**，**视同**在国外实际缴纳的税款给予税收抵免，不再按居住国税法规定的税率进行补征。

- 税收饶让是**税收抵免的延伸**，以税收抵免的发生为前提；
- 其意义已超出解决国际重复征税的范围，主要是为了**保障各国税收优惠措施的实际效果**；
- **多数发生在发展中国家和发达国家之间**，两国之间一般采取**签订税收协定**的方式确定；
- 税收饶让**不影响**发达国家作为居住国行使居民管辖权的正当税收权益。

### 考点10 国际避税与反避税 ★

#### 一、国际避税的含义与产生原因

**国际避税**是跨国纳税人利用各国税法规定的差异和漏洞，以**不违法的手段**减轻或消除国际税负的行为。

| 原因 | 内容 |
|---|---|
| **内在动机** | 跨国纳税人对**利润的追求** |
| **外部条件** | **各国税收制度的差别和税法的缺陷** |

#### 二、国际避税的基本手段

| 手段 | 具体内容 |
|---|---|
| **利用转让定价转移利润** | 一般是指跨国总公司与其各分支机构、母公司与子公司之间，通过**人为制定内部交易结算价格**转移利润，逃避国际纳税义务的行为 |
| **利用避税地规避纳税义务** | 避税地一般允许投资和从事经营活动的企业享受**不纳税或少纳税**的优惠待遇；跨境纳税人利用避税地提供的种种便利，采用**虚设机构中转销售、虚设信托财产**等方法，将利润从**高税区转移到避税地** |
| **滥用国际税收协定** | 一个**第三国（或地区）居民**利用其他两个国家（或地区）之间签订的国际税收协定，获取其**本不应该得到的税收利益** |

#### 三、国际反避税措施

1. **完善税法**：完善税制；加强税收立法，制定专门的反避税条款；国际避税案件的裁定还应形成相应法规，作为法院或税务官员裁定的依据；
2. **加强税务管理**：采用先进的征管手段，加强税务调查与审计等；
3. **加强国际多边合作**：税收信息、资料的提供，以及签订协议等。

#### 四、国际税收协定（★）

**国际税收协定**是指两个或两个以上的主权国家，为了协调处理相互之间跨国纳税人征税事务方面的税收关系，本着**对等**的原则，通过政府谈判所签订的一种书面税收协议或条约。

| 项目 | 内容 |
|---|---|
| **分类** | ①按参加国的多少：**双边**国际税收协定和**多边**国际税收协定（目前大量是双边）；②按涉及的内容和范围的大小：**一般**国际税收协定和**特定**国际税收协定 |
| **作用** | ①体现主权国家之间相互尊重和平等协商；②是本国居民履行跨国纳税义务的安全保障；③其本身就是适应国际经济技术交流需要的产物 |
| **范本** | 《**OECD 协定范本**》（《经济合作与发展组织关于对所得和财产避免双重征税的协定范本》）和《**UN 协定范本**》（《联合国关于发达国家与发展中国家间避免双重征税的协定范本》），是目前国际上最重要、影响力最大的两个范本。范本有两个特征：**规范化、内容弹性化** |

#### 五、BEPS 行动计划与国际税收合作（★）

**税基侵蚀和利润转移（BEPS）**是指国际跨境企业利用国际征税规则的缺失以及各国税制差异和征管漏洞，最大限度减少其全球总体税负，甚至达到双重不征税的效果，造成对各国税基的侵蚀与利润转移，从而导致税收流失。**2015 年 11 月，G20 领导人峰会正式批准了由经济合作与发展组织发布的 BEPS 行动计划 15 项成果报告**，标志着国际税收规则重塑取得了重要突破。

**国际税收合作**是通过**信息交换、征管互助、相互协商**等方式提高各国税收征管能力，打击跨国纳税人利用税制差异和信息不对称向避税地和低税地转移利润或隐匿收入的逃避税行为的各种合作、协调措施。我国参与情况：《多边税收征管互助公约》**2013 年 8 月 27 日**签署、**2017 年 1 月 1 日**起执行；《金融账户涉税信息自动交换多边主管当局间协议》**2015 年 12 月**签署；《实施税收协定相关措施以防止税基侵蚀和利润转移的多边公约》**2017 年 6 月 7 日**签署、**2022 年 9 月 1 日**正式生效。

| 方法 | 关键动作 | 能否彻底解决 |
|---|---|---|
| 低税法 | 境外所得单独适用较低税率 | 不能（税率趋于 0 时才彻底） |
| 扣除法 | 国外已纳税额视为费用扣除 | 不能 |
| 免税法 | 居住国单方面放弃对境外所得征税权 | **能彻底**，但居住国损失大 |
| 抵免法 | 国外已纳税额从本国税款中抵扣 | **目前最有效** |

### 表9 三种抵免限额

| 方法 | 公式 | 一句话 |
|---|---|---|
| 分国抵免限额 | 某一外国应税所得额×本国税率 | 一国一额，分别算 |
| 综合抵免限额 | 国外应税所得额×本国税率 | 不分国别汇总算，**抵免最充分** |
| 分项抵免限额 | 国外某一单项所得额×本国税率 | 按项目单独算，防超限额与不足限额互抵 |

### 表10 「X 个不等于」避坑表（专治选择题陷阱）

| 说法 | 正解 |
|---|---|
| 税收的本质是由税收的**职能**决定的 | ✗ 恰恰相反——**税收的职能是由税收的本质决定的** |
| 税收首要和基本的职能是**经济职能** | ✗ 是**财政职能（收入职能）** |
| 纳税人**就是**代扣代缴义务人 | ✗ 纳税义务人一定**不是**代扣代缴义务人、代收代缴义务人 |
| 纳税人**等于**负税人 | ✗ 只有**直接税**中纳税人才等于负税人；**间接税**中纳税人不等于负税人 |
| 亚当·斯密第一次提出税收原则 | ✗ 第一次提出的是**威廉·配第**；斯密是在《国富论》中提出著名**四**原则 |
| 设计和实施税收制度最重要的原则是**经济原则** | ✗ 是**公平原则** |
| 经济效率原则＝节约税收行政费用 | ✗ 节约行政费用是**税收本身的效率原则**；经济效率原则的检验标准是**额外负担最小化、额外收益最大化** |
| 横向公平＝对经济条件不同的纳税人区别征税 | ✗ 那是**纵向公平**；横向公平是对**相同境遇**者征**相同**税收 |
| 国际税收是一种独立的税种 | ✗ 国际税收**不是独立税种**，是由国家税收派生出来的**税收分配关系**，且**不能离开跨国纳税人** |
| 国际重复征税的根本原因是**各国都开征所得税** | ✗ 各国开征所得税只是**重要前提**；**根本原因是各国税收管辖权的交叉** |
| 低税法、扣除法能**彻底**解决国际重复征税 | ✗ 二者都**不能彻底解决**；只有**免税法**能彻底解决（但居住国损失大） |
| 税收饶让多发生在**发达国家之间** | ✗ 多发生在**发展中国家与发达国家之间**，且以签订税收协定方式确定 |
| 税收饶让会影响发达国家行使居民管辖权的正当权益 | ✗ **不会**影响；其目的主要是**保障各国税收优惠措施的实际效果** |
| 国际避税是**违法**行为 | ✗ 国际避税是以**不违法的手段**减轻或消除税负；与偷逃税性质不同 |
| 微观税负指标能**精确**反映纳税人实际负担 | ✗ 因货物和劳务税存在转嫁，微观税负指标往往只能作为**参考性指标** |

## 四、公式与计算（本章计算题重点）

### 4.1 税收负担衡量指标

**（1）宏观税负**

```
国民生产总值（或国内生产总值）负担率 = 税收收入总额 ÷ 国民生产总值（或国内生产总值）× 100%
国民收入负担率                 = 税收收入总额 ÷ 国民收入 × 100%
```

> 两者比较：**国民收入负担率更能准确地衡量一国总体的税收负担水平**。

**例题 4-1（宏观税负）** 某国一定时期税收收入总额为 3000 亿元，国民生产总值为 50000 亿元，国民收入为 40000 亿元。
演算：GNP 负担率＝3000÷50000×100%＝**6%**；国民收入负担率＝3000÷40000×100%＝**7.5%**。
结论：同一国家两个指标数值不同，衡量总体税收负担水平应看**国民收入负担率**。

**（2）微观税负**

```
企业（个人）综合税收负担率 = 各项税收总和 ÷ 企业总产值（个人毛收入）× 100%
直接税负担率            = 所得税（含财产税）÷ 纯收入 × 100%
货物和劳务税税收负担率   = 实纳货物和劳务税税额 ÷ 同期销售（营业）收入 × 100%
企业所得税税收负担率     = 实纳所得税税额 ÷ 同期实现利润总额 × 100%
个人所得税税收负担率     = 实纳个人所得税税额 ÷ 同期个人收入总额 × 100%
企业增值税税收负担率     = 实纳增值税税额 ÷ 同期实现营业收入总额 × 100%
```

**例题 4-2（货物和劳务税负担率，2025 年真题改编）** 某企业当年取得营业收入 1000 万元，营业利润 200 万元，缴纳增值税 10 万元、消费税 15 万元、车船税 1 万元。
演算：货物和劳务税＝增值税 10＋消费税 15＝**25 万元**（**车船税属财产税，不计入**；营业利润 200 万元为干扰项）；
货物和劳务税收负担率＝25÷1000×100%＝**2.5%**。
答案：**A（2.5%）**。

**例题 4-3（企业所得税负担率，2022 年真题）** 某企业 2021 年度销售收入额 1000 万元，投资收益 300 万元，实现利润总额 300 万元，缴纳企业所得税 25 万元。
演算：企业所得税税收负担率＝25÷300×100%≈**8.33%**（分母是**利润总额 300**，不是销售收入 1000）。
答案：**A（8.33%）**。

**例题 4-4（增值税负担率，2022 年补考真题）** 某企业 2021 年度销售收入额 1000 万元，营业外收入 100 万元，增值额 200 万元，利润总额 50 万元，缴纳增值税 56 万元。
演算：企业增值税税收负担率＝56÷1000×100%＝**5.6%**。
答案：**B（5.6%）**。

### 4.2 税收弹性（定性）

素材仅给出概念性表述：**税收弹性包含税收收入弹性和税率弹性两个方面**；**弹性原则**要求税收收入应随着财政支出的需要进行调整。本章素材**未给出税收弹性的量化计算公式**，考题以定性判断为主——紧缩性财政政策下税收负担加重，扩张性财政政策下税收负担减轻。

### 4.3 税负转嫁与归宿的方向判断（本章无定量公式，考方向）

素材给出的判断规则（可据以做"边界演算"）：
- 需求**完全无弹性** → 税负**全部由需求方负担**（前转比例 100%）；
- 需求**完全有弹性** → 税负**全部由供给方负担**（前转比例 0%）；
- 供给**完全无弹性** → 税负**全部由供给方负担**；供给**完全有弹性** → 税负**全部由需求方负担**。

**例题 4-5（转嫁方向判断）** 某商品需求完全无弹性、供给弹性较大，政府对该商品征税。
演算：按规则，需求完全无弹性时税负全部由需求方负担，且"供给弹性较大、需求弹性较小的商品征税较易转嫁"，故该税基本上可通过**提高价格前转**给购买者；若该商品需求完全有弹性，则税负将**全部由供给方负担**，无法前转。

### 4.4 累进税率与速算扣除数

```
全额累进税额 = 全部数额 × 对应一级税率
超额累进税额 = Σ（各级距数额 × 各级距税率）
速算扣除数   = 全额累进税额 − 超额累进税额
应纳税额     = 应纳税所得额 × 适用税率 − 速算扣除数
```

**例题 4-6（超额累进，含速算扣除数验证）** 王先生应纳税所得额为 30000 元，适用三级累进税率：①不超过 20000 元的部分 20%；②超过 20000 元至 50000 元的部分 30%；③超过 50000 元的部分 40%。

演算：
- 未用速算扣除数：应纳税额＝20000×20%＋（30000－20000）×30%＝4000＋3000＝**7000 元**；
- 全额累进：应纳税额＝30000×30%＝**9000 元**；
- 速算扣除数＝9000－7000＝**2000 元**；
  验证公式：第二级速算扣除数＝（30%－20%）×20000＋0＝**2000 元**；
- 用速算扣除数：应纳税额＝30000×30%－2000＝9000－2000＝**7000 元**（与分段计算一致）。

**例题 4-7（速算扣除数反推，2025 年真题）** 王先生应税所得按全额累进税率计算的应纳税额为 3520 元，按超额累进税率计算的应纳税额为 1000 元。
演算：本级速算扣除数＝全额累进税额－超额累进税额＝3520－1000＝**2520 元**。
答案：**D（2520）**。

**例题 4-8（速算扣除数反推，2022 年真题）** 李某工资薪金按超额累进税率计算的应缴个人所得税为 2000 元，速算扣除数为 600 元。
演算：全额累进税额＝超额累进税额＋速算扣除数＝2000＋600＝**2600 元**。
答案：**B（2600）**。

### 4.5 超率累进税率（土地增值税）

```
应纳税额 = 增值额 × 适用税率 − 扣除项目金额 × 速算扣除系数
```

**例题 4-9（超率累进）** 某房地产项目土地增值额为 300 万元，扣除项目金额为 200 万元。
演算：增值额与扣除项目金额的比率＝300÷200＝**150%**，落入第三级"超过 100% 至 200% 的部分"，适用税率 **50%**，速算扣除系数 **15%**；
应纳税额＝300×50%－200×15%＝150－30＝**120 万元**。

### 4.6 国际重复征税免除的计算

**（1）低税法**

```
居住国对境外所得按单独较低税率计征 + 对境内所得按本国税率计征
总税负 = 居住国实缴 + 国外已纳税额
```

**例题 4-10（低税法）** 甲国 A 公司 2017 年境内、外所得总计 200 万元，其中来自境内所得 160 万元，来自设在乙国的分公司所得 40 万元，在乙国已纳所得税额为 12 万元。甲国税率为 30%，但对本国居民来自境外所得实行 15% 的低税率。
演算：来自乙国的 40 万元所得应纳税额＝40×15%＝**6 万元**；来自境内的 160 万元所得应纳税额＝160×30%＝**48 万元**；A 公司需在甲国缴纳所得税＝6＋48＝**54 万元**；总税负＝54＋12＝**66 万元**。
结论：其中 6 万元属重复征税部分，说明**低税法并未彻底解决国际重复征税**，只是使之得到一定缓解，缓解程度取决于所得税税率降低的幅度。

**（2）免税法**

```
居住国应纳税所得额 = 总所得 − 境外所得
居住国应纳税额     = 境内所得 × 本国税率
总税负             = 居住国应纳税额 + 国外已纳税额
```

**例题 4-11（免税法）** A 国甲公司某一纳税年度总所得 300 万元，其中来自 A 国 200 万元、B 国 100 万元。A 国税率 40%，B 国税率 30%，A 国对境外所得实行免税法。
演算：A 国缴纳所得税＝200×40%＝**80 万元**；B 国缴纳所得税＝100×30%＝**30 万元**；总税负＝80＋30＝**110 万元**。
答案对应 2020 年真题选项 **C（110 万元）**。

**（3）扣除法**

```
居住国应纳税所得额 = 总所得 − 国外已纳所得税额
居住国应纳税额     = 居住国应纳税所得额 × 本国税率
总税负             = 居住国应纳税额 + 国外已纳税额
```

**例题 4-12（扣除法）** A 国 R 公司某一纳税年度总所得 300 万元，其中源自 A 国 200 万元、B 国 100 万元。A 国税率 35%，B 国税率 20%，A 国对境外所得实行扣除法。
演算：R 公司在 B 国缴纳所得税＝100×20%＝**20 万元**；在 A 国的应纳税所得额＝300－20＝**280 万元**；在 A 国应纳所得税＝280×35%＝**98 万元**；总税负＝98＋20＝**118 万元**。

**（4）抵免法（分国／综合／分项限额）**

```
分国抵免限额 = 某一外国应税所得额 × 本国税率
综合抵免限额 = 国外应税所得额 × 本国税率
分项抵免限额 = 国外某一单项所得额 × 本国税率
允许抵免额   = min(抵免限额, 国外实纳税额)
回国应补缴税款 = 抵免限额 − 允许抵免额（仅当限额 > 实纳税款时）
```

**例题 4-13（分国抵免限额）** 甲国居民 A 有来源于甲国所得 0 元、乙国所得 100 万元、丙国所得 80 万元，甲、乙、丙三国所得税税率分别为 40%、50%、30%，均实行属人兼属地税收管辖权，在分国抵免法下计算居民 A 在甲国应缴纳的所得税。

| 计算步骤 | 乙国 | 丙国 |
|---|---|---|
| 抵免限额 | （100＋80）×40%×100÷180＝**40 万元** | （100＋80）×40%×80÷180＝**32 万元** |
| 国外实纳税款 | 100×50%＝**50 万元** | 80×30%＝**24 万元** |
| 允许抵免额 | 40 万元（取小） | 24 万元（取小） |
| 回国补缴税额 | 0（限额＜实纳，不补） | 32－24＝**8 万元** |

结论：居民 A 来自国外所得回甲国应补缴所得税共计 **8 万元**。

**例题 4-14（综合抵免限额）** 同例题 4-13 资料，假设甲国采用综合抵免限额法。
演算：综合抵免限额＝（100＋80）×40%×（180÷180）＝**72 万元**；在国外实际纳税＝100×50%＋80×30%＝50＋24＝**74 万元**＞72 万元，实际抵免额为 **72 万元**；在甲国应补缴税额＝**0**。可见综合抵免可使不同国家的不足限额与超限额相互抵消，纳税人获得**最大限度的抵免**。

**例题 4-15（分项抵免限额）** 甲国居民 J 有来源于乙国经营所得 200 万元、特许使用权所得 50 万元；甲、乙两国经营所得的所得税税率分别为 30%、20%，特许使用权所得的所得税税率分别为 10%、15%，甲国实行分项抵免限额法。

| 计算步骤 | 经营所得 | 特许权使用费所得 |
|---|---|---|
| 抵免限额 | 200×30%＝**60 万元** | 50×10%＝**5 万元** |
| 国外实纳税款 | 200×20%＝**40 万元** | 50×15%＝**7.5 万元** |
| 允许抵免额 | 40 万元（＜限额，全额抵免） | 5 万元（＞限额，按限额） |
| 甲国补税 | 60－40＝**20 万元** | 5－5＝**0** |

合计在甲国应纳税额 **20 万元**。

**（5）税收饶让**

```
饶让抵免额 = 按居住国税法规定税率计算的应纳税额（视同已纳税款，而非实际缴纳额）
```

**例题 4-16（税收饶让）** 甲国某总公司在乙国设立一个分公司，该分公司来源于乙国所得 1000 万元，乙国所得税税率为 30%。乙国为鼓励外来投资，对该分公司减按 15% 的税率征收所得税。甲、乙两国均实行属人兼属地税收管辖权，两国之间签订了税收饶让协定，并对境外所得实行综合抵免限额法，甲国所得税税率为 40%。
演算：该分公司在乙国按税法规定应纳税额＝1000×30%＝**300 万元**，减按 15% 征税后实际只缴纳 1000×15%＝**150 万元**；乙国的抵免限额＝1000×40%＝**400 万元**。由于签订税收饶让协定，甲国政府对其在国外缴纳的所得税**不是按实际纳税额 150 万元抵免，而是按税法规定税率计算的 300 万元应纳税额给予抵免**；来源于乙国的所得可以抵免税额为 300 万元，在甲国应补税额＝400－300＝**100 万元**。

## 五、高频考点速记卡

1. **Q：税收的形式特征与产生条件？**
   A：特征为**强制性、无偿性、固定性**；产生条件——社会经济是**内在的、根本的决定因素**，**国家的存在和对资金的需求是必要的前提条件**。

2. **Q：税收三项基本职能及地位？**
   A：财政职能（**收入职能**）、经济职能（**调节职能**）、监督职能；**财政职能是首要的和基本的职能**；职能**由税收的本质决定**，具有客观性。

3. **Q：历史上第一次提出税收原则的是谁？三条标准是什么？亚当·斯密四原则是什么？**
   A：**威廉·配第**第一次提出，标准为**公平、简便、节省**；**亚当·斯密**在《国富论》中提出**平等、确定、便利、最少征收费用**四原则。

4. **Q：瓦格纳"四端九项"？**
   A：财政政策原则（收入充分、收入弹性）；国民经济原则（慎选税源、慎选税种）；社会公正原则（普遍、平等）；税务行政原则（确定、便利、节约）。

5. **Q：现代税收原则三大类及各自分项？**
   A：财政原则（**充裕、弹性、便利、节约**）；经济原则（**配置、效率**）；公平原则（**普遍、平等**）。

6. **Q：设计和实施税收制度最重要的原则？公平原则的两分项？**
   A：**公平原则**；分**普遍原则**与**平等原则**（横向公平＝相同境遇同税；纵向公平＝不同境遇异税）。

7. **Q：测定纳税人纳税能力的最好尺度？三个标准？**
   A：**收入**是最好尺度；三个标准为**收入、财产和消费支出**。判断境遇的标准一般包括**受益标准和能力标准**。

8. **Q：税收经济效率原则的检验标准？与"本身的效率原则"区别？**
   A：经济效率原则的检验标准是**税收额外负担最小化和额外收益最大化**；税收本身的效率原则是**节约行政费用、以最小税收成本取得最大税收收入**。

9. **Q：税制的基本要素与其他要素？**
   A：基本要素＝**纳税人、征税对象、税率**；其他要素＝**纳税环节、纳税期限、减税免税、违章处理**。

10. **Q：税制的中心环节、最活跃最有力的因素？区别税种的主要标志？**
    A：**税率**是中心环节、最活跃最有力因素；区别税种的主要标志是**征税对象**。

11. **Q：三种基本税率形式及典型税种？**
    A：**比例税率**（商品流转额，如增值税）；**累进税率**（超额累进用于个人所得税综合所得，超率累进用于土地增值税）；**定额税率**（从量计征，如车船税）。

12. **Q：速算扣除数的两个公式？**
    A：速算扣除数＝**全额累进税额－超额累进税额**；本级速算扣除数＝（本级税率－上一级税率）×上一级征税对象的最高数额＋上一级速算扣除数。应纳税额＝应纳税所得额×适用税率－速算扣除数。

13. **Q：起征点与免征额的区别？**
    A：起征点是"开始征税的起点"，达到起征点**全额征税**；免征额是"免予征税的数额"，超过免征额**只就超过部分征税**。

14. **Q：税基式减免与税额式减免各包括哪些？**
    A：税基式＝**起征点、免征额、项目扣除、跨期结转**；税额式＝**全部免征、减半征收、核定减免率、另定减征税额**。

15. **Q：我国现行税制多少个税种、几大类？单个税种中占比前两位？**
    A：**18 个税种、5 大类**；**增值税比重最高，其次是企业所得税**。

16. **Q：税制结构三种模式及典型国家？**
    A：**所得税为主体**（主要发达国家）；**货物和劳务税为主体**（一些发展中国家）；**双主体**（我国转型方向）。

17. **Q：宏观税负两个指标？哪个更准确？微观税负率的分母怎么找？**
    A：国民生产总值（或国内生产总值）负担率、**国民收入负担率**，后者**更能准确衡量一国总体税收负担水平**；微观上**企业所得税税负率分母是利润总额，增值税税负率分母是销售（营业）收入**。

18. **Q：税负转嫁的四种形式及别称？**
    A：**前转（顺转）、后转（逆转）、消转（税收转化）、税收资本化（资本还原）**。

19. **Q：税负转嫁的两个条件？**
    A：**商品经济的存在**；**自由的价格体制**。

20. **Q：需求弹性、供给弹性与税负前转、后转的关系？**
    A：需求弹性与前转**成反比**、与后转**成正比**；供给弹性与前转**成正比**、与后转**成反比**。需求完全无弹性→税负全由**需求方**负担；需求完全有弹性→全由**供给方**负担。

21. **Q：税负转嫁一般规律四条？**
    A：①供给弹性较大、需求弹性较小的商品征税较易转嫁；②**垄断性商品**较易转嫁（竞争性商品较弱）；③**货物和劳务税（间接税）**较易转嫁，**所得税（直接税）一般不能转嫁**；④**征税范围广**的税种较易转嫁。

22. **Q：国际重复征税产生的根本原因？免除的四种方法？哪种最有效、哪种能彻底解决？**
    A：根本原因是**各国税收管辖权的交叉**；方法有**低税法、扣除法、免税法、抵免法**；**抵免法目前最有效**，**免税法能彻底解决**但居住国利益损失较大。

23. **Q：三种抵免限额公式？哪种抵免最充分？**
    A：分国＝某一外国应税所得额×本国税率；综合＝国外应税所得额×本国税率；分项＝国外某一单项所得额×本国税率。**综合抵免可使纳税人获得最大限度的抵免**。

24. **Q：税收饶让的要点？**
    A：对境外**减免优惠部分视同已纳税款**给予抵免；是**税收抵免的延伸**；多发生在**发展中国家与发达国家之间**；不影响居住国行使居民管辖权的正当权益。

25. **Q：国际避税的三个基本手段？反避税三项措施？**
    A：手段＝**利用转让定价转移利润、利用避税地规避纳税义务、滥用国际税收协定**；措施＝**完善税法、加强税务管理、加强国际多边合作**。

## 六、典型真题（含解析）

> 以下收录素材中**全部带年份标签的真题，共 39 题**，按章节顺序排列；同一真题的不同网校版本已合并（选项顺序差异在解析中注明）。

### 第一节 税收概述

**1.【2022·多选】下列关于税收本质和职能的说法，正确的是（　）。**
A. 行使征收权的主体是国家　B. 税收的本质是由税收的职能决定的　C. 经济职能又称调节职能　D. 税收首要和基本的职能为经济职能　E. 财政职能也称收入职能
**答案：ACE**
**解析**：B 错——税收的职能是由税收的**本质**决定的，是税收本质的体现，选项因果颠倒；D 错——**财政职能（收入职能）**才是税收首要的和基本的职能，不是经济职能。

**2.【2014·多选】关于税收的说法，正确的有（　）。**
A. 征税权力归国家所有　B. 税收的职能具有客观性　C. 监督职能是税收的首要职能　D. 税收可以调节居民消费结构　E. 税收的监督职能涉及宏观和微观两个层次
**答案：ABDE**
**解析**：C 错——财政职能（收入职能）是税收首要的和基本的职能。B 对——尽管在不同社会形态和经济形态下税收形式不尽相同，但其体现特殊分配关系的本质是不变的，因此税收的职能具有客观性。D 对——税收可以调节居民消费结构（经济职能内容之一）。

**3.【2018·多选】税收的基本职能包括（　）。**
A. 分配职能　B. 收入职能　C. 货币职能　D. 调节职能　E. 监督职能
**答案：BDE**
**解析**：税收有三项基本职能：财政职能（**收入职能**）、经济职能（**调节职能**）和监督职能。

### 第二节 税收原则

**4.【2021·多选】关于税收原则的说法，错误的是（　）。**
A. 税收活动必须有利于资源配置　B. 一般情况下，税收应由本国全体公民共同负担　C. 亚当·斯密在《国富论》中第一次提出了税收原则　D. 检验税收经济效率原则的标准，是税收额外负担最小化和额外收益最大化　E. 经济原则是设计和实施税收制度的最重要的原则
**答案：CE**
**解析**：C 错——**威廉·配第**第一次提出税收原则理论（公平、简便、节省），亚当·斯密是在《国富论》中提出著名的税收**四**原则；E 错——**公平原则**（而非经济原则）是设计和实施税收制度的最重要的原则。A、B、D 本身说法正确，因题目选"错误的"，不选。

**5.【2022·多选】现代财政税收原则包括（　）。**
A. 充裕原则　B. 弹性原则　C. 便利原则　D. 节约原则　E. 配置原则
**答案：ABCD**
**解析**：财政原则包括**充裕、弹性、便利、节约**四项；配置原则属于**经济原则**，故不选 E。

**6.【2022·多选】现代税收的财政原则包括（　）。**
A. 充裕原则　B. 配置原则　C. 公平原则　D. 中性原则　E. 弹性原则
**答案：AE**
**解析**：财政原则包括充裕原则、弹性原则、便利原则、节约原则；本题选项中只有 A、E 属于财政原则（便利、节约未列入选项）。配置原则属经济原则，公平原则自成一类，"中性原则"素材未列为现代税收原则分项。

**7.【2025·多选】下列关于现代税收原则的说法，错误的有（　）。**
A. 税收的节约原则是指要以尽可能少的税务行政费用，获取应得的税收收入　B. 税收的配置原则是指税收活动必须遵循有利于资源有效配置的原则　C. 税收的经济效率原则是指应节约税收的行政费用　D. 税收的横向公平是指对社会经济条件不同的纳税人区别征税　E. 税收本身的效率原则是指税收应有利于资源的有效配置
**答案：CDE**
**解析**：C 错——"节约税收的行政费用"是**税收本身的效率原则**；E 错——"有利于资源的有效配置"是**税收的经济效率原则**，二者恰好被选项互换；D 错——横向公平是对**相同境遇（经济条件相同）**的纳税人课征**相同**的税收，对社会经济条件不同者区别征税属**纵向公平**。A、B 说法正确。

**8.【2025·单选】通过征税获得的收入要能满足一定时期财政支出的需要，体现的税收原则是（　）。**
A. 弹性原则　B. 充裕原则　C. 便利原则　D. 节约原则
**答案：B**
**解析**：充裕原则是指通过征税获得的收入要充分，能满足一定时期财政支出的需要。

**9.【2017·单选】下列原则中，属于体现税收公平内涵的是（　）。**
A. 税收制度由民意机关参与制定　B. 税收要保证国家财政收入充分并有弹性　C. 税收额外负担最小化　D. 对纳税人不同来源的收入予以不同的征税方式
**答案：D**
**解析**：A 是财政原则中**便利原则**的要求；B 属财政原则；C 是**税收经济效率原则**的检验标准。对同来源的收入加以区分、予以不同征税，也是**公平原则**的要求。

**10.【2018·单选】当代西方税收学界看来，设计和实施税收制度的最重要的原则是（　）。**
A. 效率原则　B. 公平原则　C. 经济原则　D. 财政原则
**答案：B**
**解析**：税收公平原则是设计和实施税收制度的最重要的原则，指国家征税要使各个纳税人承受的负担与其经济状况相适应，并使各个纳税人之间的负担水平保持均衡。

### 第三节 税制与税制结构

**11.【2020·单选】下列属于征税对象数额或相对比例越大，规定的等级税率越高情形的税率是（　）。**
A. 累进税率　B. 比例税率　C. 定额税率　D. 定率税率
**答案：A**
**解析**：累进税率是随征税对象数额或相对比例的增大而逐级提高税率的一种递增等级税率。

**12.【2020·多选】下列优惠方式属于税额式减免的有（　）。**
A. 全部免征　B. 减半征收　C. 核定减免率　D. 项目扣除　E. 跨期结转
**答案：ABC**
**解析**：D、E 属于**税基式减免**（通过直接缩小计税依据实现）；税额式减免是直接减少应纳税额，包括全部免征、减半征收、核定减免率以及另定减征税额等。

**13.【2022·单选】李某工资薪金总额为 20000 元，按照超额累进税率计算的应缴个人所得税为 2000 元，速算扣除数为 600 元，按照全额累进税率计算的个人所得税是（　）元。**
A. 2000　B. 2600　C. 600　D. 20000
**答案：B**
**解析**：速算扣除数＝全额累进税额－超额累进税额，故全额累进税额＝2000＋600＝**2600 元**。

**14.【2022·单选】下列关于税收制度的构成要素的说法中错误的是（　）。**
A. 征税对象规定了每一种税的征税界限，是一种税区别于另一种税的主要标志　B. 征税对象可以从质和量两方面进行划分　C. 税率是税收制度中最活跃、最有力的因素　D. 纳税人就是代扣代缴义务人
**答案：D**
**解析**：纳税人是直接负有纳税义务的单位和个人；代扣代缴义务人是按照税法规定负有代扣代缴义务的单位和个人，二者不是同一概念，**纳税义务人一定不是代扣代缴义务人、代收代缴义务人**。

**15.【2024·单选】下列关于起征点与免征额的说法中，正确的是（　）。**
A. 收入超过起征点的，只就超过部分纳税　B. 收入超过免征额的，应就全部收入纳税　C. 收入超过免征额的，应就超过部分纳税　D. 收入不超过起征点的，应就全部收入纳税
**答案：C**
**解析**：起征点达到即**全额征税**；免征额超过只就**超过部分**征税。A 把起征点当成了免征额，B、D 均与规则相反。

**16.【2024·单选】李某工资薪金按照超额累进税率计算的应交个人所得税为 800 元，按照全额累进税率计算的个人所得税是 1000 元，速算扣除数为（　）。**
A. 2000　B. 2600　C. 600　D. 200
**答案：D**
**解析**：速算扣除数＝全额累进税额－超额累进税额＝1000－800＝**200 元**。

**17.【2025·单选】王先生的应税所得按照全额累进税率计算出来的应纳税额为 3520 元，按照超额累进税率计算出来的应纳税额为 1000 元，则本级速算扣除数为（　）。**
A. 3520　B. 0　C. 1000　D. 2520
**答案：D**
**解析**：速算扣除数＝全额累进税额－超额累进税额＝3520－1000＝**2520 元**。（部分网校版本选项为 A.4520、B.3520、C.2520、D.1000，答案同为 2520 元）

**18.【2012·单选】王先生某月取得劳务收入为 5000 元，假设当地规定的起征点为 2000 元，则王先生本月应税收入为（　）元。**
A. 2000　B. 3000　C. 5000　D. 7000
**答案：C**
**解析**：起征点是征税数额达到一定数额开始征税的起点，收入达到起征点应按**全部收入**征税，故应税收入为 5000 元。若为免征额 2000 元，则应税收入才是 3000 元。

**19.【2022 补考·单选】下列关于税制结构的说法，正确的是（　）。**
A. 以所得税为主体的税制结构模式具有一定的累退性　B. 货物与劳务税具有一定的累进性　C. 货物与劳务税征税复杂，征税成本较高　D. 所得税税负不易转嫁，有利于实现税收的公平原则
**答案：D**
**解析**：A、B 错——**累退性**是以货物和劳务税为主体税制结构的局限性；C 错——货物与劳务税征管相对容易，征收成本较小。

**20.【2012·单选】下列税种中，属于财产和行为税类的是（　）。**
A. 增值税　B. 房产税　C. 消费税　D. 个人所得税
**答案：B**
**解析**：增值税、消费税属于货物和劳务税类，个人所得税属于所得税类；财产税类包括房产税、契税、车船税。

### 第四节 税收负担

**21.【2025·单选】某企业当年取得营业收入 1000 万元，营业利润 200 万元，缴纳增值税 10 万元、消费税 15 万元、车船税 1 万元，该企业当年货物和劳务税收负担率为（　）。**
A. 2.5%　B. 2.6%　C. 12.5%　D. 13%
**答案：A**
**解析**：货物和劳务税税收负担率＝实际缴纳的货物和劳务税税额÷同期销售（营业）收入×100%＝（10＋15）÷1000×100%＝**2.5%**。注意：**车船税属财产税，不计入货物和劳务税**；营业利润 200 万元是干扰项（若误用 200 作分母会错选 C）。

**22.【2022·单选】某企业 2021 年度销售收入额为 1000 万元，投资收益为 300 万元，实现的利润总额为 300 万元，缴纳的企业所得税为 25 万元，该企业的企业所得税税收负担率为（　）。**
A. 8.33%　B. 2.5%　C. 1.92%　D. 30%
**答案：A**
**解析**：企业所得税税收负担率＝企业在一定时期实际缴纳的所得税税额÷同期实现利润总额×100%＝25÷300×100%≈**8.33%**。分母是**利润总额 300**，不是销售收入 1000（误用则错选 B）。

**23.【2022 补考·单选】某企业 2021 年度销售收入额为 1000 万元，营业外收入为 100 万元，增值额为 200 万元，利润总额为 50 万元，缴纳增值税为 56 万元，该企业的增值税税负率为（　）。**
A. 2.8%　B. 5.6%　C. 3.4%　D. 2.6%
**答案：B**
**解析**：企业增值税税收负担率＝企业在一定时期实际缴纳的增值税税额÷同期实现营业收入总额×100%＝56÷1000×100%＝**5.6%**。

**24.【2021·单选】下列关于税收负担的说法中错误的是（　）。**
A. 经济发展水平高的国家，其税收负担相对较高　B. 中央集权制的国家税收负担要高一些　C. 当社会需求过旺时，应适当增加社会总体税负，以抑制需求的增长　D. 当国家实行紧缩性的财政政策时，税收负担会相对较轻
**答案：D**
**解析**：国家实行**紧缩性**财政政策时，需要增加税收、减少财政支出，这时税收负担会**加重**；实行**扩张性**财政政策时税收负担才会有所减轻。

**25.【2019·单选】关于税收负担的说法，错误的是（　）。**
A. 税收的加成使纳税人税收负担加重　B. 经济发展过热时应适当提高社会总体税负　C. 经济发展水平是税收负担的影响因素　D. 累进税率下，纳税人的边际税率等于实际税率
**答案：D**
**解析**：不考虑其他因素（如税收转嫁、税前扣除）时，实行**比例税率**，税率等于纳税人的实际税收负担率；**累进税率**下名义的边际税率与纳税人实际税收负担率是不同的，税率累进程度越大，名义税率与实际税率、边际税率与平均税率的差距也越大。

**26.【2020·单选】纳税人通过压低生产要素的进价从而将应缴纳的税款转嫁给生产要素的销售者或生产者负担的形式是（　）。**
A. 前转　B. 后转　C. 消转　D. 税收资本化
**答案：B**
**解析**：后转亦称"逆转"，是通过压低生产要素进价把税款转嫁给要素销售者或生产者负担的形式。

**27.【2022·单选】税负转嫁给最终消费者的是（　）。**
A. 后转　B. 前转　C. 旁转　D. 消转
**答案：B**
**解析**：前转亦称"顺转"，是纳税人通过提高价格把税款向前转移给商品或劳务的购买者或**最终消费者**负担的形式，是最典型和最普通的转嫁形式。

**28.【2024·单选】关于税负转嫁的说法，正确的是（　）。**
A. 商品需求弹性大小与税负向前转嫁的程度成正比　B. 商品供给弹性越小，税负后转的程度越小　C. 竞争性商品的转嫁能力较强　D. 征税范围广的税种较易转嫁
**答案：D**
**解析**：A 错——需求弹性与税负**前转成反比**、与后转成正比；B 错——供给弹性与前转成正比、与后转成反比，故供给弹性越小时**后转程度越大**；C 错——**垄断性商品**转嫁能力强，竞争性商品根据市场供求决定价格，转嫁能力较弱。（该题为 2014 年真题原题重现）

**29.【2024·单选】生产要素的生产者将税负转嫁给制造者，厂商通过对商品加价，税负最终由消费者承担，这属于税负转嫁中的（　）。**
A. 前转　B. 旁转　C. 消转　D. 混转
**答案：A**
**解析**：前转亦称"顺转"，是纳税人在进行货物或劳务交易时通过**提高价格**的方法，把税款向前转移给购买者或最终消费者负担的形式。

### 第五节 国际税收

**30.【2020·单选】按纳税人国籍、住所为标准确定国家行使税收管辖权范围的原则称为（　）。**
A. 属人兼属地主义原则　B. 属地兼属人主义原则　C. 属地主义原则　D. 属人主义原则
**答案：D**

**31.【2021·单选】关于税收管辖权的说法，正确的是（　）。**
A. 实行居民管辖权的国家有权对非本国居民来自本国境内的所得征税　B. 实行地域管辖权的国家有权对本国居民取得的境外所得征税　C. 税收管辖权的交叉会产生国际重复征税　D. 一国政府不能同时行使居民管辖权和地域管辖权
**答案：C**
**解析**：A 错——对非本国居民来自本国境内所得征税属**收入来源地（地域）管辖权**；B 错——对本国居民境外所得征税属**居民管辖权**；D 错——多数国家包括我国**同时实行**两种管辖权。

**32.【2018·多选】对应税收管辖权确立的属地主义和属人主义的不同原则，税收管辖权分为（　）。**
A. 收入来源地管辖权　B. 第三国管辖权　C. 地域管辖权　D. 双重管辖权　E. 居民管辖权
**答案：ACE**
**解析**：税收管辖权分为**收入来源地管辖权**和**居民管辖权**，其中收入来源地管辖权又称为**地域管辖权**，故 C 与 A 为同一概念的不同表述，同时入选。

**33.【2020·单选】已知甲国 A 企业某一纳税年度的总所得为 300 万元，其中源自甲国的所得为 200 万元，源自乙国的所得为 100 万元。甲国所得税率为 40%，乙国所得税率为 30%，且甲乙两国均实行属人兼属地税收管辖权，甲国政府对本国居民来自境外所得实行免税法，则 A 公司在该年度的应纳税额为（　）万元。**
A. 30　B. 80　C. 110　D. 130
**答案：C**
**解析**：免税法下甲国对境外所得单方面放弃征税，甲国应纳税额＝200×40%＝80 万元；乙国＝100×30%＝30 万元；合计**110 万元**。

**34.【2021·单选】甲国居民 A 有来源于甲国所得 100 万元、乙国所得 100 万元，甲、乙两国所得税税率分别为 30%、40%。已知甲、乙两国均实行属人兼属地税收管辖权，在抵免法下，居民 A 在甲国应纳税额为（　）万元。**
A. 10　B. 30　C. 40　D. 0
**答案：B**
**解析**：抵免限额＝100×30%＝30 万元；在乙国实纳＝100×40%＝40 万元＞抵免限额，允许抵免 30 万元；甲国应纳税额＝（100＋100）×30%－30＝**30 万元**。

**35.【2023·单选】甲国某居民有来源于甲国所得 100 万元、乙国所得 200 万元、丙国所得 300 万元，甲、乙、丙三国所得税税率分别为 50%、40%、60%，在分国抵免下，甲国应对上述所得征收所得税（　）万元。**
A. 20　B. 60　C. 70　D. 100
**答案：C**
**解析**：国内外应税所得额＝100＋200＋300＝600 万元。乙国抵免限额＝600×50%×200÷600＝**100 万元**，乙国实纳＝200×40%＝80 万元＜限额，允许抵免 80 万元，**补税 20 万元**；丙国抵免限额＝600×50%×300÷600＝**150 万元**，丙国实纳＝300×60%＝180 万元＞限额，允许抵免 150 万元，不补税。甲国应纳所得税＝100×50%＋20＝**70 万元**。（部分网校版本选项为 A.70 万、B.60 万、C.30 万、D.240 万，答案同为 70 万元）

**36.【2024·单选】甲国 A 企业，在乙国取得收入 100 万元，在丙国取得收入 200 万元，甲、乙、丙三国的企业所得税的税率分别是 20%、30%、10%，甲国实行分国抵免，则 A 企业在甲国应缴纳的企业所得税是（　）万元。**
A. 20　B. 10　C. 30　D. 0
**答案：A**
**解析**：乙国抵免限额＝100×20%＝20 万元，乙国实纳＝100×30%＝30 万元＞限额，允许抵免 20 万元，不补税；丙国抵免限额＝200×20%＝40 万元，丙国实纳＝200×10%＝20 万元＜限额，允许抵免 20 万元，**补税 20 万元**。故甲国应缴纳 **20 万元**。

**37.【2017·单选】假定甲国居民企业 A 在某纳税年度中的境内外总所得为 100 万元，其中来自甲国的所得 60 万元，来自乙国的所得 10 万元，来自丙国的所得 30 万元。甲、乙、丙三国的所得税税率分别为 30%、25% 和 20%。甲国同时实行属地与属人税收管辖权，针对本国居民的境外所得实行免税法，则 A 企业在该年度应向甲国缴纳的所得税税额为（　）。**
A. 60.0 万元　B. 30.0 万元　C. 21.5 万元　D. 18.0 万元
**答案：D**
**解析**：免税法下，甲国居民计算在甲国的应纳税额时，其来源于乙国、丙国的所得免税，故甲国缴纳的所得税＝60×30%＝**18 万元**。

**38.【2017·单选】关于税收饶让的说法，正确的是（　）。**
A. 税收饶让多发生在发达国家之间　B. 两国之间一般采取签订税收协定的方式确定税收饶让政策　C. 税收饶让主要是为了解决国际重复征税　D. 税收饶让会影响发达国家作为居住国行使居民管辖权的正当税收权益
**答案：B**
**解析**：A 错——税收饶让多发生在**发展中国家与发达国家之间**；C 错——税收饶让主要是为了**保障各国税收优惠措施的实际效果**；D 错——税收饶让**不影响**发达国家作为居住国行使居民管辖权的正当税收权益。

**39.【2018·案例分析题节选】A 国居民公司甲在某一纳税年度的总所得为 1000 万元，其中源自 A 国的所得为 700 万元，源自 B 国的所得 300 万元。A 国所得税率为 30%，B 国所得税率为 25%。已知 A、B 两国均实行属人兼属地税收管辖权。为避免国际重复征税问题，A 国政府可采取的方法为（　）。**
A. 低税法　B. 扣除法　C. 免税法　D. 抵免法
**答案：ABCD**
**解析**：国际重复征税的免除方法主要有**低税法、扣除法、免税法、抵免法**四种，四种均可采用。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"本质决定职能"颠倒成"职能决定本质" | 题干出现"本质""职能"谁决定谁，一律选**本质决定职能**；且**财政职能（收入职能）是首要和基本的职能**，不是经济职能 |
| 2 | 把威廉·配第和亚当·斯密的原则张冠李戴 | **配第第一次提出**（公平、简便、节省，三原则）；**斯密《国富论》四原则**（平等、确定、便利、最少征收费用）；**瓦格纳四端九项** |
| 3 | 认为"经济原则"是设计和实施税收制度最重要的原则 | 是**公平原则**（瓦格纳称社会正义原则）。经济原则只讲配置与效率 |
| 4 | 混淆"税收的经济效率原则"与"税收本身的效率原则" | 经济效率＝**额外负担最小化、额外收益最大化**（管资源配置）；本身效率＝**节约行政费用、最小成本换最大收入**（管征收成本）。题干互换即错 |
| 5 | 把横向公平理解成"区别征税" | **横向公平＝相同境遇征相同的税**；**纵向公平＝不同境遇征不同的税**。判断境遇看**受益标准和能力标准** |
| 6 | 认为纳税人＝代扣代缴义务人 | 纳税人是直接负有纳税义务者；代扣代缴义务人**不承担纳税义务**，只是源泉控制。**纳税义务人一定不是代扣代缴、代收代缴义务人** |
| 7 | 认为纳税人一定等于负税人 | 只有**直接税**中纳税人才等于负税人；**间接税**中纳税人不等于负税人（这正是税负转嫁的前提） |
| 8 | 把税目和计税依据的作用记混 | **税目**体现征税的**广度**（质的细化）；**计税依据**是算多少钱（量的细化，从价看金额、从量看重量/体积/数量） |
| 9 | 把起征点和免征额的税务处理记反 | 起征点是"**起点**"——达到即**全额征税**；免征额是"**免除额**"——超过只就**超过部分**征税 |
| 10 | 把税基式减免和税额式减免的具体形式记混 | **税基式**：起征点、免征额、项目扣除、跨期结转（**缩税基**）；**税额式**：全部免征、减半征收、核定减免率、另定减征税额（**减税额**） |
| 11 | 速算扣除数用错方向或记错公式 | 速算扣除数＝**全额累进税额－超额累进税额**；应纳税额＝所得额×税率**－**速算扣除数（是减不是加） |
| 12 | 把三种税制结构模式的优势/局限张冠李戴 | **累退性**是货物和劳务税主体结构的局限；所得税主体结构的局限是抑制积极性＋征管复杂成本高 |
| 13 | 企业所得税税负率、增值税税负率的分母记错 | **企业所得税税负率找利润总额**；**增值税税负率找销售（营业）收入**。题干常同时给出多个数字做干扰 |
| 14 | 算货物和劳务税负担率时把车船税等财产税也算进去 | 货物和劳务税只含**增值税、消费税、关税**等货物劳务税类；车船税、房产税属财产税，不计入 |
| 15 | 认为紧缩性财政政策下税收负担较轻 | **紧缩→增税减支→税负加重**；**扩张→税负减轻**。二者恰好相反 |
| 16 | 认为微观税负指标能精确反映实际负担 | 因货物和劳务税存在**转嫁**，微观税负指标往往只能作为**参考性指标** |
| 17 | 税负转嫁四种形式的方向、别称、手段记混 | 前转＝顺转＝**提价**给消费者；后转＝逆转＝**压进价**给生产者；消转＝税收转化＝**自行消化**；税收资本化＝资本还原＝**扣购入价**给出售者 |
| 18 | 认为税收资本化可发生在任何交易中 | 只发生在某些**资本品**交易中（如土地税使地价下降，实际由出售者负担） |
| 19 | 需求弹性/供给弹性与前转、后转的关系记反 | 需求弹性：前转**反比**、后转**正比**；供给弹性：前转**正比**、后转**反比**。**完全无弹性的一方不承担税负，完全有弹性的一方承担全部税负** |
| 20 | 认为所得税（直接税）容易转嫁 | **间接税（货物和劳务税）易转嫁**；**直接税（所得税）一般由纳税人负担，不能转嫁** |
| 21 | 认为"各国都开征所得税"是国际重复征税的根本原因 | 那只是**重要前提**；**根本原因是各国税收管辖权的交叉** |
| 22 | 把低税法、扣除法当成能彻底解决重复征税 | 二者都**不能彻底解决**；**免税法能彻底解决**（但居住国损失大）；**抵免法目前最有效** |
| 23 | 认为税收饶让按实际纳税额抵免、多发生在发达国家之间 | 饶让按**税法规定税率计算的税额视同已纳税**给予抵免；多发生在**发展中国家与发达国家之间**；且**不影响**居住国行使居民管辖权的正当权益 |
| 24 | 认为综合抵免、分国抵免、分项抵免效果一样 | **综合抵免**可使不足限额与超限额相互抵消，纳税人获得**最大限度抵免**；**分国**一国一额；**分项**按项目单独算（防避税） |
| 25 | 把国际避税当成违法行为 | 国际避税是以**不违法的手段**减轻或消除税负，利用的是**税法差异和漏洞**；反避税靠完善税法、加强税务管理、加强国际多边合作 |
