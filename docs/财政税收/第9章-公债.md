## 二、知识点精讲

### 考点1 公债的含义与特征 ★★（46版本标★★★）

**核心概念**：政府举借的债务称为**公债**。

**（一）按举债层级分类**

| 举债层级 | 名称 | 定义（素材原文） |
|---|---|---|
| 中央政府 | **国债** | 中央政府在国内外发行债券或向外国政府和银行借款所形成的国家债务 |
| 地方政府 | **地方债** | 地方政府举借的各种类型的债务 |

**（二）按举债主体分类**

| 举债主体 | 债务类型 | 担保物 |
|---|---|---|
| 政府 | **公债** | **政府信誉** |
| 私人、企业 | 私债（民间债务） | 财产、收益 |

> 公债的担保物是政府信誉，可靠性强于私债，通常将公债称为**"金边债券"**。与私债相比：**无需担保物；信誉高，可靠性强**。
> **准公债**：在公债和私债之间的一种债，如**国有企业债和政府担保债**。

**（三）公债的特点（与税收对比，素材两种表述并列）**

| 比较对象 | 公债 | 税收 |
|---|---|---|
| 收入性质 | **非经常性**的财政收入 | 经常性的财政收入 |
| 偿还性 | **有偿性**：有借有还，到期不仅还本还要支付一定利息（遵循信用原则）；既具有偿还性，又是一种**预期的财政支出** | 无偿性 |
| 认购方式 | **自愿性**（非强制性）：除某种特殊情况下发行的强制公债以外，人们是否认购、认购多少，完全由认购者自己决定 | 强制征收 |
| 可靠性 | 担保物是政府信誉，具有可靠性，被称为"金边债券" | —— |

> 另有来源将特点归纳为**灵活性、自愿性、偿还性**；还有来源归纳为**有偿性、非强制性、可靠性**。三种表述指向一致，考试按题意匹配即可。

**（四）公债产生的条件（两个基本条件）**

1. **财政支出需要**；
2. **社会闲置资金的存在**。

> 补充（素材原文）：一般认为，公债产生于**奴隶社会**。时至今日，公债已成为世界各国筹集财政资金的重要形式和调节宏观经济的重要工具。

**逻辑链**：

```
财政支出需要 ＋ 社会闲置资金的存在
        ↓ 公债产生
政府举借的公债（担保物＝政府信誉，"金边债券"）
        ↓ 按举债层级
国债（中央政府：国内外发债或向外国政府、银行借款）／地方债（地方政府）
        ↓ 按举债主体
公债（政府信誉）／私债（财产和收益）／准公债（国有企业债和政府担保债）
```

**速记口诀**：**"两级三类一信誉"**——举债层级分中央/地方两级；举债主体分公债/私债/准公债三类；公债只凭政府信誉，故称"金边债券"。

### 考点2 公债发行的原则 ★★★

公债发行必须坚持**四项原则**：

| 原则 | 具体内容 |
|---|---|
| **景气发行原则** | 发行公债应根据社会经济状况而定，必须有利于社会经济的稳定和发展 |
| **稳定市场秩序原则** | 发行公债不应导致证券市场的巨大波动，特别是要维持**债券市场价格**的稳定 |
| **发行成本最小原则** | 公债的**利息支出及其他发行费用支出**应尽量节约，最大限度地降低筹资成本 |
| **发行有度原则** | 公债**发行量**要适度，既要考虑到财政资金运用的需要，也要考虑到社会、居民的**应债能力** |

**景气发行的双向调节（理解要点）**：

```
社会总需求 ＞ 总供给 → 发行公债起到抑制社会总需求、降低经济增长速度的作用
社会总供给 ＞ 总需求 → 发行公债起到刺激总需求、提高经济增长速度、促进经济复苏的作用
```

**发行成本最小原则的三方面含义**（素材明确，多选题考点）：
1. 在每次发行公债时都能使用在当时条件下最低成本来筹集所需要的资金；
2. 降低全部公债的成本；
3. 降低利息和其他各种发行费用。

**速记口诀**：**"度本景稳"**——发行有**度**、成本最小为**本**、**景**气发行、**稳**定市场秩序。（注意顺序是"度本景稳"，不是"景气稳定"）

### 考点3 公债发行的方式 ★★★

世界各国通用的公债发行方式主要有**四种**：

| 发行方式 | 具体内容 | 路径示意 |
|---|---|---|
| **直接发行方式** | 发行主体直接向个人或机构投资者销售公债 | 政府 → 投资者 |
| **承购包销方式** | 发行主体与承销人共同协商发行条件，签订承销合同，明确双方权利义务关系，由承销人向投资者分销 | 政府 → 承销商 → 投资者 |
| **公募招标方式** | 通过金融市场公开招标、投标确定发行条件；招标投标方式通过市场机制确定发行条件，具有较强的适应性和生命力，**已经成为当今世界各国的主导发行方式** | 公开招标投标 |
| **连续发行方式** | 发行主体**不预先确定**发行条件，而是委托发行网点和代理销售机构**相机确定**，且可**随时调整**发行条件，调节发行量 | 委托网点随行就市 |

**速记口诀**：**"包公直连"**——承购包销、公募招标、直接发行、连续发行。

**易混辨析**：公募招标是"公开招标、投标确定条件"（**主导方式**）；连续发行是"不预先确定条件、委托网点相机确定、随时调整"。两者都涉及市场，但前者是招标竞价，后者是委托销售随行就市。

### 考点4 公债的偿还 ★★

公债偿还，指政府按期偿还公债的本金和支付利息。

**（一）公债偿还的资金来源（三个）**

| 资金来源 | 具体内容 |
|---|---|
| **通过预算安排（预算列支）** | 政府将每年的公债偿还数额作为**财政支出的一个项目**列入当年的支出预算，由**经常性的财政收入**保证公债的偿还 |
| **设立偿债基金** | 政府在财政预算中设置**专项基金**用以偿还公债，在公债还清之前不减少预算拨款，以期逐年减少债务，故也称**减债基金** |
| **举借新债** | 政府通过发行新债为到期债务的偿还筹措资金（"借新还旧"） |

**（二）偿还本金的方式（五种）**

| 方式 | 具体内容 |
|---|---|
| **市场购销偿还法** | 政府按照**市价**从债券市场回收（收回）公债券，进而使公债免除 |
| **抽签偿还法** | 政府在发行公债时规定将**定期抽签**，分期分批予以偿还（以中签年度作为偿还期） |
| **比例偿还法** | 将公债总额分为**若干份**，**逐年**按既定份额偿还 |
| **到期一次偿还法** | 实行在债券到期日按**票面额**一次性偿清全部的本金和利息的办法 |
| **调换偿还法** | 政府发行**新债券**偿还即将到期的**旧债券** |

**（三）公债的付息方式（两类）**

| 付息方式 | 做法 | 适用范围 |
|---|---|---|
| **按期分次支付法** | 将债券应付利息在债券存在期限内**分几次**（如每一年或半年）支付 | 期限**较长**或在持有期限内**不准兑现**的债券 |
| **到期一次支付法** | 将债券应付利息同偿还本金结合起来，在债券到期时**一次支付** | 期限**较短**或超过一定期限后**随时可以兑现**的债券 |

**逻辑链**：

```
公债偿还 ＝ 还本金 ＋ 付利息
   ├─ 资金来源：预算安排（经常性收入保证）／偿债基金（＝减债基金）／举借新债
   ├─ 还本五法：市场购销（市价回收）· 抽签（定期抽签）· 比例（分份逐年）
   │            到期一次（票面额偿清）· 调换（发新还旧）
   └─ 付息两法：按期分次（期限长/不准兑现）· 到期一次（期限短/可兑现）
```

**速记口诀**：**"来源三个：预算、基金、新债；还本五个：购签比例到调；付息两个：分次配长、一次配短"**。

### 考点5 公债管理制度 ★★（冲刺来源标★★★）

**（一）公债的发行管理权限**

| 要点 | 内容 |
|---|---|
| **中心问题** | 是否授予**地方政府**以公债**发行权**和相应的**管理权** |
| **主要依据** | 按照财政管理体制中设置财政机构的原则，**有一级政权就应设置一级财政** |
| 我国地方财政四级构成 | 省（自治区、直辖市）、市（自治州）、县（自治县、县级市）、乡（镇） |
| 权限延伸判断 | 乡（镇）财政建立时间比较短，业务上对县级财政依赖性较强，一般认为地方公债的发行管理权限应扩展到**县一级**比较合适 |
| 公债分类 | 中央公债（国债）、地方公债、**准公债**（国有企业债和政府担保债） |

**2018 年再次修订的《预算法》对地方发债的规定（高频考点，四条）**：

1. 地方各级预算按照**量入为出、收支平衡**的原则编制，除另有规定外，**不列赤字**；
2. 经国务院批准的省、自治区、直辖市的预算中必需的建设投资的部分资金，可以在**国务院确定的限额内**，通过发行地方政府债券举借债务的方式筹措。举借债务的规模，由**国务院报全国人民代表大会或者全国人民代表大会常务委员会批准**。省、自治区、直辖市依照国务院下达的限额举借的债务，列入**本级预算调整方案**，报**本级人民代表大会常务委员会**批准。举借的债务应当有偿还计划和稳定的偿还资金来源，**只能用于公益性资本支出，不得用于经常性支出**；
3. 除上述规定外，地方政府及其所属部门**不得以任何方式举借债务**；
4. 除法律另有规定外，地方政府及其所属部门**不得为任何单位和个人的债务以任何方式提供担保**。

**（二）公债的收入使用**

- 公债最早是为**弥补国家的财政赤字**而产生；
- 随着一些资本主义国家债务危机的发生，一些国家开始严格限制公债收入的使用方向。如**日本财政法**规定：国家的财政支出，必须用公债和借款以外的财源来解决；只有作为公共投资费用和投资贷款的财源，在国会议决的金额范围内，才可以发行公债和借入资金。**日本、德国、英国**等国家都限制（严格禁止）将债务收入用于弥补财政赤字；
- 社会主义国家历来强调公债使用的**生产性**，将公债作为国家增加建设资金的补充方式之一；我国**建设性预算赤字**可以通过发行公债筹措的资金予以弥补（经常性预算必须在当年平衡，建设性预算不必在各年内平衡；素材注明"这虽然限制了公债收入的使用方向和范围，但尚未在法律中明确规定"）。

**（三）公债的持有者（政府的债权人、发行对象）**

市场经济比较发达的国家，公债持有者通常包括**中央银行、商业银行、非银行金融机构、政府机构、企业和个人**。

| 持有者 | 素材要点 |
|---|---|
| **中央银行** | ①各国公债管理制度和有关法律中一般**禁止中央银行直接认购公债或直接承办发行公债**（如日本、美国、法国等）；②各国允许中央银行**持有**一定量的公债，这些公债是中央银行通过**公开市场业务、在公开市场上购买取得**的（不会引起通货膨胀） |
| **商业银行** | ①允许和鼓励商业银行参与国债市场是各市场经济国家的通行做法；②商业银行持有公债**有助于公债一级市场的形成**，是中央银行实施公开市场操作的**前提条件之一**，也是**成熟的公债市场的主要标志之一** |
| **机构** | ①机构持有公债可以**减少公债销售的环节**，有助于降低公债发行成本；②机构持有公债的目的是**投资**，长期持有有利于稳定公债市场；我国规定，**养老保险基金和待业保险基金结余主要用于购买公债** |
| **个人** | ①居民个人收入是**应债资金的主要来源**；②鼓励居民购买公债，可以充分发挥公债吸收社会闲散资金、变个人消费资金为国家生产建设资金的作用，也为个人提供了一种理想的投资渠道；③可以通过设立**公债投资基金**，提高公债发行的效率，并为长期公债的发行和公债市场的良性循环创造条件 |

> **多来源冲突标注**：02.公债概述（二）称"我国商业银行持有国债曾经有过不良后果，因此**目前商业银行不能持有公债**"。此说法与 01.公债概述"允许和鼓励商业银行参与国债市场是各市场经济国家的通行做法"及【21年真题】（"商业银行持有公债有助于公债一级市场的形成"为正确项、"中央银行不得持有公债"为错误项）相矛盾，**考试以"允许商业银行参与国债市场并持有公债"为准**。

**（四）公债流通**

| 维度 | 内容 |
|---|---|
| **广义**的公债流通 | 公债发行（通过流通市场）、转让和偿还（购销法）的**全过程** |
| **狭义**的公债流通 | 公债在流通市场上的**转让** |
| 制度内容 | 通常包括对公债流通**范围、办法、渠道以及价格决定方式**的一系列规定 |
| 基本规定 | **并非所有公债都能流通、转让**。不能在金融市场上交易转让的公债称为**不可转让公债**，一般都有特定的用途 |

**不可转让公债按期限分类**：

| 分类 | 具体内容 |
|---|---|
| **短期不可转让公债** | 主要形式是**预付税款券**，以**工商企业**为发行对象，期限**不超过1年**，按票面金额**打折发行、预扣利息**，到期按票面金额计算，到期日通常为企业各种重要税收的缴款日期 |
| **中长期不可转让公债** | ①对居民家庭发行的**储蓄债券**（限制其他投资者或单位购买：美国禁止商业银行认购，法国禁止所有金融机构认购，卢森堡只限于出售给个人）；②对特定金融机构发行的**专用债券**（很多国家推销具有强制性：美国根据各个信托基金账户的盈余数额摊派，西班牙根据商业银行和储蓄银行的存款增加额摊派） |

**速记口诀**：**"权限中心在地方，一级政权一级财政，权限到县；用途只准公益性资本支出，不准经常性；担保除法律另有规定外一律不准"**。

### 考点6 国债的基本管理办法——国债余额管理制度 ★★（素材未单独标星）

**核心定义**：从**2006年**开始，参照国际通行的做法，我国改行**国债余额管理制度**。国债余额管理制度，指立法机关**不具体限定中央政府当年国债发行额度**，而是通过**限定一个年末不得突破的国债余额上限**来限制国债规模的国债管理方式。

**国债余额包括三部分**（是中央政府以后年度必须偿还的国债价值总额，能够客观反映国债负担情况）：
1. 中央政府历年预算赤字和盈余相互冲抵后的**赤字累计额**；
2. 向国际金融组织和外国政府借款**统借统还部分**；
3. 经立法机关批准发行的**特别国债累计额**。

**我国国债余额管理制度的基本管理办法（五条）**：

1. 每年向全国人大作预算报告时，报告当年年度预算赤字和年末国债余额限额，全国人大予以审批；一般情况下，**年度预算赤字即为当年年度新增国债限额**；
2. 在年度预算执行中，如出现特殊情况需要**增加年度预算赤字或发行特别国债**，由**国务院提请全国人大常委会审议批准**，相应追加年末国债余额限额；
3. **当年期末国债余额不得突破年末余额限额**；
4. 国债**借新还旧**部分由国务院授权**财政部**自行运作；
5. 每年**第一季度**，在中央预算批准前，由财政部在该季度到期国债还本数额以内合理安排国债发行额。

**逻辑链**：

```
国债余额管理（2006年起改行）
   ↓ 管什么
不限"当年发行额度"，限"年末不得突破的余额上限"
   ↓ 余额三构成
赤字盈余冲抵后的累计额 ＋ 统借统还外债 ＋ 特别国债累计额
   ↓ 怎么管
年度赤字＝当年新增国债限额（全国人大审批）
特殊情况追加限额（国务院提请全国人大常委会批准）
期末余额不得突破年末限额／借新还旧财政部自行运作
```

**速记口诀**：**"限额不限量，余额管总量；赤字等于新增限额，超限必须人大常委会"**。

### 考点7 公债市场的概念及其分类 ★

**概念**：公债市场是**证券市场的一个组成部分**，是进行公债交易的证券市场。政府通过证券市场发行和偿还公债，意味着公债进入了交易过程，而进行公债交易的证券市场即为公债市场。

**按构成分类（两大市场）**：

| 分类 | 别称 | 内容 | 地位 |
|---|---|---|---|
| **发行市场** | 一级市场、初级市场 | 为发行新债券提供销售场所，国家通过该市场**从认购者手中筹集到所需资金** | 发行市场的存在是**流通市场存在的前提条件** |
| **流通市场** | 二级市场 | 公债交易的**第二阶段**，一般承载**公债承购机构与认购者之间**的交易，也包括**公债持有者与政府或公债认购者之间**的交易 | 分为**场内交易**和**场外交易** |

**流通市场的场内/场外二分**：

| 分类 | 内容 | 特点 |
|---|---|---|
| **场内交易市场** | 在**证券交易所内**买卖债券所形成的市场 | 证券交易所是证券交易的组织者，**本身不参加债券的买卖和价格的决定**，只是为债券买卖双方创造条件、提供服务，并进行监管 |
| **场外交易市场**（又称"店头市场"或柜台交易市场） | 证券经纪商和证券自营商**不通过证券交易所**，而是在证券商之间或证券商与客户之间直接进行交易的证券分散买卖市场；还包括**银行间交易市场**，以及一些机构投资者通过电话、计算机网络等通信手段形成的市场 | 证券经营机构**既是交易的组织者，又是交易的参与者**；**柜台市场是场外交易市场的主体** |

> **我国债券流通市场由三部分组成**：即**证券交易所市场、银行间交易市场和证券经营机构柜台交易市场**。

**场外交易的方式（两种）**：

| 方式 | 内容 |
|---|---|
| **自由买卖公债** | 投资者根据证券商挂牌上市公布的买卖价格，直接与证券商自由洽谈买卖公债，如达成协议，即可成交 |
| **委托买卖公债** | 投资者委托证券商代其买卖公债，证券商**仅作为中介不参与买卖业务**，交易价格由委托买卖双方分别挂牌，双方价格达成一致后形成 |

**速记口诀**：**"一级筹钱、二级交易；场内交易所组织不参战，场外柜台既组织又参战"**。

### 考点8 公债市场的功能 ★

公债**既是财政政策工具，又是货币政策工具**。公债市场具有**两种功能**：

1. **实现公债的顺利发行和偿还**；
2. **合理有效地调节社会资金的运行，提高社会资金效率**。

**功能2的具体表现（五条，多选题高频）**：
1. 公债市场是一国**金融市场**的重要组成部分；
2. 公债市场是**连接货币市场和资本市场的渠道**；
3. 公债市场**拓宽了居民的投资渠道**；
4. 公债是**中央银行在公开市场上最重要的操作工具**；
5. 公债市场的发展有利于**完善商业银行资本结构，降低不良资产率**，使其**抗风险能力**大大增强。

**速记口诀**：**"一发一调：发行偿还顺顺利利，资金运行调高效"**——功能只有两条，"解决经常性财政支出的不足"不是公债市场的功能（21年真题干扰项）。

### 考点9 公债流通市场 ★★

**（一）我国债券流通市场的构成（三部分）**

> **证券交易所市场、银行间交易市场、证券经营机构柜台交易市场**。

**（二）公债流通市场的交易方式（四种）**

| 交易方式 | 定义（素材原文） | 关键词 |
|---|---|---|
| **现货交易** | 交易双方在成交后**即时清算交割**其债券和价款 | 即时交割 |
| **期货交易** | 公债买卖双方成交后按**契约中规定的价格、数量进行远期交割** | 远期交割 |
| **回购交易** | 公债交易商或投资者在**卖出**某种公债的同时，约定于未来某一时间以事先确定的价格**再买回**同一品牌、同等数量的公债；**实质是证券的卖出者借入资金** | 卖出＋约定买回 |
| **期权交易** | 公债交易双方为限制损失或保障利益而签订的，同意在约定时间内按协定价格买进或卖出契约中指定的债券，**也可以放弃**买进或卖出这种债券的交易方式 | 可放弃 |

> **逆回购交易**：与回购相反，交易商或投资者**买进**公债并约定于未来某一时间按事先确定的价格再将等量的同一牌名的公债卖给最初出售者，**实质是证券买入者向交易对象贷出资金**。

**公债回购和逆回购的四点作用**：
1. 作为一种**融资与融券相结合**的交易方式，将证券市场与货币市场相连接，扩大了经纪商承销公债的能力，扩大了公债一级市场的容量，从而有助于公债顺利发行以及公债运行机制的市场化改革；
2. 是**中央银行在公债市场开展公开市场业务操作的基本方式**，是实现货币政策的重要工具；
3. **公债回购率是公债期货价格确定的依据**；
4. 给短期资金富余者提供了投资机会，直接增加了市场对公债的需求，从而直接增加了公债的**流动性**。

> 目前，我国公债回购业务发展速度比较快，交易量大，逐渐成为重要的交易工具。

**（三）国债期货的发展沿革（时间线，素材原文）**

```
1993年 —— 开放国债期货市场，首先在上海证券交易所进行试点
   ↓ 由于期货交易的杠杆性以及过度的投机，造成市场的混乱和不成熟
1995年5月 —— 政府宣布暂停国债期货交易
   ↓ 经过多年的准备
2013年9月6日 —— 5年期国债期货正式在中国金融期货交易所上市交易，国债期货交易得以恢复
```

> 素材补充：目前我国**尚未开展公债的期权交易**。日本可以在证交所上市的公债只有长期国债和个别有代表性的政府保证券以及地方债，绝大部分公债流通是在证交所以外的市场（主要是柜台交易）上进行的；美国对政府短期债券流通的一般规定是买主和卖主均可委托证券商上市，价格决定方式为**约定价格和随行就市**两种。

**速记口诀**：**"现货即时、期货远期、回购是借钱、期权可放弃"**。

### 考点10 直接债务和或有债务的概念 ★

**两个层次的划分**：

| 划分标准 | 类型 | 含义 |
|---|---|---|
| 按是否必然承担 | **直接债务** | 无论在**任何情况下都要承担**的债务，**不依附于任何事件**，是可以根据某些特定的因素来预测和控制的负债，如政府的**内、外债**及由法律规定的**养老金负债**等 |
| | **或有债务** | 由某一**或有事项**引发的债务，能否会成为现实，需要看或有事项是否发生以及由此引发的债务能否最终由政府来承担。**不是政府能够完全控制的**，同时也**不一定最终完全转化为财政负担**，它取决于**转化的方向和转化的概率** |
| 按债务风险角度 | **显性债务** | 被**法律或者合同所认可**的政府债务 |
| | **隐性债务** | 反映**公众和利益集团压力**的政府**道义上**的债务 |

**四类债务与两类债务风险**：

```
直接债务（任何情况下都要承担，不依附于任何事件）
   ├─ 直接显性债务 ＝ 直接债务风险（由财政直接承担的债务）
   └─ 直接隐性债务 ┐
或有债务（看或有事项是否发生）                  ├─ 间接债务风险（由财政间接承担的国家预算体系以外的债务）
   ├─ 或有显性债务 ┘
   └─ 或有隐性债务
```

- 这种划分实际上指明了两类债务风险：一是**直接债务风险**，即由财政直接承担的债务，相当于**直接显性债务**；二是**间接债务风险**，即由财政间接承担的国家预算体系以外的债务，包括**直接隐性债务、或有显性债务和或有隐性债务**。

**速记口诀**：**"直接必然扛，或有看事项；显性有法依，隐性靠道义；直接风险只一家，其余三家算间接"**。

### 考点11 我国政府的债务类型 ★★★★（本章最高频）

| 类型 | 具体内容 | 巧思妙记 |
|---|---|---|
| **直接显性债务** | ①**政府公债**；②**欠发职工工资**而形成的债务；③**粮食收购和流通中的亏损挂账**（政策性因素造成的粮食收购和流通中的亏损挂账、棉花亏损挂账、外贸企业亏损挂账等）；④**乡镇财政债务** | **"政府欠粮乡"** |
| **直接隐性债务** | 主要是**社会保障资金缺口**所形成的债务，如**养老保险金、失业救济金**（养老保险资金缺口、失业救济负担） | **"社保缺口大"** |
| **或有显性债务** | ①**公共部门的债务**——内债来看，主要是非公债债务，其中**近80%属于政策性金融债券**；外债情况看，主要是国内企业和金融机构的对外负债、租赁公司及其他事业单位的对外负债，这些债务因为隐含了政府的担保，基本上也属于公共部门的负债；②**公债投资项目的配套资金** | **"部门需配套"** |
| **或有隐性债务** | ①**金融机构不良资产**；②**国有企业未弥补亏损**；③**对供销社系统及对农村合作基金会的援助** | **"金国来援助"** |

**防范直接隐性债务和或有债务风险**：

- **特点**：直接隐性债务和或有债务具有**隐蔽性强、风险源多、涉及面广、潜伏期长、不易察觉**等特点，既不在预算中反映，人们又缺乏对它们的认识。如果缺乏规范管理和有效的监督机制，一旦泛滥，则会对财政的稳定构成巨大的冲击，束缚国家宏观调控的空间。
- **认识偏差**：从实践来看，**各国政府都十分关注直接显性债务，而往往忽视直接隐性债务和或有债务**。
- **化解措施（必须通过深化改革）**：深化金融体制改革（充分发挥金融资产管理公司的作用，降低商业银行新增的不良贷款率，妥善处理不良资产损失的承担问题）；进一步完善社会保障制度（明确基本养老保险的有限责任，强化保险费的收缴与基金管理）；加快国有企业改革；加快资本市场建设的步伐；完善直接隐性债务和或有债务的科学规范的统计指标体系和管理体系，建立包括直接隐性债务和或有债务的**政府综合债务预警系统和分析系统**，建立统管机构，编制债务风险预算，逐步实现法治化管理等。

**速记口诀**：**"政府欠粮乡，社保缺口大，部门需配套，金国来援助"**——四句分别对应直接显性、直接隐性、或有显性、或有隐性。

### 考点12 地方政府债务的形成与治理、风险防范 ★（素材未标注星级）

**（一）地方政府债务的形成**

- 地方政府债务主要是指**地方政府融资平台公司向银行的借款**。
- **融资平台公司**：指由地方政府及其部门和机构等通过**财政拨款或注入土地与股权等资产**设立，承担政府投资项目融资功能并拥有**独立法人资格**的经济实体。

**融资平台公司债务（地方政府债务）的两类**：

| 项目类型 | 债务性质 |
|---|---|
| 承担**公益性项目**建设举借：项目本身有稳定经营性收入（**有收入无利润**）并主要依靠**财政性资金偿还**的债务 | 地方政府债务 |
| 承担**非公益性项目**建设举借：项目本身有稳定经营性收入并主要依靠**自身收益偿还**的债务 | 地方政府**或有债务**，或是变相的地方政府或有债务 |

**融资平台公司债务的三个特点**：
1. **普遍性**——全国各个地方政府都存在这种债务，只是多少的差别；
2. **融资数额巨大，增长快**；
3. **管理不统一，运作不规范**——不仅未纳入预算，甚至有的地方财政部门根本无权过问公司债务。

**（二）恢复地方债务管理，防范地方债务风险——《国务院关于加强地方政府性债务管理的意见》四项措施**

1. **加快建立规范的地方政府举债融资机制**：赋予地方政府依法适度举借权限，**剥离融资平台公司政府融资职能**，推广使用**政府与社会资本合作（PPP）模式**；
2. **对地方政府债务实行规模控制和预算管理**：实行**限额管理**，严格规定举债程序和资金用途，把地方政府债务分门别类纳入**全口径预算管理**；建立限额管理机制；**发行地方政府债券置换存量债务**，有效缓解了地方政府的偿债压力；目前地方政府债务已经**全部纳入预算管理**，财政部发布**一般债券和专项债券预算管理办法**，分别在**2016年**全国预算草案、地方预算草案和预算调整方案中完整反映地方政府债务情况，改变了以往政府债务游离于预算之外的局面，主动接受人大监督；
3. **控制和化解地方政府性债务风险**：建立地方政府性债务**风险预警机制**，建立**债务风险应急处理机制**，严肃财经纪律；
4. **妥善处理存量债务和在建项目后续融资**：抓紧将存量债务纳入预算管理，积极降低存量债务利息负担。

**逻辑链**：

```
地方政府债务形成：融资平台公司（财政拨款/注入土地股权设立，独立法人）向银行借款
   ↓ 一分为二
公益性项目（靠财政性资金偿还）→ 地方政府债务
非公益性项目（靠自身收益偿还）→ 地方政府或有债务
   ↓ 治理四招
建机制（剥离平台融资职能＋PPP）· 限规模入预算（限额＋置换债券＋全口径）
防风险（预警＋应急）· 化存量（纳入预算＋降利息）
```

## 五、高频考点速记卡

1. **Q：什么是公债？按举债层级分哪两类？**
   A：政府举借的债务。中央政府举借的称**国债**（国内外发债或向外国政府、银行借款形成的国家债务），地方政府举借的称**地方债**。

2. **Q：公债与私债的本质区别？**
   A：担保物不同——私债担保物是**财产和收益**，公债担保物是**政府信誉**，故公债可靠性强，称**"金边债券"**；公债与私债相比**无需担保物**。

3. **Q：什么是准公债？**
   A：公债与私债之间的一种债，如**国有企业债和政府担保债**。

4. **Q：公债产生的两个基本条件？**
   A：**财政支出需要**＋**社会闲置资金的存在**。

5. **Q：公债与税收的三大对比？**
   A：公债是**非经常性**财政收入（税收是经常性）；公债**有偿/偿还性**（税收无偿）；公债**自愿认购**（税收强制征收）。

6. **Q：公债发行的四原则及口诀？**
   A：**景气发行、稳定市场秩序、发行成本最小、发行有度**——口诀"**度本景稳**"。

7. **Q：景气发行原则如何双向调节？**
   A：总需求＞总供给时，发债**抑制**总需求、降低增速；总供给＞总需求时，发债**刺激**总需求、提高增速、促进复苏。

8. **Q：发行成本最小原则的三方面含义？**
   A：每次发行都用当时条件下最低成本筹集所需资金；降低全部公债成本；降低利息和其他各种发行费用。

9. **Q：公债发行四方式及口诀？**
   A：**直接发行、承购包销、公募招标、连续发行**——口诀"**包公直连**"。

10. **Q：当今世界各国的主导发行方式？**
    A：**公募招标方式**（通过金融市场公开招标、投标确定发行条件）。

11. **Q：连续发行方式的特点？**
    A：**不预先确定**发行条件，委托发行网点和代理销售机构**相机确定**，且可**随时调整**发行条件、调节发行量。

12. **Q：公债偿还的资金来源有几个？**
    A：三个——**通过预算安排、设立偿债基金（减债基金）、举借新债**。

13. **Q：偿还本金的五种方式？**
    A：**市场购销偿还法、抽签偿还法、比例偿还法、到期一次偿还法、调换偿还法**。

14. **Q：两种付息方式各适用什么债券？**
    A：**按期分次**适用于期限较长或持有期内不准兑现的债券；**到期一次**适用于期限较短或超过一定期限后可随时兑现的债券。

15. **Q：公债发行管理权限的中心问题和主要依据？**
    A：中心问题是**是否授予地方政府公债发行权和相应管理权**；主要依据是**有一级政权就应设置一级财政**；一般认为权限扩展到**县一级**较合适。

16. **Q：2018年《预算法》对地方发债的四条核心规定？**
    A：①量入为出、收支平衡，不列赤字；②限额内发债，规模由国务院报全国人大或其常委会批准，列入本级预算调整方案；③只能用于**公益性资本支出**，不得用于经常性支出；④不得违规举债、不得提供担保。

17. **Q：中央银行与公债的关系？**
    A：一般**禁止直接认购、直接承办发行**（如日本、美国、法国）；**允许**通过公开市场业务购买**持有**一定量公债。

18. **Q：公债市场的两大功能？**
    A：**实现公债的顺利发行和偿还**；**合理有效地调节社会资金的运行，提高社会资金效率**。

19. **Q：我国债券流通市场由哪三部分组成？**
    A：**证券交易所市场、银行间交易市场、证券经营机构柜台交易市场**。

20. **Q：公债流通市场的四种交易方式？**
    A：**现货交易**（即时交割）、**期货交易**（远期交割）、**回购交易**（卖出并约定买回，实质卖出者借钱）、**期权交易**（可放弃；我国尚未开展）。

21. **Q：直接债务与或有债务的区别？**
    A：直接债务是**任何情况下都要承担、不依附于任何事件**；或有债务由**或有事项**引发，是否成现实看事项是否发生及是否最终由政府承担，取决于**转化的方向和概率**。

22. **Q：显性债务与隐性债务的区别？**
    A：显性债务是**被法律或合同认可**的政府债务；隐性债务是反映**公众和利益集团压力**的政府**道义上**的债务。

23. **Q：两类债务风险如何划分？**
    A：**直接债务风险**＝直接显性债务（财政直接承担）；**间接债务风险**＝直接隐性＋或有显性＋或有隐性（财政间接承担的预算外债务）。

24. **Q：我国直接显性债务和或有隐性债务各包括什么？**
    A：直接显性＝**政府公债、欠发职工工资、粮食收购和流通中的亏损挂账、乡镇财政债务**（政府欠粮乡）；或有隐性＝**金融机构不良资产、国有企业未弥补亏损、对供销社系统及对农村合作基金会的援助**（金国来援助）。

25. **Q：国债余额管理制度管什么？**
    A：从**2006年**起改行；**不限定当年发行额度**，而是限定**年末不得突破的国债余额上限**；一般情况下**年度预算赤字即为当年新增国债限额**；期末余额不得突破年末限额。

## 六、典型真题（含解析）

> 以下收录素材中**全部带年份标签的真题，共 18 道**（单选 15 道、多选 3 道），答案与解析按素材原样保留。文末另附网校自编例题（无年份标签）供练习。

**1.【25年真题·单选】关于公债的说法，错误的是（　）。**
A. 公债是一种经常性的财政收入
B. 公债发行的前提是社会存在闲置资金
C. 公债发行遵循信用原则
D. 公债的担保物不是财产和收益

**答案：A**
**解析**：公债是一种**非经常性**的财政收入，经常性财政收入是税收。B、C、D 均为正确表述：公债产生需具备财政支出需要和社会闲置资金两个条件；公债发行必须遵循信用原则（有借有还、还本付息）；公债的担保物是政府信誉而非财产和收益。

**2.【20年真题·单选】"发行公债要维持债券市场价格的稳定"体现了公债发行的（　）原则。**
A. 发行成本最小　B. 稳定市场秩序　C. 发行有度　D. 景气发行

**答案：B**
**解析**：稳定市场秩序原则要求发行公债不应导致证券市场的巨大波动，**特别是要维持债券市场价格的稳定**。景气发行强调根据社会经济状况、有利于经济稳定发展；发行有度强调发行量适度、考虑应债能力。

**3.【20年真题·单选】发行主体不预先确定发行条件，而是委托发行网点和代理销售机构相机确定，且可随时调整发行条件，调节发行量的公债发行方式是（　）。**
A. 直接发行方式　B. 承购包销方式　C. 公募招标方式　D. 连续发行方式

**答案：D**
**解析**：连续发行方式即发行主体不预先确定发行条件，而是委托发行网点和代理销售机构相机确定，且可随时调整发行条件，调节发行量。

**4.【24年真题·单选】发行公债必须坚持的原则不包括（　）。**
A. 景气发行原则　B. 发行成本最小原则　C. 发行有度原则　D. 信用原则

**答案：D**
**解析**：公债发行四原则为景气发行、稳定市场秩序、发行成本最小、发行有度。信用原则强调"有借有还、还本付息"，不属于这四项发行原则之列。

**5.【21年真题·单选】将公债总额分为若干份，逐年按既定份额偿还的方法是（　）。**
A. 市场购销偿还法　B. 到期一次偿还法　C. 比例偿还法　D. 调换偿还法

**答案：C**
**解析**：比例偿还法即将公债总额分为若干份，逐年按既定份额偿还。市场购销偿还法是按市价从债券市场回收公债券；到期一次偿还法是到期日按票面额一次偿清；调换偿还法是发新债还旧债。

**6.【22年真题·单选】下列关于我国现行地方债管理制度的说法错误的是（　）。**
A. 在特定情况下，允许地方政府发行债券
B. 地方政府举借的债务只能用于资本性的公益支出
C. 地方政府举借的债务只能用于经常性的公益支出
D. 地方政府举借债务的规模，由国务院报全国人民代表大会或者全国人民代表大会常务委员会批准

**答案：C**
**解析**：地方举借债务**只能用于公益性资本支出，不得用于经常性支出**，C 项"经常性"说法错误。A、B、D 均为《预算法》的正确规定。

**7.【24年真题·单选】下列关于我国现行地方债管理制度的说法错误的是（　）。**
A. 在特定情况下，允许地方政府发行债券
B. 地方政府举借的债务只能用于资本性的公益支出
C. 地方政府举借的债务只能用于经常性支出
D. 地方政府举借债务的规模，由国务院报全国人民代表大会或者全国人民代表大会常务委员会批准

**答案：C**
**解析**：同上。举借债务只能用于**公益性资本支出**，"经常性支出"被法律明确禁止。（该题在两家网校素材中重复出现，属同一考点连年考查）

**8.【25年真题·单选】地方政府债券发行的主体是（　）。**
A. 中央政府　B. 市级政府　C. 县级政府　D. 省、自治区、直辖市政府

**答案：D**
**解析**：经国务院批准的**省、自治区、直辖市**的预算中必需的建设投资的部分资金，可以在国务院确定的限额内，通过发行地方政府债券举借债务的方式筹措。发行主体为省级政府，不是市、县级。

**9.【21年真题·单选】关于公债的说法中，错误的是（　）。**
A. 机构持有公债，可以减少公债销售环节
B. 个人持有公债，主要是为了储蓄
C. 中央银行不得持有公债
D. 商业银行持有公债，有助于公债一级市场的形成

**答案：C**
**解析**：各国一般禁止中央银行**直接认购**公债或**直接承办发行**公债，但**允许中央银行持有**一定量的公债（通过公开市场业务在公开市场上购买取得）。A、B、D 均为正确表述。

**10.【21年真题·多选】公债市场的功能有（　）。**
A. 提高社会资金效率　B. 合理有效调节社会资金的运行
C. 实现公债的顺利发行　D. 解决经常性财政支出的不足　E. 实现公债的顺利偿还

**答案：ABCE**
**解析**：公债市场两大功能：实现公债的顺利发行和偿还；合理有效地调节社会资金的运行，提高社会资金效率。**"解决经常性财政支出的不足"不是公债市场的功能**（属干扰项）。

**11.【24年真题·单选】公债买卖双方成交后按契约中规定的价格、数量进行远期交割的交易方式为（　）。**
A. 期货交易　B. 期权交易　C. 远期交易　D. 现货交易

**答案：A**
**解析**：期货交易是指公债买卖双方成交后按契约中规定的价格、数量进行**远期交割**的一种债券交易方式。现货交易是成交后即时清算交割。

**12.【25年真题·单选】公债的（　）是指公债交易双方为限制损失或保障利益而签订的，同意在约定时间内按协定价格买进或卖出契约中指定的债券，也可以放弃买进或卖出这种债券的交易方式。**
A. 现货交易　B. 期货交易　C. 回购交易　D. 期权交易

**答案：D**
**解析**：关键词是"**也可以放弃**买进或卖出"，这是期权交易的本质特征。目前我国尚未开展公债的期权交易。

**13.【20年真题·单选】下列政府债务中属于直接债务风险的是（　）。**
A. 直接显性债务　B. 直接隐性债务　C. 或有显性债务　D. 或有隐性债务

**答案：A**
**解析**：直接债务风险即由财政直接承担的债务，**相当于直接显性债务**；直接隐性债务、或有显性债务和或有隐性债务同属间接债务风险。

**14.【22年真题·多选】下列各项中属于我国政府直接显性债务的有（　）。**
A. 政府公债　B. 乡镇财政债　C. 欠发职工工资而形成的债务　D. 金融机构不良资产　E. 国有企业弥补亏损

**答案：ABC**
**解析**：直接显性债务包括政府公债、欠发职工工资而形成的债务、粮食收购和流通中的亏损挂账、乡镇财政债务。D 金融机构不良资产与 E 国有企业未弥补亏损均属**或有隐性债务**。

**15.【20年真题·单选】在我国，金融机构不良资产属于政府债务中的（　）。**
A. 或有隐性债务　B. 或有显性债务　C. 直接隐性债务　D. 直接显性债务

**答案：A**
**解析**：或有隐性债务包括金融机构不良资产、国有企业未弥补亏损、对供销社系统及对农村合作基金会的援助。

**16.【24年真题·单选】下列不属于或有隐性债务的是（　）。**
A. 国有企业未弥补亏损　B. 金融机构不良资产　C. 对供销社系统及对农村合作基金会的援助　D. 乡镇财政债务

**答案：D**
**解析**：或有隐性债务包括金融机构不良资产、国有企业未弥补亏损、对供销社系统及对农村合作基金会的援助，A、B、C 都属于。**D 乡镇财政债务属于直接显性债务**。（该题在两家网校素材中重复出现）

**17.【22年真题·单选】各国十分关注显性债务的原因不包括（　）。**
A. 直接显性债务主要是公债，是遵循严格的法律程序行事，即通过国家预算加以安排
B. 直接显性债务受立法机构的审批和监督，具有明确的刚性、透明性和法制性特征
C. 直接显性债务的规模决定直接隐性债务的规模
D. 对到期的直接显性债务，政府必须履行还本付息的义务，否则政府诚信将受损

**答案：C**
**解析**：各国政府十分关注直接显性债务，而往往忽视直接隐性债务和或有债务。直接显性债务通过预算安排、受立法机构审批监督、到期必须还本付息；但其规模**并不能决定**直接隐性债务的规模，C 项不构成关注原因。

**18.【25年真题·多选】下列各项中，属于我国政府直接显性债务的有（　）。**
A. 养老保险资金不足　B. 乡镇财政债务　C. 欠发职工工资而形成的债务　D. 金融机构不良资产　E. 国有企业未弥补亏损

**答案：BC**
**解析**：A 养老保险资金不足属**直接隐性债务**（社会保障资金缺口形成）；D、E 属**或有隐性债务**。直接显性债务仅包括政府公债、欠发职工工资形成的债务、粮食收购和流通中的亏损挂账、乡镇财政债务。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把公债当成"经常性财政收入" | 公债是**非经常性**财政收入，税收才是经常性的（25年真题） |
| 2 | 把"信用原则"算进公债发行四原则 | 四原则＝**景气发行、稳定市场秩序、发行成本最小、发行有度**（度本景稳）；信用原则指有借有还、还本付息（24年真题） |
| 3 | 把"维持债券市场价格稳定"归到景气发行 | **稳定市场秩序**管市场价格稳定；**景气发行**管根据社会经济状况、利于稳定发展（20年真题） |
| 4 | 把公募招标与连续发行混为一谈 | 公募招标＝**公开招标投标**定条件（世界主导方式）；连续发行＝**委托网点相机确定、随时调整**（20年真题） |
| 5 | 以为公债担保物是财产和收益 | 那是**私债**；公债担保物是**政府信誉**（25年真题D项） |
| 6 | 漏掉"准公债" | 准公债＝**国有企业债和政府担保债**，是公债与私债之间的债 |
| 7 | 混淆五种还本方式 | **比例**＝分份逐年；**抽签**＝定期抽签中签年还；**市场购销**＝市价回收；**到期一次**＝票面额偿清；**调换**＝发新还旧（21年真题） |
| 8 | 以为偿债基金是"第四种来源" | 偿还来源只有三个：**预算安排、偿债基金（＝减债基金）、举借新债** |
| 9 | 以为付息方式与债券期限无关 | **按期分次配长期限/不准兑现；到期一次配短期限/可随时兑现** |
| 10 | 以为乡镇可以发地方债 | 一般认为权限扩展到**县一级**较合适；现行发行主体是**省级政府**（25年真题） |
| 11 | 以为地方债可用于经常性支出 | **只能用于公益性资本支出**（22、24两年连考） |
| 12 | 以为地方政府可为国企债务担保 | 除法律另有规定外，**一律不得担保** |
| 13 | 以为"中央银行不得持有公债" | 禁止的是**直接认购、直接承办发行**；允许公开市场**购买持有**（21年真题） |
| 14 | 把一级、二级市场功能对调 | **发行市场（一级）筹集资金、是前提**；流通市场（二级）才是交易第二阶段 |
| 15 | 以为证券交易所参与买卖和定价 | 交易所**只组织、服务、监管**，不参加买卖和价格决定 |
| 16 | 以为柜台市场证券机构只是中介 | 柜台市场（场外）中证券经营机构**既是组织者又是参与者** |
| 17 | 把回购和逆回购搞反 | **回购**＝卖出并约定买回（**卖出者借钱**）；**逆回购**＝买入并约定卖出（买入者放贷） |
| 18 | 以为我国已开展公债期权交易 | 素材明确"**目前我国尚未开展**公债的期权交易" |
| 19 | 把金融机构不良资产归入直接债务 | 属**或有隐性债务**（20年真题）；国企未弥补亏损、对供销社及农金会援助也是 |
| 20 | 把"直接债务风险"理解成直接隐性债务 | 直接债务风险＝**直接显性债务**；其余三类（直接隐性、或有显性、或有隐性）都是**间接债务风险**（20年真题） |
| 21 | 以为国债余额管理制度是限制当年发行额度 | 限的是**年末不得突破的余额上限**；一般情况下**年度预算赤字＝当年新增国债限额** |
| 22 | 混淆"社会保障资金缺口"的归属 | 属**直接隐性债务**（社保缺口大），不是直接显性、也不是或有债务 |
