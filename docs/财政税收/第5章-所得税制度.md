## 二、知识点精讲

### 考点1 企业所得税的纳税人 ★

**核心概念**：在中华人民共和国境内，企业和其他取得收入的组织（以下统称企业）为企业所得税的纳税人。纳税人包括企业、事业单位、社会团体，**不包括个人独资企业和合伙企业**。

**判定标准是"是否具有法人资格"**：个人独资企业和合伙企业不具备法人资格，因此不是企业所得税的纳税人，其个人投资者按**"经营所得"**缴纳个人所得税。一些组织虽不冠名"企业"，但具备法人资格，也是企业所得税纳税义务人。

**外商独资企业**依据中国法律并且在中国境内成立，是**居民企业**纳税义务人。

| 分类 | 判定标准（满足其一即可） | 纳税义务 |
|---|---|---|
| **居民企业** | ①依法在中国境内成立；②依照外国（地区）法律成立但**实际管理机构在中国境内** | 全面纳税义务：来源于中国境内、**境外**的全部所得 |
| **非居民企业** | ①依照外国（地区）法律成立且实际管理机构不在中国境内，但在中国境内设立机构、场所；②在中国境内未设立机构、场所，但有来源于中国境内所得 | 有限纳税义务：境内所得（或与机构场所有实际联系的境内外所得） |

**逻辑链**：

```
是否具有法人资格？
├─ 否 → 个人独资企业/合伙企业 → 不缴企业所得税，个人投资者按"经营所得"缴个税
└─ 是 → 企业所得税纳税人
      ├─ 境内成立 或 实际管理机构在境内 → 居民企业 → 境内外全部所得，税率25%
      └─ 境外成立且实际管理机构在境外
            ├─ 境内设机构场所 → 有实际联系的所得 25%；无实际联系的境内所得 10%
            └─ 境内未设机构场所 → 境内所得 10%
```

**速记口诀**：**"法人资格是门槛，独资合伙不进门；注册地或实际管，二者居其一即居民"**。

> 素材提示：境外中资企业判定为实际管理机构在境内（居民企业）需同时符合 4 个条件：①高层管理人员及高层管理部门履行职责场所主要位于中国境内；②财务决策和人事决策由境内机构或人员决定或批准；③主要财产、会计账簿、公司印章、董事会和股东会议纪要档案等位于或存放于中国境内；④1/2（含）以上有投票权的董事或高层管理人员经常居住于中国境内。

### 考点2 企业所得税的征税对象 ★★

**征税对象**：企业的各项所得，包括销售货物所得、提供劳务所得、转让财产所得、股息红利等权益性投资所得、利息所得、租金所得、特许权使用费所得、接受捐赠所得和其他所得。

**居民企业 vs 非居民企业如何征税**：

| 纳税人 | 征税范围 |
|---|---|
| **居民企业** | 来源于中国境内、**境外**的全部所得 |
| 非居民企业·境内设立机构、场所 | ①所设机构、场所取得的来源于中国境内的所得；②发生在中国境外但与其所设机构、场所**有实际联系**的所得 |
| 非居民企业·境内未设立机构、场所 | 来源于中国境内的所得（虽设立机构、场所但取得的所得与其机构、场所**没有实际联系**的，同此项） |

**所得来源地确定（选择题高频，必背）**：

| 所得项目 | 来源地确定标准 |
|---|---|
| 销售货物所得 | **交易活动发生地** |
| 提供劳务所得 | **劳务发生地** |
| 转让不动产所得 | **不动产所在地** |
| 转让动产所得 | 转让动产的企业或者机构、场所所在地 |
| 转让权益性投资资产所得 | **被投资企业所在地** |
| 股息、红利等权益性投资所得 | **分配所得的企业所在地** |
| 利息、租金、特许权使用费所得 | 负担、支付所得的企业或者机构、场所所在地；或者负担、支付所得的**个人住所地** |
| 其他所得 | 由国务院财政、税务主管部门确定 |

**速记口诀**：**"货看交易劳看地，不动产地动产企，权益看被投，股息看分配，利息租金特许看支付"**。

> **非居民企业境内"机构、场所"范围**：①管理机构、营业机构、办事机构；②工厂、农场、开采自然资源的场所；③提供劳务的场所；④从事建筑、安装、装配、修理、勘探等工程作业的场所；⑤其他从事生产经营活动的机构、场所。委托营业代理人在境内从事生产经营活动（经常代签合同、储存交付货物等）的，该营业代理人**视为**非居民企业在境内设立的机构、场所。

### 考点3 企业所得税的税率 ★★

| 种类 | 税率 | 适用范围 |
|---|---|---|
| **法定税率** | **25%** | ①居民企业；②在中国境内设有机构、场所且取得的所得与机构、场所有实际联系的非居民企业 |
| **优惠税率** | **20%** | 符合规定条件的小型微利企业 |
| | **15%** | ①国家需要重点扶持的高新技术企业；②经认定的技术先进型服务企业；③设在西部地区的鼓励类产业企业（至 **2030 年 12 月 31 日**） |
| | **10%** | 非居民企业（在中国境内未设立机构、场所的，或者虽设立机构、场所但取得的所得与其机构、场所没有实际联系的） |

**小型微利企业（三个条件同时满足）**：
1. 年度应纳税所得额**不超过 300 万元**
2. 从业人数**不超过 300 人**
3. 资产总额**不超过 5000 万元**

从事国家非限制和禁止行业。**至 2027 年 12 月 31 日，对小型微利企业减按 25% 计算应纳税所得额，按 20% 的税率缴纳企业所得税。**

**西部地区鼓励类产业企业**：以《西部地区鼓励类产业目录》中规定的产业项目为主营业务，且主营业务收入占企业收入总额 **60% 以上**。

**高新技术企业认定条件**（拥有核心自主知识产权，同时符合）：
- 主要产品（服务）发挥核心支持作用的技术属于《国家重点支持的高新技术领域》范围；
- 企业近 3 个会计年度研究开发费用总额占同期销售收入总额的比例：最近 1 年销售收入**小于 5000 万元（含）的不低于 5%**；**5000 万元至 2 亿元（含）的不低于 4%**；**2 亿元以上的不低于 3%**。其中企业在中国境内发生的研究开发费用总额占全部研究开发费用总额的比例**不低于 60%**；
- 近 1 年高新技术产品（服务）收入占企业同期总收入的比例**不低于 60%**；
- 从事研发和相关技术创新活动的科技人员占企业当年职工总数的比例**不低于 10%**。

**速记口诀**：**"小微300/300/5000，高新6成又6成，西部鼓励到2030，非居民十折"**。

### 考点4 企业所得税的计税依据 ★

**计算原则**：
1. **权责发生制原则**：属于当期的收入和费用，不论款项是否收付，均作为当期的收入和费用；不属于当期的收入和费用，即使款项已经在当期收付，均不作为当期的收入和费用。
2. **税法优先原则**：在计算应纳税所得额时，财务、会计处理办法与税收法律、行政法规的规定不一致的，应当依据税收法律、行政法规的规定计算。

**两种计算方法**：

```
直接法：
  应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损

间接法：
  应纳税所得额 = 会计利润 + 纳税调整增加金额 − 纳税调整减少金额
```

**亏损弥补（数字必背）**：
- 亏损是指企业每一纳税年度的收入总额减除不征税收入、免税收入和各项扣除后小于零的数额；
- 企业纳税年度发生的亏损，准予向以后年度结转，用以后年度的所得弥补，**结转年限最长不得超过 5 年**；
- 自 **2018 年 1 月 1 日**起，当年具备高新技术企业或科技型中小企业资格的企业，其**具备资格年度之前 5 个年度**发生的尚未弥补完的亏损，准予结转以后年度弥补，**最长结转年限由 5 年延长至 10 年**。

**速记口诀**：**"一般企业5年，特殊企业10年"**。

### 考点5 企业收入确认 ★★★

**（一）一般收入项目的确认条件**

**销售货物收入**（4 个条件同时满足）：
1. 货物销售合同已经签订，企业已将货物所有权相关的主要风险和报酬转移给购货方；
2. 企业对已售出的货物既没有保留通常与所有权相联系的继续管理权，也没有实施有效控制；
3. 收入的金额能够可靠地计量；
4. 已发生或将发生的销售方的成本能够可靠地核算。

**提供劳务收入**（完工进度/完工百分比法，4 个条件同时满足）：
1. 收入的金额能够可靠地计量；
2. 交易的完工进度能够可靠地确定；
3. 交易中已发生和将发生的成本能够可靠地核算；
4. 相关的经济利益很可能流入企业。

**完工进度确定方法（3 种，多选高频）**：①已完工作的测量；②已提供劳务占劳务总量的比例；③发生成本占总成本的比例。

**（二）特殊收入项目的确认时间（必背）**

| 收入项目 | 确认时间 |
|---|---|
| 利息收入 | 合同约定的**债务人应付利息的日期** |
| 租金收入 | 合同约定的**承租人应付租金的日期**（租期跨年度且租金提前一次性支付的，可在租赁期内**分期均匀**确认） |
| 特许权使用费收入 | 合同约定的**特许权使用人应付特许权使用费的日期** |
| 股息、红利等权益性投资收益 | **被投资方作出利润分配决定的日期** |
| 接受捐赠收入 | **实际收到捐赠资产的日期** |
| 分期收款方式销售货物 | 合同约定的收款日期 |
| 产品分成方式取得收入 | 企业**分得产品的日期**（收入额按产品公允价值确定） |
| 受托加工制造大型机械设备、船舶、飞机及建筑安装等持续**超过 12 个月** | 纳税年度内**完工进度或者完成的工作量** |
| 转让股权收入 | **转让协议生效且完成股权变更手续时** |
| 债务重组收入 | 债务重组合同或协议**生效时** |

**（三）不征税收入（4 项）**
1. 财政拨款；
2. 依法收取并纳入财政管理的行政事业性收费；
3. 依法收取并纳入财政管理的政府性基金；
4. 国务院规定的专项用途财政性资金（须满足：从县级以上各级人民政府财政部门及其他部门取得；能提供规定资金专项用途的拨付文件；财政部门对该资金有专门管理办法或具体管理要求；企业对该资金及支出单独核算）。

**（四）免税收入（5 项）**
1. 国债利息收入（**国债转让收益要纳税**）；
2. 地方政府债券利息收入；
3. 符合条件的居民企业之间的股息、红利等权益性投资收益——居民企业**直接投资**于其他居民企业；**不包括**连续持有居民企业公开发行并上市流通的股票**不足 12 个月**取得的投资收益；
4. 在中国境内设立机构、场所的非居民企业从居民企业取得与该机构、场所有实际联系的股息、红利（同样不包括持股不足 12 个月部分）；
5. 符合条件的非营利组织的收入（接受捐赠收入；除财政拨款外的其他政府补助收入但不包括因政府购买服务取得的收入；按省级以上民政、财政部门规定收取的会费；不征税收入和免税收入孳生的银行存款利息收入；其他）。

**速记口诀**：**"不征税：财政资金不征税；免税：国债股利非营利"**。

### 考点6 企业所得税的税前扣除 ★★★★（本章最核心）

**（一）税前扣除四原则**
1. **真实性、相关性和合理性原则**：企业实际发生的与取得收入直接相关的合理支出（成本、费用、税金、损失）准予扣除；
2. **区分收益性支出和资本性支出原则**：收益性支出在发生当期直接扣除；资本性支出应分期扣除或计入有关资产成本，不得在发生当期直接扣除；
3. **不征税收入形成支出不得扣除原则**；
4. **不得重复扣除原则**。

**（二）限额扣除项目（数字必须一字不差）**

| 项目 | 扣除标准 | 超额是否结转 |
|---|---|---|
| 职工福利费 | 不超过**工资薪金总额 14%** | 否 |
| 工会经费 | 不超过**工资薪金总额 2%** | 否 |
| 职工教育经费 | 不超过**工资薪金总额 8%** | **是**，结转以后纳税年度 |
| 党组织工作经费 | 不超过**工资薪金总额 1%**（据实扣除） | 否 |
| 补充养老保险费 | 不超过**职工工资总额 5%** | 否 |
| 补充医疗保险费 | 不超过**职工工资总额 5%** | 否 |
| 业务招待费 | 按**发生额的 60%** 扣除，但最高不得超过当年**销售（营业）收入的 5‰** | 否 |
| 广告费和业务宣传费 | 一般企业不超过当年**销售（营业）收入 15%**；化妆品制造或销售、医药制造和饮料制造（不含酒类制造）企业不超过**30%**（2025 年 12 月 31 日之前） | **是**，结转以后纳税年度 |
| 公益性捐赠 | 不超过**年度利润总额 12%** | **是**，结转以后 **3 年**内 |
| 利息费 | 非金融企业向非金融企业借款：不超过**金融企业同期同类贷款利率**计算的数额 | 否 |

**速记口诀**：**"福工教育党组织，14、2、8、1；补充保险5个点；业务招待两个限额比一比，取最小；广宣一般15特殊30；捐赠利润12转3年"**。

**（三）据实扣除项目**
- 企业发生的合理的工资、薪金支出；
- 为职工缴纳的基本养老保险费、基本医疗保险费、失业保险费、工伤保险费等基本社会保险费和**住房公积金**；
- 为**特殊工种职工**购买的人身安全保险费；
- 企业参加的财产保险；
- 非金融企业向**金融企业**借款的利息支出、金融企业的各项存款利息支出和同业拆借利息支出、企业经批准发行债券的利息支出；
- 企业职工因公出差乘坐交通工具发生的**人身意外保险费**；
- 企业依照法律、行政法规有关规定提取的用于环境保护、生态恢复等方面的**专项资金**（提取后**改变用途的不得扣除**）；
- 非居民企业境内机构、场所分摊境外总机构费用（能提供总机构出具的费用汇集范围、定额、分配依据和方法等证明文件并**合理分摊**的）。

**（四）扣除基数"销售收入（营业收入）"的界定（易错）**
- 一般企业销售收入 = 主营业务收入 + 其他业务收入 + **视同销售收入**；
- **不包括**：营业外收入、投资收益、资产处置损益；
- 典型：股息红利、利息（会计作投资收益）；固定资产、无形资产转让（会计作营业外收入/资产处置损益）；股权转让——均不作为广宣费、业务招待费扣除限额的基数。

**（五）禁止税前扣除的项目（19 项，案例题高频）**

```
不得扣除：
① 向投资者支付的股息、红利等权益性投资收益款项
② 企业所得税税款
③ 税收滞纳金
④ 罚金、罚款和被没收财物的损失（经营性罚款可扣，行政性罚款不可扣）
⑤ 超标准的捐赠支出以及非公益性捐赠支出
⑥ 赞助支出
⑦ 未经核定的准备金支出
⑧ 企业为投资者或职工支付的商业保险费（特殊工种人身安全险等除外）
⑨ 环保专项资金提取后改变用途的部分
⑩ 企业之间支付的管理费、企业内营业机构之间支付的租金和特许权使用费、
   以及非银行企业内营业机构之间支付的利息
⑪ 企业对外投资期间持有的投资资产成本
⑫ 与关联方分摊成本时违反税法规定自行分摊的成本
⑬ 从关联方接受的债权性投资与权益性投资比例超过规定标准而发生的利息支出
⑭ 按特别纳税调整规定针对补缴税款向税务机关支付的利息
⑮ 不征税收入用于支出所形成的费用
⑯ 烟草企业的烟草广告费和业务宣传费支出
⑰ 按投资资产处理的用于收藏、展示、保值增值的文物、艺术品
⑱ 与取得收入无关的其他支出
⑲ 国务院财政、税务主管部门规定不得扣除的其他项目
```

**速记口诀**：**"不得扣除：税后支出、不合法支出、不合理支出、不合规支出"**。

**（六）经营性罚款 vs 行政性罚款（高频辨析）**

| 项目 | 税务处理 |
|---|---|
| 罚金、行政性罚款 | 不得税前扣除 |
| 经营性罚款（银行罚息、合同违约金等） | 准予税前扣除 |

### 考点7 企业所得税的税收优惠 ★★★★

**（一）税基式优惠**

**1. 农、林、牧、渔业项目**
- **免征**：①蔬菜、谷物、薯类、油料、豆类、棉花、麻类、糖料、水果、坚果的种植；②农作物新品种的选育；③中药材的种植；④林木的培育和种植；⑤牲畜、家禽的饲养；⑥林产品的采集；⑦灌溉、农产品初加工、兽医、农技推广、农机作业和维修等农林牧渔服务业项目；⑧远洋捕捞。
- **减半征收**：①花卉、茶以及其他饮料作物和香料作物的种植；②海水养殖、内陆养殖。
- **速记口诀**：**"花茶饮香海内"**（减半）；免征记"种培育养采集、加工捕捞"。

**2. 三免三减半**（自项目取得第一笔生产经营收入所属纳税年度起，第 1—3 年免征，第 4—6 年减半）

- 从事符合条件的环境保护、节能节水项目所得。

- 一个纳税年度内，居民企业技术转让所得**不超过 500 万元的部分免征**企业所得税；
- **超过 500 万元的部分减半征收**企业所得税。
- 居民企业转让专利技术、计算机软件著作权、集成电路布图设计权、植物新品种、生物医药新品种、5 年（含）以上非独占许可使用权等属于优惠范围。

**4. 减计收入**
- 企业综合利用资源，生产国家非限制和禁止并符合国家和行业相关标准的产品取得的收入，**减按 90% 计入收入总额**。

**5. 创业投资企业投资抵免（抵扣应纳税所得额）**
- 采取股权投资方式投资于**未上市的中小高新技术企业 2 年以上**的，按照其**投资额的 70%** 在股权持有满 2 年的当年**抵扣应纳税所得额**；当年不足抵扣的可以在以后纳税年度结转抵扣；
- 公司制创业投资企业采取股权投资方式**直接投资于种子期、初创期科技型企业满 2 年**的，同样按投资额的 70% 抵扣应纳税所得额。

**（二）加计扣除（计算题必考）**

### 考点8 企业所得税应纳税额的计算 ★★

```
应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额

应纳税所得额（直接法）= 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损
应纳税所得额（间接法）= 会计利润 + 纳税调整增加金额 − 纳税调整减少金额
```

**非居民企业应纳税所得额的计算**（未设机构场所，或虽设但无实际联系）：
1. 股息、红利等权益性投资收益和利息、租金、特许权使用费所得，以**收入全额**为应纳税所得额；
2. 转让财产所得，以**收入全额减除财产净值后的余额**为应纳税所得额（财产净值 = 计税基础 − 已扣除的折旧、折耗、摊销、准备金等）；
3. 其他所得，参照前两项规定。
- 扣缴企业所得税应纳税额 = 应纳税所得额 × 实际征收率。

**境外所得已纳税额抵免**

**（1）直接抵免**（适用于同一经济实体，如总分公司）
- 抵免对象：①居民企业来源于中国境外的应税所得；②非居民企业在中国境内设立机构、场所，取得发生在中国境外但与该机构、场所有实际联系的应税所得；
- 企业可以选择按**"分国（地区）不分项"**或**"不分国（地区）不分项"**方式计算抵免限额，**一经选择，5 年内不得改变**；
- 抵免限额公式：
  ```
  境外所得税税款抵免限额
    = 境内、境外所得按税法计算的应纳税总额 × 来源于某国（地区）的应纳税所得额 ÷ 境内境外应纳税所得总额
    = 来源于某国（地区）的应纳税所得额 × 25%
  ```
- **孰低原则：多不退少要补**。设境外已缴纳所得税额为 a，抵免限额为 b：
  - a < b：抵免 a，少缴的税款要在国内补缴；
  - a > b：抵免 b，(a−b) 为多缴税款，不能退，但可在以后 **5 个年度**内抵补。

**（2）间接抵免**（适用于跨国母子公司）
- 居民企业从其**直接或间接控制**的外国企业分得的来源于中国境外的股息、红利等权益性投资收益，外国企业在境外实际缴纳的所得税税额中属于该项所得负担的部分，可以作为可抵免境外所得税税额，在抵免限额内抵免；
- 直接控制：居民企业直接持有外国企业 **20% 以上**股份；
- 间接控制：以间接持股方式持有外国企业 **20% 以上**股份。

### 考点9 企业资产的税务处理 ★★

**基本原则**：企业各项资产以**历史成本**为计税基础。持有各项资产期间发生资产增值或减值，除国务院财政、税务主管部门规定可以确认损益外，**不得调整该资产的计税基础**。

**（一）固定资产**
- 定义：为生产产品、提供劳务、出租或经营管理而持有的、**使用时间超过 12 个月**的非货币性资产；
- **折旧方法**：按**直线法**计算的折旧准予扣除；**投入使用月份的次月起**计提折旧，**停止使用月份的次月起**停止计提折旧；预计净残值一经确定不得变更；
- **最低折旧年限（必背）**：

| 资产类别 | 最短折旧年限 |
|---|---|
| 房屋、建筑物 | **20 年** |
| 飞机、火车、轮船、机器、机械和其他生产设备 | **10 年** |
| 与生产经营活动有关的器具、工具、家具等 | **5 年** |
| 飞机、火车、轮船以外的运输工具 | **4 年** |
| 电子设备 | **3 年** |

- **不得计算折旧扣除的固定资产（7 项）**：
  1. 房屋、建筑物以外**未投入使用**的固定资产（注意：未投入使用的**房屋**可以计提折旧）；
  2. 以**经营租赁方式租入**的固定资产（由出租方计提折旧）；
  3. 以**融资租赁方式租出**的固定资产（出租方不再计提折旧）；
  4. 已足额提取折旧仍继续使用的固定资产；
  5. 与经营活动无关的固定资产；
  6. 单独估价作为固定资产入账的土地；
  7. 其他不得计算折旧扣除的固定资产。

**（二）生产性生物资产**
- 包括经济林、薪炭林、产畜和役畜等；按直线法计提折旧；
- 最低折旧年限：**林木类 10 年；畜类 3 年**。

**（三）无形资产**
- 包括专利权、商标权、著作权、土地使用权、非专利技术、商誉等；
- 按**直线法**计算摊销费用，摊销年限**不得低于 10 年**；
- **不得摊销**：①自行开发的支出已在计算应纳税所得额时扣除的无形资产；②**自创商誉**；③与经营活动无关的无形资产；④其他不得计算摊销费用扣除的无形资产；
- 外购商誉的支出，在企业整体转让或清算时准予扣除。

**（四）长期待摊费用**

| 支出类型 | 摊销方式 |
|---|---|
| 已足额提取折旧的固定资产的改建支出 | 按固定资产**预计尚可使用年限**分期摊销 |
| 租入固定资产的改建支出 | 按合同约定的**剩余租赁期限**分期摊销 |
| 固定资产的大修理支出（修理支出达取得固定资产时计税基础 **50% 以上**，且修理后使用年限延长 **2 年以上**） | 按固定资产**尚可使用年限**分期摊销 |
| 其他应当作为长期待摊费用的支出 | 自支出发生月份的次月起分期摊销，摊销年限**不得低于 3 年** |

- 一般修理支出作为当期费用直接扣除。

**（五）投资资产**
- 对外投资期间，投资资产的成本在计算应纳税所得额时**不得扣除**；在转让或处置投资资产时，投资资产的成本准予扣除。

**（六）存货**
- 计价方法在**先进先出法、加权平均法、个别计价法**中选用一种，一经选用不得随意变更。

### 考点10 企业所得税的源泉扣缴 ★

| 扣缴方式 | 内容 |
|---|---|
| **法定扣缴** | 非居民企业在境内未设立机构、场所，或虽设立机构、场所但取得的所得与其机构、场所**没有实际联系**的，其应缴纳的所得税实行源泉扣缴，以**支付人**为扣缴义务人。纳税地点：支付人所在地 |
| **指定扣缴** | 对非居民企业在境内取得**工程作业和劳务所得**应缴纳的所得税，税务机关可以指定工程价款或劳务费的支付人为扣缴义务人。情形：①预计工程作业或提供劳务期限不足一个纳税年度，且有证据表明不履行纳税义务；②没有办理税务登记或临时税务登记，且未委托境内代理人履行纳税义务；③未按规定期限办理企业所得税纳税申报或预缴申报 |
| **特定扣缴** | 依照税法规定应当扣缴的所得税，扣缴义务人未依法扣缴或无法履行扣缴义务的，由纳税人在**所得发生地**缴纳；纳税人未依法缴纳的，税务机关可以从该纳税人在境内其他收入项目的支付人应付的款项中追缴应纳税款 |

**扣缴申报**：扣缴义务人每次代扣的税款，应当自代扣之日起 **7 日内**缴入国库，并向所在地税务机关报送扣缴企业所得税报告表。

**速记口诀**：**"法指定，特追缴"**。

### 考点11 企业所得税的征收管理 ★

| 事项 | 规定 |
|---|---|
| **纳税地点** | 居民企业：登记注册地；登记注册地在境外的，为实际管理机构所在地。非居民企业在境内设立机构、场所的，以机构、场所所在地 |
| **纳税方式** | 居民企业在境内设立**不具有法人资格**的营业机构的，应当**汇总**计算并缴纳企业所得税；除国务院另有规定外，企业之间**不得合并**缴纳企业所得税 |

| **中间终止经营** | 自实际经营终止之日起 **60 日内**办理当期汇算清缴 |
| **货币单位** | 以人民币计算；所得以人民币以外货币计算的，应折合成人民币计算并缴纳税款 |

### 考点12 个人所得税的纳税人 ★

**纳税人范围**：包括中国公民、和合伙企业的个人投资者、个体工商户、个得所得的外籍人员（含在华取得所得的外籍人员）和港、澳、台同胞。

| 类型 | 判定标准 | 纳税义务 |
|---|---|---|
| **居民个人** | 在中国境内**有住所**，或者无住所但一个纳税年度内在中国境内居住**累计满 183 天** | 无限纳税义务：境内、境外所得均纳税 |
| **非居民个人** | 在中国境内**无住所**且一个纳税年度内居住**累计不满 183 天** | 有限纳税义务：境内所得纳税 |

**要点**：纳税年度自公历 1 月 1 日起至 12 月 31 日止；"住所"指因**户籍、家庭、经济利益关系**而在中国境内习惯性居住。

**来源于境内所得（不论支付地点是否在境内）**：
1. 因任职、受雇、履约等在中国境内提供劳务取得的所得；
2. 将财产出租给承租人在中国境内使用而取得的所得；
3. 许可各种特许权在中国境内使用而取得的所得；
4. 转让中国境内的不动产等财产或者在中国境内转让其他财产取得的所得；
5. 从中国境内企业、事业单位、其他组织以及居民个人取得的利息、股息、红利所得。

**纳税人 vs 扣缴义务人 vs 负税人（高频）**：
- 纳税人/负税人 = 取得所得的个人；
- 扣缴义务人 = 向个人支付所得的单位或个人；
- 支付工资、薪金所得的扣缴义务人应当于**年度终了后两个月内**向纳税人提供其个人所得和已扣缴税款等信息。

### 考点13 个人所得税的征税对象 ★★

**九大应税项目**：

| 应税项目 | 内涵 | 备注 |
|---|---|---|
| **工资、薪金所得** | 个人因任职或受雇取得的工资、薪金、奖金、年终加薪、劳动分红、津贴、补贴以及与任职或受雇有关的其他所得 | 属于**非独立个人劳动所得** |
| **劳务报酬所得** | 个人独立从事非雇佣的各种劳务取得的所得，包括设计、装潢、安装、制图、化验、测试、医疗、法律、会计、咨询、讲学、翻译、审稿、书画、雕刻、影视、录音、录像、演出、表演、广告、展览、技术服务、介绍服务、经纪服务、代办服务等 | **27 项**；兼职收入按劳务报酬 |
| **稿酬所得** | 个人因其作品以**图书、报刊等形式出版、发表**而取得的所得 | 不以图书、报刊形式出版、发表 → 劳务报酬 |
| **特许权使用费所得** | 个人提供专利权、商标权、著作权、非专利技术以及其他特许权的**使用权**取得的所得 | 提供著作权的使用权所得**不包括稿酬所得** |
| **经营所得** | ①个体工商户从事生产、经营活动取得的所得；个人独资企业投资人、合伙企业的个人合伙人来源于境内注册企业生产、经营的所得；②个人依法从事办学、医疗、咨询以及其他有偿服务活动取得的所得；③个人对企业、事业单位承包经营、承租经营以及转包、转租取得的所得；④个人从事其他生产、经营活动取得的所得（如彩票代销、个体出租车运营） | 5%—35% 五级超额累进 |
| **利息、股息、红利所得** | 个人拥有债权、股权等而取得的利息、股息、红利所得 | 20% |
| **财产租赁所得** | 个人出租不动产、机器设备、车船以及其他财产取得的所得 | 财产转租收入也属此范围；20%（出租住房 10%） |
| **财产转让所得** | 个人转让有价证券、股权、合伙企业中的财产份额、不动产、机器设备、车船以及其他财产取得的所得 | 20% |
| **偶然所得** | 个人得奖、中奖、中彩票以及其他偶然性质的所得 | 20% |

**速记口诀**：**"综合所得：工、劳、稿、特；分类所得：利、偶、转、租"**（经营所得单列）。

**三大归类辨析（案例题高频）**：
1. **工资薪金 vs 劳务报酬**：是否为"独立个人劳动"——受雇于单位、有任职关系 → 工资薪金；独立从事非雇佣劳务 → 劳务报酬。**营销业绩奖励**：奖励雇员 → 工资薪金；奖励非雇员 → 劳务报酬。**董事费/监事费**：在公司（含关联公司）任职受雇同时兼任董事、监事 → 工资薪金；担任董事、监事但**不在公司任职受雇** → 劳务报酬。
2. **稿酬 vs 劳务报酬**：是否以图书、报刊形式**出版、发表**。与图书、报刊相关的**翻译、审稿、书画**所得 → 劳务报酬。
3. **特许权使用费 vs 财产转让**：个人所得税中不区分专利权的所有权转让还是授予特许使用权，**均按"特许权使用费所得"**计税。

### 考点15 个人所得税的计税依据和应纳税额 ★★★★（本章最难）

**（一）综合所得（工、劳、稿、特）**

**1. 按年计征（汇算清缴）**
```
应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数
全年应纳税所得额 = 每一纳税年度收入额 − 费用 6 万元 − 专项扣除 − 专项附加扣除 − 其他扣除
```

**收入额的确定（必背）**：

| 综合所得项目 | 收入额 |
|---|---|
| 工资、薪金所得 | **全额**计入收入额 |
| 劳务报酬所得 | 收入 ×（1 − 20%） |
| 特许权使用费所得 | 收入 ×（1 − 20%） |
| 稿酬所得 | 收入 ×（1 − 20%）× **70%** |

**扣除项目**：

| 扣除项目 | 标准 |
|---|---|
| **减除费用** | **6 万元/年**（免征额 5000 元/月） |
| **专项扣除** | 居民个人缴纳的基本养老保险、基本医疗保险、失业保险和住房公积金（"三险一金"） |
| **专项附加扣除** | 见下表 |
| **其他扣除** | 个人缴付符合国家规定的企业年金、职业年金、个人养老金；个人购买符合国家规定的商业健康保险、税收递延型商业养老保险的支出。**个人向个人养老金的缴费按 12000 元/年的限额标准据实扣除** |

**专项附加扣除标准表（数字必背）**：

| 项目 | 标准 | 关键规定 |
|---|---|---|
| **子女教育** | 每个子女**每月 2000 元** | 年满 3 周岁，接受学前教育和学历教育（含境外留学，不含 3 岁前及博士后阶段）；多个符合条件子女可扣多份；父母可选一方按 100% 扣，也可双方各扣 50%；**扣除方式在一个纳税年度内不能变更** |
| **3 岁以下婴幼儿照护** | 每名婴幼儿**每月 2000 元** | 可由夫妻一方全额扣，也可双方各扣 50%；监护人不是父母的也可扣除 |
| **继续教育** | 学历：**每月 400 元**，扣除期限**不超过 48 个月**；职业资格：**取得证书当年一次性 3600 元** | 当年取得多个证书也只能扣一个 3600 元；本科及以下学历（学位）继续教育可选择由父母扣除或本人扣除 |
| **大病医疗** | 扣除医保报销后个人负担累计**超过 15000 元**的部分，在**80000 元限额内**据实扣除 | **只能在汇算清缴时扣除**；可选择由本人或其配偶扣除；未成年子女的医药费用可选择由其父母一方扣除 |
| **住房贷款利息** | **每月 1000 元**，扣除期限最长**不超过 240 个月** | 首套住房贷款利息；纳税人或配偶单独/共同使用商业银行或住房公积金个人住房贷款购买境内住房；夫妻双方约定由一方扣，方式年度内不变更；**纳税人和配偶不能同时享受住房贷款利息和住房租金扣除** |
| **住房租金** | **每月 1500 元 / 1100 元 / 800 元** | 直辖市、省会（首府）城市、计划单列市及国务院确定的其他城市 1500 元；除上述外市辖区户籍人口超过 100 万的城市 1100 元；不超过 100 万的城市 800 元；由签订租赁合同的承租人扣除；夫妻双方主要工作城市相同的只能由一方扣除 |
| **赡养老人** | **每月 3000 元**（独生子女全额）；非独生子女分摊，**每人每月最高不超过 1500 元** | 老人年满 60 岁；一名被赡养人年满 60 岁即可享受，赡养多名老人也只能扣一份；可均摊、约定分摊或被赡养人指定分摊，**指定分摊优先于约定分摊**，须签订书面分摊协议，方式和额度年度内不能变更 |

**速记口诀**：**"专项扣除三险一金；专项附加扣除：教育、老人、房子（加大病）"**。

**2. 按月或按次预扣预缴（分别计算）**

**（1）工资薪金所得——累计预扣法**
```
累计预扣预缴应纳税所得额
  = 累计收入 − 累计免税收入 − 累计减除费用 − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除
本期应预扣预缴税额
  =（累计预扣预缴应纳税所得额 × 预扣率 − 速算扣除数）− 累计减免税额 − 累计已预扣预缴税额
```
- 累计减除费用按照 **5000 元/月** × 纳税人当年截至本月在本单位的任职受雇月份数计算；
- 预扣预缴时，专项附加扣除中的**大病医疗不能扣**（只能扣婴幼儿照护、子女教育、赡养老人、住房贷款利息、住房租金、继续教育，继续教育也可选择在汇算清缴时扣）；
- 余额为负值时暂不退税，纳税年度终了后余额仍为负值的，通过汇算清缴多退少补；
- 特殊：一个纳税年度内**首次取得**工资薪金所得的居民个人，可按 5000 元/月 × 截至本月月份数计算累计减除费用；上一完整纳税年度内每月均在同一单位预扣预缴且全年工资薪金收入**不超过 6 万元**的居民个人，累计减除费用自 1 月份起直接按全年 6 万元计算扣除。

**（2）劳务报酬、稿酬、特许权使用费所得预扣预缴**
```
劳务报酬：应预扣预缴税额 = 预扣预缴应纳税所得额 × 预扣率 − 速算扣除数（三级超额累进）
稿酬、特许权使用费：应预扣预缴税额 = 预扣预缴应纳税所得额 × 20%
```

**预扣预缴应纳税所得额（收入额）的确定**：

| 税目 | 每次收入 ≤ 4000 元 | 每次收入 > 4000 元 |
|---|---|---|
| 劳务报酬所得 | 每次收入 − **800** | 每次收入 ×（1 − 20%） |
| 特许权使用费所得 | 每次收入 − **800** | 每次收入 ×（1 − 20%） |
| 稿酬所得 | （每次收入 − 800）× **70%** | 收入 ×（1 − 20%）× **70%** |

> **【说明】** 年度汇算清缴时，劳务报酬、稿酬、特许权使用费所得以收入减除 **20%** 的费用后的余额为收入额，稿酬所得的收入额**减按 70%** 计算。也就是说，**只有在预扣预缴时才考虑是否超过 4000 元**。

**每次收入的确定**：

| 税目 | 具体规定 |
|---|---|
| 劳务报酬、稿酬、特许权使用费 | ①属于一次性收入的，以取得该项收入为一次；②属于同一事项连续取得收入的，以 **1 个月内**取得的收入为一次 |
| 利息、股息、红利所得 | 以支付利息、股息、红利时取得的收入为一次 |
| 财产租赁所得 | 以 **1 个月内**取得的收入为一次 |
| 财产转让所得 | 以每次取得该项收入为一次 |
| 偶然所得 | 以每次取得该项收入为一次 |

**（二）经营所得**
```
应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数
全年应纳税所得额 = 每一纳税年度的收入总额 − 成本 − 费用 − 损失
```
- 成本、费用：生产、经营活动中发生的各项直接支出和分配计入成本的间接费用以及销售费用、管理费用、财务费用；
- 损失：固定资产和存货的盘亏、毁损、报废损失，转让财产损失，坏账损失，自然灾害等不可抗力因素造成的损失以及其他损失；
- **取得经营所得的个人，没有综合所得的**，计算其每一纳税年度的应纳税所得额时，应当减除**费用 6 万元、专项扣除、专项附加扣除以及依法确定的其他扣除**；
- 同时取得综合所得和经营所得的纳税人，可在综合所得或经营所得中申报减除费用 6 万元、专项扣除、专项附加扣除及依法确定的其他扣除，但**不得重复申报减除**；
- 从事生产、经营活动，未提供完整、准确的纳税资料，不能正确计算应纳税所得额的，由主管税务机关核定。

**（三）分类所得（利、偶、转、租）**
```
应纳税额 = 每月或每次应纳税所得额 × 20%
```
1. **利息、股息、红利所得和偶然所得**：以**每次收入额**为应纳税所得额；
2. **财产转让所得**：应纳税所得额 = 收入总额 − 财产原值 − 合理费用；
3. **财产租赁所得**：
   - 每次（月）收入 ≤ 4000 元：应纳税所得额 = 每次收入 − 800；
   - 每次（月）收入 > 4000 元：应纳税所得额 = 每次收入 ×（1 − 20%）；
   - 计算个人房屋出租应纳税额时依次扣除：财产租赁过程中缴纳的税费 → 向出租方支付的租金 → 由纳税人负担的租赁财产实际开支的**修缮费用（每月上限 800 元）** → 税法规定的费用扣除标准（800 或 20%）；
   - 个人按市场价出租住房**减按 10%** 的税率征收。

**（四）公益捐赠扣除**
- 个人将其所得通过中国境内公益性社会组织、国家机关向教育、扶贫、济困等公益慈善事业的捐赠；
- **捐赠额未超过纳税人申报的应纳税所得额 30% 的部分**，可以从其应纳税所得额中扣除。

**（五）年终奖（全年一次性奖金）单独计税**
- 素材明确：工资薪金所得中"**全年一次性奖金应纳税额计算有特殊规定**"；
- 素材明确：年度汇算**不涉及**纳税人按规定**选择不并入综合所得（例如年终奖）**计算纳税的所得；
- **其具体计算方法与适用税率，本套素材未明确，请以现行教材/政策为准。**

### 考点16 个人所得税的税收优惠 ★★★★

**（一）法定免税项目**
1. 省级人民政府、国务院部委和中国人民解放军军以上单位，以及外国组织、国际组织颁发的科学、教育、技术、文化、卫生、体育、环境保护等方面的奖金；
2. 国债和国家发行的金融债券的利息；
3. 按照国家统一规定发给的补贴、政府特殊津贴、院士津贴；
4. 福利费、抚恤金、救济金；
5. 保险赔款；
6. 军人的转业费、复员费、退役金；
7. 按照国家统一规定发给干部、职工的安家费、退职费、基本养老金或者退休费、离休费、离休生活补助费；
8. 依照有关法律规定应予免税的各国驻华使馆、领事馆的外交代表、领事官员和其他人员的所得；
9. 中国政府参加的国际公约、签订的协议中规定免税的所得；
10. 国务院规定的其他免税所得（以上免税规定由国务院报全国人大常委会备案）。

**（二）法定减税项目（减征幅度和期限由省级政府规定）**
1. 残疾、孤老人员和烈属的所得；
2. 因自然灾害遭受重大损失的。

**（三）其他免税或暂免征收项目**
1. 个人举报、协查各种违法、犯罪行为获得的奖金；
2. 个人办理代扣代缴取得的扣缴手续费；
3. 个人转让自用 **5 年以上**且是**唯一**家庭生活用房取得的收入；
4. 个人购买体育彩票（社会福利有奖募捐奖券），一次中奖在 **1 万元以下（含 1 万元）**的收入；
5. 法律援助人员获得的法律援助补贴；
6. 计入个人养老金账户的投资收益。

**利息股息的特殊优惠（素材补充）**：
- 国债利息、地方政府债券利息、国家发行的金融债券利息、居民储蓄存款利息**免税**；
- 铁路债券利息**减按 50%** 计税；
- 上市公司和全国中小企业股份转让系统（新三板）挂牌公司的股息红利：持股期限 ≤ 1 个月的**全额计税**；持股期限 > 1 个月但 ≤ 1 年的**暂减按 50%** 计税；持股期限 > 1 年的**免税**。

### 考点17 个人所得税的征收管理 ★★

**征收方式**：扣缴义务人扣缴申报和纳税人自行申报相结合。

**（一）扣缴申报（全员全额扣缴申报）**
- 扣缴义务人 = 向个人支付所得的单位或个人；
- 扣缴义务人应当在**代扣税款的次月 15 日内**，向主管税务机关报送相关信息；每月或每次预扣、代扣的税款，应当在**次月 15 日内**缴入国库；
- 应税所得范围（**注意：没有经营所得**）：工资薪金、劳务报酬、稿酬、特许权使用费、利息股息红利、财产租赁、财产转让、偶然所得，以及经国务院财政部门确定征税的其他所得；
- 其他所得扣缴申报：扣缴义务人支付利息、股息、红利所得，财产租赁所得，财产转让所得或偶然所得时，应按次或按月代扣代缴税款，适用 **20%** 的比例税率。

**（二）自行申报情形（7 项）**
1. 取得综合所得需要办理汇算清缴；
2. 取得应税所得没有扣缴义务人；
3. 取得应税所得，扣缴义务人未扣缴税款；
4. 取得境外所得；
5. 因移居境外注销中国户籍；
6. 非居民个人在中国境内从两处以上取得工资、薪金所得；
7. 国务院规定的其他情形。

**（三）汇算清缴的办理**
```
汇算应退或应补税额 = [（综合所得收入额 − 60000 元 − "三险一金"等专项扣除
   − 子女教育等专项附加扣除 − 依法确定的其他扣除 − 捐赠）× 适用税率 − 速算扣除数]
   − 减免税额 − 已预缴税额
```
- 应纳税额 > 已预缴税额 → 补税；应纳税额 < 已预缴税额 → 退税；一致 → 不补不退；
- **无须办理年度汇算的情形**：①年度汇算需补税但综合所得收入全年**不超过 12 万元**；②年度汇算需补税金额**不超过 400 元**；③已预缴税额与年度汇算应纳税额一致；④符合年度汇算退税条件但**不申请退税**的；
- **需要办理年度汇算的情形**：①已预缴税额大于年度汇算应纳税额且**申请退税**的；②纳税年度内取得的综合所得收入**超过 12 万元**且需要补税金额**超过 400 元**的；
- 办理方式：自行办理、通过任职受雇单位代为办理、委托涉税专业服务机构或其他单位及个人办理（受托人需与纳税人签订授权书）；
- 办理地点：按方便就近原则向纳税人任职受雇单位的主管税务机关申报；有两处及以上任职受雇单位的可自主选择其中一处；没有任职受雇单位的，向其户籍所在地、经常居住地或主要收入来源地的主管税务机关申报（主要收入来源地指纳税年度内取得的劳务报酬、稿酬及特许权使用费三项所得累计收入最大的扣缴义务人所在地）。

**（四）纳税申报期限（必背）**

| 情形 | 期限 |
|---|---|
| 居民个人取得综合所得办理汇算清缴 | 取得所得的**次年 3 月 1 日至 6 月 30 日** |
| 纳税人取得经营所得 | 月度或季度终了后 **15 日内**预缴；取得所得的**次年 3 月 31 日前**办理汇算清缴 |
| 利息、股息、红利，财产租赁，财产转让，偶然所得 | 取得所得的**次年 6 月 30 日前** |
| 居民个人从中国境外取得所得 | 取得所得的**次年 3 月 1 日至 6 月 30 日** |
| 非居民个人取得工资薪金、劳务报酬、稿酬、特许权使用费（扣缴义务人未扣缴） | 取得所得的**次年 6 月 30 日前**向扣缴义务人所在地主管税务机关申报 |
| 非居民个人在境内从两处以上取得工资薪金 | 取得所得的**次月 15 日内** |
| 因移居境外注销中国户籍 | 申请注销中国户籍前，向户籍所在地主管税务机关申报并税款清算 |

**（五）三种征税方法**

| 征税方法 | 适用税目 |
|---|---|
| **按年计征** | 居民个人取得的综合所得；经营所得 |
| **按月计征** | 工资、薪金所得预缴；财产租赁所得 |
| **按次计征** | 居民个人：劳务报酬、稿酬、特许权使用费所得预缴；财产转让所得；利息、股息、红利所得；偶然所得 |

### 考点18 所得税相关案例分析题 ★★★★

案例分析题是本章分值最集中的题型（5 道/10 分），本质是把前 17 个考点串成一道大题。素材给出的解题框架如下：

**（一）企业所得税案例题"一条线"逻辑**
```
第 1 步：确定收入总额（销售货物、劳务、特许权使用费、租金、转让财产、股息红利、
        接受捐赠、其他收入——含视同销售收入）
第 2 步：剔除非应税收入（不征税收入 + 免税收入）
第 3 步：逐项计算准予扣除金额
        · 成本、税金及附加、期间费用（销售/管理/财务费用）
        · 限额扣除项目：福利费14%、工会经费2%、职教经费8%、补充保险5%、
          业务招待费（60%与5‰孰低）、广宣费（15%/30%）、捐赠（利润12%）、利息（同期同类利率）
        · 不得扣除项目：行政罚款、滞纳金、非公益性捐赠、赞助支出、企业所得税税款、
          企业之间管理费、烟草企业广宣费等
第 4 步：弥补以前年度亏损（最长5年，高新/科技型中小10年）
第 5 步：×适用税率 − 减免税额 − 抵免税额
```

**（二）个人所得税案例题"分项分别计算"逻辑**
```
应纳税额应分项分别计算
  综合所得应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数
  经营所得应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数
  其他所得应纳税额 = 每月或每次应纳税所得额 × 适用税率
  应纳税额 = 综合所得应纳税额 + 经营所得应纳税额 + 其他所得应纳税额
```
案例题常考组合：专项附加扣除标准判定（赡养老人分摊、大病医疗扣除主体、住房贷款利息）+ 预扣预缴税额计算（制图收入按劳务报酬、专利许可按特许权使用费）。

## 四、公式与计算（本章计算题最重，必须极其详尽）

> 每个公式均配 1 道带数字演算例题。例题来源标注【真题】者为素材原题；标注【按素材规则演算】者为依素材所列规则所作的算术演示。

### （一）企业所得税

#### 公式1 应纳税所得额（直接法）
```
应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损
```

**【真题演算·2024 案例】** 某企业 2024 年当年主营业务收入 1000 万元，其他业务收入 100 万元，国债利息收入 20 万元，地方政府债券利息收入 10 万元，依法收取并纳入财政管理的政府性基金 50 万元。全年营业成本 400 万元，管理费用 50 万元，财务费用 20 万元（无资本化利息），销售费用 100 万元（其中广告费、宣传费列支 80 万元），营业外支出共计 8 万元（含直接向合作单位赞助的衣物 2 万元、税收滞纳金 1 万元），全年与生产经营有关的业务招待费共列支 40 万元，允许弥补的以前年度亏损 20 万元，营业税金及附加合计 50 万元。适用 25% 税率，非化妆品/医药/饮料制造企业。

```
第一步：确定需计税的收入
  收入总额 = 1000 + 100 + 20 + 10 + 50 = 1180（万元）
  不征税收入（政府性基金）= 50（万元）
  免税收入（国债利息 + 地方政府债券利息）= 20 + 10 = 30（万元）
  应税收入 = 1180 − 50 − 30 = 1100（万元）      ← 即"需要计算缴纳企业所得税的收入"

第二步：各项扣除
  营业成本 400
  管理费用 50
  财务费用 20
  销售费用 100
  营业外支出可扣除 = 8 − 2（赞助）− 1（滞纳金）= 5
  营业税金及附加 50
  业务招待费可扣除 = min(40×60%, 1100×5‰) = min(24, 5.5) = 5.5
  弥补以前年度亏损 20
  各项扣除合计 = 400+50+20+100+5+50+5.5+20 = 650.5（万元）

第三步：应纳税所得额
  = 1180 − 50 − 30 − 650.5 = 449.5（万元）

第四步：应纳税额 = 449.5 × 25% = 112.375（万元）     ← 与真题答案 D 一致
```

#### 公式2 应纳税所得额（间接法）
```
应纳税所得额 = 会计利润 + 纳税调整增加金额 − 纳税调整减少金额
```

**【按素材规则演算】** 某居民企业 2025 年会计利润 800 万元，当年超标业务招待费 12.5 万元、超标职工福利费 3 万元，取得国债利息收入 15 万元，发生加计扣除研发费用 50 万元。

```
应纳税所得额 = 800 + 12.5 + 3 − 15 − 50 = 750.5（万元）
应纳税额 = 750.5 × 25% = 187.625（万元）
```

#### 公式3 企业所得税应纳税额
```
应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额
```

**【真题演算·2025 案例】** 某集成电路生产企业 2024 年实现技术转让所得 600 万元；综合利用资源生产符合规定产品取得收入 500 万元；自行研发发生研发费用 100 万元全部计入当期损益；购进节能节水专用设备一套，设备投资额 300 万元；对原有安全生产设备进行智能化改造投入 150 万元。

```
技术转让所得应纳税所得额 = (600 − 500) × 50% = 50（万元）   ← 不超500万免征，超500万部分减半
综合利用资源产品确认收入 = 500 × 90% = 450（万元）           ← 减按90%计入收入总额
研发费用税前允许扣除 = 100 + 100×120% = 220（万元）          ← 集成电路企业120%加计扣除
```

#### 公式4 研发费用加计扣除
```
费用化：税前扣除金额 = 实际发生额 × (1 + 加计扣除比例)
资本化：税前摊销金额 = 无形资产成本 × 200%（或220%）
```

**【真题演算·2024 案例】** 某企业当年安置残疾人员，实际发放残疾人员工资 10 万元，直接计入当期损益。

```
准予税前扣除的残疾人员工资 = 10（据实扣除）+ 10 × 100%（加计扣除）= 20（万元）
```
（真题答案 B）

#### 公式5 小型微利企业优惠
```
小型微利企业应纳税额 = 应纳税所得额 × 25% × 20%
```
（条件：年应纳税所得额 ≤300 万元、从业人数 ≤300 人、资产总额 ≤5000 万元；至 2027-12-31）

**【按素材规则演算】** 某小型微利企业 2025 年应纳税所得额 280 万元。

```
应纳税额 = 280 × 25% × 20% = 14（万元）
```

#### 公式6 应纳税额抵免（专用设备）
```
当年可抵免税额 = 专用设备投资额 × 10%
不足抵免的，可以在以后 5 个纳税年度结转抵免
```

**【真题演算·2024 案例】** 某医药制造企业当年购置安全生产专用设备 1000 万元，购置完毕即投入使用。

```
至多可抵免当年应纳税额 = 1000 × 10% = 100（万元）   ← 与真题答案 C 一致
```

**【真题演算·2025 案例】** 购进节能节水专用设备投资额 300 万元；对原有安全生产设备智能化改造投入 150 万元。

```
专用设备投资额 10% = 300 × 10% = 30（万元）
智能化改造投入抵免：不超过原计税基础 50% 的部分 × 10%
两项支出均可从当年应纳税额中抵免（对应真题答案 AC）
```

#### 公式7 抵扣应纳税所得额（创业投资）
```
可抵扣应纳税所得额 = 投资额 × 70%（须股权持有满 2 年的当年）
当年不足抵扣的，可以在以后纳税年度结转抵扣
```

**【真题演算】** 甲创业投资企业 2020 年 4 月 1 日向未上市的取得高新技术企业资格的乙公司（中小企业）投资 120 万元，股权持有至 2022 年 6 月 1 日。

```
2022 年度可抵免应纳税所得额 = 120 × 70% = 84（万元）
```

#### 公式8 境外所得抵免（直接抵免）
```
境外所得税税款抵免限额 = 来源于某国（地区）的应纳税所得额 × 25%
孰低原则：a（境外已纳税额）< b（抵免限额）→ 抵免 a，国内补缴差额
          a > b → 抵免 b，(a−b) 以后 5 个年度内抵补
```

**【真题演算】** 某企业 2024 年度境内应纳税所得额 200 万元，全年已预缴税款 50 万元；来源于境外某国税前所得 100 万元，境外实纳税款 20 万元；税率 25%。

```
抵免限额 = 100 × 25% = 25（万元）
实际抵免税额 = 20（万元）（孰低）
汇算清缴应补（退）税款 = (200 + 100) × 25% − 20 − 50 = 75 − 20 − 50 = 5（万元）
```

**【真题演算】** 某国有企业适用 25% 税率，2024 年境内应纳税所得额 1000 万元，A 国分支机构境外应纳税所得额 500 万元，已在 A 国缴纳所得税 100 万元。

```
A 国抵免限额 = 500 × 25% = 125（万元）
允许抵免税额 = 100（万元）（已缴 100 < 限额 125）
2024 年度应纳税额 = 1000 × 25% + 125 − 100 = 275（万元）
若在 A 国已缴 150 万元，则应纳税额 = 1000 × 25% + 125 − 125 = 250（万元）
```

### （二）个人所得税

#### 公式9 综合所得应纳税额（汇算清缴）
```
应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数
全年应纳税所得额 = 每一纳税年度收入额 − 费用 6 万元 − 专项扣除 − 专项附加扣除 − 其他扣除
收入额：工资薪金全额；劳务报酬、特许权使用费 ×(1−20%)；稿酬 ×(1−20%)×70%
```

**【真题演算】** 小王 2023 年度每月工资 15000 元，每月应扣除"三险一金"1000 元，每月可办理的专项附加扣除为赡养老人支出 3000 元。2023 年 3 月取得劳务报酬 3 万元，8 月取得稿酬 1 万元，11 月取得特许权使用费收入 5000 元。

```
（1）综合所得收入额
  工资薪金收入额 = 15000 × 12 = 180000（元）
  劳务报酬收入额 = 30000 × (1 − 20%) = 24000（元）
  稿酬收入额     = 10000 × (1 − 20%) × 70% = 5600（元）
  特许权使用费收入额 = 5000 × (1 − 20%) = 4000（元）
  合计 = 213600（元）

（2）全年应纳税所得额
  = 213600 − 60000 − 12×1000 − 12×3000
  = 213600 − 60000 − 12000 − 36000 = 105600（元）

（3）全年应纳税额
  = 105600 × 10% − 2520 = 8040（元）
```

#### 公式10 工资薪金所得预扣预缴（累计预扣法）
```
累计预扣预缴应纳税所得额
 = 累计收入 − 累计免税收入 − 累计减除费用 − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除
本期应预扣预缴税额
 =（累计预扣预缴应纳税所得额 × 预扣率 − 速算扣除数）− 累计减免税额 − 累计已预扣预缴税额
```

**【真题演算】** 某职员 2023 年每月应发工资均为 10000 元，每月减除费用 5000 元，"三险一金"等专项扣除 1500 元，从 1 月起享受境内首套住房贷款利息扣除 1000 元。

```
1 月：(10000 − 5000 − 1500 − 1000) × 3% = 75（元）
2 月：(10000×2 − 5000×2 − 1500×2 − 1000×2) × 3% − 75 = 75（元）
3 月：(10000×3 − 5000×3 − 1500×3 − 1000×3) × 3% − 75 − 75 = 75（元）
```

**【综合演算·李某 2025 年】** 每月工资 30000 元，"三险一金"4500 元，享受子女教育（一个子女）和赡养老人（独生子）两项专项附加扣除；全年医疗费支出 42000 元，其中 20000 元为医保报销部分，其余自付。

```
（1）每月预扣预缴（子女教育 2000 + 赡养老人 3000 = 5000）
  1 月：累计应纳税所得额 = 30000 − 5000 − 4500 − 5000 = 15500
       预扣预缴税额 = 15500 × 3% = 465（元）
  2 月：累计 = 15500 × 2 = 31000
       税额 = 31000 × 3% − 465 = 465（元）
  3 月：累计 = 15500 × 3 = 46500
       税额 = 46500 × 10% − 2520 − 465 − 465 = 1200（元）
  4 月：累计 = 15500 × 4 = 62000
       税额 = 62000 × 10% − 2520 − 465 − 465 − 1200 = 1550（元）

（2）全年预扣预缴
  累计应纳税所得额 = (30000 − 5000 − 4500 − 5000) × 12 = 186000（元）
  全年预扣预缴税额 = 186000 × 20% − 16920 = 20280（元）

（3）汇算清缴
  大病医疗专项附加扣除 = 42000 − 20000 − 15000 = 7000（元）
```

#### 公式11 劳务报酬所得预扣预缴
```
应预扣预缴税额 = 预扣预缴应纳税所得额 × 预扣率 − 速算扣除数
预扣预缴应纳税所得额：每次收入 ≤4000 元 → 收入 − 800；每次收入 >4000 元 → 收入 ×(1−20%)
预扣率表：≤20000 元 20%（速算扣除数 0）；20000—50000 元 30%（2000）；>50000 元 40%（7000）
```

**【真题演算】** 小林 7 月因提供著作权特许权使用费取得收入 35000 元，提供专利权特许使用费取得收入 65000 元，计算当月应预扣预缴的个人所得税。

```
特许权使用费所得预扣预缴：应纳税所得额 = 收入 ×（1 − 20%），预扣率为 20% 比例（不适用劳务报酬三级累进）
著作权特许权使用费：
  35000 × (1 − 20%) × 20% = 28000 × 20% = 5600（元）
专利权特许使用费：
  65000 × (1 − 20%) × 20% = 52000 × 20% = 10400（元）
  合计 = 5600 + 10400 = 16000（元）
```
> **【要点】** 特许权使用费（及稿酬）预扣预缴一律按 **20% 比例预扣率**，不用劳务报酬的 20%/30%/40% 三级超额累进表。故正确答案为 **16000 元**。若误套劳务报酬三级累进表（28000×30%−2000=6400、52000×40%−7000=13800）会得 20200 元，属混淆税目所致的典型错误。

**【素材例题】** 某居民个人取得劳务报酬所得 4 次，分别为 3000 元、22000 元、30000 元、100000 元。

```
第一次 3000 元（<4000）：(3000 − 800) × 20% = 440（元）
第二次 22000 元（>4000）：22000 × (1 − 20%) = 17600 → 17600 × 20% = 3520（元）
第三次 30000 元（>4000）：30000 × (1 − 20%) = 24000 → 24000 × 30% − 2000 = 5200（元）
第四次 100000 元（>4000）：100000 × (1 − 20%) = 80000 → 80000 × 40% − 7000 = 25000（元）
```

**【真题演算·2023 案例】** 小陈 6 月为 B 公司制图取得收入 30000 元。

```
应纳税所得额 = 30000 × (1 − 20%) = 24000（元）
应预扣预缴税额 = 24000 × 30% − 2000 = 5200（元）   ← 答案 D
```

#### 公式22 固定资产折旧（一次性算折旧额）
```
年折旧额 = 计税基础 × (1 − 残值率) ÷ 折旧年限
当月投入使用，次月开始计提折旧
```

**【真题演算】** 2023 年 4 月 20 日购进一台机械设备，购入成本 90 万元，当月投入使用，按直线法折旧，期限 10 年，残值率 5%。

## 五、高频考点速记卡

1. **Q：企业所得税的纳税人包括哪些？不包括哪些？**
   A：包括企业和其他取得收入的组织（企业、事业单位、社会团体）。**不包括个人独资企业和合伙企业**——二者不具有法人资格，个人投资者按"经营所得"缴个税。

2. **Q：居民企业与非居民企业的判定标准？**
   A：看"登记注册地"和"实际管理机构所在地"：**二者有一个在境内即为居民企业**（全面纳税义务，境内外所得）；都不在境内的为非居民企业（有限纳税义务）。

3. **Q：企业所得税各档税率？**
   A：法定 **25%**；小型微利企业 **20%**（至 2027-12-31 减按 25% 计算应纳税所得额）；高新技术企业、技术先进型服务企业、西部地区鼓励类产业企业 **15%**；非居民企业 **10%**。

4. **Q：小型微利企业的三个条件？**
   A：年应纳税所得额**不超过 300 万元**、从业人数**不超过 300 人**、资产总额**不超过 5000 万元**。

5. **Q：亏损弥补年限？**
   A：一般企业最长 **5 年**；自 2018-01-01 起具备高新技术企业或科技型中小企业资格的企业，其具备资格年度之前 5 个年度尚未弥补完的亏损，最长延长至 **10 年**。

6. **Q：不征税收入有哪几项？**
   A：财政拨款；依法收取并纳入财政管理的行政事业性收费；依法收取并纳入财政管理的政府性基金；国务院规定的专项用途财政性资金。

7. **Q：免税收入有哪几项？**
   A：国债利息收入；地方政府债券利息收入；符合条件的居民企业之间的股息红利（**不包括连续持有上市公司股票不足 12 个月**的收益）；符合条件的非营利组织收入。

8. **Q：工资薪金支出、四项经费和补充保险的扣除标准？**
   A：合理工资薪金支出据实扣除；职工福利费 **14%**、工会经费 **2%**、职工教育经费 **8%**（超额结转）、党组织工作经费 **1%**；补充养老保险费、补充医疗保险费分别在不超过**职工工资总额 5%** 标准内扣除，超过不予扣除。

9. **Q：业务招待费怎么扣？**
    A：按**发生额的 60%** 扣除，但最高不得超过当年**销售（营业）收入的 5‰**——两个限额比一比，取最小。

10. **Q：广宣费扣除标准？**
    A：一般企业不超过当年销售（营业）收入 **15%**；化妆品制造或销售、医药制造和饮料制造（不含酒类制造）企业不超过 **30%**（2025-12-31 之前）；超标部分结转以后纳税年度。

11. **Q：公益性捐赠扣除标准？**
    A：不超过**年度利润总额 12%** 的部分准予扣除，超过部分准予结转以后 **3 年** 内扣除。必须通过公益性社会团体或县级以上人民政府及其部门。

12. **Q：研发费用加计扣除比例？**
    A：一般企业未形成无形资产**加计扣除 100%**、形成无形资产按**200%** 摊销；集成电路企业和工业母机企业分别 **120%/220%**；安置残疾人员工资 **100%**；出资给非营利科研机构、高校用于基础研究 **100%**。

13. **Q：哪些行业不适用研发费用加计扣除？**
    A：烟草制造业、住宿和餐饮业、批发和零售业、房地产业、租赁和商务服务业、娱乐业——**"批零烟、租商房、住餐娱"**。

14. **Q：固定资产最低折旧年限？哪些不得计提折旧？**
    A：年限：房屋建筑物 **20 年**；飞机火车轮船机器机械 **10 年**；器具工具家具 **5 年**；飞机火车轮船以外的运输工具 **4 年**；电子设备 **3 年**（投入使用次月起计提，停用次月起停止）。
    不得计提折旧：①房屋建筑物以外未投入使用的；②经营租赁租入的；③融资租赁租出的；④已足额提取折旧仍继续使用的；⑤与经营活动无关的；⑥单独估价作为固定资产入账的土地。

15. **Q：企业所得税源泉扣缴的三种方式？**
    A：**法定扣缴**（支付人为扣缴义务人）、**指定扣缴**（税务机关指定工程价款或劳务费支付人）、**特定扣缴**（未依法扣缴时由纳税人在所得发生地缴纳，税务机关可追缴）。扣缴义务人每次代扣税款应自代扣之日起 **7 日内**缴入国库。

16. **Q：居民个人与非居民个人的判定？**
    A：境内**有住所**，或无住所但一个纳税年度内居住**累计满 183 天** → 居民个人（无限纳税义务）；无住所且不满 183 天 → 非居民个人（有限纳税义务）。

17. **Q：个人所得税综合所得包括哪四项？税率？**
    A：工资薪金、劳务报酬、稿酬、特许权使用费。按年汇算清缴适用**七级超额累进 3%—45%**；预扣预缴时工资薪金 3%—45%（累计预扣法）、劳务报酬 20%/30%/40% 三级、稿酬和特许权使用费 20%。

18. **Q：综合所得收入额如何确定？**
    A：工资薪金**全额**；劳务报酬、特许权使用费 **×(1−20%)**；稿酬 **×(1−20%)×70%**。

19. **Q：专项附加扣除七项标准？大病医疗何时扣、谁能扣？**
    A：标准：子女教育 2000 元/月；3 岁以下婴幼儿照护 2000 元/月；继续教育学历 400 元/月（≤48 个月）、职业资格 3600 元/年；大病医疗超 15000 元部分在 80000 元限额内据实扣；住房贷款利息 1000 元/月（≤240 个月）；住房租金 1500/1100/800 元/月；赡养老人 3000 元/月（非独生子女每人最高 1500 元/月）。
    大病医疗**只能在汇算清缴时扣除**（预扣预缴不能扣）；可选择由本人或其配偶扣除，未成年子女的医药费用可由父母一方扣除。

20. **Q：住房贷款利息和住房租金能否同时扣？**
    A：**不能**。纳税人和配偶不能同时享受；夫妻双方主要工作城市相同的，住房租金只能由一方扣除。

21. **Q：经营所得如何计税？分类所得如何计税？公益捐赠怎么扣？**
    A：经营所得：应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数；应纳税所得额 = 收入总额 − 成本 − 费用 − 损失；适用 **5%—35% 五级超额累进**。没有综合所得的，再减除 6 万元、专项扣除、专项附加扣除和其他扣除。
    分类所得：应纳税额 = 每次（月）应纳税所得额 × **20%**。利息股息红利、偶然所以每次收入额为应纳税所得额；财产转让 = 收入 − 财产原值 − 合理费用；财产租赁 ≤4000 减 800、>4000 ×(1−20%)，出租住房减按 10%。
    个税公益捐赠：捐赠额未超过纳税人申报的**应纳税所得额 30%** 的部分可以扣除。

22. **Q：个税汇算清缴的办理时间？无须办理的情形？**
    A：时间：综合所得次年 **3 月 1 日—6 月 30 日**；经营所得次年 **3 月 31 日前**；分类所得次年 **6 月 30 日前**；境外所得次年 **3 月 1 日—6 月 30 日**。
    无须办理：①需补税但综合所得收入全年不超过 **12 万元**；②需补税金额不超过 **400 元**；③已预缴税额与年度应纳税额一致；④符合退税条件但不申请退税。

23. **Q：年终奖是否并入综合所得汇算？**
    A：素材明确年度汇算**不涉及**纳税人按规定选择**不并入综合所得（例如年终奖）**计算纳税的所得，且"全年一次性奖金应纳税额计算有特殊规定"；**其具体计算方法素材未明确，请核对教材。**

## 六、典型真题（含解析）

> 素材中所有带年份标签的真题全部收录（同一真题不同来源重复出现的合并为一处，解析取更完整版本）。

### （一）企业所得税纳税人

**【2024·多选】下列（ ）为企业所得税的纳税义务人。**
A. 集体企业　B. 合伙企业　C. 外国企业　D. 个人独资企业　E. 外商独资企业
**答案：ACE**
**解析**：个人独资企业和合伙企业不具有法人资格，不缴纳企业所得税。外商投资企业（外商独资企业）依据中国法律并且在中国境内成立，是居民企业。

**【2021·单选】下列各项中不属于企业所得税纳税人的是（　）。**
A. 事业单位　B. 社会团体　C. 合伙企业　D. 民办非企业单位
**答案：C**

**【2020·单选】下列关于企业所得税纳税人的表述中，正确的是（　）。**
A. 依照外国法律成立但实际管理机构在境内的企业均属于居民企业
B. 依照外国法律成立且实际管理机构不在中国境内的企业均属于非居民企业
C. 依照外国法律成立但在中国境内设立机构、场所的企业均属于非居民企业
D. 依法在我国境内成立但实际管理机构在境外的企业均属于非居民企业
**答案：A**
**解析**：居民企业判定看"登记注册地"或"实际管理机构所在地"，二者有一在境内即为居民企业。D 错——在境内成立即为居民企业，与实际管理机构是否在境外无关。

### （二）征税对象与所得来源地

**【2023·单选】关于判断来源于中国境内、境外的所得的说法中，错误的是（　）。**
A. 销售货物所得，按照交易活动发生地确定
B. 提供劳务所得，按照劳务发生地确定
C. 股息、红利等权益性投资所得，按照分配所得的企业所在地确定
D. 权益性投资资产转让所得，按照投资方企业所在地确定
**答案：D**
**解析**：权益性投资资产转让所得应按**被投资企业所在地**确定。

**【2020·多选】根据企业所得税法，下列判断来源于中国境内、境外的所得的原则中，正确的有（　）。**
A. 销售货物所得，按照生产货物所在地确定
B. 提供劳务所得，按照劳务发生地确定
C. 股息所得，按照被投资企业所在地确定
D. 利息所得，按照负担、支付所得的企业或者机构、场所所在地确定
E. 不动产转让所得，按照不动产所在地确定
**答案：BDE**
**解析**：销售货物所得按**交易活动发生地**；股息红利等权益性投资所得按**分配所得的企业所在地**。

**【2024·多选】在境内未设立机构、场所的非居民企业从事下列活动取得的所得，需在我国缴纳企业所得税的有（　）。**
A. 将设备出租给中国居民企业在境内使用
B. 将境外货物出口到境内
C. 在境外为境内企业提供服务
D. 将境外不动产出租给中国居民企业使用
E. 转让中国居民企业股权
**答案：ADE**
**解析**：A 租金所得按支付方所在地确定为境内所得；B 销售货物所得按交易活动发生地为境外；C 劳务所得按劳务发生地为境外；D 不动产在境外，不属于境内所得；E 权益性投资资产转让所得按被投资企业所在地确定为境内。

### （六）税前扣除

**【2020·多选】在计算应纳税所得额时，有关费用支出不超过规定比例部分的准予扣除，超过部分准予在以后纳税年度结转扣除的项目有（　）。**
A. 工会经费　B. 职工教育经费　C. 公益性捐赠　D. 广告费　E. 非经核定的准备金支出
**答案：BCD**
**解析**：职工教育经费（8%）、广宣费（15%/30%）、公益性捐赠（12%）超标部分可结转以后年度扣除；公益性捐赠结转期限为 **3 年**。工会经费超标部分不得结转；准备金支出不得扣除。

**【2023·单选】企业发放补充医疗保险作为职工福利，该项职工福利不超过职工工资总额的一定比例可以在计算企业所得税应纳税所得额时扣除，该扣除比例（　）。**
A. 8%　B. 14%　C. 5%　D. 2%
**答案：C**

**【2023·单选】根据企业所得税法，下列属于不得税前扣除的项目是（　）。**

### （十四）案例分析题

**【2020 真题·案例】** 某居民企业上一年度经税务机关核准的应纳税所得额为 −100 万元。本年度：①取得商品销售收入 5000 万元，特许权使用费收入 200 万元；②全年发生销售成本 2200 万元，税金及附加 320 万元；③销售费用 1340 万元，其中广告费 700 万元，业务宣传费 200 万元；④管理费用 960 万元，其中业务招待费 80 万元，支付给其他企业的管理费 30 万元；⑤营业外支出 80 万元，其中支付客户违约金 20 万元，被市场监督管理部门处以罚款 7 万元，税款滞纳金 3 万元，非广告性质的赞助支出 50 万元。适用税率 25%。

1. 关于收入确认时间的表述中，正确的有（　）。
A. 接受捐赠收入，按照实际收到捐赠资产的日期确认收入的实现
B. 利息收入，按照债权人实际取得利息收入的日期确认收入的实现
C. 企业转让股权收入，应于转让协议生效，且完成股权变更手续时确认收入的实现
D. 债务重组收入，应在债务重组合同或协议生效时确认收入的实现
**答案：ACD**
**解析**：B 应为"合同约定的债务人**应付利息的日期**"，不是实际取得利息的日期。

2. 该企业本年度企业所得税前可以扣除的销售费用为（　）万元。
A. 700　B. 1340　C. 780　D. 1220
**答案：D**
**解析**：广宣费扣除限额 = (5000+200) × 15% = 780（万元），实际发生 700+200=900（万元），允许扣除 780 万元；其余销售费用 1340 − 900 = 440（万元）可扣除，合计 440 + 780 = 1220（万元）。

3. 该企业本年度企业所得税前可以扣除的营业外支出为（　）万元。
A. 80　B. 70　C. 30　D. 20
**答案：D**
**解析**：只有支付客户违约金 20 万元（经营性罚款）准予扣除；行政罚款 7 万元、税款滞纳金 3 万元、非广告性赞助 50 万元均不得扣除。

4. 该企业本年度应缴纳的企业所得税税额为（　）万元。
A. 1300　B. 86　C. 113.5　D. 116
**答案：D**
**解析**：逐项计算如下——
- 收入总额 = 5000 + 200 = 5200（万元）；
- 广宣费扣除限额 = (5000 + 200) × 15% = 780（万元），实际 900 万元，允许扣除 780 万元；其余销售费用 1340 − 900 = 440（万元）可扣，**销售费用合计扣除 1220 万元**；
- 管理费用 960 万元中：支付给其他企业的管理费 30 万元不得扣除；业务招待费扣除限额 = min(80 × 60%, 5200 × 5‰) = min(48, 26) = 26（万元），调增 54 万元；**管理费用合计扣除 960 − 30 − 54 = 876（万元）**；
- 营业外支出仅违约金 20 万元可扣；
- 应纳税所得额 = 5200 − 2200 − 320 − 1220 − 876 − 20 − 100（弥补上年亏损）= 464（万元）；
- **应纳税额 = 464 × 25% = 116（万元）**。

2. 该月因提供著作权、专利权特许使用费应预扣预缴的个人所得税为（　）元。
A. 16000　B. 1520　C. 1480　D. 5480
**答案：A**
**解析**：特许权使用费所得预扣预缴按 **20% 比例预扣率**（不适用劳务报酬三级累进表）——

- 专利权特许使用费 65000 元：65000 × (1 − 20%) × 20% = 52000 × 20% = 10400（元）；
- 合计 = 5600 + 10400 = **16000（元）**。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把个人独资企业、合伙企业当企业所得税纳税人 | 判定标准是**法人资格**；二者无法人资格，个人投资者按**"经营所得"**缴个税 |
| 2 | 认为"境内成立 + 实际管理机构在境外"就是非居民企业 | 居民企业看"注册地**或**实际管理机构"，**二者有一在境内即为居民企业** |
| 3 | 所得来源地记混：销售货物按"生产货物所在地" | 销售货物所得按**交易活动发生地**；劳务按**劳务发生地** |
| 4 | 权益性投资资产转让所得按"投资方企业所在地" | 应按**被投资企业所在地** |
| 5 | 不动产转让所得按"交易活动发生地" | 不动产转让所得按**不动产所在地** |
| 6 | 认为"西部地区企业一律 15%" | 只有**设在西部地区的鼓励类产业企业**（主营业务收入占收入总额 60% 以上）减按 15%，且至 **2030-12-31** |
| 7 | 小型微利企业直接按 20% 乘应纳税所得额 | 须先**减按 25% 计算应纳税所得额**，再按 20% 税率，且三个条件**同时满足** |
| 8 | 高新技术企业条件记成"60%、60%、10%"三条件 | 还有研发费用占销售收入比例（5%/4%/3%）和境内研发费用占比 60%，共 4 项 |
| 9 | 把不征税收入与免税收入混为一谈 | 不征税收入**本就不属于征税范围**；免税收入**已构成应税收入但免除**。口诀："财政资金不征税，国债股利非营利" |
| 10 | 认为国债转让收益也免税 | **国债利息收入免税，国债转让收益要纳税** |
| 11 | 持有上市公司股票不满 12 个月的股息红利也免税 | **连续持有居民企业公开发行并上市流通的股票不足 12 个月**取得的投资收益**不免税** |
| 12 | 业务招待费按发生额 60% 全额扣 | **双限额孰低**：min(发生额 × 60%, 销售（营业）收入 × 5‰) |
| 13 | 把营业外收入、投资收益计入广宣费/业务招待费扣除基数 | 基数 = 主营业务收入 + 其他业务收入 + **视同销售收入**，**不含**营业外收入、投资收益、资产处置损益 |
| 14 | 视同销售漏计（如对外捐赠、自产货物对外投资） | 税法上视同销售，**应计入销售（营业）收入**；对外捐赠最典型 |
| 15 | 认为所有罚款都不能扣除 | **行政性罚款不得扣，经营性罚款（银行罚息、合同违约金）准予扣** |
| 16 | 职工教育经费、广宣费超标部分以为不能扣了 | 二者超标部分**准予结转以后纳税年度扣除**；公益性捐赠超 12% 部分结转 **3 年** |
| 17 | 工会经费、职工福利费超标部分以为能结转 | **不能结转**，超额部分永久不得扣除 |
| 18 | 把"补充保险费 5%"与"职工福利费 14%"混淆 | 补充养老/医疗各 **5%**；职工福利费 **14%**；工会经费 **2%**；职工教育经费 **8%**；党组织工作经费 **1%** |
| 19 | 利息费用全额扣除 | 只有向**金融企业**借款才据实扣；向**非金融企业**借款按**金融企业同期同类贷款利率**为限；**资本化利息不得当期直接扣** |
| 20 | 加计扣除与抵免应纳税额混淆 | 加计扣除减**税基**（先 − 再 ×）；专用设备 10% 是抵免**税额**（先 × 后 −），结转 **5 年** |
| 21 | 研发费用加计扣除比例记成 75% | 现行：未形成无形资产 **100%**，形成无形资产 **200%**；集成电路/工业母机 **120%/220%** |
| 22 | 漏记"不适用加计扣除行业" | "**批零烟、租商房、住餐娱**"——批发零售、租赁商务、烟草制造、房地产、住宿餐饮、娱乐 |
| 23 | 房屋建筑物以外未投入使用的固定资产，以为房屋也不能提折旧 | **未投入使用的房屋可以提折旧**；不能提的是"房屋建筑物**以外**未投入使用"的 |
| 24 | 融资租赁/经营租赁折旧方搞反 | **经营租赁租入**→出租方提；**融资租赁租出**→出租方**不再**提（承租方提） |
| 25 | 固定资产折旧起始时间记错 | **投入使用月份次月起**计提；**停止使用月份次月起**停止 |
| 26 | 无形资产摊销年限记成 5 年 | **不得低于 10 年**；自创商誉不得摊销 |
| 27 | 源泉扣缴三种方式混淆 | **法定扣缴**（支付人）、**指定扣缴**（工程/劳务，税务机关指定）、**特定扣缴**（未扣缴时追缴）；代扣税款 **7 日内**缴入国库 |
| 28 | 企业所得税预缴/汇算期限记混 | 预缴：月度或季度终了 **15 日内**；汇算清缴：年度终了 **5 个月内**；中间终止经营：**60 日内** |
| 29 | 个税"纳税人/扣缴义务人/负税人"混淆 | 纳税人与负税人都是**取得所得的个人**；扣缴义务人是**支付所得的单位或个人** |
| 30 | 居民个人按 183 天以外标准判断（如 90 天、1 年） | 无住所居住**累计满 183 天**为居民个人；不满 183 天为非居民个人 |
| 31 | 综合所得收入额一律按全额 | 工资薪金全额；劳务报酬、特许权使用费 **×(1−20%)**；稿酬 **×(1−20%)×70%** |
| 32 | 预扣预缴与汇算清缴的费用扣除口径混淆 | 预扣预缴时劳务/稿酬/特许权 ≤4000 元减 800；**汇算清缴时统一按 20%**，不再考虑 4000 元 |
| 33 | 大病医疗在预扣预缴时扣除 | 大病医疗**只能在汇算清缴时扣除**，且只扣超 15000 元部分、80000 元限额内 |
| 34 | 赡养老人按老人人数累加 | 一名老人年满 60 岁即可，**多名老人也只扣一份 3000 元**；非独生每人**最高 1500 元/月** |
| 35 | 住房贷款利息与住房租金同时扣 | **不能同时享受**；夫妻同城工作，租金只能一方扣 |
| 36 | 经营所得适用 3%—45% 税率 | 经营所得适用 **5%—35% 五级**超额累进；3%—45% 是综合所得 |
| 37 | 经营所得由扣缴义务人代扣代缴 | 经营所得**自行申报**；全员全额扣缴申报范围内**没有经营所得** |
| 38 | 个税汇算清缴时间记错 | 综合所得与境外所得：次年 **3.1—6.30**；经营所得：次年 **3.31 前**；分类所得：次年 **6.30 前** |
