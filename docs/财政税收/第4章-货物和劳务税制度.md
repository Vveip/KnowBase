# 第4章 货物和劳务税制度

> **本章考情**：本章是**难度较大的超级重要章节**，是全书计算题最重、分值最高的章节之一。

**一句话串全章**：
> 货物和劳务税＝**增值税（普征、多环节、价外、抵扣制）＋消费税（特征、单环节、价内、15 个税目）＋关税（进出境、海关管）**。
> 增值税「销项－进项」靠抵扣链条；消费税「从价/从量/复合」三把尺子量销售额或数量；关税「完税价格×税率」先把 FOB/CFR 折成 CIF。三者的计税依据都绕不开「含税价÷(1＋税率或征收率)」这一下。

## 二、知识点精讲

### 考点1 增值税的概念与特点 ★

**概念**：增值税是对在中华人民共和国境内销售货物、服务、无形资产、不动产（以下称应税交易），以及**进口货物**的**单位和个人**就其实现的**增值额**为征税对象而征收的一种税（流转税，或称货物与劳务税）。

> 就某一商品或服务而言，其总增值额是该商品或服务在生产经营各环节新增加价值之和，相当于该商品或服务**进入终端消费环节时的最终销售额**。

**六大特点（务必与其他税种对比记忆）**：

| 特点 | 关键点 | 对比对象 |
|---|---|---|
| 1. 仅就增值额征税，避免重复征税 | **最本质的特征** | 已取消的营业税原则上对销售额全额征税，存在重复征税 |
| 2. 普遍征收 | ①对货物、服务、无形资产、不动产等应税交易普遍征收；②各个生产流通环节征收，流转一次征收一次 | 消费税、资源税只选取部分消费品和资源品征收 |
| 3. 税收负担由最终消费者承担 | 纳税人把税负转嫁下一环节，**纳税人与负税人往往不一致＝间接税** | 所得税、财产税不易转嫁，纳税人与负税人一致＝直接税 |
| 4. 实行税款抵扣制度 | 扣除上一环节已负担的税款，凭购货发票抵扣 | 营业税全额征税，原则上不存在抵扣制度 |
| 5. 实行比例税率 | 我国采用**行业差别比率税率**，不是单一比例税率 | 消费税对有些应税消费品按销售量征收；城镇土地使用税按面积征收 |
| 6. 实行价外税制度 | 计税依据的销售额中**不包含**增值税税额 | 消费税、资源税等是价内税，计税依据中含应纳税额 |

**速记口诀**：**"增值、普遍、消费者、抵扣、比例、价外"**——六个词各对应一个特点；考试常问"错误的是实行单一比率税率"（应为行业差别比率税率）。

### 考点2 增值税的纳税人和扣缴义务人 ★

**纳税人**：在境内销售货物、服务、无形资产、不动产以及进口货物的**单位和个人**（包括个体工商户）。单位指企业、行政单位、事业单位、军事单位、社会组织及其他单位；个人指个体工商户和自然人。

**纳税人分类**（划分标准：年应税销售额）：

| 分类 | 划分标准 | 计税规定 |
|---|---|---|
| 小规模纳税人 | 年应税销售额 **500 万元及以下** | 实行**简易计税办法** |
| 一般纳税人 | 年应税销售额 **500 万元以上** | 实行**一般计税/简易计税**方法 |

- **年应税销售额**：纳税人在**连续不超过 12 个月或 4 个季度**的经营期内累计应征增值税销售额，包括**纳税申报销售额、稽查查补销售额、纳税评估调整销售额**。
- 年应税销售额未超过标准但**会计核算健全**、能提供准确税务资料的，也可办理一般纳税人登记。
- **登记为一般纳税人后，不得转为小规模纳税人**（原则）。
- **自然人属于小规模纳税人**；不经常发生应税交易且主要业务不属于应税交易范围的非企业单位（选择按小规模纳税人纳税的）不办理一般纳税人登记。
- 会计核算健全：能按国家统一会计制度设置账簿，根据合法有效凭证核算。

**扣缴义务人**：中华人民共和国**境外**的单位或个人在境内发生应税销售行为，且在境内**未设有经营机构**的，其**境内购买方（接收方）**为法定扣缴义务人。

```
应扣缴税额 = 接收方支付的价款 ÷（1 + 增值税税率）× 增值税税率
```

**速记口诀**：**"五百万分两家，大的一般计税，小的简易计税；境外的没机构，买方来代扣。"**

### 考点3 增值税的征税范围 ★★★★

**五大类征税范围**：

| 范围 | 内容 | 税率概述 |
|---|---|---|
| 销售货物 | 有偿转让货物所有权，货物＝有形动产，包括电力、热力、气体 | 默认 13%，9% 低税率单独记 |
| 进口货物 | 申报进入我国海关境内的货物 | 不分纳税人，默认 13% |
| 销售服务 | 交通运输、邮政、电信、建筑、金融、生产生活（现代＋生活）服务 | 交邮基电建不动产租 9%；加工修理修配、有形动产租赁 13%；其余默认 6% |
| 销售无形资产 | 技术、商标、著作权、商誉、自然资源使用权（土地使用权、海域使用权、探矿权、采矿权、取水权）和其他无形资产 | 默认 6%，**转让土地使用权 9%** |
| 销售不动产 | 转让不动产所有权，含建筑物、构筑物 | 9% |

**销售服务七大类速查**：

| 服务类别 | 税率 | 记忆要点 |
|---|---|---|
| 交通运输服务 | 9% | 陆路、水路、航空、管道。**程租、期租、湿租**属交通运输；**光租、干租**属有形动产经营租赁 13% |
| 邮政服务 | 9% | 邮政普遍服务、邮政特殊服务、其他邮政服务（邮政储蓄按金融服务 6%） |
| 电信服务 | 基础 9% / 增值 6% | 基础＝语音通话、出租出售带宽波长；增值＝电子数据传输应用、互联网接入、卫星电视信号落地转接 |
| 建筑服务 | 9% | 工程、安装、修缮、装饰、其他建筑服务。**出租建筑设备配备操作人员属建筑服务 9%**；单纯出租设备 13% |
| 金融服务 | 6% | 贷款服务、直接收费金融服务、保险服务、金融商品转让。**融资性售后回租按贷款服务**；以货币资金投资收取固定利润或保底利润按贷款服务 |
| 现代服务（生产生活服务主体） | 6%（租赁除外） | 研发技术、信息技术、文化创意、物流辅助、租赁（13%/9%）、鉴证咨询、广播影视、商务辅助 |
| 生活服务 | 6% | 文化体育、教育医疗、旅游娱乐、餐饮住宿、居民日常、其他生活服务 |

【巧思妙记】**现代服务、生活服务少不了"交邮建电金"**。
【巧思妙记】销售货物 9%：**农业、水气、文娱**；销售服务 9%：**交邮基电建不动产**。

**易混归属（选择题高频）**：
- 车辆停放服务、道路通行服务（过路费、过桥费、过闸费）→ **不动产经营租赁** 9%
- 不动产广告位出租 → 不动产租赁 9%；飞机车辆等有形动产广告位出租 → 有形动产租赁 13%
- 水路运输的光租、航空运输的干租 → **有形动产经营租赁 13%**
- 出租车公司向使用本公司自有出租车的司机收取的管理费 → 陆路运输 9%
- 无运输工具承运业务、运输工具舱位承包/互换 → 交通运输 9%
- 装卸搬运、仓储、收派、打捞救助、港口码头、货运客运场站、航空服务 → 现代服务中的**物流辅助服务 6%**
- 快递企业提供快递服务收入 → 收派服务 6%
- 宾馆旅馆提供会议场地及配套服务 → 会议展览服务（文化创意）6%
- 游览场所经营索道、摆渡车、电瓶车、游船 → 文化体育服务 6%
- 纳税人提供植物养护服务 → 其他生活服务 6%
- 纳税人对安装运行后的电梯提供的维护保养服务 → 其他现代服务 6%
- 纳税人办理退票收取的退票费、手续费 → 其他现代服务 6%
- 物业管理、经纪代理、人力资源、安全保护 → 商务辅助服务 6%
- 翻译服务和市场调查服务 → 按咨询服务 6%

**（一）视同应税交易（《增值税法》第五条）**

```
① 单位和个体工商户（无自然人）将自产或者委托加工的货物用于集体福利或者个人消费
② 单位和个体工商户（无自然人）无偿转让货物
③ 单位和个人（有自然人）无偿转让无形资产、不动产或者金融商品
```

**（二）非应税交易（《增值税法》第六条，不征收增值税）**
1. 员工为受雇单位或者雇主提供取得工资、薪金服务；
2. 收取行政事业性收费、政府性基金；
3. 依照法律规定被征收、征用而取得补偿；
4. 取得存款利息收入。
（另：非上市公司股权转让、被保险人获得的保险赔付、已缴过企业所得税的股息红利，也不征增值税。）

**（三）混合销售与兼营**

| | 混合销售 | 兼营 |
|---|---|---|
| 含义 | **一项**销售行为既涉及货物又涉及服务 | 纳税人**同时兼有**销售货物、提供应税劳务、发生应税行为 |
| 税务处理 | 按**主业**交税 | 分别核算适用不同税率或征收率的销售额；**未分别核算的，从高适用税率** |

【提示】纳税人销售活动板房、机器设备、钢结构件等自产货物**同时提供建筑、安装服务，应分别核算**货物和建筑服务的销售额，分别适用不同税率或征收率。

**速记口诀**：**"一项销售主附关系混合销，两项以上各自核算兼营收；不分别算就从高。"**

### 考点4 增值税的税率和征收率 ★★★★

**（一）税率**

| 税率 | 适用范围 |
|---|---|
| **13%** | 销售或进口一般货物；加工、修理修配劳务；**有形动产租赁服务**；进口货物（另有规定除外） |
| **9%** | ①**货物**：农产品（粮食）、食用植物油、食用盐、二甲醚、自来水、暖气、冷气、热水、煤气、石油液化气、天然气、沼气、居民用煤炭制品、图书、报纸、杂志、音像制品、电子出版物、饲料、化肥、农药、农机、农膜。②**服务**：交通运输、邮政、**基础电信**、建筑、不动产租赁服务、销售不动产、**转让土地使用权** |
| **6%** | 销售一般服务、增值电信服务、金融服务、生产生活服务（租赁除外）、销售或租赁无形资产（转让土地使用权除外） |
| **零税率** | ①纳税人出口货物；②境内单位和个人跨境销售国务院规定范围内的服务、无形资产（完全在境外消费的研发、合同能源管理、设计、广播影视制作发行、软件、电路设计测试、信息系统、业务流程管理、离岸服务外包；完全在境外使用的技术；国际运输、航天运输、对外修理修配） |

【巧思妙记】9% 口诀：**"民生：6 气 2 水油盐煤；农业：3 农饲料和化肥；文化：图书报纸和杂志，音像电子二甲醚；行业：不动产是交邮的基础。"**

**（二）征收率**

| 征收率 | 适用情形 |
|---|---|
| **3%** | ①小规模纳税人；②一般纳税人销售特定货物（县级及以下小型水力发电单位生产的电力、自产自来水、建筑用和生产建筑材料所用的砂土石料、商品混凝土、抗癌药品和罕见病药品、用微生物或人/动物血液组织制成的生物制品）；③一般纳税人特定应税行为（公共交通运输服务、动漫产品设计制作、电影放映、仓储、装卸搬运、收派、文化体育服务）；④建筑服务（清包工、甲供工程、建筑工程老项目、跨县市提供建筑服务） |
| **5%** | ①一般纳税人选择简易计税的不动产销售；②一般纳税人选择简易计税的不动产经营租赁；③转让 2016 年 4 月 30 日前取得的土地使用权选择简易计税；④劳务派遣服务选择差额纳税；⑤人力资源外包服务选择简易计税 |
| **3% 减按 2%** | 销售自己使用过的不得抵扣且未抵扣进项税额的固定资产；销售旧货 |
| **5% 减按 1.5%** | 个人出租住房 |
| **3% 减按 0.5%** | 从事二手车经销的纳税人销售其收购的二手车（2023-09-22 至 2027-12-31） |

【巧思妙记】3% 特定货物：**"小水电、建材、药品、生物制品"**；3% 特定行为：**"公交放动漫，文体仓卸派"**。

**（三）小规模纳税人优惠征收率**
- 2023-01-01 至 2027-12-31：月销售额 **10 万元以下（含）免征增值税**；适用 3% 征收率的应税销售收入**减按 1%** 征收。
- 2026-01-01 至 2027-12-31：小规模纳税人发生除销售、出租不动产或转让土地使用权之外的应税交易，依 3% 征收率**减按 1%** 征收。

**（四）涉及不同税率、征收率的规定**
- 一项应税交易涉及两个以上税率、征收率的，按**主要业务**适用（须同时符合：包含两个以上不同税率业务＋业务间有明显主附关系）。
- 两项以上应税交易的，**分别核算**；未分别核算的，**从高适用税率**。

**速记口诀**：**"十三货物加工修配动产租；九是农水气文娱加交邮基电建不动；六是余下服务和无形；出口跨境零税率。"**

### 考点5 增值税的计税依据——销售额的确定 ★★★★

**（一）一般销售方式**

**计入销售额**：向购买方收取的**全部价款＋价外费用**。
价外费用包括：手续费、集资费、奖励费、违约金、滞纳金、延期付款利息、赔偿金、包装费、**包装物租金**、储备费、优质费、运输装卸费、代收款项、代垫款项等。**价外费用视为含税收入**。

**不计入销售额**：
1. 增值税销项税额；
2. 受托加工应征消费税的消费品所**代收代缴的消费税**；
3. 符合条件的代垫运输费用（运费发票开具给购买方并转交购买方）；
4. 符合条件的代为收取的政府性基金和行政事业性收费（全额上缴财政）；
5. 销售货物同时代办保险收取的保险费，以及代购买方缴纳的**车辆购置税、车辆牌照费**；
6. 以委托方名义开具发票代委托方收取的款项。

**（二）含税与不含税的判断**

| 含税销售额 | 不含税销售额 |
|---|---|
| 价税合计金额、含税收入 | 增值税专用发票上注明的价款 |
| 普通发票上注明的金额 | |
| 价外费用、逾期包装物押金 | |
| 零售价、差额计税情形 | |

【提示】题目中如果没有特别说明是含税收入，一般作为**不含税**收入处理。一般纳税人一般计税业务默认不含税；小规模纳税人默认含税。

**（三）特殊销售方式**

| 销售方式 | 销售额确定 |
|---|---|
| 商业折扣 | 销售额和折扣额在**同一张发票"金额"栏**分别注明 → 按折扣后；仅在"备注"栏注明或另开发票 → 不得减除 |
| 销售折扣（现金折扣） | 融资性质理财费用，**不得**从销售额中减除 |
| 销售折让 | 按规定开具**红字增值税专用发票**，从当期销项税额中抵减 |
| 以旧换新 | 一般货物按**新货物**同期销售价格；**金银首饰**按实际收取的不含税差价 |
| 还本销售 | 销售额就是货物售价，**不得扣减**还本支出 |
| 以物易物 | **双方均作购销处理**，各自发出的货物核算销售额计销项，收到的货物计进项 |

**（四）包装物押金**

| 情形 | 收取时 | 逾期时 |
|---|---|---|
| 一般货物（增值税） | 不并入 | 换算不含税价并入 |
| 一般货物（消费税） | 不并入 | 并入 |
| 啤酒、黄酒、成品油（增值税） | 不并入 | **并入** |
| 啤酒、黄酒、成品油（消费税） | 不并入 | **不并入**（从量定额征收） |
| 除啤酒黄酒外的其他酒类（增值税/消费税） | **并入** | 不再并入 |

【提示】收取 1 年以上的押金，无论是否退还，均并入销售额征税。白酒生产企业向商业销售单位收取的**品牌使用费**应并入销售额计征消费税。

**（五）视同销售/价格明显偏低的销售额核定顺序**

```
① 按纳税人最近时期销售同类产品（货物、服务、无形资产或不动产）的平均价格
② 按其他纳税人最近时期销售同类产品的平均价格
③ 按组成计税价格确定
```
【巧思妙记】**"先看市场售价，再计算组价。"**

```
一般货物组价   = 成本 ×（1 + 成本利润率）
应税消费品组价 = 成本 ×（1 + 成本利润率）÷（1 - 消费税比例税率）
成本利润率 = 10%（国务院税务主管部门可调整）
```

**（六）差额计税（允许从含税销售额中扣除的价款）**

| 业务 | 扣除项目 |
|---|---|
| 金融商品转让（6%） | （卖出价－买入价）÷（1＋6%）；不得开专票；负差可抵下期、不可转下年 |
| 旅游服务 | 支付给他人的住宿费、餐饮费、交通费、签证费、门票费、其他接团企业旅游费 |
| 建筑服务（简易） | 支付的分包款 |
| 融资租赁 | 借款利息、发行债券利息、车辆购置税（**两息一税**） |
| 融资性售后回租 | 借款利息、发行债券利息（**两息**） |
| 客运场站服务 | 支付给承运方的运费 |
| 航空运输服务 | 代收的机场建设费、代售其他航空运输企业客票代收转付的价款 |
| 经纪代理服务 | 代委托方收取并代为支付的政府性基金或行政事业收费 |
| 劳务派遣服务 | 代用工单位支付给劳务派遣员工的工资、福利、社保及住房公积金 |
| 房地产老项目销售 | 不动产购置原价或取得时的作价 |
| 金银首饰以旧换新 | 旧金银首饰的作价 |
| 房地产开发企业售房 | 土地价款（按可售建筑面积比例分摊）：当期允许扣除的土地价款＝当期销售建筑面积÷可供销售建筑面积×支付的土地价款 |

【提示】扣除的价款应取得合法有效凭证留存备查，否则不得扣除。

**速记口诀**：**"全额加价外，六项不计入；押金酒类收时就并，其他逾期才并；差额扣除凭凭证。"**

### 考点6 一般计税方法：销项税额与进项税额 ★★★★

**（一）销项税额**

```
销项税额 = 不含税销售额 × 增值税税率
不含税销售额 = 含税销售额 ÷（1 + 增值税税率）
```

**（二）进项税额——准予抵扣**

| 类别 | 内容 |
|---|---|
| 凭票抵扣 | ①增值税专用发票（含税控机动车销售统一发票）注明的税额；②海关进口增值税专用缴款书注明的税额；③代扣代缴完税凭证注明的税额 |
| 计算抵扣——农产品 | 按收购发票或销售发票注明的买价和**扣除率**计算：一般 **9%**；购进用于生产或委托加工 **13% 税率货物**的农产品（如购入番茄加工番茄酱）按 **10%** |
| 计算抵扣——道路桥闸通行费 | 收费公路电子普票按票面税额；**桥、闸通行费：发票注明金额 ÷（1＋5%）×5%** |
| 计算抵扣——国内旅客运输服务 | 航空：（票价＋燃油附加费）÷（1＋9%）×9%；铁路：票面金额÷（1＋9%）×9%；公路、水路：票面金额÷（1＋3%）×3%。电子发票按票面税额。**限于与本单位签订劳动合同的员工及劳务派遣员工** |

【提示】纳税人租入固定资产、不动产，既用于一般计税项目，又用于简易计税、免税、集体福利或个人消费的，进项税额**准予全额抵扣**。

**（三）进项税额加计抵减**
- 2023-01-01 至 2027-12-31：**先进制造业**按当期可抵扣进项税额**加计 5%** 抵减应纳税额。
- 2023-01-01 至 2027-12-31：**集成电路企业、工业母机企业**按当期可抵扣进项税额**加计 15%** 抵减。

```
当期加计抵减额 = 当期可抵扣进项税额 × 加计比例（5% 或 15%）
```

**（四）进项税额留抵**
当期销项税额小于进项税额不足抵扣时，不足部分可**结转下期继续抵扣**。

**速记口诀**：**"专票缴款书完税证，凭票抵扣；农产 9 挑 10，桥闸五五，行程单九三。"**

### 考点7 不得抵扣的进项税额、转出与转入 ★★★★

**（一）不得从销项税额中抵扣的进项税额**

```
① 用于简易计税项目、免征项目、集体福利或个人消费的购进货物、劳务、服务、无形资产、不动产
② 非正常损失的购进货物
③ 非正常损失的在产品、产成品所耗用的购进货物
④ 非正常损失的不动产，以及该不动产所耗用的购进货物、设计服务和建筑服务
⑤ 非正常损失的不动产在建工程所耗用的购进货物、设计服务和建筑服务
⑥ 购进的贷款服务、餐饮服务、居民日常服务和娱乐服务
```

【巧思妙记】**"贷餐常乐"**——贷款、餐饮、居民日常、娱乐四类服务进项一律不得抵扣（即使取得专票）。
【提示】**非正常损失**指因**管理不善**造成被盗、丢失、霉烂变质的损失，以及被执法部门依法没收、销毁、拆除的货物或不动产（自然灾害等不属于非正常损失）。

**（二）无法划分时的不得抵扣公式**

```
不得抵扣的进项税额
 = 当期无法划分的全部进项税额 ×（当期简易计税项目销售额 + 免税项目销售额）÷ 当期全部销售额
```

**（三）进项税额转出**（已抵扣进项税额的购进货物发生不得抵扣情形）

```
货物、服务：转出额 = 已抵扣进项税额 × 损失比例
购入免税农产品：进项税额转出 = 成本 ÷（1 - 10%）× 10%   （用于生产13%税率货物）
                进项税额转出 = 成本 ÷（1 -  9%）×  9%   （用于生产9%税率货物）
固定资产/无形资产/不动产：进项税额转出 = 净值 × 适用税率
```

**（四）进项税额转入**（不得抵扣且未抵扣的长期资产，改变用途用于允许抵扣项目，**次月**计算）

```
可抵扣进项税额 = 增值税扣税凭证注明或计算的进项税额 × 不动产净值率
可抵扣进项税额 = 固定资产、无形资产、不动产净值 ÷（1 + 适用税率）× 适用税率
```

**速记口诀**：**"不产生销项的进项不得抵扣；法定不得抵扣：贷餐常乐；已抵扣的要转出，没抵扣的可转入。"**

### 考点8 简易计税方法应纳税额 ★★★★

```
应纳税额 = 不含税销售额 × 征收率
不含税销售额 = 含税销售额 ÷（1 + 征收率）
```

**常见差额简易计税公式**：

| 业务 | 公式 |
|---|---|
| 跨县市提供建筑服务（简易 3%） | 应纳税额＝（全部价款和价外费用－支付的分包款）÷（1＋3%）×3% |
| 销售 2016-4-30 前取得（不含自建）不动产（5%） | 应纳税额＝（收入－购置原价）÷（1＋5%）×5% |
| 销售 2016-4-30 前自建不动产（5%） | 应纳税额＝收入÷（1＋5%）×5% |
| 出租 2016-4-30 前取得的不动产（5%） | 应纳税额＝收入÷（1＋5%）×5% |
| 销售自己使用过的固定资产（3% 减按 2%） | 应纳增值税＝含税销售额÷（1＋3%）×2% |
| 二手车经销（3% 减按 0.5%） | 应纳增值税＝含税销售额÷（1＋0.5%）×0.5% |
| 个人出租住房（5% 减按 1.5%） | 按 3% 征收率减按 1.5% 计算 |

**销售自己使用过的固定资产归类**：

| 纳税人 | 情形 | 税务处理 |
|---|---|---|
| 小规模纳税人 | 销售自己使用过的固定资产 | 3% 减按 2% |
| 小规模纳税人 | 销售自己使用过的除固定资产外的物品 | 3% |
| 一般纳税人 | 已抵扣进项税额 | 按适用税率 13% |
| 一般纳税人 | 未抵扣进项税额（不得抵扣且未抵扣） | 3% 减按 2% |
| 纳税人 | 销售旧货（旧汽车、旧摩托车、旧游艇，不含自己使用过的物品） | 3% 减按 2% |

【提示】一般纳税人自选择适用简易计税方法当月起，**36 个月内不得变更**。

### 考点9 进口货物应纳税额 ★★★★

```
应纳税额 = 组成计税价格 × 增值税税率（不得抵扣任何税额）
```

| 货物类型 | 组成计税价格 |
|---|---|
| 一般货物 | 关税完税价格 + 关税 |
| 从价计征应税消费品 | （关税完税价格 + 关税）÷（1 - 消费税比例税率） |
| 复合计征应税消费品 | （关税完税价格 + 关税 + 进口数量 × 消费税定额税率）÷（1 - 消费税比例税率） |

纳税人为进口货物的收货人或者办理报关手续的单位和个人。

### 考点10 出口货物、劳务及服务退（免）税 ★★★★

遵循**"征多少、退多少""未征不退和彻底退税"**原则，实行免税与退税相结合的政策，包括三种：**出口退免税政策、出口免税政策、出口征税政策**。

| 政策 | 内容 |
|---|---|
| 出口退免税（"免税并退税"） | 出口环节免征增值税，出口前承担的增值税按规定退还，即**零税率**政策 |
| 出口免税（"免税不退税"） | 出口环节免征增值税，但不退还 |
| 出口征税（"不免税不退税"） | 与内销商品一样征收增值税 |

**两种退免税办法**：
1. **免抵退税办法**：免征出口环节增值税，对应进项税额抵减应纳增值税额（不包括即征即退、先征后返、简易计税部分），未抵减完的退还。适用于生产企业出口自产货物和视同自产货物、列名生产企业出口非自产货物、生产企业跨境销售服务无形资产等。
2. **免退税办法**：外贸企业或其他单位出口货物、跨境销售外购的服务或无形资产，免征出口环节增值税，对应进项税额予以退还。

【提示】除财政部和税务总局明确的外，**出口退税率与适用税率相同**；退税率的执行时间以出口货物报关单（出口退税专用）注明的出口日期为准。销售适用零税率的服务和无形资产，退税率即其增值税税率。

### 考点11 增值税的减税、免税 ★

**（一）起征点**
- 适用范围：**小规模纳税人**。
- 2026-01-01 至 2027-12-31：月销售额 **10 万元**；季度销售额 **30 万元**；按次纳税每次（日）销售额 **1000 元**（一日内多次应税交易按日适用起征点标准）。
- 达到起征点的，**全额**计算缴纳增值税。
- 【沿革说明】旧《增值税暂行条例》起征点为按期纳税月销售额 5000～20000 元、按次纳税每次销售额 300～500 元，**已过时**；现行口径为月 10 万/季 30 万，旧值仅作沿革了解。

**（二）法定免税项目（高频）**
1. 农业生产者销售的自产农产品（含农业机耕、排灌、病虫害防治、农牧保险及相关培训）；
2. 医疗机构提供的医疗服务；
3. 古旧图书；自然人销售自己使用过的物品；
4. 直接用于科学研究、科学试验和教学的进口仪器、设备；
5. 外国政府、国际组织无偿援助的进口物资和设备；
6. 由残疾人组织直接进口供残疾人专用的物品；残疾人个人提供的服务；
7. 托儿所、幼儿园、养老机构、残疾人服务机构提供的育养服务；婚姻介绍服务；殡葬服务；
8. 学校提供的学历教育服务；学生勤工俭学提供的服务；
9. 纪念馆、博物馆、文化馆、文物保护单位管理机构、美术馆、展览馆、书画院、图书馆举办文化活动的门票收入；宗教场所举办文化、宗教活动的门票收入（**第一道门票**）；
10. 个人转让著作权；个人销售自建自用住房；避孕药品和用具。

【巧思妙记】**"需要照顾的（老弱病残幼）；需要鼓励的（科教文卫）。"**

**（三）即征即退**
1. 一般纳税人销售自行开发生产的软件产品，实际税负**超过 3% 的部分**即征即退；
2. 一般纳税人提供管道运输服务，实际税负超过 3% 的部分即征即退；
3. 经批准从事融资租赁业务的一般纳税人，提供有形动产融资租赁和融资性售后回租服务，实际税负超过 3% 的部分即征即退；
4. 安置残疾人的单位和个体工商户，按安置残疾人人数限额即征即退。

【提示】纳税人兼营优惠项目应单独核算销售额，未单独核算不得享受优惠；放弃优惠的 36 个月内不得享受该项优惠（小规模纳税人除外）。

### 考点12 增值税的征收管理 ★★

**（一）纳税义务发生时间**

| 销售方式 | 纳税义务发生时间 |
|---|---|
| 直接收款 | 收到销售额或取得索取销售额凭据的当天；**先开具发票的为开票当天** |
| 赊销和分期收款 | 书面合同约定的收款日期当天；无书面合同或未约定收款日期的，为**货物发出当天** |
| 委托代销 | 收到代销清单或收到全部/部分货款当天；未收到代销清单，为发出货物**满 180 天**当天 |
| 托收承付和委托收款 | 发出货物并办妥托收手续当天 |
| 预收款方式销售货物 | 货物发出当天 |
| 预收款方式提供租赁服务 | 收到预收款当天 |
| 视同销售货物 | 货物移送当天 |
| 金融商品转让 | 金融商品所有权转移当天 |
| 进口货物 | 报关进口当天 |

**（二）纳税期限**
- 计税期间：**1 日、3 日、5 日、10 日、15 日、1 个月或 1 个季度**。不能按固定期限纳税的，可以按次纳税。
- 以 1 个月或 1 个季度为纳税期的，自期满之日起 **15 日内**申报纳税。

**（三）纳税地点**
- 固定业户：机构所在地或居住地；总分支机构不在同一县市的，分别向各自所在地申报（经省级以上批准可汇总）。
- 非固定业户：销售地或劳务发生地。
- 进口货物：报关地海关。

### 考点13 消费税的纳税人和征税范围 ★★★

**概念**：消费税是对我国境内从事**生产、委托加工和进口**应税消费品的单位和个人，就其销售额或销售数量，在**特定环节**征收的一种税。消费税是对**特定的消费品和消费行为**在特定环节征收的一种货物劳务税。

**15 个税目（按性质分类记）**：

| 类别 | 税目与具体范围 |
|---|---|
| 不健康 | **烟**：卷烟、雪茄烟、烟丝、电子烟（不含烟叶）；**酒**：白酒、黄酒、啤酒、其他酒（不含调味料酒、酒精） |
| 不便宜（奢侈/非生活必需） | 高档化妆品、高档手表（不含税价 **10000 元/含以上**）、贵重首饰及珠宝玉石、高尔夫球及球具 |
| 不环保（高能耗） | 游艇（长度大于 8 米小于 90 米的非营利机动艇）、小汽车、摩托车（气缸容量 **250 毫升含以上**） |
| 鞭炮焰火 | 不含体育上用的发令纸、鞭炮引线 |
| 成品油 | 汽油、柴油、航空煤油、石脑油、溶剂油、润滑油、燃料油 |
| 小汽车 | 乘用车、中轻型商用客车；**超豪华小汽车**每辆不含增值税零售价 **130 万元及以上**（财税〔2016〕129号）[^ccar] |
| 木制一次性筷子 | 不含竹制筷子 |
| 实木地板 | 含实木复合地板、未经涂饰的素板 |
| 电池、涂料 | 原电池、蓄电池、燃料电池、太阳电池等 |

**征税环节**：

| 环节 | 规定 |
|---|---|
| 基本环节 | 生产销售、委托加工、进口。除金银铂钻饰品外，其他应税消费品都要在该环节征收 |
| 特殊环节 | **零售**：金银铂钻饰品只在零售环节征收；**超豪华小汽车在零售环节加征一道** |
| 批发环节 | **卷烟、电子烟在批发环节加征一道** |

【提示】高档化妆品指生产（进口）环节销售（完税）价格（不含增值税）**10 元/毫升（克）或 15 元/片（张）及以上**的高档美容、修饰类化妆品、高档护肤类化妆品和成套化妆品。

**速记口诀**：**"三高两车一艇油（高档化妆品、高档手表、高尔夫球、小汽车、摩托车、游艇、成品油）；珠宝首饰烟酒炮（贵重首饰及珠宝玉石、烟、酒、鞭炮焰火）；电池、地板、一筷、涂。"**

[^ccar]: 超豪华小汽车判定门槛以现行有效政策财税〔2016〕129号为准，为不含增值税零售价 130 万元及以上，在零售环节加征 10% 消费税。个别 2026 网校资料标注"90 万元"，未见任何官方文件（财政部/税务总局）支持下调，出题与正文一律按 130 万元。

### 考点14 消费税的税率 ★★

| 税率形式 | 应税消费品 |
|---|---|
| 比例税率 | 大部分应税消费品（常见 15%、20%），税率从 1% 至 56% |
| 定额税率 | **黄酒 240 元/吨；啤酒 250 元/吨（甲类）、220 元/吨（乙类）；成品油 1.52 元/升、1.2 元/升** |
| 复合税率 | **卷烟**（生产进口委托加工：每条价格≥70 元 56% 加 150 元/箱或 0.6 元/条；每条价格<70 元 36%；批发环节 11% 加 250 元/箱或 1 元/条）；**白酒 20% 加 0.5 元/500 克** |

**其他常用税率**：
- 电子烟：生产、委托加工、进口 **36%**；批发环节 **11%**。
- 摩托车：气缸容量 250 毫升 **3%**；250 毫升（不含）以上 **10%**。
- 药酒、葡萄酒（红酒）**10%**；以发酵酒为酒基、酒精度低于 20 度（含）的配制酒 **10%**；其他配制酒参照白酒 **20% 加 0.5 元/斤**。
- 卷烟批发环节（2023 真题）：**11% 加 0.005 元/支**。

**特殊规定**：
1. 纳税人**兼营**不同税率应税消费品，应分别核算销售额、销售数量；**未分别核算的，按最高税率征税**。
2. 将应税消费品与非应税消费品、不同税率应税消费品**组成成套消费品销售**的，按**最高税率**征税。
3. 纳税人兼营卷烟批发和零售业务，未分别核算的，按全部销售额、销售数量计征批发环节消费税。

【提示】消费税税率考试一般会给出，无须特别记忆。

### 考点15 消费税的计税依据 ★★★★

**（一）三种计税方法**

| 计税方法 | 计税依据 | 应纳税额 |
|---|---|---|
| 从价定率 | 全部价款＋价外费用 | 销售额（或组价）× 比例税率 |
| 从量定额 | 销售数量（重量、容积） | 销售/加工/进口数量 × 定额税率 |
| 复合计征 | 销售额＋销售数量 | 销售额（或组价）× 比例税率 ＋ 销售/加工/进口数量 × 定额税率 |

**销售数量规定**：销售应税消费品＝销售数量；自产自用＝移送使用数量；委托加工＝收回数量；进口＝海关核定进口数量。

**（二）从价计征的销售额**
销售额＝向购买方收取的全部价款和价外费用（价外费用默认含增值税，需换算）。**不包括**：增值税税款；符合条件的代垫运输费用；符合条件的政府性基金或行政事业性收费。

```
应税消费品的销售额 = 含增值税的销售额 ÷（1 + 增值税税率或征收率）
```

【提示】一般情况下，从价计算消费税的销售额与计算增值税销项税的销售额**是同一个数字**。

**（三）自产自用**

| 用途 | 增值税 | 消费税 |
|---|---|---|
| 用于连续生产应税消费品（自产烟丝生产卷烟） | 不交 | 不交 |
| 用于连续生产非应税消费品（自产白酒生产酒心巧克力） | 领用环节交，巧克力销售时交 | 巧克力销售时**不交** |
| 用于分配、赠送、职工福利 | 市场平均价 | 市场平均价 |
| 用于**换取生产资料和消费资料、投资入股、抵偿债务** | 市场平均价 | **市场最高售价** |
| 用于在建工程、管理部门、集资、广告、样品 | 不适用 | 市场平均价 |

- 有同类消费品销售价格的，按同类售价（当月各期价格高低不同的，按销售数量**加权平均**；价格明显偏低无正当理由的、无销售价格的，不得列入加权平均）。
- 无同类售价的，按组成计税价格计税（见第四部分公式）。

**（四）委托加工**
- 委托加工：委托方提供原料和主要材料，受托方只收取加工费和代垫部分辅助材料。
- **假委托加工**（按销售自制应税消费品缴消费税）：①受托方提供原材料生产；②受托方先将原材料卖给委托方再接受加工；③受托方以委托方名义购进原材料生产。
- 纳税：除受托方为个人外，由**受托方**在交货时**代收代缴**；委托个人加工的，由**委托方**收回后缴纳。
- 委托加工收回后**直接销售的不再缴纳消费税**。

**（五）电子烟计税依据**（2022-11-01 起）
- 生产、批发电子烟按**销售额**纳税；生产环节纳税人采用代销方式的，按**经销商（代理商）销售给电子烟批发企业**的销售额纳税；进口电子烟按组成计税价格纳税。
- 代加工业务应分开核算持有商标与代加工的销售额，未分开核算的一并缴纳消费税。

**（六）自设非独立核算门市部**
纳税人通过自设非独立核算门市部销售的自产应税消费品，按**门市部对外销售数额或销售数量**计征消费税。

**速记口诀**：**"连续生产不纳税，其他方面移送纳；换投抵用最高价，增税平均消费税最高；门市部对外卖才算数。"**

### 考点16 消费税应纳税额的计算 ★★★★

**（一）应纳税额计算总览**

| 环节 | 有同类售价 | 无同类售价 |
|---|---|---|
| 自行销售 | 同类售价 × 税率 | —— |
| 自产自用 | 同类消费品销售单价 × 自产自用数量 × 税率 | 组成计税价格 × 税率 |
| 委托加工 | 受托方同类售价 × 委托加工数量 × 税率 | 组成计税价格 × 税率 |
| 进口 | —— | 组成计税价格 × 税率 |

**（二）组成计税价格**

| 情形 | 公式 |
|---|---|
| 自产自用（从价） | （成本＋利润）÷（1－消费税比例税率）＝成本×（1＋成本利润率）÷（1－消费税比例税率） |
| 自产自用（复合） | （成本＋利润＋自用数量×定额税率）÷（1－消费税比例税率） |
| 委托加工（从价） | （材料成本＋加工费）÷（1－消费税比例税率） |
| 委托加工（复合） | （材料成本＋加工费＋委托加工数量×定额税率）÷（1－消费税比例税率） |
| 进口（从价） | （关税完税价格＋关税）÷（1－消费税比例税率） |
| 进口（复合） | （关税完税价格＋关税＋进口数量×消费税定额税率）÷（1－消费税比例税率） |

【巧思妙记】**"部分/比例＝整体"**——组价中消费税是组价的一部分，所以除以（1－比例税率）。

**（三）进口卷烟的特殊组价试算**
先按**乙类卷烟 36%** 组价试算，看每条价格是否**≥70 元**；大于或等于 70 元按**甲类 56%** 组价计算，小于 70 元按乙类计算。

**速记口诀**：**"自产组价看成本利润，委托组价看材料加工，进口组价看完税加关税；复合计税分子再加定额税。"**

### 考点17 已纳消费税的扣除 ★★★★

**（一）外购已税消费品扣除范围**
1. 外购已税**烟丝**生产卷烟；
2. 外购已税**高档化妆品**生产高档化妆品；
3. 外购已税**珠宝玉石**生产贵重首饰及珠宝玉石；
4. 外购已税**鞭炮、焰火**生产鞭炮、焰火；
5. 外购已税**杆头、杆身和握把**生产高尔夫球杆；
6. 外购已税**木制一次性筷子**生产木制一次性筷子；
7. 外购已税**实木地板**生产实木地板；
8. 外购已税**汽油、柴油**连续生产汽油、柴油；
9. 外购已税**汽油、柴油、石脑油、燃料油、润滑油**连续生产应税成品油。

**（二）委托加工收回已税消费品扣除范围**
与上述基本一致，另包括以委托加工收回的已税**摩托车**连续生产应税摩托车。

**（三）扣除计算**

```
当期准予扣除的外购应税消费品已纳税款
 = 当期准予扣除的外购应税消费品买价（或数量）× 外购应税消费品适用税率（或税额）
当期准予扣除的买价（或数量）
 = 期初库存 + 当期购进 - 期末库存   （买价均不含增值税）
```

```
当期准予扣除的委托加工应税消费品已纳税款
 = 期初库存已纳税款 + 当期收回已纳税款 - 期末库存已纳税款
```

**（四）扣除注意事项**
① 不包括除葡萄酒以外的其他酒，以及摩托车、小汽车、高档手表、游艇等；
② 原则上必须是**同一税目、同一纳税环节**才能扣除；
③ 按**生产领用数量**抵扣已纳消费税（目的是避免重复征税）。

### 考点18 消费税的征收管理 ★★

**（一）纳税义务发生时间**

| 结算方式 | 纳税义务发生时间 |
|---|---|
| 赊销和分期收款 | 书面合同约定的收款日期当天；无书面合同或未约定的，为发出应税消费品当天 |
| 预收货款 | 发出应税消费品当天 |
| 托收承付和委托银行收款 | 发出应税消费品并办妥托收手续当天 |
| 其他结算方式 | 收讫销售款或取得索取销售款凭据当天 |
| 自产自用 | 移送使用当天 |
| 委托加工 | 纳税人**提货**当天 |
| 进口 | 报关进口当天 |

**（二）纳税期限**
- 分别为 1 日、3 日、5 日、10 日、15 日、1 个月或 1 个季度。
- 以 1 个月或 1 个季度为纳税期的，自期满之日起 **15 日内**申报纳税。
- 以 1 日、3 日、5 日、10 日、15 日为纳税期的，自期满之日起 **5 日内预缴**，次月 1 日起 15 日内申报结清上月应纳税款。
- 进口应税消费品，自海关填发税款缴款书之日起 15 日内缴纳。

**（三）纳税地点**
- 销售的应税消费品以及自产自用的：机构所在地或居住地主管税务机关。
- 委托加工：受托方（单位）代收代缴，向受托方所在地申报；**委托个人加工的，由委托方向其机构所在地或居住地申报**。
- 进口：进口人或其代理人向**报关地海关**申报。

### 考点19 增值税与消费税的区别 ★★

| 税种 | 增值税 | 消费税 |
|---|---|---|
| 征税对象 | 对所有物都征收 | 仅对少量特定物征税（15 个税目） |
| 税率 | 行业差别比例税率 | 多为比例税率，也有定额税率和复合税率 |
| 征税环节 | 多环节道道征收 | 原则单环节征收，但有例外（金银首饰零售、卷烟电子烟批发、超豪华小汽车零售） |
| 价税关系 | **价外税** | **价内税** |
| 与税前利润的关系 | 通过"应交税费——应交增值税"单独核算，不影响所得 | 一般计入**税金及附加**，作为期间费用影响所得 |
| 关系 | **征收消费税的一定征收增值税；征收增值税的不一定征收消费税** | |

### 考点20 关税的纳税人、征税范围与税率 ★

**概念**：关税是由**海关**对进出国境或**关境**的货物、物品征收的一种税。"境"指关境（海关境域/关税领域）。一国通常关境与国境一致；设自由港或自由贸易区时关境小于国境（香港、澳门为单独关境区）。

| 对象 | 纳税人 |
|---|---|
| 进口货物 | 收货人 |
| 出口货物 | 发货人 |
| 物品 | 所有人、推定所有人（携带行李物品的携带人、运输工具上自用物品持有人、进口个人邮件收件人等） |

**征税范围**：凡是国家允许，属于《进出口税则》规定应税的货物、物品。**货物**＝贸易性商品；**物品**＝非贸易性商品（入境旅客行李、个人邮递物品、运输工具服务人员自用物品等）。

**税率**：
- 进口货物：**普通税率**（原产于与我国未订有关税互惠协议的国家或地区）、**优惠税率**（原产于与我国订有关税互惠协议的国家或地区）。
- 出口货物：**没有普通税率和优惠税率之分，是一种差别比例税率**。
- 税率运用：进出口货物适用**海关接受申报进口或出口之日**实施的税率；保税货物不复运出境、减免税货物转让或移作他用、暂准进境货物不复运出境、租赁进口分期缴税的，适用**海关接受申报办理纳税手续之日**税率。

### 考点21 关税的完税价格 ★★★★

**（一）进口货物完税价格**

```
进口货物完税价格 = 货价 + 货物运抵我国境内输入地点起卸前的运输及相关费用、保险费（即 CIF）
```

**不计入**货物成交价格的项目：
1. 货物运抵境内输入地点起卸**后**的运输费用、保险费；
2. 进口关税；
3. 由买方负担的**购货佣金**。

**运费与保险费**：
- 运费按买方实际支付或应当支付的费用计算；无法确定的，按进口同期运输行业公布的运费率（额）计算。运输工具利用自身动力进境的，不再另行计入运费。
- 保险费按实际支付的费用计算；**无法确定或未实际发生时：保险费＝（货价＋运费）× 3‰**。
- 邮运进口的货物，以**邮费**作为运输及相关费用、保险费。

**特殊货物完税价格**：

| 特殊货物 | 完税价格 |
|---|---|
| 运往境外修理的设备 | 境外修理费 + 料件费 |
| 运往境外加工的货物 | 境外加工费 + 料件费 + 复运进境的运输及相关费用、保险费 |
| 经海关批准留购的暂时进境货物 | 留购价格 |
| 以租金方式对外支付的租赁货物 | 海关审定的租金（利息计入） |
| 留购的租赁货物 | 留购价格 |
| 减税/免税进口货物补税 | 原进口时价格 ×[1－已使用时间（月）÷（监管年限×12）] |

**海关估价方法（成交价格不能确定时依次适用）**：

```
① 相同货物成交价格估价方法
② 类似货物成交价格估价方法
③ 倒扣价格估价方法
④ 计算价格估价方法
⑤ 合理估价方法（补救方法）
```
【巧思妙记】**"相同类似，倒扣计算。"**
【提示】纳税义务人提供资料后可申请**颠倒倒扣价格估价方法和计算价格估价方法的适用次序**。

**（二）出口货物完税价格**

```
出口货物完税价格 = 成交价格 + 货物运至我国境内输出地点装载前的运输及其相关费用、保险费
```

**不计入**：①出口关税；②价款中单独列明的运至输出地点装载后的运输及其相关费用、保险费；③单独列明由卖方承担的佣金。

### 考点22 关税应纳税额的计算 ★★★★

| 计税方式 | 应纳关税税额 |
|---|---|
| **从价税** | 应税进（出）口货物数量 × 单位完税价格 × 适用税率 ＝ 完税价格 × 适用税率 |
| **从量税** | 应税进（出）口货物数量 × 单位货物税额 |
| **复合税** | 应税进（出）口货物数量 × 单位货物税额 ＋ 应税进（出）口货物数量 × 单位完税价格 × 适用税率 |
| **滑准税** | 应税进（出）口货物数量 × 单位完税价格 × 滑准税税率 |

**三种价格条款**：

| 条款 | 全称 | 别称 | 处理 |
|---|---|---|---|
| CIF | 成本加运费、保险费 | **到岸价格** | 可直接计算税款 |
| FOB | 船上交货 | **离岸价格** | 需折算成 CIF |
| CFR | 成本加运费 | **离岸加运费价格** | 需折算成 CIF |

```
FOB 折算：完税价格 =（FOB 价格 + 运费）×（1 + 保险费率）
```

【巧思妙记】**"C-成本，I-保险费，F-运费。"**

### 考点23 关税的税收优惠 ★★

**（一）法定减免税——免征关税**
1. 关税税额在**人民币 50 元以下**的一票货物；
2. 无商业价值的广告品和货样；
3. 外国政府、国际组织无偿赠送的物资；
4. 在海关**放行前**损失的货物；
5. 进出境运输工具装载的途中必需的燃料、物料和饮食用品。

**（二）法定减免税——暂不缴纳关税**
缴纳保证金或提供担保后暂不缴纳，并应自进境或出境之日起 **6 个月内**复运出境/进境：
1. 展览会、交易会、会议及类似活动中展示或使用的货物；
2. 文化、体育交流活动中使用的表演、比赛用品；
3. 新闻报道或摄制电影电视节目使用的仪器、设备及用品；
4. 科研、教学、医疗活动使用的仪器、设备及用品；
5. 上述活动使用的交通工具及特种车辆、货样、安装调试检测设备用的仪器工具、盛装货物的容器、其他非商业目的货物。

**（三）特定减免税**：科教用品、残疾人专用品、加工贸易产品、边境贸易进口物资、保税区进出口货物、出口加工区进出口货物、国家鼓励发展的国内投资项目和外商投资项目进口设备等。

**（四）临时减免税**：由国务院对某个单位、某类商品、某个项目或某批进出口货物的特殊情况，**一案一批、专文下达**的减免税。

### 考点24 关税的征收管理 ★★

**（一）缴纳**

| 项目 | 规定 |
|---|---|
| 申报时间 | 进口货物自运输工具**申报进境之日起 14 日内**；出口货物在运抵海关监管区后**装货的 24 小时以前** |
| 纳税期限 | 自海关**填发税款缴款书之日起 15 日内**向指定银行缴纳 |
| 顺延 | 缴纳期限最后 1 日是周末或法定节假日的，顺延至过后**第 1 个工作日** |
| 延期 | 因不可抗力或国家税收政策调整，经**海关总署**批准可延期，**最长不得超过 6 个月** |

**（二）强制执行**
- 滞纳金自缴纳期限届满滞纳之日起至缴纳关税之日止，按滞纳税款 **0.5‰（万分之五）按日**征收，周末或法定节假日不予扣除。
  ```
  关税滞纳金金额 = 滞纳关税税额 × 滞纳金征收比率 × 滞纳天数
  ```
- 自海关填发缴款书之日起**超过 3 个月**仍未缴纳税款，经**海关关长**批准，可强制扣缴、变价抵缴。

**（三）补征和追征（"一补三追"）**
- 海关发现少征或漏征税款的，自缴纳税款或货物放行之日起 **1 年内**补征。
- 因纳税人违反规定造成少征或漏征的，自应缴纳税款之日起 **3 年以内**追征，并按日加收 **0.5‰（万分之五）** 滞纳金。

**（四）退还**
纳税人自缴纳关税之日起 **1 年内**可申请退还：
1. 已征进口关税的货物，因品质或规格原因原状退货复运出境；
2. 已征出口关税的货物，因品质或规格原因原状退货复运进境，并已重新缴纳因出口而退还的国内环节有关税收；
3. 已征出口关税的货物，因故未装运出口，申报退关。

【提示】海关应自受理退税申请之日起 **30 日内**查实并通知；纳税人自收到通知之日起 **3 个月内**办理退税手续。

### 表6 「N 个不等于」避坑表（本章核心）

| # | 错误说法 | 正解 |
|---|---|---|
| 1 | 增值税是单一比例税率 | ✗ 我国实行**行业差别比率税率** |
| 2 | 消费税是价外税 | ✗ 消费税是**价内税**；增值税才是价外税 |
| 3 | 征收增值税的一定征收消费税 | ✗ 恰恰相反：**征消费税的一定征增值税，征增值税的不一定征消费税** |
| 4 | 包装物押金收取时都要并入销售额 | ✗ 只有**除啤酒、黄酒外的其他酒类**收取时就并入；一般货物逾期才并入 |
| 5 | 啤酒、黄酒的逾期包装物押金要并入增值税销售额 | ✗ 消费税**不并入**（从量定额），但增值税逾期**要并入** |
| 6 | 以旧换新都按差价计税 | ✗ 只有**金银首饰**按实际收取差价；一般货物按**新货物**同期售价 |
| 7 | 商业折扣都可以扣除 | ✗ 必须销售额和折扣额在**同一张发票"金额"栏**分别注明 |
| 8 | 现金折扣（销售折扣）可以减除 | ✗ 销售折扣是融资费用，**不得**从销售额中减除 |
| 9 | 购进贷款服务、餐饮服务的进项可以抵扣 | ✗ **贷餐常乐**（贷款、餐饮、居民日常、娱乐）一律不得抵扣 |
| 10 | 自然灾害损失要进项转出 | ✗ 只有**管理不善**造成的被盗、丢失、霉烂变质（及被没收销毁）才转出 |
| 11 | 自产货物用于集体福利不视同销售 | ✗ **自产或委托加工**货物用于集体福利、个人消费**视同销售**；但**购进**货物用于集体福利**不视同** |
| 12 | 自然人无偿转让货物视同销售 | ✗ 视同销售第一、二类主体是**单位和个体工商户（无自然人）**；第三类含自然人 |
| 13 | 用于投资入股、抵偿债务按平均价计消费税 | ✗ 换取生产资料消费资料、投资入股、抵偿债务，消费税按**最高售价**，增值税按平均价 |
| 14 | 委托加工收回的应税消费品再销售要缴消费税 | ✗ **直接销售不再缴纳**消费税 |
| 15 | 受托方提供原材料也按委托加工 | ✗ 受托方提供原材料、先卖料再加工、以委托方名义购料，均按**销售自制应税消费品**缴税 |
| 16 | 委托个人加工由受托方代收代缴 | ✗ 委托**个人**加工由**委托方**收回后缴纳 |
| 17 | 红酒的包装物押金收取时不并入 | ✗ 除啤酒、黄酒外其他酒类（含红酒）收取时即并入 |
| 18 | 金银首饰在生产环节缴消费税 | ✗ 金银铂钻**只在零售环节**缴 |
| 19 | 卷烟只在生产环节缴 | ✗ 卷烟、电子烟在**批发环节加征**一道 |
| 20 | 关税完税价格含起卸后的运保费 | ✗ 只含**起卸前**的运输及相关费用、保险费 |
| 21 | 购货佣金计入完税价格 | ✗ **买方负担的购货佣金不计入** |
| 22 | CFR 是到岸价格 | ✗ **CIF 才是到岸价格**；CFR 是离岸加运费价格 |
| 23 | FOB 成交可直接计税 | ✗ FOB、CFR 须先折算成 **CIF** |
| 24 | 出口关税分普通税率和优惠税率 | ✗ 出口关税**没有普通/优惠之分**，是差别比例税率 |
| 25 | 个人邮递物品的发件人是纳税人 | ✗ 进口个人邮件的纳税人是**收件人** |
| 26 | 消费税都可以扣除已纳消费税 | ✗ 葡萄酒以外的其他酒、摩托车、小汽车、高档手表、游艇等**不得扣除**；须同税目同环节、按生产领用数量扣 |

## 四、公式与计算（本章重中之重）

### （一）增值税

**公式1 销项税额**
```
销项税额 = 不含税销售额 × 增值税税率
```
> **例题**：某百货公司为增值税一般纳税人，2026 年 4 月销售给消费者日用品一批，收取含税价款 62400 元，当月货物购进时取得增值税专用发票注明价款 30000 元，税率 13%。计算 4 月份应缴纳的增值税。
> **解**：不含税销售额 = 62400 ÷（1＋13%）= 55221.24 元
> 销项税额 = 55221.24 × 13% = 7178.76 元
> 进项税额 = 30000 × 13% = 3900 元
> 应纳增值税 = 7178.76 − 3900 = **3278.76 元**

**公式2 含税销售额换算**
```
不含税销售额 = 含税销售额 ÷（1 + 税率）          【一般计税】
不含税销售额 = 含税销售额 ÷（1 + 征收率）        【简易计税】
```
> **例题**：某植物油加工厂是增值税一般纳税人，2020 年销售食用植物油取得含税销售额 76.3 万元，计算该项业务的销项税额。
> **解**：食用植物油适用 9% 税率。
> 销项税额 = 76.3 ÷（1＋9%）× 9% = 70 × 9% = **6.3 万元**

**公式3 应纳增值税额（一般计税）**
```
应纳增值税额 = 当期销项税额 - 当期进项税额
```
> **例题**：某船运公司为一般纳税人，6 月购进配件取得增值税专票，价款 300 万元、税额 39 万元。6 月开具普票取得：国内运输收入 1090 万元、期租业务收入 272.5 万元、打捞收入 173.31 万元。计算 6 月应缴纳增值税。
> **解**：国内运输、期租按 9%；打捞（物流辅助）按 6%。
> 销项税额 = 1090÷1.09×9% ＋ 272.5÷1.09×9% ＋ 173.31÷1.06×6%
> 　　　　 = 90 ＋ 22.5 ＋ 9.81 = 122.31 万元
> 应纳增值税 = 122.31 − 39 = **83.31 万元**

**公式4 进项税额计算抵扣**
```
农产品进项税额 = 买价 × 扣除率（一般 9%，用于生产13%税率货物 10%）
桥、闸通行费进项税额 = 发票注明金额 ÷（1+5%）× 5%
航空旅客运输进项税额 =（票价 + 燃油附加费）÷（1+9%）× 9%
铁路旅客运输进项税额 = 票面金额 ÷（1+9%）× 9%
公路、水路旅客运输进项税额 = 票面金额 ÷（1+3%）× 3%
```
> **例题**：某企业为一般纳税人，2022 年 4 月从农民手中购入 5 万元苹果用于生产苹果醋，支付运费取得增值税专票注明金额 0.6 万元，销售苹果醋取得不含税收入 12 万元。计算 4 月应缴纳增值税。
> **解**：苹果用于生产 13% 税率货物，扣除率 10%：
> 农产品进项 = 5 × 10% = 0.5 万元
> 运费进项 = 0.6 × 9% = 0.054 万元
> 销项税额 = 12 × 13% = 1.56 万元
> 应纳增值税 = 1.56 − 0.5 − 0.054 = **1.006 万元**

**公式5 不得抵扣进项税额的划分**
```
不得抵扣的进项税额 = 当期无法划分的全部进项税额
                      ×（当期简易计税项目销售额 + 免税项目销售额）÷ 当期全部销售额
```
> **例题**：某一般纳税人当期无法划分的进项税额为 10 万元，当期全部销售额 200 万元，其中简易计税项目销售额 30 万元、免税项目销售额 20 万元。
> **解**：不得抵扣的进项税额 = 10 ×（30＋20）÷ 200 = 10 × 25% = **2.5 万元**

**公式6 进项税额转出**
```
货物、服务：转出额 = 已抵扣进项税额 × 损失比例
免税农产品：转出额 = 成本 ÷（1 - 扣除率）× 扣除率
长期资产：转出额 = 净值 × 适用税率
```
> **例题**：某企业（一般纳税人）因管理不善导致库存原材料毁损，原材料购入时已抵扣进项（税率 13%），材料总成本 110 万元，其中含支付给运输公司（一般纳税人）的运费成本 10 万元。计算应转出的进项税额。
> **解**：应转出进项税额 =（110 − 10）× 13% ＋ 10 × 9% = 13 ＋ 0.9 = **13.9 万元**
> **例题2**：某企业库存购入的用于简单加工后销售的免税农产品，成本 182 万元，因管理不善霉烂变质。
> **解**：应转出进项税额 = 182 ÷（1 − 9%）× 9% = 200 × 9% = **18 万元**

**公式7 进项税额转入**
```
可抵扣进项税额 = 扣税凭证注明或计算的进项税额 × 不动产净值率
可抵扣进项税额 = 固定资产、无形资产、不动产净值 ÷（1+适用税率）× 适用税率
```
> **例题**：2022 年 5 月购进房产用于职工宿舍，增值税专用发票上金额 2000 万元、税额 100 万元，2024 年 5 月完全改成办公楼。假如房产净值率 90%，计算 2024 年可抵进项税额。
> **解**：可抵扣进项税额 = 100 × 90% = **90 万元**

**公式8 简易计税**
```
应纳增值税额 = 不含税销售额 × 征收率
```
> **例题**：某建筑公司为增值税小规模纳税人，2026 年 1 月总包一项工程，含税总包价款 412000 元，分包款 260000 元。计算应纳增值税。
> **解**：应纳增值税 =（412000 − 260000）÷（1＋1%）× 1% = 152000 ÷ 1.01 × 1% = **1504.95 元**
> **例题2**：某修理修配厂（小规模纳税人）2026 年 1 月取得含税收入 360000 元。
> **解**：应纳增值税 = 360000 ÷（1＋1%）× 1% = **3564.36 元**

**公式9 3% 征收率减按 2%（旧固定资产/旧货）**
```
应纳增值税 = 含税销售额 ÷（1+3%）× 2%
```
> **例题**：某企业（小规模纳税人）2022 年 2 月将已使用 5 年的机器以 20 万元价格售出。
> **解**：应纳增值税 = 200000 ÷（1＋3%）× 2% = 194174.76 × 2% = **3883.5 元**

**公式10 二手车减按 0.5%**
```
应纳增值税 = 含税销售额 ÷（1+0.5%）× 0.5%
```
> **例题**：某小规模纳税人主营二手车交易，2023 年 2 月取得含税销售额 40.2 万元。
> **解**：应纳增值税 = 40.2 ÷（1＋0.5%）× 0.5% = 40 × 0.5% = **0.2 万元**

**公式11 进口货物增值税**
```
应纳增值税 = 组成计税价格 × 增值税税率
一般货物：组成计税价格 = 关税完税价格 + 关税
应税消费品：组成计税价格 =（关税完税价格 + 关税）÷（1 - 消费税比例税率）
```
> **例题**：甲公司 2019 年 5 月从国外进口一批音响，海关核定关税完税价格 117 万元，缴纳关税 11.7 万元，增值税税率 13%。
> **解**：应纳增值税 =（117 ＋ 11.7）× 13% = 128.7 × 13% = **16.73 万元**

**公式12 扣缴税额**
```
应扣缴税额 = 接收方支付的价款 ÷（1 + 增值税税率）× 增值税税率
```

**公式13 进项税额加计抵减**
```
当期加计抵减额 = 当期可抵扣进项税额 × 5%（先进制造业）/ 15%（集成电路、工业母机企业）
```

### （二）消费税

**公式14 从价定率**
```
应纳税额 = 销售额 × 比例税率
```
> **例题**：甲酒厂 2020 年 10 月销售果木酒，取得不含增值税销售额 10 万元，同时收取包装物押金 1.13 万元、优质费 2.26 万元。果木酒消费税税率 10%，增值税税率 13%。
> **解**：果木酒属其他酒（10%），包装物押金收取时并入（除啤酒黄酒外的酒类）。
> 消费税 = [10 ＋（1.13 ＋ 2.26）÷（1＋13%）] × 10% = [10 ＋ 3] × 10% = **1.3 万元**

**公式15 从量定额**
```
应纳税额 = 销售数量 × 定额税率
```
> **例题**：位于省会城市的甲餐饮企业 2023 年 4 月取得餐饮服务收入价税合计 636 万元（含自酿 6 吨鲜啤酒金额 2.25 万元），消费税税率甲类啤酒 250 元/吨、乙类 220 元/吨，出厂价 3000 以上为甲类。
> **解**：每吨出厂价 = 22500 ÷ 6 = 3750 元 > 3000 元 → 甲类啤酒。
> 应纳消费税 = 6 × 250 = 1500 元 = **0.15 万元**

**公式16 复合计税**
```
应纳税额 = 销售额 × 比例税率 + 销售数量 × 定额税率
```
> **例题**：某酒厂（一般纳税人）2023 年 4 月销售粮食白酒 12000 斤，售价 5 元/斤；本月销售礼品盒 6000 套，售价 300 元/套，每套含粮食白酒 2 斤（单价 80 元/斤）、薯类白酒 2 斤（单价 70 元/斤）。白酒消费税 20%＋0.5 元/斤，其他酒 10%。（单价均为不含税价）
> **解**：成套销售按最高税率（粮食白酒）征税。
> 白酒部分 = 12000×5×20% ＋ 12000×0.5 = 12000 ＋ 6000 = 18000 元
> 礼品盒部分 = 6000×300×20% ＋ 6000×（2＋2）×0.5 = 360000 ＋ 12000 = 372000 元
> 合计 = 18000 ＋ 372000 = **390000 元**
> **例题2**：某白酒生产企业本月销售自产白酒 500 斤，其中 80% 对外销售，取得不含税销售额 20000 元。比例税率 20%，定额税率 0.5 元/500 克。
> **解**：对外销售数量 = 500 × 80% = 400 斤
> 从价 = 20000 × 20% = 4000 元
> 从量 = 400 × 0.5 = 200 元
> 合计 = **4200 元**

**公式17 自产自用组成计税价格**
```
从价：组成计税价格 = 成本 ×（1 + 成本利润率）÷（1 - 消费税比例税率）
复合：组成计税价格 =（成本 + 利润 + 自用数量 × 定额税率）÷（1 - 消费税比例税率）
```
> **例题**：某高档化妆品厂将一批自产高档化妆品用于集体福利，生产成本 35000 元；将新研制的高档香水用于广告样品，生产成本 20000 元。成本利润率 5%，消费税税率 15%，均无同类产品售价。
> **解**：应纳消费税 =（35000 ＋ 20000）×（1＋5%）÷（1 − 15%）× 15%
> 　　　　 = 55000 × 1.05 ÷ 0.85 × 0.15 = 60588.24 × 0.15 = **9088.24 元**
> （素材中同型题答案为 10191.18 元，系成本利润率/组价口径差异，考试以题目给定成本利润率为准）

**公式18 委托加工组成计税价格**
```
从价：组成计税价格 =（材料成本 + 加工费）÷（1 - 消费税比例税率）
复合：组成计税价格 =（材料成本 + 加工费 + 委托加工数量 × 定额税率）÷（1 - 消费税比例税率）
```
> **例题**：甲公司 2023 年 3 月委托乙酒厂加工 5 吨粮食白酒，甲提供全部酿酒原材料（不含税）10 万元，乙收取加工费并开具专票注明不含税加工费 9.5 万元和辅料费 1 万元。乙酒厂无同类产品销售价格。白酒消费税 20%＋0.5 元/500 克。计算乙酒厂 5 月应代收代缴消费税。
> **解**：5 吨 = 10000 斤，定额税 = 5 吨 × 1000 元/吨 = 5000 元 = 0.5 万元
> 组价 =（10 ＋ 9.5 ＋ 1 ＋ 0.5）÷（1 − 20%）= 21 ÷ 0.8 = 26.25 万元
> 应代收代缴消费税 = 26.25 × 20% ＋ 0.5 = 5.25 ＋ 0.5 = **5.75 万元**
> **例题2**：某化妆品厂受托加工高档化妆品，委托方提供原材料成本 30000 元，收取加工费 10000 元、代垫辅助材料款 5000 元，无同类售价，税率 15%。
> **解**：组价 =（30000 ＋ 10000 ＋ 5000）÷（1 − 15%）= 45000 ÷ 0.85 = 52941.18 元
> 应代收代缴消费税 = 52941.18 × 15% = **7941.18 元**

**公式19 进口应税消费品组成计税价格**
```
从价：组成计税价格 =（关税完税价格 + 关税）÷（1 - 消费税比例税率）
复合：组成计税价格 =（关税完税价格 + 关税 + 进口数量 × 消费税定额税率）÷（1 - 消费税比例税率）
```
> **例题**：某企业 2023 年 10 月进口 180 辆小汽车，每辆关税完税价格 15 万元。关税税率 20%，消费税税率 5%。
> **解**：完税价格 = 180 × 15 = 2700 万元；关税 = 2700 × 20% = 540 万元
> 组价 =（2700 ＋ 540）÷（1 − 5%）= 3240 ÷ 0.95 = 3410.53 万元
> 应纳消费税 = 3410.53 × 5% = **170.53 万元**
> **例题2**：某外资企业进口一批化妆品，海关核定关税完税价格 600 万元，关税税率 60%，消费税税率 15%。
> **解**：组价 =（600 ＋ 600×60%）÷（1 − 15%）= 960 ÷ 0.85 = 1129.41 万元
> 应纳消费税 = 1129.41 × 15% = **169.41 万元**

**公式20 已纳消费税的扣除**
```
当期准予扣除的外购应税消费品已纳税款 = 当期准予扣除买价（或数量）× 适用税率（或税额）
当期准予扣除买价 = 期初库存 + 当期购进 - 期末库存
```
> **例题**：某卷烟生产企业月初库存外购应税烟丝金额 50 万元，当月外购应税烟丝 500 万元（不含增值税），月末库存 30 万元，其余被当月生产卷烟领用。烟丝消费税税率 30%。
> **解**：当期准予扣除的买价 = 50 ＋ 500 − 30 = 520 万元
> 当月准予扣除的已纳消费税 = 520 × 30% = **156 万元**

### （三）关税

**公式21 进口货物完税价格**
```
完税价格 = 货价 + 起卸前的运输及相关费用、保险费
保险费（无法确定或未实际发生）=（货价 + 运费）× 3‰
境外修理：完税价格 = 境外修理费 + 料件费
境外加工：完税价格 = 境外加工费 + 料件费 + 复运进境运保费
减免税补税：完税价格 = 原进口时价格 ×[1 - 已使用时间（月）÷（监管年限×12）]
```
> **例题**：甲企业进口一批货物，成交价格 80 万元，运抵我国关境内输入地点起卸前的运费和保险费 5 万元，关税税率 20%。
> **解**：完税价格 = 80 ＋ 5 = 85 万元
> 应纳关税 = 85 × 20% = **17 万元**
> **例题2**：某医疗器械厂 2019 年 8 月进口一批医疗器械，成交价格 202 万元，支付购货佣金 3 万元，运抵我国海关前发生运费 8 万元，保险费无法确定。关税税率 30%。
> **解**：购货佣金 3 万元不计入。
> 保险费 =（202 ＋ 8）× 3‰ = 0.63 万元
> 完税价格 = 202 ＋ 8 ＋ 0.63 = 210.63 万元
> 应纳关税 = 210.63 × 30% = **63.19 万元**

**公式22 从价税**
```
应纳关税税额 = 完税价格 × 适用税率
FOB 折算：完税价格 =（FOB 价格 + 运费）×（1 + 保险费率）
```
> **例题**：某公司进口一批货物共 1000 吨，成交价格 FOB 伦敦 10 万英镑/吨，单位运费 0.1 万英镑，保险费率 0.3%，外汇中间价 1 英镑 = 11.500 元人民币，关税税率 15%。
> **解**：每吨完税价格 =（10 ＋ 0.1）×（1＋0.3%）= 10.1303 万英镑
> 折合人民币 = 10.1303 × 11.5 = 116.49845 万元/吨
> 应纳关税 = 1000 × 116.49845 × 15% = **17474.77 万元**

**公式23 境外加工货物的关税**
> **例题**：某企业 2023 年 5 月将一批货物运往境外加工，货物价值 100 万元，报关出境前发生运费和保险费 1 万元，境外加工费 5 万元，加工料件费 1.2 万元，复运进境发生的运费和保险费 1.5 万元。关税税率 10%。
> **解**：完税价格 = 5 ＋ 1.2 ＋ 1.5 = 7.7 万元
> 应纳关税 = 7.7 × 10% = **0.77 万元**

**公式24 减免税货物补税**
> **例题**：某科技公司 2021 年 5 月 7 日经批准免税进口一套特定免税设备，2023 年 10 月 27 日经海关批准出售。设备进口时审定的完税价格 320 万元，关税税率 10%，监管年限 5 年。
> **解**：已使用时间按月计算，不足 1 个月超过 15 日的按 1 个月，不超过 15 日不计：24 ＋ 6 = 30 个月
> 应补缴关税 = 320 ×（1 − 30÷60）× 10% = 320 × 0.5 × 10% = **16 万元**

**公式25 从量税、复合税、滑准税**
```
从量税：应纳关税税额 = 应税进（出）口货物数量 × 单位货物税额
复合税：应纳关税税额 = 数量 × 单位货物税额 + 数量 × 单位完税价格 × 适用税率
滑准税：应纳关税税额 = 数量 × 单位完税价格 × 滑准税税率
```

**公式26 关税滞纳金**
```
关税滞纳金金额 = 滞纳关税税额 × 0.5‰（万分之五）× 滞纳天数
```

## 五、高频考点速记卡

1. **Q：小规模纳税人与一般纳税人的划分标准？**
   A：年应税销售额 **500 万元**。500 万元及以下为小规模纳税人（简易计税）；500 万元以上为一般纳税人（一般计税/简易计税）。登记为一般纳税人后原则上不得转回。

2. **Q：年应税销售额包括哪些？偶然销售不动产、无形资产的销售额计入吗？**
   A：包括纳税申报销售额、稽查查补销售额、纳税评估调整销售额；**偶然发生的销售无形资产、转让不动产的销售额不计入**。

3. **Q：增值税税率三档各适用于什么？**
   A：**13%**——一般货物、加工修理修配劳务、有形动产租赁；**9%**——农产品等民生货物＋交邮基电建不动产等服务；**6%**——其余服务和无形资产。另有零税率。

4. **Q：9% 税率的货物怎么记？**
   A：**"农业、水气、文娱"**——农产品、食用植物油、食用盐、水气冷暖、图书报纸杂志、音像制品、饲料化肥农药农机农膜、二甲醚、居民用煤炭制品。

5. **Q：9% 税率的服务怎么记？**
   A：**"交邮基电建不动产"**——交通运输、邮政、基础电信、建筑、不动产租赁、销售不动产、转让土地使用权。

6. **Q：征收率有哪几档？各举一例。**
   A：**3%**（小规模纳税人、公共交通运输）；**5%**（不动产简易租赁、劳务派遣差额）；**3% 减按 2%**（自己使用过的旧固定资产）；**5% 减按 1.5%**（个人出租住房）；**3% 减按 0.5%**（二手车经销）；**3% 减按 1%**（小规模纳税人的应税销售收入）。

7. **Q：视同应税交易有哪三种情形？**
   A：①单位和个体工商户将自产或委托加工的货物用于集体福利或个人消费；②单位和个体工商户无偿转让货物；③单位和个人无偿转让无形资产、不动产或金融商品。

8. **Q：哪些情形不征收增值税？**
   A：员工为受雇单位提供工资薪金服务；收取行政事业性收费、政府性基金；被征收征用取得补偿；取得存款利息收入。

9. **Q：销项税额和进项税额公式？**
   A：销项税额 = 不含税销售额 × 税率；应纳增值税 = 当期销项税额 − 当期进项税额。

10. **Q：含税价怎么换算？**
    A：一般计税 ÷（1＋税率）；简易计税 ÷（1＋征收率）。价外费用、逾期押金、零售价、普票金额均视为含税。

11. **Q：购进农产品的扣除率？**
    A：一般 **9%**；购进用于生产或委托加工 **13% 税率货物**的农产品按 **10%**。

12. **Q：国内旅客运输服务进项怎么算？**
    A：航空 =（票价＋燃油附加费）÷1.09×9%；铁路 = 票面金额÷1.09×9%；公路水路 = 票面金额÷1.03×3%。仅限签合同员工和劳务派遣员工，纸质票、定额票、国际票不得抵扣。

13. **Q：哪几类进项一律不得抵扣？**
    A：**"贷餐常乐"**——购进的贷款服务、餐饮服务、居民日常服务、娱乐服务。

14. **Q：非正常损失如何界定？**
    A：因**管理不善**造成被盗、丢失、霉烂变质，以及被执法部门依法没收、销毁、拆除的货物或不动产。自然灾害不属于。

15. **Q：无法划分的进项如何计算不得抵扣部分？**
    A：不得抵扣进项 = 无法划分全部进项 ×（简易计税销售额＋免税销售额）÷ 全部销售额。

16. **Q：包装物押金的增值税/消费税处理有何不同？**
    A：除啤酒黄酒外的其他酒类，两税收取时都并入；一般货物逾期都并入；**啤酒、黄酒、成品油：增值税逾期并入，消费税始终不并入**。

17. **Q：以旧换新、商业折扣、还本销售、以物易物的销售额？**
    A：以旧换新——一般货物按新货售价，金银首饰按实际差价；商业折扣——须同一张发票金额栏注明才可扣；还本销售——不得扣减还本支出；以物易物——双方均作购销处理。

18. **Q：消费税的 15 个税目？**
    A：烟、酒、高档化妆品、贵重首饰及珠宝玉石、鞭炮焰火、成品油、摩托车、小汽车、高尔夫球及球具、高档手表、游艇、木制一次性筷子、实木地板、电池、涂料。

19. **Q：消费税的计税方法有哪三种？各自典型税目？**
    A：从价定率（大部分税目）；从量定额（啤酒、黄酒、成品油）；复合计税（卷烟、白酒）。

20. **Q：自产应税消费品用于换取生产资料、投资入股、抵偿债务，增值税和消费税分别按什么价？**
    A：**消费税按同类最高售价，增值税按平均价**。

21. **Q：委托加工消费税的纳税人和代收代缴规则？**
    A：纳税人是委托方；受托方为单位的由受托方代收代缴，受托方为个人的由委托方收回后缴纳。委托加工收回后直接销售不再缴税。

22. **Q：消费税三个环节的组价公式？**
    A：自产自用 =（成本＋利润）÷（1−比例税率）；委托加工 =（材料成本＋加工费）÷（1−比例税率）；进口 =（完税价格＋关税）÷（1−比例税率）。复合计税分子加定额税。

23. **Q：哪些已纳消费税准予扣除？**
    A：外购/委托加工收回的已税烟丝、高档化妆品、珠宝玉石、鞭炮焰火、杆头杆身握把、木制一次性筷子、实木地板、汽柴油等连续生产应税消费品；按生产领用数量扣，同税目同环节，葡萄酒以外的酒及摩托车、小汽车、高档手表、游艇不得扣。

24. **Q：进口货物关税完税价格由什么构成？**
    A：货价＋起卸前的运输及相关费用、保险费。不含起卸后运保费、进口关税、买方负担的购货佣金。保险费无法确定时 =（货价＋运费）× 3‰。

25. **Q：CIF、FOB、CFR 分别是什么？**
    A：CIF = 成本加运费保险费 = 到岸价格（可直接计税）；FOB = 船上交货 = 离岸价格；CFR = 成本加运费 = 离岸加运费价格。FOB、CFR 须折成 CIF：完税价格 =（FOB＋运费）×（1＋保险费率）。

26. **Q：关税的滞纳金、补征、追征？**
    A：滞纳金按日 **0.5‰（万分之五）**；少征漏征 **1 年内补征**；因纳税人违反规定 **3 年内追征**并加收万分之五滞纳金。缴款期限为填发缴款书之日起 **15 日**，延期最长 **6 个月**。

| 37 | 以为金银首饰在生产环节缴消费税 | 金银铂钻**只在零售环节**缴 |
| 38 | 以为卷烟只在生产环节缴 | 卷烟、电子烟在**批发环节加征**一道 |

| 48 | 把补征/追征年限记反 | **1 年补征、3 年追征**（"一补三追"） |
| 49 | 以为海关发现多征不能退 | 海关多征的税款发现后**立即退还**；纳税人申请退还有期限（1 年内） |
