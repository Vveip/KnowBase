## 第一节 甄选及其有效性

### 知识点 1　甄选的概念及其意义 ★

**1. 甄选的基本概念及其内涵**

甄选是指通过运用一定的工具和手段对已经招募到的求职者进行观察和鉴别，从而最终挑选出最符合组织需要的、最为恰当的职位空缺填补者的过程。

**甄选的目的在于谋求职位需求与求职者所具有的某种特性实现最优匹配**。在构建有效的甄选体系时，组织的目的可能并非总是要挑出那些在某种特定方面最好的人。

**2. 甄选过程注意不要犯的错误**
① 不要把注意力过多地放在对求职者进行相互比较上；
② 应该重点关注求职者和空缺职位需要达到的客观标准之间的比较。

**3. 甄选的价值与意义**
① 符合企业需要的优秀员工是确保组织战略目标达成的最根本保障；
② 甄选决策失误的代价可能极高（直接成本和机会成本）；
③ 甄选决策失误可能会对员工本人造成伤害。

::: warning 高频陷阱
- "甄选最主要目的是为企业找到水平最高的人才并录用"→ **错误**，是找出最有可能达到或超越组织绩效标准要求的人，谋求**最优匹配**。
:::

### 知识点 2　甄选的可靠性与有效性 ★★★

任何一种甄选方法都应当达到一定的信度和效度。
- **信度是效度的必要条件（但不是充分条件）**；
- 一项甄选测试的信度如果不好，那么其效度一定较差；
- 相反，如果一项测试的效度较好，则其信度一定也比较高。

**1. 信度**

信度是指一种测试手段**不受随机误差干扰**的程度，反映一个人反复接受同一种测试或等值形式的测试时所得到的分数的一致性程度，又称为测试的内部一致性程度或稳定性程度。

- 信度的高低用**信度系数**表述，介于 0～1 之间。0 表示信度最低，1 表示信度最高。
- **一般情况下，信度系数不低于 0.70 的测试工具被视为信度较好。**

| 类型 | 内容 |
|---|---|
| **重测信度**（再测信度） | 用同一种测试工具在不同的时间对同一群人进行多次测试所得到结果的一致性程度 |
| **复本信度** | 对同一组被测试者进行某种测试时，使用两种功能等值但表面内容并不相同的测试形式，考查两种等值测试中取得分数之间的相关程度。常作为备用测验，如高考中的 A 卷和 B 卷 |
| **内部一致性信度** | 反映同一测试内容的各个题目之间的得分一致性程度。考察方式：**分半信度**（将一个测试中的题目一分为二，考察两个半份测试结果之间的相关系数，最常见的分半方法是根据奇偶顺序划分）和**同质性信度**（测试内部所有题目考察同一内容的程度） |
| **评价者信度** | 不同评价者在使用同一种测试工具时所给出的分数之间的一致性程度 |

**达到较高信度需注意的问题**：① 测试过程要标准化；② 选取的样本要具有广泛的代表性，样本应尽量具有**异质性**；③ 保持良好的测试环境（心理环境和物理环境），使被试者保持轻松自然的心态；④ 注意测试的难度和长度，避免出现"**地板效应**"或"**天花板效应**"；⑤ 测试条目越多信度往往越高，但太多条目容易引起疲劳和厌倦。

**2. 效度**

效度即一种测试的有效性，反映一种测试工具对于它所要测量的内容或特质进行准确测量的程度。主要包括：**内容效度、效标效度、构想效度**。

| 类型 | 内容 |
|---|---|
| **内容效度** | 一项测试的内容与测试所要达到的目标之间的相关程度，即一项测试的内容能够代表它所要测量的主题或特质的程度。两个条件：① 确定好想要测试的内容范围，并且使测试中的全部项目均在此范围之内；② 测试中的项目应当是已经界定好的内容范围中具有代表性的样本。**检验主要采用专家判断法**，不太适合对较为抽象的特质进行评价 |
| **效标效度**（效标关联效度） | 一种测试或甄选技术对被测试者的一种或多种工作行为或工作绩效进行预测的准确程度。两种：**预测效度**（考查员工被雇用之前的测试分数与其被雇用之后的实际工作绩效之间是否存在实证性联系；组织必须等待很长时间才能得到数据）和**同时效度**（直接选取已经在某种岗位上从事工作的任职者，让他们完成某种测试，得到测试分数，再与绩效数据考查相关关系） |
| **构想效度**（结构效度） | 一项测试对于某种不可观察的、比较抽象的构想或特质进行测量的程度。影响因素：① 理论上的构想代表性不足；② 构想代表性过宽，以至于包括了无关的事物。这是一个存在争议的概念 |

**内容效度的局限性**：① 如果组织准备在甄选和雇用求职者之后，再通过正式培训计划来教会他们掌握工作必需的技能，内容效度就不太适合；② 在内容效度中主观判断的作用很大，必须设法将判断过程中的推测成分减至最少，最好将评价者的评分建立在某种相对具体和可观察的行为的基础之上。

::: warning 高频陷阱
- **信度是效度的必要不充分条件**；效度好则信度一定较高。
- 信度系数 **不低于 0.70**。
- A 卷/B 卷 → **复本信度**；不同题目测同一内容 → **内部一致性信度**；不同评分者 → **评价者信度**；不同时间同一群人 → **重测信度**。
- 测试题目设计不佳（考逻辑却变成考记忆）→ **内容效度**低。
- 录用时分数高但实际绩效差 → **预测效度**低。
- "测试越难越好"→ **错误**（地板效应/天花板效应）。
:::

## 第二节 甄选的主要方法

### 知识点 1　心理测试 ★★★

心理测试是一种通过一系列的工具或手段将人的某种心理特征加以量化，从而衡量个体心理因素水平和个体心理差异的科学测量方法。心理测试可以划分为：**能力测试、人格测试、职业兴趣测试**。

**1. 能力测试**（包括认知能力测试、运动与身体能力测试）

| 类型 | 内容 |
|---|---|
| **一般认知能力测试** | 也称一般心理能力测试、智力测试或智商测试，是对一个人的多种认知能力所做的较为全面的测试，涉及的各种认知能力是从事任何一种工作的人都必须具备的基本心理能力。**通常所说的智商测试属于此类** |
| **特殊认知能力测试** | 也称特定心理能力测试，是针对一些特定认知能力（如归纳和演绎能力、语言理解力、记忆力、数字能力等）设计的更为具体和深入的测试，目的是测量一个人在从事某种特定领域（音乐、美术、飞行等）具有的特殊才能或熟练水平。又称**能力倾向测试/职业能力倾向测试**，可分为单项特殊认知能力测试和总体性特殊认知能力测试 |
| **心理运动能力测试** | 对一个人的精神运动能力或受个体意识支配的精细动作能力进行的测试（选择反应时间、肢体运动速度、四肢协调、手指灵活、手臂稳定、速度控制等），大多与手的灵巧性有关。常用于体力要求比较高的职位，如收音机装配工、电视组装工或手表装配工 |
| **身体能力测试** | 对一个人的动态强度、爆发力、广度灵活性、动态灵活性、身体协调性与平衡性等进行的测试。不仅预测求职者未来可能达到的工作绩效水平，而且有利于预测出哪些人将来更有可能发生工伤或导致伤残等情况 |

**2. 人格测试**（三种测量方法）

| 方法 | 定义 |
|---|---|
| **自陈量表法** | 编制好一套人格测试问卷之后，由被测试者本人根据自己的实际情况或感受来回答问卷中的全部问题，以此为衡量一个人的人格 |
| **评价量表法** | 首先提供一组描述人的个性或特质的词或句子，然后让其他人通过对被测试者的观察，对被测试者的人格或特质作出评价 |
| **投射法** | 首先向被测试者提供一些未经组织的刺激情境，然后让被测试者在不受限制的情境下自由表现出自己的反应。使用并不普遍 |

**MBTI 人格测试**（4 个两极性维度）：

| 维度 | 内容 |
|---|---|
| **外倾—内倾** | 一个人的注意力集中方向（外部世界还是内部世界） |
| **感觉—直觉** | 获取信息的方式（通过感觉和经验，还是通过想象和抽象性思维） |
| **思考—情感** | 处理信息和做出决策的方式（主要依赖逻辑关系，还是事物对自己和他人的价值和重要性） |
| **判断—知觉** | 通常表现出来的对待外界的方式（判断性的、有计划的、有目的的，还是灵活的、好奇的、容易冲动的、适应性强的） |

**"大五"人格测试**：一个人在**外向性、愉悦性、尽责性、神经质和开放性**五个人格特征方面的表现。

**3. 职业兴趣测试**

霍兰德职业兴趣测试（职业性向测试）提出了六种基本的职业兴趣类型：**现实型、研究型、艺术型、社会型、企业型和常规型**。

| 类型 | 人格倾向 | 适宜职业 |
|---|---|---|
| **现实型** | 偏好与具体的物体（工具、机械、电子设备等）打交道，喜欢有规则的具体劳动以及需要基本操作技能的工作；不喜欢跟人打交道，不适应社会性质的职业 | 技能性和技术性的职业 |
| **研究型** | 聪明、理性、细致、喜欢批评，喜欢抽象的、分析性的、独立性的工作，愿意进行系统的创造性探究；缺乏组织和领导才能，不喜欢从事说服性或重复性的工作 | 科学研究类、工程设计类工作 |
| **艺术型** | 具有想象力、冲动、直觉、理想化、有创意，偏好模糊、自由和非系统化的活动；不重视实际，不善于从事事务性工作，厌恶明确、有秩序和系统化的活动 | 文学艺术方面的工作 |
| **社会型** | 合作、友善、善于言谈和社交，观察能力强、喜欢社会交往，关心社会问题，重视社会公平和正义，有教导、指点和培训别人的能力和愿望；不喜欢与材料、工具、机械等实物打交道 | 教育、咨询等方面的工作 |
| **企业型** | 冒险、乐观、自信、精力充沛、有进取心，喜欢担任有领导责任的工作，看重政治和经济方面的成就，喜欢追求财富、权力和地位，喜欢与人争辩，喜欢说服别人接受自己的观点；不喜欢从事研究性的活动 | 企业性质的工作，担任企业领导或行政管理者 |
| **常规型** | 顺从、谨慎、保守、实际、稳重，喜欢条理性强的工作，偏好对文字和数据等资料进行明确、有序的整理；厌恶模糊、不正规、非程序化或探究性的活动，不喜欢自己对事情做判断和决策 | 办公室事务性工作、图书管理、会计、统计类工作 |

::: warning 高频陷阱
- 心理测试三大类：**能力、人格、职业兴趣**（不含成就测试、评价中心技术）。
- 智商测试 = **一般认知能力测试**。
- 自陈量表法 = 自己填答问卷；投射法 = 提供未经组织的刺激情境自由反应。
- **与企业型相邻的是常规型和社会型**（霍兰德六边形）。
- "常规型偏好灵活处理问题"→ **错误**，常规型喜欢条理性强的工作。
:::

### 知识点 2　成就测试 ★★★

成就测试又称为**熟练性测试或学绩测验**，通常是对一个人在接受了一定的教育或训练之后获得的成果进行测试，测试目的是考查一个人在多大程度上掌握了对于从事某种具体的工作而言非常重要的那些知识或技能。

成就测试包括：**知识测试**和**工作样本测试**两种类型。

**1. 知识测试**

知识测试就是我们通常所说的考试，它所要考查的是一个人在特定领域掌握的知识的广度和深度。可以划分为综合知识测试、专业知识测试、外语测试等各种不同类型。通常以笔试方式完成，但并非所有笔试都属于知识测试。

**2. 工作样本测试**

工作样本测试是在一个对实际工作的一部分或全部进行模拟的环境中，让求职者实地完成某些具体的工作任务的一种测试方法。测试的效度要远远高于认知能力测试和人格测试，对于被测试者未来的工作绩效有很高的预测效度。

| 优点 | 缺点 |
|---|---|
| 测试所要求的行为与实际工作所要求的行为之间具有高度的一致性，它和工作绩效之间存在直接而且明显的联系，所以这种测试工具的**效标关联效度和内容效度都很高** | ① 普遍适用性很低，只能针对不同的职位来开发不同的测试；② 开发成本相对较高 |

::: warning 高频陷阱
- 注册会计师考试、司法考试 → **知识测试**；对客运人员的实际驾驶测试 → **工作样本测试**。
- "工作样本测试具有通用性"→ **错误**，只能针对不同职位专门开发。
:::

### 知识点 3　评价中心技术 ★★★

评价中心技术也称为**管理评价中心技术**，它是一个由多位评价者对于求职者在一系列练习中的表现进行评价的过程。它通过**情景模拟**的方法来对求职者进行评价，它的一个重要基石是**工作样本测试**。

| 对比 | 内容 |
|---|---|
| **工作样本测试** | 用**实际的**工作任务进行测试 |
| **评价中心技术** | 用**模拟的**工作任务进行测试 |

评价中心技术主要考查管理类工作所需要的人格特征、管理技能以及人际关系技能，也越来越多地用于考查个人是否具备在一个团队中工作所需要的技能。它是若干种测试手段综合运用于对管理类职位候选人进行甄选的过程，其中可能会用到面试、心理测试、主题演讲等，所以它的效标效度一般较高。

主要介绍三种测试方法：**公文筐测试、无领导小组讨论、角色扮演**。

**1. 公文筐测试**（公文处理测验）——一种情景模拟测试。在测试中，求职者要面对一大堆报告、备忘录、来电记录、信函、声明、请示以及其他资料，在规定时间和限定的时间（通常 1-3 小时）内对每一份公文进行处理。

| 优点 | 缺点 |
|---|---|
| ① 非常适合对应聘管理职位的被测试者进行评价；② 具有较高的内容效度和效标关联效度；③ 操作比较简单，对场地没有过多的要求；④ 表面效度较高，容易得到被测试者的理解和接受 | ① 编制成本较高，评分比较困难；② 不同的评价者由于自身的背景、工作经验、管理理念等不同，对不同的公文处理方式的看法也会有所不同；③ **无法考查被测试者的人际交往能力和团队工作能力** |

**2. 无领导小组讨论**

采用情景模拟的方式让一组求职者进行集体讨论，然后观察他们在讨论过程中的言行。**所谓的无领导小组，就是指在讨论的过程中，组织者不会为该小组指定一名领导人，而是让大家自由发言**。

- 通常为 **5-7 人**求职者组成一个小组，就某一个问题进行 **1 小时左右**的讨论。
- 特点：① 大家的地位是平等的，没有人事先就被指定扮演领导者；② 讨论之前会明确讨论的问题、所要达到的目标及总体的时间限制；③ 评价者不参与讨论过程，甚至不在现场进行观察。

**五种试题形式**：① 开放式问题（没有固定答案，答案范围可以很广）；② 两难性问题（在两种互有利弊的答案中选择一种）；③ 多项选择问题（在多种备选答案中选择其中有效的几种，或对备选答案按照重要性进行排序）；④ 操作性问题（提供一些材料、工具或道具，利用这些材料设计出一个或一些指定的物体）；⑤ 资源争夺性问题（指定角色的无领导小组讨论，让处于同等地位的被测试者就有限的资源进行分配）。

| 优点 | 存在的问题 |
|---|---|
| 可以考查被测试者的组织协调能力、口头表达能力、说服能力、领导能力、人际交往能力等 | ① 对测试题目的要求较高；② 对评价者的评分技术要求较高；③ 在有些情况下，被测试者仍然有可能会有意识地表现自己或掩饰自己，以达到通过测试的目的 |

**3. 角色扮演**

要求被测试者扮演一位管理者或者某岗位员工，然后让他们根据自己对角色的认识或担任相关角色的经验进行相应的语言表达和行为展示。被测试者扮演管理者，则下属的角色通常由评价中心设计小组中的成员来担任。

**评价中心技术中的各种练习想要衡量的技能**（记忆口诀：人人问领导行不行）：

| 技能 | 公文筐测试 | 无领导小组讨论 | 角色扮演 |
|:-:|:-:|:-:|:-:|
| 领导能力 | √ | √ | √ |
| 问题解决能力 | √ | √ | √ |
| 人际交往能力 | — | √ | √ |
| 行政管理能力 | √ | √ | — |
| 人格（压力承受能力） | √ | √ | √ |

::: warning 高频陷阱
- 评价中心技术用**模拟工作任务**，不是实际工作任务。
- 公文筐测试**不能**考查人际交往能力和团队工作能力。
- 角色扮演**不能**考查行政管理能力。
- 无领导小组讨论**不指定领导人**，评价者不参与讨论过程。
:::

### 知识点 4　面试 ★★★

**1. 面试的概念**

面试是迄今为止在实践中运用最广泛的一种人员甄选方法。

| 优点 | 缺点 |
|---|---|
| 简便快捷、容易操作、不需要复杂的专用测试工具和方法，面对面了解和观察求职者，产生比较真切的整体性感受 | 面试过程需要精心设计，否则面试的效度较低；受主观判断偏差影响；从组织的角度，派人专门面试存在机会成本 |

**2. 根据面试结构划分的类型**

| 类型 | 内容 |
|---|---|
| **非结构化面试** | 在面试过程中，不存在结构化面试指南或必须遵循的既定格式，没有面试提纲和明确的提问顺序 |
| **结构化面试** | 又称标准化面试，是依据预先确定的面试内容、程序、评分结构等进行的面试形式。面试考官必须根据事先拟定的面试提纲逐项提问，不能随意变动 |
| **半结构化面试** | 介于非结构化和结构化之间，结合两者优点，有效避免任何一种单一方法的不足。在一部分预先设计好的问题基础上，面试考官可以向被面试者提出另外一些比较随机的问题 |

> **结构化面试的信度和效度比非结构化面试高得多**。

**3. 根据面试组织形式划分的面试类型**

| 类型 | 定义 |
|---|---|
| **单独面试**（一对一面试） | 面试考官和被面试者两个人单独见面，面试考官进行口头引导或询问，被面试者作出回答 |
| **系列面试**（顺序面试） | 组织根据某种特定的先后顺序，安排组织中的若干人员对同一名被面试者进行多轮面试，最后再将所有面试考官独立得出的面试结论加以汇总，从而最终得出面试结论 |
| **小组面试** | 由一组面试考官在同一时间和同一场所，共同对一名被面试者进行提问、观察并做出评价的面试形式（类似若干新闻记者在新闻发布会上向发言人分别提问） |
| **集体面试** | 多位被面试者在同一时间和同一场合，共同接受面试考官面对面询问的面试形式。面试考官既可以是多人，也可以是一个人 |

> **多位考官对一位应聘者 → 小组面试；多位被面试者同时接受询问 → 集体面试。**

**4. 特殊面试形式——压力面试**

压力面试指面试考官在面试过程中**故意制造出一种紧张气氛**，对被面试者施加一定的心理压力，然后观察被面试者在压力状况下的情绪变化及反应的面试形式。主要目的是考查被面试者在一定的压力环境下是否能够妥善地调整自己的情绪，并作出正确的回答或行为反应。

| 优点 | 缺点 |
|---|---|
| ① 帮助面试考官了解被面试者在未来的某种具有特定压力的工作环境中是否能够达到较好的绩效；② 帮助组织辨别哪些被面试者属于过于敏感或者压力承受能力较弱的人 | ① 如果对压力面试掌控不好，面试可能会因为过于具有侵犯性或者有违一般道德规范而受到质疑甚至起诉；② 在不需要采用压力面试的手段时，就没有必要非采用压力面试的做法，如果确实需要也一定要让经过相关方面的特殊培训的面试考官来组织面试 |

**5. 改善面试效果的主要方法**

**（1）采用情境化结构面试**

情境化面试属于结构化面试的一种，有时又称为"**行为事件面试技术**"。通常需要遵循所谓的"**STAR**"原则：

| 字母 | 含义 |
|---|---|
| **S** | Situation：向被面试者描述他们可能会面对的典型环境 |
| **T** | Task：需要完成的主要工作任务 |
| **A** | Action：询问他们实际上采取了何种行动 |
| **R** | Result：让他们说明这种行动产生了怎样的结果 |

情境化结构面试的题目可以划分为两类：

| 类型 | 内容 | 效度 |
|---|---|---|
| **过去导向型** | 要求被面试者回答他们在过去的工作中遇到的某种情形，以及他们当时是如何处理的 | **效度更高** |
| **未来导向型** | 要求被面试者回答将来一旦遇到某种假设的情形，他们将会采取怎样的处理措施 | 效度较好 |

**（2）面试前做好充分准备**：① 安排好面试所需的时间、场地和资料；② 认真阅读简历材料和职位说明书，准备好相关的问题。

**（3）系统培训面试考官**

面试考官在面试过程中可能会犯的错误：① 说话过多，影响收集与工作相关的信息数量；② 对不同的被面试者提问的问题不一致；③ 提问与履行工作职责无关或者相关性不大的问题；④ 对自己评价被面试者的能力过于自信，导致匆忙下结论；⑤ 受到被面试者一些非语言行为的影响或干扰；⑥ 因前面一位求职者的表现而影响到对后一位被面试者的评价。

面试考官的培训重点关注四个方面：① 明确面试考官的职责及其在面试过程中所扮演的角色；② 传授引导和控制面试过程的技巧；③ 让面试考官学会如何与各种不同类型的被面试者打交道；④ 使面试考官理解在进行面试评价时可能会出现的各种偏差，正确理解评分标准，掌握评分方法和评分尺度。

::: warning 高频陷阱
- STAR 中 **A = Action 行动**。
- 人力资源部门是面试环节中的重要参与部门，不能让用人部门自行选择面试官而人力资源部门不参与。
:::

### 知识点 5　传记资料分析技术 ★★

传记资料分析技术（或传记数据分析、**履历分析**），通过对一个人的基本背景以及学习、工作、生活经历甚至个人习惯等与工作相关的履历信息进行收集和分析，判断一个人对未来工作岗位的适应性以及**预测其未来工作绩效、任职年限和流动性**等特征的一种人才测评方法。

**最基本假设：一个人的行为具有一致性**，即一个人过去的行为是对其未来行为进行预测的最佳依据。

**对履历的三个要求**：① 履历信息必须**真实**；② 履历信息必须**全面**；③ 履历信息必须**相关**。

最新发展是**目标履历分析法**：与传统的履历分析技术试图去预测一个人的总体工作绩效不同，这种履历分析技术的目的是预测不同的人在某些与工作相关的具体行为或兴趣方面存在的差异。

::: warning 高频陷阱
- "履历分析不适用于预测求职者在未来的工作绩效"→ **错误**，它正是用来预测未来工作绩效、任职年限和流动性的。
- 不能为提高效率忽略看上去不重要的履历细节，履历信息越全面越有助于判断。
:::

## 易混点对比

**1. 四种信度**

| 类型 | 判别关键词 |
|---|---|
| 重测信度 | **同一工具、不同时间、同一群人** |
| 复本信度 | **两种功能等值、表面内容不同**（A 卷/B 卷） |
| 内部一致性信度 | **同一测试内部不同题目**（分半信度、同质性信度） |
| 评价者信度 | **不同评价者**使用同一工具 |

**2. 三种效度**

| 类型 | 判别关键词 | 常考陷阱 |
|---|---|---|
| 内容效度 | 测试内容能否代表要测量的主题；专家判断法 | 题目设计不佳（考逻辑却考记忆）→ 内容效度低 |
| 效标效度（预测效度/同时效度） | 能否预测未来工作绩效 | 录用时分数高但实际绩效差 → 预测效度低 |
| 构想效度 | 对不可观察的抽象构想或特质的测量 | 存在争议、无单一数量指标 |

**3. 心理测试三大类与细分**

| 大类 | 细分 |
|---|---|
| 能力测试 | 一般认知能力测试（智商）、特殊认知能力测试（能力倾向）、心理运动能力测试、身体能力测试 |
| 人格测试 | 自陈量表法、评价量表法、投射法；MBTI、大五人格 |
| 职业兴趣测试 | 霍兰德六种类型 |

**4. 成就测试的两种类型**

| 类型 | 内容 | 例子 |
|---|---|---|
| 知识测试 | 特定领域知识的广度和深度 | 注册会计师考试、司法考试、法律法规条文掌握 |
| 工作样本测试 | 模拟实际工作让求职者完成具体任务 | 对客运人员的实际驾驶测试 |

**5. 评价中心三种练习的对比**

| 对比项 | 公文筐测试 | 无领导小组讨论 | 角色扮演 |
|---|---|---|---|
| 形式 | 单独处理公文 | 集体自由讨论 | 扮演管理者/员工 |
| 适合对象 | 管理职位 | 群体互动 | 角色情境 |
| 优点 | 操作简单、场地要求低、内容效度与效标关联效度高 | 考查组织协调、口头表达、说服、领导、人际交往 | 考查领导、问题解决、人际交往、人格 |
| 不能考查 | 人际交往能力、团队工作能力 | — | 行政管理能力 |
| 关键缺点 | 编制成本高、评分困难 | 题目与评分技术要求高、可能掩饰 | — |

**6. 面试的类型**

| 划分标准 | 类型 |
|---|---|
| 按结构 | 非结构化、结构化、半结构化 |
| 按组织形式 | 单独面试、系列面试、小组面试、集体面试 |
| 特殊形式 | 压力面试 |

> **小组面试 = 多位考官对一位应聘者；集体面试 = 多位应聘者同时接受询问。**

**7. 信度与效度的关系**

| 关系 | 结论 |
|---|---|
| 信度 → 效度 | 信度是效度的**必要不充分**条件 |
| 信度不好 | 效度一定较差 |
| 效度较好 | 信度一定也比较高 |
