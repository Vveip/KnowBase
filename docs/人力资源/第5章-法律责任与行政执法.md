## 第一节 劳动法律责任

### 知识点 1　劳动法律责任形式 ★

| 责任形式 | 内容 |
|---|---|
| **行政责任** | 行为人因违反劳动法律规定、不履行法律规定，依法应当承担，并由有关行政机关或行为人所在单位以行政制裁方式予以追究的法律责任。**两种方式**：① **行政处罚**：警告、责令改正、责令停止、查封、吊销执照、行政拘留等；② **行政处分**：警告、记过、记大过、降级、撤职、留用察看、开除 |
| **民事责任** | 一方当事人违反了劳动法的规定或劳动合同的约定而承担的法律责任 |
| **刑事责任** | 对违法行为人的人身进行制裁，**是最严厉的一种法律责任**，具有强制性 |

::: warning 高频陷阱
**查封、吊销执照、责令改正属于行政责任，不是刑事或民事责任；开除属于行政处分（行政责任）**。
:::

### 知识点 2　用人单位违反劳动法律的责任 ★

| 违法情形 | 法律责任 |
|---|---|
| **侵害女职工及未成年工权益** | 由劳动行政部门责令改正，并按**受侵害的劳动者每人 1000 元以上 5000 元以下**的标准罚款。包括：安排女职工从事矿山井下劳动、国家规定的第四级体力劳动强度劳动或其他禁忌劳动；安排女职工在经期从事高处、低温、冷水作业或第三级体力劳动强度劳动；安排怀孕期间从事第三级体力劳动强度劳动或孕期禁忌劳动；安排怀孕 7 个月以上女职工夜班劳动或延长工时；女职工生育享受产假少于 98 天；安排哺乳未满 1 周岁婴儿期间从事第三级体力劳动强度劳动或哺乳期禁忌劳动及延长工时/夜班；安排未成年工从事矿山井下、有毒有害、第四级体力劳动强度劳动或其他禁忌劳动；未对未成年工定期进行健康检查 |
| **规章制度违法** | 劳动行政部门给予警告责令改正；逾期不改的给予通报批评；给劳动者造成伤害的应承担法律责任 |
| **未订立书面劳动合同** | 自用工之日起超过一个月不满一年未订立书面劳动合同的，应当向劳动者**每月支付 2 倍的工资** |
| **未依法订立无固定期限劳动合同** | 自应当订立无固定期限劳动合同之日起向劳动者**每月支付 2 倍工资** |
| **未依法提供劳动合同文本** | 由劳动行政部门责令改正；造成损害的应承担赔偿 |
| **违法约定试用期** | 由劳动行政部门责令改正；违法约定的试用期已经履行的，由用人单位以劳动者**试用期满月工资**为标准，按已经履行的超过法定试用期的期间向劳动者支付**赔偿金** |
| **违法解除或终止劳动合同** | 应依照《劳动合同法》规定的经济补偿标准的 **2 倍**向劳动者支付**赔偿金**；支付了赔偿金的，不再支付经济补偿；赔偿金的计算年限自用工之日起计算 |
| **未出具解除或终止劳动合同证明** | 由劳动行政部门责令改正；给劳动者造成损失的应承担赔偿责任 |
| **招用与其他用人单位存在劳动关系的劳动者** | 给其他单位造成损失的，应当承担**连带赔偿责任** |
| **违法延长劳动者工作时间** | 由劳动行政部门给予警告，责令限期改正，并可按**受侵害的劳动者每人 100 元以上 500 元以下**的标准计算，处以罚款 |
| **违反工资支付规定** | 由劳动保障行政部门责令限期支付劳动者工资报酬、低于当地最低工资标准的差额或解除劳动合同的经济补偿；逾期不支付的，责令用人单位按应付金额 **50% 以上 1 倍以下**的标准向劳动者**加付赔偿金** |
| **违反劳动安全规定** | 由有关部门责令改正，可以处以罚款；情节严重的，提请县级以上人民政府责令停产整顿；造成劳动者生命和财产损失的，对责任人员追究刑事责任 |
| **非法招用未满 16 周岁未成年人** | 劳动行政部门责令改正，处以罚款；情节严重的，由市场监督行政管理部门吊销营业执照 |
| **违反《工会法》** | 劳动保障行政部门责令改正：阻挠劳动者依法参加和组织工会，或者阻挠上级工会帮助、指导劳动者筹建工会的；劳动者因参加工会活动而被解除劳动合同的 |
| **违反劳动监察规定** | 由劳动保障行政部门责令改正，处 **2000 元以上 2 万元以下**的罚款 |
| **违反职业培训、职业介绍规定** | 由劳动保障行政部门责令改正，没收违法所得，并处 **1 万元以上 5 万元以下**的罚款；情节严重的吊销许可证 |
| **违法扣押证件** | 由劳动行政部门责令限期退还本人，并依照有关法律规定给予处罚；以担保或其他名义向劳动者收取财物，或劳动者依法解除或终止劳动合同而用人单位扣押劳动者档案或其他物品的，由劳动行政部门责令限期退还，并以**每人 500 元以上 2000 元以下**的标准处以罚款；造成损害的应承担赔偿责任 |

### 知识点 3　劳动者违反劳动法律的责任 ★

① 因劳动者存在违法情形，致使劳动合同被依法确认无效，给用人单位造成损失的，劳动者应当承担**赔偿责任**；
② 劳动者违反《劳动合同法》的规定解除劳动合同，或者违反劳动合同中约定的**保密义务、竞业限制**，给用人单位造成损失的，应当承担赔偿责任；
③ 有下列情况之一，用人单位与劳动者解除约定服务期的劳动合同的，劳动者应按合同约定向用人单位支付**违约金**：
- 劳动者**严重违反**用人单位的规章制度的；
- 劳动者**严重失职，营私舞弊**，给用人单位造成**重大损害**的；
- 劳动者**同时与其他用人单位建立劳动关系**，对完成本单位的工作任务造成严重影响，或经用人单位提出，拒不改正的；
- 劳动者以**欺诈、胁迫**的手段或乘人之危，使用人单位在违背真实意思的情况下订立或变更劳动合同的；
- 劳动者**被依法追究刑事责任**的。

### 知识点 4　违反集体合同的法律责任

① 企业违反集体合同，企业主管人员须承担**行政责任**，甚至**刑事责任**；
② 工会不履行集体合同规定的义务，应对上级工会和工会会员负道义上和政治上的责任，由上级工会给予批评、教育或纪律处分；
③ 职工不履行集体合同规定的义务，其行为违反了集体合同中的规定时，也应承担相应的**违约责任**。

## 第二节 社会保险法律责任

### 知识点 1　用人单位违反《社会保险法》的法律责任 ★

| 情形 | 责任 |
|---|---|
| **不办理社会保险登记** | 社会保险行政部门责令限期改正；逾期不改正的，对用人单位处**应缴社会保险费数额 1 倍以上 3 倍以下**的罚款，对其**直接负责的主管人员和其他直接责任人员处 500 元以上 3000 元以下**的罚款 |
| **未按时足额缴纳社会保险费** | 由社会保险费征收机构责令限期缴纳或补足，并自欠缴之日起**按日加收 0.05% 的滞纳金**（即万分之五）；逾期仍不缴纳的，处**欠缴数额 1 倍以上 3 倍以下**的罚款 |
| **未依法代扣代缴** | 由社会保险费征收机构责令限期缴纳，并自欠缴之日起按日加收 **0.05% 的滞纳金，滞纳金由用人单位承担** |
| **拒不向职工出具终止或解除劳动关系证明**，导致职工无法享受社会保险待遇 | 依法承担**赔偿责任** |
| **未按月告知职工缴费明细** | 由社会保险行政部门责令改正；逾期不改按《劳动保障监察条例》处理 |
| **应参加工伤保险而未参加**，职工发生工伤 | 由用人单位按照《工伤保险条例》规定的待遇项目和标准**支付费用**；拒不协助社会保险行政部门对事故进行调查核实的，责令改正，处 **2000 元以上 2 万元以下**罚款 |
| **伪造、变更、故意毁灭账册材料或不设账册**，致使缴费基数无法确定 | 给予行政处罚、纪律处分、刑事处罚外，继续依照规定征缴；迟延缴纳的加收滞纳金，并对直接负责的主管人员和其他直接责任人员处 **5000 元以上 2 万元以下**的罚款 |

### 知识点 2　骗取社会保险基金支出或者骗取社会保险待遇的法律责任

① 以**欺诈、伪造证明材料或者其他手段**骗取社会保险基金支出或者骗取社会保险待遇的，应当**退回**，并处**骗取金额 2 倍以上 5 倍以下**的罚款；
② 属于社会保险服务机构的，**解除服务协议**；
③ 直接主管和其他直接责任人员有执业资格的，**依法吊销其职业资格**；
④ 用人单位、工伤职工或者其近亲属骗取工伤保险待遇，医疗机构、辅助器具配置机构骗取工伤保险基金支出的，由社会保险行政部门责令退还，处**骗取金额 2 倍以上 5 倍以下**的罚款；情节严重构成犯罪的，依法追究刑事责任。

## 易混点对比

**1. 行政责任的两类**

| 类别 | 具体形式 |
|---|---|
| 行政处罚 | 警告、责令改正、责令停止、查封、吊销执照、行政拘留 |
| 行政处分 | 警告、记过、记大过、降级、撤职、留用察看、开除 |

**2. 常见罚款标准速记**

| 违法行为 | 罚款标准 |
|---|---|
| 侵害女职工及未成年工权益 | 受侵害劳动者每人 1000–5000 元 |
| 违法延长工作时间 | 每人 100–500 元 |
| 拖欠工资加付赔偿金 | 应付金额 50%–1 倍 |
| 违反劳动监察规定 | 2000–2 万元 |
| 违反职业培训、职业介绍规定 | 1 万–5 万元 |
| 违法扣押证件/收取财物 | 每人 500–2000 元 |
| 不办理社保登记（单位） | 应缴社保费 1–3 倍 |
| 不办理社保登记（责任人员） | 500–3000 元 |
| 骗取社保基金/待遇 | 骗取金额 2–5 倍 |
| 伪造账册致缴费基数不明（责任人员） | 5000–2 万元 |

**3. 劳动保障监察程序与期限**

| 环节 | 内容 |
|---|---|
| 程序 | 立案 → 调查 → 处理 → 告知 |
| 调查期限 | 自立案之日起 **60 个工作日**内完成；情况复杂的经批准可延长 **30 个工作日** |
| 不再查处 | 违法行为 2 年内未被发现也未被举报、投诉的不再查处 |
| 2 年期限起算 | 一次性违法违规自**行为发生之日**；连续或继续状态自**行为终了之日** |

**4. 行政复议范围 vs 不属于复议范围**

| 可以申请行政复议 | 不属于行政复议范围 |
|---|---|
| 行政处罚（警告、罚款、没收违法所得、关闭、吊销许可证）决定不服 | 人社部门作出的**行政处分**或其他人事处理决定 |
| 行政处理决定不服 | 劳动者与用人单位之间发生的**人力资源争议** |
| 行政许可、行政审批不服 | **劳动能力鉴定委员会**的行为 |
| 行政确认不服 | **劳动人事争议仲裁委员会**的仲裁、调解等行为 |
| 认为不履行法定职责 | 已就同一事项向其他有权受理的行政机关申请复议 |
| 认为违法收费或违法要求履行义务 | 人民法院已依法受理的行政诉讼 |
| 工伤认定结论、单位缴费费率、工伤保险待遇核定等 | 法律法规规定的其他情形 |

关于劳动法律责任形式的说法，正确的是（ ）。

A. 吊销执照属于刑事责任
B. 责令改正属于民事责任
C. 开除属于民事责任

@answer D
@explanation 行政责任包括行政处罚和行政处分。行政处罚包括警告、责令改正、责令停止、查封、吊销执照、行政拘留等；行政处分包括警告、记过、记大过、降级、撤职、留用察看、开除。开封、吊销执照、责令改正、开除均属于行政责任。
