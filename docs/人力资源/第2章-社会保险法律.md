## 第一节 社会保险法律关系

### 知识点 1　社会保险法律关系的概念 ★

**1. 社会保险**：指国家通过立法设立社会保险基金，并在一定范围内对社会保险基金实行统筹调剂，对遭遇劳动风险的劳动者给予必要的物质帮助和补偿的一种**社会保障制度**。

**2. 社会保险法律关系**：指社会保险各主体之间就社会保险的权利义务所产生的法律关系。这里的\"各主体之间\"指的是：**国家和劳动者之间、社会保险经办机构与劳动者之间、社会保险经办机构之间、社会保险经办机构与用人单位之间、用人单位与劳动者之间**。

::: warning 高频陷阱
- **企业年金合同**争议按劳动争议/集体合同争议处理规定执行，**不属于**社会保险法律关系。
- **商业保险**（如商业保险公司的意外伤害险、住院津贴）**不属于**社会保险法律关系范畴。
:::

### 知识点 2　社会保险法律关系的主体与客体 ★★★

**（一）从社会保险责任划分的主体**

| 主体 | 内容 |
|---|---|
| **国家** | 对社会保险的运行和实施给予**法律和财政上的支持**，是社会保险法的**特殊主体** |
| **社会保险的管理和经办机构** | 我国**征缴社会保险费的法定机构是税务机关** |
| **用人单位** | 承担缴纳社会保险费的义务，是**社会保险基金的主要缴纳者** |
| **劳动者及其家庭** | 既是社会保险的受益人，同时劳动者本人还要承担相应的缴费义务 |

**（二）从保险业务划分的主体**

| 主体 | 内容 |
|---|---|
| **保险人** | 依法收取社会保险费，并按照规定支付保险待遇的主体。保险人称为**社会保险经办机构**。主要职责：① 依法收缴社会保险费，督促投保人和被保险人按时足额缴纳；② 管理基金；③ 社会保险待遇的给付；建立社会保险档案和个人账户；④ 向保险人和被保险人提供社会保险方面的咨询和查询服务 |
| **投保人** | 为被保险人的利益投保社会保险的主体，指**用人单位**。主要权利：① 向保险人查验本单位的社会保险缴费记录；② 要求保险人提供社会保险的政策咨询；③ 监督保险人的社会保险工作；④ 就与本单位有关的社会保险争议按照法律程序请求解决 |
| **被保险人** | 对社会保险标的具有直接保险利益的主体。被保险人为在参保单位中就业的劳动者；**自谋职业的劳动者在履行缴费义务后，也可以成为被保险人** |
| **受益人** | 基于被保险人的一定关系而享有一定保险利益的主体 |
| **管理人** | 依法负有管理职责的**社会保险行政部门** |
| **监督人** | 指依法负有监督职责的机构 |

**（三）社会保险法律关系的客体**：是社会保险法律关系主体的权利和义务所指向的对象，**可以是资金、物，也可以是服务行为**。例如：养老保险中缴纳的养老保险费和支付的养老保险待遇；失业保险中的失业保险金、就业服务项目；医疗保险中的医疗津贴、医疗服务等。

### 知识点 3　社会保险法律关系的产生、变更和消灭

| 类型 | 内容 |
|---|---|
| **产生** | 主体间依照社会保险法律规定建立起社会保险法律关系，从而产生一定的权利与义务 |
| **变更** | 主体间已建立的社会保险法律关系，依照法律的规定变更其内容，从而引起权利义务内容和范围的变动 |
| **消灭** | 主体间的社会保险法律关系依法解除或终止，即劳动权利与义务的消灭 |

### 知识点 4　社会保险法律事实

指社会保险法律规定的，**能引起社会保险法律关系产生、变更、消灭的客观情况**。

## 第二节 社会保险法律适用

### 知识点 1　社会保险法律适用的概念及特征

**1. 概念**：指社会保险行政部门和法律授权的组织根据法定职权和法定程序，规范社会保险关系，维护公民参加社会保险和享受社会保险待遇的合法权益，使公民共享改革发展成果，促进社会和谐稳定，用来解决具体问题的专门活动。

**2. 五个特征**：① **主体的特殊性**；② **专业性**；③ **国家强制性**；④ **程序性**；⑤ **明确性**（必须有表明法律适用结果的法律文书）。

### 知识点 2　社会保险法律适用的基本原则

① **以事实为根据，以法律为准绳**；
② **公民在法律面前一律平等**；
③ **实事求是，有错必纠**。

### 知识点 3　社会保险法律适用的基本要求

**合法、准确、及时**。

### 知识点 4　社会保险法律适用的基本规则 ★★

① **上位法的效力高于下位法**（**宪法具有最高的法律效力，法律的效力高于行政法规、地方性法规、规章**）；
② **同位法中特别规定与一般规定不一致时，适用特别规定**（特别法优于一般法）；
③ **同位法中新的规定与旧的规定不一致时，适用新的规定**（新法优于旧法）；
④ **原则上不溯及既往**。但为了更好地保护公民、法人和其他组织的权利和利益而作的特别规定除外。

::: warning 高频陷阱
- **社会保险法律不具有溯及力**（原则上不溯及既往）。
- 效力层级：**宪法 > 法律 > 行政法规 > 地方性法规 > 规章**。
- 省级人民政府制定的规章效力**高于**本行政区域较大市的人民政府制定的规章。
:::

## 易混点对比

**1. 社会保险法律关系六类主体（从保险业务划分）**

| 主体 | 对应主体 |
|---|---|
| 保险人 | 社会保险经办机构 |
| 投保人 | 用人单位 |
| 被保险人 | 参保单位中就业的劳动者 |
| 受益人 | 基于与被保险人的一定关系享有保险利益的人 |
| 管理人 | 社会保险行政部门 |
| 监督人 | 依法负有监督职责的机构 |

**2. 投保人的权利 vs 保险人的职责**

| 投保人（用人单位）的权利 | 保险人的职责 |
|---|---|
| 向保险人查验本单位的社会保险缴费记录 | 依法收缴社会保险费，督促投保人和被保险人按时足额缴纳 |
| 要求保险人提供社会保险的政策咨询 | 管理基金；建立社会保险档案和个人账户 |
| 监督保险人的社会保险工作 | 社会保险待遇的给付 |
| 就与本单位有关的社会保险争议按照法律程序请求解决 | 向保险人和被保险人提供咨询和查询服务 |

**3. 社会保险法律适用基本规则**

| 规则 | 内容 |
|---|---|
| 上位法优于下位法 | 宪法 > 法律 > 行政法规 > 地方性法规 > 规章 |
| 特别法优于一般法 | 同位法中特别规定与一般规定不一致时 |
| 新法优于旧法 | 同位法中新的规定与旧的规定不一致时 |
| 不溯及既往 | 原则上；更好地保护公民、法人和其他组织权利和利益的特别规定除外 |

**4. 社会保险覆盖范围**

| 人员类型 | 参加保险 |
|---|---|
| 用人单位及职工、无雇工的个体工商户、未在用人单位参加社保的非全日制从业人员及灵活就业人员 | 职工基本养老保险、职工基本医疗保险 |
| 农村居民、城镇未就业的居民 | 城乡居民基本养老保险、城乡居民基本医疗保险 |
| 工伤保险、失业保险、生育保险 | 覆盖所有用人单位及其职工 |
| 被征地农民 | 按国务院规定纳入相应的社会保险制度 |
