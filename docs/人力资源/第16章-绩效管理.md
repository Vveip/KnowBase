## 第一节 绩效管理概述

### 知识点 1　绩效管理的概念、作用、特征及影响因素 ★★★

#### 一、三个概念的层级关系

| 概念 | 定义 |
|---|---|
| **绩效** | 员工个人或群体在完成工作任务时实现的**工作结果**和在此过程中表现出的**行为**。绩效是对工作行为以及工作结果的一种反映，也是员工**内在素质和潜能**的一种体现 |
| **绩效考核** | 一套**正式的、结构化的制度**，用来**衡量、评价、反馈并影响**员工的工作特征、行为和结果 |
| **绩效管理** | 管理者与员工通过**持续开放的沟通**，就组织目标和目标实现方式**达成共识**的过程，也是促进员工做出有利于组织的行为、达成组织目标、取得卓越绩效的管理实践 |

**绩效考核与绩效管理的联系与区别：**

| | 内容 |
|---|---|
| **联系** | ① 绩效考核是绩效管理的**重要组成部分**，绩效考核的顺利实施不仅取决于评价过程本身，更取决于与评价相关的**整个绩效管理过程**；② 有效的绩效考核是对绩效管理的有力支撑，成功的绩效管理也会推动绩效考核的顺利开展 |
| **区别** | ① **绩效管理是一个完整的管理过程**，而绩效考核只是绩效管理中的**一个环节**；② 绩效管理侧重于**信息的沟通和绩效的提高**，绩效考核则侧重于**绩效的识别、判断和评价** |

::: warning 高频陷阱（几乎每年必考）
- "绩效考核与绩效管理是等价的"→ **错误**。
- "绩效考核是绩效管理的重要组成部分"（正确）≠ "绩效管理是绩效考核的重要组成部分"（错误）。
- **绩效管理**→信息的沟通和绩效的提高；**绩效考核**→绩效的识别、判断和评价。二者千万别互换。
- "绩效管理的有效性在一定程度上取决于绩效考核的科学性"→ 正确说法。
:::

#### 二、绩效管理的作用

**1. 在组织管理中的作用：** ① 有助于组织内部的**沟通**；② 有助于管理者**节约成本**；③ 有助于促进员工的**自我发展**；④ 有助于建立**和谐的组织文化**；⑤ 是实现**组织战略**的重要手段。

**2. 在人力资源管理中的作用：**
- 为其他人力资源管理环节的有效实施提供**依据**：① 为**薪酬的发放**提供依据；② 为**人员的配置和甄选**提供依据；③ 帮助组织更有效地实行**员工开发**。
- 可以用来评价**人员招聘、员工培训**等计划的执行效果。

#### 三、有效的绩效管理五大特征（必背）

| 特征 | 含义 |
|---|---|
| **敏感性** | 可以**明确地区分高效率员工和低效率员工** |
| **可靠性** | **不同评价者对同一个员工**所作的评价**基本相同** |
| **准确性** | 把**工作标准和组织目标联系起来**确定绩效的好坏；为实现准确性，必须进行**周期性的调整和修改** |
| **可接受性** | 组织上下对绩效工作的**共同支持**才能促成绩效管理的成功 |
| **实用性** | 绩效管理体系的**建立和维护成本要小于**绩效管理体系带来的**收益** |

> **只要绩效管理体系满足前三个特征（敏感性、可靠性、准确性），即可认为它是有效的。**

::: warning 高频陷阱
- 实用性的表述方向：**成本 < 收益**。写成"收益要小于建立和维护成本"就是错误项。
- 可接受性和实用性**也是**有效绩效管理体系的特征，说"不是"就是错误项。
:::

#### 四、绩效管理有效实施的影响因素（8 条）

1. **管理者**对绩效管理的认识程度
2. **高层领导支持**
3. **人力资源管理部门**的尽职程度
4. **员工**对绩效管理的态度
5. 绩效管理与**组织战略**的相关性
6. **绩效目标**的设定
7. **绩效指标**的设置
8. 绩效系统的**时效性**

> "绩效奖金的发放方式"**不属于**影响因素。

### 知识点 2　战略性绩效管理 ★★★【新教材变动】

> **战略性绩效管理**是指将组织的战略目标与**日常运营、员工行为及绩效评估体系**紧密连接起来，通过有效的绩效管理，确保组织资源和行动始终聚焦于实现长期战略愿景的一种管理方法。它打破了传统绩效管理仅关注"过去表现"或"短期目标达成"的局限，强调**前瞻性、协同性与战略一致性**。

**实施逻辑：** 组织的整体发展战略决定绩效管理的策略；处于不同环境下的组织会选择不同的发展战略，也需要选择与此相适应的绩效管理策略。这种绩效管理策略实际上是对**绩效管理技术和方法的选择**。

> **实施战略性绩效管理时，首先要做的是：分析组织战略目标。**

#### 一、适用于不同组织整体战略的绩效管理

不同组织在面对相同市场环境时也可能会采取截然不同的战略行为。从组织适应环境的方式来看，组织通常会选择**探索者战略、防御者战略或分析者战略**。组织成功的关键不在于采用"最强"的战略，而在于保证实施的战略与**环境、组织设计、管理流程、人员能力**相匹配。

**1. 探索者战略**

总是不断地开发新产品、挖掘新市场，寻找更广阔的市场机会。特点是**强调创新与市场敏感度，敢于冒险，灵活、变化快**。通常是那些在**动荡、不确定环境**中通过持续创新获得增长的组织（科技企业、初创企业）。组织特征：**扁平化、去中心化、鼓励跨部门协作、重视通才**。

| 项目 | 绩效内容 |
|---|---|
| 绩效管理 | **鼓励创新与尝试，容忍合理失败**，强调**灵活性和外部导向性** |
| 绩效考核 | 侧重对**新产品开发、新市场突破、创新成果**进行考查，采用**结果与过程并重、长期与短期结合**的考核方式 |
| 绩效管理沟通 | 将组织目标**融入员工的个人发展目标**，使组织和员工的利益趋向一致 |
| 考核结果的运用 | 应用于**薪酬分配**，激励员工最大限度发挥潜能 |

**2. 防御者战略**

专注现有市场。特点是**追求效率、控制成本、保证质量、避免风险**。应尽量维持内部的稳定性，将更多精力放在组织的长期发展上。通常是成熟行业中以运营效率为核心竞争力的组织（公用事业、传统制造业）。组织特征：**高度规范化、集中决策、垂直整合、流程标准化**。

| 项目 | 绩效内容 |
|---|---|
| 绩效管理 | 强调**成本控制、生产效率、质量稳定、运营规范** |
| 绩效考核 | 以**量化、短期、结果导向**的指标为主，考核标准清晰、流程严格，强调**稳定性与可控性**；选择**系统化的评价方法**，**多角度选择考核指标** |
| 绩效管理沟通 | 管理者侧重点应当是**调动员工潜能、发挥员工工作的积极性** |
| 考核周期 | 与**奖金发放的周期相一致**，便于考核操作 |
| 考核结果的运用 | 运用到员工的**开发、培训**中 |

**3. 分析者战略**

兼具防御者与探索者战略的特征：在核心业务上追求效率（防御者），同时谨慎地模仿竞争对手并在此基础上进行改进、创新（探索者）。组织特点是**平衡，一边稳定、一边创新**。通常是那些既想保持稳定又不愿错失机会的**大型多元化企业**。它并非被动模仿，而是有选择地、系统性地跟进并优化。

| 项目 | 绩效内容 |
|---|---|
| 绩效管理 | 强调**双维度重点**，即提倡效率和适度创新，**平衡短期业绩与长期发展，兼顾控制与灵活** |
| 绩效考核 | 既有保障现有业务的**效率指标**，也有探索新业务的**创新指标**；考核体系兼具**规范性与适应性**；该类组织可以选用**标杆超越法** |
| 绩效管理沟通 | 采用**与标杆组织进行对照**的方式与员工分析绩效现状并加以改进 |

#### 二、适用于不同竞争战略的绩效管理

从"竞争优势类型"和"市场范围"来看，组织通常会选择**成本领先战略、差异化战略或市场集中战略**，通过清晰定位建立可持续竞争优势，避免"夹在中间"的战略困境。

**1. 成本领先战略**

通过**规模效应、流程优化、严格的成本控制、供应链整合**，成为行业内总成本最低的生产者或服务提供者。目标市场是**大众市场**，竞争基础是**低价**。

| 项目 | 绩效内容 |
|---|---|
| 绩效计划、监控和反馈面谈 | 管理者应**强化员工的成本意识** |
| 绩效考核 | 尽量选择**以结果为导向的、实施成本较低**的评价方法 |
| 绩效考核指标 | 以**财务与运营效率指标**为主，强调**可量化、标准化**。通常包括**单位生产成本、产能利用率、采购成本节约率、库存周转率、运营费用占比**等 |
| 评价主体 | **只选择直接上级**作为评价主体，以**节约实施成本** |
| 绩效考核周期 | **不宜太短**，因为频繁的绩效考核会增加组织的管理成本 |
| 绩效改进 | 选择**标杆超越法**，将行业的领先者作为改进标杆 |
| 考核结果利用 | 应充分运用于**成本的改进和控制**，对绩效较好员工进行奖励 |

**2. 差异化战略**

通过提供被客户认为**独特且有价值**的产品或服务，从而获得**溢价能力**，形成竞争优势。差异化主要体现在四个方面：**产品设计、技术、功能，品牌形象与声誉，客户服务体验，分销渠道与售后支持**。

| 项目 | 绩效内容 |
|---|---|
| 绩效管理 | 关注**长期价值而非短期利润**，**鼓励试错和跨部门协作**，重视创新与专业能力，**容忍短期亏损** |
| 绩效考核 | 应选择那些**以行为为导向**的评价方法，因为**创新的成果通常是难以用量化的指标去衡量**的 |
| 绩效考核指标 | 包括**客户满意度、品牌认知度、品牌忠诚度、新产品收入占比、专利数量、研发投入占比、溢价能力**等 |
| 评价主体 | 评价主体应当**多元化** |
| 考核周期 | **不宜过短**，因为革新效果不一定能在短期内见到成效 |
| 考核结果的运用 | 应用于员工的**开发、培训**工作，使员工不断学习更先进的理论，与组织共同成长 |

**3. 市场集中战略**

集中资源并服务于某一**特定细分市场**（特定客户群体、地理区域或产品类型），在该细分市场中建立优势。两种子类型：**成本聚焦**（细分市场中成本最低）和**差异化聚焦**（细分市场中提供高度定制化服务或独特价值）。

| 项目 | 绩效内容 |
|---|---|
| 绩效管理 | 强调**客户黏性与响应力**，核心是**细分市场深度渗透、定制化响应速度** |
| 绩效考核指标 | 聚焦特定客户群体，通常包括**目标客户市场份额、客户留存率、定制交付周期、客户生命周期价值、细分市场利润率**等 |

::: warning 高频陷阱
- 成本领先：**结果导向 + 直接上级单一主体 + 周期不宜太短 + 客观财务指标**
- 差异化：**行为导向 + 主体多元化 + 周期不宜过短 + 客户满意度/品牌/专利等指标**
- "对所有岗位上的员工都实施量化考核"→ 差异化战略**不**这样。
- "关注企业的短期财务指标"→ 差异化关注**长期价值**。
- 成本领先战略下**不能多选主观性指标**，应多选**客观的财务指标**。
:::

## 第二节 绩效计划与绩效监控及辅导

### 知识点 1　绩效计划 ★★

#### 一、概念与要点

> **绩效计划是绩效管理的第一个环节，是绩效管理的起点。**

- 不但包括组织对员工**工作成果的期望**，而且包括组织希望员工表现的**行为和使用的技能**。
- 还是主管人员与员工在**绩效年开始之初**围绕绩效目标进行**反复沟通**的过程，将双方的共识落实为**绩效计划书**。
- **人力资源管理部门**对绩效管理的**监督与协调**负主要责任。
- **各级主管人员**要参与对绩效计划的制订。
- 绩效计划的制订是一个**自上而下**的过程，也是将**组织绩效分解成个人绩效目标**的过程。

#### 二、绩效计划目标的种类

| 种类 | 内容 |
|---|---|
| **绩效目标** | 来源于**组织目标、部门目标和个人目标**，主要用于描述员工应执行的**职位职责**和应完成的**量化产出指标** |
| **发展目标** | 指**支持员工实现绩效目标、促进员工自身发展的能力标准**，主要强调与组织目标相一致的**价值观、能力和核心行为** |

#### 三、绩效计划的内容（8 项）

1. 员工在该绩效周期内的**工作目标以及各工作目标的权重**
2. 完成目标的**结果**
3. 结果的**衡量方式和判别标准**
4. 员工**工作结果信息的获取方式**
5. 员工在完成工作中的**权限范围**
6. 员工完成工作需要利用的**资源**
7. 员工在达到目标的过程中**可能遇到的困难和障碍**以及管理者能够提供的**帮助和支持**
8. 管理者与员工进行**沟通的方式**

> "员工的实际绩效薪酬金额"**不属于**绩效计划的内容。

#### 四、绩效计划的制订原则（7 项，口诀：**突出统战价值，参与职位测量**）

| 原则 | 内容 |
|---|---|
| **价值驱动原则** | 绩效计划的制订与组织追求的提升组织价值的宗旨相一致 |
| **战略相关性原则** | 绩效计划中的工作目标应与**组织战略目标**密切相关 |
| **系统化原则** | 绩效计划应当与**战略计划、财务计划、经营计划、人力资源计划**等密切结合、相互匹配、配套使用 |
| **职位特色原则** | 绩效计划的内容、形式、指标的设定要充分考虑**不同职位的特点** |
| **突出重点原则** | 设定指标要突出重点，选择那些与**组织目标和本职位职责关联程度较高**的指标，引导员工将注意力集中在最关键的绩效目标和发展目标上 |
| **可测量性原则** | 绩效计划中设定的绩效指标或工作标准**必须是可以清晰测量的** |
| **全员参与原则** | 人力资源部门的主管人员、员工都应当**积极参与**到绩效计划制订过程 |

#### 五、制订步骤

1. **准备阶段**：搜集制订绩效计划所需信息——① 组织近几年的绩效管理资料；② 工作分析的相关资料；③ 组织最新的战略管理资料。
2. **沟通阶段**：管理者与员工通过**反复沟通**就绩效计划的内容达成一致的过程。

---

### 知识点 2　绩效监控及辅导 ★★★

> **绩效监控与辅导是联结绩效计划与绩效考核的桥梁。**

#### 一、绩效监控

> **绩效监控**是在绩效考核期间内管理者为了**掌握员工的工作绩效情况**而进行的一系列活动。绩效监控通过管理者和员工**持续的沟通**，观测、预防或解决绩效周期内可能存在的问题，更好地完成绩效计划。

- **优点**：管理者可以**随时发现**员工工作中出现的问题并及时加以调整。
- **局限性**：工作行为和工作结果相比更加**主观**，有时很难进行**客观、准确的评价**。

#### 二、绩效辅导

> **绩效辅导**是在**掌握了员工工作绩效的前提下**，为了**提高员工绩效水平和自我效能感**而进行的一系列活动。

- 与绩效反馈面谈的不同：绩效辅导**贯穿于绩效实施的整个过程中**，是一种**经常性的管理行为**。
- 绩效监控**能够为绩效辅导提供良好的基础**。

**1. 内容**（典型的两方面）：① **探讨绩效现状**；② **寻找改进绩效的方法**。

**2. 步骤**（6 步，顺序必背）：

| 步骤 | 内容 |
|:-:|---|
| 1 | **收集资料** |
| 2 | 定好基调 |
| 3 | 达成一致 |
| 4 | 探索可能 |
| 5 | 制订计划 |
| 6 | 给予信心 |

#### 三、绩效计划的调整

- 员工的绩效计划目标**每个绩效周期核定一次**，没有特殊情况**不做调整**。
- 如在绩效执行过程中发生**组织业务发展计划变更、组织结构调整、市场环境变化、不可抗拒的事件**等情况，需要调整计划时，员工可以向主管人员提出**书面申请**，由**人力资源部**组织有关职能部门**重新审定**，经**高层批准**后实施。

::: warning 高频陷阱
- **绩效计划是绩效管理的起点**，不是绩效监控。
- 绩效监控 = 掌握绩效情况；绩效辅导 = 提高绩效水平和自我效能感，二者定义别互换。
- 绩效辅导**贯穿于**绩效实施整个过程（不是只在面谈时）。
- 绩效辅导**首先要做的是收集资料**。
:::

## 第三节 绩效评价与绩效管理工具

### 知识点 1　绩效评价 ★★

#### 一、绩效评价技术三大类

| 大类 | 包含方法 |
|---|---|
| **量表法** | ① **图尺度评价法**；② **行为锚定法**；③ **行为观察量表法** |
| **比较法** | ① **排序法**（简单排序法、交替排序法）；② **配对比较法**；③ **强制分布法** |
| **描述法** | ① **关键事件法**；② **不良事故评估法** |

::: warning 高频陷阱
- **关键事件法属于描述法，不属于量表法**（高频错项）。
- 量表法共 3 种、比较法共 3 种、描述法共 2 种，合计 8 种。
:::

**1. 图尺度评价法（等级评价法）**——最简单也最常用的绩效评价方法。列举一些特征要素，并分别为每一个特征要素列举绩效的取值范围。

| | 内容 |
|---|---|
| **优点** | ① 开发非常容易，对不同的工作、不同的战略以及不同的组织都具有**普遍适应性**；② **实用且开发成本小** |
| **缺点** | ① 与组织战略之间常常差异较大；② 往往只有**模糊和抽象的绩效标准**，导致不同的评价者对绩效标准产生不同的理解；③ 绩效评价结果受评价者的**主观因素**影响比较大；④ 无法为员工改进工作提供**具体的指导**，不利于绩效评价的反馈 |

**2. 行为锚定法**——将每项工作的特定行为用一张等级表进行反映，该等级表将每项工作划分为各种行为级别（从最积极的行为到最消极的行为），评价时评价者只需将员工的行为**对号入座**即可。

| | 内容 |
|---|---|
| **优点** | ① 使工作的**计量更为准确**，比其他方法更能准确描述绩效；② 评价标准**更为明确**，等级尺度上所附带的**关键事件**使评价者清楚知道什么是"优秀"、什么是"一般"，排除了评价者的主观臆断，评价结果具有**较高的信度**；③ 评价结果具有良好的**反馈功能**；④ 评价者很容易向员工解释其优势与不足，同时明确改进方向 |
| **缺点** | ① **开发成本很高，操作流程复杂**；② 需付出大量人力、物力、财力才能够制定出合理的行为等级表 |

**3. 行为观察量表法**——由工作绩效所要求的一系列合乎组织期望的行为组成的表单。列举出评价指标（通常是期望员工工作中出现的比较好的行为），然后要求评价者在观察的基础上将员工的工作行为同评价标准进行对照，看该行为出现的**频率或完成的程度**如何（从"几乎没有"到"几乎总是"）。

| | 内容 |
|---|---|
| **优点** | ① **内部一致性令人满意**，所有区分成功和不成功绩效的行为都被包括在量表中；② 用使用者的数据针对使用者而开发，因而对量表的理解和使用比较便利；③ 有利于绩效反馈，鼓励管理者和员工间就员工优缺点进行讨论；④ 清楚的绩效反馈结合明确的目标设定，可以促进产生和保持积极的行为变化；⑤ 可以**单独作为职位说明书的补充** |
| **缺点** | ① 根据行为清单对员工进行观察，很难包含所有行为指标的代表性样本，**效度有待提高**；② 管理者单独考核**工作量太大，不具有可操作性** |

**4. 排序法**——将员工的业绩按照从高到低的顺序进行排列。

- **简单排序法**：评价者把所有员工按照业绩的顺序排列起来。
- **交替排序法**：简单排序法的一种改进，将员工从绩效最好到最差进行**交替排序**，最后根据序列值来计算得分，也是一种"**掐头去尾**"和"**逐级评价**"的方法。

| | 内容 |
|---|---|
| **优点** | 操作简单，评价结果简单明了；实施成本低廉 |
| **缺点** | 容易造成员工有心理压力；不容易接受评价的结果；很难提供详细具体的绩效评价结果 |

**5. 配对比较法**——根据某项评价标准将每位员工逐一与其他员工比较，选出每次比较的优胜者，最后根据每位员工**获胜的次数**进行绩效排序。

- **优点**：比排序法更科学，能在**人数较少**时快速比出员工绩效水平。
- **缺点**：当员工人数增加时，评价的工作量会**成倍增加**；且只能得到员工绩效的排名，**不能反映绩效差距和工作能力差距**。

**6. 强制分布法**——要求评价者将被评价者的绩效结果放入一个类似于**正态分布**的标准中。基于一个有争议的假设：在被评价者中，优秀、一般和较差的员工同时存在。

- **优点**：能够有效避免考核结果**趋中趋势**、有利于管理手段的实施。
- **缺点**：评价者可能存在主观意识，将员工的评价分数划定在一个区域内，**弱化评价分数的差距**。

**7. 关键事件法**——要求评价者在绩效周期内，将发生在员工身上的**关键事件**都记录下来，并将它们作为绩效评价的事实依据。**只记录工作中非同寻常的行为**。核心是明确关键事件的定义和包含的项目。

| | 内容 |
|---|---|
| **优点** | ① 工作行为与绩效评价结果联系在一起，评价结果更**客观**（削弱了评价者偏见对考核结果的影响）；② 分析关键事件来确定员工优势与不足，**有针对性进行培训**；③ 为绩效反馈面谈奠定基础，关键事件记录使上下级双方很容易就绩效现状达成一致 |
| **缺点** | ① **非常费时**；② 无法提供员工之间、部门之间和团队之间的业绩比较信息 |

**8. 不良事故评估法**——通过预先设计**不良事故的清单**对员工的绩效进行考核。

- **优点**：迎合企业需要，使企业尽量避免巨大的损失。
- **缺点**：① 不能提供丰富的绩效反馈信息；② 不能用来比较员工、部门、团队的绩效水平。

#### 二、绩效评价常见八大误区（必考匹配）

| 误区 | 定义 |
|---|---|
| **晕轮效应** | 因对被评价者的**某一特质强烈而清晰的感知**，而掩盖了该人其它方面的品质。评价者通常会给信任和喜爱的部下较高分数，对不喜欢的员工给予较低评价 |
| **趋中倾向** | 评价者不愿意得罪人或所辖范围过大，很难全面了解员工工作表现，将员工的考核分数**集中在某一固定范围**的变动中，评价结果无好坏的差异 |
| **过宽或过严倾向** | 一些评价者在绩效评价过程中，有**过分严厉或过分宽大**地评定员工的倾向。原因是采取了主观评价标准，忽略了客观的评价标准 |
| **年资或职位倾向** | 评价者倾向于给予那些**服务年资较久、担任职级较高**的被评价者较高的分数 |
| **盲点效应** | 评价者**难于发现员工身上存在的与自身相似的缺点和不足** |
| **刻板印象** | 个人对他人的看法，往往受到他人**所属群体**的影响（如错误地认为男性的工作能力较女性容易受到肯定） |
| **首因效应** | 人们在相互交往的过程中，往往根据**最初的印象**去判断一个人 |
| **近因效应** | **最近的或最终的印象**往往是最强烈的，可以冲淡之前产生的各种因素 |

::: warning 高频陷阱
- "最初印象"→ **首因效应**；"最终/最近印象"→ **近因效应**。
- "某一特质强烈清晰感知掩盖其他品质"→ **晕轮效应**。
- "难以发现与自身相似的缺点"→ **盲点效应**。
- "受他人所属群体影响"→ **刻板印象**。
- "分数集中在固定范围、无好坏差异"→ **趋中倾向**。
:::

#### 三、绩效评价主体的培训

1. **培训内容**：让每一个评价者都了解绩效评价的理论和技术，向评价者说明以前绩效评价中存在的问题及合理解决方案。为增加培训有效性，还应增加工作绩效的**多角度性**、**客观记录所见事实的重要性**、合格与不合格员工的具体事例等内容。
2. **培训方式**：传统的授课模式、群体讨论会、专题研讨会。
3. **培训反馈**：培训结束后，管理者应对培训的效果加以评价，查看评价者是否将培训中获得的知识运用于工作中。

### 知识点 2　绩效管理工具 ★★★

四大工具：**目标管理法、标杆超越法、关键绩效指标法、平衡计分卡法**。

**演变历程**：横向上不断拓展评价范围，从单纯财务指标扩展到全面地考察企业；纵向上不断提升关注经营的功能，从单纯的绩效评价工具上升到承接组织战略的**战略性绩效管理工具**。

#### 一、目标管理法

> 一种**沟通的程序或过程**，强调企业上下一起协商，将企业目标分解成个人目标，并将这些目标作为企业经营、评价、奖励的标准。**企业战略相对稳定时，适合使用目标管理法。**

**设计流程**：① 绩效目标的确定（各层级目标必须与企业层次上所设定的目标相一致，目标必须**具体化、相关的、可实现的、可测量的**）→ ② 确定考核指标的权重（四类：重要又迫切、重要但不迫切、不重要但迫切、既不重要又不迫切）→ ③ 实际绩效水平与目标绩效相比较 → ④ 制定新的绩效目标。

| 优势 | 劣势 |
|---|---|
| ① 有效性 | ① 倾向于聚焦**短期目标**，可能牺牲企业长远利益为代价 |
| ② 启发了员工的**自觉性** | ② 认为员工是**乐于工作**的，**高估了企业内部自觉、自治氛围** |
| ③ 实施过程比关键指标法和平衡计分卡法**更易操作** | ③ 可能增加企业的**管理成本** |
| ④ 较为**公平** | ④ 目标有时可能**难以制定** |

#### 二、标杆超越法

> 通过**对比和分析业内外领先企业的经营方式**，对本企业的产品或服务、业务流程等关键成功因素进行改进和变革，使企业成为同行最佳的系统过程。实际是通过学习同行业经验，改掉制约企业发展陋习的过程。

三个方面理解：① 标杆指的是**最佳实践或最佳标准**；② 标杆的寻找范围**并不局限在同行业**，应该有更广阔的视角；③ 相比其他系统的考核方法**更重视比较和衡量**。

**设计流程**：发现"瓶颈" → 选择标杆（两个标准：标杆企业要有**卓越的业绩**；被瞄准的领域与本企业有**相似特点**；分为**内部标杆、竞争标杆、行业标杆和最优标杆**四类）→ 收集数据 → 通过比较分析确定绩效标准 → 沟通与交流 → 采取行动。

| 优势 | 劣势 |
|---|---|
| ① 有助于激发企业中员工、团队和整个企业的**潜力，提高绩效** | ① 容易使企业陷入**模仿标杆企业的漩涡**中，失去自身的特色 |
| ② 促进企业经营者**激励机制**的完善 | ② 标杆的选取出现偏差，导致自身经营决策失误 |

#### 三、关键绩效指标法（KPI）

> 反映**个体关键绩效贡献**的评价依据和量化指标。**适用于企业战略进行重大调整的时期。**

五个要点：① 对**企业战略目标的分解**，是联结个人绩效与企业绩效的桥梁；② 主管人员决策**并被员工认可**的绩效指标；③ 对**重点经营活动**的反映，**不是所有业务流程活动的概括**；④ 必须是**可量化的或可行为化**的；⑤ **不是一成不变的**，随企业战略的变化而调整。

**设计流程**：
1. **确定考核指标**——遵守 **SMART 原则**：具体的（Specific）、可测量的（Measurable）、可实现的（Attainable）、相关的（Relevant）、有时限的（Time-bound）。
   - 四种类型：**数量类**（产品的数量、销售量）、**质量类**（合格产品的数量、**不合格品比率**）、**成本类**（单位产品的成本、投资回报率）、**时限类**（及时性、供货周期）。
2. **确定评价标准**——两个标准：
   - **基本标准**：管理者期望被评价者达到的水平，作为**非激励性**的人力资源措施的实施依据。
   - **卓越标准**：即超额完成任务，主要用于**识别核心员工**，是**激励性**措施实施依据（如额外的奖金、晋升等）。

**注意事项**：① 指标数量**不宜过多**；② 同类型职位的关键绩效指标必须**保持一致**；③ 要彻底贯彻企业战略重点。

| 优势 | 劣势 |
|---|---|
| ① 企业绩效指标与企业战略目标**紧密联系在一起** | ① 某些职位设计关键绩效指标比较困难，如**知识型员工贡献是无形的** |
| ② **自上而下**地确定各个级别绩效目标，将企业和个人目标很好地整合在一起 | ② 缺少一套完整的对操作具有指导意义的指标框架体系 |

#### 四、平衡计分卡法

> 一种**新型的战略性绩效管理的工具和方法**，**适用于企业战略进行重大调整的时期**，着眼于公司的长远发展，从**四个角度**关注企业的绩效。

| 角度 | 说明 |
|---|---|
| **财务角度** | 关注企业**已采取行动所达成的结果** |
| **客户角度** | 补充财务指标，支持未来财务指标的改进 |
| **内部流程角度** | 同上 |
| **学习与发展角度** | 同上 |

> 财务指标关注企业已采取行动所达成的**结果**，另外三个方面的指标用来**补充财务指标，同时支持未来财务指标的改进**。

**设计流程**：审视企业战略和竞争目标 → 设立绩效指标 → 开发各级平衡计分卡 → 设定各级指标的评价标准 → 进行绩效考核 → 分析考核结果并修正指标及标准。

**注意事项**：① 高层管理者参与实施，并鼓励员工参与绩效体系的设计过程，提高员工的理解度与支持度；② **防止平衡计分卡使用目的的单一**——既是绩效考核办法，又是战略管理工具；③ 要谨慎选择考核指标，指标要正确反映战略目标，能够客观、可量化，同时指标数量不宜过多；④ 要充分重视实施的连续性和持久性。

| 优势 | 劣势 |
|---|---|
| ① 改变了**财务指标一统天下**的局面 | 实施**成本很高**，需要耗费大量的人力、物力和财力 |
| ② 从企业的**战略层次**考虑问题，并揭示了**四个考核角度之间的因果关系**，发展了战略管理系统 | |
| ③ 实现了**评估系统与控制系统**的结合 | |
| ④ 使管理者将所有的重要绩效指标在一起综合考虑，提高了企业发展的**协调性** | |

::: warning 高频陷阱（四大工具辨析，每年必考）
- **目标管理法**：战略**相对稳定**期；聚焦**短期**目标；假设员工乐于工作；较为公平；更易操作。
- **标杆超越法**：标杆范围**不局限同行业**；更重视比较和衡量；易陷入模仿漩涡。
- **关键绩效指标法**：战略**重大调整**期；反映**个体**贡献；可量化或可行为化；随战略调整而变；指标**不宜过多**；不合格品比率属**质量类**。
- **平衡计分卡法**：战略**重大调整**期；四角度；揭示**因果关系**；实施**成本很高**。
- 目标管理法与平衡计分卡都"适用于战略重大调整期"？——**不是**。目标管理法适用于**战略相对稳定**期。
:::

## 第四节 绩效反馈面谈、绩效改进和绩效考核结果的分析与应用

### 知识点 1　绩效反馈面谈 ★

#### 一、目的及作用

**目的**：① 向员工**反馈绩效考核结果**；② 向员工**传递组织远景目标**；③ 弄清员工**绩效不合格的原因**（绩效管理的目的是改进绩效，不是简单奖惩）；④ 为**下一个绩效周期**工作的展开做好准备，将改进计划落实到新的绩效合约中。

**作用**：① 为评价者与员工提供了**沟通平台**，使考核公开化；② 能够使员工客观地了解自己工作中不足，利于改善绩效；③ 可以消除组织目标与个人目标之间的冲突，增强组织竞争力。

#### 二、操作流程

**1. 面谈准备阶段**：① 全面收集资料；② 准备面谈提纲；③ 选择合适的时间和地点，并提前通知面谈对象。

**2. 面谈实施阶段**：① 分析绩效差距的**症结所在**；② 协商解决办法；③ 绩效反馈面谈的原则：

| 原则 | 内容 |
|---|---|
| **建立彼此之间的信任** | 维护员工的自尊，避免挫伤员工工作热情 |
| **开诚布公、坦诚沟通** | 具体、详细、客观解释绩效现状，**切忌含糊笼统** |
| **避免对立与冲突** | — |
| **关注未来而不是过去** | — |
| **该结束时立即结束** | 当出现紧急事务、严重分歧和超时情况 |

**3. 面谈评价阶段**：面谈结束后，主管人员应对面谈效果进行评价，分析是否达到目的、对员工有所了解、有哪些可以改进的地方。

#### 三、内容及注意事项

**内容**：① 就**绩效现状达成一致**；② 探讨绩效中**可改进之处**，并确定**行动计划**；③ 商讨下一年的**工作目标**。

**注意事项**：① 采取**赞扬与建设性批评结合**的方式，在肯定员工表现的同时，指出其可改进之处，避免员工产生抵触情绪；② **把重点放在解决问题上**——反馈面谈的最终目的是**改进绩效**，分析不良绩效产生的原因并探讨解决方案才是面谈的核心；③ **鼓励员工积极参与**到反馈过程中，营造一种相互尊重的氛围。

#### 四、面谈中评价者的五大误区

| 误区 | 表现 |
|---|---|
| **不适当发问** | 尽量避免**诱导发问、发问内容没有逻辑性、同时对两件以上的事情发问**等情况 |
| **理解不足** | 员工有夸大、忽略、曲解观点的可能。主管人员要将对方的谈话加以**归纳、回馈、质疑后再确定**，以确保对问题的真正理解 |
| **期待预期结果** | 发问或谈话过程中如果存在**强烈的预期心理**，期待得到对方某种回答，往往会在无意识中曲解员工的观点 |
| **自我中心和感情化的态度** | 主管人员陷入自我感情或自我中心的想法时，就会失去面谈的客观性和公正性 |
| **以对方为中心及同情对方** | 过多考虑对方立场，从同情的角度给予过多的建议。过犹不及，过度关怀可能使对方产生厌烦 |

#### 五、绩效面谈的技巧

1. **时间场所的选择**：避开上下班、开会等让人分心的时段；地点选择**安静、轻松的会客厅**。目的是为员工营造一种轻松、平等的氛围。
2. **认真倾听**：使用目光的接触和恰当的表情来表示对对方谈话的理解。**切忌主管人员喋喋不休，时常打断对方谈话**。
3. **鼓励员工多说话**：面谈是一种**双向沟通**，让下属充分表达观点，主管人员可以多提一些**开放性**的话题。
4. **以积极的方式结束对话**：采用积极的令人振奋的方式结束面谈，结束时给员工**鼓励而非打击**。因为绩效管理更关注的是**未来的绩效**而不是过去的。

::: warning 高频陷阱
- 面谈的**根本目的不是指出员工的不足**，而是**弄清楚绩效不合格的原因、改进绩效**。
- 面谈**重点不是赞扬突出绩效**，而是**放在解决问题上**。
- 食堂吃午餐时间面谈 → **错误**（让人分心）。
- 避免"理解不足"→ 面谈结束时**归纳并确认谈话内容**。
:::

### 知识点 2　绩效改进 ★★

> **绩效改进**是指通过找出组织或员工工作绩效中的差距，制订并实施有针对性的改进计划来提高员工绩效水平的过程。

#### 一、绩效改进的程序

**1. 绩效诊断与分析**——绩效改进**第一步，也是基本环节**。① 发现问题：发现组织绩效问题和不良绩效员工；② 解决问题：为改进方案制定做准备。

**2. 组建绩效改进部门**——组织可根据绩效改进的实际需求设立专门的绩效改进部门，通过提供**咨询、培训、分析和评价服务**来确保个人与组织绩效的不断改进。

**3. 选择绩效改进方法**

| 方法 | 关注点 |
|---|---|
| **卓越绩效标准** | 关注组织的**管理理念** |
| **六西格玛管理** | 关注组织**流程的误差率** |
| **ISO 质量管理体系** | 关注组织**产品（或服务）的生产过程** |
| **标杆超越** | 关注点**可以灵活多变** |

- **卓越绩效标准**：通过描述卓越组织的管理信念和行为，改进组织的整体效率和能力。波多里奇的卓越绩效标准树立了一套相互关联的核心价值观，核心概念包括领导的远见卓识、以顾客为导向追求卓越、组织的和个人的学习、尊重员工和合作伙伴、灵敏性、关注未来、管理创新、基于事实的管理、社会责任、重在结果及创新价值、系统观点。
- **六西格玛管理**：核心理念是在企业整个业务流程的所有环节上，都运用科学的方法提高效率、减少失误率，使整个流程达到最佳状态，从而满足客户的要求。
- **ISO 质量管理体系**：根据 ISO 9000 的标准，由**四大板块**组成，即**管理职责、资源管理、产品实现**以及**测量、分析和改进**。特点：① 明确了管理层在质量管理中的职责；② 强调**纠正和预防措施**；③ 强调**审核和监督**。
- **标杆超越**：企业标杆的设立比较灵活，可以将优秀企业的某一管理"片断"作为标杆，也可以将优秀企业整体作为标杆。

**4. 绩效改进实施管理**——需注意：① 恰当选择绩效改进方案执行的**时机**；② 给予员工**改善绩效的机会**；③ 绩效改进方案要以**正式的文件**传达下来；④ 采取进一步行动前，要与**人力资源顾问及组织的高层管理者**进行充分的沟通。

**5. 绩效改进效果评价**——四个维度：

| 维度 | 内容 |
|---|---|
| **反馈** | 员工、客户、供应商对改进结果的反馈 |
| **能力** | 绩效改进实施后员工能力素质提升的程度 |
| **转变** | 绩效改进活动对工作方式的影响 |
| **结果** | 绩效改进所达成的结果与预期的对比 |

::: warning 高频陷阱
- 绩效改进工具 = **卓越绩效标准、六西格玛管理、ISO 质量管理体系、标杆超越法**（**不含平衡计分卡法**）。
- 六西格玛关注**流程的误差率**，不是"流程设置的合理性"。
- 卓越绩效标准关注**组织的管理理念**，不是"个体卓越绩效指标"。
- ISO 关注**产品的生产过程**。
:::

### 知识点 3　绩效考核结果的分析与应用 ★★

#### 一、绩效考核结果的分析

通过绩效考核，组织可以掌握员工的**工作态度**和**工作能力**。通过这两个维度的交叉分析，组织员工可以划分为**四种类型**：

| 员工类型 | 特征 | 组织行为 |
|---|---|---|
| **贡献型** | 工作态度好 + 工作能力强 | 组织要给予**必要的奖励** |
| **安分型** | 工作态度好 + 工作能力差 | 组织要对其进行**必要的培训**以提升其工作技能 |
| **堕落型** | 工作态度差 + 工作能力强 | 组织要对其进行**适当的惩罚、敦促其改进绩效** |
| **冲锋型** | 工作态度差 + 工作能力差 | 主管人员应当对其进行**绩效辅导** |

::: warning 高频陷阱
- 交叉分析的两个维度是**工作态度和工作能力**，不是年龄/性别/工作经验。
- **没有"防守型"员工**。
- "安分型"→ 培训；"堕落型"→ 惩罚；"冲锋型"→ 绩效辅导；"贡献型"→ 奖励。
:::

#### 二、绩效考核结果的应用（5 项）

1. 应用于**衡量招聘结果**——招聘是否有效，要通过新员工在一段时间内的绩效考核结果来衡量。
2. 为**人员调配**提供依据——为员工晋升、调整、淘汰提供决策支持。
3. 为**奖金分配**提供依据——可以强化薪酬的激励作用。
4. 应用于员工的**培训与开发**——考核结果加深组织对员工能力和素质水平的认识，特别是劣势与不足，也可以用于衡量培训的有效性。
5. 应用于**员工职业生涯发展规划**。

> 绩效考核结果**不能**用于**职位评价**。

## 第五节 特殊群体的绩效考核

### 知识点 1　团队绩效考核 ★★

#### 一、团队绩效考核的流程（5 步）

1. 人力资源部**发布考核通知**，启动考核程序，公布考核要求；
2. 对各个**团队负责人**的绩效进行考核；
3. 根据员工所在**团队负责人的评价结果**确定团队成员的评价结果分布；
4. 进行**团队成员评价**（间接上级、直接上级、员工本人都应参与）；
5. 员工的**直接上级**与员工就绩效考核结果进行沟通，并制定下一阶段的工作目标。

#### 二、团队绩效考核指标确定的方法

**三个步骤**：① 确定团队和团队成员两个层面的绩效考核指标；② 划分团队与个体绩效所占的**权重和比例**；③ 分解绩效考核的关键要素，用具体的评价指标来衡量他们。

> **团队层面的绩效考核指标是该体系的关键点。**

**建立团队层面绩效考核指标的四种方法**：① 利用**客户关系图**；② 利用**组织绩效指标**；③ 利用**绩效金字塔**；④ 利用**工作流程图**。

#### 三、知识型团队的绩效考核方法

知识型团队的任务一般是**创造性的而不是重复性的**。考核要**以结果为导向，而不是以行为为导向**。需综合以下四个角度的指标：

| 指标 | 内容 |
|---|---|
| **效益型指标** | 可以直接用来判断知识型团队的**工作产出成果**，即团队的产出满足客户要求的程度 |
| **效率型指标** | 为获得效益指标所付出的**成本和投入产出的比例** |
| **递延型指标** | 团队工作过程和工作结果对**客户、投资者、团队成员的长远影响** |
| **风险型指标** | 判断**不确定性风险的数量**和对团队及其成员的危害程度的指标 |

#### 四、跨部门的团队绩效考核方法

1. **跨部门绩效考核的关键是做好标准化工作**：① 考核目标的标准化；② 考核程序的标准化；③ 组织的标准化；④ 方法手段的标准化。
2. 建立**以人为本**的跨部门考核制度。
3. **矩阵形式的组织结构**比较适合跨部门的团队绩效考核。
4. **统一标准**：① 对于性质相同的部门要采用**同一评价的方法**，使考核结果具有可比性；② 考核的手段也应该标准化，评价卡片、绩效目标资料都要由**人力资源部统一印刷**。

### 知识点 2　国际人力资源的绩效考核

| 维度 | 特点 |
|---|---|
| **目标** | 不但关注**业绩**，而且突出**战略方向**，强调企业的**长远发展** |
| **目的** | 加入了新的目的，如重视**个人、团队和公司目标的密切结合**，寻找在工作要求、个人能力、兴趣和工作重点之间的**最佳契合点** |
| **侧重点** | 更倾向于**基于结果的绩效考核**而不是基于员工特征的绩效考核 |
| **操作过程** | 在绩效的评价与反馈过程中，比传统考核**更加注重管理者和员工的沟通** |

## 易混点对比

### 一、绩效考核 vs 绩效管理

| 对比项 | 绩效考核 | 绩效管理 |
|---|---|---|
| 定位 | 绩效管理中的**一个环节** | **完整的管理过程** |
| 性质 | 正式的、结构化的**制度** | 持续开放的**沟通过程** |
| 侧重 | 绩效的**识别、判断和评价** | **信息的沟通和绩效的提高** |
| 二者关系 | 是绩效管理的**重要组成部分** | 有效性一定程度上取决于绩效考核的科学性 |

### 二、绩效评价技术三大类

| 对比项 | 量表法 | 比较法 | 描述法 |
|---|---|---|---|
| 方法 | 图尺度评价法、行为锚定法、行为观察量表法 | 排序法、配对比较法、强制分布法 | 关键事件法、不良事故评估法 |
| 共同特点 | 有等级量表 | 员工之间相互比较得出排名 | 记录事实、文字描述 |
| 易错点 | 关键事件法**不在**此类 | 强制分布法基于**正态分布**假设 | 关键事件法**非常费时** |

### 三、量表法三种方法

| 对比项 | 图尺度评价法 | 行为锚定法 | 行为观察量表法 |
|---|---|---|---|
| 别称 | 等级评价法 | — | — |
| 形式 | 特征要素 + 绩效取值范围 | 等级表 + 关键事件，行为**对号入座** | 行为表单 + 频率/完成程度（几乎没有→几乎总是） |
| 开发成本 | **小** | **很高**，操作流程复杂 | 较高 |
| 信度 | 受主观因素影响大 | **较高** | 内部一致性令人满意 |
| 反馈功能 | 无法提供具体指导 | **良好** | 有利于反馈，可单独作为职位说明书补充 |
| 主要缺点 | 标准模糊抽象、与战略差异大 | 开发成本高 | 效度有待提高；管理者工作量太大 |

### 四、四大绩效管理工具

| 对比项 | 目标管理法 | 标杆超越法 | 关键绩效指标法 | 平衡计分卡法 |
|---|---|---|---|---|
| 适用时期 | 战略**相对稳定**期 | — | 战略**重大调整**期 | 战略**重大调整**期 |
| 核心 | 上下协商、目标分解为个人目标 | 对比业内外领先企业 | 个体关键绩效贡献的量化依据 | 财务/客户/内部流程/学习与发展四角度 |
| 关键假设/标准 | 员工乐于工作（高估自觉性） | 标杆要有卓越业绩 + 领域相似 | 可量化或可行为化 | 指标要正确反映战略目标 |
| 突出优势 | 较为公平、更易操作 | 激发潜力、重视比较衡量 | 与企业战略紧密联系、自上而下整合目标 | 揭示四角度因果关系、评估与控制系统结合 |
| 突出劣势 | 聚焦短期目标、可能增加管理成本 | 易陷入模仿漩涡、失去特色 | 知识型员工难设计、缺少完整框架 | **实施成本很高** |
| 易错点 | 不是聚焦长期目标 | 标杆**不局限同行业** | 指标**不宜过多**；不合格品比率属**质量类** | 不是实施成本很低 |

### 五、绩效改进四种方法

| 对比项 | 卓越绩效标准 | 六西格玛管理 | ISO 质量管理体系 | 标杆超越 |
|---|---|---|---|---|
| 关注点 | 组织的**管理理念** | 组织**流程的误差率** | 组织产品（或服务）的**生产过程** | **可以灵活多变** |
| 关键词 | 波多里奇、核心价值观 | 科学方法、减少失误率 | 四大板块、纠正预防、审核监督 | 学习先进、改掉陋习 |

### 六、员工四类型（工作态度 × 工作能力）

| | 工作能力强 | 工作能力差 |
|---|---|---|
| **工作态度好** | **贡献型** → 给予**奖励** | **安分型** → **培训**提升技能 |
| **工作态度差** | **堕落型** → **惩罚、敦促改进** | **冲锋型** → **绩效辅导** |

### 七、知识型团队四类指标

| 对比项 | 效益型 | 效率型 | 递延型 | 风险型 |
|---|---|---|---|---|
| 回答什么 | 产出成果如何（满足客户要求的程度） | 付出了多少成本和投入产出比 | 对客户/投资者/成员的长远影响 | 不确定性风险的数量及危害程度 |
| 关键词 | 成果 | 成本、比例 | 长远影响 | 风险 |

### 八、绩效反馈面谈五大误区

| 对比项 | 表现 | 对策 |
|---|---|---|
| 不适当发问 | 诱导发问、无逻辑、同时问多件事 | 注意提问技巧 |
| **理解不足** | 员工夸大、忽略、曲解观点 | **归纳、回馈、质疑后再确定** |
| 期待预期结果 | 强烈预期心理 | 保持客观 |
| 自我中心和感情化 | 失去客观性和公正性 | 避免感情化 |
| 以对方为中心及同情 | 过度关怀使对方厌烦 | 过犹不及 |
