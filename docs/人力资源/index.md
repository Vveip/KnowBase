## 六、内容组织方式

每章笔记统一模板：

```md
# 第 X 章　章名

## 一、考情概况
（年份 × 题型分值表 + 趋势简评）

## 二、知识框架
（本章节结构）

## 三、核心知识点
（按课件「本节知识点」逐条展开，★ 标注星级）

## 四、高频考点汇总
（考点 / 出题形式 / 重要度）

## 五、易混点对比
（表格形式对比易混淆概念）

## 六、本章题目
（quiz 题库块，直接用于刷题系统）
```

题目写在笔记里，构建时由脚本自动抽取生成题库，**知识点和考题永不脱节**。

## 七、星级说明

课件中知识点用 ★ 标注重要度：

| 标记 | 含义 | 投入 |
|---|---|---|
| ★★★ | 极高频，必考 | 精读 + 刷题 + 能默写 |
| ★★ | 高频，常考 | 理解 + 做题巩固 |
| ★ | 一般，偶考 | 有印象，能判断 |
| 无星 | 低频 | 考前扫一眼 |
