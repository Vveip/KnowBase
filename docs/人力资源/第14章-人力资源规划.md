## 第一节 人力资源规划及其供求预测

### 知识点 1　人力资源规划概述 ★

#### 一、概念

> 人力资源规划是指组织**根据自身战略的需要**，采用科学的手段来预测组织未来可能会遇到的人力资源需求和供给状况，进而制订必要的人力资源**获取、利用、保留和开发**计划，满足组织对于人力资源**数量和质量**的需求。

| 口径 | 范围 |
|---|---|
| **广义** | 人力资源战略规划、人员供求规划、培训开发规划、绩效管理规划、薪酬福利规划、员工关系规划、中高层管理人员的**接班计划或继任规划**等 |
| **狭义**（本章所讲） | 专指组织的**人员供求规划或雇用规划** |

#### 二、狭义人力资源规划的四步流程（必背顺序）

| 步骤 | 内容 | 关键点 |
|:-:|---|---|
| 第一步 | **人力资源需求预测** | 通过对**组织战略规划**的细致分析明确规划期内的人力资源需求；不仅包括**数量**，还包括员工的**质量和结构** |
| 第二步 | **人力资源供给预测** | 分析组织**外部劳动力市场形势 + 内部人员供给情况**，预测规划期内供给的数量、质量、结构，并了解外部招募难度 |
| 第三步 | **人力资源供求平衡分析** | 对比前两步结果，得出未来可能出现的供求平衡情况 |
| 第四步 | **实施人力资源供求平衡计划** | 分步骤加以实施 |

::: warning 高频陷阱
- 人力资源规划**从明确组织的战略规划开始**，不是从了解外部劳动力市场开始。
- 需求预测阶段**不涉及**"员工的职业发展轨迹分析"——那是供给预测/职业生涯管理的活儿。
- 需求预测**不考虑**组织内部现有人力资源状况。
:::

#### 三、人力资源规划的意义和作用

1. 有利于**组织战略目标的实现**。
2. 有利于组织整体人力资源管理系统的**稳定性、一致性和有效性**，有利于组织的健康和可持续发展。
3. 有助于组织对**人工成本**的合理控制。

> 组织内外部环境不断变化，缺乏有效规划就只能**被动适应**环境变化——规划是组织**主动应对**环境变化的过程。

### 知识点 2　人力资源需求预测 ★★★

#### 一、内容

预测组织未来一段时期内到底需要**多少名员工**以及需要的是**哪些类型**的员工。**不考虑**组织内部现有的人力资源状况。

#### 二、四大影响因素（必背）

| # | 因素 | 典型情形 |
|:-:|---|---|
| 1 | **组织的战略定位和战略调整** | 进入一个新的业务领域、在原业务领域快速扩大经营规模 |
| 2 | **组织提供的产品和服务的变化情况** | 国家宏观政策调整、新法律法规出台、国际贸易环境变化、消费者偏好变化、竞争对手推出更好的替代产品和服务 |
| 3 | **组织的技术变革** | 生产自动化、新技术引进、人工智能使用 |
| 4 | **组织结构调整及流程再造** | 直线职能制→事业部制、流程再造、业务外包 |

#### 三、主要方法：定性 vs 定量（高频对比）

| 类别 | 方法 | 特点 |
|---|---|---|
| **定性**（主观判断） | **经验判断法**、**德尔菲法** | 适合中小型企业 |
| **定量**（统计学） | **比率分析法**、**趋势预测法**、**回归分析法** | 数据充分时预测更准确、更精确 |

**1. 经验判断法**

- 是**最简单**的人力资源需求预测方法。
- 让组织中**中高层管理人员**凭借过去积累的工作经验以及个人直觉，估计未来所需人力资源的数量和结构。
- 主要适用于**短期预测**，以及规模较小、或经营环境相对稳定、人员流动率不是很高的企业。
- 要求管理者必须具有**比较丰富的工作经验**。

**2. 德尔菲法**

- 又称**专家预测法**，20 世纪 40 年代末由美国**兰德公司**率先使用。
- 优点：
  1. 吸取和综合了**众多专家的意见**，避免个人预测的片面性；
  2. **不采用集体讨论**，**匿名进行**，使专家独立判断，避免**从众行为**，也避免专家必须一起开会的麻烦；
  3. 采取**多轮预测**方法，具有**较高的准确性**。
- 需要注意的问题：
  1. 专家人数不能太少，**至少要达到 20～30 人**；
  2. 专家的挑选要有**代表性**；
  3. 问题设计要合理，不要让专家一次回答过多问题；
  4. 向专家提供的资料和信息要相对**充分**。

> ⚠️ 德尔菲法的优点里**没有**"花费时间较短"——多轮预测反而费时。

**3. 比率分析法**

- 基于某种**关键的经营或管理指标**与组织人力资源需求量之间的**固定比率关系**来预测。
- 实际上是**假定人均生产率**不变。若技术进步等原因导致生产率提高或降低，预测结果就不能保证准确。

**4. 趋势预测法**

- 实际上是一种**简单的时间序列分析法**，根据组织**雇佣水平在最近若干年的总体变化趋势**预测未来需求数量。
- 特点：① 实用性比较强；② 比较粗糙，准确度打折扣；③ **假设组织的技术等因素不会发生大的变化**。

**5. 回归分析法**

- 一种**定量**预测技术。建立人力资源需求数量与影响因素之间的**函数关系**，代入影响因素的未来估计值计算需求量。
- 分**一元回归**和**多元回归**，**多元回归预测准确性高于一元回归**。
- 分**线性回归**和**非线性回归**，实践中经常采用**线性回归分析法**（非线性方程建立比较复杂）。

### 知识点 3　人力资源供给预测 ★★★

#### 一、内容与影响因素

预测组织在未来某一特定时期内**能够获得**的人力资源**数量、质量、结构**。

| 来源 | 内容 |
|---|---|
| **外部** | 地区性劳动力市场和全国性劳动力市场。来源包括各类学校的毕业生、失业人员、退役军人、其他组织中准备离职换工作的人，还可能包括获得相关政策支持的**外国人** |
| **内部** | 除人员数量和一般结构的统计分析外，更重要的是了解**现有人员的技能水平**，以及不久的将来因**退休、晋升、调动、自愿流动、解雇**等原因出现的变动。很重要的一点是建立**组织内部的员工技能数据库** |

> 供给预测**既受内部供给状况影响，也受外部劳动力市场供给情况影响**——"只需预测外部"是典型错误。

#### 二、两种主要方法（对比记忆）

| | 人员替换分析法 | 马尔科夫分析法 |
|---|---|---|
| **针对范围** | **具体职位**（某个或某些特定职位） | **多种职位以及人员流动** |
| **核心工具** | 确定能在未来承担该职位工作的**合格候选人** | **转移矩阵**（显示不同时间、不同职位类型员工所占比例或数量） |
| **作用** | 强调从**组织内部**选拔合适候选人担任更高一级职位；有利于**激励员工士气、降低招聘成本**，为未来职位填补提前准备候选人 | 描绘公司一段时间内人力资源供给变化趋势；若公司各种条件比较稳定，可用来**预测未来的人力资源供给状况**；可看出**职业发展通道**（如生产操作工→生产管理者→厂长助理） |
| **补充说明** | — | 供给的历史变化趋势并非总是可靠的未来指标，统计学预测方法同样需要**专家主观判断法**加以补充 |

::: warning 高频陷阱
- 马尔科夫分析法依据的是**企业过去的人员变动规律**（转移矩阵），不是外部经营环境变化、未来生产经营状况或离职率。
- 马尔科夫分析法**不能预测未来人员的需求**，只做供给预测。
- 人员替换分析法体现"企业内部职位晋升通道"的是**人员替换分析法**，不是马尔科夫分析法。
:::

## 第二节 人力资源供求平衡的基本对策与方法

### 知识点 1　人力资源供求平衡的基本对策 ★★★

#### 一、需求大于供给（缺人）

| # | 对策 | 适用/说明 |
|:-:|---|---|
| 1 | **延长现有员工的工作时间**（加班） | 需求是**短期性或阶段性**时首选 |
| 2 | 做好**招募**工作；聘用**已退休人员**、雇用**非全日制员工** | 需求增长是**长期性**时 |
| 3 | 采取各种措施**降低现有人员的流失率** | — |
| 4 | 改进生产技术、优化工作流程、加强员工培训，**提高工作效率** | 从而减少对人力资源**数量**的需求 |
| 5 | 将部分**非核心业务外包** | 减少组织对人力资源的需求 |

#### 二、需求小于供给（人多）

| # | 对策 | 说明 |
|:-:|---|---|
| 1 | **冻结雇用** | 不再从外部招聘，靠内部灵活调配满足当前需要，长期通过**自愿离职和退休自然减员** |
| 2 | **鼓励员工提前退休** | — |
| 3 | **缩短每名现有员工的工作时间**，采用**职位分享**或**工作分享** | 避免解雇员工 |
| 4 | **临时性解雇或永久性裁员** | — |
| 5 | 对**冗余人员**进行**培训** | — |

> **职位分享 vs 工作分享**：职位分享 = **两位或多位员工共同分担一个全日制职位**；工作分享 = **一组员工的工作时间都暂时性减少**。

#### 三、需求与供给结构不匹配

1. **加强对现有人员的培训开发**，使其能胜任当前尤其是未来的工作需要。
2. 现有人员胜任未来工作有困难时，通过**到期终止劳动合同、自然退休**等方式让一些员工离开，同时从**外部招聘**与需求匹配的新员工。
3. 组织仍处**扩张期**、人才需求不断增长时，可将**技能不足的老员工逐渐替换到辅助性岗位**，把重要生产、管理类岗位留给后来招聘的有能力的候选人。

::: warning 结构不匹配 ≠ 数量失衡
"5 个人干 3 个人的活，关键岗位又缺合适人选"= **人力资源结构性失衡**，即供求**数量大体平衡**但**结构不一致**。
:::

### 知识点 2　人力资源供求平衡的方法分析 ★★

#### 一、减少未来出现劳动力过剩的方法（必背表格）

| 方法 | 速度 | 员工受伤害的程度 |
|---|:-:|:-:|
| **裁员** | 快 | 高 |
| **降薪** | 快 | 高 |
| **降级** | 快 | 高 |
| 职位调动 | 快 | 中等 |
| 工作分享 | 快 | 中等 |
| 冻结雇用 | 慢 | 低 |
| 自然减员 | 慢 | 低 |
| 鼓励提前退休 | 慢 | 低 |
| 进行重新培训 | 慢 | 低 |

> 口诀：**"快而伤"三兄弟——裁员、降薪、降级**。

#### 二、避免未来出现劳动力短缺的方法（必背表格）

| 方法 | 速度 | 可撤回程度 |
|---|:-:|:-:|
| **加班加点** | 快 | 高 |
| **雇用临时工** | 快 | 高 |
| **业务外包** | 快 | 高 |
| 再培训后换岗 | 慢 | 高 |
| 降低流动率 | 慢 | 中等 |
| 从外部雇用新员工 | 慢 | 低 |
| 技术创新 | 慢 | 低 |

> 口诀：**"快而可撤"三件套——加班加点、雇用临时工、业务外包**。

#### 三、裁员

**1. 企业选择裁员的主要原因**

1. 劳动力成本在公司总成本中往往占很大一部分，会成为企业**最先着手**的地方。
2. 关闭过时落后的工厂，或在原有工厂引进新技术，导致人员需求减少。
3. 因经济原因**改变经营地点**，员工难以随之迁移。

**2. 实施裁员却没达到强化绩效预期效果的原因**

1. 管理不当的裁员可能产生**长期性负面作用**，导致人才流失，并破坏激发员工创造性和灵活性所必需的社会网络。
2. 放走的员工实际上可能是企业**根本无法替代**的重要资产。
3. **幸存员工**心存戒备，对未来晋升和职业前途不确定，工作积极性可能大幅下降，并随时准备另找工作。
4. 与裁员相联系的**负面公众印象**有损企业在劳动力市场上的形象，日后更难招募员工。

**3. 避免公司声誉受损的措施**

1. 为裁员的必要性提供**合理解释**，保证过程公平，对待被裁员工方式更人性化。
2. 避免不加选择地任意全面裁员，应采用**手术式的战略裁员**。

> ⚠️ 裁员**不必在企业亏损时才能采取**——不少企业在盈利时也裁员。裁员往往被视为经济衰退时扭转局势的方法，但对削减成本有立竿见影的效果，对长期绩效可能产生负面影响。

#### 四、提前退休计划

1. 老员工成本有时比新员工高（资历长、薪酬高、社会保险缴费额度高），当老员工工作经验的价值无法弥补其较高成本时，企业希望用成本更低的新员工替代。
2. 老员工通常占据薪酬水平最高的职位，有时会阻碍公司雇用新员工或阻碍其晋升。

#### 五、雇用临时员工或劳务派遣人员

**优点**

1. 使企业**免除很多管理任务以及财务负担**。
2. 一些没有能力制订甄选计划的小公司往往通过临时雇用或使用劳务派遣人员的方式来**甄选并最终雇用员工**。
3. 临时员工派遣出来前都会得到**培训**，既降低企业培训成本，又使相互适应更容易。
4. 临时员工在企业中工作经验非常少，对组织及工作程序存在的问题往往有**比较客观的看法**。
5. 可能在其它企业积累了丰富工作经验，有时能提供更多**解决问题的备选方案**。

**需要注意克服的不利之处**

1. 招用前必须确认原有正式员工已从**裁员阴影**中走出来，两项行动之间留出**相当长的缓冲时间**。
2. 正式员工可能产生**受到威胁**的心理反应，可雇用威胁性更低的临时员工，或对两类人的工作内容和职责划分加以区分；同时尽可能让全日制正式员工感到受重视。
3. 注意不能形成临时员工或劳务派遣人员**低人一等**的印象。

#### 六、业务外包及离岸经营

**1. 外包对人力资源管理的好处**

1. 适当控制和精减企业自身直接雇用的人员数量，把涉及人数较多、并不复杂的**日常事务性工作**外包后，人力资源管理可集中于更重要的**关键岗位和关键人才**，提升人力资源管理价值。
2. 人力资源管理业务本身也可部分外包，把人力资源部门**从日常事务中解放**，集中精力于**战略层面**问题。

**2. 离岸经营**

- 是一种**特殊的外包形式**，即将**工作岗位从一个国家转移到另一个国家**。
- 最初外包出去的岗位工作范围比较窄、内容比较简单（生产岗位、呼叫中心服务岗位等），**现在已经延伸到很多高技能的工作岗位**（证券分析、技术研发等）。

**3. 确保离岸经营取得成功的步骤**

1. 选择外包服务供应商时，通常是**规模越大、历史越长越好**。
2. **不要**对有专利权或需要严格安全保障措施的工作实行离岸经营；被外包的工作最好是**"模块化的"**。
3. 外包最好**先从小的工作入手**，同时**密切监督**完成情况，尤其在刚开始的时候。

#### 七、调整薪酬和工作时数

| 方法 | 做法 |
|---|---|
| **加班加点** | 面临劳动力短缺，但不愿增加新员工、也不愿增加临时员工或劳务派遣人员时，让现有员工每天工作更长时间 |
| **减少工作时间** | 让员工接受降薪，有时可避免裁员；或**保持单位时间薪酬水平不变**，减少全体员工工作时间以避免裁员，通常被称为**工作共享或职位共享**；员工之间还可**自觉转让工作时间**（经济较好的员工出让部分工作时间给经济条件较差的员工） |
| **非带薪休假或放假** | 经济不景气导致用工需求下降时，降低人工成本并避免解雇员工 |

## 易混点对比

### 1. 需求预测 vs 供给预测

| | 需求预测 | 供给预测 |
|---|---|---|
| **回答的问题** | 未来**需要多少、需要哪些类型**员工 | 未来**能够获得**多少数量、什么质量、什么结构 |
| **是否考虑现有人员** | **不考虑**组织内部现有状况 | **必须**考虑内部人员及技能水平 |
| **主要方法** | 经验判断法、德尔菲法、比率分析法、趋势预测法、回归分析法 | 人员替换分析法、马尔科夫分析法 |
| **核心影响因素** | 战略定位、产品服务、技术变革、组织结构调整及流程再造 | 外部劳动力市场 + 内部人员变动（退休/晋升/调动/流动/解雇） |

### 2. 需求预测的定性方法与定量方法

| | 定性（主观判断法） | 定量（统计学方法） |
|---|---|---|
| **包含方法** | 经验判断法、**德尔菲法** | **比率分析法**、趋势预测法、回归分析法 |
| **准确性** | 偏主观，适合中小型企业 | 数据充分时更准确、更精确 |
| **易错点** | 德尔菲法虽"专家"但仍是**定性/主观判断法** | 趋势预测法要求经营环境和技术稳定 |

### 3. 人员替换分析法 vs 马尔科夫分析法

| | 人员替换分析法 | 马尔科夫分析法 |
|---|---|---|
| **针对** | **具体职位** | **多种职位 + 人员流动** |
| **工具** | 合格候选人名单 | **转移矩阵** |
| **核心价值** | 内部晋升、激励士气、降低招聘成本 | 预测未来供给、显示职业发展通道 |
| **依据** | 候选人绩效与晋升潜力 | **过去的人员变动规律** |

### 4. 需求大于供给 vs 需求小于供给（对策）

| | 需求大于供给（缺人） | 需求小于供给（人多） |
|---|---|---|
| **工时** | **延长**工作时间（加班） | **缩短**工作时间（职位分享/工作分享） |
| **招聘** | 招募 + 聘用已退休人员 + 非全日制 | **冻结雇用** |
| **人员退出** | 降低流失率 | 鼓励提前退休、临时性解雇或永久性裁员 |
| **效率** | 提高工作效率、非核心业务外包 | 对冗余人员培训 |
| **多选陷阱** | — | "冻结雇用、鼓励提前退休"**不属于**需求大于供给的对策 |

### 5. 减少过剩 vs 避免短缺（速度与程度）

| 维度 | 减少劳动力过剩 | 避免劳动力短缺 |
|---|---|---|
| **衡量指标** | 速度 + **员工受伤害的程度** | 速度 + **可撤回程度** |
| **快 + 程度高** | 裁员、降薪、降级 | 加班加点、雇用临时工、业务外包 |
| **快 + 程度中** | 职位调动、工作分享 | — |
| **慢 + 程度高** | — | 再培训后换岗 |
| **慢 + 程度低** | 冻结雇用、自然减员、鼓励提前退休、重新培训 | 从外部雇用新员工、技术创新 |

### 6. 职位分享 vs 工作分享

| | 职位分享 | 工作分享 |
|---|---|---|
| **谁参与** | **两位或多位**员工 | **一组**员工 |
| **怎么分** | 共同分担**一个全日制职位** | 所有人的工作时间**都暂时性减少** |
| **共同点** | 都属于需求小于供给时缩短工作时间、避免裁员的办法 | 同左 |

### 7. 业务外包 vs 离岸经营

| | 业务外包 | 离岸经营 |
|---|---|---|
| **关系** | 一般概念 | 一种**特殊的外包形式** |
| **定义** | 把部分工作交给外部机构完成 | 将**工作岗位从一个国家转移到另一个国家** |
| **适用工作** | 日常事务性、非核心工作 | 最好是**"模块化"**的工作；不要选有专利权或需严格安全保障的工作 |
| **范围演变** | — | 从生产岗位、呼叫中心服务岗位，**已延伸到高技能岗位**（证券分析、技术研发） |
