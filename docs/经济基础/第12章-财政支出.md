## 二、知识点精讲

### 考点1 如何理解财政支出数据

**核心概念**：财政支出是**政府为履行职能，取得所需商品和劳务而进行的资金支付，是政府行为活动的成本**。

理解财政支出数据，看三个方面：

| 维度 | 看什么 |
|---|---|
| 财政支出规模 | 支出总量有多大（绝对数＋相对数） |
| 财政支出结构 | 钱花在了哪些方面 |
| 财政支出的经济性质 | 购买性支出与转移性支出各占多少 |

**逻辑链**：

```
政府要履行职能 → 需要取得商品和劳务 → 发生资金支付 = 财政支出（政府行为活动的成本）
                                        ↓ 看数据看三样
                          规模（有多大）＋结构（花在哪）＋经济性质（怎么花）
```

**速记口诀**：**"履职买货付钱财，就是财政支出口；规模结构加性质，三个维度看数据。"**

---

### 考点2 财政支出分类方法 ★★★

财政支出分类有两种基本方法。

**方法一：适用于编制政府预算的统计分类**

| 分类 | 依据 | 说明 |
|---|---|---|
| 支出功能分类 | 性质、职能范围 | 反映政府各项职能活动 |
| 支出经济分类 | 成本投入、具体用途 | 对政府支出活动**更为明细**的反映 |

国际货币基金组织（IMF）即按此两套分类：

| 功能分类 | 经济分类 |
|---|---|
| 一般公共服务 | 雇员补偿 |
| 国防 | 商品和服务的使用 |
| 公共秩序 | 固定资本消耗 |
| 经济事务 | 利息 |
| 环境保护 | 补贴 |
| 住房和社会服务 | 赠与 |
| 医疗保健 | 社会福利 |
| 娱乐、文化和宗教 | 其他支出 |
| 教育 | — |
| 社会保护 | — |

**方法二：根据交易的经济性质分类**

| 类别 | 含义 | 构成 |
|---|---|---|
| **购买性支出** | 政府为履行其职能**从私人部门取得物品和劳务**并支付相应资金发生的费用 | 政府消费性支出＋政府投资性支出 |
| **转移性支出** | 政府**扮演中介角色**，依法向受益对象拨付财政资金但并不要求获得相应的物品和劳务 | 社会保障支出＋财政补贴 |

**逻辑链**：

```
财政支出分类
├─ 按编制政府预算的统计分类
│    ├─ 支出功能分类：性质、职能范围
│    └─ 支出经济分类：成本投入、具体用途（更明细）
└─ 按交易的经济性质分类
     ├─ 购买性支出：一手交钱一手取货（消费性＋投资性）
     └─ 转移性支出：政府当中介只给钱（社保＋财政补贴）
```

**速记口诀**：**"预算分类两把尺：功能看职能、经济看用途；交易性质分两家：购买取货、转移给钱。"**

### 考点4 衡量财政支出规模的指标 ★

| 指标类型 | 内容 |
|---|---|
| 绝对规模指标 | 财政支出总额 |
| 相对规模指标（常用） | 用比重、人均值等表示 |

**三个常用相对指标**：

| 相对指标 | 反映什么 | 变化趋势 |
|---|---|---|
| 当年财政支出占当年国内生产总值的比重 | 反映**政府干预经济的程度** | 不断增长 |
| 当年中央财政支出占全国财政支出的比重 | 反映**中央对地方政府控制程度** | 相对稳定 |
| 人均财政支出 | 反映**人均享受公共服务水平** | 不断增长 |

**速记口诀**：**"支出占 GDP 看干预，中央占比看控制，人均支出看服务；两头递增中间稳。"**

### 考点5 财政支出规模变化的指标 ★★

| 指标 | 公式／含义 |
|---|---|
| 1. 财政支出增长率指标 | △G%＝△G/Gn-1＝(Gn－Gn-1)/Gn-1 |
| 2. 财政支出增长弹性系数 | 财政支出增长率 ÷ 国内生产总值增长率 |
| 3. 财政支出增长边际倾向 | 财政支出增长额 ÷ 国内生产总值增长额 |

**逻辑链**：

```
财政支出规模变化 → 三个观测口径
├─ 增长率：自己跟自己比（本期支出 vs 上期支出）
├─ 弹性系数："率"比"率"（支出增速 ÷ GDP增速）→ 大于1说明支出增长快于经济
└─ 边际倾向："量"比"量"（支出增量 ÷ GDP增量）
```

**速记口诀**：**"率率相比是弹性，量量相比是边际，自身环比是增长。"**

### 考点6 财政支出规模增长的理论解释 ★★★★★

| 理论 | 提出者／国家 | 核心观点 |
|---|---|---|
| **瓦格纳法则**（"政府活动扩张法则"） | 德国 瓦格纳（19世纪80年代） | 工业化→市场活动增加→政府参与→财政支出增加；经济增长→文化、教育福利增加→政府支出增加 |
| **皮考克和魏斯曼"梯度渐进增长理论"** | 英国（对1890—1955年英国公共支出研究，20世纪60年代提出） | 正常年份随税收增长逐渐上升；突变时急剧上升；突变后下降但**不会低于原有水平**。内在原因＝公众所容忍的税收水平；外在原因＝社会突变（战争、危机、自然灾害） |
| **马斯格雷夫"经济发展阶段增长理论"** | 美国 马斯格雷夫 | 财政支出变化随不同时期财政支出作用不同而变化：**初期阶段、中期阶段、成熟阶段** |
| **鲍莫尔"非均衡增长理论"** | 美国 鲍莫尔 | 通过分析**公共部门**平均劳动生产率状况解释财政支出增长：进步部门（技术起决定作用）vs 非进步部门（劳动） |
| **公共选择学派** | 选民、政治家、官僚和民主制度 | 财政幻觉；政治家为选票扩大支出；官僚机构预算最大化；公共利益很难界定 |

**公共选择学派四视角逻辑链**：

```
选民     → 财政幻觉：只关心扩大公共支出给自己的好处，忽视税收负担同时增加
政治家   → 为争取选票，以更大的财政支出作为争取选民的手段
官僚机构 → 预算最大化，以最大化部门的权力和利益
民主制度 → 公共利益很难界定，选民往往各有其利益要求
```

**速记口诀**：**"瓦格纳扩张、皮魏梯度、马氏阶段、鲍莫尔非均衡；公共选择四主体：选民幻觉、政客拉票、官僚扩编、民主难界定。"**

### 考点8 政府财政支出效益分析与微观经济组织生产经营支出效益分析的区别 ★

| 区别 | 素材表述（以微观经济组织为参照） |
|---|---|
| 计算所得费用与所得范围不同 | 微观经济组织只计算其自身投入的各项费用和自身实际所得 |
| 衡量效益的标准不同 | 微观经济组织效益分析的标准十分明确、易于把握，就是单纯的经济效益 |
| 择优标准不同 | 对支出活动进行效益分析的目的，就是要通过效益比较选择最优方案 |

**速记口诀**：**"算钱范围、效益标准、择优标准，三处不同。"**

### 考点9 财政支出效益分析方法 ★★★★

**四种方法总览**：

| 方法 | 核心做法 | 适用 |
|---|---|---|
| **成本—效益分析法** | 根据国家确定的建设目标提出若干方案，计算成本—效益比率分析比较，选最优方案 | **适合投资性支出** |
| **最低费用选择法** | 只计算备选方案的**有形成本**，不用货币计算社会效益，以成本最低择优 | **军事、行政、文化、卫生**等支出项目 |
| **公共劳务收费法** | 通过制定合理的价格与收费标准，使公共劳务的使用达到提高财政支出效益的目的 | 国防建设、道路建设与维护、城市供水与排水等公共劳务 |
| **公共定价法** | 政府相关管理部门通过一定程序和规则制定提供公共物品的价格和收费标准 | 自然垄断行业（电力、燃气、自来水、电信等） |

**成本—效益分析法要点**：
- 概念首次出现在19世纪；1940年美国经济学家**尼古拉斯·卡尔德和约翰·希克斯**提炼前人理论，形成其理论基础，此后开始渗透到政府活动中。
- 需考虑三对（及更多）成本效益：**实际成本与效益/金融成本与收益；直接成本与效益/间接成本与效益；有形成本与效益/无形成本与效益**。此外还有内部与外部、中间与最终成本效益等分类。

**最低费用选择法要点**：
- 操作步骤与成本—效益分析法大体相同，但**不要求计算支出的无形成本与效益**，运用更简单。
- 三步：①政府规定目标不变下提出多种备选方案 → ②分别计算各备选方案的有形费用（涉及垄断价格用**影子价格**消除不合理价格因素；多年投资项目用**贴现法**换算费用流现值，保证可比性）→ ③按费用高低顺序排列供决策者选择。

**公共劳务收费法四种定价政策**：

| 政策 | 依据 | 典型例子 |
|---|---|---|
| **免费政策** | 民族整体利益、普遍使用，讲社会效益 | 义务教育、注射疫苗 |
| **低价政策** | 国家总体利益，免费又造成资源浪费的公共劳务 | 医疗保障 |
| **平价政策** | 无须特别鼓励使用，也不必加以限制；可弥补公共劳务的人力、物力消耗 | 公园、邮电、公路、铁路 |
| **高价政策** | 从全社会利益看必须限制使用的公共劳务 | 繁华地段机动车停车费 |

**公共定价法三种方法**：

| 方法 | 要点 |
|---|---|
| **平均成本定价法** | 在保持企业收支平衡下尽可能使经济福利最大化。理论上按**边际成本**定价最理想，但会使企业长期亏损、靠财政补贴运行；故成本递减行业按**高于边际成本的平均成本**定价（需求曲线与平均成本曲线交点定价），既不让企业亏损，又限制超额利润，亏盈相抵、收支平衡 |
| **二部定价法** | 构成：①与使用量无关的按月/按年支付的"**基本费**"；②按使用量支付的"**从量费**"。是定额定价与从量定价相结合。适用于几乎所有受管制行业（电力、燃气、自来水、电信等自然垄断行业）。问题：不付基本费即被拒之门外，消费量低于效率产量；基本费相当于对所有使用者开征等额税，不符合公平原则 |
| **负荷定价法** | 对不同时段或时期的需求制定不同价格。高峰需求缺乏弹性定高价，低谷需求弹性充足定低价，以平衡需求 |

**逻辑链**：

```
财政支出效益分析四法
├─ 成本—效益分析法：算比率选优 → 投资性支出（实际/金融、直接/间接、有形/无形）
├─ 最低费用选择法：只算有形成本 → 军事、行政、文化、卫生（影子价格、贴现法）
├─ 公共劳务收费法：定价格标准 → 免费/低价/平价/高价四种政策
└─ 公共定价法：定公共物品价格 → 平均成本＋二部＋负荷
```

**速记口诀**：**"投资成本效益算，军文最低费用选；公共劳务四价政（免低平价高），公共定价三法全（平均二部加负荷）。"**

### 考点10 政府消费性支出 ★★

**含义**：政府部门为全社会提供的公共服务的消费支出，和免费或以较低价格向居民住户提供的商品和服务的净支出。
- 前者＝政府服务的产出价值－政府单位所获得的经营收入的价值；其中政府服务的产出价值＝经营性业务支出＋固定资产折旧
- 后者＝免费或低价提供的商品和服务的市场价值－向居民住户收取的报酬

**地位**：社会总消费构成社会总需求的一部分，政府消费又构成社会总消费的一部分，所以**政府消费性支出构成社会总需求的组成部分**。

**具体包括**：行政管理费支出、国防支出、教育支出、科学技术支出、卫生健康支出。

**速记口诀**：**"行政、国防、教育、科技、卫生，五项消费进总需求。"**

---

### 考点11 政府投资性支出 ★★★★

**含义**：也称**财政投资或公共投资**，是以政府为主体，将其从社会产品或国民收入中筹集起来的财政资金用于国民经济各部门的一种**集中性、政策性投资**，是财政支出的重要组成部分。

**三大特征**：非营利性、长期性、外部性。

**速记口诀**：**"投资三特点：非营利、长期性、外部性；'增长性'不算数。"**

---

### 考点12 社会保障支出 ★★

**转移性支出含义**：政府单方面将资金无偿地支付出去，而没有相应的商品和劳务流入政府手中的支出，体现为资金从政府手中转移到他人手中的收入再分配活动。**转移性支出主要由社会保障支出和财政补贴构成**。

**社会保障支出含义**：国家向丧失劳动能力、失去就业机会以及遇到其他事故而面临经济困难的公民提供的基本生活保障支出。

| 内容 | 要点 |
|---|---|
| **社会保险** | 国家通过立法，按照**权利与义务相对应原则**，多渠道筹集资金，对参保者遭遇年老、疾病、工伤、失业、生育等风险时提供物质帮助（含现金补贴和服务）。目的：①防止个人在现在与将来安排上因选择不当造成贫困（如退休养老）；②防范某些不可预见的风险（如事故、疾病）；③减少市场经济不确定性产生的风险和困难（如失业） |
| **社会救助** | 通过国家财政拨款，保障生活确有困难的贫困者和遭受不可抗拒的自然风险（如自然灾害）的不幸者**最低限度**的生活需要。主要包括贫困救助、灾害救助和特殊救助等 |
| **社会福利** | 国家和社会通过各种福利事业、福利设施、福利服务为社会成员提供基本生活保障并使其基本生活状况**不断改善**的社会政策和制度的总称，资金大部分来源于国家预算拨款 |
| **社会优抚** | 国家按规定对法定优抚对象（现役军人及其家属、退役军人、烈士遗属等）提供保证其一定生活水平所需的资助和服务 |

**速记口诀**：**"社保四块：保险立法、救助兜底、福利改善、优抚军人；立法＋权利义务对应是社会保险的关键词。"**

---

### 考点13 财政补贴 ★★

**含义**：国家为了实现特定的政治、经济和社会目标，将一部分财政资金**无偿补助**给企业和居民的一种再分配形式。

**五种分类维度**：

| 分类依据 | 类别 |
|---|---|
| 按财政补贴的项目和形式 | 价格补贴、企业亏损补贴、外贸补贴、房租补贴、职工生活补贴、财政贴息等 |
| 按财政补贴的环节 | 生产环节、流通环节、分配环节、消费环节补贴 |
| 按财政补贴的经济性质 | 生产补贴、生活补贴 |
| 按财政补贴的内容 | 现金补贴、实物补贴 |
| 按WTO分类方法（按对国际贸易可能造成的危害程度） | 禁止性补贴、可诉补贴、不可诉补贴 |

**速记口诀**：**"补贴五把尺：项目形式、环节、性质、内容、WTO。"**

---

### 考点14 购买性支出与转移性支出功能比较 ★★

| 比较维度 | 购买性支出 | 转移性支出 |
|---|---|---|
| **构成** | 消费性支出（行政、国防、教育、科技、卫生）＋投资性支出（非营利、长期性、外部性） | 社会保障性支出＋财政补贴性支出 |
| **特点** | 有偿性、等价性 | 无偿性、非等价性 |
| **对生产与就业影响** | **直接**刺激社会生产规模扩大 | **只发生间接**的影响作用 |
| **对政府支出效益约束强度** | 较强 | 较弱 |
| **体现财政职能** | 在财政支出总额中占比重大 → 财政具有较强的**资源配置**职能 | 在财政支出总额中占比重大 → 财政具有较强的**收入分配**职能 |

**逻辑链**：

```
交易时是否"一手交钱、一手取货"？
├─ 是（等价交换，取得物品与劳务）→ 购买性支出
│    → 直接刺激生产就业、效益约束强、体现资源配置职能
└─ 否（单方面无偿拨付）→ 转移性支出
     → 间接影响生产就业、效益约束弱、体现收入分配职能
```

**速记口诀**：**"购买有偿又等价，直接强约束配资源；转移无偿非等价，间接弱约束分收入。"**

## 四、公式与计算

### 4.1 三个核心公式

| 公式 | 表达式 | 记忆点 |
|---|---|---|
| 财政支出增长率 | △G%＝△G/Gn-1＝(Gn－Gn-1)/Gn-1 | 自身环比 |
| 财政支出增长弹性系数 | 财政支出增长率 ÷ 国内生产总值增长率 | 率率相比 |
| 财政支出增长边际倾向 | 财政支出增长额 ÷ 国内生产总值增长额 | 量量相比 |

### 4.2 真题演算（数据来自素材）

**演算一（弹性系数）**：2020 年 GDP 101.6 万亿元、一般公共预算支出 24.55 万亿元；2021 年 GDP 114.2 万亿元、一般公共预算支出 24.63 万亿元。

```
财政支出增长率 =（24.63－24.55）÷ 24.55 = 0.326%
GDP增长率    =（114.2－101.6）÷ 101.6 = 12.4%
弹性系数      = 0.326% ÷ 12.4% ≈ 0.026
```

**演算二（边际倾向，2022 真题数据）**：2020 年 GDP 101.6 万亿元、一般公共预算支出 24.55 万亿元；2021 年 GDP 114.33 万亿元、一般公共预算支出 24.63 万亿元。

```
财政支出增长额 = 24.63－24.55 = 0.08 万亿元
GDP增长额     = 114.33－101.6 = 12.73 万亿元
边际倾向       = 0.08 ÷ 12.73 ≈ 0.006
```

> 提示：两道题共用一组素材数据，区别只在 GDP 取 114.2 还是 114.33，以及问的是"弹性系数"还是"边际倾向"——**先看问法再选公式**。

### 4.3 关键机制与适用条件

**（1）财政支出增长五大理论的核心机制**

| 理论 | 机制关键词 |
|---|---|
| 瓦格纳法则 | 工业化、市场活动增加 → 政府活动扩张；经济增长 → 科教文卫福利支出增加 |
| 梯度渐进增长理论 | 内在原因＝公众可容忍的税收水平；外在原因＝突变；正常年份随税收渐升，突变后阶梯式跃升且不回落至原水平 |
| 经济发展阶段增长理论 | 初期、中期、成熟阶段，各阶段财政支出作用不同 |
| 非均衡增长理论 | 进步部门（技术，生产率提高快）vs 非进步部门（劳动，生产率提高慢）→ 公共部门平均劳动生产率状况解释支出增长 |
| 公共选择学派 | 财政幻觉、政治家拉票、官僚预算最大化、公共利益难界定 |

**（2）效益分析方法的适用条件**

| 方法 | 适用条件 |
|---|---|
| 成本—效益分析法 | 适合投资性支出；需考虑实际/金融、直接/间接、有形/无形等成本效益 |
| 最低费用选择法 | 军事、行政、文化、卫生等；只算有形成本；可用影子价格、贴现法处理 |
| 公共劳务收费法 | 能制定价格与收费标准的公共劳务；四价政按公共物品性质选择 |
| 公共定价法 | 自然垄断行业；平均成本（收支平衡＋福利最大）、二部（基本费＋从量费）、负荷（峰谷差价） |

## 五、高频考点速记卡

1. **Q：财政支出的定义？**
   A：政府为履行职能，取得所需商品和劳务而进行的资金支付，是政府行为活动的成本。

2. **Q：理解财政支出数据的三个方面？**
   A：财政支出规模、财政支出结构、财政支出的经济性质。

3. **Q：按交易的经济性质，财政支出分哪两类？**
   A：购买性支出（消费性支出＋投资性支出）和转移性支出（社会保障支出＋财政补贴）。

4. **Q：中国支出功能分类科目设哪三级？**
   A：类、款、项三级（无"目"、无"属"）。

5. **Q：支出分类改革的具体科目设计目标？**
   A：体系完善，反映全面，分类明细，口径可比，便于操作。

6. **Q：反映政府干预经济程度的指标？**
   A：当年财政支出占当年国内生产总值的比重。

7. **Q：哪个相对规模指标"相对稳定"？**
   A：中央财政支出占全国财政支出的比重（反映中央对地方政府控制程度）。

8. **Q：财政支出增长弹性系数怎么算？**
   A：财政支出增长率 ÷ 国内生产总值增长率（率率相比）。

9. **Q：财政支出增长边际倾向怎么算？**
   A：财政支出增长额 ÷ 国内生产总值增长额（量量相比）。

10. **Q："政府活动扩张法则"是谁提出的？**
    A：德国经济学家瓦格纳（瓦格纳法则）。

11. **Q：梯度渐进增长理论的内在原因和外在原因？**
    A：内在原因是公众所容忍的税收水平；外在原因是社会突变。突变结束后支出下降但不低于原有水平。

12. **Q：经济发展阶段增长理论的提出者？三阶段？**
    A：美国经济学家马斯格雷夫；初期阶段、中期阶段、成熟阶段。

13. **Q：非均衡增长理论的分析对象和部门划分？**
    A：分析公共部门平均劳动生产率状况；分进步部门（技术起决定作用）和非进步部门（劳动）。

14. **Q：公共选择学派理解政府支出规模的四个视角？**
    A：选民、政治家、官僚行为、民主制度；核心现象是"财政幻觉"。

15. **Q：衡量财政支出效益的四种方法？**
    A：成本—效益分析法、最低费用选择法、公共劳务收费法、公共定价法。

16. **Q：公共劳务收费法的四种定价政策及例子？**
    A：免费（义务教育、注射疫苗）、低价（医疗保障）、平价（公园、邮电、公路、铁路）、高价（繁华地段机动车停车费）。

17. **Q：公共定价法包括哪三种？**
    A：平均成本定价法、二部定价法、负荷定价法。

18. **Q：政府消费性支出包括哪些？**
    A：行政管理费支出、国防支出、教育支出、科学技术支出、卫生健康支出。

19. **Q：政府投资性支出的三大特征？**
    A：非营利性、长期性、外部性。

20. **Q：社会保障支出的四个内容？**
    A：社会保险、社会救助、社会福利、社会优抚。

## 六、典型真题（含解析）

> 素材中带年份标签的真题共 9 道，全部收录如下；无年份标签的教材例题 16 道编入本节末尾"例题选编"，便于对照巩固。

### （一）带年份标签真题（9 道）

**【2022·单选】** 2020 年国内生产总值 101.6 万亿元，一般公共预算收入 18.29 万亿元，一般公共预算支出 24.55 万亿元。2021 年国内生产总值 114.33 万亿元，一般公共预算收入 20.25 万亿元，一般公共预算支出 24.63 万亿元，2021 年一般公共支出增长边际倾向为（　）。
A. 0.006　B. 0.080　C. 0.026　D. 0.041

**答案：A**
**解析**：财政支出增长的边际倾向表明财政支出增长额与国内生产总值增长额之间的关系。一般公共支出增长边际倾向＝(24.63－24.55)/(114.33－101.6)＝0.08/12.73≈0.006。注意与"弹性系数"区分：弹性系数＝率率相比＝0.026（选项 C）。

**【2022·单选】** 下列属于"梯度渐进增长理论"的观点的是（　）。
A. 伴随着工业化进程，社会和经济的发展增加了对政府活动的需求
B. 突变期结束后，公共支出水平虽然会有所下降，但不会低于原有水平
C. 财政支出数量的变化，是随着不同时期财政支出作用的变化而变化
D. 生产率偏低的政府部门必然越来越大，政府部门的支出必然会快速增长

**答案：B**
**解析**：梯度渐进增长理论由英国经济学家皮考克和魏斯曼在 20 世纪 60 年代提出，认为英国的公共支出增长是"阶梯式的""非连续的"：（1）公共支出水平在正常年份表现出随着税收收入的增长而逐渐上升的趋势；（2）当社会经历战争、危机或自然灾害等突变时，公共支出会急剧上升；（3）突变期结束后，公共支出水平虽然会有所下降，但不会低于原有水平。增长原因上，内在原因讲税收，公众可容忍税收水平的提高是公共支出增长的内在原因；外在原因讲突变，社会经济发展出现突变是公共支出增长的外在原因。选项 A 是瓦格纳法则的观点，C 是马斯格雷夫经济发展阶段增长理论的观点，D 是鲍莫尔非均衡增长理论的观点。

**【2019·单选】** 在解释财政支出增长时，经济发展阶段增长理论的提出者是（　）。
A. 英国经济学家亚当·斯密　B. 德国经济学家瓦格纳
C. 法国经济学家李嘉图　D. 美国经济学家马斯格雷夫

**答案：D**
**解析**：解释财政支出增长时，经济发展阶段增长理论的提出者是美国经济学家马斯格雷夫。瓦格纳（德国）提出"政府活动扩张法则"，亚当·斯密、李嘉图与本题五理论无关。

**【2023补·多选】** 衡量财政支出效益的方法有（　）。
A. 公共劳务收费法　B. 最低费用选择法　C. 成本—效益分析法　D. 公共定价法　E. 净现值法

**答案：ABCD**
**解析**：衡量财政支出效益的方法主要有成本—效益分析法、最低费用分析法（选择法）、公共劳务收费法和公共定价法。净现值法不在其中。

**【2022·多选】** 公共定价法主要包括（　）。
A. 公共劳务收费法　B. 平均成本定价法　C. 最低费用选择法　D. 二部定价法　E. 负荷定价法

**答案：BDE**
**解析**：公共定价法主要包括平均成本定价法、二部定价法和负荷定价法。公共劳务收费法、最低费用选择法是与公共定价法并列的效益分析方法，不是公共定价法的子类。

**【2022·多选】** 属于政府消费性支出（　）。
A. 行政管理支出（素材原文作"行政经济支出"）　B. 国防支出　C. 教育支出　D. 科学技术支出　E. 社会保障支出

**答案：ABCD**
**解析**：在国家财政支出项目中，属于政府消费性支出的有行政管理支出、国防支出、教育支出、科学技术支出、卫生健康支出等。E 社会保障支出属于转移性支出，不属于政府消费性支出。

**【2022·单选】** 政府投资性支出的特点不包括（　）。
A. 增长性　B. 非营利性　C. 长期性　D. 外部性

**答案：A**
**解析**：政府投资性支出具有非营利性、长期性、外部性三个特点，不包括增长性。

**【2023补·单选】** 关于购买性支出与转移性支出的说法正确的是（　）。
A. 转移性支出对社会生产与就业产生影响
B. 购买性支出可直接改变社会财富的结构
C. 转移性支出时政府效益约束相对较强
D. 购买性支出遵循市场的等价交换原则

**答案：D**
**解析**：购买性支出遵循市场的等价交换原则，对政府具有较强的效益约束；转移性支出对政府的效益约束则相对较弱。转移性支出通过增加一部分居民、企业、团体的收入，可以直接改变社会财富的分配结构和国民收入分配比例，从而有效缓解社会收入分配的不均衡状况，支持经济效益低而社会效益大的产业发展。政府购买性支出对社会生产与就业有着直接而重要的影响；转移性支出对社会生产与就业产生间接的影响。故 A 应为"间接影响"，B 是转移性支出的功能，C 应为"较弱"。

**【2022·多选】** 社会保障支出主要包括（　）。
A. 社会保险　B. 社会救助　C. 社会福利　D. 社会优抚　E. 财政补贴

**答案：ABCD**
**解析**：社会保障支出主要包括社会保险、社会救助、社会福利、社会优抚四个方面。财政补贴与社会保障支出并列，同属转移性支出的主要内容。

### （二）例题选编（无年份标签，16 道）

1. **【单选】** 政府为履行职能，取得所需商品和劳务而进行的资金支付，是（　）。A. 财政收入　B. 财政支出　C. 政府预算　D. 财政政策
   **答案：B**。财政支出是政府行为活动的成本。

2. **【单选】** 《政府收支分类科目》中一般公共预算支出功能分类不包括（　）。A. 外交支出　B. 城乡社区支出　C. 粮油物资储备支出（素材作"物质"，已修正）　D. 社会保障补助支出
   **答案：D**。功能分类科目为类、款、项三级，列表中设"社会保障和就业支出"，无"社会保障补助支出"。

3. **【单选】** 政府仅扮演中间角色，未与私人部门发生直接经济交易的政府支出是（　）。A. 转移性支出　B. 消费性支出　C. 投资性支出　D. 购买性支出
   **答案：A**。购买性支出中政府与私人部门发生经济交换并实际参与社会资源配置；转移性支出中政府仅扮演中介者角色，依法向受益对象拨付财政资金但不要求获得物品与劳务。

4. **【多选】** 我国政府支出功能分类科目设有（　）。A. 目　B. 款　C. 属　D. 类　E. 项
   **答案：BDE**。支出功能分类科目设类、款、项三级。

5. **【单选】** 反映政府干预经济程度的指标是（　）。A. 财政收入征管效率　B. 财政支出绩效水平　C. 中央财政支出占全国财政支出的比重　D. 财政支出占国内生产总值的比重
   **答案：D**。财政支出规模指财政支出总额占 GDP 的比重，反映政府实际上参与社会经济生活的程度，有助于了解政府支配了多少社会资源。

6. **【单选】** 某国 2020 年 GDP 101.6 万亿元、一般公共预算支出 24.55 万亿元；2021 年 GDP 114.2 万亿元、一般公共预算支出 24.63 万亿元，则 2021 年一般公共支出增长的弹性系数是（　）。A. 0.006　B. 0.080　C. 0.026　D. 0.041
   **答案：C**。弹性系数＝财政支出增长率/GDP 增长率＝[(24.63－24.55)/24.55]÷[(114.2－101.6)/101.6]＝0.326%÷12.4%≈0.026。

7. **【单选】** "政府活动扩张法则"的提出者是（　）。A. 马斯格雷夫　B. 瓦格纳　C. 皮考克　D. 鲍莫尔
   **答案：B**。

8. **【单选】** 公共选择学派认为，选民在进行财政事务决策时，更关心扩大公共支出能给自己带来的好处，而忽视税收负担也可能同时增加，这种现象称为（　）。A. 财政幻觉　B. 预算幻觉　C. 超额负担　D. 超额支出
   **答案：A**。

9. **【单选】** 根据皮考克和魏斯曼的"梯度渐进增长理论"，在正常年份财政支出的最高限度是（　）。A. 社会财富总量　B. 财政支出需要　C. 公众可以容忍的税收负担　D. 政府举借债务规模
   **答案：C**。

10. **【多选】** 公共选择学派分别从（　）的特征等方面，提出了理解政府支出规模的新视角。A. 选民　B. 政治家　C. 官僚行为　D. 民主制度　E. 政府机关的效率
    **答案：ABCD**。

11. **【多选】** 关于非均衡增长理论的说法，正确的有（　）。A. 部门的差异来自技术和劳动发挥的作用不同　B. 通过分析私人部门平均劳动生产率的状况得出　C. 非均衡增长理论是由英国经济学家鲍莫尔提出的　D. 将国民经济部门区分为生产率不断提高与生产率提高缓慢两大类别　E. 在生产率不断提高的部门，技术起着决定作用
    **答案：ADE**。鲍莫尔是美国经济学家，C 错误；非均衡增长理论是通过分析公共部门平均劳动生产率状况，对公共财政支出增长原因作出解释，B 错误。

12. **【多选】** 下列项目中，适宜用最低费用选择法衡量效益的是（　）。A. 军事设施　B. 铁路设施　C. 文化设施　D. 卫生设施　E. 义务教育
    **答案：ACD**。最低费用选择法主要适用于军事、行政、文化、卫生等支出项目。

13. **【单选】** 关于"公共劳务"收费法的说法正确的是（　）。A. 通过制定合理的价格与收费标准，来达到对"公共劳务"有效地节约地使用　B. 是对财政支出备选方案的选择　C. 有免费和高价二种定价方式　D. 与成本—效益分析法以及最低费用选择法没有区别
    **答案：A**。公共劳务收费法有免费、低价、平价、高价四种定价政策，与成本—效益分析法、最低费用选择法是不同的方法。

14. **【多选】** 公共劳务收费法在对公共物品定价时的政策方法有（　）。A. 平价政策　B. 低价政策　C. 免费政策　D. 高价政策　E. 平均成本定价法
    **答案：ABCD**。平均成本定价法属公共定价法。

15. **【单选】** 下列关于购买性支出的说法中，正确的是（　）。A. 购买性支出是指政府为了履行其职能，从私人部门或公共部门取得物品与劳务并支付相应资金而发生的费用　B. 购买性支出直接表现为政府购买商品和服务的活动　C. 购买性支出包括政府消费性支出，不包括政府用于各种公共投资的支出　D. 购买性体现政府作为经济主体参与市场性经济活动，反映了政府在收入分配方面的作用
    **答案：B**。购买性支出是从**私人部门**取得物品与劳务；包括政府消费性支出和政府投资性支出两部分；发生购买性支出过程中政府进行等价交换，体现政府在**配置资源**方面的作用。

16. **【多选】** 关于购买性支出与转移性支出功能的说法，正确的是（　）。A. 购买性支出对政府具有较强的效益约束　B. 转移性支出对社会生产与就业只能发生间接的影响作用　C. 转移性支出对政府的效益约束较强　D. 购买性支出反映了政府在配置资源方面的作用　E. 购买性支出对社会生产与就业有着直接而重要的影响
    **答案：ABDE**。转移性支出对政府的效益约束相对较弱，C 错误。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"规模、结构、经济性质"理解成财政支出的分类方法 | 前两者是**看数据的三个视角**；分类方法是功能/经济分类与交易性质分类两条线 |
| 2 | 混淆支出功能分类与支出经济分类 | 功能看"干什么"（性质、职能范围），经济看"花在哪"（成本投入、具体用途，更明细） |
| 3 | 以为功能分类科目有"目"级或"属"级 | 只有**类、款、项**三级；"社会保障补助支出"不属于功能分类科目 |
| 4 | 把"文化体育与传媒支出"与"文化旅游体育与传媒支出"当两个科目 | 是同一科目的简写/全称之别，以真题解析的"文化旅游体育与传媒支出"为准 |
| 5 | 把三个相对规模指标的反映内容记串 | 干预程度→支出/GDP；中央控制→中央占比；服务水平→人均支出 |
| 6 | 认为中央财政支出占比"不断增长" | **相对稳定**；不断增长的是支出占 GDP 比重和人均财政支出 |
| 7 | 弹性系数与边际倾向公式混用 | 弹性＝率率相比；边际＝量量相比；先看题目问哪个 |
| 8 | 五大理论的提出者与国家记混 | 瓦格纳（德）、皮考克和魏斯曼（英）、马斯格雷夫（美）、鲍莫尔（美）、公共选择学派（四主体） |
| 9 | 认为梯度渐进理论中突变后支出回到原来水平 | 阶梯式跃升，**下降但不低于原有水平** |
| 10 | 认为鲍莫尔分析的是私人部门劳动生产率 | 分析**公共部门**平均劳动生产率；且鲍莫尔是**美国**经济学家 |
| 11 | 把"公共劳务收费法"算进公共定价法 | 公共定价法＝平均成本＋二部＋负荷；公共劳务收费法是**并列的第四种方法** |
| 12 | 认为最低费用选择法要算无形成本与效益 | 只算**有形成本**，社会效益不用货币计算 |
| 13 | 认为平均成本定价就是边际成本定价 | 边际成本定价最理想但致亏损；实际按**高于边际成本的平均成本**定价（交点定价） |
| 14 | 把"二部定价法"的基本费和从量费搞反 | 基本费与使用量**无关**（按月/年定额），从量费按使用量收 |
| 15 | 把社会保障支出归入政府消费性支出 | 社保是**转移性支出**的主要内容；消费性支出是行政、国防、教育、科技、卫生五项 |
| 16 | 政府投资性支出特点多选"增长性" | 三特点：**非营利性、长期性、外部性**，增长性是干扰项 |
| 17 | 认为购买性支出体现收入分配职能 | 购买性→**资源配置**职能；转移性→收入分配职能 |
| 18 | 认为财政补贴五分类中的"生产补贴、生活补贴"是按环节分 | 生产/生活补贴按**经济性质**分；按环节是生产、流通、分配、消费四环节 |
