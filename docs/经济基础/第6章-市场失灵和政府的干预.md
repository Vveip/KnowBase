# 第6章 市场失灵和政府的干预

> **本章考情**：理解型＋记忆型兼具的章节。全章一条主线：帕累托最优是"效率标尺"→ 四条件不满足就市场失灵 → 失灵四大原因（垄断、外部性、公共物品、信息不对称）→ 政府按症下药。三组最高频辨析点：公共物品的**非竞争性/非排他性**、外部性的**正外部性/负外部性**、信息不对称的**逆向选择/道德风险**。本章真题密度极高（单选、多选均大量出现），务必精讲＋刷题并重。

## 二、知识点精讲

### 考点1 帕累托最优状态 ★★★★★

**（1）核心定义（两种等价表述）**

- 一种资源的任何重新分配，已经**不可能**实现在**不使**一个人福利减少的情况下，使任何一个人的福利增加。
- 如果资源在某种配置下，**不可能**由重新组合生产和分配来使一个人或多个人的福利增加，**而不使**其他任何人的福利减少。

**（2）帕累托改进**

如果资源的重新分配能够在**不使任何人情况变坏**的前提下，使得**至少一个人变得更好**，则这种改进被称为帕累托改进。

**（3）两者关系（必背一句话）**

> **满足帕累托最优状态，就是不存在帕累托改进的资源配置状态。**

**（4）三个别称／等价说法**

| 表述 | 含义 |
|---|---|
| 帕累托最优状态 | 又被称作**经济效率**；满足即具有经济效率，不满足即缺乏经济效率 |
| 一般均衡状态（瓦尔拉斯均衡状态） | 市场达到均衡，供求相等，不存在过剩，也不存在短缺；此时也是资源最优配置状态 |
| 资源最优配置 | 经济处于一般均衡／瓦尔拉斯均衡状态时，资源实现最优配置 |

**（5）帕累托最优的实现条件（"三个完全＋无外部性"）**

1. 经济主体是**完全理性**的
2. 信息是**完全**的
3. 市场是**完全竞争**的
4. 经济主体行为**不存在外部影响**

这些条件不具备，资源最优配置或帕累托最优状态通常不能得到实现。

**（6）做题技巧（讲义原话）**：**双重否定选最优，一个否定选改进**。

**逻辑链**：

```
完全理性 + 完全信息 + 完全竞争 + 无外部影响
        ↓ 四条件同时成立
帕累托最优状态（＝经济效率＝一般均衡／瓦尔拉斯均衡＝资源最优配置）
        ↓ 判定标准
不存在帕累托改进
        ↓ 若还存在帕累托改进（不使任何人变坏、至少一人变好）
尚未实现最优配置 → 缺乏经济效率 →（四条件不满足时）市场失灵
```

**速记口诀**：**"三完全一无，最优无改进；双重否定选最优，一个否定选改进。"**

---

### 考点2 市场失灵的含义 ★

**定义**：由于市场机制**不能充分地发挥作用**而导致的**资源配置缺乏效率或资源配置失当**的情况。

**推导逻辑**：在一个经济社会中，整个经济实现一般均衡、资源配置达到帕累托最优状态是**有条件的**。一旦"三个完全、无外部性"的条件不成立（如存在垄断、信息不对称），帕累托最优通常无法实现，市场失灵随之出现。

**逻辑链**：

```
理想四条件
   ↓ 被破坏（垄断 / 外部性 / 公共物品 / 信息不对称）
市场机制不能充分发挥作用
   ↓
资源配置缺乏效率或失当
   ↓
市场失灵
```

**速记口诀**：**"市场不万能，四条件缺一样就失灵。"**

---

### 考点3 垄断 ★

**垄断与市场失灵（核心结论，一句话）**：

> 垄断企业的产量**低于**社会的最优产量，价格**高于**市场均衡价格，使**消费者的剩余减少而生产者的剩余增加**，社会福利受到损害。

**要点展开**：

- 垄断是导致市场失灵的一种原因；
- 只有在**完全竞争**市场上，市场机制才能实现资源有效配置；
- 在**完全垄断**市场，市场机制很难充分有效地发挥作用，资源就不能实现最优配置；
- 在**不完全竞争**（垄断竞争、寡头垄断）市场上，市场机制同样难以实现资源有效配置。

**逻辑链**：

```
市场不是完全竞争的（垄断 / 寡头 / 垄断竞争）
        ↓ 企业拥有价格影响力
产量 ↓（低于社会最优产量）    价格 ↑（高于市场均衡价格）
        ↓
消费者剩余减少、生产者剩余增加
        ↓
社会福利受到损害 → 资源配置失当 → 市场失灵
```

**速记口诀**：**"垄断：量低价高，消费者受损，福利下降。"**

---

### 考点4 外部性 ★★★★★（本章最高频辨析点之一）

**（1）含义与分类**

外部性指某人或某企业的经济活动给社会上其他成员带来影响（带来利益或造成损害），而该人或该企业**不必为这种损害进行补偿**（外部不经济时）。分为**正外部性（外部经济）**和**负外部性（外部不经济）**两类，每一类又可按主体分为生产、消费两个层面：

| 分类 | 正外部性（外部经济） | 负外部性（外部不经济） |
|---|---|---|
| **生产的外部性** | 生产的外部经济 | 生产的外部不经济 |
| **消费的外部性** | 消费的外部经济 | 消费的外部不经济 |

**（2）两类外部性的影响对比（必背）**

| 类型 | 核心机理 | 产出水平 | 市场结果 |
|---|---|---|---|
| **外部经济（正外部性）** | 私人利益**小于**社会利益（私人收益＜社会收益） | 低于社会最优产出 | 生产缺乏积极性，**供给不足** |
| **外部不经济（负外部性）** | 私人成本**小于**社会成本（边际私人成本＜边际社会成本） | 高于社会最优产出 | 倾向扩大生产，**供给过剩** |

**（3）易错提醒**

- 外部不经济的标准表述是"**边际私人成本低于边际社会成本**"，不是"边际私人成本低于边际社会收益"。
- 看到"**供给不足**"→ 对应**正外部经济效果**；看到"**供给过剩**"→ 对应**负外部经济效果**。

**逻辑链**：

```
某经济活动对外部产生影响
   ├── 给别人带来好处且得不到报酬 → 外部经济（正外部性）
   │        ↓ 私人利益 < 社会利益
   │    生产者缺乏积极性 → 产出低于社会最优 → 供给不足
   │
   └── 给别人造成损害且不必补偿 → 外部不经济（负外部性）
            ↓ 私人成本 < 社会成本（边际私人成本 < 边际社会成本）
        生产者倾向扩大生产 → 产出高于社会最优 → 供给过剩
```

**速记口诀**：**"正外不足，负外有余；经济看收益（私人利益小于社会利益），不经济看成本（私人成本小于社会成本）。"**

### 考点5 公共物品 ★★（高频辨析点：非竞争性 vs 非排他性）

**（1）含义**：满足**社会公共需要**的物品。

**（2）两大特征（务必分清）**

| 特征 | 定义要点 | 关键词 |
|---|---|---|
| **非竞争性** | 消费者对某一种公共物品的消费**并不影响**其他人对该公共物品的消费；对某一人的供给不会减少对其他人的供给；某人分享该公共物品的利益，通常不会减少其他人分享该公共物品的利益 | "不影响他人消费" |
| **非排他性** | 公共物品可以由**任何**消费者进行消费，**不排除任何人** | "不排除任何人" |

**（3）分类**

| 类别 | 特征 | 典型例子 |
|---|---|---|
| **纯公共物品** | 通过纳税**间接购买**，**被动消费**；消费时**无法分割**；只能由**政府**提供 | 国防、治安 |
| **准公共物品** | **有限的**非竞争性和非排他性；有一定程度的**拥挤**；可部分间接购买、也可直接购买；消费时可以**部分分割**；**政府和私人都可以提供** | 教育、医疗卫生、收费公路 |

**（4）市场需求曲线（易错点）**

- **公共物品**的市场需求曲线 = 所有消费者需求曲线沿**纵向相加**得到（一定价格下所有人愿意支付的价格加总）。
- **私人物品**的市场需求曲线 = 所有消费者需求曲线**横向加总**得到（一定价格下所有人的需求量加总）。

**（5）搭便车**：公共物品的消费可能产生"**搭便车**"现象。

**逻辑链**：

```
非竞争性 + 非排他性
        ↓
"搭便车"（不付费也能消费）
        ↓ 市场不愿意／无法有效提供
纯公共物品 → 只能由政府提供
准公共物品 → 有限的非竞争性和非排他性 → 政府和私人都可以提供，市场机制可发挥一定作用
```

**速记口诀**：**"非竞争是'不影响别人'，非排他是'不排除任何人'；纯公共政府独包（国防治安），准公共两家可包（教医收费路）；公共纵向加，私人横向加。"**

### 考点6 信息不对称 ★★（高频辨析点：逆向选择 vs 道德风险）

**含义**：市场上**买卖双方掌握的信息量不一样**。

| 表现形式 | 典型例子 | 发生环节 |
|---|---|---|
| **逆向选择** | 旧车市场（**注意不限于此市场**） | 交易**之前**，信息优势方以次充好，优质退出 |
| **道德风险** | 保险市场（**注意不限于此市场**） | 交易**之后**，签约方改变行为、不负责任 |

> 素材提示：旧车市场、保险市场只是典型代表，**不限于此市场**，考试遇到其他市场也要会判断属于哪一类。

**（1）后果**：信息不对称会导致**道德风险**；会导致某些商品或者服务市场出现**萎缩甚至消失**；市场机制实现资源帕累托最优配置的功能必然受到影响，进而导致市场失灵。

**（2）因果关系**：产生逆向选择和道德风险的**原因**是**信息不对称**。

**逻辑链**：

```
买卖双方信息量不一样（信息不对称）
        ├── 交易前：买方无法判断质量，好货被劣货驱逐 → 逆向选择（旧车市场）
        └── 交易后：一方行为无法被观测，签约后降低努力 → 道德风险（保险市场）
                ↓
        市场萎缩甚至消失 → 资源配置受影响 → 市场失灵
                ↓ 政府干预
        法律法规（商品说明、质量标准、广告等）+ 信息服务
```

**速记口诀**：**"信息不对称生两害：事前逆向选旧车，事后道德险保险。"**

---

### 考点7 政府干预的措施和方式 ★★

**（1）四类失灵的干预手段汇总（必背大表）**

| 失灵原因 | 干预手段 |
|---|---|
| **垄断** | 法律手段：**反不正当竞争法和反垄断法**；**公共管制** |
| **外部性** | **税收和补贴（津贴）**；**企业合并**；**明确和界定产权** |
| **公共物品** | **政府提供** |
| **信息不对称** | **法律法规**；**信息服务** |

**（2）科斯定理（本章最重要理论）**

> 只要**财产权是明确的**，并且**交易成本是零或者很小**，那么**无论开始时将财产权赋予谁**，市场均衡的最终结果都是有效率的，实现资源配置的帕累托最优。

- 科斯定理有利于**解决外部性问题**（注意：不是解释公共物品的供求关系）。
- "明确和界定产权"已经成为消除外部性的重要途径。

**逻辑链**：

```
垄断      → 反垄断法／反不正当竞争法 + 公共管制
外部性    → 税收和补贴（外部性内部化）+ 企业合并（外部性内部化）+ 明确界定产权（科斯定理）
公共物品  → 政府提供（纯公共物品只能政府提供）
信息不对称 → 法律法规（质量标准、广告规范等）+ 信息服务
                ↓ 共同目标
        弥补市场失灵，使资源配置趋向帕累托最优
```

**速记口诀**：**"垄断反垄加管制，外部税收补合并权，公共物品政府办，信息不对称法加信息。"**

### 表3 本章"不等于"避坑表

| # | 错误说法 | 正解 |
|---|---|---|
| 1 | 帕累托最优 ＝ 帕累托改进 | ✗ 帕累托最优状态是**不存在**帕累托改进的状态，二者互斥 |

## 四、关键机制与适用条件

本章**无计算公式**，核心是三大机制的逻辑与适用条件，均为素材原述。

**（1）科斯定理（解决外部性）**

- **内容**：只要财产权是明确的，并且交易成本是零或者很小，那么无论在开始时将财产权赋予谁，市场均衡的最终结果都是有效率的，实现资源配置的帕累托最优。
- **适用条件**：① 财产权明确；② 交易成本为零或者很小。
- **结论指向**：解决外部性问题；产权初始分配不影响最终效率结果。
- **对应手段**：政府干预外部性的方式之一——明确和界定产权。

```
财产权明确 + 交易成本很小
        ↓ 市场自主交易／谈判
外部性成本被内部化
        ↓ 无论产权最初给谁
有效率的结果 → 帕累托最优
```

**（2）税收和补贴（津贴）——外部性内部化**

- **适用对象**：外部性（外部经济与外部不经济）。
- **逻辑**：对存在外部不经济（私人成本＜社会成本）的活动课税、对存在外部经济（私人利益＜社会利益）的活动给予补贴（津贴），使私人成本／收益向社会成本／收益靠拢。
- **定性**：消除外部性的**传统方法**之一。
- **适用边界**：它解决的是**外部性**，不能解决信息不对称导致的市场失灵。

**（3）企业合并——外部性内部化**

- **适用对象**：外部性。
- **逻辑**：将具有外部关系的相关企业合并，使外部影响转入企业内部，外部性被内部化。
- **定性**：消除外部性的**传统方法**之一。

**（4）法律与公共管制**

- **反垄断**：反不正当竞争法、反垄断法（法律手段）＋公共管制，针对垄断。
- **信息不对称**：制定有关商品说明、质量标准和广告等法律法规，并辅以信息服务。

**（5）政府直接提供**

- **适用对象**：公共物品。纯公共物品只能由政府提供；准公共物品政府和私人都可提供，市场机制可以发挥一定作用。

> 说明：素材未涉及"排污权交易""庇古税"等机制的具体表述，为避免超纲补充，此处不作展开。

## 五、高频考点速记卡

1. **Q：帕累托最优状态的定义？**
   A：资源的任何重新分配已经不可能在不使一个人福利减少的情况下使任何一个人福利增加；等价于不存在帕累托改进的资源配置状态。

2. **Q：什么是帕累托改进？**
   A：资源的重新分配在不使任何人情况变坏的前提下，使得至少一个人变得更好。

3. **Q：帕累托最优状态又被称作什么？**
   A：经济效率。满足帕累托最优就是具有经济效率，不满足就是缺乏经济效率。

4. **Q：帕累托最优的实现条件有哪些？**
   A："三个完全、无外部性"——经济主体完全理性、信息完全、市场完全竞争、经济主体行为不存在外部影响。

5. **Q：一般均衡状态／瓦尔拉斯均衡状态与资源最优配置的关系？**
   A：经济处于一般均衡（瓦尔拉斯均衡）状态时，市场均衡、供求相等、无过剩无短缺，此时资源实现最优配置。

6. **Q：市场失灵的含义？**
   A：由于市场机制不能充分地发挥作用而导致的资源配置缺乏效率或资源配置失当的情况。

7. **Q：垄断如何导致市场失灵？**
   A：垄断企业产量低于社会最优产量、价格高于市场均衡价格，消费者剩余减少而生产者剩余增加，社会福利受到损害。

8. **Q：外部性分哪几类？**
   A：按影响分正外部性（外部经济）和负外部性（外部不经济）；按主体分生产的外部性和消费的外部性，组合成四类。

9. **Q：外部经济为什么导致供给不足？**
   A：私人利益小于社会利益（私人收益＜社会收益），生产者缺乏积极性，产出水平低于社会最优产出，造成产品供给过少。

10. **Q：外部不经济的标准判断？**
    A：边际私人成本低于边际社会成本，倾向扩大生产，产出水平大于社会最优产出，造成产品供给过多。

11. **Q：公共物品的含义和两大特征？**
    A：满足社会公共需要的物品；特征是非竞争性（不影响他人消费）和非排他性（不排除任何人）。

12. **Q：纯公共物品与准公共物品的区别？**
    A：纯公共物品通过纳税间接购买、被动消费、无法分割、只能由政府提供（国防、治安）；准公共物品具有有限的非竞争性和非排他性、有一定拥挤、可部分分割、政府和私人都可提供（教育、医疗卫生、收费公路）。

13. **Q：公共物品的市场需求曲线如何得到？**
    A：所有消费者需求曲线沿**纵向相加**；私人物品才是横向加总。

14. **Q：什么是"搭便车"？**
    A：公共物品的消费可能产生搭便车现象——不付费也能消费他人付费的物品。

15. **Q：信息不对称的两种表现形式及例子？**
    A：逆向选择（旧车市场，注意不限于此市场）和道德风险（保险市场，注意不限于此市场）。

16. **Q：逆向选择和道德风险的原因是什么？**
    A：信息不对称。

17. **Q：信息不对称有哪些后果？**
    A：导致道德风险；导致某些商品或者服务市场出现萎缩甚至消失；使市场机制实现帕累托最优配置的功能受到影响。

18. **Q：针对四类市场失灵，政府分别如何干预？**
    A：垄断——反不正当竞争法、反垄断法、公共管制；外部性——税收和补贴、企业合并、明确和界定产权；公共物品——政府提供；信息不对称——法律法规、信息服务。

19. **Q：科斯定理的内容与条件？**
    A：财产权明确且交易成本为零或很小时，无论开始时将财产权赋予谁，市场均衡的最终结果都是有效率的，实现帕累托最优。它有利于解决外部性问题。

20. **Q：税收和补贴、明晰产权分别解决什么问题？**
    A：税收和补贴、企业合并、明确和界定产权都是消除外部性的方法；它们不能解决信息不对称导致的市场失灵。

## 六、典型真题（含解析）

**【2021·单选】具有经济效率特征的资源配置状态是（　）。**
A. 市场处于寡头垄断的状态
B. 市场处于垄断竞争的状态
C. 不存在帕累托改进的状态
D. 市场存在外部影响的状态

**答案：C**
**解析**：帕累托最优状态是不存在帕累托改进的资源配置状态。换言之，如果对于某种既定的资源配置状态还存在帕累托改进，即在该状态下还存在某些改变可以至少使一个人的境况变好而不使任何人的境况变坏，则这种状态就不是帕累托最优状态。帕累托最优状态又被称作经济效率。满足帕累托最优状态就是具有经济效率的，而不满足帕累托最优状态就是缺乏经济效率的。寡头垄断、垄断竞争、存在外部影响都不满足"三个完全、无外部性"的条件。

**【2015·多选】关于信息不对称和市场失灵的说法，正确的是（　）。**
A. 信息不对称会导致道德风险
B. 信息不对称会导致某些商品或者服务市场出现萎缩甚至消失
C. 通过税收和补贴手段，可以解决信息不对称导致的市场失灵
D. 政府可以制定有关商品说明、质量标准和广告等的法律法规，以克服信息不对称所导致的市场失灵
E. 通过明晰产权可以克服信息不对称所引起的市场失灵

**答案：ABD**
**解析**：当现实经济中出现信息不对称时，市场机制实现资源帕累托最优配置的功能必然受到影响，进而导致市场失灵。消除外部性的传统方法，包括使用税收和补贴、将相关企业合并从而使外部性内部化等手段，故 C 错误。明确和界定产权已经成为消除外部性的重要途径，故 E 错误。

---

**【2025·多选】信息不对称是导致市场失灵的重要原因，表现形式有（　）。**
A. 帕累托改进
B. 逆向选择
C. 道德风险
D. 增加交易成本
E. 搭便车

**答案：BC**
**解析**：信息不对称的表现形式是逆向选择和道德风险。帕累托改进是资源重新配置的改进过程，与信息不对称的表现形式无关；"增加交易成本"并非信息不对称在本教材中的表现形式；"搭便车"是公共物品消费中的现象。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"帕累托最优"和"帕累托改进"混为一谈 | 最优＝**没有**改进空间；改进＝已经变好了一次，说明原来不是最优 |
| 2 | 做题时把"双重否定"看成"一个否定" | 口诀：**双重否定选最优，一个否定选改进** |
| 3 | 认为"满足帕累托最优就是缺乏经济效率" | 帕累托最优状态**又被称作经济效率**，满足即有效率 |
| 4 | 认为一般均衡／瓦尔拉斯均衡时资源"不一定"实现最优配置 | 三者等价：一般均衡＝瓦尔拉斯均衡＝资源最优配置 |
| 5 | 漏记帕累托最优的实现条件 | **三个完全（理性、信息、竞争）＋无外部影响**，缺一不可 |
| 6 | 认为不完全竞争市场也能实现资源有效配置 | 只有**完全竞争**市场才能；垄断、寡头、垄断竞争都不行 |
| 7 | 把外部性理解为只发生在生产领域 | 外部性＝生产的外部性＋消费的外部性，各有经济与不经济 |
| 8 | 外部经济／外部不经济的产出方向记反 | **正外不足、负外有余**：外部经济产出低、供给不足；外部不经济产出高、供给过剩 |
| 9 | 外部不经济的判断写成"边际私人成本低于边际社会收益" | 标准说法是**边际私人成本＜边际社会成本** |
| 10 | 混淆公共物品的"非竞争性"与"非排他性" | 非竞争＝**不影响**别人消费；非排他＝**不排除**任何人 |
| 11 | 认为所有公共物品都必须由政府提供 | 只有**纯公共物品**只能政府提供；准公共物品政府和私人都可以 |
| 12 | 公共物品的市场需求曲线记成"横向加总" | 公共物品**纵向相加**，私人物品才横向加总 |
| 13 | 把逆向选择和道德风险混为一谈 | 逆向选择在**交易前**（旧车市场），道德风险在**交易后**（保险市场） |
| 14 | 把旧车市场、保险市场当成唯一对应场景 | 素材明确提示"**注意不限于此市场**"，要会迁移判断 |
| 15 | 认为"帕累托改进""搭便车""增加交易成本"是信息不对称的表现形式 | 信息不对称的表现形式只有**逆向选择**和**道德风险** |
| 16 | 认为科斯定理能解决公共物品供求 | 科斯定理解决**外部性**问题 |
| 17 | 认为税收和补贴、明晰产权能解决信息不对称 | 二者都是消除**外部性**的方法；信息不对称靠**法律法规＋信息服务** |
| 18 | 混淆政府干预手段与失灵原因的对应关系 | 垄断→反垄法＋公共管制；外部性→税补＋合并＋产权；公共物品→政府提供；信息不对称→法规＋信息服务 |

## 八、本章数字速记

| 数字 | 考点 |
|---|---|
| 三个完全 | 帕累托最优条件：完全理性、完全信息、完全竞争 |
| 一个"无" | 帕累托最优条件：不存在外部影响 |
| 四个条件 | 三个完全＋无外部性，缺一即可能出现市场失灵 |
| 四大失灵原因 | 垄断、外部性、公共物品、信息不对称 |
| 外部性两类 | 正外部性（外部经济）、负外部性（外部不经济） |
| 外部性四种形态 | 生产／消费 × 外部经济／外部不经济 |
| 公共物品两大特征 | 非竞争性、非排他性 |
| 公共物品两大类 | 纯公共物品（国防、治安）、准公共物品（教育、医疗卫生、收费公路） |
| 信息不对称两种表现 | 逆向选择（事前）、道德风险（事后） |
| 两种需求曲线加总 | 私人物品横向加总；公共物品纵向加总 |
| 政府干预四类手段 | 法律／管制、税收补贴＋合并＋产权、政府提供、法规＋信息服务 |
| 科斯定理两条件 | 财产权明确；交易成本为零或很小 |
