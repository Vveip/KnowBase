## 二、知识点精讲

### 考点1 国际贸易理论的演变 ★★★★

> 素材目录标"考点1 国际贸易理论★★★★"，正文标题为"国际贸易理论的演变"，二者为同一考点，此处沿用正文标题。

**（一）五大理论总览**

| 理论 | 人物 | 核心观点 | 归属 |
|---|---|---|---|
| 绝对优势理论 | 亚当·斯密 | 劳动生产率和成本的**绝对差异**是国际贸易基础 | 自由贸易理论 |
| 比较优势理论 | 大卫·李嘉图 | 决定国际贸易的因素是两个国家产品的**相对生产成本** | 自由贸易理论 |
| 要素禀赋理论（赫克歇尔-俄林理论，H-O 模型，掌握） | 赫克歇尔、俄林 | 要素禀赋是指一国所拥有的**两种生产要素的相对比例**；各国应集中生产并出口能够充分利用本国相对丰裕要素的产品，进口那些需要密集使用本国相对稀缺要素的产品；国际贸易的基础是生产资源配置或要素储备比例上的差别 | 自由贸易理论 |
| 规模经济贸易理论（当代贸易理论） | 美国经济学家克鲁格曼 | 解释**相似资源储备国家之间和同类工业品之间的双向贸易**现象；大规模生产可以降低单位产品的生产成本；各国利用规模经济生产有限类别的产品，通过国际贸易实现产品流动，实现国际分工的规模效益，这是现代国际贸易的基础 | 自由贸易理论 |
| 保护贸易理论（26 新增） | 德国经济学家弗里德里希·李斯特（19 世纪初期） | 主张国家应对国际贸易进行干预，实行"奖出限入"的对外贸易政策；代表性理论为**保护幼稚工业理论** | 保护贸易理论 |

**（二）自由贸易理论与保护贸易理论的分野**

- 前四种理论（绝对优势、比较优势、要素禀赋、规模经济）大多强调开展自由贸易能够给国际贸易参与方带来益处，属于国际贸易理论体系中的**自由贸易理论**。
- 保护贸易理论则主张国家应对国际贸易进行干预，实行"奖出限入"的对外贸易政策。其中比较有影响力的是李斯特于 19 世纪初期提出的**保护幼稚工业理论**，其核心观点包括：
  1. **经济发展阶段论**——认为国家在经济发展的不同阶段应结合本国国情选择与之相适应的贸易政策；
  2. **生产力论**——强调发展生产力是制定贸易政策的出发点；
  3. **国家干预论**——主张通过国家干预经济的方式保护本国幼稚工业。
- 结论：保护贸易理论也因此成为**经济落后国家发展本国工业的重要理论依据**。

**（三）要素禀赋理论的两个推论（选择题常考）**

1. 各国应该**集中生产并出口**那些能够充分利用本国相对丰裕要素的产品，**进口**那些需要密集使用本国相对稀缺要素的产品；
2. 通过国际贸易，往往会使各个国家之间的要素报酬（如工资、利息、地租等）差异趋于缩小，出现**要素价格均等化趋势**。

**逻辑链**：

```
自由贸易理论线（强调自由贸易给参与方带来益处）
  亚当·斯密   绝对优势理论   → 劳动生产率与成本的绝对差异
  大卫·李嘉图 比较优势理论   → 两国产品的相对生产成本
  赫克歇尔-俄林 要素禀赋理论 → 两种生产要素相对比例（H-O 模型）
                              → 要素价格均等化趋势
  克鲁格曼     规模经济贸易理论 → 相似资源国家、同类工业品双向贸易

保护贸易理论线（26 新增）
  李斯特（19 世纪初期）保护幼稚工业理论
    ├─ 经济发展阶段论：不同发展阶段选择相适应的贸易政策
    ├─ 生产力论：发展生产力是制定贸易政策的出发点
    └─ 国家干预论：通过国家干预保护本国幼稚工业
      → 经济落后国家发展本国工业的重要理论依据
```

**速记口诀**：**"斯绝对、李比较，赫俄要素 H-O，克鲁格曼规模经济；保护贸易李斯特，幼稚工业有三论（阶段、生产力、国家干预）。"**

### 考点2 影响国际贸易的因素 ★★

| 影响出口贸易的因素 | 影响进口贸易的因素 |
|---|---|
| （1）自然资源的丰裕程度 | （1）一国的经济总量或总产出水平——GDP 越大，进口贸易额越大 |
| （2）生产能力和技术水平的高低 | （2）汇率水平 |
| （3）汇率水平 | （3）国际市场商品的供给情况和价格水平的高低 |
| （4）国际市场需求水平和需求结构 | |

> **关键提示**：**汇率水平同时出现在出口、进口两条线中**，是唯一重叠因素；其余因素各归各线，选择题常设"张冠李戴"陷阱。

**逻辑链**：

```
出口贸易 ← 自然资源丰裕程度 ＋ 生产能力和技术水平 ＋ 汇率水平 ＋ 国际市场需求水平和需求结构
进口贸易 ← 经济总量/总产出水平（GDP 越大进口越大）＋ 汇率水平 ＋ 国际市场商品供给情况和价格水平
```

**速记口诀**：**"出口四件套：资源、技术、汇率、需求；进口三件套：总量、汇率、供给；汇率两头都在。"**

### 考点3 政府对进出口贸易的干预 ★★★★

**（一）干预目的（3 点）**

1. 保护国内产业免受国外竞争者的损害；
2. 维持本国的经济增长；
3. 维护本国国际收支平衡。

**（二）干预措施**

| 干预方向 | 类别 | 具体措施 |
|---|---|---|
| 对进口贸易的干预 | 关税限制（壁垒） | 征收高额关税 |
| | 非关税限制（壁垒） | 进口配额制、自愿出口限制、歧视性公共采购、技术标准和卫生检疫标准 |
| 对出口贸易的干预 | 出口补贴——直接补贴 | 直接补贴 |
| | 出口补贴——间接补贴 | 出口退税、出口信贷 |

**逻辑链**：

```
政府干预目的：保护国内产业 ＋ 维持经济增长 ＋ 维护国际收支平衡
        ↓
对进口贸易的干预 ── 关税壁垒（征收高额关税）
                 └─ 非关税壁垒（进口配额制、自愿出口限制、
                              歧视性公共采购、技术标准和卫生检疫标准）
对出口贸易的干预 ── 出口补贴 ── 直接补贴
                             └─ 间接补贴（出口退税、出口信贷）
```

**速记口诀**：**"进口拦两道：高关税＋非关税（配额、自愿限制、歧视采购、技术检疫）；出口扶一把：直接补贴＋间接补贴（退税、信贷）。"**

### 考点4 倾销与反倾销 ★★★

**（一）倾销的含义（两要件，缺一不可）**

倾销是指出口商以**低于正常价值**的价格向进口国销售产品，并因此给进口国产业造成**损害**的行为。

**（二）倾销的类型**

| 类型 | 要点 |
|---|---|
| 掠夺性倾销 | 先以低价倾销排除竞争对手，待排除竞争对手后再重新提高产品销售价格的行为 |
| 持续性倾销 | 出口企业为长期占领市场、实现利润最大化而无限期地持续以低价向国外市场出口产品的行为 |
| 隐蔽性倾销 | 出口商按正常价格销售给进口商，进口商以倾销性低价在进口国市场抛售产品，亏损由出口企业补偿 |
| 偶然性倾销 | 出口国国内存在大量剩余产品，为处理这些产品而向国外市场抛售 |

**（三）反倾销**

1. 反倾销税是**正常海关税收之外**，进口国主管机关对确认的倾销产品征收的一种**附加税**；
2. 税额**不得超过**裁定的倾销幅度；
3. 纳税义务人是**倾销产品的进口商**，出口商不得直接或间接替进口商承担反倾销税；
4. 反倾销措施属于**贸易救济措施**；
5. 世界贸易组织规定，对出口国某一产品征收反倾销税要求：①该产品存在着以**低于正常价值水平**进入另一国市场的事实；②倾销对某一成员方的相关产业造成**重大损失**；③损害与低价倾销之间存在**因果关系**。

**逻辑链**：

```
低于正常价值的价格销售 ＋ 给进口国产业造成损害
        ↓ 两要件同时满足
构成倾销
        ↓ 进口国主管机关确认（WTO 三条件）
① 低于正常价值进入另一国市场的事实
② 对相关产业造成重大损失
③ 损害与低价倾销之间有因果关系
        ↓
征收反倾销税（贸易救济措施）
   ├─ 性质：正常海关税收之外的附加税
   ├─ 上限：税额不得超过裁定的倾销幅度
   └─ 纳税人：倾销产品的进口商（出口商不得直接或间接替其承担）
```

**速记口诀**：**"倾销两要件：低价＋损害；反倾销税：不超幅度、进口商纳税、贸易救济措施；WTO 三条件：低价事实＋重大损失＋因果关系。"**

### 考点5 我国对外贸易增长速度较快的原因 ★

1. 加入世界贸易组织为我国经济融入国际市场提供了重要的基础；
2. 我国逐步下调关税水平有力地促进了进出口的不断扩大；
3. 我国的各项改革不断深化，为我国的企业和产品的竞争力不断提高提供了不竭的动力。

**速记口诀**：**"入世给基础、降关税扩规模、改革增动力。"**

---

### 考点6 建设更高水平对外开放型经济新体制的内涵 ★★★

1. 进一步打通国内国际两个市场，高效利用国内国际两种资源，促进国内国际要素资源有序自由流动、全球高效配置；
2. 要在构建双循环新发展格局中实现更高水平的对外开放，并把它作为双循环新发展格局的重要内容。

**党的二十大报告相关部署**：稳步扩大规则、规制、管理、标准等**制度型开放**。推动货物贸易优化升级，创新服务贸易发展机制，发展数字贸易、加快建设贸易强国。为进一步推进高水平对外开放指明了方向。

**速记口诀**：**"两个市场两种资源，要素流动全球配置；双循环中扩开放；制度型开放四词：规则、规制、管理、标准。"**

---

### 考点7 建设高水平对外开放新体制的措施 ★★

**定位**：对外开放是我国基本国策，是中国特色社会主义制度重要特征；开放是中国式现代化的鲜明标志。

**"十五五"纲要（26 新增）**：坚持开放合作、互利共赢，稳步扩大**制度型开放**。建设更高水平开放型经济新体制，推动一带一路高质量发展，拓展国际循环，以开放促改革促发展，倡导平等有序的世界多极化、普惠包容的经济全球化。

**扩大高水平对外开放、开创合作共赢新局的三个方面**：

1. **一是积极扩大自主开放**——对接国际高标准经贸规则扩大开放，促进国内国际规则、规制、管理、标准相通相容，营造透明稳定可预期的制度环境。有序扩大开放领域和区域；构建与高标准经贸规则相衔接的制度和监管体系；优化区域开放布局，打造形态多样的开放高地，加快形成陆海内外联动、东西双向互济的全面开放格局。
2. **二是提升贸易投资合作质量和水平**——强化进口和出口协调、货物和服务并重，统筹吸引外资和境外投资，塑造国际贸易和双向投资合作新优势。包括：推动贸易创新发展；更大力度吸引和利用外资，持续优化外商投资环境，健全外商投资服务保障体系；全面落实外资企业国民待遇，清理与外商投资法不符的文件法规，落实好"准入又准营"；促进国际产业与投资合作，健全海外综合服务体系，促进贸易投资一体化，引导产业链供应链合理有序跨境布局。
3. **三是高质量共建"一带一路"**——坚持共商共建共享、开放绿色廉洁、高标准惠民生可持续的指导原则，完善推进高质量共建"一带一路"机制，深化基础设施"硬联通"、规则标准"软联通"、同共建国家人民"心联通"。

**速记口诀**：**"自主开放、提质合作、一带一路三联通（硬、软、心）。"**

| 关税壁垒：征收高额关税 | 出口补贴·直接补贴 |
| 非关税壁垒：进口配额制、自愿出口限制、歧视性公共采购、技术标准和卫生检疫标准 | 出口补贴·间接补贴：出口退税、出口信贷 |

### 表4 倾销的四种类型

| 类型 | 一句话判别 |
|---|---|
| 掠夺性倾销 | 先低价排挤对手，事后再提价 |
| 持续性倾销 | 无限期持续低价，长期占领市场 |
| 隐蔽性倾销 | 出口商正常价出货，进口商低价抛售，亏损出口商补偿 |
| 偶然性倾销 | 处理国内大量剩余产品，偶尔抛售 |

### 表5 WTO 征收反倾销税三条件与反倾销税要点

| 项目 | 内容 |
|---|---|
| 条件① | 产品存在以低于正常价值水平进入另一国市场的事实 |
| 条件② | 倾销对某一成员方的相关产业造成重大损失 |
| 条件③ | 损害与低价倾销之间存在因果关系 |
| 性质 | 正常海关税收之外的附加税，属贸易救济措施 |
| 税额上限 | 不得超过裁定的倾销幅度 |
| 纳税人 | 倾销产品的进口商；出口商不得直接或间接替进口商承担 |

### 表6 "七个不等于"（避坑专用）

| 说法 | 正解 |
|---|---|
| 绝对优势 ≠ 比较优势 | ✗ 斯密看劳动生产率和成本的**绝对差异**；李嘉图看两国产品的**相对生产成本** |
| 要素禀赋理论 ≠ 规模经济理论 | ✗ 前者是赫克歇尔-俄林（H-O，两种要素比例）；后者是克鲁格曼（规模降成本、双向贸易） |
| 自由贸易理论 ≠ 保护贸易理论 | ✗ 前四家（绝对、比较、要素禀赋、规模经济）属自由贸易；李斯特保护幼稚工业理论属保护贸易 |
| 低价出口 ≠ 倾销 | ✗ 倾销＝低于正常价值**＋**给进口国产业造成损害，两要件缺一不可 |
| 出口信贷 ≠ 非关税壁垒 | ✗ 出口信贷是鼓励**出口**的间接补贴；非关税壁垒是限制**进口**的措施 |
| 反倾销税 ≠ 非关税壁垒 | ✗ 反倾销税是关税之外的**附加税**；非关税壁垒是配额、自愿出口限制、歧视性公共采购、技术标准、卫生检疫标准 |
| 反倾销税可以随意定 ≠ 正确 | ✗ 税额不得超过裁定的倾销幅度，且纳税人是**进口商** |

## 四、关键机制与适用条件

本章**无计算公式**，核心是四组机制的逻辑与适用条件，均依素材原述整理。

**（1）要素价格均等化机制（要素禀赋理论的推论）**

- **逻辑**：各国要素禀赋（两种生产要素的相对比例）不同 → 各国集中生产并出口充分利用本国丰裕要素的产品、进口密集使用稀缺要素的产品 → 国际贸易使各国要素报酬（工资、利息、地租等）差异趋于缩小。
- **结论**：出现**要素价格均等化趋势**。

```
要素禀赋不同（两种生产要素相对比例不同）
        ↓ 集中生产并出口充分利用本国丰裕要素的产品
进口密集使用本国稀缺要素的产品
        ↓ 国际贸易开展
各国要素报酬（工资、利息、地租）差异趋于缩小
        ↓
   要素价格均等化趋势
```

**（2）规模经济机制（现代国际贸易的基础）**

- **逻辑**：大规模生产可以降低单位产品的生产成本 → 各国利用规模经济来生产**有限类别**的产品 → 通过国际贸易实现产品的流动 → 实现国际分工的规模效益。
- **解释对象**：相似资源储备国家之间和同类工业品之间的**双向贸易**现象（古典理论解释不了，故称当代贸易理论）。

```
大规模生产 → 单位产品生产成本降低
        ↓ 各国只生产有限类别的产品
通过国际贸易实现产品跨境流动
        ↓
国际分工的规模效益（现代国际贸易的基础）
```

**（3）倾销认定机制（两要件）**

- **适用条件**：同时满足①以低于正常价值的价格向进口国销售产品；②因此给进口国产业造成损害。仅有低价、未造成损害的，不构成倾销。
- **认定关键**：认定产品的**正常价值**。

```
出口商以低于正常价值的价格向进口国销售产品
        ＋ （同时满足）
给进口国产业造成损害
        ↓
构成倾销（认定关键：产品的正常价值）
```

**（4）反倾销税征收机制（WTO 三条件＋两限制）**

- **适用条件（WTO 规定，三者齐备方可征收）**：①低于正常价值进入另一国市场的事实；②对相关产业造成重大损失；③损害与低价倾销之间存在因果关系。
- **两限制**：税额不得超过裁定的倾销幅度；纳税义务人是进口商，出口商不得直接或间接替进口商承担。

```
WTO 三条件齐备（低价事实＋重大损失＋因果关系）
        ↓ 进口国主管机关确认倾销
征收反倾销税（附加税，贸易救济措施）
   ├─ 上限：不超过裁定的倾销幅度
   └─ 纳税人：进口商（出口商不得变相承担）
```

**（5）保护幼稚工业理论的适用逻辑**

- **适用对象**：经济落后国家发展本国工业（因此成为这些国家发展工业的重要理论依据）。
- **逻辑**：经济发展阶段论（按发展阶段选贸易政策）→ 生产力论（发展生产力是出发点）→ 国家干预论（以国家干预保护幼稚工业）。
- **政策取向**：国家应对国际贸易进行干预，实行"奖出限入"的对外贸易政策。

```
经济发展阶段论：不同发展阶段选择相适应的贸易政策
        ↓ 出发点
生产力论：发展生产力是制定贸易政策的出发点
        ↓ 手段
国家干预论：国家干预经济，保护本国幼稚工业，"奖出限入"
        ↓ 适用对象
经济落后国家发展本国工业的重要理论依据
```

## 五、高频考点速记卡

1. **Q：当前主要的国际贸易理论（自由贸易理论）有哪些？**
   A：绝对优势理论、比较优势理论、要素禀赋理论（赫克歇尔-俄林）、规模经济贸易理论。不含"外贸依存理论"。

2. **Q：绝对优势理论的人物和核心？**
   A：亚当·斯密；劳动生产率和成本的**绝对差异**是国际贸易基础。

3. **Q：比较优势理论的人物和核心？**
   A：大卫·李嘉图；决定国际贸易的因素是两个国家产品的**相对生产成本**。

4. **Q：要素禀赋理论的别称、人物和定义？**
   A：即赫克歇尔-俄林理论，又称 H-O 模型；要素禀赋是指一国所拥有的**两种生产要素的相对比例**。

5. **Q：要素禀赋理论主张的贸易模式？**
   A：集中生产并出口能够充分利用本国相对丰裕要素的产品，进口需要密集使用本国相对稀缺要素的产品；国际贸易基础是生产资源配置或要素储备比例上的差别；结果是要素价格均等化趋势。

6. **Q：规模经济贸易理论的人物和解释对象？**
   A：美国经济学家克鲁格曼；解释相似资源储备国家之间和同类工业品之间的双向贸易现象。

7. **Q：保护贸易理论（26 新增）的代表人物和核心观点？**
   A：德国经济学家李斯特，19 世纪初期提出保护幼稚工业理论；核心观点为经济发展阶段论、生产力论、国家干预论。

8. **Q：影响出口贸易的四因素？**
   A：自然资源的丰裕程度；生产能力和技术水平的高低；汇率水平；国际市场需求水平和需求结构。

9. **Q：影响进口贸易的三因素？**
   A：一国的经济总量或总产出水平（GDP 越大，进口贸易额越大）；汇率水平；国际市场商品的供给情况和价格水平的高低。

10. **Q：政府干预进出口贸易的三个目的？**
    A：保护国内产业免受国外竞争者的损害；维持本国的经济增长；维护本国国际收支平衡。

11. **Q：非关税壁垒包括哪些？**
    A：进口配额制、自愿出口限制、歧视性公共采购、技术标准和卫生检疫标准。

12. **Q：出口补贴的两种形式？**
    A：直接补贴；间接补贴（出口退税、出口信贷）。

13. **Q：倾销的构成要件？**
    A：以低于正常价值的价格向进口国销售产品**并且**给进口国产业造成损害，两要件缺一不可。

14. **Q：倾销的四种类型怎么记？**
    A：掠夺性（排对手再提价）、持续性（无限期低价占市场）、隐蔽性（出口商正常价、进口商低价抛售、亏损出口商补偿）、偶然性（处理国内剩余产品）。

15. **Q：反倾销税的三个关键规定？**
    A：税额不得超过裁定的倾销幅度；纳税义务人是倾销产品的进口商；反倾销措施属于贸易救济措施。

16. **Q：WTO 规定征收反倾销税的三条件？**
    A：①产品存在以低于正常价值水平进入另一国市场的事实；②倾销对相关产业造成重大损失；③损害与低价倾销之间存在因果关系。

17. **Q：我国对外贸易增长速度较快的原因？**
    A：加入 WTO 奠定基础；逐步下调关税水平；各项改革不断深化提供不竭动力。

18. **Q：建设更高水平对外开放型经济新体制的内涵？**
    A：打通国内国际两个市场、高效利用两种资源，促进要素资源有序自由流动、全球高效配置；在构建双循环新发展格局中实现更高水平对外开放。

19. **Q：建设高水平对外开放新体制的三方面措施？**
    A：一是积极扩大自主开放；二是提升贸易投资合作质量和水平；三是高质量共建"一带一路"。

20. **Q："制度型开放"指什么？**
    A：稳步扩大规则、规制、管理、标准等制度型开放（二十大报告）；"十五五"纲要同样强调稳步扩大制度型开放。

**【2017·多选】关于倾销和反倾销的说法，正确的有（　）。**
A. 反倾销属于贸易救济措施
B. 进口国征收反倾销税可以根据本国需要随意确定标准
C. 倾销的实质就是低价出口产品
D. 反倾销的措施可采用征收反倾销税

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"绝对优势"与"比较优势"混为一谈 | 斯密绝对优势看劳动生产率和成本的**绝对差异**；李嘉图比较优势看两国产品的**相对生产成本** |
| 2 | 把要素禀赋理论说成规模经济理论的人物 | 要素禀赋＝赫克歇尔-俄林（H-O，两种要素比例）；规模经济＝克鲁格曼（双向贸易） |
| 3 | 漏记保护贸易理论是 26 新增考点 | 李斯特保护幼稚工业理论属**保护贸易理论**，不是自由贸易理论 |
| 4 | 把"贸易保护论"选进自由贸易理论 | 自由贸易理论只有四家：绝对优势、比较优势、要素禀赋、规模经济 |
| 5 | 出口因素与进口因素"串门" | 出口四因素：资源、技术、汇率、需求；进口三因素：总量、汇率、供给；**汇率是唯一重叠项** |
| 6 | 把"出口信贷"当成非关税壁垒 | 出口信贷是鼓励**出口**的间接补贴；非关税壁垒是限制**进口**的措施 |
| 7 | 把反倾销税当成非关税壁垒 | 反倾销税是关税之外的**附加税**；非关税壁垒＝进口配额、自愿出口限制、歧视性公共采购、技术标准、卫生检疫标准 |
| 8 | 认为反倾销税税额可以随意确定 | 税额**不得超过裁定的倾销幅度** |
| 9 | 认为出口商是反倾销税的纳税人 | 纳税义务人是**进口商**，出口商不得直接或间接替进口商承担 |
| 10 | 把"低价出口"等同于倾销 | 倾销＝低于正常价值**＋**给进口国产业造成损害，两要件缺一不可；认定关键是产品的**正常价值** |
| 11 | 四种倾销类型记混 | 掠夺性（排对手再提价）、持续性（无限期占市场）、隐蔽性（正常价出货、进口商抛售、亏损出口商补偿）、偶然性（处理国内剩余产品） |
| 12 | WTO 反倾销税三条件漏掉"因果关系" | 低价事实＋重大损失＋因果关系，三者缺一不可 |
| 13 | 把"制度型开放"的内容记错 | 四个词：**规则、规制、管理、标准** |
| 14 | 把"一带一路"三联通记混 | 基础设施**硬**联通、规则标准**软**联通、同共建国家人民**心**联通 |
| 15 | 混淆"建设更高水平对外开放型经济新体制"与"建设高水平对外开放新体制" | 素材中前者是**内涵**（考点2）、后者是**措施**（考点3），指向同一件事 |
| 16 | 把我国外贸增长快的原因只记一条 | 三条：入世给基础、下调关税、改革深化增动力 |
