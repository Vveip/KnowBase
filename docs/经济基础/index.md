# 中级经济师 · 经济基础知识

> 《经济基础知识》是**所有专业的公共必考科目**。本栏目按 **2026 年教材**（6 大部分、37 章）整理，每章为「知识地图 → 知识点精讲 → 必背表格 → 公式与计算 → 速记卡 → 典型真题 → 易错点 → 数字速记」八段式笔记，章末题目自动进入[刷题系统](/quiz/)（专业大类选「经济基础」）。

## 一、考试概览

| 项目 | 内容 |
|---|---|
| 考试科目 | 《经济基础知识》（各专业共同科目） |
| 本科目满分 | 140 分 |
| 题型与题量 | 单选 70 题 × 1 分、多选 35 题 × 2 分 |
| 成绩管理 | 两年滚动有效，需在连续两个考试年度内通过全部科目 |

::: tip 得分规则
多选**错选不得分，少选所选的每个选项得 0.5 分**。考试安排与复习方法见 [备考总览](/经济师备考/)。
:::

## 二、2026 教材变动提示

- 教材整体变动率约 **25%**，大改集中在第 1、5、8、9、10、14、16、19、23、33、37 章。
- **第 14 章增值税按《增值税法》重写**：小规模纳税人为年应征增值税销售额**未超过 500 万元**；增值税计税期间为 **10 日、15 日、1 个月或 1 个季度**。
- 会计部分名词完善：「实收资本」改为「实收资本（或股本）」，「成本类、费用类」改为「成本（费用）类」。
- 第 37 章不正当竞争行为扩充为 **9 类**；抽奖式有奖销售最高奖超过 **5 万元**即违法。
