## 二、知识点精讲

### 考点1 法学中"经济"的概念（素材未标星级）

**核心概念**：从法学视角来界定，"经济"就是指人们围绕社会物质财富的**生产、交换、分配和消费**过程所进行的各种**社会关系的总和**。

**逻辑链**：

```
社会物质财富
   → 生产（创造）→ 交换（流转）→ 分配（归属）→ 消费（消耗）
   → 四个环节中形成的人与人之间的社会关系
   → 法学视角下称之为「经济」
```

**速记口诀**：**"经法四环：生、换、分、消；四环关系总和就是法眼里的经济。"**

> **「素材未覆盖」提示**：**法的本质与特征**（如法的国家意志性、强制性、规范性、普遍约束力等）在本素材中完全未出现，仅在"法律调整的对象是社会关系"一句中侧面触及。按内容纪律不凭记忆补写，请以现行教材为准。

---

### 考点2 法律对经济关系的调整阶段 ★★★

**总起句（必背）**：法律的调整对象是**社会关系**，调整经济是法律的一项重要功能。从历史的角度看，法律对经济关系的调整经历了**三个阶段**。

| 阶段 | 历史时期 | 调整模式 | 主导力量 |
|---|---|---|---|
| 第一阶段 | 奴隶制社会和封建社会 | **诸法合一，刑法、民法不分** | —— |
| 第二阶段 | 封建社会末期和自由资本主义阶段 | 从诸法合一发展为**刑法、民法分离**；后又分为民法、刑法、行政法，以致发展到**十几个法律部门** | **民商法**起主导作用 |
| 第三阶段 | 当代社会 | 法律体系**重新整合**，民法、商法和经济法**共同**对经济关系进行调整 | 民商法＋经济法共同主导；**社会保障法、环境保护法**等新兴法律部门成为**辅助性**法律部门 |

**逻辑链**：

```
阶段一：诸法合一（刑民不分）—— 奴隶社会、封建社会
   ↓ 封建社会末期起
阶段二：刑民分离 → 分为民法、刑法、行政法 → 十几个法律部门
        主导：民商法（自由资本主义阶段）
   ↓ 当代社会
阶段三：法律体系重新整合
        主导：民法 + 商法 + 经济法（共同调整）
        辅助：社会保障法、环境保护法等新兴法律部门
   ＝ 当代中国的调整模式
```

**当代中国调整模式（真题答案句式）**：**民商法、经济法主导，环境法、劳动法、社会保障法等辅助模式**。

**速记口诀**：**"一合二分三整合：合一刑民不分，二分民商主导，三整合民商经济法并肩、社保环保来辅助。"**

---

### 考点3 "经济法"和"调整经济的法"的区别 ★★★

| 概念 | 定位 | 外延（包括什么） |
|---|---|---|
| **经济法** | 与民法、商法、行政法、刑法等部门法**并列的一个法律部门** | 仅指这一个部门的法律规范 |
| **调整经济的法** | 一国所有调整经济关系的**法律规范的总和** | ①传统法律体系中的**民法、商法**；②近代产生的**经济法**；③调整国内经济关系的法；④调整国际经济关系的**国际私法和国际经济法** |

**逻辑链**：

```
「调整经济的法」（总和，外延大）
   ├─ 民法、商法（传统）
   ├─ 经济法（近代产生）← 只是其中一个部门
   ├─ 调整国内经济关系的法
   └─ 国际私法、国际经济法（调整国际经济关系）

「经济法」（一个部门，外延小）—— 被「调整经济的法」包含
```

**速记口诀**：**"经济法是部门，调整经济的法是总和；部门被总和包，外延小的那个叫经济法。"**

---

### 考点4 民商法 ★★★

**核心定位**：在对市场经济进行规制的法律体系中，**民商法处于基本法地位**。其中**民法是市场经济基本法**，**商法主要调整市场力量发挥作用的经济领域**。

| 部门 | 法律制度构成 | 细分内容 |
|---|---|---|
| **民法** | ①民事主体制度；②物权法和知识产权法；③合同法律制度；④民事责任制度 | 民事主体制度：民事主体种类、民事权利能力、民事行为能力、监护、法人、非法人组织；民事责任制度：违约责任、侵权责任 |
| **商法** | 合伙企业法律制度、公司法律制度、外商投资法律制度、破产法律制度、票据法、证券法、海商法、保险法 | 进一步对市场主体予以构造、规范和保护 |

**逻辑链**：

```
民商法（市场经济规制体系中的基本法）
   ├─ 民法（市场经济基本法）
   │     ├─ 民事主体制度（谁有资格：种类、权利能力、行为能力、监护、法人、非法人组织）
   │     ├─ 物权法 + 知识产权法（财产归属）
   │     ├─ 合同法律制度（交易规则）
   │     └─ 民事责任制度（违约 + 侵权）
   └─ 商法（调整市场力量发挥作用的经济领域）
         合伙企业 / 公司 / 外商投资 / 破产 / 票据 / 证券 / 海商 / 保险
```

**速记口诀**：**"民商法是基本法，民法是基本法的基本法；民法四制：主体、物权知产、合同、责任；商法八类：合伙公司外资破产票据证券海商保险。"**

---

### 考点5 经济法 ★★

**核心定位**：
- 经济法也是**市场经济制度的基本法**，其调整对象主要是**国家对市场经济进行宏观调控所形成的法律关系**。
- 经济法与民商法**协调互补**，构成现代市场经济社会调整经济关系的**两大法律体系**。

**调整对象三类**：

| 类别 | 含义与要点 |
|---|---|
| **经济管理关系** | 国家作为社会管理者运用一系列手段在对宏观经济进行调控过程中所形成的社会关系。四个特征：①是一种**经济关系**（以此区别于行政指导关系）；②以**市场经济体制**为基础；③是**宏观领域**的经济关系，关系国计民生，是对经济进行全局性、整体性调控而形成的；④综合运用各种手段，可划分出各种具体的宏观经济关系：**财政政策、货币政策、产业政策、计划政策** |
| **市场管理关系** | 国家在市场管理过程中所形成的一种社会关系，**由经济法调整**。具体包括：①**维护公平竞争关系**；②**产品质量管理关系**；③**消费者权益保护关系** |
| **组织管理性的流转和协作关系** | 国家通过政府机构或设立企业，委托代理人直接参与经济活动或经济关系，如**招标、订购货、发包、出让、信贷、担保**等活动时发生的合同关系；平等国家机关或财政主体间的经济协作关系。**超出民法调整范畴的"平等主体"之财政关系，应当作为经济法的调整对象** |

**逻辑链**：

```
经济法（市场经济制度的基本法）
   └─ 调整对象：国家对市场经济进行宏观调控所形成的法律关系
         ├─ 经济管理关系（宏观：财政政策、货币政策、产业政策、计划政策）
         ├─ 市场管理关系（监管：公平竞争、产品质量、消费者权益）
         └─ 组织管理性的流转和协作关系（国家直接参与：招标、订购货、发包、出让、信贷、担保）
经济法 + 民商法 ＝ 现代市场经济社会调整经济关系的两大法律体系（协调互补）
```

**速记口诀**：**"经济法三对象：宏观管理、市场管理、组织协作；市场管理三内容：竞争、质量、消费者；国家直接参与六活动：招、订、发、让、贷、担。"**

### 「6 个不等于」避坑表

| # | 不等于 | 正解 |
|---|---|---|
| 1 | "经济法" ≠ "调整经济的法" | 前者是**一个法律部门**，后者是**一国所有调整经济关系的法律规范的总和** |
| 2 | "调整经济的法" ≠ 只包括经济法 | 它还包括**民法、商法**，以及调整国际经济关系的**国际私法和国际经济法** |
| 3 | "经济法"的外延 ≠ 比"调整经济的法"大 | 恰恰相反，**"调整经济的法"包含"经济法"**，外延更大 |
| 4 | 民商法 ≠ 只指民法 | 民商法＝**民法＋商法**，两者共同处于基本法地位 |
| 5 | 商法制度 ≠ 含人格权法律制度 | **人格权法律制度属于民法**；公司、合伙企业、破产法律制度才是商法 |
| 6 | 经济管理关系 ≠ 行政指导关系 | 经济管理关系**是一种经济关系**，以此区别于行政指导关系 |

## 四、关键机制与适用条件

> **「无公式」声明**：本版素材**未包含任何计算公式与计算例题**。按内容纪律，本节不凭记忆补写公式，改为梳理素材中的关键机制与适用条件。

**机制1 法律调整经济关系的演进机制（三阶段递进）**

```
起点：诸法合一（刑民不分）—— 奴隶社会、封建社会
   ↓ 条件：封建社会末期、自由资本主义阶段
中介：刑民分离 → 部门法分化（民法、刑法、行政法……十几个部门），民商法主导
   ↓ 条件：当代社会，法律体系重新整合
归宿：民法 + 商法 + 经济法共同调整；社会保障法、环境保护法等新兴部门法辅助
```

**机制2 "民商法主导"的适用条件**：仅适用于**第二阶段**（封建社会末期和自由资本主义阶段）。当代社会已是民商法与经济法**共同**调整，不能再答"民商法主导模式"。

**机制3 民商法"基本法地位"的适用条件**：限于"在对市场经济进行规制的法律体系中"。民法是市场经济基本法；商法的适用领域是**市场力量发挥作用的经济领域**。

**机制4 经济管理关系的四个适用条件**（缺一不可）：①是一种**经济关系**（区别于行政指导关系）；②以**市场经济体制**为基础；③属**宏观领域**、关系国计民生、具有全局性整体性；④**综合运用各种手段**（财政政策、货币政策、产业政策、计划政策）。

**机制5 市场管理关系的调整机制**：国家在市场管理过程中形成的社会关系，**由经济法调整**，具体落在公平竞争、产品质量、消费者权益保护三处。

**机制6 组织管理性的流转和协作关系的适用条件**：须满足"国家通过政府机构或设立企业，委托代理人**直接参与**经济活动或经济关系"，典型活动为**招标、订购货、发包、出让、信贷、担保**；判据是**超出民法调整范畴的"平等主体"之财政关系，应当作为经济法的调整对象**。

**机制7 辅助性法律部门的适用条件**：当代社会（第三阶段）中，**社会保障法、环境保护法**等新兴法律部门作为调整经济关系的**辅助性**法律部门存在，不占主导。

## 五、高频考点速记卡

1. **Q：法学中"经济"的概念？**
   A：人们围绕社会物质财富的**生产、交换、分配和消费**过程所进行的各种社会关系的总和。

2. **Q：法律的调整对象是什么？**
   A：**社会关系**（法律调整的对象是社会再生产过程中形成的各种关系）。

3. **Q：法律对经济关系的调整经历了哪三个阶段？**
   A：①奴隶制社会和封建社会**诸法合一、刑民不分**；②封建社会末期和自由资本主义阶段**刑民分离**、部门法分化；③当代社会**法律体系重新整合**，民法、商法和经济法共同调整。

4. **Q：哪个阶段对经济关系调整起主导作用的是民商法？**
   A：**第二阶段**（封建社会末期和自由资本主义阶段）。

5. **Q：当代中国的法律对经济关系调整模式是？**
   A：**民商法、经济法主导，环境法、劳动法、社会保障法等辅助模式**。

6. **Q：当代社会的辅助性法律部门有哪些？**
   A：**社会保障法、环境保护法**等新兴法律部门。

7. **Q："经济法"的定位？**
   A：与民法、商法、行政法、刑法等部门法**并列的一个法律部门**。

8. **Q："调整经济的法"指什么？**
   A：一国所有调整经济关系的**法律规范的总和**，既包括民法、商法，也包括经济法；既包括调整国内经济关系的法，也包括调整国际经济关系的国际私法和国际经济法。

9. **Q："经济法"和"调整经济的法"是什么关系？**
   A：**"调整经济的法"包括"经济法"**；"经济法"外延更小。

10. **Q：在对市场经济进行规制的法律体系中，处于基本法地位的是？**
    A：**民商法**。其中民法是市场经济基本法，商法主要调整市场力量发挥作用的经济领域。

11. **Q：民法包括哪些法律制度？**
    A：民事主体制度、物权法和知识产权法、合同法律制度、民事责任制度（违约责任、侵权责任）。

12. **Q：商法包括哪些法律制度？**
    A：合伙企业法律制度、公司法律制度、外商投资法律制度、破产法律制度、票据法、证券法、海商法、保险法。

13. **Q：经济法的调整对象主要是？**
    A：**国家对市场经济进行宏观调控所形成的法律关系**。

14. **Q：经济法调整对象有哪三类？**
    A：**经济管理关系、市场管理关系、组织管理性的流转和协作关系**。

15. **Q：市场管理关系具体包括哪三项？**
    A：维护公平竞争关系、产品质量管理关系、消费者权益保护关系。

16. **Q：经济管理关系的四个特征？**
    A：①是一种**经济关系**（区别于行政指导关系）；②以**市场经济体制**为基础；③是**宏观领域**的关系，关系国计民生、全局性整体性调控；④综合运用各种手段（财政政策、货币政策、产业政策、计划政策）。

17. **Q：组织管理性的流转和协作关系的典型活动？**
    A：国家通过政府机构或设立企业、委托代理人直接参与经济关系时发生的**招标、订购货、发包、出让、信贷、担保**等合同关系。

18. **Q：经济法与民商法的关系？**
    A：经济法与民商法**协调互补**，构成现代市场经济社会调整经济关系的**两大法律体系**。

19. **Q：法律调整经济关系的方式（授权、禁止、强制、鼓励）素材有吗？**
    A：**素材未覆盖**。本版素材完全没有出现该考点，不凭记忆补写，请以现行教材为准。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"经济法"和"调整经济的法"当成一回事 | **经济法＝一个部门；调整经济的法＝全部规范的总和**，前者被后者包含 |
| 2 | 答"经济法的外延比调整经济的法大" | 正好相反：**调整经济的法外延大**，包含经济法 |
| 3 | 以为"调整经济的法"只有经济法 | 它还包括**民法、商法**，以及调整国际经济关系的**国际私法和国际经济法** |
| 4 | 把当代中国的调整模式答成"民商法主导模式" | 民商法主导只属于**第二阶段**；当代是**民商法＋经济法主导、环境法劳动社会保障法等辅助** |
| 5 | 把第一阶段特征记成"刑民分离" | 第一阶段是**诸法合一、刑民不分**；分离是第二阶段的事 |
| 6 | 漏掉"重新整合"这个关键词 | 第三阶段法律体系**重新整合**，民法商法经济法**共同**调整 |
| 7 | 把社会保障法、环境保护法当成主导部门 | 它们是**辅助性**法律部门，主导的是民商法和经济法 |
| 8 | 把人格权法律制度归入商法 | **人格权法律制度属民法**；商法是合伙、公司、外资、破产、票据、证券、海商、保险 |
| 9 | 以为民商法只指民法 | 民商法＝**民法＋商法**，二者共同处于基本法地位 |
| 10 | 把产品质量法、消费者权益保护法选成民商法 | 二者是**市场管理关系**的内容，属经济法调整对象一侧 |
| 11 | 把经济管理关系等同于行政指导关系 | 经济管理关系**是一种经济关系**，以此区别于行政指导关系 |
| 12 | 漏选市场管理关系的第三项 | 三项记牢：**公平竞争、产品质量、消费者权益** |
| 13 | 把合同、物权法律关系归入市场管理关系 | 它们是**民法**调整对象；经济法只管国家调控/市场管理/组织协作三类 |
| 14 | 混淆两大法律体系的构成 | 现代市场经济调整经济关系的两大法律体系＝**经济法＋民商法**（协调互补） |
