> **本章考情**：理解＋记忆并重型章节，四种市场结构的对比是绝对核心（★★★★★）。高频考法集中在六处：①划分市场结构的三个因素；②四种市场结构特征对比（数目/产品差别/价格控制力/进入难度）；③完全竞争"三线合一"与行业、企业需求曲线之别；④完全垄断 MR＜AR 与价格歧视三级分类；⑤垄断竞争的两条需求曲线；⑥寡头垄断的协议价格制与价格领袖制。曲线关系与"不等于"类辨析是选择题重灾区。

## 二、知识点精讲

### 考点1 市场结构的含义和划分标准 ★

**1. 核心概念**

| 概念 | 内容 |
|---|---|
| 市场结构 | 指一个行业内部**买方和卖方的数量及其规模分布、产品差别的程度和新企业进入该行业的难易程度**的综合状态。也可以说，市场结构就是指某种产品或服务的**竞争状况和竞争程度** |
| 划分标准 | 市场的**竞争程度或垄断程度** |

**2. 划分依据的三个因素（多选高频，2024 真题）**

| 序号 | 因素 |
|---|---|
| 1 | 本行业内部的生产者数目或企业数目 |
| 2 | 本行业内各企业生产的产品的差别程度 |
| 3 | 进入障碍的大小 |

**3. 逻辑链**

```
行业内部生产者数目 ──┐
产品差别程度       ──┼──→ 市场的竞争程度 / 垄断程度 ──→ 市场结构的类型（四种）
进入障碍的大小     ──┘
```

**4. 速记口诀**

> **「数、差别、障」**——数目、差别、障碍，三选三不选"对外依存度""技术进步程度"（2024 真题干扰项）。

---

### 考点2 各市场结构的特征 ★★★★★（本章最高频）

**1. 核心对比表（必背，选择题直接对应）**

| 市场类型 | 生产者数目 | 产品差别 | 价格控制力 | 进入退出难易 |
|---|---|---|---|---|
| 完全竞争（信息充分了解） | 很多 | 无差别（同质） | 没有（价格接受者） | 很容易（无障碍） |
| 垄断竞争 | 很多 | 有差别 | 有一些 | 比较容易（障碍小） |
| 寡头垄断 | 几个 | 有差别或无差别 | 相当程度 | 比较困难 |
| 完全垄断 | 唯一 | 独特（无合适替代品） | 很大程度 | 很困难 |

**2. 三条记忆规律（从完全竞争 → 垄断竞争 → 寡头 → 完全垄断）**

- 生产者数目：很多 → 很多 → 几个 → 唯一（**递减**）
- 价格控制力：没有 → 有一些 → 相当程度 → 很大程度（**递增**）
- 进入难度：很容易 → 比较容易 → 比较困难 → 很困难（**递增**）

**3. 各市场结构的详细特征（真题解析原文口径）**

| 市场类型 | 特征 |
|---|---|
| 完全竞争 | ①很多的生产者和消费者；②各企业生产的产品**同质、无质量差别**；③**买卖双方对市场信息有充分了解**；④企业可自由进出市场；⑤每个生产者都是**价格接受者** |
| 完全垄断 | ①只有一个生产者，生产者是**价格的决定者**而非接受者；②产品是**没有合适替代品的独特性产品**；③其他企业进入这一市场**非常困难** |
| 垄断竞争 | ①具有很多的生产者和消费者；②产品具有**差别性**，生产者对价格有**一定程度的控制**；③进入或退出市场**比较容易**，不存在什么进入障碍 |

**4. 选项归属速查（由真题选项反推，快速排除）**

| 常见选项表述 | 归属 |
|---|---|
| 同一行业中只有为数不多的生产者 | **寡头垄断** |
| 少数几个企业控制一个行业的供给 | **寡头垄断** |
| 每个生产者都是价格的决定者 | **完全垄断** |
| 整个行业内有很多生产者和消费者 | **完全垄断的反向描述**（垄断只有一个生产者） |
| 企业生产的产品具有差别性 | **完全垄断的反向描述**（垄断产品是无合适替代品的独特性产品） |
| 同一行业中各生产者生产同一种产品没有质量差别 | **完全竞争** |
| 买卖双方对市场信息有充分的了解 | **完全竞争** |
| 各企业或生产者可自由进出市场 | **完全竞争** |
| 同行业各个企业生产的产品存在一定差别 | **垄断竞争** |
| 生产者对价格有一定程度的控制 | **垄断竞争** |
| 企业进入或退出市场比较容易 | **垄断竞争** |

**5. 关键结论**

- **区分垄断竞争市场和完全竞争市场的主要判断依据＝产品差别程度**（单选题高频）。
- 近似于完全垄断市场的行业：**电力、固定电话服务**等公用事业；煤炭生产、汽车生产、农产品粗加工均不属于（2021 真题）。

**5. 逻辑链**

```
完全竞争：很多企业 + 产品同质 + 自由进出
        → 单个企业无法影响价格
        → 只能接受行业供求决定的价格（价格接受者）

垄断竞争：很多企业 + 产品有差别
        → 企业对价格有一定控制力
        → 但仍面临激烈竞争，进入退出容易

寡头垄断：几家企业
        → 每家都有相当程度价格控制力
        → 相互依存，可能勾结（协议价格）或跟随（价格领袖）

完全垄断：唯一企业 + 无合适替代品 + 进入很困难
        → 企业是价格的决定者
```

**6. 速记口诀**

> **「数目四连降，价格四连升，进门四连难」**：完全竞争"多、同、无、易"；垄断竞争"多、差、一些、较易"；寡头"几个、可有、相当、较难"；完全垄断"唯一、独特、很大、很难"。

### 考点3 完全竞争市场行业和个别企业需求曲线 ★★★★

**1. 核心概念**

| 曲线 | 形状 |
|---|---|
| 完全竞争**行业（整个市场）**需求曲线 | **向右下方倾斜** |
| 完全竞争**个别企业**需求曲线 | **三线合一，平行于横轴的水平线** |

**2. 曲线关系（讲义此处以图呈现，文字+ASCII 复原）**

```
   行业（整个市场）                企业（厂商）
   P                              P
   │        D                     │ PE ──────────── d（水平线）
   │         ╲                    │  ↕ 三线合一：d = AR = MR = P
   │          ╲ S                 │
   │           ╳                  └───────────────→ Q
   └──────────────→ Q                  Q1（任意销售量）
```

**3. 逻辑链（为什么企业需求曲线是水平线）**

```
整个行业的供给曲线 + 需求曲线 共同决定市场价格 P
            ↓
单个企业规模极小，只能是价格的接受者
            ↓
   高于 P 出售 → 一件也卖不出去（消费者可向别家购买）
   低于 P 出售 → 只能是招致损失
            ↓
企业按既定价格 P 可卖出任意数量
            ↓
企业需求曲线 d：平行于横轴的水平线，且 AR = MR = P
```

**4. 速记口诀**

> **「行业右下，企业水平；价格行业定，企业只接受。」**

### 考点4 完全竞争厂商的收益曲线 ★★

**1. 核心概念（三个收益）**

| 收益 | 定义 | 公式 |
|---|---|---|
| 总收益 TR | 企业出售一定数量的产品获得的全部收入 | **TR = P×Q** |
| 平均收益 AR | 按销售量平均计算的收益 | **AR = TR/Q = P** |
| 边际收益 MR | 增加一单位产品的销售时总收益的增加量 | **MR = △TR/△Q = P** |

**2. 曲线关系（讲义此处以图呈现，文字+ASCII 复原）**

```
 完全竞争企业（图b）                完全竞争企业总收益（图a）
 P                                  TR
 │ PE ────────── d                  │      ╱ TR = P×Q（过原点的直线）
 │  ↕ AR = MR = P = d（同一条线）    │    ╱
 │                                   │  ╱
 └──────────→ Q                      └──────────→ Q
```

**3. 逻辑链**

```
价格 P 由行业决定且固定不变
        ↓
每多卖一单位，总收益增加量恒为 P
        ↓
MR = △TR/△Q = P
        ↓
AR = TR/Q = P×Q/Q = P
        ↓
平均收益线 AR、边际收益线 MR、需求曲线 d 是同一条水平线（三线合一）
```

**4. 速记口诀**

> **「三线合一：AR=MR=P=d」**——若见"平均收益曲线、边际收益曲线和需求曲线是同一曲线"，直接判定为**完全竞争市场**。

### 考点5 厂商产量决策的基本原则 ★★★

**1. 核心概念**

| 项目 | 内容 |
|---|---|
| 企业利润 | 总收益－总成本，即 **π = TR－TC** |
| 决策原则 | 厂商利润最大化的条件 **MR = MC** |
| 原则含义 | 利润最大化，亏损最小化（**双重含义**） |
| 停止营业点 | 市场价格 **P = 平均可变成本 AVC** |

**2. 对 MR=MC 的全面理解（2025 真题）**

- 企业在 MR=MC 点上获得了**最大的利润**，但并不是说只要做到 MR=MC 就一定能获得利润。
- 在 MR=MC 点上，企业**可能是盈利的，也可能是亏损的**；如果是亏损的，则这时的亏损**一定是相对最小的**。
- 无论盈利还是亏损，MR=MC 时都是**最优产量**——所以它既可用作**利润最大化的均衡条件**，也可用作**亏损最小的均衡条件**。

**3. 停止营业点的逻辑（讲义此处以图呈现，文字+ASCII 复原）**

```
完全竞争企业的产量决策图：
 P
 │        MC
 │         ╲    ╱
 │          ╲  ╱         ← MC 与 MR 的交点 E：MR=MC，最优产量 Qe
 │   AVC ────╳────────  ← 停止营业点：P = AVC（MC 与 AVC 的交点）
 │    ╲    ╱ E
 │     ╲  ╱
 │  d: AR=MR=P ─────────
 └──────────────→ Q
        Q(停业)   Qe
```

**4. 逻辑链**

```
π = TR － TC
        ↓ 边际分析：每多生产一单位
边际收益 MR vs 边际成本 MC
        ↓
MR > MC → 增加产量能提高利润 → 应扩产
MR < MC → 增加产量会减少利润 → 应减产
        ↓
MR = MC → 利润最大 / 亏损最小（均衡产量）
        ↓
若市场价格 P < AVC → 收益连可变成本都收不回
        → 停止生产，以避免产生更大的亏损（P=AVC 即停止营业点）
```

**5. 速记口诀**

> **「MR=MC，盈亏都最优；P=AVC，营业停止点。」**（注意：停止营业点是 P=AVC，不是 P=AC、P=AFC、P=MC）

### 考点6 完全竞争厂商的供给曲线 ★

**1. 核心概念**

完全竞争企业的短期供给曲线：**位于平均可变成本 AVC 以上的边际成本（MC）部分**。

**2. 曲线关系（讲义此处以图呈现，文字+ASCII 复原）**

```
 P
 │           MC
 │          ╱
 │    ─────╱────────  ← AVC（停止营业点对应的价格水平）
 │      ╱ ╱
 │    ╱ ╱   ← AVC 以上的 MC 段才是短期供给曲线
 │  ╱ ╱
 └────────────→ Q
```

**3. 逻辑链**

```
企业在每一个价格水平下，都按 MR=MC 选择能带来最大利润或最小亏损的产量
        ↓
当 P ≥ AVC 时，MC 曲线上对应的产量就是企业的供给量
        ↓
当 P < AVC 时，企业停止生产（供给量为 0）
        ↓
短期供给曲线 = 位于 AVC 之上的那一段 MC 曲线
```

**4. 速记口诀**

> **「供给曲线，AVC 之上那段 MC。」**（排除"AVC 与 AFC 之间""ATC 之上""AFC 之上"三个干扰项）

### 考点7 完全垄断市场的需求曲线 ★★★★

**1. 完全垄断的形成条件（四种）**

| 形成原因 | 要点 |
|---|---|
| 政府垄断 | 政府垄断 |
| 原材料垄断 | 对某些特殊原材料的单独控制 |
| 专利权垄断 | 专利权垄断 |
| 自然垄断 | 行业中只有一家企业能够有效率地生产，或当一个企业能以**低于两个或更多企业的成本**为整个市场供给一种产品时，该行业就是自然垄断；**和规模经济有密切关系** |

**2. 自然垄断的三个必背结论（2019 真题）**

- 自然垄断是形成**完全垄断的条件之一**（不是形成寡头垄断的条件）。
- 自然垄断**和规模经济有着密切的关系**。
- 注意辨析：**对某些特殊原材料的单独控制而形成的垄断属于"原材料垄断"**，不是自然垄断；"必定能够有效率地进行生产"的绝对化表述不选。

**3. 需求曲线（讲义此处以图呈现，文字+ASCII 复原）**

- 完全垄断企业的需求曲线**向右下方倾斜，斜率为负**。
- **完全垄断企业的需求曲线就是整个行业的需求曲线，两者完全相同**（这是完全垄断与完全竞争市场中企业的一个重要区别）。

```
 P
 │  D（= 企业需求曲线 = 行业需求曲线，向右下方倾斜，斜率为负）
 │   ╲
 │    ╲
 │     ╲
 └──────────→ Q
```

**4. 近似完全垄断的行业**

实际生活中，**公用事业如电力、固定电话业务**近似于完全垄断市场（2021 真题：选"电力、固定电话服务"，不选煤炭生产、汽车生产、农产品粗加工）。

**5. 逻辑链**

```
只有一家企业 + 产品无合适替代品 + 其他企业进入非常困难
        ↓
企业是价格的决定者（而非接受者）
        ↓
想多卖 → 必须降低价格 → 价格与销量反向变动
        ↓
企业需求曲线向右下方倾斜，且 = 整个行业的需求曲线
```

**6. 速记口诀**

> **「垄断四因：政府、原料、专利、自然；需求右下即行业，别无他家可替代。」**

### 考点8 完全垄断企业的平均收益和边际收益 ★★

**1. 核心结论**

- 完全垄断企业的**边际收益不等于其平均收益或价格，而是小于平均收益**。
- MR 曲线位于 AR 曲线的**下方**，而且**比 AR 曲线更陡峭**——说明随着销售量的增加，**边际收益下降得比平均收益更快**。
- 完全垄断企业的**需求曲线与平均收益曲线重合**（2021 真题）。

**2. 曲线关系（讲义此处以图呈现，文字+ASCII 复原）**

```
 P
 │  D = AR（向右下方倾斜）
 │   ╲
 │    ╲        MR（位于 AR 下方，且更陡峭）
 │     ╲      ╱
 │      ╲    ╱
 │       ╲  ╱
 │        ╲╱
 │        ╱╲
 └──────────────→ Q
   MR < AR，且 MR 比 AR 下降得更快
```

**3. 逻辑链**

```
垄断企业面对向右下方倾斜的需求曲线
        ↓
想增加销量 → 必须降低全部（而非仅新增）单位的价格
        ↓
新增一单位带来的收益增量（MR）小于该单位的售价（AR=P）
        ↓
MR < AR；且销量越大，MR 比 AR 下降得越快（MR 曲线更陡峭）
```

**4. 速记口诀**

> **「MR 在 AR 下，还更陡；需求曲线就是 AR。」**

---

### 考点9 完全垄断企业进行产量和价格决策基本原则 ★★

**1. 核心原则**

完全垄断企业进行产量和价格决策的基本原则：**边际成本等于边际收益（MR = MC）**。

**2. 逻辑链**

```
垄断企业面临向右下方倾斜的需求曲线（MR < AR = P）
        ↓
与完全竞争相同，仍遵循边际分析
        ↓
MR = MC 时，企业利润最大 / 亏损最小
        ↓
先用 MR = MC 定出均衡产量，再沿需求曲线找出对应的价格
```

**3. 速记口诀**

> **「垄断也讲 MR=MC；先定量，后找价。」**

---

### 考点10 完全垄断企业定价的简单法则 ★

**1. 核心内容**

- 一个垄断企业索取的价格超过边际成本的程度，**受制于需求价格弹性**。
- **弹性低，定价高；弹性高，定价低。**
- 公式：**P = MC / (1 + 1/Ed)**

**2. 逻辑链**

```
定价高出边际成本的空间 ← 由需求价格弹性决定
        ↓
|Ed| 小（需求缺乏弹性）→ 消费者对价格不敏感 → 可定高价
|Ed| 大（需求富有弹性）→ 消费者对价格敏感   → 只能定低价
        ↓
P = MC / (1 + 1/Ed)
```

**3. 速记口诀**

> **「弹性低价就高，弹性高价就低；定价看弹性，公式 P=MC/(1+1/Ed)。」**

### 考点11 价格歧视 ★★★★

**1. 核心概念**

| 项目 | 内容 |
|---|---|
| 定义 | 也称**差别定价**，以不同价格销售同一种产品 |
| 实施条件① | 必须有可能**根据不同的需求价格弹性划分出两组或两组以上不同的购买者** |
| 实施条件② | 市场必须是**能够有效隔离开**的，**同一产品不能在不同市场间流动** |

**2. 价格歧视的分类（三级，必考）**

| 类型 | 含义 | 典型形式 |
|---|---|---|
| 一级价格歧视 | 垄断厂商对**每一单位产品**都按消费者所愿意支付的**最高价格**出售 | 一对一讨价还价 |
| 二级价格歧视 | 垄断厂商对**不同的消费数量段**规定不同的价格 | 按不同批量/数量段定价，每个购买相同批量产品的购买者支付的价格相同 |
| 三级价格歧视 | 垄断厂商对**不同需求价格弹性的消费者**收取不同的价格 | 大学生硬座优惠 |

**3. 基本原则**

- 三级价格歧视要求厂商在**需求价格弹性小的市场上定较高价格**，在**需求价格弹性大的市场上定较低价格**。
- 企业实行价格歧视的基本原则：**不同市场上的边际收益相等且等于边际成本**。

**4. 两个重要限定**

- 价格歧视是在**完全垄断市场上**实施的（"垄断竞争市场上企业经常实施价格歧视"为错误表述）。
- **完全垄断市场上不存在供给曲线**（2022 真题）。

**5. 逻辑链**

```
同一产品 + 不同的购买者/不同的购买数量
        ↓ 前置条件：①可按需求价格弹性分组 ②市场能有效隔离、产品不能跨市场流动
        ↓
一级：每一单位都按最高愿意支付价售出（一对一讨价还价）
二级：按消费数量段分别定价
三级：按需求价格弹性对消费者分组定价
        ↓ 分组定价方向
弹性小的市场 → 定较高价格
弹性大的市场 → 定较低价格
        ↓
总原则：各市场边际收益相等且等于边际成本（MR₁=MR₂=MC）
```

**6. 速记口诀**

> **「一级按单位（最高价），二级按量段，三级按人群；弹性小处定价高，各处 MR 等于 MC。」**

---

### 考点12 垄断竞争市场上生产者的行为 ★★★★

**1. 需求曲线特征**

- 垄断竞争市场单个企业的需求曲线**向右下方倾斜**。
- 垄断竞争企业之间产品存在一定的可替代性、存在竞争关系，使得垄断竞争企业的需求曲线和**完全垄断企业的需求曲线相比比较平坦**。
- 和**完全竞争市场的水平形状比较接近**。
- 每个具体企业的需求曲线**不同于市场需求曲线**（行业的需求曲线与个别企业的需求曲线是不同的）。

**2. 两条需求曲线（本节独有，高频）**

| 曲线 | 别称 | 含义 |
|---|---|---|
| 主观需求曲线 | 预期需求曲线 | 当某一企业改变其产品价格，而**其他企业并不改变各自的产品价格**时，该企业的产品价格和销售量之间的关系 |
| 实际需求曲线 | 市场份额需求曲线 | 一个企业降低价格，**其他企业会相应地调整自己的价格**，从而使整个行业的价格和销量的关系改变；表示单个企业在每一个市场价格水平的**实际销售份额**——如果一个行业有 n 个企业，不管这些企业将市场价格变动到什么水平，每个企业的实际销售份额为市场总销售量的 **1/n** |

**关键结论**：**主观需求曲线比市场份额（实际）需求曲线需求弹性更大，更平坦。**

**3. 短期均衡**

- 短期均衡条件：**MR = MC**（与完全垄断企业相同的利润最大化原则，选择 MR=MC 的产量，然后用其需求曲线找出与这种产量相对应的价格）。
- 在短期中，垄断竞争企业**是一个垄断者**。
- 垄断竞争市场的产量**一般低于完全竞争市场的产量**。

**4. 供给曲线**

- 和完全垄断市场相同，**垄断竞争市场上不存在供给曲线**。

**5. 曲线关系（讲义此处以图呈现，文字+ASCII 复原）**

```
主观需求曲线 d（预期）          实际需求曲线 D（市场份额）
P                              P
│    d（更平坦）               │   D（更陡峭）
│     ╲                        │    ╲
│      ╲                       │     ╲
│       ╲                      │      ╲
│        ╲                     │       ╲
└──────────→ Q                 └───────────→ Q
弹性更大、更平坦                弹性更小、更陡峭
（其他企业不降价时）（其他企业跟着降价时，实际份额只剩 1/n）
```

**6. 逻辑链**

```
企业数量很多 + 产品有差别
        ↓
企业对价格有一定控制能力 → 需求曲线向右下方倾斜（而非水平线）
        ↓
产品可相互替代 + 竞争关系 → 曲线比完全垄断平坦、接近完全竞争的水平形状
        ↓
本企业降价时：别的企业不跟 → 销量大增（主观 d，平坦）
             别的企业跟涨跟跌 → 实际份额受限（实际 D，陡峭，仅 1/n）
        ↓
短期按 MR = MC 定产量（此时企业类似一个垄断者）
        ↓
与完全垄断相同：不存在供给曲线
```

**7. 速记口诀**

> **「右下倾斜比垄断平，两条曲线主更平；短期 MR=MC 似垄断，没有供给曲线记清。」**

### 考点13 寡头垄断市场上生产者行为 ★★

**1. 两种价格形成方式**

| 方式 | 概念 | 方式/特点 |
|---|---|---|
| 协议价格制 | 生产者或销售者之间存在某种**市场份额划分协议**的条件下，生产者和销售者共同维持一个协议价格，使行业净利润最大 | 方式：**限制各生产者的产量，使行业边际收益等于行业边际成本**。特点：划分市场份额困难、**不稳定**，受反垄断法严格禁止 |
| 价格领袖制 | 行业中**占支配地位的企业率先确定价格**，其他企业参考保持一致 | 特点：不能只考虑自己企业利益，**要考虑整个行业利益** |

**2. 卡特尔**

- 当一些企业联合起来一起行动，就形成了**卡特尔**。
- 卡特尔要考虑对非垄断企业的影响，可能私下违背协议；许多卡特尔是**不稳定的**，也很难长期存在下去。
- 在我国或其他一些国家，企业之间实施价格共谋或卡特尔是一种**违法行为**，受到反垄断法律法规的严格禁止。

**3. 逻辑链**

```
只有几家企业进行竞争，彼此相互依存
        ↓
方式一：勾结共谋 → 达成产量/价格协议（卡特尔）
        → 限制各生产者产量，使行业 MR = 行业 MC，行业净收益最大
        → 但划分市场份额困难、不稳定、受反垄断法禁止
方式二：不公开勾结 → 价格领袖制
        → 占支配地位企业率先定价，其他企业跟随
        → 领袖定价须顾及整个行业利益
```

**4. 速记口诀**

> **「协议价格限产量，行业 MR=MC；卡特尔不稳反垄断；价格领袖随支配，要考虑全行业。」**

### 考点14 完全竞争生产者的要素需求曲线 ★★（素材附带章节）

> 说明：本考点与下一考点来自素材附带章节「完全竞争生产者对生产要素的需求」（属生产要素市场理论），与完全竞争生产者行为紧密相连，一并收录。

**1. 核心内容**

| 考法 | 要素供给曲线 | 要素需求曲线 |
|---|---|---|
| 形状 | **平行于横轴的水平线** | **向右下方倾斜** |
| 重合关系 | 要素供给曲线 = 平均要素成本（AFC）曲线 = 边际要素成本（MFC）曲线（三线合一） | 要素需求曲线 = 边际收益产品（MRP）曲线 = 边际产品价值（VMP）曲线（= P·MP） |

**2. 曲线关系（讲义此处以图呈现，文字+ASCII 复原）**

```
完全竞争生产者要素供给曲线          完全竞争生产者要素需求曲线
W                                   W
│ W₁ ────────────── MFC=AFC=W       │      VMP = MRP = P·MP
│  （水平线，价格接受者）            │       ╲
│                                    │        ╲  向右下方倾斜
└──────────→ L                       └──────────→ L
```

**3. 逻辑链**

```
完全竞争生产者在购买要素时是完全竞争的
        ↓
生产者完全是要素市场价格的接受者
        ↓
面临的要素供给曲线是一条水平线，MFC = AFC = 要素价格 W
        ↓
要素边际产量递减 → 边际产品价值 VMP = P·MP 递减
        ↓
要素需求曲线（MRP=VMP）向右下方倾斜
```

**4. 速记口诀**

> **「要素供给水平线，MFC=AFC=W；要素需求右下斜，MRP=VMP=P·MP。」**

### 考点15 完全竞争市场的要素需求曲线 ★（素材附带章节）

**1. 核心内容**

- 完全竞争市场的要素需求量：在某一价格下，**整个市场上所有生产者需求量之和**。
- 当整个市场上的所有生产者都根据要素价格的变化调整产量时，**产品价格就会发生变化**，所以生产者的要素需求曲线会变得**更陡峭**。

**2. 易混点（多选题高频）**

- 当产品价格变化时，生产者的要素需求曲线会**平移**（VMP = P×MP 中的 P 变化），但**不会改变其斜率或"平坦度"**——曲线斜率取决于边际产量（MP）的变化率，而非价格水平。
- 完全竞争生产者**无法控制要素价格**，是要素市场的价格接受者，不是价格控制者。

**3. 逻辑链**

```
单个厂商：要素需求曲线由 VMP=P·MP 决定，向右下方倾斜
        ↓
整个市场：要素需求量 = 所有生产者需求量之和
        ↓
所有生产者都随要素价格变化调整产量 → 产品价格随之变化 → VMP 进一步下移
        ↓
市场的要素需求曲线比单个厂商的要素需求曲线更陡峭
```

**4. 速记口诀**

> **「全行业调产量，产品价格跟着变，要素需求更陡峭；价格变只平移，不改陡峭度。」**

| 6 | MR=MC ≠ 一定盈利 | 可能盈利也可能亏损；若亏损，则一定是**最小亏损** |
| 7 | 停止营业点 P=AVC ≠ P=AC / P=AFC / P=MC | 停止营业点是**市场价格等于平均可变成本 AVC** |
| 8 | 完全竞争企业短期供给曲线 ≠ AVC 与 AFC 之间的 MC / ≠ ATC 之上的 MC | 是**位于 AVC 之上的 MC 曲线** |
| 9 | 一级价格歧视 ≠ 按消费数量段定价 | 一级是**每一单位**都按消费者愿意支付的最高价格；按数量段是**二级** |
| 10 | 三级价格歧视 ≠ 按购买者收入水平划分 | 是按**需求价格弹性**划分（弹性小定高价、弹性大定低价） |
| 11 | 自然垄断 ≠ 对特殊原材料的单独控制 | 原材料单独控制属"原材料垄断"；自然垄断与**规模经济**相关，是**完全垄断**的成因之一，不是寡头垄断的成因 |
| 12 | 价格歧视 ≠ 在垄断竞争市场上经常实施 | 价格歧视是在**完全垄断市场**上实施的 |
| 13 | 主观需求曲线 ≠ 实际（市场份额）需求曲线 | 主观（预期）曲线弹性**更大、更平坦**；实际曲线更陡峭，n 个企业时每家实际份额为 **1/n** |
| 14 | 协议价格制 ≠ 价格领袖制 | 协议价格制是**共谋**（限产量使行业 MR=MC）；价格领袖制是**支配企业率先定价、其他跟随** |
| 15 | 卡特尔 ≠ 稳定长久 | 卡特尔不稳定、难长期存在，受**反垄断法严格禁止** |
| 16 | 划分市场结构的依据 ≠ 对外依存度 / 技术进步程度 | 只有三个：生产者数目、产品差别程度、进入障碍大小 |
| 17 | 完全竞争生产者面临的要素供给曲线 ≠ 向右上方倾斜 | 是**水平线**（要素价格接受者），MFC=AFC=W 三线重合 |
| 18 | 产品价格变化 ≠ 改变要素需求曲线的斜率 | 价格变化只使要素需求曲线**平移**，斜率（陡峭度）取决于 MP 的变化率 |

### 表4 垄断竞争企业 vs 完全垄断企业：需求曲线异同（高频辨析）

| 比较项 | 垄断竞争企业 | 完全垄断企业 |
|---|---|---|
| 曲线形状 | 向右下方倾斜 | 向右下方倾斜（**相同**） |

| 短期决策原则 | MR=MC | MR=MC（**相同**） |
| 供给曲线 | 不存在 | 不存在（**相同**） |

## 四、公式与计算

### 4.1 完全竞争厂商的收益公式

| 公式 | 含义 |
|---|---|
| **TR = P×Q** | 总收益 = 价格 × 销售量 |
| **AR = TR/Q = P** | 平均收益 = 总收益 / 销售量 = 价格 |
| **MR = △TR/△Q = P** | 边际收益 = 总收益增量 / 销量增量 = 价格 |
| **AR = MR = P = d** | 三线合一：平均收益线、边际收益线、需求曲线是同一条水平线 |

**【演算例题1】** 某完全竞争企业面对的市场价格为 P=10 元/件，当期销售 Q=100 件。
- 总收益 TR = P×Q = 10×100 = **1000 元**
- 平均收益 AR = TR/Q = 1000/100 = **10 元 = P**
- 销量从 100 件增至 101 件：TR 增至 10×101 = 1010 元
- 边际收益 MR = △TR/△Q = (1010−1000)/(101−100) = **10 元 = P**
- **结论**：完全竞争下 AR=MR=P，三条收益线重合为一条水平线。

### 4.2 停止营业点

| 公式 | 含义 |
|---|---|
| **P = AVC** | 停止营业点（停止生产的临界点） |
| π = TR − TC | 利润 = 总收益 − 总成本 |

**判定规则**：P＞AVC → 继续生产（收益弥补全部可变成本后还有剩余弥补固定成本）；P＜AVC → 连可变成本都收不回，应停止生产以避免更大亏损。

**【演算例题2】** 某完全竞争企业产量 Q=100 件，市场价格 P=5 元/件，总可变成本 TVC=400 元，总固定成本 TFC=200 元。
- AVC = TVC/Q = 400/100 = **4 元**；AFC = TFC/Q = 200/100 = **2 元**；AC = AVC+AFC = **6 元**
- 总收益 TR = 5×100 = **500 元** ＞ TVC=400 元 → 弥补全部可变成本后还剩 100 元用于弥补固定成本
- 亏损 = TC−TR = 600−500 = **100 元** ＜ TFC=200 元 → **应继续生产**（停产则亏损全部固定成本 200 元）
- 若价格跌至 P=3 元：TR=300 元 ＜ TVC=400 元 → 连可变成本都收不回 → **应停止营业**
- **结论**：P=AVC=4 元即为停止营业点。

### 4.3 完全垄断厂商的收益曲线关系

| 公式 | 含义 |
|---|---|
| **TR = P(Q)×Q** | 总收益随价格（需求量）变化 |
| **MR ＜ AR = P** | 边际收益小于平均收益（价格） |
| MR 曲线位于 AR 曲线**下方且更陡峭** | 销量增加时，边际收益比平均收益下降得更快 |

**【演算例题3】** 某完全垄断企业面对的需求曲线为 P = 10 − Q（元/件）。
- 总收益 TR = P×Q = (10−Q)×Q = 10Q − Q²
- 列表计算：

| Q | P（=AR） | TR | MR=△TR/△Q |
|---|---|---|---|
| 1 | 9 | 9 | 9 |
| 2 | 8 | 16 | 7 |
| 3 | 7 | 21 | 5 |
| 4 | 6 | 24 | 3 |

- **结论**：每一销量下 MR 都小于 AR（如 Q=3 时 AR=7 而 MR=5）；且 AR 每降 1 元，MR 降 2 元——**MR 比 AR 下降得更快**（MR 曲线更陡峭）。

### 4.4 完全垄断企业定价的简单法则

| 公式 | 含义 |
|---|---|
| **P = MC / (1 + 1/Ed)** | 价格超出边际成本的程度受需求价格弹性制约 |
| 弹性低 → 定价高；弹性高 → 定价低 | Ed 为负值（需求定理），若已知弹性绝对值 \|Ed\|，则 P = MC/(1 − 1/\|Ed\|) |

**【演算例题4】** 某垄断企业边际成本 MC=20 元，面临市场的需求价格弹性绝对值 |Ed|=2（即 Ed=−2）。
- P = MC/(1+1/Ed) = 20/(1+1/(−2)) = 20/(1−0.5) = **40 元**
- 加价幅度 = P−MC = 40−20 = **20 元**，加价率 = (P−MC)/P = 50%
- 若 |Ed|=4：P = 20/(1−0.25) ≈ **26.7 元**，加价率仅 25%
- **结论**：需求价格弹性越小，价格超出边际成本的程度越大（定价越高）。

### 4.5 价格歧视（三级）

| 公式/原则 | 含义 |
|---|---|
| 一级价格歧视 | 每一单位产品都按消费者愿意支付的最高价格出售 |
| 二级价格歧视 | 对不同消费数量段规定不同价格 |
| 三级价格歧视 | 对不同需求价格弹性的消费者收取不同价格；**弹性小的市场定高价，弹性大的市场定低价** |
| **MR₁ = MR₂ = … = MC** | 实行价格歧视的基本原则：不同市场上的边际收益相等且等于边际成本 |

**【演算例题5】** 某垄断者可在两个相互隔离的市场实行三级价格歧视，边际成本 MC=20 元。市场1 需求价格弹性绝对值 |Ed₁|=1.5，市场2 的 |Ed₂|=4。
- 市场1：P₁ = 20/(1−1/1.5) = 20/(1−0.667) ≈ **60 元**
- 市场2：P₂ = 20/(1−1/4) = 20/0.75 ≈ **26.7 元**
- 验证基本原则：MR = P×(1+1/Ed)
  - 市场1：60×(1−0.667) ≈ 60×0.333 ≈ **20 = MC**
  - 市场2：26.7×(1−0.25) = 26.7×0.75 ≈ **20 = MC**
- **结论**：MR₁ = MR₂ = MC = 20 元，符合"不同市场边际收益相等且等于边际成本"；且弹性小的市场1 定价（60 元）远高于弹性大的市场2（26.7 元）。

### 4.6 生产要素市场公式（素材附带章节）

| 公式 | 含义 |
|---|---|
| **MFC = AFC = W** | 完全竞争生产者的边际要素成本、平均要素成本、要素供给曲线三线重合，均为水平线 |
| **MRP = VMP = P·MP** | 边际收益产品 = 边际产品价值 = 产品价格 × 边际产量（完全竞争下边际收益=P） |
| **MFC = MRP** | 生产者使用生产要素的原则：边际要素成本等于边际收益产品 |

**【演算例题6】** 某完全竞争生产者面临的产品价格 P=10 元，要素的边际产量 MP=5 件/人，要素价格 W=50 元/人。
- 边际产品价值 VMP = P×MP = 10×5 = **50 元/人**
- 完全竞争下 MR=P，故边际收益产品 MRP = MP×MR = 5×10 = **50 元/人**
- 要素供给曲线为水平线：MFC = AFC = W = **50 元/人**
- 均衡条件 MFC = MRP：50 = 50，成立 → 该要素投入量即为最优
- **结论**：完全竞争下 MRP 与 VMP 重合，要素需求曲线即 VMP 曲线，向右下方倾斜；要素供给曲线是高度为 W 的水平线。

> 说明：以上演算例题为编者依据素材所给公式自编的数值示例，用于理解公式运用，非素材原题；考试真题以「六、典型真题」收录内容为准。

## 五、高频考点速记卡

1. **Q：市场结构的含义和划分标准？**
   A：市场结构是一个行业内部买方和卖方的数量及其规模分布、产品差别程度和新企业进入难易程度的综合状态，即某种产品或服务的竞争状况和竞争程度；划分标准是市场的竞争程度或垄断程度。

2. **Q：划分市场结构依据哪三个因素？**
   A：①本行业内部的生产者数目或企业数目；②本行业内各企业生产的产品的差别程度；③进入障碍的大小。

3. **Q：区分垄断竞争市场和完全竞争市场的主要依据？**
   A：**产品的差别程度**。

4. **Q：四种市场结构的生产者数目、价格控制力、进入难度怎么排？**
   A：数目：很多→很多→几个→唯一；价格控制力：没有→有一些→相当程度→很大程度；进入难度：很容易→比较容易→比较困难→很困难。

5. **Q：完全竞争市场的特征？**
   A：很多的生产者和消费者；产品同质无质量差别；买卖双方信息充分了解；可自由进出市场；每个生产者都是价格接受者。

6. **Q：完全垄断市场三大特征？**
   A：只有一个生产者（价格决定者）；产品是没有合适替代品的独特性产品；其他企业进入非常困难。

7. **Q：垄断竞争市场三大特征？**
   A：具有很多的生产者和消费者；产品具有差别性、生产者对价格有一定程度控制；进入或退出市场比较容易、不存在什么进入障碍。

8. **Q：完全竞争行业需求曲线与个别企业需求曲线有何不同？**
   A：行业需求曲线向右下方倾斜；个别企业需求曲线是平行于横轴的水平线（三线合一，AR=MR=P）。价格由整个行业的供给和需求曲线决定，企业只是价格接受者。

9. **Q：完全竞争厂商的收益线关系？**
   A：平均收益线 AR、边际收益线 MR、需求曲线是同一条水平线，AR=MR=P；TR=P×Q。

10. **Q：厂商产量决策的基本原则及其双重含义？**
    A：MR=MC。盈利时是利润最大化条件，亏损时是亏损最小化条件——MR=MC 时可能盈利也可能亏损，若亏损则一定是最小亏损。

11. **Q：什么是停止营业点？**
    A：市场价格 P 等于平均可变成本 AVC 之处。P＜AVC 时应停止生产，以避免产生更大的亏损。

12. **Q：完全竞争厂商的短期供给曲线是什么？**
    A：位于平均可变成本 AVC 之上的边际成本曲线，表示企业在每一价格水平的供给量都是能带来最大利润或最小亏损的最优产量。

13. **Q：完全垄断形成的四个条件？**
    A：政府垄断、原材料垄断、专利权垄断、自然垄断。

14. **Q：什么是自然垄断？**
    A：行业中只有一家企业能够有效率地生产，或一个企业能以低于两个或更多企业的成本为整个市场供给一种产品的行业；与规模经济密切相关，是形成完全垄断的条件之一。

15. **Q：完全垄断企业的需求曲线和收益曲线关系？**
    A：需求曲线就是行业需求曲线，向右下方倾斜、斜率为负；边际收益 MR 小于平均收益 AR，MR 位于 AR 下方且更陡峭；需求曲线与平均收益曲线重合。

16. **Q：垄断企业定价的简单法则？**
    A：价格超出边际成本的程度受制于需求价格弹性——弹性低定价高、弹性高定价低；公式 P=MC/(1+1/Ed)。

17. **Q：价格歧视的含义、实施条件与三级分类？**
    A：以不同价格销售同一种产品。条件：①能按不同需求价格弹性划分出两组及以上购买者；②市场能有效隔离、同一产品不能在不同市场间流动。一级——每一单位按消费者愿意支付的最高价格（一对一讨价还价）；二级——按不同消费数量段；三级——按不同需求价格弹性的消费者。

18. **Q：价格歧视的基本原则？**
    A：三级价格歧视在需求价格弹性小的市场定较高价格、在弹性大的市场定较低价格；总原则是不同市场上的边际收益相等且等于边际成本。

19. **Q：垄断竞争企业的两条需求曲线？**
    A：主观需求曲线（预期需求曲线，其他企业不调价时）和实际需求曲线（市场份额需求曲线，其他企业跟着调价时）；主观曲线比实际曲线弹性更大、更平坦；n 个企业时每个企业的实际销售份额为市场总销售量的 1/n。

20. **Q：寡头垄断市场两种价格形式？哪些市场没有供给曲线？**
    A：协议价格制（限产量使行业 MR=MC，卡特尔不稳定、受反垄断法禁止）和价格领袖制（支配企业率先定价，须考虑全行业利益）。完全垄断、垄断竞争、寡头垄断市场均不存在供给曲线；只有完全竞争市场有（AVC 之上的 MC）。

### 第一节 市场结构的类型

**【2024·多选】划分一个行业属于什么类型的市场结构，依据的因素主要有（　）。**
A. 本行业的对外依存度高低　B. 本行业内各企业生产的产品的差别程度　C. 本行业内部的生产者数目或企业数目　D. 进入障碍的大小　E. 本行业的技术进步程度

**答案：BCD**
**解析**：划分市场结构依据三个因素：本行业内部的生产者数目或企业数目、本行业内各企业生产的产品的差别程度、进入障碍的大小。对外依存度、技术进步程度均不是划分依据。

### 第二节 完全竞争市场上生产者的行为

**【2024·单选】关于完全竞争市场行业需求曲线说法正确的（　）。**
A. 个别企业的需求曲线是一条平行横轴的水平线　B. 整个行业的需求曲线和企业曲线是相同的　C. 整个行业的需求曲线是一条向右上方倾斜的曲线　D. 个别企业的需求曲线是一条右下方倾斜的曲线

**答案：A**
**解析**：在完全竞争市场，企业以低于或高于市场价格的价格出售其产品都是不利的。提高价格则产品一件也卖不出去（消费者可从别家购买），降低价格只能是招致损失。因此，个别企业的需求曲线是一条平行于横轴的水平线。

**【2022·单选】从坐标图上看，在完全竞争市场上，单个企业的需求曲线是一条（　）。**
A. 与横轴相平行的水平线　B. 与整个行业的需求曲线相同　C. 与纵轴并行的垂直线　D. 向右下方倾斜的曲线

**答案：A**
**解析**：在完全竞争市场上，个别企业的需求曲线是一条平行于横轴的水平线。

**【2010·多选】关于完全竞争市场的说法，正确的有（　）。**
A. 个别企业的需求曲线和整个行业的需求曲线相同　B. 所有企业都是价格的接受者　C. 个别企业的需求曲线是一条平行于横轴的水平线　D. 不同企业生产的产品存在差别　E. 整个行业的需求曲线向右下方倾斜

**答案：BCE**
**解析**：完全竞争市场上，整个行业的需求曲线和某个企业的需求曲线是不同的；价格由整个行业的供给和需求曲线决定，企业只是价格的接受者；个别企业的需求曲线是平行于横轴的水平线；整个行业的需求曲线向右下方倾斜；完全竞争市场上不同企业生产的产品是同质的。故 A、D 错误。

**【2025·单选】完全竞争市场上，某厂商在目前的产量水平上满足边际成本等于边际收益，此时（　）。**
A. 如果盈利，不可能得到最大利润　B. 应当继续调整产量规模　C. 一定是亏损状态　D. 如果亏损，应是最小亏损

**答案：D**
**解析**：企业在 MR=MC 点上获得了最大的利润，但并不是说只要做到 MR=MC 就一定能获得利润。在 MR=MC 点上，企业可能是盈利的，也可能是亏损的；如果亏损，则这时的亏损一定是相对最小的。无论盈利还是亏损，MR=MC 时都是最优产量——所以它既可看作利润最大化的均衡条件，也可看作亏损最小的均衡条件。

**【2025 真题（11.2 上午）·单选】关于完全竞争生产者行为的说法，正确的是（　）。**
A. 完全竞争生产者的需求曲线是一条水平线　B. 完全竞争生产者的边际收益曲线与供给曲线重合　C. 完全竞争生产者不存在供给曲线　D. 完全竞争生产者的边际成本曲线是一条水平线

**答案：A**
**解析**：完全竞争市场上，个别企业的需求曲线是一条平行于横轴的水平线，A 正确。完全竞争企业的短期供给曲线是处于平均可变成本之上的边际成本曲线，C 错误。完全竞争生产者的边际成本曲线是"U 型"，受边际报酬递减规律影响先降后升，并非水平线，D 错误。因为在完全竞争市场上价格、平均收益和边际收益都相等，企业的平均收益曲线、边际收益曲线和需求曲线都是同一条水平线，B 错误。

### 第三节 完全垄断市场上生产者的行为

**【2021·多选】在现实世界中，近似于完全垄断市场的行业有（　）。**
A. 煤炭生产　B. 汽车生产　C. 电力　D. 农产品粗加工　E. 固定电话服务

**答案：CE**
**解析**：在实际生活中，公用事业如电力、固定电话业务近似于完全垄断市场。

**【2019·多选】关于自然垄断的说法，正确的有（　）。**
A. 自然垄断是对某些特殊的原材料的单独控制而形成的对这些资源和产品的完全垄断　B. 自然垄断是形成寡头垄断的条件之一　C. 自然垄断是形成完全垄断的条件之一　D. 自然垄断和规模经济有着密切的关系　E. 自然垄断必定能够有效率地进行生产

**答案：CD**
**解析**：自然垄断是指当行业中只有一家企业能够有效率地进行生产，或者当一个企业能以低于两个或更多企业的成本为整个市场供给一种产品时，这个行业就是自然垄断。自然垄断与规模经济有着密切的关系，属于完全垄断的形成原因之一。A 描述的是"原材料垄断"；B 错，自然垄断不是形成寡头垄断的条件；E"必定"表述绝对化，不选。

**【2021·单选】关于完全垄断企业的需求曲线和收益曲线的说法正确的是（　）。**
A. 边际收益曲线和平均收益曲线重合　B. 边际收益曲线位于平均收益曲线上方　C. 需求曲线与边际收益曲线重合　D. 需求曲线与平均收益曲线重合

**答案：D**
**解析**：MR 为边际收益曲线，位于平均收益曲线的下方，而且比平均收益曲线陡峭，说明随着销售量的增加，边际收益下降得比平均收益更快。需求曲线与平均收益曲线重合。

**【2022·单选】关于完全垄断市场是否存在供给曲线及其特征的说法，正确的是（　）。**
A. 完全垄断厂商的供给曲线是其边际成本曲线　B. 完全垄断厂商的供给曲线是其处于平均可变成本之上的边际成本曲线　C. 完全垄断厂商的供给曲线是其处于平均总成本之上的边际成本曲线　D. 完全垄断市场上不存在供给曲线

**答案：D**
**解析**：在完全垄断市场上不存在供给曲线。

### 第四节 垄断竞争市场和寡头垄断市场上生产者的行为

**【2021·多选】关于垄断竞争市场生产者行为和价格的说法，正确的有（　）。**
A. 垄断竞争市场存在供给曲线　B. 个别生产者的需求曲线是向右下方倾斜的　C. 垄断竞争企业面对两条不同的需求曲线　D. 在短期中，垄断竞争企业是一个垄断者　E. 垄断竞争行业是政府价格干预的重点领域

**答案：BCD**
**解析**：和完全垄断市场相同的是，垄断竞争市场上不存在供给曲线，A 错误。与完全垄断市场上的企业相同，垄断竞争市场上企业的需求曲线是向右下方倾斜的，而不是一条水平线，B 正确。垄断竞争企业面临的需求曲线有两种，分别称为主观需求曲线和实际需求曲线，C 正确。在短期中，垄断竞争企业是一个垄断者，D 正确。

**【2024·单选】关于垄断竞争市场及其生产者行为的说法，正确的是（　）。**
A. 垄断竞争市场上不存在供给曲线　B. 垄断竞争市场上，价格是由整个行业的供给和需求曲线决定的　C. 垄断竞争市场上生产者往往会实施价格歧视　D. 垄断竞争市场上生产者倾向于实施价格领袖制

**答案：A**
**解析**：和完全垄断市场相同的是，垄断竞争市场上不存在供给曲线。

**【2024·单选】关于垄断竞争市场上供给曲线的说法，正确的是（　）。**
A. 垄断竞争市场上不存在供给曲线　B. 垄断竞争企业处于平均固定成本之上的边际成本曲线　C. 垄断竞争企业处于平均总成本之上的边际成本曲线　D. 垄断竞争企业处于平均可变成本之上的边际成本曲线

**答案：A**
**解析**：和完全垄断市场相同的是，垄断竞争市场上不存在供给曲线。

**【2025·单选】关于垄断竞争市场的说法正确的是（　）。**
A. 垄断竞争市场的供给曲线向右上方倾斜　B. 垄断竞争市场上生产者总是运用价格歧视获取高额利润　C. 垄断竞争市场面临的需求曲线和完全竞争市场一样是一条水平线　D. 垄断竞争企业的产量决策原则是边际收益等于边际成本

**答案：D**
**解析**：垄断竞争市场中，企业对价格有一定控制能力，市场上企业数量较多、产品有差异，并不存在像完全竞争市场那样明确的、向右上方倾斜的行业供给曲线，A 错误。价格歧视是指企业对不同的消费者或不同的购买数量收取不同的价格，垄断竞争市场上的企业不一定总是运用价格歧视来获取高额利润，B 错误。完全竞争市场中企业面临的需求曲线是水平线（价格接受者）；垄断竞争市场中企业产品有差异、对价格有一定影响力，面临的是向右下方倾斜的需求曲线，C 错误。垄断竞争企业的产量决策原则是边际收益等于边际成本（MR=MC），此时企业能实现利润最大化或亏损最小化，D 正确。

### 补充：生产要素市场（素材附带章节，与完全竞争生产者行为相关）

**【2018·单选】关于在完全竞争要素市场上生产者面临的生产要素供给曲线的说法，正确的是（　）。**
A. 该曲线向右上方倾斜　B. 该曲线是一条折弯线　C. 该曲线是一条水平线　D. 该曲线向右下方倾斜

**答案：C**
**解析**：完全竞争生产者在购买要素时是完全竞争的，即生产者完全是要素市场价格的接受者。所以，生产者面临的要素供给曲线是一条水平线。

**【2018·多选】关于生产要素市场理论的说法，正确的有（　）。**
A. 生产者使用生产要素的原则是边际要素成本等于边际收益产品　B. 完全竞争生产者的要素供给曲线是一条水平线　C. 边际收益产品等于边际物质产品乘以边际收益　D. 生产者对生产要素的需求具有外部性　E. 生产要素市场属于最终市场

**答案：ABC**
**解析**：生产者使用生产要素的原则是边际要素成本等于边际收益产品；完全竞争生产者的要素供给曲线是一条水平线；边际收益产品等于边际物质产品乘以边际收益。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"对外依存度""技术进步程度"当成划分市场结构的依据 | 只有三个：**数目、产品差别、进入障碍**（2024 真题干扰项） |
| 2 | 认为区分垄断竞争与完全竞争看"生产者数目" | 两者**数目都很多**，区别在**产品差别程度** |
| 3 | 把完全竞争企业需求曲线和行业需求曲线混为一谈 | 企业=水平线；行业=右下方倾斜，**两者不同**（2010、2022 真题） |
| 4 | 以为完全竞争企业"三线合一"包括边际成本曲线 | 三线是 **AR=MR=需求曲线 d**，不含 MC；MC 是"U 型"曲线 |
| 5 | 认为 MR=MC 就一定盈利 | 可能盈利也可能亏损；**若亏损则一定是最小亏损**（2025 真题） |
| 6 | 把停止营业点记成 P=AC 或 P=AFC | 停止营业点是 **P=AVC**；P＜AVC 就连可变成本都收不回 |
| 7 | 完全竞争短期供给曲线选成"AVC 与 AFC 之间的 MC" | 是 **AVC 之上的 MC 曲线** |
| 8 | 以为完全垄断企业的需求曲线与完全竞争企业相同 | 垄断的是右下方倾斜且**就是行业需求曲线**；完全竞争企业的是水平线 |
| 9 | 认为完全垄断企业 MR 位于 AR 上方或与 AR 重合 | **MR＜AR**，MR 在 AR 下方且**更陡峭**；与需求曲线重合的是 AR |
| 10 | 把"对特殊原材料的单独控制"当成自然垄断 | 原材料单独控制=**原材料垄断**；自然垄断与**规模经济**相关，是**完全垄断**的成因 |
| 11 | 认为自然垄断是形成寡头垄断的条件 | 自然垄断是形成**完全垄断**的条件之一（2019 真题 B 项） |
| 12 | 把三级价格歧视的分组依据记成"收入水平" | 分组依据是**需求价格弹性**；按数量段是二级，按单位最高价是一级 |
| 13 | 以为垄断竞争市场上经常实施价格歧视 | 价格歧视在**完全垄断市场**上实施（2021 真题 B 项错误） |
| 14 | 把垄断竞争的主观需求曲线和实际需求曲线弄反 | **主观（预期）更平坦、弹性更大**；实际（市场份额）更陡峭，每家份额 **1/n** |
| 15 | 认为垄断竞争或寡头市场存在供给曲线 | 完全垄断、垄断竞争、寡头垄断**均无供给曲线**；只有完全竞争有 |
| 16 | 把协议价格制和价格领袖制混为一谈 | 协议价格制=**共谋限产量**（行业 MR=MC）；价格领袖制=**支配企业先定价、其他跟随** |
| 17 | 认为卡特尔稳定长久、受政府鼓励 | 卡特尔**不稳定**，受**反垄断法严格禁止** |
| 18 | 以为完全竞争生产者的要素供给曲线向右上方倾斜 | 是**水平线**（要素价格接受者），MFC=AFC=W 三线重合（2018 真题） |
| 19 | 把"价格由整个行业的供给和需求曲线决定"套到垄断竞争市场 | 这是**完全竞争**的定价方式；垄断竞争企业对价格有**一定控制能力**，不由行业供求单方决定 |
| 20 | 认为"产品价格变化会让要素需求曲线变平坦/变陡" | 价格变化只使要素需求曲线**平移**（VMP=P×MP 中的 P 变），斜率（陡峭度）取决于 MP 的变化率 |

## 八、本章数字速记

| 数字 | 考点 |
|---|---|
| 三个因素 | 划分市场结构：生产者数目、产品差别程度、进入障碍大小 |

| 两条需求曲线 | 垄断竞争：主观（预期）需求曲线 + 实际（市场份额）需求曲线 |

| 要素三线合一 | 完全竞争生产者：MFC=AFC=要素供给曲线（水平线）；MRP=VMP=P·MP |
| 三个"没有供给曲线"的市场 | 完全垄断、垄断竞争、寡头垄断 |
