## 二、知识点精讲

### 考点1 财政收入及其分类 ★★★★

**核心概念**：财政收入是政府为履行其职能，实施公共政策和提供公共物品与服务需要而筹集的一切资金的总和。**货币收入是衡量一国财力的重要指标**。

**两套分类标准**：

| 分类标准 | 类别 | 性质关键词 |
|---|---|---|
| 国际货币基金组织（IMF）分类 | 税收收入 | 强制性 |
| | 社会缴款 | 自愿或强制 |
| | 赠与收入 | 非强制 |
| | 其他收入 | 罚没、规费 |
| 我国《政府收支分类科目》（一般公共预算收入） | 税收收入 | —— |
| | 非税收入 | 含八款（见下） |
| | 债务收入 | —— |
| | 转移性收入 | —— |

**非税收入八款**：专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入、捐赠收入、政府住房基金收入、其他收入。

**财政收入四大口径**：

| 口径 | 内容 | 备注 |
|---|---|---|
| 最小口径 | 仅包含税收收入 | |
| 小口径 | 税收收入＋纳入公共财政预算的非税收入 | 不含政府债务收入和专款专用的政府收入；我国统计年鉴对外公布的财政收入即此口径，**最常用** |
| 中口径 | 公共财政预算收入（一般预算收入）＋社会保障缴费收入 | |
| 最大口径 | 全部的政府收入 | |

```
政府履行职能筹集资金 = 财政收入
 ├─ IMF 分类：税收(强制) / 社会缴款 / 赠与(非强制) / 其他
 └─ 我国科目：税收 / 非税(八款) / 债务 / 转移性
统计口径：最小(只有税) → 小(+预算内非税，最常用) → 中(+社保缴费) → 最大(全部政府收入)
```

**速记口诀**：我国四类「税、非税、债、转移」；非税八款「专项收费与罚没，国资资源捐赠房」；口径「最小只有税，小口加非税，中口加社保，最大全都要」。

### 考点2 财政集中度和宏观税负 ★★

**核心概念**：财政集中度，也称为宏观税负，是指国家通过各种形式，从国民经济收支环流中截取并运用的资金占国民经济总量的比重。

| 衡量宏观税负的口径 | 公式 |
|---|---|
| ① | 税收收入 / GDP |
| ② | 公共财政收入（一般预算收入）/ GDP |
| ③（最全） | （公共财政收入＋政府性基金收入＋国有资本经营预算收入＋社会保障基金收入）/ GDP |

```
财政集中度 ≡ 宏观税负（同一概念的两种叫法）
三种算法：税/GDP → 一般预算收入/GDP → 四项全加/GDP（口径由小到大）
```

**速记口诀**：「集中度就是宏观税负，三种口径数全加」。

---

### 考点3 税收的基本含义、内涵和特征 ★★

**核心概念**：税收是公共机关依法强制收取、对纳税人不附带直接回报义务的课征。

| 项目 | 要点 |
|---|---|
| 内涵① | 征收主体是**国家**，征收客体是单位和个人 |
| 内涵② | 征收目的是满足国家实现其职能的需要，或者说满足**社会公共需要** |
| 内涵③ | 征收依据是法律，凭借的是**政治权力**，而不是财产权力 |
| 内涵④ | 征税过程是物质财富从私人部门**单向地、无偿地**转移给国家的过程 |
| 内涵⑤ | 从税收征收的直接结果看，国家通过税收方式取得了财政收入 |
| 三特征 | **强制性、无偿性、固定性** |

```
税收 = 国家(主体) 依据法律、凭借政治权力
     → 向单位和个人(客体) 强制、无偿征收
     → 满足国家职能 / 社会公共需要
     → 财富由私人部门单向、无偿转移给国家
```

**速记口诀**：「主体国家客体人，依据法律凭政治，单向无偿转财富」；三特征「强、无、固」。

---

### 考点4 税收的职能 ★★

| 职能 | 别称 | 内容 |
|---|---|---|
| 财政职能 | 收入职能 | 通过参与社会产品和国民收入的再分配为国家取得财政收入——**首要的和基本的职能** |
| 经济职能 | 调节职能 | 调节社会总需求与总供给的平衡，以及资源配置、国民经济的地区分配格局、产业结构、社会财富分配、居民消费结构等；主要通过财富的所有权转移（经济手段）进行 |
| 监督职能 | —— | 既涉及宏观层次，也涉及微观层次 |

**速记口诀**：「财政为首要，经济管调节，监督宏微查」。

### 考点5 拉弗曲线和征税限度 ★★★

**核心内容**：
- 税收收入最初随着税率的提高而**增加**，达到一定税率水平后，税收收入随着税率的提高而**下降**。
- 基本含义：保持**适度的宏观税负水平**是促进经济增长的一个重要条件。
- 政策提示：征税有「禁区」，要注意**涵养税源**。
- 出处：观点来自**供给学派**，产生于**20世纪70年代**，是对此前长期盛行的**凯恩斯主义需求管理失效**的一种回应；主张解决滞胀问题，着眼于**供给方面**，主要是改善劳动及资本供给的数量和质量。

```
税率 ↑ → 税收收入 ↑（第一阶段）
税率继续 ↑ 越过临界点 → 税基受损 → 税收收入 ↓（第二阶段）
结论：税率并非越高越好 → 适度宏观税负 → 涵养税源
```

**速记口诀**：「拉弗先升后降，适度税负促增长，七十年代供给派，涵养税源避禁区」。

### 考点6 税负转嫁的方式 ★★★

**核心概念**：税负转嫁是纳税人在缴纳税款后，通过各种途径将税收负担全部或部分转移给他人的过程；税负转嫁的最终结果形成**税负归宿**。

| 方式 | 别称 | 做法 | 关键点 |
|---|---|---|---|
| 前转 | 顺转 / 向前转嫁 | 抬高价格转嫁给购买者 | **最典型、最普遍**的形式，多发生在货物和劳务税上 |
| 后转 | 逆转 / 向后转嫁 | 压低价格转嫁给供货商 | 商品交易时发生的一次性税款的一次性转嫁 |
| 混转 | 散转 | 一部分前转＋一部分后转；或一部分转嫁出去、一部分自行消化 | 前转与后转的混合 |
| 消转 | —— | 降低征税物品成本，使税负从新增利润中得到补偿 | 自我消化税款，特殊的转嫁形式 |
| 旁转 | 侧转 | 转嫁给购买者或者供应者以外的其他人 | |
| 税收资本化 | 资本还原 | 生产要素购买者将所购要素未来应纳税款，通过从购入价格中预先扣除（压低买价）的方法，向后转嫁给出售者 | **现在承担未来的税收**；主要发生在土地和收益来源较具永久性质的政府债券等资本物品交易中，最典型的是对土地交易的课税；是**税收后转的特殊形式** |

```
税负转嫁的最终结果 = 税负归宿
纳税人转嫁路径：
 前转(抬价→购买者) / 后转(压价→供应者) / 混转(两者混合)
 消转(降成本、增利润，自我消化) / 旁转(转给局外人)
 税收资本化(压低资产买价，把未来税"折"进今天 → 土地最典型)
```

**速记口诀**：「前抬后压混散转，消转降本旁给外人，资本化把未来税折进今天价」。

---

### 考点7 影响税负转嫁的因素 ★★★★

| 因素 | 规律 |
|---|---|
| 应税商品供给与需求的弹性 | **关键因素**：供给弹性较大、需求弹性较小的商品较易转嫁 |
| 课税商品的性质 | 生活必需品容易转嫁；非生活必需品不容易转嫁 |
| 课税与经济交易的关系 | 所得税较难转嫁；货物劳务税（流转税）较易转嫁 |
| 课税范围的大小 | 课税范围广泛，容易转嫁；范围狭窄，难以转嫁 |
| 商品的竞争程度 | 竞争越大，越不易转嫁 |

```
能否转嫁看五点：
弹性(关键)：供弹大 + 需弹小 → 易转
性质：生活必需品 → 易；非生活必需品 → 难
关系：流转税 → 易；所得税 → 难
范围：广 → 易；窄 → 难
竞争：越竞争 → 越难
```

**速记口诀**：「供大需小易转嫁，必需易、奢侈难，流转易、所得难，范围广易、竞争难」。

### 考点8 国债的基本含义 ★

**核心概念**：国债即国家债务，通常是指一国**中央政府**作为主体，依据**有借有还**的信用原则取得的资金来源，是一种**有偿形式的、非经常性**的财政收入。
**特点**：自愿性、有偿性和灵活性。与私债相比，国债有政府信用的担保、风险小。

**速记口诀**：「中央借、有借有还、有偿非经常；自愿有偿灵活，政府担保风险小」。

---

### 考点9 国债的种类 ★

| 分类标准 | 种类与要点 |
|---|---|
| 发行地域 | 内债、外债 |
| 偿还期限 | 短期国债（1年以内）、中期国债（1－10年）、长期国债（10年以上）；最典型的短期国债形式是**国库券** |
| 利率变动情况 | 固定利率国债、浮动利率国债 |
| 能否在证券市场流通 | 上市（流通）国债、非上市（非流通）国债；**上市国债多为中短期，非上市国债多为长期** |
| 债务本位 | 货币国债、实物国债；实物国债可避免因货币贬值给债权人带来损失，一般在存在**高通货膨胀**时采用；1950年我国发行的「人民胜利折实公债」为实物国债 |

**速记口诀**：「地域分内外，期限短中长（1年、10年分界），利率固与浮，流通上市非，本位货与实，五零折实公债」。

---

### 考点10 国债的政策功能 ★★★

1. **弥补财政赤字**——国债的**基本功能**。弥补财政赤字通常有三种方式：向中央银行借款、增税、发行国债。
2. **筹集建设资金**。
3. **调节货币供应量和利率**（短期国债：有利息的钞票）。
4. **调控宏观经济**。

**速记口诀**：「补赤字是基本功能，再筹建设、调货币利率、控宏观经济」。

### 考点11 国债的负担和限度 ★

**四方面负担**：认购者负担（债权人负担）、债务人负担（政府负担）、纳税人负担、代际负担。注意：**还债的收入来源最终是税收**。

| 类别 | 指标 | 公式 / 说明 |
|---|---|---|
| 绝对规模 | 国债余额 | 历年累积债务的总规模 |
| | 当年发行国债的总额 | —— |
| | 当年到期需还本付息的债务总额 | —— |
| 相对规模（掌握） | 国债负担率（国民经济承受能力） | 国债累计余额 / 国内生产总值 ×100% |
| | 债务依存度 | 当年的债务收入 / 当年财政支出总额 ×100% |
| 偿债能力 | 偿债能力指标 | 当年付息额 / 当年中央财政经常性收入 |

（警戒线与数字演算见本笔记第四节）

**速记口诀**：「负担四方面：认购者、债务人、纳税人、代际；还债靠税收」。

### 考点12 李嘉图的等价定理 ★

**核心内容**：在某些条件下，政府无论是用**债券**还是**税收**筹资，其效果都是相同的或者等价的。

### 考点13 国债制度 ★★★

**国债制度＝发行制度＋偿还制度＋市场交易制度**（三部分，多选题高频）。

**（1）国债发行制度＝发行方式＋发行条件**。决定国债发行条件的关键是**国债的发行方式**。

| 发行方式 | 要点 |
|---|---|
| 公募招标方式 | 面向多数投资者；市场机制，市场化 |
| 「随买」方式 | 向**小投资者**发行**不可上市**国债 |
| 承购包销方式 | 发行人与承销人平等关系；承销人向投资者分销不出去的部分由**承销者自己认购**；签订承销合同，发行过程即告结束 |
| 直接发售方式 | 发行者亲自向投资者发售，有特定发行对象（商业银行、储蓄银行、保险公司、养老基金、信托公司等），**个人投资者不能认购**；发行条件直接商定，自担风险。优点：降低举债成本、便于了解投资者的投资要求和意向；缺点：给发行单位带来较大的工作量 |

**（2）国债偿还制度（偿还方式）**：抽签分次偿还、到期一次偿还、转期偿还、提前偿还、市场购销法。

**（3）国债市场制度**：

| 分类角度 | 类别 | 要点 |
|---|---|---|
| 按交易层次 | 国债发行市场（一级市场） | 参与者：中央政府、发行中介机构和投资购买者 |
| | 国债流通市场（二级市场） | 基本职能是为国债投资者提供转让变现的机会；分为证券交易所、以分散交易形式运作的场外交易市场（柜台市场、店头市场） |
| 按成交订约和清算期限 | 现货交易 | 最古老、最普遍、最常用 |
| | 回购交易 | 即期＋远期，先卖后买 |
| | 期货交易 | 未来特定时间券款交割：期限、价格、数量、国债标的；用于套期保值 |
| | 期权交易 | —— |

```
国债制度 = 发行制度(发行方式+发行条件，关键是发行方式)
         + 偿还制度(抽签分次/到期一次/转期/提前/市场购销)
         + 市场制度(一级发行市场 + 二级流通市场；现货/回购/期货/期权)
```

**速记口诀**：「制度三兄弟：发行、偿还、市场；发行四方式：招标、随买、包销、直售；交易四方式：现货最常用」。

2. 调节社会资金的运行。

### 考点15 加强政府性债务管理 ★★★★

| 主体 | 制度要点 |
|---|---|
| 中央政府债务 | **余额管理** |
| 地方政府债务 | ①**举债融资机制**：经国务院批准，省级（省、自治区、直辖市）政府可以适度举借债务；市县级政府需举债的，由省级政府代为举借；政府债务只能通过政府及其部门举借，**不得通过企事业单位举借**。②**举债规模报批**：由国务院报全国人民代表大会或其常务委员会批准。③**规模控制和分类管理**：实行**限额管理**；分为一般债务和专项债务，**分类纳入预算管理**（一般债务发行一般债券→一般公共预算；专项债务发行专项债券→政府性基金预算）。④**限定程序和用途**：遵循**市场化原则**，建立地方政府信用评级制度，逐步完善地方政府债券市场；举债只能用于**公益性资本性支出和适度归还存量债务，不得用于经常性支出**。⑤**风险预警和化解**：财政部根据债务率、新增债务率、偿债率、逾期债务率等指标评估各地区债务风险，对高风险地区预警；硬化预算约束，防范道德风险；地方政府对举借的债务负有偿还责任，**中央政府实行不救助原则**。⑥**考核问责**：省级政府对本地区地方政府性债务负责任，**政府主要负责人为第一责任人** |

```
地方债六句话：
省级批、市县由省代借、规模由全国人大(或其常委会)定、限额分类管(一般/专项)
市场化举债、只干公益性资本支出和归还存量、不碰经常性支出
中央不兜底、主要负责人第一责任人
```

**速记口诀**：「中央余额、地方限额；一般进公共、专项进基金；只做公益资本支出；中央不救助、主要负责人第一责任」。

## 四、公式与计算

### 公式1 宏观税负（财政集中度）

| 口径 | 公式 |
|---|---|
| 最小口径 | 宏观税负 ＝ 税收收入 / GDP ×100% |
| 小口径 | 宏观税负 ＝ 公共财政收入（一般预算收入）/ GDP ×100% |
| 大口径 | 宏观税负 ＝（公共财政收入＋政府性基金收入＋国有资本经营预算收入＋社会保障基金收入）/ GDP ×100% |

**演算例题（编者自设数字，仅演示算法）**：某国2025年税收收入12万亿元，一般预算收入15万亿元，GDP为100万亿元。则最小口径宏观税负＝12÷100＝**12%**；小口径宏观税负＝15÷100＝**15%**。口径越大，数值越高。

### 公式2 税收资本化（税负转嫁）

**算法逻辑**：资产成交价被压低，压低的部分≈未来应纳税款，税负由购买者转嫁给出售者（后转的特殊形式，土地交易最典型）。

**演算例题（编者自设数字，仅演示算法）**：某地块在无税情形下的正常成交价为1000万元，买方预计持有期间未来应纳税款合计60万元，最终以940万元成交。少付的60万元即被预先扣除的未来税款，相当于卖方承担了这笔税收——这就是税收资本化。

### 公式3 国债负担率（国民经济承受能力）

**公式**：国债负担率 ＝ 国债累计余额 / 国内生产总值（GDP）×100%

**演算例题1（素材真题数字）**：某国2020年国债累计余额3万亿元，GDP为30万亿元。国债负担率＝3÷30＝**10%**。（对应真题答案B；注意「当年发行国债1.2万亿」是干扰数据）

**演算例题2（素材真题数字）**：2012年某国国债累计余额8万亿元，GDP为40万亿元。国债负担率＝8÷40＝**20%**。（对应真题答案A；「国债收入0.6万亿、财政支出10万亿」是干扰数据）

### 公式4 债务依存度

**公式**：债务依存度 ＝ 当年的债务收入 / 当年财政支出总额 ×100%

**演算例题（素材真题数字）**：承上演算例题2，该国2012年国债收入0.6万亿元，财政支出10万亿元。债务依存度＝0.6÷10＝**6%**，低于15%－20%的国际公认警戒区间。

### 公式5 偿债能力指标

**公式**：偿债能力指标 ＝ 当年付息额 / 当年中央财政经常性收入

**演算例题（编者自设数字，仅演示算法）**：某年中央财政经常性收入5万亿元，当年付息额0.3万亿元，则偿债能力指标＝0.3÷5＝**6%**。（素材仅给出公式，未给出警戒线）

### 本节「素材未覆盖」提示

- 「泰勒斯的税负转嫁」相关表述：**素材未覆盖**，不做展开。
- 「土地财政相关指标」（如土地出让收入依赖度等测算公式）：**素材未覆盖**，不做展开。本章与土地有关的可考点仅两处：①土地出让收入**不属于**一般公共预算收入科目；②税收资本化最典型地发生在**土地交易**课税中。

## 五、高频考点速记卡

1. **Q：财政收入的含义？**
   A：政府为履行其职能、实施公共政策和提供公共物品与服务需要而筹集的一切资金的总和；货币收入是衡量一国财力的重要指标。

2. **Q：我国一般公共预算收入分几类？**
   A：四类——税收收入、非税收入、债务收入、转移性收入。

3. **Q：非税收入包括哪八款？**
   A：专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入、捐赠收入、政府住房基金收入、其他收入。

4. **Q：政府从私人部门取得的强制性资金转移是什么？从其他国家政府或国际组织得到的非强制性转移是什么？**
   A：前者是**税收**；后者是**赠与收入**（可货币也可实物，是对一国自有财政收入的补充）。

5. **Q：最常用的财政收入口径是哪个？**
   A：**小口径**——税收收入＋纳入公共财政预算的非税收入，不含政府债务收入和专款专用的政府收入；我国统计年鉴对外公布的财政收入即此口径。

6. **Q：财政集中度与宏观税负是什么关系？衡量口径有几种？**
   A：财政集中度也称为宏观税负。三口径：税收/GDP；一般预算收入/GDP；（公共财政＋政府性基金＋国有资本经营预算＋社保基金）/GDP。

7. **Q：税收征收的依据和凭借是什么？**
   A：依据是法律，凭借的是**政治权力**，而不是财产权力。

8. **Q：税收三特征？哪一个是本质体现？**
   A：强制性、无偿性、固定性。**无偿性**是税收本质的体现，反映社会产品所有权、支配权的单方面转移，不是等价交换。

9. **Q：税收的首要职能是什么？三职能是哪些？**
   A：财政职能（收入职能）是首要和最基本的职能；三职能为财政（收入）、经济（调节）、监督。

10. **Q：拉弗曲线说明什么？**
    A：税收收入随税率提高先增加、达到一定税率水平后转为下降；保持适度宏观税负是促进经济增长的重要条件；提示政府征税有「禁区」，要涵养税源。该观点来自供给学派，产生于20世纪70年代。

11. **Q：最典型、最普遍的税负转嫁方式？**
    A：**前转**（顺转），抬高价格转给购买者，多发生在货物和劳务税上。

12. **Q：什么是税收资本化？**
    A：又称资本还原，生产要素购买者将所购要素未来应纳税款从购入价格中预先扣除（压低买价）向后转嫁；现在承担未来的税收，土地交易最典型；是税收**后转**的特殊形式。

13. **Q：决定税负转嫁状况的关键因素？**
    A：应税商品**供给与需求的弹性**——供给弹性大、需求弹性小的商品较易转嫁。

14. **Q：国债的含义和特点？**
    A：一国中央政府依据有借有还信用原则取得的资金来源，是有偿形式的、非经常性的财政收入；特点是自愿性、有偿性、灵活性，有政府信用担保、风险小。

15. **Q：国债两大相对规模指标及警戒线？**
    A：国债负担率＝累计余额/GDP，发达国家不超过60%、发展中国家不超过45%；债务依存度＝当年债务收入/当年财政支出总额，警戒线15%－20%。

16. **Q：弥补财政赤字的方式有哪三种？国债的基本功能是什么？**
    A：向中央银行借款、增税、发行国债；弥补财政赤字是国债的基本功能。

17. **Q：国债制度包括哪三部分？决定国债发行条件的关键是什么？**
    A：发行制度、偿还制度、市场交易制度；关键是**发行方式**。

18. **Q：向小投资者发行不可上市国债的方式？最普遍常用的国债交易方式？**
    A：「随买」发行方式；现货交易。

19. **Q：地方一般债务和专项债务分别纳入哪本预算？**
    A：一般债务（一般债券）→一般公共预算；专项债务（专项债券）→政府性基金预算。

20. **Q：地方政府举债遵循什么原则？资金用途有何限制？中央是否兜底？**
    A：市场化原则；只能用于公益性资本性支出和适度归还存量债务，**不得用于经常性支出**；中央实行不救助原则，地方政府负偿还责任，政府主要负责人为第一责任人。

## 六、典型真题（含解析）

> 本节收录素材中**全部带年份标签的真题，共12道**，答案与解析保留；个别明显串行的解析已按答案与知识点修正并注明。

**1.【2019·多选】关于不同口径的财政收入的说法，正确的有（　）。**
A. 大口径的财政收入包括政府全部收入
B. 小口径的财政收入包括政府债务收入
C. 最小口径的财政收入仅包括税收收入
D. 中口径的财政收入包括财政预算收入
E. 中口径的财政收入包括社会保障缴费收入

**答案：ACDE**
**解析**：财政收入口径有大小之分。最小口径仅包含税收收入（C对）；小口径除税收收入外，还包含纳入财政预算（即一般预算）的非税收入，但**不包括政府债务收入**（B错）；中口径是财政预算（一般预算）收入加社会保障缴费收入（D、E对）；最大口径即全部政府收入（A对）。

**2.【2021·多选】关于税收内涵的说法，正确的有（　）。**
A. 税收的征收主体是国家
B. 征税的过程是私人部门与国家之间的物质财富的双向转移
C. 国家通过税收方式取得了财政收入
D. 税收征收的依据是法律，凭信的是财务权力
E. 税收征收的目的是为了满足社会公共需求

**答案：ACE**
**解析**：税收是国家为实现其职能，凭借其**政治权力**，依法参与单位和个人的财富分配，强制、无偿地取得财政收入的一种形式。内涵：①征收主体是国家，客体是单位和个人（A对）；②满足国家实现其职能的需要/社会公共需要（E对）；③依据法律，凭借政治权力而**不是财产权力**（D错）；④物质财富从私人部门**单向、无偿**转移给国家，不是双向转移（B错）；⑤国家通过税收取得财政收入（C对）。

**3.【2021·单选】关于税收基本特征的说法，正确的是（　）。**
A. 强制性、无偿性和固定性是税收的绝对特征
B. 税收的固定性表明只有征收机关可以随意变更征纳标准
C. 税收的无偿性反映的是一种社会产品的所有权与支配权之间的等价交换关系
D. 税收的强制性是指政府通过法律形式对社会产品实行强制征收

**答案：D**
**解析**：A错——强制性、无偿性和固定性是税收的**基本特征**；B错——税收征纳双方必须按税法规定征税和纳税，双方都无权随意变更征税标准；C错——税收的无偿性是税收本质的体现，反映的是一种社会产品所有权、支配权的**单方面转移**关系，而不是等价交换关系。

**4.【2022·单选】税收的首要职能是（　）。**
A. 财政职能　B. 经济职能　C. 监督职能　D. 调控职能

**答案：A**
**解析**：财政职能也称收入职能，是指税收通过参与社会产品和国民收入的再分配，为国家取得财政收入的功能。税收自产生之日起就具备了筹集财政收入的职能，并且是首要的和最基本的职能。

**5.【2023补·单选】税收的职能不包括（　）。**
A. 收入职能　B. 调节职能　C. 竞争职能　D. 监督职能

**答案：C**
**解析**：税收的分配结果形成国家财政收入，分配过程对经济具有调控和监督作用，由此形成三项职能：财政职能（也称收入职能）、经济职能（也称调节职能）和监督职能。**竞争职能**不属于税收职能。

**6.【2020·多选】关于拉弗曲线的理解，正确的有（　）。**
A. 该曲线的提出者是英国经济学家阿瑟·拉弗
B. 该曲线是对税率与税收收入或经济增长之间关系的描述
C. 该曲线的基本含义是保持适度的宏观税负水平是促进经济增长的一个重要条件
D. 该曲线提示各国政府要提高税率，清除征税"禁区"
E. 该曲线是对凯恩斯主义需求管理失效的一种回应

**答案：BCE**
**解析**（素材原解析串行，已按答案与知识点修正）：A错——拉弗曲线的提出者并非英国经济学家；D错——拉弗曲线提示各国政府征税有"禁区"，要注意**涵养税源**，而非"提高税率、清除禁区"；B、C、E均符合拉弗曲线的基本含义（描述税率与税收收入或经济增长的关系；适度宏观税负促进经济增长；产生于20世纪70年代，是对凯恩斯主义需求管理失效的回应）。

**7.【2021·单选】纳税人用降低征税物品成本的办法使税负从新增利润中得到补偿，这种税负转嫁方式是（　）。**
A. 消转　B. 前转　C. 后转　D. 散转

**答案：A**
**解析**：消转是指纳税人用降低征税物品成本的办法使税负从新增利润中得到抵补。它既不是通过提高销售价格前转，也不是通过压低进价后转，而是通过改善经营管理、提高劳动生产率等措施降低成本、增加利润来抵消税负。

**8.【2020·单选】债务依存度是指（　）。**
A. 当年债务收入与财政收入的比例关系
B. 当年债务收入与财政支出的比例关系
C. 当年债务收入占国内生产总值的比重
D. 当年国债累计余额占国内生产总值的比重

**答案：B**
**解析**：债务依存度是指当年债务收入与财政支出的比例关系。C、D说的是债务收入/存量占GDP类口径，其中"国债累计余额/GDP"是国债负担率。

**9.【2023补·单选】政府债务管理者向小投资者发行不可上市国债的方式是（　）。**
A. "随买"发行方式　B. 直接发售方式　C. 承购包销方式　D. 公募招标方式

**答案：A**
**解析**："随买"发行方式是政府债务管理者用来向小投资者发行不可上市国债的一种方式。

**10.【2021·单选】关于地方债务的说法，正确的是（　）。**
A. 地方政府举债可以用于经常性支出
B. 地方政府债务规模实行限额管理
C. 地方专项债务纳入一般公共预算管理
D. 地方一般债务纳入政府性基金预算管理

**答案：B**
**解析**：地方政府举债只能用于公益性资本支出和适度归还存量债务，不得用于经常性支出（A错）；一般债务通过发行一般债券融资，纳入**一般公共预算**管理；专项债务通过发行专项债券融资，纳入**政府性基金预算**管理（C、D说反了）。

**11.【2019·单选】地方政府举债要遵循（　）。**
A. 市场化原则　B. 无偿性原则　C. 强制性原则　D. 公平性原则

**答案：A**
**解析**：在国务院批准的分地区限额内举借债务，必须报本级人大或其常委会批准。地方政府举债要遵循**市场化原则**，建立地方政府信用评级制度，逐步完善地方政府债券市场。

**12.【2020·单选】在地方政府预算管理中，地方政府专项债务应纳入（　）。**
A. 政府性基金预算管理　B. 一般公共预算管理　C. 中期预算管理　D. 政府债务预算管理

**答案：A**
**解析**：政府性基金预算的收入具有指定用途、专款专用的特征。地方政府专项债务通过发行专项债券融资，纳入政府性基金预算管理。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把赠与收入当成强制性收入 | 赠与收入是从其他政府或国际组织得到的**非强制**性转移；强制性的只有税收 |
| 2 | 选我国政府收入分类时漏「债务收入、转移性收入」 | 一般公共预算收入四类：税收、非税、债务、转移性，一个不能少 |
| 3 | 认为土地出让收入属于一般公共预算收入科目 | 它**不属于**四类科目（真题已考） |
| 4 | 把最小口径和小口径搞混 | 最小口径只有税收；小口径＝税收＋预算内非税，我国公布数据用小口径 |
| 5 | 认为小口径包含政府债务收入 | 小口径**不含**政府债务收入和专款专用的政府收入 |
| 6 | 认为宏观税负只有一种算法 | 三口径：税/GDP、一般预算/GDP、四项全加/GDP |
| 7 | 认为税收凭借财产权力 | 凭借**政治权力**，依据法律；财产权力是干扰项 |
| 8 | 认为征税是双向、等价交换 | 私人部门向国家**单向、无偿**转移；等价交换恰恰是无偿性反对的说法 |
| 9 | 把「竞争职能」算进税收职能 | 税收三职能：财政（收入）、经济（调节）、监督 |
| 10 | 认为拉弗曲线下税率越高税收越多 | 先增后减，越过临界点税收反而下降，要涵养税源 |
| 11 | 把税收资本化当成消转 | 资本化是**后转的特殊形式**（压低买价预扣未来税）；消转是降成本自我消化 |
| 12 | 认为需求弹性大的商品容易转嫁 | 相反：供给弹性大、需求弹性小才易转嫁；生活必需品易、非生活必需品难 |
| 13 | 认为所得税容易转嫁 | 所得税较难转嫁，货物劳务税（流转税）较易转嫁 |
| 14 | 混淆国债负担率与债务依存度 | 负担率看**存量**（累计余额/GDP）；依存度看**流量**（当年债务收入/当年财政支出） |
| 15 | 两条警戒线记混 | 负担率：发达国家60%、发展中国家45%；依存度：15%－20% |
| 16 | 计算国债负担率时误用「当年发行国债额」 | 用**累计余额**，当年发行额、当年还本付息额都是干扰数据 |
| 17 | 混淆承购包销与直接发售 | 承购包销：承销商认购销不掉的部分；直接发售：发行者亲自向特定机构发售，个人不能认购 |
| 18 | 认为市县级政府可自行适度举债 | 市县由省级政府**代为举借**；省级举债须经国务院批准，规模由国务院报全国人大或其常委会批准 |
| 19 | 一般债务与专项债务的预算归属记反 | 一般→一般公共预算；专项→政府性基金预算 |
| 20 | 认为中央政府会为地方债兜底 | 中央实行**不救助**原则；地方政府负偿还责任，主要负责人为第一责任人 |
