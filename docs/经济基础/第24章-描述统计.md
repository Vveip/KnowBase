# 第24章 描述统计

> **本章考情**：本章是《经济基础知识》**计算题最集中的一章**，平均分值 **6 分左右**。内容多、考点多、分值占比高，出题大多围绕「计算＋概念辨析」搭配考查：计算题型常年锁定**中位数、离散系数、标准分数**三处轮换出题；多选题习惯于把集中趋势、离散程度、分布形态三类指标混杂设置选项，要求考生区分归类；**偏态系数搭配均值、中位数、众数的位置排序**是全章综合命题热点（试卷几乎年年涉及，题干多用居民收入、考试成绩等生活化实例辅助出题）；相关系数侧重区间范围与强弱正负相关的文字判断，基本不设置计算考题。

1. **计算三处轮换**：中位数（先排序、奇偶两种情形）、离散系数（先开方再除均值）、标准分数（减均值除标准差）——三处几乎年年轮换出现，务必练熟演算。
2. **多选混设选项**：习惯把集中趋势、离散程度、分布形态三类指标混在一题里，要求区分归类（如「用于测量集中趋势的有哪些」「数值型数据离散程度的测度指标有哪些」）。
3. **辨析型单选密集**：集中于「适用范围×数据类型」「是否受极端值影响」「是否充分利用全部信息」三个维度。
4. **综合命题热点**：偏态系数与均值、中位数、众数的位置排序结合，多用居民收入、考试成绩等生活化实例。

## 二、知识点精讲

### 考点1 均值 ★★★★★

**核心概念**：均值也叫**平均数**，就是数据组中所有数值的总和除以该组数值的个数。

| 项目 | 内容 |
|---|---|
| 含义 | 数据组中所有数值的总和 ÷ 该组数值的个数 |
| 地位 | 均值是集中趋势**最主要的测度值**，是一组数据的**重心所在**，解释了一组数据的平均水平 |
| 适用范围 | 主要适用于**数值型数据**，**不适用**于分类数据和顺序数据 |
| 特点 | **易受极端值的影响**——极端值的出现，会使平均数向极大值或极小值方向倾斜，使均值的真实性受到干扰、代表性减弱 |

```
均值的定位链：
数值型数据 → 求和 ÷ 个数 → 得到中心值（重心）
   ↓
优点：充分利用数据全部信息，大小受每个观测值影响，比较稳定
   ↓
缺点：怕极端值（有明显极端值时代表性较差）
   ↓
极端值明显 / 偏态分布 → 换中位数或众数
```

**速记口诀**：**「均值全部加完除个数，就怕极端值来搅和」**。

**考法提示（据素材真题归纳）**：①直接问「集中趋势最主要的测度值」——选均值；②给出一组数据求平均数，一步除法；③辨析「适用于数值型数据、易受极端值影响」；④与方差、标准差混搭时注意：方差和标准差也是离散程度指标、同样怕极端值，但题干问「集中趋势」时只能选均值。

---

### 考点2 中位数 ★★★★★

**核心概念**：把一组数据按**从小到大或从大到小的顺序**排列，**位置居中**的数值叫做中位数，用 **Me** 表示。中位数将数据分为两部分，其中一半的数据小于中位数，另一半数据大于中位数。

**计算思路**：数据排序 → 确定中位数的位置 → 确定中位数的具体数值（n 为数据个数）。

| 数据个数 | 位置确定 | 中位数取值 |
|---|---|---|
| n 为**奇数** | 位置 = (n+1)/2 | 该位置所对应的数值 |
| n 为**偶数** | 位置介于 n/2 与 n/2+1 之间 | 第 n/2 位与第 n/2+1 位两个数值的**平均数** |

| 项目 | 内容 |
|---|---|
| 适用范围 | 主要用于**顺序数据和数值型数据**，**不适用**于分类数据 |
| 特点 | 中位数是一个**位置代表值**，**不受极端值的影响**，抗干扰性强，尤其适用于**收入类偏斜分布的数值型数据** |

```
中位数计算链：
原始数据 → ①先排序（关键步骤，不排序必错）
        → ②数个数 n
        → ③n 奇：取第 (n+1)/2 位
           n 偶：取第 n/2 位与第 n/2+1 位的平均值
        → ④得到 Me
```

**速记口诀**：**「中位数站中间，先排序后定位；奇数取中间，偶数取俩平均」**。

**考法提示（据素材真题归纳）**：①给数据求中位数——先排序，注意奇数、偶数两种情形（偶数取中间两数的平均）；②辨析「不受极端值影响、抗干扰性强，尤其适用于收入类偏斜分布的数值型数据」；③「严重左偏分布适合测度集中趋势的统计量」——选中位数；④多选常与「是否适用于分类数据」「是否充分利用全部信息」组合命题。

---

### 考点3 众数 ★★★★★

**核心概念**：众数是一组数据中**出现次数（频数）最多**的变量值。

**示例**：某能源公司有 9 个分公司，主营产品分别为煤制品、有机化工原料、火电、煤制品、热力、电解铝、火电、煤制品、煤制品，「煤制品」出现 4 次最多，故众数为**煤制品**。

| 项目 | 内容 |
|---|---|
| 适用范围 | 适于描述**分类数据和顺序数据**的集中趋势，**不适用于定量数据** |
| 特殊情形 | 有些情况下可能出现**双众数、多众数或者没有众数**，难以描述数据的集中位置 |
| 性质 | 众数是**位置平均数**（不是算术平均数的一种） |
| 优点 | 不受极端值的影响，尤其是**分布明显呈偏态时，众数的代表性更好** |
| 缺点 | 没有充分利用数据的全部信息，**缺乏稳定性，而且可能不唯一** |

```
众数判断链：
数据 → 数每个值出现的频数 → 取频数最大者
   ↓
分类/顺序数据：一定能用
   ↓
定量（数值型）数据：可能出现多众数、无众数 → 不适用
```

**速记口诀**：**「众数找最多，分类顺序都能用；定量数据会翻车，多众无众不稳定」**。

**考法提示（据素材真题归纳）**：①定义题——「一组数据中出现次数（频数）最多的变量值」；②适用范围——分类数据和顺序数据，**不适用于定量数据**；③三个特性——可能多众数/无众数、不唯一、缺乏稳定性；④与中位数的共同优点是不受极端值影响；与均值、中位数相比缺点是缺乏稳定性；⑤注意众数是**位置平均数**，不是算术平均数的一种。

### 考点4 均值、中位数和众数的比较及适用范围 ★★★

| 指标 | 是否受极端值影响 | 数值型数据（定量数据） | 分类数据 | 顺序数据 |
|---|---|---|---|---|
| 均值 | **受影响** | 适用 | 不适用 | 不适用 |
| 中位数 | 不受影响 | 适用 | 不适用 | 适用 |
| 众数 | 不受影响 | **不适用** | 适用 | 适用 |

| 指标 | 优点 | 缺点 |
|---|---|---|
| **均值** | 能够充分利用数据的全部信息，均值大小受每个观测值的影响，**比较稳定** | **易受极端值的影响**，如果观测值中有明显极端值，则均值的代表性较差 |
| **中位数** | 不受极端值的影响 | 没有充分利用数据的全部信息，**稳定性差于均值，优于众数** |
| **众数** | 不受极端值的影响，尤其是分布明显呈偏态时，众数的代表性更好 | 没有充分利用数据的全部信息，**缺乏稳定性，而且可能不唯一** |

```
三类指标选用决策链：
先看数据类型：
  分类数据   → 只能众数
  顺序数据   → 中位数、众数
  数值型数据 → 均值、中位数（众数不适用）
        ↓
数值型数据中再看分布：
  对称分布、无明显极端值 → 均值（信息利用最充分）
  偏斜分布 / 有明显极端值（如收入）→ 中位数（抗干扰）
        ↓
集中趋势最主要的测度值 = 均值（但怕极端值）
```

**速记口诀**：**「均值怕极端、中位站中间、众数找最多；分类只能用众数，顺序中位加众数，定量均值最稳定」**。

**考法提示（据素材真题归纳）**：本节是全章多选题的「选项库」。四类排列组合反复出现——「适用于数值型数据的有哪些」（均值、中位数、方差、标准差、离散系数，不含众数）；「适用于分类数据的有哪些」（只有众数）；「适用于顺序数据的有哪些」（中位数、众数）；「容易受极端值影响的有哪些」（均值、方差、标准差）。做题时先把指标按「集中趋势/离散程度/分布形态/相关分析」归类，再按数据类型筛选。

### 考点5 方差 ★★★★

**核心概念**：方差是数据组中各数值与其均值**离差平方的平均数**，能较好地反映出数据的离散程度，是实际中应用最广泛的离散程度测度值。

| 项目 | 内容 |
|---|---|
| 与均值的关系 | 方差越小，说明数据值与均值的平均距离越小，**均值的代表性越好** |
| 公式（样本） | 样本方差 = Σ(Xi − X̄)² / (n−1) |
| 适用范围 | 只适用于**数值型数据**；与均值一样，**对极端值也很敏感** |
| 单位缺陷 | 方差的单位是原数据单位的**平方**，没有解释意义 |

```
方差计算链（以 5 名营业员销售额为例）：
① 算均值 X̄ = 570
② 算各数值与均值的差（离差）：-50, 30, -90, 180, -70
③ 离差平方后求和：2500+900+8100+32400+4900 = 48800
④ 除以 n-1 = 4 → 方差 = 12200
```

**速记口诀**：**「方差就是离差平方和，再除 (n−1)；越小越集中，均值越有代表性」**。

**考法提示（据素材真题归纳）**：①定义题——「各数值与其均值离差平方的平均数」；②与均值代表性的关系——方差越小，均值的代表性越好；③单位缺陷——原数据单位的平方，没有解释意义；④只适用于数值型数据，分类数据无法计算方差；⑤受极端值影响（离差平方会放大极端值的作用）。

---

### 考点6 标准差 ★★★★

**核心概念**：标准差即方差的**平方根**。

| 项目 | 内容 |
|---|---|
| 公式（样本） | 样本标准差 = √[ Σ(Xi − X̄)² / (n−1) ] |
| 地位 | 标准差与方差是应用最广泛的统计离散程度的测度方法 |
| 适用范围 | 只适用于**数值型数据**；对极端值很敏感 |
| 特点 | 不仅能度量数值与均值的平均距离，**还与原始数值具有相同的计量单位** |

```
标准差 vs 方差：
方差 12200（单位：元²，无解释意义）
   ↓ 开平方
标准差 ≈ 110.45（单位：元，与原始数据同单位 → 可解释、可比较）
   ↓
记忆点：标准差是方差的平方根；方差是标准差的平方
```

**速记口诀**：**「标准差是方差的根，单位还原能解释；俩都只认数值型，极端值前都敏感」**。

**考法提示（据素材真题归纳）**：①与方差的关系——标准差是方差的平方根，方差是标准差的平方（真题考过两次）；②与方差相比的优点——与原始数值具有相同的计量单位；③与标准差相比方差的缺点——单位是原数据单位的平方，没有解释意义；④给方差求标准差（开方），给标准差求方差（平方）；⑤适用范围仅限数值型数据，且对极端值敏感。

### 考点7 离散系数 ★★★★

**核心概念**：离散系数也称为**变异系数或标准差系数**，即**标准差与均值的比值**，主要用于**不同类别数据离散程度的比较**，记为 **CV**。

| 项目 | 内容 |
|---|---|
| 公式 | CV = S / X̄（标准差 ÷ 均值） |
| 为什么要用它 | 标准差的大小不仅与数据的**测度单位**有关，也与观测值的**均值大小**有关，**不能直接用标准差比较不同变量的离散程度** |
| 核心优势 | 离散系数**消除了测度单位和观测值水平不同的影响**，因此可以直接用来比较变量的离散程度 |
| 判读 | CV 越大，离散程度越大；CV 越小，离散程度越小 |

```
离散程度指标选用链：
同一变量、同一单位、均值水平相近 → 可用标准差直接比
        ↓
不同单位（如身高 cm vs 体重 kg）
或均值水平差距大（如学生 20 岁 vs 教师 38 岁）
        ↓
必须先消除量纲 → 用离散系数 CV = S / X̄
```

**速记口诀**：**「离散系数除均值，消单位消水平；要比两类数据，先算 CV 再大小」**。

**考法提示（据素材真题归纳）**：①定义——标准差与均值的比值（分母是**算术平均数**，不是几何平均数，真题专门设过这个陷阱）；②给方差和均值求 CV——必须先开方得标准差，再除以均值；③比较两类数据（学生 vs 教师年龄、身高 vs 体重）——均值水平或单位不同，只能用 CV；④选项出现「比较不同类别数据的**位置**差异」即为错项，应为**离散程度**差异。

### 考点8 偏态系数 ★★★★

**核心概念**：偏度是指数据分布的偏斜方向和程度，描述的是数据分布**对称程度**。测度数据分布偏度的统计量称为**偏态系数**。

**公式（素材文字表述）**：偏态系数取决于**离差三次方的平均数与标准差三次方的比值**。

| 偏态系数取值 | 分布形态 | 说明 |
|---|---|---|
| = 0 | 对称分布（正态分布） | 图形对称 |
| > 0 | 右偏分布 | 0～0.5 轻度右偏；0.5～1 中度右偏；> 1 严重右偏 |
| < 0 | 左偏分布 | 0～−0.5 轻度左偏；−0.5～−1 中度左偏；< −1 严重左偏 |

> **补充**：偏态系数的**绝对值越大**，数据分布偏斜程度越大。

```
偏态系数判读链：
看符号定方向：正 → 右偏；负 → 左偏；零 → 对称
        ↓
看绝对值定程度：|SK| < 0.5 轻度
              0.5 ≤ |SK| < 1 中度
              |SK| ≥ 1 严重
        ↓
例题判读：SK=0.3 → 轻度右偏；SK=0.96 → 中度右偏
          SK=-0.33 → 轻度左偏；SK=-2 → 严重左偏；SK=3.0 → 严重右偏
```

**速记口诀**：**「正右负左零对称，点五一分轻中重」**。

**考法提示（据素材真题归纳）**：①测度对象——数据分布的**不对称性**（不是分散度、集中度、代表程度）；②偏态系数取决于**离差三次方的平均数与标准差三次方的比值**；③给 SK 判形态：0.3→轻度右偏，0.96→中度右偏，3.0→严重右偏，−0.33→轻度左偏，−2→左偏且严重；④「分布是左偏的，偏态系数取值范围」——小于 0；⑤比较偏斜程度看**绝对值**（−2 比 1 更偏）。

### 考点9 标准分数 ★★★★

**核心概念**：标准分数也称为 **Z 分数**，是统计上常用的一种标准化方法，用于某一个数值在一组数据中**相对位置**的度量。

| 项目 | 内容 |
|---|---|
| 计算公式 | Zi = (Xi − X̄) / S（数值 − 均值，再除以标准差） |
| 适用场景 | 均值和标准差不同时，不同变量的数值是不能比较的，来自不同分布的变量值不可比；但每个数值在变量分布中**相对于均值的相对位置是可比的**，因此可通过标准分数比较不同变量的取值 |
| 重要提示 | 转变后的标准分数**并没有改变数值在原始分布中的位置，也没有改变数据原分布的偏度**；标准分数的**均值为 0，标准差为 1** |
| 经验法则 | 对于服从**对称的钟形分布（正态分布）**的标准分数：约 **68%** 在 [−1, +1]；约 **95%** 在 [−2, +2]；约 **99%** 在 [−3, +3] |

```
标准分数应用链：
两次考核 / 两类变量，均值标准差都不同
   ↓
原始分不可直接比 → 各自换算成 Z = (Xi − X̄)/S
   ↓
Z 大 → 相对排名高（高于均值更多个标准差）
Z = 0 → 中等水平；Z < 0 → 低于平均
   ↓
经验法则（对称钟形分布）：±1σ 约 68%，±2σ 约 95%，±3σ 约 99%
```

**速记口诀**：**「标准分数减均值除标准差；三舅舅，二舅我，一路发」（3σ→99%、2σ→95%、1σ→68%）**。

**考法提示（据素材真题归纳）**：①公式计算——给均值、标准差和一个数值求 Z；②两次考核/两类变量比较相对排名——各自算 Z，Z 大的排名高（原始分不可直接比）；③经验法则——68%/95%/99% 与区间互换（均值 10000、标准差 2000，68% 对应 [8000, 12000]）；④「不改变数值在原始分布中的位置、不改变原分布的偏度；变换后均值 0、标准差 1」；⑤Z 为负说明该数值低于均值。

### 考点10 变量之间的相关关系 ★★

**核心概念**：按三种标准分类。

| 分类标准 | 类别 | 含义 | 举例 |
|---|---|---|---|
| 按相关的**程度** | 完全相关 | 一个变量的取值变化**完全由另一个变量的取值变化所确定** | 价格不变的条件下，某种商品的销售额由其销售量决定 |
| | 不完全相关 | 两个变量之间的关系介于完全相关和不相关之间 | 居民的食品支出与收入水平；商品销售额与广告费支出；某产品利润与单位成本；某市景点游客数量与票价 |
| | 不相关 | 两个变量的取值变化彼此互不影响 | 股票的价格与气温的高低 |
| 按相关的**方向** | 正相关 | 一个变量的取值由小变大，另一个变量的取值也相应地由小变大（同方向） | 工人的工资随着劳动生产率的提高而增加 |
| | 负相关 | 一个变量的取值由小变大，另一个变量的取值由大变小（反方向） | 商品销售量随着单价的升高而降低 |
| 按相关的**形式** | 线性相关 | 两个相关变量之间的关系大致呈现为直线关系 | —— |
| | 非线性相关 | 不表现直线关系，而近似于某种曲线方程的关系 | —— |

> **【注】相关关系并不等于因果关系**，也不等同于函数关系。**大部分相关现象均属于不完全相关**。

```
相关关系分类链：
程度：完全相关 / 不完全相关（大多数） / 不相关
方向：正相关（同向） / 负相关（反向）
形式：线性相关 / 非线性相关
        ↓
三者可组合描述，如「正相关、不完全相关、线性相关」
        ↓
铁律：相关 ≠ 因果，相关 ≠ 函数
```

**速记口诀**：**「程度看完全不完全，方向看同向反向，形式看直线曲线；相关不等于因果」**。

**考法提示（据素材真题归纳）**：①三种分类标准要能对应到具体类别；②完全相关的定义——「一个变量的取值变化完全由另一个变量的取值变化所确定」（价格不变时销售额由销售量决定）；③不相关——取值变化彼此互不影响（股票价格与气温）；④「两个变量只有完全相关和不相关两种形式」是错项，还有**不完全相关**，且大部分相关现象属于不完全相关；⑤相关关系**不等同于**因果关系，也**不等同于**函数关系。

### 考点11 两变量的散点图 ★★

**核心概念**：两变量之间的关系可以用**散点图**来展示。在散点图中，**每个点代表一个观测值**，横纵坐标值分别代表两个变量相应的观测值。

| 散点图形态 | 对应关系 |
|---|---|
| 不相关 | 散点分布无规律 |
| 正线性相关 | 散点大致沿一条**上升**直线分布 |
| 完全正线性相关 | 散点**完全在一条上升直线**上 |
| 负线性相关 | 散点大致沿一条**下降**直线分布 |
| 完全负线性相关 | 散点**完全在一条下降直线**上 |
| 非线性相关 | 散点呈曲线模式 |

```
散点图判读链：
① 看走势定方向：上升 → 正相关；下降 → 负相关；无规律 → 不相关
        ↓
② 看模式定形式：呈直线 → 线性相关；呈曲线 → 非线性相关
        ↓
③ 看是否落在一条直线上定程度：
   完全在一条直线上 → 完全相关；大致呈直线 → 不完全相关
        ↓
铁律：散点图只能说明相关，不能推出因果
```

**速记口诀**：**「散点看图两步走：先看升降定正负，再看直曲定线性；全在直线上才叫完全相关」**。

**考法提示（据素材真题归纳）**：①基本特征——每个点代表一个观测值，横纵坐标分别是两个变量相应的观测值；②工龄与月平均工资的散点图——走势上升判**正相关**，观测点呈曲线模式判**非线性相关**；③「散点大致呈直线」只是不完全相关，**完全相关要求散点完全在一条直线上**；④散点图只能说明相关，不能据此推出因果。

### 考点12 相关系数 ★★★

**核心概念**：相关系数是度量两个变量之间相关关系的统计量。最常用的是 **Pearson（皮尔逊）相关系数 r**，**只适用线性相关关系**。

| r 的取值 | 两变量之间的关系 |
|---|---|
| 0 < r ≤ 1 | 存在**正线性相关** |
| −1 ≤ r < 0 | 存在**负线性相关** |
| r = 1 | **完全正线性相关** |
| r = −1 | **完全负线性相关** |
| r = 0 | **不存在线性相关关系**，但并不能说明两变量之间没有任何关系，它们之间可能存在**非线性相关关系** |

Pearson 相关系数的取值范围在 +1 和 −1 之间，即 **−1 ≤ r ≤ 1**。根据实际数据计算出的 r，其取值一般为 −1 < r < 1。

| \|r\| 的取值 | 相关程度 |
|---|---|
| \|r\| < 0.3 | 相关程度极弱，可视为**无线性相关关系** |
| 0.3 ≤ \|r\| < 0.5 | **低度相关** |
| 0.5 ≤ \|r\| < 0.8 | **中度相关** |
| \|r\| ≥ 0.8 | **高度相关** |

> ※ **相关系数的绝对值越大，相关程度越高**（正负号只表示方向，不代表强度）。

```
相关系数判读链：
看符号：r > 0 正相关；r < 0 负相关；r = 0 无线性相关
        ↓
看绝对值定强度：<0.3 极弱（视作无）；0.3–0.5 低度；0.5–0.8 中度；≥0.8 高度
        ↓
看端点：r = ±1 完全线性相关
        ↓
提示：散点图和相关系数通常结合考核——给出散点图应能判断 r 的大致范围，
      给出 r 的范围也应能大致判断散点图形状；重点考正线性相关和负线性相关
```

**速记口诀**：**「相关系数负一到正一，绝对值越大越紧密；三八二零三点五（0.3/0.5/0.8），极弱低度中度高度」**。

**考法提示（据素材真题归纳）**：①Pearson 相关系数**只适用线性相关关系**；②取值范围 **−1 ≤ r ≤ 1**；③r 取值含义表（0<r≤1 正线性相关、−1≤r<0 负线性相关、r=±1 完全线性相关、r=0 无线性相关但可能有非线性相关）；④相关程度四级划分与「绝对值越大，相关程度越高」；⑤与散点图结合判读——给出散点图能判断 r 的大致范围，给出 r 的范围能大致判断散点图形状，重点考正线性相关和负线性相关。

### 本章五大核心辨析（综合命题热点，考前必过一遍）

**辨析一：算术平均数 vs 几何平均数的适用场景**

素材中出现的平均数**只有算术平均数**一种（总和÷个数），集中趋势最主要的测度值指的也是它。几何平均数仅在两道题的干扰选项中出现，素材并借此强调「离散系数的分母是**算术平均数**，不是几何平均数」。**几何平均数的公式与适用场景：素材未覆盖**，本节不作补写，复习时以教材原文为准。可确定的一条结论：**标准差系数（离散系数）的分母是算术平均数**。

**辨析二：均值 vs 中位数 vs 众数（含偏态分布下的选用）**

| 比较维度 | 均值 | 中位数 | 众数 |
|---|---|---|---|
| 是否受极端值影响 | 受影响 | 不受影响 | 不受影响 |
| 是否充分利用全部信息 | 是（较稳定） | 否（稳定性差于均值、优于众数） | 否（缺乏稳定性、可能不唯一） |
| 偏态分布下的表现 | 代表性较差 | **尤其适用于收入类偏斜分布的数值型数据** | 分布明显偏态时代表性更好 |
| 严重左偏分布选谁 | —— | **选中位数** | —— |

> 素材提示「偏态系数搭配均值、中位数、众数位置排序是全章综合命题热点」，但**未给出三者数值大小的具体排序规则**（如偏态时三者谁大谁小），该规则属**素材未覆盖**，不要凭印象硬记，请以教材原文为准。

**辨析三：标准差 vs 离散系数（是否消除量纲影响）**

| 比较维度 | 标准差 | 离散系数 |
|---|---|---|
| 计算 | 方差的平方根 | 标准差 ÷ 均值 |
| 单位 | 与原数据相同 | 无单位（相对数） |
| 受测度单位影响 | 是 | **否（已消除）** |
| 受观测值均值水平影响 | 是 | **否（已消除）** |
| 能否直接比较不同类别数据 | **不能** | **能** |

结论：标准差的大小不仅与数据的测度单位有关，也与观测值的均值大小有关，所以**不能直接用标准差比较不同变量的离散程度**；离散系数消除了这两方面影响，可以直接比较。典型真题：学生与教师标准差都是 3 岁，但均值 20 岁与 38 岁不同，必须用 CV（0.15 vs 0.0789）判定学生更分散。

**辨析四：偏态系数的正负含义**

正 → 右偏；负 → 左偏；零 → 对称（正态分布）。程度不看符号看**绝对值**：|SK| 在 0～0.5 轻度、0.5～1 中度、大于 1 严重。因此 −2 的偏斜程度比 1 更严重，−0.33 只是轻度左偏。

**辨析五：相关系数的取值与相关强度**

符号定方向（正相关/负相关），绝对值定强度；分界值 0.3、0.5、0.8 对应极弱、低度、中度、高度；端点 ±1 为完全线性相关；r = 0 只说明不存在线性相关关系，不能说明两变量没有任何关系（可能存在非线性相关）。比较相关程度时负号不参与大小比较，如 −0.93 的相关程度高于 0.82。

### 4.0 本章计算题抢分策略

素材考情分析明确指出：**计算题型常年锁定中位数、离散系数、标准分数三处轮换出题**。三处的通用解法可以归纳为同一套动作：

```
第一步：判断考哪个指标（题干关键词）
   「平均数/平均水平」      → 算术平均数
   「排序后居中/位置居中」  → 中位数
   「出现次数最多」        → 众数
   「离散程度/差异程度」    → 方差、标准差
   「不同类别数据比离散」  → 离散系数
   「相对位置/相对排名」   → 标准分数
第二步：套公式前先检查前提
   中位数 → 必须先排序（奇数/偶数两种公式）
   离散系数 → 若给的是方差，先开方得标准差
   标准分数 → 两次考核必须各自算 Z，不能比原始分
第三步：算完对照选项，注意单位与量纲
   标准差带原单位；离散系数、标准分数、相关系数均无单位
```

**三个高频失分点**：①中位数忘排序；②给方差求离散系数时忘记先开方；③两次考核直接比原始分数。

### 4.1 集中趋势的测度

#### 公式1 算术平均数（简单平均数）

**公式**：

```
简单算术平均数  X̄ = (X1 + X2 + … + Xn) / n = ΣXi / n
```

**演算例题1（素材教材例题）**：某售货小组有 5 名营业员，元旦一天的销售额分别为 520 元、600 元、480 元、750 元和 500 元，求该日平均销售额。

```
平均销售额 = (520 + 600 + 480 + 750 + 500) / 5
           = 2850 / 5
           = 570（元）
```

**演算例题2（素材真题数字）**：某城市 2014 年 4 月空气质量检测结果中，随机抽取 6 天的质量指数分别为 30、40、50、60、80 和 100。

```
平均数 = (30+40+50+60+80+100) / 6 = 360 / 6 = 60   （答案 C）
```

**演算例题3（素材练一练）**：某地级市 9 个县市区的苹果产量（万吨）为 10、10、12、21、23、38、41、45、72。

```
平均数 = (10+10+12+21+23+38+41+45+72) / 9 = 272 / 9 ≈ 30.22（万吨）
```

#### 公式4 中位数

**公式**：

```
步骤：① 排序 → ② 定位 → ③ 取值
n 为奇数：位置 = (n+1)/2，取该位数值
n 为偶数：位置介于 n/2 与 n/2+1 之间，
          Me = (第 n/2 位数 + 第 n/2+1 位数) / 2
```

**演算例题1（素材教材例题，n 为奇数）**：某地级市下辖 9 个县，面积分别为 1455、2019、912、1016、1352、1031、2128、1075、2000。

```
① 排序：912  1016  1031  1075  1352  1455  2000  2019  2128
② 定位：(9+1)/2 = 5 → 第 5 位
③ Me = 1352
```

**演算例题2（素材教材例题，n 为偶数）**：某地级市下辖 10 个县，面积分别为 912、1000、1016、1031、1075、1352、1455、2000、2019、2128（已排好序）。

```
① 定位：(10+1)/2 = 5.5 → 第 5 位与第 6 位之间
② Me = (1075 + 1352) / 2 = 2427 / 2 = 1213.5
```

**演算例题3（素材真题数字）**：2020 年某省 8 个地市的财政支出（万元）分别为 59000、50002、65602、66450、78000、78000、78000、132100。

```
① 排序：50002  59000  65602  66450  78000  78000  78000  132100
② n=8 为偶数 → 取第 4、第 5 位的平均数
③ Me = (66450 + 78000) / 2 = 144450 / 2 = 72225（万元）
```

#### 公式5 众数

**公式**：出现次数（频数）最多的变量值即为众数。

**演算例题1（素材例题）**：2020 年某省 8 个地市财政支出中，78000 出现 3 次（频数最多）→ 众数 = **78000 万元**（故该题中位数与众数分别为 72225 和 78000）。

**演算例题2（素材例题）**：9 个分公司主营产品中「煤制品」出现 4 次 → 众数 = **煤制品**。

**演算例题3（素材练一练）**：苹果产量 10、10、12、21、23、38、41、45、72 中，10 出现 2 次 → 众数 = **10 万吨**（该组数据：平均数 ≈30.22，中位数 = 第 5 位 = 23，众数 = 10，三者差异明显，典型右偏特征）。

### 4.2 离散程度的测度

#### 公式6 极差（Range）

> **素材未覆盖**。素材未给出极差的定义与公式（仅在一道真题中作为错误选项出现），本节不作补写。

#### 公式7 方差（样本）

**公式**：

```
样本方差 = Σ(Xi − X̄)² / (n − 1)
```

**演算例题1（素材教材例题）**：5 名营业员元旦销售额 520、600、480、750、500 元。

```
① 均值 X̄ = 570
② 离差：520-570=-50；600-570=30；480-570=-90；750-570=180；500-570=-70
③ 离差平方和 = (-50)²+(30)²+(-90)²+(180)²+(-70)²
            = 2500+900+8100+32400+4900 = 48800
④ 样本方差 = 48800 / (5-1) = 48800 / 4 = 12200
```

**演算例题2（素材例题）**：某售货小组有 3 名营业员，国庆一天的销售额为 2、4、6。

```
① 均值 = (2+4+6)/3 = 4
② 离差：-2, 0, +2 → 平方和 = 4+0+4 = 8
③ 样本方差 = 8 / (3-1) = 4
```

#### 公式8 标准差（样本）

**公式**：

```
样本标准差 S = √[ Σ(Xi − X̄)² / (n − 1) ] = √方差
```

**演算例题1（承上 5 名营业员例题）**：

```
样本标准差 = √12200 ≈ 110.45（元）
```

**演算例题2（承上 3 名营业员例题）**：方差 = 4 → 样本标准差 = √4 = **2**。

> 记忆点：标准差是方差的**平方根**，方差是标准差的**平方**；标准差与原始数值具有**相同的计量单位**，方差没有。

#### 公式9 离散系数（标准差系数 / 变异系数）

**公式**：

```
CV = S / X̄  （标准差 ÷ 均值）
```

**演算例题1（承上 5 名营业员例题）**：

```
CV = 110.45 / 570 ≈ 0.19
```

**演算例题2（素材真题数字）**：一组数据的方差为 25，均值为 500。

```
标准差 = √25 = 5
CV = 5 / 500 = 0.01        （答案 B）
```

**演算例题3（素材真题数字）**：某学校学生平均年龄 20 岁、标准差 3 岁；教师平均年龄 38 岁、标准差 3 岁。

```
学生 CV = 3/20   = 0.15
教师 CV = 3/38   ≈ 0.0789
0.15 > 0.0789 → 学生年龄的离散程度更大   （答案 D）
（标准差都是 3 岁，但均值水平不同，必须用离散系数）
```

**演算例题4（素材真题数字）**：某班级身高 CV = 0.05，体重 CV = 0.08。

```
0.08 > 0.05 → 体重的离散程度更大   （答案 B）
（身高与体重单位不同，更必须用离散系数）
```

#### 公式12 标准分数（Z 分数）

**公式**：

```
Zi = (Xi − X̄) / S
```

**演算例题1（素材例题）**：甲、乙、丙、丁四人在某次语文考试中分别获得 72、60、48、90 分，全体学生平均成绩 60 分，标准差 12 分。

```
Z甲 = (72-60)/12 = 1
Z乙 = (60-60)/12 = 0
Z丙 = (48-60)/12 = -1
Z丁 = (90-60)/12 = 2.5
```

**演算例题2（素材真题数字）**：一组数据均值为 60、标准差 20，其中一个数值为 40。

```
Z = (40-60)/20 = -20/20 = -1        （答案 B）
```

**演算例题3（素材真题数字）**：一组数据的平均值为 70，标准差为 10，其中一个数值为 80。

```
Z = (80-70)/10 = 1                  （答案 C）
```

**演算例题4（素材真题数字，两次考核比较）**：考核 A 均值 70、标准差 5；考核 B 均值 80、标准差 10。某员工在 A 中得 80 分，在 B 中得 90 分。

```
A 的标准分数 = (80-70)/5 = 2   → 比平均高 2 个标准差
B 的标准分数 = (90-80)/10 = 1  → 比平均高 1 个标准差
→ 该员工在考核 A 中的相对排名高于考核 B        （答案 A）
```

**演算例题5（素材例题）**：考核 A 均值 80、标准差 20；考核 B 均值 60、标准差 5。张三两项考核均得 80 分。

```
A 的标准分数 = (80-80)/20 = 0  → 中等水平
B 的标准分数 = (80-60)/5  = 4  → 名列前茅
```

**演算例题6（经验法则，素材真题数字）**：某城市居民月收入服从对称钟形分布，均值 10000 元，标准差 2000 元，求约 68% 的居民月收入范围。

```
μ ± 1σ = 10000 ± 2000 → [8000, 12000]      （答案 D）
（若问 95% → μ ± 2σ = [6000, 14000]；若问 99% → μ ± 3σ = [4000, 16000]）
```

### 4.6 计算题常见错误对照

| 题型 | 典型错法 | 正确做法 |
|---|---|---|
| 求中位数 | 不排序直接数个数；n 为偶数时只取中间一个数 | 先排序；n 偶取第 n/2 与第 n/2+1 位的**平均数** |
| 求标准差 | 把方差直接当标准差；或忘记开方 | 标准差 = √方差（12200 → 110.45） |
| 求离散系数 | 给方差时直接用方差除以均值 | 必须先开方：√25 = 5，再 5/500 = 0.01 |
| 比较离散程度 | 标准差相同就认为离散程度相同 | 均值不同时必须用 CV（3/20 vs 3/38） |
| 标准分数 | 两次考核直接比原始分（80 vs 90） | 各自算 Z（2 vs 1），Z 大的排名高 |
| 经验法则 | 68% 对应 ±2σ | 1σ→68%、2σ→95%、3σ→99% |
| 相关系数 | 认为 −0.93 比 0.82 相关程度低 | 看绝对值：0.93 > 0.82 |

## 五、高频考点速记卡

1. **Q：集中趋势的测度是什么？反映什么？**
   A：一组数据向某一中心值靠拢的程度，反映一组数据**中心点的位置**所在；集中趋势的测度也就是寻找数据**一般水平代表值或中心值**。

2. **Q：集中趋势最主要的测度值是哪个？**
   A：**均值**。它是一组数据的重心所在，解释了一组数据的平均水平。

3. **Q：均值适用于什么数据？有什么特点？**
   A：主要适用于**数值型数据**，不适用于分类数据和顺序数据；特点是**易受极端值影响**，能充分利用数据全部信息、比较稳定。

4. **Q：中位数的计算步骤？n 为奇数和偶数分别怎么取？**
   A：数据排序 → 确定位置 → 确定数值。n 为奇数取第 (n+1)/2 位；n 为偶数取第 n/2 位与第 n/2+1 位两个数的平均数。

5. **Q：中位数适用于哪些数据？最大优点是什么？**
   A：主要用于**顺序数据和数值型数据**，不适用于分类数据；优点是**不受极端值影响、抗干扰性强**，尤其适用于收入类偏斜分布的数值型数据。

6. **Q：众数的定义？适用于哪些数据？**
   A：一组数据中**出现次数（频数）最多**的变量值；适用于**分类数据和顺序数据**，不适用于定量数据。

7. **Q：众数的缺点是什么？**
   A：没有充分利用数据的全部信息，**缺乏稳定性，而且可能不唯一**（定量数据中可能出现多众数、无众数）。

8. **Q：众数是算术平均数的一种吗？**
   A：不是。众数是**位置平均数**。

9. **Q：中位数与众数的共同优点？**
   A：**不受极端值影响**。

10. **Q：与均值、中位数相比，众数的缺点？**
    A：**缺乏稳定性**。

11. **Q：离散程度反映什么？与集中趋势测度值的代表性有什么关系？**
    A：反映数据之间的**差异程度**。离散程度**越大**，集中趋势测度值的代表性**越差**；离散程度**越小**，代表性**越好**。

12. **Q：方差的定义？与均值的代表性有什么关系？**
    A：各数值与其均值**离差平方的平均数**。方差越小，数据值与均值的平均距离越小，**均值的代表性越好**。

13. **Q：方差、标准差的适用范围和共同缺陷？**
    A：只适用于**数值型数据**；与均值一样**对极端值很敏感**；方差的单位是原数据单位的平方，**没有解释意义**。

14. **Q：与方差相比，标准差的优点是什么？**
    A：不仅能度量数值与均值的平均距离，还**与原始数值具有相同的计量单位**。

15. **Q：离散系数是什么？解决什么问题？**
    A：也称**变异系数或标准差系数**，是**标准差与均值的比值**（CV = S/X̄）。它**消除了测度单位和观测值水平不同的影响**，可直接比较不同类别数据的离散程度。

16. **Q：学生平均年龄 20 岁、标准差 3 岁，教师平均年龄 38 岁、标准差 3 岁，谁更分散？**
    A：学生。学生 CV = 3/20 = 0.15，教师 CV = 3/38 ≈ 0.0789，**CV 大的离散程度大**。

17. **Q：偏态系数测度什么？正负分别代表什么？**
    A：测度数据分布的偏斜方向和程度，描述分布的**对称程度**。**为正右偏、为负左偏、为零对称**。

18. **Q：偏态系数的程度怎么分？**
    A：|SK| 在 0～0.5 轻度、0.5～1 中度、大于 1 严重；**绝对值越大偏斜程度越大**。

19. **Q：标准分数怎么算？有什么用？**
    A：Z = (Xi − X̄)/S。用于度量某个数值在一组数据中的**相对位置**；均值和标准差不同时，不同变量的原始值不可比，但**相对位置可比**。

20. **Q：标准分数变换后有什么不变、有什么变？**
    A：**不改变**数值在原始分布中的位置，也**不改变**数据原分布的偏度；变换后标准分数的**均值为 0、标准差为 1**。

21. **Q：经验法则的三个数字？**
    A：对称钟形分布下，约 **68%** 在 ±1σ、约 **95%** 在 ±2σ、约 **99%** 在 ±3σ。

22. **Q：Pearson 相关系数的取值范围？r = 0 说明什么？**
    A：**−1 ≤ r ≤ 1**。r = 0 说明**不存在线性相关关系**，但不能说明两变量没有任何关系，可能存在**非线性相关**。

23. **Q：相关程度怎么分级？**
    A：|r| < 0.3 极弱（视作无线性相关）；0.3～0.5 低度；0.5～0.8 中度；≥ 0.8 高度。**绝对值越大，相关程度越高**。

24. **Q：变量间相关关系有哪三种分类标准？**
    A：按**程度**分完全相关、不完全相关、不相关；按**方向**分正相关、负相关；按**形式**分线性相关、非线性相关。

25. **Q：散点图怎么判读？完全相关的标志是什么？**
    A：先看走势定正负、再看模式定直曲。**散点完全在一条直线上**才是完全相关；大致呈直线只是不完全相关。

### 第三节 分布形态的测度（15 道）

**39.【2023补·单选】下列统计量中，适用于描述数据分布对称程度的是（　）。**
A. 相关分数　B. 标准分数　C. 离散系数　D. 偏态系数
**答案：D**　**解析**：偏度是指数据分布的偏斜方向和程度，描述的是数据分布对称程度。

**40.【2022·单选】如果一组数据的分布是左偏的，则这组数据的偏态系数的取值范围应该是（　）。**
A. 小于 0　B. 绝对值小于 1　C. 大于 0　D. 绝对值大于 1
**答案：A**　**解析**：偏态系数为负值说明分布为左偏，取值在 0 和 −0.5 之间说明轻度左偏，−0.5 和 −1 之间中度左偏，小于 −1 严重左偏；偏态系数的绝对值越大，说明数据分布的偏斜程度越大。

**41.【2021·单选】对数据分布偏态的测度，反映数据分布的（　）。**
A. 分散度　B. 集中度　C. 不对称性　D. 代表程度
**答案：C**　**解析**：数据分布特征的测度分三个方面：分布的集中趋势，反映各数据向其中心值靠拢或聚集的程度；分布的离散程度，反映各数据之间的差异程度，也能反映中心值对数据的代表程度；分布的偏态，反映数据分布的**不对称性**。

**42.【2020·单选】如果一组数据的偏态系数为 0.3，则该组数据的分布为（　）。**
A. 轻度右偏　B. 轻度左偏　C. 严重右偏　D. 中度右偏
**答案：A**　**解析**：偏态系数为正说明分布右偏，取值在 0～0.5 之间说明轻度右偏，0.5～1 之间中度右偏，大于 1 严重右偏；0.3 落在 0～0.5，故为轻度右偏。

**43.【2024·单选】一组数据的偏态系数为 −0.33，则可以判断该组数据的分布为（　）。**
A. 轻度右偏　B. 严重左偏　C. 中度左偏　D. 轻度左偏
**答案：D**　**解析**：偏态系数取决于离差三次方的平均数与标准差三次方的比值。等于 0 对称；为正在 0～0.5 轻度右偏、0.5～1 中度右偏、大于 1 严重右偏；为负在 0～−0.5 轻度左偏、−0.5～−1 中度左偏、小于 −1 严重左偏。−0.33 落在 0～−0.5，故轻度左偏。

**44.【单选】测度数据分布偏度的统计量称为偏态系数，下列偏态系数说明数据分布的偏斜程度最大的是（　）。**
A. 偏态系数为 0　B. 偏态系数为 0.5　C. 偏态系数为 1　D. 偏态系数为 −2
**答案：D**　**解析**：偏态系数的绝对值越大，说明数据分布的偏斜程度越大；|−2| = 2 最大。

**45.【多选】某企业员工年收入数据分布的偏态系数为 3.0，则该组数据分布形态为（　）。**

**46.【单选】偏度是指数据分布的偏斜方向和程度，描述的是数据分布对称程度。当偏态系数 = 0.96 时，说明（　）。**

### 第四节 变量间的相关分析（14 道）

**54.【2024·多选】关于变量间相关关系的说法，正确的有（　）。**
A. 如果两个变量之间相关，当一个变量的取值由小变大，另一个变量的取值也应由小变大
B. 相关关系并不等同于因果关系
C. 两个变量之间的相关形式都是线性的
D. 当一个变量的取值变化完全由另一个变量的取值变化所确定时，这两个变量间的关系为完全相关
E. 两个变量之间的关系只有完全相关和不相关两种形式
**答案：BD**　**解析**：A 错误，一个变量由小变大、另一个由大变小称为负相关；C 错误，按相关形式可分为线性相关和非线性相关；E 错误，按相关程度可分为完全相关、不完全相关和不相关。

**55.【2023补·多选】某散点图如下，关于这两个变量间关系的说法，正确的有（　）。**
A. 为负相关关系　B. 不相关　C. 为因果关系　D. 为不完全相关关系　E. 正相关
**答案：AD**　**解析**：按相关程度可分为完全相关、不完全相关和不相关；按方向可分为正相关和负相关；按形式可分为线性相关和非线性相关。该散点图为负相关且未落在一条直线上，属不完全相关；需要注意**相关关系并不等同于因果关系**。

**56.【单选】某企业员工的工龄和月平均工资的散点图如下（横轴为工龄，纵轴为月平均工资），根据此散点图，工龄和月平均工资两个变量的相关关系为（　）。**

**57.【多选】根据变量 X 和变量 Y 的散点图，可以看出这两个变量间的相关关系为（　）。**
A. 正相关　B. 不相关　C. 负相关　D. 线性相关　E. 完全相关

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把均值、中位数、众数的适用范围记混 | 一张表搞定：**分类→众数；顺序→中位数＋众数；定量→均值＋中位数**（众数不适用定量） |
| 2 | 以为中位数可以测度分类数据 | 中位数是**位置代表值**，分类数据无大小位置，只适用顺序数据和数值型数据 |
| 3 | 以为众数是算术平均数的一种 | 众数是**位置平均数**；算术平均数只有「总和÷个数」 |
| 4 | 以为一组数据的众数唯一 | 定量数据中可能**多众数、无众数**，所以众数不适用于定量数据 |
| 5 | 以为均值最稳健、什么数据都能用 | 均值**易受极端值影响**且只适用数值型数据；偏态分布（如收入）选中位数 |
| 6 | 算中位数忘记先排序 | 口诀「**先排序后定位**」，奇数取中间、偶数取俩平均 |
| 7 | 以为方差与原始数据同单位 | 方差单位是原单位的**平方**、无解释意义；**标准差**才与原始数据同单位 |
| 8 | 以为方差、标准差可用于分类数据 | 二者**只适用于数值型数据**，且对极端值很敏感 |
| 9 | 直接用标准差比较不同变量的离散程度 | 单位和均值水平都不同，必须先算 **CV = S/X̄** 再比大小 |
| 10 | 把标准差系数的分母记成几何平均数或极值 | 分母是**均值（算术平均数）**；真题专门考过这个点 |
| 11 | 以为离散系数是比较「位置」差异 | 是比较**离散程度**差异，题干写「位置差异」就是错项 |
| 12 | 以为离散程度越大，均值代表性越好 | **反向**：离散程度越大，集中趋势测度值代表性**越差** |
| 13 | 偏态系数正负记反 | **正右负左零对称**；程度看绝对值（0.5 和 1 两道分界） |
| 14 | 以为 −2 的偏斜程度不如 1 大 | 偏斜程度看**绝对值**：\|−2\| > \|1\|，所以 −2 偏斜更严重 |
| 15 | 经验法则 68/95/99 记混 | 1σ→68%、2σ→95%、3σ→99%；口诀「**三舅舅，二舅我，一路发**」 |
| 16 | 以为标准分数改变了数据的相对位置 | 标准分数**不改变**数值在原始分布中的位置，也**不改变**原分布的偏度；变换后均值 0、标准差 1 |
| 17 | 两次考核原始分直接比高低 | 均值和标准差不同，原始分不可比；各自算 **Z = (Xi − X̄)/S**，Z 大的排名高 |
| 18 | 以为 r = 0 就是两变量毫无关系 | r = 0 只是**无线性相关**，仍可能存在**非线性相关** |
| 19 | 以为相关系数为负就是相关程度低 | 负号只表示**方向**，强度看**绝对值**（−0.93 比 0.82 更强） |
| 20 | 把相关关系当成因果关系或函数关系 | 相关**≠**因果、**≠**函数；这是每年多选的固定错项 |
| 21 | 以为散点大致呈直线就是完全相关 | 完全相关要求散点**完全落在一条直线上**；大致呈直线只是不完全相关 |
| 22 | 分不清「偏态系数搭配均值、中位数、众数位置排序」的具体规则 | 素材仅提示这是全章综合命题热点，**未给出三者位置排序的具体规则**，属素材未覆盖，复习时以教材原文为准，不要凭印象硬记 |
| 23 | 计算题只记公式不记前提 | 中位数**先排序**；离散系数若给方差**先开方**；标准分数两次考核**各自算 Z**——前提错了，公式再熟也白算 |
| 24 | 把「偏态系数为负」和「偏斜程度大」画等号 | −0.33 只是**轻度左偏**；程度看**绝对值**，−2 才叫严重左偏 |
| 25 | 混淆「标准差系数」与「标准分数」 | 标准差系数 = 标准差/均值（比离散程度）；标准分数 = (数值−均值)/标准差（看相对位置），分母一个是均值一个是标准差 |
