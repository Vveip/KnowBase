## 二、知识点精讲

### 考点1 财政管理体制的含义 ★

**核心概念**：财政管理体制是指国家管理和规范中央与地方政府之间以及地方各级政府之间划分**财政收支范围**和**财政管理职责与权限**的一项**根本制度**。

| 口径 | 包含内容 |
|---|---|
| 广义的财政管理体制 | 政府预算管理体制、税收管理体制、公共部门财务管理体制 |
| 狭义的财政管理体制 | 政府预算管理体制 |

**关键结论**：**政府预算管理体制是财政管理体制的中心环节**。

```
财政管理体制（划分财政收支范围与管理职责权限的根本制度）
 ├─ 广义 → 政府预算管理体制 ＋ 税收管理体制 ＋ 公共部门财务管理体制
 └─ 狭义 → 政府预算管理体制  ★中心环节
```

**速记口诀**："广义三兄弟（预算、税收、公共部门财务），狭义留预算；预算体制是中心环节。"

### 考点2 财政管理体制的内容 ★★★

四大内容：

```
财政管理体制的内容（四件套）
 ① 财政分配和管理机构的设置 —— 目前我国财政管理机构分为五级
 ② 政府间事权及支出责任划分 —— 四原则：受益、效率、区域、技术
 ③ 政府间财政收入的划分 —— 税种属性是主要标准；四原则：集权、效率、恰当、收益与负担对等
 ④ 政府间财政转移支付制度 —— 协调中央与地方财政关系的重要配套制度
```

**（1）机构设置**：目前我国财政管理机构分为**五级**。

**（2）政府间事权及支出责任划分的原则**

| 原则 | 划分依据 | 素材示例 |
|---|---|---|
| 受益原则 | 根据公共产品和服务的**受益范围** | 全国性公共产品和服务→中央政府；地方性公共产品和服务→地方政府 |
| 效率原则 | 根据产品的**配置效率**来确定事权归属 | —— |
| 区域原则 | 根据公共产品和服务的**区域性** | —— |
| 技术原则 | 根据公共产品和服务的**规模大小、技术难易程度** | —— |

**（3）政府间财政收入的划分**

**税种属性**是决定政府间财政收入划分的主要标准。市场经济成熟国家一般遵循四个原则：

| 原则 | 做法 |
|---|---|
| 集权原则 | 将收入份额较大的主体税种划归中央政府 |
| 效率原则 | 流动性较强的收入作为中央政府收入；流动性不强的收入划归地方政府 |
| 恰当原则 | 体现宏观调控的消费税、体现主权的关税归中央 |
| 收益与负担对等原则 | 收益和负担能够直接对应的收入（如使用费）作为地方政府收入 |

**（4）国际经验的基本特征**：政府间财政收支划分呈现**收入结构与支出结构的非对称性安排**——收入结构划分以**中央政府**为主，支出结构划分则以**地方政府**为主。

**速记口诀**："内容四件套：机构、事权、收入、转移支付；事权四原则'受效区域技术'，收入四原则'集效当对'；收支非对称——收入归中央、支出归地方。"

### 考点3 财政管理体制的类型 ★

| 维度 | 财政联邦制模式 | 财政单一制模式 |
|---|---|---|
| 权力划分 | 联邦政府和州权力划分遵循"**州余权主义**" | **中央政府统一领导** |
| 中央与地方关系 | 中央和州相对独立、平等、互不从属；公民隶属两级或多级政府，中央和州在宪法规定事务上相互协调 | 地方政府拥有的分权水平**较低**，自主性**小** |
| 典型国家 | 美国、加拿大、德国、澳大利亚、俄罗斯、墨西哥、印度 | 英国、法国、日本、韩国、意大利 |

**我国财政管理体制沿革（了解）**：

```
新中国成立以来：统收统支、高度集中的财政管理体制
1980—1993：三次大改革，统称"包干制"
   ├─ 1980—1984 "划分收支，分级包干"（"分灶吃饭"体制）
   ├─ 1985—1987 "划分税种、核定收支、分级包干"
   └─ 1988—1993 包干财政体制
1994年起：取消包干制，实行分税制财政管理体制
```

**速记口诀**："联邦州余权、美加德澳俄墨印；单一中央统领导、英法日韩意；我国九四改分税。"

### 考点5 分税制财政管理体制改革的内容 ★★★★（本章最高频）

**定义**：分税制财政管理体制，简称**分税制**，是将国家的**全部税种**在中央和地方之间进行划分，借以确定中央和地方财政收入范围的一种财政管理体制。

**两项内容**：
- **确定支出范围**：按照中央政府与地方政府各自的事权，确定各级财政的支出范围；
- **收入划分**：依据**财权与事权相统一**的原则，合理划分中央与地方收入，**按税种**划分中央和地方收入。

**（1）现行中央财政和地方财政收入划分**

| 类别 | 具体项目 |
|---|---|
| 中央固定收入 | 关税，海关代征的增值税和消费税，出口退税，船舶吨税；消费税，证券交易印花税，车辆购置税；各银行总行、保险总公司等部门集中缴纳的收入（利润和城市维护建设税）、中央企业所得税和上缴利润等收入 |
| 地方固定收入 | 地方企业上缴利润；城镇土地使用税、土地增值税、城市维护建设税、耕地占用税、国有土地有偿使用收入；房产税、印花税、烟叶税、契税、车船税 |
| 中央与地方共享收入 | 增值税（不含进口环节由海关代征的部分）：中央 50%、地方 50%；资源税：海洋石油资源税归中央，其余资源税归地方；企业所得税和个人所得税：中央 60%、地方 40% |

**（2）现行中央财政和地方财政支出责任划分**

| 中央财政支出 | 地方财政支出 |
|---|---|
| 国防，武警经费，外交支出，中央级行政管理费，中央统筹的基本建设投资，中央直属企业的技术改造和新产品试制经费，地质勘探费，中央安排的农业支出，中央负担的国内外债务的还本付息支出，中央负担的公检法支出和文化、教育、卫生、科学等各项事业费支出 | 地方行政管理费，公检法经费，民兵事业费，地方统筹安排的基本建设投资，地方企业的技术改造和新产品试制经费，地方安排的农业支出，城市维护建设费，地方文化、教育、卫生等各项事业费及其他支出 |

```
分税制 ＝ 确定支出范围（按事权） ＋ 收入划分（按税种，财权与事权相统一）
 ├─ 中央固定：关税／海关代征增值税消费税、消费税、证券交易印花税、车辆购置税、
 │            船舶吨税、出口退税、银行保险总公司集中缴纳收入（利润＋城建税）、
 │            中央企业所得税和上缴利润
 ├─ 地方固定：地方企业上缴利润、城镇土地使用税、土地增值税、城市维护建设税（不含银行保险集中部分）、
 │            耕地占用税、国有土地有偿使用收入、房产税、印花税（不含证券交易印花税）、
 │            烟叶税、契税、车船税
 └─ 共享收入：增值税 中央50%／地方50%
             企业所得税＋个人所得税 中央60%／地方40%
             资源税 海洋石油归中央、其余归地方
```

**速记口诀**："支出按事权、收入按税种；增值税五五开，所得税六四开，海洋石油归中央；城建、印花有例外（不含银行保险集中部分），证券交易印花税、车辆购置税归中央。"

### 考点7 深化财政体制改革的主要任务 ★★★

依据《中共中央关于进一步全面深化改革推进中国式现代化的决定》，深化财税体制改革、健全预算制度等作出重要部署。四条任务：

| 序号 | 任务 | 关键动作 |
|---|---|---|
| 1 | 健全预算制度，加强财政资源和预算统筹 | 把依托行政权力、政府信用、国有资源资产获取的收入全部纳入政府预算管理；完善国有资本经营预算和绩效评价制度；强化国家重大战略任务和基本民生财力保障；强化对预算编制和财政政策的宏观指导；加强公共服务绩效管理，强化事前功能评估；**深化零基预算改革**；统一预算分配权，提高预算管理统一性、规范性，完善预算公开和监督制度；完善权责发生制政府综合财务报告制度 |
| 2 | 健全有利于高质量发展、社会公平、市场统一的税收制度 | 优化税制结构；研究同新业态相适应的税收制度；全面落实税收法定原则，规范税收优惠政策，完善对重点领域和关键环节支持机制；**健全直接税体系**，完善**综合和分类相结合的个人所得税制度**，规范经营所得、资本所得、财产所得税收政策，实行劳动性所得统一征税；深化税收征管改革 |
| 3 | 建立权责清晰、财力协调、区域均衡的中央和地方财政关系 | 增加地方自主财力，拓展地方税源，适当扩大地方税收管理权限；完善财政转移支付体系，**清理规范专项转移支付、增加一般性转移支付**，提升市县财力同事权相匹配程度；建立促进高质量发展转移支付激励约束机制；**推进消费税征收环节后移并稳步下划地方**，完善增值税留抵退税政策和抵扣链条，优化共享税分享比例；研究把城市维护建设税、教育费附加、地方教育附加合并为**地方附加税**，授权地方在一定幅度内确定具体适用税率；合理扩大地方政府专项债券支持范围；完善政府债务管理制度，建立全口径地方债务监测监管体系和防范化解隐性债务风险长效机制，加快地方融资平台改革转型；规范非税收入管理，适当下沉部分非税收入管理权限，由地方结合实际差别化管理 |
| 4 | 适当加强中央事权、提高中央财政支出比例 | 中央财政事权原则上通过**中央本级**安排支出，减少委托地方代行的中央财政事权；**不得违规要求地方安排配套资金**，确需委托地方行使事权的，通过**专项转移支付**安排资金 |

**速记口诀**："一健预算、二优税收、三调关系、四强中央。"

### 考点8 财政转移支付的含义 ★

- **含义**：政府间财政转移支付制度，是在处理中央与地方财政关系时，协调上下级财政之间关系的一项重要制度。
- **最早提出**转移支付概念的是著名经济学家**庇古**（据真题解析，为 1928 年提出）。
- **建立目的**：为了解决地方政府收支不平衡的问题，以及因地区间经济发展不平衡而引起的全国公共服务水平不均衡问题，实现经济社会的稳定协调发展。

**速记口诀**："庇古首提转移支付；弥缺口、均服务、稳协调。"

---

### 考点9 财政转移支付的特点 ★★

五个特点：**完整性、对称性、科学性、统一性和灵活性相结合、法制性**。

| 特点 | 素材展开 |
|---|---|
| 完整性 | 素材仅列名称，未展开 |
| 对称性 | 上级政府对下级政府转移支付的财力，与能够满足该级政府承担、履行的事权职责需求相对应 |
| 科学性 | 素材仅列名称，未展开 |
| 统一性和灵活性相结合 | 素材仅列名称，未展开 |
| 法制性 | 素材仅列名称，未展开 |

**补充要点**：**一般性转移支付系数**主要取决于**转移支付资金总量、地方收支缺口、各地财政困难程度**等因素。

```
五特点：完整 → 对称（财力与事权需求相对应） → 科学 → 统一性和灵活性相结合 → 法制性
一般性转移支付系数的决定因素：资金总量 ＋ 地方收支缺口 ＋ 各地财政困难程度
```

**速记口诀**："完、对、科、统灵结合、法；对称就看事权需求配不配。"

### 考点10 财政转移支付分类 ★★★★

| 类别 | 内容 |
|---|---|
| **均衡拨款** | 对于**地方事权范围**的支出项目，中央政府通过**一般性转移支付**实施财力匹配与均衡 |
| **专项拨款** | 专项转移支付严格限于**中央委托事务、共同事权事务、效益外溢事务和符合中央政策导向事务** |

**速记口诀**："均衡拨款走一般（地方事权用一般性），专项拨款限四类（委托、共管、外溢、导向）。"

### 考点11 我国的财政转移支付分类 ★★

| 类别 | 定义与要点 |
|---|---|
| **一般性转移支付** | 为弥补财政实力薄弱地区的财力缺口，均衡地区间财力差距，实现地区间基本公共服务能力的均等化，中央财政安排给地方财政的补助支出，**由地方统筹安排**。包括均衡性转移支付、民族地区转移支付、县级基本财力保障机制奖补资金、调整工资转移支付、农村税费改革转移支付、资源枯竭城市转移支付等具体项目 |
| **专项转移支付** | 需要按照规定用途使用；重点用于**教育、医疗卫生、社会保障、支农**等公共服务领域 |

**按事权和支出责任划分，专项转移支付分为五类**：

| 类别 | 事权归属 | 定义 |
|---|---|---|
| 委托类专项转移支付 | **中央事权** | 属于中央事权，中央委托地方实施而相应设立 |
| 共担类专项转移支付 | **中央与地方共同事权** | 属于中央与地方共同事权，中央将应分担部分委托地方实施而设立 |
| 引导类专项转移支付 | **地方事权** | 属于地方事权，中央为鼓励和引导地方按照中央的政策意图办理事务而设立 |
| 救济类专项转移支付 | **地方事权** | 属于地方事权，中央为帮助地方应对因自然灾害等发生的增支而设立 |
| 应急类专项转移支付 | **地方事权** | 属于地方事权，中央为帮助地方应对和处理影响区域大、影响面广的突发事件而设立 |

```

 ├─ 一般性转移支付：弥补财力缺口、均衡地区差距、均等化基本公共服务；由地方统筹安排

 │               农村税费改革、资源枯竭城市转移支付
 └─ 专项转移支付：按规定用途使用；重点用于教育、医疗卫生、社会保障、支农
      按事权分五类：委托类（中央事权）／共担类（共同事权）
                     引导类、救济类、应急类（均为地方事权）
```

## 四、关键机制与适用条件

> 本章无公式、无计算题，以下为必须掌握的机制与适用条件。

**机制1：事权与支出责任划分的"四原则"判别逻辑**

```
看受益范围 → 全国性公共产品和服务归中央，地方性归地方（受益原则）
看配置效率 → 谁配置效率高归谁（效率原则）
看区域特征 → 区域性公共产品和服务按区域划分（区域原则）
看规模与技术 → 规模大小、技术难易程度（技术原则）
```
适用条件：政府间事权及支出责任划分应遵循的原则（多选题 ABCD，不含"均等原则"）。

**机制2：财政收入划分"四原则"与非对称性安排**

```
集权原则 → 收入份额大的主体税种归中央
效率原则 → 流动性强的收入归中央，流动性不强的归地方
恰当原则 → 宏观调控的消费税、体现主权的关税归中央
收益与负担对等原则 → 使用费等直接对应的收入归地方
── 汇总结果 ──→ 收入结构以中央为主、支出结构以地方为主（非对称性安排）
```
适用条件：税种属性是决定政府间财政收入划分的主要标准；"调控功能强、收入份额大、流动性大、收益与负担不直接对应"的收入归中央。

**机制3：转移支付的运行逻辑**

```
地方政府收支缺口 / 地区间财力差距 → 一般性（均衡）转移支付 → 地方统筹安排
中央委托事务、共同事权事务、效益外溢事务、符合中央政策导向事务 → 专项转移支付 → 按规定用途使用
```
适用条件：均衡拨款对应"地方事权范围的支出项目"；专项拨款严格限于上述四类事务。

**机制4：专项转移支付五类的事权归属判别**

```
事权归属判别（按"谁的事权、谁出钱、谁实施"）
  中央事权          → 委托类
  中央与地方共同事权 → 共担类
  地方事权          → 引导类 / 救济类 / 应急类
```
适用条件：自然灾害增支→救济类；影响区域大、影响面广的突发事件→应急类；鼓励引导地方按中央政策意图办事→引导类。

**机制5：财政事权动态调整与省以下划分机制**

```
中央事权：中央出钱（委托地方行使 → 中央专项转移支付安排经费）
地方事权：地方出钱（委托中央行使 → 地方安排经费）
共同事权：区分情况；国民待遇、公民权利、全国统一市场和要素自由流动的事务 → 共同承担或中央为主
省以下：省级管区域稳定、协调发展、基本公共服务均等化；基层管居民生活、社会治安、城乡建设、公共设施管理
```
适用条件：避免将过多的支出责任交给基层政府承担。

## 五、高频考点速记卡

1. **Q：财政管理体制的含义？广义与狭义各指什么？**
   A：国家管理和规范中央与地方政府之间以及地方各级政府之间划分财政收支范围和财政管理职责与权限的一项**根本制度**。广义＝政府预算管理体制＋税收管理体制＋公共部门财务管理体制；狭义＝政府预算管理体制，它是财政管理体制的**中心环节**。

2. **Q：财政管理体制的内容有哪四方面？**
   A：财政分配和管理机构的设置（我国财政管理机构分五级）；政府间事权及支出责任划分；政府间财政收入的划分；政府间财政转移支付制度。

3. **Q：政府间事权及支出责任划分的四原则？**
   A：受益原则、效率原则、区域原则、技术原则（注意不含"均等原则"）。

4. **Q：收入划分的四原则？决定收入划分的主要标准是什么？**
   A：集权原则（主体税种归中央）、效率原则（流动性强归中央）、恰当原则（消费税、关税归中央）、收益与负担对等原则（使用费等归地方）。主要标准是**税种属性**。

5. **Q：政府间财政收支划分的基本特征？**
   A：收入结构与支出结构的**非对称性安排**——收入以中央为主，支出以地方为主。

6. **Q：财政联邦制与财政单一制的区别？**
   A：联邦制遵循"州余权主义"，央地相对独立平等，典型如美国、加拿大、德国、澳大利亚、俄罗斯、墨西哥、印度；单一制由中央统一领导，地方分权水平低、自主性小，典型如英国、法国、日本、韩国、意大利。

7. **Q：我国财政管理体制沿革的关键节点？**
   A：新中国成立以来统收统支；1980—1993 三次改革统称"包干制"；**1994 年**取消包干制、实行分税制。

8. **Q：分税制的内容？**
   A：按事权确定支出范围；按税种划分收入，遵循财权与事权相统一的原则。

9. **Q：共享收入的分享比例？**
   A：增值税中央 50%/地方 50%；企业所得税和个人所得税中央 60%/地方 40%；资源税中海洋石油归中央、其余归地方。

10. **Q：属于中央固定收入的税种？**
    A：关税、海关代征的增值税和消费税、消费税、证券交易印花税、车辆购置税、船舶吨税、出口退税、中央企业所得税等。

11. **Q：属于地方固定收入的税种？**
    A：地方企业上缴利润、城镇土地使用税、土地增值税、城市维护建设税（不含银行保险集中部分）、耕地占用税、国有土地有偿使用收入、房产税、印花税（不含证券交易印花税）、烟叶税、契税、车船税。

12. **Q：不属于地方财政支出的典型是哪项？**
    A：**地质勘探费**（属中央财政支出）；地方支出含地方行政管理费、公检法经费、民兵事业费、城市维护建设费等。

13. **Q：分税制改革的三大成效？**
    A：建立财政收入稳定增长机制；增强中央政府宏观调控能力；促进产业结构调整和资源优化配置。

14. **Q：财政转移支付的含义、目的与最早提出者？**
    A：协调上下级财政之间关系的重要制度；目的是解决地方收支不平衡和地区间公共服务水平不均衡，实现经济社会稳定协调发展；最早由经济学家**庇古**（1928 年）提出。

15. **Q：财政转移支付的五个特点？**
    A：完整性、对称性、科学性、统一性和灵活性相结合、法制性。

16. **Q：一般性转移支付系数的决定因素？我国一般性转移支付包括哪些具体项目？**
    A：系数取决于转移支付资金总量、地方收支缺口、各地财政困难程度等；具体项目有均衡性转移支付、民族地区转移支付、县级基本财力保障机制奖补资金、调整工资转移支付、农村税费改革转移支付、资源枯竭城市转移支付等。

17. **Q：均衡拨款与专项拨款的区别？**
    A：均衡拨款＝地方事权范围的支出项目，通过**一般性**转移支付实施财力匹配与均衡；专项拨款严格限于中央委托事务、共同事权事务、效益外溢事务和符合中央政策导向事务。

18. **Q：专项转移支付五类及其事权归属？**
    A：委托类（中央事权）、共担类（共同事权）、引导类/救济类/应急类（均为地方事权）。

19. **Q：合理划分中央与地方财政事权的总体要求与划分原则？**
    A：总体要求 5 条——坚持社会主义和党的领导、坚持财政事权由中央决定、坚持有利于健全社会主义市场经济体制、坚持法制化规范化道路、坚持积极稳妥统筹推进；划分原则 5 条——体现基本公共服务受益范围、兼顾政府职能和行政效率、实现权责利相统一、激励地方政府主动作为、支出责任和财政事权相适应。

20. **Q："强中央、保地方、减共管"如何理解？委托行使时经费如何安排？省以下如何划分？**
    A：强中央＝国防、外交、国家安全等上划中央；保地方＝社会治安、市政交通、农村公路等区域性信息复杂事务留给地方；减共管＝减少并规范共同财政事权。中央事权委托地方行使，通过**中央专项转移支付**安排经费，且委托事项以委托单位名义行使职权、承担责任。省以下：省级管区域经济社会稳定、协调发展、区域基本公共服务均等化，基层管居民生活、社会治安、城乡建设、公共设施管理，避免把过多支出责任交给基层政府。

## 六、典型真题（含解析）

> 本节收录素材全部真题 **16 道**，其中带年份标签 **11 道**（2022×4、2023×1、2023补×4、2025×2），按年份标注；其余 5 道为素材题库真题（无年份标注）。素材中一道重复题目（2025 专项转移支付地方事权）已去重。

### 第一节 财政管理体制内容与类型

**1.【真题·多选】划分政府间事权和支出责任应遵循的原则有（　）。**
A. 受益原则　B. 效率原则　C. 区域原则　D. 技术原则　E. 均等原则

**答案：ABCD**
**解析**：本题考查财政管理体制的内容。政府间事权及支出责任划分一般遵循的重要原则有受益原则、效率原则、区域原则、技术原则，不含均等原则。

**2.【真题·单选】根据政府间财政收入划分原则，一般应作为地方政府财政收入的是（　）。**
A. 流动性强的税收收入　B. 调控功能比较强的税收收入
C. 收入份额较大的主体税收收入　D. 收益和费用能够直接对应的使用费收入

**答案：D**
**解析**：收入划分原则包括恰当原则、集权原则、效率原则、收益与负担对等原则。调控功能强、收入份额大、流动性大、收益与负担不直接对应的收入归中央政府；收益和负担能够直接对应的收入（如使用费）归地方。

**3.【2022·单选】政府间财政收支划分呈现的基本特征是（　）。**
A. 收入结构与支出结构的非对称性安排
B. 收入结构以地方政府为主，支出结构以中央政府为主
C. 收支结构均以地方政府为主
D. 收支结构均以中央政府为主

**答案：A**
**解析**：根据国际经验，政府间财政收支划分呈现的基本特征是收入结构与支出结构的非对称性安排，即收入结构划分以中央政府为主，支出结构划分则以地方政府为主。B 把主次说反了。

**4.【2023补·多选】政府间财政收入的划分原则包括（　）。**
A. 集权原则　B. 效率原则　C. 恰当原则　D. 收益和负担对等原则　E. 收入结构和支出结构对称原则

**答案：ABCD**
**解析**：本题考查财政管理体制的内容。政府间财政收入的划分遵循 4 个重要原则：集权原则、效率原则、恰当原则、收益和负担对等原则。

**5.【2022·单选】关于财政管理体制的说法，正确的是（　）。**
A. 我国于 1994 年取消包干制，实行了分税制财政管理体制
B. 我国的科技研发和高等教育支出由中央承担了主要责任
C. 根据国际经验，政府间财政收支划分呈现的基本特点是对称性安排
D. 德国实行的财政管理体制属于财政单一制

**答案：A**
**解析**：国务院于 1994 年对中央和地方间财政管理体制进行了新的构建，取消包干制，实行了分税制财政管理体制。B 错——科技研发、高等教育属于中央与地方共同事权（本章第四节"减共管"内容），并非由中央承担主要责任；C 错——基本特点是**非对称性**安排；D 错——德国是财政联邦制模式的典型代表。

**6.【2023补·单选】为了加快建立社会主义市场经济体制，我国从（　）开始实施分税制财政体制。**
A. 1995　B. 1998　C. 1994　D. 1996

**答案：C**
**解析**：从 1994 年开始实施分税制财政体制。

### 第二节 分税制财政管理体制

**7.【2022·多选】下列税种中收入归地方所有的是（　）。**
A. 车辆购置税　B. 船舶吨税　C. 契税　D. 耕地占用税　E. 证券交易印花税

**答案：CD**
**解析**：归入地方财政收入的有：地方企业上缴利润，城镇土地使用税，城市维护建设税（不含各银行总行、各保险公司总公司集中缴纳的部分），房产税，车船税，印花税（不含证券交易印花税），耕地占用税，契税，烟叶税，土地增值税，国有土地有偿使用收入等。A、B、E 为中央财政收入。

**8.【2023补·多选】关于现行中央财政与地方财政收入划分，错误的有（　）。**
A. 契税划入地方财政收入
B. 资源税均为地方财政收入
C. 车辆购置税划入中央财政收入
D. 企业所得税和个人所得税中央分享 50%，地方分享 50%
E. 增值税中央分享 60%，地方分享 40%

**答案：BDE**
**解析**：增值税中央分享 50%、地方分享 50%；纳入共享范围的企业所得税和个人所得税中央分享 60%、地方分享 40%；资源税按不同的资源品种划分，海洋石油资源税为中央收入，其余资源税为地方收入。A、C 表述正确。

**9.【2022·单选】财政支出中，不属于地方财政支出的是（　）。**
A. 地质勘探费　B. 城市维护建设费　C. 民兵事业费　D. 公检法经费

**答案：A**
**解析**：地方财政支出包括：地方行政管理费，公检法经费，民兵事业费，地方统筹安排的基本建设投资，地方企业的技术改造和新产品试制经费，地方安排的农业支出，城市维护建设费，地方文化、教育、卫生等各项事业费以及其他支出。地质勘探费属于中央财政支出（中央财政支出还包括国防、外交支出等）。

### 第三节 财政转移支付制度

**10.【真题·单选】上级政府对下级政府转移支付的财力，与能够满足该级政府承担、履行的事权职责需求相对应，体现了转移支付的（　）特点。**
A. 完整性　B. 法制性　C. 对称性　D. 灵活性

**答案：C**
**解析**：本题考查财政转移支付的特点。对称性，即上级政府对下级政府转移支付的财力，与能够满足该级政府承担、履行的事权职责需求相对应。

**11.【2023补·单选】关于财政转移支付制度说法，正确的是（　）。**
A. 我国专项转移支付重点用于教育、社会保障、支农等公共服务领域
B. 最早提出转移支付概念的学者是李嘉图
C. 对于地方事权范围的支出项目，中央政府通过专项转移支付实施财力匹配与均衡
D. 一般转移支付严格限于中央委托事务、共同事权事务、效益外溢事务和符合中央政策导向事务

**答案：A**
**解析**：通常情况下，对于地方事权范围的支出项目，中央政府通过**一般性转移支付**实施财力匹配与均衡；**专项转移支付**严格限于中央委托事务、共同事权事务、效益外溢事务和符合中央政策导向事务。最早提出转移支付概念的是著名经济学家**庇古**，B 错误。专项转移支付重点用于教育、医疗卫生、社会保障、支农等公共服务领域。

**12.【2023·多选】在我国专项转移支付的使用范围包括（　）。**
A. 中央委托事务　B. 效益外溢事务　C. 地方事权事务
D. 符合中央政策导向事务　E. 共同事权事务

**答案：ABDE**
**解析**：专项转移支付严格限于中央委托事务、共同事权事务、效益外溢事务和符合中央政策导向事务。

**13.【2025·多选】关于财政转移支付制度的说法，错误的有（　）**
A. 一国财政转移支付结构取决于本国特定国情
B. 美国是财政单一制模式的典型代表，无转移支付制度
C. 财政转移支付制度能够增强地方政府提供本地区公共产品和服务的能力
D. 应急类专项转移支付按照事权和支出责任划分属于中央事权
E. 我国一般性转移支付包括均衡性转移支付、民族地区转移支付、县级基本财力保障机制奖补资金等具体项目

**答案：BD**
**解析**：美国是**财政联邦制**模式的典型代表，但美国是少有的没有建立一般性转移支付制度的国家，联邦政府的转移支付全部以专款和分类转移支付方式下达，州政府的资金自主使用权限受到较大限制。日本是财政单一制国家，相对集权，但日本每年的地方交付税（属于均衡拨款）都要高于国库支出金（属于专项拨款）。应急类专项转移支付是指按照事权和支出责任划分属于**地方事权**，中央为帮助地方应对和处理影响区域大、影响面广的突发事件而设立的专项转移支付。

**14.【2025·多选】按事权的支出责任划分，下列专项转移支付中，属于地方事权的是（　）**
A. 委托类转移性支付　B. 引导类转移性支付　C. 救济类转移性支付
D. 共担类转移性支付　E. 应急类转移性支付

**答案：BCE**
**解析**：委托类专项转移支付属于中央事权，共担类属于中央与地方共同事权；引导类、救济类、应急类均属于地方事权。

### 第四节 合理划分中央与地方财政事权和支出责任

**15.【真题·多选】关于财政管理体制说法错误的（　）。**
A. 增加中央与地方共同事权
B. 加快省以下事权和支出责任划分，过多的支出责任交给基层政府承担
C. 逐步将国家安全、国界河湖治理、社会治安、市政交通等确定为中央的财政事权
D. 信息复杂的为中央政府承担
E. 委托事项以委托单位名义行使职权，承担责任

**答案：ABCD**
**解析**：改革方向是**减少并规范**共同财政事权，A 错；应合理安排省以下事权和支出责任划分，**避免**将过多支出责任交给基层政府承担，B 错；社会治安、市政交通属**地方**财政事权，C 错；区域性、信息复杂的事务属**地方**事权，D 错；E 正确——委托事项以委托单位名义行使职权、承担责任。

**16.【真题·多选】关于财政转移支付的说法，正确的有（　）。**
A. 中央出台减收增支政策形成的地方财力缺口，原则上通过专项转移支付调节
B. 属于地方事务且数额相对固定的项目，一般性转移支付
C. 转移支付概念最早是由经济学家庇古在 1928 年提出的
D. 一般性转移支付系数主要取决于转移支付资金总量、各地财政困难程度等因素
E. 中央财政事权如委托地方行使，要通过中央专项转移支付安排相应经费

**答案：BCDE**
**解析**：A 错误——中央出台减收增支政策形成的地方财力缺口，原则上通过**一般性**转移支付调节。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"财政管理体制"等同于"政府预算管理体制" | 广义包含预算、税收、公共部门财务管理三大体制；**狭义**才只是预算管理体制，它是**中心环节** |
| 2 | 事权划分原则漏选或误选"均等原则" | 只有**受益、效率、区域、技术**四个原则；均等原则是干扰项 |
| 3 | 把收入划分四原则与事权划分四原则混记 | 事权看"受效区域技术"；收入看"集权、效率、恰当、收益对等" |
| 4 | 认为收入划分主要标准是"税种性质" | 是**税种属性**（同一税种的不同属性决定归属） |
| 5 | 把非对称性安排说成"对称性安排"或主次说反 | **收入以中央为主、支出以地方为主** |
| 6 | 把美国、德国归入财政单一制 | 美国、德国都是**财政联邦制**；单一制典型是英、法、日、韩、意 |
| 7 | 认为财政单一制下地方毫无分权 | 是分权水平**较低**、自主性**小**，不是零 |
| 8 | 记错我国实行分税制的起始年份 | **1994 年**取消包干制、实行分税制；1980—1993 是"包干制" |
| 9 | 认为分税制只分收入不分支出 | 分税制＝按事权定**支出范围**＋按税种划**收入**，财权与事权相统一 |
| 10 | 记混分享比例：增值税 60/40、所得税 50/50 | 增值税 **50/50**；企业所得税和个人所得税 **60/40**（中央/地方） |
| 11 | 认为资源税全部归地方 | **海洋石油**资源税归中央，其余归地方 |
| 12 | 把证券交易印花税、车辆购置税当地方税 | 二者归**中央**；地方印花税**不含**证券交易印花税 |
| 13 | 忽略城建税的"银行保险集中缴纳部分"归中央 | 城市维护建设税归地方的部分**不含**各银行总行、各保险公司总公司集中缴纳的部分 |
| 14 | 把地质勘探费、民兵事业费归错层级 | **地质勘探费归中央**；民兵事业费归**地方** |
| 15 | 认为地方事权的财力均衡用专项转移支付 | 地方事权范围的支出项目用**一般性（均衡）转移支付**；专项限于委托、共管、外溢、导向四类 |
| 16 | 认为救济类、应急类专项属中央事权 | 五类专项中只有**委托类**属中央事权；引导、救济、应急全归**地方** |
| 17 | 把转移支付概念的提出者记成李嘉图或凯恩斯 | 是**庇古**（1928 年） |
| 18 | 认为中央事权委托地方行使由地方配套经费 | 通过**中央专项转移支付**安排经费；且不得违规要求地方安排配套资金 |
| 19 | 认为委托事项以受托地方名义行使职权 | 以**委托单位**名义行使职权、承担责任 |
| 20 | 认为省以下改革要把更多支出责任压给基层 | 要**避免**将过多支出责任交给基层政府承担 |
