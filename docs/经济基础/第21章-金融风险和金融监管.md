## 二、知识点精讲

### 考点1 金融风险的含义 ★（素材未标星级）

**核心概念**：**投资者和金融机构**在**货币资金的借贷和经营过程**中，由于各种**不确定性**因素影响，使**预期收益和实际收益**发生偏差，从而**发生损失的可能性**。

```
不确定性因素 → 资金借贷和经营过程 → 预期收益≠实际收益 → 发生损失的可能性
```

**两个推论**：① 是损失的**可能性**，未必真实发生；② 市场经济体系中**客观存在、难以完全避免**。

**速记口诀**：**"借贷经营有不定，预期实际两相分"**。

---

### 考点2 金融风险的基本特征 ★★

| 特征 | 要点 |
|---|---|
| **不确定性** | 能否发生、何时发生、损失大小均不确定 |
| **相关性** | 与经营主体、市场环境相关联 |
| **高杠杆性** | 金融企业负债率偏高、财务杠杆大、负外部性大；衍生金融工具以小博大 |
| **传染性** | 风险可跨机构、跨市场传导 |

```
高负债率 → 财务杠杆大 → 负外部性大
衍生工具 → 以小博大   → 高度金融风险 → 跨机构跨市场扩散 → 传染性
```

**我国经济转轨时期金融风险的三个主要特征**（勿与四特征混淆）：① 金融结构失衡与融资形式畸形发展使**风险集中于银行**；② 金融风险与财政风险相互**传感放大**；③ **非正规金融规模庞大**成为安全隐患。

**速记口诀**：**"不定相关高杠杆，一染全传快如梭"**。

---

### 考点3 常见的金融风险的四种类型 ★★★（本章最高频）

| 类型 | 定义（关键词） |
|---|---|
| **市场风险** | **市场因素**（利率、汇率、股价、商品价格等）**波动**导致资产价值变化 |
| **信用风险** | **借款人或市场交易对手违约**导致损失 |
| **流动性风险** | **资产流动性降低**导致 |
| **操作风险** | **交易系统不完善、管理失误或其他人为错误**导致 |

**信用风险的广狭义（高频陷阱）**：

```
广义：交易对方所有背信弃义、违反约定的风险
狭义：货币资金借贷中还款违约的风险 → 最大承受者是商业银行
```

**速记口诀**：**"市价波动信违约，流动变现操人为"**。

> **素材未覆盖提示**：本章素材只讲上述四种。**国家风险、法律风险、合规风险、声誉风险**在本素材中完全未出现，请勿凭记忆补写。

### 考点4 金融危机的含义 ★（素材未标星级）

**核心概念**：一个**国家或几个国家与地区**的**全部或大部分金融指标**的**急剧、短暂和超周期**的恶化。

**四个特点**：**频繁性、广泛性、传染性、严重性**。

| 对象 | 特征 |
|---|---|
| 金融风险 | 不确定性、相关性、高杠杆性、传染性 |
| 金融危机 | 频繁性、广泛性、传染性、严重性 |

> 二者只有"传染性"重合；**"频繁性"属于危机、不属于风险**，是经典陷阱。

**速记口诀**：**"危机指标骤短超，频广传严四特征"**。

---

### 考点5 金融危机的类型 ★★★

| 类型 | 别称/判别词 | 核心内容 |
|---|---|---|
| **①债务危机** | **支付能力危机** | 一国债务不合理、无法按期偿还；一般发生在**发展中国家** |
| **②货币危机** | 钉住汇率安排 | **货币大幅贬值**；货币内外价值脱节，通常反映为**本币汇率高估** |
| **③流动性危机** | 流动性不足 | 分**国内**与**国际**流动性危机两个层面 |
| **④综合性金融危机** | 几种危机结合 | **现实中的金融危机都是综合性金融危机**；分外部、内部 |

**债务危机发生国的三大特征**：① 出口不断萎缩，外汇主要来源于**举借外债**；② 国际债务条件对债务国**不利**；③ 缺乏外债管理经验，外债投资效益不高、创汇能力低。

**流动性危机分层处置**：

```
国内流动性不足 → 央行发挥最后贷款人作用 → 避免"挤兑"引发大范围银行危机
国际流动性不足 → IMF等国际组织及时采取措施
```

**两个经典案例（对比记忆）**：

| 案例 | 诱因 | 结论 |
|---|---|---|
| **1997年亚洲金融危机** | 危机前**财政赤字和宏观经济状况良好**，均不能解释危机；是**市场信心的变化导致危机的自我实现**。一方面制度性道德风险积累超市场承受程度→不良资产只能靠财政注资→**隐性财政赤字**；另一方面**银行体系流动性不足**→恐慌性资金冲击 | 属**货币危机**；诱因**不是**财政赤字和高失业率 |
| **1992年英镑危机** | 英国**没有财政赤字货币化历史**，筹集外汇也不是问题，但**政府偏好具有决定意义**：市场强烈贬值预期下，国内**高失业率**使维持钉住汇率**成本远大于收益**，政府放弃钉住汇率制 | 原因是**高失业率**；不是信用扩张快、赤字规模大、债务结构不合理 |

**速记口诀**：**"债难偿还货贬值，流动不足综相加"**。

### 考点6 次贷危机 ★（素材未标星级）

**定义**：发生在美国，因**次级抵押贷款机构破产、投资基金被迫关闭、股市剧烈震荡**引起的金融风暴。

```
第一阶段：债务危机 → 第二阶段：流动性危机 → 第三阶段：信用危机
   → 投资者对建立在信用基础上的金融活动产生怀疑 → 全球金融恐慌
```

**速记口诀**：**"债→流动→信用，一路恐慌到全球"**。

---

### 考点7 金融监管的含义 ★（素材未标星级）

**核心概念**：一国的**金融管理部门**为达到**稳定货币、维护金融业正常秩序**等目的，依法对金融机构及其经营活动实施**外部监督、稽核、检查**和对其违法违规行为进行**处罚**等一系列行为。

**监管首先从银行开始——银行三大特性**：

| 特性 | 含义 |
|---|---|
| **期限转换功能** | 储蓄—投资转化中，为储蓄者提供短期资产和流动性，集合储蓄再按投资者需要提供期限较长的负债和资金 |
| **支付体系的重要组成部分** | 作为票据清算者，降低交易费用 |
| **信用创造和流动性创造功能** | 银行能创造信用与流动性 |

```
先监管银行（三大特性使维持银行业稳定成为必要）
   → 非银行金融机构面临的问题有共性 → 扩展到整个金融业
```

**速记口诀**：**"转期限、清票据、创信用"**。

### 考点8 金融监管的一般性理论 ★★

| 理论 | 核心观点 | 实践形式/关键词 |
|---|---|---|
| **①公共利益论** | 源于**20世纪30年代美国经济危机**，直到20世纪60年代都是被接受的正统理论；监管是政府对公众要求纠正某些社会个体和社会组织**不公平、不公正、无效率或低效率**的回应 | 30年代危机 |
| **②保护债权论** | 为保护**债权人**利益需要监管；债权人＝**存款人、证券持有人、投保人** | **存款保险制度** |
| **③金融风险控制论** | 源于**"金融不稳定假说"**：银行利润最大化目标促使其增加有风险活动→系统内不稳定；来源于**高负债经营、借短放长、部分准备金制度** | 三大不稳定来源 |
| **④金融全球化对传统金融监管理论的挑战** | 全球化挑战传统理论 | — |

```
利润最大化目标 → 系统内增加有风险活动 → 不稳定
   来源于：①高负债经营 ②借短放长 ③部分准备金制度
```

**速记口诀**：**"公益源自三十年代，债权保的是存款户，风险控制三来源：高负债、短放长、部分准备金"**。

### 考点9 金融监管体制的含义与分类 ★（素材未标星级）

**核心概念**：一国**金融管理部门的构成及其分工**的有关安排。

**（1）按监管主体及中央银行角色**：以中央银行为重心的监管体制（**美国、法国、印度、巴西**）｜独立于中央银行的综合监管体制（**德国、英国、日本、韩国**）。

**（2）按监管客体**：统一（综合）监管体制（**英国、瑞士、日本、韩国**）｜分业监管体制（**大多数发展中国家**）。

**美国模式：双线多头**。双线＝联邦与州两级监管机构；多头＝联邦一级多个分工协作机构。

| 机构 | 监管对象 |
|---|---|
| 美联储 | 在各州注册的联储会员银行 |
| 联邦存款保险公司 | 所有在州注册的非联储会员银行 |
| 货币监理署 | 在联邦注册的国民银行和外国银行分支机构 |
| 储贷监理署 | 参加联邦保险的储贷协会和互助储蓄银行 |
| 国家信用社管理局 | 所有参加联邦保险的信用社 |
| 各州金融监管当局 | 在本州注册的银行（尤其是非联储会员银行） |

> 几乎所有州立银行都参加联邦存款保险→同时接受其监管→处于**联邦和州两级双重监管**。

**德国模式：独立于中央银行的综合监管体制（典型）**：

| 要点 | 内容 |
|---|---|
| 联邦银行监督局 | 1961年《银行法》授权成立，**隶属财政部**，在银行监管中发挥**中心作用**；负责**制定和颁布监管规章制度** |
| 综合性 | 德国银行可同时经营证券和保险业务→银行监督局是**综合性金融监管机构** |
| 德意志联邦银行 | 作用独特：监督局**缺乏分支机构、没有统计职能**，须借助其网点→被要求参与监管；负责**分析金融机构各种报告、进行日常监管** |
| 两者关系 | 功能密不可分，**各有侧重点、彼此制约**；央行并未失去独立制定货币政策职能 |

**1999年美国《金融服务现代化法案》**：以**金融控股公司**形式确立美国金融混业经营制度框架，同时赋予**美联储对金融控股公司的监管权力**。

**速记口诀**：**"主体角色美法印巴、德英日韩；监管客体英国综合、发展中国家分业；美国双线多头、德国央行独特"**。

### 考点10 我国金融监管体制演变 ★★★

**演变主线**：自20世纪80年代由 **单一全能型 → 分业监管体制 → 综合监管型**。

**2023年《党和国家机构改革方案》**（党的二十届二中全会审议通过，十四届全国人大一次会议第三次全体会议表决通过）六项金融内容：

```
① 在银保监会基础上组建国家金融监督管理总局，强化机构监管、行为监管、
   功能监管、穿透式监管、持续监管
② 建立以中央金融管理部门地方派出机构为主的地方金融监管体制，
   压实地方金融监管主体责任
③ 将中国证券监督管理委员会调整为国务院直属机构
④ 统筹推进中国人民银行分支机构改革
⑤ 完善国有金融资本管理体制
⑥ 加强金融管理部门工作人员统一规范管理
```

**现代金融监管的基本内涵（六个）**：宏观审慎管理、微观审慎监管、保护消费权益、打击金融犯罪、维护市场稳定和处置问题机构。

**现阶段六大挑战**：① 世界经济复苏分化加剧、增长动力不足；② 高速增长向高质量发展转变阶段，金融与实体经济适配性不足、资金循环不畅和供求脱节相互影响；③ 现代科技广泛应用使金融业态、风险形态、传导路径和安全边界重大变化；④ 金融机构公司治理与高质量发展要求仍有差距；⑤ 专业化处置机构和常态化风险处置机制不健全；⑥ 金融生态、法制环境和信用体系建设任重道远。

**加强和完善现代金融监管八个着力点**：① 强化党对金融工作的集中统一领导；② 深化金融供给侧结构性改革；③ 健全"风险为本"的审慎监管框架；④ 加强金融机构公司治理和内部控制；⑤ 营造严厉打击金融犯罪的法治环境；⑥ 切实维护金融消费者合法权益；⑦ 完善金融安全网和风险处置长效机制；⑧ 加快金融监管数字化智能化转型。

**速记口诀**：**"单一全能→分业→综合；2023组建金监总局，五个监管全强化"**。

### 考点11 近年来我国对重点领域的监管进展 ★（素材未标星级）

**（1）影子银行**

**定义**：**常规银行体系以外**的各种金融中介业务，通常以**非银行金融机构**为载体，对金融资产的信用、流动性和期限等风险因素进行转换，扮演**"类银行"**角色。

**五个特点**：① 以银行为核心，表现为"**银行的影子**"；② 以**监管套利**为主要目的，违法违规较普遍；③ 存在**刚性兑付**或刚性兑付预期；④ 收取**通道费用**的盈利模式普遍；⑤ 以**类贷款**为主，信用风险突出。

**治理时间线**：2017年2月中央财经领导小组第十五次会议（坚决治理市场乱象）→ 2017年起银保监会开展**"三违反""三套利""四不当""十乱象"**专项整治，推动"类信贷"表外业务**回表** → 2018年4月27日人民银行等发布**《关于规范金融机构资产管理业务的指导意见》**（明确资管业务属性、统一产品标准、减少跨机构跨市场套利）→ 野蛮生长得到**根本遏制**。

**（2）地方金融组织**

**范围**（多选高频）：**小额贷款公司、融资担保公司、区域性股权市场、典当行、融资租赁公司、商业保理公司、地方资产管理公司**＋法律行政法规和国务院授权省级人民政府监管的其他机构。**村镇银行不属于**（真题已排除）。

**时间线**：2017年以来各省区市成立**地方金融监督管理局** → 2021年4月国务院金融稳定发展委员会办公室印发**《地方金融组织统计制度（试行）》** → 2021年12月人民银行发布**《地方金融监督管理条例》（草案征求意见稿）**，提供上位法依据。

**（3）金融控股公司**

**定义**：对**两个或两个以上不同类型金融机构拥有实质控制权**，自身**仅开展股权投资管理、不直接从事商业性经营活动**的有限责任公司或股份有限公司。

**时间线**：2020年9月国务院发布**《关于实施金融控股公司准入管理的决定》**；同月人民银行会同相关部门印发**《金融控股公司监督管理试行办法》**。

**速记口诀**：**"影子银行五个点，地方金融七类加兜底，金控公司只持股不经营"**。

### 考点12 建立维护金融稳定长效机制 ★（素材未标星级）

**（1）完善机构设置**

```
2017年全国金融工作会议 → 设立国务院金融稳定发展委员会（金融委）
   ├─ 强化人民银行宏观审慎管理和系统性风险防范职责
   ├─ 强化金融监管部门监管职责
   └─ 地方：金融委办公室地方协调机制 + 金融稳定发展领导小组
                    ↓
2023年《党和国家机构改革方案》：
   ├─ 组建中央金融委员会（党中央决策议事协调机构）：顶层设计、统筹协调、
   │   整体推进、督促落实 → 不再保留金融委及办事机构，其办公室职责划入
   │   中央金融委员会办公室
   └─ 组建中央金融工作委员会（党中央派出机关，与中央金融委员会办公室合署办公）
```

**（2）推进金融稳定立法——《中华人民共和国金融稳定法（草案）》**

压实**三类责任**：**金融机构及其主要股东、实际控制人的主体责任**；**地方政府的属地责任**；**金融监管部门的监管责任**。
机制要点：风险**早发现、早干预**；建立**市场化、法治化处置机制**，明确处置资金来源和使用安排、完善处置措施工具、保护市场主体合法权益；强化违法违规责任追究，守住不发生系统性金融风险底线。

**（3）强大的金融监管**：强化金融稳定保障体系；全面强化**机构监管、行为监管、功能监管、穿透式监管、持续监管**，消除监管空白和盲区；加快建设统筹协调、有力有效的现代金融监管框架；加快法律法规建设、补足监管法律短板；坚持**宏观审慎管理和微观行为监管协调配合**；统筹金融管理资源，加强基层监管力量，强化地方监管责任。

**速记口诀**：**"三责任：机构股东、地方政府、监管部门；两新机构：中央金融委员会＋中央金融工作委员会"**。

### 考点13 完善宏观审慎管理体系 ★（26新增）

**核心定位**：加强宏观审慎管理，防范金融风险的**顺周期积累**以及**跨机构、跨市场、跨部门和跨境传染**，是国际金融监管改革的核心内容。宏观审慎管理**直接和集中作用于金融体系本身**，聚焦具有**系统性特征**的风险，维护金融体系整体稳定、阻断或弱化顺周期自我强化。

**两个维度（必考对应）**：

| 维度 | 措施 | 目标 |
|---|---|---|
| **跨时间维度** | 对**资本水平、杠杆率**提出**动态逆周期要求** | 抑制**顺周期性** |
| **跨空间维度** | 加强**系统重要性金融机构监管**和**金融市场宏观审慎管理** | 防控风险跨机构、跨市场、跨部门、跨境传染 |

**八个方面**：

```
① 2021年人民银行《宏观审慎政策指引（试行）》→ 明确管理思路和政策框架
② 2016年将差别存款准备金动态调整和合意贷款管理机制升级为宏观审慎评估（MPA）
③ 建立健全系统重要性金融机构监管总体框架 → 截至2025年年底：5家全球系统重要性
   银行；21家国内系统重要性银行，资产合计约占银行业总资产7成
④ 设立跨境融资宏观审慎调节参数等工具，对跨境资本流动逆周期调节
⑤ 探索金融市场宏观审慎管理，动态观察评估债券市场运行，加强风险提示
   → 2024年创设支持资本市场稳定发展的两项货币政策工具
⑥ 完善房地产金融宏观审慎管理，动态调整房贷首付比、房贷利率等工具
⑦ 搭建金融控股公司监管框架，依法开展准入和监管
⑧ 加强市场预期管理
```

**速记口诀**：**"时间看资本杠杆，空间看系统重要；5家全球21家国内占七成"**。

### 考点14 巴塞尔协议产生的背景与发展 ★（素材未标星级）

| 原因 | 内容 |
|---|---|
| **直接原因** | **国际性银行倒闭事件和国际贷款违约事件**使监管当局全面审视拥有广泛国际业务的银行监管问题 |
| **主要原因** | 随**金融国际化**必须在金融监管上进行**国际协调**；1975年2月由**国际清算银行发起**，西方十国集团以及瑞士、卢森堡等**12国中央银行**成立**巴塞尔银行监管委员会** |

**影响最大的三个协议**：1988年巴塞尔报告、2003年新巴塞尔资本协议、2010年巴塞尔协议Ⅲ。

```
国际性银行倒闭 + 国际贷款违约（直接） + 金融国际化要求监管协调（主要）
        ↓ 1975年2月 国际清算银行发起，12国央行 → 巴塞尔委员会
        ↓ 1988报告 → 2003新协议 → 2010巴Ⅲ
```

**避坑**：巴塞尔委员会由**国际清算银行发起**，不是西方十国集团发起。

**速记口诀**：**"倒闭违约是直接，金融国际化是主因；1975清算银行发起十二国"**。

### 考点15 1988年巴塞尔报告 ★★★

**全称**《关于统一国际银行资本衡量和资本标准的报告》（1988年7月），**主要内容就是确认了监督银行资本的可行统一标准**。

**（1）资本组成**：

| 层级 | 别称 | 内容 | 占比 |
|---|---|---|---|
| **核心资本** | **一级资本** | **实收股本（普通股）和公开储备** | 至少占全部资本 **50%** |
| **附属资本** | **二级资本** | **未公开储备、资产重估储备、普通准备金和呆账准备金、混合资本工具、长期次级债券** | — |

> 只有两层，**不存在"超额资本"**（真题陷阱）。

**（2）风险资产权重**：按资产和表外业务的相对风险大小赋予 **0%、10%、20%、50%、100%** 五档，权重越大风险越大。表外业务按**信用换算系数**折算成表内业务，再按同样权重计算。

**（3）资本标准**：到 **1992年底**，签约国国际业务银行**资本充足率（资本÷风险加权资产）不得低于8%**，**核心资本比率不得低于4%**。

**（4）过渡期安排**：**1987年年底～1992年年底**。

```
1988年巴塞尔报告
 ├─ 核心资本（一级：实收股本+公开储备，≥50%）/ 附属资本（二级）
 ├─ 风险权重五档：0/10/20/50/100%
 ├─ 表外业务：×信用换算系数 → 折成表内 → 再按同样权重
 ├─ 资本标准：资本充足率≥8%，核心资本比率≥4%（1992年底前）
 └─ 过渡期：1987年底~1992年底
```

**速记口诀**：**"核心一半股本加公开，权重五档零十二十五十百，八字四率"**。

### 考点16 2003年新巴塞尔资本协议 ★★★

| 支柱 | 内容 |
|---|---|
| **①最低资本要求** | 继承以**资本充足率**为核心的监管思想，将资本金要求视为**最重要的支柱**；风险防范拓展到**信用风险、操作风险、市场风险**；**计量方法改进**；**鼓励使用内部模型**；**资本约束范围扩大** |
| **②监管当局监督检查** | **全面监管银行资本充足情况**，培育银行内部信用评估系统，加快制度化建设 |
| **③市场约束** | 富有成效的**奖惩机制**；建立**信息披露制度（一年至少披露一次财务状况）** |

```
最低资本要求（最重要）→ 风险三类：信用+操作+市场，鼓励内部模型
监管当局监督检查       → 全面监管资本充足，培育内部信用评估系统
市场约束              → 奖惩机制 + 信息披露（一年至少一次）
```

**速记口诀**：**"资本要求、监督检查、市场约束三支柱；风险三类信用操作加市场"**。

### 考点17 2010年巴塞尔协议Ⅲ ★★★

**总体要求**：体现**微观审慎与宏观审慎有机结合**；**资本监管和流动性监管并重、资本数量和质量同步提高、资本充足率与杠杆率并行、长期影响与短期效应统筹兼顾**。

**（1）强化资本充足率监管标准**（资本监管是本轮改革核心）：

| 指标 | 最低要求 |
|---|---|
| 普通股充足率 | **4.5%** |
| 一级资本充足率 | **6%** |
| 总资本充足率 | **8%** |
| **留存超额资本**（普通股构成） | **2.5%** |
| **反周期超额资本**（与信贷过快增长挂钩） | **0～2.5%** |

> 新标准实施后正常情况下，商业银行三档资本充足率应分别达到 **7%、8.5%、10.5%**。

**（2）引入杠杆率监管标准**：自 **2011年初**按 **3%**（**一级资本÷总资产**）监管，**2013年初**进入过渡期，**2018年**正式纳入第一支柱。

**（3）建立流动性风险量化监管标准**：引入**流动性覆盖率**和**净稳定融资比率**两个指标。

**（4）过渡期**：为期 **8年（2011～2018）**。

```
2010年巴Ⅲ
 ├─ 资本：普通股4.5%/一级6%/总资本8% + 留存2.5% + 反周期0~2.5%
 │    → 正常合计 7%/8.5%/10.5%
 ├─ 杠杆率：一级资本/总资产 = 3%（2011年起，2018年纳入第一支柱）
 ├─ 流动性：流动性覆盖率 + 净稳定融资比率
 └─ 过渡期：8年（2011~2018）
```

**最终方案**：初步框架暴露第一支柱计量标准不统一、内部模型套利致资本充足水平降低，第二支柱监管难度大，第三支柱信息披露不透明等问题。最终以**"简单性、可比性和风险敏感度"平衡**为目标修订风险资产计量方法：重新划分**资产类别**、嵌入**风险驱动因子**、细化**风险权重**；**规范内部模型使用**；调整**内评法资本计量底线**；对**全球系统重要性银行提出最低杠杆率附加要求**。

**速记口诀**：**"四五、六八、两五附加；杠杆率三成；流动两覆盖；过渡整八年"**。

### 考点18 巴塞尔协议在我国的实施 ★★★

```
2011年 → 开始借鉴巴Ⅲ
2011年4月 → 《中国银行业实施新监管标准的指导意见》
2023年2月 → 银保监会会同人民银行修订《商业银行资本管理办法（试行）》
             → 《商业银行资本管理办法（征求意见稿）》
```

**五项重点修订**：① 构建**差异化**资本监管体系；② **全面修订风险加权资产计量规则**；③ 要求银行制定有效政策、流程、制度和措施，**确保风险权重的适用性和审慎性**；④ **强化监督检查**，优化压力测试应用；⑤ 提高**信息披露**标准。

**《商业银行金融资产风险分类办法》**：遵循**真实性、及时性、审慎性、独立性**四原则（口诀**"审时独立"**）；对**承担信用风险的全部表内外金融资产**开展风险分类；**拓展风险分类的资产范围**，提出新风险分类定义，强调以**债务人履约能力为中心**的分类理念；对加强风险分类提出**系统化要求**并明确监管措施。

**速记口诀**：**"差异计量审慎监督披露；分类四原则审时独立"**。

## 四、公式与计算（本章计算题重点）

> **素材覆盖说明**：本章素材可提炼出公式的只有**资本充足率、核心一级（素材称"普通股"）充足率、一级资本充足率、杠杆率、风险加权资产**五项；**流动性覆盖率（LCR）**与**净稳定资金比例（NSFR）**素材**仅点名指标、未给公式**，已标注「素材未覆盖」，不作记忆补写。

### 公式1 资本充足率（1988年巴塞尔报告核心指标）

```
资本充足率   = 资本 ÷ 风险加权资产 × 100%       ≥ 8%
核心资本比率 = 核心资本 ÷ 风险加权资产 × 100%   ≥ 4%
```

**例题**：某国际业务签约行年末资本总额400亿元，风险加权资产5000亿元，其中核心资本160亿元。

- 资本充足率 ＝ 400 ÷ 5000 × 100% ＝ **8%** → 达到"不得低于8%"下限；
- 核心资本比率 ＝ 160 ÷ 5000 × 100% ＝ **3.2%** → **低于4%，不达标**。

**结论**：两个比率必须**同时满足**，仅资本充足率压线不够。

### 公式2 核心一级资本（素材表述为"普通股"）充足率 / 一级资本充足率

> 素材未使用"核心一级资本充足率"一词，对应指标为**普通股充足率4.5%**与**一级资本充足率6%**。

```
普通股充足率   = 普通股 ÷ 风险加权资产 × 100%    ≥ 4.5%
一级资本充足率 = 一级资本 ÷ 风险加权资产 × 100%  ≥ 6%
总资本充足率   = 总资本 ÷ 风险加权资产 × 100%    ≥ 8%
考虑超额资本后（正常情况）应分别达到 7% / 8.5% / 10.5%
```

**例题**：某商业银行普通股300亿元、一级资本360亿元、总资本400亿元，风险加权资产5000亿元。

| 指标 | 计算 | 最低标准 | 含超额资本要求 | 是否达标 |
|---|---|---|---|---|
| 普通股充足率 | 300÷5000＝6% | 4.5% | **7%** | 最低达标，**含超额资本不达标**（差350−300＝50亿元） |
| 一级资本充足率 | 360÷5000＝7.2% | 6% | **8.5%** | 最低达标，**含超额资本不达标**（差425−360＝65亿元） |
| 总资本充足率 | 400÷5000＝8% | 8% | **10.5%** | 最低达标，**含超额资本不达标**（差525−400＝125亿元） |

**结论**：留存超额资本2.5%由普通股构成，是额外要求；总资本充足率要从8%提到10.5%。

### 公式3 杠杆率

```
杠杆率 = 一级资本 ÷ 总资产 × 100%   ≥ 3%（2011年初起按此标准监管）
（分母为未经风险加权的总资产）
```

**例题**：某银行一级资本425亿元，表内总资产10000亿元。

- 杠杆率 ＝ 425 ÷ 10000 × 100% ＝ **4.25%** → 高于3%，达标；
- 若总资产扩至15000亿元而一级资本不变：425 ÷ 15000 × 100% ＝ **2.83%** → **低于3%，不达标**。

**结论**：杠杆率**不经风险权重调整**，用来约束"风险权重低但规模巨大"的扩张。

### 公式4 风险加权资产（RWA）

```
风险加权资产 = Σ（每笔资产金额 × 对应风险权重）
风险权重五档：0% / 10% / 20% / 50% / 100%
表外业务：先按"信用换算系数"折算成表内业务，再按同样风险权重计算
```

**例题**：某银行表内资产如下，计算风险加权资产。

| 资产 | 金额（亿元） | 适用权重* |
|---|---|---|
| 资产A | 1000 | 0% |
| 资产B | 2000 | 20% |
| 资产C | 5000 | 100% |
| 资产D | 1000 | 50% |

风险加权资产 ＝ 1000×0% ＋ 2000×20% ＋ 5000×100% ＋ 1000×50% ＝ 0＋400＋5000＋500 ＝ **5900（亿元）**
若该行资本472亿元，则资本充足率 ＝ 472 ÷ 5900 × 100% ＝ **8%**，恰好达标。

> \* **素材提示**：素材只给出**五档权重值**，**未给出"哪类资产对应哪档权重"的对照表**，上表档位仅为演算演示；表外业务的**信用换算系数具体数值素材亦未给出**，只给出计量路径。

### 公式5 流动性覆盖率（LCR）——素材未覆盖

- 素材覆盖情况：**仅作为2010年巴Ⅲ引入的两个流动性风险量化监管指标之一被点名**（与净稳定融资比率并列），**未给出计算公式与监管下限数值**。
- 结论：**素材未覆盖，无法演算。请勿凭记忆补写公式与数值。**

- 素材覆盖情况：**仅被点名**为流动性风险量化监管指标之一（真题选项作"净稳定融资比率"），**未给出计算公式与数值**。
- 结论：**素材未覆盖，无法演算。请勿凭记忆补写。**

## 五、高频考点速记卡

1. **Q：金融风险的定义？**
   A：投资者和金融机构在货币资金借贷和经营过程中，由于不确定性因素使预期收益和实际收益发生偏差，从而发生损失的可能性。

2. **Q：金融风险四个基本特征？**
   A：**不确定性、相关性、高杠杆性、传染性**（"频繁性、市场性、独立性"均为干扰项）。

3. **Q：四种常见金融风险及成因？**
   A：市场风险（利率汇率股价商品价格波动）／信用风险（借款人或交易对手违约）／流动性风险（资产流动性降低）／操作风险（交易系统不完善、管理失误、人为错误）。

4. **Q：广义与狭义信用风险的区别？**
   A：广义＝交易对方**所有背信弃义、违反约定**；狭义＝借贷中还款违约，**最大承受者是商业银行**。

5. **Q：金融危机四特点与四类型？**
   A：特点＝频繁性、广泛性、传染性、严重性；类型＝债务危机（支付能力危机）、货币危机、流动性危机、综合性金融危机（**现实中都是综合性**）。

6. **Q：货币危机最容易在什么国家发生？**
   A：实行固定汇率制或带有固定汇率制色彩的**钉住汇率安排**的国家，通常反映为**本币汇率高估**。

7. **Q：债务危机发生国的三个特征？**
   A：出口萎缩、外汇主要靠举借外债；国际债务条件不利；缺乏外债管理经验、投资效益不高、创汇能力低。

8. **Q：流动性危机分几个层面？谁兜底？**
   A：国内——央行发挥**最后贷款人**作用；国际——**IMF**等国际组织及时采取措施。美国次贷危机三阶段＝债务→流动性→信用（**不含货币危机**）。

9. **Q：金融监管为什么首先从银行开始？**
   A：银行三大特性——**期限转换功能、支付体系的重要组成部分、信用创造和流动性创造功能**。

10. **Q：金融监管一般性理论有哪几个？**
    A：公共利益论（源于20世纪30年代美国经济危机）／保护债权论（债权人＝存款人、证券持有人、投保人，实践形式＝**存款保险制度**）／金融风险控制论（源于**金融不稳定假说**）／金融全球化对传统理论的挑战。

11. **Q：金融不稳定假说的三大不稳定来源？**
    A：**高负债经营、借短放长、部分准备金制度**（注意是"借**短**放长"）。

12. **Q：金融监管体制的两种分类标准及结果？**
    A：按主体与央行角色——以中央银行为重心（美法印巴）／独立于央行的综合监管（德英日韩）；按监管客体——统一（综合）监管（英瑞日韩）／分业监管（大多数发展中国家）。

13. **Q：美国监管体制的特点？**
    A：**双线多头**。双线＝联邦+州两级；多头＝联邦级多机构（美联储、联邦存款保险公司、货币监理署、储贷监理署、国家信用社管理局）。1999年《金融服务现代化法案》以**金融控股公司**确立混业框架，并赋予美联储对金融控股公司的监管权。

14. **Q：德国监管体制的特点？**
    A：**联邦银行监督局**（隶属财政部）制定颁布规章；**德意志联邦银行**分析报告、日常监管（局无分支机构、无统计职能）；德国银行可兼营证券保险→综合性监管机构。

15. **Q：2023年《党和国家机构改革方案》中地方金融监管体制怎么建？**
    A：建立以**中央金融管理部门地方派出机构为主**的地方金融监管体制，压实地方主体责任；同时组建**国家金融监督管理总局**，证监会调整为**国务院直属机构**。

16. **Q：我国影子银行五特点？地方金融组织范围？**
    A：影子银行——银行的影子、监管套利、刚性兑付、通道费、类贷款信用风险突出；地方金融组织——小贷公司、融资担保公司、区域性股权市场、典当行、融资租赁公司、商业保理公司、地方资产管理公司＋兜底（**不含村镇银行**）。

17. **Q：金融控股公司定义要点？**
    A：对**两个或两个以上不同类型金融机构拥有实质控制权**，自身**仅开展股权投资管理、不直接从事商业性经营活动**。2020年9月《关于实施金融控股公司准入管理的决定》＋《金融控股公司监督管理试行办法》。

18. **Q：金融稳定法草案要压实哪三类责任？**
    A：**金融机构及其主要股东、实际控制人的主体责任**；**地方政府的属地责任**；**金融监管部门的监管责任**。

19. **Q：宏观审慎管理两个维度？我国系统重要性机构数量？**
    A：跨时间——**资本水平、杠杆率**动态逆周期要求；跨空间——**系统重要性金融机构监管和金融市场宏观审慎管理**。截至2025年年底：**5家全球系统重要性银行、21家国内系统重要性银行**（资产约占银行业总资产**7成**）。

20. **Q：1988年巴塞尔报告核心内容？2003年三大支柱？2010年巴Ⅲ标准？**
    A：1988——核心资本（一级：实收股本＋公开储备，≥全部资本50%）和附属资本（二级）；权重五档**0/10/20/50/100%**；资本充足率≥**8%**、核心资本比率≥**4%**；过渡期1987年底~1992年底。2003——最低资本要求（最重要，风险拓展到信用/操作/市场，鼓励内部模型）＋监管当局监督检查＋市场约束（信息披露一年至少一次）。2010——普通股4.5%／一级6%／总资本8%；留存2.5%；反周期0~2.5%；正常合计**7%/8.5%/10.5%**；杠杆率＝**一级资本÷总资产≥3%**；流动性指标＝**流动性覆盖率＋净稳定融资比率**（公式素材未覆盖）。

**【多选】2010年巴塞尔协议Ⅲ对银行监管国际规则进行改革，内容包括（　）。**
A. 要求银行建立反周期超额资本　B. 引入杠杆率监管标准　C. 确立了最低资本要求、监管当局的监督检查和市场约束等"三大支柱"　D. 要求银行建立留存超额资本　E. 引入流动性覆盖率监管标准
**答案：ABDE**　**解析**：改革内容为（1）强化资本充足率监管标准；（2）引入杠杆率监管标准；（3）建立流动性风险量化监管标准；（4）确定过渡期。**"三大支柱"是2003年新巴塞尔资本协议确立的**，故C不选。

**【多选】关于1988年巴塞尔报告的说法，错误的有（　）。**
A. 普通股至少占全部资本的50%　B. 确认了监督银行资本的可行的统一标准　C. 表外业务计算风险加权资产要按照信用换算系数进行　D. 银行资本分为核心资本、附属资本和超额资本　E. 二级资本包括公开储备、普通准备金和呆账准备金
**答案：ADE**　**解析**：银行资本分为**核心资本和附属资本**（D错）。核心资本（一级）包括**实收股本（普通股）和公开储备**，这部分资本至少占全部资本的50%（A错——应为"核心资本至少占50%"）。附属资本（二级）包括未公开储备、资产重估储备、普通准备金和呆账准备金、混合资本工具和长期次级债券（E错——"公开储备"属核心资本）。C正确：表外业务按信用换算系数折算成表内，再按同样权重计算。B正确。

**【单选】美国次贷危机后，巴塞尔委员会要求银行建立留存超额资本，用于吸收严重经济和金融衰退给银行体系带来的损失，最低要求为（　）。**
A. 3%　B. 2.5%　C. 0%　D. 4.5%
**答案：B**　**解析**：留存超额资本**由普通股构成，最低要求为2.5%**。

**【单选】2010年巴塞尔协议Ⅲ建立了商业银行流动性风险量化监管标准，主要监管指标有（　）。**
A. 资本充足率　B. 反周期超额资本　C. 净稳定融资比率　D. 流动性覆盖率　E. 杠杆率
**答案：CD**　**解析**：两个流动性量化指标是**流动性覆盖率**和**净稳定融资比率**。资本充足率、杠杆率属资本监管标准，反周期超额资本属超额资本要求。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"频繁性"当成金融风险的特征 | 风险四特征＝**不确定性、相关性、高杠杆性、传染性**；**频繁性是金融危机的特点** |
| 2 | 把"市场性、外溢风险、消费风险"选进金融风险类型 | 常见金融风险只有四种：**市场、信用、流动性、操作** |
| 3 | 把"名义收益率与实际收益率偏离"当风险表现 | 是**预期收益和实际收益**发生偏差；且风险只是**损失的可能性**，未必真实发生 |
| 4 | 把流动性风险与流动性危机混为一谈 | 流动性风险是风险类型；流动性危机是危机类型，分**国内/国际**两个层面 |
| 5 | 认为货币危机源于债务不合理、缺乏外债管理经验 | 货币危机＝**钉住汇率安排**；债务不合理、缺乏外债管理经验是**债务危机**发生国特征 |
| 6 | 认为亚洲金融危机由财政赤字和高失业率导致 | 危机前财政与宏观经济**良好**；诱因是**市场信心的自我实现**＋制度性道德风险＋银行流动性不足 |
| 7 | 认为英镑危机源于财政赤字货币化或债务结构 | 英国**没有**赤字货币化历史；原因是**高失业率**使维持钉住汇率成本大于收益，政府主动放弃 |
| 8 | 把次贷危机第三阶段记成货币危机 | 三阶段＝**债务→流动性→信用**，全程无货币危机 |
| 9 | 把"银行出现时间最早"当作监管起点原因 | 三大特性是**期限转换、支付体系、信用与流动性创造**；且监管后扩展到**整个金融业** |
| 10 | 把"贷款人、抵押人、担保人"当成保护债权论的债权人 | 债权人＝**存款人、证券持有人、投保人**；实践形式是**存款保险制度** |
| 11 | 漏选金融不稳定假说的来源／把"借长放短"当选对 | 三个来源：**高负债经营、借短放长、部分准备金制度** |
| 12 | 把统一（综合）监管体制的代表记成美国 | 按监管客体：统一（综合）＝**英、瑞、日、韩**；分业＝**大多数发展中国家** |
| 13 | 认为德国体制下央行不起作用/已无货币政策职能 | 德国是独立于央行的**综合**监管；央行负责**分析报告、日常监管**，作用独特 |
| 14 | 认为美国混业经营框架是"全能型银行/金融集团" | 是**金融控股公司**（1999年《金融服务现代化法案》） |
| 15 | 把地方金融监管主体记成"地方金融监管部门/金融办" | 2023年方案：以**中央金融管理部门地方派出机构为主** |
| 16 | 把村镇银行选进地方金融组织 | 地方金融组织七类＝小贷、融资担保、区域性股权市场、典当、融资租赁、商业保理、地方AMC |
| 17 | 把"金融消费者的客户责任"选进压实责任范围 | 三类责任＝**金融机构及主要股东/实际控制人＋地方政府属地＋监管部门** |
| 18 | 认为跨时间维度管"系统重要性机构" | 跨时间＝**资本水平、杠杆率**（逆周期）；跨空间＝**系统重要性机构＋金融市场**（防传染） |
| 19 | 把"三大支柱"归到2010年巴Ⅲ名下／混淆两类超额资本 | 三大支柱属**2003年新协议**；留存**2.5%**、反周期**0~2.5%**；2010是资本强化＋杠杆率＋流动性量化＋过渡期 |
| 20 | 认为1988年报告把资本分成三层（含超额资本） | 只有**核心资本（一级）和附属资本（二级）**；核心资本≥全部资本**50%**；**公开储备属核心资本**；流动性量化指标是**流动性覆盖率＋净稳定融资比率**，不是资本充足率、杠杆率 |
