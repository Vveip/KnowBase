## 二、知识点精讲

### 考点1 回归分析的概念 ★★

**核心概念**

1. **含义**：回归分析就是根据相关关系的**具体形态**（正相关还是负相关、是否是高度相关），选择一个合适的**数学模型**（即确定一个相关的数学方程式），来近似地表达变量间的**依赖关系**。根据这个数学方程式可以**从已知量推测未知量**（例如从居民收入水平的数量变化情况来估算和预测食品支出的数量变化情况）。
2. **实质**：在相关分析的基础上，研究变量间的**数量变化规律**。
3. **因变量与自变量**：
   - **因变量**：被预测或被解释的变量，一般用 **Y** 表示；
   - **自变量**：用来预测或解释因变量的变量，一般用 **X** 表示。
   - 素材例1（边际消费倾向）：预测一定人均收入条件下的人均消费金额 → **人均消费金额是因变量 Y，人均收入是自变量 X**。
   - 素材例2（质量与用户满意度）：**用户满意度是被预测的变量（因变量 Y），质量是自变量 X**。此例仅用于说明如何判定自/因变量，并非在论证「相关即因果」；回归分析与相关分析的共同研究对象始终是变量间的**相关关系**，「相关关系≠因果关系」的专门辨析素材未覆盖。

**回归分析 vs 相关分析（必考对比表）**

| 维度 | 相关分析 | 回归分析 |
|---|---|---|
| 研究对象 | 变量间的相关关系 | 变量间的相关关系（二者相同） |
| 研究内容 | 相关的**方向和程度** | 相关关系的**具体形式** |
| 能否指出具体形式 | **不能** | **能**（确定数学方程式） |
| 能否推测未知量 | **不能**从一个变量的变化推测另一个变量 | **能**从已知量推测未知量，为估算和预测提供方法 |
| 是否区分自/因变量 | **不需要** | **需要**（首先确定因变量和自变量） |

**二者的联系（4 条，多选高频）**：
1. 具有共同的研究对象，具体应用时常常必须互相补充；
2. 相关分析需要**依靠回归分析**来表明现象数量相关的**具体形式**；
3. 回归分析需要**依靠相关分析**来表明现象数量变化的**相关程度**；
4. 只有**高度相关**时，进行回归分析寻求其相关的具体形式才是有意义的。

**逻辑链**：

```
相关分析（辨方向、定程度：是否高度相关）
        ↓ 只有高度相关时，回归才有意义
回归分析（选合适数学模型，定具体形式，可推测未知量）
        ↓ 首先确定
因变量 Y（被预测/被解释） ←—— 自变量 X（预测/解释 Y）
```

**速记口诀**：**相关辨强弱，回归定模样；不分自因属相关，划分自因是回归。**

### 考点2 一元线性回归模型 ★★★

**核心概念**

1. **回归模型的分类**：
   - 按**自变量的多少**：一元回归模型 / 多元回归模型；
   - 按回归模型**是否线性**：线性回归模型 / 非线性回归模型。
2. **一元线性回归模型**：只包括**一个自变量和一个因变量**，且二者关系可用**一条直线近似**表示；是描述两个变量之间相关关系的**最简单的回归模型**。
3. **多元线性回归模型**：包括**两个或两个以上**的自变量，且因变量和自变量之间是线性关系。
4. **模型表达式**：**Y = β0 + β1X + ε**
   - β0、β1 为模型的参数（也叫回归系数）；
   - **ε 即误差项**，是一个**随机变量**，表示除 X 和 Y 的线性关系之外的**随机因素对 Y 的影响**；
   - β0+β1X 反映了由于自变量 X 的变化而引起的因变量 Y 的线性变化。
5. **回归方程**：描述因变量 Y 的期望 **E(Y)** 如何依赖自变量 X 的方程，形式为 **E(Y) = β0 + β1X**。
   - **β0 是回归直线的截距**：自变量 X=0 时，因变量 Y 的期望值 E(Y)；
   - **β1 是回归直线的斜率**：X 每变动一个单位时，Y 的**平均变动量**；
   - 一元线性回归方程的图示是**一条直线**。

**三个符号的含义（几乎每年必考）**

| 符号 | 名称 | 含义 |
|---|---|---|
| β0 | 截距 | 自变量 X=0 时，因变量 Y 的期望值 E(Y) |
| β1 | 斜率 | 自变量 X 每变动一个单位时，因变量 Y 的平均变动量 |
| ε | 误差项 | 随机变量，除 X 和 Y 线性关系之外的随机因素对 Y 的影响 |

**回归模型 vs 回归方程（高频陷阱）**

| 项目 | 回归模型 | 回归方程 |
|---|---|---|
| 表达式 | Y = β0 + β1X + ε | E(Y) = β0 + β1X |
| 描述对象 | 因变量 Y 如何依赖自变量 X **和误差项 ε** | 因变量 Y 的期望 E(Y) 如何依赖自变量 X |
| 是否含误差项 | 含 ε | 不含 ε |

**回归系数符号与变量关系方向**：回归分析要根据相关关系的具体形态（正相关还是负相关）选择模型，**回归系数的符号反映两变量关系的方向**。素材示例：y = 3 − 0.5x 中斜率为 −0.5，表示 X 每增长 1 个单位，Y 平均**减少** 0.5 个单位（负向关系）。

**逻辑链**：

```
判定模型类型：自变量个数（1个=一元，≥2个=多元）＋ 是否线性
        ↓
一元线性回归模型：Y = β0 + β1X + ε（含随机误差项）
        ↓ 对 Y 取期望 E(Y)，剔除随机因素
回归方程：E(Y) = β0 + β1X  →  图示为一条直线
        ↓
β0 = 截距（X=0 时 E(Y) 的值）
β1 = 斜率（X 每变动 1 个单位时 Y 的平均变动量，符号定方向）
```

**速记口诀**：**模型带误差，方程不带它；β0 截距 β1 斜率，一单位变动看 β1。**

**随堂例题（素材原题，无年份标签）**

1. 线性回归模型 Y=β0+β1X+ε 中误差 ε 的含义是（　）。
   A. 回归直线的截距　B. 除 X 和 Y 线性关系之外的随机因素对 Y 的影响
   C. 回归直线的斜率　D. 观测值和估计值之间的残差
   **答案：B**。ε 是随机变量，表示除 X 和 Y 线性关系之外的随机因素对 Y 的影响（注意与选项 D「残差」区分）。

2. 下列回归模型中，属于一元线性回归模型的是（　）。
   A. Y=β0+β1x1+β2x2+ε　B. Y=β0+β1x1+β1x2²+ε
   C. Y=β0x1^β1x2^β2+ε　D. Y=β0+β1x+ε
   **答案：D**。只涉及一个自变量的一元线性回归模型可表示为 Y=β0+β1x+ε。

### 考点3 最小二乘法 ★★

**核心概念**

1. 现实中，模型的参数 β0、β1 都是**未知的**，必须利用**样本数据**去估计，采用的估计方法是**最小二乘法**。
2. **原理**：最小二乘法就是使得因变量的**观测值与估计值之间的离差（又称残差）平方和最小**，来估计参数 β0 和 β1 的方法。
3. 直观理解：**寻找距离各观测点最近的一条直线**，即使实际观测点和直线间的距离最小。
4. 假设可得到 X 和 Y 的 n 组观测值，根据样本统计量估计模型中的参数，得到**估计的回归方程**（系数估计值上加「∧」）。素材中该处公式符号在清洗时丢失，**β̂0、β̂1 的具体求和计算公式素材未覆盖**，考试只考「离差平方和最小」这一原理。

**逻辑链**：

```
样本数据（X 和 Y 的 n 组观测值）
        ↓ 最小二乘法估计
β̂0、β̂1  →  估计的回归方程
        ↓ 估计目标
min Σ(观测值 Yi − 估计值 Ŷi)²   （离差/残差平方和最小）
```

**速记口诀**：**二乘用来估参数，离差平方和最小。**

### 考点4 回归模型的拟合效果分析 ★★

**核心概念**

**（一）使用估计的回归方程之前，需要对模型进行检验（3 项，多选高频）**：
1. 结合经济理论和经验分析回归系数的**经济含义是否合理**；
2. 分析估计的模型对数据的**拟合效果如何**（用**决定系数**来测度）；
3. 对模型进行**假设检验**。

**（二）决定系数 R²（拟合优度/判定系数）**：
- **含义**：可以测度回归直线对样本数据的**拟合程度**；决定系数是回归模型所能**解释的因变量变化占因变量总变化的比例**。
- **取值**：在 **0 到 1 之间**；越接近 1，回归直线的拟合效果越好。
- R²=1：回归直线可以解释因变量的**所有变化**（所有观测点都落在回归直线上）。
- R²=0：回归直线**无法解释**因变量的变化，因变量的变化与自变量无关。
- 现实应用中 R² 大多落在 0 和 1 之间。素材真题将「自变量个数对 R² 没有影响」判为**错误**选项，且二元模型给出的是**调整后 R²**。

**（三）回归系数的显著性检验（t 检验）**：
- 在大样本假定的条件下，回归系数的最小二乘估计量渐进服从正态分布，可以用 **t 检验法**验证自变量 X 对因变量 Y 是否有显著影响。
- **t 检验的原理是反证法**：原假设为 β1=0（自变量 X 对因变量 Y 没有影响）。
- **若 P<0.05**，则可以在 0.05 的显著性水平下**拒绝原假设**，认为自变量 X 对因变量 Y **有显著影响**；
- 若 **P≥0.05**，则**不能认为**有显著影响（如 2025 年真题 P=0.08）。

**素材例题输出表1（一元：收入→消费）**

| 系数 | 标准误差 | t检验 | P值 |
|---|---|---|---|
| 截距 | 1368.674 | 107.0967227 | 12.77979 | 1.82×10⁻⁹ |
| 城镇居民人均可支配收入 | 0.637271 | 0.004248599 | 149.9955 | 3.05×10⁻²⁵ |

最小二乘估计值分别为 1368.674 和 0.637271。自变量 P 值 = 3.05×10⁻²⁵ ＜ 0.05，可以在 0.05 的显著性水平下拒绝 β1=0 的原假设，认为城镇居民人均可支配收入对城镇居民人均消费支出**有显著影响**。

**素材例题输出表2（二元：受教育年限+职位→年薪）**

| 系数 | 标准误差 | t检验 | P值 |
|---|---|---|---|
| 截距 | −18716.2 | 16600.7096 | −1.12743 | 0.26948 |
| 受教育年限（edu） | 3669.002 | 1209.412447 | 3.033684 | 0.00529 |
| 职位（position） | 27144.47 | 8197.976538 | 3.311118 | 0.00265 |

- 二元线性回归模型的**调整后 R²=0.605**，表示受教育年限和职位的二元回归模型对年薪的变化**可解释程度为 60.5%**；
- 受教育年限和职位的 t 检验 P 值 0.00529 和 0.00265 **都小于 0.05**，表明 2 个自变量都通过了 t 检验，对年薪有**显著的线性影响**；
- 在相同的职位上，受教育年限每增长 1 年，年薪平均增长 3669 元；相同受教育年限条件下，管理者年薪比一般职员平均增长 27144.47 元；
- 按 P<0.05 的规则直接比较，截距项 P 值 0.26948＞0.05 未通过检验（素材未就此展开，编者按规则提示）。

**R² 取值与解释（必背）**

| R² 取值 | 解释 |
|---|---|
| = 1 | 回归直线可以解释因变量的**所有**变化（观测点全部落在回归直线上） |
| 越接近 1 | 拟合效果越好，模型解释因变量的能力越强 |
| = 0 | 回归直线**无法解释**因变量的变化，因变量的变化与自变量无关 |
| 越接近 0 | 拟合效果越差 |
| 取值范围 | **0 到 1 之间**（不是 −1 到 1） |

**t 检验判断规则（必背）**

| P 值（α=0.05） | 结论 |
|---|---|
| P ＜ 0.05 | 拒绝原假设 β1=0，认为 X 对 Y **有显著影响** |
| P ≥ 0.05 | 不能拒绝原假设，**不能认为** X 对 Y 有显著影响 |

**逻辑链**：

```
估计出回归方程后、投入使用前必须检验
   ├─ ① 经济含义是否合理（结合经济理论和经验）
   ├─ ② 拟合效果如何 → 决定系数 R²（0~1，越接近 1 越好）
   └─ ③ 假设检验 → t 检验（反证法，原假设 β1=0）
              └─ P<0.05 → 拒绝 → X 对 Y 有显著影响
```

**速记口诀**：**t 检判断显著性，0.05 划界限；P 值小于 0.05，影响显著有力度；P 值大于 0.05，显著影响不存在。**

**随堂例题（素材原题，无年份标签）**

1. 某一元线性回归模型 X 检验的 P 值为 0.02，则对该结果的正确解释是（　）。
   A. 在 0.05 的显著性水平下拒绝原假设，认为自变量对因变量有显著影响
   B. 在 0.05 的显著性水平下拒绝原假设，认为自变量对因变量没有显著影响
   C. 在 0.05 的显著性水平下接受原假设，认为自变量对因变量有显著影响
   D. 在 0.05 的显著性水平下接受原假设，认为自变量对因变量没有显著影响
   **答案：A**。P=0.02＜0.05，拒绝 β1=0 的原假设，认为自变量对因变量有显著影响。

2. 下列关于回归分析的说法，错误的是（　）。
   A. 描述因变量如何依赖自变量和误差项的方程称为回归模型
   B. 决定系数可以测度回归直线对样本数据的拟合程度
   C. 决定系数越接近 1，回归直线的拟合效果越好
   D. R²=0，说明回归直线可以解释因变量的所有变化
   **答案：D**。R²=**1** 才说明回归直线可以解释因变量的所有变化；R²=0 说明完全无法解释。

3. 关于决定系数 R²，表述正确的是（　）。
   A. 取值区间从 0 到 1　B. R² 越大，回归直线的拟合效果越好
   C. R²=0，说明回归直线无法解释因变量的变化
   D. R² 的取值范围是大于 0　E. 自变量个数对 R² 没有影响
   **答案：AC**。D 错——R² 可以取 0；E 错——「自变量个数对 R² 没有影响」被素材判为错误说法，且二元模型给出的是**调整后 R²**。

### 考点5 模型预测 ★

**核心概念**

1. 回归分析的一个重要应用就是**预测**，即利用估计的回归模型**预估因变量数值**。
2. 方法：将自变量 X 的取值代入估计的回归方程，得到因变量的**预测值 Ŷ**。
3. 素材教材例题（一元）：估计的城镇居民人均可支配收入和人均消费的一元线性回归方程为 **Ŷ=1292.6+0.629X**；当 X=15000 元时，人均消费支出 Ŷ=1292.6+0.629×15000（数值演算见第四节）。
4. 素材例题（二元，编者据素材系数表还原方程）：年薪模型含截距 −18716.2、edu 系数 3669.002、position 系数 27144.47；员工甲受教育年限 10 年、一般职员（预测时不代入职位项），Ŷ=−18716.2+3669×10=17937.8 元（复核演算见第四节编者注）。
5. 素材提示陷阱：**预测区间比置信区间范围更大**（具体讲解素材未覆盖）。

**逻辑链**：

```
给定自变量 X（或 edu、position）的取值
        ↓ 代入估计的回归方程
一元：Ŷ = β̂0 + β̂1X
二元（素材例题）：Ŷ = −18716.2 + 3669×edu + 27144.47×position
        ↓
得到因变量的预测值（教材例题：X=15000 → 人均消费支出）
```

**速记口诀（编者整理）**：**预测就是代 X 求 Ŷ，区间比置信更宽。**

## 三、必背表格汇总

### 表0 回归模型的分类

| 分类角度 | 类型 | 要点 |
|---|---|---|
| 按**自变量的多少** | 一元回归模型 | 只包括一个自变量和一个因变量 |
| | 多元回归模型 | 包括两个或两个以上的自变量 |
| 按回归模型**是否线性** | 线性回归模型 | 因变量和自变量之间是线性关系 |
| | 非线性回归模型 | 变量间关系不能用直线近似表示 |
| 二者交叉 | **一元线性回归模型** | 一个自变量＋可用一条直线近似表示；是描述两个变量相关关系的最简单回归模型 |

### 表1 回归模型 vs 回归方程

| 项目 | 回归模型 | 回归方程 |
|---|---|---|
| 表达式 | Y = β0 + β1X + ε | E(Y) = β0 + β1X |
| 描述对象 | Y 如何依赖 X **和误差项 ε** | Y 的期望 E(Y) 如何依赖 X |
| 是否含误差项 | 含 | 不含 |

### 表2 三个符号含义

| 符号 | 名称 | 含义 |
|---|---|---|
| β0 | 截距 | X=0 时因变量 Y 的期望值 E(Y) |
| β1 | 斜率 | X 每变动一个单位时 Y 的平均变动量 |
| ε | 误差项 | 除 X 和 Y 线性关系之外的随机因素对 Y 的影响（随机变量） |

### 表3 回归分析 vs 相关分析

| 维度 | 相关分析 | 回归分析 |
|---|---|---|
| 研究内容 | 相关的方向和程度 | 相关关系的具体形式 |
| 能否指出具体形式 | 不能 | 能 |
| 能否推测未知量 | 不能 | 能 |
| 是否区分自/因变量 | 不需要 | 需要 |

### 表4 决定系数 R² 取值与解释

| R² 取值 | 解释 |
|---|---|
| 0 到 1 之间 | 取值范围 |
| 越接近 1 | 拟合效果越好 |
| =1 | 解释因变量的所有变化 |
| =0 | 无法解释因变量的变化（与自变量无关） |

### 表5 t 检验判断规则

| P 值 | 结论（0.05 显著性水平） |
|---|---|
| P＜0.05 | 拒绝 β1=0，X 对 Y 有显著影响 |
| P≥0.05 | 不能认为 X 对 Y 有显著影响 |

### 表6 「6 个不等于」避坑表

| # | 错误说法 | 正解 |
|---|---|---|
| 1 | 回归分析 = 相关分析 | ✗ 研究方法和研究目的有明显区别：相关辨强弱，回归定模样 |

| 6 | R²=0 说明能解释所有变化 | ✗ R²=**1** 才能解释所有变化；R²=0 完全无法解释 |

## 四、公式与计算（本章计算题重点）

> **本章计算题两大类型**：①**代入回归方程求预测值**；②**P 值与 0.05 比较**判断显著性。以下例题全部使用素材给定的方程与数字；素材未覆盖的公式已明确标注，不凭记忆补写。

### 4.1 一元线性回归模型与参数含义

**公式（素材覆盖）**：
- 回归模型：**Y = β0 + β1X + ε**
- 回归方程：**E(Y) = β0 + β1X**（β0 截距、β1 斜率）

**例题 1（素材原题）**：一元线性回归模型 y = 3 − 0.5x 中，参数 −0.5 的含义为（ ）。
**数字演算**：
```
x = 0 时，y = 3 − 0.5×0 = 3
x = 1 时，y = 3 − 0.5×1 = 2.5
x 增加 1 个单位，y 平均减少 0.5 个单位
```
**结论**：β1 = −0.5 表示自变量 x 每增长 1 个单位时，因变量 Y **平均增长 −0.5 个单位**（即减少 0.5 个单位）。对应素材答案 **B**。

### 4.2 最小二乘法估计参数

**原理（素材覆盖）**：使因变量的**观测值与估计值之间的离差（残差）平方和最小**，即 min Σ(观测值−估计值)²（符号化为编者整理，素材为文字表述）。
**素材未覆盖**：β̂0、β̂1 的具体求和计算公式（素材此处公式符号在清洗中丢失），考试只考原理。

**例题 2（素材估计输出）**：素材给出收入→消费回归的最小二乘估计结果：截距 1368.674、斜率 0.637271。
**数字演算**：
```
估计方程：Ŷ = 1368.674 + 0.637271X
X = 0 时，Ŷ = 1368.674（截距：收入为 0 时消费的期望值）
X 增加 1 元，Ŷ 增加 0.637271 元（斜率：收入每增 1 元，消费平均增加 0.637271 元）
X 增加 1000 元，Ŷ 增加 0.637271×1000 = 637.271 元
```
**结论**：最小二乘估计就是寻找使所有观测点「观测值 − 估计值」离差平方和最小的 β̂0、β̂1。

### 4.3 回归系数的显著性检验（t 检验）

**规则（素材覆盖）**：反证法，原假设 β1=0；**P<0.05 拒绝原假设**，认为 X 对 Y 有显著影响。

**例题 3（素材 2025 年真题数字）**：药物剂量的 t 检验 P 值为 0.08。
**数字演算**：
```
P = 0.08 > 0.05
→ 在 0.05 显著性水平下不能拒绝原假设
→ 不能认为药物剂量对康复率有显著影响
```
**结论**：答案为「在 0.05 的显著性水平下，**不能**认为药物剂量对康复率有显著影响」。注意：0.08 不是「提高 8%」，也不能反推「无线性关系」。

**例题 4（素材二元输出表）**：edu 的 t=3.033684、P=0.00529；position 的 t=3.311118、P=0.00265。
**数字演算**：
```
0.00529 < 0.05 → 拒绝 βedu=0 → 受教育年限对年薪有显著影响
0.00265 < 0.05 → 拒绝 βposition=0 → 职位对年薪有显著影响
（截距 P = 0.26948 > 0.05 → 截距项未通过检验，素材未展开）
```
**结论**：两个自变量都通过 t 检验，对年薪有显著的线性影响。

### 4.4 拟合优度 R²

**公式（素材覆盖，文字定义）**：**R² = 回归模型所能解释的因变量变化 ÷ 因变量总变化**；取值 0 到 1 之间，越接近 1 拟合效果越好。
**素材未覆盖**：SSR/SST 或 1−SSE/SST 的分解写法。

**例题 5（素材二元输出）**：二元线性回归模型的调整后 R²=0.605。
**数字演算**：
```
R² = 0.605 → 0.605 × 100% = 60.5%
→ 受教育年限和职位的二元回归模型对年薪变化的可解释程度为 60.5%
```
**结论**：若所有观测点都落在回归直线上，R²=1（解释 100%）；R²=0 则完全无法解释因变量的变化。

### 4.5 预测值与残差

**公式（素材覆盖）**：
- 预测值：将 X 代入估计的回归方程得 **Ŷ**；
- 残差 = **观测值 − 估计值**（素材：「观测值与估计值之间的离差（又称残差）」）。素材未提供成对观测数据，**残差的数值演算例题素材未覆盖**。

**例题 6（素材教材例题，一元预测）**：Ŷ=1292.6+0.629X，当 X=15000 元时，人均消费支出是多少？
**数字演算**：
```
Ŷ = 1292.6 + 0.629×15000
  = 1292.6 + 9435
  = 10727.6 元
```
> **编者注（复核）**：素材原文结果为 **10731 元**。按素材给定方程复核为 **10727.6 元**（0.629×15000=9435）。两版数字并存列出，考试时以题目给定的方程和选项为准，此处差异疑为素材笔误。

**例题 7（素材例题，二元预测）**：员工甲受教育年限 10 年、一般职员。
**数字演算**：
```
Ŷ = −18716.2 + 3669×10
  = −18716.2 + 36690
  = 17973.8 元
```
> **编者注（复核）**：素材原文结果为 **17937.8 元**。按素材给定系数复核为 **17973.8 元**（3669×10=36690）。两版数字并存列出，考试时以题目给定数据为准，此处差异疑为素材笔误。另：素材中教材例题系数（1292.6、0.629）与软件估计输出（1368.674、0.637271）是**两套不同数据**，不要混用。

## 五、高频考点速记卡

1. **Q：回归分析的实质是什么？**
   A：在相关分析的基础上，研究变量间的**数量变化规律**；根据相关关系的具体形态选择数学模型，近似表达变量间的依赖关系。

2. **Q：因变量和自变量怎么区分？**
   A：**被预测或被解释**的是因变量 Y；**用来预测或解释**因变量的是自变量 X。

3. **Q：回归分析与相关分析的联系？**
   A：研究对象相同；相关分析靠回归分析表明**具体形式**，回归分析靠相关分析表明**相关程度**；只有**高度相关**时回归分析才有意义。

4. **Q：回归分析与相关分析的区别？**
   A：相关分析研究**方向和程度**，不能指出具体形式、不能推测未知量、不需区分自/因变量；回归分析研究**具体形式**，能推测未知量，首先需确定因变量和自变量。

5. **Q：一元线性回归模型的表达式？**
   A：**Y=β0+β1X+ε**（含误差项）。ε 是随机变量，表示除 X 和 Y 线性关系之外的随机因素对 Y 的影响。

6. **Q：一元线性回归方程的形式？**
   A：**E(Y)=β0+β1X**，描述 Y 的期望如何依赖 X，图示是**一条直线**，不含 ε。

7. **Q：β0 的含义？**
   A：回归直线的**截距**，即自变量 X=0 时因变量 Y 的期望值 E(Y)。

8. **Q：β1 的含义？**
   A：回归直线的**斜率**，即 X 每变动一个单位时 Y 的**平均变动量**（注意不是「绝对变化量」）。

9. **Q：回归模型怎么分类？**
   A：按自变量多少分**一元/多元**；按是否线性分**线性/非线性**。一个自变量＋直线近似＝一元线性回归模型。

10. **Q：估计 β0、β1 的方法是什么？**
    A：**最小二乘法**（利用样本数据估计未知参数）。

11. **Q：最小二乘法的原理？**
    A：使因变量的**观测值与估计值之间的离差（残差）平方和最小**；即找距离各观测点最近的一条直线。

12. **Q：使用估计的回归方程前要检验什么？**
    A：三项——①回归系数的**经济含义是否合理**；②模型对数据的**拟合效果**（决定系数测度）；③模型的**假设检验**。

13. **Q：决定系数 R² 的含义？**
    A：也称**拟合优度/判定系数**，测度回归直线对样本数据的拟合程度；是**模型能解释的因变量变化占因变量总变化的比例**。

14. **Q：R² 的取值范围与解释？**
    A：**0 到 1 之间**；越接近 1 拟合越好；R²=1 解释因变量所有变化；R²=0 无法解释因变量的变化（与自变量无关）。

15. **Q：t 检验的原理和判断规则？**
    A：**反证法**，原假设 β1=0；**P<0.05 拒绝原假设**，认为 X 对 Y 有显著影响；P≥0.05 不能认为有显著影响。

16. **Q：P=0.08 说明什么？**
    A：0.08>0.05，在 0.05 显著性水平下**不能认为**自变量对因变量有显著影响；但不等于「无线性关系」，也不是「提高 8%」。

17. **Q：t 检验用来判断什么？**
    A：**自变量 X 对因变量 Y 的影响是否显著**（不判断正态性、经济含义合理性或整体拟合优度）。

18. **Q：模型预测怎么算？**
    A：把 X 代入估计的回归方程求 Ŷ；素材教材例题：X=15000 时，Ŷ=1292.6+0.629×15000。

19. **Q：二元模型调整后 R²=0.605 说明什么？**
    A：受教育年限和职位的二元回归模型对年薪变化的**可解释程度为 60.5%**；两个自变量的 P 值（0.00529、0.00265）都小于 0.05，都通过 t 检验。

20. **Q：素材提示的两个陷阱是什么？**
    A：①**预测区间比置信区间范围更大**；②模型假定条件、残差分析是常考细碎考点（本章素材未展开）。

**【2022·单选】** 一元线性回归方程形式为（　）。
A. E(Y)=β0+β1X　B. Y=β1X+ε　C. E(Y)=β0+β1+ε　D. Y=β0+β1X

**答案：A**
**解析**：一元线性回归方程的形式为 E(Y)=β0+β1X。一元线性回归方程的图示是一条直线，β0 是回归直线的截距，β1 是回归直线的斜率，表示 X 每变动一个单位时 E(Y) 的变动量。

**【2021·单选】** 一元线性回归方程 E(Y)＝β0＋β1X 中，β0 的含义为（　）。
A. 自变量 X 为 0 时，因变量 Y 的期望值
B. 自变量 X 每增长 1% 时，因变量 Y 平均增长 β1%
C. 自变量 X 为 0 时，ε 的期望值
D. 自变量 X 每变动 1 个单位时，E(Y) 的变动量

**答案：A**
**解析**：β0 是回归直线的截距，表示自变量 X 为 0 时，因变量 Y 的期望值，即 E(Y) 的值。

### 考点3 最小二乘法

**【2024·单选】** 在回归分析中，估计回归系数的最小二乘法的原理是（　）。
A. 使得因变量观测值与均值之间的离差平方和最小
B. 使得因变量估计值与均值之间的离差平方和最小
C. 使得观测值与估计值之间的乘积最小
D. 使得因变量观测值与估计值之间的离差平方和最小

**答案：D**
**解析**：最小二乘法就是使得因变量的观测值与估计值之间的离差（残差）平方和最小来估计回归系数的方法。

**【2023·单选】** 对于一元线性回归模型 Y=β0+β1X+ε，确定 β0 和 β1 的方法是（　）。
A. 二次平均　B. 加权平均　C. 斯特基方法　D. 最小二乘法

**答案：D**
**解析**：在现实中，模型的参数 β0 和 β1 都是未知的，需要利用样本数据去估计，采用的估计方法是最小二乘法。

### 考点4 回归模型的拟合效果分析

**【2025·单选】** 在一元线性回归中，t 检验用于判断（　）。
A. 因变量是否服从正态分布
B. 自变量对因变量的影响是否显著
C. 回归系数的经济含义是否合理
D. 回归模型整体拟合优度

**答案：B**
**解析**：t 检验方法用来验证自变量 X 对因变量 Y 是否有显著影响。

**【2025·单选】** 某医学机构采用回归分析方法评估药物剂量对患者康复率的影响，回归模型中药物剂量的 t 检验 P 值为 0.08，这表明（　）。
A. 药品剂量每增加 1 个单位，康复率提高 8%
B. 药品剂量和康复率无线性关系
C. 在 0.05 的显著性水平下，可以认为药物剂量对康复率有显著影响
D. 在 0.05 的显著性水平下，不能认为药物剂量对康复率有显著影响

**答案：D**
**解析**：t 检验的原理是反证法。在原假设 β1=0（自变量 X 对因变量 Y 没有影响）的正确假设下，基于抽样分布计算一次抽样情况下得到该样本或更极端样本的概率，如果 P＜0.05，则可以在 0.05 的显著性水平下拒绝原假设，认为自变量 X 对因变量 Y 有显著影响。本题 P=0.08＞0.05，因此在 0.05 显著性水平下，不能认为药物剂量对康复率有显著影响。A 项混淆了 P 值与回归系数含义；B 项表述绝对，P 值不否定所有关系，仅否定「显著线性关系」。
> **编者注**：素材两个版本的该题 C、D 选项顺序互换（另一版本 C 为「不能认为」、D 为「可以认为」），答案均为「**不能**认为药物剂量对康复率有显著影响」。

**【2024·单选】** 回归模型决定系数是指（　）的比例。
A. 因变量总变化占模型能解释的因变量变化
B. 模型能解释的因变量变化占自变量总变化
C. 自变量的变化占因变量变化
D. 模型能解释的因变量变化占因变量总变化

**答案：D**
**解析**：决定系数是回归模型所能解释的因变量变化占因变量总变化的比例，取值范围在 0 到 1 之间。决定系数越高，模型的拟合效果就越好，即模型解释因变量的能力越强。

**【2024·多选】** 关于决定系数，下列说法正确的有（　）。

D. 决定系数为 0 说明回归直线无法解释因变量的变化

**【2023 补·多选】** 在使用估计的回归方程之前，一般需要对回归模型进行的检验有（　）。

C. 样本数据的真实性检验

**答案：ABD**
**解析**：一般情况下，在使用估计的回归方程之前，需要对模型进行检验：①结合经济理论和经验分析回归系数的经济含义是否合理；②分析估计的模型对数据的拟合效果如何；③对模型进行假设检验。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把回归模型和回归方程混为一谈 | 模型 **Y=β0+β1X+ε** 带误差项；回归方程 **E(Y)=β0+β1X** 是取期望后的直线，**不带 ε**（2022、2023补、2025 反复考） |
| 2 | 认为 β0 是因变量 Y 的均值 | β0 是**截距**：X=0 时 Y 的期望值（2026 真题 B 选项错在此） |
| 3 | 把 β1 理解成「绝对变化量」 | β1 是 X 每变动 1 个单位时 Y 的**平均**变动量（2025 真题 A 项陷阱） |
| 4 | 把 ε 理解成「观测值和估计值之间的残差」 | ε 是线性关系**之外的随机因素**，是随机变量；残差＝观测值−估计值，两者不同（素材真题错误选项） |
| 5 | 认为相关分析能从一个变量推测另一个变量 | 只有回归分析能推测未知量；相关分析只辨**方向和程度**（2024 多选 B 错） |
| 6 | 认为相关分析需要明确自变量和因变量 | 只有**回归分析**首先需要确定因变量和自变量（2024 多选 E 错） |
| 7 | 以为不高度相关也可以直接做回归分析 | 只有**高度相关**时，寻求具体形式才有意义 |
| 8 | 把最小二乘法原理记成「与均值的离差平方和最小」 | 是**观测值与估计值之间**的离差（残差）平方和最小（2024 真题 A/B 均为陷阱） |
| 9 | 以为 R² 取值范围是 −1 到 1 | R² 在 **0 到 1 之间** |
| 10 | 把 R²=0 和 R²=1 的解释弄反 | =**1** 解释所有变化；=**0** 完全无法解释，因变量变化与自变量无关 |
| 11 | 认为 R² 越接近 0 拟合越好 | 越接近 0 拟合**越差**（2024 多选 B 错） |
| 12 | 把决定系数的比例说反 | 是「模型能解释的因变量变化 **÷** 因变量总变化」，不能倒过来说（2024 单选） |
| 13 | P=0.08 就认为「有显著影响」 | 0.08＞0.05，**不能认为**有显著影响；但也不能说成「无线性关系」（表述绝对化） |
| 14 | 把 P 值当成回归系数 | P=0.08 不是「康复率提高 8%」（2025 真题 A 项混淆概念） |
| 15 | 以为 t 检验是检验正态性、经济含义或拟合优度 | t 检验**只判断自变量 X 对因变量 Y 的影响是否显著**（2025 真题） |
| 16 | 漏记使用回归方程前的检验内容 | 三项：经济含义合理＋拟合效果（R²）＋假设检验；**不含**样本数据真实性/随机性检验（2023补多选 C、E 错） |
| 17 | 忘记预测区间的陷阱 | 素材提示：**预测区间比置信区间范围更大** |
| 18 | 二元模型预测时漏代或错代职位项 | 素材例题：一般职员预测时不代入职位项（Ŷ=−18716.2+3669×10） |
| 19 | 忽视模型假定条件和残差分析 | 素材提示是常考细碎考点，本章素材未展开（标注「素材未覆盖」） |
| 20 | 教材例题系数与软件输出系数混用 | 教材例题 Ŷ=1292.6+0.629X 与软件输出 1368.674/0.637271 是两套数据，做题以题目给定方程为准 |
