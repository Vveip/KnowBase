# 第29章 会计循环

> **本章考情**：本章是第五部分「会计」的收尾章，四节内容（会计确认→会计计量→会计记录→财务会计报告）环环相扣，是「核算职能四环节」的完整展开。命题以**概念辨析＋分类归属＋记账规则**为主：高频集中在会计计量的五种属性、会计记录的方法、借贷记账法"有借必有贷、借贷必相等"及两种试算平衡公式、五种账务处理程序的优缺点与适用范围、会计报表的四种分类依据。计算题主要落在借贷记账法的试算平衡与账户余额计算上。

> 会计循环就是「**确认 → 计量 → 记录 → 报告**」四步走：**确认**回答"要不要记、何时记、记成哪项要素"（三个问题＋三条规定）；**计量**回答"记多少钱"（五种属性，平时默认用历史成本）；**记录**回答"怎么记"（设置账户＋复式记账，借贷记账法守"有借必有贷、借贷必相等"，用发生额、余额两种试算平衡来自查）；**报告**回答"怎么交卷"（会计报表＋附注，资产负债表/利润表/现金流量表三张主表）。凭证和账簿是把四步串起来的载体，五种账务处理程序的**唯一差别**是"拿什么登记总分类账"。

## 二、知识点精讲

### 考点1 会计确认的概念 ★

**核心概念**：会计确认是指会计数据进入会计系统时确定如何进行记录的过程，即将某一会计事项作为**资产、负债、所有者权益、收入、费用或利润**等会计要素**正式列入会计报表**的过程。

**会计确认主要解决三个问题**：

| 序号 | 问题 | 关键词 |
|---|---|---|
| 1 | 确定某一经济业务**是否需要进行确认** | 要不要 |
| 2 | 确定该业务**应在何时进行确认** | 何时 |
| 3 | 确定该业务**应确认为哪个会计要素** | 哪项 |

**逻辑链（必背顺序）**：

```
是否需要确认 ──→ 何时进行确认 ──→ 确认为哪个会计要素
   （要不要）        （何时算）          （算哪项）
```

**速记口诀**：**"要不要、何时算、算哪项"**——三个问题按此顺序提问，顺序本身就是考点。

---

### 考点2 会计确认的标准 ★

**会计确认的一般标准（3 项）**：

1. 被确认的项目是通过**经济业务活动**所产生的，其**交易性质符合会计要素**的要求；
2. 与该项目有关的**未来经济利益**流入或流出企业的**不确定性能明确地评估**；
3. 该项目应有**可以计量的属性**，并能**可靠地进行计量**。

**关键结论（选择题高频）**：

> **权责发生制构成了确认收入和费用的基础，也进一步构成了资产和负债的确认基础。**

**速记口诀**：**"业务真、利益清、金额靠"**——业务是真实经济业务产生的、未来经济利益的不确定性可评估、金额能可靠计量。（权责发生制是确认收入费用的"地基"。）

---

### 考点3 会计计量的概念 ★

| 项目 | 内容 |
|---|---|
| **含义** | 会计计量是指为了在会计报表中确认和计量有关会计要素的实际状况，而确定其**货币金额**的过程 |
| **地位** | **计量问题是会计的核心问题**，贯穿于会计从**确认、记录到报告**的全过程 |
| **目的** | 进一步明确一项经济业务所带来的某一会计要素变化的**数量多少**，体现会计信息的**定量化**特点 |

**会计计量的两个方面构成**：

```
会计计量
 ├── 计量单位：主要是货币量度，辅之以各种实物量度
 └── 计量属性：历史成本、重置成本、可变现净值、现值、公允价值（5种）
```

---

### 考点4 会计计量的属性 ★

| 计量属性 | 别称 | 关键词 | 含义 |
|---|---|---|---|
| **历史成本** | 原始成本／实际成本 | **取得资产时实际发生** | 以取得资产时**实际发生的成本**作为资产的入账价值 |
| **重置成本** | 现行成本 | **重新取得** | 企业按照当前市场条件**重新取得**与其所拥有的某项资产相同或与其功能相当的资产需要支付的现金或现金等价物 |
| **可变现净值** | —— | **估计售价 − 成本费用税** | 企业在日常生产经营活动中，以**估计售价**减去**完工时估计将要发生的成本**以及**估计销售所必需的费用以及相关税费**后的金额 |
| **现值** | —— | **折现** | 企业在正常生产经营活动中，以估计的**未来现金流入扣除未来现金流出后的余额**，用恰当的**折现率**予以折现而得到的价值 |
| **公允价值** | —— | **公平交易＋自愿** | 在**公平交易**中，熟悉情况的交易双方**自愿**进行资产交换或者债务清偿的金额 |

**必背【注意】**：

> 企业对会计要素进行计量时，**一般应当采用历史成本**。采用重置成本、可变现净值、现值、公允价值计量的，应保证所确定的会计要素金额**能够取得并可靠计量**。

**速记口诀**：**"智（置）力（历）变贡（公）献（现）"**——重置、历史、可变现、公允、现值，五种属性一口气念完；默认用"历史"，其余四种要"可靠计量"兜底。

---

### 考点5 会计记录的概念 ★★

**核心概念**：会计记录是通过**账户、会计凭证和账簿**等载体，运用**复式记账**等手段，对**确认和计量的结果**进行记录，为**编制财务会计报告积累数据**的过程。

**三个关键词**：载体（账户、会计凭证、账簿）＋手段（复式记账）＋目的（为编报积累数据）。

---

### 考点6 会计记录的方法 ★★★

**会计记录的方法主要包括 4 项**：

| 序号 | 方法 | 一句话要点 |
|---|---|---|
| 1 | **设置账户** | 根据会计科目设置，分类反映会计要素增减变动的载体 |
| 2 | **复式记账** | 对每项经济业务以相等金额同时记入两个或两个以上账户 |
| 3 | **填制和审核凭证** | 会计工作的**开始**，登记账簿的依据 |
| 4 | **登记账簿** | 联结会计凭证和财务会计报告的**中间环节** |

**高频陷阱**：**"划分会计期间"不属于会计记录的方法**——它是会计基本前提（会计分期）的内容。

**速记口诀**：**"3账1证"**——设置账户、复式记账、登记账簿三种"账"，加填制审核凭证一种"证"。

---

### 考点7 设置账户 ★★★

**（1）概念**：账户是指根据**会计科目**设置的，具有一定格式和结构，用于**分类反映会计要素各项目增减变动情况及其结果**的载体。

**（2）账户的两类分类**：

| 分类标准 | 类别 |
|---|---|
| 按账户所反映的**会计要素的具体内容** | **资产类、负债类、所有者权益类、成本类和损益类**（损益类又分为收入类和费用类） |
| 按账户所提供信息的**详细程度** | **总分类账户**、**明细分类账户** |

**（3）账户结构**：分为两个基本部分，即**左方（记账符号为借）**和**右方（记账符号为贷）**两个方向，一方登记增加，另一方登记减少。

- 登记本期增加的金额＝**本期增加发生额**；登记本期减少的金额＝**本期减少发生额**；增减相抵后的差额为**余额**（按期初/期末分为期初余额、期末余额）。
- **在哪一方记增加、哪一方记减少，取决于账户的类型。**

**（4）两类账户的登记规则与余额公式**：

| 账户类型 | 登记规则 | 余额方向 | 期末余额公式 |
|---|---|---|---|
| **资产、成本、费用类** | **借方登记增加额，贷方登记减少额** | 借方 | 期初余额＋本期借方发生额－本期贷方发生额 |
| **负债、所有者权益、收入类** | **贷方登记增加额，借方登记减少额** | 贷方 | 期初余额＋本期贷方发生额－本期借方发生额 |

```
借方  资产类（账户名称）          贷方
┌──────────────┬──────────────┐
│  期初余额     │              │
│  本期增加发生额│  本期减少发生额│
│  期末余额     │              │
└──────────────┴──────────────┘
        增加在借 ↓ 减少在贷

借方  负债类（所有者权益）        贷方
┌──────────────┬──────────────┐
│  本期减少发生额│  期初余额     │
│              │  本期增加发生额│
│              │  期末余额     │
└──────────────┴──────────────┘
        减少在借 ↓ 增加在贷
```

**基本关系（通用公式）**：

```
期末余额 = 期初余额 + 本期增加发生额 − 本期减少发生额
```

**速记口诀**：**"资产成本费用是'借方派'（借增贷减），负债权益收入是'贷方派'（贷增借减）"**。

### 考点8 复式记账与借贷记账法 ★★★

**（1）复式记账**：对每一项经济业务都要以**相等的金额**，**同时计入两个或两个以上的有关账户**的一种记账方法。

- **主要的复式记账法有三种**：**借贷记账法、收付记账法、增减记账法**。
- **其中借贷记账法是一种被普遍接受并广泛使用的记账方法**（考试只考借贷记账法）。

**（2）借贷记账法**：以**"借""贷"作为记账符号**，反映各项会计要素增减变动情况的一种记账方法。

| 项目 | 内容 |
|---|---|
| **账户基本结构** | **左方为借方，右方为贷方** |
| 资产类账户 | 借方记增加，贷方记减少，**余额在借方** |
| 负债、所有者权益类账户 | **增加记贷方、减少记借方**，余额一般在贷方 |
| **记账规则** | **有借必有贷，借贷必相等** |
| **试算平衡方法** | **发生额试算平衡法**和**余额试算平衡法**，要求都是**借贷平衡** |

**（3）两种试算平衡公式**：

| 方法 | 公式 |
|---|---|
| **发生额试算平衡法** | **全部账户本期借方发生额合计 = 全部账户本期贷方发生额合计** |
| **余额试算平衡法** | **全部账户的借方期初余额合计 = 全部账户的贷方期初余额合计**；<br>**全部账户的借方期末余额合计 = 全部账户的贷方期末余额合计** |

> 试算平衡是通过**编制总分类账户试算平衡表**进行的。

**逻辑链**：

```
每一项经济业务
   ↓ 以相等金额，同时记入两个或两个以上账户（复式记账）
借方账户 ←── 有借必有贷 ──→ 贷方账户
   └──────── 借贷必相等 ────────┘
   ↓
全部账户加总：借方发生额合计 = 贷方发生额合计  （发生额试算平衡）
全部账户加总：借方余额合计   = 贷方余额合计    （余额试算平衡）
```

**速记口诀**：**"有借必有贷，借贷必相等；两边一对账，合计必平衡。"**

### 考点9 填制和审核凭证 ★★★

| 项目 | 内容 |
|---|---|
| **会计凭证的含义** | 记录经济业务、明确经济责任的**书面证明**，也是**登记账簿的依据** |
| **地位** | **填制和审核会计凭证是会计工作的开始** |
| **分类** | 按照填制程序和用途分为**原始凭证**和**记账凭证** |
| **原始凭证** | 经济业务**发生时取得或填制**的，证明业务发生或完成情况 |
| **记账凭证** | 根据**审核无误的原始凭证或汇总原始凭证**填制，作为**登记账簿的直接依据** |

**作用（补充）**：通过填制和审核会计凭证，可以**控制经济活动，保证会计资料真实正确，明确经济责任，为记账提供可靠依据，保证会计记录真实可靠**。

---

### 考点10 登记账簿 ★★★

| 项目 | 内容 |
|---|---|
| **账簿的含义** | 由一定格式的**账页**组成的，以**会计凭证为依据**，全面、系统、连续地记录各项经济业务的**簿籍** |
| **地位** | 设置和登记账簿是**会计工作得以开展的基础环节**，是**联结会计凭证和财务会计报告的中间环节** |
| **分类（按用途）** | **序时账簿、分类账簿和备查账簿**三类 |
| **对账要求** | 定期对账，做到**账证相符、账账相符、账实相符、账表相符** |
| **对账频率** | 对账工作**至少每年进行一次** |

**速记口诀**：**"账簿三用途：序时、分类、备查；对账四相符：证、账、实、表；一年至少对一次。"**

### 考点11 账务处理程序（会计核算组织程序）★★★★

**（1）总述**

- **含义**：账务处理程序也称**会计核算组织程序**，是指对会计数据的**记录、归类、汇总、报告**的步骤和方法。
- **基本模式**：`原始凭证 → 记账凭证 → 会计账簿 → 会计报表`
- **核心结论（必考）**：**各种账务处理程序的主要区别在于登记总分类账的依据和方法不同。**

**（2）五种主要账务处理程序对比总表**

| 账务处理程序 | 含义 | 程序链条 | 优点 | 缺点 | 适用范围 |
|---|---|---|---|---|---|
| **记账凭证账务处理程序** | 对发生的经济业务事项，都要根据原始凭证或汇总原始凭证编制记账凭证，然后**直接根据记账凭证逐笔登记总分类账**。它是**基本账务处理程序** | 原始凭证→记账凭证→总分类账 | 简单明了，易于理解，较详细地反映经济业务 | 登记总分类账的工作量较大 | 规模较小、经济业务较少的单位 |
| **汇总记账凭证账务处理程序** | 根据原始凭证或汇总原始凭证编制记账凭证，**定期根据记账凭证分类编制汇总收款凭证、汇总付款凭证和汇总转账凭证**，再根据汇总记账凭证登记总分类账 | 原始凭证→记账凭证→汇总收款/付款/转账凭证（汇总记账凭证）→总分类账 | 减轻了登记总账的工作量，**便于了解账户之间的对应关系** | 不利于会计分工，当转账凭证较多时，工作量大 | 规模较大、经济业务较多的单位 |
| **科目汇总表账务处理程序**（又称**记账凭证汇总表账务处理程序**） | 根据记账凭证**定期编制科目汇总表**，再根据科目汇总表登记总分类账 | 原始凭证→记账凭证→**科目汇总表**→总分类账 | 减轻了登记总账的工作量，并可做到**试算平衡** | **不能反映账户对应关系**，不利于查对账目 | 经济业务较多的单位（另一版本表述为"经济业务较多、使用会计科目较少的单位"） |
| **多栏式日记账账务处理程序** | 根据收款凭证和付款凭证**逐日登记多栏式现金日记账和多栏式银行存款日记账**，然后根据它们登记总分类账 | 收款凭证和付款凭证→多栏式日记账→总分类账 | 可减少登记总分类账的工作量 | 若经济业务多，会造成日记账栏目过多、账页庞大、**容易串行串栏**、不便于登记 | 规模大、经济业务量多，但**使用会计科目较少**的单位 |
| **日记总账账务处理程序** | 将日记账和总分类账**结合起来，设置一本联合的账簿，称为日记总账**，所有经济业务都登记在日记总账上 | 日记账＋总分类账→日记总账 | 简单易行 | 所有科目都设在一张账页内，导致账页过长，不便于记账和查阅 | 经济业务量少，使用会计科目也较少的单位 |

> **适用范围版本冲突提示**：科目汇总表账务处理程序的适用范围，一版素材作"经济业务较多的单位"，另一版作"经济业务较多、使用会计科目较少的单位"，考试以教材原文为准，此处两说并列。

**记忆抓手**：五种程序的差别只在"**中间那张表是什么**"——记账凭证（直接）、汇总记账凭证、科目汇总表、多栏式日记账、日记总账。

---

### 考点12 财务会计报告的概念 ★★

**核心概念**：财务会计报告（财务报告）是指企业**对外提供**的，反映企业在**某一特定日期财务状况**和**某一会计期间经营成果、现金流量**等会计信息的文件。

**关键拆解**：财务状况对应"某一特定**日期**"（时点），经营成果、现金流量对应"某一会计**期间**"（时期）。

---

### 考点13 财务会计报告的内容 ★★

- 会计报告包括**会计报表、会计报表附注**和**其他应当在会计报告中披露的相关信息和资料**三部分。
- 我国企业对外提供的会计报表包括：**资产负债表、利润表、现金流量表**、资产减值准备明细表、利润分配表、股东权益增减变动表、分部报表和其他附表等。
- 我国企业对外提供的会计报表**至少应当包括资产负债表、利润表、现金流量表**。
- **小企业编制的会计报表可以不包括现金流量表**（高频判断题陷阱）。

---

### 考点14 会计报表的分类 ★★★

| 分类依据 | 类别 |
|---|---|
| 按照会计报表所反映的**经济内容**不同 | ①反映**财务状况**的报表（资产负债表）②反映**经营成果**的报表（利润表）③反映**现金流量**的报表（现金流量表） |
| 按照会计报表**报送对象**不同 | ①**对外**会计报表：种类、格式和编制方法由**财政部统一规定**②**对内**会计报表：根据企业内部需要**自行规定、自行设计** |
| 按照会计报表**编报主体**不同 | ①**个别**会计报表 ②**合并**会计报表 |
| 按照会计报表**编制的时间范围**不同 | ①**年度**会计报表 ②**季度**会计报表 ③**月份**会计报表 |

**合并会计报表（常考定义）**：企业**对外投资总额占被投资企业的资本总额 50% 以上**的情况下，将被投资企业和本企业**视为一个整体**，将其有关经济指标与本企业的数字**合并**而编制的会计报表。

**速记口诀**：**"内容分财、利、现；对象分内、外；主体分个、合；时间分年、季、月。"**

| # | 常见错误说法 | 正解 |
|---|---|---|
| 1 | 会计记录的方法只有三种 | ✗ 是**四项**：设置账户、复式记账、填制和审核凭证、**登记账簿** |
| 2 | 划分会计期间是会计记录的方法 | ✗ 属会计基本前提（会计分期） |
| 3 | 记账凭证是会计记录的方法 | ✗ 记账凭证是**会计凭证**的一种；方法指的是"**复式记账**" |

| 9 | 科目汇总表账务处理程序能反映账户对应关系 | ✗ **不能**反映账户对应关系；能反映的是**汇总记账凭证**账务处理程序 |

## 四、公式与计算（本章计算题重点）

> **说明**：以下公式全部出自本章素材原文；三道例题的**数字为本书为演示公式而设的示例**（素材原文未给数字题），演算过程严格按素材公式书写，帮助理解试算平衡的验算逻辑。

### 公式清单

| 编号 | 公式 | 适用场景 |
|---|---|---|
| **公式1** | 期末余额 = 期初余额 + 本期增加发生额 − 本期减少发生额 | 账户结构基本关系（通用） |
| **公式2** | 期末余额 = 期初余额 + **本期借方发生额** − **本期贷方发生额** | **资产、成本、费用类**账户 |
| **公式3** | 期末余额 = 期初余额 + **本期贷方发生额** − **本期借方发生额** | **负债、所有者权益、收入类**账户 |
| **公式4** | **全部账户本期借方发生额合计 = 全部账户本期贷方发生额合计** | 发生额试算平衡法 |
| **公式5** | 全部账户借方期初余额合计 = 全部账户贷方期初余额合计<br>全部账户借方期末余额合计 = 全部账户贷方期末余额合计 | 余额试算平衡法 |
| **公式6** | 每一笔分录：**借方金额 = 贷方金额** | 有借必有贷，借贷必相等 |

### 例题1 发生额试算平衡法

**题目**：某企业本月发生下列四笔经济业务，试算本月全部账户借方发生额合计与贷方发生额合计是否平衡。

1. 收到投资者投入货币资金 200,000 元，存入银行；
2. 用银行存款 50,000 元购入设备一台；
3. 从银行取得短期借款 80,000 元，存入银行；
4. 用银行存款偿还前欠货款 30,000 元。

**第一步：编制会计分录（有借必有贷，借贷必相等）**

```
① 借：银行存款        200,000
     贷：实收资本              200,000
② 借：固定资产         50,000
     贷：银行存款               50,000
③ 借：银行存款         80,000
     贷：短期借款               80,000
④ 借：应付账款         30,000
     贷：银行存款               30,000
```

**第二步：汇总各账户本期发生额**

| 账户 | 借方发生额 | 贷方发生额 |
|---|---|---|
| 银行存款 | 200,000＋80,000 ＝ **280,000** | 50,000＋30,000 ＝ **80,000** |
| 固定资产 | 50,000 | —— |
| 实收资本 | —— | 200,000 |
| 短期借款 | —— | 80,000 |
| 应付账款 | 30,000 | —— |
| **合计** | **360,000** | **360,000** |

**第三步：代入公式4验算**

```
全部账户本期借方发生额合计 = 200,000 + 50,000 + 80,000 + 30,000 = 360,000（元）
全部账户本期贷方发生额合计 = 200,000 + 50,000 + 80,000 + 30,000 = 360,000（元）
360,000 = 360,000  →  借贷平衡，试算通过 ✔
```

### 例题2 余额试算平衡法

**题目**：承例题1，已知有关账户期初余额如下，计算各账户期末余额并作余额试算平衡。

| 账户 | 期初余额 | 方向 |
|---|---|---|
| 银行存款 | 120,000 | 借方 |
| 固定资产 | 380,000 | 借方 |
| 实收资本 | 400,000 | 贷方 |
| 应付账款 | 100,000 | 贷方 |
| 短期借款 | 0 | —— |

**第一步：资产类账户用公式2（借增贷减）**

```
银行存款期末余额 = 120,000 + 280,000 − 80,000 = 320,000（元，借方）
固定资产期末余额 = 380,000 +  50,000 −   0   = 430,000（元，借方）
```

**第二步：负债及所有者权益类账户用公式3（贷增借减）**

```
实收资本期末余额 = 400,000 + 200,000 − 0    = 600,000（元，贷方）
短期借款期末余额 =       0 +  80,000 − 0    =  80,000（元，贷方）
应付账款期末余额 = 100,000 +      0 − 30,000 =  70,000（元，贷方）
```

**第三步：余额试算平衡验算**

```
期初：借方余额合计 = 120,000 + 380,000 = 500,000
      贷方余额合计 = 400,000 + 100,000 = 500,000   → 500,000 = 500,000 ✔

期末：借方余额合计 = 320,000 + 430,000 = 750,000
      贷方余额合计 = 600,000 +  80,000 + 70,000 = 750,000
      → 750,000 = 750,000 ✔  余额试算平衡通过
```

**第四步：交叉验证（会计等式）**

```
资产      = 320,000 + 430,000 = 750,000
负债+权益 = 80,000 + 70,000 + 600,000 = 750,000
左右相等，说明记录无误。
```

### 例题3 账户对应关系与会计分录编制

**账户对应关系**：采用借贷记账法登记每项经济业务时，在有关账户之间形成的**应借、应贷的相互对应关系**；存在对应关系的账户互称**对应账户**。它决定了一笔业务"钱从哪来、到哪去"。

**题目**：根据下列业务编制会计分录，并指出账户对应关系。

| 业务 | 会计分录 | 账户对应关系 |
|---|---|---|
| 从银行提取现金 5,000 元备用 | 借：库存现金 5,000<br>贷：银行存款 5,000 | 库存现金 ←→ 银行存款（**一借一贷**） |
| 购买原材料 10,000 元，货款未付 | 借：原材料 10,000<br>贷：应付账款 10,000 | 原材料 ←→ 应付账款（**一借一贷**） |
| 购买原材料 10,000 元，其中 6,000 元以银行存款支付，4,000 元暂欠 | 借：原材料 10,000<br>贷：银行存款 6,000<br>　　 应付账款 4,000 | 原材料 ←→ 银行存款、应付账款（**一借多贷**） |
| 销售产品取得货款 30,000 元，其中 20,000 元收存银行，10,000 元尚未收到 | 借：银行存款 20,000<br>　　 应收账款 10,000<br>贷：主营业务收入 30,000 | 银行存款、应收账款 ←→ 主营业务收入（**多借一贷**） |

**验算（公式6：每笔分录借方金额=贷方金额）**

```
业务三：借方 10,000 = 贷方 6,000 + 4,000 = 10,000 ✔
业务四：借方 20,000 + 10,000 = 30,000 = 贷方 30,000 ✔
```

> **考点提示**：**汇总记账凭证账务处理程序便于了解账户之间的对应关系**；而**科目汇总表账务处理程序不能反映账户对应关系**，不利于查对账目——这是两种程序最核心的辨析点。

## 五、高频考点速记卡

1. **Q：什么是会计确认？**
   A：会计数据进入会计系统时确定如何进行记录的过程，即将某一会计事项作为资产、负债、所有者权益、收入、费用或利润等会计要素正式列入会计报表的过程。

2. **Q：会计确认主要解决哪三个问题？**
   A：①是否需要进行确认；②应在何时进行确认；③应确认为哪个会计要素。顺序为"要不要→何时→哪项"。

3. **Q：会计确认的三项一般标准？**
   A：①项目由经济业务活动产生且交易性质符合会计要素要求；②未来经济利益流入或流出的不确定性能明确评估；③有可计量属性并能可靠计量。

4. **Q：什么构成了确认收入和费用的基础？**
   A：**权责发生制**，并进一步构成资产和负债的确认基础。

5. **Q：会计计量的地位与构成？**
   A：计量问题是会计的**核心问题**，贯穿确认、记录到报告全过程；由**计量单位**（主要是货币量度，辅以实物量度）和**计量属性**两方面构成。

6. **Q：五种会计计量属性？**
   A：历史成本、重置成本、可变现净值、现值、公允价值。

7. **Q：企业对会计要素计量一般应当采用什么？**
   A：**历史成本**。采用其他四种计量的，应保证金额能够取得并可靠计量。

8. **Q：重置成本与公允价值如何区分？**
   A：重置成本＝按当前市场条件**重新取得**相同或功能相当的资产需支付的现金或现金等价物；公允价值＝**公平交易**中熟悉情况的交易双方**自愿**进行资产交换或债务清偿的金额。

9. **Q：会计记录的定义？**
   A：通过账户、会计凭证和账簿等载体，运用复式记账等手段，对确认和计量的结果进行记录，为编制财务会计报告积累数据的过程。

10. **Q：会计记录的方法包括哪几项？**
    A：设置账户、复式记账、填制和审核凭证、登记账簿（共四项）。"划分会计期间"不属于。

11. **Q：账户如何分类？**
    A：按反映会计要素的具体内容分为资产类、负债类、所有者权益类、成本类和损益类（损益类又分收入类和费用类）；按提供信息详细程度分为总分类账户和明细分类账户。

12. **Q：账户结构的基本关系？哪类账户借方登记增加额？**
    A：期末余额＝期初余额＋本期增加发生额－本期减少发生额。**资产、成本、费用类**借方登记增加额。

13. **Q：负债、所有者权益、收入类账户的登记规则与余额公式？**
    A：贷方登记增加额、借方登记减少额，余额一般在贷方；期末余额＝期初余额＋本期贷方发生额－本期借方发生额。

14. **Q：复式记账的含义？主要的复式记账法有哪几种？**
    A：对每一项经济业务都以相等金额同时计入两个或两个以上有关账户。主要有借贷记账法、收付记账法、增减记账法；其中借贷记账法被普遍接受并广泛使用。

15. **Q：借贷记账法的记账规则？**
    A：**有借必有贷，借贷必相等。**

16. **Q：试算平衡有哪两种方法？公式分别是什么？**
    A：①发生额试算平衡法：全部账户本期借方发生额合计＝全部账户本期贷方发生额合计；②余额试算平衡法：全部账户借方期初余额合计＝全部账户贷方期初余额合计，全部账户借方期末余额合计＝全部账户贷方期末余额合计。

17. **Q：会计凭证如何分类？各自定义与地位？**
    A：按填制程序和用途分原始凭证和记账凭证。原始凭证是经济业务发生时取得或填制的，证明业务发生或完成情况；记账凭证根据审核无误的原始凭证或汇总原始凭证填制，是登记账簿的直接依据。填制和审核会计凭证是**会计工作的开始**。

18. **Q：账簿按用途分几类？登记账簿的地位与对账要求？**
    A：按用途分序时账簿、分类账簿和备查账簿三类。登记账簿是会计工作得以开展的基础环节、联结会计凭证和财务会计报告的中间环节；对账做到账证相符、账账相符、账实相符、账表相符，至少每年进行一次。

19. **Q：账务处理程序的含义、基本模式与主要区别？**
    A：又称会计核算组织程序，是对会计数据的记录、归类、汇总、报告的步骤和方法；基本模式为原始凭证→记账凭证→会计账簿→会计报表。各种程序的主要区别在于**登记总分类账的依据和方法不同**。

20. **Q：我国各经济单位通常采用的主要账务处理程序有哪五种？哪一种是基本程序？**
    A：记账凭证账务处理程序、汇总记账凭证账务处理程序、科目汇总表账务处理程序、多栏式日记账账务处理程序、日记总账账务处理程序。其中**记账凭证账务处理程序**是基本账务处理程序，直接根据记账凭证逐笔登记总分类账。

21. **Q：科目汇总表与汇总记账凭证账务处理程序的核心区别？**
    A：汇总记账凭证程序**便于了解账户之间的对应关系**；科目汇总表程序可做到试算平衡，但**不能反映账户对应关系**，不利于查对账目。

22. **Q：多栏式日记账账务处理程序适用于什么单位？**
    A：规模大、经济业务量多，但**使用会计科目较少**的单位。

23. **Q：财务会计报告的概念与内容？**
    A：企业对外提供的反映企业在某一特定日期财务状况和某一会计期间经营成果、现金流量等会计信息的文件；包括会计报表、会计报表附注和其他应当在会计报告中披露的相关信息和资料。

24. **Q：会计报表有哪四种分类依据？对外报表由谁规定？**
    A：反映的经济内容、报送对象、编报主体、编制的时间范围。**对外**会计报表的种类、格式和编制方法由**财政部**统一规定；对内报表由企业自行规定、自行设计。

25. **Q：什么是合并会计报表？小企业报表有何特殊规定？**
    A：合并会计报表指企业对外投资总额占被投资企业资本总额 **50% 以上**时，将被投资企业和本企业视为一个整体而合并编制的报表。小企业编制的会计报表**可以不包括现金流量表**。

### （二）素材经典例题（无年份标签，按素材原样收录）

**2.【单选】** 企业在对会计要素进行计量时一般应当采用（　）计量。
A. 历史成本　B. 现值　C. 重置成本　D. 公允价值

**答案：A**

**3.【单选】** 在公平交易时，熟悉情况的交易双方自愿进行资产交换或债务清偿的金额称为（　）。

**答案：B**
**解析**：公允价值是指在公平交易中，熟悉情况的交易双方自愿进行资产交换或者债务清偿的金额。

**4.【多选】** 会计确认主要解决的问题包括（　）。

B. 确定一项经济业务的货币金额
C. 确定某一经济业务应在何时进行确认
D. 确定某一经济业务应确认为哪个会计要素
E. 为编制财务报告积累数据

**答案：ACD**
**解析**：会计确认主要解决三个问题：一是确定某一经济业务是否需要进行确认；二是确定该业务应在何时确认；三是确定该业务应确认为哪个会计要素。B 是会计计量要解决的问题，E 是会计记录的目的。

**答案：BCDE**

**7.【单选】** 账户结构的基本关系是（　）。

**8.【单选】** 负债类账户的发生额与余额之间的关系是（　）。
A. 期初余额+本期贷方发生额=期末余额
B. 期初余额+本期借方发生额－本期贷方发生额=期末余额
C. 期初余额+本期借方发生额=期末余额

**9.【多选】** 在借贷记账法下，经济业务发生时借方登记增加额的账户有（　）。
A. 负债类账户　B. 收入类账户　C. 资产类账户　D. 所有者权益类账户　E. 费用类账户

**答案：CE**
**解析**：资产、成本、费用类账户，借方登记增加额；负债、所有者权益、收入类账户，贷方登记增加额。

**10.【单选】** 下列会计账户类别中，应在借方登记增加额的是（　）账户。
A. 负债类　B. 收入类　C. 所有者权益类　D. 资产类

**答案：D**
**解析**：资产、成本、费用类账户借方登记增加额；负债、所有者权益、收入类账户贷方登记增加额。

**11.【多选】** 借贷记账法的记账规则包括（　）。
A. 有借必有贷，借贷必相等
B. 全部账户本期借方发生额合计=全部账户本期贷方发生额合计
C. 全部账户期末借方余额合计=全部账户期末贷方余额合计
D. 资产账户余额合计=负债账户余额合计
E. 收入账户本期发生额合计=费用账户本期发生额合计

**答案：ABC**
**解析**：记账规则为"有借必有贷，借贷必相等"，并由此形成发生额试算平衡（全部账户本期借方发生额合计＝贷方发生额合计）和余额试算平衡（借方余额合计＝贷方余额合计）。D、E 均非借贷记账法规则。

**12.【单选】** 关于借贷记账法的说法，正确的是（　）。
A. 账户借方登记增加额，贷方登记减少额，余额在借方
B. 一个企业的全部借方账户与全部贷方账户相对应
C. 从单个账户看，借方发生额等于贷方发生额
D. 一个企业全部账户本期借方发生额合计等于全部账户本期贷方发生额合计

**答案：D**
**解析**：只有资产、成本、费用类账户才是借方记增加、贷方记减少；试算平衡是**全部账户合计**相等，不是单个账户相等，也不是"全部借方账户与全部贷方账户相对应"这种表述。

**13.【单选】** 下列账户记录方法中，符合负债类账户记账规则的是（　）。
A. 增加记借方　B. 增加记贷方　C. 减少记贷方　D. 期末无余额

**答案：B**
**解析**：负债与所有者权益类账户增加记贷方，资产类账户增加记借方。

**14.【多选】** 关于借贷记账法的说法，正确的有（　）。
A. 有借必有贷，借贷必相等
B. 资产账户余额合计等于负债账户余额合计
C. 全部账户本期借方发生额合计等于全部账户本期贷方发生额合计
D. 全部账户借方期末余额合计等于全部账户贷方期末余额合计
E. 收入账户本期发生额合计等于费用账户本期发生额合计

**答案：ACD**
**解析**：同第 11 题。B 把"全部账户借方余额合计＝全部账户贷方余额合计"偷换成"资产＝负债"；E 无此规则。

**15.【单选】** 在会计账务处理中，对发生的经济业务事项都要根据原始凭证或汇总原始凭证编制记账凭证，然后直接根据记账凭证逐笔登记总分类账。这种账务处理程序是（　）。
A. 记账凭证账务处理程序
B. 汇总记账凭证账务处理程序
C. 科目汇总表账务处理程序
D. 日记总账账务处理程序

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把会计确认的三个问题记成"两个"或顺序颠倒 | **要不要→何时→哪项**，顺序固定：先判断是否确认，再判断时点，最后判断要素 |
| 2 | 把"确定一项经济业务的货币金额"算作会计确认的问题 | 那是**会计计量**的事；确认只问"要不要、何时、哪项" |
| 3 | 漏掉权责发生制的地位表述 | **权责发生制是确认收入和费用的基础**，并进一步构成资产和负债的确认基础 |
| 4 | 认为会计计量有六种、七种属性 | 只有**五种**：历史成本、重置成本、可变现净值、现值、公允价值 |
| 5 | 以为会计要素计量必须用历史成本，其他属性都不能用 | **一般应当采用历史成本**；其他四种在"能够取得并可靠计量"前提下可以采用 |
| 6 | 把重置成本和历史成本混淆 | 重置＝**重新取得**（现在再买一个）；历史＝**当初实际发生**（当初花了多少） |
| 7 | 把可变现净值和公允价值混淆 | 可变现净值＝估计售价**减去**成本费用税；公允价值＝公平交易中**自愿**交换的金额 |
| 8 | 会计记录的方法漏选"登记账簿" | 共**四项**：设置账户、复式记账、填制和审核凭证、登记账簿。口诀"3账1证" |
| 9 | 把"划分会计期间"当成会计记录的方法 | 划分会计期间是**会计基本前提/会计分期**，与记录方法无关 |
| 10 | 账户分类漏掉"成本类"或"损益类" | 资产、负债、所有者权益、**成本**、**损益**（损益又分收入和费用），共五类 |
| 11 | 记错各类账户的借贷方向 | **资产、成本、费用＝借方派（借增贷减）；负债、所有者权益、收入＝贷方派（贷增借减）** |
| 12 | 把收入类账户归入"借方登记增加额" | 收入类与负债、所有者权益同类，**贷方登记增加额**，这是多选题高频陷阱 |
| 13 | 认为单个账户借方发生额等于贷方发生额 | 试算平衡是**全部账户合计**相等；单个账户本期发生额通常不相等 |
| 14 | 把余额试算平衡写成"资产余额合计=负债余额合计" | 正确表述是**全部账户借方余额合计＝全部账户贷方余额合计**（含权益，是全额平衡） |
| 15 | 忘记余额试算平衡有两个等式 | 期初一个、期末一个，**两个都要写** |
| 16 | 混淆五种账务处理程序的适用范围 | 记"中间那张表"：记账凭证（小规模）／汇总记账凭证（大规模）／科目汇总表（业务多）／多栏式日记账（科目少）／日记总账（业务少、科目少） |
| 17 | 认为科目汇总表能反映账户对应关系 | **不能**。能反映对应关系的是**汇总记账凭证**账务处理程序，这是两者的核心区别 |
| 18 | 把多栏式日记账的适用范围记成"会计科目多的单位" | 恰恰相反，是**使用会计科目较少**的单位；科目多了日记账栏目过多、账页庞大、容易串行串栏 |
| 19 | 漏掉第五种账务处理程序 | 除四种常见程序外还有**日记总账账务处理程序**，共**五种** |
| 20 | 把"填制和审核凭证是会计工作的开始"记成"登记账簿是开始" | **凭证是开始**，账簿是**中间环节**（联结凭证与报告） |
| 21 | 账簿按用途分类漏掉"备查账簿" | **序时账簿、分类账簿、备查账簿**三类，备查最易漏 |
| 22 | 对账"四相符"漏掉"账表相符" | 账**证**、账**账**、账**实**、账**表**，四个字：证账实表 |
| 23 | 把对内会计报表的制定主体记成财政部 | **对外**报表由财政部统一规定；**对内**报表由企业自行规定、自行设计 |
| 24 | 认为小企业会计报表必须编制现金流量表 | 小企业**可以不包**现金流量表（判断题常考） |
| 25 | 合并会计报表的投资比例记错 | 对外投资总额占被投资企业资本总额 **50% 以上** |
