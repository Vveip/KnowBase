## 二、知识点精讲

### 考点1 时间序列的含义及构成基本因素 ★

**核心概念**

| 项目 | 内容 |
|---|---|
| **含义** | 时间序列也称**动态数列**，是将某一统计指标在各个不同时间上的数值，**按时间先后顺序编制**形成的序列 |
| **构成因素（1）** | 被研究现象所属**时间** |
| **构成因素（2）** | 反映该现象在一定时间条件下数量特征的**指标值** |

**注意**：同一时间序列中，各指标值的**时间单位一般要求相等**。

```
时间序列 = 时间（被研究现象所属时间）
         + 指标值（反映现象一定时间条件下数量特征的数值）
   ↓ 按时间先后顺序排列，所以也叫「动态数列」
   ↓ 后续一切分析（水平分析/速度分析）都以这两个要素为基础
```

**速记口诀**：**「一时一值」**——时间加指标值，顺序不能乱。

---

### 考点2 时间序列的分类 ★★★（本章最高频辨析点）

按照构成要素中**统计指标值的表现形式**，分为四种：

| 类型 | 指标值及内容 | 示例 |
|---|---|---|
| **绝对数时间序列** | **时期序列**：每一指标值反映现象在一段时期内发展的结果，即**「过程总量」**【说明】时期数通常可以累积，从而得到更长时期内的总量 | 国内生产总值、产品产量、财政收入、商品零售额 |
| | **时点序列**：每一指标值反映现象在一定时点上的**「瞬间水平」**【提示】时点数通常**不能累积**，各时点数累积后没有实际意义 | 年底人口总数、库存量、股票价格 |
| **相对数时间序列** | 统计指标值是**两个绝对数之比** | 城镇人口比重、经济增长率 |
| **平均数时间序列** | 统计指标值是**平均数或均值** | 人均国内生产总值、人均利润 |

**最强对比：时期序列 vs 时点序列（选择命题眼）**

| 维度 | 时期序列 | 时点序列 |
|---|---|---|
| 反映内容 | 一段时期内发展的**结果**（过程总量） | 一定时点上的**瞬间水平** |
| 典型问法 | 「某年 GDP」「某年产量」「某年投资额」 | 「年底人口数」「年末员工人数」「库存量」「外汇储备余额」 |
| 能否累加 | **可以**累加，累加后有意义 | **不能**累加，累加后无实际意义 |
| 代表指标 | 国内生产总值、产品产量、财政收入、商品房销售额 | 年底总人口数、库存量、股票价格、外汇储备余额 |

```
看到指标先问一句：这个数是「一段时期攒出来的」还是「某个时点拍的快照」？
  攒出来的（流量）      → 时期序列   → 可累加
  时点拍的（存量）      → 时点序列   → 不可累加
  两个数之比            → 相对数时间序列
  平均数/均值           → 平均数时间序列
```

**速记口诀**：**「时期看总量，时点记瞬间；平均相对数，类别要分辨。」**

**高频陷阱**：城镇化率、城镇人口比重、经济增长率 → **相对数**时间序列；人均 GDP、人均生活消费支出、土地平均购置价格 → **平均数**时间序列；外汇储备余额、年末员工人数、年底人口总数 → **时点**序列；年广告支出、商品房销售面积、房地产开发企业完成投资额 → **时期**序列。

### 考点3 发展水平 ★★

发展水平是时间序列中对应于具体时间的指标数值。具体分为六个：

| 序号 | 名称 | 定义 |
|---|---|---|
| 1 | **发展水平** | 时间序列中对应于具体时间的指标数值 |
| 2 | **最初水平** | 序列中**第一项**的指标值（常用 y₀ 或 y₁ 表示） |
| 3 | **最末水平** | 序列中**最末项**的指标值（常用 yₙ 表示） |
| 4 | **中间水平** | 处于第一项和最末项二者之间的各期指标值 |
| 5 | **基期水平** | 作为对比的**基础时期**的水平 |
| 6 | **报告期水平** | 所要反映与研究的**那一时期**的水平 |

```
y₀（最初水平）→ y₁ → y₂ → … → yₙ（最末水平）
                    ↑ 中间水平
        y₀ = 基期水平（对比的基准）
        yᵢ = 报告期水平（被研究、被反映的那一期）
```

**速记口诀**：**「首最初、尾最末、中间夹着基期和报告期」**——基期是被比的，报告期是主比的。

### 考点4 平均发展水平 ★★（全书计算最密集的考点）

**核心概念**：平均发展水平也称**序时平均数**或**动态平均数**，是对时间序列中各时期发展水平计算的平均数，可以概括性描述现象在一段时期内所达到的**一般水平**。**时间序列类型不同，计算方法也不同。**

**算法总表（必须形成条件反射）**

| 序列类型 | 细分情形 | 计算方法 | 权数/说明 |
|---|---|---|---|
| **绝对数时间序列** | **时期序列** | **简单算术平均数** | n 为时期序列的项数 |
| | **时点序列** → **连续时点** | ① 资料**逐日登记且逐日排列** | **简单算术平均数** | —— |
| | | ② 资料登记的时间单位仍是 1 天，但**只在指标值发生变动时才记录一次** | **加权算术平均数** | 权数 = 每一指标值的**持续天数** |
| | **时点序列** → **间断时点** | ③ **间隔相等** | 「**两次平均**」：**两次都是简单算术平均** | 先求各时间间隔内的简单算术平均数，再对这些平均数简单算术平均 |
| | | ④ **间隔不等** | 「**两次平均**」：**一次简单算术平均，一次加权算术平均** | 权数 = **间隔长度** |
| **相对数或平均数时间序列** | 派生数列 | **序时平均数 ÷ 序时平均数**（先分别求分子、分母序列的序时平均数，再对比） | **不能**就序列中的相对数/平均数直接平均 |

**关键判别路径（做题第一步）**

```
拿到「求平均发展水平」的题，先判断序列类型：
  绝对数？
    ├─ 时期序列 ────────────────→ 简单算术平均（直接加总 ÷ 项数）
    └─ 时点序列
         ├─ 连续时点（逐日登记）
         │    ├─ 逐日排列 ──────→ 简单算术平均
         │    └─ 有变化才记 ────→ 加权算术平均（权数=持续天数）
         └─ 间断时点（隔一段登记一次）
              ├─ 间隔相等 ──────→ 两次平均（两次简单算术平均）
              └─ 间隔不等 ──────→ 两次平均（一次简单算术平均，一次加权算术平均，权数=间隔长度）
  相对数或平均数？
    └─ 先算分子的序时平均数，再算分母的序时平均数，最后相除
```

**相对数/平均数时间序列计算三句话**：

1. 相对数或平均数时间序列是**派生数列**，通常由两个绝对数对比形成；
2. **不能**就序列中的相对数或平均数直接进行平均计算；
3. 正确做法：分别求出**分子指标**和**分母指标**时间序列的序时平均数，然后再进行对比。

**速记口诀**：**「时期直接除项数；连续时点看登记，逐日用简单、变动用加权；间断时点两次平均，等距两次简单、不等一次加权；相对平均数，分子分母分别算。」**

### 考点5 增长量与平均增长量 ★★

**1. 增长量**

| 项目 | 内容 |
|---|---|
| **含义** | 报告期发展水平与基期发展水平**之差**，反映报告期比基期**增加（减少）的绝对数量** |
| **基本公式** | **增长量 = 报告期水平 − 基期水平** |
| **分类依据** | 根据基期确定方法的不同，分为**逐期增长量**和**累计增长量** |

| 类型 | 公式 | 对比基准 |
|---|---|---|
| **逐期增长量** | 报告期水平 **−** 前一期水平 | 前一时期 |
| **累计增长量** | 报告期水平 **−** 某一固定时期水平（通常是最初水平） | 固定时期 |

**核心关系（必考）**：**同一时间序列中，累计增长量 = 相应时期逐期增长量之和**。

```
销售额：y₀=1 → y₁=2 → y₂=6 → y₃=9 → y₄=10
逐期增长量：(2-1)=1、(6-2)=4、(9-6)=3、(10-9)=1
累计增长量（以 y₀=1 为基准）：(10-1)=9
验证：1+4+3+1 = 9 = 累计增长量 ✔
```

**2. 平均增长量**

| 项目 | 内容 |
|---|---|
| **含义** | 时间序列中**逐期增长量的序时平均数**，表明现象在一定时段内**平均每期**增加（减少）的数量 |
| **公式（两式等价）** | 平均增长量 = 逐期增长量的合计 ÷ 逐期增长量的个数 = **累计增长量 ÷（时间序列项数 − 1）** |

**速记口诀**：**「逐期比上期，累计比初期；累计逐期加，平均逐期均。」**

### 考点6 发展速度与增长速度 ★★（本章计算核心）

**一、发展速度**

| 项目 | 内容 |
|---|---|
| **含义** | 以**相对数**形式表示的两个不同时期发展水平的**比值**，表明报告期水平已发展到基期水平的**几分之几或若干倍** |
| **公式** | **发展速度 = 报告期水平 ÷ 基期水平** |

| 类型 | 含义 | 计算公式 |
|---|---|---|
| **定基发展速度** | 报告期水平与**某一固定时期水平**（通常是最初水平 y₀）的比值 | yᵢ / y₀ |
| **环比发展速度** | 报告期水平与其**前一期水平**的比值 | yᵢ / yᵢ₋₁ |

**定基与环比的两条铁律**：

1. **定基发展速度 = 相应时期内各环比发展速度的连乘积**（简称「定基积」）
2. **环比发展速度 = 两个相邻时期定基发展速度的比率**（简称「环比比」）

```
定基积：a₁×a₂×a₃×…×aₙ = Aₙ
       （A₁=a₁；A₂=a₁×a₂；A₃=a₁×a₂×a₃ …）
环比比：Aₙ / Aₙ₋₁ = aₙ
```

**二、增长速度**

| 项目 | 内容 |
|---|---|
| **含义** | 报告期**增长量**与**基期水平**的比值，表明报告期比基期增长了百分之几或若干倍 |
| **公式** | **增长速度 = 报告期增长量 ÷ 基期水平** |

| 类型 | 对应增长量 | 计算公式 |
|---|---|---|
| **定基增长速度** | 累计增长量 | **定基增长速度 = 定基发展速度 − 1** |
| **环比增长速度** | 逐期增长量 | **环比增长速度 = 环比发展速度 − 1** |

**速度之间的换算逻辑链（做题主线）**：

```
增长速度 ± 1 ⇄ 发展速度
  定基增长速度 + 1 = 定基发展速度
  环比增长速度 + 1 = 环比发展速度

发展速度内部：
  定基发展速度 = 各环比发展速度的连乘积
  环比发展速度 = 相邻两期定基发展速度之比

增长速度之间：★不能★像发展速度那样互相推算！
  定基增长速度 ≠ 各环比增长速度的连乘积
  相邻两期定基增长速度之比 ≠ 环比增长速度
```

**速记口诀**：**「定基环比连乘积（定基积），环比相邻定基比（环比比）」**；**「发展加一得增长，增长减一回发展」**。

### 考点7 平均发展速度与平均增长速度 ★★

**一、平均发展速度**

| 项目 | 内容 |
|---|---|
| **含义** | 反映现象在一定时期内**逐期发展变化**的一般程度，是一定时期内各期**环比发展速度的序时平均数** |
| **计算方法** | 通常采用**几何平均法**（因为各时期对比的基础不同，不能采用一般序时平均数的计算方法） |
| **公式** | 平均发展速度 = （环比发展速度连乘积）的 n 次方根 = （定基发展速度）的 n 次方根 |
| **n 的含义** | n 表示**环比发展速度的时期数**，且 **n = 时期数 − 1** |

> 【说明】几何平均数：n 个观察值连乘积的 n 次方根就是几何平均数。

**结论**：平均发展速度是**环比发展速度的连乘积的开方**，或是**定基发展速度的开方**（开「时期数 − 1」次方）。

**二、平均增长速度**

| 项目 | 内容 |
|---|---|
| **含义** | 反映现象在一定时期内逐期**增长（降低）**变化的一般程度 |
| **数量关系** | **平均增长速度 = 平均发展速度 − 1** |

**为什么平均增长速度不能直接算？**
因为平均增长速度**既不能由各期的环比增长速度求得，也不能根据一定时期的总增长速度计算**，它只能通过与平均发展速度之间的数量关系求得。

**速记口诀**：**「几何算发展，再减一是增长。」**

---

### 考点8 速度的分析与应用 ★

应用速度分析实际问题时，必须注意两点：

**1. 指标值出现 0 或负数时，不宜计算速度。**
在这种情况下，适宜**直接用绝对数进行分析**。

**2. 速度指标的数值与基数的大小有密切关系。**
在环比增长速度时间序列中，**各期的基数不同**，因此运用速度指标反映现象增长的快慢时，往往要**结合水平指标的分析**才能得出正确结论。**「增长 1% 的绝对值」**就是进行这一分析的指标——它反映**同样的增长速度，在不同时间条件下所包含的绝对水平**。

```
增长1%的绝对值 = 逐期增长量 ÷ 环比增长速度
              = (yᵢ − yᵢ₋₁) ÷ [ (yᵢ − yᵢ₋₁) / yᵢ₋₁ × 100 ] × 100
              = 报告期前一期发展水平 × 1%
```

**速记口诀**：**「有零有负不算速；速度要比配绝对，增长 1% 看前期。」**

---

### 考点9 时间序列的成分 ★★

时间序列的变化可能受一种或几种因素的影响，这种因素称为**时间序列的成分**。成分通常有四种：

| 成分 | 具体内容 |
|---|---|
| **长期趋势（T）** | 时间序列在**较长一段时间**内呈现的**持续上升或持续下降**的变动。这种趋势**可能是线性的，也可能是非线性的** |
| **季节变动（S）** | 时间序列在**一年内重复出现**的周期性波动。例如，旅游、商品销售、农业生产、交通运输等行业的生产经营中都有明显的季节变动特征 |
| **循环波动（C）** | 时间序列呈现出的**非固定长度的周期性变动**。例如，经济周期有涨落相间的交替波动，周期长短不一，无固定规律 |
| **不规则波动（I）** | 时间序列中**除去长期趋势、季节变动和循环波动之后的随机波动**。不规则波动往往是由一些偶然因素引起的，难以预测和控制，因此在时间序列预测中**通常不予单独考虑** |

**四成分最强对比**

| 成分 | 周期长度 | 方向性 | 是否可预测 |
|---|---|---|---|
| 长期趋势 T | 较长一段时间 | 持续上升 **或** 持续下降（单向） | 可测（线性/非线性） |
| 季节变动 S | **一年内**重复出现 | 周期性 | 可测 |
| 循环波动 C | **非固定长度**的周期 | 涨落相间交替 | 周期长短不一、无固定规律 |
| 不规则波动 I | 随机 | 随机 | 偶然因素引起，难以预测控制，通常不单独考虑 |

```
时间序列 Y ──分解──→ T（长期趋势）
                    ├→ S（季节变动）
                    ├→ C（循环波动）
                    └→ I（不规则波动，通常剔除不考虑）
```

**速记口诀**：**「常（长）规环节」**——长（长期趋势）、规（循环/规律性交替）、环（循环波动）、节（季节变动）。

---

### 考点10 时间序列分解模型 ★

一个时间序列可能**只包含一种成分**，也可能是由**几种成分混合**而成的。时间序列分析时经常在一定的**模型假定**下把这些成分从时间序列里分离出来，对各成分分别进行分析。不同的模型对四种成分之间关系的假定不同：

| 模型 | 假定关系 |
|---|---|
| **加法模型** | Yt = Tt + St + Ct + It |
| **乘法模型** | Yt = Tt × St × Ct × It |

---

### 考点11 时间序列的预测程序 ★

时间序列分析的一个主要目的就是**根据历史数据对未来进行预测**。步骤如下：

```
第一步：确定时间序列所包含的成分
   ↓
第二步：找出适合该时间序列的预测方法
   ↓
第三步：对可能的预测方法进行评估，以确定最佳预测方案
   ↓
第四步：利用最佳预测方案进行预测
```

**速记口诀**：**「定成分 → 找方法 → 评方案 → 做预测」**。

---

### 考点12 平滑预测法概述 ★

| 项目 | 具体内容 |
|---|---|
| **目的** | 为了「**消除**」时间序列的**不规则成分**所引起的**随机波动**，包括移动平均法和指数平滑法等 |
| **适用对象** | 适合于**平稳时间序列**的预测，即**没有明显的趋势、循环和季节波动**的时间序列 |
| **优点** | **简单易用，对数据的要求最低**，通常对于**近期（如下一期）**的预测具有较高的精度 |

> 注意：只有**平稳序列**才适合（指数）平滑预测——这是本章常考辨析。

---

### 考点13 移动平均法 ★★

**核心概念**：移动平均法使用时间数列中**最近 k 期数据值的平均数作为下一期的预测值**。

```
公式：F(t+1) = ( Y(t-k+1) + Y(t-k+2) + … + Y(t-1) + Yt ) / k
      k 为移动间隔，1 < k < t
```

**操作要点**：
- k 取多少，就往前数 k 期；
- 取的是这 k 期数据的**简单算术平均数**；
- 预测的是**下一期（t+1）**的值。

**速记口诀**：**「移动平均很简单，最近 k 期加一加，除以 k 就是下期预测值。」**

---

### 考点14 指数平滑法 ★★

**核心概念**：指数平滑法是利用过去时间序列值的**加权平均数作为预测值**，使得**第 t+1 期的预测值等于第 t 期的实际观察值与第 t 期预测值的加权平均值**。

```
公式：F(t+1) = α·Yt + (1 − α)·Ft
      F(t+1)、Ft —— 第 t+1 期、第 t 期的指数平滑预测值
      Yt         —— 第 t 期的实际观察值
      α          —— 平滑系数（即权重），取值范围 0 < α < 1
```

**特点**：观测值离预测时期**越久远，其权重也变得越小**，呈现出**指数下降**，因而称为指数平滑。

**权重分配逻辑**：

```
第 t 期实际值 Yt ──权重 α───┐
                            ├──→ F(t+1)（下一期预测值）
第 t 期预测值 Ft ─权重(1-α)─┘
α 越大 → 越看重最新实际值，预测对近期变化越敏感
α 越小 → 越看重历史预测值，预测越平滑稳定
```

**速记口诀**：**「指数平滑两件套：这期实际乘 α，这期预测乘 (1−α)，加起来就是下期预测。」**

### 附：本章六大核心辨析（极易混，务必做强对比）

#### 辨析一：定基发展速度 vs 环比发展速度

| 维度 | 定基发展速度 | 环比发展速度 |
|---|---|---|
| 对比基准 | 某一**固定时期**水平（通常是最初水平 y₀） | **前一期**水平 yᵢ₋₁ |
| 公式 | yᵢ ÷ y₀ | yᵢ ÷ yᵢ₋₁ |
| 基准是否变动 | **固定不变** | **逐期后移** |
| 换算关系 | 等于相应时期内各环比发展速度的**连乘积** | 等于两个相邻时期定基发展速度的**比率** |
| 口诀 | **「定基积」** | **「环比比」** |

> 演算：环比发展速度为 101%、102%、104% → 定基发展速度 = 101%×102%×104% ≈ **107%**；相邻两期定基发展速度为 137.4%、164.3% → 环比发展速度 = 164.3%÷137.4% ≈ **119.6%**。

#### 辨析二：定基增长速度 vs 环比增长速度

| 维度 | 定基增长速度 | 环比增长速度 |
|---|---|---|
| 对应增长量 | **累计**增长量 | **逐期**增长量 |
| 公式 | 定基发展速度 **− 1** | 环比发展速度 **− 1** |
| 能否互相推算 | **不能**——定基增长速度 ≠ 各环比增长速度的连乘积 | **不能**——相邻定基增长速度之比 ≠ 环比增长速度 |

> 演算：环比增长速度为 4%、6%、9%、10% → 定基增长速度 = **(104%×106%×109%×110%) − 1**，绝不是 4%×6%×9%×10%。
> 演算：定基增长速度为 14.40%、14.85% → **先 +1** 得定基发展速度 114.40%、114.85% → 环比**发展**速度 = 114.85%÷114.40% ≈ **100.39%**。

#### 辨析三：累计增长量 vs 逐期增长量

| 维度 | 累计增长量 | 逐期增长量 |
|---|---|---|
| 基准 | 某一固定时期水平（通常最初水平 y₀） | 前一期水平 yᵢ₋₁ |
| 公式 | yᵢ − y₀ | yᵢ − yᵢ₋₁ |
| 对应速度 | 定基增长速度 | 环比增长速度 |
| 数量关系 | **累计增长量 = 相应时期逐期增长量之和** | —— |

> 演算：销售额 1、2、6、9、10 → 逐期增长量 1、4、3、1；2018 年累计增长量 = 10−1 = **9** = 1+4+3+1 ✔

#### 辨析四：平均发展速度 vs 平均增长速度

| 维度 | 平均发展速度 | 平均增长速度 |
|---|---|---|
| 含义 | 一定时期内各期**环比发展速度的序时平均数**，反映逐期发展变化的一般程度 | 反映逐期**增长（降低）**变化的一般程度 |
| 算法 | **几何平均法**：环比发展速度连乘积（或定基发展速度）开 **n = 时期数−1** 次方 | **不能**直接用几何平均法；只能 平均发展速度 **− 1** |
| 能否由增长速度求得 | —— | **不能**——既不能由各期环比增长速度求得，也不能由总增长速度计算 |

> 演算：某市财政收入 2003 年比 1998 年增长 72.6% → 定基发展速度 172.6%，n = 5 → 平均发展速度 = ⁵√172.6% ≈ **111.5%** → 平均增长速度 ≈ **11.5%**。
> 演算：某企业年平均增长速度 27.6% → 年平均发展速度 = **127.6%**。

#### 辨析五：增长 1% 的绝对值

| 项目 | 内容 |
|---|---|
| 公式 | 增长1%的绝对值 = **逐期增长量 ÷ 环比增长速度** = **报告期前一期发展水平 × 1%** |
| 反映什么 | 同样的增长速度，在**不同时间**条件下所包含的**绝对水平** |
| 为什么需要它 | 环比增长速度序列中**各期基数不同**，速度高低不能直接比快慢，必须结合水平指标 |
| 三个「不是」 | 分母**不是**环比发展速度、**不是**定基发展速度、**不是**定基增长速度 |

> 演算：销售额 32 → 35 万元，逐期增长量 3 万元，环比增长速度 9.375% → 增长 1% 的绝对值 = 3÷9.375 = **0.32 万元** = 32×1% ✔

#### 辨析六：时点序列 vs 时期序列的平均发展水平算法

| 序列类型 | 具体情形 | 算法 | 权数 |
|---|---|---|---|
| **时期序列** | —— | 简单算术平均数 | 无 |
| **连续时点序列** | 逐日登记且逐日排列 | 简单算术平均数 | 无 |
| **连续时点序列** | 登记单位仍是 1 天，但只在指标值变动时才记录 | 加权算术平均数 | 持续天数 |
| **间断时点序列** | 间隔相等 | 两次平均：**两次简单算术平均** | 无 |
| **间断时点序列** | 间隔不等 | 两次平均：**一次简单算术平均，一次加权算术平均** | 间隔长度 |
| **相对数/平均数序列** | 派生数列 | 分子序时平均数 ÷ 分母序时平均数 | 无 |

> 一句话总结：**时期序列最简单（直接除项数）；时点序列看「连续/间断」，间断再看「间隔等/不等」，一共四种算法；相对数/平均数序列必须先分子、后分母、再相除。**

| **速度分析** | 发展速度、增长速度、**平均发展速度**、**平均增长速度** | 平均发展水平、平均增长量 |

> 记忆锚点：名称里带「**速度**」二字的一律归速度分析；「平均发展**水平**」和「平均增长**量**」是**水平**指标，虽名字里有「平均」也属水平分析。

### 表8 速度指标 ↔ 增长量指标 ↔ 基期选择 对应表

| 增长速度 | 对应的增长量 | 对应的基期 |
|---|---|---|
| 定基增长速度 | 累计增长量 | 某一固定时期（通常最初水平 y₀） |
| 环比增长速度 | 逐期增长量 | 前一期水平 yᵢ₋₁ |

> 三者必须「对号入座」：**定基—累计—固定期**；**环比—逐期—前一期**。

### 表9 「X 个不等于」避坑表（本章最锋利）

| # | 错误说法 | 正解 |
|---|---|---|
| 1 | 累计增长量 = 相应时期逐期增长量的**平均数/乘积/加权平均** | ✗ 等于**之和** |
| 2 | 平均增长量 = 累计增长量的序时平均数 | ✗ 是**逐期增长量**的序时平均数 |
| 3 | 定基增长速度 = 各环比增长速度的**连乘积** | ✗ 增长速度之间不能互相推算；只有**发展速度**可以 |
| 4 | 相邻两期定基增长速度之比 = 环比增长速度 | ✗ 不成立 |
| 5 | 定基发展速度 = 各环比增长速度的连乘积 | ✗ 是各**环比发展速度**的连乘积 |
| 6 | 平均增长速度可以用几何平均法直接算 | ✗ 几何平均法算的是**平均发展速度**；平均增长速度 = 平均发展速度 − 1 |
| 7 | 平均发展速度可以用简单算术平均法算 | ✗ 各时期对比基础不同，通常采用**几何平均法** |
| 8 | 时点序列的序时平均数可以直接用算术平均数算 | ✗ 时点序列须分连续/间断、间隔等/不等，方法各不相同 |
| 9 | 相对数时间序列的平均发展水平可以直接对相对数算 | ✗ 必须先分别求分子、分母的序时平均数再对比 |
| 10 | 连续时点序列与间断时点序列算法相同 | ✗ 完全不同 |
| 11 | 时点序列与时期序列算法相同 | ✗ 不同 |
| 12 | 平均发展速度 = 定基发展速度开「时期数」次方 | ✗ 开 **n = 时期数 − 1** 次方 |
| 13 | 平滑法适合有明显趋势、循环和季节波动的序列 | ✗ 适合**平稳时间序列**（无明显趋势、循环、季节波动） |
| 14 | 指数平滑公式是 F(t+1) = α·Ft + (1−α)·Yt | ✗ 权重位置反了，应为 F(t+1) = **α·Yt + (1−α)·Ft** |
| 15 | 序列中出现 0 或负数也能算速度 | ✗ **不宜计算速度**，宜直接用绝对数分析 |
| 16 | 「季节比率」是时间序列的成分 | ✗ 成分是**季节变动（S）**；季节比率是素材中未展开的概念 |
| 17 | 时期序列的指标值不能累加 | ✗ 时期数**通常可以累加**；不能累加的是**时点数** |

### 4.1 时间序列成分分解

**模型假定**

| 模型 | 公式 |
|---|---|
| 加法模型 | **Yt = Tt + St + Ct + It** |
| 乘法模型 | **Yt = Tt × St × Ct × It** |

**成分速查**

| 成分 | 一句话定义 |
|---|---|
| T 长期趋势 | 较长一段时间内持续上升或持续下降的变动（线性或非线性） |
| S 季节变动 | 一年内重复出现的周期性波动 |
| C 循环波动 | 非固定长度的周期性变动 |
| I 不规则波动 | 除去 T、S、C 后的随机波动，通常不单独考虑 |

> 说明：素材仅给出加法/乘法模型的**成分关系式**，**未覆盖**各成分的具体分离/测算公式（如趋势方程拟合、季节比率计算等），考纲本章不要求展开计算。

**例题 4.1（概念判别）**：某旅行社 2019—2024 年季度营业收入呈现「每年一季度高、三季度低」的规律性起伏，同时整体逐年抬升，并受突发事件影响出现无规律跳动。问：分别属于哪种成分？
- 整体逐年抬升 → **长期趋势（T）**
- 每年一季度高、三季度低 → **季节变动（S）**
- 无规律跳动 → **不规则波动（I）**

### 4.2 水平分析（一）：发展水平与平均发展水平

#### 4.2.1 时期序列的序时平均数 —— 简单算术平均法

**公式**

```
           y1 + y2 + … + yn        Σyi
ȳ = ─────────────────────── = ─────
                n                  n
   （n 为时期序列的项数）
```

**例题 4.2.1（教材例题）**：根据下表国内生产总值时间序列，计算各年度的平均国内生产总值。

| 年份 | 1991 | 1992 | 1993 | 1994 | 1995 | 1996 | 1997 |
|---|---|---|---|---|---|---|---|
| 国内生产总值（亿元） | 21618 | 26638 | 34634 | 46759 | 58478 | 67885 | 74772 |

**演算**：
```
ȳ = (21618 + 26638 + 34634 + 46759 + 58478 + 67885 + 74772) ÷ 7
  = 330784 ÷ 7
  = 47254.857（亿元）
```
**答：1991—1997 年平均国内生产总值约为 47254.86 亿元。**

**例题 4.2.1'（真题同型）**：某地区 1999～2003 年原煤产量如下表，该地区 1999～2003 年的平均每年原煤产量为（ ）万吨。

| 年份 | 1999 | 2000 | 2001 | 2002 | 2003 |
|---|---|---|---|---|---|
| 原煤产量（万吨） | 45 | 46 | 59 | 68 | 72 |

**演算**：原煤产量是**时期序列**，采用简单算术平均数：
```
ȳ = (45 + 46 + 59 + 68 + 72) ÷ 5 = 290 ÷ 5 = 58（万吨）
```
**答：58 万吨（选项 A）。**

#### 4.2.2 连续时点序列的序时平均数

**情形 A：资料逐日登记且逐日排列 → 简单算术平均数**

**公式**：`ȳ = Σyi ÷ n`

**例题 4.2.2A**：某商场 1—5 日库存量（台）分别为 20、20、22、22、22，求平均日库存量。
```
ȳ = (20 + 20 + 22 + 22 + 22) ÷ 5 = 106 ÷ 5 = 21.2（台）
```

**情形 B：资料登记时间单位仍是 1 天，但只在指标值发生变动时才记录一次 → 加权算术平均数**

**公式**：

```
        Σ (yi × fi)        y1f1 + y2f2 + … + ynfn
ȳ = ───────────────── = ───────────────────────
          Σfi                  f1 + f2 + … + fn
   fi = 每一指标值的持续天数（权数）
```

**例题 4.2.2B（教材例题）**：某种商品 6 月份的库存量记录如下，求该商品 6 月份的平均日库存量。

| 日期 | 1-4 | 5-7 | 8-13 | 14-20 | 21-23 | 24-28 | 29-30 |
|---|---|---|---|---|---|---|---|
| 持续天数（权数） | 4 | 3 | 6 | 7 | 3 | 5 | 2 |
| 库存量（台） | 49 | 52 | 39 | 29 | 43 | 38 | 51 |

**演算**：
```
ȳ = (49×4 + 52×3 + 39×6 + 29×7 + 43×3 + 38×5 + 51×2)
    ÷ (4 + 3 + 6 + 7 + 3 + 5 + 2)
  = (196 + 156 + 234 + 203 + 129 + 190 + 102) ÷ 30
  = 1210 ÷ 30
  = 40（台）
```
**答：6 月份平均日库存量为 40 台。**

**例题 4.2.2B'（真题同型）**：某超市 2013 年 6 月某商品库存记录见下表，该商品的 6 月平均日库存量是（ ）台。

| 日期 | 1～9 日 | 10～15 日 | 16～27 日 | 28～30 日 |
|---|---|---|---|---|
| 持续天数 | 9 | 6 | 12 | 3 |
| 库存量（台） | 50 | 60 | 40 | 50 |

**演算**：
```
ȳ = (50×9 + 60×6 + 40×12 + 50×3) ÷ 30
  = (450 + 360 + 480 + 150) ÷ 30
  = 1440 ÷ 30
  = 48（台）
```
**答：48 台（选项 A）。**

#### 4.2.3 间断时点序列的序时平均数

**情形 A：间隔相等 → 「两次平均」，两次都是简单算术平均**

**公式**：

```
        (y1+y2)/2 + (y2+y3)/2 + … + (y(n-1)+yn)/2
ȳ = ─────────────────────────────────────────────
                      n − 1
```

**例题 4.2.3A（教材例题）**：我国 2007—2013 年年底总人口数如下，计算 2007—2013 年平均每年总人口数。

| 年份 | 2007 | 2008 | 2009 | 2010 | 2011 | 2012 | 2013 |
|---|---|---|---|---|---|---|---|
| 年底总人口数（万人） | 132129 | 132802 | 133450 | 134091 | 134735 | 135404 | 136072 |

**演算**（本题属于**间隔相等的间断时点序列**，两次简单算术平均）：
```
第一次（相邻两年求平均）：
(132129+132802)/2 = 132465.5
(132802+133450)/2 = 133126
(133450+134091)/2 = 133770.5
(134091+134735)/2 = 134413
(134735+135404)/2 = 135069.5
(135404+136072)/2 = 135738

第二次（对各间隔平均数再简单算术平均，共 6 个间隔）：
ȳ = (132465.5 + 133126 + 133770.5 + 134413 + 135069.5 + 135738) ÷ 6
  = 804582.5 ÷ 6
  = 134097.08 ≈ 134097（万人）
```
**答：2007—2013 年平均每年总人口数约为 134097 万人。**

**情形 B：间隔不等 → 「两次平均」，一次简单算术平均、一次加权算术平均（权数为间隔长度）**

**公式**：

```
          Σ [ (yi + yi+1)/2 × fi ]
ȳ = ─────────────────────────────
                Σ fi
   fi = 相邻两个时点之间的间隔长度
```

**例题 4.2.3B（真题同型）**：某行业 2000 年至 2008 年的职工数量（年底数）记录如下，则该行业 2000 年至 2008 年平均每年职工人数为（ ）万人。

| 年份 | 2000 | 2003 | 2005 | 2008 |
|---|---|---|---|---|
| 职工人数（万人） | 1000 | 1200 | 1600 | 1400 |

**演算**（间隔分别为 3 年、2 年、3 年）：
```
第一次（各间隔内简单算术平均）：
(1000+1200)/2 = 1100
(1200+1600)/2 = 1400
(1600+1400)/2 = 1500

第二次（用间隔长度加权）：
ȳ = (1100×3 + 1400×2 + 1500×3) ÷ (3+2+3)
  = (3300 + 2800 + 4500) ÷ 8
  = 10600 ÷ 8
  = 1325（万人）
```
**答：1325 万人（选项 B）。**

#### 4.2.4 相对数或平均数时间序列的序时平均数

**公式**：

```
             ā           分子指标序列的序时平均数
c̄  =  ─────────  =  ─────────────────────────
             b̄           分母指标序列的序时平均数
```

**计算三步骤**：
1. 先求**分子指标**时间序列的序时平均数；
2. 再求**分母指标**时间序列的序时平均数；
3. 然后两者**对比**。

**例题 4.2.4（教材例题）**：计算我国 2008 年至 2013 年第三产业从业人员数占总从业人员数比重的年平均数。

我国 2008—2013 年从业人员数（年底数，间隔相等的间断时点序列）

| 年份 | 2008 | 2009 | 2010 | 2011 | 2012 | 2013 |
|---|---|---|---|---|---|---|
| 从业人员数 | 65554 | 66373 | 67199 | 67947 | 68850 | 69600 |
| 其中：第三产业人数 | 12979 | 14071 | 15456 | 16851 | 17901 | 18375 |
| 第三产业所占比重（%） | 19.80 | 21.20 | 23.00 | 24.80 | 26.00 | 26.40 |

**演算**：
```
（1）分子（第三产业从业人员数）序时平均数：
(12979+14071)/2 = 13525
(14071+15456)/2 = 14763.5
(15456+16851)/2 = 16153.5
(16851+17901)/2 = 17376
(17901+18375)/2 = 18138
ā = (13525 + 14763.5 + 16153.5 + 17376 + 18138) ÷ 5 = 79956 ÷ 5 = 15991.2

（2）分母（总从业人员数）序时平均数：
(65554+66373)/2 = 65963.5
(66373+67199)/2 = 66786
(67199+67947)/2 = 67573
(67947+68850)/2 = 68398.5
(68850+69600)/2 = 69225
b̄ = (65963.5 + 66786 + 67573 + 68398.5 + 69225) ÷ 5 = 337946 ÷ 5 = 67589.2

（3）对比：
c̄ = ā ÷ b̄ = 15991.2 ÷ 67589.2 = 23.66%
```
**答：2008—2013 年第三产业从业人员数所占比重的年平均数约为 23.66%。**

> 【多来源提示】另一版本素材给出 2018—2023 年同结构数据（从业人员数 75782、75447、75064、74652、73351、74041；第三产业 34911、35561、35806、35868、34583、35639），算法与结论形式完全一致，结果为 ā = 35418.6、b̄ = 74685.1、c̄ ≈ 47.4%。两版数据不同、算法相同，做题时任选其一练手即可。

### 4.3 水平分析（二）：增长量与平均增长量

**公式**

| 指标 | 公式 |
|---|---|
| 增长量 | 报告期水平 − 基期水平 |
| 逐期增长量 | 报告期水平 − 前一期水平 |
| 累计增长量 | 报告期水平 − 某一固定时期水平（通常是最初水平） |
| 平均增长量 | 逐期增长量的合计 ÷ 逐期增长量的个数 = 累计增长量 ÷（时间序列项数 − 1） |

**例题 4.3A（逐期与累计的关系验证）**：假设某商品 2014—2018 年销售额（万元）如下：

| 年份 | 2014 | 2015 | 2016 | 2017 | 2018 |
|---|---|---|---|---|---|
| 销售额 | 1 | 2 | 6 | 9 | 10 |

**演算**：
```
逐期增长量：
2015 年 = 2 − 1 = 1
2016 年 = 6 − 2 = 4
2017 年 = 9 − 6 = 3
2018 年 = 10 − 9 = 1

2018 年累计增长量 = 10 − 1 = 9（万元）
验证：1 + 4 + 3 + 1 = 9（万元）= 累计增长量 ✔
```
**答：2018 年累计增长量 9 万元，等于相应时期逐期增长量之和。**

**例题 4.3B（平均增长量）**：假设某商品 2014—2018 年销售额（万元）如下，该商品 2014—2018 年销售额的平均增长量为（ ）。

| 年份 | 2014 | 2015 | 2016 | 2017 | 2018 |
|---|---|---|---|---|---|
| 销售额 | 32 | 35 | 43 | 51 | 76 |

**演算**（两种算法）：
```
方法一：平均增长量 = 累计增长量 ÷（时间序列项数 − 1）
       = (76 − 32) ÷ (5 − 1) = 44 ÷ 4 = 11（万元）

方法二：平均增长量 = 逐年增长量的合计 ÷ 逐年增长量的个数
       逐年增长量：3、8、8、25，合计 44，个数 4
       = 44 ÷ 4 = 11（万元）
```
**答：平均增长量为 11（选项 B）。**

**例题 4.3C（易错警示：给的是逐期增长量，不是各期水平）**：我国 2000—2005 年不变价国内生产总值逐期增长量（亿元）如下表，我国 2000 年—2005 年期间不变价国内生产总值累计增加（ ）亿元。

| 年份 | 2000 | 2001 | 2002 | 2003 | 2004 | 2005 |
|---|---|---|---|---|---|---|
| 逐期增长量（亿元） | — | 8235.1 | 9758.6 | 11750.6 | 13005.6 | 16056.2 |

**演算**：
```
累计增长量 = 各逐期增长量之和
= 8235.1 + 9758.6 + 11750.6 + 13005.6 + 16056.2
= 58806.1（亿元）
```
**答：58806.1 亿元（选项 A）。**
> 注意：题目给出的已知条件是**逐期增长量**，而不是各年的生产总值，直接相加即可，切勿再找各年水平。

### 4.4 速度分析

#### 4.4.1 发展速度（定基 / 环比）

**公式**

| 指标 | 公式 |
|---|---|
| 发展速度 | 报告期水平 ÷ 基期水平 |
| 定基发展速度 | 报告期水平 ÷ **某一固定时期水平**（通常是最初水平 y₀） |
| 环比发展速度 | 报告期水平 ÷ **前一期水平** yᵢ₋₁ |
| 关系① | **定基发展速度 = 相应时期内各环比发展速度的连乘积** |
| 关系② | **环比发展速度 = 两个相邻时期定基发展速度的比率** |

**例题 4.4.1A（连乘积型）**：已知一个序列的环比发展速度为 101%、102%、104%，则该序列的定基发展速度为（ ）。
```
定基发展速度 = 101% × 102% × 104%
            = 1.01 × 1.02 × 1.04
            = 1.071408 ≈ 107%
```
**答：107%（选项 D）。**

**例题 4.4.1B（相邻定基之比型）**：以 2000 年为基期，我国 2002、2003 年广义货币供应量的定基发展速度分别是 137.4% 和 164.3%，则 2003 年与 2002 年相比的环比发展速度是（ ）。
```
环比发展速度 = 164.3% ÷ 137.4% = 1.19592 ≈ 119.6%
```
**答：119.6%（选项 D）。**

#### 4.4.2 增长速度（定基 / 环比）

**公式**

| 指标 | 公式 |
|---|---|
| 增长速度 | 报告期增长量 ÷ 基期水平 |
| 定基增长速度 | **定基发展速度 − 1**（对应累计增长量） |
| 环比增长速度 | **环比发展速度 − 1**（对应逐期增长量） |

**例题 4.4.2A（给的是定基增长速度，求环比发展速度）**：以 2000 年为基期，2008 年和 2009 年我国粮食总产量定基增长速度分别为 14.40% 和 14.85%。2009 年对 2008 年的环比发展速度为（ ）。
```
第一步：定基发展速度 = 定基增长速度 + 1
      2008 年：114.40%     2009 年：114.85%
第二步：环比发展速度 = 相邻两期定基发展速度之比
      114.85% ÷ 114.40% = 1.003933 ≈ 100.39%
```
**答：100.39%（选项 C）。**
> 本题最大陷阱：题目给的是**增长速度**，问的是**发展速度**，中间必须「+1」转换。

**例题 4.4.2B（给的是环比增长速度，求定基增长速度）**：已知某地区 2002—2006 年社会消费品零售总额的环比增长速度分别为 4%、6%、9%、10%，则这一时期该地区社会消费品零售总额的定基增长速度为（ ）。
```
第一步：环比发展速度 = 环比增长速度 + 1
      → 104%、106%、109%、110%
第二步：定基发展速度 = 各环比发展速度的连乘积
      → 104% × 106% × 109% × 110% = 1.3217776 ≈ 132.18%
第三步：定基增长速度 = 定基发展速度 − 1
      → (104%×106%×109%×110%) − 1 ≈ 32.18%
```
**答：（104%×106%×109%×110%）− 1（选项 C）。**

#### 4.4.3 平均发展速度 —— 几何平均法

**公式**

```
                    n √(环比发展速度连乘积)          n √(定基发展速度)
平均发展速度 = ───────────────────────────  =  ─────────────────
                                                              y0

其中 n = 环比发展速度的时期数 = 「时期数 − 1」
定基发展速度 = yn / y0 = 1 + 定基增长速度
```

**例题 4.4.3A（给的是定基增长速度）**：某市财政收入 2003 年比 1998 年增长了 72.6%，则该市 1998 年至 2003 年财政收入的平均发展速度为（ ）。
```
第一步：定基发展速度 = 1 + 定基增长速度 = 1 + 72.6% = 172.6%
第二步：n = 时期数 − 1 = 5（1998→2003 共 5 个环比发展速度）
第三步：平均发展速度 = 172.6% 的 5 次方根 ≈ 111.5%
（编者按公式推算值，素材仅给出选项形式「5√172.6%」，答案选 D）
```
**答：选项 D，即 5√172.6%（≈111.5%）。**

**例题 4.4.3B（两端水平值型）**：某市 2012 年年末常住人口为 2070 万人，2022 年年末常住人口为 2154 万人，求 2012～2022 年年末常住人口的平均增长速度。
```
第一步：定基发展速度 = 2154 ÷ 2070 = 1.04058
第二步：n = 2022 − 2012 = 10
第三步：平均发展速度 = 1.04058 的 10 次方根 ≈ 1.00399 ≈ 100.40%
第四步：平均增长速度 = 平均发展速度 − 1 ≈ 0.40%
```
**答：平均增长速度约 0.40%（对应选项 A，素材选项内容缺失，仅保留答案与解析）。**

**例题 4.4.3C（给定基发展速度，求平均发展速度）**：以 2000 年为基期，我国 2002、2003 年广义货币供应量的定基发展速度分别是 137.4% 和 164.3%，分别计算 2000—2002 年、2000—2003 年的平均发展速度。
```
2000→2002：定基发展速度 = 137.4%，n = 2
  平均发展速度 = √137.4% = √1.374 ≈ 1.172 ≈ 117.2%

2000→2003：定基发展速度 = 164.3%，n = 3
  平均发展速度 = ∛164.3% = ∛1.643 ≈ 1.180 ≈ 118.0%
```
**答：2000—2002 年平均发展速度约 117.2%，2000—2003 年平均发展速度约 118.0%。**
> 易错点：n 是**环比发展速度的时期数**，等于「末年 − 基年」。2000→2002 跨 2 个环比，开 **2 次方**；2000→2003 跨 3 个环比，开 **3 次方**。切勿按「数据项数」开方。

#### 4.4.4 平均增长速度

**公式**

```
平均增长速度 = 平均发展速度 − 1
```

**例题 4.4.4**：某企业 2000 年—2006 年销售收入的年平均增长速度是 27.6%，这期间相应的年平均发展速度是（ ）。
```
年平均发展速度 = 年平均增长速度 + 1 = 27.6% + 100% = 127.6%
```
**答：127.6%（选项 C）。**

#### 4.4.5 增长 1% 的绝对值

**公式**

```
            逐期增长量            yi − yi-1
增长1%的绝对值 = ───────────── = ───────────────────────
              环比增长速度     (yi − yi-1)/yi-1 × 100 × 100

                    = 报告期前一期发展水平 × 1%  =  yi-1 × 1%
```

**推导要点**：因为 逐期增长量 = 前一期水平 × 环比增长速度（%），所以 逐期增长量 ÷ 环比增长速度 = 前一期水平 × 1%。

**例题 4.4.5（演算）**：承例题 4.3B，某商品 2014—2018 年销售额 32、35、43、51、76（万元），计算 2015 年「增长 1% 的绝对值」。
```
2015 年逐期增长量 = 35 − 32 = 3（万元）
2015 年环比增长速度 = 3 ÷ 32 × 100% = 9.375%
增长1%的绝对值 = 3 ÷ 9.375 = 0.32（万元）
验证：前一期水平 × 1% = 32 × 1% = 0.32（万元）✔
```
**答：2015 年增长 1% 的绝对值为 0.32 万元。**
> 意义：同样是「增长 1%」，2015 年对应 0.32 万元，而若发生在销售额更高的年份，对应的绝对量就更大——所以**速度必须配合水平指标**才能得出正确结论。

### 4.5 平滑预测法

#### 4.5.1 移动平均法

**公式**

```
            Y(t-k+1) + Y(t-k+2) + … + Y(t-1) + Yt
F(t+1) = ───────────────────────────────────────
                            k

k 为移动间隔，1 < k < t
```

**例题 4.5.1（真题演算）**：某公司 2019～2023 年主要产品销售额（单位：万元）分别为 114、115、121、120 和 116，取移动间隔 K=3，用移动平均法预测 2024 年公司的主要产品销售额。
```
最近 3 期 = 2021、2022、2023 年 = 121、120、116
F(2024) = (121 + 120 + 116) ÷ 3 = 357 ÷ 3 = 119（万元）
```
**答：119 万元（选项 D）。**

**例题 4.5.1'（真题演算，含数据勘误）**：2011 年—2016 年我国工业生产者出厂价格指数分别为 106.0、98.3、98.1、98.1、98.4、98.6，选取移动间隔 K=3，应用移动平均预测法 2017 年工业生产者出厂价格指数，则预测值为（ ）。

| 年份 | 2011 | 2012 | 2013 | 2014 | 2015 | 2016 |
|---|---|---|---|---|---|---|
| 指数 | 106.0 | 98.3 | 98.1 | 98.1 | 98.4 | 98.6 |

```
最近 3 期 = 2014、2015、2016 年
按素材解析所列算式：(98.1 + 98.4 + 98.6) ÷ 3 = 97.17 ≈ 97.2
```
**答：97.2（选项 D）。**

> ⚠ **数据勘误（务必留意）**：该题素材解析原文写作「（98.1 十 **94.8** + 98.6）/3 = 97.17」。按此算式反推，2015 年数值应为 **94.8**（清洗时串行讹作 98.4），最近三期为 98.1、94.8、98.6。无论按 94.8 还是按题面 98.4 处理，命题答案均为 D（97.2）。考场上以「最近 K 期简单算术平均」这一方法为准，不必纠缠个别数字。

#### 4.5.2 指数平滑法

**公式**

```
F(t+1) = α · Yt + (1 − α) · Ft

F(t+1)、Ft —— 第 t+1 期、第 t 期的指数平滑预测值
Yt          —— 第 t 期的实际观察值
α           —— 平滑系数（即权重），取值范围 0 < α < 1
```

**例题 4.5.2（真题演算）**：时间序列中 2019 年～2023 年的指标为：455、553、258、693（素材列示不完整），根据指数平滑法预测，平滑系数 0.8。2024 年的指标值的公式为（ ）。
```
α = 0.8，则 (1 − α) = 0.2
F(2024) = α · Y(2023) + (1 − α) · F(2023)
        = 0.8 × Y(2023) + 0.2 × F(2023)
```
**答：F₂₀₂₄ = 0.8×Y₂₀₂₃ + 0.2×F₂₀₂₃（选项 B）。**
> 本题只考公式形式：**权重 α 挂在「本期实际值 Yt」上，(1−α) 挂在「本期预测值 Ft」上**，位置不能反。

## 五、高频考点速记卡

1. **Q：时间序列的两个基本构成因素？**
   A：①被研究现象所属**时间**；②反映该现象在一定时间条件下数量特征的**指标值**。同一序列中各指标值的时间单位一般要求相等。

2. **Q：时间序列按指标值表现形式分哪四种？**
   A：绝对数时间序列（再分**时期序列**和**时点序列**）、**相对数**时间序列、**平均数**时间序列。

3. **Q：区分时期序列和时点序列的关键？各自的典型指标有哪些？**
   A：时期序列反映一段时期内发展的**结果（过程总量）**，指标值**可累加**，如国内生产总值、产品产量、财政收入、商品房销售额；时点序列反映一定时点上的**瞬间水平**，指标值**不能累加**，如年底人口总数、库存量、股票价格、年末员工人数、外汇储备余额。

4. **Q：城镇人口比重、经济增长率属于哪类序列？人均 GDP 呢？**
   A：前者是**相对数**时间序列（两个绝对数之比）；人均 GDP、人均利润是**平均数**时间序列。

5. **Q：平均发展水平又称什么？**
   A：**序时平均数**或**动态平均数**，是对时间序列中各时期发展水平计算的平均数，概括性描述现象一段时期内达到的一般水平。

6. **Q：时期序列的序时平均数怎么算？**
   A：**简单算术平均数**——各指标值相加除以项数 n。

7. **Q：连续时点序列的两种算法？**
   A：①资料**逐日登记且逐日排列** → 简单算术平均数；②登记单位仍是 1 天但**只在指标值变动时才记录一次** → **加权算术平均数**，权数是每一指标值的**持续天数**。

8. **Q：间断时点序列的两种算法？与间隔相等的间断时点序列计算思路相同的是哪一种？**
   A：①**间隔相等** → 「两次平均」，两次都是**简单算术平均**；②**间隔不等** → 「两次平均」，**一次简单算术平均、一次加权算术平均**，权数是**间隔长度**。与间隔相等的间断时点序列计算思路相同的是**间隔不相等的间断时点序列**——两者都采用「两次平均」的思路。

9. **Q：相对数/平均数时间序列的序时平均数能直接对相对数平均吗？**
   A：**不能**。它是派生数列，必须先分别求出**分子指标**和**分母指标**序列的序时平均数，然后再对比。

10. **Q：增长量的基本公式与两种分类？**
   A：增长量 = 报告期水平 − 基期水平；分为**逐期增长量**（比前一期）和**累计增长量**（比固定时期，通常是最初水平）。

11. **Q：累计增长量与逐期增长量的数量关系？**
   A：**累计增长量 = 相应时期逐期增长量之和**（不是平均数、不是乘积）。

12. **Q：平均增长量的公式？**
   A：平均增长量 = 逐期增长量的合计 ÷ 逐期增长量的个数 = **累计增长量 ÷（时间序列项数 − 1）**。它是**逐期**增长量的序时平均数。

13. **Q：定基发展速度与环比发展速度的两条关系？**
   A：①**定基发展速度 = 各环比发展速度的连乘积**；②**环比发展速度 = 两个相邻时期定基发展速度的比率**。

14. **Q：定基增长速度与环比增长速度之间能互相推算吗？**
   A：**不能**。定基增长速度 ≠ 各环比增长速度的连乘积；相邻两期定基增长速度之比 ≠ 环比增长速度。只有**发展速度**可以这样推算。

15. **Q：发展速度与增长速度的换算？**
   A：**定基增长速度 = 定基发展速度 − 1**；**环比增长速度 = 环比发展速度 − 1**。反过来：发展速度 = 增长速度 + 1。

16. **Q：平均发展速度用什么方法算？开几次方？**
   A：通常采用**几何平均法**，等于环比发展速度连乘积（或定基发展速度）开 **n = 时期数 − 1** 次方。

17. **Q：平均增长速度怎么求？能由环比增长速度直接算吗？**
   A：**平均增长速度 = 平均发展速度 − 1**。它**既不能由各期环比增长速度求得，也不能根据一定时期的总增长速度计算**。

18. **Q：应用速度分析必须注意哪两点？**
   A：①时间序列中的指标值出现 **0 或负数时不宜计算速度**，此时适宜直接用**绝对数**进行分析；②速度指标的数值与**基数**大小密切相关，各期基数不同，必须结合**增长 1% 的绝对值**等水平指标才能得出正确结论。

19. **Q：增长 1% 的绝对值怎么算？反映什么？**
   A：= 逐期增长量 ÷ 环比增长速度 = **报告期前一期发展水平 × 1%**。它反映**同样的增长速度在不同时间条件下所包含的绝对水平**。

20. **Q：时间序列的四种成分？**
   A：**长期趋势（T）、季节变动（S）、循环波动（C）、不规则波动（I）**。其中「非固定长度的周期性变动」是**循环波动**，「一年内重复出现」是**季节变动**。

21. **Q：加法模型与乘法模型的假定？**
   A：加法模型 Yt = Tt + St + Ct + It；乘法模型 Yt = Tt × St × Ct × It。

22. **Q：时间序列预测程序四步？**
   A：①确定所含成分；②找出适合的预测方法；③对可能的预测方法进行评估以确定最佳方案；④利用最佳方案进行预测。

23. **Q：平滑预测法的目的、适用对象与优点？**
   A：目的是「消除」不规则成分引起的**随机波动**；适合**平稳时间序列**（无明显趋势、循环和季节波动）的预测；**简单易用、对数据要求最低**，对近期预测精度较高。

24. **Q：移动平均法的公式与要点？**
   A：F(t+1) = 最近 k 期数据值的平均数，k 为移动间隔且 1 < k < t。预测下一期时往前数 k 期即可。

25. **Q：指数平滑法的公式与 α 的含义？**
   A：F(t+1) = α·Yt + (1−α)·Ft。α 是**平滑系数（权重）**，0 < α < 1；观测值离预测期越久远权重越小，呈指数下降。

### 2025 年（7 道）

**【2025 单选真题】下列统计指标的时间序列中，属于时期序列的是（ ）**
A. 城镇化率　B. 年末员工人数　C. 年广告支出　D. 外汇储备余额

**答案：C**
**解析**：时期序列中每一指标值反映现象在一段时期内发展的结果，即「过程总量」。年广告支出是**一年内累积发生的总量**，属于时期序列。A 城镇化率是**相对数**时间序列；B 年末员工人数、D 外汇储备余额都是**某一时点上的瞬间水平**，属于时点序列。

---

**【2025·单选】2021～2024 年某企业营业收入的简单环比增长速度分别为 5%、10%、15%，则 2021 年至 2024 年该企业营业收入的定基增长速度为（ ）**
A. 5%×10%×15%　B. (105%×110%×115%)−1　C. 1.05×1.10×1.15　D. 5%+10%+15%

**答案：B**
**解析**：定基发展速度 = 相应时期内各环比发展速度的连乘积。先把环比增长速度**+1** 还原为环比发展速度：105%、110%、115%；定基发展速度 = 105%×110%×115%；定基增长速度 = 定基发展速度 − 1 = (105%×110%×115%)−1。故选 B。A 是增长速度直接相乘（错），C 少了「−1」得到的是发展速度，D 是简单相加（错）。

---

**【2025·多选】关于时间序列长期趋势成分的说法，正确的有（ ）**
A. 长期趋势可能是由计量误差导致的周期性
B. 长期趋势是序列一段时间内持续上升或持续下降的变动
C. 长期趋势是随机无规律的变动
D. 长期趋势是一年内重复出现的周期性波动

D. F(t+1) = αFt

**解析**：本题考查指数平滑法。指数平滑法是利用过去时间序列值的**加权平均数**作为预测值，即使得第 t+1 期的预测值等于第 t 期的**实际观察值与第 t 期预测值的加权平均值**。其公式为 **F(t+1) = αYt + (1−α)Ft**。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把「时期序列」和「时点序列」搞反 | 问自己：是**一段时期攒出来的**（时期，可累加）还是**某个时点拍的快照**（时点，不可累加）。「年底/年末/余额/库存」几乎都是时点 |
| 2 | 把「相对数」和「平均数」时间序列搞混 | 看到「比重、率」→ **相对数**；看到「人均、平均价格」→ **平均数** |
| 3 | 认为时点序列的序时平均数可以直接算术平均 | 时点序列必须先分**连续/间断**，间断再分**间隔相等/不等**，四种情形算法各不相同 |
| 4 | 认为相对数时间序列可以直接对相对数求平均 | 派生数列必须先算**分子序时平均数 ÷ 分母序时平均数** |
| 5 | 把「两次平均」用错地方 | 「两次平均」只用于**间断时点序列**（间隔相等：两次简单；间隔不等：一次简单一次加权）。连续时点和时期序列都**不是**两次平均 |
| 6 | 混淆间隔相等与间隔不等的第二种平均 | **间隔相等 → 第二次仍是简单算术平均**；**间隔不等 → 第二次是加权算术平均**（权数为间隔长度） |
| 7 | 连续时点序列的两种情形分不清 | **逐日排列 → 简单算术平均**；**只在变动时记录 → 加权算术平均**（权数为持续天数） |
| 8 | 平均增长量当成「累计增长量的序时平均数」 | 是**逐期增长量**的序时平均数。公式：逐期增长量合计 ÷ 个数 = 累计增长量 ÷（项数 − 1） |
| 9 | 累计增长量与逐期增长量的关系记成「平均数」「乘积」 | 唯一正确关系：**累计 = 逐期之和** |
| 10 | 题目给的是「逐期增长量」却去找各期水平 | 若题中直接给出各期**逐期增长量**，求累计增长量**直接相加**即可，无需还原水平值 |
| 11 | 定基发展速度与环比发展速度的关系记反 | 「**定基积**」（定基 = 各环比连乘积）、「**环比比**」（环比 = 相邻定基之比） |
| 12 | 把「增长速度」的关系套成「发展速度」的关系 | **增长速度之间不能互相推算**！定基增长速度 ≠ 环比增长速度连乘积；相邻定基增长速度之比 ≠ 环比增长速度 |
| 13 | 发展速度与增长速度换算时忘记 ±1 | 发展速度 = 增长速度 **+ 1**；增长速度 = 发展速度 **− 1**。题干给增长速度、问发展速度时最易漏 |
| 14 | 平均发展速度用简单算术平均法算 | 各时期对比基础不同，必须用**几何平均法**：环比发展速度连乘积（或定基发展速度）开 n 次方 |
| 15 | 平均发展速度开方的次数错 | 开 **n = 时期数 − 1** 次方（不是时期数次方）。如 1998→2003 是 5 个环比发展速度，开 5 次方 |
| 16 | 平均增长速度想用几何平均法直接算 | 只能**平均发展速度 − 1**；它既不能由各期环比增长速度求得，也不能由总增长速度计算 |
| 17 | 增长 1% 的绝对值的分母用错 | 分母是**环比增长速度**，不是环比发展速度、更不是定基指标。最简算法：**前一期水平 × 1%** |
| 18 | 看到序列中有 0 或负数还算速度 | **出现 0 或负数时不宜计算速度**，应直接用绝对数分析 |
| 19 | 速度大就认为增长快 | 速度受**基数**大小影响，各期基数不同，必须结合**增长 1% 的绝对值**等水平指标才能下结论 |
| 20 | 把「循环波动」和「季节变动」的定义记反 | 「**一年内**重复出现」→ 季节变动；「**非固定长度**的周期性变动」→ 循环波动 |
| 21 | 把「不规则波动」当成可预测成分 | 不规则波动是除去 T、S、C 后的**随机波动**，偶然因素引起，难以预测控制，**通常不予单独考虑** |
| 22 | 认为平滑法适用于有明显趋势/季节波动的序列 | 平滑法适合**平稳时间序列**（没有明显的趋势、循环和季节波动） |
| 23 | 指数平滑公式权重位置写反 | **α 挂在 Yt（实际观察值）上，(1−α) 挂在 Ft（预测值）上**：F(t+1) = α·Yt + (1−α)·Ft，且两项权重之和为 1 |
| 24 | 移动平均法取错期数 | 预测 t+1 期，取的是**最近 k 期**（即 t−k+1 到 t 期），不是从序列开头取 k 期 |
| 25 | 真题中 PPI 移动平均题被题干数字带偏 | 素材存在串行讹误（98.4/94.8）。抓住方法「**最近 K 期简单算术平均**」，答案仍为 97.2 |
