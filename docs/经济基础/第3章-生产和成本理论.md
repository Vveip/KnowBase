## 二、知识点精讲

### 考点1 生产者及其组织形式 ★

**核心概念**：

- **生产者**：能够作出统一的生产决策的单个经济单位，即**企业或厂商**。
- **企业**：产品生产过程中的主要组织形式。
- **三种组织形式**：**个人独资企业、合伙制企业和公司制企业**。
- **基本假设**：在生产者行为的分析中，一般假设生产者或企业的目标是**追求利润最大化**。

**利润最大化目标的「现实折扣」（理解即可，考选择题）**：

| 层次 | 内容 |
|---|---|
| 动机层面 | 经济学家实际上并不认为追求利润最大化是人们从事生产和交易的**唯一动机** |
| 两权分离 | 企业所有者往往不是真正的经营者，日常决策由经营者作出；经营者还有其他目标——企业的生存、舒适的生活、优厚的薪资等 |
| 信息问题 | 由于**信息不完全、信息不对称**，所有者不能完全监督和控制经营者，经营者可能在一定程度上偏离利润最大化目标而追求自身利益，也可能只顾短期利益而牺牲长期利益 |
| 操作困难 | 即使经营者目标是利润最大化，要准确计算最大利润也**缺乏资料**；实际长期生存的经验做法，就是实现**销售收入最大化或市场份额最大化**，以此取代利润最大化决策 |
| 最终结论 | 不管找到利润最大化决策多难、经营者偏离动机多强，**长期不以利润最大化为目标的企业终将被市场淘汰**——实现利润最大化是所有企业在竞争中求得生存的关键 |

**速记口诀**：**"独—合—公司"三种形式，"利润最大化"是假设，两权分离＋信息不完全会让它打折，但长期不追利润的企业必被淘汰。**

### 考点2 企业形成的理论 ★★★★★

**核心概念（科斯，1937 年《企业的本质》）**：

| 要点 | 内容 |
|---|---|
| 企业产生的根本原因 | 为**节约市场交易费用和交易成本**而产生 |
| 企业的本质／显著特征 | **市场机制或价格机制的替代物** |
| 交易费用 | 围绕**交易契约**所产生的成本或费用 |
| 市场机制与企业交易费用不同的主要原因 | **信息的不完全性** |

**两种协调生产和资源配置的方式**：

| 协调方式 | 手段 |
|---|---|
| **企业（内部）** | 行政命令 |
| **市场（外部）** | 磋商、谈判、讨价还价 |

- 两种交易方式**都要支付成本和费用**。
- 当**企业交易方式的交易费用 ＜ 市场交易方式的交易费用**时，企业就应运而生了。
- 企业作为生产的一种组织形式，在一定程度上是对市场机制的替代，**大大减少需要签订的契约数量**，节约费用。
- 从历史上看，企业产生以后，社会上形成了**两种交易**：企业外部的市场交易和企业内部的交易。

**逻辑链**：

```
信息不完全性
    ↓ 导致
市场交易方式（磋商/谈判/讨价还价）要付交易费用
    ↓ 比较
企业交易方式（行政命令）也要付交易费用
    ↓ 当 企业费用 < 市场费用
企业应运而生
    ↓ 本质
市场机制/价格机制的替代物（减少签约数量、节约费用）
```

**速记口诀**：**"科斯省费用，本质是替代，差异因信息，内部用命令、外部靠谈判。"**

**例题巩固（讲义例题，无年份标签）**：

- 【多选】关于科斯企业形成理论，下列说法正确的是（ BCE ）。解析：A 错——企业的产生是**减少**而非增加市场交易费用；D 错——企业要盈利，追求利润最大化是企业长期生存的关键。
- 【多选】关于科斯的企业本质理论的说法，正确的有（ ABDE ）。解析：C 错——"追求生产规模最大化是唯一动机"说法错误，应为追求利润最大化。
- 【单选】根据科斯理论，企业产生的原因是（ A 节约交易成本 ）。

### 考点3 生产及相关概念 ★

**生产要素**：**资本、劳动、土地、企业家才能**等。

**短期生产与长期生产的划分依据：能否变动全部生产要素**（不是按时间长短！）。

| 类型 | 含义 | 要点 |
|---|---|---|
| **短期生产** | 至少有一种生产要素是可变的，其他投入不可以改变 | 生产者来不及调整全部生产要素的数量；生产要素可分为**不变投入和可变投入**；一种可变要素的生产函数即**短期生产函数** |
| **长期生产** | 全部生产要素都是可变的 | 当各种投入要素都可变时，研究企业的长期行为 |

> **易错警示**：短期与长期**不是**以「一年」为界划分的，而是看生产者能否调整所有生产要素。

**速记口诀**：**"要素四样：资劳土企；长短看全部，不按期一年。"**

---

### 考点4 生产函数 ★

**定义**：表示**在一定时期内，在技术不变的情况下**，生产中所使用的**各种生产要素的数量与所能生产的最大产量**之间的函数关系。

| 分类 | 依据 | 内容 |
|---|---|---|
| 短期生产函数 | 能否变动全部生产要素 | 至少有一种生产要素可变，其他投入不可改变 |
| 长期生产函数 | 能否变动全部生产要素 | 全部生产要素都可变 |

> 定义中的三个限定词——**一定时期内、技术不变、最大产量**——是单选题最常设置的陷阱（把「最大产量」换成「平均产量」即错）。

**速记口诀**：**"技术不变、时期一定，要素数量换最大产量。"**

---

### 考点5 一种可变要素的生产函数及曲线 ★★★（本章计算核心）

**一种可变要素生产函数 = 短期生产函数。**

**三大产量指标**：

| 指标 | 定义 | 记忆点 |
|---|---|---|
| **总产量 TP** | 一定要素投入量相对应的最大产量；生产出来的用**实物单位**衡量的产出总量（如多少吨水泥） | 总量 |
| **平均产量 AP** | 平均每一单位要素投入量所生产的最大产量；总产量除以总投入的单位数，即每单位投入生产的产出 | 每一单位 |
| **边际产量 MP** | 增加一单位要素投入量所增加的产量；其他投入保持不变的条件下，新增一单位可变要素投入量所增加的产量或产出 | 新增一单位 |

**核心关系（必背，两条线）**：

| MP 与 AP 的关系 | MP 与 TP 的关系 |
|---|---|
| **MP = AP 时，AP 最大** | **MP > 0 时，TP 递增** |
| **MP > AP 时，AP 递增** | **MP < 0 时，TP 递减** |
| **MP < AP 时，AP 递减** | **MP = 0 时，TP 达到最大值** |

**逻辑链**：

```
连续追加劳动 L（资本不变）
        ↓
MP 先递增 → 越过临界点后 MP 递减 → MP=0 → MP<0
        ↓                    ↓              ↓
TP 以递增增长率上升   TP 仍升但增速放缓   TP 达到最大值后下降
        ↓
AP 变化：只要 MP 曲线在 AP 曲线上方（MP>AP），AP 就递增
        ↓ MP 曲线下穿 AP 曲线（MP=AP）
AP 达到最大
        ↓ 此后 MP<AP
AP 递减
```

**曲线关系图（讲义此处以图呈现，文字还原如下）**：

```
 产量
   |                         TP
   |                       ／|
   |                     ／  |     ← MP=0 处 TP 达最高点
   |                   ／    |       之后 MP<0，TP 下降
   |                 ／      |
   |               ／        |
   |             ／          |
   |           ／            |
   +--------------------------------- L（劳动投入）
       L1    L2    L3    L4
        ↑     ↑     ↑
      MP递  MP=AP  MP=0
      增段  AP最大  TP最大

  MP 曲线：先上升后下降，穿过横轴后转为负值
  AP 曲线：倒 U 型，MP 曲线自上而下穿过 AP 曲线（交点即 AP 最大）
  顺序：MP 最先下降 → AP 后下降 → TP 最后下降
```

**变化顺序（2022 真题考点）**：在总产量、平均产量、边际产量三个变量的变化过程中，**首先发生的是边际产量下降**。因为如果确定**边际产量**的图形，就可以得到总产量和平均产量的图形（不能反过来说确定 AP 图形就得到 TP 和 MP 图形）。

**四阶段判读（对应讲义图中的 L1～L4）**：

| 阶段 | MP 状态 | AP 状态 | TP 状态 |
|---|---|---|---|
| L1 之前 | MP 递增 | AP 递增（MP > AP） | TP 以**递增的增长率**上升 |
| L1→L2 | MP 递减但仍 > AP | AP 继续递增 | TP 仍升，增速放缓 |
| L2 处 | **MP = AP** | **AP 达到最大** | TP 继续上升 |
| L2→L3 | MP 递减且 < AP | AP 递减 | TP 继续上升 |
| L3 处 | **MP = 0** | AP 继续递减 | **TP 达到最大值** |
| L3 之后 | MP < 0 | AP 递减 | **TP 下降** |

> 阶段划分中 L1～L4 的符号沿用素材讲义原图标注；各阶段的 MP/AP/TP 状态均由「MP 与 AP 的关系」「MP 与 TP 的关系」两条规则直接推出。

**速记口诀**：**"边际压平均，平均往上走；边际托平均，平均往下溜；边际等于平均，平均到顶了；边际归零，总量到顶。"**

**例题巩固（素材原题）**：

- 【单选】在其他条件不变的情况下，如果连续增加劳动的投入，在总产量达到最大值时，劳动的边际产量（　）。
  A. 大于零　B. 小于零　C. 等于零　D. 等于平均产量
  **答案：C**。解析：MP > 0 时 TP 递增；MP < 0 时 TP 递减；**MP = 0 时 TP 达到最大值**。

- 【多选】一般来说，对于短期生产函数，总产量和平均产量、边际产量的关系是（　）。
  A. 如果边际产量大于平均产量，则平均产量递增
  B. 如果边际产量等于平均产量，则平均产量达到最大点
  C. 如果边际产量为零，则总产量达到最大点

### 考点6 边际产量递减规律 ★★

**含义（边际报酬／边际产量递减规律）**：在**技术水平不变**（和其他投入保持不变）的条件下，连续等量地把一种可变要素增加到其他生产要素上，总是存在着一个**临界点**——在该要素投入量**小于**某一特定值时，所带来的边际产量是**递增**的；当该要素连续投入量**超过**某一特定值（临界点）后，所带来的边际产量**递减**，直到出现**负值**。

**原因**：在任何产品的短期生产中，可变要素投入与固定要素投入之间存在着一个**最佳数量组合比例**。

**逻辑链**：

```
技术水平不变 + 固定要素不变
    ↓
可变要素与固定要素存在"最佳组合比例"
    ↓ 可变要素投入量 < 临界点
边际产量递增
    ↓ 可变要素投入量 > 临界点
边际产量递减 → 直至为负
```

**速记口诀**：**"技术不变连加料，临界之前往上飘，过了临界往下掉，最佳组合是奥妙。"**

**例题巩固（素材原题）**：

- 【单选】假设只有一种生产要素的投入可变，其他生产要素的投入不可变，关于边际产量和平均产量关系的说法中，正确的是（　）。
  A. 只要边际产量大于平均产量，平均产量就是递增的
  B. 只要边际产量等于平均产量，平均产量就是递增的
  C. 只要边际产量小于平均产量，平均产量就是递增的
  D. 只要边际产量等于平均产量，平均产量就是递减的
  **答案：A**。解析：边际产量大于平均产量，即边际产量曲线在平均产量曲线上方，平均产量就是递增的。

### 考点7 规模报酬 ★

**含义**：也称**规模收益**，指在其他条件不变时，企业内部**各种生产要素按相同比例变化**所带来的产量变化，即**企业的生产规模变化与所引起的产量变化之间的关系**。

**研究的是长期生产决策问题**——只有长期中才能改变全部生产要素的投入，从而影响生产规模。

| 类型 | 关系 |
|---|---|
| **规模报酬递增** | 产量增加比例 **大于** 各种生产要素增加比例 |
| **规模报酬不变** | 产量增加比例 **等于** 各种生产要素增加比例 |
| **规模报酬递减** | 产量增加比例 **小于** 各种生产要素增加比例 |

**长期生产中的一般规律**：企业规模较小时扩大生产，规模报酬递增，此时企业会扩大规模以得到产量递增所带来的好处，**将生产保持在规模报酬不变阶段**；此后如果继续扩大生产，就会出现规模报酬递减。

**逻辑链**：

```
规模较小 → 扩大生产 → 规模报酬递增（产量增幅 > 要素增幅）
    ↓ 得到产量递增的好处
保持规模 → 规模报酬不变（产量增幅 = 要素增幅）
    ↓ 继续盲目扩大
规模报酬递减（产量增幅 < 要素增幅）
```

> **注意**：规模报酬可以分为**三类**（不是两类）；是**生产要素的投入**决定生产规模，不是技术进步决定生产规模。

**速记口诀**：**"同比例加要素，长期才谈规模；三大类：大于、等于、小于；先递增、再不变、后递减。"**

**例题巩固（素材原题）**：

- 【单选】关于规模报酬的说法，正确的是（　）。
  **提示**：本题已按 2021 年真题完整收录于「六、典型真题」，答案 AC。易错项为「规模报酬可以分为两类」（应为三类）与「技术进步决定生产规模」（应为生产要素投入决定生产规模）。

### 考点8 成本的含义 ★★（极易混淆）

**五大概念一张网**：

| 概念 | 定义 | 关键点 |
|---|---|---|
| **显性成本（显成本）** | 厂商在生产要素市场**购买或租用**要素的实际可见支出；企业购买或租用的生产要素所**实际支付的货币支出** | 看得见的货币支出 |
| **隐性成本（隐成本）** | 厂商**自己拥有的**且被用于该企业生产过程的那些生产要素的总价格。包括**自有资金、土地、房子、企业家才能**等 | 看不见，但真实存在 |
| **经济成本** | 显性成本 + 隐性成本 | 总成本 = 显成本 + 隐成本 |
| **机会成本** | 当一种生产要素被用于生产单位某产品时，所放弃的使用**相同生产要素**在其他生产用途中所得到的**最高收入** | 「最高」不是平均、不是最低 |
| **正常利润** | 厂商对自己所提供的**企业家才能的报酬支付**，是生产成本的一部分，以**隐性成本**计入成本 | 正常利润 ⊂ 隐成本 |

**经济利润（超额利润）**：

- **经济利润 = 总收益 − 总成本**（总成本 = 显成本 + 隐成本）
- 企业所追求的最大利润，指的就是**最大的经济利润**；经济利润也被称为**超额利润**。
- **经济利润中不包括正常利润**（因为正常利润已作为隐成本计入总成本）。

**逻辑链**：

```
总收益
  −  总成本
        ├── 显成本（购买/租用要素的实际货币支出）
        └── 隐成本（自有要素的总价格）
                  └── 内含：正常利润（企业家才能的报酬）
  =
经济利润（超额利润）  ← 不含正常利润
```

**速记口诀**：**"显性是买租花的钱，隐性是自有要素的价；机会成本取最高，正常利润算隐本；经济利润超额赚，里头不含正常利。"**

**例题巩固（素材原题）**：

- 【单选】机会成本是指当一种生产要素被用于生产某种产品时所放弃的使用该生产要素在其他生产用途中所得到的（　）。
  A. 最高收入　B. 最低收入　C. 平均收入　D. 超额收入
  **答案：A**。解析：机会成本是指当一种生产要素被用于生产单位某产品时，所放弃的使用相同要素在其他生产用途中所得到的**最高收入**。

- 【单选】关于经济利润的说法，正确的是（　）。
  A. 经济利润是指企业的总收益和总成本的差额
  B. 经济利润包括正常利润和超额利润
  C. 经济利润等于其正常利润
  D. 经济利润是指企业的总收益和显性成本的差额
  **答案：A**。解析：企业的经济利润是指企业的总收益和总成本的差额，简称企业的利润。B、C 错——正常利润是生产成本的一部分，是作为隐成本的一部分计入成本，因此经济利润中**不包括**正常利润；D 错——不是与显性成本的差额，而是与**总成本**（显＋隐）的差额。

- 【多选】关于成本的说法，正确的有（　）。
  A. 折旧费属于可变成本
  B. 企业的总成本从长期来看可以划分为固定成本和可变成本
  C. 正常利润是生产成本的一部分
  D. 企业的所有显成本和隐成本共同构成了企业的总成本
  E. 隐成本实际上也是一种机会成本
  **答案：CDE**。解析：A 错——可变成本主要包括原材料、燃料和动力以及生产工人的工资费用等，**厂房设备折旧属固定成本**；B 错——**长期成本中没有什么固定成本，一切成本都是可变的**；C 对——正常利润是作为隐成本的一部分计入成本的，因此经济利润中不包括正常利润；D、E 对——隐成本是企业自己拥有并使用的资源的成本，实际上也是一种机会成本，应按自有生产要素在其他用途中所得的最高收入来计算。

### 考点9 成本函数 ★

| 项目 | 内容 |
|---|---|
| **含义** | 表示**企业总成本和产量之间关系**的公式 |
| **短期成本函数** | 有固定成本和可变成本，**C = b + f(Q)** |
| **长期成本函数** | 一切生产要素都是可变的，**C = f(Q)** |

> 短期成本函数中之所以有个常数项 b，是因为短期存在不随产量变动的固定成本；长期一切要素皆可变，故无常数项。

**速记口诀**：**"成本函数看总成本与产量的关系；短期带个 b（固定），长期光溜溜。"**

### 考点10 短期成本的有关概念 ★★★

**七大成本（名称 / 定义 / 数学表述）**：

| 名称 | 定义 | 数学表述 |
|---|---|---|
| **总固定成本 TFC** | 短期内**不随产量增减而变动**的成本——厂房和设备的折旧、管理人员工资费用 | TFC |
| **总可变成本 TVC** | **随产量变动而变动**的成本——原材料、燃料和动力、生产人员工资费用 | TVC |
| **总成本 TC** | 企业在生产中投入的所有生产要素的市场价值 | **TC = TVC + TFC** |
| **平均固定成本 AFC** | 总固定成本除以产量 | **AFC = TFC / Q** |
| **平均可变成本 AVC** | 总可变成本除以产量 | **AVC = TVC / Q** |
| **平均成本（平均总成本）ATC** | 总成本除以产量 | **ATC = TC / Q = AFC + AVC** |
| **边际成本 MC** | 每多增加一单位产量所带来的总成本增量 | **MC = △TC / △Q** |

**归属速记**：固定成本＝厂房设备折旧＋管理人员工资；可变成本＝原材料、燃料和动力＋生产人员工资。**高管人员工资属于固定成本，生产工人工资属于可变成本**（2023 补真题考点）。

**速记口诀**：**"三总四平均一 marginal：TFC 不动、TVC 动、TC 两家凑；AFC、AVC 除产量，ATC 是哥俩相加；MC 只看增量。"**

### 考点11 短期成本分类与曲线图形 ★★★★

**七大成本考法总结（本节最重要的一张表）**：

| 考法 | 成本 |
|---|---|
| **右上方**（从纵轴截点出发） | **总成本 TC** |
| **右上方**（从原点出发） | **总可变成本 TVC** |
| **呈 U 型** | **平均成本 AC、平均可变成本 AVC、边际成本 MC** |
| **特殊——平行于横轴的一条直线** | **总固定成本 TFC** |
| **特殊——平行右下方倾斜** | **平均固定成本 AFC** |
| **相交点左边** | 边际小于平均，两平均成本是**递减**的 |
| **相交点右边** | 边际大于平均，两平均成本是**递增**的 |
| **变化速度** | **边际比平均先到最低点** |

**曲线关系图（讲义此处以图呈现，文字还原如下）**：

```
（一）总量曲线：TC / TVC / TFC

 成本
  C
  |                    TC
  |                  ／
  |                ／   ← 先以递减的增长率上升，
  |              ／       产量达一定水平后以递增的增长率上升
  |            ／
  |     F ●－－－－－－－－－－－－－－－－－  TFC（平行于横轴的直线）
  |      ／＾
  |    ／   ＾ TVC（从原点出发，与 TC 保持同样的变动规律）
  |  ／
  +-------------------------------- Q
   F = 纵轴截点：Q = 0 时 TC = TFC
   TC 与 TVC 的垂直距离恒等于 TFC

（二）平均与边际曲线：ATC / AVC / MC（三条 U 型曲线）

 成本
  C
  |                MC
  |               ／\
  |              ／  \              ATC
  |             ／    \            ／\
  |            ／      \          ／  \＿＿
  |           ／   .----\--------／        －－－－
  |          ／   ／      \    ／  AVC          ＿＿
  |         ／   ／        \／＿＿＿＿＿＿＿＿＿＿＿＿＿＿
  |        ／   ／        ／
  |       ／   ／        ／
  +-------------------------------------------- Q
          ↑          ↑
        AVC 最低   ATC 最低
       (MC=AVC)   (MC=ATC)
   ● MC 自下向上先穿过 AVC 最低点，再穿过 ATC 最低点
   ● 到达最低点的先后：MC 最早 → AVC 次之 → ATC 最晚

（三）平均固定成本 AFC（单独一条，右下方倾斜）

 成本
  C
  |＼
  |  ＼
  |    ＼＿＿＿＿＿＿＿＿  ← 随产量增加持续递减，逐渐向横轴接近
  |
  +-------------------------------- Q
   ● AFC 与 MC、ATC 均不相交；ATC 始终位于 AFC 上方
```

**四条必背结论**：

1. **总成本曲线**从**纵轴一个截点**（产量为零时总成本等于固定成本的那个点）开始，随产量的增加而逐步上升；**开始时以递减的增长率上升，当产量达到一定水平后，便以递增的增长率上升**。
2. **总可变成本曲线**从**原点**开始，随产量的增加而逐步上升；总成本曲线与总可变成本曲线的**变动规律是一致的**（两者的垂直距离恒等于 TFC）。
3. **总固定成本曲线**是一条**平行于横轴**的直线；**平均固定成本曲线**随产量增加而递减，逐渐向横轴接近。
4. **边际成本曲线**先降低后增加；**边际比平均先到最低点**（边际的变动快于平均）。MC 与 AVC 相交于 **AVC 最低点**，MC 与 ATC 相交于 **ATC 最低点**；**交点左边边际小于平均、平均递减，交点右边边际大于平均、平均递增**。

**速记口诀**：**"总量看起点：TC 截点、TVC 原点、TFC 横线；平均边际是 U 型；交点左减右增，边际抢先到最低；AFC 一直往下溜，谁都不相交。"**

**四条必背结论的「三句话压缩版」**：

1. **看起点**：TC 从纵轴截点（TFC）出发、TVC 从原点出发、TFC 是横线 → 凡说「TC 从原点开始」必错。
2. **看形状**：AC、AVC、MC 三条 U 型；AFC 一路向右下倾斜 → 凡说「AFC 是 U 型」或「AFC 与 MC/ATC 相交」必错。
3. **看交点**：MC 穿 AVC 最低点、MC 穿 ATC 最低点；交点左「边际 < 平均、平均递减」，交点右「边际 > 平均、平均递增」→ 凡说「ATC 与 AFC 相交于最低点」必错。
4. **看快慢**：边际比平均先到最低点 → 凡说「ATC 比 MC 更早到最低点」必错。

**例题巩固（素材原题）**：

- 【单选】关于短期边际成本曲线和平均成本曲线之间关系的说法，正确的是（　）。
  A. 平均固定成本曲线和边际成本曲线都具有 U 型特征
  B. 当边际成本与平均成本相等时，平均总成本位于最低点
  C. 平均总成本曲线比边际成本曲线更早到达最低点
  D. 平均固定成本曲线总是高于边际成本曲线
  **答案：B**。解析：平均固定成本曲线随着产量的增加而递减，逐渐向横轴接近；边际成本曲线先降低后增加（A、D 错）。**平均总成本曲线比边际成本曲线更晚**到达最低点（C 错）。

- 【多选】关于短期成本曲线的说法，正确的有（　）。
  A. 总成本曲线从原点开始，并随产量的增加而逐步上升
  B. 总成本曲线从纵轴一个截点即产量为零时总成本等于固定成本的那个点开始，并随产量的增加而逐步上升
  C. 总可变成本曲线从原点开始，并随产量的增加而逐步上升
  D. 总可变成本曲线从纵轴一个截点即产量为零时总成本等于固定成本的那个点开始，并随着产量的增加而逐步下降
  E. 总固定成本曲线是平行于横轴的一条直线
  **答案：BCE**。解析：总成本曲线从**纵轴的一个截点**开始并逐步上升（A 错）；总可变成本曲线从**原点**出发并逐步上升（D 错）。

### 公式1 生产函数（概念公式）

**表述**：在一定时期内、在技术不变的情况下，生产中所使用的**各种生产要素的数量**与所能生产的**最大产量**之间的函数关系。

| 项目 | 内容 |
|---|---|
| 限定条件 | 一定时期内 + 技术不变 |
| 自变量 | 各种生产要素的数量（资本、劳动、土地、企业家才能等） |
| 因变量 | **最大**产量（不是平均产量） |
| 短期成本函数形式 | **C = b + f(Q)**（含固定成本 b） |
| 长期成本函数形式 | **C = f(Q)**（一切要素可变，无常数项） |

**演算示例（自编，非真题）**：某企业在技术不变条件下，投入 3 单位劳动与 2 单位资本，最大产出为 500 件；若技术不变、投入量不变，产出不可能超过 500 件——这正是「最大产量」的含义；若把「最大产量」误作「平均产量」，则本题无解。命题陷阱即在此。

### 公式2 总产量、平均产量、边际产量

**公式**：

```
TP = 总产量
AP = TP / L        （L 为可变要素投入量）
MP = △TP / △L     （其他投入不变）
```

**关系**：MP > AP → AP 递增；MP = AP → AP 最大；MP < AP → AP 递减。MP > 0 → TP 递增；MP = 0 → TP 最大；MP < 0 → TP 递减。

**演算例题1（素材数据表）**：

| 劳动投入 L | 总产量 TP | 边际产量 MP | 平均产量 AP |
|---|---|---|---|
| 1 | 2000 | 2000 | 2000 |
| 2 | 3000 | 1000 | 1500 |

验证：AP₁ = 2000 / 1 = 2000 ✔；AP₂ = 3000 / 2 = 1500 ✔；MP₂ = (3000 − 2000) / (2 − 1) = 1000 ✔。此时 MP(1000) < AP(1500)，AP 由 2000 降到 1500，即 **AP 递减**，符合「MP < AP 时 AP 递减」。

**演算例题2（2023 真题原题）**：劳动投入 3 单位时总产量 3500 台；劳动投入 4 单位时平均产量 950 台。求边际产量。

```
TP(4) = AP(4) × 4 = 950 × 4 = 3800（台）
MP    = △TP / △L = (3800 − 3500) / (4 − 3) = 300（台）
```

**答案：A（300）**。关键步骤：题目给的是 **AP**，必须先还原成 **TP**。

**演算例题3（2018 真题原题）**：资本投入不变，劳动从 4 单位增至 5 单位，总产量从 38000 件增至 39000 件，平均产量从 950 件降至 780 件。求边际产量。

```
MP = △TP / △L = (39000 − 38000) / (5 − 4) = 1000（件）
```

**答案：D（1000）**。平均产量的变化（950 → 780）是**干扰条件**，计算 MP 不需要 AP。

### 公式3 等产量曲线与边际技术替代率

> **说明**：本章素材（生产者的组织形式与企业理论、生产函数和生产曲线、成本函数和成本曲线三个版本）**未涉及等产量曲线与边际技术替代率**的任何表述、公式或真题。按「不添加素材外内容」的纪律，此处仅作占位说明，不作展开。本笔记不对该考点编写公式与结论。

### 公式4 成本函数

| 类型 | 形式 | 含义 |
|---|---|---|
| 短期成本函数 | **C = b + f(Q)** | b 为固定成本，f(Q) 为随产量变动的可变成本 |
| 长期成本函数 | **C = f(Q)** | 一切生产要素都可变，无固定成本项 |

**演算例题（2022 真题原题）**：某工厂生产产品，生产 10 个单位时总成本为 500，生产 11 个单位时平均成本为 51，则该产品边际成本为（ ）。

```
TC(11) = AC(11) × 11 = 51 × 11 = 561
MC     = △TC / △Q = (561 − 500) / (11 − 10) = 61
```

**答案：C（61）**。陷阱：题目给的是第 11 单位的**平均成本**，必须先乘回**总成本**再求差；若直接用 51 − 50 = 1 或用 500/10 = 50 与 51 相减，都会错。

### 公式5 机会成本、显成本、隐成本、经济利润与正常利润

```
经济成本 = 显成本 + 隐成本
总成本   = 显成本 + 隐成本
经济利润 = 总收益 − 总成本 = 总收益 − 显成本 − 隐成本
正常利润 ⊂ 隐成本（企业家才能的报酬，以隐成本计入成本）
经济利润中不包括正常利润
机会成本 = 放弃的其他用途中的最高收入
```

**演算示例（自编，非真题）**：某店主用自有资金 100 万元开店（若存入银行一年可得利息 4 万元＝机会成本），自有店铺若出租一年可得租金 6 万元，自己管理企业的企业家才能若受雇可得年薪 10 万元；另支付工人工资与原材料等共 30 万元。若一年总收益为 60 万元：

```
显成本 = 30（万元）
隐成本 = 4 + 6 + 10 = 20（万元）   ← 内含正常利润 10 万元
总成本 = 30 + 20 = 50（万元）
经济利润 = 60 − 50 = 10（万元）   ← 超额利润，不含正常利润
```

结论：经济利润为正 10 万元，说明获得了超额利润；若经济利润为 0，企业仍获得了正常利润（10 万元），可以继续经营。

### 公式6 短期成本总量与平均关系

```
TC  = TFC + TVC
ATC = TC / Q = AFC + AVC
AFC = TFC / Q
AVC = TVC / Q
MC  = △TC / △Q
```

**演算示例（自编，非真题）**：某企业短期中 TFC = 100 元，产量 Q = 10 件时 TVC = 200 元。

```
TC  = 100 + 200 = 300（元）
AFC = 100 / 10 = 10（元/件）
AVC = 200 / 10 = 20（元/件）
ATC = 300 / 10 = 30（元/件） = AFC + AVC = 10 + 20 = 30 ✔
```

当 Q 增至 20 件、TVC 增至 360 元时：

```
TC(20) = 100 + 360 = 460
MC     = (460 − 300) / (20 − 10) = 16（元/件）
ATC(20) = 460 / 20 = 23（元/件） < ATC(10) = 30，ATC 下降
        → 反推：MC(16) < ATC(23)，符合"交点左边边际小于平均、平均递减"
```

### 公式7 MC 与 AC（AVC）的交点规律

```
MC < AC  → AC 递减
MC = AC  → AC 处于最低点
MC > AC  → AC 递增
MC < AVC → AVC 递减
MC = AVC → AVC 处于最低点
MC > AVC → AVC 递增
边际比平均先到最低点（MC 最低点 → AVC 最低点 → ATC 最低点）
```

**演算例题（2021 真题原题）**：从短期看，当边际成本低于平均总成本时（ ）。

```
已知 MC < ATC
→ 交点（ATC 最低点）左边，ATC 递减
→ 结论：平均总成本下降
```

**答案：D**。

**演算示例（自编，非真题）**：某产品 AC 序列为：Q=10 时 AC=30，Q=11 时 AC=28，Q=12 时 AC=27，Q=13 时 AC=27.5。

```
Q:10→11，MC = 28×11 − 30×10 = 308 − 300 = 8   → MC(8) < AC(28)，AC 下降 ✔
Q:11→12，MC = 27×12 − 28×11 = 324 − 308 = 16  → MC(16) < AC(27)，AC 下降 ✔
Q:12→13，MC = 27.5×13 − 27×12 = 357.5 − 324 = 33.5 → MC(33.5) > AC(27.5)，AC 上升 ✔
```

结论：AC 的最低点出现在 Q = 12 附近，此处 MC 由小于 AC 转为大于 AC，即 **MC 穿过 AC 最低点**。

### 公式8 规模报酬

> **说明**：本章素材中的规范表述是「**规模报酬**」（也称规模收益），指各种生产要素按相同比例变化所带来的产量变化；素材中**未出现「规模经济」这一表述**，二者不可混用。

```
设各种生产要素按相同比例 k 增加：
规模报酬递增：产量增加比例 > k
规模报酬不变：产量增加比例 = k
规模报酬递减：产量增加比例 < k
```

**演算示例（自编，非真题）**：某企业原来投入劳动 100 单位、资本 50 单位，产量 1000 件。现将劳动、资本**同比例**扩大为原来的 2 倍（劳动 200、资本 100）：

| 结果 | 判定 |
|---|---|
| 产量达到 2400 件（增幅 140% > 100%） | 规模报酬**递增** |
| 产量达到 2000 件（增幅 100% = 100%） | 规模报酬**不变** |
| 产量只有 1600 件（增幅 60% < 100%） | 规模报酬**递减** |

注意：必须是**各种生产要素按相同比例变化**才是规模报酬问题；只有一种要素变化属于边际产量递减规律（短期）问题。

## 五、高频考点速记卡

1. **Q：生产者／企业的含义？**
   A：能够作出统一的生产决策的单个经济单位，即企业或厂商；企业是产品生产过程中的主要组织形式。

2. **Q：企业的三种组织形式？基本假设目标是什么？**
   A：个人独资企业、合伙制企业、公司制企业；一般假设目标是追求利润最大化。

3. **Q：利润最大化是唯一动机吗？**
   A：不是。经济学家并不认为它是唯一动机，经营者还有企业生存、舒适生活、优厚薪资等目标；由于信息不完全、不对称，所有者难以完全监督经营者。但长期不以利润最大化为目标的企业终将被市场淘汰。

4. **Q：科斯认为企业产生的根本原因？企业的本质？**
   A：为节约市场交易费用和交易成本而产生；本质是市场机制或价格机制的替代物。

5. **Q：市场机制与企业交易费用不同的主要原因？**
   A：**信息的不完全性**（不是信息不对称、不是信息鸿沟）。

6. **Q：两种协调生产和资源配置的方式及手段？**
   A：企业内部用行政命令；企业外部用磋商、谈判、讨价还价。两种都要支付交易费用，当企业交易费用小于市场交易费用时，企业应运而生。

7. **Q：划分短期与长期生产的依据？**
   A：**能否变动全部生产要素**。短期至少一种要素可变、其他不可改变；长期全部要素可变。不是按一年期限。

8. **Q：生产函数的定义（三个关键词）？**
   A：在一定时期内、技术不变条件下，各种生产要素的数量与所能生产的**最大产量**之间的函数关系。

9. **Q：TP、AP、MP 的定义？**
   A：TP 是一定要素投入量相对应的最大产量（实物单位）；AP 是平均每一单位要素投入所生产的产量；MP 是增加一单位要素投入所增加的产量。

10. **Q：MP 与 AP、MP 与 TP 的各三条关系？**
    A：MP > AP，AP 递增；MP = AP，AP 最大；MP < AP，AP 递减。MP > 0，TP 递增；MP = 0，TP 达到最大值；MP < 0，TP 递减。

11. **Q：TP、AP、MP 三者中谁先下降？**
    A：**边际产量 MP 最先下降**；且只能由 MP 图形推出 TP 与 AP 图形，不能反向。

12. **Q：边际产量递减规律的含义与原因？**
    A：技术水平和其他投入不变时，连续追加一种要素，临界点之前 MP 递增、超过临界点后 MP 递减直至为负；原因是可变要素与固定要素之间存在一个最佳数量组合比例。

13. **Q：规模报酬分几类？各自含义？研究的是长期还是短期？**
    A：分三类——递增（产量增幅 > 要素增幅）、不变（等于）、递减（小于）；研究的是**长期**生产决策问题，因为只有长期才能改变全部要素投入。

14. **Q：显成本与隐成本的区别？机会成本是什么？**
    A：显成本是购买或租用生产要素实际支付的货币支出；隐成本是企业自己拥有且被用于该企业生产过程的那些生产要素的总价格（自有资金、土地、房子、企业家才能）。机会成本是放弃的相同要素在其他生产用途中所得到的**最高收入**；隐成本实际上也是一种机会成本。

15. **Q：经济利润怎么算？包括正常利润吗？正常利润是什么？**
    A：经济利润 = 总收益 − 总成本（总成本 = 显成本 + 隐成本），又称超额利润；**不包括正常利润**。正常利润是厂商对自己所提供的企业家才能的报酬支付，是生产成本的一部分，以隐性成本计入成本。

16. **Q：短期成本函数与长期成本函数的形式？七大短期成本的公式？**
    A：短期 C = b + f(Q)（含固定成本 b），长期 C = f(Q)（一切要素可变）。七大成本：TC = TVC + TFC；AFC = TFC/Q；AVC = TVC/Q；ATC = TC/Q = AFC + AVC；MC = △TC/△Q。

17. **Q：总成本曲线、总可变成本曲线、总固定成本曲线的起点？**
    A：TC 从纵轴一个截点（Q=0 时 TC = TFC）开始上升，先以递减增长率、后以递增增长率上升；TVC 从原点开始上升；TFC 是平行于横轴的直线。

18. **Q：MC 与 AVC、ATC 的交点在哪？交点两侧怎么变？**
    A：MC 与 AVC 相交于 AVC 最低点，MC 与 ATC 相交于 ATC 最低点。交点左边边际小于平均、平均递减；交点右边边际大于平均、平均递增。

19. **Q：三条 U 型曲线谁最早到最低点？ATC 与 AFC 相交吗？**
    A：**边际成本曲线最早**到达最低点（边际的变动快于平均），AVC 次之，ATC 最晚。ATC 与 AFC **不相交**，平均总成本曲线始终高于平均固定成本曲线，AFC 随产量增加而递减并逐渐接近横轴。

20. **Q：哪些属于可变成本？**
    A：原材料、燃料和动力、生产工人工资。**不属于**：企业高管人员工资、固定资产折旧费（属固定成本）。

**【2023·多选】从坐标图上看，当边际产量曲线和平均产量曲线最终相交时，该生产者的（　）。**

**解析**：MP 曲线与 AP 曲线相交时 MP = AP，此时**平均产量最大**（A 对）；此时总产量仍在递增（E 对，因此时 MP 仍大于 0）；相交时边际产量处于递减过程（D 对）。B、C 错——总产量达到最大点要等到 **MP = 0**，而非 MP = AP。（素材原稿误标为「单选题」，按 5 个选项与答案 ADE 判定应为多选题，已修正。）

B. 在坐标图上，总成本曲线不随产量的变动而变动

**【2022·单选】某工厂生产产品，生产 10 个单位时总成本为 500，生产 11 个单位时平均成本为 51，则该产品边际成本为（　）。**
A. 51　B. 52　C. 61　D. 80

**答案：C**
**解析**：生产 11 个单位的总成本 = 51 × 11 = 561；边际成本 = (561 − 500)/(11 − 10) = **61**。关键是把「平均成本 51」先还原为「总成本 561」。

**【2021·多选】关于规模报酬的说法，正确的有（　）。**
A. 规模报酬是企业的生产规模与所引起的产量之间的关系
B. 规模报酬可以分为两类
C. 规模报酬研究的是长期生产决策问题
D. 技术进步决定生产规模
E. 规模报酬以成本不变为基础

**答案：AC**
**解析**：规模报酬也称规模收益，是指在其他条件不变的情况下，企业内部各种生产要素按照**相同比例**变化时所带来的产量变化，也就是企业生产规模变化与所引起的产量变化之间的关系（A 对）。企业只有在长期中才能改变全部生产要素的投入，进而影响生产规模，所以规模报酬研究的是企业的**长期**生产决策问题（C 对）。规模报酬可分为**三类**（B 错）；是**生产要素的投入**决定生产规模（D 错）。

**【2020·多选】关于成本的概念的说法，正确的有（　）。**
A. 显成本是指企业购买或租用的生产要素所实际支付的货币支出
B. 机会成本是指当一种生产要素被用于生产单位某产品时所放弃的使用相同要素在其他生产用途中所得到的最高收入

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把「短期＝一年以下」当划分标准 | 只看**能否变动全部生产要素**：短期至少一种要素不变，长期全部可变 |
| 2 | 认为追求利润最大化是唯一动机 | 是「一般假设的目标」；现实中经营者还有生存、舒适生活、优厚薪资等目标 |
| 3 | 认为企业的产生**增加**了市场交易费用 | 科斯：企业是为**节约**市场交易费用和交易成本而产生 |
| 4 | 把企业本质记成「扩大生产规模」 | 企业本质是**市场机制／价格机制的替代物**，减少签约数量 |
| 5 | 把交易费用差异的原因记成「信息不对称」「信息鸿沟」 | 唯一正确答案是**信息的不完全性** |
| 6 | 混淆两种协调方式的手段 | **企业内部＝行政命令；企业外部＝磋商、谈判、讨价还价** |
| 7 | 生产函数定义中的「最大产量」写成「平均产量」 | 定义三要素：一定时期＋技术不变＋**最大产量** |
| 8 | 认为确定 AP 图形就能推出 TP 和 MP | 只能由 **MP 图形**推出 TP 和 AP 图形，方向不可反 |
| 9 | 记混「谁先下降」，或以为 TP 最大时 MP 最大 | 顺序：**MP 先降 → AP 后降 → TP 最后降**；TP 最大时 **MP = 0** |
| 10 | 把边际产量递减的原因记成「技术落后」 | 原因是可变要素与固定要素之间存在**最佳数量组合比例**（前提是技术水平不变） |
| 11 | 认为规模报酬分两类 | 分**三类**：递增、不变、递减 |
| 12 | 认为技术进步决定生产规模 | 是**生产要素的投入**决定生产规模；规模报酬研究**长期**决策 |
| 13 | 把正常利润算进经济利润 | 正常利润是隐成本的一部分，**经济利润不含正常利润** |
| 14 | 把隐成本说成「购买／租用要素的货币支出」，或机会成本取「平均收入」 | 购买/租用货币支出是**显成本**；隐成本是自有要素（自有资金、土地、房子、企业家才能）的总价格；机会成本必须取**最高收入** |
| 15 | 把企业高管工资、固定资产折旧费算成可变成本 | 高管工资、折旧属**固定成本**；可变成本＝原材料、燃料和动力、生产工人工资 |
| 16 | 认为长期成本也可分固定与可变 | 长期中**一切成本都是可变的**，没有固定成本 |
| 17 | 认为 ATC 与 AFC 相交于 ATC 最低点 | ATC **始终高于** AFC，两者不相交；MC 才与 ATC 相交于其最低点 |
| 18 | 认为三条 U 型曲线同时到最低点 | **MC 最早**到最低点，AVC 次之，ATC 最晚（边际变动快于平均） |
| 19 | 计算 MC 时直接用平均成本相减 | 先把平均成本**乘回总成本**再求差：MC = △TC/△Q（如 51×11 = 561） |
| 20 | 算 MP 时被平均产量数据干扰 | MP = △TP/△L，只需总产量差额；AP 变化是干扰项（如 2018 年真题 950→780） |
