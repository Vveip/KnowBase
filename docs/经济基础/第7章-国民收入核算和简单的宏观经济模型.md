## 二、知识点精讲

### 考点1 国内生产总值的含义 ★

**核心定义**：国内生产总值（GDP）是按**市场价格**计算的一个**国家（或地区）**在**一定时期内生产活动**的**最终成果**。

**定义五要素（拆解题眼）**：

| 要素 | 题眼 |
|---|---|
| 按市场价格计算 | 排除不变价格法、市场价格法作为"计算方法"的混淆项 |
| 一个国家（或地区） | 是**地域**概念，不是国民概念 |
| 一定时期内 | 流量概念，非存量 |
| 生产活动 | 只算生产出来的最终成果 |
| 最终成果 | 不含中间投入的重复计算 |

**三种形态（多选高频）**：价值形态、收入形态、产品形态。**没有**"支出形态""实物形态"。

**GDP 与 GNI 的区别**：

| 项目 | 国内生产总值 GDP | 国民总收入 GNI |
|---|---|---|
| 概念性质 | **生产**概念 | **收入**概念 |
| 定义 | 按市场价格计算的一定时期内生产活动的最终成果 | 一个国家（或地区）所有常住单位在一定时期内**收入初次分配**的最终结果 |
| 换算关系 | —— | **GNI ＝ GDP ＋ 来自国外的净要素收入** |

**逻辑链**：

```
GDP（市价 / 国内 / 期内 / 生产 / 最终成果）
   │
   ├─ 三种形态 ─────────── 价值形态 │ 收入形态 │ 产品形态
   │
   └─ 与 GNI 的桥梁 ───── GNI = GDP + 来自国外的净要素收入
                          GDP=生产概念      GNI=收入概念
```

**速记口诀**：**"市价国内期内产，最终成果三种态；GDP 管生产，GNI 管收入，中间隔着一个国外净要素。"**

> **考法提示**：①多选考"三种形态"，干扰项固定设"支出形态""实物形态"；②单选考"说法正确的是"，干扰项"GDP 又称为国民总收入/国民生产总值"必错，只有定义原文正确；③GNI 与 GDP 的换算关系（GNI＝GDP＋来自国外的净要素收入）与概念性质（生产 vs 收入）是固定搭配考点。

### 考点2 国内生产总值的计算方法 ★★（另有版本标 ★★★）

**核心结论**：实际核算中国内生产总值的计算方法有**三种**——**生产法、支出法、收入法**。（不是"市场价格法""不变价格法"。）

| 方法 | 计算角度 | 构成（素材明确列示部分） |
|---|---|---|
| **收入法** | 从生产过程中创造**原始收入**的角度 | **劳动者报酬 ＋ 固定资产折旧 ＋ 生产税净额 ＋ 营业盈余** |
| **支出法** | 从社会**最终使用**的角度 | **最终消费 ＋ 资本形成总额 ＋ 净出口**，即 GDP＝C＋I＋G＋(X−M) |
| **生产法** | —— | 素材仅列出方法名称，未展开具体计算公式（不做补充） |

**收入法四项细分**：

- **劳动者报酬**：工资总额、福利费、其他实物形式的劳动报酬、**农户和个体劳动者生产经营所获得的纯收益**（不含营业盈余）。
- **生产税净额 ＝ 生产税 － 生产补贴**。

**支出法三项细分**：

- **最终消费** ＝ 居民消费 ＋ 政府消费。
- **资本形成总额** ＝ 固定资产投资 ＋ 存货投资（固定资本形成 ＋ 存货增加）。
- **净出口** ＝ 出口 − 进口。

**逻辑链**：

```
GDP 三种核算方法
   │
   ├─ 收入法（看原始收入）
   │     劳动者报酬 + 固定资产折旧 + 生产税净额 + 营业盈余
   │     └─ 生产税净额 = 生产税 − 补贴
   │
   ├─ 支出法（看最终使用）
   │     C + I + G + (X − M)
   │     ├─ 最终消费 = 居民消费 + 政府消费
   │     ├─ 资本形成总额 = 固定资本形成 + 存货增加
   │     └─ 净出口 = X − M
   │
   └─ 生产法（素材仅列名称）
```

**速记口诀**：**"收支产生三种法；收入四块'劳折税盈余'；支出'消费资本加出口'；税净额，税减补。"**

> **考法提示**：①多选考"三种计算方法"，干扰项"市场价格法""不变价格法"；②多选考"劳动者报酬包括"，干扰项"营业盈余"；③单选考"生产税净额减去什么"，答案是**生产补贴**，干扰项"中间投入""固定资产折旧""营业盈余"；④多选考"最终消费包括"，答案是**居民消费＋政府消费**，干扰项"固定资本形成""存货增加""净出口"；⑤单选考支出法公式，干扰项把 X−M 改成 X＋M 或 −M；⑥2025 年考过"收入法构成中**不包括**"（答案是原材料总投入）。

### 考点3 两部门储蓄-投资恒等式 ★★

**核心内容**：

| 分析角度 | 两部门经济 |
|---|---|
| 支出角度 | Y ＝ C ＋ I |
| 收入角度 | Y ＝ C ＋ S |
| 储蓄-投资恒等式 | **I ＝ S** |

**涉及部门**：企业、消费者（居民）。**不含**政府部门、国外部门。

**逻辑链**：

```
两部门经济（企业 + 居民）
   支出角度：Y = C + I
   收入角度：Y = C + S
        ↓ 左右消去 C
   I = S        ← 投资恒等于储蓄
```

**速记口诀**：**"两部门消 C 得 I＝S。"**

> **考法提示**：本节很少单独考两部门，主要作为三部门、四部门的推导基础。命题时两部门常以"支出角度 Y＝C＋I、收入角度 Y＝C＋S"的形式出现在恒等式表格题中。

### 考点4 三部门储蓄-投资恒等式 ★★

**核心内容**：

| 分析角度 | 三部门经济 |
|---|---|
| 支出角度 | Y ＝ C ＋ I ＋ G |
| 收入角度 | Y ＝ C ＋ S ＋ T |
| 储蓄-投资恒等式 | **I ＝ S ＋（T − G）** |

**涉及部门**：企业、消费者（居民）、政府部门。**不含**国外部门。

**逻辑链**：

```
三部门经济（企业 + 居民 + 政府）
   支出角度：Y = C + I + G
   收入角度：Y = C + S + T
        ↓ 消去 C，移项
   I = S + (T − G)
        ↑ 政府净储蓄（税收 − 政府购买）
```

**速记口诀**：**"三部门加 G 加 T，恒等式尾巴挂 (T−G)。"**

> **考法提示**：多选考"三部门条件下的储蓄-投资恒等式涉及的部门"，答案是**企业、消费者（居民）、政府部门**；干扰项"国外部门"（属四部门）、"地方部门"（无此划分）。

---

### 考点5 四部门储蓄-投资恒等式 ★★

**核心内容**：

| 分析角度 | 四部门经济 |
|---|---|
| 支出角度 | Y ＝ C ＋ I ＋ G ＋（X − M） |
| 收入角度 | Y ＝ C ＋ S ＋ T |
| 储蓄-投资恒等式 | **I ＝ S ＋（T − G）＋（M − X）** |

**涉及部门**：企业、居民、政府、**国外部门**。

**逻辑链**：

```
四部门经济（企业 + 居民 + 政府 + 国外）
   支出角度：Y = C + I + G + (X − M)
   收入角度：Y = C + S + T
        ↓ 消去 C，移项
   I = S + (T − G) + (M − X)
        ↑ 国内储蓄  政府净储蓄  国外净储蓄（对本国的净流入）
```

**速记口诀**：**"四部门再加 (X−M)，恒等式换成 (M−X)，方向千万别记反。"**

> **考法提示**：单选高频。给 I、S、T、G、X、M 问恒等式，正确答案必为 **I＝S＋(T−G)＋(M−X)**。三类干扰项：①漏括号写成 I＝S＋T−G＋M；②少一项写成 I＝S＋(T−G) 或 I＝S＋(M−X)；③方向错写成 X−M。

### 考点6 消费理论 ★★★（另有版本标 ★★）

**三大理论对比（本章最核心表格）**：

| 理论 | 代表人物 | 公式 | 核心观点 |
|---|---|---|---|
| **凯恩斯消费理论** | 凯恩斯 | **C ＝ α ＋ βY** | 建立在**三个假设**之上：①边际消费倾向递减规律；②**收入是决定消费的最重要的因素**；③平均消费倾向（APC）随收入增加而减少 |
| **生命周期消费理论** | 莫迪利安尼 | **C ＝ a·WR ＋ c·YL** | a＝财富的边际消费倾向，WR＝财产收入；c＝劳动的边际消费倾向，YL＝劳动收入。消费取决于家庭所处的生命周期阶段 |
| **持久收入理论** | 弗里德曼 | **Ct ＝ c·YPt** | Ct＝现期消费支出，c＝边际消费倾向，YPt＝现期持久收入。消费不是由当前收入决定，而是由**持久收入**（可预期到的长期收入）决定 |

**凯恩斯消费理论的三个关键结论**：

1. **边际消费倾向 MPC ＝ β ＝ ΔC/ΔY**，且 **0 < MPC < 1**（可能小于、等于、大于 1 的是 APC，不是 MPC）。
2. **平均消费倾向 APC ＝ C/Y**（消费总量/收入总量），**APC 可以小于 1、等于 1、大于 1**（因为消费可能大于、等于或小于收入）；APC 随收入增加而**减少**。
3. **APC 总是大于 MPC**（口诀"**平大边际**"），即 **MPC < APC**。

**生命周期理论与持久收入理论的共同点**：长期中消费函数是**稳定**的。
- 生命周期理论：人口构成没有重大变化时，从长期看边际消费倾向是**稳定**的，消费支出与可支配收入和实际国民生产总值之间存在一种**稳定**的关系；若人口构成比例变化，MPC 也变化——**老年人和年轻人比例增大 → 消费倾向提高；中年人比例增大 → 消费倾向降低**。
- 持久收入理论：长期中持久性收入是**稳定**的，所以消费函数是**稳定**的。

**逻辑链**：

```
消费理论三兄弟
   │
   ├─ 凯恩斯  C = α + βY
   │     ① MPC 递减   ② 收入决定消费（最重要）  ③ APC 随收入增加而减少
   │     推论：0 < MPC < 1 ；APC 可大/等/小于 1 ；MPC < APC（平大边际）
   │
   ├─ 莫迪利安尼（生命周期） C = a·WR + c·YL
   │     看公式认理论：WR=财产收入，YL=劳动收入
   │     人口结构变化 → MPC 变（老少比例大→升；中年比例大→降）
   │
   └─ 弗里德曼（持久收入） Ct = c·YPt
         看公式认理论：YPt = 现期持久收入
         长期持久收入稳定 → 消费函数稳定
```

**速记口诀**：**"凯恩斯三条假设，平大边际要记清；WR加YL是生命周期，YP是持久收入。"**

> **考法提示**：①多选考"凯恩斯消费理论的假设"，干扰项必来自另两个理论——"消费是持久收入的稳定函数"（弗里德曼）、"消费取决于家庭所处的生命周期阶段"（莫迪利安尼）；②单选考"APC 的取值"，答案是"可能大于、等于或小于 1"；③单选考"MPC 与 APC 的关系"，答案是"MPC 总是小于 APC"；④单选考"以下属于××理论的是"，**认公式最快**：C＝a·WR＋c·YL 找 WR/YL，Ct＝c·YPt 找 YP，C＝α＋βY 是凯恩斯。

### 考点7 储蓄函数 ★

**核心定义**：储蓄是收入中减去消费的余额。

- **S ＝ Y − C**
- 推导：**S ＝ Y − C ＝ Y −（α ＋ βY）＝ −α ＋（1 − β）Y**
- 收入是决定储蓄的**最主要**因素，收入变化决定着储蓄变化。
- 储蓄和收入之间的依存关系称为**储蓄函数**（不是"储蓄与消费之间的依存关系"）。
- 随着收入不断增加，消费增加会越来越少，**储蓄增加会越来越多**。

**消费函数与储蓄函数的关系（互为补数）**：

| 关系式 | 含义 |
|---|---|
| C ＋ S ＝ Y | 二者之和总是等于收入 |
| APC ＋ APS ＝ 1 | 平均消费倾向 + 平均储蓄倾向 |
| MPC ＋ MPS ＝ 1 | 边际消费倾向 + 边际储蓄倾向 |

**逻辑链**：

```
Y = C + S
  │
  ├─ 消费函数：C = α + βY      （α=自发消费，βY=引致消费）
  ├─ 储蓄函数：S = −α + (1−β)Y
  │
  └─ 互补关系：C+S=Y → APC+APS=1，MPC+MPS=1
```

**速记口诀**：**"储蓄是收入减消费；互为补数三个一：C+S=Y、APC+APS=1、MPC+MPS=1。"**

> **考法提示**：①单选考"表述错误的是"，陷阱是"储蓄与**消费**之间的依存关系被称为储蓄函数"——正确说法是储蓄与**收入**之间的依存关系；②单选考"消费函数和储蓄函数的关系"，答案是**互补关系**（互为补数）；③记牢"消费等于自发消费和引致消费之和"（C＝α＋βY，α 为自发消费、βY 为引致消费）。

### 考点8 投资函数 ★

**核心定义**：投资是形成固定资产的活动，一般**不包括金融投资**在内（建造厂房、购置设备、增加存货都算投资；金融投资不算）。

**决定投资的因素**：

| 因素 | 地位 |
|---|---|
| 实际利率 | 主要因素 |
| 预期收益率 | 主要因素 |
| 投资风险 | 主要因素 |
| 预期的通货膨胀率、折旧 | 在一定程度上影响投资 |
| 投资乘数 | **不是**投资的决定因素 |

**投资函数**：凯恩斯认为，实际利率越低，投资量越大。因此，**投资是利率的减函数**：**I ＝ I(r) ＝ e − dr**。

**逻辑链**：

```
投资（形成固定资产，不含金融投资）
   │
   ├─ 决定因素：实际利率 / 预期收益率 / 投资风险（主要）
   │            预期通货膨胀率 / 折旧（一定程度）
   │
   └─ 投资函数：I = I(r) = e − dr
         r↓ → I↑      （利率的减函数）
```

**速记口诀**：**"投资是实利率的减函数，e 减 dr；厂房设备存货算，金融投资不算。"**

> **考法提示**：①单选考"不应算作投资的是"，答案是**金融投资**；建造厂房、购置设备、增加存货均属投资；②多选考"投资的决定因素"，答案是**实际利率、预期收益率、投资风险、预期的通货膨胀率**，干扰项是"投资乘数"——乘数不是投资的决定因素。

### 考点9 简单国民收入决定 ★

**核心内容**：两部门经济中，**Y ＝ C ＋ I**，代入消费函数与自发投资：

```
Y = C + I = (α + βY) + Ī
移项：Y − βY = α + Ī
得：  Y = (α + Ī) / (1 − β)
```

**素材例题（原题演算）**：两部门经济中，已知消费函数 C＝100＋0.8Y，投资总额 I＝460 亿元，求均衡国民收入。

```
解：Y = C + I = (100 + 0.8Y) + 460
    0.2Y = 560
    Y = 560 / 0.2 = 2800（亿元）
```

**速记口诀**：**"均衡收入＝(自发消费＋自发投资) ÷ (1 − 边际消费倾向)。"**

> **考法提示**：计算题唯一样板。给消费函数 C＝α＋βY 和投资总额 I，求均衡国民收入。步骤：Y＝C＋I → Y−βY＝α＋I → Y＝(α＋I)/(1−β)。最易错的是**只算出分子 α＋I 就停手**，忘了除以 (1−β)。

### 考点10 投资乘数 ★★★★★

**核心定义**：乘数也叫倍数，即一个因素或变量的变化对整个社会经济活动的影响程度。增加一笔投资 ΔI，在国民经济重新达到均衡状态时，由此引起的国民收入增加量并不仅限于这笔初始的投资量，而是初始投资的**若干倍**。

**公式**：

$$K = \frac{\Delta Y}{\Delta I} = \frac{1}{1-\beta} = \frac{1}{MPS}$$

**核心结论**：
- β 为**边际消费倾向**，所以**投资乘数的大小主要取决于边际消费倾向**（不是平均消费倾向、不是投资函数、不是实际利率）。
- 投资乘数 K 为**边际储蓄倾向 MPS 的倒数**（不是平均消费倾向、不是边际消费倾向、不是平均储蓄倾向的倒数）。
- MPC 越大 → (1−MPC) 越小 → K 越大。

**逻辑链**：

```
ΔI（初始投资增加）
   ↓ 变成收入 → 按 MPC 消费 → 再变收入 → 再消费 …（无穷级数）
ΔY = ΔI × (1 + β + β² + β³ + …) = ΔI × 1/(1−β)
   ↓
K = ΔY/ΔI = 1/(1−β) = 1/MPS
   ↑ 乘数大小只取决于边际消费倾向 β
```

**速记口诀**：**"乘数看边际：K＝1/(1−MPC)＝1/MPS；MPC 越大，乘数越大。"**

> **考法提示**：本考点四种问法：①"投资乘数的大小主要取决于"→ **边际消费倾向**；②"投资乘数是谁的倒数"→ **边际储蓄倾向的倒数**；③给 MPC 求 K（如 MPC＝0.8 → K＝5）；④给 MPS 求 K（如 MPS＝0.2 → K＝5）；⑤给 ΔI 与 MPC 求 ΔY（如 MPC＝0.75、支出增 100 万 → K＝4、ΔY＝400 万）。所有选项干扰都围绕"平均消费倾向""边际消费倾向的倒数"设置。

### 考点11 总需求 ★★★★

**核心定义**：在其他条件不变的情况下，在某一给定的价格水平上，一个国家或地区各种经济主体**愿意购买**的产品总量。

**影响因素**：

| 影响因素 | 对总需求的影响 | 方向 |
|---|---|---|
| 利率 | 利率上升，总需求减少；利率下降，总需求增加 | 反向 |
| 货币供给量 | 货币供给量增加，总需求增加；减少，总需求减少 | 同向 |
| 政府购买 | 政府购买增加，总需求增加；减少，总需求减少 | 同向 |
| 税收 | 税收减少，总需求增加；税收增加，总需求减少 | 反向 |
| 预期 | 乐观预期，总需求增加；悲观预期，总需求减少 | 同向 |
| 价格总水平 | 价格总水平下降，总需求增加；上升，总需求减少 | 反向 |

> **反向变动因素**（多选高频）：**利率、税收、价格总水平**。政府购买、货币供给量、预期为同向。

**总需求曲线（AD）**：假定其他因素不变，总需求曲线表示的是**价格总水平和总需求**之间的关系，**向右下方倾斜**。原因有三效应：

| 效应 | 含义 |
|---|---|
| **财富效应** | 价格总水平变动引起居民收入及财富的实际购买力**反方向**变动，从而导致总需求反方向变动 |
| **利率效应** | 由价格变化引起的利率变化，利率与投资、消费及总需求的**反方向**变化关系。利率上升增加企业投资成本、增加居民购买住宅和耐用消费品的借款成本，从而减少投资与消费 |
| **出口效应** | 由价格总水平通过汇率变动影响出口需求的变化，并与总需求**反方向**变化的现象。固定汇率制下，价格总水平上升→出口减少、进口增加；浮动汇率制下，价格总水平上升→利率上升→吸引国外资本流入→本国货币升值压力→出口需求下降 |

**逻辑链**：

```
总需求（给定价格水平上，各经济主体愿意购买的产品总量）
   │
   ├─ 影响因素：利率↓货币供给量↑政府购买↑税收↓预期↑价格总水平↓ → AD↑
   │
   └─ AD 曲线（价格总水平 P 为纵轴）向右下方倾斜
         价格总水平 P ↑
            ├─ 财富效应：实际购买力 ↓ → 需求 ↓
            ├─ 利率效应：利率 ↑ → 投资/消费成本 ↑ → 需求 ↓
            └─ 出口效应：汇率变动 → 出口需求 ↓
                    ↓ 三者叠加
              总需求反方向减少
```

**速记口诀**：**"AD 向右下，三效应：财富、利率、出口；反向因素三个——利率、税收、价格总水平。"**

> **考法提示**：①多选考"影响总需求的因素"，干扰项是**生产成本**（属影响总供给的因素）；②多选考"与总需求成**反方向**变动的因素"，答案是**利率、税收、价格总水平**；③单选考"价格总水平通过影响汇率从而影响出口需求"→ **出口效应**，干扰项"财富效应""收入—物价效应""汇率—利率效应"；④三效应的辨析：看题干关键词——"实际购买力"→财富效应，"利率变动引致投资消费成本变化"→利率效应，"汇率变动影响出口"→出口效应。

### 考点12 总供给 ★★★★

**核心定义**：在其他条件不变的情况下，一定时期内在一定价格水平上，一个国家或地区的生产者**愿意向市场提供**的产品总量。

**关键结论**：**总供给的变动主要取决于企业的利润水平**。

**影响总供给的因素**：

| 因素 | 地位 |
|---|---|
| 价格与成本 | **基本因素** |
| 预期（企业预期） | **重要因素** |
| 劳动、资本、技术、经济体制 | **长期**总供给的影响因素 |

**总供给曲线**：反映在其他因素不变的条件下，总供给与**价格总水平**变动的关系。由于决定供给的价格和成本中的**工资在长期具有灵活性，在短期具有黏性或缺乏弹性**，所以总供给曲线分为长期与短期两种形式。

| 曲线 | 形状 | 与价格的关系 | 决定因素 |
|---|---|---|---|
| **短期总供给曲线 SRAS** | 向右上方倾斜 | 与价格有关 | 价格、成本、预期 |
| **长期总供给曲线 LRAS** | 与横轴（总产出）相交的**垂直线** | 与价格无关 | 劳动、资本、技术、经济体制 |

**逻辑链**：

```
总供给（一定价格水平上，生产者愿意向市场提供的产品总量）
   │ 变动主要取决于企业的利润水平
   │
   ├─ 影响因素：价格与成本（基本）／预期（重要）／劳动资本技术体制（长期）
   │
   └─ 为什么分长短两条曲线？
         工资：长期有灵活性，短期有黏性/缺乏弹性
            │
            ├─ 短期 SRAS：向右上方倾斜（与价格有关）
            └─ 长期 LRAS：垂直于横轴（与价格无关，只取决于劳动/资本/技术/经济体制）
```

**速记口诀**：**"总供给看利润；基本看价格成本，重要看预期；短期向上倾，长期一竖线；长短之别全在工资灵不灵。"**

> **考法提示**：①多选考"关于总供给说法正确的"，干扰项"政府购买是影响总供给的重要因素"（政府购买影响**总需求**）、"总供给曲线向右下方倾斜"（短期应向右**上**）；②单选考"总供给曲线反映的是总供给与谁变动的关系"→ **价格总水平**；③单选考"长期总供给曲线的特征"→ **垂直于横轴**；④多选考"对长期总供给具有决定作用的"→ **技术、资本、劳动**（另含经济体制，不含价格总水平、政府购买）；⑤单选考"总供给曲线为何分为长期与短期"→ **工资在长期有灵活性、短期有黏性或缺乏弹性**，注意主体是"工资"而非技术、预期、利率。

## 四、公式与计算（本章计算题重点章）

> **演算例题说明**：以下例题分为两类——①「素材原题」：完全来自素材原文，答案已核对；②「自编演算题」：为演示公式用法而设的纯数字演算，不引入素材之外的任何知识点或结论。

### 公式1 支出法 GDP ＝ C ＋ I ＋ G ＋（X − M）

- **含义**：从社会最终使用角度核算 GDP。C＝最终消费（居民消费＋政府消费），I＝投资（资本形成总额＝固定资本形成＋存货增加），G＝政府购买，X−M＝净出口。
- **易错点**：净出口必须是 **X − M**，不是 X ＋ M。

**【自编演算题】** 某国某年：居民与政府最终消费 C＝4000 亿元，资本形成总额 I＝1200 亿元，政府购买 G＝1500 亿元，出口 X＝900 亿元，进口 M＝700 亿元。求支出法 GDP。

```
解：GDP = C + I + G + (X − M)
        = 4000 + 1200 + 1500 + (900 − 700)
        = 6700 + 200
        = 6900（亿元）
```

### 公式2 收入法 GDP ＝ 劳动者报酬 ＋ 固定资产折旧 ＋ 生产税净额 ＋ 营业盈余

- **含义**：从生产过程中创造原始收入的角度核算 GDP。
- **易错点**：不含"原材料总投入/中间投入"；营业盈余是独立一项，不属于劳动者报酬。

**【素材原题·2025 单选】** 按收入法计算，国内生产总值（GDP）的构成中**不包括**（　）。
A. 固定资产折旧　B. 营业盈余　C. 原材料总投入　D. 劳动者报酬
**答案：C**
**解析**：收入法国内生产总值＝劳动者报酬＋固定资产折旧＋生产税净额＋营业盈余。

**【自编演算题】** 某年劳动者报酬 3200 亿元，固定资产折旧 800 亿元，生产税净额 500 亿元，营业盈余 1500 亿元。

```
解：收入法 GDP = 3200 + 800 + 500 + 1500 = 6000（亿元）
```

### 公式3 四部门储蓄-投资恒等式 I ＝ S ＋（T − G）＋（M − X）

- **含义**：投资恒等于国内储蓄、政府净储蓄与国外净储蓄之和。
- **易错点**：括号位置不能丢；最后一项是 **M − X**（与支出法中的 X − M 方向相反）。

**【素材原题】** 如果用 I 表示投资、S 表示储蓄、T 表示税收、G 表示政府购买，X 表示出口、M 表示进口，则四部门经济中储蓄和投资的恒等关系是（　）。
A. I＝S＋（T−G）＋（M−X）　B. I＝S＋T−G＋M　C. I＝S＋（T−G）　D. I＝S＋（M−X）
**答案：A**

**【自编演算题】** 四部门经济中：S＝2000 亿元，T＝1200 亿元，G＝1000 亿元，X＝800 亿元，M＝600 亿元。求 I。

```
解：I = S + (T − G) + (M − X)
     = 2000 + (1200 − 1000) + (600 − 800)
     = 2000 + 200 + (−200)
     = 2000（亿元）
```

### 公式4 边际消费倾向 MPC 与平均消费倾向 APC

$$MPC = \beta = \Delta C / \Delta Y \quad (0 < MPC < 1)；\quad APC = C / Y$$

- **关系**：**APC 总是大于 MPC**（口诀"平大边际"）；APC 可能大于、等于或小于 1；MPC 介于 0 与 1 之间。

**【自编演算题】** 消费函数 C＝100＋0.8Y，求 Y＝1000 亿元与 Y＝2000 亿元时的 APC 和 MPC。

```
Y=1000：C = 100 + 0.8×1000 = 900   APC = 900/1000 = 0.90
Y=2000：C = 100 + 0.8×2000 = 1700  APC = 1700/2000 = 0.85
MPC = ΔC/ΔY = (1700 − 900)/(2000 − 1000) = 800/1000 = 0.80
验算：APC(0.90) > MPC(0.80) ✓ ；APC 随收入增加由 0.90 降至 0.85 ✓
```

### 公式5 边际储蓄倾向 MPS 与平均储蓄倾向 APS

$$MPS = \Delta S / \Delta Y = 1 - MPC；\quad APS = S / Y = 1 - APC$$

- **关系**：**MPC ＋ MPS ＝ 1**；**APC ＋ APS ＝ 1**。

**【自编演算题】** 沿用上题消费函数 C＝100＋0.8Y（储蓄函数 S＝−100＋0.2Y），求 MPS、APS。

```
MPS = 1 − MPC = 1 − 0.8 = 0.20
Y=1000：S = −100 + 0.2×1000 = 100   APS = 100/1000 = 0.10
Y=2000：S = −100 + 0.2×2000 = 300   APS = 300/2000 = 0.15
验算：APC+APS = 0.90+0.10 = 1 ✓ ；0.85+0.15 = 1 ✓
      MPC+MPS = 0.80+0.20 = 1 ✓
```

### 公式6 消费函数与均衡国民收入 Y ＝（α ＋ Ī）/（1 − β）

- **含义**：两部门经济中 Y＝C＋I，代入 C＝α＋βY 与自发投资 Ī 后解得。
- **易错点**：分子是 α＋Ī，分母是 (1−β)，两步都不能省。

**【素材原题】** 在一个两部门经济中，已知消费函数 C＝100＋0.8Y，投资总额 I＝460 亿元，求均衡国民收入。

```
解：Y = C + I = (100 + 0.8Y) + 460
    Y − 0.8Y = 560
    0.2Y = 560
    Y = 560 / 0.2 = 2800（亿元）
```

### 公式7 投资乘数 K ＝ ΔY/ΔI ＝ 1/（1 − β）＝ 1/MPS

- **含义**：初始投资增加量引起的国民收入增加量的倍数。
- **核心结论**：K 的大小**只取决于边际消费倾向 β**（或边际储蓄倾向 MPS）；K 是 **MPS 的倒数**。

**【素材原题1】** 假设一个社会的边际消费倾向为 0.8，则投资乘数 K＝（　）。
A. 0.2　B. 1.25　C. 5　D. 0.8　**答案：C**
**解析**：投资乘数＝1/(1−0.8)＝5。

**【素材原题2】** 假设边际储蓄倾向 s 是 0.2，则投资乘数 k 应为（　）。
A. 1.25　B. 2.5　C. 5.5　D. 5　**答案：D**
**解析**：投资乘数等于 1/(1−MPC)＝1/MPS＝1/0.2＝5。

**【自编演算题】** MPC＝0.6，自发投资增加 ΔI＝200 亿元，求国民收入增加额。

```
解：K = 1/(1−0.6) = 1/0.4 = 2.5
    ΔY = K × ΔI = 2.5 × 200 = 500（亿元）
```

### 公式8 政府购买（政府支出）乘数

- **素材覆盖情况**：素材**未单独给出**政府购买乘数的公式条文，仅在 2022 年真题中以其数值作为选项出现（选项"政府支出乘数 3"为错误项）。下面结果由该真题与投资乘数公式 K＝1/(1−β) 反推得出，**不作为独立知识点背诵**。

**【素材原题·2022 单选】** 边际消费倾向 0.75，投资（财政支出）增加 100 万，下列说法正确的是（　）。
A. 国民收入增加 75　B. 国民收入增加 400　C. 投资乘数 3　D. 投资乘数 −0.75
**答案：B**

```
解：K = ΔY/ΔI = 1/(1−β) = 1/(1−0.75) = 1/0.25 = 4
    ΔY = K × ΔI = 4 × 100 = 400（万元）
    故 B 正确；C 项"乘数 3"错误（应为 4）；D 项"−0.75"错误。
```

## 五、高频考点速记卡

1. **Q：GDP 的定义？**
   A：按市场价格计算的一个国家（或地区）在一定时期内生产活动的最终成果。五要素：市价、国内、期内、生产、最终成果。

2. **Q：GDP 的三种形态？**
   A：价值形态、收入形态、产品形态。**没有**支出形态、实物形态。

3. **Q：GDP 与 GNI 的关系？**
   A：GNI＝GDP＋来自国外的净要素收入；GDP 是**生产**概念，GNI 是**收入**概念。

4. **Q：GDP 的三种计算方法？**
   A：生产法、支出法、收入法。不选"市场价格法""不变价格法"。

5. **Q：收入法 GDP 的四项构成？劳动者报酬包括哪些？**
   A：四项＝劳动者报酬＋固定资产折旧＋生产税净额＋营业盈余，**不含**原材料/中间投入；生产税净额＝生产税−补贴。劳动者报酬＝工资总额＋福利费＋其他实物形式的劳动报酬＋农户和个体劳动者生产经营所获得的纯收益，**不含**营业盈余。

6. **Q：支出法 GDP 的公式与构成？**
   A：GDP＝C＋I＋G＋(X−M)；最终消费（居民＋政府）＋资本形成总额（固定资本形成＋存货增加）＋净出口。

7. **Q：最终消费包括什么？**
   A：居民消费和政府消费。固定资本形成、存货增加属于资本形成总额，净出口单列。

8. **Q：三部门储蓄-投资恒等式？**
   A：I＝S＋（T−G）。涉及企业、居民、政府三个部门。

9. **Q：四部门储蓄-投资恒等式？**
    A：I＝S＋（T−G）＋（M−X）。注意最后是 M−X，方向别反。

10. **Q：凯恩斯消费理论的三个假设？**
    A：①边际消费倾向递减规律；②收入是决定消费的最重要的因素；③平均消费倾向随收入增加而减少。

11. **Q：MPC 与 APC 的取值范围及关系？**
    A：0＜MPC＜1；APC 可大于、等于或小于 1；**APC 总是大于 MPC**（平大边际）。

12. **Q：三大消费理论的公式怎么认？**
    A：凯恩斯 C＝α＋βY；莫迪利安尼生命周期 C＝a·WR＋c·YL；弗里德曼持久收入 Ct＝c·YPt。

13. **Q：储蓄函数表达式？**
    A：S＝Y−C＝−α＋（1−β）Y。收入是决定储蓄的最主要因素。

14. **Q：消费函数与储蓄函数的关系？**
    A：互为补数。C＋S＝Y；APC＋APS＝1；MPC＋MPS＝1。

15. **Q：投资函数表达式？什么不算投资？**
    A：I＝I(r)＝e−dr，利率的减函数。金融投资不算投资；建造厂房、购置设备、增加存货都算。

16. **Q：两部门均衡国民收入怎么求？**
    A：Y＝C＋I＝（α＋Ī）/（1−β）。例：C＝100＋0.8Y、I＝460 → Y＝2800 亿元。

17. **Q：投资乘数公式？大小取决于什么？**
    A：K＝ΔY/ΔI＝1/(1−β)＝1/MPS。取决于**边际消费倾向**，是**边际储蓄倾向的倒数**。

18. **Q：影响总需求的因素中哪些是反向的？**
    A：利率、税收、价格总水平。同向的有货币供给量、政府购买、预期。

19. **Q：总需求曲线为何向右下方倾斜？**
    A：财富效应、利率效应、出口效应三个效应共同作用。

20. **Q：长期总供给曲线有何特征？为何分长短两条？**
    A：长期总供给曲线是与横轴（总产出）相交的**垂直线**，与价格无关；短期总供给曲线向右上方倾斜。分长短的原因：决定供给的价格和成本中的**工资在长期有灵活性，短期有黏性或缺乏弹性**。

**【2022·单选】关于边际消费倾向、平均消费倾向及其相互关系的说法，正确的是（　）。**

**【2022·单选】边际消费倾向 0.75，投资（财政支出）增加 100 万，下列说法正确的是（　）。**

**【2022·单选】以下属于莫迪利安尼的生命周期消费理论的是（　）。**
A. 边际消费倾向总是小于平均消费倾向
B. 在人口构成没有发生重大变化的情况下，从长期来看，边际消费倾向是稳定的，消费支出与可支配收入和实际国民生产总值之间存在一种稳定的关系
C. 消费者的消费支出不是根据他的当前收入决定的，而是根据他的持久收入决定的
D. 平均消费倾向随着收入的增加而减少

**答案：B**
**解析**：莫迪利安尼的生命周期消费理论认为，各个家庭的消费取决于他们在整个生命周期内所获得的收入与财产，即消费取决于家庭所处的生命周期阶段。在人口构成没有发生重大变化的情况下，从长期来看，边际消费倾向是稳定的，消费支出与可支配收入和实际国民生产总值之间存在一种稳定的关系。如果一个社会的人口构成比例发生变化，则边际消费倾向也会发生变化：社会上年轻人和老年人的比例增大，则消费倾向会提高；中年人的比例增大，则消费倾向会降低。
A、D 属于凯恩斯消费理论的结论；C 属于弗里德曼持久收入理论的观点。

**【2025·单选】价格总水平通过影响汇率变动从而影响出口需求的变化导致净出口与总需求变化的现象，称为（　）。**
A. 财富效应　B. 出口效应　C. 收入—物价效应　D. 汇率—利率效应

**答案：B**
**解析**：一个国家或地区的出口需求与汇率变化关系密切，而汇率在很大程度上受价格总水平的影响。在固定汇率制度下，价格总水平上升使国内产品与进口产品的比价发生变化，国内产品价格升高，进口产品相应地变得便宜，消费者和企业就会增加对进口产品的购买而减少对国内产品的购买，导致进口增加、出口下降；反之，价格总水平下降则会刺激出口、抑制进口。而在浮动汇率制度下，价格总水平上升会使利率上升，从而吸引国外资本流入，给本国货币带来升值压力，使得进口产品价格相对便宜，出口需求相应下降。这种由价格总水平通过汇率变动影响出口需求的变化并与总需求呈反方向变化的现象被称为"**出口效应**"。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把 GNI 当成 GDP 的别名，或把 GDP 叫"国民生产总值" | GNI＝GDP＋来自国外的净要素收入；GDP 是**生产**概念，GNI 是**收入**概念 |
| 2 | GDP 形态多选"支出形态""实物形态" | 只有**价值、收入、产品**三种形态 |
| 3 | GDP 计算方法选"市场价格法""不变价格法" | 三种方法＝**生产法、支出法、收入法** |
| 4 | 收入法 GDP 多选"原材料总投入/中间投入" | 收入法四项：劳动者报酬＋固定资产折旧＋生产税净额＋营业盈余 |
| 5 | 把"营业盈余"算进劳动者报酬 | 营业盈余是独立一项；劳动者报酬是工资、福利、实物报酬、农户个体纯收益 |
| 6 | 生产税净额减的是"中间投入/折旧" | 生产税净额＝生产税 **− 生产补贴** |
| 7 | 支出法把净出口写成 X＋M | 必须是 **X − M**（出口减进口） |
| 8 | 把"固定资本形成/存货增加"算进最终消费 | 最终消费＝居民消费＋政府消费；固定资本形成与存货增加属**资本形成总额** |
| 9 | 三部门恒等式写成 I＝S＋T−G 不带括号 | 必须写成 **I＝S＋(T−G)**，括号表示政府净储蓄 |
| 10 | 四部门恒等式最后一项写成 X−M | 四部门是 **I＝S＋(T−G)＋(M−X)**，与支出法的 X−M 方向相反 |
| 11 | 认为 MPC 可能大于 1 | **0＜MPC＜1**；可能大于、等于、小于 1 的是 APC |
| 12 | 记反 MPC 与 APC 的大小关系 | 口诀"**平大边际**"：APC 总大于 MPC |
| 13 | 三个消费理论的观点张冠李戴 | 认公式：C＝α＋βY 凯恩斯；C＝a·WR＋c·YL 生命周期；Ct＝c·YPt 持久收入 |
| 14 | 把"储蓄与消费的依存关系"当储蓄函数 | 储蓄和**收入**之间的依存关系才叫储蓄函数 |
| 15 | 把金融投资算作投资 | 投资是形成固定资产的活动，一般**不含金融投资** |
| 16 | 投资乘数记成 1/MPC | K＝**1/(1−MPC)**＝1/MPS，是 MPS 的倒数，不是 MPC 的倒数 |
| 17 | 认为投资乘数取决于平均消费倾向 | 取决于**边际消费倾向 β** |
| 18 | 认为长期总供给曲线向右上方倾斜 | 短期 SRAS 向右上；**长期 LRAS 垂直于横轴**，与价格无关 |
| 19 | 把政府购买当成影响总供给的因素 | 政府购买影响**总需求**；影响总供给的基本因素是**价格与成本** |
| 20 | 算均衡国民收入只做到 α＋Ī 就停 | 分子 α＋Ī 还要**除以 (1−β)**：C＝100＋0.8Y、I＝460 → (100+460)/0.2＝2800 |
