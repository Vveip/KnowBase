## 二、知识点精讲

### 考点1 会计报表的概念 ★★

**核心概念**：会计报表是以**日常账簿资料**为主要依据编制的，总括反映企业**财务状况、经营成果和现金流量**等会计信息的书面文件。会计报表是**会计核算环节的最后一个环节，也是会计循环过程的终点**。

**一套完整的会计报表至少应包括**：

| 报表 | 反映内容 |
|---|---|
| 资产负债表 | 反映企业在**某一特定日期**财务状况的报表 |
| 利润表 | 反映企业在**一定会计期间**经营成果的报表 |
| 现金流量表 | 反映企业在**一定会计期间**现金和现金等价物流入和流出情况的报表 |
| 所有者权益变动表 | 反映构成所有者权益的**各组成部分当期的增减变动**情况的报表 |
| 附注（财务报表附注） | 对上述报表中列示项目的**文字描述或明细资料**，以及对未能在这些报表中列示项目的说明 |

**速记口诀**：**"账簿编报表，核算最后一环；三表一变动，外加一附注。"**

> 【经典例题·单选】会计核算工作中，以日常会计账簿资料为主要依据定期编制的，包括反映企业财务状况、经营成果和现金流量等会计信息的书面文件是（　）。A.财务分析报告　B.决算报告　C.会计凭证　D.会计报表——**答案 D**。会计凭证是登记账簿的依据，财务分析报告、决算报告不属于会计报表范畴。

---

### 考点2 会计报表的目标和作用 ★

**两大目标**：
1. 向会计报表使用者提供与企业财务状况、经营成果和现金流量等有关的信息，以帮助会计信息使用者**做出经济决策**；
2. 反映企业管理层的**受托责任履行**情况，有助于评价企业的**经营管理责任以及资源使用的有效性**。

**三大作用**：

| 使用者 | 作用 |
|---|---|
| 投资者、债权人 | 进行正确**投资决策和信贷决策**的依据；也是投资者评估企业管理层受托资源的经营管理责任履行情况的依据 |
| 企业管理者 | 据以考核和分析企业**财务成本计划或预算**的完成情况，评价企业经济效益 |
| 国家有关部门 | 了解和掌握各部门、各地区的**经济运行情况** |

**速记口诀**：**"目标两条：决策有用＋受托责任；作用三方：投资者债权人、管理者、国家部门。"**

---

### 考点3 会计报表的编制要求 ★★（含编制前准备工作）

**三项编制要求**：
1. 在编制会计报表前应当依法对**会计账簿记录**（包括总账、明细账、日记账和其他辅助性账簿）进行审核，内容要全面；
2. 会计报表的编制应当符合**《会计法》和国家统一会计制度**关于会计报表的编制要求、提供对象和提供期限的规定；
3. 企业编制的会计报表应当**真实可靠、全面完整、编报及时、便于理解**。

**编制前的两项准备工作**：

| 准备工作 | 具体内容 |
|---|---|
| 全面财产清查 | 全面清查资产、核实债务 |
| 检查会计事项的处理结果 | ①账证核对；②定期结账，进行账账核对；③检查会计核算是否合法；④没有规定统一核算方法的，检查是否按会计核算一般原则进行处理；⑤检查是否存在因会计差错、会计政策变更等原因需要调整前期或者本期相关项目 |

**速记口诀**：**"先审账簿再编表，四词要求要记牢：真实、完整、及时、易懂；准备工作两条线：清查债务＋查账务。"**

> 【经典例题·多选】编制财务会计报表前准备工作包括（　）。A.全面财产清查　B.全面核实债务　C.检查税收是否完全缴纳　D.检查企业经营目标是否实现　E.检查会计事项的处理结果——**答案 ABE**。编前准备只包括全面财产清查（清查资产、核实债务）和检查会计事项的处理结果两大类；缴纳税金、实现经营目标不属于编前准备工作。

### 考点4 资产负债表的概念和作用 ★★

| 维度 | 内容 |
|---|---|
| 概念 | 反映企业在**某一特定日期**财务状况的会计报表，是按一定标准和顺序适当排列编制的，反映某一特定日期全部**资产、负债和所有者权益**情况的会计报表 |
| 报表状态 | **月度报表**，反映**静态**财务状况 |
| 编制基础 | 以"**资产＝负债＋所有者权益**"这一基本等式为基础编制 |

**四点作用**：
1. 为报表使用者提供企业所拥有或控制的经济资源及这些经济资源的**分布和构成**的信息；
2. 总括反映企业**资金的来源渠道和构成情况**；
3. 通过分析可以了解企业的**财务状况，判断企业的偿债能力和支付能力**；
4. 通过前后期资产负债表的对比分析，了解企业**资金结构的变化情况**和变化趋势。

**速记口诀**：**"静态月度表，家底一天清；资源分布＋来源渠道＋偿债支付＋趋势变化。"**

> 【经典例题·多选】一般情况下，下列账户的期末余额应列入资产负债表中流动负债类（　）。A.长期股权投资　B.预付账款　C.其他应付款　D.应付账款　E.存货——**答案 CD**。A 属非流动资产；B、E 属流动资产；只有其他应付款、应付账款是偿还期在一年以内的负债。

### 考点5 资产负债表的格式和内容 ★★★

**两种格式**：**账户式**和**报告式**——**我国采用账户式**资产负债表。

**三大内容板块及排列规则**：

| 板块 | 分类 | 内容 | 排列规则 | 排列顺序 |
|---|---|---|---|---|
| 资产类项目 | 流动资产 | 在**一年或一个经营周期以内**可以变现的全部资产，包括一年内耗用和售出的全部资产 | 按**流动性（变现能力）**排列，**流动性强的在前，流动性差的在后** | 货币资金、短期投资（交易性金融资产）、应收票据及应收账款、预付账款、其他应收款、存货、待摊费用等 |
| | 非流动资产 | 变现能力在**一年或一个经营周期以上**的资产 | 同上 | 长期股权投资、固定资产、在建工程、无形资产、其他非流动资产 |
| 负债类项目 | 流动负债 | 偿还期在**一年以内**的全部负债 | 按**到期日的远近**排列，**先到期的排在前，后到期的排在后** | 短期借款、应付票据及应付账款、预收款项、应付职工薪酬、应交税费、应付股利、其他应付款、持有待售负债、一年内到期的非流动负债 |
| | 非流动负债 | 偿还期在**一年以上**的全部负债 | 同上 | 长期借款、应付债券、长期应付款、其他非流动负债 |
| 所有者权益项目 | 投入资本、资本公积、盈余公积、未分配利润 | 按实收资本（股本）→资本公积→盈余公积→未分配利润顺序排列 | —— | 口诀：**"实资未盈"** |

**速记口诀**：**"账户式我国用；资产看变现（由强到弱），负债看到期（由近到远）；所有者权益实资未盈。"**

> 【经典例题】在资产负债表上，资产按流动性排列，流动性强的排在前面。排在应收账款前面的是（　）。A.固定资产　B.长期投资　C.存货　D.货币资金——**答案 D**。解析：流动资产在前（货币资金、应收票据及应收账款、预付账款、其他应收款、存货和待摊费用等），再到长期股权投资、固定资产、在建工程、无形资产等非流动资产。

> 【经典例题】①我国企业的资产负债表中，资产类项目的排序规则是（　）。A.按照资产的变现能力顺序由快到慢排列　B.由慢到快排列　C.按照资产金额由大到小　D.按照各项资产占总资产的比重由大到小——**答案 A**。②下列资产项目中，流动性最强的是（　）。A.存货　B.固定资产　C.长期股权投资　D.应收票据——**答案 D**。③资产负债表中负债项目按照（　）进行排列。A.到期日的远近　B.金额大小　C.发生时间先后　D.重要程度——**答案 A**。

### 考点6 资产负债表的编制方法 ★★

**两个时点栏目**：各项目分别填列"**年初数（余额）**"和"**期末数（余额）**"。
- 年初数：根据**上年末资产负债表的期末数**填列或调整填列；
- 期末数：根据相应的总账科目期末余额填列，方法有**直接填列法**和**分析计算填列法**两种。

**填列方法归类表（必背）**：

| 方法 | 规则 | 适用项目 |
|---|---|---|
| **直接填列法** | 根据**总账科目**的期末余额直接填列 | 短期借款、应付职工薪酬、应交税费、实收资本、资本公积、盈余公积 |
| **分析计算填列法** | ①根据**若干总账科目**期末余额分析计算填列 | **货币资金**（库存现金＋银行存款＋其他货币资金）、**未分配利润**（本年利润和利润分配科目余额之和或之差） |
| | ②根据总账科目期末余额与其**备抵科目抵销后**的数据填列 | 固定资产、在建工程、无形资产、长期股权投资、其他应收款、持有待售资产 |
| | ③根据有关**明细账**期末余额分析计算填列 | **预收账款**（根据"应收账款"和"预收账款"账户所属明细账贷方余额之和填列）、**其他应付款**（根据"其他应收款"和"其他应付款"两个总账科目所属明细账期末贷方余额之和填列） |
| | ④根据**总账科目和明细科目**余额分析计算填列 | 长期借款、其他非流动负债中**一年内到期的列入一年内非流动负债**项目、**存货**（物资采购、原材料、包装物、低值易耗品、自制半成品、生产成本、库存商品、材料成本差异等科目期末借方余额之和，减去存货跌价准备后的金额） |

**速记口诀（素材"匠匠总结"）**：
```
1. 直接填：短借薪税、实收公积盈余
2. 加总填：库现＋银存＋其他币＝货币资金、未分配利润
3. 净额填：固资/无形/长投，减备抵科目
4. 分明细：往来借贷重分类（应收预收、其他应收应付，合并填列）
5. 分期限：长债一年内，单独划流动
```

> 【经典例题·多选】在资产负债表中，根据有关明细账期末余额分析计算填列的项目有（　）。A.应付工资　B.固定资产　C.实收资本　D.应付账款　E.预收账款——**答案 DE**。

> 【经典例题·单选】①下列资产负债表项目中，根据若干总账科目期末余额分析计算填列的是（　）。A.货币资金　B.长期借款　C.短期借款　D.资本公积——**答案 A**（若干总账科目期末余额分析计算填列的包括货币资金和未分配利润）。②在资产负债表中，根据总账科目余额直接填列的项目是（　）。A.应收账款　B.短期借款　C.预付账款　D.存货——**答案 B**。

### 考点7 利润表的概念和作用 ★★

| 维度 | 内容 |
|---|---|
| 概念 | 反映企业在**一定会计期间经营成果**的报表 |
| 编制基础 | 依据**权责发生制原则和配比原则**的要求，以"**收入－费用＝利润**"的会计等式为基础，按照各项收入、费用以及构成利润的各个项目分类分项编制而成的**动态**会计报表 |
| 报表状态 | **月度报表** |
| 作用 | 为报表使用者提供企业**盈利能力**方面的信息 |

**速记口诀**：**"动态月度表，一段期间成果单；权责发生配比原则，收入减费用出利润。"**

> 【经典例题·多选】企业利润表的作用在于（　）。A.提供企业盈利能力方面的信息　B.提供企业所拥有或控制的经济资源及其分布和构成情况的信息　C.提供企业财务状况、偿还能力和支付能力的信息　D.反映企业在一定会计期间的经营结果　E.反映企业在一定会计期间内现金的流动情况——**答案 AD**。B、C 为资产负债表的作用；E 为现金流量表的作用。

> 【经典例题·单选】利润表是反映企业在一定会计期间（　）的报表。A.财务状况　B.经营成果　C.盈利能力　D.管理水平——**答案 B**。财务状况是资产负债表反映的内容。

### 考点8 利润表的格式和内容 ★★

**两种格式**：**单步式**和**多步式**——**我国目前采用多步式**利润表。多步式利润表分为**正表**和**补充资料**两大部分。

**三级利润计算公式（必考）**：

| 层级 | 计算公式 |
|---|---|
| **营业利润** | 营业利润＝营业收入－营业成本－税金及附加－销售费用－管理费用－研发费用－财务费用－资产减值损失－信用减值损失＋其他收益＋投资收益＋公允价值变动收益＋资产处置收益 |
| **利润总额** | 利润总额＝营业利润＋（营业外收入－营业外支出） |
| **净利润** | 净利润＝利润总额－所得税（费用） |

> **提示（高频陷阱）**：**不影响营业利润**的项目是——**营业外收入、营业外支出、所得税费用**。营业外收支影响的是**利润总额**，所得税影响的是**净利润**。

**速记口诀**：**"营业利润加减十项，营业外收支进利润总额，所得税最后抠出净利润；三笔'营业外＋税'，营业利润不沾边。"**

> 【经典例题·单选】下列会计项目中，对利润表中营业利润具有影响的是（　）。A.营业外收入　B.营业外支出　C.所得税　D.财务费用——**答案 D**。解析：营业外收入、营业外支出及所得税均不影响营业利润。

> 【经典例题·单选】下列会计项目中，对利润表中利润总额不具有影响的是（　）。A.营业外收入　B.营业外支出　C.所得税　D.财务费用——**答案 C**。解析：所得税对净利润有影响，对利润总额没有影响。

> 【经典例题·多选】利润表的基本格式主要有（　）。A.账户式　B.单步式　C.多步式　D.报告式　E.复合式——**答案 BC**。账户式、报告式是资产负债表的格式。

### 考点9 利润表的编制方法 ★★

利润表一般设有"**本月数**"和"**本年累计数**"两栏：
1. "本月数"栏反映各项目的**本月实际发生数**；
2. "本年累计数"栏反映各项目**自年初起至本月末止的累计实际发生数**，编报时应根据有关**损益类科目的本期累计发生额**计算填列。

**速记口诀**：**"两栏：本月实际数＋年初至今累计数；累计看损益类发生额。"**

### 考点10 现金流量表的概念和作用 ★★★

**核心概念**：现金流量表是反映企业在一定会计期间有关**现金和现金等价物的流入和流出**的报表。

| 概念 | 内容 |
|---|---|
| **现金** | 企业的库存现金、可以随时用于支付的存款，包括**库存现金、银行存款、其他货币资金** |
| **现金等价物** | 企业持有的**期限短、流动性强、易于转换为已知金额的现金、价值变动风险很小**的投资 |
| **现金流量** | 指一定会计期间内企业现金和现金等价物**流入和流出的数量** |

**影响现金流量的三大活动**：

| 活动 | 概念 | 举例 |
|---|---|---|
| **经营活动** | 企业**投资活动和筹资活动以外的所有交易和事项** | 销售商品或提供劳务、购买原材料或接受劳务等 |
| **投资活动** | 企业**长期资产的购建**和不包括在现金等价物范围内的**投资及其处置活动** | 购建和处置固定资产、无形资产等 |
| **筹资活动** | 导致企业**资本及债务规模和构成发生变化**的活动 | 发行股票、从银行取得借款等 |

**判断是否影响现金流量的两条铁律（必考）**：

```
① 只涉及「现金各项目之间」的变动（如从银行提取现金、将现金存入银行）
   或只涉及「非现金项目之间」的变动（如以固定资产清偿债务、
   用原材料或固定资产对外投资）→ 不影响现金流量
② 只有涉及「现金项目」与「非现金项目」之间的变动
   （如用现金购买材料、用现金对外投资、收回长期债券投资）
   → 才会影响现金流量
```

**三点作用**：①便于使用者了解和评价企业**获取现金的能力**，预测未来现金流量；②说明企业一定期间内现金流入和流出的原因，说明企业**偿债能力和支付股利的能力**；③分析企业未来获取现金的能力，分析投资和理财活动对经营成果和财务状况的影响，有助于对企业的整体财务状况作出客观评价。

**速记口诀**：**"现金三兄弟：库存现金、银行存款、其他货币资金；三大活动：经营是日常、投资买长期资产、筹资动本钱；现金内部转、非现金对调，都不算数。"**

> 【经典例题·多选】影响企业现金流量的因素包括（　）。A.生产活动　B.经营活动　C.投资活动　D.筹资活动　E.管理活动——**答案 BCD**。

> 【经典例题·单选】在企业发生的下列经济业务中，影响现金流量的有（　）。A.现金存入银行　B.用固定资产偿还债务　C.用原材料对外投资　D.用银行存款购买材料——**答案 D**。A 属现金之间的变动；B、C 属非现金项目之间的变动，均不影响现金流量。

> 【经典例题·多选】企业编制现金流量表的作用在于（　）。A.提供企业一定会计期间内现金和现金等价物流入和流出的信息　B.提供企业盈利能力方面的信息　C.提供企业所拥有和控制的经济资源及其构成的信息　D.提供企业财务状况、偿债能力和支付能力的信息——**答案 A**。B 为利润表的作用；C、D 为资产负债表的作用。

### 考点11 现金流量表的内容和格式 ★★

现金流量表属于**年度报表**，由**报表正表**和**补充资料**两部分组成。

| 部分 | 具体内容 |
|---|---|
| **正表** | ①是现金流量表的**主体**，现金流量的信息主要由正表提供；②正表采用**报告式**，依次分类反映**经营活动、投资活动、筹资活动**现金流量，最后汇总反映企业**现金和现金等价物增加额** |
| **补充资料** | 包括三个部分：①**将净利润调节为经营活动现金流量**（即按间接法编制经营活动现金流量）；②**不涉及现金收支的投资和筹资活动**；③**现金及现金等价物净增加情况** |

**速记口诀**：**"年度报表两份家：正表报告式列三类活动，补充资料三段话。"**

### 考点12 现金流量表的编制方法 ★★

**总原则**：我国企业应按**直接法**编制现金流量表**正表**，在**补充资料**中提供按**间接法**将净利润调节为经营活动现金流量的信息。

**（一）正表三大活动的现金流量项目**

| 活动 | 流入项目 | 流出项目 |
|---|---|---|
| **经营活动** | ①销售商品、提供劳务收到的现金；②收到的税费返还；③收到的其他与经营活动有关的现金 | ①购买商品、接受劳务支付的现金；②支付给职工以及为职工支付的现金；③支付的各项税费；④支付的其他与经营活动有关的现金 |
| **投资活动** | ①收回投资所收到的现金；②取得投资收益所收到的现金；③处置固定资产、无形资产和其他长期资产所收回的现金净额；④处置子公司及其他营业单位收到的现金净额；⑤收到的其他与投资活动有关的现金 | ①购建固定资产、无形资产和其他长期资产所支付的现金；②投资支付的现金；③取得子公司和其他营业单位支付的现金净额；④支付的其他与投资活动有关的现金 |
| **筹资活动** | ①吸收投资收到的现金；②取得借款收到的现金；③收到的其他与筹资活动有关的现金 | ①偿还债务支付的现金；②分配股利、利润或偿付利息支付的现金；③支付的其他与筹资活动有关的现金 |

**（二）正表各项目的关系**

```
经营活动产生的现金流量净额 = 经营活动现金流入量 − 经营活动现金流出量
投资活动产生的现金流量净额 = 投资活动现金流入量 − 投资活动现金流出量
筹资活动产生的现金流量净额 = 筹资活动现金流入量 − 筹资活动现金流出量

现金及现金等价物净增加额
   = 经营活动净额 + 投资活动净额 + 筹资活动净额
   + 汇率变动对现金的影响额
```

**（三）补充资料的三个部分**

1. **将净利润调节为经营活动现金流量（间接法）**：以净利润为基础，需要加以调整的项目分为**四大类**——①没有实际支付现金的费用；②没有实际收到现金的收益；③不属于经营活动的损益；④经营性应收应付项目的增减变动；
2. **不涉及现金收支的投资和筹资活动**（特别注意）：应作为重要信息在补充资料中反映，包括：①**债务转为资本**；②**一年内到期的可转换企业债券**；③**融资租入固定资产**；
3. **现金及现金等价物净增加情况**：净增加额＝（现金期末余额－现金期初余额）＋（现金等价物期末余额－现金等价物期初余额）。

> **注意**：补充资料中的"现金及现金等价物净增加额"与正表中最后一项"现金及现金等价物净增加额"项目的金额**应当相等**。

**速记口诀（素材"匠匠口诀"）**：
```
经营：销货回款税返还，日常营收都进来；进货发薪交税费，经营开销往外飞
投资：卖资收本拿红利，投资回款归这里；买产投钱往外花，长期投入属投资
筹资：募资借款引股本，筹钱进账记分明；还本付息分红利，出钱还贷是筹资
方法：正表直接法，补充间接法；间接调整四大类，无现金费用收益、
     非经营损益、经营性应收应付
```

> 【经典例题·单选】①我国企业现金流量表编制的方法是（　）。A.采用间接法编制正表，补充资料中提供按直接法将净利润调节为经营活动现金流量的信息　B.采用直接法编制正表，补充资料中提供按间接法将净利润调节为经营活动现金流量的信息　C.正表和补充资料均采用直接法　D.正表和补充资料均采用间接法——**答案 B**。②支付给职工以及为职工支付的现金属于（　）产生的现金流量。A.汇率变动　B.筹资活动　C.经营活动　D.投资活动——**答案 C**。

> 【经典例题·多选】①下列经济业务中，因经营活动而引起的现金流入有（　）。A.收到咨询收入　B.销售商品取得货款　C.收到出口退税　D.收到银行借款　E.处置固定资产取得现金——**答案 ABC**（收到银行借款属筹资活动；处置固定资产取得现金属投资活动；另一版本选项中"收到投资收益"同理属投资活动，不选）。②以下属于"投资活动现金流量"项目的是（　）。A.取得投资收益所收到的现金　B.销售商品、提供劳务收到的现金　C.购买商品、接受劳务支付的现金　D.购建固定资产、无形资产和其他长期资产所支付的现金　E.收回投资所收到的现金——**答案 ADE**（B、C 属经营活动）。

> 【经典例题·单选】①下列经济业务所产生的现金流量中，应列入"投资活动产生的现金流量"项目的是（　）。A.支付设备价款　B.支付应交税费　C.支付职工薪酬　D.支付现金股利——**答案 A**（B、C 属经营活动；D 属筹资活动）。②应列入"经营活动产生的现金流量"项目的是（　）。A.变卖固定资产收回的现金　B.支付经营租赁费用付出的现金　C.取得投资收益收到的现金　D.取得银行借款收到的现金——**答案 B**（A、C 属投资活动；D 属筹资活动）。

> 【经典例题·多选】编制现金流量表时，为了将净利润调节为经营活动的现金流量，需要以净利润为基础，采用间接法加以调整的项目有（　）。A.没有实际支付现金的费用　B.没有实际收到现金的收益　C.不属于经营活动的损益　D.经营性应收应付项目的增减变动　E.不涉及现金的投资活动——**答案 ABCD**。

| **分析计算填列法②**（总账余额与备抵科目抵销后） | 固定资产、在建工程、无形资产、长期股权投资、其他应收款、持有待售资产 |
| **分析计算填列法③**（有关明细账期末余额分析计算） | **预收账款**（"应收账款"和"预收账款"所属明细账贷方余额之和）、**其他应付款**（"其他应收款"和"其他应付款"所属明细账期末贷方余额之和） |
| **分析计算填列法④**（总账科目和明细科目余额分析计算） | 长期借款、一年内到期的非流动负债（长债一年内单独划流动）、**存货**（物资采购、原材料、包装物、低值易耗品、自制半成品、生产成本、库存商品、材料成本差异等借方余额之和－存货跌价准备） |

### 表4 「18 个不等于」避坑表

| # | 错误说法 | 正解 |
|---|---|---|
| 1 | 会计报表就是三张表 | ✗ 一套完整的会计报表至少还包括**所有者权益变动表和附注** |
| 2 | 附注是独立于会计报表之外的文件 | ✗ 附注是**一套完整会计报表的组成部分** |
| 3 | 资产负债表反映企业"一定会计期间"的财务状况 | ✗ 是"**某一特定日期**"；"一定会计期间"是利润表、现金流量表 |
| 4 | 利润表反映企业"某一特定日期"的经营成果 | ✗ 是"**一定会计期间**" |
| 5 | 现金流量表是月度报表 | ✗ 是**年度报表**（资产负债表、利润表才是月度报表） |

| 7 | 我国采用单步式利润表 | ✗ 我国采用**多步式** |

| 9 | 资产类项目按到期日远近排列 | ✗ 资产按**流动性（变现能力）**由强到弱；按到期日远近排列的是**负债** |
| 10 | 预收账款根据总账科目余额直接填列 | ✗ 应根据"应收账款"和"预收账款"所属**明细账贷方余额之和**填列 |
| 11 | 未分配利润根据总账余额直接填列 | ✗ 根据**本年利润和利润分配**科目余额**之和或之差**填列 |
| 12 | 货币资金等于库存现金 | ✗ 货币资金＝库存现金＋银行存款＋**其他货币资金** |
| 13 | 固定资产按总账余额直接填列 | ✗ 按总账余额与其**备抵科目（累计折旧、减值准备）抵销后**的净额填列 |
| 14 | 营业外收支影响营业利润 | ✗ 营业外收入、营业外支出**不影响营业利润**，影响的是**利润总额** |
| 15 | 所得税费用影响利润总额 | ✗ 所得税只影响**净利润**，对利润总额没有影响 |
| 16 | 从银行提取现金、将现金存入银行会影响现金流量 | ✗ 属**现金各项目之间的变动**，不影响现金流量 |
| 17 | 以固定资产清偿债务、用原材料对外投资会影响现金流量 | ✗ 属**非现金项目之间的变动**，不影响现金流量 |
| 18 | 补充资料与正表的"现金及现金等价物净增加额"可以不相等 | ✗ 两者金额**应当相等** |

## 四、公式与计算（本章计算题重点）

### 计算点1 资产负债表的编制——各项目期末余额计算

**公式总览**：

```
货币资金 = 库存现金 + 银行存款 + 其他货币资金
未分配利润 = 本年利润科目余额 + 利润分配科目余额（方向相反时取之差）
预收账款项目 = 应收账款明细账贷方余额 + 预收账款明细账贷方余额
存货项目 = （物资采购 + 原材料 + 包装物 + 低值易耗品 + 自制半成品
           + 生产成本 + 库存商品 + 材料成本差异等借方余额）－ 存货跌价准备
固定资产项目 = 固定资产总账期末余额 － 累计折旧 － 固定资产减值准备
```

**例题 1（货币资金，按素材规则自编演算）**：某企业期末"库存现金"科目借方余额 5 万元，"银行存款"科目借方余额 200 万元，"其他货币资金"科目借方余额 15 万元。资产负债表"货币资金"项目期末余额为多少？

```
货币资金 = 5 + 200 + 15 = 220（万元）
```

**例题 2（应收账款项目，按"往来借贷重分类"规则自编演算）**：某企业"应收账款"所属明细账期末借方余额合计 120 万元；"预收账款"所属明细账中存在借方余额 30 万元（实质为应收性质的债权）。

```
应收账款项目 = 应收账款明细账借方余额 + 预收账款明细账借方余额
             = 120 + 30 = 150（万元）
```

> 说明：素材明确给出的是"预收账款、其他应付款按明细账贷方余额合并填列"及"往来借贷重分类（应收预收、其他应收应付，合并填列）"原则，本题按同一重分类原理演算，帮助理解"应收"与"预收"对冲列示的逻辑。

**例题 3（预收账款项目，按素材规则自编演算）**：某企业"应收账款"所属明细账贷方余额合计 20 万元，"预收账款"所属明细账贷方余额合计 80 万元。

```
预收账款项目 = 20 + 80 = 100（万元）
```

**例题 4（存货项目，按素材规则自编演算）**：某企业期末"原材料"借方余额 100 万元、"生产成本"借方余额 50 万元、"库存商品"借方余额 60 万元、"材料成本差异"借方余额 5 万元，"存货跌价准备"贷方余额 15 万元。

```
存货项目 = (100 + 50 + 60 + 5) － 15 = 215 － 15 = 200（万元）
```

**例题 5（未分配利润项目，按素材规则自编演算）**：某企业期末"本年利润"科目贷方余额 300 万元，"利润分配"科目借方余额（累计未弥补亏损）50 万元。

```
未分配利润 = 300 － 50 = 250（万元）（方向相反，取之差）
```

**例题 6（固定资产项目，按素材规则自编演算）**：某企业"固定资产"总账期末余额 1 000 万元，"累计折旧"贷方余额 300 万元，"固定资产减值准备"贷方余额 50 万元。

```
固定资产项目 = 1 000 － 300 － 50 = 650（万元）
```

### 计算点2 利润表的计算——营业利润、利润总额、净利润

**公式链**：

```
营业利润 = 营业收入 － 营业成本 － 税金及附加 － 销售费用 － 管理费用
          － 研发费用 － 财务费用 － 资产减值损失 － 信用减值损失
          + 其他收益 + 投资收益 + 公允价值变动收益 + 资产处置收益
利润总额 = 营业利润 +（营业外收入 － 营业外支出）
净利润   = 利润总额 － 所得税（费用）
```

**例题 1（2023 真题）**：某企业 2022 年共取得营业收入 2 000 万元，发生营业成本 1 200 万元、税金及附加 340 万元、销售费用 100 万元、管理费用 420 万元，取得投资收益 120 万元，发生资产处置收益 20 万元，营业外收入 10 万元、营业外支出 20 万元。该企业当年的营业利润是（　）万元。
A.－60　B.70　C.90　D.80

```
营业利润 = 2000 － 1200 － 340 － 100 － 420 + 120 + 20
        = 800 － 340 = 460
        = 460 － 100 = 360
        = 360 － 420 = －60
        = －60 + 120 = 60
        = 60 + 20 = 80（万元）
（营业外收入 10 万元、营业外支出 20 万元不影响营业利润）
```

**答案：D（80 万元）**。

**例题 2（利润总额与净利润，接上题数据续算）**：该企业营业利润 80 万元，营业外收入 10 万元、营业外支出 20 万元，所得税费用 20 万元。

```
利润总额 = 80 +（10 － 20）= 70（万元）
净利润   = 70 － 20 = 50（万元）
```

> 说明：营业外收支取自 2023 真题原题数据；所得税费用 20 万元为自编假设值，仅用于演示"利润总额→净利润"的扣减关系。

### 计算点3 现金流量表的计算——现金流量净额

**公式**：

```
各活动现金流量净额 = 该活动现金流入量 － 该活动现金流出量
现金及现金等价物净增加额
   = 经营活动现金流量净额 + 投资活动现金流量净额
   + 筹资活动现金流量净额 + 汇率变动对现金的影响额

补充资料口径：现金及现金等价物净增加额
   =（现金期末余额 － 现金期初余额）+（现金等价物期末余额 － 现金等价物期初余额）
```

**例题（2006 年真题）**：某企业经营活动产生的现金流入量为 3 000 万元，现金流出量为 2 400 万元；投资活动产生的现金流入量为 300 万元，现金流出量为 1 400 万元；筹资活动产生的现金流入量为 1 500 万元，现金流出量为 1 000 万元；汇率变动导致现金流入量为 100 万元。该企业当年现金流量表上，现金和现金等价物净增加额为（　）万元。
A.100　B.600　C.4 900　D.0

```
（1）经营活动现金流量净额 = 3 000 － 2 400 = 600（万元）
（2）投资活动现金流量净额 = 300 － 1 400 = －1 100（万元）
（3）筹资活动现金流量净额 = 1 500 － 1 000 = 500（万元）
（4）汇率变动对现金的影响额 = 100（万元）

现金及现金等价物净增加额 = 600 +（－1 100）+ 500 + 100 = 100（万元）
```

**答案：A（100 万元）**。

## 五、高频考点速记卡

1. **Q：什么是会计报表？其地位如何？**
   A：以**日常账簿资料**为主要依据编制的，总括反映企业财务状况、经营成果和现金流量等会计信息的书面文件；是**会计核算环节的最后一个环节，也是会计循环过程的终点**。

2. **Q：一套完整的会计报表至少应包括哪些？**
   A：**资产负债表、利润表、现金流量表、所有者权益（或股东权益）变动表和财务报表附注**。

3. **Q：编制会计报表的两大目标与四项编制要求？**
   A：目标：①提供与财务状况、经营成果和现金流量等有关的信息，帮助使用者**做出经济决策**；②反映企业管理层的**受托责任履行**情况。要求：**真实可靠、全面完整、编报及时、便于理解**。

4. **Q：编制会计报表前的两项准备工作？**
   A：①**全面财产清查**（全面清查资产、核实债务）；②**检查会计事项的处理结果**（账证核对、定期结账与账账核对、检查核算合法性等）。

5. **Q：资产负债表的编制基础是什么？反映什么状态的财务状况？**
   A：以"**资产＝负债＋所有者权益**"为编制基础，反映企业**静态**财务状况，属**月度报表**。

6. **Q：资产负债表的两种格式？我国采用哪种？**
   A：**账户式**和**报告式**；我国采用**账户式**。

7. **Q：资产类项目和负债类项目各按什么规则排列？**
   A：资产按**流动性（变现能力）**由强到弱排列；负债按**到期日的远近**排列，先到期的在前。

8. **Q：所有者权益包括哪些项目？排列顺序如何？**
   A：**实收资本（股本）、资本公积、盈余公积、未分配利润**（口诀"实资未盈"）。

9. **Q：资产负债表各项目分别填列哪两个时点的数据？期末数有哪两种填列方法？**
    A："**年初数（余额）**"（根据上年末资产负债表的期末数填列或调整填列）和"**期末数（余额）**"；期末数填列方法有**直接填列法**和**分析计算填列法**两种。

10. **Q：哪些项目根据总账科目期末余额直接填列？**
    A：**短期借款、应付职工薪酬、应交税费、实收资本、资本公积、盈余公积**。

11. **Q：货币资金与未分配利润项目如何填列？**
    A：货币资金＝**库存现金＋银行存款＋其他货币资金**（合计数）；未分配利润＝**本年利润和利润分配**科目期末余额**之和或之差**。

12. **Q：哪些项目按总账余额与备抵科目抵销后的数据填列？**
    A：**固定资产、在建工程、无形资产、长期股权投资、其他应收款、持有待售资产**。

13. **Q：预收账款项目如何填列？**
    A：根据"应收账款"和"预收账款"账户所属**明细账贷方余额之和**填列（其他应付款同理，按"其他应收款"和"其他应付款"明细账贷方余额之和填列）。

14. **Q：存货项目如何填列？**
    A：物资采购、原材料、包装物、低值易耗品、自制半成品、生产成本、库存商品、材料成本差异等科目期末**借方余额之和，减去存货跌价准备**。

15. **Q：利润表的编制基础和会计恒等式？**
    A：依据**权责发生制原则和配比原则**，以"**收入－费用＝利润**"为基础编制的动态会计报表。

16. **Q：我国采用哪种利润表格式？另一种是什么？**
    A：我国采用**多步式**；另一种是**单步式**。

17. **Q：三级利润的计算公式？**
    A：营业利润＝营业收入－营业成本－税金及附加－销售费用－管理费用－研发费用－财务费用－资产减值损失－信用减值损失＋其他收益＋投资收益＋公允价值变动收益＋资产处置收益；利润总额＝营业利润＋（营业外收入－营业外支出）；净利润＝利润总额－所得税（费用）。

18. **Q：哪些项目不影响营业利润？**
    A：**营业外收入、营业外支出、所得税费用**。

19. **Q：利润表设哪两栏？各反映什么？**
    A："**本月数**"（本月实际发生数）和"**本年累计数**"（自年初起至本月末止的累计实际发生数，根据损益类科目本期累计发生额填列）。

20. **Q：现金与现金等价物的含义？**
    A：现金＝库存现金及可以随时用于支付的存款（库存现金、银行存款、其他货币资金）；现金等价物＝期限短、流动性强、易于转换为已知金额现金、价值变动风险很小的投资。

21. **Q：影响现金流量的三大活动及其定义？**
    A：**经营活动**（投资活动和筹资活动以外的所有交易和事项）、**投资活动**（长期资产的购建和不包括在现金等价物范围内的投资及其处置活动）、**筹资活动**（导致企业资本及债务规模和构成发生变化的活动）。

22. **Q：哪些业务不会影响现金流量？**
    A：只涉及**现金各项目之间**的变动（如从银行提取现金、现金存入银行）或只涉及**非现金项目之间**的变动（如以固定资产清偿债务、用原材料或固定资产对外投资）。

23. **Q：现金流量表正表与补充资料分别采用什么方法？间接法调整哪四大类项目？**
    A：正表按**直接法**编制；补充资料按**间接法**将净利润调节为经营活动现金流量。调整四大类：①没有实际支付现金的费用；②没有实际收到现金的收益；③不属于经营活动的损益；④经营性应收应付项目的增减变动。补充资料中还反映**不涉及现金收支的投资和筹资活动**（债务转为资本、一年内到期的可转换企业债券、融资租入固定资产）。

24. **Q：现金及现金等价物净增加额如何计算？**
    A：经营活动净额＋投资活动净额＋筹资活动净额＋汇率变动对现金的影响额；补充资料口径为（现金期末－期初）＋（现金等价物期末－期初），且与正表最后一项金额**应当相等**。

25. **Q：附注的含义？**
    A：对在资产负债表、利润表、现金流量表（和所有者权益变动表）等报表中列示项目的**文字描述或明细资料**，以及对未能在这些报表中列示项目的说明。

## 六、典型真题（含解析）

> 本节收录素材中**全部带年份标签的真题，共 10 道**（含题干带年份的 2006 年真题 1 道），按考点归类，答案与解析均保留素材原意。

### （一）会计报表的概念与编制要求

**【2025·单选】根据企业会计准则的规定，企业对外提供的会计报表至少应该包括（　）。**
A. 资产负债表　B. 利润表　C. 现金流量表　D. 净资产差异表　E. 收入费用表
**答案：ABC**
**解析**：根据《企业会计准则第30号——财务报表列报》的规定，一套完整的会计报表至少应当包括：资产负债表、利润表、现金流量表、所有者权益（或股东权益）变动表以及附注。

**【2025·多选】根据规定，企业编制的会计报表应当（　）。**
A. 真实可靠　B. 全面完整　C. 编报及时　D. 准确无误　E. 便于理解
**答案：ABCE**
**解析**：企业编制的会计报表应当真实可靠、全面完整、编报及时、便于理解。

**【2025·多选】企业在编制年度会计报表前，应当开展的主要工作包括（　）。**
A. 缴纳税金　B. 收回贷款　C. 核实债务　D. 清查资产　E. 核对账簿与凭证
**答案：CDE**
**解析**：企业在编制会计报表前，除应当全面清查资产、核实债务外，还应当检查会计处理事项的结果，如核对各会计账簿记录与会计凭证的内容、金额等是否一致，记账方向是否相符；按照规定的结账日进行结账，结出有关会计账簿的余额和发生额，并核对各会计账簿之间的余额等。

### （二）资产负债表

**【2025·单选】编制资产负债表时，由总账科目期末余额直接填列的项目是（　）。**
A. 固定资产　B. 存货　C. 实收资本　D. 预收款项
**答案：C**
**解析**：直接填列法是根据总账科目的期末余额直接填列，如"短期借款""应付职工薪酬""应交税费""实收资本""资本公积""盈余公积"等项目。固定资产按备抵抵销后填列，存货、预收款项均需分析计算填列。

**【2025·多选】编制资产负债表时，按照总账科目期末余额与其备抵科目抵销的数据填列的科目有（　）。**
A. 资本公积　B. 长期借款　C. 在建工程　D. 固定资产　E. 无形资产
**答案：CDE**
**解析**：根据总账科目期末余额与其备抵科目抵销后的数据填列，如"固定资产""在建工程""无形资产""长期股权投资""其他应收款""持有待售资产"等，都是根据该账户期末余额与其备抵科目（减值准备）余额抵销后的金额填列。

### （三）利润表

**【2025·单选】我国企业的利润表大多采用的编制形式是（　）。**
A. 报告式　B. 单步式　C. 账户式　D. 多步式
**答案：D**
**解析**：利润表的格式包括单步式和多步式，我国企业的利润表多采用多步式。

**【2023·单选】已知某企业2022年共取得营业收入2000万元，发生营业成本1200万元、税金及附加340万元、销售费用100万元、管理费用420万元，取得投资收益120万元，发生资产处置收益20万元，营业外收入10万元、营业外支出20万元，则该企业当年的营业利润是（　）万元。**
A.－60　B.70　C.90　D.80
**答案：D**
**解析**：营业利润＝2000－1200－340－100－420＋120＋20＝80（万元）。营业外收入、营业外支出不影响营业利润。

**【2022年·单选】下列会计科目中，影响营业利润的是（　）。**
A. 资本公积　B. 所得税费用　C. 营业外收入　D. 销售费用
**答案：D**
**解析**：营业利润＝营业收入－营业成本－营业税金及附加－销售费用－管理费用－研发费用－财务费用－资产减值损失－信用减值损失＋其他收益＋投资收益＋公允价值变动收益＋资产处置收益。资本公积属所有者权益项目；所得税费用只影响净利润；营业外收入影响利润总额。

### （四）现金流量表

**【2023·单选】下列经济业务中，不会发生现金流量的有（　）。**
A. 从银行提取现金　B. 用固定资产对外投资　C. 销售产品取得现金　D. 以固定资产清偿债务　E. 用现金购买原材料
**答案：ABD**
**解析**：企业发生的经济业务，若只是涉及现金各项目之间的变动或非现金项目之间的增减变动，如从银行提取现金或将现金存入银行等，属于现金各项目之间内部资金的转换，不会发生现金流量；以固定资产清偿债务、用原材料或固定资产等对外投资，属于非现金各项目之间的增减变动，也不会发生现金流量。只有涉及现金项目与非现金项目之间的增减变动时，如用现金购买原材料、用现金对外投资、收回长期债券投资等，才会影响现金流量。

**【2006·单选】某企业经营活动产生的现金流入量为3000万元，现金流出量为2400万元；投资活动产生的现金流入量为300万元，现金流出量为1400万元；筹资活动产生的现金流入量为1500万元，现金流出量为1000万元；汇率变动导致现金流入量为100万元，则该企业当年现金流量表上，现金和现金等价物净增加额为（　）万元。**
A.100　B.600　C.4900　D.0
**答案：A**
**解析**：现金及现金等价物净增加额＝经营活动产生的现金流量净额＋投资活动产生的现金流量净额＋筹资活动产生的现金流量净额＋汇率变动对现金的影响额＝(3000－2400)＋(300－1400)＋(1500－1000)＋100＝600＋(－1100)＋500＋100＝100（万元）。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把会计报表只记成"三张表" | 一套完整报表至少 **5 件**：资产负债表、利润表、现金流量表、**所有者权益变动表、附注** |
| 2 | 把附注排除在会计报表之外 | 附注是**一套完整会计报表的组成部分**，不是对外文件 |
| 3 | 混淆"某一特定日期"与"一定会计期间" | 资产负债表＝**特定日期**（静态）；利润表、现金流量表＝**一定期间**（动态） |
| 4 | 认为现金流量表是月度报表 | 现金流量表是**年度报表**；资产负债表、利润表才是月度报表 |
| 5 | 把我国资产负债表格式记成报告式 | 我国用**账户式**；报告式、账户式是"两种格式"，别和"正表报告式"（现金流量表）打架 |
| 6 | 把我国利润表格式记成单步式 | 我国用**多步式**；单步式是另一种 |
| 7 | 认为现金流量表正表按间接法编制 | 正表＝**直接法**；间接法只在**补充资料**（净利润调节为经营活动现金流量） |
| 8 | 资产类项目按到期日远近排列 | 资产按**流动性**；负债才按**到期日远近**（先到期在前） |
| 9 | 流动/非流动的时间界限记错 | 流动资产：**一年或一个经营周期以内**变现；流动负债：偿还期在**一年以内** |
| 10 | 所有者权益项目顺序记混 | **实收资本（股本）→资本公积→盈余公积→未分配利润**，口诀"实资未盈" |
| 11 | 把"实收资本、盈余公积"当成分析计算填列 | 它们和短期借款、应付职工薪酬、应交税费、资本公积一样，**直接填列** |
| 12 | 货币资金只算库存现金 | **库存现金＋银行存款＋其他货币资金**，三项合计 |
| 13 | 未分配利润只取"利润分配"余额 | **本年利润与利润分配余额之和或之差**，两个科目都要看 |
| 14 | 固定资产按总账余额直接填列 | 按总账余额与其**备抵科目（累计折旧、减值准备）抵销后净额**填列 |
| 15 | 预收账款按总账余额填列 | 按"应收账款"和"预收账款"所属**明细账贷方余额之和**填列（重分类） |
| 16 | 存货项目忘减存货跌价准备 | 各材料类科目**借方余额之和－存货跌价准备** |
| 17 | 长期借款全部列非流动负债 | 其中**一年内到期的部分**应列入"一年内到期的非流动负债" |
| 18 | 认为营业外收支影响营业利润 | 营业外收支只影响**利润总额**；营业利润只受营业收入、成本费用及收益类项目影响 |
| 19 | 认为所得税影响利润总额 | 所得税只影响**净利润**；利润总额＝营业利润＋营业外收支净额 |
| 20 | 以为一切经营业务都影响现金流量 | 只涉及**现金项目之间**或**非现金项目之间**变动的，不影响现金流量 |
| 21 | 把"收到的税费返还"归入筹资活动 | 属**经营活动**流入（销售商品收现、税费返还、其他经营流入） |
| 22 | 把"支付现金股利"归入经营活动 | "分配股利、利润或偿付利息支付的现金"属**筹资活动**流出 |
| 23 | 把"取得投资收益收到的现金"归入经营活动 | 属**投资活动**流入；处置固定资产收回现金也属投资活动 |
| 24 | 认为补充资料与正表的净增加额可以不一致 | 两者金额**应当相等**，这是编报勾稽要求 |
