## 二、知识点精讲

### 考点1 税制要素 ★★★

**（1）税收制度的三个基本要素——纳税人、征税对象和税率**

| 概念 | 含义 | 关键点 |
|---|---|---|
| **纳税人（纳税主体）** | 直接负有纳税义务的单位和个人 | 可以是**自然人**，也可以是**法人** |
| **负税人** | 最终负担税款的单位和个人 | 与纳税人是否一致，取决于税负能否转嫁 |
| **扣缴义务人** | 法律、行政法规规定的负有代扣代缴、代收代缴税款义务的单位和个人 | 基于**行政便宜主义**设定，为**法定义务** |

**（2）课税对象（"征税课体"）**

- 定义：税法规定的**征税目的物**。
- 地位：**是一个税种区别于另一个税种的主要标志**。
- 三个相关概念：

| 概念 | 含义 |
|---|---|
| **税源** | 税收的经济来源或最终出处 |
| **税目** | 税法规定的课税对象的具体项目，反映具体征税范围，**代表征税的广度** |
| **计税依据** | 计算应纳税额的依据 |

**（3）税率——税收制度的中心环节**

- 定义：税法规定的**应征税额与征税对象数额（量）之间的比例**，是计算应征税额的标准，**体现征税的深度**。
- 意义：反映税收政策和经济政策，直接关系财政收入和纳税人的负担。

| 税率形式 | 内容 | 细分 |
|---|---|---|
| **比例税率** | 对同一征税对象，不论数量大小，都按同一比例征税 | 单一比例税率和差别比例税率；差别比例税率包括**产品差别、行业差别、地区差别、幅度差别** |
| **定额税率** | 按征税对象的一定计量单位规定固定税额 | 四种形式：**单一、差别、幅度、分类分级** |
| **累进税率** | 按数额大小分等级，等级由低到高规定税率 | **全额累进税率**：对课税对象的全部数额，都按与之相应的税率计算税额；**超额累进税率**：把课税对象按数额大小划分为若干个等级，每个等级分别按该等级的税率计征 |

**（4）税收制度的其他要素**

| 要素 | 要点 |
|---|---|
| **纳税环节** | 国民收入与支出环流中，税法规定的纳税环节 |
| **纳税期限** | 纳税人缴纳税款的周期，通常为一个时间段 |
| **纳税申报期限**（26 新增） | 纳税人在纳税期限届满后向税务机关进行申报并缴纳税款的时间段。纳税人什么时间缴纳税款，由**纳税期限和纳税申报期限**共同确定 |
| **减税免税** | 减税＝对应纳税额**少征一部分**税款；免税＝对应纳税额**全部免征**。除税法列举的免税项目外，一般都属**定期减免**性质，到期恢复征收 |
| **违章处理** | 税务机关对纳税人违反税法的行为采取的处罚性措施，是税收**强制性**特征的体现 |
| **纳税地点** | 与纳税义务发生地一致；例外情况——与总公司不在同一地点的分公司的利润在总公司汇总纳税 |

**速记口诀**：**"纳对税"**——纳税人、课税对象、税率三基本；税率是中心（深度），税目定广度，违章显强制。

### 考点2 税收分类 ★★★

| 分类标准 | 类别 | 具体税种（素材列举） |
|---|---|---|
| **按课税对象的不同** | **货物劳务税** | 我国税收收入的**主体税种，60% 以上**。包括增值税、消费税、关税等 |
| | **所得税** | 个人所得税和企业所得税 |
| | **财产税** | 房产税、契税、车船税 |
| | **资源税** | 资源税、城镇土地使用税、耕地占用税、土地增值税 |
| | **行为目的税** | 环境保护税、印花税、城市维护建设税、车辆购置税、烟叶税、船舶吨税 |
| **按计量课税对象的标准不同** | **从价税** | 增值税、所得税 |
| | **从量税** | 消费税中的啤酒、汽油、柴油 |
| **按税收与价格的关系不同** | **价内税** | 消费税 |
| | **价外税** | 增值税 |
| **按税收是否能够转嫁** | **直接税** | 纳税人即负税人，不易转嫁。个人所得税、企业所得税、财产税属于直接税 |
| | **间接税** | 纳税人不一定是负税人，可以转嫁。消费税、增值税属于间接税 |
| **按税收管理权限和使用权限** | **中央税** | 消费税、关税 |
| | **地方税** | 契税、房产税、耕地占用税、土地增值税、城镇土地使用税、车船税等 |
| | **中央和地方共享税** | 增值税、企业所得税、个人所得税 |

**速记口诀**：
- 课税对象五分法：**"货、所、财、资、行"**——货（物劳务）所占六成是主体。
- 价内外：**"增值在外、消费在内"**。
- 转嫁分直接间接：**"个企财直接，货消间接"**。
- 央地分：**"消费税关税归中央，增值个企三分享，其余多归地方管"**。

### 考点4 增值税 ★★★★★（本章第一重点）

**（1）概念、特点与优点**

- **概念**：以单位和个人生产经营过程中取得的**增值额**为课征对象征收的一种税。

| 特点 | 内容 |
|---|---|
| 1 | **不重复征税**（中性税收） |
| 2 | **逐环节征税，逐环节扣税**，最终消费者承担税款（生产—批发—零售—进口） |
| 3 | 税基广阔，征收的普遍性、连续性 |

**优点（五条，多选高频）**：① 平衡税负，促进公平竞争；② 便于对出口商品退税；③ 避免进口商品征税不足；④ 组织财政收入上具有稳定性和及时性；⑤ 税收征管上相互制约，交叉审计。

**（2）增值税的三种类型**

| 类型 | 固定资产税款处理 | 课税对象 | 性质 |
|---|---|---|---|
| **消费型增值税** | 允许扣除购入固定资产中含的税款 | 全部生产资料不课税，只限于消费资料 | 体现**鼓励投资**政策的增值税 |
| **收入型增值税** | 允许扣除固定资产**折旧**中所含税款 | 相当于国民收入 | 不含重复征税，是**完全的增值税** |
| **生产型增值税** | **不允许**扣除固定资产中所含的税款 | 相当于国民生产总值 | 具有一定程度的重复征税（**不完全的增值税**） |

**（3）征税范围与纳税人**

- **征税范围**：生产、批发、零售、进口**四个环节**；覆盖第一产业、第二产业、第三产业。
- **纳税人**：在中华人民共和国境内销售货物、服务、无形资产或者不动产以及**进口货物**的单位和个人。
- **一般纳税人与小规模纳税人**：小规模纳税人为**年应征增值税销售额未超过 500 万元（五百万元）**者，自然人属于小规模纳税人；**登记为一般纳税人后不得转为小规模纳税人**。

**（4）税率与征收率**

| 档位 | 适用范围 |
|---|---|
| **13%** | 销售或进口货物（除规定外）、提供加工修理修配劳务、提供有形动产租赁服务 |
| **9%** | ① 粮食、食用植物油；② 自来水、暖气、冷气、热水、煤气、液化气、天然气、沼气、居民煤炭制品、二甲醚；③ 图书、报纸、杂志、音像制品、电子出版物；④ 农产品、饲料、化肥、农药、农机、农膜；⑤ 食用盐；⑥ 交通运输、邮政、**基础电信**、建筑、不动产租赁服务，销售不动产，转让土地使用权 |
| **0%** | 出口货物（国务院另有规定的除外）；境内单位和个人跨境销售服务、无形资产行为 |
| **6%** | 电信服务（**增值电信**）、金融服务、现代服务、生活服务、转让土地使用权以外的其他无形资产 |
| **征收率 3%** | 适用于简易征税办法 |

**（5）计税方法**

| 纳税人 | 方法 |
|---|---|
| **一般纳税人（扣税法）** | 应纳税额＝**销项税额 − 进项税额**；销项税额＝销售额×适用税率；进项税额以当期购货发票中注明的允许扣除的增值税款为准 |
| **小规模纳税人** | 不实行扣税法：应纳税额＝销售额×征收率 |
| **进口货物** | 应纳税额＝组成计税价格×税率 |

**（6）征收管理**

- **纳税义务发生时间**：① 发生应税销售行为，为收讫销售款项或取得索取销售款项凭据的当天；**先开具发票的，为开具发票的当天**；② 进口货物，为报关进口的当天；③ 扣缴义务发生时间为纳税人增值税纳税义务发生的当天；④ 发生视同应税交易，为完成视同应税交易当日（26 新增）。
- **计税期间（纳税期限）**：分别为 **10 日、15 日、1 个月或者 1 个季度**（2026《增值税法》口径，已删去旧的 1 日/3 日/5 日）；具体由主管税务机关按应纳税额大小核定；不能按固定期限纳税的，可以按次纳税。
  - 以 1 个月或 1 个季度为 1 个计税期间的，自期满之日起 **15 日内**申报纳税；
  - 以 10 日或 15 日为 1 个计税期间的，自期满之日起 **5 日内**预缴税款，于**次月 1 日起 15 日内**申报纳税；
  - 进口货物，自海关填发海关进口增值税专用缴款书之日起 **15 日内**缴纳。
- **纳税地点**：① 有固定生产经营场所的，向其机构所在地或居住地主管税务机关申报；总机构和分支机构不在同一县（市）的分别申报，经省级以上财政、税务部门批准可由总机构汇总申报；② 没有固定生产经营场所的销售货物或劳务，向交易发生地申报，未申报的由机构所在地或居住地主管税务机关补征；③ 自然人销售或租赁不动产、转让自然资源使用权、提供建筑服务，向不动产所在地、自然资源地、建筑服务发生地申报；④ 进口货物向报关地海关申报；⑤ 扣缴义务人向其机构所在地或居住地主管税务机关申报缴纳。
- **发票管理**：电子发票和纸质发票效力相等。不得开具增值税专用发票的情形：购买方为自然人；应税交易免征增值税；国务院财政、税务部门规定的其他情形。
- **税收优惠（2026 年教材新增）**：
  - ① 小规模纳税人发生应税交易，销售额**未达到起征点的免征**增值税；达到起征点的**全额**计算缴纳。起征点标准由国务院规定，报全国人大常委会备案；
  - ② 免征项目：农业生产者销售自产农产品及相关农业服务、家禽牲畜水生动物的配种和疾病防治；医疗机构提供的医疗服务；古旧图书、自然人销售自己使用过的物品；直接用于科学研究、科学试验和教学的进口仪器设备；外国政府、国际组织无偿援助的进口物资和设备；残疾人组织直接进口供残疾人专用的物品、残疾人个人提供的服务；托儿所、幼儿园、养老机构、残疾人服务机构提供的育养服务、婚姻介绍服务、殡葬服务；学校提供的学历教育服务、学生勤工俭学提供的服务；纪念馆、博物馆、文化馆、文物保护单位管理机构、美术馆、展览馆、书画院、图书馆举办文化活动的门票收入，宗教场所举办文化、宗教活动的门票收入；
  - ③ 纳税人兼营增值税优惠项目的，应当**单独核算**优惠项目的销售额；未单独核算的不得享受优惠。纳税人可以放弃优惠，放弃的在 **36 个月内**不得享受该项优惠，**小规模纳税人除外**。

**速记口诀**：**"增值中性又价外，四档税率三六九零加一三；一般扣税销减进，小规模来三征收；进口组成计税价格；十五日内要申报"**。

### 考点5 消费税 ★★

**（1）概念与特点**

- **概念**：对**特定消费品和消费行为**征收的一种商品税。我国消费税是在对货物普遍征收增值税基础上，选择少数消费品**再征收一道**消费税。
- **目的**：调整产品结构、引导消费方向、保证国家财政收入。

| 特点 | 内容 |
|---|---|
| ① | 征收范围具有**选择性** |
| ② | 一般情况下，征税环节具有**单一性** |
| ③ | 平均税率水平比较**高**且税负差异大 |
| ④ | 计税方法具有**灵活性** |

**（2）范围和纳税人、税目、税率**

- **纳税人**：我国境内**生产、委托加工和进口**应税消费品的单位和个人（列举征税办法）。
- **税目**：**15 类**消费品——烟、酒、高档化妆品、贵重首饰珠宝玉石、高尔夫球球杆球具、高档手表、游艇、鞭炮烟火、摩托车、小汽车、涂料、电池、成品油、木质一次性筷子、实木地板。
- **税率**：**比例和定额两种**，一般为 **1%~56%**；啤酒、黄酒、成品油适用定额税率；白酒、卷烟等实行**定额税率和比例税率相结合**计征。

**（3）计税方法（三种，计算题核心）**

```
① 从价定率：应纳税额 = 应税消费品销售额 × 比例税率
② 从量定额：应纳税额 = 应税消费品销售数量 × 定额税率
③ 复合计税：应纳税额 = 应税消费品销售额 × 比例税率
                      + 应税消费品销售数量 × 定额税率
```

**（4）征收管理**

- **纳税期限**：消费税仍适用《消费税暂行条例》，为 1 日、3 日、5 日、10 日、15 日、1 个月或 1 个季度（**注意与已按《增值税法》改为 10 日/15 日/月/季度的增值税不同**）；以月/季度为纳税期的自期满之日起 15 日内申报纳税；以 1/3/5/10/15 日为纳税期的自期满之日起 5 日内预缴，次月 1 日起 15 日内结清。
- **进口应税消费品**：自海关填发海关进口消费税专用缴款书之日起 **15 日内**缴纳税款。
- **纳税地点**：销售及自产自用应税消费品（除国务院财政、税务主管部门另有规定外），向**机构所在地或居住地**主管税务机关申报；委托加工应税消费品，除受托方为个人外，由**受托方**向其机构所在地或居住地主管税务机关解缴税款；进口应税消费品，由进口人或其代理人向**报关地海关**申报纳税。

**速记口诀**：**"消费税选少数、价内、环节单一；十五税目记牢靠，酒烟复合油啤定额"**。

### 考点6 关税 ★★★★★

**（1）概念与"境"的界定**

- **概念**：海关依法对**进出境货物、物品**征收的一种税。
- **"境"＝关境**（又称"海关境域"或关税领域），是一个国家海关法**全面实施**的领域。
- **关境与国境**：通常情况下一致；但由于**自由港、自由贸易区或关税同盟**的存在，关境与国境有时**不完全一致**。

**（2）征税对象、纳税人、征税范围**

- **征税对象**：准许进出境的**货物和物品**。货物＝贸易性商品；物品＝入境旅客随身携带的行李物品、个人邮递物品、各种运输工具上服务人员携带进口的自用物品、馈赠物品以及其他方式进境的个人物品。
- **纳税人**：进口货物的**收货人**、出口货物的**发货人**、进出境物品的**所有人**。
- **物品所有人的推定**：

| 情形 | 推定所有人 |
|---|---|
| 携带进境的物品 | 其**携带人** |
| 分离运输的行李 | 相应的进出境**旅客** |
| 以邮递方式**进境**的物品 | 其**收件人** |
| 以邮递或其他运输方式**出境**的物品 | 其**寄件人或托运人** |

- **征税范围**：中华人民共和国准许进出口的货物、进境物品，除法律、行政法规另有规定外。

**（3）税率**

进口关税设置**最惠国税率、协定税率、特惠税率、普通税率、关税配额税率**等；对实行关税配额管理的进出口货物，设置关税配额税率；对进出口货物在一定期限内可以实行**暂定税率**。

**（4）完税价格与应纳税额计算**

- **完税价格**：海关规定的对进出口货物计征关税时使用的价格；由海关以该货物的**成交价格为基础**审查确定；成交价格不能确定时，由海关**依法估定**。纳税人可以**书面**形式要求海关作出**书面说明**。

| 计征方式 | 公式 | 素材说明 |
|---|---|---|
| **从价税**（我国海关计征关税**主要**标准） | 关税税额＝应税进（出）口货物数量×单位完税价格×税率 | —— |
| **从量税** | 关税税额＝应税进（出）口货物数量×单位货物税额 | 我国目前对**原油、啤酒和胶卷**等进口商品征收 |
| **复合税** | 关税税额＝数量×单位完税价格×税率＋数量×单位货物税额 | —— |

**（5）征收管理（数字密集，必背）**

- **申报期限**：进口货物纳税人应自**运输工具申报进境之日起 14 日内**；出口货物纳税人除海关特准外，应在货物运抵海关监管区后、**装货的 24 小时以前**，向货物进出境地海关申报。
- **缴纳期限**：纳税人应自海关填发税款缴款书之日起 **15 日内**向指定银行缴纳税款；缴款期限届满日遇星期六、星期日等休息日或法定节假日，顺延至其后的**第 1 个工作日**。
- **延期缴纳**：因不可抗力或者国家税收政策调整不能按期缴纳的，经依法提供税款担保后可以延期缴纳，但**最长不得超过 6 个月**。
- **强制执行**：① 征收关税**滞纳金**——自缴纳期限届满滞纳之日起至缴纳之日止，按滞纳税款**万分之五**的比例**按日**征收，**休息日或法定节假日不予扣除**；滞纳金金额＝滞纳关税税额×征收比率×滞纳天数；② 强制征收——自缴纳税款期限届满之日起 **3 个月**仍未缴纳的，经直属海关关长或其授权的隶属海关关长批准，可采取**强制扣缴、变价抵缴**等措施。
- **退还**：海关发现多征税款的，应立即通知纳税人办理退还手续。需要退还税款的，纳税人可自**收到税额确认书之日起 3 个月内**办理退还手续；纳税人发现多缴税款的，可自**缴纳税款之日起 3 年内**向海关书面申请退还（**26 年变化**）。
- **补征与追征**：因纳税人**违反**海关规定造成短征关税的，称为**追征**；**非因**纳税人违反规定造成短征的，称为**补征**。进出境货物和物品放行后，海关发现少征或漏征税款的，应当自缴纳税款或者货物、物品放行之日起 **3 年内**补征税款（**26 教材重大变化**）；因纳税人、扣缴义务人违反规定造成少征税款的，可自放行之日起 **3 年以内**追征税款，并按日加收少征或漏征税款**万分之五**的滞纳金。

**速记口诀**：**"关境国境偶不一，十四申报十五缴；滞纳万分五日节假日不除，三月强扣六年延期；退还三月三年征，补追均限三年整"**。

### 考点7 所得税的概念和特点 ★★★

- **概念**：所得税是对**所有以所得为课税对象的税种的总称**。

| 特点 | 内容 |
|---|---|
| 1 | 税负相对比较**公平** |
| 2 | 征税**不重复**且**不易转嫁**（25 教材变化），**单环节** |
| 3 | 税源可靠，收入具有**弹性** |

- **核心结论**：所得税能够自动适应经济发展周期的变化，发挥"**内在稳定器**"的作用。

### 考点8 企业所得税 ★

| 要素 | 内容 |
|---|---|
| **纳税人** | 企业及其他取得收入的组织；**个人独资、合伙企业不适用**企业所得税法 |
| **税率** | **25%**；非居民企业 **20%** |
| **征收管理** | 居民企业以**企业登记注册地**为纳税地点；登记注册地在境外的，以**实际管理机构所在地**为纳税地点 |
| **应纳税所得额** | 每一纳税年度的**收入总额**，减除**不征税收入、免税收入、各项扣除**以及允许弥补的**以前年度亏损**后的余额 |
| **应纳税额** | 应纳税所得额 × 适用税率，减除依照税法关于税收优惠规定**减免和抵免税额**后的余额 |

**速记口诀**：**"独资合伙不适用，居民二五非居民二十；注册地在境外看实际管理"**。

### 考点9 个人所得税 ★★★★★（与增值税并列本章第一重点）

**（1）征收制度与纳税人识别号**

- 我国现行个人所得税采取**综合与分类相结合**征收制度。
- 以**所得人**为纳税人，以**支付所得的单位或个人**为扣缴义务人。
- 纳税人识别号：纳税人有中国公民身份号码的，以**中国公民身份号码**为纳税人识别号；没有的，由**税务机关赋予**。
- **纳税年度**：自公历 **1 月 1 日起至 12 月 31 日**止。

**（2）居民个人与非居民个人**

| 类别 | 判定标准 | 纳税义务 |
|---|---|---|
| **居民个人** | 在中国境内**有住所**，或者无住所而一个纳税年度内在中国境内居住累计**满 183 天** | 从中国**境内和境外**取得的所得纳税 |
| **非居民个人** | 在中国境内无住所又不居住，或者无住所而一个纳税年度内居住累计**不满 183 天** | 从中国**境内**取得的所得纳税 |

**（3）所得项目与税率（九项所得，两套税率）**

| 类别 | 所得项目 | 计税方式 | 税率 |
|---|---|---|---|
| **综合所得** | ① 工资、薪金所得 ② 劳务报酬所得 ③ 稿酬所得 ④ 特许权使用费所得 | 居民个人**按纳税年度合并计算**；非居民个人**按月或按次分项计算** | **3%~45% 超额累进** |
| **分类所得** | ⑤ 经营所得 | 按年分别计算 | **5%~35% 超额累进** |
| | ⑥ 利息、股息、红利所得 ⑦ 财产租赁所得 ⑧ 财产转让所得 ⑨ 偶然所得 | 按次/按月分别计算 | **20% 比例税率** |

**（4）计税方法（应纳税所得额的计算）**

| 所得项目 | 应纳税所得额 |
|---|---|
| **综合所得**（居民个人） | 每纳税年度的**收入额**减除费用 **60000 元**以及**专项扣除、专项附加扣除**和依法确定的**其他扣除**后的余额。其中劳务报酬、稿酬、特许权使用费所得以收入**减除 20% 费用**后的余额为收入额；**稿酬所得的收入额减按 70% 计算** |
| **综合所得**（非居民个人） | 工资、薪金所得：每月收入额减除费用 **5000 元**后的余额；劳务报酬、稿酬、特许权使用费所得：以**每次收入额**为应纳税所得额 |
| **经营所得** | 每一纳税年度的收入总额减除**成本、费用以及损失**后的余额 |
| **财产租赁所得** | 每次收入**不超过 4000 元**的，减除费用 **800 元**；**4000 元以上**的，减除 **20%** 的费用 |
| **财产转让所得** | 转让财产的收入额减除**财产原值和合理费用**后的余额 |
| **利息、股息、红利所得和偶然所得** | 以**每次收入额**为应纳税所得额 |

**（5）扣除与税收优惠**

- **公益慈善捐赠**：捐赠额未超过纳税人申报的应纳税所得额 **30%** 的部分，可以从应纳税所得额中扣除；国务院规定对公益慈善事业捐赠实行全额税前扣除的，从其规定。
- **专项扣除**：基本养老保险、基本医疗保险、失业保险等社会保险费和住房公积金等。
- **专项附加扣除**：子女教育、继续教育、大病医疗、住房贷款利息或者住房租金、赡养老人等支出。
- **免征个人所得税（十项）**：① 省级人民政府、国务院部委和中国人民解放军军以上单位，以及外国组织、国际组织颁发的科学、教育、技术、文化、卫生、体育、环境保护等方面的奖金；② 国债和国家发行的金融债券利息；③ 按照国家统一规定发给的补贴、津贴；④ 福利费、抚恤金、救济金；⑤ 保险赔款；⑥ 军人的转业费、复员费、退役金；⑦ 按照国家统一规定发给干部、职工的安家费、退职费、基本养老金或者退休费、离休费、离休生活补助费；⑧ 依照有关法律规定应予免税的各国驻华使馆、领事馆的外交代表、领事官员和其他人员的所得；⑨ 中国政府参加的国际公约、签订的协议中规定免税的所得；⑩ 国务院规定的其他免税所得。
- **减征个人所得税（两项，幅度和期限由省级政府规定）**：① 残疾、孤老人员和烈属的所得；② 因自然灾害遭受重大损失的。国务院可以规定其他减税情形，报全国人大常委会备案。

**（6）征收管理（两种办法）**

**① 自行申报纳税——应当依法办理纳税申报的七种情形**：

1. 取得综合所得需要办理**汇算清缴**；
2. 取得应税所得**没有扣缴义务人**；
3. 取得应税所得，扣缴义务人**未扣缴税款**；
4. 取得**境外所得**；
5. 因**移居境外注销中国户籍**；
6. 非居民个人在中国境内从**两处以上**取得工资、薪金所得；
7. 国务院规定的其他情形。

**② 综合所得汇算清缴**

- 需办理汇算清缴的情形：a. 从**两处以上**取得综合所得，且综合所得年收入额减除专项扣除后的余额**超过 6 万元**；b. 取得劳务报酬、稿酬、特许权使用费所得中一项或者多项，且综合所得年收入额减除专项扣除的余额**超过 6 万元**；c. 纳税年度内预缴税额**低于**应纳税额；d. 纳税人**申请退税**。
- 时间与地点：应当在取得所得的**次年 3 月 1 日至 6 月 30 日**内申报；向任职、受雇单位所在地主管税务机关办理；有两处以上任职受雇单位的，选择向其中一处；没有任职受雇单位的，向**户籍所在地或经常居住地**主管税务机关办理。

**③ 经营所得申报**：按年计算个人所得税；纳税人在**月度或季度终了后 15 日内**向经营管理所在地主管税务机关办理**预缴**申报（A 表）；在取得所得的**次年 3 月 31 日前**办理**汇算清缴**（B 表）；从两处以上取得经营所得的，选择向其中一处办理年度**汇总申报**（C 表）。

**④ 全员全额扣缴申报纳税**

- 扣缴义务人向个人支付应税款项时，应当依规定预扣或者代扣税款，按时缴库，并专项记载备查；应当在**代扣税款的次月 15 日内**向主管税务机关报送相关信息。
- **实行全员全额扣缴申报的应税所得**：工资、薪金所得，劳务报酬所得，稿酬所得，特许权使用费所得，利息、股息、红利所得，财产租赁所得，财产转让所得，偶然所得。**注意：没有经营所得。**
- 居民个人工资、薪金所得按**累计预扣法**计算预扣税款，按月办理扣缴申报；年度预扣预缴税额与年度应纳税额不一致的，由居民个人于**次年 3 月 1 日至 6 月 30 日**办理汇算清缴，税款**多退少补**。
- 劳务报酬、稿酬、特许权使用费所得预扣预缴：收入以收入减除费用后的余额为收入额（**每次收入不超过 4000 元减除 800 元；4000 元以上减除 20%**）；**稿酬所得的收入额减按 70% 计算**；劳务报酬适用"居民个人劳务报酬所得预扣预缴率表"，稿酬、特许权使用费适用 **20% 比例预扣率**。
- **收入次数认定**：劳务报酬、稿酬、特许权使用费所得属于一次性收入的，以取得该项收入为一次；属于同一项目连续性收入的，以**一个月内**取得的收入为一次。财产租赁所得，以一个月内取得的收入为一次。利息、股息、红利所得，以支付时取得的收入为一次。偶然所得，以每次取得该项收入为一次。

**速记口诀**：**"一八三天定居民，六万每年五千每月；综合四项累进四五，经营五到三十五，其余二零比例；稿酬七折、劳务八扣，经营不属全员扣缴"**。

### 考点11 房产税 ★★★

| 要素 | 内容 |
|---|---|
| **纳税人** | 在我国**城市、县城、建制镇和工矿区**内拥有房屋产权的单位和个人。具体包括**产权所有人、承典人、房产代管人或者使用人** |
| **征税对象** | **房屋** |
| **征税范围** | 城市、县城、建制镇和工矿区的房屋。**独立于房屋之外的建筑物**，如围墙、烟囱、水塔、菜窖、室外游泳池等**不属于**征税范围 |
| **税率** | 比例税率。**从价计征 1.2%**；**从租计征 12%**；个人按市场价格出租的居民住房**减按 4%** |
| **计税依据** | 从价计征以**房产余值**为计税依据——房产原值**一次减除 10%~30%** 后的余值；从租计征以**租金收入**为计税依据（**不含增值税**） |
| **纳税地点** | 房产税在**房产所在地**缴纳；房产不在同一地方的，按坐落地点分别向房产所在地税务机关申报 |
| **纳税期限** | **按年计算、分期缴纳**，具体纳税期限由省、自治区、直辖市人民政府规定 |

**纳税义务发生时间（八种情形）**：

| 情形 | 起征时点 |
|---|---|
| 原有房产用于生产经营 | 从**生产经营之月**起 |
| 自行新建房屋用于生产经营 | 从**建成之次月**起 |
| 委托施工企业建设房屋 | 从**办理验收手续之次月**起 |
| 购置新建商品房 | 自**房屋交付使用之次月**起 |
| 购置存量房 | 自办理房屋权属转移、变更登记手续，房地产权属登记机关**签发房屋权属证书之次月**起 |
| 出租、出借房产 | 自**交付出租、出借房产之次月**起 |
| 房地产开发企业自用、出租、出借本企业建造的商品房 | 自**房屋使用或交付之次月**起 |
| 因房产实物或权利状态发生变化而依法终止纳税义务 | 计算截止到房产的实物或权利状态发生变化的**当月末** |

**速记口诀**：**"原有房产当月算，新建验收次月算；从价余值扣三成税率一二，从租十二居民四"**。

### 考点12 契税 ★★★

**（1）概念与纳税人**

- **概念**：在中华人民共和国境内**转移土地、房屋权属**为征税对象，向**产权承受人**征收的一种财产税。
- **纳税人**：转移土地、房屋权属，**承受**的单位和个人。土地、房屋权属指**土地使用权和房屋所有权**。

**（2）征税范围**

| 属于征税范围 | 不属于征税范围 |
|---|---|
| 国有土地使用权出让 | 土地**承包经营权和土地经营权**的转移 |
| 土地使用权转让（出售、赠与、互换） | 土地、房屋**典当、分拆（分割）、抵押以及出租** |
| 房屋买卖、赠与、互换 | 不涉及土地使用权和房屋所有权转移变动的房屋附属设施 |
| 获奖取得房屋所有权（实质是接受赠与房产） | **法定继承人**继承土地、房屋权属 |
| 以作价投资（入股）、偿还债务、划转、奖励等方式转移权属 | —— |
| 公司增资扩股中以土地、房屋权属作价入股或出资投入企业 | —— |
| 企业破产清算期间，非债权人承受破产企业土地、房屋权属 | —— |

- **房屋互换**：以互换**差额**为计税依据，**多付货币的一方**为纳税人；互换价格相等时**免征**契税。
- **非法定继承人**根据遗嘱承受死者生前土地、房屋权属，属于赠与行为，征收契税。

**（3）税率与优惠**

- **幅度税率 3%~5%**：具体执行税率由各省、自治区、直辖市人民政府在 3%~5% 幅度内提出，报同级人民代表大会常务委员会决定，并报全国人大常委会和国务院备案；可对不同主体、不同地区、不同类型的住房的权属转移确定**差别税率**。
- **优惠（自 2024 年 12 月 1 日起）**：对个人购买**家庭唯一住房**（家庭成员范围包括购房人、配偶以及未成年子女），面积 **140 平方米及以下**的，**减按 1%** 征收；面积 **140 平方米以上**的，**减按 1.5%** 征收。

**（4）计税依据与应纳税额**

- 计税依据**不含增值税**：
  1. 土地使用权出售、房屋买卖：按土地、房屋权属转移合同确定的价格（包括承受者应交付的货币、实物、其他经济利益对应的价款）；
  2. 土地使用权赠与、房屋赠与及其他没有价格的转移行为：税务机关参照市场价格**依法核定**的价格；
  3. 土地使用权互换、房屋互换：所换取土地使用权、房屋的**价格差额**；
  4. 国有土地使用权出让：承受人为取得该土地使用权而支付的**全部经济利益**；
  5. 房屋附属设施：不涉及土地和房屋权属转移变动的不征收；分期付款购买的按**合同规定的总价款**计征；**单独计价**的按当地确定的适用税率征收，与房屋统一计价的适用与房屋**相同的税率**。
- **应纳税额 = 计税依据 × 税率**。

**（5）征收管理**

- 纳税义务发生时间：签订土地、房屋权属转移合同的**当日**，或取得其他具有权属转移合同性质凭证的当日。
- 纳税期限与地点：应当在依法办理土地、房屋**权属登记手续前**申报缴纳；在土地、房屋所在地的征收机关缴纳。
- 未按规定缴纳契税的，不动产登记机构**不予办理**土地、房屋权属登记。

**速记口诀**：**"契税向承受方收，三五幅度唯一住房一或一五；登记之前必须交，不交不给办登记"**。

### 考点13 车船税 ★

| 要素 | 内容 |
|---|---|
| **概念** | 在中华人民共和国境内的车辆、船舶，按照规定税目和税额计算征收的税 |
| **纳税人** | 境内属于《车船税法》所附《车船税税目税额表》规定的车辆、船舶的**所有人或者管理人**；从事机动车第三者责任强制保险业务的**保险机构**为机动车车船税的**扣缴义务人** |
| **征税范围** | 税目税额表规定的车辆、船舶：① 依法应当在车船管理部门登记的机动车辆和船舶；② 依法不需要登记、在单位内部场所行驶或者作业的机动车辆和船舶。境内单位和个人**租入外国籍船舶的不征收**；将船舶**出租到境外的应依法征收** |
| **税目** | **六大类**：乘用车、商用车、挂车、其他车辆、摩托车和船舶 |
| **税率** | **定额税率**（对征税车船规定单位固定税额） |
| **优惠** | 自 **2024 年 7 月 1 日**起，符合相关标准的节能汽车和节能商用车**减半征收**；符合相关标准的**新能源车船免征** |

**计税单位**：乘用车、商务客车、摩托车按"**每辆**"；商务货车、挂车按"**整备质量每吨**"；机动船舶按"**净吨位每吨**"；游艇按"**艇身长度每米**"。

**应纳税额的特殊计算**：

- 购置当年的应纳税额自纳税义务发生的当月起**按月计算**：

```
应纳税额 =（年应纳税额 ÷ 12）× 应纳税月份数
应纳税月份数 = 12 − 纳税义务发生时间（取月份）+ 1
```

- 已完税车船被盗抢、报废、灭失的，可申请退还自被盗抢、报废、灭失月份起至该纳税年度终了的税款；失而复得的，从公安机关出具相关证明的**当月**起计算缴纳。
- 已缴纳车船税的车船在同一纳税年度内**转让过户的，不另纳税，也不退税**。
- 因质量原因退回生产企业或经销商的，可申请退还自退货月份起至年度终了的税款（以退货发票所载日期的当月为准）。

**征收管理**：纳税义务发生时间为**取得车船所有权或者管理权的当月**（以购买车船的发票或其他证明文件所载日期的当月为准）；**按年申报，分月计算，一次性缴纳**（年度为 1 月 1 日至 12 月 31 日）；纳税地点为车船登记地或扣缴义务人所在地——扣缴义务人代收代缴的，为**扣缴义务人所在地**；自行申报的，为**车船登记地**的主管税务机关所在地；依法不需办理登记的车船，为**所有人或管理人所在地**。

**速记口诀**：**"车船定额六大类，按年申报月算一次交；新能源免节能半，租入外籍不征出租出境征"**。

| 要素 | 地位 | 核心内容 |
|---|---|---|
| **纳税人** | 基本要素 | 直接负有纳税义务的单位和个人（自然人/法人）；区别于负税人（最终负担税款者）和扣缴义务人（代扣代缴、代收代缴，法定义务） |
| **课税对象** | 基本要素 | 税法规定的征税目的物（"征税课体"），**是区分税种的主要标志**；相关概念：税源（经济来源）、税目（具体项目，代表广度）、计税依据（计算应纳税额的依据） |
| **税率** | 基本要素＋**中心环节** | 应征税额与征税对象数额（量）之间的比例，体现征税**深度**；三种形式：比例税率、定额税率、累进税率（全额累进/超额累进） |
| **纳税环节** | 其他要素 | 国民收入与支出环流中税法规定的纳税环节 |
| **纳税期限** | 其他要素 | 纳税人缴纳税款的周期（通常为一个时间段） |
| **纳税申报期限** | 其他要素（26 新增） | 纳税期限届满后申报并缴纳税款的时间段；缴款时间由纳税期限＋纳税申报期限共同确定 |
| **减税免税** | 其他要素 | 减税＝少征一部分；免税＝全部免征；一般属定期减免，到期恢复征收 |
| **违章处理** | 其他要素 | 处罚性措施，体现税收**强制性**特征 |
| **纳税地点** | 其他要素 | 通常与纳税义务发生地一致；例外：分公司利润在总公司汇总纳税 |

### 表3 "X 个不等于"避坑表

| # | 说法 | 正解 |
|---|---|---|
| 1 | 纳税人 ＝ 负税人 | ✗ 只有**直接税**（个税、企业所得税、财产税）纳税人才是负税人；间接税（增值税、消费税）税负可转嫁，纳税人不一定是负税人 |
| 2 | 扣缴义务人 ＝ 纳税人 | ✗ 扣缴义务人是负有代扣代缴、代收代缴义务的单位和个人，是法定义务，与纳税人身份不同 |
| 3 | 免税 ＝ 不征税 | ✗ 免税是对**应纳税额全部免征**（仍在征税范围内）；"不征税"本就不属于征税范围（2018 真题陷阱） |
| 4 | 减税免税是无限期的 | ✗ 除税法列举的免税项目外，一般属**定期减免**性质，到期恢复征税 |
| 5 | 纳税期限 ＝ 纳税申报期限 | ✗ 纳税期限是缴税周期；纳税申报期限是期限届满后申报缴款的时段，二者共同确定缴款时间（26 新增） |
| 6 | 纳税地点一定 ＝ 纳税义务发生地 | ✗ 原则上一致；例外：与总公司不在同一地点的分公司利润在**总公司汇总纳税** |
| 7 | 税目 ＝ 税源 ＝ 计税依据 | ✗ 税目是课税对象的具体项目（广度）；税源是经济来源或最终出处；计税依据是计算应纳税额的依据 |
| 8 | 增值税税率 ＝ 征收率 | ✗ 税率 13%/9%/6%/0% 适用于一般计税；3% 是小规模纳税人的**征收率** |
| 9 | 关境 ＝ 国境 | ✗ 通常一致；存在自由港、自由贸易区或关税同盟时**不完全一致** |
| 10 | 综合所得包含经营所得 | ✗ 经营所得属**分类所得**（5%~35% 超额累进），单独按年计算，不属于综合所得 |
| 11 | 稿酬"减按 70%"＝ 税额打七折 | ✗ 是**收入额**减按 70% 计算，不是应纳税额乘 70% |
| 12 | 房产税从价计征直接按"原值×1.2%" | ✗ 必须先减除 10%~30% 算**房产余值**，再乘 1.2% |
| 13 | 契税向转让方征收 | ✗ 契税向**产权承受方**征收；互换时由多付货币的一方缴纳 |

## 四、公式与计算（本章计算题重点）

> **演算例题说明**：例题分两类——①「素材原题」：完全来自素材，答案已核对；②「自编演算题」：为演示公式用法而设的纯数字演算，仅使用素材中的税率与规则，不引入素材之外的知识点。

### 公式1 增值税一般纳税人：应纳税额 ＝ 销项税额 − 进项税额

- 销项税额 ＝ 销售额 × 适用税率；**含税销售额换算：不含税销售额 ＝ 含税销售额 ÷（1＋适用税率）**。
- 易错点：含税收入必须先除以（1＋税率）还原，不能直接乘税率；换算用**增值税税率**，不是其他税种的税率。

**【自编演算题】** 某服装厂为增值税一般纳税人，当月销售服装取得含税销售收入 113 万元（税率 13%），当月购进原材料取得增值税专用发票注明进项税额 6.5 万元。计算当月应纳增值税。

```
解：不含税销售额 = 113 ÷ (1 + 13%) = 100（万元）
    销项税额 = 100 × 13% = 13（万元）
    进项税额 = 6.5（万元）
    应纳增值税 = 13 − 6.5 = 6.5（万元）
```

### 公式2 增值税小规模纳税人：应纳税额 ＝ 销售额 × 征收率（3%）

- 易错点：小规模纳税人不实行扣税法，**进项税额不能抵扣**。

**【自编演算题】** 某小规模纳税人季度取得销售额 30 万元（征收率 3%）。

```
解：应纳增值税 = 30 × 3% = 0.9（万元）
```

### 公式3 进口货物增值税：应纳税额 ＝ 组成计税价格 × 税率

**【自编演算题】** 某公司进口一批货物，已知其组成计税价格为 50 万元，增值税税率 13%。

```
解：应纳增值税 = 50 × 13% = 6.5（万元）
```

> 素材仅给出该公式，未给出组成计税价格的构成明细，演算按"已知组成计税价格"处理。

### 公式4 消费税从价定率：应纳税额 ＝ 应税消费品销售额 × 比例税率

**【素材原题】** 某化妆品厂销售一批化妆品，取得含税收入 5850 元，已知化妆品消费税税率为 15%，则该笔收入应纳消费税为（　）元。
A. 1755　B. 850　C. 776.55　D. 2507.14

**答案：C**

```
解：不含税收入 = 含税收入 ÷ (1 + 13%) = 5850 ÷ 1.13 = 5176.99（元）
    应纳消费税 = 5176.99 × 15% = 776.55（元）
```

> 易错点：换算除以（1＋**13%**），是增值税税率而非消费税税率 15%。

### 公式5 消费税从量定额：应纳税额 ＝ 应税消费品销售数量 × 定额税率

**【自编演算题】** 某啤酒厂销售啤酒 200 吨，定额税率每吨 250 元。

```
解：应纳消费税 = 200 × 250 = 50000（元）
```

> 素材仅说明啤酒、黄酒、成品油适用定额税率，未给出具体税额标准，此处定额税率为演示设定值。

### 公式6 消费税复合计税：应纳税额 ＝ 销售额 × 比例税率 ＋ 销售数量 × 定额税率

**【素材原题·2022 单选】** 某公司生产 100 吨白酒全部销售，共计收入 400 万，白酒税率是 20% 加 0.5 元/500 克，共需交税多少（　）。
A. 85　B. 90　C. 95　D. 80

**答案：B**

```
解：从价部分 = 400 × 20% = 80（万元）
    从量部分 = 100 吨 × 2000 × 0.5 元 = 10（万元）
              （1 吨 = 1000 千克 = 2000 个 500 克）
    应纳消费税 = 80 + 10 = 90（万元）
```

### 公式7 企业所得税：应纳税所得额 ＝ 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损

应纳税额 ＝ 应纳税所得额 × 适用税率 − 减免和抵免税额

**【自编演算题】** 某居民企业某年度收入总额 8000 万元，不征税收入 200 万元，免税收入 300 万元，各项扣除 4500 万元，允许弥补的以前年度亏损 500 万元，适用税率 25%，无减免和抵免税额。

```
解：应纳税所得额 = 8000 − 200 − 300 − 4500 − 500 = 2500（万元）
    应纳税额 = 2500 × 25% = 625（万元）
```

### 公式8 个人所得税综合所得：应纳税所得额 ＝ 年收入额 − 60000 元 − 专项扣除 − 专项附加扣除 − 其他扣除

- 劳务报酬、稿酬、特许权使用费所得：**收入额 ＝ 收入 ×（1 − 20%）**；**稿酬所得收入额再减按 70%**。
- 非居民个人工资、薪金所得：每月收入额减除费用 **5000 元**。

**【自编演算题】** 某居民个人某纳税年度取得工资薪金收入 20 万元，劳务报酬收入 5 万元；专项扣除（社会保险费和住房公积金）3 万元，专项附加扣除 2.4 万元。

```
解：工资薪金收入额 = 20（万元）
    劳务报酬收入额 = 5 × (1 − 20%) = 4（万元）
    收入额合计 = 24（万元）
    应纳税所得额 = 24 − 6 − 3 − 2.4 = 12.6（万元）
```

> 素材未附综合所得年度税率表，具体应纳税额需按 3%~45% 超额累进税率表计算，本笔记不展开。

### 公式9 个人所得税其他项目应纳税所得额

```
经营所得：应纳税所得额 = 收入总额 − 成本 − 费用 − 损失
财产租赁所得：每次收入 ≤ 4000 元 → 减除费用 800 元；
              每次收入 > 4000 元 → 减除 20% 的费用
财产转让所得：应纳税所得额 = 转让财产收入额 − 财产原值 − 合理费用
利息、股息、红利所得和偶然所得：应纳税所得额 = 每次收入额
```

**【自编演算题】** 某个人一次取得财产租赁收入 3000 元，另一次取得偶然所得 8000 元（税率 20%）。

```
解：财产租赁应纳税所得额 = 3000 − 800 = 2200（元）
    偶然所得应纳税所得额 = 8000（元）
    偶然所得应纳税额 = 8000 × 20% = 1600（元）
```

### 公式10 关税应纳税额

```
从价税：关税税额 = 应税进（出）口货物数量 × 单位完税价格 × 税率
从量税：关税税额 = 应税进（出）口货物数量 × 单位货物税额
复合税：关税税额 = 数量 × 单位完税价格 × 税率 + 数量 × 单位货物税额
滞纳金：关税滞纳金金额 = 滞纳关税税额 × 征收比率（万分之五）× 滞纳天数
```

**【自编演算题1】** 某公司进口一批货物 1000 件，单位完税价格 200 元/件，关税税率 10%。

```
解：关税税额 = 1000 × 200 × 10% = 20000（元）
```

**【自编演算题2】** 某纳税人滞纳关税 1 万元，滞纳 10 天（万分之五按日征收）。

```
解：关税滞纳金 = 10000 × 0.0005 × 10 = 50（元）
```

### 公式11 房产税应纳税额

```
从价计征：应纳税额 = 房产余值 × 1.2%
          房产余值 = 房产原值 ×（1 − 10%~30%）
从租计征：应纳税额 = 租金收入（不含增值税）× 12%
          个人按市场价格出租的居民住房减按 4%
```

**【自编演算题】** 某企业房产原值 1000 万元，按减除 30% 后的余值从价计缴房产税；另将一处房屋出租，年租金收入 60 万元。

```
解：房产余值 = 1000 × (1 − 30%) = 700（万元）
    从价计征应纳税额 = 700 × 1.2% = 8.4（万元）
    从租计征应纳税额 = 60 × 12% = 7.2（万元）
    全年应纳房产税合计 = 8.4 + 7.2 = 15.6（万元）
```

### 公式12 契税应纳税额 ＝ 计税依据 × 税率

**【自编演算题】** 某家庭购买家庭唯一住房，建筑面积 120 平方米，不含增值税价款 300 万元（2024 年 12 月 1 日起，140 平方米及以下减按 1%）。

```
解：应纳契税 = 300 × 1% = 3（万元）
```

### 公式13 车船税购置当年应纳税额

```
应纳税额 =（年应纳税额 ÷ 12）× 应纳税月份数
应纳税月份数 = 12 − 纳税义务发生时间（取月份）+ 1
```

**【自编演算题】** 某乘用车年应纳税额 600 元，2026 年 9 月购置（纳税义务发生于 9 月）。

```
解：应纳税月份数 = 12 − 9 + 1 = 4（个月）
    应纳税额 = (600 ÷ 12) × 4 = 200（元）
```

## 五、高频考点速记卡

1. **Q：税收制度的基本要素是哪三个？核心环节是什么？**
   A：纳税人、征税对象（课税对象）和税率。其中**税率是税收制度的中心环节**，体现征税的深度。

2. **Q：纳税人、负税人、扣缴义务人有何区别？**
   A：纳税人是直接负有纳税义务的单位和个人（可以是自然人或法人）；负税人是最终负担税款的单位和个人；扣缴义务人是法律、行政法规规定负有代扣代缴、代收代缴税款义务的单位和个人，基于行政便宜主义设定，属法定义务。

3. **Q：课税对象为什么被称为区分税种的主要标志？**
   A：课税对象是税法规定的征税目的物（"征税课体"），每个税种据此相互区别。税源是税收的经济来源，税目是课税对象的具体项目（代表广度），计税依据是计算应纳税额的依据。

4. **Q：税率的三种基本形式及细分？**
   A：比例税率（单一比例税率、差别比例税率——产品/行业/地区/幅度差别）、定额税率（单一、差别、幅度、分类分级四种形式）、累进税率（全额累进、超额累进）。

5. **Q：税收按课税对象分为哪五类？哪类是主体税种？**
   A：货物劳务税、所得税、财产税、资源税、行为目的税。其中**货物劳务税是我国税收收入的主体税种，占 60% 以上**。

6. **Q：直接税与间接税的划分依据和典型税种？**
   A：依据**税负能否转嫁**划分。直接税纳税人即负税人，不易转嫁——个人所得税、企业所得税、财产税；间接税可以转嫁——消费税、增值税。

7. **Q：价内税和价外税各是哪个税？**
   A：价内税是消费税，价外税是增值税。

8. **Q：中央税、地方税、中央地方共享税各包括哪些？**
   A：中央税——消费税、关税；地方税——契税、房产税、耕地占用税、土地增值税、城镇土地使用税、车船税等；共享税——增值税、企业所得税、个人所得税。

9. **Q：我国现行税收法律制度的法律级次？（哪几个是国务院经授权立法的暂行条例？）**
   A：六级：全国人大及常委会制定的税法→授权立法（国务院制定暂行条例）→国务院税收行政法规→地方税收地方性法规→税务部门规章→地方政府地方规章。素材列举的授权立法暂行条例有《房产税暂行条例》《城镇土地使用税暂行条例》《消费税暂行条例》（26 新增）。

10. **Q：增值税的特点和优点？**
    A：特点：不重复征税（中性税收）、逐环节征税逐环节扣税（最终消费者承担）、税基广阔有普遍性连续性。优点：平衡税负促进公平竞争；便于出口退税；避免进口商品征税不足；财政收入稳定及时；征管上相互制约、交叉审计。

11. **Q：消费型、收入型、生产型增值税的区别？**
    A：消费型允许扣除购入固定资产所含税款（只对消费资料课税，鼓励投资）；收入型允许扣除固定资产折旧中所含税款（课税对象相当于国民收入，完全的增值税）；生产型不允许扣除（相当于国民生产总值，有重复征税，不完全的增值税）。

12. **Q：增值税各档税率适用范围？**
    A：13%——销售或进口货物（除规定外）、加工修理修配劳务、有形动产租赁；9%——粮食食用植物油、水暖燃气、图书报纸杂志音像电子出版物、农产品饲料化肥农药农机农膜、食用盐、交通运输邮政基础电信建筑不动产租赁销售不动产转让土地使用权；6%——增值电信、金融、现代、生活服务及转让土地使用权以外的其他无形资产；0%——出口货物（另有规定除外）、跨境销售服务无形资产。

13. **Q：增值税三种计税方法？**
    A：一般纳税人扣税法：应纳税额＝销项税额−进项税额（进项以当期购货发票注明允许扣除的税款为准）；小规模纳税人：应纳税额＝销售额×征收率 3%；进口货物：应纳税额＝组成计税价格×税率。

14. **Q：一般纳税人与小规模纳税人的划分及转换限制？**
    A：小规模纳税人为**年应征增值税销售额未超过 500 万元（五百万元）**者，自然人属于小规模纳税人；**登记为一般纳税人后不得转为小规模纳税人**。

15. **Q：增值税纳税义务发生时间的特殊规定？**
    A：先开具发票的，为开具发票的当天；进口货物为报关进口的当天；扣缴义务发生时间为纳税人纳税义务发生的当天；发生视同应税交易，为完成视同应税交易当日（26 新增）。

16. **Q：消费税的特点与三种计税方法？**
    A：特点：征收范围有选择性、征税环节一般单一、平均税率较高且税负差异大、计税方法灵活。计税方法：从价定率（销售额×比例税率）、从量定额（销售数量×定额税率）、复合计税（从价＋从量）。

17. **Q：消费税 15 个税目？（哪些常考"不征"？）**
    A：烟、酒、高档化妆品、贵重首饰珠宝玉石、高尔夫球球杆球具、高档手表、游艇、鞭炮烟火、摩托车、小汽车、涂料、电池、成品油、木质一次性筷子、实木地板。注意普通化妆品、竹制一次性筷子、药品、月饼、高档手机均不征。

18. **Q：关境与国境的关系？关税纳税人及物品所有人如何推定？**
    A：通常关境与国境一致，但因自由港、自由贸易区或关税同盟存在，二者有时不完全一致。纳税人为进口货物收货人、出口货物发货人、进出境物品所有人；推定规则：携带进境推定携带人、分离运输行李推定旅客、邮递进境推定收件人、邮递或其他方式出境推定寄件人或托运人。

19. **Q：关税征收管理中的关键数字？**
    A：进口自运输工具申报进境之日起 14 日内申报；出口装货的 24 小时以前申报；自海关填发税款缴款书之日起 15 日内缴纳；延期缴纳最长 6 个月；滞纳金按日万分之五（节假日不予扣除）；期限届满 3 个月未缴可强制扣缴、变价抵缴；多征退还可自缴纳税款之日起 3 年内申请（26 变化）；少征漏征自放行之日起 3 年内补征或追征（26 重大变化）。

20. **Q：企业所得税的纳税人范围和税率？**
    A：个人独资、合伙企业不适用企业所得税法；税率 25%，非居民企业 20%。居民企业以登记注册地为纳税地点，注册地在境外的以实际管理机构所在地为纳税地点。

21. **Q：个人所得税居民个人与非居民个人的判定？**
    A：在中国境内有住所，或无住所而一个纳税年度内居住累计满 183 天的，为居民个人（境内外所得纳税）；无住所又不居住，或无住所而累计不满 183 天的，为非居民个人（仅境内所得纳税）。

22. **Q：个人所得税九个所得项目的税率？**
    A：综合所得（工资薪金、劳务报酬、稿酬、特许权使用费）适用 3%~45% 超额累进税率，按纳税年度合并计算；经营所得适用 5%~35% 超额累进税率；利息股息红利、财产租赁、财产转让、偶然所得适用 20% 比例税率。

23. **Q：居民个人综合所得的扣除体系？**
    A：每年减除费用 60000 元＋专项扣除（基本养老、基本医疗、失业保险等社会保险费和住房公积金）＋专项附加扣除（子女教育、继续教育、大病医疗、住房贷款利息或住房租金、赡养老人）＋依法确定的其他扣除。劳务报酬、稿酬、特许权使用费收入先减除 20% 费用，稿酬收入额再减按 70%。

24. **Q：全员全额扣缴申报的范围和期限？（哪个项目不在其中？）**
    A：范围包括工资薪金、劳务报酬、稿酬、特许权使用费、利息股息红利、财产租赁、财产转让、偶然所得——**不含经营所得**。扣缴义务人应在代扣税款的**次月 15 日内**报送。

25. **Q：房产税的税率、计税依据与征税范围？**
    A：从价计征税率 1.2%，以房产余值（原值一次减除 10%~30%）为计税依据；从租计征税率 12%，以租金收入（不含增值税）为计税依据，个人按市场价格出租居民住房减按 4%。仅对城市、县城、建制镇和工矿区内的房屋征税，围墙、烟囱、水塔、菜窖、室外游泳池等独立建筑物不征。

26. **Q：契税的纳税人、税率与最新优惠？**
    A：向土地、房屋权属的**承受方**征收；幅度税率 3%~5%；自 2024 年 12 月 1 日起，个人购买家庭唯一住房 140 平方米及以下减按 1%、140 平方米以上减按 1.5% 征收；互换以差额计税，等值互换免征。

27. **Q：车船税的申报方式、扣缴义务人和优惠？**
    A：按年申报、分月计算、一次性缴纳；从事机动车第三者责任强制保险业务的保险机构为扣缴义务人；自 2024 年 7 月 1 日起节能汽车减半征收、符合标准的新能源车船免征。

**第一节 税收要素与税收分类**

**【2018·单选】关于减税和免税的说法，错误的是（　）。**
A. 免税是指不征税
B. 减税是指对应纳税额少征一部分税
C. 免税是指对应纳税额全部免征
D. 减税、免税一般都具有定期减免性质

**答案：A**
**解析**：减税和免税是税法对某些纳税人或课税对象给予鼓励和照顾的特殊规定。减税，是指对应纳税额少征一部分税款；免税，是指对应纳税额全部免征。除税法列举的免税项目外，一般减税、免税都属于定期减免性质，税法规定有具体的减免条件和期限，到期就应当恢复征税。选项 A 错误，为本题正确答案——免税是"应纳税额全部免征"，不等于"不征税"。

**【2020·单选】税制要素中的违章处理体现的税收特征是（　）。**
A. 有效性　B. 强制性　C. 固定性　D. 无偿性

**答案：B**
**解析**：违章处理，是指税务机关对纳税人违反税法的行为采取的处罚性措施。它是税收**强制性**特征的体现。

**【2020·多选】下列税种中，属于财产税的是（　）。**
A. 增值税　B. 关税　C. 契税　D. 房产税　E. 消费税

**答案：CD**
**解析**：本题考查财产税。按课税对象分类，财产税包括房产税、契税、车船税等。增值税、消费税属货物劳务税，关税也属货物劳务税类。

**【2023补·单选】按课税对象分类，印花税属于（　）。**
A. 资源税　B. 行为目的税　C. 所得税　D. 货物和劳务税

**答案：B**
**解析**：行为目的税类包括环境保护税、印花税、城市维护建设税、车辆购置税、烟叶税、船舶吨税，主要是为了达到特定目的，对特定对象和特定行为发挥调节作用。

**【2022·多选】下列税种中，属于由全国人民代表大会及其常务委员会制定，以国家法律形式发布实施的有（　）。**
A. 城市维护建设税　B. 城镇土地使用税　C. 车辆购置税　D. 环境保护税　E. 个人所得税

**答案：ACDE**
**解析**：全国人大及其常委会制定的税收法律，如《税收征收管理法》《企业所得税法》《个人所得税法》《车船税法》《环境保护税法》《烟叶税法》《船舶吨税法》《耕地占用税法》《车辆购置税法》《资源税法》《契税法》《城市维护建设税法》等。城镇土地使用税依据的是国务院经授权制定的《城镇土地使用税暂行条例》，不是国家法律。

**【2022·多选】下列属于地方税的有（　）。**
A. 消费税　B. 城镇土地使用税　C. 城市维护建设税　D. 土地增值税　E. 车船税

**答案：BCDE**
**解析**：地方税是指由地方管辖课征并支配的税种，如目前我国的契税、房产税、耕地占用税、土地增值税、城镇土地使用税、车船税等。消费税属于中央税。

**【2022·单选】由国务院颁布的税是（　）。**
A. 资源税　B. 增值税　C. 房产税　D. 车船税

**答案：C**
**解析**：房产税依据的是国务院经授权立法所制定的《房产税暂行条例》。资源税、车船税由全国人大常委会制定法律；增值税法为 26 新增法律。

**【2023·单选】下列税种不属于行为目的税的是（　）。**
A. 环境保护税　B. 印花税　C. 城市维护建设税　D. 资源税

**答案：D**
**解析**：行为目的税类包括环境保护税、印花税、城市维护建设税、车辆购置税、烟叶税、船舶吨税。资源税属于资源税类。

**第二节 货物和劳务税类**

**【2022·单选】某公司生产 100 吨白酒全部销售，共计收入 400 万，白酒税率是 20% 加 0.5 元/500 克，共需交税多少（　）。**
A. 85　B. 90　C. 95　D. 80

**答案：B**
**解析**：白酒实行复合计税。从价部分：400 万×20%＝80 万；从量部分：100 吨×2000×0.5＝10 万（1 吨＝2000 个 500 克）；应纳消费税＝80＋10＝90（万元）。

**第三节 所得税类**

**【2022·单选】关于个人所得税纳税人的说法，正确的是（　）。**
A. 在中国境内无住所且一个纳税年度内在中国境内居住累计满 90 天的个人，为居民个人纳税人
B. 个人所得税以支付所得的单位为纳税人
C. 纳税人没有中国公民身份号码的，以其护照号码为纳税人识别号
D. 纳税人有中国公民身份号码的，以其中国公民身份号码为纳税人识别号

**答案：D**
**解析**：纳税人有中国公民身份号码的，以其中国公民身份号码为纳税人识别号；纳税人没有中国公民身份号码的，由税务机关赋予其纳税人识别号（不是护照号码）。居民个人判定标准是累计满 183 天，不是 90 天。个人所得税以所得人为纳税人，以支付所得的单位或个人为扣缴义务人。

**【2023补·多选】适用 20% 比例税率的个人所得税课税对象有（　）。**
A. 偶然所得　B. 财产租赁所得　C. 稿酬所得　D. 经营所得　E. 利息、股息、红利所得

**答案：ABE**
**解析**：利息、股息、红利所得、财产租赁所得、财产转让所得和偶然所得，适用 20% 比例税率。稿酬所得属综合所得（3%~45% 超额累进），经营所得适用 5%~35% 超额累进税率。

**【2020·单选】个人所得中的综合所得适用的税率为（　）。**
A. 3%~45% 的超额累进税率　B. 5%~35% 的超额累进税率
C. 20% 的比例税率　D. 25% 的比例税率

**答案：A**
**解析**：综合所得（工资薪金、劳务报酬、稿酬、特许权使用费）适用 3%~45% 的七级超额累进税率；5%~35% 是经营所得，20% 是利息股息红利、财产租赁、财产转让、偶然所得。

**【2020·单选】非居民个人取得稿酬所得，其应纳税所得额是（　）。**
A. 每月收入额减除 3500 元后的余额　B. 每次收入额
C. 每月收入额减除 30% 的费用后的余额　D. 每次收入额的 70%

**答案：B**
**解析**：非居民个人的劳务报酬所得、稿酬所得、特许权使用费所得，以**每次收入额**为应纳税所得额。每月减除 5000 元只适用于非居民个人的工资、薪金所得；减除 20% 和减按 70% 是预扣预缴或居民个人计税时的收入额计算规则，不是非居民个人的应纳税所得额确定规则。

**【2020·单选】下列个人所得税中，不能享受免征个人所得税税收优惠的是（　）。**
A. 抚恤金　B. 省级政府颁发的环境保护奖金　C. 福利费　D. 某地级市政府颁发的创新奖

**答案：D**
**解析**：免征个人所得税的奖金，限于**省级人民政府、国务院部委和中国人民解放军军以上单位**，以及外国组织、国际组织颁发的科学、教育、技术、文化、卫生、体育、环境保护等方面的奖金。地级市政府颁发的奖项不在免税范围内。抚恤金、福利费均属法定免税项目。

**【2025·多选】根据《中华人民共和国个人所得税法》，有下列情形之一的，纳税人应当依法办理纳税申报的有（　）。**
A. 取得偶然所得　B. 取得境外所得　C. 取得应税所得没有扣缴义务人
D. 取得转让不动产所得　E. 取得综合所得需要办理汇算清缴

**答案：BCE**
**解析**：应当依法办理纳税申报的情形包括：（1）取得综合所得需要办理汇算清缴；（2）取得应税所得没有扣缴义务人；（3）取得应税所得，扣缴义务人未扣缴税款；（4）取得境外所得；（5）因移居境外注销中国户籍；（6）非居民个人在中国境内从两处以上取得工资、薪金所得；（7）国务院规定的其他情形。取得偶然所得、转让不动产所得本身不必然触发自行申报义务（有扣缴义务人时由扣缴义务人扣缴）。

**【2025·单选】下列不属于全员全额扣缴申报纳税的是（　）。**
A. 特许权使用费所得　B. 稿酬所得　C. 利息股息红利　D. 经营所得

**答案：D**
**解析**：实行个人所得税全员全额扣缴申报的应税所得包括工资、薪金所得，劳务报酬所得，稿酬所得，特许权使用费所得，利息、股息、红利所得，财产租赁所得，财产转让所得，偶然所得——**不含经营所得**。经营所得由纳税人自行申报（预缴＋汇算清缴）。

**第四节 财产税类**

**【2023补·单选】下列税种中，属于财产税的是（　）。**
A. 消费税　B. 车船税　C. 个人所得税　D. 印花税

**答案：B**
**解析**：财产税是指以各类动产和不动产为征税对象的税种，我国现行财产税有房产税、契税和车船税。消费税属货物劳务税，个人所得税属所得税，印花税属行为目的税。

**附：素材中无年份标签的经典例题精选**

**1.【单选】扣缴义务人是指法律、行政法规规定负有（　）。**

C. 代扣代缴、代收代缴税款义务的单位　D. 代扣代缴、代收代缴税款义务的单位和个人
**答案：D**。解析：扣缴义务人是指法律、行政法规规定负有代扣代缴、代收代缴税款义务的单位和个人。

**4.【多选】我国货物劳务税种包括（　）。**
A. 土地增值税　B. 增值税　C. 消费税　D. 房产税　E. 所得税

**5.【多选】按现行税收管理权限和税收使用权限划分，中央和地方共享税税种包括（　）。**
A. 增值税　B. 个人所得税　C. 消费税　D. 企业所得税　E. 房产税
**答案：ABD**。解析：中央和地方共享税税种包括增值税、企业所得税、个人所得税。

**7.【多选】增值税的优点有（　）。**

C. 在组织财政收入上具有稳定性和及时性　D. 税收征管可以互相制约，交叉审计　E. 税负不易转嫁
**答案：ABCD**。解析：增值税是间接税，税负可以转嫁，E 错误。

**8.【多选】下列商品或服务中，属于实行增值税税率 9% 的有（　）。**
A. 农机　B. 生活服务　C. 建筑服务　D. 电子出版物　E. 煤气
**答案：ACDE**。解析：9% 涵盖粮食等农产品、食用植物油、食用盐；自来水、暖气、煤气、石油液化气、天然气、二甲醚、沼气、居民煤制品；图书、报纸、杂志、音像制品、电子出版物；饲料、化肥、农药、农机、农膜；以及交通运输、邮政、基础电信、建筑、不动产租赁服务，销售不动产，转让土地使用权。生活服务适用 6%。

**9.【多选】下列纳税人提供的服务中，增值税税率为 6% 的有（　）。**
A. 基础电信服务　B. 邮政服务　C. 增值电信服务　D. 不动产租赁服务　E. 金融服务
**答案：CE**。解析：6% 包括增值电信服务、金融服务、生活服务以及除不动产租赁之外的现代服务，除转让土地使用权之外的销售无形资产。基础电信服务、邮政服务、不动产租赁服务为 9%。

**10.【单选】某化妆品厂销售一批化妆品，取得含税收入 5850 元，已知化妆品消费税税率为 15%，则该笔收入应纳消费税为（　）元。**
A. 1755　B. 850　C. 776.55　D. 2507.14
**答案：C**。解析：不含税收入＝5850÷(1+13%)＝5176.99 元，应纳消费税＝5176.99×15%＝776.55 元。

**11.【单选】下列各项中，不属于个人所得税的"综合所得"项目按年计算征税的是（　）。**
A. 工资薪金所得　B. 劳务报酬所得　C. 经营所得　D. 特许权使用费所得
**答案：C**。解析：综合所得包括工资薪金、劳务报酬、稿酬、特许权使用费四项；经营所得属于"分类所得"。

**12.【单选】我国现行个人所得税法规定非居民个人工资、薪金所得的费用扣除标准为每人每月（　）元。**
A. 800　B. 1600　C. 3500　D. 5000
**答案：D**。解析：非居民个人工资、薪金所得，以每月收入额减除费用 5000 元后的余额为应纳税所得额。

**13.【单选】关于个人所得税应纳税所得额的计算的说法，错误的是（　）。**
A. 经营所得，以每一纳税年度的收入总额减除成本、费用以及损失后的余额，为应纳税所得额
B. 财产租赁所得，每次收入不超过 4000 元的，减除费用 500 元
C. 利息、股息、红利所得和偶然所得，以每次收入额为应纳税所得额
D. 非居民个人的工资、薪金所得，以每月收入额减除费用 5000 元后的余额为应纳税所得额
**答案：B**。解析：财产租赁所得，每次收入不超过 4000 元的，减除费用 800 元；4000 元以上的，减除 20% 的费用。

**14.【单选】关于我国所得税的说法，正确的是（　）。**
A. 合伙企业适用企业所得税法　B. 企业所得税税率为 15%
C. 偶然所得是个人所得税的课税对象　D. 居民个人的综合所得，以每一纳税年度的收入额减除费用 60000 元为应纳税所得额
**答案：C**。解析：个人独资、合伙企业不适用企业所得税法；企业所得税税率一般为 25%；居民个人综合所得的应纳税所得额还要减除专项扣除、专项附加扣除和其他扣除，不是只减 60000 元。

**15.【单选】根据个人所得税法律制度的规定，属于纳税人需要办理汇算清缴情形的有（　）。**
A. 在两处或者两处以上取得综合所得，且综合所得年收入额减去专项扣除的余额超过 6 万元
B. 取得劳务报酬所得、稿酬所得、特许权使用费所得中一项或者多项所得，且综合所得年收入额减去专项扣除的余额超过 6 万元
C. 纳税年度内预缴税额低于应纳税额的
D. 纳税人申请退税的
E. 取得境外所得
**答案：ABCD**。解析：取得境外所得属于"应当办理纳税申报"的情形，不属于综合所得汇算清缴的情形。

**16.【多选】下列建筑物中，不属于房产税的征税范围的是（　）。**
A. 农村的房屋　B. 农村的菜窖　C. 城市的露天游泳池　D. 县城的商铺　E. 市区的房屋
**答案：ABC**。解析：房产税征税范围为城市、县城、建制镇和工矿区的房屋；独立于房屋之外的建筑物，如围墙、烟囱、水塔、菜窖、室外游泳池等不属于征税范围。

**17.【多选】关于房产税计税依据的说法，正确的有（　）。**
A. 从价计征的房产税，是以房产余值为计税依据
B. 房产出租的，以房屋出租取得的租金收入为计税依据
C. 计征房产税的租金收入不含消费税，含增值税
D. 从价计征的房产税，是以房产公允价值为计税依据
E. 从价计征的房产税，是以房产原值为计税依据
**答案：AB**。解析：C 错——计征房产税的租金收入不含增值税；D、E 错——从价计征以房产余值（原值一次减除 10%~30%）为计税依据，不是公允价值或原值。

**18.【单选】根据契税法律制度的规定，下列各项中，属于契税纳税人的是（　）。**
A. 抵押商铺的李某　B. 转让土地使用权的乙公司　C. 出租住房的王某　D. 受让土地使用权的甲公司
**答案：D**。解析：契税向权属转移的承受方征收。抵押、出租不属于契税征税范围；转让方（乙公司）不是纳税人。

**19.【单选】下列需要交契税的是（　）。**
A. 北京人小张在澳大利亚买的房　B. 美国人杰克在北京买的房
C. 老李对土地承包经营权的转让　D. 老张在乡下租了一套别墅
**答案：B**。解析：在中华人民共和国境内转移土地、房屋权属，承受的单位和个人为契税纳税人。杰克在北京买房属于在境内购买房屋。境外购房、土地承包经营权转让、租赁均不征契税。

**20.【单选】车船税的申报方式是（　）。**
A. 年度汇算　B. 按年申报　C. 按季度申报　D. 按月缴费
**答案：B**。解析：车船税按年申报，分月计算，一次性缴纳。

**21.【多选】车船税的纳税地点有（　）。**
A. 车船管理人所在地　B. 车船所有人所在地　C. 车船登记地　D. 车船税扣缴义务人所在地　E. 进口车船报关地
**答案：ABCD**。解析：车船税纳税地点为车船登记地或扣缴义务人所在地；扣缴义务人代收代缴的，为扣缴义务人所在地；自行申报的，为车船登记地的主管税务机关所在地；依法不需要登记的车船，为所有人或管理人所在地。

**22.【多选】关于关税的征收管理的规定，下列选项正确的有（　）。**
A. 出口货物在货物运抵海关监管区后装货的 24 小时前，向货物出境地海关申报
B. 关税的延期缴纳税款，最长不得超过 6 个月
C. 关税滞纳按滞纳税款万分之五的比例按日征收，法定节假日可予扣除
D. 进出境货物和物品放行后，海关发现少征或者漏征税款，应当自缴纳税款或者货物、物品放行之日起 2 年内，向纳税义务人补征
E. 纳税人发现多缴税款的，可以自缴纳税款之日起 3 年内，向海关书面申请退还缴纳的税款

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"纳税人"和"负税人"混为一谈 | 间接税（增值税、消费税）纳税人不一定是负税人，税负可转嫁；只有直接税（个税、企业所得税、财产税）纳税人即负税人 |
| 2 | 把扣缴义务人当成纳税人 | 扣缴义务人是代扣代缴、代收代缴税款的主体，基于行政便宜主义设定的**法定义务**，不等于纳税人 |
| 3 | 混淆税目、税源、计税依据 | 税目＝课税对象的具体项目（代表**广度**）；税源＝经济来源或最终出处；计税依据＝计算应纳税额的依据 |
| 4 | 认为"免税"就是"不征税" | 免税是对**应纳税额全部免征**，仍在征税范围内；"不征税"本就不属征税范围（2018 真题 A 项陷阱） |
| 5 | 以为减税免税一劳永逸 | 除税法列举项目外，一般都属**定期减免**，到期恢复征税 |
| 6 | 混淆纳税期限与纳税申报期限 | 纳税期限是缴税**周期**；纳税申报期限是期限届满后申报缴款的**时段**，两者共同确定缴款时间（26 新增） |
| 7 | 以为纳税地点永远等于纳税义务发生地 | 原则一致；例外是**分公司利润在总公司汇总纳税** |
| 8 | 把土地增值税归入财产税 | 素材主流分类（三处一致）将其归入**资源税类**；个别旧真题解析列入财产税，按五分法记忆，考试以"房产税、契税、车船税"为财产税 |
| 9 | 把车辆购置税当地方税 | 2022 真题中车辆购置税**不属于**地方财政收入（属中央收入） |
| 10 | 含税收入直接乘税率算增值税 | 必须先 ÷（1＋税率）还原不含税销售额；换算用**增值税税率**，不是其他税税率 |
| 11 | 混淆增值税税率与征收率 | 13%/9%/6%/0% 是税率；3% 是小规模纳税人的**征收率** |
| 12 | 把基础电信服务、邮政服务、不动产租赁服务记成 6% | 这三项是 **9%**；6% 的是增值电信、金融、生活服务和除不动产租赁外的现代服务 |
| 13 | 以为一般纳税人可以转回小规模 | **登记为一般纳税人后不得转为小规模纳税人** |
| 14 | 把所有化妆品、一次性筷子都纳入消费税 | 只有**高档**化妆品、**木质**一次性筷子征税；普通化妆品、竹制筷子不征 |
| 15 | 白酒消费税只算从价部分 | 白酒是**复合计税**：从价 20% ＋ 从量 0.5 元/500 克，两部分必须相加 |
| 16 | 把关境与国境画等号 | 存在**自由港、自由贸易区或关税同盟**时，关境与国境不一致 |
| 17 | 关税滞纳金计算时扣除休息日、节假日 | 滞纳金按日万分之五征收，休息日或法定节假日**不予扣除** |
| 18 | 关税补征追征期限记成 1 年或 2 年 | 按 2026 教材新规，自放行之日起 **3 年内**补征或追征（旧题口径已过时，注意按新规答题） |
| 19 | 把经营所得当成综合所得 | 经营所得属**分类所得**，适用 5%~35% 超额累进税率，且**不在全员全额扣缴申报范围内** |
| 20 | 居民个人居住标准记成 90 天或 365 天 | 无住所者一个纳税年度内居住累计**满 183 天**才是居民个人 |
| 21 | 非居民个人费用扣除额记错 | 非居民工资薪金**每月减 5000 元**；居民综合所得**每年减 60000 元** |
| 22 | 稿酬"减按 70%"理解成税额打七折 | 是**收入额**减按 70% 计算，不是应纳税额乘 70% |
| 23 | 财产租赁费用减除额记成 500 元或 3500 元 | 每次收入**4000 元以下减 800 元，4000 元以上减 20%** |
| 24 | 房产税从价计征直接拿原值乘 1.2% | 先减除 10%~30% 算**房产余值**，再乘 1.2%；租金收入**不含增值税**，个人出租居民住房减按 4% |
