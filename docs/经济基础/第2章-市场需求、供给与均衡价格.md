# 第2章 市场需求、供给与均衡价格

> **本章考情**：本章是《经济基础知识》的「图形＋计算」双高发章节，四节内容环环相扣：需求 → 供给 → 均衡 → 弹性。核心考法集中在三类：① 影响因素与曲线平移方向的判断（单选/多选主力，几乎每年必考「线动」题）；② 最高限价与保护价格的对比（多选主力）；③ 需求价格弹性的计算与「弹性—总收益」策略（计算题主力）。整体理解为主、记忆负担中等，但图形方向和公式计算必须动手练。

**一句话串全章**：
> 需求（愿意＋能够）与供给（愿意＋能够）各自受一组因素影响 → **自身价格**引起「点的移动」，**非自身价格**引起「线的平移」→ 需求线与供给线相交定均衡（Qd＝Qs，且供求平衡只是偶然的、暂时的、相对的）→ 政府用**最高限价**（低于均衡价，保消费者）和**保护价格**（高于均衡价，保生产者）干预 → 用四种弹性（价格／交叉／收入／供给）度量反应程度，其中**需求价格弹性**直接决定企业「涨价还是降价」。

## 二、知识点精讲

### 考点1 需求的含义 ★

**核心概念**：需求是指消费者在一定时期内，在一定的价格水平下**愿意而且能够购买**的该商品的数量。

| 项目 | 内容 |
|---|---|
| 需求 | 在一定时期和一定价格条件下，消费者对某种商品或服务愿意而且能够购买的数量 |
| 构成要素 | **愿意**＝购买欲望；**能够**＝支付能力。**两者缺一不可** |
| 市场需求 | 在一定时间、一定价格条件和一定市场上，**所有消费者**对某种商品或服务愿意而且能够购买的数量，即**所有消费者需求的总和** |

**逻辑链**：

```
            购买欲望（愿意）
                  ∧
                  │ 缺一不可
                  ∨
            支付能力（能够）
                  │
                  ▼
         构成「需求」
    仅有欲望无能力 → 不是需求
    仅有能力无欲望 → 不是需求
```

**典型辨析题（素材原题）**：「需求」是经济学中的重要概念，下列属于「需求」的是（　）。
A. 小郑月收入 1000 元（另一版讲义记为 2000 元），准备 2 年内购置 150 万的房产
B. 小周想买一盒巧克力，备好了钱但还没到超市去买
C. 小黄月收入 1.3 万元，但最近没有购买计划
D. 小王想购买一款智能手机，但手头拮据

**答案：B**。解析：需求是在一定时期和一定价格条件下愿意而且能够购买的数量，B 符合「愿意＋能够」两个要素。A 是无支付能力（150 万远超收入），C 是无购买计划（无欲望），D 是手头拮据（无支付能力）。

**速记口诀**：**「愿＋能，缺一不可；想要买不起、买得起不想，都不算需求。」**

### 考点2 影响需求的基本因素 ★★★

**六大因素（务必与「影响供给的因素」区分记忆）**：

| 主要因素 | 具体内容 | 与需求的关系 |
|---|---|---|
| **1. 产品价格** | 产品自身价格是影响需求**最重要、最关键**的因素 | **反**方向（价格和需求的变动方向相反） |
| **2. 消费者偏好** | 支配着消费者在使用价值相同或者相近的**替代品之间**的消费选择；偏好不是固定不变的，在一系列因素作用下**缓慢变化** | 正 |
| **3. 相关商品的价格** | **替代品**为正：某一种商品价格提高，其替代品需求增加；**互补品**为负：某一种商品价格提高，其互补品需求减少 | 替代品为正，互补品为负 |
| **4. 消费者的个人收入** | 消费者收入一般指**一个社会的人均收入**；一般来说收入增加引起需求增加，收入减少引起需求减少 | **正常品正、低档品负** |
| **5. 消费者对价格的预期** | 预期价格上涨，**提前购买**；预期价格下跌，**推迟购买** | 同（与预期同向） |
| **6. 其他因素** | 商品的品种、质量、广告宣传、地理位置、季节、国家政策等 | —— |

**逻辑链**：

```
自身价格 ↑ ────────────────→ 需求量 ↓（反方向，最关键）
替代品价格 ↑ ─────────────→ 本商品需求 ↑（正）
互补品价格 ↑ ─────────────→ 本商品需求 ↓（负）
收入 ↑ ──┬─ 正常品 ───────→ 需求 ↑（正）
         └─ 低档品 ───────→ 需求 ↓（负）
预期涨价 ─────────────────→ 当前需求 ↑（提前购买）
预期跌价 ─────────────────→ 当前需求 ↓（推迟购买）
偏好 ↑ / 品种质量广告地理季节政策改善 → 需求 ↑
```

**素材练习题**：
- 影响商品需求的最关键的因素是（　）。**答案：A 商品价格**（自身价格是最关键因素）。
- 影响需求变动的主要因素有（　）。A.生产技术 B.消费者偏好 C.替代品的价格 D.生产成本 E.互补品的价格。**答案：BCE**（生产技术和生产成本属于影响**供给**的因素）。
- 关于需求的说法，正确的有（　）。A.个人收入增加需求增加 B.价格与需求变化成反方向 C.价格上涨替代品需求增加 D.价格上升互补品需求上升 E.预期价格上涨当前需求增加。**答案：ABCE**（D 错：价格上涨会导致需求量下降，其互补品需求也下降）。

**速记口诀**：**「价反、偏正、替补互替（替代正互补负）、收入看档、预期同向、其他锦上添花。」**

---

### 考点3 需求函数、需求规律和需求曲线 ★★★

**需求函数**：表示一种商品的需求量与影响该需求量的各种因素之间的相互关系。描述一种商品的需求量与价格、收入、偏好、预期以及其他商品价格等之间关系的数学表达式。**假设其他因素不变，只考虑需求量随价格变化：Qd = Qd（P）**。

**需求规律（需求定理）**：在其他条件不变的情况下，商品需求量与价格变化成**反向关系**。价格高需求量小，价格低则需求量大。

**需求曲线**：商品需求量与价格关系的曲线（纵轴 P、横轴 Q，向右下方倾斜）。

**本考点最核心的一对概念——「点动」与「线动」**：

| | 需求量的变动 | 需求的变动 |
|---|---|---|
| 原因 | 其他条件不变，只考虑**自身价格**影响 | 产品价格不变，**非自身价格**因素引起变化 |
| 图形表现 | **点到点的移动**（沿同一条需求曲线） | **整条线平移**（需求曲线位移） |
| 典型例子 | 商品降价，沿曲线向右下方移动 | 收入增加、偏好增强 → 需求曲线**向右上方**移动；收入减少 → **向左下方**移动 |

**逻辑链**：

```
           价格（自身）变化
                 │
        ┌────────┴────────┐
        ▼                 ▼
  需求量的变动        需求的变动
  （点的移动）        （线的平移）
  沿同一条 D 曲线     整条 D 曲线位移
        ▲                 ▲
        └────────┬────────┘
            非价格因素
     （收入、偏好、相关商品价格、预期等）
```

**平移方向速判**：
- 收入增加（正常品）/ 偏好增强 / 替代品涨价 / 互补品降价 / 预期涨价 → 需求曲线**向右上方**移动
- 收入减少（正常品）/ 偏好减弱 / 替代品降价 / 互补品涨价 / 预期跌价 → 需求曲线**向左下方**移动
- **生产成本**变化 → 影响的是**供给**曲线，不影响需求曲线
- **价格弹性**不影响需求曲线

**素材练习题**：
- 一个商品价格下降对其互补品最直接的影响是（　）。**答案：A 互补品的需求曲线向右移动**（价格提高，互补品需求减少、曲线左移；价格下降，互补品需求增加、曲线右移）。
- 以纵轴代表价格、横轴代表产量绘制需求曲线和供给曲线，其他条件不变，当消费者收入增加时表现为（　）。**答案：C 需求曲线向右上方移动**（收入属影响需求的因素，排除两个供给选项；收入增加表现为需求曲线位移，向右上方移动）。
- 能够导致某种商品的需求曲线发生转移的因素包括（　）。A.该商品自身的价格 B.消费者偏好 C.消费者收入 D.价格弹性 E.生产成本。**答案：BC**（位移与自身价格无关；价格弹性不影响需求曲线；生产成本引起供给曲线位移）。
- 根据需求理论，导致某一时期高档品牌衣服需求曲线向右平移的原因有（　）。A.该品牌衣服价格上升 B.该衣服品质很好 C.消费者对该品牌衣服偏好增加 D.该品牌衣服生产成本下降 E.消费者收入水平上升。**答案：BCE**（线的移动是自身价格以外的因素导致，排除 A；D 是影响供给的因素）。
  > **变式说明**：另有「高档品牌饮品」版本（B 选项为「该饮品广告费用上升」），该版答案为 **CE**。两版差异在选项设置，答题时以题面选项为准。

**速记口诀**：**「自身价格点动，非自身价格线动；收入偏好线动，生产成本只管供给。」**

### 考点4 供给的含义 ★

| 项目 | 内容 |
|---|---|
| 供给 | 在某一时间内和一定的价格水平下，生产者**愿意而且能够**为市场提供某种商品或服务的数量 |
| 市场供给 | 在每一个可能的价格下，生产同一种商品的所有生产者供给的总和（即**所有生产者供给的总和**） |

> 供给同样隐含「愿意＋能够」两个要素，与需求的定义结构完全对称。

---

### 考点5 影响供给的因素 ★★★

| 因素 | 具体内容 |
|---|---|
| **产品自身价格** | 其他条件不变的情况下，某种产品自身的价格与其供给的变动呈**正方向**变化 |
| **非自身价格因素** | ① **生产成本**（反向）<br>② **生产技术水平**（正向）<br>③ **相关产品的价格**（与需求中的影响相反）<br>④ **生产者预期**<br>⑤ 其他因素：**生产要素的价格和国家政策**等 |

**逻辑链**：

```
自身价格 ↑ ─────────────────→ 供给量 ↑（正方向）
生产成本 ↑（原料价、税负）──→ 供给 ↓（反向）→ 供给曲线左移
生产技术水平 ↑ ─────────────→ 供给 ↑（正向）→ 供给曲线右移
相关产品价格 / 生产者预期 / 要素价格 / 国家政策 → 影响供给
```

**素材练习题**：
- 影响供给的因素有（　）。A.消费者收入 B.销售者预期 C.产品价格 D.生产成本 E.消费者偏好。**答案：BCD**（消费者偏好与消费者收入属于影响**需求**的因素，选 B、C、D 时注意题干「影响供给」）。

**速记口诀**：**「价正、本反、技正；预期、相关品、要素价、国家政策都算非价格因素。」**

---

### 考点6 供给函数、供给规律和供给曲线 ★★

**供给函数**：表示某一种商品的供给量和影响该商品供给量的各种因素之间的相互关系。假设其他因素不变，只考虑价格：**Qs = Qs（P）**。

**供给规律（供给定理）**：其他条件不变的情况下，商品供给量与价格的变化成**正比（正方向）关系**。价格高供给量大，价格低供给量小。

**供给曲线**：某商品供给量与价格之间关系的曲线（向右上方倾斜）。

**「点动」与「线动」（与需求完全对称）**：

| | 供给量的变动 | 供给的变动 |
|---|---|---|
| 原因 | 其他条件不变，只考虑**自身价格**影响 | 产品价格不变，**非自身价格**因素引起变化 |
| 图形表现 | **点到点的移动**（沿同一条供给曲线） | **整条线平移**（供给曲线位移） |
| 典型例子 | 商品涨价，沿曲线向右上方移动 | 成本上升 → 供给曲线**向左**移动；成本下降 → **向右**移动 |

**素材练习题**：
- 假如生产某种物品所需原料价格上升了，则这种商品的（　）。**答案：B 供给曲线向左方移动**（成本上升，供给曲线左移；成本下降，供给曲线右移）。
- 导致某种商品供给曲线发生位移的因素是（　）。A.该商品的成本 B.该商品的价格 C.该商品的税率 D.消费者偏好。**答案：A**（假定价格不变，由于价格以外的其他因素如成本、预期等因素发生变动而引起供给的变动，称为供给的变化，表现为供给曲线的位移）。
  > **串扰提示**：由「香烟增税 → 生产成本增加 → 供给曲线向左移动」一题可见，**税率是通过生产成本间接影响供给的**；本题单选取最直接因素「成本」。
- 假设纵轴是商品价格、横轴是数量，绘制出某种香烟的供给曲线和需求曲线。当政府实行增税措施，使得香烟的生产成本增加时，曲线变化是（　）。**答案：C 香烟的供给曲线将向左移动**。

**速记口诀**：**「供给价同向；成本涨、线左移，成本降、线右移。」**

### 考点7 均衡价格和均衡数量的形成和变动 ★

**市场均衡**：需求与供给两种力量作用下，市场达到 **Qd = Qs** 的状态。

| 项目 | 内容 |
|---|---|
| 均衡价格 | 市场供求达到平衡时（Qd＝Qs）对应的价格 |
| 均衡数量 | 市场供求达到平衡时（Qd＝Qs）对应的数量 |
| 供求平衡的性质 | **偶然的、暂时的、相对的** |

**逻辑链**：

```
       需求曲线 D（向右下方）
              ＼
                ＼   ← 均衡点 E
        ─────────●─────────
                  ／ ＼
       供给曲线 S（向右上方）
              ＼   ＼
                ＼   ＼
         0 ─────└───┴────→ Q
                Qe
        D 与 S 相交：Qd = Qs → 均衡价格 Pe、均衡数量 Qe
```

---

### 考点8 均衡价格模型的运用（最高限价、保护价格）★★★

最高限价与保护价格是政府对市场价格的**干预措施**，二者是本章多选最高频考点，务必成对记忆。

**（一）最高限价**

| 项目 | 内容 |
|---|---|
| 定义 | 政府为某种产品规定一个具体价格，市场交易**只能在这一价格之下**进行 |
| 目的 | **保护消费者的利益**或者降低某些生产者的生产成本 |
| 定位 | **低于市场均衡价格**，属于政府对市场价格的干预措施 |
| 采用情形 | 当某些产品价格上涨幅度过大，有可能影响居民的基本生活需要，或影响生产的正常进行时采用 |
| 影响 | ① 严重的排队现象；② 商品供给短缺；③ 黑市交易和黑市高价；④ 变相涨价（以次充好、缺斤短两）；⑤ 产生腐败问题（走后门） |
| 解决 | 政府**配给制**；必须有强有力的行政措施和分配措施 |
| 适用 | **短期、局部地区**使用，不应长期化 |

**（二）保护价格（也称支持价格、最低限价）**

| 项目 | 内容 |
|---|---|
| 定义 | 政府为某种产品规定一个具体价格，市场交易**只能在这一价格之上**进行 |
| 目的 | 大多为**扶持某些行业发展**，或基于**保护生产者**的考虑 |
| 定位 | **高于市场均衡价格**，属于政府对市场价格的干预措施 |
| 采用情形 | 当某些产品价格下降幅度过大，生产者收入过少，有可能影响生产的正常进行时采用 |
| 影响 | ① 供给过剩；② 政府为过剩的商品买单；③ 增加财政负担；④ 黑市交易、变相降价 |
| 解决 | 政府建立**收购和储备系统** |
| 适用 | **粮食等少数农产品** |

**逻辑链（成对记忆）**：

```
          最高限价                    保护价格（支持价格/最低限价）
   ┌──────────────────┬──────────────────┐
   │ 交易只能在价格「之下」 │ 交易只能在价格「之上」 │
   │ 低于均衡价格        │ 高于均衡价格        │
   │ 保护消费者 / 降成本  │ 保护生产者 / 扶持产业 │
   │ 刺激消费、限制生产   │ 刺激生产、限制消费   │
   │ → 供给短缺、排队、黑市│ → 供给过剩、财政负担 │
   │ 解决：配给制        │ 解决：收购储备系统   │
   │ 短期/局部           │ 粮食等少数农产品     │
   └──────────────────┴──────────────────┘
        「最高」保「最低」的人 → 保消费者
        「最低」保「最高」的人 → 保生产者
```

**素材练习题**：
- 政府为了保护农业生产者，对部分农业产品规定了保护价格。为了采取这种价格政策，应采取相应的措施是（　）。A.取消农业税 B.对城镇居民实行粮食配给制 C.当市场上出现农产品过剩时进行收购 D.扩大农民家电消费。**答案：C**（当实施保护价格出现过剩时，如果没有政府的收购，就会出现变相降价或黑市交易等问题；当市场出现供给过剩时，政府要及时入市收购过剩产品并予以储备，否则保护价格必然会流于形式）。

**速记口诀**：**「最高限价在下方，短缺排队配给忙；保护价格在上方，过剩收储财政扛。」**

### 考点9 需求价格弹性 ★★

**含义**：一定时期内一种商品的需求量变动对于该商品价格变动的反应程度。

**计算**：需求量变动百分比与价格变动百分比的比率，即**需求量的相对变动 ÷ 价格的相对变动**。

**类型**：

| 类型 | 系数 | 判别 |
|---|---|---|
| **富有弹性（高弹性）** | Ed＞1 | 需求量变动百分数**大于**价格变动百分数 |
| **缺乏弹性（低弹性）** | Ed＜1 | 需求量变动百分数**小于**价格变动百分数 |
| **单一弹性（单位弹性）** | Ed＝1 | 需求量变动百分数**等于**价格变动百分数 |

**需求弹性与总收益的关系（TR = P × Q）——计算题与策略题核心**：

| 类型 | 价格变动→数量变动 | 总收益 TR | P 与 TR | 策略 |
|---|---|---|---|---|
| **富有弹性** | P↑ Q↓↓ → TR↓；P↓ Q↑↑ → TR↑ | 反向 | **降价策略** | 富有弹性—奢侈品—降价策略 |
| **缺乏弹性** | P↑↑ Q↓ → TR↑；P↓↓ Q↑ → TR↓ | 同向 | **涨价策略** | 缺乏弹性—必需品—高价策略 |
| **单位弹性** | —— | 降价或涨价都不会影响销售收入 | —— | 价格变动不影响收入 |

**记忆要点**：
- 企业实行**薄利多销**的理论基础 = 需求价格弹性系数**大于 1**时，降低价格使销售收入增加。
- 想通过降价增加总销售收入 → 该商品需求价格弹性系数应**大于 1**。
- 富有弹性的商品应**适当降价销售**。

**影响需求价格弹性的因素（四个）**：

| 因素 | 具体内容 |
|---|---|
| 1. 替代品的数量和相近程度 | 替代品越多、越相近 → 弹性越大；替代品越少 → 弹性越小 |
| 2. 商品的重要性 | 生活必需品（即使涨价也得买）→ 缺乏弹性；非必需的高档商品（贵重首饰、高档服装）→ 弹性大 |
| 3. 商品用途的多少 | 用途越多 → 需求弹性越大；反之缺乏弹性 |
| 4. 时间的长短 | 时间越短 → 弹性越小；时间越长 → 弹性越大 |

**素材练习题**：
- 某种商品的价格下降 2%，其需求量增加了 4%，那么这种产品需求价格弹性属于（　）。**答案：C 需求富有弹性**（Ed＝4%÷2%＝2＞1）。
- 需求缺乏弹性的表现为（　）。**答案：A 需求弹性系数小于 1**。
- 在其他条件既定的情况下，需求富有弹性的商品应该（　）。**答案：A 适当降价销售**。
- 就生产者和销售者而言，如果想通过降低价格来增加其总销售收入，那么该商品的（　）。**答案：C 需求价格弹性系数应大于 1**。
- 企业实行薄利多销策略的理论基础是（　）。**答案：B 商品需求价格弹性系数大于 1 时，降低价格使得销售收入增加**。
- 决定某种商品需求价格弹性大小的因素主要有（　）。A.替代品的数量和相近程度 B.生产周期长短 C.生产自然条件状况 D.商品在生活消费中的重要性 E.商品用途多少。**答案：ADE**（B、C 属于影响**供给**价格弹性的因素）。
- 关于需求价格弹性影响因素的说法，正确的有（　）。A.生活必需品的需求缺乏弹性 B.时间越短，商品的需求弹性越小 C.奢侈品需求弹性大 D.一种商品如果有极少的替代品，该商品的需求弹性大 E.商品的用途越多，需求弹性越大。**答案：ABCE**（D 错：替代品越少，弹性越小）。
- 一般来说，需求弹性较大的产品是（　）。A.用途多的产品 B.高档品 C.有很多互补品的产品 D.有很多替代品的产品 E.生活必需品。**答案：ABD**（E 错：生活基本必需品弹性小）。

**速记口诀**：**「Ed 一看 1：大于 1 富有、小于 1 缺乏、等于 1 单一；富降缺涨，单位弹性不影响收入。」**

### 考点10 需求交叉弹性 ★★★

**含义**：一定时期内一种商品的需求量的变动对于它的**相关商品**价格的变动的反应程度。即商品 i 需求量变动百分比与商品 j 价格变动百分比的比率。

**计算**：商品 i 需求量的相对变动 ÷ 商品 j 价格的相对变动。

**公式**：Eij = （ΔQi/Qi）÷（ΔPj/Pj）

**类型**：

| 两种商品关系 | 系数 |
|---|---|
| **替代品** | Eij＞0 |
| **互补品** | Eij＜0 |
| **独立品（无关）** | Eij＝0 |

**逻辑链**：

```
  Eij > 0 ──→ 替代品（使用价值相同或相似）
              j 涨价 → i 需求量增加
  Eij < 0 ──→ 互补品
              j 涨价 → i 需求量减少
  Eij = 0 ──→ 独立品（无关）
```

**素材练习题**：
- 若 X 和 Y 两商品的交叉价格弹性是 -2.3，则（　）。**答案：D X 和 Y 是互补品**（Eij＜0，商品 j 价格上涨引起商品 i 需求量下降，二者为互补品）。
- 需求交叉弹性小于 0 的是（　）。A.燃气和电 B.汽车和汽油 C.口罩和钻石 D.苹果和自行车。**答案：B**（交叉弹性小于 0 表明两种商品为互补品，汽车和汽油属于互补品）。
- 若 X 和 Y 两商品使用价值相近似，则这两种商品的需求交叉价格弹性为（　）。**答案：C 大于 0**（使用价值相同或相似说明两者是替代关系，替代品的需求交叉弹性为正数）。

**速记口诀**：**「替代品为正，互补品为负，独立品为零。」**

### 考点11 需求收入弹性 ★★★

**含义**：一定时期内消费者对某种商品的需求量的变动对消费者收入变动的反应程度，即需求量变动百分比与收入变动百分比的比率。

**公式**：Ey = （ΔQ/Q）÷（ΔY/Y）

**类型**：

| 类型 | 系数 | 特征 |
|---|---|---|
| **高档品** | Ey＞1 | 需求数量的相应增加**大于**收入的增加 |
| **必需品** | 0＜Ey＜1 | 需求数量的相应增加**小于**收入的增加 |
| **低档品** | Ey＜0 | 收入增加时买得少，收入降低时买得多 |
| 特例 | Ey＝1 | 收入变动和需求数量变动成相同比例 |
| 特例 | Ey＝0 | 无论收入如何变动，需求均不变 |

**归类结论（多选高频）**：凡是需求收入弹性系数**大于 1** 的商品都可以称为「高档品」；需求收入弹性系数**大于 0 小于 1** 的商品称为「必需品」；「高档品」和「必需品」统称为**正常品**；需求收入弹性系数为**负值**的商品称为「低档品」。

**素材练习题**：
- 假定消费者收入增加 25%，会导致某种商品的需求量增加 10%，则该商品的类型为（　）。**答案：D 必需品**（Ey＝10%÷25%＝0.4，0＜Ey＜1）。
- 若某商品的需求收入弹性为负，则该商品为（　）。**答案：B 低档品**（Ey＜0，收入增加时买得少、收入降低时买得多）。
- 关于需求收入弹性的说法，正确的有（　）。A.需求收入弹性系数大于 0 而小于 1 属于正常品 B.小于 0 属于低档品或劣等品 C.大于 1 属于奢侈品 D.大于 0 属于正常品 E.大于 0 属于奢侈品。**答案：ABCD**（E 错：大于 0 只是正常品，大于 1 才是高档品/奢侈品）。

**速记口诀**：**「一看收入弹性：大于 1 高档、0 到 1 必需、小于 0 低档；高档＋必需＝正常品。」**

### 考点12 供给价格弹性 ★

**含义**：一定时期内一种商品供给量的变动对于该商品的价格变动的反应程度，即供给量变动百分比与价格变动百分比的比率（供给量的相对变动 ÷ 价格的相对变动）。

**公式**：Es = （ΔQs/Qs）÷（ΔP/P）

**类型**：

| 类型 | 系数 |
|---|---|
| 供给价格弹性充足 | Es＞1 |
| 供给价格弹性不充足 | Es＜1 |
| 供给完全无弹性 | Es＝0 |
| 供给弹性系数为 1（单位弹性） | Es＝1 |
| 供给完全有弹性 | Es＝∞ |

**影响供给价格弹性的因素（三个）**：

| 影响因素 | 具体内容 |
|---|---|
| **1. 时间（首要因素）** | 短期内，供给价格弹性小；长期内，供给价格弹性大 |
| **2. 生产周期和自然条件** | 在短期内，供给价格弹性几乎为零 |
| **3. 投入品的替代性大小和相似程度** | 投入品替代品多 → 弹性大；投入品难以加入 → 供给缺乏弹性 |

**素材练习题**：
- 某种商品供给完全无弹性是指该商品的供给弹性系数（　）。**答案：C 等于 0**。
- 影响某种商品的供给价格弹性的因素有（　）。A.使用价值 B.生产周期和自然条件 C.需求函数 D.商品在生产中的重要性 E.投入品替代性大小和相似程度。**答案：BE**（三个因素：时间、生产周期和自然条件、投入品替代性大小和相似程度）。

**速记口诀**：**「时间定弹性（首要），周期自然条件卡短期，投入品替代表长期。」**

### 考点13 恩格尔定律 ★★★

| 项目 | 内容 |
|---|---|
| 食物支出收入弹性 | 消费者用于购买食物的支出对于消费者收入变动的反应程度 |
| **定律** | 一个家庭或一个经济体中，食物支出在收入中占的比例随着收入的增加而**减少** |
| 弹性结论 | **富裕程度越高，则食物支出的需求收入弹性越小；反之，食物支出的需求收入弹性越大** |

**逻辑链**：

```
收入 ↑ ──→ 食物支出在收入中的占比 ↓（恩格尔定律）
      └─→ 食物支出的需求收入弹性 ↓
富裕程度 ↑ ──→ 食物支出需求收入弹性 ↓
```

**素材练习题**：
- 关于恩格尔定律说法正确的是（　）。**答案：D 一个家庭或一个经济体中，食物支出在收入中占的比例随着收入的增加而减少**（A 错：恩格尔定律是对**需求收入弹性**研究的结果；B 错：比例是减少不是增加；C 错：富裕程度越高，食物支出的需求收入弹性越**小**）。
- 根据恩格尔定律，一个家庭富裕程度越高，其食品支出的（　）越小。**答案：A 需求收入弹性**。

**速记口诀**：**「越富裕，吃饭占比越小，食物的收入弹性也越小。」**

| 保护价格低于均衡价格 | ✗ 保护价格（支持价格/最低限价）**高于**均衡价格 |

| 最高限价需要政府建立收购和储备系统 | ✗ 那是**保护价格**的配套；最高限价靠**配给制** |
| 保护价格就是最高限价 | ✗ 两者是**相反方向**的干预 |
| 保护价格的目的是保护消费者利益 | ✗ 是**保护生产者利益**或支持某一产业发展 |
| 交叉弹性为正是互补品 | ✗ **替代品为正、互补品为负、独立品为零** |
| 需求收入弹性大于 0 就是高档品 | ✗ 大于 0 只是正常品；**大于 1 才是高档品** |
| 恩格尔定律是对需求价格弹性研究的结果 | ✗ 是对**需求收入弹性**研究的结果 |
| 富裕程度越高，食物支出的需求收入弹性越大 | ✗ 富裕程度越高，食物支出占比**越小**、食物支出需求收入弹性**越小** |
| 生产周期长短是影响需求价格弹性的因素 | ✗ 生产周期和自然条件是影响**供给**价格弹性的因素 |

## 四、公式与计算（本章重点）

### 公式1 需求价格弹性系数（端点公式）

```
             需求量变动百分比
  Ed = ─────────────────────── = 需求量的相对变动 ÷ 价格的相对变动
                 价格变动百分比

              ΔQ / Q
       ─────────────────
              ΔP / P
```

**端点公式例题（素材原例）**：已知某商品 P1 = 5 元、P2 = 7 元，Q1 = 500 件、Q2 = 300 件。分别以 P1/Q1 和 P2/Q2 为端点计算需求价格弹性。

**演算**：
- 以 P1、Q1 为基期：ΔQ/Q = (300−500)/500 = **−40%**；ΔP/P = (7−5)/5 = **+40%**
  Ed = (−40%)/(+40%) = **−1**，取绝对值为 1 → 单一弹性
- 以 P2、Q2 为基期：ΔQ/Q = (300−500)/300 ≈ **−66.7%**；ΔP/P = (7−5)/7 ≈ **+28.6%**
  Ed = (−66.7%)/(+28.6%) ≈ **−2.33**，取绝对值大于 1 → 富有弹性

**结论**：同一段价格变动，选不同端点算出的弹性系数不同（1 与 2.33），这正是要引入**中点公式（弧弹性）**的原因。

---

### 公式2 需求价格弧弹性（中点公式）

```
              ΔQ
        ────────────────            ΔQ / [(Q1+Q2)/2]
  Ed = ────────────────   即  Ed = ─────────────────────
              ΔP                       ΔP / [(P1+P2)/2]
        [(Q1+Q2)/2] 与 [(P1+P2)/2] 分别为数量与价格的中点（平均值）
```

**弧弹性例题（素材原题）**：某商品的价格为 2 元/件时，销售量为 300 件；当价格提高到 4 元/件时，销售量为 100 件。按照弧弹性公式计算，该商品的需求价格弹性是（　）。
A. 0.40　B. 0.67　C. 1.50　D. 2.00

**演算**：
- ΔQ = 100 − 300 = **−200**；数量中点 (Q1+Q2)/2 = (300+100)/2 = **200** → 需求量相对变动 = −200/200 = **−100%**
- ΔP = 4 − 2 = **+2**；价格中点 (P1+P2)/2 = (2+4)/2 = **3** → 价格相对变动 = 2/3 ≈ **+66.7%**
- Ed = (−100%)/(+66.7%) = **−1.5**，取绝对值 **|Ed| = 1.50**

**答案：C**。

---

### 公式3 需求价格点弹性

```
  点弹性系数 = 需求量的相对变化 ÷ 价格的相对变化
```

**点弹性例题（素材原题）**：已知某商品的需求价格点弹性系数为 −0.5，当价格为每件 32 元时，其市场销售量为 1000 件。如果该商品价格下降 10%，在其他因素不变的条件下，其销售量应是（　）件。
A. 1050　B. 950　C. 1200　D. 1100

**演算**：
- 已知价格相对变化 = 10%，点弹性系数绝对值 = 0.5
- 需求量的相对变化 = 0.5 × 10% = **5%**
- 销售量变化 = 1000 × 5% = **50 件**
- 价格下降 → 销售量上升 → 销售量 = 1000 + 50 = **1050 件**

**答案：A（1050 件）**。

---

### 公式4 需求交叉弹性

```
            商品 i 需求量变动百分比                ΔQi / Qi
  Eij = ────────────────────────      Eij = ────────────────
                商品 j 价格变动百分比               ΔPj / Pj
```

**交叉弹性演算例题**：已知商品 i 的需求量由 200 件下降到 160 件（相对变动 −20%），同期其相关商品 j 的价格由 20 元上升到 25 元（相对变动 +25%），其他条件不变。

**演算**：
- Eij = (−20%)/(+25%) = **−0.8**
- Eij＜0 → 商品 i 与商品 j 为**互补品**（j 涨价导致 i 需求量下降）

**判读**：Eij＞0 替代品；Eij＜0 互补品；Eij＝0 独立品。

---

### 公式5 需求收入弹性

```
             需求量变动百分比                ΔQ / Q
   Ey = ──────────────────────     Ey = ────────────────
                 收入变动百分比                ΔY / Y
```

**收入弹性演算例题（素材原题）**：假定消费者收入增加 25%，会导致某种商品的需求量增加 10%。

**演算**：
- Ey = 10% ÷ 25% = **0.4**
- 0＜Ey＜1 → 需求数量的相应增加小于收入的增加 → 该商品为**必需品**

**判读表**：Ey＞1 高档品；0＜Ey＜1 必需品；Ey＜0 低档品；Ey＝1 同比例；Ey＝0 需求不变。

---

### 公式6 供给价格弹性

```
             供给量变动百分比                ΔQs / Qs
   Es = ──────────────────────     Es = ────────────────
                 价格变动百分比                 ΔP / P
```

**供给弹性演算例题**：已知某商品价格上升 10%，生产者愿意提供的数量增加 4%，其他条件不变。

**演算**：
- Es = 4% ÷ 10% = **0.4**
- Es＜1 → 供给价格弹性**不充足**（短期供给对价格反应较弱）

**判读表**：Es＞1 弹性充足；Es＜1 弹性不充足；Es＝0 完全无弹性；Es＝1 单位弹性；Es＝∞ 完全有弹性。

---

### 公式7 「量的变动」与「的变动」——方向的算术验证

**需求的变动（线的平移）例题（素材原题）**：某月内，甲商品的替代品和互补品的价格同时上升，引起的甲商品的需求变动量分别为 50 单位和 80 单位。

**演算**：
- 替代品价格上升 → 甲商品需求 **增加 50 单位**（正）
- 互补品价格上升 → 甲商品需求 **减少 80 单位**（负）
- 共同作用：+50 − 80 = **−30 单位** → 甲商品需求量**减少 30 单位**

**答案：B（减少 30 单位）**。此为「非自身价格因素 → 整条需求曲线平移」的算术验证。

**供给量的变动（点的移动）验证**：某商品价格由 2 元/件提高到 4 元/件，销售量由 300 件降到 100 件——这是**自身价格**变化引起的「供给量/需求量变动」，在图形上表现为沿同一条曲线的**点的移动**，而不是曲线平移。

## 五、高频考点速记卡

1. **Q：需求的构成要素？**
   A：**愿意**（购买欲望）＋**能够**（支付能力），两者缺一不可。

2. **Q：市场需求如何形成？**
   A：市场需求 = **所有消费者需求的总和**（市场需求曲线是所有个别消费者需求曲线的**水平加总**）。

3. **Q：影响需求最关键的因素是什么？关系方向？**
   A：**产品自身价格**，且价格与需求变动方向**相反**。

4. **Q：替代品与互补品价格如何影响本商品需求？**
   A：替代品价格提高 → 本商品需求**增加**（正）；互补品价格提高 → 本商品需求**减少**（负）。

5. **Q：收入与需求的关系？**
   A：收入增加一般引起需求增加；对**正常品为正、低档品为负**。

6. **Q：价格预期如何影响当前需求？**
   A：预期涨价 → **提前购买**（当前需求增加）；预期跌价 → **推迟购买**。

7. **Q：「需求量的变动」与「需求的变动」区别？**
   A：自身价格变化 → **点的移动**（沿曲线）；非自身价格因素变化 → **整条线平移**。

8. **Q：哪些因素能使需求曲线位移？**
   A：消费者偏好、消费者收入、相关商品价格、预期等**非价格因素**；自身价格、价格弹性不能；生产成本影响的是**供给**曲线。

9. **Q：消费者收入增加，图形上如何表现？**
   A：需求曲线向**右上方**移动。

10. **Q：供给的定义与影响因素？**
    A：一定时期、一定价格下生产者**愿意而且能够**提供出售的数量。影响因素：产品价格（正）、生产成本（反）、生产技术（正）、相关产品价格、生产者预期、生产要素价格和国家政策。

11. **Q：原料价格上升，曲线怎么动？**
    A：成本增加 → **供给曲线向左方移动**（成本下降向右移动）。

12. **Q：什么是市场均衡？**
    A：**Qd = Qs** 的状态；供求平衡是**偶然的、暂时的、相对的**。

13. **Q：最高限价与保护价格的核心区别？**
    A：最高限价 = 交易只能在价格**之下**、**低于**均衡价、保**消费者**、导致**短缺**、靠**配给制**、宜短期；保护价格（支持价格/最低限价）= 交易只能在价格**之上**、**高于**均衡价、保**生产者**、导致**过剩**、靠**收购储备系统**、适用粮食等少数农产品。

14. **Q：薄利多销的理论基础？**
    A：需求价格弹性系数**大于 1**（富有弹性）时，降价使销售收入增加。

15. **Q：四种弹性「一看就懂」的界限？**
    A：Ed＞1 富有 / ＝1 单一 / ＜1 缺乏；Eij＞0 替代 / ＜0 互补 / ＝0 独立；Ey＞1 高档 / 0～1 必需 / ＜0 低档；Es＞1 充足 / ＝0 完全无弹性 / ∞ 完全有弹性。

16. **Q：影响需求价格弹性的四个因素？**
    A：替代品的数量和相近程度、商品的重要性、商品用途的多少、时间的长短。（生产周期与自然条件属**供给**弹性因素）

17. **Q：影响供给价格弹性的三个因素？**
    A：时间（首要因素）、生产周期和自然条件、投入品的替代性大小和相似程度。

18. **Q：恩格尔定律怎么说？**
    A：食物支出在收入中占的比例随收入增加而**减少**；富裕程度越高，食物支出的需求收入弹性越**小**。

**【2024·单选】如果某种商品的价格上升导致另一种商品的需求量增加，这两种商品是（　）。**
A. 替代关系　B. 互补关系　C. 低档品　D. 正常品

**答案：A**
**解析**：当两种商品可以相互替代时，一种商品价格上升，就会有部分消费者不再购买该商品而去购买另一种替代商品，替代商品的需求量增加。故替代关系的价格变动和需求量变动是**同一方向**（交叉弹性为正）。

---

**【2023补·单选】通常情况下，在坐标图上，引起小汽车的需求曲线向左平移的原因应是（　）。**
A. 公共交通票价上调　B. 小汽车的生产成本下降　C. 汽油等能源价格上涨　D. 消费者的收入增长

**答案：C**
**解析**：假定价格不变，由于消费者收入或消费者偏好以及预期等因素的变化引起需求的相应变化，这种变化表现为需求曲线的位移。汽油等能源价格上涨属于小汽车**互补品**的价格上涨，会导致小汽车的需求量下降，因此需求曲线**向左平移**。（B 生产成本影响的是供给曲线；A 公共交通票价上调会使小汽车需求增加、曲线右移；D 收入增长同样使需求曲线右移。）

**【2024·单选】横轴表示需求量、纵轴表示价格，假定其他条件不变，消费者预期某种商品价格将要上升，会导致该商品的市场需求数量和需求曲线发生的变化是（　）。**
A. 需求曲线向右上方移动，需求数量增加
B. 需求曲线向左下方移动，需求数量减少
C. 需求曲线不变，需求数量沿着该曲线增加
D. 需求曲线不变，需求数量沿着该曲线增加

**答案：A**
**解析**：当消费者预期某种商品的价格将要上升时，他们会在当前购买更多的该商品，以避免未来价格上涨带来的损失。因此，当前的需求数量会增加。当需求量增加时，需求曲线会**向右移动**。

**【2020·单选】关于需求曲线的说法，正确的是（　）。**
A. 假定价格不变，由于消费者预期的变化引起需求量变动
B. 假定价格不变，由于消费者偏好的变化引起需求量变动
C. 市场需求曲线是所有个别消费者需求曲线的水平加总
D. 假定价格不变，由于消费者收入的变化引起需求量变动

**答案：C**
**解析**：由于消费者收入、消费者偏好、消费者预期等因素的变化引起需求的相应变化，这种变化表现为需求曲线的**位移**（是「需求的变动」而非「需求量的变动」），故 A、B、D 均把「线动」误述为「量变」。由于某种商品的市场需求就是所有消费者个人对该商品的需求之和，因此市场需求曲线也就是所有个别消费者需求曲线的**水平加总**。

**【2025·多选】下列关于最高限价说法正确的是（　）。**
A. 在我国最高限价是政府对市场的干预措施
B. 若最高限价低于市场均衡价格，将会刺激消费，限制生产，导致市场供给短缺
C. 当实施最高限价出现短缺现象时，市场就会出现严重的排队现象
D. 最高限价的目的是保护消费者利益或降低某些生产者的生产成本
E. 最高限价的目的是保护生产者利益，或提高某些生产者收入

**解析**：所谓最高限价，即由政府为某种产品规定一个具体的价格，市场交易只能在这一价格之下进行。其目标是**保护消费者利益或降低某些生产者的生产成本**。在我国，最高限价属于政府对市场价格的**干预措施**。当某种或某些产品价格上涨幅度过大，有可能影响居民的基本生活需要或影响生产的正常进行时，政府可以采取这种方式进行。E 错——「保护生产者利益、提高生产者收入」是**保护价格**的目的。

**【2024·单选】关于保护价格的说法正确的是（　）。**

**【2023·多选】关于保护价格的说法，正确的有（　）。**

E. 保护价格只适宜在粮食等少数农产品上实行

**答案：ADE**
**解析**：保护价格，也称支持价格或最低限价，即由政府规定一个具体的价格，市场交易只能在这一价格之上进行，其目的是**保护生产者利益或支持某一产业的发展**（选项 B 错误）；要保证保护价格顺利实施，除了要有强有力的行政措施外，还必须建立政府的**收购和储备系统**（选项 C 错误，配给制是最高限价的解决手段）。

**【2022·多选】下列关于保护价格的说法，正确的有（　）。**
A. 保护价格可能导致市场供给过剩
B. 保护价格可以刺激消费
C. 一些国家或地区采用保护价格政策来支持农业生产和稳定农民收入水平
D. 保护价格一般高于均衡价格
E. 保护价格就是最高限价

**答案：ACD**
**解析**：所谓保护价格，也称支持价格或最低限价，即由政府规定一个具体的价格，市场交易只能在这一价格之上进行，其目的是保护生产者利益或支持某一产业的发展。在我国，保护价格属于政府对市场价格的干预措施。当某种或某些产品价格下降幅度过大，生产者收入过少，有可能影响生产的正常进行时，政府可以采取这种方式进行干预。我国和其他一些国家或地区采用保护价格政策来**支持农业生产和稳定农民收入水平**。由于保护价格高于均衡价格，因此会**刺激生产、限制消费**，导致市场供给过剩。B 错在「刺激消费」（应为限制消费）；E 错在把保护价格等同于最高限价。

**【2025·单选】关于恩格尔定律说法正确的是（　）。**
A. 恩格尔定律是对需求价格弹性研究的结果
B. 一个家庭或一个经济体中，食物支出在收入中占的比例随着收入的增加而增加
C. 富裕程度越高，则食物支出的需求收入弹性越大
D. 一个家庭或一个经济体中，食物支出在收入中占的比例随着收入的增加而减少

**答案：D**
**解析**：选项 A 错误，恩格尔定律是对**需求收入弹性**研究的结果。选项 B 错误，一个家庭或一个经济体中，食物支出在收入中占的比例随着收入的增加而**减少**。选项 C 错误，富裕程度越高，则食物支出的需求收入弹性越**小**。

**【2024·单选】需求的交叉弹性是指（　）。**
A. 一种商品的需求量引起另外一种商品价格的变动
B. 商品的需求量引起商品本身价格的变动
C. 商品的需求量对于消费者收入变动的反应程度
D. 商品的需求量的相对变化与价格相对变化之比

**答案：A**
**解析**：需求的交叉弹性是指一种商品的需求量引起另外一种商品价格的变动。**避坑**：C 是需求收入弹性的定义，D 是需求价格弹性的定义（且未体现「另一种商品」），均不能选。

**【经典·单选】某商品的价格为 2 元/件时，销售量为 300 件；当价格提高到 4 元/件时，销售量为 100 件。按照弧弹性公式计算，该商品的需求价格弹性是（　）。**
A. 0.40　B. 0.67　C. 1.50　D. 2.00

**答案：C**
**解析**：按弧弹性（中点）公式，Ed = [ΔQ/((Q1+Q2)/2)] ÷ [ΔP/((P1+P2)/2)] = [−200/200] ÷ [2/3] = −1.5，取绝对值为 **1.50**。

**【经典·单选】已知某商品的需求价格点弹性系数为 −0.5，当价格为每件 32 元时，其市场销售量为 1000 件，如果该商品价格下降 10%，在其他因素不变的条件下，其销售量应是（　）件。**
A. 1050　B. 950　C. 1200　D. 1100

**答案：A**
**解析**：点弹性系数 = 需求量的相对变化 ÷ 价格的相对变化。价格相对变化为 10%，点弹性系数为 0.5，故需求量的相对变化 = 0.5 × 10% = 5%；销售量变化 = 1000 × 5% = 50 件。价格下降，销售量上升，故销售量为 1000 + 50 = **1050 件**。

A. 消费者收入　B. 销售者预期　C. 产品价格　D. 生产成本　E. 消费者偏好

**答案：BCD**
**解析**：影响供给的主要因素有：产品价格、生产成本、生产技术、预期、相关产品的价格以及其他因素。**消费者偏好与消费者收入属于影响需求的因素**，选项 A、E 错误。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 认为「想买但买不起」也算需求 | 需求 = 愿意（欲望）＋能够（支付能力），**缺一不可** |
| 2 | 认为「还没到超市去买」就不是需求 | 需求不要求当下成交，只要**愿意＋能够**即可 |
| 3 | 把影响需求最关键的因素记成收入或偏好 | 最关键的是**产品自身价格**，且方向**相反** |
| 4 | 认为收入增加所有商品需求都增加 | **正常品正、低档品负**，看到收入先分档 |
| 5 | 分不清替代品与互补品的影响方向 | **替代品同向（正）、互补品反向（负）**；价格上涨，替代品需求增加、互补品需求减少 |
| 6 | 自身价格变化也说成「需求曲线平移」 | 自身价格 → **点的移动**；非自身价格（收入/偏好/相关品/预期）→ **线的平移** |
| 7 | 用生产成本变化判断需求曲线 | 生产成本影响的是**供给**曲线；需求曲线只看需求侧因素 |
| 8 | 以为价格弹性能让需求曲线位移 | 价格弹性**不影响**需求曲线位移 |
| 9 | 收入增加时把需求曲线画成左移 | 收入增加（正常品）→ 需求曲线向**右上方**移动 |
| 10 | 把「生产成本下降」选成需求曲线右移的原因 | 生产成本下降是**供给**曲线右移；需求曲线右移看收入、偏好 |
| 11 | 把最高限价与保护价格的「与均衡价关系」记反 | 最高限价**低于**均衡价；保护价格**高于**均衡价 |
| 12 | 把两种价格的后果记混 | 最高限价 → **短缺**（排队、黑市高价）；保护价格 → **过剩**（政府买单、财政负担） |
| 13 | 把解决手段张冠李戴 | 最高限价靠**配给制**；保护价格靠**收购和储备系统** |
| 14 | 认为最高限价需要政府建立收购储备系统 | 那是**保护价格**的配套，最高限价只需行政措施/分配措施 |
| 15 | 认为保护价格能刺激消费 | 保护价格**刺激生产、限制消费**，才导致过剩 |
| 16 | 认为保护价格就是最高限价 | 两者方向相反：一个在均衡价**之上**，一个在**之下** |
| 17 | 把生产周期、自然条件算成需求价格弹性的因素 | 它们属于**供给**价格弹性的因素；需求弹性看替代品、重要性、用途、时间 |
| 18 | 认为需求收入弹性大于 0 就是高档品 | 大于 0 只是**正常品**；**大于 1 才是高档品** |
| 19 | 把恩格尔定律归到需求价格弹性 | 恩格尔定律是**需求收入弹性**研究的结论 |
| 20 | 把弧弹性和端点弹性混用 | 两端点算出的弹性不同时，用**中点（弧弹性）**公式；题干给「弧弹性」必用中点 |
| 21 | 点弹性计算忘记「价格下降、销量上升」的方向 | 先算相对变化率，再按价格方向给销量**加/减**，价格降则销量增 |
