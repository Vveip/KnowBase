## 二、知识点精讲

### 考点1 公共物品及其特征 ★★★（第一节）

**核心概念**：
- **公共物品**：增加一个人对该物品的消费，并不同时减少其他人对该物品消费的那类物品。如国防、航海中的灯塔等。
- **"纯公共物品"的两大特征**：消费上的非竞争性（主要特征）、消费上的非排他性（派生特征）。

| 特征 | 地位 | 含义 | 对供给的意义 |
|---|---|---|---|
| 消费上的非竞争性 | **主要特征** | 增加一个人消费的边际供给成本为零；一人消费不影响其他人消费，消费者之间没必要展开竞争或争夺 | 集体提供的潜在收益 |
| 消费上的非排他性 | 派生特征 | 任何消费者都不会被排除在外；某些公共物品技术上存在排他可能，但排他成本非常昂贵，以致在经济上不可行 | 市场提供的潜在困难 |

> 具有上述特点的例子：国防、道路、环境治理、电视广播等。

**逻辑链**：

```
公共物品：增加一人消费，不同时减少他人消费（国防、灯塔）
        ↓ 纯公共物品
非竞争性（主要）→ 边际供给成本为零 → 集体提供的潜在收益
非排他性（派生）→ 排他成本昂贵、经济上不可行 → 市场提供的潜在困难
        ↓ 真题结论（2024）
阻碍自愿融资的关键因素 = 非排他性
```

**速记口诀**：**竞争是主要、排他是派生；竞争看边际成本为零，排他看"撵人"成本太高。**

> 📌 素材未覆盖：私人物品对应的两大特征（竞争性、排他性）及"公共物品 vs 私人物品四个特征"的完整对比框架（"竞争性/排他性"仅作为 2024 年真题的干扰选项出现）。

### 考点2 公共物品的需求显示 ★★（第一节）

**核心概念**：

| 物品类型 | 需求显示方式 | 交易性质 |
|---|---|---|
| 私人物品 | 自愿的市场交易——用出价多少表示需求强度和需求数量 | 自愿 |
| 公共物品 | 具有强制性的政治交易（现实生活中通过政治机制） | 强制 |

> 关键结论：在商品和服务市场上，出价机制对私人物品有效，但同样的机制对公共物品并不完全有效。

**逻辑链**：

```
私人物品 → 自愿市场交易 → 出价高低 = 需求强度与需求数量
公共物品 → 出价机制不完全有效 → 政治机制（强制性政治交易）显示需求
```

**速记口诀**：**私人靠市场（自愿出价），公共靠政治（强制交易）。**

### 考点3 公共物品的融资和生产 ★★★（第一节）

**核心概念**：公共物品供给分两步——先**融资**（解决资金问题），再**生产**（决定通过何种方式完成公共物品的生产或公共服务的递送）。

**融资三方式**：

| 融资方式 | 性质 | 特点/缺点 |
|---|---|---|
| 政府融资 | 强制融资 | 难以满足社会成员对公共物品的多样化需求 |
| 私人融资 | 自愿融资 | 导致公共物品供给的数量不足和结构不平衡 |
| 联合融资 | — | 财政补贴和税收优惠，鼓励私人机构提供 |

**生产三方式**：

| 生产方式 | 要点 |
|---|---|
| 政府生产 | 传统生产方法（雇用公共雇员） |
| 合同外包 | 公共服务提供私有化的表现；支持者认为私人生产成本低，反对者认为私人生产降低了服务质量；私人签约者可能是营利性机构，也可能是非营利性机构 |
| 特许经营、合同委托 | 介于政府生产和合同外包之间；供给主体不仅限于政府和私人企业，还有社会组织、慈善机构、事业单位等；不同性质供给主体平等待遇、公平竞争 |

> **政府生产和合同外包是两种典型的生产方式。**

**逻辑链**：

```
融资三分：政府融资（强制）｜私人融资（自愿）｜联合融资（补贴+税收优惠）
生产三分：政府生产（传统）｜合同外包（私有化表现，签约者营利/非营利均可）
          ｜特许经营、合同委托（多元主体、平等待遇、公平竞争）
典型生产 = 政府生产 + 合同外包
```

**速记口诀**：**融资"政私联"，生产"政包特"；外包签约者营利非营利均可，供给主体不止政企。**

### 考点4 公共物品供给的制度结构 ★（第一节）

**核心概念**：理性的社会成员利用其智慧，通过规则的创新，以获取来自公共物品交易的共同利益，并公正地分享收益和分担成本。制度结构涉及四个方面内容：

| 序号 | 内容 | 地位 |
|---|---|---|
| 1 | 公共物品供给的决策制度 | **核心** |
| 2 | 公共物品供给的融资制度 | — |
| 3 | 公共物品供给的生产制度 | — |
| 4 | 公共物品的受益分配制度 | — |

**目标**：多元的、竞争的、均衡的、效率的。

**逻辑链**：

```
四内容：决策（核心）→ 融资 → 生产 → 受益分配
目标四词：多元、竞争、均衡、效率
```

**速记口诀**：**"决融生分"决策是核心，目标"多竞均效"。**

### 考点5 市场和市场效率 ★（第二节）

**核心概念**：
- 市场系统由**居民、企业和政府**三个相对独立的主体组成。
- 市场是交易的场所，是在无数个买方和卖方的相互作用下形成的商品交易机制，是**具有效率的商品交易机制**。
- 市场机制的基本规律是**供求规律**：供给大于需求，价格下降、库存增加、生产低迷；反之，价格上升、库存减少、生产增长。

| 主体 | 定位 |
|---|---|
| 政府 | 构成市场系统的一个主体 |
| 居民 | 社会的基本细胞，也是社会生活的基本单位 |
| 企业 | 商品生产和商品交换的基本单位；目标是利润最大化和扩大再生产 |

**逻辑链**：

```
市场系统 = 居民 + 企业 + 政府
供 > 需 → 价格下降、库存增加、生产低迷
供 < 需 → 价格上升、库存减少、生产增长
```

**速记口诀**：**三方主体"居民企政"，企业目标"利润+扩产"，供求规律"价库反向动"。**

---

### 考点6 政府的经济活动范围 ★★★（第二节）

**核心概念**：市场并不总是有效率的。为克服市场失灵、弥补市场机制的缺陷或不足，政府需要通过法律、行政和经济等手段进行干预，其经济活动范围主要集中在五个方面：

| 序号 | 范围 |
|---|---|
| 1 | 提供公共物品或服务 |
| 2 | 矫正外部性 |
| 3 | 维持有效竞争 |
| 4 | 调节收入分配 |
| 5 | 稳定经济 |

**逻辑链**：

```
市场并不总是有效率 → 政府干预（法律、行政、经济手段）
五条：公共物品/服务 → 矫正外部性 → 维持有效竞争 → 调节收入分配 → 稳定经济
两个"不包括"：保证绝对公平（2021 干扰项）、决定资源配置（2023补 干扰项）
```

**速记口诀**：**"外公维持收入稳定"**（外公 = 提供公共物品或服务）。

### 考点7 资源配置职能 ★★（第三节）

**核心概念**：在社会主义市场经济条件下，财政具有资源配置、收入分配、经济稳定和发展职能。
- **含义**：通过财政收支，引导社会资金流向，弥补市场缺陷，最终实现全社会资源配置效率的最优状态。
- **范围**：财政资源配置范围的大小**取决于政府职能范围的大小**；主要是市场失灵而又需要的公共物品和服务的领域。
- 市场经济条件下财政配置的范围包括：①满足政府执行职能的需要；②市场不能有效提供而社会又需要的**准公共物品和服务**的支出；③对社会资源配置的引导性支出。

**机制和手段（5 条）**：

| 序号 | 机制和手段 |
|---|---|
| 1 | 根据政府职能的动态变化确定社会公共需要的基本范围，确定财政收支占国内生产总值的合理比例，从总量上实现高效的社会资源配置 |
| 2 | 优化财政支出结构 |
| 3 | 为公共工程提供必要的资金保障 |
| 4 | 通过政府直接投资、财政贴息、税收优惠等方式，引导和调节社会投资方向，提高社会整体投资效率 |
| 5 | 通过部门预算制度、国库集中收付制度和绩效评价制度等体制、机制改革，提高财政自身管理和运营效率 |

**逻辑链**：

```
范围大小 ← 政府职能范围大小
范围三块：政府执行职能需要 + 准公共物品和服务支出 + 引导性支出
手段五条：总量比例 → 支出结构 → 公共工程 → 引导投资（直投/贴息/税收优惠）→ 自身效率（预算/国库/绩效）
```

**速记口诀**：**范围看政府职能；五手段"总量、结构、工程、投资、自身"。**

> 📌 素材未覆盖：纯公共物品与准公共物品的划分标准（素材仅在财政配置范围中提及"准公共物品和服务"）。

### 考点8 收入分配职能 ★★★（第三节）

**核心概念**：
- **目标**：实现公平分配。
- **性质**：政府运用财政手段调整国民收入**初次分配**结果的职能（不是二次分配）。
- **初次分配条件**：市场经济条件下，初次分配是按**要素所有者的禀赋条件和公平的市场定价**实现的。

**机制和手段（4 条）**：

| 序号 | 机制和手段 | 具体内容 |
|---|---|---|
| 1 | 明确市场和政府对社会收入分配的范围和界限 | 根据市场和政府的职责分工 |
| 2 | 加强税收调节 | 企业所得税、个人所得税、遗产税、资源税等；资源税调节资源形成的级差收入 |
| 3 | 发挥财政转移支付作用 | 增加对经济发展相对较慢地区的转移性支出，增加社会保障、收入保障、教育和健康等转移性支出 |
| 4 | 发挥公共支出的作用 | 如增加社会保障支出、提供社会福利 |

**逻辑链**：

```
目标：公平分配（不是效率最大化）
初次分配 = 禀赋条件 + 公平的市场定价
手段四条：划界限 → 税收调 → 转移支付 → 公共支出
```

**速记口诀**：**"界税收支"四手段；调初次分配、目标为公平。**

---

### 考点9 经济稳定和发展职能 ★★（第三节）

**核心概念**：财政经济稳定职能主要包括**充分就业、稳定物价、国际收支平衡、经济增长**四大目标。

**机制和手段（4 条）**：

| 序号 | 机制和手段 |
|---|---|
| 1 | 通过财政政策和货币政策的协调配合，推动社会总供求的基本平衡，保证物价和经济发展的稳定，实现充分就业和国际收支平衡 |
| 2 | 通过税收、财政补贴、财政贴息、公债等，调节社会投资需求水平，影响就业水平，使经济保持一定的增长；通过财政直接投资，调节社会经济结构，调节社会有效供给能力 |
| 3 | 通过税收等调节个人消费水平和结构 |
| 4 | 财政加大对节约资源、能源和环境保护的投入，加大对科技、文化、卫生、教育事业的投入，完善社会保障制度等，实现经济和社会的协调健康发展 |

**逻辑链**：

```
四大目标：充分就业、稳定物价、国际收支平衡、经济增长
手段：财政+货币政策协调 → 社会总供求基本平衡
      税收/补贴/贴息/公债 → 调节社会投资需求水平、影响就业
      财政直接投资 → 调节社会经济结构、调节社会有效供给能力
      税收 → 调节个人消费水平和结构
      加大资源能源环保、科教研卫投入，完善社保 → 协调健康发展
```

**速记口诀**：**目标"就业、物价、外汇、增长"；手段"政策协调、投资需求、消费结构、协调投入"。**

| 资源配置 | 优化财政支出结构；为公共工程提供资金保障；政府直接投资、财政贴息、税收优惠引导投资方向；部门预算、国库集中收付、绩效评价 |

## 四、关键机制与适用条件

> 本章无计算类公式，以下为必须理解的机制链条。

**机制 1：公共物品为什么需要政府介入**

```
非排他性（派生特征）→ 排他成本昂贵、经济上不可行
      → 对自愿融资起阻碍作用（2024 真题结论）
      → 市场提供存在潜在困难 → 需要集体提供/政府融资介入
```

**机制 2：融资方式的适用条件**

```
政府融资（强制融资）：难以满足社会成员多样化需求
私人融资（自愿融资）：受非排他性阻碍 → 数量不足、结构不平衡
联合融资：财政补贴 + 税收优惠 → 鼓励私人机构提供
```

**机制 3：生产方式的适用条件**

```
政府生产：传统方法，雇用公共雇员
合同外包：与私人厂商签约；公共服务提供私有化的表现
          支持者认为私人生产成本低，反对者认为降低了服务质量
特许经营、合同委托：介于两者之间；多元主体平等待遇、公平竞争
典型生产方式 = 政府生产 + 合同外包
```

**机制 4：初次分配的界定**

```
市场经济条件下，初次分配按要素所有者的禀赋条件和公平的市场定价实现（2020）
收入分配职能 = 政府运用财政手段调整初次分配结果，目标为公平分配
```

## 五、高频考点速记卡

1. **Q：公共物品的定义？**　A：增加一个人对该物品的消费，并不同时减少其他人对该物品消费的那类物品。如国防、航海中的灯塔等。
2. **Q：纯公共物品两大特征及各自地位？**　A：消费上的非竞争性（主要特征，边际供给成本为零）；消费上的非排他性（派生特征，市场提供的潜在困难）。
3. **Q：对自愿融资起阻碍作用的关键因素？**　A：非排他性。
4. **Q：私人物品与公共物品的需求显示方式？**　A：私人物品靠自愿的市场交易；公共物品靠具有强制性的政治交易（政治机制）。
5. **Q：融资三方式及各自缺点？**　A：政府融资（强制）——难以满足多样化需求；私人融资（自愿）——数量不足、结构不平衡；联合融资——财政补贴和税收优惠鼓励私人提供。
6. **Q：生产三方式？哪两种是典型？**　A：政府生产、合同外包、特许经营/合同委托；政府生产和合同外包是两种典型生产方式。
7. **Q：合同外包中的私人签约者一定是营利性机构吗？**　A：不一定，也可能是非营利性机构。
8. **Q：公共物品供给制度结构的核心？**　A：公共物品供给的决策制度。
9. **Q：制度结构的目标？**　A：多元的、竞争的、均衡的、效率的。
10. **Q：市场系统由哪三个主体组成？企业的目标？**　A：居民、企业和政府；企业的目标是利润最大化和扩大再生产。
11. **Q：市场机制的基本规律？**　A：供求规律。供给大于需求，价格下降、库存增加、生产低迷；反之相反。
12. **Q：政府经济活动范围五条？**　A：提供公共物品或服务、矫正外部性、维持有效竞争、调节收入分配、稳定经济。
13. **Q：财政的三大职能？**　A：资源配置、收入分配、经济稳定和发展。
14. **Q：财政资源配置职能范围的大小取决于什么？**　A：取决于政府职能范围的大小。
15. **Q：收入分配职能的目标？调整初次还是再分配？**　A：实现公平分配；调整国民收入初次分配结果。
16. **Q：市场经济条件下初次分配的实现条件？**　A：按要素所有者的禀赋条件和公平的市场定价。
17. **Q：收入分配职能的机制和手段四条？**　A：明确市场和政府分配范围界限、加强税收调节、发挥财政转移支付作用、发挥公共支出作用。
18. **Q：财政经济稳定职能的四大目标？**　A：充分就业、稳定物价、国际收支平衡、经济增长。

## 六、典型真题（含解析）

### （一）带年份真题 14 道

**1.【2021·单选】** 某种公共物品一旦被提供，增加一个人消费的边际供给成本为零，这说明该公共物品具有（ ）的特征。
A. 非排他性　B. 经济性　C. 公平性　D. 非竞争性
**答案：D**
**解析**：非竞争性指消费者对某一种公共物品的消费并不影响其他人对该公共物品的消费；公共物品可以被许多人同时消费，对某一人的供给并不会减少对其他人的供给，如国防、道路、环境治理、电视广播等。非排他性指公共物品可以由任何消费者进行消费，任何一个消费者都不会被排除在外；某些公共物品虽存在技术上排他的可能，但排他成本非常昂贵，以致在经济上不可行。

**2.【2021·多选】** 市场并不总是有效率的，政府经济活动范围主要集中在（ ）。
A. 保证绝对公平　B. 调节收入分配　C. 维持有效竞争　D. 矫正外部性　E. 提供公共产品和服务
**答案：BCDE**
**解析**：政府经济活动范围主要集中在：①提供公共物品或服务；②矫正外部性；③维持有效竞争；④调节收入分配；⑤稳定经济。不含"保证绝对公平"。

**3.【2022·单选】** 在社会主义市场经济条件下，财政不具备的职能是（ ）。
A. 经济稳定和发展职能　B. 确定要素价格职能　C. 资源配置职能　D. 收入分配职能
**答案：B**
**解析**：社会主义市场经济条件下，财政具有资源配置、收入分配、经济稳定和发展职能，不具备确定要素价格职能。

**4.【2022·多选】** 公共物品生产方式有（ ）。
A. 合同委托　B. 特许经营　C. 联合融资　D. 合同外包　E. 政府生产
**答案：ABDE**
**解析**：当公共物品供给所需的资金问题已经解决，社会成员还需决定通过何种方式完成公共物品的生产或公共服务的递送。其中，政府生产和合同外包是两种典型的生产方式，其他介于政府生产和合同外包之间的公共物品供给方式还包括特许经营、合同委托等。服务供给主体也不仅限于政府和私人企业，还包括社会组织、慈善机构、事业单位等；不同性质的供给主体应享有平等待遇，以促进其公平竞争，提高公共物品供给的数量与质量。联合融资属于融资方式，不是生产方式。

**5.【2022·单选】** 关于财政收入分配职能的说法，正确的是（ ）。
A. 财政收入分配职能是指社会运用市场手段调整国民收入二次分配结果的职能
B. 财政收入分配职能是指政府运用财政手段调整国民收入二次分配结果的职能
C. 财政收入分配职能旨在实现效率最大化的目标
D. 财政收入分配职能旨在实现公平收入分配的目标
**答案：D**
**解析**：财政收入分配职能是指政府运用财政手段调整国民收入初次分配结果的职能，旨在实现公平收入分配的目标。选项 ABC 说法错误。

**6.【2023补·多选】** 关于公共物品生产的说法，正确的是（ ）。
A. 合同委托属于公共物品生产的方式
B. 根据公共物品供给单位的不同需要对社会组织、慈善机构、事业单位进行区别对待
C. 在合同外包中，生产公共物品的私人签约者一定是营利性机构
D. 特许经营属于公共物品生产的方式
E. 政府提供公共物品的成本最低
**答案：AD**
**解析**：公共物品的生产包括：①政府生产，雇用公共雇员；②合同外包，与私人厂商签约，是公共服务提供私有化的表现；③特许经营、合同委托，主体为政府、私人企业、社会组织、慈善机构、事业单位等。其中，政府生产和合同外包是两种典型的公共物品生产方式。不同性质供给主体应平等待遇而非区别对待；合同外包的私人签约者不一定是营利性机构。

**7.【2023补·单选】** 为了克服市场失灵，弥补市场机制的缺陷或不足，政府需要通过法律、行政和经济等手段进行干预，其经济活动范围不包括（ ）。
A. 提供公共物品和服务　B. 决定资源配置　C. 矫正外部性　D. 稳定经济
**答案：B**
**解析**：政府经济活动范围包括：提供公共物品和服务、矫正外部性、维持有效竞争、调节收入分配、稳定经济。不包括"决定资源配置"。

**8.【2023补·多选】** 财政实现收入分配职能的机制和手段主要有（ ）。
A. 根据市场和政府的职责分工，明确市场和政府对社会收入分配的范围和界限
B. 加强税收调节
C. 通过税收、财政补贴、财政贴息、公债等，调节社会投资需求水平
D. 发挥财政转移支付作用
E. 发挥公共支出的作用
**答案：ABDE**
**解析**：财政实现收入分配职能的机制和手段：①根据市场和政府的职责分工，明确市场和政府对社会收入分配的范围和界限；②加强税收调节；③发挥财政转移支付作用，如增加对经济发展相对较慢地区的转移性支出，增加社会保障、收入保障、教育和健康等转移性支出；④发挥公共支出的作用。C 项属于经济稳定和发展职能的手段。

**9.【2020·单选】** 市场经济条件下进行初次分配时，其实现的条件是按（ ）。
A. 禀赋条件和公平的市场定价　B. 垄断情况和公平的市场定价
C. 禀赋条件和公平的政府定价　D. 垄断情况和公平的政府定价
**答案：A**
**解析**：在市场经济条件下，初次分配是按要素所有者的禀赋条件和公平的市场定价实现的。

**10.【2020·多选】** 现代市场经济中，财政实现收入分配职能的手段主要有（ ）。
A. 没收财产并重新分配　B. 增加社会保障支出　C. 提供社会福利　D. 加强税收调节　E. 增加经济建设支出

**解析**：财政实现收入分配职能的机制和手段：①根据市场和政府的职责分工，明确市场和政府对社会收入分配的范围和界限；②加强税收调节，通过税收进行的收入再分配活动是在全社会范围内进行的收入的直接调节，具有一定的强制性；③发挥财政转移支付作用，将资金直接补贴给地区和个人，有明确的收益对象、收益范围和政策选择性，对改变社会分配不公的程度具有重要作用；④发挥公共支出的作用。

**11.【2019·单选】** 关于政府融资和私人融资的说法，正确的是（ ）。

**解析**：财政配置社会资源的机制和手段：①根据政府职能的动态变化确定社会公共需要的基本范围，确定财政收支占国内生产总值的合理比例，从总量上实现高效的社会资源配置；②优化财政支出结构；③为公共工程提供必要的资金保障；④通过政府直接投资、财政贴息、税收优惠等方式，引导和调节社会投资方向；⑤通过部门预算制度、国库集中收付制度和绩效评价制度等体制改革，提高财政自身管理和运营效率。

**6.【单选】** 收入分配职能的目标是（ ）。
A. 实现按劳分配　B. 完善收入体制　C. 实现共同富裕　D. 实现公平分配
**答案：D**　解析：实现公平分配是收入分配职能的目标。

**7.【多选】** 下列实现公共财政职能的手段中，属于实现收入分配职能的手段有（ ）。
A. 征收企业所得税　B. 征收遗产税　C. 开征资源税调节自然资源形成的级差收入　D. 征收个人所得税　E. 优化财政支出结构
**答案：ABCD**　解析：优化财政支出结构属于资源配置职能。

**8.【多选】** 财政经济稳定职能主要包括（ ）。
A. 扩大社会总需求　B. 扩大社会总供给　C. 实现充分就业　D. 稳定物价水平　E. 国际收支平衡
**答案：CDE**　解析：财政经济稳定职能包括实现充分就业、稳定物价水平和国际收支平衡、经济增长。

**9.【多选】** 公共财政的基本职能有（ ）。
A. 稳定价格　B. 配置资源　C. 分配收入　D. 稳定和发展经济　E. 平衡国际收支
**答案：BCD**　解析：公共财政的基本职能是资源配置、收入分配、经济稳定和发展。

**10.【单选】** 我国中央财政不断加大对中西部地区财政转移支付力度，逐步缩小地区间基本公共服务差距，这是公共财政履行（ ）职能的体现。
A. 经济发展　B. 经济稳定　C. 市场维护　D. 收入分配
**答案：D**　解析：本题考查公共财政的收入分配职能。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把非排他性当成公共物品的主要特征 | 非竞争性是主要特征，非排他性是派生特征 |
| 2 | 认为非竞争性阻碍自愿融资 | 阻碍自愿融资的关键因素是非排他性（2024） |
| 3 | 看到"边际供给成本为零"选非排他性 | 边际成本为零 = 非竞争性（2021） |
| 4 | 认为公共物品需求显示靠市场机制 | 靠具有强制性的政治交易；市场机制只显示私人物品需求 |
| 5 | 认为政府融资一定导致公共物品供给数量不足 | 数量不足是私人融资的缺点；政府融资缺点是难以满足多样化需求 |
| 6 | 多选把"联合融资"选进生产方式 | 联合融资属融资；生产方式只有政府生产、合同外包、特许经营/合同委托（2022） |
| 7 | 认为合同外包签约者一定是营利性机构 | 营利、非营利均可（2023补） |
| 8 | 认为制度结构核心是融资/生产/受益分配制度 | 核心是决策制度 |
| 9 | 认为政府经济活动范围包括"保证绝对公平" | 五条中没有"绝对公平"，只有调节收入分配（2021） |
| 10 | 认为政府经济活动范围包括"决定资源配置" | 不包括（2023补） |
| 11 | 认为财政资源配置范围取决于财政收入/支出多少 | 取决于政府职能范围的大小 |
| 12 | 把"降低个人所得税税率"选成资源配置手段 | 个税属收入分配职能的税收调节，资源配置五手段中没有 |
| 13 | 认为收入分配职能调整二次分配结果 | 调整初次分配结果（2022） |
| 14 | 认为初次分配按垄断情况或政府定价 | 按禀赋条件和公平的市场定价（2020） |
| 15 | 把优化财政支出结构归为收入分配手段 | 属资源配置职能 |
| 16 | 把"税收、财政补贴、财政贴息、公债调节投资需求"归为收入分配 | 属经济稳定和发展职能（2023补） |
| 17 | 把"增加经济建设支出"选成收入分配手段 | 收入分配靠社保、福利、转移支付等公共支出（2020） |
| 18 | 认为财政具备"确定要素价格"职能 | 财政只有三大职能（2022） |
| 19 | 把"稳定价格""平衡国际收支"当成财政基本职能 | 基本职能是资源配置、收入分配、经济稳定和发展；稳定物价、国际收支平衡是经济稳定职能的目标内容 |
| 20 | 混淆转移支付体现的职能 | 中央财政加大对中西部转移支付、缩小地区公共服务差距 = 收入分配职能 |
