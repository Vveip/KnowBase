## 二、知识点精讲

### 考点1 货币需求与货币需求量 ★

**核心概念**：

| 概念 | 内容 |
|---|---|
| 货币需求 | 经济主体在既定的收入和财富范围内**能够并愿意**持有货币的数量。货币需求是**有效需求、经济需求、派生需求** |
| 货币需求量 | 一定时期内经济对货币的**客观需求量** |
| 货币职能 | 货币是固定充当一般等价物的特殊商品，具有价值尺度、流通手段、支付手段、贮藏手段等职能 |

**逻辑链**：

```
收入与财富范围（既定约束）
        ↓ 能够并愿意
货币需求（有效需求 / 经济需求 / 派生需求）
        ↓ 客观化
货币需求量（一定时期内经济的客观需要）
```

**速记口诀**：**"能且愿，有效派生经济求"**——货币需求是"能够并愿意"持有的数量，三重属性：有效、经济、派生。

---

### 考点2 传统货币数量说 ★★★★★

传统货币数量说包括**费雪方程式**与**剑桥方程式**，二者结论方向一致、侧重不同。

| 维度 | 费雪方程式 | 剑桥方程式 |
|---|---|---|
| 公式 | **MV＝PT** | **π＝k×Y / M**（可变形为 M＝kY/π） |
| 别称 | 交易方程式 | 现金余额方程 |
| 核心结论 | **货币量决定物价（正比）** | 强调**贮藏货币**；货币量与**货币价值成反比** |
| 稳定因素 | V（货币流通速度）和 T（交易量/产出量） | K（以现金形式持有货币的比重） |
| 变量含义 | M 货币量（最活跃）、P 物价、V 货币流通速度、T 商品和劳务的交易量 | K 以现金形式持有货币比重、π 代表货币价值、Y 总收入 |

**逻辑链（费雪方程式的传导机制，必考）**：

```
MV = PT
  ↓ M↑（V、T 短期稳定，V 由制度因素决定，可视为常数；
  ↓      T 取决于资本、劳动、自然资源供给与生产技术水平等非货币因素）
只有 P（物价）与 M 有直接关系 → 货币量决定物价水平
```

**速记口诀**：**"费雪交易定物价，剑桥余额藏货币"**——费雪强调交易，货币量与物价正相关；剑桥强调贮藏（现金余额），货币量与货币价值反相关。

> 说明：剑桥方程式的图形化推导、剑桥学派完整传承脉络，**素材未覆盖**。

### 考点3 凯恩斯的货币需求理论——流动性偏好论 ★★★★★

**核心概念**：凯恩斯认为货币需求由**三类动机**决定，其需求函数建立在**未来的不确定性**和**收入是短期资产**两个假设条件之上，采用了大量的**心理分析法**。

| 动机 | 对应需求 | 函数 | 决定因素 |
|---|---|---|---|
| 交易动机 | 交易性需求 | **L1＝L1（Y）** | 与收入**正相关** |
| 预防动机 | 预防性需求 | L1＝L1（Y） | 与收入**正相关** |
| 投机动机 | 投机性需求 | **L2＝L2（i）** | 由**利率高低**决定，与利率**负相关** |

**总需求函数（必须掌握）**：

```
L = L1(Y) + L2(i)
       ↑          ↑
   与收入正相关   与利率负相关（由利率高低决定）
```

**流动性陷阱（高频陷阱）**：

```
 利率 i
  │
  │╲
  │  ╲
  │    ╲
  │      ╲
  │        ╲____________ ← 流动性陷阱：利率降到 i₀ 这一低点时，
  │        货币需求无限增大，无人愿意持有债券，都愿意持有货币
  └──────────────────── 货币需求 L
```

> 讲义此处以图呈现（本图据文字描述还原）：当利率降到某一低点时，货币需求就会无限增大；由于利率过低，"流动性偏好"就具有**绝对性**，产生"流动性陷阱"。

**速记口诀**：**"三动机、两假设、投机看利率、陷阱讲绝对"**——交易与预防看收入（正相关），投机看利率（负相关）；流动性陷阱中流动性偏好具有**绝对性**（不是相对性）。

### 考点4 弗里德曼的现代货币数量说 ★★★★★

**核心概念**：弗里德曼的现代货币数量说是**关于货币需求的理论**。它接受了剑桥学派观点，认为人们持有货币的原因既在于交换、又在于货币也是财富；货币数量说是**货币需求理论，不是产出、货币或者物价水平的理论**。

**货币需求函数（必须掌握）**：

```
M/P = f（Yp；W；rm，rb，re；1/p · dp/dt；μ）

M：名义货币量            P：物价水平
Yp：恒久性收入           W：非人力财富占总财富的构成
rm，rb，re：存款、债券、股票的预期名义收益率
1/p · dp/dt：物价水平的预期变动率        μ：随机因素的影响总和
```

**影响持有实际货币量的因素（四个＋其他）**：

| 因素 | 与货币需求的关系 |
|---|---|
| ① 财富总额（恒久性收入） | 恒久性收入越高，所需货币越多（**正比**） |
| ② 财富构成（人力财富与非人力财富） | 人力财富比例越高，所需准备货币就越多（**正比**） |
| ③ 金融资产的预期收益率 | 其他金融资产收益率越高，持有货币机会成本越大，持有货币数量就越少（**反比**） |
| ④ 物价通胀 | 物价上涨、通货膨胀，持有货币意味着损失，人们减少持有货币（**反比**） |
| 其他因素 | 不属上述因素、又能影响货币需求的各种随机因素 |

**速记口诀**：**"恒久收入正向走，人力财富越多留；收益率高通胀高，持币成本往上浮"**——恒久性收入、人力财富比例与货币需求正相关；金融资产收益率、物价通胀与货币需求负相关。

### 考点5 货币供给和货币供应量 ★★

**核心概念**：货币供给主体即**一国货币区的银行系统**向经济主体供给货币以满足其货币需求的过程；货币供应量就是**流通中的货币数量**。货币供给层次划分的基本原则：一般依据资产的**流动性**。

**我国货币供应量三个层次**：

| 层次 | 构成 | 定位 |
|---|---|---|
| **M0** | 流通中的货币（企事业单位、个人、机关团体、非存款类金融机构持有的硬币和现钞总和） | 最窄口径 |
| **M1** | M0＋单位活期存款＋个人活期存款＋非银行支付机构客户备付金 | 流动性强，我国的**狭义货币供应量**，央行重点调控对象 |
| **M2** | M1＋单位定期存款＋个人定期存款＋其他存款（**财政存款除外**） | **广义货币量**，研究宏观经济调控的变量；其中单位定期存款＋个人定期存款＋其他存款属于**准货币**，流动性弱 |

```
M0 ──(＋单位/个人活期存款＋非银行支付机构客户备付金)──▶ M1（狭义，央行重点调控）
M1 ──(＋单位/个人定期存款＋其他存款，财政存款除外)──▶ M2（广义，宏观调控变量）
                                                            └▶ 定期类＋其他存款 = 准货币
```

**社会融资规模**：指一定时期内（每月、每季度、每年）**实体经济（非金融企业和住户）从金融体系得到的资金总额**。

| 部分 | 内容 |
|---|---|
| ① 表内业务 | 人民币贷款和外币贷款 |
| ② 表外业务 | 委托贷款、信托贷款和未贴现的银行承兑汇票 |
| ③ 直接融资 | 非金融企业境内股票筹资和企业债券融资 |
| ④ 其他方式 | 保险公司赔偿、投资性房地产、小额贷款公司和贷款公司贷款 |
| ⑤ 政府部门债券市场融资 | 国债、地方政府专项债券和地方政府一般债券 |

> 版本冲突提示：本节知识讲解列**五部分**（含政府部门债券市场融资）；而 2021 年真题解析中表述为**四个部分**（未含政府部门债券市场融资）。两者并列保留，做题时以真题年份口径为准。

**速记口诀**：**"M0 现、M1 活、M2 定期准货币；社融五块：表内、表外、直接、其他、政府"**。

### 考点6 货币供给机制 ★★★

**核心概念**：货币供应量包括**现金和存款**两个部分——现金是**中央银行的负债**，存款是**商业银行的负债**。

| 机制 | 要点 |
|---|---|
| ① 中央银行的信用创造货币机制 | 中央银行只能利用自身掌握的**货币发行权和信贷管理权**来创造信贷资金来源。信用创造货币是当代不兑现信用货币制度下货币供给机制的重要内容，且信用创造货币的功能**为中央银行所掌握** |
| ② 商业银行的扩张信用、创造派生存款机制 | 商业银行**不具备**信用创造货币的功能，却具备在中央银行发行货币的基础上**扩张信用、创造派生存款**的能力 |

**商业银行创造派生存款的三类制约因素**：

```
① 缴存中央银行存款准备金
② 公众提取现金数量
③ 企事业单位及社会公众缴付税款等限制
```

**基础货币与货币乘数**：

| 概念 | 内容 |
|---|---|
| **基础货币 B** | 包括**现金**和**商业银行在中央银行的存款**；B＝中央银行发行的货币＋商业银行在中央银行的存款 |
| **货币乘数 k** | 基础货币的扩张倍数，取决于**存款准备金率**以及需要转化为现金及财政存款等所占比重的货币结构比率 |
| **货币供应量公式** | **M＝B×k** |

**速记口诀**：**"央行创货币、商业银行派生；B 是现金加准备金，M＝B 乘 k"**。

> 说明：货币乘数的具体分解公式（如存款准备金率、现金漏损率、财政存款比率的代数推导式），**素材未覆盖**，素材仅给出 M＝B×k 的总体关系与定性决定因素。

### 考点7 数字人民币 ★★★★★

**数字货币的产生背景**：货币起源于人类商品交换过程，先后经历了实物货币、金属货币、纸币和电子货币等形态。2008 年国际金融危机之后，一种尝试脱离中央银行货币发行机制的新货币——**数字货币**开始出现；2009 年，世界上第一个加密数字货币**比特币**正式诞生。

| 分类 | 含义 |
|---|---|
| **法定数字货币** | 中央银行发行的数字货币 |
| **私人数字货币** | 私人部门发行的以数字加密技术和分布式账本技术为基础的加密数字货币 |

**数字货币的四大特点**：① 匿名性；② 安全性；③ 可编程性；④ 高效率性。

**数字人民币的发展**：2026 年 1 月 1 日起，新一代数字人民币**计量框架、管理体系、运营机制和生态体系**正式启动实施，明确数字人民币具有**商业银行负债属性**；数字人民币钱包余额按照流动性分别计入相应的**货币层次**。

**数字人民币采用"中央银行—商业机构"的双层运营体系**，设计具有以下特征：
① 兼具账户和价值特征；② 实名数字人民币钱包余额可计付利息；③ 低成本；④ 支付即结算；⑤ 匿名性，遵循"**小额匿名、大额依法可溯**"的原则；⑥ 安全性；⑦ 可编程性。

**速记口诀**：**"两发行（法定/私人）四特点，双层运营七特征；小额匿名大额溯，商业银行负债属性"**。

### 考点8 货币均衡与失衡 ★★（素材另处标 ★★★★★，两星级并列）

**货币均衡的含义**：即货币供求均衡，是指在一定时期经济运行中的货币需求与货币供给在**动态上保持一致**的状态。

**货币均衡的三个特征**：

```
① 货币供给与货币需求的"大体一致"，而非数量上的完全相等
② 货币均衡是一个动态过程（短期可能不一致，长期大体一致）
③ 现代经济中的货币均衡在一定程度上反映了经济总体均衡状况
```

**货币失衡**：

| 类型 | 要点 |
|---|---|
| **总量性货币失衡** | 两种情况：货币供给量**小于**货币需求量；货币供应量**大于**货币需求量。造成货币供应量大于货币需求量的原因：财政赤字、扩张性货币政策等 |
| **结构性货币失衡** | 主要发生在**发展中国家**，原因在于**社会经济结构的不合理**；必须通过**经济结构调整**加以解决 |

**关键结论**：中央银行在宏观调控时**更多地注意总量性失衡**。

**速记口诀**：**"均衡三条：大体一致、动态过程、反映总体；失衡两类：总量看大小、结构调经济"**。

> 说明：货币均衡的具体判断标志（如通过物价、利率、国际收支等指标观测均衡状况）及货币均衡与社会总供求均衡的关系图，**素材未覆盖**。

### 考点9 通货膨胀的含义 ★★

**核心概念**：

| 定义来源 | 内容 |
|---|---|
| **萨缪尔森**《经济学》 | "在一定时期内，商品和生产要素价格总水平**持续不断地上涨**" |
| **马克思主义货币理论** | 同纸币的流通及其规律联系在一起，即在纸币流通条件下，由于纸币的**过度发行**而引起的纸币**贬值、物价上涨**的现象 |

**性质**：通货膨胀是**价值符号流通条件下的特有现象**。

**各种定义的共同点**：一是**有效需求大于有效供给**；二是**物价持续上涨**。**物价上涨是通货膨胀的基本标志**。

**速记口诀**：**"萨缪尔森价格持续涨，共同点：求大于供、物价涨；物价上涨是基本标志"**。

### 考点10 通货膨胀的类型 ★★★

| 划分标准 | 类型 | 要点 |
|---|---|---|
| **按成因** | 需求拉上型 | 因社会总需求过度增长，超过社会总供给的增长幅度，导致商品和劳务供给不足、物价持续上涨。特点：**自发性、诱发性、支持性**；过多的货币追逐过少的商品 |
| | 成本推进型 | 工会推动的"**工资推进型**通货膨胀"；垄断企业推动的"**利润推进型**通货膨胀" |
| | 输入型 | 是一种**国际传导现象** |
| | 结构型 | 经济结构因素变动影响总供给和总需求的均衡状态 |
| **按表现形式** | 公开型（开放性） | 货币数量变动导致的物价上涨是主要标志 |
| | 抑制型（隐蔽性） | 表现为人们普遍**持币待购**而使**货币流通速度减慢** |

**速记口诀**：**"成因四：需求拉上、成本推进、输入、结构；表现两：公开看物价、抑制看持币"**。

> 说明：通货膨胀的度量指标（CPI、PPI、GDP 平减指数与通货膨胀率计算）及通货紧缩，**素材未覆盖**。

---

### 考点11 通货膨胀的原因 ★

| 层次 | 内容 |
|---|---|
| **直接原因** | 过度的**信贷供给**，包括过度的现金发放和过度的信用供给 |
| **主要原因** | ① 财政原因（赤字政策、赤字）；② 信贷原因——**信用膨胀** |
| **其他原因** | 投资规模过大，国民经济结构比例失调，国际收支长期顺差等 |

**速记口诀**：**"直接过度信贷，主要财政加信用，其他投资结构顺差"**。

### 考点12 通货膨胀的治理 ★★★★★

**两类政策工具**：

| 政策 | 具体措施 |
|---|---|
| **① 紧缩的需求政策** | **紧缩性财政政策**：① 减少政府支出（削减购买性支出和转移性支出）；② 增加税收；③ 发行公债<br>**紧缩性货币政策**：① 提高法定存款准备金率；② 提高再贴现率；③ 公开市场业务（**卖出证券**） |
| **② 积极的供给政策** | **减税**、削减社会福利开支、**适当增加货币供给发展生产**和精简规章制度等（供给学派） |

**逻辑链**：

```
经济过热、出现通货膨胀
   ├─▶ 紧缩的需求政策 ──┬─▶ 紧缩性财政：减支出 / 增税收 / 发公债
   │                    └─▶ 紧缩性货币：提存准率 / 提再贴现率 / 公开市场卖出证券
   └─▶ 积极的供给政策（供给学派）：减税 / 削福利 / 适当增货币发展生产 / 精简规章
```

**速记口诀**：**"需求两手紧（财政三招：减支增税发公债；货币三招：提准提贴卖证券），供给学派四招：减税、削福利、增货币、简规章"**。

## 四、公式与计算（本章计算题重点）

> 本章真题以概念辨析为主，计算题集中在下述五个公式。以下例题为**按素材公式自编的演算示例**（非真题、非素材原文，数字仅用于演示代入方法），帮助熟悉公式运用。

### 4.1 货币供给层次划分（M0/M1/M2）

```
M0 = 流通中现金
M1 = M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金
M2 = M1 + 单位定期存款 + 个人定期存款 + 其他存款（财政存款除外）
```

**例题**：假设某期流通中现金 5 万亿元，单位活期存款 20 万亿元，个人活期存款 8 万亿元，非银行支付机构客户备付金 1 万亿元，单位定期存款 15 万亿元，个人定期存款 10 万亿元，其他存款（财政存款除外）4 万亿元。求 M1、M2。

**演算**：
```
M1 = 5 + 20 + 8 + 1 = 34（万亿元）
M2 = M1 + 15 + 10 + 4 = 34 + 29 = 63（万亿元）
准货币 = 15 + 10 + 4 = 29（万亿元）
```
**结论**：M1＝34 万亿元，M2＝63 万亿元；定期类与其他存款构成准货币 29 万亿元。

### 4.2 基础货币与货币乘数关系（M＝B×k）

```
B = 中央银行发行的货币 + 商业银行在中央银行的存款
M = B × k
```

**例题**：设基础货币 B＝30 万亿元，货币乘数 k＝4；后因存款准备金率提高，k 降为 3.5。求货币供应量变化。

**演算**：
```
M₁ = 30 × 4   = 120（万亿元）
M₂ = 30 × 3.5 = 105（万亿元）
ΔM = 105 - 120 = -15（万亿元）
```
**结论**：基础货币不变时，货币乘数由 4 降为 3.5，货币供应量由 120 万亿元减至 105 万亿元，减少 15 万亿元——体现"货币乘数取决于存款准备金率等货币结构比率"。

### 4.3 费雪方程式（MV＝PT）

**例题**：设 M＝100，V＝5，T＝200，求 P；若 M 增至 120、V 与 T 不变，再求 P。

**演算**：
```
P₁ = MV/T = 100×5/200 = 500/200 = 2.5
P₂ = 120×5/200 = 600/200 = 3.0
```
**结论**：V、T 短期稳定时，货币量由 100 增至 120（增 20%），物价由 2.5 升至 3.0（同比例上升 20%）——**货币量决定物价水平**。

### 4.4 剑桥方程式（π＝k×Y/M）

**例题**：设 Y＝1000，k＝0.2，M＝200，求货币价值 π；若 M 增至 250，再求 π。

**演算**：
```
π₁ = k×Y/M = 0.2×1000/200 = 200/200 = 1
π₂ = 0.2×1000/250 = 200/250 = 0.8
```
**结论**：货币量增加使货币价值由 1 降至 0.8——**货币量与货币价值成反比**。

### 4.5 凯恩斯流动性偏好（L＝L1（Y）＋L2（i））

> 素材给出函数形式 L1＝L1（Y）（与收入正相关）、L2＝L2（i）（与利率负相关），未给出具体参数；下列线性参数为演示自设。

**例题**：设 L1＝0.3Y，L2＝600－40i（i 为利率百分数），当 Y＝1000、i＝5 时求 L；若利率降至 i＝2，再求 L。

**演算**：
```
L1 = 0.3 × 1000 = 300
i = 5 时：L2 = 600 - 40×5 = 400    → L = 300 + 400 = 700
i = 2 时：L2 = 600 - 40×2 = 520    → L = 300 + 520 = 820
```
**结论**：收入不变时，利率由 5 降至 2，投机性需求由 400 增至 520，货币总需求由 700 增至 820——投机性需求与利率负相关；若利率继续降至"某一低点"，货币需求将无限增大（流动性陷阱）。

### 4.6 弗里德曼现代货币数量说（M/P＝f(...)）

**例题**：设名义货币需求 M＝400。① P＝2 时求实际货币需求；② 物价上涨至 P＝2.5、M 不变时再求；③ 若恒久性收入上升推动名义货币需求增至 M＝500、P＝2，求实际货币需求。

**演算**：
```
① M/P = 400/2   = 200
② M/P = 400/2.5 = 160
③ M/P = 500/2   = 250
```
**结论**：物价上涨（通货膨胀）时，同等名义货币对应的实际货币需求下降（200→160），印证"持有货币意味着损失，人们减少持有货币"；恒久性收入上升则实际货币需求增加（200→250），印证"恒久性收入越高，所需货币越多"。

## 五、高频考点速记卡

1. **Q：货币需求的三个属性？**
   A：**有效需求、经济需求、派生需求**——在既定收入和财富范围内能够并愿意持有货币的数量。

2. **Q：费雪方程式的形式与结论？**
   A：MV＝PT；V（货币流通速度）和 T（交易量）短期稳定，V 由制度因素决定、可视为常数，T 取决于资本、劳动、自然资源与生产技术水平等非货币因素，故**货币量决定物价水平**。

3. **Q：剑桥方程式的形式与结论？**
   A：π＝k×Y/M（现金余额方程），强调**贮藏货币**；货币量与货币价值成**反比**。

4. **Q：凯恩斯货币需求的三类动机及函数？**
   A：交易动机（交易性需求 L1＝L1（Y），与收入正相关）、预防动机（与收入正相关）、投机动机（投机性需求 L2＝L2（i），由利率高低决定、与利率负相关）；L＝L1（Y）＋L2（i）。

5. **Q：凯恩斯理论的两个假设和研究方法？**
   A：建立在**未来的不确定性**和**收入是短期资产**两个假设上，采用大量**心理分析法**。

6. **Q：什么是流动性陷阱？**
   A：当利率降到某一低点时，货币需求无限增大，无人愿意持有债券、都愿意持有货币，"流动性偏好"具有**绝对性**。

7. **Q：弗里德曼货币需求函数？**
   A：M/P＝f（Yp；W；rm，rb，re；1/p·dp/dt；μ）；是关于**货币需求**的理论，不是产出、货币或物价水平的理论。

8. **Q：弗里德曼理论中与货币需求成正比的因素？**
   A：**恒久性收入（Yp）**和**人力财富比例（W 中人力财富占比）**；金融资产收益率、物价通胀与货币需求成反比。

9. **Q：货币供给层次划分的依据？**
   A：资产的**流动性**。

10. **Q：M1 包括哪些？**
    A：M0＋单位活期存款＋个人活期存款＋非银行支付机构客户备付金；是我国的**狭义货币供应量**、央行重点调控对象。

11. **Q：M2 中的准货币指什么？**
    A：单位定期存款＋个人定期存款＋其他存款（**财政存款除外**），流动性弱。

12. **Q：现金与存款分别是谁的负债？**
    A：现金是**中央银行的负债**；存款是**商业银行的负债**。

13. **Q：信用创造货币与创造派生存款分别由谁完成？**
    A：中央银行利用**货币发行权和信贷管理权**创造货币；商业银行在央行发行货币基础上**扩张信用、创造派生存款**，但不具备信用创造货币功能。

14. **Q：制约商业银行创造派生存款的三类因素？**
    A：① 缴存中央银行存款准备金；② 公众提取现金数量；③ 企事业单位及社会公众缴付税款等。

15. **Q：基础货币与货币供应量公式？**
    A：B＝现金＋商业银行在中央银行的存款；**M＝B×k**（k 为货币乘数，取决于存款准备金率及货币结构比率）。

16. **Q：数字货币如何分类？数字人民币属于哪类？**
    A：按发行人分为**法定数字货币**（央行发行）与**私人数字货币**；数字人民币是**法定数字货币**，采用"中央银行—商业机构"双层运营体系，具有**商业银行负债属性**。

17. **Q：数字货币的四大特点？**
    A：匿名性、安全性、可编程性、高效率性。

18. **Q：货币均衡的三个特征？**
    A：① 是货币供求的**大体一致**而非数量完全相等；② 是一个**动态过程**；③ 在一定程度上反映**经济总体均衡状况**。

19. **Q：总量性货币失衡与结构性货币失衡的区别？**
    A：总量性失衡指货币供给量小于或大于货币需求量（供大于求常由财政赤字、扩张性货币政策造成），央行宏观调控**更关注总量性失衡**；结构性失衡主要发生在**发展中国家**，源于社会经济结构不合理，须通过**经济结构调整**解决。

20. **Q：治理通货膨胀的措施有哪些？**
    A：**紧缩的需求政策**（紧缩财政：减少政府支出、增加税收、发行公债；紧缩货币：提高法定存款准备金率、提高再贴现率、公开市场卖出证券）＋**积极的供给政策**（减税、削减社会福利开支、适当增加货币供给发展生产、精简规章制度）。

**【多选】（2019）经济学家凯恩斯提出的货币需求理论认为（　）。**

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把货币均衡理解成"货币供给与货币需求在数量上完全相等" | 是**大体一致**，非完全相等（2020 真题 D 选项即此陷阱） |
| 2 | 认为货币均衡是静态的、瞬间相等的 | 是**动态过程**：短期可能不一致，长期大体一致 |
| 3 | 认为现代经济中货币均衡不能反映总体均衡 | 恰恰相反，货币均衡在一定程度上**反映了经济总体均衡状况** |
| 4 | 把剑桥方程式结论记成"货币量与货币价值成正比" | 剑桥方程式 π＝kY/M，货币量与货币价值成**反比** |
| 5 | 以为费雪方程式中 T（交易量）由货币量决定 | T 取决于资本、劳动、自然资源供给与生产技术水平等**非货币因素**，V 由制度因素决定 |
| 6 | 把流动性陷阱中流动性偏好写成"相对性" | 是**绝对性**（经典改错题，D 选项陷阱） |
| 7 | 把弗里德曼理论说成"产出理论/物价理论" | 它是**货币需求理论**，接受剑桥学派观点，既在于交换也在于货币是财富 |
| 8 | 认为金融资产预期收益率越高，持币越多 | 收益率越高，持币**机会成本越大**，持币数量越少（反比） |
| 9 | 漏选人力财富比例与货币需求的关系 | 人力财富比例越高，所需准备的货币**越多**（正比） |
| 10 | 把财政存款算进 M2 | M2 的其他存款中**财政存款除外**（2025 真题 E 选项陷阱） |
| 11 | 把派生存款能力归给中央银行 | 中央银行**信用创造货币**；商业银行**创造派生存款**且不具备信用创造货币功能 |
| 12 | 以为制约派生存款的因素含"同业拆借" | 三类因素：缴存准备金、公众提取现金、缴付税款；**不含同业拆借** |
| 13 | 把基础货币等同于"商业银行在中央银行的存款" | 基础货币＝现金＋商业银行在中央银行的存款（B） |
| 14 | 把数字货币等同于数字人民币 | 数字人民币是**法定**数字货币；私人数字货币是私人部门发行的加密数字货币 |
| 15 | 认为数字人民币不具有可编程性 | 数字人民币七项特征中**包含可编程性** |
| 16 | 把抑制型通货膨胀理解成"物价公开上涨" | 抑制型（隐蔽性）表现为**持币待购、货币流通速度减慢**；公开型才是物价上涨为主要标志 |
| 17 | 把"减少货币发行量"当成紧缩性财政政策 | 属于**紧缩性货币政策**；财政政策是减支出、增税收、发公债 |
| 18 | 积极的供给政策误选"增加社会福利开支/增加税收" | 供给学派是**减税、削减社会福利开支**、适当增加货币供给发展生产 |
| 19 | 混淆总量性与结构性货币失衡的解决方式 | 总量性（供大于/小于求）央行更关注；结构性（短缺与滞留并存）须**经济结构调整**，主要发生在发展中国家 |
| 20 | 漏选社会融资规模中政府部门债券融资 | 五部分含国债、地方政府专项债券和地方政府一般债券；2021 年真题按当年四部分口径作答 |
