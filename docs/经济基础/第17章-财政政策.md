## 二、知识点精讲

### 考点1 财政政策的含义 ★★

**核心概念**：财政政策是一国政府为实现预期的经济社会发展目标，对**财政收支关系**进行调整的**指导原则和措施**，属于**宏观调控手段**。

**构成（素材表述一）**：预算政策、税收政策、支出政策、国债政策。

> 注意：本节"构成"讲四政策；第二节"工具"讲六项（预算、税收、公债、公共支出、政府投资、财政补贴）。两处是素材的不同表述，多选题问"工具"时按六项选（见第六节真题）。

**逻辑链**：

```
财政政策
 ├─ 主体：一国政府
 ├─ 目标：实现预期的经济社会发展目标
 ├─ 对象：调整财政收支关系
 ├─ 性质：指导原则和措施
 └─ 属性：宏观调控手段（不是法律手段、不是行政命令）
```

**速记口诀**：**"一国政府调收支，预算税收支出国，宏观调控一手段"**。

---

### 考点2 财政政策的功能 ★★

**核心概念**：财政政策的功能是财政政策起作用的方式和机制，共**四项**。

| 功能 | 作用机制 | 素材举例 |
|---|---|---|
| **导向功能** | 通过利益机制引导经济行为 | 政府为扩大投资，采用加速折旧、补贴、贴息、税收优惠，激励私人投资 |
| **协调功能** | 协调分配关系和失衡关系 | 财政转移支付、个人所得税；投资、支出、税收、预算相互协调 |
| **控制功能** | 通过调整经济行为实现调整社会行为 | 消费税控制资源浪费、引导消费方向 |
| **稳定功能** | 调整总需求和总供给的平衡 | —— |

**逻辑链**：

```
利益机制引导经济行为 ──→ 导向功能
协调分配/失衡关系   ──→ 协调功能
调整经济行为→调整社会行为 ─→ 控制功能
调整总需求与总供给平衡 ──→ 稳定功能
```

**速记口诀**：**"导、协、控、稳"**——导向引、协调衡、控制行、稳定供需；没有"管理功能"。

---

### 考点3 财政政策的目标 ★★★

**核心概念**：财政政策的目标即政府通过财政政策要实现的预期经济社会发展目标，共**四个**：

| 目标 | 关键词 |
|---|---|
| 促进充分就业 | 就业 |
| 物价基本稳定 | 物价 |
| 国际收支平衡 | 收支 |
| 经济稳定增长 | 增长 |

**逻辑链**：

```
财政政策目标 = 充分就业 ＋ 物价基本稳定 ＋ 国际收支平衡 ＋ 经济稳定增长
        ↓
与"四大功能"对应：功能是"怎么起作用"，目标是"要到达哪"
```

**速记口诀**：**"业、价、支、增"**（就业—物价—收支—增长），四个字背下四个目标。

---

### 考点4 财政政策的工具 ★★★★

**核心概念**：财政政策工具是财政政策主体所选择的用以达到政策目标的各种财政手段，共**六种**：**预算、税收、公债、公共支出、政府投资、财政补贴**。

**各工具要点**：

| 工具 | 要点 |
|---|---|
| **1. 预算政策** | **逆经济风向行事**；调节经济的作用主要表现在**财政收支的规模及其差额**上。总供给>总需求→赤字预算、增加支出、减少税收（扩张性）；总供给<总需求→盈余预算、减少支出、增加税收（紧缩性）；总供求基本平衡→中性财政政策 |
| **2. 税收政策** | ①保持经济稳定运行的重要手段：繁荣时增加税收、降低社会总需求，避免经济过热；萧条时减少税收、增加社会总需求，促进经济增长。②政府公平收入分配的重要手段 |
| **3. 公债政策** | ①调整公债的**流动性程度**，改变社会经济资源的流动状况，产生扩张性或紧缩性影响。**期限越短，流动性越高，变现能力越强；期限越长，流动性越低，变现能力越弱**。②调整国债发行利率水平，影响金融市场利率变化，产生扩张性或紧缩性影响 |
| **4. 公共支出政策** | ①狭义的购买性支出＝政府的消费性支出；②转移性支出＝财政资金**无偿、单方面**转移的支出，包括政府补助支出、捐赠支出和债务利息支出 |
| **5. 政府投资政策** | ①调整投资规模→影响社会总供求和未来社会总供给→影响供求总量；②调整投资方向→调节经济结构、促进资源合理配置和产业结构优化。过热时降低投资支出水平；萧条时提高投资支出水平；总供求基本平衡但结构有问题时**有保有压** |
| **6. 补贴政策** | ①保持经济稳定运行的重要手段之一：过热时减少财政补贴支出、抑制社会总需求；萧条时增加财政补贴支出、扩大社会总需求。②政府公平收入分配的重要手段 |

**逆周期操作一览表（素材原表，必背）**：

| 经济状况 | 政策类型 | 预算政策 | 税收政策 | 国债政策 | 公共支出政策 | 政府投资政策 | 补贴政策 |
|---|---|---|---|---|---|---|---|
| 总供给大于总需求（经济萧条） | 扩张性 | 赤字政策 | 减税 | √ | 增加 | 增加 | 增加 |
| 总供给小于总需求（经济过热） | 紧缩性 | 盈余政策 | 增税 | √（素材标注"挤出效应"） | 减少 | 减少 | 减少 |

> 说明：国债政策栏素材仅标注符号，紧缩性项下附"挤出效应"字样，具体展开素材未覆盖。

**逻辑链**：

```
经济过热（总供给 < 总需求）                经济萧条（总供给 > 总需求）
        │                                            │
   紧缩性财政政策                              扩张性财政政策
        │                                            │
盈余预算 / 增税 / 减少支出               赤字预算 / 减税 / 增加支出
        ↓                                            ↓
  抑制社会总需求                          扩大社会总需求
```

**速记口诀**：**"预、税、公、支、投、补"**六大工具；操作上"**萧条扩张加支减税，过热紧缩减支增税**"。

### 考点5 财政政策的类型 ★★★★★（本章最高频）

**核心概念**：财政政策有两种划分维度。

| 划分依据 | 类型 |
|---|---|
| 根据财政政策**调节经济周期的作用** | 自动稳定的财政政策、相机抉择的财政政策 |
| 根据财政政策在**调节国民经济总量和结构中的不同功能** | 扩张性财政政策、紧缩性财政政策、中性财政政策 |

#### （1）自动稳定的财政政策（自动稳定器）

财政制度本身存在一种**内在的、不需要政府采取其他干预行为**就可以随着经济社会的发展，**自动**调节经济运行的机制。主要表现在两个方面：

1. **累进所得税**（包括个人所得税和企业所得税）的自动稳定作用；
2. 政府**福利支出**的自动稳定作用。

#### （2）相机抉择的财政政策

政府根据一定时期的经济社会状况，**主动灵活地选择**不同类型的反经济周期的财政政策工具，干预经济运行，实现财政政策目标。分为两种：

| 类型 | 内容 | 特点 |
|---|---|---|
| **汲水政策** | 在经济萧条时，通过**公共投资**来启动社会需求，使经济恢复活力的方法 | 四个特点：①以市场经济所具有的自发机制为前提，是一种**诱导经济复苏**的政策；②以扩大公共投资规模为手段，启动和活跃社会投资；③财政投资规模具有**有限性**——社会投资恢复活力、经济实现自主增长后，政府就不再投资或缩小投资规模；④经济萧条状况不再存在就不实行，因而是**短期**财政政策 |
| **补偿政策** | 政府有意识地从当时经济状态的**反方向**上调节经济变动的财政政策 | 以实现稳定经济波动的目的 |

#### （3）扩张性／紧缩性／中性财政政策

| 类型 | 适用情形 | 手段 | 结果 |
|---|---|---|---|
| **扩张性财政政策** | 社会总需求不足、经济萧条 | 减税、增加财政支出等手段扩大需求 | 往往导致**财政赤字扩大** |
| **紧缩性财政政策** | 社会总需求大于社会总供给、经济繁荣 | 增加税收、减少财政支出等手段抑制社会需求 | 往往导致**财政赤字缩小或盈余扩大** |
| **中性财政政策**（均衡性财政政策） | 社会总供求基本平衡、经济稳定增长时期 | 财政收支基本平衡或者动态平衡 | 既不产生扩张效应，也不产生紧缩效应，保持经济持续稳定发展 |

**逻辑链**：

```
财政政策
├─ 按调节经济周期的作用划分
│   ├─ 自动稳定的财政政策（自动稳定器）
│   │    ├─ 累进所得税（个人所得税＋企业所得税）的自动稳定作用
│   │    └─ 政府福利支出的自动稳定作用
│   └─ 相机抉择的财政政策（政府主动灵活选择反周期工具）
│        ├─ 汲水政策：萧条时以公共投资启动需求（短期、规模有限、以市场自发机制为前提）
│        └─ 补偿政策：从经济状态的反方向调节，稳定经济
└─ 按调节国民经济总量和结构的功能划分
     ├─ 扩张性：总需求不足/萧条 → 减税＋增支 → 赤字扩大
     ├─ 紧缩性：总需求>总供给/繁荣 → 增税＋减支 → 赤字缩小或盈余扩大
     └─ 中性（均衡性）：总供求基本平衡/稳定增长期 → 收支基本平衡或动态平衡
```

**速记口诀**：**"自动稳定无需为（累进所得税＋福利支出），相机抉择主动为（汲水短期有限、补偿反向调节）；需求不足扩张、需求过旺紧缩、供求平衡中性。"**

### 考点6 财政政策的乘数 ★★★★★

**核心概念**：财政政策乘数用来衡量财政政策效果的大小，共**三种**（多选题常考"包括哪些"）。

| 乘数 | 概念 | 计算公式 |
|---|---|---|
| **税收乘数 KT** | 收入变动与引起这种变动的税收变动的比率 | KT = ∆Y/∆T = **-b/(1-b)** |
| **政府购买支出乘数 KG** | 收入变动与引起这种变动的政府购买支出变动的比率 | KG = ∆Y/∆G = **1/(1-b)** |
| **平衡预算乘数 Kb** | 政府收支同时以相等数量增加或减少时，对国民收入变动的影响程度 | Kb = **1** |

**关键结论**：即使实行平衡预算政策，**仍具有扩张效应，其效应等于 1**。

> **素材未覆盖提示**：素材只列出上述三种乘数，**转移支付乘数素材未覆盖**，本节不补写公式，请勿凭记忆作答。

**逻辑链**：

```
b = 边际消费倾向
   ├─ 政府购买支出乘数 KG = 1/(1-b)                    → 正向，数值最大
   ├─ 税收乘数        KT = -b/(1-b)                    → 负向（增税→减收）
   └─ 平衡预算乘数    Kb = 1/(1-b) + [-b/(1-b)] = 1    → 仍具扩张效应
```

**速记口诀**：**"购买乘数 1/(1-b)，税收乘数带负号 -b/(1-b)，平衡预算恒等于 1"**。

### 考点7 财政政策的时滞 ★★

**核心概念**：财政政策实施一般会产生**五种时滞**，分为内在时滞和外在时滞。

| 时滞 | 含义 | 归属 |
|---|---|---|
| **认识时滞** | 经济现象发生到决策者有所认识 | **内在时滞**（只属于研究过程，与决策机关没有直接联系） |
| **行政时滞** | 制定政策前的调查研究耗费的时间 | **内在时滞** |
| **决策时滞** | 财政部门将分析结果提交给立法机关审议通过需要的时间 | **外在时滞**（与决策单位直接发生关系，且直接影响社会的经济活动） |
| **执行时滞** | 立法机关批准后交付有关单位付诸实施需要的时间 | **外在时滞** |
| **效果时滞** | 正式实施到产生效果需要的时间 | **外在时滞** |

**逻辑链**：

```
财政政策时滞
├─ 内在时滞（研究过程，与决策机关无直接联系）
│   ├─ 认识时滞：经济现象发生 → 决策者有所认识
│   └─ 行政时滞：制定政策前的调查研究耗时
└─ 外在时滞（与决策单位直接相关，直接影响社会经济活动）
    ├─ 决策时滞：提交立法机关审议通过
    ├─ 执行时滞：批准后交付实施
    └─ 效果时滞：正式实施 → 产生效果
```

**速记口诀**：**"认识、行政属内在；决策、执行、效果属外在"**。

### 考点8 财政政策与货币政策协调配合的三种类型（素材未标注星级）

| 类型 | 组合 | 效果 |
|---|---|---|
| （1）**"双松"** | 松的财政政策＋松的货币政策 | 可以刺激经济增长、扩大就业，但也会带来**通货膨胀**的风险 |
| （2）**"双紧"** | 紧的财政政策＋紧的货币政策 | 可以有效抑制需求膨胀与通货膨胀，但也可能带来**经济停滞** |
| （3）**紧财政＋松货币** | 紧的财政政策与松的货币政策 | 在控制通货膨胀的同时，可以保持适度的经济增长，但货币政策过松，**难以制止通货膨胀** |
| （4）**松财政＋紧货币** | 松的财政政策与紧的货币政策 | 可以在保持经济适度增长的同时尽可能避免通货膨胀，但长期使用这种政策组合，会**积累大量财政赤字** |

> 说明：素材在"（3）紧配松"之后将两类松紧搭配并列列出，本表按素材原文分四行呈现；其中"双松""双紧"与两类松紧搭配共构成协调配合的主要类型。

**速记口诀**：**"双松增长带通胀，双紧抑胀怕停滞，一松一紧取中庸"**。

### 表2 六大工具 × 逆周期操作（必背大表）

| 工具 | 经济萧条（总供给>总需求，扩张性） | 经济过热（总供给<总需求，紧缩性） |

## 四、公式与计算**（本章计算题重点）**

### 4.1 乘数公式总表

| 乘数 | 概念 | 公式 |
|---|---|---|
| 税收乘数 KT | 收入变动与引起这种变动的税收变动的比率 | KT = ∆Y/∆T = **-b/(1-b)** |
| 政府购买支出乘数 KG | 收入变动与引起这种变动的政府购买支出变动的比率 | KG = ∆Y/∆G = **1/(1-b)** |
| 平衡预算乘数 Kb | 政府收支同时以相等数量增加或减少时对国民收入变动的影响程度 | Kb = **1** |
| 转移支付乘数 | —— | **素材未覆盖**（素材未给出该公式，切勿凭记忆补写） |

### 4.2 例题演算（数字均取自素材真题设定 b=0.75）

**例题1｜税收乘数**

已知边际消费倾向 b = 0.75，求税收乘数；若税收增长 10%，国民收入如何变动？

```
KT = -b/(1-b) = -0.75/(1-0.75) = -0.75/0.25 = -3

KT = ∆Y/∆T  →  ∆Y = KT × ∆T = -3 × 10% = -30%
```

**答：税收乘数为 -3；税收增长 10% 时，国民收入下降 30%（不是增长）。**

**例题2｜政府购买支出乘数**

已知边际消费倾向 b = 0.75，求政府购买支出乘数；若政府购买支出增加，国民收入变动倍数是多少？

```
KG = 1/(1-b) = 1/(1-0.75) = 1/0.25 = 4
```

**答：政府购买支出乘数等于 4，即政府购买支出每增加 1 单位，国民收入同向变动 4 单位。**

**例题3｜平衡预算乘数**

已知 b = 0.75，验证平衡预算乘数。

```
KG = 1/(1-b) = 4
KT = -b/(1-b) = -3
Kb = KG + KT = 4 + (-3) = 1
```

**答：平衡预算乘数等于 1。政府购买与税收以相等数量增减时，国民收入仍会同向变动同等数量，即仍具有扩张效应。**

## 五、高频考点速记卡

1. **Q：财政政策的含义？**
   A：一国政府为实现预期的经济社会发展目标，对财政收支关系进行调整的指导原则和措施，属于宏观调控手段。

2. **Q：财政政策的构成（四政策）？**
   A：预算政策、税收政策、支出政策、国债政策。

3. **Q：财政政策的四大功能？**
   A：导向功能、协调功能、控制功能、稳定功能（没有"管理功能"）。

4. **Q：财政政策的四大目标？**
   A：促进充分就业、物价基本稳定、国际收支平衡、经济稳定增长。

5. **Q：财政政策工具有哪些？利率是不是？**
   A：预算、税收、公债、公共支出、政府投资、财政补贴。利率不是财政政策工具。

6. **Q：预算政策如何"逆经济风向行事"？**
   A：总供给>总需求→赤字预算、增支减税（扩张性）；总供给<总需求→盈余预算、减支增税（紧缩性）；总供求基本平衡→中性财政政策。

7. **Q：税收政策的两个作用？**
   A：保持经济稳定运行的重要手段；政府公平收入分配的重要手段。

8. **Q：公债政策影响经济运行的两条途径？期限与流动性什么关系？**
   A：调整公债流动性程度；调整国债发行利率水平影响金融市场利率。期限越短流动性越高、变现能力越强；期限越长流动性越低、变现能力越弱。

9. **Q：狭义的购买性支出和转移性支出怎么区分？**
   A：狭义购买性支出＝政府的消费性支出；转移性支出＝财政资金无偿、单方面转移的支出（政府补助支出、捐赠支出和债务利息支出）。

10. **Q：政府投资政策的两条途径？**
    A：调整投资规模影响社会总供求和未来总供给；调整投资方向调节经济结构、促进资源合理配置和产业结构优化。

11. **Q：政府投资在过热、萧条、结构问题三种情形下的操作？**
    A：过热降低投资支出水平；萧条提高投资支出水平；总供求基本平衡但结构有问题时有保有压。

12. **Q：补贴政策的操作？**
    A：过热减少财政补贴支出抑制总需求；萧条增加财政补贴支出扩大总需求；也是政府公平收入分配的重要手段。

13. **Q：财政政策有哪两种划分维度？**
    A：按调节经济周期的作用分为自动稳定的财政政策和相机抉择的财政政策；按调节国民经济总量和结构的不同功能分为扩张性、紧缩性、中性财政政策。

14. **Q：自动稳定政策的两大表现？**
    A：累进所得税（个人所得税和企业所得税）的自动稳定作用；政府福利支出的自动稳定作用。

15. **Q：汲水政策的四个特点？**
    A：①以市场经济自发机制为前提，是诱导经济复苏的政策；②以扩大公共投资规模为手段；③财政投资规模具有有限性；④短期财政政策。

16. **Q：补偿政策是什么？**
    A：政府有意识地从当时经济状态的反方向上调节经济变动的财政政策，以实现稳定经济的目的。

17. **Q：扩张性、紧缩性、中性财政政策的适用情形与手段？**
    A：扩张性——总需求不足/萧条，减税增支，赤字扩大；紧缩性——总需求>总供给/繁荣，增税减支，赤字缩小或盈余扩大；中性——总供求基本平衡/稳定增长期，收支基本平衡或动态平衡。

18. **Q：三种财政政策乘数的公式？**
    A：税收乘数 KT=-b/(1-b)；政府购买支出乘数 KG=1/(1-b)；平衡预算乘数 Kb=1。

19. **Q：b=0.75 时各乘数是多少？**
    A：政府购买支出乘数=4，税收乘数=-3，平衡预算乘数=1；税收增长10%时国民收入下降30%。

20. **Q：五种时滞哪些属于内在时滞？**
    A：认识时滞、行政时滞属于内在时滞；决策时滞、执行时滞、效果时滞属于外在时滞。

**答案：D**
**解析**：政府购买支出乘数 = 1/(1-b) = 1/(1-0.75) = 4；税收乘数 = -b/(1-b) = 0.75/(1-0.75) = -3，即 -3 = 国民收入变动率/10%，所以当税收增长10%时，国民收入下降30%；平衡预算乘数 = 1。

**【多选题】财政政策实施一般会产生五种时滞，下列时滞中属于内在时滞的有（　）。**

**解析**：认识时滞和行政时滞属于内在时滞，只属于研究过程，与决策机关没有直接联系；决策时滞、执行时滞、效果时滞属于外在时滞，与决策单位直接发生关系，且直接影响社会的经济活动。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 多选把"管理功能"选进财政政策功能 | 功能只有**导、协、控、稳**四个 |
| 2 | 把"财政政策构成"（四政策）和"财政政策工具"（六项）混用 | 构成＝预算、税收、支出、国债政策；工具＝预算、税收、公债、公共支出、政府投资、财政补贴 |
| 3 | 认为利率也是财政政策工具 | 利率属货币政策工具；选项中"投资"指**政府投资** |
| 4 | 总供给>总需求时选"盈余预算/提高税率" | 萧条要**扩张**：赤字预算、扩大支出、减税 |
| 5 | 认为自动稳定器包括增值税比例税、政府预算 | 自动稳定只有**累进所得税（个税＋企业所得税）**和**政府福利支出** |
| 6 | 认为汲水政策是长期政策、有自动调节机制 | 汲水政策＝**短期**、投资规模**有限**、以市场自发机制为前提、诱导复苏 |
| 7 | 认为相机抉择效果可通过累进所得税自动稳定实现 | 累进所得税自动稳定属**自动稳定类**，不是相机抉择 |
| 8 | 把中性财政政策说成"不作为"或"自动稳定" | 中性＝均衡性：收支基本平衡或动态平衡，稳定增长期采用 |
| 9 | 混淆扩张与紧缩的手段 | 扩张＝减税＋增支；紧缩＝增税＋减支；"**减少税收优惠**"也属紧缩 |
| 10 | 税收乘数符号记成正 | 税收乘数**为负**：增税使国民收入减少 |
| 11 | 税收增长10%时答"国民收入增长30%" | 是**下降**30%（b=0.75 时 KT=-3） |
| 12 | 把平衡预算乘数记成0 | 平衡预算乘数**等于1**，仍具扩张效应 |
| 13 | 认为财政政策乘数还包括债务乘数、赤字预算乘数 | 乘数只有**税收、政府购买支出、平衡预算**三个 |
| 14 | 把决策/执行/效果时滞归入内在时滞 | 内在时滞只有**认识时滞＋行政时滞** |
| 15 | 公债期限与流动性关系记反 | **期限越短，流动性越高**、变现能力越强 |
| 16 | 政府投资"有保有压"用错情形 | 只在**总供求基本平衡但结构存在问题**时有保有压 |
| 17 | 双松、双紧的效果记反 | 双松刺激增长但带通胀风险；双紧抑胀但可能停滞 |
| 18 | 松紧搭配的效果张冠李戴 | 紧财政＋松货币：难止通胀；松财政＋紧货币：长期用会积累大量财政赤字 |

关于财政政策与货币政策协调配合的说法，正确的有（ ）。

A. "双松"政策可以刺激经济增长、扩大就业，但会带来通货膨胀风险
B. "双紧"政策可以有效抑制需求膨胀与通货膨胀，但可能带来经济停滞
C. 紧的财政政策与松的货币政策组合，若货币政策过松，难以制止通货膨胀
D. 松的财政政策与紧的货币政策组合，长期使用会积累大量财政赤字
E. "双紧"政策能够在抑制通胀的同时显著扩大就业

@answer ABCD
@explanation "双松"刺激增长但有通胀风险；"双紧"抑制通胀但可能导致经济停滞，E错误；紧财政松货币在控通胀同时保持适度增长，但货币过松难以制止通胀；松财政紧货币长期使用会积累大量财政赤字。
