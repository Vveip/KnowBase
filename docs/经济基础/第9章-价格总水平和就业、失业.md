## 二、知识点精讲

### 考点1 价格总水平的含义和度量 ★

**核心概念**：价格总水平，也叫**一般价格水平**，指一个国家或地区在一定时期内全社会各类商品和服务价格变动状态的**平均或综合**，一般用**价格指数**来度量。

- **CPI（居民消费价格指数，Consumer Price Index）**是度量价格总水平的**主要指标**，我国也采用 CPI 作为衡量价格总水平变动的**基本指标**。
- 边界：这里说的价格总水平**只包括全社会商品和服务价格的变动**，**不包括**证券、期货、债券等生产要素市场价格的变动情况。

**速记口诀**：**"平均综合看 CPI，证券期货债券不算内"**。

> ⚠️ 常见配套指标 **GDP 平减指数**在本素材中**未覆盖**（素材仅讲 CPI），此处不作展开，以免误记，需另补。

---

### 考点2 决定价格总水平变动的因素 ★★★

**（1）费雪方程式**

```
MV = PT        或        P = MV / T
微分（差分）：π = m + v − y

π = 价格总水平变动率
m = 货币供给量变动率     → 与 π 同方向
v = 货币流通速度变动率   → 与 π 同方向
y = GDP（总产出）变动率  → 与 π 反方向
```

**（2）总需求与总供给**

| 情形 | 关系 |
|---|---|
| 价格总水平 vs 总需求 | **反方向**变动 |
| 价格总水平 vs 总供给（**短期**） | **同方向**变动 |
| 价格总水平 vs 总供给（**长期**） | **无关** |
| 总需求增长**快于**总供给增长 | 价格总水平**上升** |
| 总需求增长**慢于**总供给增长 | 价格总水平**下降** |

**速记口诀**：**"货币增速加流速，减掉产出就是通胀；短期同向、长期无关，需给反着变"**。

---

### 考点3 价格总水平变动的经济效应 ★

| 类别 | 效应 | 公式/结论 |
|---|---|---|
| **直接效应** | 对工资的影响 | 实际工资变动率 = 名义工资变动率 ÷ 价格总水平变动率 |
| | 对利率的影响 | 实际利率 = 名义利率 − 价格总水平变动率（素材记作 i = r − π） |
| | 对汇率的影响 | 本国价格总水平上涨率**高于**外国 → **本币贬值、外币升值** |
| **间接效应** | 对企业生产决策的影响 | —— |
| | 对收入分配结构的影响 | —— |
| | 对经济增长的影响 | **轻度**通胀在一定程度上可能有利于经济增长；**严重**通胀不利于经济增长 |

**速记口诀**：**"工资除、利率减、汇率看谁涨得快；间接效应三条线：生产决策、收入分配、经济增长"**。

> ⚠️ 素材中"i = r − π"与文字"实际利率 = 名义利率 − 价格总水平变动率"的符号方向相反（i、r 谁代表名义谁代表实际），**按文字表述记**更稳：实际利率 = 名义利率 − 价格总水平变动率。

### 考点4 就业和失业的含义 ★

| 概念 | 定义 | 三个条件 |
|---|---|---|
| **就业** | 一定年龄段的人们所从事的为获取报酬或经营收入所进行的活动 | 一定的年龄、收入条件、时间条件 |
| **失业** | 有劳动能力**并愿意就业**但**目前没有**从事有报酬或收入的工作的现象 | 没有工作、当前可以工作、正在寻找工作 |

**速记口诀**：**"就业要三有（年龄、收入、时间），失业要三无（无工作、能工作、在找）"**。

---

### 考点5 我国就业和失业的含义和统计口径 ★★★

- **就业人口**：指在 **16 周岁以上**，从事一定社会劳动并取得劳动报酬或营业收入的人员。
- 我国政府部门计算和公布的就业和失业水平指标主要有两个：**城镇调查失业率**和**城镇登记失业率**。

| 维度 | 城镇登记失业率 | 城镇调查失业率 |
|---|---|---|
| 计算公式 | 报告期末登记失业人员期末实有人数 ÷（期末从业人员总数 + 登记失业人员期末实有人数）×100% | 城镇失业人口 ÷（城镇就业人口 + 失业人口）×100% |
| 数据来源 | 人社部门根据失业人员在就业服务机构登记的**行政记录** | 统计部门**劳动力调查**，调查员**入户访问** |
| 就业人员定义 | 城镇单位就业人员、城镇单位不在岗职工、城镇私营业主、个体户主、城镇私营企业和个体就业人员之和 | 采用**国际劳工组织（ILO）国际标准**：为取得收入，在调查参考周内工作 **1 小时以上（含 1 小时）**；或因在职学习、休假等原因参考周内暂时未工作 |
| 失业人员定义 | 有劳动能力、有就业要求、处于无业状态，并在公共就业和人才服务机构进行失业登记的**城镇常住人员** | 依 ILO 标准 |
| 统计范围 | 劳动年龄内（**16 周岁至退休年龄**）城镇常住人口 | **16 周岁及以上常住人口**，**不考虑户籍所在地和类型** |

**速记口诀**：**"登记靠行政记录、调查靠入户访问；登记卡户籍和退休年龄，调查只看 16 岁以上和参考周 1 小时"**。

### 考点6 就业和失业水平的统计 ★★

- 在发达国家，**失业率**是反映一个国家或地区**劳动力资源利用**状况的**最重要指标**。
- **失业率 = 失业总人数 ÷ 民用劳动力总人数 × 100%**
- **就业率 = 就业人口 ÷ 民用成年人口人数 × 100%**

**相关概念——自然失业率**：
- 定义：劳动力市场处于**均衡状态**、价格总水平处于**稳定状态**时的失业率。
- **弗里德曼**：处于**充分就业状态**的失业率。
- **斯蒂格里茨**：**通货膨胀率为零**的失业率。
- 又叫**非加速通货膨胀失业率**。

**速记口诀**：**"自然失业率：均衡＋价格稳定；弗里德曼说充分就业，斯蒂格里茨说零通胀"**。

### 考点7 失业的类型 ★★★（本章最高频）

```
                        失  业
          ┌──────────────┴──────────────┐
      自愿失业                       非自愿失业
   ┌──────┴──────┐              （需求不足型失业 / 周期性失业）
摩擦性失业      结构性失业        ← 宏观经济学关注的重点
（换工作间隙）  （技能/区域不匹配）（经济衰退、需求不足引起）
```

| 类型 | 归属 | 关键特征 |
|---|---|---|
| **摩擦性失业** | **自愿失业** | 劳动者在正常流动过程中产生的、短期的"找到工作前"的失业 |
| **结构性失业** | **自愿失业** | 劳动力供给结构与需求结构不匹配（技能、地区、产业）造成 |
| **需求不足型失业 / 周期性失业** | **非自愿失业** | 经济衰退导致总需求不足而引起，是**宏观经济学关注的重点**、**宏观经济调控的重点** |

**按古典经济学观点**：完全竞争市场条件下工资可自由波动，价格机制会引导劳动力资源全部用于生产，**不存在非自愿失业**；此时的失业只能是"自愿失业"，即**摩擦性失业和结构性失业**。

**速记口诀**：**"自愿＝摩擦＋结构，非自愿＝需求不足（周期）；衰退引起是周期，调控重点是非自愿"**。

### 考点8 我国就业和失业问题的特点 ★

- **城乡二元结构**：现代工业部门和传统农业部门并存的经济结构。二元结构理论把一国或地区的经济分为两个部门：**现代的城市工业部门**＋**传统的农村农业部门**。
- 党的二十大报告："**就业是最基本的民生**。强化就业优先政策，健全就业促进机制，促进高质量充分就业。"
- 努力扩大就业、降低失业率，使劳动力资源得到更充分利用，是提高人民生活水平的重要途径。
- 扩大就业的路径：保持经济长期稳定增长不断创造岗位；健全就业公共服务体系（免费政策咨询、职业介绍）；全面提升劳动者就业创业能力，健全终身技能培训制度；统筹城乡就业政策。
- **（2026 新增）《"十五五"规划纲要》**：深入实施就业优先战略，坚持扩大就业容量和提升就业质量相结合，健全就业促进机制，建立**就业友好型发展方式**。目标之一：就业保持整体稳定，**城镇调查失业率低于 5.5%**，高质量充分就业取得新进展。

**速记口诀**：**"二元＝城市工业＋农村农业；民生之首是就业，调查失业率红线 5.5%"**。

### 考点9 奥肯定律 ★★★★

**内容**：相对于**潜在的 GDP**，实际 GDP 每下降 **2 个百分点**，失业率就会上升 **1 个百分点**；或者说，相对于**自然失业率**，失业率每提高 **1 个百分点**，GDP 就会下降 **2 个百分点**。

**公式**：

```
(y − y*) / y* = −2 × (u − u*)

y  = 实际 GDP          y* = 潜在 GDP
u  = 实际失业率        u* = 自然失业率
```

**政策含义**（美国）：经济增长与失业之间存在一定的**负相关**关系，政府应当把**促进经济增长**作为降低失业率的主要途径。

**速记口诀**：**"奥肯 2 换 1：GDP 差 2，失业动 1；经济增长是降失业的主路"**。

### 考点10 就业弹性系数 ★★

- **定义**：**就业弹性系数 = 就业增长率 ÷ 经济增长率**（两者之间的比值）。
- **结论**：**第三产业（服务业）**在国民经济中所占比重较大，就业弹性系数相对**较高**。

**速记口诀**：**"就业弹性＝就业增速比经济增速；三产比重高，弹性就高"**。

---

### 考点11 菲利普斯曲线 ★★★★★（本章最高频）

| 要点 | 内容 |
|---|---|
| **简单菲利普斯曲线** | 描述**通货膨胀率与失业率**之间相互关系的曲线，二者呈**负相关**关系 |
| **背景** | 20 世纪 50 年代最初反映**失业率与货币工资率**之间的变化关系（失业率低，工资增长率高） |
| **改造** | 美国经济学家**萨缪尔森和索洛**在 20 世纪 60 年代将其改进为表示**通货膨胀与失业率**相互关系的图形，即"简单的菲利普斯曲线" |
| **弗里德曼观点** | 某一个水平的失业率可以对应**多个水平**的通货膨胀率；通货膨胀与失业的替代关系在**短期内可能存在**，**长期不存在** |
| **长期菲利普斯曲线** | **垂直于横轴**的直线 |

**速记口诀**：**"菲利普斯：通胀失业负相关；弗里德曼分短长，短期替代长期无，长期曲线垂直横轴"**。

### 考点12 宏观经济治理的内涵 ★★

党的二十大报告指出，健全宏观经济治理体系：
- 发挥**国家发展规划的战略导向作用**；
- 加强**财政政策和货币政策协调配合**；
- 着力扩大内需，增强**消费**对经济发展的**基础性作用**和**投资**对优化供给结构的**关键作用**。

## 四、公式与计算

> 下列例题中的数字均为**编者自拟的演示数据**（素材原文未给数字例题），仅用于演示公式用法；公式本身全部来自素材。

### 公式1 费雪方程式与价格总水平变动率

```
MV = PT   ⇒   P = MV / T
π（价格总水平变动率）= m（货币供给量变动率）+ v（货币流通速度变动率）− y（GDP 变动率）
```

**例题**：某年货币供给量增长 8%，货币流通速度加快 2%，实际 GDP 增长 5%，求价格总水平变动率。
**演算**：π = 8% + 2% − 5% = **5%**，价格总水平上升 5%。
**点拨**：m、v 与 π 同向，y 与 π 反向——多减少加。

### 公式2 实际工资变动率

```
实际工资变动率 = 名义工资变动率 ÷ 价格总水平变动率
```

**例题**：名义工资提高 6%，价格总水平上涨 3%，实际工资变动率是多少？
**演算**：6% ÷ 3% = **2**，即实际工资变动率为价格总水平变动率的 2 倍，实际工资上升。
**点拨**：若名义工资不提高或提高幅度低于价格上升幅度，**实际工资下降**。

### 公式3 实际利率

```
实际利率 = 名义利率 − 价格总水平变动率
```

**例题**：名义利率 4%，价格总水平上涨率 3%，实际利率是多少？若通胀升至 6% 呢？
**演算**：4% − 3% = **1%**；通胀 6% 时，4% − 6% = **−2%**（实际利率为负）。
**点拨**：名义利率不变时，**实际利率与价格总水平反向变动**；通胀越高实际利率越低。

### 公式4 失业率与就业率

```
失业率 = 失业总人数 ÷ 民用劳动力总人数 × 100%
就业率 = 就业人口 ÷ 民用成年人口人数 × 100%
```

**例题**：某地区民用劳动力总人数 1000 万人，失业总人数 50 万人，就业人口 700 万人，民用成年人口 1200 万人。求失业率与就业率。
**演算**：失业率 = 50 ÷ 1000 × 100% = **5%**；就业率 = 700 ÷ 1200 × 100% ≈ **58.33%**。
**点拨**：失业率分母是**民用劳动力总人数**，就业率分母是**民用成年人口**，别混。

### 公式5 城镇登记失业率与城镇调查失业率

```
登记失业率 = 登记失业人员期末实有人数 ÷（期末从业人员总数 + 登记失业人员期末实有人数）× 100%
调查失业率 = 城镇失业人口 ÷（城镇就业人口 + 失业人口）× 100%
```

**例题**：某城镇期末从业人员 480 万人，登记失业人员期末实有人数 20 万人；同期劳动力调查得失业人口 25 万人、就业人口 475 万人。求两个失业率。
**演算**：登记失业率 = 20 ÷（480 + 20）×100% = **4%**；调查失业率 = 25 ÷（475 + 25）×100% = **5%**。
**点拨**：两套口径不同，数值通常**不相等**；政策目标"低于 5.5%"说的是**城镇调查失业率**。

### 公式6 奥肯定律

```
(y − y*) / y* = −2 × (u − u*)
```

**例题**：潜在 GDP 为 10000 亿元，实际 GDP 为 9600 亿元，求失业率比自然失业率高多少？
**演算**：(9600 − 10000) ÷ 10000 = −4%，即 (y−y*)/y* = −0.04；由 −0.04 = −2 × (u − u*)，得 u − u* = 0.02，即失业率比自然失业率**高 2 个百分点**。
**点拨**：GDP 缺口 4% → 失业率高出 2 个百分点，"**2 换 1**"。

### 公式7 就业弹性系数

```
就业弹性系数 = 就业增长率 ÷ 经济增长率
```

**例题**：某年经济增长 6%，就业增长 1.2%，求就业弹性系数。
**演算**：1.2% ÷ 6% = **0.2**。就业弹性系数为 0.2，表示经济每增长 1 个百分点，就业增长 0.2 个百分点。
**点拨**：第三产业（服务业）占比大 → 就业弹性系数**较高**。

### 公式8 菲利普斯曲线（定性，无计算）

- 简单曲线：**通货膨胀率 ↑ ⇒ 失业率 ↓**（负相关）。
- 弗里德曼：替代关系**短期可能存在，长期不存在**；长期菲利普斯曲线**垂直于横轴**。

**例题（定性）**：某国短期内通胀率由 2% 升至 5%，按简单菲利普斯曲线，失业率最可能如何变化？
**演算**：负相关 ⇒ 失业率**下降**；但若这是长期中的变化，按弗里德曼观点，失业率**不会持续下降**，长期替代关系不存在。

## 五、高频考点速记卡

1. **Q：价格总水平用什么度量？我国的基本指标是什么？**
   A：用价格指数度量；我国以 **CPI（居民消费价格指数）** 作为衡量价格总水平变动的**基本指标**。

2. **Q：价格总水平包括证券、期货、债券价格的变动吗？**
   A：**不包括**。只包括全社会商品和服务价格的变动。

3. **Q：价格总水平与货币供给量、货币流通速度、总产出的方向关系？**
   A：与前两者**同方向**，与总产出**反方向**（π = m + v − y）。

4. **Q：短期和长期看，总供给变动与价格总水平的关系？**
   A：**短期同方向**变动，**长期无关**。

5. **Q：总需求增长快于总供给增长，价格总水平如何变？**
   A：**上升**；反之（总需求增长慢于总供给）则**下降**。

6. **Q：价格总水平变动的三大直接经济效应？**
   A：对**工资**、**利率**、**汇率**的影响；间接效应是对企业生产决策、收入分配结构、经济增长的影响。

7. **Q：本国价格总水平上涨率高于外国，汇率如何变？**
   A：**本币贬值、外币升值**。

8. **Q：就业的三个条件？失业的三个条件？**
   A：就业＝一定的年龄、收入条件、时间条件；失业＝没有工作、当前可以工作、正在寻找工作。

9. **Q：我国就业人口年龄门槛？**
   A：**16 周岁以上**，从事一定社会劳动并取得劳动报酬或营业收入。

10. **Q：我国公布就业和失业水平的两大指标？**
    A：**城镇调查失业率**和**城镇登记失业率**。

11. **Q：调查失业率中"就业人员"的认定标准？**
    A：按 ILO 国际标准，调查参考周内工作 **1 小时以上（含 1 小时）**；或因在职学习、休假等暂时未工作。

12. **Q：反映劳动力资源利用状况最重要的指标？**
    A：**失业率**（发达国家亦然）。失业率 = 失业总人数 ÷ 民用劳动力总人数 ×100%。

13. **Q：自然失业率怎么定义？两位经济学家的说法？**
    A：劳动力市场均衡、价格总水平稳定时的失业率。**弗里德曼**＝充分就业状态的失业率；**斯蒂格里茨**＝通胀率为零的失业率。又称**非加速通货膨胀失业率**。

14. **Q：自愿失业包括哪两种？**
    A：**摩擦性失业**和**结构性失业**。

15. **Q：非自愿失业又称什么？谁是宏观调控重点？**
    A：**需求不足型失业 / 周期性失业**；它是**宏观经济学关注的重点**、宏观经济调控的重点。

16. **Q：按古典经济学观点，为什么只存在自愿失业？**
    A：完全竞争下工资可自由波动，价格机制引导劳动力资源全部用于生产，故不存在非自愿失业。

17. **Q：奥肯定律的内容和公式？**
    A：实际 GDP 相对潜在 GDP 每降 **2 个百分点**，失业率升 **1 个百分点**；(y−y*)/y* = −2×(u−u*)。政策含义：把**促进经济增长**作为降低失业率的主要途径。

18. **Q：就业弹性系数是什么？哪类产业占比高时它较高？**
    A：就业增长率与经济增长率的比值；**第三产业（服务业）**占比大时较高。

19. **Q：简单菲利普斯曲线描述什么关系？最初又是什么关系？**
    A：**通货膨胀率与失业率**的负相关关系；20 世纪 50 年代最初反映**失业率与货币工资率**关系。

20. **Q：弗里德曼对菲利普斯曲线的观点？长期曲线形状？**
    A：替代关系**短期可能存在、长期不存在**；长期菲利普斯曲线是**垂直于横轴**的直线。

21. **Q：当前财政货币政策取向？**
    A：**更加积极的财政政策**和**适度宽松的货币政策**。

22. **Q："十五五"时期城镇调查失业率目标？**
    A：**低于 5.5%**。

## 六、典型真题（含解析）

> 素材中带年份标签的真题共 **7 道**，全部收录如下，答案与解析按素材保留（已修正明显错别字）。

**【2020·单选】关于价格总水平影响因素的说法，错误的是（　）。**
A. 价格总水平与货币流通速度的变化呈正方向变动
B. 价格总水平取决于总需求与总供给的比例关系
C. 从长期来看，总供给变动与价格总水平无关
D. 价格总水平与货币供给量的变化呈反方向变动

**答案：D**
**解析**：根据费雪方程式 MV=PT，可判断价格总水平与货币供应量的变化呈**同方向**变动，D 错。

**【2018·多选】关于决定价格总水平变动因素的说法，正确的有（　）。**
A. 在其他影响因素不变的情况下，货币供应量增长，价格总水平一般会趋于上升
B. 如果总需求增长快于总供给的增长，价格总水平就有可能上升
C. 在其他影响因素不变的情况下，货币流通速度加快，就会促使价格总水平下降
D. 从长期来看，影响价格总水平的是总需求
E. 从长期来看，总供给与价格总水平是反方向变动

**答案：ABD**
**解析**：在其他影响因素不变的情况下，货币流通速度加快，会促使价格总水平**上涨**，选项 C 错误。从长期看，总供给变动与价格总水平**无关**，选项 E 错误。

**【2015·单选】关于价格总水平影响因素的说法，正确的是（　）。**
A. 从长期来看，总供给变动与价格总水平无关
B. 从长期来看，价格总水平的变动与总产出的变化呈同方向变动
C. 价格总水平的变动与货币供给量呈反方向变动
D. 如果总需求增长慢于总供给的增长，价格总水平就有可能上升

**答案：A**
**解析**：从长期来看，总供给不受价格总水平的影响。价格总水平的变动与货币供给量**同方向**变动；总需求增长慢于总供给，价格总水平**下降**。

**【2016·多选】关于价格总水平变动的经济效应的说法，正确的有（　）。**
A. 实际利率是在货币购买力上升时的利率
B. 价格总水平上涨过程，名义工资不提高或提高幅度低于价格上升幅度，实际工资会下降
C. 在名义利率不变时，实际利率与价格总水平呈反向变动
D. 价格总水平的变动会在一定条件下影响汇率的变动
E. 任何通货膨胀都有利于促进经济增长

**答案：BCD**
**解析**：选项 A 错误，实际利率是**扣除了价格总水平变动影响因素的利率**，也可以是在货币购买力**不变**时的利率。选项 E 错误，**轻度**通货膨胀在一定程度上可能有利于促进经济增长，而**严重的**通货膨胀则不利于经济增长。

**【2020·单选】我国关于城镇登记失业人员劳动年龄的规定是（　）。**
A. 18 周岁至退休年龄　B. 20 周岁至退休年龄　C. 16 周岁至退休年龄　D. 19 周岁至 60 周岁

**答案：C**
**解析**：城镇登记失业人员是指有非农业户口，在一定的劳动年龄内（**16 周岁至退休年龄**），有劳动能力，无业而要求就业，并在当地公共就业服务机构进行失业登记的人员。

**【2020·单选】关于失业的说法，错误的是（　）。**
A. 失业率是反映一个国家或地区劳动力资源利用状况的最重要的指标
B. 如何减少失业是宏观经济调控的重要任务
C. 失业是指有劳动能力的人目前没有从事有报酬或收入的工作的现象
D. 自然失业率是指劳动力市场供求处于均衡状态、价格总水平处于稳定状态时的失业率

**答案：C**
**解析**：选项 C 错误，失业是指有劳动能力**并愿意就业**但目前没有从事有报酬或收入的工作的现象。

**【2021·多选】按照古典经济学观点，自愿失业的有（　）。**
A. 结构性失业　B. 体制性失业　C. 周期性失业　D. 二元经济结构失业　E. 摩擦性失业

**答案：AE**
**解析**：按照西方古典经济学的观点，在完全竞争市场条件下，工资可以自由波动，价格机制将引导劳动力资源全部用于生产，从而不存在失业。在这种情况下，如果有失业，就只能是"自愿失业"。自愿失业包括**摩擦性失业和结构性失业**两种形式。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 以为价格总水平涵盖证券、期货、债券价格 | 只包括**商品和服务**价格，生产要素市场价格不算 |
| 2 | 把"与货币供给量同向"记成反向 | 费雪方程式 MV=PT，M 在分子上，必然**同向** |
| 3 | 分不清短期/长期总供给 | **短期同向、长期无关**；只有总需求是"永远反向" |
| 4 | 把实际工资公式记成"乘" | 实际工资变动率 = 名义工资变动率 **÷** 价格总水平变动率（"工资除"） |
| 5 | 把实际利率公式记成"加" | 实际利率 = 名义利率 **−** 价格总水平变动率（"利率减"） |
| 6 | 认为任何通胀都有利于经济增长 | 只有**轻度**可能有利，**严重**不利 |
| 7 | 失业定义漏掉"愿意就业" | 失业三条件缺一不可：没工作、能工作、**正在找** |
| 8 | 把摩擦性/结构性失业归入非自愿失业 | **自愿 = 摩擦 + 结构**；非自愿 = 需求不足型/周期性 |
| 9 | 把季节性失业与周期性失业混为一谈 | 周期性失业即**需求不足型**失业，由经济衰退引起；二者是并列概念 |
| 10 | 奥肯定律方向记反 | **GDP 动 2、失业动 1**，且方向相反（GDP 降则失业升） |
| 11 | 就业弹性系数分子分母颠倒 | 分子是**就业增长率**，分母是经济增长率 |
| 12 | 认为菲利普斯曲线一开始就是通胀—失业关系 | 20 世纪 50 年代最初是**失业率与货币工资率**关系，60 年代才被萨缪尔森、索洛改造 |
| 13 | 认为长期菲利普斯曲线也是负相关 | 长期**垂直于横轴**，替代关系不存在（弗里德曼） |
| 14 | 混淆城镇调查失业率与登记失业率 | 调查＝入户访问＋ILO 口径＋16 岁及以上常住；登记＝行政记录＋16 岁至退休年龄城镇常住 |
| 15 | 把政策目标"低于 5.5%"安到登记失业率上 | 说的是**城镇调查失业率** |
| 16 | 自然失业率两位学者定义记混 | **弗里德曼＝充分就业**；**斯蒂格里茨＝通胀率为零** |
| 17 | 把"需求不足型失业"和"结构性失业"并列进自愿失业 | 需求不足型即周期性失业，属**非自愿**，是调控重点 |
| 18 | 把"就业弹性高"归因于第二产业 | 是**第三产业（服务业）**占比大时就业弹性系数较高 |

```quiz
某国潜在 GDP 为 25000 亿元，实际 GDP 为 24000 亿元，自然失业率为 4%。根据奥肯定律，该国实际失业率约为（ ）。

A. 6%
B. 5%
C. 4.5%
D. 3%

@answer A
@explanation 奥肯定律：(y－y*)/y*＝－2×(u－u*)。(24000－25000)/25000＝－4%＝－2×(u－4%)，解得 u－4%＝2%，u＝6%，故选 A。
```

```quiz
某地区一定时期就业增长率为 1.2%，同期经济增长率为 6%，则该地区就业弹性系数为（ ）。

A. 0.2
B. 5
C. 0.72
D. 7.2

@answer A
```
