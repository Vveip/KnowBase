## 二、知识点精讲

### 考点1 抽样调查基本概念 ★★★

#### 一、总体与样本

| 概念 | 含义 |
|---|---|
| **总体** | 调查对象的**全体**；组成总体的各个个体称作**总体单元（或单位）** |
| **样本** | 总体的一部分，由从总体中按一定原则或程序抽出的部分个体所组成；样本与总体一样也是一个**集合** |
| **入样单位** | 每个被抽中进入样本的单位 |
| **样本量** | 样本中包含的入样单位的个数，记为 **n** |

**经典示例（必背，真题反复换皮）**：研究某城市居民家庭消费结构，在全部 **50 万户**家庭中随机抽取 **3000 户**入户调查：
- 50 万户家庭 = **总体**
- 50 万户中的每一户 = **总体单元**
- 抽出来的 3000 户 = **样本**
- 这 3000 户中的每一户 = **入样单位**
- **样本量 = 3000**

#### 二、总体参数 vs 样本统计量

| 概念 | 含义 | 常用指标 |
|---|---|---|
| **总体参数** | 总体指标值，**未知的常数**，根据总体中**所有单位**的数值计算，是通过调查想要了解的，**不受样本抽选结果影响** | 总体总量、总体均值、总体比例、总体方差 |
| **样本统计量** | 根据**样本中**各单位的数值计算，是对总体参数的**估计**，也称**估计量**；它是一个**随机变量**，取决于样本设计和正好被选入样本的单元特定组合 | 样本均值、样本比例、样本方差 |

**对应关系**：用样本统计量（如 100 名员工的平均工资）去估计总体参数（500 名员工的平均工资）。

#### 三、抽样框

- **含义**：供抽样所用的**所有抽样单元的名单**，是**抽样总体的具体表现**。
- **常见形式**：名录框，如企业名录、电话簿、人员名册；也可以是**一张地图**或其他适当形式。
- **硬性要求**：不管哪种形式，抽样框中的单位**必须是有序的，便于编号**。
- **高质量抽样框**：应提供被调查单位更多的信息，并且**没有重复和遗漏**。
- 上例中若以每户家庭为抽样单元，则 50 万户家庭的名单即为抽样框。

```
概念链条（判断题挖空处）：
总体（全体）→ 总体单元（每个个体）→ 抽样框（全部单元的名单，总体的具体表现）
                                              ↓ 按一定原则或程序抽取
样本（局部集合）→ 入样单位（被抽中的每个）→ 样本量 n（入样单位个数）
                                              ↓ 计算
样本统计量（估计量，随机变量）→ 去估计 → 总体参数（未知常数）
```

**「八件套」对照示例表（拿 50 万户案例一套一个准）**：

| 概念 | 在 50 万户/3000 户案例中对应 | 在 2000 家餐饮个体户案例中对应 |
|---|---|---|
| 总体 | 全部 50 万户家庭 | 全市 2000 家登记在册餐饮个体户 |
| 总体单元 | 50 万户中的每一户家庭 | 每一户登记在册餐饮个体户 |
| 样本 | 抽取出来的 3000 户家庭 | 随机抽取的 200 家登记在册餐饮个体户 |
| 入样单位 | 这 3000 户中的每一户 | 抽中的每一户 |
| 样本量 | 3000 | 200 |
| 总体参数 | 全市居民家庭消费结构的有关指标值 | 全市所有登记在册餐饮个体户的平均月营收 |
| 样本统计量 | 3000 户调查数据算出的指标值 | 200 家登记在册餐饮个体户的平均月营收 |
| 抽样框 | 50 万户家庭的名单 | 全市 2000 家登记在册餐饮个体户的完整名册 |

**★ 一句话总结**：先认清"谁全体、谁局部、谁名单"，再分清"参数在总体、统计量在样本"。

**速记口诀**：**「总体是全体，样本取局部；参数属总体，统计估参数；抽样框，即名录」**

### 考点2 概率抽样和非概率抽样 ★★★

根据抽样方法不同，抽样分为**概率抽样（随机抽样）**和**非概率抽样（非随机抽样）**。

#### 一、概率抽样

| 项目 | 内容 |
|---|---|
| **定义** | 也称**随机抽样**，依据**随机原则**，按照某种**事先设计的程序**，从总体中抽取部分单元的方法 |
| **特点** | ① 按一定概率以随机原则抽取样本，每个单元都有一定的机会被抽中；② 总体中每个单元被抽中的概率是**已知的或可以计算出来的**；③ 用样本估计总体参数时，要**考虑每个样本单元被抽中的概率** |
| **分型** | 每个单位被抽入样本的概率相等 = **等概率抽样**；概率不同 = **不等概率抽样** |
| **五种方式** | 简单随机抽样、分层抽样、系统抽样、整群抽样、多阶段抽样 |

**速记口诀**：**「简分系整多」**

#### 二、非概率抽样

| 项目 | 内容 |
|---|---|
| **定义** | 又称**非随机抽样**，调查者根据自己的**方便或主观判断**抽取样本的方法 |
| **最主要特征** | 抽取样本时**并不是依据随机原则** |
| **四种方式** | 判断抽样、方便抽样、自愿样本、配额抽样 |

| 方式 | 含义 | 典型例子 |
|---|---|---|
| **判断抽样** | 调查人员依据调查目的和对调查对象的了解，**人为确定样本单元** | — |
| **方便抽样** | 依据**方便原则**，最大限度降低调查成本 | **"拦截式"调查**（街边或居民小区拦住行人） |
| **自愿样本** | 由**自愿接受调查**的单元组成的样本 | **网上调查** |
| **配额抽样** | 将总体各单元按一定标准划分为若干类型，把样本数额分配到各类型中，从各类型中抽取样本的方法**没有严格限制**，一般采用**方便抽样** | — |

**速记口诀**：**「判方配自愿」**

**两大类抽样正面对比表**：

| 维度 | 概率抽样（随机抽样） | 非概率抽样（非随机抽样） |
|---|---|---|
| 依据 | **随机原则** + 事先设计的程序 | **方便或主观判断** |
| 被抽中概率 | **已知或可以计算出来**（每个单元都有一定机会被抽中） | 不依据随机原则，概率未知 |
| 估计总体参数时 | **要考虑每个样本单元被抽中的概率** | 无法据此进行概率意义上的推断 |
| 具体方式 | 简单随机、分层、系统、整群、多阶段 | 判断、方便、自愿、配额 |
| 典型干扰项 | "每个单位概率都相等"（✗，还有不等概率抽样） | "最大限度降低调查成本"是方便抽样的目的，不是概率抽样的特点 |

```
两大类分水岭（选择题秒杀）：
题干出现"随机原则 / 事先设计的程序 / 概率已知或可计算" → 概率抽样
题干出现"方便 / 主观判断 / 人为确定 / 自愿 / 配额"     → 非概率抽样
```

### 考点3 抽样调查的一般步骤 ★

五步，按顺序记忆：

| 步骤 | 要干什么 |
|---|---|
| **1. 确定调查问题** | 要做什么样的调查研究，**为什么**要做这项调查研究 |
| **2. 调查方案设计** | 明确**如何实施**调查，包括**抽样方案的设计**和**问卷设计** |
| **3. 实施调查过程** | 按方案开展现场调查、采集数据 |
| **4. 数据处理分析** | 对采集数据进行整理与统计分析 |
| **5. 撰写调查报告** | 形成最终调查结论与报告 |

**速记口诀**：**「问题→方案→实施→数据→报告」**

**★ 一句话总结**：先想清楚为什么做，再设计怎么做（抽样方案＋问卷），然后去做、去算、去写报告。

### 考点4 抽样调查中的误差 ★★★

样本估计值和总体参数真值之间的差异称为**误差**，分为**抽样误差**和**非抽样误差**两类。

| 类别 | 成因 |
|---|---|
| **抽样误差** | 由于抽样的**随机性**造成的，用样本统计量估计总体参数时出现的误差。**抽到不同的样本，对总体的估计就会不同**，这是抽样误差产生的根本原因 |
| **非抽样误差** | 除抽样误差外，由其他原因引起的样本统计量与总体真值之间的差异 |

**非抽样误差的三大产生原因**：

| 原因 | 内容 |
|---|---|
| **抽样框误差** | 抽样框不完善造成的，抽样框存在**重复、遗漏**等现象 |
| **无回答误差** | 调查人员**没能从被调查者那里得到所需要的数据**。分两类：① 随机因素造成，如被调查者**恰巧不在家**；② 非随机因素造成，如被调查者不愿告诉实情而**拒绝回答** |
| **计量误差** | 调查所获得的数据与其真值之间**不一致**。可能由调查人员、问卷设计、受访者等原因造成 |

**计量误差的典型情形（多选高频）**：调查员有意无意**诱导**被调查者；调查中的**提问错误**或**记录答案错误**；调查人员**有意作弊**；因问卷原因受访者对问题**理解有偏误**；受访者**记忆不清**；受访者提供**虚假数字**。

**关键结论**：
- 抽样误差**无法避免，但可以计算**。
- 非抽样误差**可以人为规避**。
- 描述抽样误差的统计量是**估计量方差**。

**两大类误差正面对比表**：

| 维度 | 抽样误差 | 非抽样误差 |
|---|---|---|
| 成因 | 抽样的**随机性** | 抽样框不完善、无回答、数据计量失真等其他原因 |
| 产生环节 | 抽样本环节（抽到不同样本，估计就不同） | 抽样框编制、现场调查、数据记录与处理等环节 |
| 能否避免 | **无法避免** | **可以人为规避** |
| 能否计算 | **可以计算**（用估计量方差描述） | 一般难以量化计算 |
| 典型来源 | —— | 抽样框重复/遗漏；不在家、拒绝回答、因病无法接受；虚假数字、记忆不清、诱导、提问错误、记录错误、作弊 |

```
误差归因秒判：
抽样的随机性（抽到不同样本）      → 抽样误差
抽样框重复/遗漏                  → 非抽样误差·抽样框误差
不在家/拒绝回答/因病无法接受调查 → 非抽样误差·无回答误差
提供虚假数字/记忆不清/诱导/作弊  → 非抽样误差·计量误差
```

**★ 一句话总结**：随机性带来抽样误差（躲不掉、算得出），其余原因带来非抽样误差（躲得掉）。

### 考点5 简单随机抽样 ★

**含义**：最基本的随机抽样方法。分**不放回**与**有放回**两类。

| 分法 | 操作 | 特点 |
|---|---|---|
| **不放回简单随机抽样** | 从总体中逐个随机抽取单元并**不放回**，每次都在所有尚未被抽入样本的单元中**等概率**抽取下一个单元，直到抽满 n 个 | 每个单位**最多只能被抽中一次**，不会因重复抽中而提供重叠信息，**比放回抽样有更低的抽样误差** |
| **有放回简单随机抽样** | 随机抽出一个样本单位，记录观测结果后**放回总体**，再抽第二个，直到抽满 n 个 | 单位有被**重复抽中**的可能，容易造成**信息重叠**而影响估计效率，**较少采用** |

| 优点 | 是最基本的随机抽样方法，**操作简单**，且**每个单位入样概率相同** |
|---|---|
| 缺点 | ① 没有利用抽样框更多的辅助信息，用样本统计量估计总体参数的**效率受到影响**；② 样本的分布可能十分分散，**增加调查费用和时间** |
| 适用条件 | ① 抽样框中**没有更多可以利用的辅助信息**；② 调查对象分布的**范围不广阔**；③ 个体之间的**差异不是很大** |

**速记口诀**：**「不放回、等概率、无辅助、范围小、差异小」**

**★ 一句话总结**：什么都不挑的时候用它——操作最简单、概率最平等，但白瞎了抽样框里的辅助信息。

### 考点6 分层抽样 ★★★★

- **含义**：先按照某种规则把总体**分为不同的层**，然后在不同的层内**独立、随机地**抽取样本，所得样本称为**分层样本**；如果每层中的抽样都是简单随机抽样，则称为**分层随机抽样**。
- **样本量在各层的分配方法**：**等比例分配**和**不等比例分配**两类（不等比例分配抽样误差可能更小）。

| 优点 | ① 不仅可以估计**总体参数**，也可以估计**各层参数**；② 便于抽样工作的组织；③ 每层都抽取一定样本单位，样本在总体中**分布比较均匀**，可以**降低抽样误差** |
|---|---|
| 应用条件 | ① 抽样框中有**足够的辅助信息**，能够将总体单位按某种标准划分到各层之中；② **同一层内**各单位之间的差异**尽可能小**，**不同层之间**各单位差异**尽可能大** |

**教材例题**：某部门 6 位员工（3 名经理 + 3 名普通职员），经理层年薪 12、14、14（万元），普通职员层 6、6、8（万元），则经理层合计 40、职员层合计 20，**总体均值 =（40+20）÷6 = 10 万元**；适用概率抽样方法随机抽取 2 人为样本，用样本数据对总体均值进行估计。

**例题数字拆解（据素材所给数字整理）**：

| 层 | 人数 | 各人年薪（万元） | 层内合计 | 层内均值（据素材数字推算） |
|---|---|---|---|---|
| 经理层 | 3 | 12、14、14 | 40 | 40÷3 ≈ 13.33 |
| 普通职员层 | 3 | 6、6、8 | 20 | 20÷3 ≈ 6.67 |
| 合计 | 6 | —— | 60 | 60÷6 = **10** |

可见两层均值差距明显（约 13.33 万 vs 约 6.67 万），这正是"**层间差异尽可能大**"的直观体现；若两层内部各自差异小、层与层之间差异大，分层就能用较少的样本把总体特征抓稳。

**★ 一句话总结**：先分层、再随便抽；层内越齐、层间越开，抽样越省、误差越小。

**速记口诀**：**「先分层，再随便抽；层内差异小，层间差异大」**

### 考点7 系统抽样 ★★★★

- **含义**：先将总体中**所有单元按一定顺序排列**，在规定范围内**随机抽取一个初始单元**，然后按**事先规定的规则**抽取其他样本单元。最简单的系统抽样是**等距抽样**。
- **抽样间隔**：**K = N/n**（总体规模 / 样本量）。

**教材例题（四步操作）**：从 600 件产品中抽取 60 件——
1. 将 600 件产品按直线排列，依次编号 1，2，3，…，600；
2. 确定抽样间隔 **K = N/n = 600/60 = 10**；
3. 在第 1 部分中用简单随机抽样抽取一个号码（如 8 号）；
4. 从该号码起，每隔 10 个号码取一个号码，得容量 60 的样本（8，18，28，…，598）。

| 优点 | ① **操作简便**，起始单位一确定，整个样本随之确定；② 对抽样框的要求比较简单：只要求总体单位按一定顺序排列，**不一定是一份具体的名录清单** |
|---|---|
| 缺点 | **方差估计比较复杂**，给计算抽样误差带来一定困难 |
| 适用条件 | 系统抽样的估计效果与**总体单位排列顺序**有关 |

| 排列方式 | 含义 | 估计效果 |
|---|---|---|
| **无关标识排列** | 排列顺序与调查内容**没有联系** | 与简单随机抽样估计**效率相仿** |
| **有关标识排列** | 排列顺序与调查内容**有关** | 抽样精度**一般比简单随机抽样的精度高** |

**示例**：调查汽车尾气排放情况——按汽车**牌号**排列（牌号与尾气排放无关）属**无关标识排列**；按汽车**价格**排列（价格与尾气排放量有相关性）属**有关标识排列**。

**抽样间隔速算对照（据素材例题整理）**：

| 总体规模 N | 样本量 n | 间隔 K=N/n | 抽取方式 |
|---|---|---|---|
| 600 | 60 | 10 | 随机起点 8 号 → 8、18、28、…、598 |

**★ 一句话总结**：整体先排序、随机定开头、固定间隔抽；排列顺序与调查内容越相关，抽得越准。

**速记口诀**：**「整体先排序，随机定开头，固定间隔抽」**

### 考点8 整群抽样 ★★★★

- **含义**：将总体中所有的基本单位按照一定规则划分为**互不重叠的群**，抽样时**直接抽取群**，对抽中的群调查其**全部**基本单位，对没有抽中的群则不进行调查。

| 优点 | ① 实施调查方便，可以**节省费用和时间**；② **抽样框编制得以简化**，抽样时**只需要群的抽样框**，不要求全部基本单位的抽样框 |
|---|---|
| 缺点 | 群内各单位之间存在**相似性、差异比较小**，而群与群之间的差别比较大，使得整群抽样的**抽样误差比较大** |
| 适用条件 | **群内差异尽可能大，群间差异尽可能小**；若群内各单位存在较大差异、群与群结果相似，整群抽样会**降低**估计误差 |

**经典例题**：调查某城市小学教师亚健康状况，从该市 200 所小学中随机抽取 40 所，每所被抽小学的所有教师都参与调查 → **整群抽样**。

**★ 一句话总结**：抽"群"不抽"人"，抽中就全查——省钱省事，但群内太齐、群间太散时误差最大。

**速记口诀**：**「抽群不抽人，群内要大、群间要小」**

### 考点9 多阶段抽样 ★★★

- **含义**：对经过**两个及两个以上抽样阶段**的抽样方法的**统称**。
- **缺点**：多阶段的抽样设计比较复杂，其**抽样误差计算也比较复杂**。
- **适用条件**：在**大范围**的抽样调查中，采用多阶段抽样是必要的。

**经典例题**：调查居民对市政建设的满意度，先从全市所有居委会中随机抽取 20 个居委会，再从每个被抽中居委会中随机抽取 30 个居民家庭入户调查 → **多阶段抽样**。

**五种方式的同场景对照（重要，帮助区分）**：某研究机构抽样了解某市餐饮行业——

| 方法 | 操作 |
|---|---|
| 简单随机抽样 | 从所有餐饮企业中随机抽取一家，再从剩余企业中等概率随机抽取一家，以此类推直到抽满 n 家 |
| 分层抽样 | 先把所有餐饮企业按**所在行政区划和行业**分组，然后在各组内独立进行简单随机抽样 |
| 系统抽样 | 将该市所有餐饮企业按**职工人数规模由高到低排序**，随机抽取一家为初始起点，然后按固定间隔依次抽取 |
| 整群抽样 | 从该城市所有**调查小区**中随机抽取 50 个，对每个被抽中调查小区中**所有**餐饮行业个体户全面调查 |
| 多阶段抽样 | 从所有居（村）委会中随机抽取 50 个，再在每个被抽中的居（村）委会随机抽取 5 个餐饮个体户 |

**易混提醒**：多阶段抽样与整群抽样的区别在于——整群抽样对**抽中的群调查全部基本单位**；多阶段抽样是在**每个被抽中的大单位里再抽小单位**，不进行全面调查。

**★ 一句话总结**：阶段 ≥ 2 就是多阶段；大范围调查非它不可，代价是设计和误差计算都变复杂。

### 考点10 估计量的性质 ★★★

衡量估计量好坏的标准有三个：

| 性质 | 含义 | 判别关键词 |
|---|---|---|
| **无偏性** | 对于**不放回简单随机抽样**，所有可能的样本均值取值的**平均值总是等于总体均值**，这就是样本均值估计量的无偏性。注意：无偏性**不是**要求估计量与总体参数不得有偏差，既然是抽样必然存在抽样误差，不可能与总体完全相同 | "**平均/期望等于**真值" |
| **有效性** | 估计量与总体参数之间必然存在误差，衡量误差大小的指标是**方差**，**方差越小**，估计量对总体的估计越准确，也就越有效。在同一抽样方案下，对某一总体参数 θ 有两个无偏估计量 θ̂₁、θ̂₂，若 θ̂₂ 的可能样本取值较**密集**在真值 θ 附近，则认为 θ̂₂ 比 θ̂₁ 更有效，必有 **Var(θ̂₂) < Var(θ̂₁)** | "**方差更小/取值更密集**" |
| **一致性** | 随着**样本量的增大**，估计量的值如果**稳定于**总体参数的真值，该估计量就有一致性，可称为**一致估计量** | "**样本量增大后稳定于**真值" |

**重要限定**：**有效性仅适用于无偏估计量之间对比**。

**★ 一句话总结**：平均等于真值叫无偏，方差更小叫有效，样本大了稳定住叫一致。

**速记口诀**：**「一无所有」**——无偏（平均等于）、有效（方差更小）、一致（稳定于真值）。

### 考点11 抽样误差的估计 ★★

**抽样误差虽然无法避免，但它是可计算的。**

**影响因素**：

| 因素 | 具体影响 |
|---|---|
| ① 与**总体分布**有关 | 总体单位值之间差异越大，即**总体方差越大，抽样误差越大** |
| ② 与**样本量 n** 有关 | 其他条件相同，**样本量越大，抽样误差越小** |
| ③ 与**抽样方式和估计量的选择**有关 | 例如**分层抽样的估计量方差一般小于简单随机抽样** |
| ④ 利用**有效辅助信息**的估计量 | 也可以有效减小抽样误差 |

**计算公式（不放回简单随机抽样，样本均值估计总体均值）**：

```
        n         s²
V(ȳ) = (1 - ——) × ——
        N          n
```

其中 N 为总体规模，n 为样本量，s² 为样本方差。实践中**总体方差未知，通常用样本方差来替代**。

**公式符号与含义速查**：

| 符号 | 含义 | 备注 |
|---|---|---|
| V(ȳ) | 估计量（样本均值）的方差，用于**描述抽样误差** | 方差越大，抽样误差越大 |
| N | 总体规模 | 例题中常给 10000 |
| n | 样本量 | 例题中常给 100 或 200 |
| (1 − n/N) | **不放回**修正因子（有限总体修正） | n/N 越大，修正越明显；n 远小于 N 时接近 1 |
| s² | 样本方差 | 实践中替代未知的总体方差 |

**四因素影响方向速查表**：

| 因素变化 | 抽样误差方向 |
|---|---|
| 总体方差 ↑ | 抽样误差 **↑** |
| 样本量 n ↑ | 抽样误差 **↓** |
| 改用分层抽样（相比简单随机抽样） | 抽样误差 **↓** |
| 利用有效辅助信息 | 抽样误差 **↓** |

**★ 一句话总结**：误差躲不掉但算得出；总体越散误差越大，样本越多误差越小，方法越妙（分层、用辅助信息）误差越小。

### 考点12 样本量的计算 ★★★★

**基本关系**：通常情况下，样本量 n 增大，相应样本估计量的抽样误差会**减小**；反之亦然。

**影响因素**：

| 因素 | 如何影响 |
|---|---|
| **1. 调查的精度** | 要求的调查精度越高（误差水平越小），所需样本量**越大** |
| **2. 总体的离散程度** | 其他条件相同，**总体方差越大**，所需样本量**越大** |
| **3. 总体的规模** | 对于**大规模的总体**，总体规模对样本量的需求**几乎没有影响**；对**小规模的总体**，总体规模越大，为保证相同估计精度，样本量也要随之增大（但**不是同比例**的） |
| **4. 无回答情况** | 无回答减少了有效样本量；**无回答率较高**的调查项目，样本量要**大一些** |
| **5. 经费的制约** | 样本量是**调查经费与调查精度之间的某种折中和平衡** |
| **6. 其他因素** | 调查的限定时间、实施调查的人力资源等 |

**公式与符号含义**：不考虑费用限制、无回答情况及其他影响因素时，简单随机抽样的样本量计算公式为

```
         2  2
        uα·S
   n₀ = ——————
          2
          d
```

- **N**：总体规模。当 N 很大时，对样本量 n 的影响较小，样本量 n 接近于 n₀。
- **uα**：标准正态分布的**双侧 α 分位数**。当置信度（1−α）为 **95%** 时，uα = **1.96**。
- **d**：**绝对允许误差**。允许误差越小，人们就越相信抽样结果接近于"真实"。
- **S²**：总体方差。S² 未知时，一般用**样本方差 S² 替代**。
- **比例估计中**：若 P 为总体比例，则总体方差 **S² = P(1−P)**。假定总体比例在 **0.5** 附近，则 S² = 0.5×0.5 = **0.25**。

**教材算例（必背）**：假定总体比例在 0.5 附近，总体规模为 **1000 万个**，当绝对允许误差 d 分别为 **0.01、0.03、0.05** 时，简单随机抽样所需样本量分别为 **9604、1068、385**。随着样本量的增大，增加同等样本所增加的**精度幅度呈下降趋势**。

**样本量计算五步法**：

```
第1步  定精度：写出绝对允许误差 d（越小越精细，样本量越大）
第2步  定置信：95% 置信度取 uα = 1.96
第3步  定方差：比例估计 S² = P(1-P)；P 未知且假定在 0.5 附近时 S² = 0.25
第4步  代入公式：n₀ = uα²·S² / d² = 1.96² × S² / d²
第5步  看总体：N 很大时 n ≈ n₀；N 不大时按"总体规模"因素上调（非同比例）
```

**样本量与 d 的反比关系演算（据素材数字整理）**：

| d | d² | n₀ = 3.8416×0.25÷d² | 相对 d=0.05 的样本量倍数 |
|---|---|---|---|
| 0.01 | 0.0001 | **9604** | 约 25 倍 |
| 0.03 | 0.0009 | **1068** | 约 2.8 倍 |
| 0.05 | 0.0025 | **385** | 1 倍 |

可见 **d 缩小一半，样本量约翻两番**（样本量与 d² 成反比）；同时从 385 增到 1068 再增到 9604，每提升一档精度所付出的样本代价急剧上升——这就是"增加同等样本所增加的精度幅度呈下降趋势"的体现。

**★ 一句话总结**：精度要高、总体越散、无回答越多、经费越足，样本量就越大；总体规模只在"小总体"时才管用。

## 三、必背表格汇总

### 表1 五种概率抽样方式对比总表（本章核心）

| 方式 | 含义 | 特点 | 适用场景/应用条件 | 抽样误差大小 |
|---|---|---|---|---|
| **简单随机抽样** | 最基本的随机抽样方法，分不放回与有放回两类；每个单位入样概率相同 | 优：操作简单、最基本；缺：未利用抽样框辅助信息、估计效率受影响、样本分散增加费用和时间 | ① 抽样框中没有更多可利用的辅助信息；② 调查对象分布范围不广阔；③ 个体之间差异不是很大 | **不放回 < 有放回**（不放回无重复抽中、无信息重叠，误差更低） |
| **分层抽样** | 先按某种规则把总体分为不同的层，再在各层内独立、随机抽取样本；每层均为简单随机抽样则称分层随机抽样 | 优：可估计总体参数**和各层参数**、便于组织、样本分布均匀可降低误差；样本量分配分**等比例/不等比例**两类（不等比例误差可能更小） | 抽样框中有足够辅助信息能分层；**层内差异尽可能小，层间差异尽可能大** | **一般小于简单随机抽样**（估计量方差更小） |
| **系统抽样（等距抽样）** | 总体所有单元按一定顺序排列，随机抽一个初始单元，再按事先规定的规则抽取；最简单的是等距抽样，间隔 **K=N/n** | 优：操作简便、起始单位定则样本定、对抽样框要求简单（只需有序排列，无需名录清单）；缺：**方差估计复杂**，计算抽样误差困难 | 估计效果与**总体单位排列顺序**有关：无关标识排列 ≈ 简单随机抽样效率；有关标识排列精度更高 | 无关标识排列时**与简单随机抽样相仿**；有关标识排列时**一般高于简单随机抽样** |
| **整群抽样** | 把总体基本单位划分为互不重叠的群，直接抽群，对抽中的群调查**全部**基本单位，未抽中的群不调查 | 优：实施方便、省费用时间、抽样框只需群的名单；缺：群内相似性高、群间差别大 | **群内差异尽可能大，群间差异尽可能小** | **比较大**（群内差异小、群间差异大时误差最大；2021 真题：同样本量下误差最大） |
| **多阶段抽样** | 对经过**两个及两个以上**抽样阶段的抽样方法的统称 | 缺：设计复杂、**抽样误差计算复杂**；优：大范围调查中必要 | **大范围**的抽样调查 | 素材未给出与其他方式的直接排序（仅说明误差计算复杂） |

### 表2 非概率抽样方式对比表

| 方式 | 核心含义 | 判别关键词/典型例子 | 所属大类 |
|---|---|---|---|
| **判断抽样** | 调查人员依据调查目的和对调查对象的了解，**人为确定样本单元** | "人为确定" | 非概率抽样 |
| **方便抽样** | 依据**方便原则**，最大限度降低调查成本 | "**拦截式**调查"、街边/居民小区拦住行人、下班时在厂门口每隔 2 分钟抽 1 人 | 非概率抽样 |
| **自愿样本** | 由**自愿接受调查**的单元所组成的样本 | "**网上调查**"、网络有奖问卷 | 非概率抽样 |
| **配额抽样** | 将总体各单元划分为若干类型，样本数额分配到各类型，各类型内抽取方法**没有严格限制**，一般采用方便抽样 | "配额/分配名额" | 非概率抽样 |

### 表3 「18 个不等于」避坑表

| # | 不等于 | 正解 |
|---|---|---|
| 1 | 样本 ≠ 总体 | 样本只是总体的**一部分**，是由按一定原则或程序抽出的部分个体组成的集合 |
| 2 | 入样单位 ≠ 总体单元 | 总体单元是总体中的每个个体；**入样单位**仅指被抽中进入样本的单位 |
| 3 | 总体参数 ≠ 样本统计量 | 参数由总体**所有单位**计算、是**未知常数**、不受抽选结果影响；统计量由**样本**计算、是**估计量**、是**随机变量** |
| 4 | 抽样框 ≠ 样本 | 抽样框是供抽样所用的**所有抽样单元的名单**（总体的具体表现），不是抽出来的那部分 |
| 5 | 抽样框 ≠ 会议签到表/被抽中者名录 | 必须是**全部**抽样单元的有序名单，无重复遗漏；只含部分人的签到表、被抽中的 200 人名录都不行 |
| 6 | 概率抽样 ≠ 每个单位概率都相等 | 概率抽样含**等概率抽样**与**不等概率抽样**两种 |
| 7 | 抽样误差 ≠ 非抽样误差 | 抽样误差源于**抽样的随机性**；非抽样误差源于抽样框、无回答、计量等原因 |
| 8 | 无回答误差 ≠ 计量误差 | 没拿到数据（不在家、拒绝回答、因病无法接受）= 无回答误差；拿到了但数据失真（虚假数字、记忆不清、诱导、作弊）= 计量误差 |
| 9 | 分层抽样 ≠ 配额抽样 | 分层抽样是**概率抽样**；配额抽样是**非概率抽样**，层内一般用方便抽样 |
| 10 | 分层抽样 ≠ 整群抽样 | 分层：**层内差异小、层间差异大**，每层都抽；整群：**群内差异大、群间差异小**，只抽部分群且全查 |
| 11 | 系统抽样 ≠ 简单随机抽样 | 系统抽样按固定间隔抽取，只需总体有序排列，不要求名录清单 |
| 12 | 多阶段抽样 ≠ 整群抽样 | 整群对抽中群**全部调查**；多阶段是抽中大单位后再**从中再抽小单位** |
| 13 | 无偏性 ≠ 有效性 ≠ 一致性 | 无偏=平均等于真值；有效=方差更小；一致=样本量增大后稳定于真值 |
| 14 | 有效性 ≠ 可跨全部估计量比较 | **有效性仅适用于无偏估计量之间对比** |
| 15 | 样本量增大 ≠ 精度同比例提高 | 增加同等样本量所增加的精度幅度**呈下降趋势** |
| 16 | 总体规模越大 ≠ 样本量同比例增大 | 大规模总体中总体规模对样本量**几乎没有影响**；小规模总体中样本量随之增大但**不同比例** |
| 17 | 抽样误差可计算 ≠ 可消除 | 抽样误差**无法避免**，但**可以计算** |
| 18 | 有放回抽样 ≠ 不放回抽样 | 不放回每个单位最多被抽中一次、无信息重叠、**误差更低**、是主流 |

### 表4 五种概率抽样「秒判流程图」

```
看题干怎么抽？
├─ 逐个随机抽、单位最多中一次、无辅助信息可用 ─────────→ 简单随机抽样（不放回）
├─ 先"按某标准分成若干层/组"，再在每层内各自随机抽 ───→ 分层抽样
│     └─ 关键词：层内差异小、层间差异大；每层都抽
├─ 先"排序/编号"，随机定一个开头，再按固定间隔抽 ─────→ 系统抽样（等距抽样）
│     └─ 关键词：K=N/n；有关标识排列精度更高
├─ 划分成若干"群"，只抽部分群，且抽中的群"全部调查" ─→ 整群抽样
│     └─ 关键词：群内差异大、群间差异小；省费用时间但误差大
└─ 抽完大单位，再从大单位里抽小单位（阶段≥2）────────→ 多阶段抽样
      └─ 关键词：居委会→家庭；省→市→个人
```

> **用法**：做多选"该调查采用了哪些抽样方法"时，**按流程一步一步对号入座**，常见组合是「分层＋系统＋整群＋多阶段」（2015 真题）、「多阶段＋分层」（2025 真题）、「分层＋整群＋多阶段」（延迟退休真题）。

## 四、公式与计算（本章计算题重点）

### 4.1 抽样间隔：K = N / n

- **适用**：系统抽样（等距抽样）。
- **例题**：从 600 件产品中抽取 60 件，K = 600/60 = **10**，即每隔 10 个号码取一个。
- **真题印证**：【2025·单选】等距抽样的抽样间隔计算公式为 → **总体规模/样本量（A）**。

### 4.2 估计量方差（不放回简单随机抽样）

```
        n         s²
V(ȳ) = (1 - ——) × ——
        N          n
```

> 素材仅给出此"了解"级公式；实践中总体方差未知，用**样本方差 s² 替代**。

**带数字演算例题**（真题原型）：采取不放回简单随机抽样从总体 **N = 10000** 中抽取样本 **n = 100**，用样本均值估计总体均值，**样本方差 s² = 100**，则估计量的方差为（ ）。

```
V(ȳ) = (1 - n/N) × s²/n
    = (1 - 100/10000) × 100/100
    = (1 - 0.01) × 1
    = 0.99 × 1
    = 0.99
```
**答案：C（0.99）**。注意分母 N 取 **10000**，别错用 1000；s²/n = 100/100 = 1，别漏除。

### 4.3 样本量计算：n₀ = uα²·S² / d²

**带数字演算例题 1（教材算例）**：总体比例在 0.5 附近，总体规模 1000 万个，置信度 95%（uα=1.96），绝对允许误差 **d = 0.01**。

```
S² = P(1-P) = 0.5 × (1-0.5) = 0.25
n₀ = uα²·S²/d² = 1.96² × 0.25 / 0.01²
   = 3.8416 × 0.25 / 0.0001
   = 0.9604 / 0.0001
   = 9604
```
**答案：n₀ = 9604**（与素材所给一致）。同法算得 d=0.03 → **1068**；d=0.05 → **385**。

**规律**：d 缩小为原来的 1/3，样本量约扩大为 9 倍（样本量与 d² 成反比）；**误差减半、样本量翻两番**。

**带数字演算例题 2（变形）**：若总体方差改为 S² = 0.21（即 P≈0.3），其他条件不变（uα=1.96，d=0.05），则

```
n₀ = 3.8416 × 0.21 / 0.0025 = 0.8067 / 0.0025 ≈ 322.7 → 取 323
```
**结论**：总体方差越小，所需样本量越小（印证「总体离散程度」因素）。

> **「素材未覆盖」提示**：本节仅覆盖**重复抽样（有放回）**下的简单随机抽样样本量公式 n₀ = uα²S²/d²，素材同时说明"当 N 很大时 n 接近于 n₀"。**不重复抽样（有限总体修正）下的样本量修正公式 n = n₀/(1 + n₀/N)，素材未覆盖**，考纲若出现请以官方教材为准，不要凭记忆套用。

### 4.4 估计量优良标准：无偏性 / 有效性 / 一致性

三者不用复杂计算，靠**定义关键词**判别：

**带数字演算例题**（真题原型，2023）：假设一个总体包含 **10000** 个数字，均值为 μ，采用某抽样方法随机抽选 **200** 个数字作为样本，用样本均值估计总体均值 μ，**所有可能的样本均值取值的平均值总是等于总体均值**，这说明该方案的均值估计量具有（ ）。

```
"所有可能样本均值取值的平均值 = 总体均值"  →  期望等于真值  →  无偏性
```
**答案：C（无偏性）**。

| 若题干改为…… | 则答案 |
|---|---|
| 随着样本量的增大，估计量的值**稳定于**总体参数真值 | **一致性** |
| 两个无偏估计量相比，取值更**密集**、**方差更小** | **有效性** |

### 4.5 置信区间与边际误差（绝对允许误差 d）

- **d 的含义**：在一定的置信度（1−α）下，样本估计值与总体参数 θ 之间的误差**不超过某一给定的最大可能范围**；允许误差越小，表明人们越相信抽样结果接近于"真实"。
- **数学表述**（真题原文选项）：**Pr(|θ̂ − θ| ≤ d) = 1 − α**。
- **uα**：标准正态分布的**双侧 α 分位数**；置信度 95% 时 uα = **1.96**。

**带数字演算例题**（真题原型，2023补）：在置信度（1−α）下用随机样本估计量估计总体参数 θ，绝对允许误差 d 的含义是（ ）。

```
A. Pr(|θ̂ − θ| ≤ d) = 1 − α     ← 正确
B. Pr(|θ̂ − θ| ≥ d) = 1 − α     ← 方向反了
C. Pr(|θ̂ − θ| ≥ 1 − α) ≥ d     ← 把 α 和 d 混为一谈
D. Pr(|θ̂ − θ| ≤ d) ≥ 1 − α     ← 等号写成不等号
```
**答案：A**。

> **「素材未覆盖」提示**：素材只给出 d 的定义式 **Pr(|θ̂−θ|≤d)=1−α** 及 uα=1.96，**未给出完整的置信区间构造式（如 θ̂ ± d）**，也未给出边际误差与样本量联立求解的例题，此处不补写。

## 五、高频考点速记卡

1. **Q：抽样调查中"样本"指什么？**
   A：从总体中按一定原则或程序抽出的部分个体所组成的集合（如 50 万户中抽出的 3000 户）。

2. **Q：总体参数与样本统计量的区别？**
   A：总体参数由总体**所有单位**数值计算，是**未知常数**，不受抽选结果影响；样本统计量由**样本**数值计算，是对总体参数的估计，也称估计量，是**随机变量**。

3. **Q：什么是抽样框？高质量抽样框的标准？**
   A：供抽样所用的**所有抽样单元的名单**，是抽样总体的具体表现。标准：提供被调查单位更多信息，**无重复、无遗漏**，单位有序便于编号。

4. **Q：概率抽样的三个特点？**
   A：① 按一定概率以**随机原则**抽取样本；② 每个单元被抽中的概率**已知或可计算**；③ 估计总体参数时要考虑每个样本单元被抽中的概率。

5. **Q：概率抽样五种方式？非概率抽样四种方式？**
   A：概率——简单随机、分层、系统、整群、多阶段（**简分系整多**）；非概率——判断、方便、自愿、配额（**判方配自愿**）。

6. **Q：等概率抽样与不等概率抽样如何区分？**
   A：每个单位被抽入样本的概率**相等**为等概率抽样；**不相等**为不等概率抽样。

7. **Q："拦截式"调查属于哪种抽样？网上调查呢？**
   A：拦截式（街边拦住行人）＝**方便抽样**；网上调查＝**自愿样本**。

8. **Q：配额抽样有什么特点？属于概率抽样吗？**
   A：将总体分若干类型并分配样本数额，各类型内抽取方法没有严格限制，一般采用方便抽样；属于**非概率抽样**。

9. **Q：抽样调查的一般步骤？**
   A：① 确定调查问题；② 调查方案设计（含抽样方案设计和问卷设计）；③ 实施调查过程；④ 数据处理分析；⑤ 撰写调查报告。

10. **Q：抽样误差产生的根本原因？**
    A：抽样的**随机性**——抽到不同的样本，对总体的估计就会不同。

11. **Q：非抽样误差的三类原因？**
    A：**抽样框误差**（重复、遗漏）、**无回答误差**（拿不到数据）、**计量误差**（数据与真值不一致）。

12. **Q：拒绝接受调查、不在家、因病无法接受调查，属于哪种误差？**
    A：**无回答误差**（非抽样误差的一种）。

13. **Q：受访者提供虚假数字、记忆不清、调查员诱导，属于哪种误差？**
    A：**计量误差**（非抽样误差的一种）。

14. **Q：简单随机抽样的适用条件？**
    A：① 抽样框中没有更多可利用的辅助信息；② 调查对象分布范围不广阔；③ 个体之间差异不是很大。

15. **Q：分层抽样的优点和应用条件？**
    A：优点——可估计总体和各层参数、便于组织、样本分布均匀可**降低抽样误差**；条件——抽样框有足够辅助信息能分层，**层内差异小、层间差异大**。

16. **Q：系统抽样的抽样间隔怎么算？对抽样框有什么要求？**
    A：**K = N/n**（总体规模/样本量）；只要求总体单位按一定顺序排列，**不一定需要具体名录清单**。缺点是方差估计复杂。

17. **Q：整群抽样的适用条件和误差特点？**
    A：**群内差异尽可能大、群间差异尽可能小**；抽中群后调查其**全部**基本单位。群内差异小、群间差异大时**误差比较大**。

18. **Q：多阶段抽样的定义和适用场景？**
    A：对经过**两个及两个以上**抽样阶段方法的统称；适用于**大范围**抽样调查；设计复杂、误差计算复杂。

19. **Q：估计量的三个性质及判别关键词？**
    A：**无偏性**（所有可能样本均值取值的平均值等于总体均值）、**有效性**（方差更小、取值更密集）、**一致性**（样本量增大后稳定于真值）。

20. **Q：有效性适用于什么范围比较？**
    A：**仅适用于无偏估计量之间**对比。

21. **Q：影响抽样误差的四因素？**
    A：① 总体方差越大误差越大；② 样本量越大误差越小；③ 与抽样方式和估计量选择有关（分层抽样估计量方差一般小于简单随机抽样）；④ 利用有效辅助信息可减小误差。

22. **Q：影响样本量的因素有哪些？**
    A：调查的精度、总体离散程度、总体规模、无回答情况、经费制约、其他因素（限定时间、人力资源）。

23. **Q：总体规模与样本量是什么关系？**
    A：大规模总体中总体规模对样本量**几乎没有影响**；小规模总体中总体规模越大样本量随之增大，但**不是同比例**。

24. **Q：95% 置信度对应的 uα 是多少？比例估计中总体方差怎么算？**
    A：uα = **1.96**；S² = P(1−P)，P 在 0.5 附近时 S² = **0.25**。

25. **Q：d=0.01、0.03、0.05 时（N=1000 万，P≈0.5）样本量分别是多少？说明什么规律？**
    A：**9604、1068、385**。样本量与 d² 成反比；且随着样本量增大，增加同等样本所增加的精度幅度**呈下降趋势**。

## 六、典型真题（含解析）

B. 公司某次会议员工出席签到表

**【2017·多选】随机抽样的特点主要包括（　）。**
A. 每个总体单元被抽入样本的概率都相等

**解析**：分别从东、中、西部地区**各自抽取**＝先分层（若直接从全国随机抽 10 个区域，则不选分层）；对被抽中企业的**所有**在职职工调查＝整群抽样；两个阶段＝多阶段抽样。

**10.【多选】导致非抽样误差出现的原因主要有（　）。**
A. 抽样框误差　B. 无回答误差　C. 计量误差　D. 抽样的随机性　E. 受访者提供虚假数字
**答案：ABCE**（D"抽样的随机性"造成的是**抽样误差**，故不选）

**11.【多选】影响样本量的因素有（　）。**
A. 总体的离散程度　B. 调查的精度　C. 无回答情况　D. 经费的制约　E. 抽样方法
**答案：ABCD**（"抽样方法"不在素材所列六因素之内）

**12.【单选】在抽样估计中，随着样本量的增大，如果估计量的值稳定于总体参数的真值，这个估计量具有的性质是（　）。**
A. 一致性　B. 无偏性　C. 有效性　D. 确定性
**答案：A**

**13.【多选】关于概率抽样特点的说法，正确的有（　）。**
A. 按照一定的概率以随机原则抽取样本点
B. 总体中每个单元被抽入样本的概率都相等
C. 总体中每个单元被抽中的概率是已知或可计算的
D. 每个样本被抽中的概率都相等
E. 总体中每个单元都有一定的机会被抽中

**答案：ACE**
**解析**：概率抽样也称随机抽样，特点为：① 按一定概率以随机原则抽取样本，每个单元都有一定机会被抽中；② 每个单元被抽中的概率已知或可计算；③ 估计时要考虑每个样本单元被抽中的概率。B、D 错——概率抽样还包括**不等概率抽样**，不能断言"都相等"。

**14.【多选】下列关于抽样误差的表述，错误的有（　）。**
A. 利用有效辅助信息的估计量也可以有效地减小抽样误差
B. 抽样误差与总体分布有关，总体方差越大，抽样误差越大
C. 其他条件相同，样本量越大，抽样误差越大
D. 抽样误差与抽样方式和估计量的选择也有关
E. 分层抽样的估计量方差一般大于简单随机抽样

**答案：CE**
**解析**：C 错——其他条件相同，样本量越大，抽样误差**越小**；E 错——分层抽样的估计量方差一般**小于**简单随机抽样。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"样本"和"入样单位"混为一谈 | 样本是**抽出来的全部 3000 户这个集合**；入样单位是其中**每一户** |
| 2 | 把"总体参数"和"总体"混为一谈 | 总体是**调查对象的全体**（如所有在职员工）；总体参数是**总体指标值**（如他们的平均薪酬满意度） |
| 3 | 以为样本统计量是常数 | 样本统计量是**随机变量**，取决于样本设计和正好被选入样本的单元组合 |
| 4 | 认为抽样框可以是"被抽中者的名录"或"某次会议签到表" | 抽样框必须是**所有**抽样单元的名单；签到表、被抽中者名录都缺人，不合格 |
| 5 | 认为抽样框只能是名录清单 | 也可以是**一张地图**或其他适当形式，但单位必须**有序、便于编号** |
| 6 | 认为概率抽样中每个单位被抽中的概率都相等 | 概率抽样含**等概率**与**不等概率**两种，只说"概率已知或可计算" |
| 7 | 把"拦截式调查"归到判断抽样 | 拦截式 = **方便抽样**（依据方便原则、降低成本）；判断抽样是"人为确定样本单元" |
| 8 | 把"网上调查/有奖问卷"归到方便抽样 | 网上调查、自愿填答 = **自愿样本** |
| 9 | 把配额抽样当成概率抽样 | 配额抽样是**非概率抽样**，各类型内一般用**方便抽样** |
| 10 | 把"抽样的随机性"算作非抽样误差的原因 | 随机性 → **抽样误差**；非抽样误差只有抽样框、无回答、计量三类 |
| 11 | 把"提供虚假数据/记忆不清"归到无回答误差 | 拿到了数据但数据失真 = **计量误差**；只有"没拿到数据"才是无回答误差 |
| 12 | 认为分层抽样是"层内差异大、层间差异小" | 恰好相反：**层内差异小、层间差异大**（口诀：先分层再随便抽） |
| 13 | 把分层抽样和整群抽样的差异要求记反 | 分层——层内小、层间大，**每层都抽**；整群——群内大、群间小，**只抽部分群且全查** |
| 14 | 认为整群抽样误差小、省时所以什么都好 | 整群抽样**省费用时间、抽样框简单**，但群内同质、群间差异大时**误差最大**（2021 真题） |
| 15 | 把等距抽样当成简单随机抽样 | 随机抽第一个再按固定间隔抽 = **系统（等距）抽样**，不是简单随机抽样（2015 真题陷阱） |
| 16 | 认为多阶段抽样就是对抽中群全部调查 | 抽中群**全部调查**是整群抽样；多阶段是抽中大单位后**再抽小单位** |
| 17 | 把无偏性、有效性、一致性的关键词记混 | 无偏=**平均等于**；有效=**方差更小/更密集**；一致=**样本量增大后稳定** |
| 18 | 用有效性比较两个非无偏估计量 | **有效性仅适用于无偏估计量之间**对比 |
| 19 | 认为总体方差越大抽样误差越小 | 总体方差越大，抽样误差**越大**；样本量越大，抽样误差**越小** |
| 20 | 认为分层抽样误差大于简单随机抽样 | 分层抽样的估计量方差**一般小于**简单随机抽样 |
| 21 | 认为总体规模越大样本量要同比例增大 | 大规模总体中规模对样本量**几乎没有影响**；小规模总体中也**不是同比例** |
| 22 | 认为"增加同等样本量，降低的误差相同" | 随着样本量增大，增加同等样本所增加的精度幅度**呈下降趋势** |
| 23 | 计算估计量方差时把 N 和 n 用反 | V(ȳ)=(1−**n/N**)×s²/**n**；N=10000、n=100 → 系数是 0.99 不是 99 |
| 24 | 把"调查指标数量"算作样本量的影响因素 | 素材所列六因素：精度、离散程度、总体规模、无回答、经费、其他（时间/人力），**不含抽样方法与指标数量** |
| 25 | 以为绝对允许误差 d 就是 Pr(|θ̂−θ|≥d)=1−α | 正确表述是 **Pr(|θ̂−θ|≤d)=1−α**，是"不超过" |
