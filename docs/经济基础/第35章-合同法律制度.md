# 第35章 合同法律制度

> **本章考情**：本章属于法律部分中**内容最密、点最多**的一章，围绕合同"从生到死"的全生命周期展开——订立、效力、履行、担保、保全、转让、违约。命题以单选、多选的**概念辨析、归类判断、数字记忆**为主。素材标注：考点01合同的法律特征及分类 ★★★、考点02合同的效力 ★★★、考点03合同的订立履行及终止 ★★、考点04合同担保的形式 ★★、考点05合同保全的方式 ★★、考点06合同的转让 ★、考点07违约责任（素材未标星级）。最该拿分的三处是**合同的分类六组、合同效力四态（有效/无效/效力待定/可撤销）、担保与保全的数字（30日、1年、3个月、5年、20%）**。

**一句话串全章**：
> 合同是**平等主体之间设立、变更、终止民事权利义务关系的协议**（四大特征）→ 先按六组标准分类（双务单务、诺成实践、有名无名、要式不要式、主从）→ 一份合同的效力有**四种状态**：满足"主体资格+内容合法+意思表示真实+形式合法"即**有效**，反之落入**无效**（自始无效、溯及既往）、**效力待定**（待权利人追认）、**可撤销**（误解、胁迫、显失公平，须当事人主张）→ 合同怎么订：**要约+承诺**（要约到达生效、承诺送达合同成立）→ 怎么履行：全面/诚信/绿色三原则＋**同时/不安/先履行三种抗辩权**→ 怎么终止：履行、抵销、提存、免除、混同五种事由→ 为保履行设**担保**（保证、定金，定金不超20%、定金罚则与违约金二选一）→ 为防债务人财产流失设**保全**（代位权、撤销权）→ 当事人可变化：**合同的转让**（权利转让通知即可、义务转让须债权人同意）→ 不履行则担**违约责任**（违约金可增可减，不可抗力等可免责）。

## 二、知识点精讲

### 考点1 合同的法律特征及分类 ★★★

**（1）合同的概念和法律特征**

| 项目 | 主要内容 |
|---|---|
| 概念 | 平等主体的自然人、法人、其他组织之间**设立、变更、终止民事权利义务关系**的协议 |
| 法律特征 | ①合同当事人的**法律地位平等**；②合同是在当事人**自愿**基础上进行的民事法律行为；③合同是**双方或多方**的民事法律行为；④合同是关于民事权利义务关系的协议 |

> **辨析要点**：**非民事性质的行政关系中的权利义务不属于《民法典·合同编》的内容**；有关身份关系的协议，如**婚姻、收养、监护**等，也不由《民法典·合同编》调整。

**（2）合同的分类（六组）**

| 分类标准 | 分类 | 判别与举例 |
|---|---|---|
| 权利义务的分担方式 | **双务合同** | 各方相互享有权利、相互负有义务。例：买卖合同、租赁合同 |
| | **单务合同** | 一方只负义务、另一方只享权利。例：借用合同、赠与合同 |
| 成立是否以交付标的物为要件 | **诺成合同** | 双方**意思表示一致**即成立（不要物）。绝大多数合同 |
| | **实践合同** | 意思表示一致外，还需**实际交付标的物**才成立（要物）。例：保管合同、借用合同、定金合同 |
| 法律上是否规定名称 | **有名合同** | 法律有明文规定名称和规则（典型合同）。例：买卖、赠与、借款、保证、租赁 |
| | **无名合同** | 有名合同以外，只要不违背法律和社会公共利益即有效 |
| 成立是否需要特定形式 | **要式合同** | 需采取特定方式才成立（书面、口头、其他形式） |
| | **不要式合同** | 成立不需采用特定形式 |
| 合同间的主从关系 | **主合同** | 能独立存在。例：借款合同 |
| | **从合同（附属合同）** | 必须以主合同存在为前提。例：担保合同 |

> **易混提示**：借用合同**既是单务合同、又是实践合同**（两组分类中都出现）；定金合同是**实践合同**。

**妙记口诀：双务租单借赠；实践管借用；主从保定。**

### 考点2 合同的效力 ★★★

**（1）合同的效力与生效要件**

| 项目 | 主要内容 |
|---|---|
| 合同的效力 | 依法成立的合同对当事人具有**法律约束力**：一经成立即应按约履行，不得擅自变更或解除 |
| 成立 vs 生效 | 当事人**达成合意**即合同**成立**；符合法律规定的生效要件才**生效**、才受法律保护 |

**四大生效要件（口诀：主内合意 = 主体、内容、合法形式、意思真实）：**

| 生效要件 | 要点 |
|---|---|
| **主体资格** | 行为人具有相应**行为能力**：①**完全民事行为能力人**——满18周岁的自然人，或16～18周岁以自己劳动收入为主要生活来源者，可单独订立合同；②**限制行为能力人**——8周岁以上不满18周岁、不能完全辨认自己行为的精神病人，只能从事与其年龄智力精神状况相适应的活动；③**无民事行为能力人**——不满8周岁、不能辨认自己行为的精神病人，只能由法定代理人代理 |
| **内容合法** | 不得与法律的**强制性或禁止性规范**相抵触；不得违反社会公共利益、不得违背**公序良俗** |
| **意思表示真实** | 内心意愿**自由产生**并与所表达的意思**相一致**；有瑕疵者可能无效或可变更、撤销 |
| **形式合法** | 法律规定必须采用某种形式的（如须办理登记、审批的），不采用则合同不成立或不生效 |

**（2）无效合同**

| 项目 | 主要内容 |
|---|---|
| 定义 | 不具备生效要件、不能发生当事人所预期法律后果的合同 |
| 五种种类 | ①**无民事行为能力人**签订的；②违反法律、行政法规**强制性规定**的；③违背**公序良俗**的；④行为人与相对人以**虚假的意思表示**签订的；⑤行为人与相对人**恶意串通**损害他人合法权益的 |
| 效力 | **自始没有法律约束力**，**溯及既往**（从成立时起无效，非从被确认时起）；**部分无效**不影响其他部分效力；**不影响独立存在的争议解决条款效力** |

> **强制性规定的理解**：水果店违法出售种子，商店须担违法责任，但出于保护农户目的，**不宜认定该买卖种子合同无效**。
> **虚假意思表示（"虚伪表示"）**：甲为逃避债权人执行，假装把房屋卖给乙并办过户。①甲乙买卖合同属双方虚假行为，**无效**；②合同无效，乙虽办过户也**不能取得房屋所有权**。

**（3）效力待定合同**

| 项目 | 主要内容 |
|---|---|
| 定义 | 合同已成立，但不完全具备有效条件，是否生效须**权利人的承认**才能确定 |
| 种类一：主体行为能力欠缺 | 限制民事行为能力人订立的合同，经**法定代理人追认**后有效；但**纯获利益的合同**、与其年龄智力精神状况相适应的合同，不必追认 |
| 种类二：无权代理 | 无代理权、超越代理权或代理权终止后以被代理人名义订立的合同，未经被代理人追认，对被代理人不发生效力，由行为人担责。相对人可催告被代理人自收到通知起 **30日内**追认，未作表示**视为拒绝追认**；追认前**善意相对人有撤销权**（以通知方式作出） |

**（4）可撤销合同**

| 项目 | 主要内容 |
|---|---|
| 定义 | 合同已成立并生效，但因当事人**意思表示不真实**，可因一方行使撤销权而**自始不发生效力** |
| 种类 | ①基于**重大误解**；②一方**欺诈**、对方知道或应当知道的；③一方或第三人**胁迫**；④一方利用对方**危困状态、缺乏判断能力**致**显失公平** |
| 撤销权消灭的情形 | ①自知道或应知撤销事由起 **1年内**、**重大误解**当事人自知道或应知起 **3个月内**未行使；②受胁迫方自**胁迫行为终止之日起1年内**未行使；③明确表示或以行为放弃撤销权；④自**民事法律行为发生之日起5年内**未行使的，撤销权消灭 |
| 效力 | 一经撤销即消灭合同关系，效力**追溯到合同成立时**；撤销前均为**有效合同**，行使撤销权后才自始无效；当事人未请求的，法院或仲裁机构**不能主动撤销** |

**妙记口诀：可撤销合同的种类——误解胁迫失公平。**

### 考点3 合同的订立、履行及终止 ★★

当事人订立合同，采取**要约、承诺**方式。

**（1）要约**

| 项目 | 主要内容 |
|---|---|
| 要约（**发盘**） | 一方以订立合同为目的，就合同主要条款向另一方提出建议的意思表示。发出者为要约人，接受者为受要约人/相对人 |
| 要约邀请 | 希望他人向自己发出要约的意思表示 |
| 要约 vs 要约邀请 | ①**目的效果不同**：要约经承诺即合同成立；要约邀请只招来对方的要约，合同不成立；②**对象不同**：要约向**特定人**、要约邀请向**不特定人**；③**内容不同**：要约含**主要条款**、要约邀请不含；④**法律约束力不同**：要约经承诺即受约束，要约邀请无约束力 |
| 典型的要约邀请形式 | **拍卖公告、招标公告、招股说明书、债券募集办法、基金招募说明书、商业广告和宣传、寄送的价目表** |
| 要约的撤回 | 要约**到达受要约人时生效**；撤回通知须在要约到达**之前或与要约同时**到达，后于要约到达则不发生撤回效力 |
| 要约的撤销 | 要约生效后、受要约人发出承诺前可撤销。**不得撤销**的情形：①要约人确定了承诺期限或以其他形式明示不可撤销；②受要约人有理由认为不可撤销并已为履行做准备 |

**妙记口诀：寄送拍卖招标股，债基说明广宣传。**

**（2）承诺**

承诺是受要约人同意要约的意思表示。**承诺一经作出并送达要约人，合同即告成立。**

承诺必须具备的要件：①只能由**受要约人向要约人**作出；②必须在**有效期限**内作出（超期承诺除要约人及时通知有效外，为**新要约**）；③内容**必须与要约的内容一致**（**最实质的要件**）。

- **实质性内容**：合同标的、数量、质量、价款或报酬、履行期限、履行地点和方式、违约责任和解决争议方法等。
- 要约未定承诺期限的到达规则：**对话方式**作出的应**即时**承诺（另有规定除外）；**非对话方式**作出的承诺应在**合理期限**内到达。
- 受要约人对要约内容作**实质性变更**的，为**新要约**；作**非实质性变更**的，除要约人及时反对或要约表明不得变更外，该承诺有效，合同内容以承诺为准。
- **承诺的撤回**：撤回通知须在承诺通知到达要约人**之前或与之同时**到达。承诺已生效则合同已成立，不能再撤回，**因此承诺不存在撤销的可能**。

**（3）缔约过失责任**

| 项目 | 主要内容 |
|---|---|
| 定义 | **合同订立过程中**因一方过错给对方造成损失所应承担的民事责任 |
| 承担赔偿的情形 | ①**假借订立合同，恶意进行磋商**；②**故意隐瞒**重要事实或**提供虚假情况**；③其他违背**诚实信用原则**的行为 |
| 与违约责任的区别 | 缔约过失责任发生在**订立合同过程中**（合同尚未成立、无合同义务）；违约责任发生在**合同成立之后**（违反合同义务） |

**（4）合同履行的基本原则**

| 基本原则 | 具体内容 |
|---|---|
| **全面履行原则** | 严格按约定全面适当履行，四点要求：①**履行主体适当**（约定或法定须本人履行的不得由第三人代替）；②**履行标的适当**（未经债权人同意以其他方式代替实际履行为不适当）；③**履行期限适当**（届满后履行构成**迟延履行**）；④**履行地点和方式适当**——地点不明确时：**给付货币在接受货币一方所在地；交付不动产在不动产所在地；其他标的在履行义务一方所在地**；一次性履行不得分次，分期履行不得一次性，约定不明按**有利于实现合同目的的方式**履行 |
| **诚实信用原则** | 履行中应积极履行**通知义务、协助履行义务和保密义务** |
| **绿色原则** | 应**避免浪费资源、污染环境和破坏生态**，最大限度节约资源，树立可持续发展观念 |

**（5）双务合同履行中的抗辩权**

抗辩权是债务人在法定条件下对抗债权人请求权而**暂时拒绝履行债务**的权利。

| 抗辩权种类 | 具体内容 |
|---|---|
| **同时履行抗辩权** | 无约定先后履行顺序时，一方在对方未对等给付前有权拒绝履行；互负债务无先后顺序的应**同时履行** |
| **不安抗辩权** | **有先给付义务的当事人**，在有证据证明后给付人丧失或可能丧失履行能力时，可**中止**先给付履行。情形：①**经营状态严重恶化**；②**转移财产、抽逃资金**逃避债务；③**丧失商业信誉**；④其他丧失或可能丧失履行能力的情形 |
| **先履行抗辩权** | **履行顺序在后的一方**，在顺序在先方未履行或不适当履行时，有权拒绝其履行要求。它是一种**延期抗辩权**，只能使对方请求权延期，不能消灭请求权 |

**（6）合同的终止（消灭）——五种法律事实**

| 法律事实 | 具体内容 |
|---|---|
| **合同的履行** | 合同终止的**最正常、最主要的形式** |
| **抵销** | 条件：①双方**互有债务债权**；②给付债务为**同一种类**；③债务**均已到履行期**；④均为**可抵销债务**。**不得抵销的债务**：①相互提供劳务的；②与人身不可分离的；③法律禁止强制执行的；④侵权行为所生损害赔偿债务 |
| **提存** | 债务已届履行期时，将**无法给付的标的物交给提存机关**以消灭债务；提存后债务即告消灭 |
| **免除债务** | **债权人免除债务人债务**使合同关系消灭；部分或全部免除则债权债务部分或全部终止，但债务人在合理期限内拒绝的除外 |
| **混同** | **债权与债务同归于一人**使合同关系终止；与人的意志无关，属**事件**范畴。原因：①**概括承受**（主要原因，如企业合并）；②**特定承受**（债权让与或债务承担）。效力是合同关系**绝对消灭**，但损害第三人利益的除外 |

### 考点4 合同担保的形式 ★★

**（1）合同担保主要考点**

| 项目 | 主要内容 |
|---|---|
| 概念 | 根据法律规定或当事人约定的担保措施保证合同义务人履行义务的法律制度 |
| 法律特征 | ①明确的目的性；②**自愿性和平等性**；③**从属性** |
| 担保的形式 | **担保物权**都是合同担保形式，此外还包括**保证、定金** |
| 保证 | 保证人与债权人约定，债务人不履行债务时保证人按约履行债务或承担责任；保证人须是有代偿能力的法人、其他组织或公民。**国家机关和学校、幼儿园、医院等以公益为目的的事业单位、社会团体以及企业法人的分支机构、职能部门均不得作为保证人** |
| 一般保证 vs 连带责任保证 | **一般保证**：只对债务人不履行承担**补充责任**；主合同纠纷未经审判/仲裁并对债务人财产强制执行仍不能履行前，对债权人可**拒绝承担保证责任**。**连带责任保证**：债务人不履行时保证人与债务人承担**连带责任**。**约定不明确或没有约定的，按一般保证承担保证责任** |
| 定金 | 一方为保证履行，在订立时或履行前给付对方一定金钱的担保方式；履行债务后定金应**抵作价款或收回**；担保作用通过**定金罚则**体现。**定金合同是实践合同，从实际交付定金之日起生效** |

**（2）定金罚则和违约金**

| 项目 | 主要内容 |
|---|---|
| 定金罚则 | **给付定金一方不履行债务的，无权要求返还定金；收受定金一方不履行的，应双倍返还定金**。**定金数额由当事人约定，但不得超过主合同标的额的20%**；超过部分**无效**（只认定20%以内部分的效力） |
| 定金罚则与违约金 | **联系**：都使违约方丧失一定金钱利益，都能督促积极履行合同。**区别**：①**交付时间**——定金于履行前交付、违约金只在违约后交付；②**效力**——定金有证明合同成立和预先给付的效力，违约金没有；③**性质**——定金主要起担保作用，违约金是违约责任的一种形式。**定金罚则与违约金不能并用，二者只能选择其一适用** |

### 考点5 合同保全的方式 ★★

合同保全是为防止债务人财产不当减少致债权实现受危害，而设置的保全债务人责任财产的法律制度。

法律特征：①它是**债的对外效力**的体现，也是**合同相对性原则的例外**；②主要发生在**合同有效成立期间**；③基本方法是**代位权和撤销权**的行使。

**（1）债权人的代位权**

债务人**怠于行使**其债权对债权人造成损害时，债权人为保全债权，享有向法院请求**以自己的名义**行使债务人权利的权利。行使范围以债权人的**到期债权**为限，相对人对债务人的抗辩可向债权人主张。

成立条件：①债务人对第三人享有权利；②债务人怠于行使且可能危及债权人债权；③债权人对债务人的债权已届清偿期而未获清偿；④债务人对第三人的权利为**非专属权利和可强制执行的权利**。

> 代位权必须通过**诉讼方式**行使，范围以债权人债权为限，必要费用由**债务人**负担。经法院审理认定代位权成立的，由第三人向债权人履行清偿义务，相应的债权债务关系消灭。

**（2）债权人的撤销权**

当债务人**减少其财产的行为**危害债权实现时，债权人为保全债权请求法院撤销该行为的权利。情形：
①债务人以**放弃债权、放弃债权担保、无偿转让财产**等无偿处分财产权益，或**恶意延长其到期债权的履行期限**，影响债权实现的；
②债务人以**明显不合理的低价转让财产、以明显不合理的高价受让财产或为他人债务提供担保**，影响债权实现，且相对人知道或应当知道该情形的。

> 行使范围以债权人债权为限，必要费用由**债务人**负担。撤销权自债权人知道或应当知道撤销事由起 **1年内**行使；**自债务人的行为发生之日起5年内**未行使的消灭。被撤销的行为**自始没有法律约束力**。

### 考点6 合同的转让 ★

合同的转让是当事人依法将合同权利义务转让给他人的合法行为。**合同的转让不改变合同的内容**，只发生当事人的变化。

| 情形 | 主要内容 |
|---|---|
| **合同权利的转让** | 债权人将全部或部分债权转让给第三人。**不得转让**的情形：①根据债权性质（人身性质、基于特定信用的债权）；②按当事人约定；③依照法律规定。约定**非金钱债权**不得转让的，不得对抗**善意第三人**；约定**金钱债权**不得转让的，不得对抗**第三人**。债权人转让债权，**未通知债务人的，该转让对债务人不发生效力**；转让通知不得撤销（经受让人同意除外）。转让发生在**债权人和第三人之间**，**不需要债务人同意** |
| **合同义务的转让（债务的承担）** | 债务人将债务全部或部分转移给第三人，**应当经债权人同意**——**取得债权人同意是有效条件之一**。债务人或第三人可催告债权人在合理期限内同意，**债权人未作表示的，视为不同意** |
| **合同权利义务的概括转让** | 一方将权利义务一并转让、第三人**概括承受**。分为**意定概括转让**（当事人转让协议）和**法定概括转让**（依法律规定）。一方经对方同意，可将合同中的权利义务一并转让给第三人 |

> **对照记忆**：权利转让**通知即可**（不需债务人同意）；义务转让**须债权人同意**；概括转让**须对方同意**。

### 考点7 违约责任

**（1）违约金的概念及法律特征**

| 法律特征 | 具体内容 |
|---|---|
| ①约定性 | 当事人可约定违约金；**没有约定违约金则不产生违约金的责任形式** |
| ②可调整性 | 约定的违约金**低于**造成的损失的，可请求法院或仲裁机构予以**增加**；**过分高于**损失的，可请求予以**适当减少** |
| ③事后性 | **只有在违约行为发生后才生效**；履行了合同义务则不发生支付违约金问题 |

**（2）违约的免责事由**

| 免责事由 | 具体内容 |
|---|---|
| **不可抗力** | **不能预见、不能避免并不能克服**的客观情况；**仅指客观情况**，属**事件**范畴，不属于民事主体行为；具**不可预见性、不可避免和不可克服性**。免责应根据不可抗力**影响范围的大小**确定。**当事人迟延履行后发生不可抗力的，不免除违约责任**；对方应采取适当措施防止损失扩大，未采取致损失扩大的，**不得就扩大的损失要求赔偿** |
| **免责条款** | 根据**意思自治和合同自由原则**可约定免责条款。**下列免责条款无效**：①造成对方**人身伤害**的；②因**故意或重大过失**造成对方**财产损失**的。违反法律或社会公共利益的免责条款不发生免责效力 |

## 五、高频考点速记卡

1. **Q：合同的概念？** A：平等主体的自然人、法人、其他组织之间**设立、变更、终止民事权利义务关系**的协议。

2. **Q：哪些协议不由《民法典·合同编》调整？** A：非民事性质的**行政关系**中的权利义务；**婚姻、收养、监护**等身份关系协议。

3. **Q：借用合同属于哪几类？** A：**单务合同**且**实践合同**。

4. **Q：实践合同（要物合同）有哪些？** A：**保管合同、借用合同、定金合同**。

5. **Q：合同的四大生效要件？** A：**主体资格（行为能力）、内容合法、意思表示真实、形式合法**（口诀：主内合意）。

6. **Q：完全民事行为能力人年龄？** A：满**18周岁**；或**16～18周岁**以自己劳动收入为主要生活来源者。限制行为能力人：**8周岁以上不满18周岁**；无民事行为能力人：**不满8周岁**。

7. **Q：无效合同的五种种类？** A：无民事行为能力人订立、违反**强制性规定**、违背**公序良俗**、**虚假意思表示**、**恶意串通**损害他人。

8. **Q：无效合同的效力起算点？** A：**自始没有法律约束力、溯及既往**，从合同成立时起无效（非从被确认时起）。

9. **Q：无权代理，相对人催告追认期限？未表示如何？** A：**30日内**追认，被代理人未表示**视为拒绝追认**；追认前**善意相对人有撤销权**。

10. **Q：可撤销合同的四种情形？** A：**重大误解、欺诈、胁迫、显失公平**（口诀：误解胁迫失公平）。

11. **Q：撤销权的三组时限？** A：一般**1年**、重大误解**3个月**、受胁迫自胁迫终止起**1年**、最长自行为发生起**5年**。

12. **Q：可撤销合同法院能否主动撤销？** A：**不能**，须当事人请求。

13. **Q：要约何时生效？可否撤回撤销？** A：**到达受要约人时生效**；撤回通知须在要约**之前或同时**到达；生效后承诺前可撤销，但确定承诺期限/明示不可撤销、或受要约人已为履行做准备的**不得撤销**。

14. **Q：典型的要约邀请？** A：拍卖公告、招标公告、招股说明书、债券募集办法、基金招募说明书、商业广告和宣传、寄送的价目表（口诀：寄送拍卖招标股，债基说明广宣传）。

15. **Q：承诺最实质的要件？** A：内容**必须与要约的内容一致**。实质性变更为**新要约**。

16. **Q：承诺有无撤销？** A：可**撤回**（到达前或同时），但承诺生效合同即成立，**不存在撤销**。

17. **Q：三种抗辩权分别谁行使？** A：同时履行抗辩权——无先后顺序时未获对等给付方；不安抗辩权——**有先给付义务方**；先履行抗辩权——**履行顺序在后方**。

18. **Q：合同终止的五种法律事实？** A：**履行、抵销、提存、免除债务、混同**。其中履行是最主要形式，混同属**事件**。

19. **Q：哪些主体不得作保证人？** A：**国家机关、以公益为目的的事业单位社会团体（学校、幼儿园、医院等）、企业法人的分支机构和职能部门**。

20. **Q：保证方式约定不明按什么承担？** A：按**一般保证**承担保证责任。

21. **Q：定金数额上限？违约后果？** A：不超过主合同标的额**20%**（超出无效）；给付方违约无权返还、收受方违约**双倍返还**。

22. **Q：定金与违约金能否并用？** A：**不能并用，二者只能选其一适用**。

23. **Q：合同保全的两种方法？** A：**代位权和撤销权**；它是债的对外效力体现、**合同相对性原则的例外**。

24. **Q：代位权、保全撤销权的费用谁负担？** A：均由**债务人**负担。

25. **Q：债权转让与债务承担谁需同意？** A：债权转让**只需通知债务人**（不需其同意）；债务承担**须经债权人同意**。

26. **Q：违约金能否调整？** A：低于损失可请求**增加**，过分高于损失可请求**适当减少**。

27. **Q：不可抗力的三性？迟延履行后发生不可抗力？** A：**不能预见、不能避免、不能克服**；**当事人迟延履行后发生不可抗力的，不免除违约责任**。

28. **Q：哪些免责条款无效？** A：造成对方**人身伤害**的；因**故意或重大过失**造成对方**财产损失**的。

## 六、典型真题

> **说明**：本章**素材未附任何带年份的真题原文**，按内容纪律不编造真题。以下为**按素材知识点自编的巩固练习**，每题均标注"**自编**"，仅供检验记忆，答案与解析严格依据素材原文，不引入素材外的数字或法条。

**【自编·单选】下列合同中，属于实践合同（要物合同）的是（　）。**
A. 买卖合同　B. 租赁合同　C. 保管合同　D. 借款合同
**答案：C**
**解析**：实践合同需一方实际交付标的物才成立，素材列举**保管合同、借用合同、定金合同**。买卖、租赁属诺成合同。

**【自编·多选】合同的生效要件包括（　）。**
A. 主体具有相应行为能力　B. 内容合法　C. 意思表示真实　D. 形式合法　E. 已实际履行
**答案：ABCD**
**解析**：四大生效要件为主体资格、内容合法、意思表示真实、形式合法（口诀"主内合意"）；是否实际履行不属生效要件。

**【自编·单选】关于无效合同的效力，说法正确的是（　）。**
A. 从被确认无效时起无效　B. 自始没有法律约束力、溯及既往　C. 部分无效必导致全部无效　D. 争议解决条款随之无效
**答案：B**
**解析**：无效合同自始没有法律约束力、溯及既往；部分无效不影响其他部分；不影响独立存在的争议解决条款效力。

**【自编·单选】无权代理订立的合同，相对人催告后被代理人在30日内未作表示的，视为（　）。**
A. 追认　B. 拒绝追认　C. 合同有效　D. 效力待定继续
**答案：B**
**解析**：被代理人自收到通知起30日内未作表示的，**视为拒绝追认**。

**【自编·多选】下列属于可撤销合同情形的有（　）。**
A. 重大误解　B. 欺诈　C. 胁迫　D. 显失公平　E. 恶意串通损害他人
**答案：ABCD**
**解析**：可撤销四情形为重大误解、欺诈、胁迫、显失公平；恶意串通损害他人属**无效**合同。

**【自编·单选】下列属于要约邀请的是（　）。**
A. 寄送的价目表　B. 承诺　C. 已到达受要约人的要约　D. 反要约
**答案：A**
**解析**：拍卖公告、招标公告、招股说明书、债券募集办法、基金招募说明书、商业广告和宣传、寄送的价目表均为要约邀请。

**【自编·单选】双务合同中有先给付义务的一方，在有证据证明后给付人可能丧失履行能力时，可行使（　）。**
A. 同时履行抗辩权　B. 不安抗辩权　C. 先履行抗辩权　D. 撤销权
**答案：B**
**解析**：不安抗辩权由**有先给付义务的当事人**行使，可中止先给付履行。

**【自编·多选】下列可导致合同终止的法律事实有（　）。**
A. 履行　B. 抵销　C. 提存　D. 免除债务　E. 混同
**答案：ABCDE**
**解析**：合同终止的五种法律事实为履行、抵销、提存、免除债务、混同。

**【自编·单选】保证合同当事人对保证方式没有约定或约定不明确的，按（　）承担保证责任。**
A. 连带责任保证　B. 一般保证　C. 补充责任与连带责任平摊　D. 不承担
**答案：B**
**解析**：约定不明或没有约定的，按**一般保证**承担保证责任。

**【自编·单选】定金的数额不得超过主合同标的额的（　）。**
A. 10%　B. 15%　C. 20%　D. 30%
**答案：C**
**解析**：定金数额由当事人约定，但不得超过主合同标的额的**20%**，超出部分无效。

**【自编·单选】关于合同转让，说法正确的是（　）。**
A. 债权转让须经债务人同意　B. 债务承担须经债权人同意　C. 债权转让不需通知债务人　D. 概括转让不需对方同意
**答案：B**
**解析**：债务承担须经债权人同意；债权转让不需债务人同意但须通知债务人，否则对债务人不生效；概括转让须经对方同意。

**【自编·单选】关于不可抗力，说法正确的是（　）。**
A. 迟延履行后发生不可抗力仍可全部免责　B. 不可抗力是不能预见、不能避免并不能克服的客观情况　C. 不可抗力属于民事主体的行为　D. 发生不可抗力后对方无须采取措施
**答案：B**
**解析**：不可抗力具三性且属**事件**范畴、非民事主体行为；**迟延履行后发生不可抗力的不免除违约责任**；对方应采取适当措施防止损失扩大。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把身份关系协议（婚姻、收养、监护）当合同 | 这些**不由《民法典·合同编》调整**；行政关系权利义务也不属于 |
| 2 | 把借用、赠与合同归为双务合同 | 二者是**单务合同**；借用合同还同时是**实践合同** |
| 3 | 混淆"合同成立"与"合同生效" | **达成合意即成立**；符合生效要件才**生效**、受保护 |
| 4 | 把无效合同当成"从被确认时起无效" | 无效合同**自始无效、溯及既往**，从成立时起就没有约束力 |
| 5 | 把"恶意串通损害他人"归入可撤销 | 它属**无效**合同；可撤销只有误解、欺诈、胁迫、显失公平 |
| 6 | 撤销权时限记混 | 一般**1年**、重大误解**3个月**、最长自行为发生**5年**；无权代理催告为**30日** |
| 7 | 以为法院可主动撤销可撤销合同 | 须**当事人请求**，法院/仲裁机构**不能主动撤销**；无效合同才可主动认定 |
| 8 | 把要约邀请当要约 | 要约向**特定人**、含主要条款、有约束力；要约邀请向**不特定人**、不含主要条款 |
| 9 | 以为承诺可以撤销 | 承诺可**撤回**（到达前或同时），但生效即合同成立，**不存在撤销** |
| 10 | 把缔约过失责任当违约责任 | 缔约过失在**订立过程中**（合同未成立）；违约责任在**合同成立之后** |
| 11 | 弄反不安抗辩权与先履行抗辩权的主体 | 不安抗辩权——**先给付义务方**；先履行抗辩权——**履行顺序在后方** |
| 12 | 认为公益事业单位、企业分支机构可作保证人 | 国家机关、公益事业单位社会团体、企业法人分支机构和职能部门**均不得作保证人** |
| 13 | 保证方式约定不明按连带责任 | 约定不明或无约定按**一般保证** |
| 14 | 把定金和违约金并用 | 二者**只能选其一适用**，不能并用；定金超20%部分无效 |
| 15 | 认为债权转让需债务人同意 | 债权转让**不需债务人同意**，但**须通知**债务人；债务承担才须债权人同意 |
| 16 | 以为迟延履行后遇不可抗力也免责 | **迟延履行后发生不可抗力的，不免除违约责任** |
| 17 | 把混同当成"行为" | 混同与人的意志无关，属**事件**范畴，导致合同关系**绝对消灭** |

C. 变更履行期限
D. 对无关紧要的包装方式作出调整

@answer D
@explanation 承诺对要约内容作实质性变更的为新要约；实质性内容包括合同标的、数量、质量、价款或报酬、履行期限、履行地点和方式、违约责任和解决争议方法等，故A、B、C均属实质性变更，构成新要约；对包装方式作无关紧要的调整属非实质性变更，除要约人及时反对或要约表明不得变更外该承诺有效，故选D。
