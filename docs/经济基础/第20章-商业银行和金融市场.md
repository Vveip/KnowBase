## 二、知识点精讲

### 考点1 商业银行的内涵 ★

**核心概念**

- 商业银行**又称为存款货币银行**，以经营工商业存款、放款为主要业务，并为客户提供多种金融服务，是**金融机构体系中最为核心的部分**。
- **性质**：商业银行是最典型的银行，是以**盈利为目的**、主要以吸收存款和发放贷款形式为工商企业提供融资服务、并办理结算业务的金融企业。
- 性质三概括：**经营目标盈利化；经营行为市场化；业务活动多样化。**

**三把"标尺"辨身份**

| 比较对象 | 相同点 | 关键区别 |
|---|---|---|
| 与一般工商企业 | 都是企业 | 商业银行是**金融企业**，是承担资金融通职能的企业 |
| 与中央银行、政策性银行 | 都从事银行业务，具备银行业的基本特征 | 中央银行与政策性银行**不以盈利为目的**，商业银行以盈利为目的 |
| 与非银行金融机构 | —— | 非银行金融机构经营范围很窄，经营不完全的信用业务，或不以银行信用方式融通资金；商业银行经营范围广泛，是**唯一能够面向公众吸收活期存款**的金融机构 |

**逻辑链**

```
商业银行 = 存款货币银行 = 金融体系中最为核心的部分
    ↓ 定性三句话
盈利为目的 + 吸收存款/发放贷款 + 办理结算 = 金融企业
    ↓ 辨身份三问
是企业吗？是（但属金融企业）
为盈利吗？盈（央行、政策性银行不盈）
能收活期存款吗？只有商业银行能
```

**速记口诀**：**「存贷结算为盈利，金融企业最典型；央行政策不图利，活期存款我独家。」**

### 考点2 商业银行的职能与组织形式 ★

**三大职能**

| 职能 | 内容 | 地位 |
|---|---|---|
| **信用中介** | 吸收存款，发放贷款，发挥着**化货币为资本**的作用 | **最基本的职能** |
| **支付中介** | 接受企业委托，办理与货币运动有关的技术性业务，如汇兑、非现金结算；使银行成为企业的总会计、总出纳，成为社会的总账房 | —— |
| **信用创造** | 发行信用工具，满足流通和支付手段需求，并产生信用扩张 | —— |

> 注：本素材仅列上述三项职能；「金融服务」职能在本素材中未单独展开（**素材未覆盖**）。

**组织形式（两套分类标准，别记混）**

| 分类标准 | 类型 | 典型代表 |
|---|---|---|
| 按机构设置 | 单一银行制 | 美国 |
| | 总分行制 | 大部分国家 |
| 按业务经营范围 | 专业化银行制（分业经营） | —— |
| | 综合化银行制（全能银行制） | —— |

> 注：持股公司制、连锁银行制在本素材中未涉及（**素材未覆盖**）。

**逻辑链**

```
职能：信用中介（最基本：吸存放贷、化货币为资本）
    → 支付中介（汇兑、非现金结算，社会总账房）
    → 信用创造（发行信用工具、信用扩张）
组织形式：机构设置 → 单一银行制（美国）／总分行制（大部分）
          业务范围 → 专业化银行制（分业）／综合化银行制（全能）
```

**速记口诀**：**「中介最基本，支付当账房，创造发工具；设机构单一总分，管业务专业综合。」**

### 考点3 商业银行的主要业务 ★★★★★（本章第一重点）

**总框架**

```
商业银行三大业务
├── 负债业务（资金来源业务）：自有资金 + 吸收的外来资金
├── 资产业务（资金运用业务）：票据贴现 + 贷款业务 + 投资业务
└── 中间业务（服务收费业务）：不用自己的资金，收取手续费
```

**（1）负债业务——资金来源业务**

| 构成 | 内容 |
|---|---|
| **自有资金** | 成立时发行股票所筹集的股本以及公积金、未分配利润，这部分称为**权益资本** |
| **吸收的外来资金** | 主要是吸收存款、向中央银行借款、从同业拆借市场拆借、发行金融债券、从国际货币市场借款等，**其中以吸收存款为主** |

- **吸收存款**：活期存款、定期存款、储蓄存款、**存款业务创新**（如可转让支付命令账户）
- **借款业务**：再贴现或向中央银行借款、同业拆借、发行金融债券、国际货币市场借款、**结算过程中的短期资金占用**

**（2）资产业务——资金运用业务（获得收益的主要业务活动）**

| 构成 | 要点 |
|---|---|
| **票据贴现** | 形式上是票据的买卖，**实际上是信用业务** |
| **贷款业务** | 在银行资产中的比重**一般排在首位** |
| **投资业务** | 许多国家规定只允许做债券业务，不允许做股票买卖，或允许银行以其自有资金和盈余的很小比例投资于此 |

**贷款三分类（选择高频）**

| 分类标准 | 类型 |
|---|---|
| 按归还期限 | 短期贷款（1 年以内）／中期贷款（1~5 年）／长期贷款（5 年以上） |
| 按贷款条件 | 信用贷款／担保贷款（保证贷款、抵押贷款、质押贷款） |
| 按用途 | 资本贷款／商业贷款／消费贷款 |

**（3）中间业务——不用自己钱的业务**

| 要点 | 内容 |
|---|---|
| 定义 | 商业银行**不使用自己的资金**而为客户办理支付和其他委托事项，并从中**收取手续费**的业务 |
| 别称 | **无风险业务**；商业银行作为"**支付中介**"提供的金融服务 |
| 构成 | 结算业务（转账结算/非现金结算）、信托业务（资金信托、财产信托）、租赁业务（融资性租赁、经营性租赁）、代理业务（如受财政部门委托代理发行和兑付国债）、咨询业务 |

**速记口诀**：**「负债来源自有加外来，存款为主；资产贴现贷款投资，贷款居首；中间不花自己钱，只收手续费。」**

### 考点4 商业银行的经营管理 ★

**三原则**

| 原则 | 基本含义 | 相关关系 |
|---|---|---|
| **盈利性** | 注重资产业务的盈利性，是商业银行业务经营**必须考虑的因素** | 与流动性**负相关**；与安全性**负相关** |
| **流动性** | 两层含义：①必须保有一定比例的现金资产或其他容易变现的资产；②取得现款的能力 | 与盈利性负相关；与安全性**正相关** |
| **安全性** | 在放款和投资等业务经营过程中能够**按期收回本息**，特别是要**避免本金受损** | 与盈利性负相关；与流动性正相关 |

**逻辑链**

```
三性原则"两负一正"
盈利性 ←——负相关——→ 流动性
盈利性 ←——负相关——→ 安全性
流动性 ←——正相关——→ 安全性

推论：想多盈利 → 资金投向收益高的中长期贷款/证券投资 → 流动性与安全性下降
      想保流动 → 资金停在现金或低收益短期投资 → 盈利水平低
```

**速记口诀**：**「盈利安全对着干，盈利流动对着干，流动安全手拉手。」**

> 注：本素材只讲经营管理的**原则**，未涉及经营管理的方法体系（资产管理、负债管理、资产负债综合管理）及量化指标（**素材未覆盖**，详见第四节）。

### 考点5 存款保险制度 ★★★★★（五星高频）

**定义**：存款保险制度又称**存款保障制度**，指存款类金融机构根据其吸收存款的数额，按规定的保费率向存款保险机构投保，当存款机构发生经营危机导致无法满足存款人提款要求时，由存款保险机构向存款人偿付被保险存款，从而保护存款人利益，维护银行信用，稳定金融秩序的一种制度安排。

| 项目 | 内容 |
|---|---|
| **组织形式** | ①由政府建立存款保险机构（美国、英国、加拿大）；②由政府和银行界共同建立（日本、比利时）；③在政府支持下由银行同业联合建立（德国、法国、荷兰） |
| **纳入** | 凡吸收存款的银行业金融机构，包括商业银行（含外商独资银行和中外合资银行）、农村合作银行、农村信用合作社等；被保险存款**既包括人民币存款，也包括外币存款** |
| **不纳入** | 参照国际惯例，**外国银行在中国的分支机构以及中资银行海外分支机构的存款**原则上不纳入；金融机构**同业存款**、投保机构**高级管理人员在本投保机构的存款**及存款保险基金管理机构规定不予保险的其他存款除外 |
| **偿付限额** | **每个人、每家银行分别**计算：**50 万元以内全额赔付**；超过 50 万元的部分，从该投保机构清算财产中受偿 |
| **基金来源** | ①保费；②清算中分配的财产；③基金收益；④其他 |
| **基金运用** | ①存央行；②投资政府债券、中央银行票据、**信用等级较高**的金融债券及其他高等级债券；③国务院批准的其他形式 |
| **偿付形式** | ①存款保险基金管理机构担任投保机构的接管组织；②实施被撤销投保机构的清算；③人民法院裁定受理对投保机构的破产申请；④经国务院批准的其他情形 |

**逻辑链**

```
赔付判断三步
① 机构是否参保？—— 吸收存款的银行业金融机构
② 存款是否被保险？—— 人民币/外币存款均可；
   排除：外资在华分支存款、中资海外分支存款、同业存款、高管在本机构存款
③ 数额：同一存款人在同一投保机构所有账户本息合计
   ≤ 50万 → 全额赔付
   > 50万 → 赔50万，超出部分从该机构清算财产中受偿
```

**速记口诀**：**「外资在华不参保，中资出海不算咱；同业高管请出去，每人每行五十万。」**

### 考点6 金融市场运行机理（素材未标星级）

- 货币资金在使用方面总是存在着"**时间差**"和"**空间差**"。
- 资金只有在运动过程中才能够创造价值，并使价值增值，从而产生**资金融通的客观要求**。

```
时间差 + 空间差 → 资金运动创造价值并增值 → 资金融通的客观要求 → 金融市场
```

**速记口诀**：**「时差加空间，资金要流动，融通客观有。」**

---

### 考点7 金融市场效率

- **定义**：金融市场实现**金融资源配置**功能的程度。
- **两方面内容**：①金融市场以**最低交易成本**为资金需求者提供金融资源的能力；②金融市场的资金需求者**使用金融资源向社会提供有效产出**的能力。
- **资本的本质特征：追逐利润。** 高效率的金融市场能将社会有限的金融资源配置到效益最好的企业及行业，进而创造最大产出，实现社会效益的最大化。
- 金融市场效率的发挥**以资本的合理运动为前提**。

```
资本逐利 → 流向利润率较高的部门/企业
        → 这些部门正是前景较佳、效益较好、有发展潜力的 → 优化资源配置
（前提：资本的合理运动）
```

**速记口诀**：**「效率看两力：低成本给资源，用资源出产出；资本本姓利，运动才配置。」**

### 考点8 有效市场理论 ★★

**法玛三分类**

| 类型 | 效率程度 | 对证券价格变动没有任何影响的信息 |
|---|---|---|
| **弱型效率** | 证券市场效率的**最低程度** | 有关证券的**历史资料** |
| **半强型效率** | 证券市场效率的**中等程度** | 有关证券**公开发表的资料** |
| **强型效率** | 证券市场效率的**最高程度** | 有关证券的**所有相关信息，包括公开发表的资料以及内幕信息** |

**逻辑链**

```
信息集由小到大：历史资料 ＜ 公开发表资料 ＜ 所有信息（含内幕）
效率由低到高：弱型效率 ＜ 半强型效率 ＜ 强型效率
```

**速记口诀**：**「历史弱、公开半、内幕强。」**

### 考点9 金融市场的结构 ★★★（真题最集中）

**七个子市场**：同业拆借市场、票据市场、债券市场、股票市场、投资基金市场、外汇市场、金融期货市场（金融期权市场）。

| 类型 | 子市场 | 主要功能 |
|---|---|---|
| **货币市场** | 同业拆借市场、票据市场、短期债券市场等 | 供应短期货币资金，主要解决短期内资金余缺的融通问题 |
| **资本市场** | 股票市场、长期债券市场、投资基金市场等 | 供应长期货币资金，主要解决投资方面的资金需要 |

**各子市场要点**

| 子市场 | 核心要点 |
|---|---|
| **同业拆借市场** | 金融机构之间以货币借贷方式进行短期资金融通的市场；资金主要用于弥补短期资金不足、票据清算的差额以及解决临时性资金短缺需求；特点：**期限短、流动性高、利率敏感性强、交易方便**；典型利率：伦敦银行同业拆借利率 |
| **票据市场** | 以各种票据为媒介进行资金融通的市场；**一级票据市场：承兑和签发**；**二级票据市场：直贴、转贴现和再贴现** |
| **债券市场** | 发行和买卖债券的场所，**直接融资市场**；**既具有货币市场属性，又具有资本市场属性**；按组织形式分场内交易市场和场外交易市场 |
| **股票市场** | 发行市场（一级市场）＋流通市场（二级市场）；场内市场（深交所、上交所、北交所）＋场外市场（新三板、区域股权交易市场） |
| **投资基金市场** | **利益共享、风险共担**的集合投资方式，优势是**专家理财**；美国称"共同基金"、英国称"单位信托基金"、日本称"证券投资信托基金" |
| **外汇市场** | 由中央银行、外汇银行、外汇经纪商和客户组成的买卖外汇的交易关系的总和；**不能简单归入货币市场或资本市场** |
| **金融期货/期权市场** | 金融期货：专门进行金融期货交易，具有**锁定和规避金融市场风险、实现价格发现**的功能；金融期权：买方交付一定的期权费用后，取得在特定时间内、按协议价格买进或卖出一定数量的证券的**权利** |

**票据三分**

| 票据 | 定义要点 |
|---|---|
| **汇票** | 出票人签发的，**委托付款人**在见票时或者在指定日期，无条件支付确定的金额给收款人或持票人的票据。按出票人分**商业汇票和银行汇票**；商业汇票按承兑人分**商业承兑汇票**（企业承诺到期兑付）和**银行承兑汇票**（银行承诺到期兑付，是银行信用和商业信用的结合）。商业汇票有**三个当事方：付款人、收款人和承兑人** |
| **本票** | 出票人签发、**承诺自己**在见票时，无条件支付确定的金额给收款人或持票人 |
| **支票** | 委托办理支票存款业务的银行或者其他金融机构在见票时，无条件支付确定的金额给收款人或持票人 |

**必须跟进的细节点**

- **电子商业汇票**：出票人以数据电文形式制作的票据，分电子商业承兑汇票和电子银行承兑汇票。特点：①票据记载和流通全部电子化；②票据操作通过银行网络或财务公司网络渠道进行；③电子签名取代签章；④票据信息存储在中国票据业务系统内；⑤票据信息通过网络渠道查询。
- **上海票据交易所**：2016 年 12 月 8 日开业运营，由中国人民银行批准设立的全国统一的票据交易平台，具备票据报价交易、登记托管、清算结算、信息服务等功能，承担中央银行货币政策再贴现操作等政策职能。
- **债券按期限**：短期债券（1 年期以内）／中期债券（1 年至 10 年）／长期债券（10 年以上）。**短期政府债券的流动性在货币市场中是最高的**，几乎所有的金融机构都参与这个市场的交易；其特点：违约风险小、流动性强、面额小、收入免税。
- **贴标债券**：在债券上附加特定的标识或标签，用以标识债券的特殊属性和特点；与高质量发展领域相关的贴标债券快速增长，目前有**绿色债券、乡村振兴债券、一带一路债券、科技创新债券**。
- **股票市场结构**：我国所说的**上市公司是指在股票交易所挂牌交易的企业**；在场外交易市场挂牌的企业**不属于上市公司**。股票发行市场的主要参与者：上市公司（资金需求者）、投资者（资金供给者）、中介机构（证券公司、会计师事务所、律师事务所等）。
- **投资基金**是一种金融中介机构：通过发行基金单位，集中投资者的资金，由**基金托管人托管，基金管理人管理和运用**，从事股票、债券、外汇、货币等金融工具投资。

**速记口诀**：**「七子市场要记全，拆借票据短债券属货币，股票长债基金属资本；外汇两边都不站，期货期权管风险。」**

## 四、公式与计算（本章计算题重点）

**本章计算题定位**：在本章素材中，涉及数字计算的真题仅一类——**存款保险本息赔付**（2023 补）。其余常见计算考点本素材均未覆盖（见下表）。

### 计算点1 存款保险本息赔付（素材覆盖）

**规则**：本息 ＝ 本金 ×（1＋利率）；同一存款人在同一投保机构所有账户的本息合计，50 万元以内全额赔付，超过 50 万元部分从该投保机构清算财产中受偿；限额**按人、按行分别计算**。

**例题 1（2023 补真题）**：A 在甲银行存款 49.5 万元，利率 2%；A 在乙银行存款 10 万元，利率 3%。一年后甲银行由存款保险机构接管，同时乙银行向法院提起破产申请。此时 A 提出提取存款，应由存款保险机构赔偿的金额为（　）。
A. 50 万元　B. 50.49 万元　C. 60 万元　D. 60.3 万元

**演算过程**：

```
甲银行本息：49.5 ×（1 + 2%）= 49.5 × 1.02 = 50.49（万元）
   → 超过 50 万 → 获赔 50 万元
乙银行本息：10 ×（1 + 3%）= 10 × 1.03 = 10.3（万元）
   → 未超 50 万 → 全额获赔 10.3 万元
合计赔付：50 + 10.3 = 60.3（万元）
```

**答案：D**。题眼在于"每家银行分别"计算限额，两家银行不能合并抵扣。

**例题 2（变式演算，按上述素材规则自编，帮助理解限额规则）**：某人分别在丙、丁两行各存款 60 万元，利率均为 1.5%。一年后两行均由存款保险机构接管。该人合计可获赔多少？

```
每行本息：60 ×（1 + 1.5%）= 60.9（万元）＞ 50 万
每行获赔：50 万元
合计获赔：50 × 2 = 100（万元）
（每行超出的 10.9 万元，分别从各投保机构清算财产中受偿）
```

## 五、高频考点速记卡

1. **Q：商业银行的性质？**
   A：最典型的银行，以盈利为目的，以吸收存款和发放贷款形式为工商企业提供融资服务并办理结算业务的金融企业；概括为经营目标盈利化、经营行为市场化、业务活动多样化。

2. **Q：商业银行最基本的职能？**
   A：信用中介——吸收存款、发放贷款，发挥化货币为资本的作用。

3. **Q：商业银行是唯一能干什么的金融机构？**
   A：面向公众吸收活期存款。

4. **Q：商业银行组织形式的两套分类？**
   A：按机构设置分单一银行制（美国）、总分行制（大部分国家）；按业务经营范围分专业化银行制（分业经营）、综合化银行制（全能银行制）。

5. **Q：负债业务的两大构成？**
   A：自有资金（股本、公积金、未分配利润，称权益资本）＋吸收的外来资金（以吸收存款为主）。

6. **Q：吸收存款的方式有哪些？**
   A：活期存款、定期存款、储蓄存款、存款业务创新（如可转让支付命令账户）。

7. **Q：资产业务的三大构成？**
   A：票据贴现、贷款业务（在银行资产中占比一般居首）、投资业务。

8. **Q：贷款的三套分类？**
   A：期限——短期 1 年以内/中期 1~5 年/长期 5 年以上；条件——信用贷款/担保贷款（保证、抵押、质押）；用途——资本/商业/消费贷款。

9. **Q：中间业务的定义与别称？**
   A：不使用自己的资金为客户办理支付和其他委托事项并收取手续费；别称"无风险业务"，是作为"支付中介"提供的金融服务。

10. **Q：中间业务包括哪些？**
    A：结算（转账结算）、信托（资金/财产）、租赁（融资性/经营性）、代理（如受财政部门委托代理发行和兑付国债）、咨询。

11. **Q：经营三原则及"两负一正"？**
    A：盈利性、流动性、安全性；盈利与流动负相关、盈利与安全负相关、流动与安全正相关。

12. **Q：流动性原则的两层含义？**
    A：①保有一定比例的现金资产或其他容易变现的资产；②取得现款的能力。

13. **Q：存款保险的纳入范围？**
    A：吸收存款的银行业金融机构（商业银行含外商独资/中外合资、农村合作银行、农村信用合作社）；被保险存款含人民币存款和外币存款。

14. **Q：哪些存款不纳入存款保险？**
    A：外国银行在华分支机构存款、中资银行海外分支机构存款、金融机构同业存款、投保机构高管在本机构存款等。

15. **Q：存款保险偿付限额？**
    A：每个人、每家银行分别计算，50 万元以内全额赔付，超过部分从该投保机构清算财产中受偿。

16. **Q：存款保险基金的运用形式？**
    A：存央行；投资政府债券、中央银行票据、信用等级较高的金融债券及其他高等级债券；国务院批准的其他形式。

17. **Q：金融市场效率的两方面内容？**
    A：以最低交易成本为资金需求者提供金融资源的能力；资金需求者使用金融资源向社会提供有效产出的能力。

18. **Q：法玛有效市场三类及判据？**
    A：弱型（历史资料无影响，最低程度）、半强型（公开发表资料无影响，中等程度）、强型（所有相关信息含内幕无影响，最高程度）。

19. **Q：货币市场与资本市场的子市场？**
    A：货币市场——同业拆借、票据、短期债券市场；资本市场——股票、长期债券、投资基金市场。

20. **Q：外汇市场为何特殊？**
    A：由中央银行、外汇银行、外汇经纪商和客户组成，不能简单归入货币市场或资本市场。

## 六、典型真题（含解析）

### （一）商业银行的主要业务

**【2019·多选】商业银行中间业务的说法正确的有（　）。**
A. 商业银行不能办理财产信托业务
B. 商业银行可以自主发行和兑付国债，无需财政部门委托
C. 票据贴现不属于商业银行的中间业务
D. 商业银行办理中间业务时无需投入自有资金
E. 购买有价证券属于商业银行的中间业务

**答案：CD**
**解析**：中间业务不使用自己的资金，收取手续费，包括结算业务、信托业务（含财产信托和资金信托）、租赁业务、代理业务（如商业银行受财政部门的委托，代理发行和兑付国债等）、咨询业务。A 错——可以办理财产信托；B 错——需财政部门委托；C 对——票据贴现属于资产业务；D 对；E 错——购买有价证券属于投资业务，归资产业务。

**【2021·多选】关于商业银行主要业务的说法，正确的有（　）。**
A. 贴现业务形式上是票据的买卖，实际上是间接贷款给票据持有人
B. 银行结算业务的手续费向委托人收取
C. 商业银行的借款业务包括再贴现、结算过程中的短期资金占用
D. 租赁业务是商业银行作为支付中介提供服务
E. 综合化银行制对商业银行的投资业务没有限制

**答案：ABC**
**解析**：E 错误——在这种金融体制下，金融管理当局对商业银行的经营范围和业务种类不作限制，并非特指投资业务（素材解析原文）。D 项按当年标准答案不选；素材解析未附 D 项排除理由（素材将租赁业务列入中间业务构成，而中间业务是作为"支付中介"提供的金融服务，做题以当年答案为准）。

A. 5　B. 15　C. 10　D. 3

**答案：A**
**解析**：贷款按归还期限分为短期贷款（1 年以内）、中期贷款（1~5 年）、长期贷款（5 年以上）。

**【2022·多选】商业银行根据贷款用途分为（　）。**

**【2022·单选】以下属于商业银行吸收存款方式的为（　）。**

### （二）商业银行的经营管理

**【2019·单选】关于商业银行资产盈利性、安全性、流动性相互之间关系的说法，正确的是（　）。**
A. 资产盈利性与流动性呈负相关关系
B. 三者无相关关系
C. 资产盈利性与安全性呈正相关关系
D. 流动性与安全性呈负相关关系

**答案：A**
**解析**：资产流动性与盈利性呈负相关关系；资产安全性和盈利性也呈负相关关系；流动性与安全性呈正相关关系。

**【2020·单选】下列原则中，属于商业银行经营管理基本原则的是（　）。**
A. 商业性原则　B. 合规性原则　C. 流动性原则　D. 市场性原则

**答案：C**
**解析**：商业银行经营管理的基本原则是盈利性、流动性、安全性。

**【2020·多选】关于商业银行经营管理的说法，正确的有（　）。**
A. 商业银行的资产安全性与流动性无相关关系
B. 商业银行的资产盈利性与安全性无相关关系
C. 为了保持资产的流动性，商业银行把信贷资金用于收益率为 0 或者比较低的项目上
D. 为了获得更多的盈利，商业银行总是愿意将信贷资金用于收益率高的项目上
E. 商业银行的资产盈利性与安全性呈负相关关系

**答案：CDE**
**解析**：盈利性与流动性负相关——为获得更多盈利，商业银行总愿把信贷资金用到收益率最高的中长期贷款或证券投资上，这会使资产失去流动性，严重的会导致支付危机；反之，为保持流动性，把信贷资金用于收益率为零的现金或收益率很低的短期投资上，盈利水平就很低。盈利性与安全性负相关——风险越高的资产业务，盈利就越大，银行经营的安全性就越低；反之亦然。

**【2021·单选】关于商业银行经营管理的说法，错误的是（　）。**
A. 资产盈利性与安全性是负相关关系
B. 资产流动性与盈利性是负相关关系
C. 安全性原则是指贷款和投资等业务要能够按期收回本息
D. 流动性原则是指商业银行以更低的利率吸收更多的活期存款

**答案：D**
**解析**：流动性原则包含两层含义：①保有一定比例的现金或其他容易变现的资产；②取得现款的能力。A、B、C 均正确。

### （三）存款保险制度

**【2020·单选】根据我国《存款保险条例》，下列机构中应当投保存款保险的是（　）。**

**答案：B**
**解析**：存款类金融机构包括商业银行（含外商独资银行和中外合资银行）、农村合作银行、农村信用合作社。被保险存款既包括人民币存款，也包括外币存款；不包括金融机构同业存款、高管在本机构存款，以及外国银行在中国的分支机构、中资银行海外分支机构的存款。

**【2022·单选】下列可以参加存款保险的是（　）。**
A. 外国银行在中国的分支机构的存款
B. 中资银行在海外的分支机构的存款
C. 外币存款
D. 同业存款

**答案：C**
**解析**：被保险的存款既包括人民币存款，也包括外币存款；A、B 原则上不纳入存款保险范围；D 同业存款除外。

**【2023 补·单选】A 在甲银行存款 49.5 万元，利率 2%；A 在乙银行存款 10 万元，利率 3%。一年后甲银行由存款保险机构接管，同时乙银行向法院提起破产申请。此时 A 提出提取存款，应由存款保险机构赔偿的金额为（　）。**
A. 50 万元　B. 50.49 万元　C. 60 万元　D. 60.3 万元

**答案：D**
**解析**：同一存款人在同一家投保机构所有存款账户的本金和利息加起来在 50 万元以内，全额赔付。甲银行本息 49.5×（1+2%）＝50.49 万元，获赔 50 万元；乙银行本息 10×（1+3%）＝10.3 万元，全额获赔 10.3 万元；合计 60.3 万元。

### （四）金融市场效率

**【2021·多选】关于金融市场效率的说法，正确的有（　）。**
A. 金融市场效率的发挥是以资本的合理运动为前提的
B. 金融市场的高效率是因为资本追逐利润
C. 依据资金需求者获得金融资源的等待时间衡量市场效率
D. 依据资金需求者使用资源向社会提供有效产出的规模市场效率
E. 依据资金需求者获得的融资规模衡量市场效率

**答案：ABD**
**解析**：金融市场效率指金融市场实现金融资源优化配置功能的程度，包含两方面：一是金融市场以最低交易成本为资金需求者提供金融资源的能力，二是资金需求者使用金融资源向社会提供有效产出的能力。资本的本质特征是追逐利润，资本流动的趋利性恰好达到优化资源配置的目的；效率的发挥以资本的合理运动为前提。

### （五）有效市场理论

**【2020·多选】根据有效市场理论，证券市场的有效性可以分为不同类别，这些类别主要包括（　）。**
A. 半弱型效率　B. 强型效率　C. 半强型效率　D. 弱型效率　E. 无效率

**答案：BCD**
**解析**：法玛将市场有效性分为三类：弱型效率（最低程度，历史资料对价格变动无任何影响）、半强型效率（中等程度，公开发表的资料对价格变动无任何影响）、强型效率（最高程度，所有相关信息包括内幕信息对价格变动无任何影响）。

   A. 如果有关证券公开发表的资料对其价格变动不产生任何影响，则证券市场达到半强型效率

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把商业银行与中央银行、政策性银行混同 | 央行、政策性银行**不以盈利为目的**；商业银行以盈利为目的 |
| 2 | 认为非银行金融机构也能面向公众吸收活期存款 | **唯一**能面向公众吸收活期存款的是商业银行 |
| 3 | 把"信用创造"当成最基本职能 | 最基本的是**信用中介**；信用创造是发行信用工具、产生信用扩张 |
| 4 | 组织形式两套分类记串 | 按机构设置分单一/总分行；按业务经营范围分专业化/综合化 |
| 5 | 把吸收存款、向央行借款归入资产业务 | 它们是**负债业务**（资金来源）；资产业务是贴现、贷款、投资 |
| 6 | 认为票据贴现是中间业务 | 贴现是**资产业务**，"形式是票据买卖，实质是信用业务" |
| 7 | 贷款三套分类交叉混淆 | 期限分短中长；条件分信用/担保；用途分资本/商业/消费 |
| 8 | 认为中间业务占用自有资金 | 中间业务**不使用自己的资金**，收取手续费，别称无风险业务 |
| 9 | 三性原则关系记反 | 两负一正：盈利-流动负、盈利-安全负、流动-安全正 |
| 10 | 混淆流动性与盈利性的取舍 | 盈利升则流动性降；想保流动性就得接受低收益 |
| 11 | 认为外币存款不参保 | 被保险存款**包括人民币存款和外币存款** |
| 12 | 认为外资银行在华分支存款可参保 | 外国银行在华分支存款、中资银行海外分支存款原则上**不纳入** |
| 13 | 忽略"每个人、每家银行分别" | 50 万限额**按人按行分别**计算，不是全国加总、也不是合并抵扣 |
| 14 | 把基金运用记成可投低等级金融债券 | 限于**信用等级较高**的金融债券及其他高等级债券 |
| 15 | 把债券市场归为单一市场属性 | 债券市场**兼具**货币市场和资本市场属性 |
| 16 | 认为在场外挂牌的企业就是上市公司 | 上市公司须在**股票交易所**挂牌；场外挂牌企业不是上市公司 |
| 17 | 认为外汇市场属于货币市场或资本市场 | 外汇市场**不能简单归入**任何一类 |
| 18 | 有效市场三类记混 | 历史资料→弱型；公开发表→半强型；含内幕→强型 |
