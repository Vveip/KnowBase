## 二、知识点精讲

### 考点1 政府预算的含义 ★

**核心概念**：政府预算是**法律规定和制度保证的、经法定程序审核批准的政府年度财政收支计划**；预算制度最早出现在**英国**。

| 视角 | 定位 |
|---|---|
| 形式（技术方面） | 政府的财政收支计划，是政府的工作计划 |
| 内容（政治方面） | 财政部门按法定程序管理财政资金的活动；**政府理财的主导环节和基本环节**；重大的政治行为 |
| 本质（法律性文件） | **国家和政府意志的体现**；须经国家权力机构审查批准才能生效；重要的法律性文件 |

```
政府预算（法定程序审核批准的政府年度财政收支计划）
 ├─ 形式上看 → 财政收支计划、政府工作计划
 ├─ 内容上看 → 财政部门依法管理财政资金；政府理财的主导和基本环节；重大政治行为
 └─ 本质上看 → 国家和政府意志的体现；经权力机关审查批准生效；重要法律性文件
```

**速记口诀**："英国最早立预算；形式是计划、内容是理财、本质是意志。"

### 考点2 政府预算的职能 ★

| 职能 | 作用对象 |
|---|---|
| 反映 | 政府部门的活动 |
| 监督 | 政府部门收支运作情况的功能 |
| 控制 | 政府部门的支出 |

```
反映 → 政府部门的活动
监督 → 政府部门收支运作情况
控制 → 政府部门的支出
```

**速记口诀**："反映活动、监督收支、控制支出。"

### 考点3 政府预算的原则 ★★

世界上大多数国家接受的预算原则：**完整性、统一性、可靠性、合法性、公开性、年度性**。

| 原则 | 素材展开 |
|---|---|
| 完整性 | 预算必须包括政府**所有**财政收入和支出内容，全面反映政府财政活动：①所有法律准许的政府财政活动，都要在预算中清楚地列出，不应另设其他财政收支账目；②政府所有的财政活动都不能脱离预算管理；③非政府交易活动必须排除在外 |
| 年度性 | 分**跨年制和历年制**；**我国采用历年制** |
| 统一性、可靠性、合法性、公开性 | 素材仅列名称未展开；素材真题选项中的对应表述：可靠性＝"保证预算能得到真实可靠地执行，不允许虚列冒估"；公开性＝"政府财政收支计划的制定、执行以及决算的过程应向公众公开" |

**速记口诀**："完、统、可（靠）、合（法）、公（开）、年（度）"六原则；我国预算年度＝历年制。

### 考点4 政府预算的分类 ★★★

六大分类维度总览：

```
按预算编制形式 ───────────→ 单式预算 / 复式预算
按预算编制依据的内容和方法 → 增量预算 / 零基预算
按预算作用时间长短 ───────→ 年度预算 / 多年预算（中期预算）
按预算收支平衡状况 ───────→ 平衡预算 / 差额预算（盈余预算、赤字预算）
按预算项目是否直接反映经济效益 → 投入预算 / 绩效预算 / 规划项目预算
按预算管理层级 ───────────→ 中央预算 / 地方预算
```

**（1）单式预算 vs 复式预算**

| | 单式预算 | 复式预算 |
|---|---|---|
| 构成 | 汇总为一本账 | **经常预算＋资本预算** |
| 优点 | ①简单明了、整体性强，能够清晰反映政府财政收支全貌，有利于公众监督；②编制简单、易于操作 | ①区分收入和支出的经济性质与用途，便于科学安排预算收支结构、突出重点、分类控制预算收支平衡；②便于灵活运用资本性投资和国债手段宏观调控 |

- 经常预算：收入以**税收**为主要来源，支出以**行政事业项目**为对象。
- 资本预算：收入以**国债**为主要来源，支出以**经济建设项目**为对象。

**（2）增量预算 vs 零基预算**

| | 增量预算（基数预算） | 零基预算 |
|---|---|---|
| 编制依据 | 在**以前预算年度**的基础上，按新预算年度经济发展情况加以调整后确定 | **不考虑**以前年度财政收支执行情况，以新预算年度经济社会发展情况和财力可能为依据 |
| 做法与特点 | 保持各项财政收支指标的连续性；传统的预算编制方法 | 重新评估各项收支的必要性及其所需金额 |
| 优势 | 指标连续 | 克服增量预算下财政收支指标刚性增长的弊端，提高支出效率 |

**（3）年度预算 vs 多年预算**

- 年度预算：预算有效期为**一年**的政府预算。
- 多年预算（中期预算）：有效期为几年（**多为3~5年**）；一般**不具有法律效力**，也**不需要**国家权力机关批准，但**需提交国家权力机关作为审议年度预算时的参照**；采取**逐年递推或滚动**方式，**每年编制一次**、每次向前滚动一年。

**（4）平衡预算 vs 差额预算**

- 平衡预算：**略有盈余和略有赤字都可以称为平衡预算**。
- 差额预算：包括**盈余预算**和**赤字预算**。

**（5）按预算项目是否直接反映经济效益**：投入预算、绩效预算、规划项目预算（素材仅列名称）。

**（6）中央预算 vs 地方预算**

- 中央预算＝中央政府的预算，包括**中央一般公共预算、中央政府性基金预算、中央国有资本经营预算和社会保险基金预算**。
- 地方预算由各省、自治区、直辖市总预算组成；地方各级总预算由**本级预算和汇总的下一级总预算**组成；下一级只有本级预算的，下一级总预算即指下一级的本级预算；没有下一级预算的，总预算即指本级预算。
- 我国政府预算级次与政权结构和行政区域密切相关，原则上**一级政府、一级财政、一级预算**。

**速记口诀**："形式单复、依据增零、时间年多、平衡差额、效益三类（投入/绩效/规划）、层级央地。"

### 考点5 我国政府预算管理职权划分 ★★★

```
立法机关
 ├─ 各级人民代表大会 —— 审查批准
 │   ├─ 全国人大：审查中央和地方预算草案及预算执行情况的报告；
 │   │   批准中央预算和中央预算执行情况的报告；改变或撤销全国人大常委会
 │   │   关于预算、决算的不适当决议
 │   ├─ 县级以上地方各级人大：审查本级总预算草案及执行情况的报告；批准本级
 │   │   预算和本级预算执行情况的报告；改变和撤销本级人大常委会关于预算、
 │   │   决算的不适当决议；撤销本级政府预算、决算不适当决定和命令
 │   └─ 乡、民族乡、镇人大：审查批准本级预算及执行情况报告；监督本级预算
 │       执行；审查批准本级预算调整方案；审查批准本级政府决算；撤销本级政府
 │       关于预算、决算不适当的决定和命令（素材原注："县以下增加三项"）
 └─ 各级人大常委会 —— 监督、调整、决算
     ├─ 全国人大常委会：监督中央和地方预算的执行；审查批准中央预算调整方案；
     │   审查批准中央决算；撤销国务院及省级人大、常委会违宪违法的预算决算法规决议
     └─ 县级以上地方各级人大常委会：监督本级总预算执行；审查批准本级预算
         调整方案；审查批准本级政府决算；撤销本级政府及下一级人大、常委会
         关于预算、决算不适当的决定
```

| 主体 | 职权要点 |
|---|---|
| 各级人民政府 | 编制本级预算草案并向本级人大作总预算草案报告；编制本级预算调整方案；组织本级总预算执行；**决定本级政府预备费动用**；监督本级各部门和下一级政府预算执行；改变或撤销不恰当决定命令；向本级人大及其常委会报告执行情况；**组织编制本级决算草案** |
| 各级财政部门 | 预算管理的职能部门：组织本级、编制本级、向本级政府和上级财政部门报告、**提出预备费动用方案**（素材表述较略） |
| 各级政府业务主管部门 | 编制本部门预、决算草案；组织和监督本部门预算的执行 |
| 各单位 | 组织本单位预算的执行；编制本单位预、决算草案；按规定上缴预算收入；安排预算支出；接受财政审计监督 |

**速记口诀**："人大审查批准，常委会监督调整决算；政府编草案、编调整、管执行、定预备费；财政提方案，主管编本部门，单位去执行。"

### 考点6 一般公共预算 ★（政府预算体系的基础）

**核心概念**：政府凭借国家政治权力，以**社会管理者**身份筹集以**税收**为主体的财政收入，用于保障和改善民生、维持国家行政职能正常运转、保障国家安全等方面的收支预算。我国每年统计公报公布的财政收入、财政支出、财政赤字数字，是就一般公共预算而言。其收入既包括满足政府日常行政事业活动及保障国家安全、社会稳定、发展科教文卫等事业开支需要的收入，也包括满足政府投资性支出需要的收入。

**收入构成**：
- 税收收入：增值税、消费税、企业所得税、个人所得税、资源税、城市维护建设税、房产税、印花税、城镇土地使用税、土地增值税、车船税、船舶吨税、车辆购置税、关税、耕地占用税、契税等。
- 非税收入（八款）：专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入、捐赠收入、政府住房基金收入、其他收入。

**支出两种分类**：

| 分类口径 | 主要内容 |
|---|---|
| 按支出功能 | 一般公共服务、外交、国防、公共安全、教育、科学技术、文化旅游体育与传媒、社会保障和就业、卫生健康、节能环保、城乡社区、农林水、交通运输、金融、其他支出和转移性支出等 |
| 按支出经济性质 | 工资福利支出、商品和服务支出、对个人和家庭的补助、对企事业单位的补贴、转移性支出、赠与、债务利息支出、基本建设支出、其他资本性支出、贷款转贷及产权参股、其他支出 |

**速记口诀**："税收为主体、非税八款；功能看领域、经济看性质。"

### 考点7 政府性基金预算 ★★

| 要素 | 内容 |
|---|---|
| 概念 | 为支持**特定公共基础设施建设和公共事业发展**，对公民、法人和其他组织**无偿征收**的具有专项用途的财政资金 |
| 收入构成 | 向社会征收基金、收费以及**出让土地、发行彩票**等方式取得收入 |
| 审批 | 政府性基金项目由**财政部审批**，重要的政府性基金须报**国务院**审批 |
| 管理原则 | **以收定支、专款专用、结余结转下年继续使用** |

**速记口诀**："土地彩票进基金；财政审批、重要国务院；收定支、专款用、结余留下年。"

### 考点8 国有资本经营预算 ★

| 要素 | 内容 |
|---|---|
| 核心 | 调整**国家和国有企业之间的分配关系**，是实现国有资本经营战略目标的重要手段 |
| 编制原则 | 统筹兼顾、适度集中；相互独立、相互衔接；分级编制、逐步实施 |
| 收入 | 从国家出资企业取得的利润、股利、股息和产权转让收入、清算收入等 |
| 支出 | 对重要企业补充资本金和弥补一些国有企业改革成本 |

**国有资本收益收取比例（按企业税后利润）**：

| 比例 | 适用企业 |
|---|---|
| 20% | 烟草 |
| 15% | 石油石化、电力、电信、煤炭（资源垄断特征） |
| 10% | 钢铁、运输、电子、贸易施工（一般竞争性） |
| 5% | 科研院所、邮政集团公司 |
| 免交 | 中国储备粮总公司、中国储备棉总公司等政策性公司 |

> 政策动态（素材标注"拓展了解即可"）：2024年1月，国务院印发《国务院关于进一步完善国有资本经营预算制度的意见》，提出到2024年末，基本形成全面完整、结构优化、运行顺畅、保障有力的国有资本经营预算制度。

**速记口诀**："烟草二十垄断十五，竞争十块科研五，储备粮棉不用交。"

### 考点9 社会保险基金预算 ★★

**预算原则**（五组词）：依法建立、规范统一；统筹编制、明确责任；专项基金、专款专用；相对独立、有机衔接；收支平衡、留有结余。

**编制范围（按险种分别编制）**：

```
企业职工基本养老保险基金
城乡居民基本养老保险基金
失业保险基金
城镇职工基本医疗保险基金
居民基本医疗保险基金
工伤保险基金
生育保险基金
```

**编报、执行与决算**：
```
预算草案：人力资源社会保障部汇总编制 → 财政部审核 → 财政部＋人社部联合向国务院报告
执行调整：不能随意调整；应编制社会保险基金预算调整方案
决算草案：人力资源社会保障部汇总编制 → 财政部审核 → 财政部＋人社部联合向国务院报告
```

**速记口诀**："七险种分别编；人社编、财政审、联合报国务院；不能随意调，收支平衡留有结余。"

### 考点10 预算编制制度 ★★★

**1. 建立部门预算制度**（市场经济国家财政预算管理的基本形式）

部门预算收支范围"四个既包括"：
```
既包括行政单位预算，也包括所属事业单位预算
既包括一般收支预算，也包括政府基金收支预算
既包括基本支出预算，也包括项目支出预算
既包括财政部门直接安排的预算，也包括有预算分配权部门安排的预算
```

编制方法：
- 部门**收入**预算采用**标准收入预算法**；
- 部门**支出**预算采用**零基预算法**，支出预算包括基本支出预算和项目支出预算。

编制程序：采取**自下而上**的方式，实行"两上两下"（素材仅展开"二上""二下"）：
```
二上：各部门根据财政部门下达的预算控制限额，编制部门预算草案上报同级财政部门
二下：财政部门审核各部门上报的预算草案 → 汇总成本级预算草案和部门预算草案
      → 报经政府审批 → 提交本级人民代表大会审议
      → 本级人大批准预算草案后 1 个月内，向本级各部门批复预算
      → 各部门在财政部门批复本部门预算之日起 15 日内，批复所属各单位预算，
        并负责具体执行
```

**2. 将预算外资金纳入预算管理**（素材仅列标题，未展开）

**速记口诀**："收入标准、支出零基；自下而上两上两下；人大批后1个月、财政复后15日。"

### 考点11 预算执行制度 ★

**1. 建立国库集中收付制度**——三大作用：

```
加强了预算执行的监督和控制
提高管理信息透明度
增强财政宏观调控能力
```

**2. 实行政府采购制度**——三个结合：

## 四、关键机制与适用条件

> 本章无公式、无计算题，以下为必须掌握的机制与适用条件。

**机制1：部门预算"两上两下"流程与时间红线**
```
部门编草案上报（二上）→ 财政部门审核汇总 → 政府审批 → 提交本级人大审议
→ 人大批准后 1 个月内：财政部门向本级各部门批复预算
→ 财政部门批复后 15 日内：各部门批复所属各单位预算
```
适用条件：市场经济国家财政预算管理的基本形式；自下而上编制。

**机制2：预算职权"四条线"**
```
审批线：各级人民代表大会（审查草案、批准预算）
监督线：各级人大常委会（监督执行、审批调整方案、审批决算）
执行线：各级人民政府（编制、组织执行、决定预备费动用、报告、组织编制决算）
专业线：各级财政部门（牵头）＋业务主管部门（本部门）＋各单位（本单位）
```

**机制3：社会保险基金预算编报线**
```
人社部汇总编制 → 财政部审核 → 财政部＋人社部联合向国务院报告（预算、决算同）
调整适用条件：不能随意调整，应编制社会保险基金预算调整方案
```

**机制4：政府采购"三个结合"的适用条件**
```
集中采购与分散采购相结合 → 集中为主、分散为辅
公开招标与非公开招标相结合
委托采购与自行采购相结合
主方式：公开招标、竞争性谈判
```

**机制5：国有资本收益收取比例的适用条件**
```
资源垄断特征企业（烟草、石油石化、电力、电信、煤炭）比例高
一般竞争性企业（钢铁、运输、电子、贸易施工）比例低
政策性公司（储备粮、储备棉等）免交
```

## 五、高频考点速记卡

1. **Q：政府预算从本质上看是什么？**
   A：国家和政府意志的体现；须经国家权力机构审查批准才能生效；是重要的法律性文件。

2. **Q：政府预算的三个视角？**
   A：形式（技术）上是财政收支计划、政府工作计划；内容（政治）上是财政部门依法管理财政资金的活动、政府理财的主导和基本环节、重大政治行为；本质上是国家和政府意志的体现。

3. **Q：预算制度最早出现在哪国？**
   A：英国。

4. **Q：政府预算三大职能？**
   A：反映政府部门的活动；监督政府部门收支运作情况；控制政府部门的支出。

5. **Q：预算原则有哪六个？**
   A：完整性、统一性、可靠性、合法性、公开性、年度性；我国采用历年制。

6. **Q：完整性原则的要求？**
   A：包括政府所有财政收入和支出内容；法律准许的政府财政活动都在预算中列明、不另设账目；所有财政活动不脱离预算管理；非政府交易活动排除在外。

7. **Q：按编制形式分哪两类？谁由经常预算和资本预算组成？**
   A：单式预算、复式预算；**复式预算**由经常预算和资本预算组成。

8. **Q：经常预算与资本预算的收入来源和支出对象？**
   A：经常预算以税收为收入来源、行政事业项目为支出对象；资本预算以国债为收入来源、经济建设项目为支出对象。

9. **Q：单式预算的优点？**
   A：简单明了、整体性强，清晰反映财政收支全貌，利于公众监督；编制简单、易于操作。

10. **Q：增量预算与零基预算的区别？**
    A：增量（基数）预算在以前年度基础上按新年度情况调整，保持指标连续性；零基预算不考虑以前年度执行情况，重新评估收支必要性和金额，克服指标刚性增长弊端、提高支出效率。

11. **Q：多年预算的特点？**
    A：也称中期预算，有效期多为3~5年；一般不具法律效力、不需权力机关批准，但需提交作为审议年度预算的参照；逐年递推或滚动、每年编制一次。

12. **Q：平衡预算怎么理解？**
    A：略有盈余和略有赤字都可以称为平衡预算；差额预算包括盈余预算和赤字预算。

13. **Q：预算级次的原则？中央预算包括什么？**
    A：一级政府、一级财政、一级预算；中央预算包括中央一般公共预算、中央政府性基金预算、中央国有资本经营预算和社会保险基金预算。

14. **Q：人大常委会的职权关键词？**
    A：监督预算执行、审查批准预算调整方案、审查批准决算、撤销不适当决议；"审批本级政府预算"是人大的职权。

15. **Q：各级政府的职权关键词？**
    A：编制预算草案和调整方案、组织执行、**决定预备费动用**、监督、报告执行情况、组织编制决算。

16. **Q：非税收入八款有哪些？**
    A：专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入、捐赠收入、政府住房基金收入、其他收入。

17. **Q：政府性基金预算的收入来源和管理原则？**
    A：征收基金、收费、出让土地、发行彩票；以收定支、专款专用、结余结转下年继续使用；重要基金项目须报国务院审批。

18. **Q：国有资本收益收取比例？**
    A：烟草20%；石油石化、电力、电信、煤炭15%；钢铁、运输、电子、贸易施工10%；科研院所、邮政5%；储备粮、储备棉等政策性公司免交。

19. **Q：社保基金预算的编制范围和原则？**
    A：按险种分别编制7类（企业职工养老、城乡居民养老、失业、城镇职工医保、居民医保、工伤、生育）；原则：依法建立规范统一、统筹编制明确责任、专款专用、相对独立有机衔接、收支平衡留有结余。

20. **Q：部门预算的编制方法和程序？**
    A：收入预算用标准收入预算法、支出预算用零基预算法；自下而上、"两上两下"；人大批准后1个月内批复部门预算，财政部门批复后15日内批复所属单位。

C. 保证预算能得到真实可靠地执行，不允许虚列冒估
D. 政府所有的财政活动都不能脱离预算管理
E. 政府财政收支计划的制定、执行以及决算的过程应向公众公开

**答案：ABD**
**解析**：政府预算必须包括政府所有的财政收入和支出内容，全面反映政府的财政活动。所有法律准许的政府财政活动，都要在预算中清楚地列出，不应另设其他财政收支账目；政府所有的财政活动都不能脱离预算管理，非政府交易活动必须排除在外。C是可靠性原则的表述，E是公开性原则的表述。

## 七、易错点与避坑指南

| # | 错在哪 | 怎么记 |
|---|---|---|
| 1 | 把"复式预算"的构成安到单式预算头上 | 单式预算是"一本账"；**经常预算＋资本预算**是复式预算 |
| 2 | 把单式、复式预算的优点混记 | 单式＝全貌清晰＋编制易操作；复式＝分类控制收支平衡＋资本投资和国债宏观调控 |
| 3 | 混淆增量预算与零基预算的编制依据 | 增量看**上年基数**（保连续）；零基**从零重新评估**（破刚性） |
| 4 | 认为多年预算有法律效力、需权力机关批准 | 多年（中期）预算**不具法律效力、不需批准**，只作审议年度预算的参照 |
| 5 | 认为多年预算3~5年才编制一次 | **每年编制一次**、逐年递推或滚动，每次向前滚动一年 |
| 6 | 认为平衡预算必须收支正好相等 | **略有盈余或略有赤字都算平衡预算** |
| 7 | 把"审查批准本级政府预算"当成人大常委会职权 | 审批预算在**人大**；常委会管**监督、调整方案、决算** |
| 8 | 把"审批本级预算调整方案"当成政府职权 | 政府**编制**调整方案，**人大常委会审批** |
| 9 | 忘记预备费动用由谁决定 | **各级政府决定**预备费动用；财政部门只**提出**动用方案 |
| 10 | 把彩票收入、国有股权转让收入归入一般公共预算 | 发行彩票→**政府性基金预算**；国有股权转让→**国有资本经营预算** |
| 11 | 认为政府性基金"无结余或赤字" | 原则是"以收定支、专款专用、**结余结转下年继续使用**" |
| 12 | 认为所有政府性基金项目都由财政部审批 | 财政部审批，**重要项目须报国务院审批** |
| 13 | 部门预算编制方式记成"自上而下" | 是**自下而上**，实行"两上两下" |
| 14 | 部门支出预算用增量预算法 | 支出预算用**零基预算法**；收入预算用**标准收入预算法** |
| 15 | 批复时限记混 | 人大批准后**1个月内**批复部门预算；财政部门批复后**15日内**批复所属单位 |
| 16 | 社会保险基金预算可以随意调整 | 不能随意调整，应编制**社会保险基金预算调整方案** |
| 17 | 社保基金预算编制范围漏"城乡居民" | 7类险种：企业职工养老、城乡居民养老、失业、城镇职工医保、居民医保、工伤、生育 |
| 18 | 把"三保"内容记错 | 三保＝保基本民生、保工资、保运转，在财政支出中优先安排 |
