## 二、知识点精讲

### 考点1 经济增长的含义及其与经济发展的区别 ★

**经济增长的含义**：一个国家或地区在一定时期内总产出与前期相比所实现的增长。通常用国内生产总值（GDP）或人均国内生产总值来衡量。对一国经济增长速度的度量，常用经济增长率来表示：

```
经济增长率  G = ΔYt / Yt−1
```

**两种计价方式（必考辨析）**：

| 计价方式 | 反映对象 |
|---|---|
| 现行价格（现价）计算的GDP | 经济发展**规模** |
| 不变价格计算的GDP | 经济发展**速度** |

**经济发展的含义**：是一个**比经济增长含义更广**的概念。经济发展既包括经济增长，还包括伴随经济增长过程而出现的**技术进步、结构优化、制度变迁、福利改善以及人与自然之间关系的进一步和谐**等方面的内容。

**两者关系**：**经济发展包括经济增长**（方向不可颠倒）。

**速记口诀**：**"现价看规模，不变价看速度；增长是量、发展是质，发展含着增长走。"**

> **考法提示**：①单选直接考"计算经济增长速度时应用什么价格计算的GDP"，答案是不变价格；②多选考"经济发展包括哪些内容"，关键词锁定：技术进步、结构优化、制度变迁、福利改善、人与自然关系和谐。

### 考点2 决定经济增长的基本因素 ★

**四个基本因素**（素材仅列名称，未展开具体机制）：

1. 劳动投入
2. 资本投入
3. 劳动生产率
4. 资本效率

**逻辑链**：

```
决定经济增长的基本因素（4个）
├─ 劳动投入 ──────── 对应三因素分解中的"劳动投入"
├─ 资本投入 ──────── 对应三因素分解中的"资本投入"
├─ 劳动生产率 ────── 对应两因素分解中的"每小时产出的增加率"
└─ 资本效率 ──────── 因素分解公式中未单独出现
```

**速记口诀**：**"两个投入打头阵，两个效率定高低——劳动投入、资本投入、劳动生产率、资本效率。"**

> **素材提示**：本考点素材极简，命题基本停留在"多选选全四个因素"的层次；注意不要漏选"资本效率"。

### 考点3 经济增长因素分解 ★★★（本章唯一计算点）

**① 两因素分解法**：假定其他因素不变，把经济增长率按照**劳动和劳动生产率**两项因素进行分解。

```
经济增长率 = 工作小时数的增加率 + 每小时产出的增加率
即  GQ = GH + Gp
    （GH：工作小时数的增加率；Gp：每小时产出的增加率）
```

**② 三因素分解法**：劳动投入、资本投入和全要素生产率。

```
经济增长率 = 技术进步率 +（劳动份额×劳动增长率）+（资本份额×资本增长率）
即  Gγ = GA + αGL + βGk
    （GA：技术进步率；α：劳动份额；β：资本份额；
      GL：劳动增长率；Gk：资本增长率）
```

**③ 索洛余值（全要素生产率 TFP）**：即将劳动、资本等要素投入数量等因素对经济增长率的贡献**扣除**之后，技术进步因素对经济增长的贡献份额。

```
技术进步率 = 经济增长率 −（劳动份额×劳动增长率）−（资本份额×资本增长率）
即  GA = Gγ − αGL − βGk
```

> **串行修正**：素材原文写作"技术进步率=经济增长率-(劳动份额×劳动增加率)(资本份额×资本增长率)"，疑清洗串行丢失一个减号；按下述例题演算（6%−0.4×2%−0.6×5%=2.2%），应补全为**两个减号**。

**计算示范（素材原题数据）**：劳动产出弹性 α＝0.4，资本产出弹性 β＝0.6，劳动年增长率 GL＝2%，资本年增长率 Gk＝5%，年经济增长速度 Gγ＝6%：

```
GA = 6% − 0.4×2% − 0.6×5%
   = 6% − 0.8% − 3%
   = 2.2%
```

**速记口诀**：**"两因素看工时和每小时产出；三因素技术打头，劳动资本按份额加权；余值＝总量减两块贡献，减完才是技术进步。"**

### 考点4 经济周期的含义和类型 ★★

**含义**：指总体经济活动沿着经济增长的总体趋势而出现的有规律的**扩张和收缩**。

**两种分类**：

| 分类标准 | 类型 | 别名 | 年限/特征 |
|---|---|---|---|
| 按周期波动的**时间长短** | 长周期 | 又称长波循环或**康德拉耶夫周期** | 50-60年 |
| | 中周期 | 又称大循环或**朱格拉周期** | 8年 |
| | 短周期 | 又称小循环或**基钦周期** | 3-5年 |
| 按经济总量**绝对下降或相对下降** | 古典型周期 | —— | 经济运行处在低谷时经济增长为**负增长**，经济总量GDP**绝对减少** |
| | 增长型周期 | —— | 处在低谷时经济增长率为**正值**，经济总量只是**相对减少**而非绝对减少 |

**逻辑链**：

```
经济周期 = 有规律的扩张和收缩
├─ 按时间长短分
│    ├─ 长周期 = 康德拉耶夫周期 = 50-60年
│    ├─ 中周期 = 朱格拉周期     = 8年
│    └─ 短周期 = 基钦周期       = 3-5年
└─ 按总量下降情况分
     ├─ 古典型周期 = 低谷负增长 = GDP绝对减少
     └─ 增长型周期 = 低谷正增长 = 相对减少（非绝对减少）
```

**速记口诀**：**"长波康德拉耶夫五六十，朱格拉中大循环八年整，基钦短波三五年；低谷负增长是古典，低谷正增长是增长型。"**

### 考点5 经济周期的阶段划分和阶段特征 ★

经济周期划分为**扩张阶段**和**紧缩或衰退阶段**：

- ① **扩张阶段**（产出、消费、投资、利润）
- ② **紧缩或衰退阶段**（产出、消费、投资、利润）

> **素材说明**：讲义原文对两阶段仅列举"产出、消费、投资、利润"四项，趋势词（升/降）在素材中缺失；按扩张与衰退的含义理解，扩张阶段上述指标趋于上升、紧缩或衰退阶段趋于下降（素材未明示，此处仅作方向性说明，不作展开）。

**速记口诀**：**"两阶段——扩张往上走，衰退往下走；盯的都是产出、消费、投资、利润四样。"**

### 考点6 导致经济波动的主要因素 ★

**六个因素**：

1. 投资率的变动
2. 消费需求的波动
3. 技术进步的状况
4. 预期的变化
5. 国际经济因素的冲击
6. 大规模疫情等因素的冲击

**速记口诀**：**"投资消费打头，技术预期跟上，外加国际和疫情两冲击——共六个。"**

### 考点7 分析和预测经济波动的指标体系 ★★★★★（素材目录标 ★★★★★，正文标题标 ★★★）

| 指标类型 | 含义 | 举例 | 口诀 |
|---|---|---|---|
| **一致指标** | 峰谷出现的时间与总体经济运行的峰谷出现的时间**一致**，描述总体经济所处状态 | 国内生产总值、规模以上工业增加值、工业用电量、铁路货运量 | **两值两量** |
| **先行指标** | 也称**领先指标**，可以**预测**总体经济运行的轨迹 | 消费者信心指数、采购经理指数、新开工项目计划总投资 | **信心采购计划** |
| **滞后指标** | 对总体经济运行中**已经出现**的峰谷的**确定** | 企业利润、失业率、居民消费价格指数 | **居民失利** |

**逻辑链**：

```
分析和预测经济波动的指标体系
├─ 一致指标 ── 同步描述现状 ── "两值两量"：GDP、工业增加值、工业用电量、铁路货运量
├─ 先行指标 ── 领先预测轨迹 ── "信心采购计划"：消费者信心指数、采购经理指数、新开工项目计划总投资
└─ 滞后指标 ── 事后确认峰谷 ── "居民失利"：居民消费价格指数、失业率、企业利润
```

**速记口诀**：**"一致同步两值两量，先行领先信心采购计划，滞后事后居民失利。"**

> **考法提示**：①单选常以"下列属于先行指标的是"命题，正确选项必落在"信心采购计划"三者之中；②多选考一致性指标，GDP、规模以上工业增加值、工业用电量、铁路货运量全选，消费者信心指数不选。

### 考点8 经济发展的基本理论 ★

**含义**：发展中国家或地区人民生活水平持续提高，并伴随着物质资本和人力资本的增长及技术进步。经济发展不仅包括经济增长，而且还包括**经济结构和社会结构的变化**。变化包括：

1. 产业结构的不断优化
2. 城市化进程的逐步推进
3. 广大居民生活水平的持续提高
4. 国民收入分配状况的逐步改善

**【注1】以人民为中心**：发展为了人民，这是马克思主义政治经济学的根本立场。坚持以人民为中心的发展思想，是我国经济发展的根本立场，**以人民为中心就是经济发展的基本内核**。

**【注2】以人民为中心包含**：
- 发展为了人民，发展依靠人民，发展成果归人民共享；
- 促进人的全面发展：人的潜能的全面发挥，人的需要的全面满足，满足人民群众过上更加幸福美好的生活；
- 可持续发展：**"既满足当代人的需要，又不对后代人满足其需要能力构成危害的发展"**。可持续发展的思想，就是要正确处理经济增长和资源、环境、生态保护之间的关系，使它们之间保持协调和谐的关系。

**速记口诀**：**"结构变化四条：产业、城市、生活、分配；立场一条：以人民为中心；可持续一句：当代不让后代吃亏。"**

### 考点9 新发展理念 ★★★

**定位**：党的十八大以来，以习近平同志为核心的党中央对经济社会发展提出了许多重大理论和理念，其中**新发展理念是最重要、最主要的**。党的二十大报告强调，**贯彻新发展理念是新时代我国发展壮大的必由之路**。

**五大理念的定位（必背搭配）**：

| 理念 | 定位 | 主要解决的问题 |
|---|---|---|
| **创新** | 引领发展的**第一动力** | 发展**动力**问题 |
| **协调** | 持续健康发展的**内在要求** | 发展**不平衡**问题 |
| **绿色** | 永续发展的**必要条件**和人民对美好生活追求的重要体现 | 人与自然**和谐共生**问题 |
| **开放** | 国家繁荣发展的**必由之路** | 发展**内外联动**问题（国内国际两个市场两种资源） |
| **共享** | 中国特色社会主义的**本质要求** | 共同富裕 |

坚持创新发展、协调发展、绿色发展、开放发展、共享发展是关系我国发展全局的一场深刻变革，全党全国要统一思想、协调行动、开拓前进。

**要点展开（素材）**：
- **创新**："创新"首先指**科技创新**，同时也指理论创新、制度创新、文化创新、产品创新、管理创新等各方面的创新。
- **协调**：重点解决发展不平衡问题。我国社会主要矛盾已经转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。**协调既是发展手段又是发展目标，同时还是评价发展的标准和尺度**；要找出短板，在补齐短板上多用力。着力推动区域协调发展、城乡协调发展、经济社会协调发展、物质文明和精神文明协调发展，推动经济建设和国防建设结合发展。
- **绿色**：注重解决人与自然和谐共生问题。
- **开放**：注重解决发展内外联动问题，即国内国际两个市场两种资源的联动问题。
- **共享**：必须坚持发展为了人民、发展依靠人民、发展成果由人民共享。**"共享理念实质就是坚持以人民为中心的发展思想，体现的是逐步实现共同富裕的要求"**。共享的四个维度：

| 维度 | 针对什么而言 |
|---|---|
| **全民共享** | 共享的**覆盖面**（人人享有、各得其所，不是少数人共享） |
| **全面共享** | 共享的**内容**（国家经济、政治、文化、社会、生态各方面建设成果） |
| **共建共享** | 共享的**实现途径**（共建才能共享，共建的过程也是共享的过程） |
| **渐进共享** | 共享发展的**推进进程**（从低级到高级、从不均衡到均衡） |

## 四、关键机制与适用条件

> 本章计算类公式很少，仅集中在「经济增长因素分解」一处，故本节以"机制＋适用条件"为主。菲利普斯曲线、新古典增长模型、内生增长理论等**素材未覆盖**，不作补写。

### 4.1 经济增长率公式

```
经济增长率  G = ΔYt / Yt−1
```

- 度量一国经济增长速度，常用**经济增长率**；
- 计算时必须用**不变价格**计算的GDP（现行价格只反映经济发展规模）；
- 经济增长通常用 **GDP 或人均GDP** 来衡量。

### 4.2 两因素分解法

```
经济增长率 = 工作小时数的增加率 + 每小时产出的增加率
GQ = GH + Gp
```

**适用条件**：假定其他因素不变，把经济增长率按照**劳动和劳动生产率**两项因素进行分解。

### 4.3 三因素分解法与索洛余值（本章唯一计算题来源）

```
经济增长率 = 技术进步率 +（劳动份额×劳动增长率）+（资本份额×资本增长率）
Gγ = GA + αGL + βGk

索洛余值（全要素生产率 TFP）：
GA = Gγ − αGL − βGk
```

**机制解读**：把劳动、资本等要素投入数量对经济增长率的贡献**扣除**之后，剩下的部分即技术进步因素对经济增长的贡献份额，称为"索洛余值"。

**计算示范**：

```
已知：α=0.4，β=0.6，GL=2%，Gk=5%，Gγ=6%
GA = 6% − 0.4×2% − 0.6×5%
   = 6% − 0.8% − 3%
   = 2.2%
```

**易错警示**：α、β 是**份额（产出弹性）**，必须先与对应增长率**相乘**再加总，最后从经济增长率中**减去**——不是把各项直接相加。

### 4.4 经济周期类型判定机制

```
低谷时经济增长率 < 0（GDP绝对减少） → 古典型周期
低谷时经济增长率 > 0（总量相对减少） → 增长型周期
```

## 五、高频考点速记卡

1. **Q：经济增长通常用什么衡量？计算增长速度必须用什么价格？**
   A：通常用GDP或人均GDP衡量；计算增长速度必须用**不变价格**计算的GDP，现行价格只反映经济发展规模。

2. **Q：经济增长与经济发展是什么关系？**
   A：**经济发展包括经济增长**；经济发展还包括技术进步、结构优化、制度变迁、福利改善、人与自然关系和谐等内容。

3. **Q：决定经济增长的基本因素有哪四个？**
   A：劳动投入、资本投入、劳动生产率、资本效率。

4. **Q：两因素分解法的公式？**
   A：GQ = GH + Gp，即经济增长率＝工作小时数的增加率＋每小时产出的增加率。

5. **Q：三因素分解法的公式？**
   A：Gγ = GA + αGL + βGk，即经济增长率＝技术进步率＋（劳动份额×劳动增长率）＋（资本份额×资本增长率）。

6. **Q：什么是索洛余值？**
   A：即全要素生产率（TFP），把劳动、资本等要素投入的贡献扣除后，技术进步对经济增长的贡献份额；GA = Gγ − αGL − βGk。

7. **Q：经济周期按时间长短分哪三类？年限各是多少？**
   A：长周期＝康德拉耶夫周期（长波）50-60年；中周期＝朱格拉周期（大循环）8年；短周期＝基钦周期（小循环）3-5年。

8. **Q：古典型周期和增长型周期怎么区分？**
   A：看低谷时经济增长率——负增长（GDP绝对减少）为古典型；为正值（相对减少）为增长型。

9. **Q：经济周期分为哪两个阶段？**
   A：扩张阶段、紧缩或衰退阶段（素材列举产出、消费、投资、利润四项指标）。

10. **Q：导致经济波动的主要因素有哪些？**
    A：投资率的变动、消费需求的波动、技术进步的状况、预期的变化、国际经济因素的冲击、大规模疫情等因素的冲击。

11. **Q：一致、先行、滞后三类指标的口诀和举例？**
    A：一致指标"两值两量"（GDP、规模以上工业增加值、工业用电量、铁路货运量）；先行指标"信心采购计划"（消费者信心指数、采购经理指数、新开工项目计划总投资）；滞后指标"居民失利"（居民消费价格指数、失业率、企业利润）。

12. **Q：先行指标的含义是什么？**
    A：也称领先指标，可以预测总体经济运行的轨迹。

13. **Q：新发展理念五大理念各自的定位？**
    A：创新＝引领发展的第一动力；协调＝持续健康发展的内在要求；绿色＝永续发展的必要条件和人民对美好生活追求的重要体现；开放＝国家繁荣发展的必由之路；共享＝中国特色社会主义的本质要求。

14. **Q：协调理念重点解决什么问题？协调只是手段吗？**
    A：重点解决发展**不平衡**问题；协调既是发展手段又是发展目标，还是评价发展的标准和尺度。

15. **Q：共享的四个维度分别针对什么？**
    A：全民共享看覆盖面；全面共享看内容；共建共享看实现途径；渐进共享看推进进程。

16. **Q：我国进入新发展阶段的标志是什么？**
    A：2021年7月1日宣告实现第一个百年奋斗目标、全面建成小康社会，开启第二个百年奋斗目标新征程，标志着我国进入新发展阶段。

17. **Q：新发展格局的核心内容？战略基点是什么？**
    A：坚持**扩大内需**这个战略基点，把扩大内需战略同深化供给侧结构性改革有机结合，构建以国内大循环为主体、国内国际双循环相互促进的新发展格局。

18. **Q：高质量发展的主线和三大变革是什么？**
    A：以供给侧结构性改革为主线；推动质量变革、效率变革、动力变革，提高全要素生产率。高质量发展是全面建设社会主义现代化国家的首要任务。

19. **Q：新质生产力的核心标志、特点、关键、本质分别是什么？**
    A：以全要素生产率大幅提升为核心标志；特点是创新，关键在质优，本质是先进生产力；具有高科技、高效能、高质量特征。

20. **Q：中国式现代化的五个特征和两步走安排？**
    A：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路；两步走：2020-2035年基本实现社会主义现代化，2035年到本世纪中叶建成社会主义现代化强国。

## 六、典型真题（含解析）

> **收录说明**：本章素材为单一主版本（2026 网校讲义），所附练习题**均未标注年份**。以下 9 道题按素材原样**全部收录**（答案与解析保留），未添加年份标签，以免失真。

**题1【单选】通常情况下，计算经济增长速度时应用（　）计算的GDP。**
A. 现行价格　B. 基期价格　C. 平准价格　D. 不变价格
**答案：D**
**解析**：本题考查经济增长。GDP的计算中包含了产品或服务的价格因素，可以分为用现价计算的GDP和用不变价格计算的GDP。用现行价格计算的GDP，可以反映一个国家或地区的经济发展规模；用不变价格计算的GDP可以用来计算经济增长速度。

**题2【单选】假定某国在一定时期内的劳动产出弹性和资本产出弹性分别是0.4和0.6，劳动力和资本的年增长率分别是2%和5%。如果该国在这一时期年经济增长速度为6%，则全要素生产率的增长率是（　）。**
A. 2%　B. 5%　C. 6%　D. 2.2%
**答案：D**
**解析**：全要素生产率的增长率＝6%−0.4×2%−0.6×5%＝2.2%。

**题3【单选】如果一个经济体在经济运行处于低谷时的经济增长为负增长，即经济总量GDP绝对减少，具有这种特征的经济周期称为（　）。**
A. 中周期　B. 古典型周期　C. 长波循环周期　D. 增长型周期
**答案：B**
**解析**：按照经济总量绝对下降或相对下降的不同情况，经济周期可分为古典型周期和增长型周期。如果经济运行处在低谷时的经济增长为负增长，即经济总量GDP绝对减少，通常称为古典型周期；如果处在低谷时的经济增长率为正值，即经济总量只是相对减少而非绝对减少，则为增长型周期。

**题4【单选】下列分析和预测经济波动的指标中，属于先行指标的是（　）。**
A. 国内生产总值　B. 消费者信心指数　C. 居民消费价格指数　D. 铁路货运量
**答案：B**
**解析**：先行指标也称领先指标，可以预测总体经济运行的轨迹，如消费者信心指数、采购经理指数、新开工项目计划总投资。

**题5【多选】下列分析和预测经济运行及其波动的统计指标中，属于一致性指标的是（　）。**
A. 国内生产总值　B. 规模以上工业增加值　C. 工业用电量　D. 铁路货运量　E. 消费者信心指数
**答案：ABCD**
**解析**：一致指标的峰谷出现时间与总体经济运行的峰谷出现时间一致，描述总体经济所处状态，如国内生产总值、规模以上工业增加值、工业用电量、铁路货运量；消费者信心指数属于先行指标，故不选。

**题6【多选】以下说法正确的是（　）。**
A. 创新是引领发展的第一动力
B. 绿色是持续健康发展的内在要求
C. 协调是永续发展的必要条件
D. 开放是国家繁荣发展的必由之路
E. 和谐是中国特色社会主义的本质要求
**答案：AD**
**解析**：创新是引领发展的第一动力，协调是持续健康发展的内在要求，绿色是永续发展的必要条件和人民对美好生活追求的重要体现，开放是国家繁荣发展的必由之路，共享是中国特色社会主义的本质要求。

**题7【单选】关于协调发展理念的说法，正确的是（　）。**
A. 协调发展重点要解决发展不稳定问题
B. 协调发展要着力推动全局协调发展
C. 协调发展要着力推动区域协调发展、城乡协调发展、经济社会协调发展、物质文明和精神文明协调发展，推动经济建设和国防建设结合发展

**答案：C**
**解析**：协调发展重点要解决发展不平衡问题（A错）。习近平指出，协调既是发展手段又是发展目标，同时还是评价发展的标准和尺度（D错）。协调发展，就要找出短板，在补齐短板上多用力，通过补齐短板挖掘发展潜力、增强发展后劲（B错）。我国社会主要矛盾已经转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。协调发展就是要着力推动区域协调发展、城乡协调发展、经济社会协调发展、物质文明和精神文明协调发展，推动经济建设和国防建设结合发展（C对）。

**题8【多选】关于新发展理念的说法，错误的是（　）。**
A. 共享理念实质就是坚持以人民为中心的发展思想，体现的是逐步实现同等富裕的要求
B. 开放发展注重解决发展内外联动问题，即国内国际两个市场两种资源的联动问题
C. 绿色发展就是要注重解决人与自然和谐共生问题
D. 共享是全面共享，这是就共享的覆盖面而言的
E. 共享是全民共享，这是就共享的主体而言的
**答案：ADE**
**解析**：习近平对共享发展作出了全面论述，"共享理念实质就是坚持以人民为中心的发展思想，体现的是逐步实现共同富裕的要求"（A错，是共同富裕而非同等富裕）。共享是全民共享，这是就共享的覆盖面而言的，共享发展是人人享有、各得其所，不是少数人共享、一部分人共享（E错）。共享是全面共享，这是就共享的内容而言的，要共享国家经济、政治、文化、社会、生态各方面建设成果（D错）。B、C说法正确。

B. 中国式现代化是人口规模巨大的现代化

**答案：ABE**
