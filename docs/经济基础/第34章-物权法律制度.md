# 第34章 物权法律制度

> **本章考情**：本章属民商法部分的重头戏，围绕"物权"这一支配权展开，考点密集、辨析题多。命题偏爱**概念辨析**（物权vs债权、自物权vs他物权、按份共有vs共同共有）、**归类判断**（可抵押/不得抵押财产、可出质权利）与**易考数字**（预告登记90日、不动产统一登记十类、善意取得三条件、占份额2/3以上）。素材标注**所有权★★★、担保物权★★★**为核心，**共有及业主建筑物区分所有权★**次之。担保物权三兄弟（抵押权、质权、留置权）的对比与受偿顺序是全章最高频、最易混的落点。

## 二、知识点精讲

### 考点01 物权的特征和种类（素材未标星级）

**物权的定义**：物权是特定社会人与人之间对物的占有关系在法律上的表现，是法律确认的主体对物依法享有的**支配权**，即权利人在法定范围内直接支配一定的物，并排斥他人干涉的权利。

**1. 物权与债权的区别**

| 物权的特征 | 债权的特征 |
|---|---|
| 物权是**绝对权（对世权）** | 债权是**相对权（对人权）** |
| 物权属于**支配权** | 债权属于**请求权** |
| 物权是**法定的**，物权的设定采用法定主义 | 债权不具有公示性，债权是意思表示 |
| 物权的客体一般是**物** | 债权一般直接指向**行为**，间接涉及物 |
| 物权具有**追及效力和优先效力** | 债权不具有追及效力 |

> **妙记口诀：法物配绝，优先追及。**（法定 / 物为客体 / 支配权 / 绝对权 / 优先效力 / 追及效力）

**2. 物权设定的法定主义**

- 物权的种类和基本内容由法律规定，不允许当事人自由创设物权种类，且物权设定时必须**公示**。
- 权利象征：动产所有权、动产质权、留置权以**动产的占有**为权利象征；**不动产则以登记为权利象征**。

**3. 物权的客体"物"的特征**

| 特征 | 具体内容 |
|---|---|
| 标的是**物而不是行为** | 物权关系是民事主体之间对物质资料的占有关系 |
| 必须是**特定物** | 物未特定化，权利就无法确定，权利人无从行使 |
| 必须是**独立物和有体物** | 不可能是行为 |
| 只能以**独立于人自身之外的物**为客体 | 自己或他人身体都不可成为支配对象；人体器官未经合法程序与人体分离前，也不可成为物权客体 |

**4. 物权的分类**（五组标准）

| 分类标准 | 类别 | 主要内容 |
|---|---|---|
| 按权利行使范围 | **自物权** | 对**自己所有**的标的物全面支配（范围全面性+时间无限性）。**只有所有权符合，故自物权即所有权**，是最完整最充分的物权 |
| | **他物权** | 在**他人所有**标的物上、被限定于某一特定方面或期间的物权 |
| 按设立目的 | **用益物权** | 以标的物的**使用和收益**为目的 |
| | **担保物权** | 为**担保债权的实现**而设立的他物权（抵押权、质权等） |
| 按有无从属性 | **主物权** | 可**独立存在**（所有权、地上权、永佃权、采矿权、取水权等） |
| | **从物权** | **从属于其他权利**（抵押权、质权、留置权从属债权；地役权从属需役地所有权） |
| 按是否基于当事人意思 | **法定物权** | 基于**法律直接规定**（留置权、法定抵押权） |
| | **意定物权** | 依**当事人意思**（质权、抵押权） |
| 按存续有无期限 | **有期限物权** | 抵押权、质权、留置权 |
| | **无期限物权** | **所有权属于无期限物权** |

> **区分意义**：① 主物权独立存在，从物权命运取决于主权利——**主权利消灭，从权利也消灭**；② 法定物权与意定物权**成立要件和适用法律不同**。

### 考点02 物权法律制度的基本原则（素材未标星级）

| 原则 | 基本内涵 | 具体内容 |
|---|---|---|
| **物权法定原则** | 物的种类、内容、效力、得失变更及保护方法均源自法律直接规定，当事人不得自由创设 | ①种类法定化 ②内容法定化 ③效力法定化 ④得失变更法定化 ⑤保护方法法定化 |
| **一物一权原则** | 一物之上只能存在一个所有权，不得有互不相容的两个以上物权同时存在于同一标的物 | ①一个特定标的物上只有一个所有权 ②同一物上不得设有两个以上相互冲突矛盾的物权 |
| **物权公示原则** | 民事主体对物权的享有和变动均应采取可取信于社会公众的外部表现方式 | ①公示方法必须由法律规定 ②公示效力必须由法律规定 |

### 考点03 不动产登记的范围与种类（素材未标星级）

**1. 不动产统一登记制度**

我国已开始实施不动产统一登记制度，由**国务院自然资源主管部门**负责监督、指导全国的不动产登记工作。共有**十类**不动产物权纳入统一登记范围：

（1）集体土地所有权；（2）房屋等建筑物、构筑物所有权；（3）森林、林木所有权；（4）耕地、林地、草地等土地承包经营权；（5）建设用地使用权；（6）宅基地使用权；（7）海域使用权；（8）地役权；（9）抵押权；（10）法律规定需要登记的其他不动产权利。

**2. 不动产登记的类型**

| 类型 | 主要内容 |
|---|---|
| 首次登记 | 物权首次产生时的登记，如商品房建成后第一次登记 |
| 变更登记 | 物权具体内容发生变化时的登记，权利主体形式（姓名、名称）或客体形式（名称、用途、面积）变化 |
| 转移登记 | 物权发生**权利转移**时的登记 |
| 注销登记 | 物权**消灭**时的登记，如地役权解除时的注销登记 |
| 更正登记和异议登记 | 认为登记簿记载事项错误的可申请**更正登记**；登记权利人不同意更正的，利害关系人可申请**异议登记** |
| 预告登记 | 期待的物权变动条件缺乏或尚未成就（权利取得人只对未来取得物权享有请求权）时，为保护该请求权而进行的登记。**预告登记后，债权消灭或者自能够进行不动产登记之日起 90 日内未申请登记的，预告登记失效** |
| 查封登记 | 被执行人的不动产尚未办理登记手续，由执行法院提供生效判决书或执行裁定书及协助执行通知书，登记机构对权属直接登记后再予查封 |

**3. 变更登记与转移登记的区别**

| 对比项目 | 变更登记 | 转移登记 |
|---|---|---|
| 登记前后权利主体（**最本质区别**） | 权利主体**一致** | 权利主体**不一致** |
| 行为性质 | 不是权利转让行为 | 不动产**权利转让**行为 |
| 是否缴税 | 不需缴纳税款 | 应依法缴纳相关税款 |

### 考点04 所有权 ★★★

**1. 概念及法律特征**

| 项目 | 主要内容 |
|---|---|
| 概念 | 所有人对自己的不动产或动产依法享有**占有、使用、收益和处分**的权利，包括占有权、使用权、收益权、处分权。**处分权是所有权内容的核心，是拥有所有权的根本标志** |
| 法律特征 | ①**独占性**；②**全面性**——享有占有、使用、收益、处分的完整权利，是最完整全面的物权形式；但所有权人可将权能分离出去由他人享有行使 |

**2. 所有权的取得**（原始取得 + 继受取得）

| 取得方式 | 主要内容 |
|---|---|
| **原始取得** | 所有权首次产生或不依赖原所有人意志而取得：生产、孳息、先占、拾得遗失物、发现埋藏物、添附、**善意取得**等 |
| **继受取得** | 基于他人既有权利取得：买卖、赠与、继承、接受遗赠等 |

> 又如**接受遗赠**：受遗赠人按被继承人生前合法有效遗赠指定取得遗赠财产；**因其他合法原因取得所有权**：如合作经济组织成员通过合股集资形成新的所有权形式。

**3. 善意取得**（高频）

| 项目 | 具体含义 |
|---|---|
| "善意"的理解 | 继受取得以所有人行使处分权为前提；若属占有人的**无权处分**，受让人通常不能取得所有权。但受让人取得财产时**出于善意**，则依法取得所有权，原所有人只能请求占有人赔偿损失，不得要求受让人返还 |
| **善意取得三条件** | 无权处分人转让不动产或动产，所有权人有权追回；除法律另有规定外，符合下列情形受让人取得所有权：<br>（1）受让时是**善意**；<br>（2）以**合理的价格**转让；<br>（3）应当登记的**已经登记**，不需登记的**已经交付**给受让人 |
| 财产的界定 | 转让的动产必须是国家法律**允许自由流通**的财产；**枪支弹药、黄金、麻醉品**等禁止或限制流通物**不适用**善意取得；**货币和不记名证券**是特殊动产，谁持有谁即权利主体，因此**适用善意取得**；原所有权人有权向无处分权人请求损害赔偿；善意取得其他物权的参照适用 |

**4. 所有权的消灭**

- （1）**相对消灭**：因**物权主体**的原因而消灭（如转让、抛弃物权、权利人死亡等）。
- （2）**绝对消灭**：因**所有权客体**的原因而消灭（如标的物毁损或灭失）。

> **区分关键**：相对消灭—**主体**原因；绝对消灭—**客体**原因。

### 考点05 共有及业主建筑物区分所有权 ★

**共有**：两个或两个以上权利主体就同一财产共同享有所有权，分为**按份共有**和**共同共有**。

**（1）按份共有（分别共有）**

| 项目 | 主要内容 |
|---|---|
| 含义 | 共有人按各自份额分别对共有财产享有权利、承担义务，享有一定的**应有部分** |
| 应有部分确定 | ①基于当事人意思——**有约定，按约定**；②根据法律规定——**无约定，按法定**；③两者都不能确定——推定各共有人应有部分**均等** |
| 份额转让 | **不需经其他共有人同意**即可卖出自己应有部分，**同等条件**下其他共有人有**优先购买权**。转让应及时通知其他共有人，其他共有人在合理期限内行使；多人主张优先购买的，协商确定购买比例，协商不成按转让时各自共有份额比例行使 |

**（2）共同共有**

- 以共有人之间存在**共同关系**为前提（如**夫妻关系、家庭关系**）。
- 存续期间**不能确定份额**，只有共同关系终止、财产分割后才能确定；各共有人对整个共有财产享有**平等的**占有使用收益处分权，平等承担义务。
- 处分共同共有财产一般应经**全体共同共有人**同意（另有约定除外）。
- 形式：**夫妻共同财产**（出卖赠与须取得一致意见，离婚或一方死亡继承开始时才分割）、**家庭共有财产**（使用处分分割须征得全体家庭成员同意）、**遗产分割前的共有**（继承开始后分割前由全体继承人共有）。

**（3）共同共有和按份共有的区别**

| 区别项 | 按份共有 | 共同共有 |
|---|---|---|
| 成立前提 | **不以**共同关系存在为前提 | **以**共同关系存在为前提 |
| 享有的权利 | 对应有部分享有处分权，彼此限制相对较小 | 权利**及于共有物的全部**，不按应有部分享有，原则上须经全体同意方可使用收益 |
| 对共有物的管理 | 处分和重大修缮需获**占份额 2/3 以上共有人**同意；一般保存和简易修缮可单独进行 | 处分和重大修缮应获**全体共有人**同意（法律规定或约定除外） |
| 对第三人行使权利 | 各共有人基于应有部分可向第三人行使权利，也可为全体利益就共有物全部行使请求权 | 除非全体同意，**不得擅自处分共有财产**，也无向第三人转让共有份额的可能 |
| 分割的限制 | 除不能分割或约定不得分割期限外，**可随时请求分割** | —— |

**业主的建筑物区分所有权**：业主对**专有部分**（住宅、经营性用房）享有所有权，对**共有部分**享有共有和共同管理的权利，由**专有权和共有权**两方面构成。

| 项目 | 主要内容 |
|---|---|
| 专有部分 | 经区分分割出来、可由特定主体独立使用的部分（房屋） |
| 共有部分 | 不具独立使用功能的共用部分及附属设施（支柱、屋顶、外墙、地下室、楼梯、消防设备、走廊、水塔、自来水管等） |
| 专有部分权利 | 登记后具有与普通单独所有权相同效力，可行使完全的占有使用收益处分 |
| 共有部分权利 | 因专有与共有一体性，**业主行使权利不得危及建筑物安全，不得损害其他业主合法权益**；不得违反法律法规和管理规约将住宅改为经营性用房，即使遵守也**应当经有利害关系的业主同意** |
| 道路、绿地、车位 | 建筑区划内道路属业主共有（城镇公共道路除外）；绿地属业主共有（城镇公共绿地或明示属个人除外）；规划停车车位属业主共有 |
| 共有和共同管理权 | 对共有部分与共用设备设施行使管理权；共有和共同管理权**随业主对专有部分所有权的转让而一并转让** |

### 考点06 用益物权（素材未标星级）

**1. 概念、种类和法律特征**

- **种类**（五种）：①土地承包经营权；②建设用地使用权；③宅基地使用权；④居住权；⑤地役权。

| 法律特征 | 具体内容 |
|---|---|
| （1）具有独立性的他物权 | **不以他权利成立为前提**，不随他权利让与而让与、消灭而消灭；不具担保物权的从属性和不可分性 |
| （2）是**限制物权** | —— |
| （3）具有**使用的目的** | —— |
| （4）标的物主要是**不动产** | —— |

**2. 土地承包经营权**：对承包经营的耕地、林地、草地等享有占有、使用和收益的权利，是广大农民基本生活收入的来源和保障。法律特征：①**承包经营合同**是确认的主要依据；②主体是公民或集体组织；③客体为全民所有和集体所有的土地；④属**新型的用益物权**，保护方法既含物权方法也含债权方法。

**3. 宅基地使用权**

| 项目 | 主要内容 |
|---|---|
| 概念 | 公民在依法取得的宅基地上建造住宅及附属设施而享有的占有和使用权利 |
| 法律特征 | ①属用益物权，**宅基地所有权仍属集体所有**，国家和集体必要时可依法收回；②主体是**公民**，主要为农村集体经济组织成员；③客体主要是**集体所有**用于建造住宅及附属设施的土地；④须遵循**法定申请程序**、经批准后取得；⑤受法律保护，非法定程序不得任意剥夺 |

**4. 居住权**

| 项目 | 主要内容 |
|---|---|
| 概念 | 对他人所有的住房及附属设施占有、使用的权利。可根据**遗嘱或遗赠**，也可按**合同约定**设立；**无偿设立**（另有约定除外） |
| 法律特征 | 应向登记机构申请**居住权登记**，**居住权自登记时设立**；居住权**不得转让、继承**；设立居住权的住宅**不得出租**（另有约定除外）；期限届满或居住权人死亡时消灭，消灭应及时办理**注销登记** |

### 考点07 担保物权 ★★★

**1. 概念及法律特征**

**概念**：为确保债务清偿的目的，在债务人或第三人所有的物或所属权利上设定的、以取得担保作用的**限定物权**，以取得担保标的物的**交换价值**为实质内容。

| 五大法律特征 | 主要内容 |
|---|---|
| 具有**价值权性** | 以支配标的物的交换价值为内容，以担保债务清偿为目的 |
| 具有**法定性** | 以法律规定为限，当事人不得约定设定，也不得协议变更其发生要件和内容 |
| 具有**从属性** | 从属债权而存在，成立以债权成立为前提，因债权转移而转移、消灭而消灭 |
| 具有**不可分性** | 债权未全部清偿前可就担保物全部行使权利；非性质上不可分，**当事人可约定排除**其行使的不可分性 |
| 具有**物上代位性** | 担保物变为其他价值形态时支配效力及于变形物或代替物（如毁损灭失所获赔偿金成为代替物） |

> **妙记口诀：法定价从不分。**（法定性 / 价值权性 / 从属性 / 不可分性 / 物上代位性）

**2. 抵押权**

| 项目 | 主要内容 |
|---|---|
| 概念 | 债权人对债务人或第三人提供担保的财产**不转移占有**，在债务人不履行债务时依法就该财产**优先受偿**的权利 |
| 法律特征 | ①以债权关系发生存在为前提，目的是取得抵押物**交换价值**实现债权；②**不以占有为要件**，无须交付抵押物，不动产抵押登记是为确保权利存在、预防损害第三人；③债务人不清偿时对变价款**优先于无抵押权的债权人**受偿；同一抵押物上数个抵押权，**先成立的抵押权优先于后成立的** |
| 设定方式 | **法定抵押**：无须约定，发生法律规定情形自然设立（如"以建筑物抵押的，该建筑物占用范围内的建设用地使用权一并抵押；以建设用地使用权抵押的，土地上建筑物一并抵押"）。**意定抵押**：应采**书面形式**订立抵押合同；履行期限届满前约定债务人不履行则抵押财产归债权人所有的，**只能依法就抵押财产优先受偿** |

**3. 抵押财产**

| 项目 | 主要内容 |
|---|---|
| 抵押标的 | 应具**独立的交换价值**并能依法实现；具交换价值但禁止流通的财产不能作抵押物；须是**特定的财产**；实现途径是**折价、拍卖或变卖** |
| **可以抵押的财产** | ①建筑物和其他土地附着物；②建设用地使用权；③海域使用权；④生产设备、原材料、半成品、产品；⑤正在建造的建筑物、船舶、航空器；⑥交通运输工具；⑦法律、行政法规未禁止抵押的其他财产（可**一并抵押**） |
| **不得抵押的财产** | ①**土地所有权**；②宅基地、自留地、自留山等**集体所有土地的使用权**（法律规定可抵押的除外）；③学校、幼儿园、医疗机构等为**公益目的**成立的非营利法人的教育、医疗卫生和其他公益设施；④所有权、使用权**不明或有争议**的财产；⑤依法被**查封、扣押、监管**的财产；⑥法律、行政法规规定不得抵押的其他财产 |
| 需进行抵押登记的财产 | ①建筑物和其他土地附着物；②建设用地使用权；③海域使用权；④正在建造的建筑物。这些主要是**不动产，抵押权自登记时设立**；**以动产抵押的，抵押权自抵押合同生效时设立**，未经登记不得对抗善意第三人，也不得对抗正常经营活动中已支付合理价款并取得抵押财产的买受人 |

> **妙记口诀：集体所有为公益，不明争议查扣管。**（不得抵押：集体所有土地使用权 / 公益设施 / 权属不明或争议 / 查封扣押监管）

**4. 质权**

| 项目 | 主要内容 |
|---|---|
| 概念 | 债务人或第三人将其动产或财产权利证书**移转给债权人占有**作为担保，债务人不履行时债权人就该动产或权利价值优先受偿。提供质押财产的人称**出质人**，接受担保的人称**质权人**，质押财产称**质物** |
| 法律特征 | ①**设定必须移转占有**（还须依法办理登记的须登记），这是强制性规定，不允许约定不移转占有的质权；②**标的主要为动产或权利，不包括不动产**（不动产移转有严格法定程序，法律禁止在其上设质）；③具有**物上代位性、从属性和不可分性** |
| 质权分类 | **动产质权**：移交动产占有，债务人不履行时就动产价值优先受偿；**权利质权**：以财产权利为标的设定，**不动产不能成为权利质权标的，只能作抵押权标的** |
| 可以出质的权利 | ①汇票、本票、支票；②债券、存款单；③仓单、提单；④可转让的基金份额、股权；⑤可转让的注册商标专用权、专利权、著作权等知识产权中的财产权；⑥现有的及将有的应收账款；⑦法律、行政法规规定可出质的其他财产权利 |

**5. 留置权**

| 项目 | 主要内容 |
|---|---|
| 概念 | 债权人按合同约定占有债务人的动产，债务人不按期履行债务时，有权留置该动产并就折价或拍卖、变卖价款**优先受偿** |
| 法律特征 | 成立**无须双方当事人约定**，即使合同无约定也不影响，可直接基于法律规定行使，**是一种法定的担保物权**；同一动产上已设抵押权或质权、该动产又被留置的，**留置权人优先受偿**（体现法定担保物权与意定担保物权受偿顺序不同）；只能发生在**特定合同关系**中（保管、加工承揽等）；法律规定或当事人约定不得留置的动产不得留置 |

## 三、必背表格汇总

### 表1 物权 vs 债权

| 对比项 | 物权 | 债权 |
|---|---|---|
| 效力范围 | **绝对权（对世权）** | **相对权（对人权）** |
| 权利性质 | **支配权** | **请求权** |
| 设定 | **法定**（法定主义、须公示） | 意思表示、不具公示性 |
| 客体 | 一般是**物** | 直接指向**行为** |
| 特殊效力 | 有**追及效力和优先效力** | 无追及效力 |

### 表2 按份共有 vs 共同共有

| 区别项 | 按份共有 | 共同共有 |
|---|---|---|
| 成立前提 | 不以共同关系为前提 | **以共同关系为前提**（夫妻、家庭） |
| 份额 | 有**应有部分** | 存续期间**不能确定份额** |
| 处分/重大修缮 | 占份额 **2/3 以上**共有人同意 | **全体**共有人同意 |
| 份额转让 | 不需他人同意，他人有**优先购买权** | 不得擅自处分，无转让份额可能 |
| 分割 | 可随时请求分割 | 共同关系终止后才分割 |

### 表3 变更登记 vs 转移登记

| 对比项 | 变更登记 | 转移登记 |
|---|---|---|
| 权利主体（**最本质区别**） | **一致** | **不一致** |
| 行为性质 | 非权利转让 | 权利转让 |
| 是否缴税 | 不需缴税 | 应依法缴税 |

### 表4 抵押权 / 质权 / 留置权对比

| 对比项 | 抵押权 | 质权 | 留置权 |
|---|---|---|---|
| 是否移转占有 | **不转移占有** | **移转占有**（强制性） | 占有债务人动产 |
| 标的物 | 动产、不动产均可 | **动产或权利，不含不动产** | 仅**动产** |
| 设立依据 | 法定抵押 / 意定抵押 | 意定（约定） | **法定**（无须约定） |
| 生效时点 | 不动产自登记时设立；动产自合同生效时设立 | 移转占有（部分须登记） | 依法律规定成立 |
| 受偿顺序 | 先成立优先于后成立 | —— | 同一动产已设抵押/质权又被留置的，**留置权人优先受偿** |

### 表5 可抵押 / 不得抵押财产

| 可以抵押 | 不得抵押 |
|---|---|
| 建筑物和其他土地附着物 | **土地所有权** |
| 建设用地使用权 | 集体所有土地使用权（宅基地、自留地、自留山，法律规定可抵押除外） |
| 海域使用权 | 学校、幼儿园、医疗机构等**公益**设施 |
| 生产设备、原材料、半成品、产品 | 所有权、使用权**不明或有争议**的财产 |
| 正在建造的建筑物、船舶、航空器 | 依法被**查封、扣押、监管**的财产 |
| 交通运输工具 | 法律、行政法规规定不得抵押的其他财产 |
| 法律、行政法规未禁止抵押的其他财产 | —— |

> 记忆钩子：不得抵押——**集体所有为公益，不明争议查扣管**。

## 五、高频考点速记卡（问答式）

> 以下问答均据素材知识点自编，用于巩固易考数字与易混点，**非真题**。

1. **Q：物权与债权最核心的区别？** A：物权是**绝对权（对世权）、支配权、法定**，有**追及和优先效力**；债权是**相对权（对人权）、请求权**，无追及效力。口诀"法物配绝，优先追及"。

2. **Q：自物权等于什么？** A：**自物权即所有权**（只有所有权符合"支配范围全面、支配时间无限"），是最完整最充分、且**无期限**的物权。

3. **Q：物权法律制度的三项基本原则？** A：**物权法定原则、一物一权原则、物权公示原则**。

4. **Q：不动产统一登记由谁监督指导？纳入几类？** A：**国务院自然资源主管部门**；共**十类**（集体土地所有权、建筑物构筑物所有权、森林林木所有权、土地承包经营权、建设用地使用权、宅基地使用权、海域使用权、地役权、抵押权、其他需登记的不动产权利）。

5. **Q：预告登记多久内不申请登记就失效？** A：债权消灭或**自能够进行不动产登记之日起 90 日内**未申请登记的，预告登记失效。

6. **Q：变更登记与转移登记最本质的区别？** A：登记前后**权利主体**是否一致——变更**一致**、不缴税；转移**不一致**、属权利转让、应缴税。

7. **Q：所有权的核心权能是？** A：**处分权**是所有权内容的核心、拥有所有权的根本标志（所有权含占有、使用、收益、处分四权能）。

8. **Q：善意取得的三个条件？** A：①受让时**善意**；②以**合理价格**转让；③应登记的**已登记**、不需登记的**已交付**。

9. **Q：货币适用善意取得吗？枪支黄金麻醉品呢？** A：**货币和不记名证券适用**善意取得（谁持有谁即权利主体）；**枪支弹药、黄金、麻醉品**等禁止或限制流通物**不适用**。

10. **Q：所有权相对消灭与绝对消灭的分界？** A：**相对消灭因主体原因**（转让、抛弃、权利人死亡）；**绝对消灭因客体原因**（标的物毁损灭失）。

11. **Q：按份共有处分共有物需多少份额同意？共同共有呢？** A：按份共有需**占份额 2/3 以上**共有人同意；共同共有需**全体共有人**同意。

12. **Q：居住权何时设立？能否转让继承出租？** A：**自登记时设立**；**不得转让、不得继承**；设立居住权的住宅**不得出租**（另有约定除外）；一般**无偿设立**。

13. **Q：担保物权的五大特征？** A：**价值权性、法定性、从属性、不可分性、物上代位性**——口诀"法定价从不分"。

14. **Q：抵押权、质权是否移转占有？** A：**抵押权不转移占有**；**质权必须移转占有**（强制性规定，不允许约定不移转占有的质权）。

15. **Q：质权标的能否是不动产？** A：**不能**。质权标的主要为动产或权利，不含不动产；不动产只能作**抵押权**标的。

16. **Q：留置权是约定还是法定？受偿顺序如何？** A：**法定担保物权**，无须约定；同一动产已设抵押权或质权又被留置的，**留置权人优先受偿**。

17. **Q：不得抵押的财产有哪些？** A：土地所有权、集体所有土地使用权（法律规定可抵押除外）、公益设施、权属不明或有争议财产、被查封扣押监管财产、法律法规规定不得抵押的其他财产——"集体所有为公益，不明争议查扣管"。

## 六、典型真题

> **「真题未覆盖」声明**：本章素材**未附任何带年份的真题原文**。按内容纪律不编造真题。以下为**据本章知识点自编的巩固练习**，全部标注"**自编**"，仅供辨析训练，不代表历年真题。

**【自编·单选】**下列关于物权与债权的说法，正确的是（　）。
A. 物权是相对权，债权是绝对权　B. 物权具有追及效力和优先效力，债权不具有追及效力　C. 债权采用法定主义　D. 物权的客体一般是行为
**答案：B**　解析：物权是绝对权（对世权）、债权是相对权（对人权）；物权采法定主义；物权客体一般是物。

**【自编·单选】**预告登记后，自能够进行不动产登记之日起（　）日内未申请登记的，预告登记失效。
A. 30　B. 60　C. 90　D. 180
**答案：C**　解析：素材明确为 **90 日**。

**【自编·多选】**善意取得的构成条件包括（　）。
A. 受让人受让时是善意　B. 以合理的价格转让　C. 应登记的已经登记　D. 不需登记的已经交付　E. 经原所有人同意
**答案：ABCD**　解析：善意取得**三条件**为善意、合理价格、已登记/已交付；E 与善意取得（针对无权处分）相矛盾。

**【自编·单选】**下列财产中，**不得**抵押的是（　）。
A. 建设用地使用权　B. 海域使用权　C. 土地所有权　D. 交通运输工具
**答案：C**　解析：土地所有权不得抵押；口诀"集体所有为公益，不明争议查扣管"。

**【自编·单选】**关于质权的说法，正确的是（　）。
A. 质权的设定不需移转占有　B. 不动产可以设定质权　C. 质权的标的主要为动产或权利，不包括不动产　D. 质权是法定担保物权
**答案：C**　解析：质权设定必须移转占有；不动产不能设质，只能作抵押标的；质权是意定担保物权，留置权才是法定。

**【自编·单选】**同一动产上已设立抵押权或质权，该动产又被留置的，受偿顺序是（　）。
A. 抵押权人优先　B. 质权人优先　C. 留置权人优先受偿　D. 按成立先后
**答案：C**　解析：《民法典》规定留置权人优先受偿，体现法定担保物权优先于意定担保物权。

## 七、易错点与避坑指南

| # | 错在哪 | 正解 |
|---|---|---|
| 1 | 把自物权、他物权都当所有权 | **自物权＝所有权**（只有所有权符合全面无限支配）；他物权是在**他人**标的物上的限定物权 |
| 2 | 认为货币不适用善意取得 | **货币和不记名证券适用**善意取得（谁持有谁即权利主体） |
| 3 | 把枪支、黄金、麻醉品当作可善意取得 | 禁止或限制流通物**不适用**善意取得 |
| 4 | 认为质权不必移转占有 / 可设在不动产上 | 质权**必须移转占有**（强制性），**标的不含不动产**，不动产只能抵押 |
| 5 | 把留置权当作需约定的意定担保物权 | 留置权**无须约定，是法定担保物权**，直接基于法律成立 |
| 6 | 混淆抵押权与质权是否移转占有 | **抵押权不移占有；质权移占有** |
| 7 | 把变更登记与转移登记的分界记错 | 最本质区别是**权利主体是否一致**：变更一致、转移不一致 |
| 8 | 把处分权以外的权能当作所有权核心 | **处分权是核心**，是拥有所有权的根本标志 |
| 9 | 按份共有处分份额认为要全体同意 | 按份共有转让份额**不需他人同意**，他人仅有**优先购买权**；处分共有物需**2/3以上**份额同意 |
| 10 | 把土地所有权、公益设施当可抵押 | 二者**不得抵押**；"集体所有为公益，不明争议查扣管" |
| 11 | 认为居住权可转让、继承、出租 | 居住权**不得转让、继承**，住宅**不得出租**（约定除外），**自登记设立** |
| 12 | 把宅基地使用权理解为可取得所有权 | 宅基地**所有权仍属集体**，使用权人不因占有使用而取得所有权 |
| 13 | 认为担保物权不可分性不能排除 | 不可分性**当事人可约定排除** |
| 14 | 把相对/绝对消灭主客体原因搞反 | 相对消灭—**主体**原因；绝对消灭—**客体**原因 |

## 八、本章数字速记

| 数字 | 考点 |
|---|---|
| **90** 日 | 预告登记：债权消灭或自能登记之日起90日内未申请，预告登记失效 |
| **十** 类 | 纳入不动产统一登记范围的物权（集体土地所有权……抵押权等） |
| **3** 个条件 | 善意取得：善意 + 合理价格 + 已登记/已交付 |
| **2/3** 以上份额 | 按份共有处分和重大修缮需占份额2/3以上共有人同意 |
| **4** 项权能 | 所有权：占有、使用、收益、**处分**（处分为核心） |
| **5** 大特征 | 担保物权：价值权性、法定性、从属性、不可分性、物上代位性（"法定价从不分"） |
| **5** 种用益物权 | 土地承包经营权、建设用地使用权、宅基地使用权、居住权、地役权 |
| **3** 项基本原则 | 物权法定、一物一权、物权公示 |
| **5** 组分类标准 | 自物/他物、用益/担保、主/从、法定/意定、有期限/无期限 |
| **1** 类无期限物权 | **所有权**（有期限：抵押权、质权、留置权） |

> **口诀总集**：物权特征"**法物配绝，优先追及**"；担保物权五特征"**法定价从不分**"；不得抵押财产"**集体所有为公益，不明争议查扣管**"。
